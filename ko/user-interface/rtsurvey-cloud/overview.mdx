![rtCloud 홈페이지](/images/rtsurvey-cloud-home.webp)

rtCloud는 데이터 수집, 관리 및 분석을 간소화하도록 설계된 rtSurvey 생태계의 강력한 서버 구성 요소입니다. rtSurvey 운영의 중앙 허브로서 rtCloud는 복잡한 설문 프로젝트 및 종단 연구를 지원하는 종합적인 기능 세트를 제공합니다.

## 주요 기능

### 프로젝트 관리
- 한 곳에서 설문 프로젝트의 모든 측면을 구성합니다
- 각 프로젝트 내에서 사용자 역할, 양식, 분석, 산출물 및 권한을 관리합니다

### 사용자 관리 및 보안
- 역할 기반 권한으로 사용자 계정을 만들고 관리합니다
- 모든 수준에서 데이터 보안 및 접근 제어를 보장합니다

### 양식 관리
- XLSForm을 직접 업로드하고 관리합니다
- 소규모 조정 및 구조적 변경을 포함한 양식 버전 업데이트 지원
- 양식에 멀티미디어 또는 추가 데이터를 첨부합니다
- 설문 도구에 대한 완전한 제어를 위한 진정한 양식 삭제 기능

### 데이터 수집 및 제출 관리
- rtSurvey 모바일 앱, 웹 앱 및 웹양식과 원활한 통합
- 인증된 사용자 제출 및 익명 공개 링크 모두 지원
- 제출 멀티미디어 및 데이터 첨부 처리
- 빠른 통찰을 위한 제출 데이터의 대화형 테이블 미리 보기

### 고급 제출 워크플로
- 추가 편집 또는 검증을 위해 제출을 사용자 기기로 반환
- 협업 워크플로 및 품질 관리를 위해 다른 기기로 제출 전달

### 종단 데이터 관리
- 반복 측정 및 장기 연구를 효율적으로 처리합니다
- 시간에 따른 참가자 데이터의 변경 및 업데이트를 추적합니다

### 유연한 연결성
- 양식 다운로드 및 제출 업로드를 위해 rtSurvey 모바일 앱 연결 허용
- 연결이 복원되면 원활하게 동기화되는 오프라인 데이터 수집 지원

## rtCloud의 차별점

다른 데이터 수집 플랫폼에서 영감을 받았지만 rtCloud는 돋보이는 고유한 기능을 제공합니다:

1. **진정한 양식 삭제**: 일부 플랫폼과 달리 rtCloud는 필요할 때 양식의 완전한 제거를 허용합니다.

2. **유연한 제출 워크플로**: 제출을 반환하고 전달하는 기능은 복잡한 데이터 검토 및 품질 관리 프로세스를 가능하게 합니다.

3. **통합 프로젝트 관리**: rtCloud는 양식 및 데이터 관리를 넘어 설문 프로젝트의 모든 측면을 구성하는 도구를 제공합니다.

4. **직접 XLSForm 지원**: 변환 없이 XLSForm을 직접 업로드하여 양식 생성 프로세스를 간소화합니다.

5. **종합 권한 시스템**: 프로젝트 내 사용자 접근 및 기능에 대한 세부적인 제어.

## rtCloud 시작하기

설문 프로젝트에 rtCloud를 사용하기 시작하려면:

1. rtCloud 서버를 설정하거나 호스팅 솔루션은 rtSurvey에 문의하세요.
2. 첫 번째 프로젝트를 만들고 팀원을 초대합니다.
3. XLSForm을 업로드하고 데이터 수집 워크플로를 구성합니다.
4. rtSurvey 모바일 앱을 연결하고 데이터 수집을 시작합니다.

rtCloud는 연구자, 조직 및 데이터 수집 팀이 복잡한 설문 프로젝트를 용이하고, 안전하고, 유연하게 관리할 수 있도록 합니다. 일회성 설문이든 다년간의 종단 연구든 rtCloud는 성공에 필요한 도구를 제공합니다.

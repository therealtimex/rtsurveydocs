**제출 관리** 모듈(양식 패밀리 섹션의 **데이터 보기** 버튼을 통해 접근)은 프로젝트 관리자와 감독자가 들어오는 원시 데이터와 직접 상호 작용할 수 있게 합니다. 조사원 제출을 검토하고, 기기 식별자를 추적하고, 데이터 품질 작업을 수행하는 통합 작업 공간입니다.

![제출 관리 인터페이스](/images/manage_submissions.png)

## 데이터 개요 및 열

데이터 그리드는 특정 양식에 대해 수집된 데이터를 동적으로 표시합니다. **공식**(최종 레코드) 및 **작업 중**(실시간, 미완성 레코드)이라는 두 가지 주요 모드로 운영됩니다.

### 주요 데이터 열

양식에 정의된 사용자 지정 질문에 관계없이 그리드에는 감사를 돕기 위한 몇 가지 표준 메타데이터 열이 포함됩니다:

- **제출 방법:** 제출의 출처 플랫폼 식별(예: FA - 현장 앱, WEB - 웹양식, RS - 원격 시스템).
- **세부 정보:** 해당 인스턴스에 대해 제출된 모든 변수 및 답변을 검사하기 위한 집중된 단일 레코드 보기(검색 아이콘).
- **iNote:** 수집된 데이터 자체를 변경하지 않고 감독자가 특정 레코드에 측면 메모나 내부 코멘트를 첨부할 수 있습니다(연필 아이콘으로 표시).
- **날짜 필드:** 레코드가 시작, 완료 또는 동기화된 시간을 나타내는 타임스탬프.
- **미디어 첨부:** 설문 중 수집된 이미지, 서명 또는 파일에 대한 직접 썸네일 링크.
- **반복 그룹:** 부모 양식 내의 반복 질문에 대한 중첩 테이블에 접근하기 위한 전용 링크.

## 제출 작업

적극적인 데이터 품질 관리를 용이하게 하기 위해 인터페이스는 선택된 레코드에서 실행할 수 있는 작업 가능한 명령의 드롭다운 메뉴를 제공합니다:

- **새 인스턴스 만들기:** 관리자가 데이터베이스에 새 설문 레코드를 수동으로 직접 입력할 수 있습니다.
- **인스턴스 반환:** 제출된 레코드를 거부하고 조사원에게 정보를 재확인하거나 재수집하도록 지시합니다.
- **인스턴스 팔로우업:** 추가 주의를 위해 레코드를 플래그 처리하며, 일반적으로 현장 팀에 명확화 알림을 발송합니다.
- **반환 명령 파일 / 팔로우업 명령 패키지로 내보내기:** 반환 또는 팔로우업으로 표시된 데이터셋을 포함하는 파일을 포함하는 일괄 내보내기를 생성합니다.
- **XML로 변환:** 구조화된 데이터셋을 백엔드 분석 또는 시스템 통합을 위한 원시 XML 형식으로 변환합니다.
- **인스턴스 전달:** (*작업 중* 모드에서 사용 가능) 미완성 데이터를 즉시 다른 기기 또는 사용자에게 전달합니다.
- **삭제:** 선택된 인스턴스를 데이터베이스에서 영구적으로 제거합니다.

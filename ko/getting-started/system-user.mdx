# 시스템 사용자 관리

**시스템 사용자** 모듈(`/cpms/cpmsSystemUser/admin`)은 실시간 설문 플랫폼(RT-CPMS)에 대한 접근 권한 및 수행 가능한 작업을 제어하기 위한 종합 관리 인터페이스입니다.

![시스템 사용자 인터페이스](/images/system_user.png)

## 통합 관리 방식

RT-CPMS에서 **조사원**은 시스템 사용자에게 할당된 특정 역할에 불과합니다. 별도의 "조사원" 데이터베이스는 없습니다. 웹 포털을 모니터링하는 고위 관리자든 모바일 앱으로 데이터를 수집하는 현장 조사원이든, 모든 사용자는 이 단일 통합 프레임워크 내에서 관리됩니다.

## 주요 기능

### 1. 사용자 디렉토리 및 그리드 뷰
메인 인터페이스에는 작업 공간에 연결된 모든 사용자의 페이지 매김 목록이 표시됩니다. 주요 속성은 다음과 같습니다:
* **조직 ID 및 이름**: 특정 조직 개체 아래 사용자의 논리적 그룹화(예: `rta`, `partner_org`).
* **역할**: 사용자의 권한 수준 지정(예: `Administrator`, `Leadteam`, `Enumerator`).
* **그룹**: 공간적 또는 논리적 그룹화 할당(예: 특정 지역 또는 운영 팀).
* **동기화 여부**: 계정이 중앙 SSO(싱글 사인온) 시스템과 성공적으로 통합되었는지 여부 표시.
* **상태**: 계정이 `활성`, `비활성`, `삭제됨` 또는 `차단됨`인지 확인하는 시각적 표시기.

**전역 작업:**
* **시스템 사용자 추가**: 개별 프로필을 수동으로 생성.
* **시스템 사용자 가져오기**: Excel 템플릿을 사용하여 계정을 일괄 업로드. `건너뛰기` 또는 `교체` 모드를 사용하여 충돌을 해결하고 SSO와 직접 동기화할 수 있습니다.
* **일괄 삭제**: 일괄 계정 제거를 위한 다중 선택 지원.

### 2. 접근 제어 및 보안
사용자 프로필을 생성하거나 편집할 때 여러 중요한 보안 및 워크플로 필드를 사용할 수 있습니다:
* **사용자 코드**: 로컬 CPMS 계정을 중앙 SSO 리포지토리에 연결하는 고유 식별자.
* **기기 변경 코드**: 조사원이 데이터 수집에 사용하는 모바일 기기를 전환해야 할 때 필요한 강력한 보안 토큰.
* **권한 수준**: 0(최저)에서 20(최고)까지의 세분화된 우선순위/접근 척도.
* **감독 토글**: 표준 사용자를 즉시 관리 상태로 높이는 체크박스.
* **워크플로 자동화**: "편집 요청 자동 승인" 옵션으로 신뢰할 수 있는 사용자에 대한 데이터 정제 및 검증 프로세스를 간소화.

### 3. 코드 관리 (자동 온보딩)
"코드" 하위 탭에서 찾을 수 있으며, 대규모 팀의 온보딩 프로세스를 간소화하는 해시 기반 등록 및 초대 링크를 관리합니다.

* **등록 vs. 초대**: 사용자가 배포된 링크를 사용하여 자가 등록할 수 있는지, 아니면 직접 관리자 초대가 필요한지 선택.
* **만료 날짜**: 온보딩을 특정 시간 창으로 제한.
* **사용 제한**: 단일 생성 코드를 사용하여 참여할 수 있는 사용자 수 제한.
* **사전 할당 역할**: 이 코드를 통해 참여하는 사용자는 미리 정의된 역할 및 권한 수준을 자동으로 상속하여 수동 관리자 개입 없이 즉시 작업 준비 완료.

XLSForm 및 rtSurvey의 geoshape 질문 유형은 응답자가 지도에 도형 (폴리곤)을 그려 복잡한 지리 데이터를 캡처할 수 있게 합니다. 이 기능은 공간 설문에서 지역을 매핑하거나, 경계를 정의하거나, 관심 영역을 표시할 때 특히 유용합니다.

## 기본 XLSForm 사양

| type     | name        | label                           |
|----------|-------------|--------------------------------|
| geoshape | field_area  | 밭의 경계를 그리세요  |

기본 geoshape 질문 유형에 대한 자세한 내용은 [XLSForm 사양](https://xlsform.org/en/#question-types)을 참조하세요.

## 용도

Geoshape 질문은 일반적으로 다음 용도로 사용됩니다:

1. 농업 설문에서 밭 경계 매핑
2. 환경 영향 지역 정의
3. 도시 계획 연구에서 구역 표시
4. 지질 조사를 위한 지역 윤곽 그리기
5. 공간 분석을 위한 복잡한 지리적 특징 캡처

## 모범 사례

1. 기기에서 위치 서비스가 활성화되어 있고 권한이 부여되어 있는지 확인합니다.
2. 도형을 그리는 방법과 어떤 지역을 포함해야 하는지에 대한 명확한 지침을 제공합니다.
3. 응답자가 정확하게 도형을 그릴 수 있도록 위성 이미지 또는 기본 지도 사용을 고려합니다.
4. 도형의 잠재적 복잡성과 데이터 크기 및 처리에 미치는 영향에 주의합니다.

## 예시 사용

설문에서 geoshape 질문을 사용하는 방법의 예시입니다:

| type     | name           | label                                      | hint                                        |
|----------|----------------|--------------------------------------------|--------------------------------------------|
| geoshape | forest_area    | 삼림 지대의 경계를 그리세요   | 닫힌 도형을 만들기 위해 최소 3개의 점을 사용하세요 |

## rtSurvey 확장

geoshape 질문에 대한 기본 XLSForm 사양은 간단하지만, rtSurvey는 추가 기능이나 사용자 정의를 제공할 수 있습니다:

1. 원격 지역을 위한 오프라인 지도 통합
2. 도형의 최소 및 최대 점 수 설정 옵션
3. 초기 그리기 후 도형을 편집하거나 수정하는 기능
4. 자유형 폴리곤 외에도 다른 도형 유형 (예: 직사각형, 원) 지원

## 데이터 형식

Geoshape 데이터는 일반적으로 세미콜론으로 구분된 좌표 쌍 문자열로 저장됩니다:

```
(lat1 lon1; lat2 lon2; lat3 lon3; ... latN lonN)
```

예시:
```
(38.253094215699576 21.756382658677467; 38.25021274773806 21.756382658677467; 38.25007793942195 21.763892843919166; 38.25290886154963 21.763935759263404; 38.253094215699576 21.756382658677467)
```

## 분석을 위한 고려 사항

geoshape 질문을 사용할 때는 다음을 고려합니다:

1. 지리 데이터를 시각화하고 분석하는 방법 (예: GIS 소프트웨어)
2. 복잡한 도형의 데이터 정리 또는 단순화의 잠재적 필요성
3. 상세한 공간 데이터 처리를 위한 개인 정보 보호 및 데이터 보호 조치
4. 포괄적인 분석을 위한 다른 공간 데이터 소스와의 통합

## 제한 사항

- 작은 모바일 화면에서 정확한 도형을 그리는 것은 어려울 수 있습니다.
- 복잡한 도형은 상당한 저장 및 처리 용량이 필요할 수 있습니다.
- Geoshape 질문은 모든 유형의 설문이나 응답자에게 적합하지 않을 수 있습니다.
- 상세한 공간 데이터 수집과 관련된 개인 정보 보호 우려가 있을 수 있습니다.

XLSForm 및 rtSurvey의 geopoint 질문 유형은 기기의 GPS 또는 기타 위치 서비스를 사용하여 지리적 좌표를 수집할 수 있게 합니다. 이 기능은 설문 응답을 지도에 표시하거나, 현장 활동의 위치를 확인하거나, 데이터를 특정 위치와 연결할 때 특히 유용합니다.

## 기본 XLSForm 사양

| type     | name        | label                           |
|----------|-------------|--------------------------------|
| geopoint | location    | 현재 위치를 기록하세요     |

기본 geopoint 질문 유형에 대한 자세한 내용은 [XLSForm 사양](https://xlsform.org/en/#question-types)을 참조하세요.

## 용도

Geopoint 질문은 일반적으로 다음 용도로 사용됩니다:

1. 설문 응답을 지리적으로 지도에 표시
2. 현장 활동의 위치 확인
3. 조사원의 경로 추적
4. 환경 또는 사회 데이터를 특정 위치와 연결
5. 지리 분석에서 거리 또는 면적 계산

## 모범 사례

1. 기기에서 위치 서비스가 활성화되어 있고 권한이 부여되어 있는지 확인합니다.
2. GPS가 정확한 신호를 얻을 수 있도록 충분한 시간을 허용합니다.
3. 개인 정보 보호 문제를 고려하고 응답자에게 위치 데이터 수집에 대해 알립니다.
4. 위치 데이터에 맥락을 제공하기 위해 다른 질문 유형과 함께 사용합니다.

## 예시 사용

설문에서 geopoint 질문을 사용하는 방법의 예시입니다:

| type     | name           | label                                      | hint                                        |
|----------|----------------|--------------------------------------------|--------------------------------------------|
| geopoint | sample_location| 샘플 수집 위치를 기록하세요 | 더 나은 GPS 신호를 위해 개방된 지역에 서 주세요 |

## rtSurvey 확장

geopoint 질문에 대한 기본 XLSForm 사양은 간단하지만, rtSurvey는 추가 기능이나 사용자 정의를 제공할 수 있습니다:

1. 캡처된 위치를 시각적으로 확인할 수 있는 지도 통합
2. 정확도 임계값 설정
3. 좌표를 수동으로 입력하는 옵션
4. 원격 지역을 위한 오프라인 지도 통합

## 데이터 형식

Geopoint 데이터는 일반적으로 공백으로 구분된 네 개의 값으로 저장됩니다:

```
위도 경도 고도 정확도
```

예시:
```
41.40338 2.17403 30.5 10
```

## 분석을 위한 고려 사항

geopoint 질문을 사용할 때는 다음을 고려합니다:

1. 지리 데이터를 시각화하는 방법 (예: 지도 소프트웨어)
2. 수집된 좌표의 정확도와 분석에 미치는 영향
3. 위치 데이터 처리를 위한 개인 정보 보호 및 데이터 보호 조치
4. GIS (지리 정보 시스템) 도구와의 잠재적 통합

## 제한 사항

- 정확도는 기기 및 환경 조건에 따라 달라질 수 있습니다.
- 실내 위치나 장애물이 있는 지역에서는 GPS 신호가 약하거나 사용할 수 없을 수 있습니다.
- 위치 데이터를 수집하면 기기 배터리 수명에 상당한 영향을 줄 수 있습니다.
- 정밀한 위치 데이터 수집과 관련된 개인 정보 보호 우려가 있을 수 있습니다.

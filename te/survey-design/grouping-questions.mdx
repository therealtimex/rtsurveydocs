XLSForm లో సమూహాలు మీకు సంబంధిత ప్రశ్నలను కలిసి నిర్వహించడానికి అనుమతిస్తాయి, మీ సర్వే నిర్మాణాన్ని మెరుగుపరుస్తాయి మరియు డేటా విశ్లేషణ సామర్థ్యాలను పెంచుతాయి. rtSurvey XLSForm సమూహాలకు పూర్తిగా మద్దతు ఇస్తుంది మరియు అదనపు ఫీచర్‌లతో వాటి కార్యాచరణను విస్తరిస్తుంది.

## ప్రాథమిక సమూహ నిర్మాణం

ప్రశ్నల సమూహం సృష్టించడానికి, `begin_group` మరియు `end_group` సింటాక్స్ ఉపయోగించండి:

```
| type         | name       | label                                    |
|--------------|------------|------------------------------------------|
| begin_group  | respondent | ప్రతిస్పందించే వ్యక్తి సమాచారం           |
| text         | name       | ప్రతిస్పందించే వ్యక్తి పేరు ఎంటర్ చేయండి    |
| text         | position   | ప్రతిస్పందించే వ్యక్తి స్థానం ఎంటర్ చేయండి |
| end_group    |            |                                          |
```

ముఖ్య అంశాలు:
- `begin_group` వరుసకు `name` మరియు `label` అవసరం.
- `end_group` వరుసకు పేరు లేదా లేబుల్ అవసరం లేదు.
- `begin_group` మరియు `end_group` మధ్య ప్రశ్నలు సమూహంలో భాగం.

## సమూహ అపీరెన్స్

rtSurvey సమూహాలకు వివిధ అపీరెన్స్ ఎంపికలకు మద్దతు ఇస్తుంది:

1. **field-list**: ఒకే స్క్రీన్‌లో బహుళ ప్రశ్నలు ప్రదర్శిస్తుంది.
2. **grid**: సమూహాలకు కాంపాక్ట్, పట్టిక-వంటి layout సృష్టిస్తుంది (rtSurvey-నిర్దిష్టం).
3. **collapsible**: విస్తరించదగిన/మడవగలిగే సమూహాలు సృష్టిస్తుంది (rtSurvey-నిర్దిష్టం).

## నెస్టెడ్ సమూహాలు

మరింత సంక్లిష్ట నిర్మాణాల కోసం సమూహాలు ఇతర సమూహాల లోపల నెస్ట్ చేయవచ్చు. సరైన నెస్టింగ్ నిర్వహించడానికి ఎల్లప్పుడూ ఇటీవలి ప్రారంభించిన సమూహాన్ని మొదట ముగించండి.

## సమూహాలకు స్కిప్ లాజిక్

మొత్తం సమూహాలకు స్కిప్ లాజిక్ అమలు చేయడానికి `relevant` కాలమ్ ఉపయోగించండి.

## సమూహాలు ఉపయోగించడంలో ఉత్తమ పద్ధతులు

1. డేటా విశ్లేషణను మెరుగుపరచడానికి సమూహాలకు అర్థవంతమైన పేర్లు ఉపయోగించండి.
2. సమూహాలను సంబంధిత ప్రశ్నలపై దృష్టి కేంద్రీకరించండి.
3. అతిగా సంక్లిష్టమైన నిర్మాణాలు నివారించడానికి నెస్టెడ్ సమూహాలను వివేకంగా ఉపయోగించండి.
4. సమూహాలపై `relevant` ఉపయోగించేటప్పుడు స్కిప్ లాజిక్ సమగ్రంగా పరీక్షించండి.
5. స్క్రోలింగ్ తగ్గించడానికి చిన్న సమూహాలకు `field-list` అపీరెన్స్ ఉపయోగించండి.
6. సంబంధిత సమాచారం కాంపాక్ట్‌గా ప్రదర్శించడానికి rtSurvey యొక్క grid layout ఉపయోగించండి.
7. పొడవైన ఫారాల నావిగేషన్ మెరుగుపరచడానికి collapsible సమూహాలు ఉపయోగించండి.

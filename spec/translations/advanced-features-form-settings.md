## Summary of changes
New page. Documents the `formSetting.csv` per-form behavior override file. Covers: purpose (per-form override of global collect config), file format (6 columns: type, name, value, disable, note, description), how to include (upload as family media with exact filename `formSetting.csv`), full settings reference table (22 settings: change_language, save_mid, jump_to, autosend_wifi, autosend_network, hide_incomplete_button, show_welcome_screen, show_final_screen, show_required_asterisk, navigation, buttons, navigation_swipe_up_down_left_right, font_size, disable_screen_off, disable_fullscreen, access_settings, validate_form, long_press_remove_answer, long_press_remove_repeat, change_fontsize, disable_screen_navigation, disable_swipe), example CSV, explanation of disable column behavior (locks in app UI vs still-editable default).

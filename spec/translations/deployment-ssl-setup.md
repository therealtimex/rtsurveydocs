## Summary of changes
Option 1 (Free rtsurvey.com subdomain) was significantly expanded:
- Added `ssl-setup-form.png` screenshot before the steps
- Added account activation notice (requires active account at licenses.rtsurvey.com)
- Added step to paste the rtSurvey DNS Token from licenses.rtsurvey.com
- Renamed button label from "Create https://[subdomain].rtsurvey.com" to "Create secure subdomain"
- Added `ssl-setup-progress.png` screenshot showing the provisioning progress screen
- Added explanation of the 4 automatic provisioning steps (Requesting DNS record → Waiting for DNS to propagate → Issuing SSL certificate → Activating HTTPS)

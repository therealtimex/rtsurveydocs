O aplicativo móvel rtSurvey oferece um conjunto abrangente de recursos projetados para otimizar o processo de pesquisa. Aqui estão as principais funcionalidades:

## Preencher formulário
O recurso Preencher formulário é onde os entrevistadores podem acessar e inserir dados em formulários de pesquisa em branco. Esta funcionalidade permite coleta de dados eficiente e precisa no campo. Os principais pontos incluem:

1. Listagem de formulários: Ao acessar a seção Preencher formulário, os usuários visualizam uma lista de todos os formulários em branco disponíveis atribuídos a eles.

2. Download automático de formulários: Diferentemente de algumas outras ferramentas de pesquisa, o aplicativo móvel rtSurvey baixa automaticamente os formulários aos quais o usuário tem acesso, concedido pelo administrador da pesquisa ou gerente de projeto. Isso elimina a necessidade de os entrevistadores recuperarem manualmente formulários em branco.

3. Entrada direta de dados: Os entrevistadores podem selecionar um formulário da lista e começar a inserir as respostas da pesquisa diretamente no aplicativo.

4. Atualizações em tempo real: À medida que novos formulários são atribuídos ou atualizações são feitas, a lista de formulários disponíveis é automaticamente atualizada, garantindo que os entrevistadores sempre tenham acesso às pesquisas mais recentes.

5. Capacidade off-line: Os formulários podem ser baixados quando a conectividade com a internet está disponível, permitindo que os entrevistadores os preencham mesmo em áreas com cobertura de rede fraca ou inexistente.

## Editar formulário

A funcionalidade Editar formulário no rtSurvey oferece uma abordagem abrangente e flexível para gerenciar instâncias de pesquisa, diferenciando-o de outras aplicações CAPI. Este recurso garante a precisão e integridade dos dados por meio de três abas distintas:

1. **Salvo**:
   - Acesse e modifique instâncias de entrevistas incompletas salvas no dispositivo do entrevistador.
   - Semelhante aos aplicativos CAPI tradicionais, permitindo que os usuários retomem e concluam pesquisas inacabadas.

2. **Retornado** (exclusivo do rtSurvey):
   - Edite instâncias de pesquisa que foram previamente concluídas, finalizadas e enviadas ao servidor.
   - Exclusivo do rtSurvey, este recurso permite edições pós-envio quando informações adicionais ou correções são necessárias.

3. **Encaminhado** (exclusivo do rtSurvey):
   - Acesse e edite instâncias de pesquisa originalmente criadas em outro dispositivo.
   - Este recurso inovador suporta vários cenários:
     * Supervisores podem revisar e editar envios de entrevistadores.
     * Os usuários podem continuar o trabalho em um dispositivo diferente se o dispositivo original for perdido ou danificado.
     * Habilita processos de edição colaborativa e controle de qualidade.

Principais benefícios:
- Qualidade de dados aprimorada por meio de múltiplas oportunidades de revisão e edição.
- Maior flexibilidade de fluxo de trabalho para equipes de campo e supervisores.
- Continuação perfeita do trabalho entre dispositivos, reduzindo o tempo de inatividade e os riscos de perda de dados.


## Enviar formulário
Envie formulários 100% concluídos ao servidor central. Este recurso permite transmissão de dados em tempo real, possibilitando análise e tomada de decisão imediatas.

## Notificações
Receba avisos e atualizações importantes do servidor. Isso mantém todos os membros da equipe informados sobre desenvolvimentos do projeto, mudanças ou assuntos urgentes.

## Tarefas
Acesse e gerencie tarefas atribuídas pelo servidor. Este recurso ajuda a organizar a carga de trabalho e priorizar as atividades de pesquisa para os entrevistadores de campo.

## Relatórios
Visualize todos os relatórios enviados do servidor para o tablet. Esta funcionalidade permite que os usuários acessem resultados de análises e insights do projeto diretamente no seu dispositivo.

## Revisar formulário

A funcionalidade Revisar formulário no rtSurvey oferece um sistema abrangente para examinar e gerenciar instâncias de pesquisa finalizadas, garantindo controle de qualidade e verificação de dados robustos. Este recurso é dividido em quatro abas distintas, cada uma servindo a um propósito específico no processo de gerenciamento de dados:

1. **Finalizado**:
   - Contém instâncias concluídas e finalizadas que ainda não foram enviadas ao servidor.
   - Permite verificações finais antes do envio.

2. **Enviado**:
   - Contém instâncias finalizadas que foram enviadas com sucesso ao servidor.
   - Fornece um registro dos dados transmitidos.

3. **Transferido**:
   - Exibe instâncias concluídas que foram transferidas para outros dispositivos.
   - Facilita o rastreamento da movimentação de dados entre dispositivos.

4. **Recebido**:
   - Mostra instâncias concluídas originalmente criadas em outro dispositivo e transferidas para o dispositivo atual.
   - Permite trabalho colaborativo e compartilhamento de dados entre membros da equipe.

Principais funcionalidades:
- **Acesso somente para visualização**: Todas as instâncias nessas abas são inicialmente somente para visualização, preservando a integridade dos dados de formulários finalizados.
- **Sistema de solicitação de edição**: Os usuários podem solicitar a edição de uma instância se correções forem necessárias.
  - As solicitações podem ser aprovadas automática ou manualmente por Administradores ou Gerentes de projeto.
  - Uma vez aprovada, a instância se torna editável, permitindo as modificações necessárias.

Benefícios:
- Melhora a qualidade dos dados por meio de múltiplas etapas de revisão.
- Fornece um histórico de auditoria claro de envios e transferências de dados.
- Oferece flexibilidade no gerenciamento de dados enquanto mantém o controle sobre os dados finalizados.
- Suporta fluxos de trabalho colaborativos e processos de garantia de qualidade.

Este sistema avançado de Revisão de formulário distingue o rtSurvey ao oferecer uma abordagem estruturada para gerenciar dados finalizados, garantindo precisão e permitindo edições controladas pós-finalização quando necessário. Ele equilibra a integridade dos dados com a necessidade de correções ocasionais, tornando-o uma ferramenta inestimável para projetos de pesquisa que exigem altos níveis de qualidade e responsabilidade dos dados.

## Mapa
Utilize a funcionalidade GPS para identificar a localização exata onde a entrevista está sendo realizada. Este recurso melhora a precisão dos dados e auxilia na análise espacial dos resultados da pesquisa.

## Sair
Feche o aplicativo sem sair da conta do rtSurvey. Isso permite uma rápida entrada no aplicativo sem a necessidade de autenticação repetida.

Essas funcionalidades trabalham em conjunto para criar uma poderosa ferramenta de pesquisa móvel e fácil de usar, que atende a vários papéis dentro do processo de pesquisa, desde a coleta de dados até análise e gerenciamento de projetos.

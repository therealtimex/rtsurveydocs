O rtSurvey suporta integração de mídia rica em pesquisas, permitindo aprimorar seus questionários com imagens, áudio e vídeo. Este recurso pode melhorar significativamente a experiência do respondente e a qualidade dos dados coletados.

## Tipos de mídia suportados

O rtSurvey suporta os seguintes tipos de mídia:
- Imagens (jpg, png, gif)
- Áudio (mp3, wav)
- Vídeo (mp4, webm)

## Adicionando mídia à sua pesquisa

Para incluir mídia no seu formulário rtSurvey, use as seguintes colunas no seu XLSForm:

- `image`: Para exibir imagens
- `audio`: Para reproduzir arquivos de áudio
- `video`: Para reproduzir arquivos de vídeo

Exemplo:

```
| type | name          | label         | image        | audio       | video       |
|------|---------------|---------------|--------------|-------------|-------------|
| note | media_example | Exemplo de mídia | exemplo.jpg | som.mp3  | clipe.mp4   |
```

## Gerenciamento de arquivos de mídia

### Pesquisas baseadas na web
Para pesquisas baseadas na web, o rtSurvey fornece uma interface de gerenciamento de mídia onde você pode fazer upload e organizar seus arquivos de mídia. Esses arquivos ficam automaticamente disponíveis para uso em suas pesquisas.

### Aplicativo móvel
Ao usar o aplicativo móvel rtSurvey:
1. Coloque seus arquivos de mídia na pasta `/rtSurvey/forms/[nome-do-formulário]-media/` no seu dispositivo.
2. Referencie o nome exato do arquivo no seu XLSForm.

## Recursos específicos do rtSurvey

### Carregamento dinâmico de mídia
O rtSurvey suporta carregamento dinâmico de mídia com base nas respostas da pesquisa:

```
| type         | name      | label               | image                    |
|--------------|-----------|---------------------|--------------------------|
| select_one species | animal | Selecione um animal | ${animal}.jpg           |
```

### Mídia nas opções de escolha
O rtSurvey permite usar mídia nas opções de escolha para perguntas de seleção:

```
| type                | name    | label            | media::image |
|---------------------|---------|------------------|--------------|
| select_one_from_file animals | Escolha um animal |           |
```

Na planilha choices:
```
| list_name | name  | label    | media::image |
|-----------|-------|----------|--------------|
| animals   | dog   | Cachorro | cachorro.jpg |
| animals   | cat   | Gato     | gato.jpg     |
```

### Captura de mídia
O rtSurvey estende o XLSForm com capacidades de captura de mídia:

```
| type  | name        | label               |
|-------|-------------|---------------------|
| image | photo       | Tire uma foto       |
| audio | voice_note  | Grave uma nota de voz|
| video | video_clip  | Grave um vídeo      |
```

## Práticas recomendadas para usar mídia

1. **Otimize os tamanhos dos arquivos**: Arquivos de mídia grandes podem diminuir o carregamento e o envio da pesquisa.
2. **Use formatos apropriados**: Use formatos amplamente suportados (jpg para imagens, mp3 para áudio, mp4 para vídeo).
3. **Forneça alternativas**: Sempre inclua alternativas de texto para acessibilidade.
4. **Teste minuciosamente**: Garanta que a mídia seja exibida corretamente em todos os dispositivos de destino.
5. **Considere o uso off-line**: Para pesquisas que podem ser realizadas off-line, garanta que toda a mídia esteja disponível localmente.

## Suporte de mídia multilíngue

O rtSurvey suporta mídia específica por idioma. Use o sufixo `::idioma`:

```
| type | name  | label    | image::Português | image::English |
|------|-------|----------|------------------|----------------|
| note | intro | Bem-vindo| boas_vindas_pt.jpg| welcome_en.jpg|
```

## Mídia na exportação de dados

Ao exportar dados do rtSurvey:
- Para pesquisas web, as URLs de mídia são incluídas na exportação.
- Para pesquisas no aplicativo móvel, os caminhos de arquivo são incluídos.

## Considerações sobre aplicativo móvel

- Garanta espaço de armazenamento suficiente nos dispositivos para pesquisas com muita mídia.
- O aplicativo móvel rtSurvey suporta reprodução e captura de mídia off-line.
- Arquivos de mídia grandes podem impactar o desempenho do aplicativo em dispositivos de baixo custo.

## Limitações conhecidas

- Alguns navegadores mais antigos podem não suportar todos os formatos de mídia.
- Arquivos de vídeo muito grandes podem causar problemas em situações de baixa largura de banda.

## Solução de problemas de mídia

1. **Mídia não exibindo**: Verifique os caminhos e nomes de arquivo para precisão.
2. **Problemas de reprodução**: Garanta que o formato de mídia seja suportado pelos dispositivos de destino.
3. **Carregamento lento**: Considere otimizar os tamanhos dos arquivos ou pré-carregar a mídia.

## Recursos avançados de mídia

### Geotagging
O rtSurvey pode adicionar automaticamente geotags à mídia capturada durante as pesquisas:

```
| type  | name        | label        | appearance |
|-------|-------------|--------------|------------|
| image | photo       | Tire uma foto| geotag     |
```

### Anotações de mídia
Permita que os respondentes anotem imagens:

```
| type  | name        | label          | appearance |
|-------|-------------|----------------|------------|
| image | photo       | Anote a imagem | annotate   |
```

Ao usar mídia de forma eficaz nos seus formulários rtSurvey, você pode criar pesquisas mais envolventes, informativas e precisas. Lembre-se de equilibrar os benefícios da inclusão de mídia com as considerações de desempenho, especialmente para pesquisas implantadas em áreas com conectividade limitada à internet ou em dispositivos de baixo custo.

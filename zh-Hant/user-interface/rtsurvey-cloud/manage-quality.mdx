**管理品質**模組（可從儀表板存取）提供即時分析和空間視覺化，以監控資料收集進度和調查員績效。它為專案管理員提供分割視圖介面，可在個別問卷和自訂分析報告之間快速切換。

![管理品質儀表板](/images/manage_quality.png)

## 儀表板概覽

管理品質儀表板分為兩個主要導航標籤：**表單**和**報告**。此橫向選單讓使用者可以有效地搜尋和選取他們想分析的特定資料集或報告。

### 表單分析

從清單中選取特定表單時，儀表板提供多個內建視覺化工具來追蹤提交品質和頻率：

- **按開始時間計數：** 視覺化一段時間內啟動訪談頻率的長條圖。
- **按結束時間計數：** 視覺化訪談完成時間的長條圖。
- **按提交日期計數：** 追蹤每日同步至伺服器的資料量。
- **按使用者名稱計數：** 根據總提交次數識別績效最佳調查員的長條圖。
- **訪談地圖：** 地理散點圖（由 Leaflet 提供支援），顯示每次提交發生地點的 GPS 座標，讓管理員可以驗證現場工作地點。

### 自訂報告

**報告**標籤提供對預先設定的 R Markdown 分析設計和其他自訂統計的存取。一旦選取報告，主視圖區域會透過嵌入式查看器動態載入生成的分析，從而對收集的資料進行更深入的統計驗證。

## 搜尋和篩選

側邊欄清單上方提供快速搜尋欄，讓使用者可以按名稱快速找到特定表單或報告。

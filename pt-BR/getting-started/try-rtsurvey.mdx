Experimente o rtSurvey sob diferentes perspectivas usando nossas contas de demonstração. Cada conta está configurada com funções específicas para demonstrar as funcionalidades e permissões associadas a cada tipo de usuário em um projeto de pesquisa CAPI.

### Administrador de demonstração
- **Nome de usuário:** admin_demo
- **Senha:** AdminRtSurvey
- **Função:** Acesso completo a todas as configurações do sistema, gerenciamento de usuários e configurações de projeto.

### Gerente de projeto de demonstração
- **Nome de usuário:** pm_demo
- **Senha:** PMRtSurvey
- **Função:** Gerenciar projetos, atribuir tarefas e supervisionar a implantação da pesquisa e a coleta de dados.

### Designer de pesquisa de demonstração
- **Nome de usuário:** designer_demo
- **Senha:** DesignerRtSurvey
- **Função:** Projetar e testar pesquisas usando o editor XLSForm e o construtor visual de formulários do rtSurvey.

### Entrevistador de campo de demonstração
- **Nome de usuário:** enumerator_demo
- **Senha:** EnumeratorRtSurvey
- **Função:** Realizar pesquisas de campo usando o aplicativo móvel rtSurvey, coletar dados e sincronizar com o rtSurvey Cloud.

### Analista de dados de demonstração
- **Nome de usuário:** analyst_demo
- **Senha:** AnalystRtSurvey
- **Função:** Analisar dados coletados, gerar relatórios e integrar com ferramentas de análise externas como Excel, Power BI, Python e R.

## Como usar as contas de demonstração

1. **Selecione uma função:**
   Escolha a função de demonstração que deseja explorar na lista acima.

2. **Entre no sistema:**
   Use o nome de usuário e a senha fornecidos para entrar no rtSurvey.

3. **Explore as funcionalidades:**
   Navegue pela plataforma para entender as funcionalidades disponíveis para a função selecionada.

4. **Feedback:**
   Valorizamos sua opinião! Forneça feedback sobre sua experiência para nos ajudar a melhorar o rtSurvey.

## Diretrizes de segurança e uso

- Estas são contas de demonstração compartilhadas. Por favor, não insira informações sensíveis ou pessoais.
- As contas de demonstração têm acesso limitado para garantir a segurança dos dados e prevenir uso indevido.
- O uso das contas de demonstração é monitorado para manter a integridade do sistema.

Ao usar essas contas de demonstração, você pode obter uma compreensão abrangente de como o rtSurvey funciona para diferentes funções de usuário em um projeto de pesquisa CAPI. Explore como o rtSurvey pode beneficiar suas necessidades de coleta e análise de dados em várias etapas da implementação de pesquisas.

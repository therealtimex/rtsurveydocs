ម៉ូឌុល **Manage Forms** ដើរ តួ ជា gateway ចម្បង សម្រាប់ ការ organize instruments ស្ទង់មតិ រប ស់ អ្នក ហើយ ការ coordinate ភារ កិច្ច fieldwork។ វា ផ្ដល់ ការ គ្រប់ គ្រង ដ៏ ល្អ ឡើង ចំពោះ ការ ចូល ដំណើរ ការ ទម្រង់, ការ ស្វែង មើល ទិន្ន ន័យ, ហើយ ការ target ឧបករណ៍។

![Form Management Interface](/images/manage_forms.png)

## Form Family Overview

នៅ ក្រោម menu **Form & Data Entry**, ផ្នែក **Form Family** បង្ហាញ grid ដ៏ ទូ លំ ទូ លាយ នៃ ទម្រង់ ដែល imported ទាំង អស់ ជា មួយ quick-access controls ដ៏ ចាំ បាច់។ ទ ស្សន ៈ centralized នេះ អនុញ្ញាត ឱ្យ project managers ដាក់ ពង្រាយ ហើយ configure ស្ទង់ មតិ ម្នាក់ ៗ ឆាប់ ។

### Data Columns & Configuration Options សំខាន់ ៗ

- **Data View:** ចូល ដំណើរ ការ records ដែល submitted ហើយ previews dataset ដោយ ផ្ទាល់ សម្រាប់ ទម្រង់ ម្នាក់ ៗ។
- **Allow Edit:** toggle ឆាប់ ដើម្បី lock ឬ unlock សមត្ថ ភាព workers ស្រុក ក្នុង ការ edit ទិន្ន ន័យ ដែល submitted (Active/Inactive statuses)។
- **Public Visibility:** toggle ដើម្បី ធ្វើ ឱ្យ ទម្រង់ accessible publicly ដោយ មិន ត្រូវ ការ authentication enumerator។
- **Webform's URL:** ទៅ ដណ្ដើម link public តែ មួយ គត់ ដើម្បី ចែក រំ លែក ទម្រង់ ប្រ មូ ល ទិន្ន ន័យ ដែលប ណ្ដ ាះ browser។
- **Override Settings:** modal configurations advanced (ចូល ដំណើរ ការ តាម cog icon) សម្រាប់ ការ tailor rules ជាក់ លាក់ ទម្រង់, values, ហើយ disable features ជាក់ លាក់។
- **Form Identifiers:** មើល metadata ស្ដង់ ដា រ រួម ទាំង Form Family name, Family Code, ហើយ Form ID តែ មួយ គត់ ។
- **Lock Form:** Feature ដើម្បី lock ការ ចូល submission ទៅ finalizing phase ប្រ មូ ល ទិន្ន ន័យ។

## Form Actions and Navigation

top control panel សំ ប ត ា ទំ យ batch operations ហើយ form views ជំ ន ួ ស:

- **Action to Device:** drop-down tool ដ៏ មាន ឥទ្ធ ភ ល ដែ ល អ នុ ញ្ញ ា ត project managers ចា ត់ ចែ ង ភារ កិច្ច, ផ្ញើ ទម្រ ង់ target ឬ dispatch actions ដោ យ ផ្ទ ា ល់ ទៅ ឧ ប ករណ ់ ស្ រ ុ ក ជ ាក ់ ល ា ក ់ ។
- **XLSX Form Tab:** navigate ឆ ា ប់ ពី main management grid ទ ៅ upload environments ស ម្ រ ា ប ់ ដ ំ ណ ើ រ ការ ឯ កស ា រ XLSForm native ថ ្ ម ី ។
- **Form Builder Tab:** ចូ ល ដំ ណ ើ រ ការ ឧ ប ករណ ់ built-in ស ម្ រ ា ប ់ ការ ស ា ង ទ ម្ រ ង ់ ដ ោ យ ភ្ ន ែ ក ឬ ការ ក ែ ប ្ រ ែ ទ ម្ រ ង ់ ដ ោ យ dynamic ដ ោ យ គ ្ ម ា ន ការ ប ្ រ ើ software spreadsheet ខ ា ង ក ្ រ ោ ម ។

rtSurvey គឺជាវេទិកាដ៏មានឥទ្ធិពលសម្រាប់បង្កើតទម្រង់បែបបទ និងលំហូរការងារដើម្បីប្រមូលទិន្នន័យប្រកបដោយប្រសិទ្ធភាព។ ជាមួយ rtSurvey អ្នកអាច៖

1. បង្កើតទម្រង់បែបបទដ៏ចម្រូងចម្រាស ដោយរួមបញ្ចូលរូបថត ទីតាំង GPS តក្កវិជ្ជាលាតសន្ធឹង ការគណនា ឯកសារទិន្នន័យខាងក្រៅ ភាសាច្រើន និងច្រើនទៀត។
2. ប្រមូលទិន្នន័យដោយប្រើទាំងកម្មវិធីទូរស័ព្ទ ឬចំណុចប្រទាក់វេប ជាមួយការធ្វើសម្រួលដោយស្វ័យប្រវត្តិ នៅពេលមានការភ្ជាប់អ៊ីនធឺណិត។
3. វិភាគទិន្នន័យដោយងាយ ដោយនាំចេញទៅ CSV ឬ Stata ឬដោយភ្ជាប់ rtSurvey ទៅ Excel, Power BI, Python, ឬ R សម្រាប់ផ្ទាំងព័ត៌មានជាបន្តបន្ទាប់ ដែលធ្វើបច្ចុប្បន្នភាព។

អ្នកស្រាវជ្រាវ ក្រុមការងារស្រុក និងអ្នកជំនាញក្នុងឧស្សាហកម្មផ្សេងៗ ពឹងផ្អែកលើ rtSurvey សម្រាប់តម្រូវការប្រមូលទិន្នន័យសំខាន់របស់ពួកគេ។ នេះជារបៀបចាប់ផ្តើម៖

## ១. ចូលប្រើ rtSurvey Cloud {#getting-started-get-rtCloud}

វិធីរហ័សបំផុតដើម្បីចាប់ផ្តើម គឺប្រើ [rtSurvey Cloud](https://rtsurvey.com/#rtsurvey-cloud) សេវាខ្នាតអ្នកគ្រប់គ្រងផ្លូវការរបស់យើង។ វាអាចចូលដំណើរការបាននៅគេហទំព័រ rtSurvey ហើយត្រូវបានបង្កើតនៅលើហេដ្ឋារចនាសម្ព័ន្ធដែលរឹងមាំ មានសុវត្ថិភាព។ ជាជម្រើស អ្នកអាចធ្វើ host rtSurvey នៅលើហេដ្ឋារចនាសម្ព័ន្ធផ្ទាល់ខ្លួនប្រសិនបើចង់បាន។

## ២. បង្កើតទម្រង់ស្ទង់មតិរបស់អ្នក {#getting-started-create-form}

1. រចនាទម្រង់របស់អ្នកដោយប្រើ `XLSForm` ឬប្រើគំរូ [ទម្រង់ All Widgets](https://docs.google.com/spreadsheets/d/1af_Sl8A_L8_EULbhRLHVl8OclCfco09Hq2tqb9CslwQ/edit#gid=0) របស់យើង។
2. ផ្ទុក XLSForm របស់អ្នកទៅ rtSurvey Cloud ហើយបោះពុម្ភផ្សាយ ឬប្រើ Form Builder (Beta) របស់យើង សម្រាប់បទពិសោធន៍រចនាដោយភ្នែក។

## ៣. ដំឡើងកម្មវិធី rtSurvey {#getting-started-get-collect}

ទាញយកកម្មវិធី rtSurvey នៅលើឧបករណ៍ទូរស័ព្ទរបស់អ្នក៖

### សម្រាប់ឧបករណ៍ Android:
1. ចូលទៅ [Google Play Store](https://play.google.com/store/apps/details?id=vn.rta.rtsurvey)។
2. ស្វែងរក "rtSurvey" ហើយចុចលើកម្មវិធីដែលមានស្លាក rtSurvey។
3. ចុច "ដំឡើង" ដើម្បីទាញយក និងដំឡើងកម្មវិធី។

### សម្រាប់ឧបករណ៍ iOS:
1. បើក [App Store](https://apps.apple.com/vn/app/rtsurvey/id1178851547) នៅលើឧបករណ៍របស់អ្នក។
2. ស្វែងរក "rtSurvey" ហើយស្វែងរកកម្មវិធីដែលមានស្លាក rtSurvey។
3. ចុច "ទទួលបាន" ដើម្បីទាញយក និងដំឡើងកម្មវិធី។

## ៤. ភ្ជាប់កម្មវិធី rtSurvey ទៅ rtSurvey Cloud {#getting-started-connect}

1. បង្កើតគណនី៖
   - អ្នកគ្រប់គ្រង rtSurvey Cloud អាចបង្កើតគណនីសម្រាប់អ្នកបំពេញ។
   - ជាជម្រើស អ្នកគ្រប់គ្រងអាចបង្កើត URL សម្រាប់អ្នកបំពេញ ដើម្បីបង្កើតគណនីផ្ទាល់ខ្លួនរបស់ពួកគេ។
2. បើកកម្មវិធី rtSurvey ហើយចូលដោយប្រើព័ត៌មានអត្តសញ្ញាណគណនីរបស់អ្នក។

## ៥. ធ្វើការស្ទង់មតិរបស់អ្នក {#getting-started-fill-form}

1. នៅក្នុងកម្មវិធី ជ្រើស "បំពេញទម្រង់ទទេ" ដើម្បីចាប់ផ្តើមការស្ទង់មតិថ្មី។
2. បំពេញទម្រង់ជាមួយទិន្នន័យអ្នកឆ្លើយតប។
3. នៅពេលបញ្ចប់ ទិន្នន័យទម្រង់នឹងធ្វើសម្រួលដោយស្វ័យប្រវត្តិជាមួយ rtSurvey Cloud នៅពេលមានការភ្ជាប់អ៊ីនធឺណិត។

## ៦. វិភាគទិន្នន័យរបស់អ្នកនៅក្នុង rtSurvey Cloud {#getting-started-use-data}

1. ចូលទៅ rtSurvey Cloud ដើម្បីចូលដំណើរការទិន្នន័យដែលប្រមូលបានរបស់អ្នក។
2. ទាញយកទិន្នន័យរបស់អ្នកក្នុងទម្រង់ផ្សេងៗ ដូចជា CSV ឬ Stata សម្រាប់ការវិភាគបន្ថែម។
3. ប្រើឧបករណ៍វិភាគដែលភ្ជាប់ ឬរួមបញ្ចូលជាមួយកម្មវិធីវិភាគទិន្នន័យដែលអ្នកចូលចិត្ត។

Il modulo **Gestione qualità** (accessibile tramite il Dashboard) fornisce analisi in tempo reale e visualizzazioni spaziali per monitorare l'avanzamento della raccolta dati e le prestazioni degli intervistatori. Offre ai responsabili di progetto un'interfaccia con vista divisa per passare rapidamente tra singoli questionari e report analitici personalizzati.

![Dashboard Gestione qualità](/images/manage_quality.png)

## Panoramica del Dashboard

Il dashboard di Gestione qualità è suddiviso in due schede di navigazione principali: **Moduli** e **Report**. Questo menu laterale consente agli utenti di cercare ed selezionare in modo efficiente il dataset specifico o il report che desiderano analizzare.

### Analisi dei moduli

Quando si seleziona un modulo specifico dall'elenco, il dashboard fornisce più strumenti di visualizzazione integrati per monitorare la qualità e la frequenza degli invii:

- **Conteggio per orario di inizio:** Un grafico a barre che visualizza la frequenza delle interviste avviate nel tempo.
- **Conteggio per orario di fine:** Un grafico a barre che visualizza quando le interviste sono state completate.
- **Conteggio per data di invio:** Traccia il volume giornaliero dei dati sincronizzati con il server.
- **Conteggio per nome utente:** Un grafico a barre che identifica gli intervistatori con le migliori prestazioni in base al numero totale di invii.
- **Mappa delle interviste:** Un grafico a dispersione geografico (basato su Leaflet) che mostra le coordinate GPS di dove è avvenuto ogni invio, permettendo ai responsabili di verificare le ubicazioni del lavoro sul campo.

### Report personalizzati

La scheda **Report** consente l'accesso a progettazioni analitiche R Markdown pre-configurate e altre statistiche personalizzate. Una volta selezionato un report, l'area di visualizzazione principale carica dinamicamente l'analisi generata tramite un visualizzatore incorporato, consentendo una verifica statistica più approfondita dei dati raccolti.

## Ricerca e filtraggio

Una barra di ricerca rapida è disponibile sopra l'elenco della barra laterale, consentendo agli utenti di trovare rapidamente moduli o report specifici per nome.

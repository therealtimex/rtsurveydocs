# システムダッシュボード

ダッシュボード（`/cpms/cpmsDashBoard/indexNew`）は、リアルタイム調査プラットフォーム（RT-CPMS）の管理コマンドセンターおよびメインランディングページとして機能します。

![System Dashboard Preview](/images/dashboard_overview.png)

調査管理者がアクティブなプロジェクトの概要を即座に把握し、重要なツールへのクイックリンクと、すべての主要プラットフォームモジュールを横断してナビゲートするための一元化されたハブを提供するように設計されています。

## 主な機能

### 1. プロジェクトとフォームの選択
左側のパネルには**フォームとレポート**のナビゲーターが含まれています。このエリアにはワークスペース内のすべてのアクティブな調査がリストアップされています。
* 特定の調査（例：*RTA - SURVEY 02*）を選択することで、ダッシュボードはそのプロジェクトのみに焦点を当てた監視と指標を表示します。

### 2. 可視化と指標フィルター
プロジェクトリストの上部では、リアルタイムのフィールドワーク進捗を監視するためにいくつかの重要なデータ視点を切り替えることができます：
* **開始時間/終了時間別のカウント**：調査員が調査セッションを開始・完了している時間を追跡する。
* **提出日別のカウント**：サーバーに届くデータの全体的な日次量を監視する。
* **ユーザー名別のカウント**：個々の調査員の生産性とパフォーマンスを評価する。
* **インタビューの地図**：空間的なカバレッジ要件が満たされているかを確認するために、調査回答が収集されている場所のGIS地理的分布を表示する。

### 3. アプリケーションポータル
ダッシュボードの中央はデータ収集インターフェースへの即時アクセスを提供します。調査員のハードウェアに応じて、以下にアクセスまたは案内できます：
* **Webアプリ**：ブラウザベースのデータ収集用。
* **Androidアプリ**：Google PlayストアまたはAPKへのリンク。
* **iOSアプリ**：Apple App Storeへのリンク。

### 4. 直接モジュールショートカット
3つの目立つアクションボタンにより、最も頻繁に使用される運用モジュールへの迅速な移行が可能です：
* **フォームとデータ入力**：収集データの手動管理に直接ジャンプする。
* **分析とレポート**：ビジネスインテリジェンス（BI）スイートを開き、調査回答をクロス集計してグラフ化する。
* **権限設定**：アクティブな調査へのアクセス権と各自のロールを調整する。

### 5. グローバルナビゲーションサイドバー
折りたたみ可能な左サイドバーは、RT-CPMSバックエンドモジュールの完全なエコシステムへのアクセスを提供します。ここから以下を詳しく確認できます：
* **設定**：スタッフとアクティブデバイスの管理。
* **フィールドワーク管理**：調査員の日々の活動追跡。
* **品質保証**：QAルールとフラグの実装・レビュー。
* **最終成果物**：クリーニング済みデータセットをCSV、PDF、またはStataにエクスポートする。

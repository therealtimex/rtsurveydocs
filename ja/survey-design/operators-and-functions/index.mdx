rtSurveyの式は**XPath 1.0**のサブセットで書かれ、JavaRosa/ODK関数とカスタムrtSurvey関数で拡張されています。XLSFormの`calculate`、`constraint`、`relevant`、`required`、`default`列で式を使用します。

## フィールド値の参照

`${fieldname}`を使って別のフィールドの現在の値を参照する：

```
${age} > 18
```

`.`（1つのドット）を使って**現在のフィールドの値**を参照する — `constraint`式でよく使われます：

```
. >= 0 and . <= 100
```

`..`を使って親グループを参照する（繰り返し内の高度な使用法）。

## 式の構文

式は標準的なXPathルールに従います：

- **文字列**は一重引用符で囲む必要がある：`'yes'`
- **数値**はそのまま記述：`42`、`3.14`
- **Boolean**の結果は`relevant`、`required`、`constraint`に使用される — 空でない非ゼロの値は真とみなされる
- 演算子の周りの空白は無視される

<Warning>
常に直線の引用符（`'`または`"`）を使用してください — 「スマートクォート」（カーリークォート）は絶対に使用しないでください。リッチテキストエディターは引用符を自動的に変換することが多く、式が壊れます。
</Warning>

## クイック例

| ユースケース | 式 |
|----------|------------|
| 年齢が18歳以上の場合に表示 | `${age} > 18` |
| 「はい」が選択された場合のみ表示 | `${consent} = 'yes'` |
| 別のフィールドが空でない場合に必須 | `${name} != ''` |
| 合計を計算する | `${adults} + ${children}` |
| 名前を連結する | `concat(${first_name}, ' ', ${last_name})` |
| 今日の日付 | `today()` |
| オプションが選択されているか確認する | `selected(${interests}, 'sports')` |

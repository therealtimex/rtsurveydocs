XLSFormおよびrtSurveyのbarcode質問タイプは、調査内でバーコードデータを直接スキャンして取得できます。この機能は、在庫管理、製品追跡、またはコード化された情報の迅速で正確なデータ入力が必要なあらゆるシナリオに特に便利です。

## 基本XLSForm仕様

| type    | name          | label                   |
|---------|---------------|-------------------------|
| barcode | product_code  | 製品バーコードをスキャンしてください|

基本的なbarcode質問タイプの詳細については、[XLSForm仕様](https://xlsform.org/en/#question-types)を参照してください。

## 用途

Barcode質問は一般的に以下に使用されます：

1. 在庫調査での製品識別
2. フィールド業務での資産追跡
3. イベントでのチケットやIDの確認
4. コード化された情報の迅速なデータ入力

## rtSurveyの拡張機能

XLSFormのbarcode質問タイプの基本仕様は簡単ですが、rtSurveyは追加の機能やカスタマイズを提供する場合があります：

1. 複数のバーコード形式のサポート（例：QRコード、UPC、EAN）
2. バーコードスキャンのためのデバイスカメラとの統合
3. バーコードが損傷しているか読み取れない場合の手動入力オプション

## ベストプラクティス

1. 正確なバーコードスキャンのために適切な照明条件を確保してください。
2. スキャンのためのデバイスの位置について明確な指示を提供してください。
3. スキャンが困難な場合のフォールバックとして手動入力オプションを含めてください。
4. 調査をデプロイする前に、さまざまなデバイスとバーコードタイプでバーコードスキャン機能をテストしてください。

## 制限事項

- バーコードスキャンの精度は、デバイスのカメラ品質と環境条件によって異なる場合があります。
- 一部の古いまたは低スペックのデバイスはバーコードスキャンをサポートしていない場合があります。
- 特定のバーコードタイプは、実装によってサポートされていない場合があります。

## 使用例

在庫調査でbarcode質問を使用する例を示します：

| type    | name          | label                   | hint                                      |
|---------|---------------|-------------------------|-------------------------------------------|
| barcode | product_code  | 製品バーコードをスキャンしてください| バーコードをフレーム内に配置してください     |
| integer | quantity      | 製品数量を入力してください  |                                           |
| note    | confirmation  | スキャンされた製品：${product_code}。数量：${quantity} |           |

この例では、調査は製品のバーコードを取得し、数量を尋ね、スキャンされた情報を含む確認ノートを表示します。

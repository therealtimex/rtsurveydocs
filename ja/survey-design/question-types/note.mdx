XLSFormおよびrtSurveyのnote質問タイプは、調査回答者に読み取り専用のテキストやメディアを表示するために使用されます。回答が必要な質問ではなく、調査内で情報、指示、またはコンテキストを提供する方法です。

## 基本XLSForm仕様

| type | name | label |
|------|------|-------|
| note | info_text | この調査はあなたの読書習慣についてのものです。 |

基本的なnote質問タイプの詳細については、[XLSForm仕様](https://xlsform.org/en/#question-types)を参照してください。

## 用途

Note質問は一般的に以下に使用されます：

1. 次の質問に対する指示やコンテキストの提供
2. 計算結果やサマリーの表示
3. 画像やその他のメディアの表示
4. 調査のセクションの区切り
5. 以前の回答に基づくフィードバックの提供

## ベストプラクティス

1. 回答者のエンゲージメントを維持するために、ノートのテキストは簡潔で明確にしてください。
2. 重要な情報を強調するために書式（太字、斜体）を使用してください。
3. 適切な場合は理解を高めるためにメディア（画像、音声）の使用を検討してください。
4. 調査を乱雑にしないようにノートは控えめに使用してください。

## 使用例

調査でnote質問を使用する例を示します：

| type | name | label |
|------|------|-------|
| note | intro | 読書習慣調査へようこそ。あなたの好みと読書頻度についてお伺いします。 |
| ... | ... | ... |
| calculate | books_per_month | ${fiction_books} + ${non_fiction_books} |
| note | reading_summary | あなたは月に約${books_per_month}冊の本を読んでいます。 |

この例では、調査を紹介し計算結果のサマリーを提供するためにノートを使用しています。

## 高度な使用法

### 条件付き表示

relevance式を使用してノートを条件付きで表示できます：

| type | name | label | relevant |
|------|------|-------|----------|
| note | high_reader_note | あなたは熱心な読書家です！ | ${books_per_month} > 5 |

### 計算の組み込み

ノートには動的なフィードバックを提供するための計算を含めることができます：

| type | name | label |
|------|------|-------|
| note | reading_time | あなたの回答に基づくと、毎月約${books_per_month * 5}時間読書に費やしています。 |

## 制限事項

- ノートはデータを収集しないため、回答者から情報を収集する必要がある場合には使用しないでください。
- ノートを過剰に使用すると調査が雑然とした、または長すぎると感じられる場合があります。
- 一部の高度な書式やメディアオプションは、すべてのデバイスまたはプラットフォームでサポートされていない場合があります。

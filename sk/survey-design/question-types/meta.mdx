Typy meta otázok sú špeciálne polia, ktoré sú vyplnené **automaticky** — respondent ich nikdy nevidí. Zachytávajú kontext odoslania: kedy bolo zozbierané, ktoré zariadenie bolo použité a kto ho zozbieralo. Pridajte ich do hárku `survey` rovnako ako akýkoľvek iný typ otázky; jednoducho sa nezobrazujú na obrazovke.

## Základná špecifikácia XLSForm

| type | name | label |
|------|------|-------|
| start | start | |
| end | end | |
| deviceid | deviceid | |

Popisky sú pre meta polia voliteľné, keďže sa nikdy nezobrazujú.

---

## Meta polia načasovania

### `start`

Zaznamenáva **dátum a čas otvorenia formulára**. Uložené vo formáte ISO 8601 (`YYYY-MM-DDTHH:MM:SS.sss+HH:MM`).

```
type    | name  | label
start   | start |
```

### `end`

Zaznamenáva **dátum a čas odoslania formulára**. Spolu so `start` môžete vypočítať čas strávený vypĺňaním formulára:

```
type      | name          | calculation
calculate | duration_min  | (decimal-date-time(${end}) - decimal-date-time(${start})) * 1440
```

### `today`

Zaznamenáva **aktuálny dátum** (bez časovej zložky). Uložené ako `YYYY-MM-DD`. Užitočné, keď potrebujete iba dátum bez celého časového razítka.

```
type  | name  | label
today | today |
```

---

## Meta polia zariadenia

### `deviceid`

Zaznamenáva **jedinečný identifikátor zariadenia** použitého na zber dát. Na Androide je to typicky IMEI alebo Android ID. Užitočné na sledovanie, ktoré zariadenie odoslalo každý formulár, a na detekciu duplicitných odoslaní z rovnakého zariadenia.

```
type      | name     | label
deviceid  | deviceid |
```

### `devicephonenum`

Zaznamenáva **telefónne číslo SIM karty** v zariadení (ak je dostupné). Môže byť prázdne, ak zariadenie nemá SIM alebo ak číslo nie je uložené na SIM.

```
type           | name          | label
devicephonenum | devicephonenum |
```

### `simserial`

Zaznamenáva **sériové číslo SIM karty** (ICCID). Užitočné na identifikáciu, ktorá SIM/operátor bol použitý.

```
type      | name      | label
simserial | simserial |
```

### `subscriberid`

Zaznamenáva **IMSI (International Mobile Subscriber Identity)** — jedinečný identifikátor predplatiteľa na SIM karte.

```
type         | name        | label
subscriberid | subscriberid |
```

---

## Meta polia anketára

### `username`

Zaznamenáva **používateľské meno prihláseného anketára** (účet použitý v aplikácii rtSurvey). Toto je najspoľahlivejší spôsob sledovania, kto zozbieralo každé odoslanie.

```
type     | name     | label
username | username |
```

### `email`

Zaznamenáva **e-mailovú adresu prihláseného anketára**.

```
type  | name  | label
email | email |
```

### `phonenumber`

Zaznamenáva **telefónne číslo priradené k účtu anketára** (ak je nakonfigurované).

```
type        | name       | label
phonenumber | phonenumber |
```

---

## Auditný záznam

### `audit`

Meta pole `audit` umožňuje **podrobné auditné zaznamenávanie** — zaznamenáva časovo orazítkovaný záznam každej otázky, ktorú anketár navštívil, ako dlho na nej strávil, a (voliteľne) ich GPS polohu pri každom kroku. Auditný záznam je uložený ako samostatný súbor `audit.csv` spolu s každým odoslaním.

```
type  | name  | parameters
audit | audit | location-priority=balanced location-min-interval=30 location-max-age=60
```

#### Parametre auditu

| Parameter | Popis |
|-----------|-------------|
| `location-priority` | Úroveň presnosti GPS: `no-gps`, `low-power`, `balanced`, `high-accuracy` |
| `location-min-interval` | Minimálny počet sekúnd medzi zachyteniami polohy |
| `location-max-age` | Maximálny vek (v sekundách) uloženej polohy na akceptovanie |

Auditný záznam zachytáva:
- Názov otázky a typ udalosti (`question`, `form.start`, `form.exit`, `form.save`, `form.finalize`)
- Začiatočné a koncové časové razítka pre každú udalosť
- GPS súradnice (ak je nastavené `location-priority`)

<Warning>
Pole `audit` generuje samostatný súbor na jedno odoslanie. Uistite sa, že váš dátový kanál spracúva dáta hlavného formulára aj auditný CSV.
</Warning>

## Úplný príklad

Typický prieskum domácnosti môže zahŕňať všetky meta polia načasovania a anketára:

| type | name | label |
|------|------|-------|
| start | start | |
| end | end | |
| today | today | |
| deviceid | deviceid | |
| username | username | |
| email | email | |
| audit | audit | |
| text | household_id | ID domácnosti |
| ... | ... | ... |

## Najlepšie postupy

1. Vždy zahrňte `start` a `end` — sú bezplatné, automatické a neoceniteľné pre monitorovanie kvality.
2. Vždy zahrňte `username` na sledovanie anketárov.
3. Zahrňte `deviceid`, keď chcete detekovať duplicitné odoslania alebo sledovať terénne zariadenia.
4. Používajte `audit` v prieskumoch s vysokou zodpovednosťou, kde potrebujete overiť, že anketári skutočne navštívili každú otázku.
5. SIM-súvisiace polia (`simserial`, `subscriberid`, `devicephonenum`) sú spoľahlivé iba na zariadeniach Android s aktívnymi SIM kartami — preskočte ich pre nasadenia iba s tabletmi.

---

## Obmedzenia

- Všetky meta polia sú **iba na čítanie** — nemôžu byť odkazované ani upravované inými výpočtami.
- `username` a `email` vyžadujú, aby bol anketár prihlásený; budú prázdne pre anonymné odoslania.
- Meta polia SIM/telefónu môžu vracať prázdne hodnoty na tabletoch len s Wi-Fi a niektorých verziách Androidu kvôli obmedzeniam oprávnení.

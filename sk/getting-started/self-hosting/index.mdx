Spustite rtCloud na vlastnej infraštruktúre pomocou Docker Compose. Vlastný hosting vám dáva plné vlastníctvo vašich dát, siete a prostredia nasadenia — ideálne pre organizácie s požiadavkami na lokalitu dát, vzduchom izolovanými sieťami alebo vlastnými potrebami infraštruktúry.

## Čo je vlastný hosting rtCloud?

Vlastný hosting rtCloud je oficiálny Docker image, ktorý balí celú platformu rtCloud do prenosného zásobníka kontajnerov, ktorý môžete spustiť na akomkoľvek linuxovom serveri. Zásobník zahŕňa:

| Služba | Popis |
|---------|-------------|
| **rtCloud App** | Webová aplikácia Apache 2.4 + PHP 7.4 so zabudovanou frontovoú radom (Beanstalkd), analytickým serverom (Shiny) a plánovanými úlohami |
| **MySQL 8.0** | Relačná databáza pre všetky aplikačné a prieskumné dáta |
| **Keycloak** *(voliteľné)* | Vstavaný server Single Sign-On pre správu podnikovej identity |

## Kedy použiť vlastný hosting

Vlastný hosting je správna voľba, keď:

- Vyžadujete **suverenitu dát** — všetky dáta zostávajú vo vašej vlastnej infraštruktúre
- Pracujete v **vzduchom izolovanej alebo obmedzenej sieti** bez externého cloudového prístupu
- Máte **požiadavky na súlad** (GDPR, HIPAA, vládne dátové politiky) nariaďujúce lokálne uloženie
- Potrebujete integrovať s **interným poskytovateľom identity** (Active Directory, LDAP, SAML)
- Chcete **prispôsobiť zdroje** — pridelenie CPU, RAM a úložiska podľa vlastných podmienok

## Prehľad architektúry

Nasadenie beží ako sada Docker kontajnerov prepojených v internej sieti:

```
┌────────────────────────────────────────┐
│            rtcloud-app                 │
│  Apache 2.4 (port 80)                  │
│  PHP 7.4 application                   │
│  Beanstalkd queue (internal)           │
│  Shiny Server (port 3838)              │
│  Cron scheduler                        │
└─────────────────┬──────────────────────┘
                  │ rtcloud-net (bridge)
┌─────────────────▼──────────────────────┐
│            rtcloud-mysql               │
│  MySQL 8.0 (port 3306, internal only)  │
└────────────────────────────────────────┘
```

Keď je SSO povolené, beží vedľa tretí kontajner:

```
┌─────────────────────────────────────────┐
│            rtcloud-keycloak             │
│  Keycloak (port 8080, internal only)    │
│  Admin UI (port 9000, internal only)    │
└─────────────────────────────────────────┘
```

Všetky kontajnery komunikujú cez izolovanú Docker bridge sieť. Hostiteľovi sú vystavené iba port webovej aplikácie a voliteľne port analytického servera Shiny.

## Τι είναι ένα XLSForm;
Το rtSurvey χρησιμοποιεί εκτεταμένη έκδοση του προτύπου [XLSForm](https://xlsform.org/) για σχεδιασμό φόρμας, προσφέροντας ισχυρά χαρακτηριστικά για δημιουργία εξελιγμένων ερευνών. Αυτός ο οδηγός θα σας εισαγάγει στις βασικές έννοιες σχεδιασμού φόρμας στο rtSurvey, από βασική δομή XLSForm έως προχωρημένα χαρακτηριστικά ειδικά για το rtSurvey.

Με τα XLSForms, μπορείτε να δημιουργείτε φόρμες σε αναγνώσιμη από άνθρωπο μορφή χρησιμοποιώντας το γνωστό εργαλείο Excel, καθιστώντας το προσβάσιμο σχεδόν σε όλους.
Αυτό το πρότυπο επιτρέπει εύκολη κοινοποίηση και συνεργασία στη δημιουργία φόρμας.

Ενώ τα XLSForms είναι φιλικά για αρχάριους, επιτρέπουν επίσης σε έμπειρους χρήστες να δημιουργούν σύνθετες φόρμες.

Το rtSurvey παρέχει συνεπή τρόπο ενσωμάτωσης προχωρημένων λειτουργιών όπως λογική παράλειψης σε φόρμες σε διάφορες πλατφόρμες συλλογής δεδομένων web και κινητού.

## Δομή XLSForm
Ένα XLSForm αποτελείται συνήθως από δύο κύρια φύλλα εργασίας:

1. **survey**: Ορίζει τη δομή και το περιεχόμενο της φόρμας.
2. **choices**: Καθορίζει τις επιλογές απαντήσεων για ερωτήσεις πολλαπλής επιλογής.

Ένα προαιρετικό φύλλο εργασίας **settings** μπορεί να παρέχει πρόσθετες προδιαγραφές φόρμας.

Είναι σημαντικό να σημειωθεί ότι οι υποχρεωτικές στήλες στα φύλλα εργασίας survey και choices πρέπει να υπάρχουν για να λειτουργεί σωστά η φόρμα. Οι προαιρετικές στήλες παρέχουν περαιτέρω έλεγχο συμπεριφοράς κάθε καταχώρησης αλλά δεν είναι απαραίτητες.

Οι στήλες στο βιβλίο εργασίας Excel μπορούν να εμφανίζονται σε οποιαδήποτε σειρά, και οι προαιρετικές στήλες μπορούν να αφήνονται κενές. Ωστόσο, είναι κρίσιμο να χρησιμοποιείτε την ακριβή σύνταξη και συμβάσεις ονοματολογίας που καθορίζονται στην τεκμηρίωση XLSForm.

### Το φύλλο εργασίας survey
Το **φύλλο εργασίας survey** είναι εκεί που ορίζετε τη δομή της φόρμας σας και παρέχετε το περιεχόμενο. Κάθε γραμμή στο φύλλο εργασίας survey αντιπροσωπεύει μια ερώτηση ή στοιχείο στη φόρμα σας. Οι ακόλουθες στήλες είναι υποχρεωτικές:

- `type`: Καθορίζει τον τύπο καταχώρησης που αναμένετε για την ερώτηση.
- `name`: Καθορίζει το μοναδικό όνομα μεταβλητής για εκείνη την καταχώρηση. Τα ονόματα πρέπει να ξεκινούν με γράμμα ή κάτω παύλα και να περιέχουν μόνο γράμματα, ψηφία, παύλες, κάτω παύλες και τελείες. Τα ονόματα διακρίνουν πεζά-κεφαλαία.
- `label`: Περιέχει το πραγματικό κείμενο που βλέπετε για την ερώτηση στη φόρμα.

| type                | name     | label                |
| ------------------- | -------- | -------------------- |
| today               | today    |                      |
| select_one gender   | gender   | Φύλο ερωτώμενου; |
| integer             | age      | Ηλικία ερωτώμενου;    |

### Το φύλλο εργασίας choices
Το φύλλο εργασίας **`choices`** χρησιμοποιείται για τον καθορισμό επιλογών απαντήσεων για ερωτήσεις πολλαπλής επιλογής.
Κάθε γραμμή αντιπροσωπεύει μια επιλογή απάντησης. Οι ακόλουθες στήλες είναι υποχρεωτικές:

- **`list_name`**: Ομαδοποιεί ένα σύνολο σχετικών επιλογών απαντήσεων.
- **`name`**: Καθορίζει το μοναδικό όνομα μεταβλητής για εκείνη την επιλογή απάντησης.
- **`label`**: Εμφανίζει την επιλογή απάντησης ακριβώς όπως θέλετε να εμφανίζεται στη φόρμα.

| list_name           | name        | label                |
| ------------------- | ----------- | -------------------- |
| gender              | transgender | Τρανσέξουαλ          |
| gender              | female      | Γυναίκα               |
| gender              | male        | Άνδρας                 |
| gender              | other       | Άλλο                 |

Μια σημαντική παρατήρηση κατά τη δημιουργία φορμών στο Excel: η σύνταξη που χρησιμοποιείτε πρέπει να είναι ακριβής. Για παράδειγμα, εάν γράψετε **Choices** ή **choice** αντί για **choices**, η φόρμα δεν θα λειτουργεί.

### Το φύλλο εργασίας settings

Το φύλλο εργασίας settings είναι προαιρετικό αλλά επιτρέπει να καθορίσετε μεταδεδομένα και συμπεριφορά σε επίπεδο φόρμας:

| Στήλη | Περιγραφή |
|--------|-------------|
| form_title | Ο τίτλος της φόρμας όπως εμφανίζεται στους χρήστες |
| form_id | Μοναδικό αναγνωριστικό για τη φόρμα, χρησιμοποιείται στη διαχείριση δεδομένων και κλήσεις API |
| default_language | Ο προεπιλεγμένος κωδικός γλώσσας για πολύγλωσσες φόρμες (π.χ. 'el' για Ελληνικά) |
| version | Ο αριθμός έκδοσης της φόρμας, χρήσιμος για παρακολούθηση αλλαγών |
| instance_name | Έκφραση για δημιουργία μοναδικού ονόματος για κάθε υποβολή φόρμας |
| generation | Ακέραιος που επισημαίνει τη γενιά της φόρμας. Αυξάνεται για δομικές αλλαγές |
| family | Αναγνωριστικό για ομαδοποίηση σχετικών φορμών σε δομικές αλλαγές |

### Τύποι ερωτήσεων
Το XLSForm υποστηρίζει πολλούς τύπους ερωτήσεων. Αυτές είναι μερικές από τις επιλογές που μπορείτε να εισαγάγετε στη στήλη **`type`** στο φύλλο εργασίας **`survey`**:

| Τύπος ερώτησης             | Εισαγωγή απάντησης                                                                                 |
| ------------------------- | -------------------------------------------------------------------------------------------- |
| integer                   | Εισαγωγή ακέραιου (δηλ. ολόκληρου αριθμού).                                                          |
| decimal                   | Εισαγωγή δεκαδικού.                                                                               |
| range                     | Εισαγωγή [εύρους](#range) (συμπεριλαμβανομένης βαθμολόγησης)                                                     |
| text                      | Απόκριση ελεύθερου κειμένου.                                                                        |
| select_one [options]      | Ερώτηση [πολλαπλής επιλογής](#multiple-choice)· μπορεί να επιλεγεί μόνο μία απάντηση.               |
| select_multiple [options] | Ερώτηση [πολλαπλής επιλογής](#multiple-choice)· μπορούν να επιλεγούν πολλές απαντήσεις.              |
| select_one_from_file [file]| [Πολλαπλή επιλογή από αρχείο](#multiple-choice-from-file)· μπορεί να επιλεγεί μόνο μία απάντηση.      |
| rank [options]            | Ερώτηση [κατάταξης](#rank)· διάταξη λίστας.                                                        |
| note                      | Εμφάνιση σημείωσης στην οθόνη, χωρίς εισαγωγή.                    |
| geopoint                  | Συλλογή [μεμονωμένης GPS συντεταγμένης](#gps).                                                     |
| geotrace                  | Καταγραφή [γραμμής δύο ή περισσότερων GPS συντεταγμένων](#gps).                                                |
| geoshape                  | Καταγραφή [πολυγώνου πολλαπλών GPS συντεταγμένων](#gps)· το τελευταίο σημείο είναι ίδιο με το πρώτο. |
| date                      | Εισαγωγή ημερομηνίας.                                                                                  |
| time                      | Εισαγωγή ώρας.                                                                                  |
| dateTime                  | Αποδέχεται εισαγωγή ημερομηνίας και ώρας.                                                             |
| image                     | Λήψη φωτογραφίας ή μεταφόρτωση [αρχείου εικόνας](#image).                                            |
| audio                     | Λήψη ηχογράφησης ή μεταφόρτωση ηχητικού αρχείου.                                             |
| video                     | Λήψη βίντεο ή μεταφόρτωση αρχείου βίντεο.                                               |
| file                      | Γενική εισαγωγή αρχείου (txt, pdf, xls, xlsx, doc, docx, rtf, zip)                                |
| barcode                   | Σάρωση barcode, απαιτεί εγκατεστημένη εφαρμογή σαρωτή barcode.                            |
| calculate                 | Εκτέλεση υπολογισμού.                    |
| hidden                    | Πεδίο χωρίς σχετικό στοιχείο UI που μπορεί να χρησιμοποιηθεί για αποθήκευση σταθεράς                  |

## Επεκτάσεις rtSurvey

Το rtSurvey επεκτείνει το πρότυπο XLSForm υποστηρίζοντας πρόσθετες δυνατότητες όπως `grid layout`, `μορφοποίηση html` και πολλά νέα `widgets`.

### Διάταξη πλέγματος
Το rtSurvey επιτρέπει στη φόρμα σας να μιμείται την εμφάνιση παραδοσιακών έντυπων ερευνών συμπυκνώνοντας πολλαπλές ερωτήσεις σε μία γραμμή.

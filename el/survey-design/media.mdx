Το rtSurvey υποστηρίζει πλούσια ενσωμάτωση πολυμέσων σε έρευνες, επιτρέποντάς σας να βελτιώσετε τα ερωτηματολόγιά σας με εικόνες, ήχο και βίντεο. Αυτό το χαρακτηριστικό μπορεί να βελτιώσει σημαντικά την εμπειρία του ερωτώμενου και την ποιότητα των συλλεγόμενων δεδομένων.

## Τύποι πολυμέσων που υποστηρίζονται

Το rtSurvey υποστηρίζει τους ακόλουθους τύπους πολυμέσων:
- Εικόνες (jpg, png, gif)
- Ήχος (mp3, wav)
- Βίντεο (mp4, webm)

## Προσθήκη πολυμέσων στην έρευνά σας

Για να συμπεριλάβετε πολυμέσα στη φόρμα rtSurvey σας, χρησιμοποιήστε τις ακόλουθες στήλες στο XLSForm σας:

- `image`: Για εμφάνιση εικόνων
- `audio`: Για αναπαραγωγή αρχείων ήχου
- `video`: Για αναπαραγωγή αρχείων βίντεο

Παράδειγμα:

```
| type | name          | label          | image        | audio       | video       |
|------|---------------|----------------|--------------|-------------|-------------|
| note | media_example | Παράδειγμα πολυμέσων | example.jpg  | sound.mp3   | clip.mp4    |
```

## Διαχείριση αρχείων πολυμέσων

### Web-based έρευνες
Για web-based έρευνες, το rtSurvey παρέχει διεπαφή διαχείρισης πολυμέσων όπου μπορείτε να ανεβάσετε και να οργανώσετε αρχεία πολυμέσων σας. Αυτά τα αρχεία είναι στη συνέχεια αυτόματα διαθέσιμα για χρήση στις έρευνές σας.

### Εφαρμογή κινητού
Κατά τη χρήση της εφαρμογής κινητού rtSurvey:
1. Τοποθετήστε τα αρχεία πολυμέσων στον φάκελο `/rtSurvey/forms/[form-name]-media/` στη συσκευή σας.
2. Αναφερθείτε στο ακριβές όνομα αρχείου στο XLSForm σας.

## Χαρακτηριστικά ειδικά για rtSurvey

### Δυναμική φόρτωση πολυμέσων
Το rtSurvey υποστηρίζει δυναμική φόρτωση πολυμέσων βάσει αποκρίσεων έρευνας:

```
| type         | name      | label              | image                    |
|--------------|-----------|--------------------|--------------------------| 
| select_one species | animal | Επιλέξτε ζώο | ${animal}.jpg            |
```

### Πολυμέσα στις επιλογές
Το rtSurvey σας επιτρέπει να χρησιμοποιείτε πολυμέσα στις επιλογές για ερωτήσεις επιλογής:

```
| type                | name    | label        | media::image |
|---------------------|---------|--------------|--------------|
| select_one_from_file animals | Επιλέξτε ζώο |              |
```

Στο φύλλο choices:
```
| list_name | name  | label | media::image |
|-----------|-------|-------|--------------|
| animals   | dog   | Σκύλος| dog.jpg      |
| animals   | cat   | Γάτα  | cat.jpg      |
```

### Λήψη πολυμέσων
Το rtSurvey επεκτείνει το XLSForm με δυνατότητες λήψης πολυμέσων:

```
| type  | name        | label                |
|-------|-------------|----------------------|
| image | photo       | Τραβήξτε φωτογραφία  |
| audio | voice_note  | Ηχογραφήστε σημείωση φωνής |
| video | video_clip  | Εγγράψτε βίντεο      |
```

## Βέλτιστες πρακτικές για χρήση πολυμέσων

1. **Βελτιστοποίηση μεγεθών αρχείων**: Μεγάλα αρχεία πολυμέσων μπορεί να επιβραδύνουν τη φόρτωση και υποβολή έρευνας.
2. **Χρήση κατάλληλων μορφών**: Χρησιμοποιείτε ευρέως υποστηριζόμενες μορφές (jpg για εικόνες, mp3 για ήχο, mp4 για βίντεο).
3. **Παροχή εναλλακτικών**: Πάντα συμπεριλαμβάνετε εναλλακτικά κείμενα για προσβασιμότητα.
4. **Διεξοδικές δοκιμές**: Βεβαιωθείτε ότι τα πολυμέσα εμφανίζονται σωστά σε όλες τις συσκευές-στόχους.
5. **Εξέταση εκτός σύνδεσης χρήσης**: Για έρευνες που μπορεί να διεξαχθούν εκτός σύνδεσης, βεβαιωθείτε ότι όλα τα πολυμέσα είναι διαθέσιμα τοπικά.

## Πολυγλωσσική υποστήριξη πολυμέσων

Το rtSurvey υποστηρίζει πολυμέσα ειδικά για γλώσσα. Χρησιμοποιήστε το επίθημα `::language`:

```
| type | name  | label       | image::English | image::Spanish |
|------|-------|-------------|----------------|----------------|
| note | intro | Καλώς ορίσατε | welcome_en.jpg | welcome_es.jpg |
```

## Πολυμέσα στην εξαγωγή δεδομένων

Κατά την εξαγωγή δεδομένων από το rtSurvey:
- Για web έρευνες, συμπεριλαμβάνονται URLs πολυμέσων στην εξαγωγή.
- Για έρευνες εφαρμογής κινητού, συμπεριλαμβάνονται μονοπάτια αρχείων.

## Εκτιμήσεις εφαρμογής κινητού

- Βεβαιωθείτε ότι υπάρχει επαρκής χώρος αποθήκευσης στις συσκευές για έρευνες με πολλά πολυμέσα.
- Η εφαρμογή κινητού rtSurvey υποστηρίζει εκτός σύνδεσης αναπαραγωγή και λήψη πολυμέσων.
- Μεγάλα αρχεία πολυμέσων μπορεί να επηρεάσουν την απόδοση εφαρμογής σε χαμηλής κατηγορίας συσκευές.

## Γνωστοί περιορισμοί

- Ορισμένοι παλαιότεροι browsers μπορεί να μην υποστηρίζουν όλες τις μορφές πολυμέσων.
- Πολύ μεγάλα αρχεία βίντεο μπορεί να προκαλέσουν προβλήματα σε χαμηλού εύρους ζώνης καταστάσεις.

## Αντιμετώπιση προβλημάτων πολυμέσων

1. **Τα πολυμέσα δεν εμφανίζονται**: Ελέγξτε για ακρίβεια μονοπατιών και ονομάτων αρχείων.
2. **Προβλήματα αναπαραγωγής**: Βεβαιωθείτε ότι η μορφή πολυμέσων υποστηρίζεται από τις συσκευές-στόχους.
3. **Αργή φόρτωση**: Εξετάστε βελτιστοποίηση μεγεθών αρχείων ή προ-φόρτωση πολυμέσων.

## Προχωρημένα χαρακτηριστικά πολυμέσων

### Γεωτagging
Το rtSurvey μπορεί να γεωτagγάρει αυτόματα πολυμέσα που λαμβάνονται κατά τη διάρκεια ερευνών:

```
| type  | name        | label                | appearance |
|-------|-------------|----------------------|------------|
| image | photo       | Τραβήξτε φωτογραφία  | geotag     |
```

### Σχολιασμός πολυμέσων
Επιτρέψτε στους ερωτώμενους να σχολιάζουν εικόνες:

```
| type  | name        | label                | appearance |
|-------|-------------|----------------------|------------|
| image | photo       | Σχολιάστε την εικόνα | annotate   |
```

Ο τύπος ερώτησης integer στα XLSForms και στο rtSurvey χρησιμοποιείται για τη συλλογή αποκρίσεων ολόκληρων αριθμών. Αυτός ο τύπος ερώτησης είναι απαραίτητος για τη συλλογή αριθμητικών δεδομένων χωρίς δεκαδικά ψηφία, όπως μετρήσεις, ηλικίες ή χρόνια.

## Βασική προδιαγραφή XLSForm

| type    | name  | label                       |
|---------|-------|-----------------------------|
| integer | age   | Εισαγάγετε την ηλικία σας σε έτη |

Για περισσότερες λεπτομέρειες σχετικά με τον βασικό τύπο integer, δείτε την [προδιαγραφή XLSForm](https://xlsform.org/en/#question-types).

## Χρήσεις

Οι ερωτήσεις integer χρησιμοποιούνται συνήθως για:

1. Εισόδους ηλικίας
2. Μέτρηση στοιχείων (π.χ. αριθμός παιδιών, μελών νοικοκυριού)
3. Εισόδους έτους (π.χ. έτος γέννησης)
4. Βαθμολογήσεις σε αριθμητική κλίμακα
5. Οποιαδήποτε συλλογή δεδομένων ολόκληρου αριθμού

## Επεκτάσεις rtSurvey

Ενώ η βασική προδιαγραφή XLSForm για ερωτήσεις integer είναι απλή, το rtSurvey μπορεί να προσφέρει επιπλέον χαρακτηριστικά ή προσαρμογές:

1. Επικύρωση εύρους
2. Προσαρμοσμένα μηνύματα σφάλματος
3. Επιλογές εμφάνισης για εισαγωγή αριθμού

## Βέλτιστες πρακτικές

1. Χρησιμοποιήστε σαφείς και συνοπτικές ετικέτες για να καθορίσετε την αναμενόμενη είσοδο.
2. Εφαρμόστε περιορισμούς εύρους για αποτροπή μη ρεαλιστικών ή λανθασμένων εισόδων.
3. Εξετάστε τη χρήση κειμένου υπόδειξης για παροχή παραδειγμάτων ή διευκρίνιση της αναμενόμενης μορφής.
4. Για μεγάλους αριθμούς, εξετάστε τη χρήση κόμματος στην ετικέτα για βελτίωση αναγνωσιμότητας.

## Περιορισμοί και επικύρωση

Μπορείτε να προσθέσετε περιορισμούς για να διασφαλίσετε ότι η εισαγόμενη τιμή εμπίπτει σε συγκεκριμένο εύρος:

| type    | name  | label                       | constraint        | constraint_message                        |
|---------|-------|-----------------------------|-------------------|-------------------------------------------|
| integer | age   | Εισαγάγετε την ηλικία σας σε έτη | .>0 and .<=120    | Η ηλικία πρέπει να είναι μεταξύ 1 και 120 ετών |

## Παράδειγμα χρήσης

Δείτε πώς μπορείτε να χρησιμοποιήσετε ερωτήσεις integer σε έρευνα νοικοκυριού:

| type    | name           | label                                            | constraint | constraint_message                       |
|---------|----------------|--------------------------------------------------|------------|------------------------------------------|
| integer | household_size | Πόσα άτομα ζουν στο νοικοκυριό σας;              | .>0        | Το μέγεθος νοικοκυριού πρέπει να είναι τουλάχιστον 1 |
| integer | num_children   | Πόσα παιδιά κάτω των 18 ετών υπάρχουν στο νοικοκυριό; | .>=0    | Ο αριθμός παιδιών δεν μπορεί να είναι αρνητικός |
| integer | year_built     | Σε ποιο έτος κτίστηκε το σπίτι σας;              | .>1800 and .<=2023 | Το έτος πρέπει να είναι μεταξύ 1800 και 2023 |

## Υπολογισμός με τιμές integer

Οι τιμές integer μπορούν να χρησιμοποιηθούν σε υπολογισμούς:

| type    | name           | label                                    |
|---------|----------------|------------------------------------------|
| integer | num_adults     | Αριθμός ενηλίκων στο νοικοκυριό          |
| integer | num_children   | Αριθμός παιδιών στο νοικοκυριό           |
| calculate | total_members | |

Στη γραμμή calculate, μπορείτε να χρησιμοποιήσετε:

```
calculation | ${num_adults} + ${num_children}
```

Αυτό αθροίζει τον αριθμό ενηλίκων και παιδιών για να λάβει το σύνολο μελών νοικοκυριού.

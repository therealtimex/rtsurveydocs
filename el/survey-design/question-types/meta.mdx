Οι τύποι ερωτήσεων meta είναι ειδικά πεδία που συμπληρώνονται **αυτόματα** — ο ερωτώμενος δεν τα βλέπει ποτέ. Καταγράφουν πλαίσιο σχετικά με την υποβολή: πότε συλλέχθηκε, ποια συσκευή χρησιμοποιήθηκε και ποιος το συνέλεξε. Προσθέστε τα στο φύλλο εργασίας `survey` όπως οποιονδήποτε άλλο τύπο ερώτησης· απλώς δεν εμφανίζονται στην οθόνη.

## Βασική προδιαγραφή XLSForm

| type | name | label |
|------|------|-------|
| start | start | |
| end | end | |
| deviceid | deviceid | |

Οι ετικέτες είναι προαιρετικές για πεδία meta καθώς δεν εμφανίζονται ποτέ.

---

## Πεδία meta χρονισμού

### `start`

Καταγράφει την **ημερομηνία και ώρα ανοίγματος της φόρμας**. Αποθηκεύεται σε μορφή ISO 8601 (`YYYY-MM-DDTHH:MM:SS.sss+HH:MM`).

```
type    | name  | label
start   | start |
```

### `end`

Καταγράφει την **ημερομηνία και ώρα υποβολής της φόρμας**. Μαζί με `start`, μπορείτε να υπολογίσετε τον χρόνο που αφιερώθηκε στη συμπλήρωση της φόρμας:

```
type      | name          | calculation
calculate | duration_min  | (decimal-date-time(${end}) - decimal-date-time(${start})) * 1440
```

### `today`

Καταγράφει την **τρέχουσα ημερομηνία** (χωρίς στοιχείο ώρας). Αποθηκεύεται ως `YYYY-MM-DD`. Χρήσιμο όταν χρειάζεστε μόνο την ημερομηνία χωρίς πλήρη χρονική σφραγίδα.

```
type  | name  | label
today | today |
```

## Πεδία meta συσκευής

### `deviceid`

Καταγράφει το **μοναδικό αναγνωριστικό της συσκευής** που χρησιμοποιήθηκε για συλλογή δεδομένων. Σε Android αυτό είναι τυπικά το IMEI ή το Android ID. Χρήσιμο για παρακολούθηση ποια συσκευή υπέβαλε κάθε φόρμα και εντοπισμό διπλών υποβολών.

```
type      | name     | label
deviceid  | deviceid |
```

### `devicephonenum`

Καταγράφει τον **αριθμό τηλεφώνου της κάρτας SIM** της συσκευής (εάν διαθέσιμο). Μπορεί να είναι κενό εάν η συσκευή δεν έχει SIM ή εάν ο αριθμός δεν είναι αποθηκευμένος στο SIM.

```
type           | name          | label
devicephonenum | devicephonenum |
```

### `simserial`

Καταγράφει τον **σειριακό αριθμό της κάρτας SIM** (ICCID). Χρήσιμο για αναγνώριση ποιο SIM/φορέας χρησιμοποιήθηκε.

```
type      | name      | label
simserial | simserial |
```

### `subscriberid`

Καταγράφει το **IMSI (International Mobile Subscriber Identity)** — το μοναδικό αναγνωριστικό συνδρομητή στην κάρτα SIM.

```
type         | name        | label
subscriberid | subscriberid |
```

---

## Πεδία meta απογραφέα

### `username`

Καταγράφει το **όνομα χρήστη του συνδεδεμένου απογραφέα** (ο λογαριασμός που χρησιμοποιείται στην εφαρμογή rtSurvey). Αυτός είναι ο πιο αξιόπιστος τρόπος παρακολούθησης ποιος συνέλεξε κάθε υποβολή.

```
type     | name     | label
username | username |
```

### `email`

Καταγράφει τη **διεύθυνση email του συνδεδεμένου απογραφέα**.

```
type  | name  | label
email | email |
```

### `phonenumber`

Καταγράφει τον **αριθμό τηλεφώνου που σχετίζεται με τον λογαριασμό απογραφέα** (εάν διαμορφωθεί).

```
type        | name       | label
phonenumber | phonenumber |
```

## Αρχείο καταγραφής ελέγχου

### `audit`

Το πεδίο meta `audit` ενεργοποιεί **λεπτομερή καταγραφή ελέγχου** — καταγράφει αρχείο καταγραφής με χρονική σφραγίδα κάθε ερώτησης που επισκέφθηκε ο απογραφέας, πόσο χρόνο αφιέρωσε σε κάθε μία και (προαιρετικά) τη θέση GPS τους σε κάθε βήμα. Το αρχείο καταγραφής ελέγχου αποθηκεύεται ως ξεχωριστό αρχείο `audit.csv` μαζί με κάθε υποβολή.

```
type  | name  | parameters
audit | audit | location-priority=balanced location-min-interval=30 location-max-age=60
```

#### Παράμετροι audit

| Παράμετρος | Περιγραφή |
|------------|-----------|
| `location-priority` | Επίπεδο ακρίβειας GPS: `no-gps`, `low-power`, `balanced`, `high-accuracy` |
| `location-min-interval` | Ελάχιστα δευτερόλεπτα μεταξύ λήψεων τοποθεσίας |
| `location-max-age` | Μέγιστη ηλικία (δευτερόλεπτα) κρυφής τοποθεσίας που γίνεται αποδεκτή |

Το αρχείο καταγραφής ελέγχου καταγράφει:
- Όνομα ερώτησης και τύπος γεγονότος (`question`, `form.start`, `form.exit`, `form.save`, `form.finalize`)
- Χρονικές σφραγίδες έναρξης και λήξης για κάθε γεγονός
- Συντεταγμένες GPS (εάν ορίζεται το `location-priority`)

<Warning>
Το πεδίο `audit` δημιουργεί ξεχωριστό αρχείο ανά υποβολή. Βεβαιωθείτε ότι η αλυσίδα επεξεργασίας δεδομένων σας επεξεργάζεται τόσο τα κύρια δεδομένα φόρμας όσο και το audit CSV.
</Warning>

## Πλήρες παράδειγμα

Μια τυπική έρευνα νοικοκυριού μπορεί να συμπεριλαμβάνει όλα τα πεδία meta χρονισμού και απογραφέα:

| type | name | label |
|------|------|-------|
| start | start | |
| end | end | |
| today | today | |
| deviceid | deviceid | |
| username | username | |
| email | email | |
| audit | audit | |
| text | household_id | Αναγνωριστικό νοικοκυριού |
| ... | ... | ... |

---

## Βέλτιστες πρακτικές

1. Πάντα συμπεριλαμβάνετε `start` και `end` — είναι δωρεάν, αυτόματα και ανεκτίμητα για παρακολούθηση ποιότητας.
2. Πάντα συμπεριλαμβάνετε `username` για παρακολούθηση απογραφέων.
3. Συμπεριλάβετε `deviceid` όταν θέλετε να εντοπίσετε διπλές υποβολές ή να παρακολουθήσετε συσκευές πεδίου.
4. Χρησιμοποιήστε `audit` σε έρευνες υψηλής λογοδοσίας όπου χρειάζεται να επαληθεύσετε ότι οι απογραφείς επισκέφθηκαν πράγματι κάθε ερώτηση.
5. Τα πεδία SIM (`simserial`, `subscriberid`, `devicephonenum`) είναι αξιόπιστα μόνο σε Android συσκευές με ενεργές κάρτες SIM.

---

## Περιορισμοί

- Όλα τα πεδία meta είναι **μόνο για ανάγνωση** — δεν μπορούν να αναφερθούν ή τροποποιηθούν από άλλους υπολογισμούς.
- Το `username` και το `email` απαιτούν τον απογραφέα να είναι συνδεδεμένος· θα είναι κενά για ανώνυμες υποβολές.
- Τα πεδία meta SIM/τηλεφώνου μπορεί να επιστρέφουν κενές τιμές σε tablets μόνο Wi-Fi.

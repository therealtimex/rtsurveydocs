Η εφαρμογή κινητού rtSurvey προσφέρει ολοκληρωμένο σύνολο χαρακτηριστικών σχεδιασμένων για εξορθολογισμό της διαδικασίας έρευνας. Εδώ είναι οι βασικές λειτουργίες:

## Συμπλήρωση φόρμας
Το χαρακτηριστικό Συμπλήρωση φόρμας είναι εκεί που οι απαριθμητές έχουν πρόσβαση και εισάγουν δεδομένα σε κενές φόρμες έρευνας. Βασικά σημεία:

1. Λίστα φορμών: Κατά την πρόσβαση στην ενότητα Συμπλήρωση φόρμας, οι χρήστες παρουσιάζονται με λίστα όλων των διαθέσιμων κενών φορμών που τους έχουν ανατεθεί.

2. Αυτόματη λήψη φόρμας: Σε αντίθεση με άλλα εργαλεία έρευνας, η εφαρμογή κινητού rtSurvey κατεβάζει αυτόματα φόρμες που ο διαχειριστής έρευνας ή ο διαχειριστής έργου έχει χορηγήσει πρόσβαση στον χρήστη. Αυτό εξαλείφει την ανάγκη χειροκίνητης ανάκτησης κενών φορμών.

3. Άμεση εισαγωγή δεδομένων: Οι απαριθμητές μπορούν να επιλέξουν φόρμα από τη λίστα και να αρχίσουν να εισάγουν απαντήσεις έρευνας απευθείας στην εφαρμογή.

4. Ενημερώσεις σε πραγματικό χρόνο: Καθώς ανατίθενται νέες φόρμες ή γίνονται ενημερώσεις, η λίστα διαθέσιμων φορμών ανανεώνεται αυτόματα.

5. Δυνατότητα εκτός σύνδεσης: Οι φόρμες μπορούν να ληφθούν όταν υπάρχει σύνδεση στο Διαδίκτυο, επιτρέποντας στους απαριθμητές να τις συμπληρώνουν ακόμα και σε περιοχές με κακή ή καθόλου κάλυψη δικτύου.

## Επεξεργασία φόρμας

Η λειτουργία Επεξεργασία φόρμας στο rtSurvey προσφέρει ολοκληρωμένη και ευέλικτη προσέγγιση για διαχείριση εγκαταστάσεων έρευνας μέσω τριών διακριτών καρτελών:

1. **Αποθηκευμένες**:
   - Πρόσβαση και τροποποίηση ημιτελών εγκαταστάσεων συνεντεύξεων που αποθηκεύτηκαν στη συσκευή του απαριθμητή.

2. **Επιστραφείσες** (Αποκλειστικό rtSurvey):
   - Επεξεργασία εγκαταστάσεων έρευνας που ολοκληρώθηκαν, οριστικοποιήθηκαν και υποβλήθηκαν προηγουμένως στον διακομιστή.
   - Μοναδικό στο rtSurvey, αυτό το χαρακτηριστικό επιτρέπει μετα-υποβολή επεξεργασίες όταν απαιτούνται πρόσθετες πληροφορίες ή διορθώσεις.

3. **Προωθηθείσες** (Αποκλειστικό rtSurvey):
   - Πρόσβαση και επεξεργασία εγκαταστάσεων έρευνας που δημιουργήθηκαν αρχικά σε άλλη συσκευή.
   - Αυτό το καινοτόμο χαρακτηριστικό υποστηρίζει διάφορα σενάρια:
     * Εποπτεύοντες μπορούν να ελέγξουν και να επεξεργαστούν υποβολές από απαριθμητές.
     * Οι χρήστες μπορούν να συνεχίσουν εργασία σε διαφορετική συσκευή εάν η αρχική συσκευή χαθεί ή υποστεί βλάβη.
     * Επιτρέπει συνεργατική επεξεργασία και διαδικασίες ελέγχου ποιότητας.

Βασικά οφέλη:
- Βελτιωμένη ποιότητα δεδομένων μέσω πολλαπλών ευκαιριών ελέγχου και επεξεργασίας.
- Βελτιωμένη ευελιξία ροής εργασίας για ομάδες πεδίου και εποπτεύοντες.
- Απρόσκοπτη συνέχεια εργασίας σε συσκευές, μειώνοντας χρόνους διακοπής και κινδύνους απώλειας δεδομένων.

## Αποστολή φόρμας
Υποβολή 100% ολοκληρωμένων φορμών στον κεντρικό διακομιστή. Αυτό το χαρακτηριστικό επιτρέπει μεταφορά δεδομένων σε πραγματικό χρόνο, επιτρέποντας άμεση ανάλυση και λήψη αποφάσεων.

## Ειδοποιήσεις
Λήψη σημαντικών ανακοινώσεων και ενημερώσεων από τον διακομιστή. Αυτό κρατά όλα τα μέλη ομάδας ενημερωμένα για εξελίξεις έργου, αλλαγές ή επείγοντα ζητήματα.

## Εργασίες
Πρόσβαση και διαχείριση εργασιών που ανατέθηκαν από τον διακομιστή. Αυτό το χαρακτηριστικό βοηθά στην οργάνωση φόρτου εργασίας και ιεράρχηση δραστηριοτήτων έρευνας για απαριθμητές πεδίου.

## Αναφορές
Προβολή όλων των αναφορών που αποστέλλονται από τον διακομιστή στο tablet. Αυτή η λειτουργία επιτρέπει στους χρήστες να έχουν πρόσβαση σε αποτελέσματα ανάλυσης και πληροφορίες έργου απευθείας στη συσκευή τους.

## Ανασκόπηση φόρμας

Η λειτουργία Ανασκόπηση φόρμας στο rtSurvey προσφέρει ολοκληρωμένο σύστημα για εξέταση και διαχείριση οριστικοποιημένων εγκαταστάσεων έρευνας, εξασφαλίζοντας ισχυρό έλεγχο ποιότητας και επαλήθευση δεδομένων. Αυτό το χαρακτηριστικό χωρίζεται σε τέσσερις διακριτές καρτέλες:

1. **Οριστικοποιημένες**:
   - Περιέχει ολοκληρωμένες και οριστικοποιημένες εγκαταστάσεις που δεν έχουν ακόμα υποβληθεί στον διακομιστή.

2. **Αποσταλμένες**:
   - Περιέχει οριστικοποιημένες εγκαταστάσεις που έχουν υποβληθεί επιτυχώς στον διακομιστή.

3. **Μεταφερθείσες**:
   - Εμφανίζει ολοκληρωμένες εγκαταστάσεις που έχουν μεταφερθεί σε άλλες συσκευές.

4. **Ληφθείσες**:
   - Εμφανίζει ολοκληρωμένες εγκαταστάσεις που δημιουργήθηκαν αρχικά σε άλλη συσκευή και μεταφέρθηκαν στην τρέχουσα.

Βασικά χαρακτηριστικά:
- **Πρόσβαση μόνο για ανάγνωση**: Όλες οι εγκαταστάσεις σε αυτές τις καρτέλες είναι αρχικά μόνο για ανάγνωση, διατηρώντας την ακεραιότητα δεδομένων οριστικοποιημένων φορμών.
- **Σύστημα αιτήματος επεξεργασίας**: Οι χρήστες μπορούν να ζητήσουν επεξεργασία εγκατάστασης εάν απαιτούνται διορθώσεις.
  - Τα αιτήματα μπορούν να εγκριθούν αυτόματα ή χειροκίνητα από Διαχειριστές ή Διαχειριστές έργων.
  - Μόλις εγκριθεί, η εγκατάσταση γίνεται επεξεργάσιμη.

## Χάρτης
Χρησιμοποιήστε τη λειτουργία GPS για εντοπισμό ακριβούς τοποθεσίας διεξαγωγής της συνέντευξης. Αυτό το χαρακτηριστικό ενισχύει την ακρίβεια δεδομένων και βοηθά στη χωρική ανάλυση αποτελεσμάτων έρευνας.

## Έξοδος
Κλείστε την εφαρμογή χωρίς αποσύνδεση από τον λογαριασμό rtSurvey. Αυτό επιτρέπει γρήγορη επανείσοδο στην εφαρμογή χωρίς επαναλαμβανόμενη ταυτοποίηση.

Αυτές οι λειτουργίες συνεργάζονται για τη δημιουργία ισχυρού, φιλικού προς τον χρήστη εργαλείου έρευνας κινητού που εξυπηρετεί διάφορους ρόλους εντός της διαδικασίας έρευνας, από τη συλλογή δεδομένων έως την ανάλυση και τη διαχείριση έργου.

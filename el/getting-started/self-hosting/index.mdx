Εκτελέστε το rtCloud στη δική σας υποδομή χρησιμοποιώντας Docker Compose. Η αυτο-φιλοξενία σας δίνει πλήρη ιδιοκτησία των δεδομένων, του δικτύου και του περιβάλλοντος ανάπτυξης — ιδανικό για οργανισμούς με απαιτήσεις εδαφικής κατοικίας δεδομένων, δίκτυα χωρίς σύνδεση ή ανάγκες προσαρμοσμένης υποδομής.

## Τι είναι η αυτο-φιλοξενία rtCloud;

Η αυτο-φιλοξενία rtCloud είναι μια επίσημη εικόνα Docker που συσκευάζει ολόκληρη την πλατφόρμα rtCloud σε φορητή στοίβα κοντέινερ που μπορεί να εκτελεστεί σε οποιονδήποτε διακομιστή Linux. Η στοίβα περιλαμβάνει:

| Υπηρεσία | Περιγραφή |
|---------|-------------|
| **rtCloud App** | Εφαρμογή web Apache 2.4 + PHP 7.4 με ενσωματωμένη ουρά παρασκηνίου (Beanstalkd), διακομιστή αναλύσεων (Shiny) και προγραμματισμένες εργασίες |
| **MySQL 8.0** | Σχεσιακή βάση δεδομένων για όλα τα δεδομένα εφαρμογής και ερευνών |
| **Keycloak** *(προαιρετικό)* | Ενσωματωμένος διακομιστής Ενιαίας Σύνδεσης για εταιρική διαχείριση ταυτοτήτων |

## Πότε να επιλέξετε αυτο-φιλοξενία

Η αυτο-φιλοξενία είναι η σωστή επιλογή όταν:

- Απαιτείτε **κυριαρχία δεδομένων** — όλα τα δεδομένα παραμένουν στη δική σας υποδομή
- Λειτουργείτε σε **απομονωμένο ή περιορισμένο δίκτυο** χωρίς εξωτερική πρόσβαση στο cloud
- Έχετε **απαιτήσεις συμμόρφωσης** (GDPR, HIPAA, κυβερνητικές πολιτικές δεδομένων) που επιβάλλουν τοπική αποθήκευση
- Χρειάζεστε ενσωμάτωση με **εσωτερικό πάροχο ταυτοτήτων** (Active Directory, LDAP, SAML)
- Θέλετε να **προσαρμόσετε πόρους** — CPU, RAM και αποθήκευση με τους δικούς σας όρους

## Επισκόπηση αρχιτεκτονικής

Η ανάπτυξη εκτελείται ως σύνολο κοντέινερ Docker συνδεδεμένων σε εσωτερικό δίκτυο:

```
┌────────────────────────────────────────┐
│            rtcloud-app                 │
│  Apache 2.4 (port 80)                  │
│  PHP 7.4 application                   │
│  Beanstalkd queue (internal)           │
│  Shiny Server (port 3838)              │
│  Cron scheduler                        │
└─────────────────┬──────────────────────┘
                  │ rtcloud-net (bridge)
┌─────────────────▼──────────────────────┐
│            rtcloud-mysql               │
│  MySQL 8.0 (port 3306, internal only)  │
└────────────────────────────────────────┘
```

Όταν το SSO είναι ενεργοποιημένο, ένα τρίτο κοντέινερ εκτελείται παράλληλα:

```
┌─────────────────────────────────────────┐
│            rtcloud-keycloak             │
│  Keycloak (port 8080, internal only)    │
│  Admin UI (port 9000, internal only)    │
└─────────────────────────────────────────┘
```

Όλα τα κοντέινερ επικοινωνούν μέσω απομονωμένου δικτύου bridge Docker. Μόνο η θύρα εφαρμογής web και (προαιρετικά) η θύρα διακομιστή Shiny αναλύσεων εκτίθενται στον κεντρικό υπολογιστή.

# Διαχείριση Χρηστών Συστήματος

Η ενότητα **Χρήστης Συστήματος** (`/cpms/cpmsSystemUser/admin`) είναι μια ολοκληρωμένη διεπαφή διαχείρισης για τον έλεγχο ποιος έχει πρόσβαση στην πλατφόρμα Real-Time Survey (RT-CPMS) και ποιες ενέργειες μπορεί να εκτελεί.

![Διεπαφή Χρήστη Συστήματος](/images/system_user.png)

## Ενοποιημένη προσέγγιση διαχείρισης

Στο RT-CPMS, ένας **Απαριθμητής** είναι απλώς ένας συγκεκριμένος Ρόλος που εκχωρείται σε έναν Χρήστη Συστήματος. Δεν υπάρχει ξεχωριστή βάση δεδομένων "Απαριθμητών". Είτε ο χρήστης είναι Διαχειριστής υψηλού επιπέδου που παρακολουθεί την πύλη web είτε Απαριθμητής πεδίου που συλλέγει δεδομένα μέσω εφαρμογής κινητού, όλοι διαχειρίζονται σε αυτό το ενιαίο πλαίσιο.

## Βασικά χαρακτηριστικά

### 1. Κατάλογος χρηστών και προβολή πλέγματος
Η κύρια διεπαφή εμφανίζει μια σελιδοποιημένη λίστα όλων των χρηστών που συνδέονται με τον χώρο εργασίας. Βασικά χαρακτηριστικά:
* **ID και όνομα οργανισμού**: Λογική ομαδοποίηση χρηστών υπό συγκεκριμένες οργανωτικές οντότητες (π.χ. `rta`, `partner_org`).
* **Ρόλος**: Καθορίζει το επίπεδο δικαιωμάτων του χρήστη (π.χ. `Διαχειριστής`, `Επικεφαλής ομάδας`, `Απαριθμητής`).
* **Ομάδα**: Χωρικές ή λογικές αναθέσεις ομαδοποίησης (π.χ. συγκεκριμένες περιφέρειες ή επιχειρησιακές ομάδες).
* **Είναι συγχρονισμένος**: Υποδεικνύει εάν ο λογαριασμός ενσωματώνεται επιτυχώς με το κεντρικό σύστημα Ενιαίας Σύνδεσης (SSO).
* **Κατάσταση**: Οπτικές ενδείξεις που επιβεβαιώνουν εάν ένας λογαριασμός είναι `Ενεργός`, `Ανενεργός`, `Διαγραμμένος` ή `Αποκλεισμένος`.

**Καθολικές ενέργειες:**
* **Προσθήκη χρήστη συστήματος**: Χειροκίνητη δημιουργία ατομικού προφίλ.
* **Εισαγωγή χρήστη συστήματος**: Μαζική μεταφόρτωση λογαριασμών χρησιμοποιώντας πρότυπο Excel. Μπορείτε να επιλύετε συγκρούσεις με τρόπους `Παράλειψη` ή `Αντικατάσταση` και να συγχρονίζετε απευθείας με το SSO.
* **Μαζική διαγραφή**: Υποστήριξη πολλαπλής επιλογής για μαζική αφαίρεση λογαριασμών.

### 2. Έλεγχος πρόσβασης και ασφάλεια
Κατά τη δημιουργία ή επεξεργασία προφίλ χρήστη, διατίθενται αρκετά κρίσιμα πεδία ασφάλειας:
* **Κωδικός χρήστη**: Μοναδικό αναγνωριστικό που συνδέει τον τοπικό λογαριασμό CPMS με το κεντρικό αποθετήριο SSO.
* **Κωδικός αλλαγής συσκευής**: Ισχυρό διακριτικό ασφάλειας που απαιτείται όταν ένας απαριθμητής χρειάζεται να αλλάξει τη κινητή συσκευή του.
* **Επίπεδο εξουσίας**: Κλίμακα προτεραιότητας/πρόσβασης από 0 (χαμηλότερο) έως 20 (υψηλότερο).
* **Εναλλαγή εποπτείας**: Πλαίσιο ελέγχου που ανυψώνει αμέσως έναν τυπικό χρήστη σε κατάσταση διαχείρισης.
* **Αυτοματισμός ροής εργασίας**: Επιλογή "Αυτόματη έγκριση αίτησης επεξεργασίας", που απλοποιεί τη διαδικασία καθαρισμού και επαλήθευσης δεδομένων για αξιόπιστους χρήστες.

### 3. Διαχείριση κωδικών (Αυτόματη ενσωμάτωση)
Βρίσκεται στην υποκαρτέλα "Κωδικός" και διαχειρίζεται συνδέσμους εγγραφής και πρόσκλησης βασισμένους σε κατακερματισμό, απλοποιώντας τη διαδικασία ενσωμάτωσης για μεγάλες ομάδες.

* **Εγγραφή έναντι Πρόσκλησης**: Επιλέξτε εάν οι χρήστες μπορούν να εγγραφούν μόνοι τους χρησιμοποιώντας έναν διανεμημένο σύνδεσμο ή εάν απαιτούν άμεση πρόσκληση διαχειριστή.
* **Ημερομηνίες λήξης**: Περιορισμός της ενσωμάτωσης σε συγκεκριμένα χρονικά πλαίσια.
* **Όρια χρήσης**: Περιορισμός του αριθμού χρηστών που μπορούν να εγγραφούν με έναν μόνο κωδικό.
* **Προεκχωρημένοι ρόλοι**: Οι χρήστες που εγγράφονται μέσω αυτών των κωδικών κληρονομούν αυτόματα τον προκαθορισμένο ρόλο και επίπεδο εξουσίας, διασφαλίζοντας ότι είναι έτοιμοι να εργαστούν αμέσως χωρίς χειροκίνητη παρέμβαση διαχειριστή.

# ការគ្រប់គ្រងអ្នកប្រើប្រព័ន្ធ

ម៉ូឌុល **អ្នកប្រើប្រព័ន្ធ** (`/cpms/cpmsSystemUser/admin`) គឺជាចំណុចប្រទាក់គ្រប់គ្រងដ៏ទូលំទូលាយ សម្រាប់ការត្រួតពិនិត្យអ្នកណាមានការចូលដំណើរការទៅវេទិកា Real-Time Survey (RT-CPMS) របស់អ្នក និងសកម្មភាពអ្វីដែលពួកគេអាចធ្វើ។

![ចំណុចប្រទាក់អ្នកប្រើប្រព័ន្ធ](/images/system_user.png)

## វិធីសាស្ត្រគ្រប់គ្រងប្រព័ន្ធបង្រួម

នៅក្នុង RT-CPMS **អ្នកបំពេញ** គឺគ្រាន់តែជាតួនាទីជាក់លាក់ដែលប្រគល់ឱ្យ **អ្នកប្រើប្រព័ន្ធ** ម្នាក់។ គ្មានមូលដ្ឋានទិន្នន័យ "អ្នកបំពេញ" ដាច់ដោយឡែកទេ។ មិនថាអ្នកប្រើជាអ្នកគ្រប់គ្រងកំរិតខ្ពស់ ដែលតាមដាន portal វេប ឬអ្នកបំពេញស្រុក ដែលប្រមូលទិន្នន័យតាម mobile app ទាំងអស់ត្រូវបានគ្រប់គ្រងក្នុងក្របខ័ណ្ឌប្រព័ន្ធបង្រួមមួយនេះ។

## មុខងារសំខាន់ៗ

### ១. បញ្ជីអ្នកប្រើ & ការមើលក្រឡាចត្រង្គ
ចំណុចប្រទាក់ចម្បងបង្ហាញបញ្ជីទំព័ររបស់អ្នកប្រើទាំងអស់ ដែលភ្ជាប់ជាមួយ workspace។ គុណលក្ខណៈសំខាន់ៗ រួមមាន៖
* **ID & ឈ្មោះអង្គការ**: ការដាក់ជាក្រុមតក្កវិជ្ជារបស់អ្នកប្រើ នៅក្រោមអង្គការជាក់លាក់ (ឧ. `rta`, `partner_org`)។
* **តួនាទី**: បញ្ជាក់កម្រិតការអនុញ្ញាតរបស់អ្នកប្រើ (ឧ. `Administrator`, `Leadteam`, `Enumerator`)។
* **ក្រុម**: ការចាត់តាំងជាក្រុមទំហំ ឬតក្កវិជ្ជា (ឧ. ស្រុកជាក់លាក់ ឬក្រុមប្រតិបត្តិការ)។
* **ត្រូវបានធ្វើសម្រួល**: បង្ហាញថាតើគណនីត្រូវបានរួមបញ្ចូលដោយជោគជ័យ ជាមួយប្រព័ន្ធ Single Sign-On (SSO) កណ្ដាល ឬទេ។
* **ស្ថានភាព**: សូចនាករមើលឃើញ ដែលបញ្ជាក់ថាតើគណនីជា `Active`, `Inactive`, `Deleted`, ឬ `Blocked`។

**សកម្មភាពសកល:**
* **បន្ថែមអ្នកប្រើប្រព័ន្ធ**: បង្កើតប្រវត្តិរូបបុគ្គលដោយដៃ។
* **នាំចូលអ្នកប្រើប្រព័ន្ធ**: ការបង្កើតគណនីជាច្រើនដោយប្រើគំរូ Excel។ អ្នកអាចដោះស្រាយជម្លោះ ដោយប្រើរបៀប `Skip` ឬ `Replace` ហើយធ្វើសម្រួលដោយផ្ទាល់ជាមួយ SSO។
* **លុបចោលជាច្រើន**: ការគាំទ្រ Multi-select សម្រាប់ការដករំលែកគណនីជាច្រើន។

### ២. ការត្រួតពិនិត្យការចូលដំណើរការ & សុវត្ថិភាព
នៅពេលបង្កើត ឬកែប្រែប្រវត្តិរូបអ្នកប្រើ វាលសំខាន់ៗ ពាក់ព័ន្ធនឹងសុវត្ថិភាព និងលំហូរការងារ ដែលអាចរកបាន រួមមាន៖
* **កូដអ្នកប្រើ**: អត្តសញ្ញាណតែមួយគត់ ដែលភ្ជាប់គណនី CPMS ក្នុងស្រុក ទៅឃ្លាំង SSO កណ្ដាល។
* **កូដប្ដូរឧបករណ៍**: និមិត្តសញ្ញាសុវត្ថិភាពដ៏ក្លៀវក្លា ដែលចាំបាច់ នៅពេលអ្នកបំពេញ ត្រូវការប្ដូរឧបករណ៍ mobile ដែលពួកគេប្រើ។
* **កម្រិតឥទ្ធិពល**: ខ្នាតអាទិភាព/ការចូលដំណើរការ ដ៏섬delicate ពី 0 (ទាប) ដល់ 20 (ខ្ពស់)។
* **ការប្ដូរការត្រួតពិនិត្យ**: checkbox ដែលជ្រើសដោយភ្លាមៗ ដើម្បីលើកកម្ពស់អ្នកប្រើទំនងដើម ទៅស្ថានភាពការគ្រប់គ្រង។
* **ស្វ័យប្រវត្តិកម្ម Workflow**: ជម្រើស "អនុម័តដោយស្វ័យប្រវត្តិ សំណើការកែ" ដែលសម្រួលដំណើរការសម្អាតទិន្នន័យ និងការផ្ទៀងផ្ទាត់ សម្រាប់អ្នកប្រើដែលទុកចិត្ត។

### ៣. ការគ្រប់គ្រងកូដ (ការស្វាគមន៍ស្វ័យប្រវត្តិ)
ស្ថិតនៅក្រោមផ្ទាំងរង "Code" មុខងារនេះគ្រប់គ្រងតំណភ្ជាប់ការចុះឈ្មោះ និងការអញ្ជើញ ដែលពឹងផ្អែកលើ hash ដោយសម្រួលដំណើរការស្វាគមន៍ សម្រាប់ក្រុមធំ។

* **ការចុះឈ្មោះ vs ការអញ្ជើញ**: ជ្រើសថាតើអ្នកប្រើអាចចុះឈ្មោះខ្លួនឯង ដោយប្រើតំណភ្ជាប់ ឬប្រសិនបើពួកគេត្រូវការការអញ្ជើញ admin ដោយផ្ទាល់។
* **កាលកំណត់ផុតកំណត់**: ដាក់ការស្វាគមន៍ ទៅក្នុងបង្អួចពេលវេលាជាក់លាក់។
* **ដែនកំណត់ការប្រើប្រាស់**: ដំណាល់ចំនួនអ្នកប្រើ ដែលអាចចូលរួម ដោយប្រើកូដដែលបង្កើតតែមួយ។
* **តួនាទីកំណត់ជាមុន**: អ្នកប្រើ ដែលចូលរួមតាមរយៈកូដទាំងនេះ ទទួលបានដោយស្វ័យប្រវត្តិ នូវតួនាទី និងកម្រិតឥទ្ធិពលដែលបានកំណត់ជាមុន ដោយធានាថាពួកគេ ត្រួចចូលធ្វើការភ្លាមៗ ដោយគ្មានការផ្ដួចផ្ដើម admin ដោយដៃ។

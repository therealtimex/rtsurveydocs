rtSurvey គាំទ្រប្រភេទសំណួរ XLSForm ស្តង់ដារទាំងអស់ រួមជាមួយនឹងផ្នែកពង្រីកជាច្រើន។ ប្រភេទសំណួរនីមួយៗគ្រប់គ្រងប្រភេទទិន្នន័យដែលប្រមូលបាន និងរបៀបដែល input widget ត្រូវបានបង្ហាញលើឧបករណ៍។

ដើម្បីកំណត់ប្រភេទសំណួរ សូមបញ្ចូលឈ្មោះប្រភេទក្នុងជួរ `type` នៃ **survey** worksheet ក្នុង XLSForm របស់អ្នក។

## របៀបដែល type និង appearance ធ្វើការជាមួយគ្នា

`type` កំណត់ **ប្រភេទទិន្នន័យដែលប្រមូល**។ ជួរ `appearance` គ្រប់គ្រង **រូបរាងរបស់ widget**។ ប្រភេទជាច្រើនគាំទ្រ appearances ជាច្រើន — ឧទាហរណ៍ `select_one` អាចបង្ហាញជា radio buttons, dropdown, Likert scale, ឬ compact grid។

សូមមើល [Appearance](../appearance) សម្រាប់បញ្ជីពេញលេញ។

Οι προεπιλεγμένες τιμές στο rtSurvey σας επιτρέπουν να προ-συμπληρώνετε ερωτήσεις με απαντήσεις όταν ο ερωτώμενος τις συναντά για πρώτη φορά. Αυτό το χαρακτηριστικό μπορεί να βελτιώσει σημαντικά την αποτελεσματικότητα έρευνας και την ποιότητα δεδομένων.

## Βασική χρήση

Για να ορίσετε προεπιλεγμένη τιμή, χρησιμοποιήστε τη στήλη `default` στο XLSForm σας:

```
| type    | name        | label                         | default    |
|---------|-------------|-------------------------------|------------|
| date    | survey_date | Ημερομηνία έρευνας            | 2024-07-04 |
| decimal | weight      | Βάρος ερωτώμενου; (σε kg)     | 51.3       |
```

Σε αυτό το παράδειγμα, η ημερομηνία έρευνας θα προ-συμπληρωθεί με 4 Ιουλίου 2024, και το πεδίο βάρους θα ξεκινά με 51,3 kg.

## Δυναμικές προεπιλογές

Το rtSurvey υποστηρίζει δυναμικές προεπιλεγμένες τιμές χρησιμοποιώντας συναρτήσεις:

```
| type | name | label                                    | default  |
|------|------|------------------------------------------| ---------|
| date | d    | Εισαγάγετε την ημερομηνία που συνέβη το γεγονός; | today()  |
```

Εδώ, η συνάρτηση `today()` ορίζει αυτόματα την προεπιλογή στην τρέχουσα ημερομηνία.

## Χαρακτηριστικά ειδικά για rtSurvey

### Προεπιλογές αναγνωρίσιμες από πλαίσιο

Το rtSurvey επεκτείνει τη λειτουργικότητα προεπιλογής με προεπιλογές αναγνωρίσιμες από πλαίσιο:

```
| type    | name     | label             | default            |
|---------|----------|-------------------|---------------------|
| text    | location | Τρέχουσα τοποθεσία| ${current_location} |
```

### Ιεραρχικές προεπιλογές

Το rtSurvey επιτρέπει προεπιλογές βάσει προηγούμενων απαντήσεων:

```
| type    | name     | label       | default         |
|---------|----------|-------------|-----------------|
| text    | city     | Πόλη        |                 |
| text    | district | Περιφέρεια  | ${city}-district|
```

### Προεπιλογή σε επαναλήψεις

Για ερωτήσεις μέσα σε ομάδα επανάληψης, η προεπιλογή υπολογίζεται όταν προστίθεται η επανάληψη:

```
| type         | name      | label               | default                |
|--------------|-----------|---------------------|------------------------|
| begin repeat | visits    | Επισκέψεις κλινικής |                        |
| date         | visit_date| Ημερομηνία επίσκεψης| ${previous_visit_date} |
| end repeat   |           |                     |                        |
```

## Βέλτιστες πρακτικές για χρήση προεπιλογών

1. **Χρήση με φειδώ**: Χρησιμοποιείτε προεπιλογές μόνο όπου βελτιώνουν σημαντικά την αποτελεσματικότητα ή ποιότητα δεδομένων.
2. **Εξασφάλιση ακρίβειας**: Αναθεωρείτε και ενημερώνετε τακτικά στατικές προεπιλεγμένες τιμές.
3. **Διεξοδικές δοκιμές**: Ειδικά κατά τη χρήση δυναμικών ή υπολογισμένων προεπιλογών.
4. **Εκτίμηση εμπειρίας χρήστη**: Βεβαιωθείτε ότι οι προεπιλογές δεν παραπλανούν τους ερωτώμενους ή εισάγουν μεροληψία.
5. **Σαφής τεκμηρίωση**: Βεβαιωθείτε ότι όλα τα μέλη της ομάδας κατανοούν τη λογική πίσω από τις προεπιλεγμένες τιμές.

## Προχωρημένες τεχνικές προεπιλογών

### Τυχαιοποιημένες προεπιλογές

Το rtSurvey υποστηρίζει τυχαιοποιημένες προεπιλογές για ορισμένους τύπους ερωτήσεων:

```
| type              | name    | label        | default           |
|-------------------|---------|--------------|-------------------|
| select_one options| choice  | Επιλέξτε ένα:| random(options)   |
```

### Υπό συνθήκη προεπιλογές

Χρησιμοποιήστε relevance για ορισμό υπό συνθήκη προεπιλογών:

```
| type    | name     | label       | default | relevant        |
|---------|----------|-------------|---------|-----------------|
| text    | other    | Διευκρινίστε| N/A     | ${q1} = 'other' |
```

## Εκτιμήσεις διαχείρισης δεδομένων

- Οι προεπιλεγμένες τιμές συμπεριλαμβάνονται σε εξαγωγές δεδομένων.
- Το χαρακτηριστικό ίχνους ελέγχου του rtSurvey παρακολουθεί πότε αλλάζουν προεπιλεγμένες τιμές από ερωτώμενους.

## Συμπεριφορά εφαρμογής κινητού

- Η εφαρμογή κινητού rtSurvey υποστηρίζει όλες τις λειτουργικότητες προεπιλογής.
- Η εκτός σύνδεσης λειτουργία μπορεί να επηρεάσει ορισμένες δυναμικές προεπιλογές που βασίζονται σε δεδομένα πραγματικού χρόνου.

## Γνωστοί περιορισμοί

- Σύνθετες υπολογισμένες προεπιλογές μπορεί να επηρεάσουν τον χρόνο φόρτωσης φόρμας.
- Ορισμένες δυναμικές προεπιλογές μπορεί να μην λειτουργούν όπως αναμένεται σε λειτουργία προεπισκόπησης.

## Αντιμετώπιση προβλημάτων προεπιλεγμένων τιμών

1. **Η προεπιλογή δεν εμφανίζεται**: Ελέγξτε για συντακτικά σφάλματα στην έκφραση προεπιλογής.
2. **Απροσδόκητες τιμές**: Επαληθεύστε τη λογική υπολογισμού και δοκιμάστε με διάφορα σενάρια.
3. **Προβλήματα απόδοσης**: Βελτιστοποιήστε σύνθετους υπολογισμούς προεπιλογής ή εξετάστε εναλλακτικές προσεγγίσεις.

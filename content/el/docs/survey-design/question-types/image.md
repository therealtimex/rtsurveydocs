Ο τύπος ερώτησης image στα XLSForms και στο rtSurvey επιτρέπει στους ερωτώμενους να καταγράφουν και να υποβάλλουν φωτογραφίες ως μέρος των αποκρίσεών τους. Αυτό το χαρακτηριστικό είναι ιδιαίτερα χρήσιμο για συλλογή οπτικών δεδομένων, τεκμηρίωση παρατηρήσεων ή παροχή αποδείξεων σε έρευνες πεδίου.

## Βασική προδιαγραφή XLSForm

| type  | name        | label                            |
|-------|-------------|----------------------------------|
| image | photo       | Τραβήξτε φωτογραφία της τοποθεσίας |

Για περισσότερες λεπτομέρειες σχετικά με τον βασικό τύπο image, δείτε την [προδιαγραφή XLSForm](https://xlsform.org/en/#question-types).

## Χρήσεις

Οι ερωτήσεις image χρησιμοποιούνται συνήθως για:

1. Τεκμηρίωση συνθηκών πεδίου ή παρατηρήσεων
2. Καταγραφή οπτικών αποδείξεων σε ερευνητικές μελέτες
3. Συλλογή φωτογραφιών πριν/μετά σε αξιολογήσεις επίπτωσης
4. Επαλήθευση ολοκλήρωσης εργασιών ή παρουσίας σε τοποθεσίες
5. Συλλογή οπτικών δεδομένων για απομακρυσμένη ανάλυση

## Βέλτιστες πρακτικές

1. Παρέχετε σαφείς οδηγίες για το τι πρέπει να φωτογραφηθεί.
2. Εξετάστε τις επιπτώσεις στο απόρρητο και ενημερώστε τους ερωτώμενους για τον τρόπο χρήσης των φωτογραφιών τους.
3. Να γνωρίζετε τα μεγέθη αρχείων και τους περιορισμούς αποθήκευσης, ειδικά για έρευνες σε περιοχές με περιορισμένη σύνδεση στο internet.
4. Βεβαιωθείτε ότι η συσκευή έχει επαρκή χώρο αποθήκευσης και χορηγημένες άδειες κάμερας.

## Παράδειγμα χρήσης

Δείτε πώς μπορείτε να χρησιμοποιήσετε ερώτηση image σε έρευνα:

| type  | name           | label                                    | hint                                              |
|-------|----------------|------------------------------------------|---------------------------------------------------|
| image | storefront     | Τραβήξτε φωτογραφία της εισόδου του καταστήματος | Βεβαιωθείτε ότι το όνομα του καταστήματος φαίνεται καθαρά |

## Επεκτάσεις rtSurvey

Ενώ η βασική προδιαγραφή XLSForm για ερωτήσεις image είναι απλή, το rtSurvey μπορεί να προσφέρει επιπλέον χαρακτηριστικά ή προσαρμογές:

1. Ρυθμίσεις ποιότητας εικόνας (π.χ. χαμηλή, μέτρια, υψηλή ανάλυση)
2. Επιλογή προσθήκης λεζαντών ή ετικετών σε εικόνες
3. Λήψη πολλαπλών εικόνων για μία ερώτηση
4. Ενσωμάτωση με την εγγενή εφαρμογή κάμερας ή συλλογής της συσκευής

## Χειρισμός δεδομένων

Οι εικόνες που συλλέγονται μέσω αυτού του τύπου ερώτησης συνήθως:

1. Αποθηκεύονται σε κοινή μορφή εικόνας (π.χ. JPG, PNG)
2. Αποθηκεύονται μαζί με άλλα δεδομένα έρευνας, συχνά σε ξεχωριστό φάκελο πολυμέσων
3. Είναι προσβάσιμες για προβολή και ανάλυση μέσω της πλατφόρμας διαχείρισης ερευνών

## Εκτιμήσεις για ανάλυση

Κατά τη χρήση ερωτήσεων image, εξετάστε:

1. Πώς θα αναλυθούν οι εικόνες (π.χ. χειροκίνητη αναθεώρηση, αυτοματοποιημένη ανάλυση εικόνας)
2. Τον επιπλέον χώρο αποθήκευσης που απαιτείται για αρχεία εικόνων
3. Μέτρα προστασίας απορρήτου και δεδομένων για αποθήκευση και χειρισμό φωτογραφιών
4. Πιθανή ανάγκη εργαλείων επεξεργασίας ή οργάνωσης εικόνων στη φάση ανάλυσης

## Επεκτάσεις εμφάνισης rtSurvey

Το rtSurvey επεκτείνει τον τύπο `image` με δύο επιπλέον επιλογές εμφάνισης:

| Εμφάνιση | Περιγραφή |
|----------|-----------|
| `watermark("έκφραση")` | Επικαλύπτει ένα κείμενο υδατογράφημα στις ληφθείσες φωτογραφίες. Το όρισμα είναι έκφραση XPath που αξιολογείται κατά τη λήψη. Παράδειγμα: `watermark("${id} ${today()}")` |
| `editable` | Ενεργοποιεί σχολιασμό/σχέδιο πάνω στη ληφθείσα φωτογραφία πριν την αποθήκευση |

### Παράδειγμα: Υδατογράφημα με ID ερωτώμενου και ημερομηνία

| type | name | label | appearance |
|------|------|-------|------------|
| image | site_photo | Τραβήξτε φωτογραφία της τοποθεσίας | `watermark("${respondent_id} ${today()}")` |

## Περιορισμοί

- Τα αρχεία εικόνων μπορεί να είναι μεγάλα, γεγονός που μπορεί να επηρεάσει τη μεταφορά και αποθήκευση δεδομένων.
- Δεν έχουν όλες οι συσκευές κάμερες υψηλής ποιότητας ή επαρκή χώρο αποθήκευσης.
- Η ανάλυση μεγάλου αριθμού εικόνων μπορεί να είναι χρονοβόρα.
- Ενδέχεται να υπάρχουν ανησυχίες απορρήτου κατά τη λήψη εικόνων, ειδικά σε δημόσιους χώρους.

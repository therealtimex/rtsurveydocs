Ο τύπος ερώτησης decimal στα XLSForms και στο rtSurvey χρησιμοποιείται για τη συλλογή αριθμητικών αποκρίσεων που μπορεί να περιλαμβάνουν κλασματικά μέρη. Αυτός ο τύπος ερώτησης είναι απαραίτητος για τη συλλογή ακριβών αριθμητικών δεδομένων όπως μετρήσεις, τιμές ή ποσοστά.

## Βασική προδιαγραφή XLSForm

| type    | name   | label                      |
|---------|--------|----------------------------|
| decimal | weight | Εισαγάγετε το βάρος σας σε kg |

Για περισσότερες λεπτομέρειες σχετικά με τον βασικό τύπο decimal, δείτε την [προδιαγραφή XLSForm](https://xlsform.org/en/#question-types).

## Χρήσεις

Οι ερωτήσεις decimal χρησιμοποιούνται συνήθως για:

1. Μετρήσεις (π.χ. βάρος, ύψος, απόσταση)
2. Οικονομικά δεδομένα (π.χ. τιμές, μισθοί)
3. Ποσοστά
4. Επιστημονική συλλογή δεδομένων
5. Οποιαδήποτε αριθμητικά δεδομένα που απαιτούν ακρίβεια πέρα από ολόκληρους αριθμούς

## Βέλτιστες πρακτικές

1. Χρησιμοποιήστε σαφείς και συνοπτικές ετικέτες για να καθορίσετε την αναμενόμενη είσοδο και μονάδα μέτρησης.
2. Εφαρμόστε περιορισμούς εύρους για αποτροπή μη ρεαλιστικών ή λανθασμένων εισόδων.
3. Εξετάστε τη χρήση κειμένου υπόδειξης για παροχή παραδειγμάτων ή διευκρίνιση της αναμενόμενης μορφής.
4. Καθορίστε τον επιθυμητό αριθμό δεκαδικών ψηφίων στην ετικέτα ή υπόδειξη εάν η ακρίβεια είναι σημαντική.

## Περιορισμοί και επικύρωση

Μπορείτε να προσθέσετε περιορισμούς για να διασφαλίσετε ότι η εισαγόμενη τιμή εμπίπτει σε συγκεκριμένο εύρος:

| type    | name   | label                         | constraint        | constraint_message                          |
|---------|--------|-------------------------------|-------------------|---------------------------------------------|
| decimal | height | Εισαγάγετε το ύψος σας σε μέτρα | .>0 and .<=3    | Το ύψος πρέπει να είναι μεταξύ 0 και 3 μέτρων |

## Παράδειγμα χρήσης

Δείτε πώς μπορείτε να χρησιμοποιήσετε ερωτήσεις decimal σε έρευνα υγείας:

| type    | name           | label                                     | constraint | constraint_message                              |
|---------|----------------|-------------------------------------------|------------|------------------------------------------------|
| decimal | weight         | Εισαγάγετε το βάρος σας σε kg             | .>0 and .<=500 | Το βάρος πρέπει να είναι μεταξύ 0 και 500 kg |
| decimal | height         | Εισαγάγετε το ύψος σας σε μέτρα           | .>0 and .<=3 | Το ύψος πρέπει να είναι μεταξύ 0 και 3 μέτρων |
| decimal | body_temp      | Εισαγάγετε τη θερμοκρασία σώματος σε Κελσίου | .>=35 and .<=42 | Η θερμοκρασία πρέπει να είναι μεταξύ 35°C και 42°C |
| calculate | bmi          |                                           |            |                                               |

Στη γραμμή calculate για ΔΜΣ, μπορείτε να χρησιμοποιήσετε:

```
calculation | ${weight} / (${height} * ${height})
```

Αυτό υπολογίζει τον Δείκτη Μάζας Σώματος χρησιμοποιώντας το εισαχθέν βάρος και ύψος.

## Επεκτάσεις rtSurvey

Ενώ η βασική προδιαγραφή XLSForm για ερωτήσεις decimal είναι απλή, το rtSurvey μπορεί να προσφέρει επιπλέον χαρακτηριστικά ή προσαρμογές:

1. Έλεγχος ακρίβειας (αριθμός δεκαδικών ψηφίων)
2. Προσαρμοσμένες μορφές εισόδου (π.χ. ποσοστό, νόμισμα)
3. Προχωρημένοι κανόνες επικύρωσης

## Περιορισμοί

- Η ακρίβεια των δεκαδικών αριθμών μπορεί να περιορίζεται από το υποκείμενο σύστημα ή τη βάση δεδομένων.
- Οι χρήστες μπορεί να χρειάζονται καθοδήγηση σχετικά με τον αναμενόμενο διαχωριστή δεκαδικών (τελεία ή κόμμα) ανάλογα με τη γλωσσική τους ρύθμιση.
- Μεγάλοι δεκαδικοί αριθμοί μπορεί να είναι δύσκολο να διαβαστούν ή να εισαχθούν με ακρίβεια σε κινητές συσκευές.

Το rtSurvey παρέχει ισχυρή υποστήριξη πολλαπλών γλωσσών, επιτρέποντάς σας να δημιουργείτε έρευνες σε πολλαπλές γλώσσες. Αυτό το χαρακτηριστικό είναι κρίσιμο για τη διεξαγωγή ερευνών σε διαφορετικούς γλωσσικούς πληθυσμούς ή σε πολυγλωσσικά περιβάλλοντα.

## Ρύθμιση πολυγλωσσικών ερευνών

Για να δημιουργήσετε πολυγλωσσική έρευνα στο rtSurvey, πρέπει να προσθέσετε στήλες ειδικές για γλώσσα στο XLSForm σας:

1. **Μεταφράσεις ετικετών**: Προσθέστε στήλες για κάθε γλώσσα χρησιμοποιώντας τη μορφή `label::Language (code)`.
2. **Μεταφράσεις υποδείξεων**: Χρησιμοποιήστε `hint::Language (code)` για μετάφραση υποδείξεων.
3. **Μεταφράσεις αρχείων πολυμέσων**: Για πολυμέσα ειδικά για γλώσσα, χρησιμοποιήστε `media::Language (code)`.

Παράδειγμα:

```
| type    | name | label::English (en) | label::Español (es) | hint::English (en) | hint::Español (es) |
|---------|------|---------------------|---------------------|---------------------|---------------------|
| integer | age  | How old are you?    | ¿Cuántos años tienes?| Enter your age      | Ingrese su edad     |
```

## Κωδικοί γλωσσών

Συνιστάται η χρήση των επίσημων κωδικών γλώσσας 2 χαρακτήρων (subtags) μετά το όνομα γλώσσας. Αυτό διευκολύνει την αντιστοίχιση γλώσσας φόρμας με γλώσσα διεπαφής χρήστη. Τους επίσημους κωδικούς μπορείτε να βρείτε [εδώ](https://www.iana.org/assignments/language-subtag-registry/language-subtag-registry).

## Ορισμός προεπιλεγμένης γλώσσας

Για ορισμό προεπιλεγμένης γλώσσας για συλλογή δεδομένων, χρησιμοποιήστε το φύλλο εργασίας `settings` στο XLSForm σας:

```
| form_id   | version | default_language |
|-----------|---------|-------------------|
| test_form | 101     | French (fr)       |
```

## Χαρακτηριστικά ειδικά για rtSurvey

### Δυναμική εναλλαγή γλώσσας

Το rtSurvey επιτρέπει στους χρήστες να εναλλάσσουν γλώσσες δυναμικά κατά τη συλλογή δεδομένων:

- Στη web διεπαφή, χρησιμοποιήστε το αναπτυσσόμενο γλωσσών στη γραμμή κεφαλίδας πλοήγησης.
- Στην εφαρμογή κινητού, αποκτήστε πρόσβαση στις επιλογές γλώσσας μέσω του μενού ρυθμίσεων.

### Μηνύματα επικύρωσης ειδικά για γλώσσα

Το rtSurvey επεκτείνει την πολυγλωσσική υποστήριξη σε μηνύματα επικύρωσης:

```
| type    | name | constraint | constraint_message::English (en) | constraint_message::Español (es) |
|---------|------|------------|----------------------------------|----------------------------------|
| integer | age  | . <= 150   | Age must be 150 or less          | La edad debe ser 150 o menos     |
```

### Υποστήριξη γλωσσών RTL

Για γλώσσες που γράφονται από δεξιά προς τα αριστερά (RTL) όπως Αραβικά ή Εβραϊκά, το rtSurvey προσαρμόζει αυτόματα τη διάταξη:

```
| type | name | label::English (en) | label::Arabic (ar) |
|------|------|---------------------|---------------------|
| text | name | Your name           | اسمك                |
```

### Εμφάνιση ειδική για γλώσσα

Το rtSurvey σας επιτρέπει να καθορίζετε διαφορετικές εμφανίσεις για διαφορετικές γλώσσες:

```
| type | name | label::English (en) | label::Chinese (zh) | appearance::English (en) | appearance::Chinese (zh) |
|------|------|---------------------|---------------------|--------------------------|---------------------------|
| text | address | Address          | 地址                 | multiline                | textarea                  |
```

## Βέλτιστες πρακτικές για πολυγλωσσικές έρευνες

1. **Συνεπής ονοματολογία**: Χρησιμοποιείτε συνεπείς κωδικούς γλωσσών σε ολόκληρη τη φόρμα σας.
2. **Επαγγελματική μετάφραση**: Χρησιμοποιείτε επαγγελματίες μεταφραστές που γνωρίζουν το πλαίσιο της έρευνας.
3. **Σημειώσεις πλαισίου**: Παρέχετε σημειώσεις πλαισίου για μεταφραστές για διασφάλιση ακριβών μεταφράσεων.
4. **Δοκιμές**: Δοκιμάστε τη φόρμα σας σε όλες τις γλώσσες πριν την ανάπτυξη.
5. **Υποστήριξη Unicode**: Βεβαιωθείτε ότι οι συσκευές συλλογής δεδομένων υποστηρίζουν Unicode για μη λατινικές γραφές.
6. **Πολυμέσα ειδικά για γλώσσα**: Χρησιμοποιείτε πολιτισμικά κατάλληλες εικόνες ή ήχο για κάθε γλώσσα.
7. **Αποφύγετε κείμενο σε εικόνες**: Εάν χρησιμοποιείτε εικόνες με κείμενο, δημιουργήστε ξεχωριστές εικόνες για κάθε γλώσσα.

## Χειρισμός ειδικών περιπτώσεων

### Αποκρίσεις μικτής γλώσσας

Το rtSurvey επιτρέπει στους ερωτώμενους να εισάγουν κείμενο σε οποιαδήποτε γραφή, ανεξάρτητα από την επιλεγμένη γλώσσα φόρμας.

### Εξαγωγή πολυγλωσσικών δεδομένων

Κατά την εξαγωγή δεδομένων από το rtSurvey:

- Επιλέξτε εξαγωγή σε συγκεκριμένη γλώσσα ή συμπεριλάβετε όλες τις γλωσσικές εκδοχές.
- Μεταδεδομένα γλώσσας συμπεριλαμβάνονται στην εξαγωγή, υποδεικνύοντας ποια γλώσσα χρησιμοποιήθηκε για κάθε απόκριση.

## Εκτιμήσεις εφαρμογής κινητού

- Η εφαρμογή κινητού rtSurvey υποστηρίζει εκτός σύνδεσης εναλλαγή γλώσσας.
- Βεβαιωθείτε ότι όλα τα απαιτούμενα αρχεία γλώσσας έχουν ληφθεί πριν πάτε εκτός σύνδεσης.

## Γνωστοί περιορισμοί

- Ορισμένα προχωρημένα χαρακτηριστικά μπορεί να μην είναι διαθέσιμα σε όλες τις γλώσσες.
- Εξαιρετικά μεγάλες μεταφράσεις μπορεί να επηρεάσουν τη διάταξη σε μικρότερες οθόνες.

Το **Webbox** ενσωματώνει εξωτερική ιστοσελίδα μέσα στην έρευνα ως **αναδυόμενο παράθυρο modal** (iframe). Ο απογραφέας πατά κουμπί στην ετικέτα ή κείμενο σημείωσης, η σελίδα ανοίγει σε επικάλυψη πλήρους οθόνης μέσα στη φόρμα, και όταν την κλείνουν επιστρέφουν ακριβώς εκεί που ήταν. Αυτό σάς επιτρέπει να εμφανίζετε υλικό αναφοράς, χάρτες, πίνακες ελέγχου ή προσαρμοσμένα εργαλεία χωρίς άνοιγμα ξεχωριστής καρτέλας προγράμματος περιήγησης.

---

## Σύνταξη

Εισάγετε ετικέτα HTML `<webbox>` απευθείας στη στήλη ετικέτας `label` ή `note`:

```html
<webbox src='https://example.com/reference' title='Οδηγός Αναφοράς'>Άνοιγμα Οδηγού Αναφοράς</webbox>
```

| Χαρακτηριστικό | Περιγραφή |
|-----------|-------------|
| `src` | Η URL για φόρτωση στο iframe. Υποστηρίζει μονά και διπλά εισαγωγικά. |
| `title` | Κείμενο που εμφανίζεται στη γραμμή κεφαλίδας modal. Υποστηρίζει απλό κείμενο. |
| *(περιεχόμενο)* | Η ετικέτα κουμπιού με δυνατότητα κλικ που εμφανίζεται στο πεδίο έρευνας |

---

## Βασικό παράδειγμα

| type | name | label |
|------|------|-------|
| note | ref_guide | `<webbox src='https://docs.example.com/field-guide' title='Οδηγός Πεδίου'>Άνοιγμα Οδηγού Πεδίου</webbox>` |

Αυτό αποδίδει κουμπί με ετικέτα "Άνοιγμα Οδηγού Πεδίου". Όταν πατηθεί, ανοίγει modal που εμφανίζει τον ιστότοπο οδηγού πεδίου.

## Μεταφορά τιμών φόρμας στη ενσωματωμένη σελίδα

Προσθέστε τιμές πεδίων φόρμας στη URL χρησιμοποιώντας `concat()` στη στήλη `calculation` και αναφερθείτε στο αποτέλεσμα στην ετικέτα:

| type | name | label | calculation |
|------|------|-------|-------------|
| calculate | webbox_url | | `concat('https://dashboard.example.com/household?id=', ${household_id})` |
| note | hh_dash | `<webbox src='${webbox_url}' title='Πίνακας Ελέγχου Νοικοκυριού'>Άνοιγμα Πίνακα Ελέγχου</webbox>` |

{{% alert icon=" " context="warning" %}}
Το χαρακτηριστικό `src` στην ετικέτα `<webbox>` υποστηρίζει αναφορές `${fieldname}` όταν η ετικέτα υπολογίζεται από πεδίο `calculate`. Κατασκευάστε την πλήρη URL σε πεδίο `calculate` και αναφερθείτε σε αυτό.
{{% /alert %}}

## Αλληλεπίδραση επανάληψης: κουμπιά διαγραφής

Το Webbox υποστηρίζει επίσης ειδικές ετικέτες ενέργειας για διαχείριση ομάδων επανάληψης μέσα σε ετικέτες:

```html
<delete-repeat-current>Αφαίρεση αυτής της γραμμής</delete-repeat-current>
<delete-repeat-last>Αφαίρεση τελευταίας γραμμής</delete-repeat-last>
```

Αυτά αποδίδονται ως κουμπιά που διαγράφουν παρουσίες επανάληψης όταν πατηθούν. Τοποθετήστε τα σε πεδίο `note` μέσα (ή αμέσως μετά) την ομάδα επανάληψης:

| type | name | label |
|------|------|-------|
| begin_repeat | items | Στοιχείο |
| text | item_name | Όνομα στοιχείου |
| note | delete_btn | `<delete-repeat-current>Αφαίρεση αυτού του στοιχείου</delete-repeat-current>` |
| end_repeat | | |

## Επικοινωνία με ενσωματωμένη σελίδα (postMessage)

Το iframe webbox και η γονική φόρμα μπορούν να επικοινωνούν χρησιμοποιώντας το API `postMessage` του προγράμματος περιήγησης. Το γονικό στέλνει μήνυμα `init` στο iframe όταν ανοίγει. Η ενσωματωμένη σελίδα μπορεί να αποκριθεί με:

- `delete-repeat-current` — ενεργοποιεί διαγραφή της τρέχουσας παρουσίας επανάληψης
- `delete-repeat-last` — ενεργοποιεί διαγραφή της τελευταίας παρουσίας επανάληψης

Αυτό επιτρέπει σε προσαρμοσμένα εργαλεία web (π.χ. εργαλεία σχεδίασης, διαδραστικοί χάρτες) να ενεργοποιούν ενέργειες φόρμας όταν ο χρήστης επιβεβαιώσει ενέργεια μέσα στο iframe.

## Βέλτιστες πρακτικές

1. Χρησιμοποιείτε το webbox για **υλικό αναφοράς** (οδηγίες, πίνακες αναζήτησης, χάρτες) — όχι για συλλογή δεδομένων που θα πρέπει να βρίσκονται στη φόρμα.
2. Βεβαιωθείτε ότι η ενσωματωμένη URL είναι προσπελάσιμη από το δίκτυο της συσκευής — το webbox απαιτεί συνδεσιμότητα.
3. Διατηρείτε την ενσωματωμένη σελίδα φιλική για κινητό — το modal έχει μέγιστο πλάτος 800px και 80% ύψος παραθύρου.
4. Χρησιμοποιείτε περιγραφικό κείμενο κουμπιού (π.χ. "Προβολή Χάρτη Χωριού") αντί για γενικές ετικέτες ("Κάντε κλικ εδώ").
5. Ενημερώνετε τους απογραφείς ότι το κλείσιμο του modal τους επιστρέφει στην έρευνα — ορισμένοι χρήστες ενδέχεται να μην ξέρουν πώς να κλείσουν επικάλυψη iframe.

## Περιορισμοί

- Το Webbox απαιτεί συνδεσιμότητα δικτύου για φόρτωση της ενσωματωμένης URL.
- Ορισμένοι εξωτερικοί ιστότοποι εμποδίζουν ενσωμάτωση σε iframes μέσω κεφαλίδων `X-Frame-Options` ή `Content-Security-Policy` — αυτοί οι ιστότοποι δεν μπορούν να χρησιμοποιηθούν με webbox.
- Το modal κλείνει όταν ο απογραφέας πλοηγείται μακριά από την ερώτηση — οποιαδήποτε μη αποθηκευμένη κατάσταση στο iframe χάνεται.
- Το Webbox είναι επέκταση φόρμας web rtSurvey και ενδέχεται να μην λειτουργεί σε άλλους πελάτες συμβατούς με ODK.

Η ενότητα **Διαχείριση φορμών** χρησιμεύει ως πύλη για την οργάνωση των οργάνων έρευνας και τον συντονισμό εργασιών πεδίου. Παρέχει λεπτομερή έλεγχο πρόσβασης φόρμας, προβολής δεδομένων και στόχευσης συσκευών.

![Διεπαφή διαχείρισης φορμών](/images/manage_forms.png)

## Επισκόπηση οικογένειας φορμών

Στο μενού **Φόρμα και εισαγωγή δεδομένων**, η ενότητα **Οικογένεια φορμών** εμφανίζει ένα ολοκληρωμένο πλέγμα όλων των εισαγόμενων φορμών σας μαζί με βασικά στοιχεία ελέγχου γρήγορης πρόσβασης. Αυτή η κεντρική προβολή επιτρέπει στους διαχειριστές έργων να αναπτύσσουν και να διαμορφώνουν γρήγορα μεμονωμένες έρευνες.

### Κύριες στήλες δεδομένων και επιλογές διαμόρφωσης

- **Προβολή δεδομένων:** Πρόσβαση σε υποβεβλημένες εγγραφές και προεπισκοπήσεις συνόλων δεδομένων απευθείας για κάθε φόρμα.
- **Να επιτρέπεται επεξεργασία:** Γρήγορη εναλλαγή για κλείδωμα ή ξεκλείδωμα της δυνατότητας επεξεργασίας υποβεβλημένων δεδομένων (καταστάσεις Ενεργό/Ανενεργό).
- **Δημόσια ορατότητα:** Εναλλαγή για δημόσια διαθεσιμότητα φόρμας χωρίς απαιτούμενη ταυτοποίηση.
- **URL φόρμας web:** Άμεση ανάκτηση του μοναδικού δημόσιου συνδέσμου για κοινοποίηση.
- **Παράκαμψη ρυθμίσεων:** Προχωρημένο μοντάλ διαμορφώσεων (μέσω εικονιδίου γραναζιού) για προσαρμογή κανόνων και τιμών ανά φόρμα.
- **Αναγνωριστικά φόρμας:** Προβολή τυπικών μεταδεδομένων, συμπεριλαμβανομένου ονόματος οικογένειας, κωδικού οικογένειας και μοναδικού ID φόρμας.
- **Γεωγραφική διαμόρφωση:** Συγκεκριμένες διαμορφώσεις χαρτογράφησης ή geopoint συνδεδεμένες με τη δομή φόρμας.
- **Κλείδωμα φόρμας:** Χαρακτηριστικό για κλείδωμα πρόσβασης υποβολής κατά την οριστικοποίηση φάσης συλλογής δεδομένων.

## Ενέργειες φόρμας και πλοήγηση

Ο άνω πίνακας ελέγχου διευκολύνει μαζικές λειτουργίες και εναλλακτικές προβολές φόρμας:

- **Ενέργεια στη συσκευή:** Ισχυρό αναπτυσσόμενο εργαλείο που επιτρέπει ανάθεση εργασιών, αποστολή στοχευμένων φορμών ή αποστολή ενεργειών απευθείας σε συσκευές πεδίου.
- **Καρτέλα XLSX Form:** Γρήγορη πλοήγηση για μεταφόρτωση νέων εγγενών αρχείων XLSForm.
- **Καρτέλα Form Builder:** Πρόσβαση στο ενσωματωμένο εργαλείο για οπτική κατασκευή ή τροποποίηση φορμών χωρίς εξωτερικό λογισμικό υπολογιστικών φύλλων.

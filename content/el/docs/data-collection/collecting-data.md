Μόλις έχει αναπτυχθεί μια φόρμα και έχουν ανατεθεί απογραφείς, μπορεί να ξεκινήσει η συλλογή δεδομένων. Το **rtSurvey** υποστηρίζει απρόσκοπτη συγκέντρωση δεδομένων τόσο μέσω προγραμμάτων περιήγησης web όσο και αποκλειστικών εφαρμογών κινητού, εξασφαλίζοντας ευελιξία είτε η ομάδα σας είναι συνδεδεμένη στο διαδίκτυο είτε εργάζεται σε απομακρυσμένα, offline περιβάλλοντα.

## Επιλογή της κατάλληλης μεθόδου συλλογής

Ανάλογα με τη γεωγραφία και τη συνδεσιμότητα του έργου σας, μπορείτε να επιλέξετε τη βέλτιστη μέθοδο για τους απογραφείς σας:

- **Πρόγραμμα περιήγησης Web (Online):** Βέλτιστο για τηλεφωνικά κέντρα, εισαγωγή δεδομένων από γραφείο ή ερωτώμενους που συμπληρώνουν αυτοδιαχειριζόμενες δημόσιες έρευνες.
- **rtWork / Εφαρμογή κινητού rtSurvey (Online και Offline):** Βέλτιστο για επιχειρήσεις πεδίου, απομακρυσμένες περιοχές με ασταθές διαδίκτυο και έρευνες που απαιτούν συνημμένα πολυμέσα (φωτογραφίες, συντεταγμένες GPS, χάρτες offline).

---

## Μέθοδος 1: Συλλογή δεδομένων μέσω προγράμματος περιήγησης Web

Χρησιμοποιώντας τη διεπαφή Webform επιτρέπει στους απογραφείς να ξεκινήσουν αμέσως τη συλλογή δεδομένων χωρίς εγκατάσταση λογισμικού.

### 1. Πρόσβαση στη URL Webform
Από τον πίνακα ελέγχου **Διαχείρισης Φορμών** στον Πίνακα Ελέγχου, εντοπίστε τη φόρμα στόχο σας και κάντε κλικ στο κουμπί **URL Webform** για δημιουργία ασφαλούς συνδέσμου.

### 2. Εισαγωγή φόρμας
- Ανοίξτε την παρεχόμενη URL σε οποιοδήποτε σύγχρονο πρόγραμμα περιήγησης web.
- Εάν η φόρμα απαιτεί ταυτοποίηση, ο απογραφέας πρέπει να συνδεθεί χρησιμοποιώντας τα διαπιστευτήριά του. Εάν ορίζεται ως "Δημόσια Ορατότητα", μπορούν να προχωρήσουν απευθείας.
- Συμπληρώστε τις ερωτήσεις έρευνας. Η διεπαφή θα εφαρμόσει αυτόματα λογική, μοτίβα παράλειψης και κανόνες επικύρωσης.
- **Λήψη πολυμέσων:** Εάν η φόρμα περιλαμβάνει ερωτήσεις εικόνας, ήχου ή βίντεο, το πρόγραμμα περιήγησης θα σας ζητήσει να ανεβάσετε αρχείο από τον υπολογιστή σας ή να χρησιμοποιήσετε κάμερα web/μικρόφωνο συσκευής εάν διατίθεται.

### 3. Υποβολή
Κατά την πρόσβαση στην τελευταία σελίδα, κάντε κλικ στην **Υποβολή**. Το πρόγραμμα περιήγησης απαιτεί ενεργή σύνδεση στο διαδίκτυο για ολοκλήρωση της υποβολής. Μόλις επιτύχει, τα δεδομένα θα αντικατοπτριστούν άμεσα στη διεπαφή **Διαχείρισης Υποβολών**.

## Μέθοδος 2: Συλλογή δεδομένων μέσω εφαρμογής κινητού (Offline)

Για αξιόπιστη συλλογή δεδομένων πεδίου, οι εφαρμογές κινητού παρέχουν πλήρεις δυνατότητες offline.

### 1. Εγκατάσταση και ταυτοποίηση
- Κατεβάστε την εφαρμογή **rtWork** (ή **rtSurvey**) από το Google Play Store ή το Apple App Store.
- Ανοίξτε την εφαρμογή και συνδεθείτε χρησιμοποιώντας τα διαπιστευτήρια του ανατεθέντος απογραφέα.

### 2. Λήψη φορμών (Απαιτεί διαδίκτυο)
- Μεταβείτε στην ενότητα **Φόρμες** ή **Εργασίες** στην εφαρμογή.
- Πατήστε το εικονίδιο **Συγχρονισμός** ή **Λήψη** για ανάκτηση των τελευταίων σχεδίων ερωτηματολογίων από τον διακομιστή. Μόλις ληφθούν, οι φόρμες αποθηκεύονται τοπικά στη συσκευή.

### 3. Συλλογή δεδομένων (Offline)
- Ανοίξτε τη ληφθείσα φόρμα και ξεκινήστε τη συνέντευξη.
- Μπορείτε να συλλέγετε δεδομένα με ασφάλεια εντελώς offline.
- **Λήψη πολυμέσων:** Η εφαρμογή κινητού ενσωματώνεται φυσικά με το υλικό της συσκευής σας. Μπορείτε να λαμβάνετε φωτογραφίες, να ηχογραφείτε, να καταγράφετε βίντεο και να καταγράφετε ακριβείς συντεταγμένες GPS απευθείας στην εφαρμογή, ακόμα και χωρίς σύνδεση στο διαδίκτυο.
- Όταν ολοκληρώσετε μια συνέντευξη, οριστικοποιήστε την εγγραφή. Οι οριστικοποιημένες εγγραφές τοποθετούνται σε ουρά με ασφάλεια στα εξερχόμενα της εφαρμογής.

### 4. Συγχρονισμός υποβολών (Απαιτεί διαδίκτυο)
- Μόλις ο απογραφέας επιστρέψει σε περιοχή με πρόσβαση στο διαδίκτυο (Wi-Fi ή κινητά δεδομένα), πρέπει να μεταβεί στη διεπαφή **Εξερχόμενα** ή **Συγχρονισμός**.
- Δώστε εντολή στην εφαρμογή να στείλει τις οριστικοποιημένες φόρμες. Η εφαρμογή θα μεταδώσει τις εγγραφές σε ουρά και όλα τα συνημμένα αρχεία πολυμέσων με ασφάλεια στον διακομιστή, μετά τα οποία θα εμφανιστούν στο πλέγμα δεδομένων για αναθεώρηση.

ฟิลด์แบบอ่านอย่างเดียวใน rtSurvey ช่วยให้คุณแสดงข้อมูลที่ผู้ตอบแบบสำรวจไม่สามารถแก้ไขได้ ฟีเจอร์นี้มีประโยชน์โดยเฉพาะสำหรับการแสดงข้อมูลที่เติมล่วงหน้า ผลลัพธ์ที่คำนวณ หรือข้อมูลที่ควรคงที่ตลอดการสำรวจ

## การใช้งานพื้นฐาน

ในการทำให้ฟิลด์เป็นแบบอ่านอย่างเดียว ให้ใช้คอลัมน์ `read_only` ใน XLSForm ของคุณ:

```
| type    | name | label                 | read_only | default |
|---------|------|----------------------|-----------|---------|
| integer | num  | Patient number is:    | yes       | 5       |
```

## การรวมแบบอ่านอย่างเดียวกับค่าเริ่มต้น

ฟิลด์แบบอ่านอย่างเดียวมักใช้ร่วมกับค่าเริ่มต้นเพื่อแสดงข้อมูลที่กำหนดไว้ล่วงหน้าหรือคำนวณได้:

```
| type    | name     | label               | read_only | default        |
|---------|----------|---------------------|-----------|----------------|
| text    | username | Logged in user:     | yes       | ${current_user}|
| date    | today    | Today's date:       | yes       | today()        |
```

## แนวทางปฏิบัติที่ดีที่สุด

1. **ความชัดเจน**: ระบุฟิลด์ที่เป็นแบบอ่านอย่างเดียวอย่างชัดเจนผ่านสัญลักษณ์ภาพหรือป้ายกำกับ
2. **ความสม่ำเสมอ**: ใช้ฟิลด์แบบอ่านอย่างเดียวอย่างสม่ำเสมอตลอดทั้งแบบสำรวจ
3. **การตรวจสอบ**: แม้ว่าฟิลด์แบบอ่านอย่างเดียวจะไม่สามารถแก้ไขได้ แต่ให้รวมอยู่ในกระบวนการตรวจสอบข้อมูลของคุณ
4. **ประสิทธิภาพ**: ระวังการคำนวณที่ซับซ้อนในฟิลด์แบบอ่านอย่างเดียว
5. **การเข้าถึง**: ตรวจสอบให้แน่ใจว่าฟิลด์แบบอ่านอย่างเดียวถูกทำเครื่องหมายอย่างเหมาะสมสำหรับ screen readers

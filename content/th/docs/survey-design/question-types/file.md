ประเภทคำถาม `file` ให้ผู้ตอบแบบสำรวจ **อัปโหลดไฟล์ใดๆ** จากอุปกรณ์ของตน — เอกสาร สเปรดชีต PDF หรือประเภทไฟล์อื่นๆ ต่างจาก `image`, `audio` และ `video` ที่เปิดเครื่องมือบันทึกเฉพาะทาง `file` จะเปิด file picker ทั่วไป

ประเภทคำถาม `select_multiple` แสดงรายการที่ผู้ตอบแบบสำรวจสามารถเลือก **ตัวเลือกหนึ่งหรือหลายอย่าง** โดยค่าเริ่มต้นตัวเลือกจะแสดงเป็น checkbox ค่าที่จัดเก็บเป็น **รายการที่คั่นด้วยช่องว่าง** ของค่าตัวเลือกที่เลือกทั้งหมด

## ตัวเลือก Appearance

{{< table >}}
| Appearance | คำอธิบาย |
|------------|----------|
| *(ไม่มี)* | Checkbox ค่าเริ่มต้น หนึ่งรายการต่อบรรทัด |
| `minimal` | วิดเจ็ต multi-select แบบ dropdown |
| `compact` | Grid compact ปรับคอลัมน์ตามความกว้างหน้าจอ |
| `compact-N` | Grid compact บังคับ N คอลัมน์ |
| `horizontal` | ตัวเลือกเรียงแนวนอนในแถว (เว็บ) |
| `columns(N)` | แสดงใน N คอลัมน์ (ส่วนขยาย rtSurvey) |
| `tagging` | ตัวเลือกแสดงเป็นชิปแท็กรูปเม็ดยา |
| `boxtag` | ตัวเลือกแสดงเป็นกล่องสี่เหลี่ยมที่มีสไตล์ |
| `boxtag -search` | เลย์เอาต์ Boxtag พร้อมช่องค้นหา/กรองเหนือกล่อง |
| `duolingo-style1` | เลย์เอาต์การ์ดขนาดใหญ่ — เหมาะสำหรับรายการตัวเลือกสั้น |
| `rating_box` | กล่องคะแนนแบบ Grid |
| `choices-noshow` | แสดง 10 ตัวเลือกแรกเริ่มต้น; เผยตัวเลือกที่เหลือตามต้องการ |
| `checkall` | เพิ่มตัวเลือก "เลือกทั้งหมด" ที่ด้านบนของรายการ |
| `max-items(N)` | จำกัดจำนวนตัวเลือกที่มองเห็นเป็น N |
{{< /table >}}

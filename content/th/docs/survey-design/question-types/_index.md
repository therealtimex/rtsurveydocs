rtSurvey รองรับประเภทคำถาม XLSForm มาตรฐานทั้งหมด รวมถึงส่วนขยายหลายอย่าง แต่ละประเภทคำถามควบคุมชนิดข้อมูลที่รวบรวมและวิธีแสดงวิดเจ็ตอินพุตบนอุปกรณ์

## อินพุตข้อความ

| ประเภท | คำอธิบาย |
|------|-------------|
| [text](text) | คำตอบข้อความอิสระ — อนุญาตอักขระใดๆ |
| [integer](integer) | จำนวนเต็ม (ไม่มีทศนิยม) |
| [decimal](decimal) | ตัวเลขที่มีทศนิยม |
| [range](range) | ตัวเลขที่เลือกจาก slider ในช่วง min/max ที่กำหนด |

## การเลือก

| ประเภท | คำอธิบาย |
|------|-------------|
| [select_one listname](select-one) | เลือกตัวเลือกเดียวจากรายการ |
| [select_multiple listname](select-multiple) | เลือกหนึ่งหรือหลายตัวเลือกจากรายการ |
| [rank listname](rank) | เรียงลำดับตัวเลือกตามความชอบหรือลำดับความสำคัญ |

## วันที่และเวลา

| ประเภท | คำอธิบาย |
|------|-------------|
| [date](date) | วันที่ตามปฏิทิน (ปี เดือน วัน) |
| [time](time) | เวลาของวัน (ชั่วโมง นาที) |
| [datetime](datetime-date-time) | วันที่และเวลารวมกัน |

## ตำแหน่งที่ตั้ง

| ประเภท | คำอธิบาย |
|------|-------------|
| [geopoint](geopoint) | พิกัด GPS เดียว (ละติจูด ลองจิจูด ความสูง ความแม่นยำ) |
| [geotrace](geotrace) | เส้นทาง — ชุดจุด GPS ที่ก่อตัวเป็นเส้น |
| [geoshape](geoshape) | พื้นที่ — รูปหลายเหลี่ยมปิดของจุด GPS |

## มีเดีย

| ประเภท | คำอธิบาย |
|------|-------------|
| [image](image) | การถ่ายภาพหรืออัปโหลดรูปภาพ |
| [audio](audio) | การบันทึกเสียง |
| [video](video) | การบันทึกวิดีโอ |
| [file](file) | การอัปโหลดไฟล์ทั่วไป (PDF, เอกสาร ฯลฯ) |

## อื่นๆ

| ประเภท | คำอธิบาย |
|------|-------------|
| [barcode](barcode) | สแกน barcode หรือ QR code |
| [note](note) | ข้อความแบบอ่านอย่างเดียว — แสดงคำแนะนำหรือสรุปที่คำนวณ |
| [calculate](calculate) | ฟิลด์ซ่อนที่เก็บค่าที่คำนวณ |
| [hidden](hidden) | ฟิลด์ซ่อนที่เก็บค่าคงที่หรือเติมล่วงหน้า |
| [trigger / acknowledge](trigger) | ช่องทำเครื่องหมายที่ผู้เก็บข้อมูลต้องทำเครื่องหมายเพื่อยืนยัน |
| [meta](meta) | ข้อมูลเมตาอัตโนมัติ: timestamps, device ID, ข้อมูลผู้เก็บข้อมูล |

## ส่วนขยาย rtSurvey

ประเภทเหล่านี้เป็นของ rtSurvey โดยเฉพาะและไม่ได้เป็นส่วนหนึ่งของข้อกำหนด XLSForm มาตรฐาน

| ประเภท | คำอธิบาย |
|--------|----------|
| [search-autocomplete](search-autocomplete) | ช่องข้อความพร้อมคำแนะนำการเติมข้อความอัตโนมัติจาก API แบบเรียลไทม์ |
| [mentions](mentions) | ช่องข้อความพร้อมการเติมข้อความอัตโนมัติ `@` สำหรับแท็กเอนทิตีแบบอินไลน์ |
| [texttags](texttags) | ช่องป้อนแท็ก — แต่ละรายการกลายเป็นชิปที่ถอดออกได้; เก็บเป็นสตริงที่คั่นด้วยช่องว่าง |

สำหรับกลุ่มซ้ำ ดูที่ [Repeats](../advanced-extension/repeats)

## วิธีที่ type และ appearance ทำงานร่วมกัน

`type` กำหนด **ชนิดข้อมูลที่รวบรวม** คอลัมน์ `appearance` ควบคุม **ลักษณะที่วิดเจ็ตดูเหมือน**

ดู [Appearance](../appearance) สำหรับรายการตัวเลือกทั้งหมด

ประเภทคำถาม `select_one` แจ้งให้ผู้ตอบแบบสำรวจเลือก **ตัวเลือกเดียว** จากรายการที่กำหนดไว้ โดยค่าเริ่มต้นตัวเลือกจะแสดงเป็นปุ่มวิทยุ แต่มีตัวเลือก appearance หลากหลายสำหรับเปลี่ยนเลย์เอาต์และพฤติกรรม

## ตัวเลือก Appearance

{{< table >}}
| Appearance | คำอธิบาย |
|------------|----------|
| *(ไม่มี)* | ปุ่มวิทยุค่าเริ่มต้น หนึ่งรายการต่อบรรทัด |
| `minimal` | Dropdown/spinner เดียวแทนปุ่มวิทยุ |
| `quick` | เลื่อนไปคำถามถัดไปอัตโนมัติทันทีที่เลือก (มือถือเท่านั้น) |
| `compact` | Grid ตัวเลือกแบบ compact — จำนวนคอลัมน์ปรับตามความกว้างหน้าจอ |
| `compact-N` | Grid compact บังคับ N คอลัมน์ (เช่น `compact-3`) |
| `horizontal` | ตัวเลือกเรียงในแถวแนวนอน (เว็บ) |
| `likert` | แถว Likert scale |
| `columns(N)` | แสดงใน N คอลัมน์ (ส่วนขยาย rtSurvey) |
| `distress` | วิดเจ็ตไอคอนอารมณ์ Kessler Psychological Distress (K10) |
| `search-api(...)` | ค้นหาแบบไดนามิก — โหลดตัวเลือกจาก API ขณะ runtime |
| `tagging` | แสดงตัวเลือกเป็นชิปแท็กที่คลิกได้แทนปุ่มวิทยุ |
| `boxtag` | แสดงตัวเลือกเป็นกล่องสี่เหลี่ยมที่มีสไตล์ให้แตะเพื่อเลือก |
| `boxtag -search` | เลย์เอาต์ Boxtag พร้อมช่องค้นหา/กรองเหนือกล่อง |
| `duolingo-style1` | เลย์เอาต์การ์ดสไตล์ Duolingo — การ์ดขนาดใหญ่ที่แตะได้พร้อมไอคอน |
| `rating_box` | กล่องคะแนนแบบ Grid — เหมาะสำหรับตัวเลือกตัวเลขหรือสเกล |
| `star_rating` | วิดเจ็ตคะแนนดาว — ตัวเลือกแสดงเป็นดาว 1–N ดวง |
| `choices-noshow` | แสดง 10 ตัวเลือกแรกเริ่มต้น; เผยตัวเลือกที่เหลือตามต้องการ |
| `noshow` | ซ่อนรายการตัวเลือกทั้งหมด; ค่าถูกกำหนดโดยโปรแกรม |
| `checkall` | เพิ่มตัวเลือก "เลือกทั้งหมด" ที่ด้านบนของรายการ |
| `max-items(N)` | จำกัดจำนวนตัวเลือกที่มองเห็นเป็น N (เช่น max-items(5)) |
{{< /table >}}

ประเภทคำถาม `text` รวบรวมคำตอบข้อความอิสระ — สตริงอักขระใดๆ เป็นประเภทอินพุตที่ยืดหยุ่นที่สุดและใช้สำหรับชื่อ ที่อยู่ คำอธิบาย รหัส และสิ่งใดๆ ที่ไม่เหมาะกับประเภทที่เฉพาะเจาะจงกว่า

## ตัวเลือก Appearance มาตรฐาน

| Appearance | คำอธิบาย |
|------------|----------|
| *(ไม่มี)* | ช่องข้อความบรรทัดเดียว |
| `multiline` | พื้นที่ข้อความหลายบรรทัด — เหมาะสำหรับข้อความอิสระที่ยาวกว่าบนเว็บ |
| `richtext` | โปรแกรมแก้ไขข้อความแบบ Rich text — แถบเครื่องมือพร้อมตัวหนา ตัวเอียง รายการ และลิงก์ |
| `typingtest` | อินเทอร์เฟซการทดสอบพิมพ์ดีด — แสดงข้อความและวัดความเร็วและความแม่นยำในการพิมพ์ |

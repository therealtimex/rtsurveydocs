ค่าเริ่มต้นใน rtSurvey ช่วยให้คุณเติมค่าล่วงหน้าในคำถามเมื่อผู้ตอบแบบสำรวจพบครั้งแรก ฟีเจอร์นี้สามารถปรับปรุงประสิทธิภาพการสำรวจและคุณภาพข้อมูลได้อย่างมีนัยสำคัญ

## การใช้งานพื้นฐาน

ในการตั้งค่าเริ่มต้น ให้ใช้คอลัมน์ `default` ใน XLSForm ของคุณ:

```
| type    | name        | label                         | default    |
|---------|-------------|-------------------------------|------------|
| date    | survey_date | Survey date                   | 2024-07-04 |
| decimal | weight      | Respondent's weight? (in kgs) | 51.3       |
```

## ค่าเริ่มต้นแบบไดนามิก

rtSurvey รองรับค่าเริ่มต้นแบบไดนามิกโดยใช้ฟังก์ชัน:

```
| type | name | label                              | default  |
|------|------|------------------------------------| ---------|
| date | d    | Enter the date the event occurred? | today()  |
```

ที่นี่ฟังก์ชัน `today()` ตั้งค่าเริ่มต้นเป็นวันที่ปัจจุบันโดยอัตโนมัติ

## แนวทางปฏิบัติที่ดีที่สุด

1. **ใช้อย่างประหยัด**: ใช้ค่าเริ่มต้นเฉพาะเมื่อช่วยปรับปรุงประสิทธิภาพหรือคุณภาพข้อมูลอย่างมีนัยสำคัญ
2. **รับรองความถูกต้อง**: ตรวจสอบและอัปเดตค่าเริ่มต้นคงที่เป็นประจำ
3. **ทดสอบอย่างละเอียด**: โดยเฉพาะเมื่อใช้ค่าเริ่มต้นแบบไดนามิกหรือคำนวณ
4. **พิจารณาประสบการณ์ผู้ใช้**: ตรวจสอบให้แน่ใจว่าค่าเริ่มต้นไม่ทำให้ผู้ตอบแบบสำรวจเข้าใจผิดหรือนำเข้าอคติ
5. **บันทึกอย่างชัดเจน**: ตรวจสอบให้แน่ใจว่าสมาชิกทีมทุกคนเข้าใจเหตุผลเบื้องหลังค่าเริ่มต้น

โมดูล **Managing Submissions** (เข้าถึงผ่านปุ่ม **Data View** ในส่วน Form Family) ช่วยให้ผู้จัดการโครงการและหัวหน้างานโต้ตอบโดยตรงกับข้อมูลดิบที่เข้ามา ทำหน้าที่เป็นพื้นที่ทำงานรวมเพื่อตรวจสอบการส่งของผู้ถามแบบสอบถาม ติดตามตัวระบุอุปกรณ์ และดำเนินการคุณภาพข้อมูล

![Managing Submissions Interface](/images/manage_submissions.png)

## ภาพรวมข้อมูลและคอลัมน์

กริดข้อมูลแสดงข้อมูลที่เก็บรวบรวมสำหรับแบบฟอร์มเฉพาะแบบไดนามิก ทำงานในสองโหมดหลัก: **Official** (บันทึกสุดท้าย) และ **Working** (เรียลไทม์ บันทึกที่ยังไม่สิ้นสุด)

### คอลัมน์ข้อมูลสำคัญ

โดยไม่คำนึงถึงคำถามที่กำหนดเองในแบบฟอร์ม กริดมีคอลัมน์ข้อมูลเมตามาตรฐานหลายรายการเพื่อช่วยในการตรวจสอบ:

- **Submit by:** ระบุแพลตฟอร์มต้นทางของการส่ง (เช่น FA สำหรับ Field App, WEB สำหรับ Webform, RS สำหรับระบบระยะไกล)
- **Detail:** เปิดมุมมองบันทึกเดียวที่มุ่งเน้น (ไอคอนค้นหา) เพื่อตรวจสอบทุกตัวแปรและคำตอบที่ส่งสำหรับอินสแตนซ์นั้น
- **iNote:** ช่วยให้หัวหน้างานแนบหมายเหตุข้างหรือความคิดเห็นภายในกับบันทึกเฉพาะโดยไม่เปลี่ยนข้อมูลที่เก็บรวบรวม (แสดงด้วยไอคอนดินสอ)
- **ฟิลด์วันที่:** Timestamps ที่ระบุเมื่อบันทึกถูกเริ่ม เสร็จสิ้น หรือซิงค์
- **ไฟล์แนบมีเดีย:** ลิงก์ thumbnail โดยตรงไปยังรูปภาพ ลายเซ็น หรือไฟล์ที่เก็บรวบรวมในระหว่างการสำรวจ
- **กลุ่มซ้ำ:** ลิงก์เฉพาะเพื่อเข้าถึงตารางซ้อนสำหรับคำถามที่ซ้ำภายในแบบฟอร์มหลัก

## การดำเนินการส่ง

เพื่ออำนวยความสะดวกในการควบคุมคุณภาพข้อมูลที่กระตือรือร้น อินเทอร์เฟซมีเมนูดรอปดาวน์ของคำสั่งที่ดำเนินการได้ซึ่งสามารถดำเนินการกับบันทึกที่เลือก:

- **สร้างอินสแตนซ์ใหม่:** ช่วยให้ผู้ดูแลระบบป้อนบันทึกแบบสำรวจใหม่ด้วยตนเองโดยตรงในฐานข้อมูล
- **ส่งคืนอินสแตนซ์:** ปฏิเสธบันทึกที่ส่งและมอบหมายให้ผู้ถามแบบสอบถามตรวจสอบหรือเก็บข้อมูลใหม่
- **ติดตามอินสแตนซ์:** ทำเครื่องหมายบันทึกเพื่อการดูแลเพิ่มเติม มักส่งการแจ้งเตือนไปยังทีมภาคสนามเพื่อชี้แจง
- **ส่งออกเป็นไฟล์คำสั่งส่งคืน / แพ็คเกจคำสั่งติดตาม:** สร้างการส่งออกแบบกลุ่ม (ไฟล์) ที่มีชุดข้อมูลที่ทำเครื่องหมายสำหรับการส่งคืนหรือการติดตามโดยเฉพาะ
- **แปลงเป็น XML:** แปลงชุดข้อมูลที่มีโครงสร้างกลับเป็นรูปแบบ XML ดิบสำหรับการวิเคราะห์แบ็กเอนด์หรือการรวมระบบ
- **ส่งต่ออินสแตนซ์:** (มีใน *Working* mode) ดันข้อมูลที่ยังไม่สิ้นสุดไปยังอุปกรณ์หรือผู้ใช้อื่นทันที
- **ลบ:** ลบอินสแตนซ์ที่เลือกออกจากฐานข้อมูลอย่างถาวร

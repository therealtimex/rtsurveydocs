Linode uses **StackScripts** — scripts with a form-based UI where you fill in configuration fields directly in the Linode Manager without editing any code.

> Linode StackScripts are the easiest deployment method. Fields appear as a form when you create a Linode — no script editing required.

**Download scripts:**

| Script | Description |
|--------|-------------|
| [linode-stackscript-keycloak-embed.sh](/scripts/linode-stackscript-keycloak-embed.sh) | Embedded Keycloak (Recommended) |
| [linode-stackscript.sh](/scripts/linode-stackscript.sh) | Full script — Keycloak + External OIDC |
| [linode-stackscript-oidc.sh](/scripts/linode-stackscript-oidc.sh) | External OIDC only |

## Embedded Keycloak (Recommended)

Use `linode-stackscript-keycloak-embed.sh` for the simplest setup with built-in SSO.

### Step 1 — Create the StackScript

1. In [Linode Manager](https://cloud.linode.com), go to **StackScripts** → **Create StackScript**
2. Give it a name (e.g. `rtCloud Embedded Keycloak`)
3. Set **Target Images** to `Ubuntu 22.04 LTS`
4. Paste the full contents of `linode-stackscript-keycloak-embed.sh`
5. Click **Save**

### Step 2 — Create a Linode

1. Go to **Linodes** → **Create Linode**
2. Under **Choose a Distribution**, select **StackScripts** → **Your StackScripts**
3. Select the script you just created
4. Fill in the configuration form:

| Field | Required | Description |
|-------|----------|-------------|
| Project ID | No | Unique identifier (default: `rtsurvey`). Used as database name and Keycloak client ID. |
| Keycloak Admin Password | No | Password for both Keycloak admin console and app admin login. Defaults to `admin` — **change after first login**. |
| Domain | No | Your domain name. DNS A record must point to this Linode's IP. |
| Let's Encrypt Email | Yes | Email for Let's Encrypt certificate notifications. |
| Docker Image Tag | No | Image to deploy (default: `rtawebteam/rta-smartsurvey:survey-dockerize`). |

> **Security:** All passwords default to `admin`. Change them immediately after your first login.

5. Choose **Ubuntu 22.04 LTS** as the image
6. Choose **Shared CPU 4 GB** plan or larger
7. Click **Create Linode**

### Step 3 — Add the DNS record

While the Linode boots, add an **A record** in your DNS provider:

```
Type  : A
Name  : myapp          (or @ for root domain)
Value : <linode-ip>
TTL   : 300
```

### Step 4 — Monitor progress

```bash
ssh root@<linode-ip>
tail -f /var/log/stackscript.log
```

The script prints your server IP near the start — add the DNS record as soon as you see it.

### Step 5 — Access the app

When setup completes, the log shows a summary:

```
============================================================
 rtCloud deployment complete! (Embedded Keycloak)
============================================================
 App URL   : https://myapp.example.com
 Admin     : admin / admin
 Keycloak  : https://myapp.example.com/auth/admin

 !! SECURITY: All passwords default to 'admin'.
    Change them immediately after first login.
============================================================
```

Log in with username `admin` and password `admin`, then change your password immediately.

## External OIDC Only

Use `linode-stackscript-oidc.sh` if you have an existing identity provider (Azure AD, Google, Keycloak, etc.) and do not need embedded Keycloak.

Additional form fields:

| Field | Description |
|-------|-------------|
| OIDC Issuer URL | Your identity provider's issuer URL |
| OIDC Client ID | Client ID registered with your provider |
| OIDC Client Secret | Client secret from your provider |
| Open Registration | Allow new users to self-register (`true` / `false`) |

No Keycloak container is deployed — lighter resource usage.

---

## Full StackScript

Use `linode-stackscript.sh` for full control. This script supports all modes — embedded Keycloak, external OIDC, and HTTP-only — in a single script with all options as form fields.

## After Deployment

### Change a password

```bash
nano /opt/rtcloud/.env
docker compose -f /opt/rtcloud/docker-compose.production.yml up -d --force-recreate rtcloud
```

### View all containers

```bash
docker compose -f /opt/rtcloud/docker-compose.production.yml ps
```

### Check the log

```bash
tail -200 /var/log/stackscript.log
```

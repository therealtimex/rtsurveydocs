The rtSurvey Mobile App offers a comprehensive set of features designed to streamline the survey process. Here are the key functionalities:

## Fill Form
The Fill Form feature is where enumerators can access and input data into blank survey forms. This functionality allows for efficient and accurate data collection in the field. Key points include:

1. Form Listing: Upon accessing the Fill Form section, users are presented with a list of all available blank forms assigned to them.

2. Automatic Form Download: Unlike some other survey tools, rtSurvey mobile app automatically downloads forms that are given access to the user by the survey administrator or project manager. This eliminates the need for enumerators to manually retrieve blank forms.

3. Direct Data Entry: Enumerators can select a form from the list and begin entering survey responses directly into the app.

4. Real-time Updates: As new forms are assigned or updates are made, the list of available forms is automatically refreshed, ensuring enumerators always have access to the most current surveys.

5. Offline Capability: Forms can be downloaded when internet connectivity is available, allowing enumerators to fill them out even in areas with poor or no network coverage.

## Edit Form

The Edit Form functionality in rtSurvey offers a comprehensive and flexible approach to managing survey instances, setting it apart from other CAPI applications. This feature ensures data accuracy and completeness through three distinct tabs:

1. **Saved**: 
   - Access and modify incomplete interview instances saved on the enumerator's device.
   - Similar to traditional CAPI apps, allowing users to resume and complete unfinished surveys.

2. **Returned** (rtSurvey Exclusive):
   - Edit survey instances that were previously completed, finalized, and submitted to the server.
   - Unique to rtSurvey, this feature allows for post-submission edits when additional information or corrections are needed.

3. **Forwarded** (rtSurvey Exclusive):
   - Access and edit survey instances originally created on another device.
   - This innovative feature supports various scenarios:
     * Supervisors can review and edit submissions from enumerators.
     * Users can continue work on a different device if their original device is lost or damaged.
     * Enables collaborative editing and quality control processes.

Key Benefits:
- Enhanced data quality through multiple review and edit opportunities.
- Improved workflow flexibility for field teams and supervisors.
- Seamless continuation of work across devices, reducing downtime and data loss risks.


## Send Form
Submit 100% completed forms to the central server. This feature enables real-time data transmission, allowing for immediate analysis and decision-making.

## Notifications
Receive important notices and updates from the server. This keeps all team members informed about project developments, changes, or urgent matters.

## Tasks
Access and manage tasks assigned by the server. This feature helps organize workload and prioritize survey activities for field enumerators.

## Reports
View all reports sent from the server to the tablet. This functionality allows users to access analysis results and project insights directly on their device.

## Review Form
Examine finalized forms, regardless of whether they have been sent to the server or not. This feature enables quality control and data verification before final submission.

## Map
Utilize GPS functionality to pinpoint the exact location where the interview is being conducted. This feature enhances data accuracy and helps in spatial analysis of survey results.

## Exit
Close the app without logging out of the rtSurvey account. This allows for quick re-entry into the app without the need for repeated authentication.

These functionalities work together to create a powerful, user-friendly mobile survey tool that caters to various roles within the survey process, from data collection to analysis and project management.

O rtSurvey permite que você crie formulários e fluxos de trabalho poderosos para coletar os dados de que precisa, onde quer que estejam. Você pode:

1.  Criar formulários sofisticados que incluem fotos, localizações GPS, lógica de salto,
    cálculos, conjuntos de dados externos, múltiplos idiomas e muito mais.
2.  Coletar dados off-line com o aplicativo móvel ou o aplicativo web.
    Os formulários e envios são sincronizados quando uma conexão com a Internet é
    encontrada.
3.  Analisar com facilidade baixando seus dados em formato CSV ou conectando o rtSurvey
    ao Excel, Power BI, Python ou R para criar painéis com atualização em tempo real.

Pesquisadores, equipes de campo e outros profissionais como você usam o rtSurvey
para coletar dados importantes. Veja como começar.

## 1. Obtenha o rtSurvey Cloud {#getting-started-rtCloud}

Para obter o rtSurvey Cloud, o método mais rápido e simples é usar o serviço oficial de hospedagem gerenciada chamado [rtSurvey
Cloud](https://rtSurvey.com/#rtSurvey-cloud). Está disponível no site do rtSurvey e é construído sobre uma infraestrutura rápida, confiável e segura.

## 2. Faça upload do seu XLSForm para o rtCloud ou crie um formulário usando o Form Builder (Beta) {#getting-started-create-form}

1.  Crie uma definição de formulário usando `XLSForm <xlsform>`{.interpreted-text
    role="doc"} ou experimente este [formulário com todos os widgets](https://docs.google.com/spreadsheets/d/1af_Sl8A_L8_EULbhRLHVl8OclCfco09Hq2tqb9CslwQ/edit#gid=0).
2.  `Faça upload do seu XLSForm para o rtCloud <rtCloud-forms-upload>`{.interpreted-text
    role="ref"} e publique-o.

## 3. Obtenha o aplicativo rtSurvey {#getting-started-get-collect}

Para baixar o aplicativo rtSurvey, siga estas etapas conforme o seu dispositivo:

### Para dispositivos Android:
1. Acesse o [Google Play Store](https://play.google.com/store/apps/details?id=vn.rta.rtsurvey).
2. Pesquise "rtSurvey" na barra de pesquisa.
3. Toque no aplicativo com o logotipo do rtSurvey.
4. Clique em "Instalar" para baixar e instalar o aplicativo no seu dispositivo Android.

### Para dispositivos iOS:
1. Abra a [App Store](https://apps.apple.com/vn/app/rtsurvey/id1178851547) no seu dispositivo iOS.
2. Pesquise "rtSurvey" na aba de pesquisa.
3. Localize o aplicativo com o logotipo do rtSurvey.
4. Toque em "Obter" para baixar e instalar o aplicativo no seu dispositivo iOS.

Após o aplicativo ser baixado e instalado, você pode iniciá-lo e começar a usar o rtSurvey para serviços de pesquisa e análise.

## 4. Conecte o Collect ao rtCloud {#getting-started-connect}

1.  `Crie um usuário do aplicativo <rtCloud-users-app-overview>`{.interpreted-text
    role="ref"} no rtCloud e
    `atribua seu formulário a esse usuário <rtCloud-projects-form-access>`{.interpreted-text
    role="ref"}.
2.  Abra o Collect, toque em `Configurar com código QR`{.interpreted-text
    role="guilabel"} e escaneie o código criado para o seu usuário do aplicativo.

## 5. Preencha seu formulário no Collect {#getting-started-fill-form}

1.  Selecione `Preencher formulário em branco`{.interpreted-text role="guilabel"} para
    preencher seu formulário.
2.  Os dados do seu formulário serão enviados automaticamente para o rtCloud quando você
    terminar.

## 6. Use seus dados no rtCloud {#getting-started-use-data}

1.  Entre no rtCloud e visualize seus dados.
2.  Baixe seus dados em formato CSV ou
    `visualize-os no Power BI <rtCloud-submissions-odata>`{.interpreted-text
    role="ref"}.

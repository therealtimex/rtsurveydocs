O módulo **Gerenciar formulários** serve como o gateway principal para organizar seus instrumentos de pesquisa e coordenar as tarefas de trabalho de campo. Ele fornece controle fino sobre a acessibilidade dos formulários, a visualização de dados e o direcionamento de dispositivos.

![Interface de gerenciamento de formulários](/images/manage_forms.png)

## Visão geral da família de formulários

No menu **Formulário e entrada de dados**, a seção **Família de formulários** exibe uma grade abrangente de todos os formulários importados, juntamente com controles essenciais de acesso rápido. Esta visão centralizada permite que os gerentes de projeto implantem e configurem pesquisas individuais rapidamente.

### Colunas de dados e opções de configuração principais

- **Visualização de dados:** Acesse registros enviados e visualizações de conjuntos de dados diretamente para cada formulário.
- **Permitir edição:** Um alternador rápido para bloquear ou desbloquear a capacidade dos trabalhadores de campo de editar os dados enviados (status Ativo/Inativo).
- **Visibilidade pública:** Um alternador para tornar um formulário disponível publicamente sem exigir autenticação do entrevistador.
- **URL do formulário web:** Recupere instantaneamente o link público exclusivo para compartilhar formulários de coleta de dados baseados em navegador.
- **Substituir configurações:** Um modal de configurações avançadas (acessado pelo ícone de engrenagem) para personalizar regras, valores e desabilitar recursos específicos de formulários.
- **Identificadores do formulário:** Visualize metadados padrão, incluindo o nome da família de formulários, código da família e um ID de formulário exclusivo.
- **Configuração geográfica:** Configurações específicas de mapeamento ou geoponto vinculadas à estrutura do formulário.
- **Bloquear formulário:** Funcionalidade para bloquear o acesso de envio ao finalizar a fase de coleta de dados.

## Ações e navegação de formulários

O painel de controle superior facilita operações em lote e visualizações alternativas de formulários:

- **Ação para dispositivo:** Uma poderosa ferramenta de lista suspensa que permite aos gerentes de projeto atribuir tarefas, enviar formulários direcionados ou despachar ações diretamente para dispositivos de campo de entrevistadores específicos.
- **Aba de formulário XLSX:** Navegue rapidamente da grade de gerenciamento principal para ambientes de upload para gerenciar novos arquivos XLSForm nativos.
- **Aba do Form Builder:** Acesse a ferramenta integrada para construir ou modificar formulários visualmente de forma dinâmica sem usar software de planilha externo.

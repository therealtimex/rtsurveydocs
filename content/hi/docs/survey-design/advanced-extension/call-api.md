**Call API** सुविधा एक सर्वेक्षण फील्ड को एक बाहरी सेवा को HTTP अनुरोध करने और किसी गणना किए गए मूल्य को पॉप्युलेट करने या उपयोगकर्ता इनपुट को सत्यापित करने के लिए प्रतिक्रिया का उपयोग करने देती है। यह डेटा संग्रह के दौरान रियल-टाइम लुकअप, ID सत्यापन, barcode लुकअप और किसी भी अन्य सर्वर-साइड चेक को सक्षम करती है।

**Dynamic Search** (जिसे Search API भी कहा जाता है) एक `select_one`, `select_multiple` या `text` फील्ड को गणनाकर्ता के टाइप करते समय **रनटाइम पर** एक दूरस्थ वेब सेवा से अपने विकल्प लोड करने की अनुमति देता है। यह सही दृष्टिकोण है जब आपकी विकल्प सूची CSV फ़ाइल में बंडल करने के लिए बहुत बड़ी हो, बार-बार अपडेट की जाती हो, या किसी लाइव डेटाबेस से आती हो।

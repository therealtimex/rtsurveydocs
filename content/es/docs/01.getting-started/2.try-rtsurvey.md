Experimente rtSurvey desde diferentes perspectivas usando nuestras cuentas de demostración. Cada cuenta está configurada con roles específicos para mostrar las funcionalidades y permisos asociados con cada tipo de usuario en un proyecto de encuesta CAPI.

### Administrador de demostración
- **Usuario:** admin_demo
- **Contraseña:** AdminRtSurvey
- **Rol:** Acceso completo a todas las configuraciones del sistema, gestión de usuarios y configuraciones de proyectos.

### Gestor de proyecto de demostración
- **Usuario:** pm_demo
- **Contraseña:** PMRtSurvey
- **Rol:** Gestionar proyectos, asignar tareas y supervisar el despliegue de encuestas y la recopilación de datos.

### Diseñador de encuestas de demostración
- **Usuario:** designer_demo
- **Contraseña:** DesignerRtSurvey
- **Rol:** Diseñar y probar encuestas usando el editor XLSForm y el constructor de formularios visual de rtSurvey.

### Encuestador de campo de demostración
- **Usuario:** enumerator_demo
- **Contraseña:** EnumeratorRtSurvey
- **Rol:** Realizar encuestas en el campo usando la aplicación móvil de rtSurvey, recopilar datos y sincronizar con rtSurvey Cloud.

### Analista de datos de demostración
- **Usuario:** analyst_demo
- **Contraseña:** AnalystRtSurvey
- **Rol:** Analizar los datos recopilados, generar informes e integrarlos con herramientas de análisis externas como Excel, Power BI, Python y R.

## Cómo usar las cuentas de demostración

1. **Seleccione un rol:**
   Elija el rol de demostración que desea explorar de la lista anterior.

2. **Inicie sesión:**
   Use el nombre de usuario y la contraseña proporcionados para iniciar sesión en rtSurvey.

3. **Explore las funciones:**
   Navegue por la plataforma para comprender las funcionalidades disponibles para el rol seleccionado.

4. **Comentarios:**
   ¡Valoramos su opinión! Por favor, comparta sus comentarios sobre su experiencia para ayudarnos a mejorar rtSurvey.

## Pautas de seguridad y uso

- Estas son cuentas de demostración compartidas. Por favor, no ingrese información sensible o personal.
- Las cuentas de demostración tienen acceso limitado para garantizar la seguridad de los datos y prevenir usos indebidos.
- El uso de las cuentas de demostración es monitoreado para mantener la integridad del sistema.

Al usar estas cuentas de demostración, podrá obtener una comprensión integral de cómo funciona rtSurvey para diferentes roles de usuario en un proyecto de encuesta CAPI. Explore cómo rtSurvey puede beneficiar su recopilación de datos y necesidades de análisis en las distintas etapas de la implementación de encuestas.

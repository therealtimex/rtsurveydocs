XLSForm 和 rtSurvey 中的 note 题目类型用于向调查受访者显示只读文本或媒体。它不是需要回答的问题，而是在调查中提供信息、说明或上下文的一种方式。

## 基本 XLSForm 规范

| type | name | label |
|------|------|-------|
| note | info_text | 本调查关于您的阅读习惯。 |

有关基本 note 题目类型的更多详情，请参阅 [XLSForm 规范](https://xlsform.org/en/#question-types)。

## 用途

注释题目通常用于：

1. 为后续问题提供说明或上下文
2. 显示计算结果或摘要
3. 显示图像或其他媒体
4. 分隔调查的各个部分
5. 根据之前的回答提供反馈

## 最佳实践

1. 保持注释文本简洁明了，以维持受访者的参与度。
2. 使用格式（粗体、斜体）来强调重要信息。
3. 在适当时考虑使用媒体（图像、音频）来增强理解。
4. 谨慎使用注释，以避免使调查显得杂乱。

## 使用示例

以下是您可能在调查中使用注释题目的示例：

| type | name | label |
|------|------|-------|
| note | intro | 欢迎参加我们的阅读习惯调查。我们将询问您的偏好和阅读频率。 |
| ... | ... | ... |
| calculate | books_per_month | ${fiction_books} + ${non_fiction_books} |
| note | reading_summary | 您每月大约阅读 ${books_per_month} 本书。 |

在这个示例中，我们使用注释来介绍调查并提供计算结果的摘要。

## rtSurvey 扩展

虽然注释题目的基本 XLSForm 规范很简单，但 rtSurvey 可能提供额外功能或自定义选项：

1. 富文本格式
2. 支持嵌入媒体（图像、音频、视频）
3. 基于之前回答的动态内容
4. 自定义样式选项

## 高级用法

### 条件显示

您可以使用相关性表达式来有条件地显示注释：

| type | name | label | relevant |
|------|------|-------|----------|
| note | high_reader_note | 您是一位热爱阅读的读者！ | ${books_per_month} > 5 |

### 包含计算

注释可以包含计算以提供动态反馈：

| type | name | label |
|------|------|-------|
| note | reading_time | 根据您的回答，您每月大约花费 ${books_per_month * 5} 小时阅读。 |

## 限制

- 注释不收集数据，因此在需要从受访者处收集信息时不应使用它们。
- 过度使用注释会使调查显得杂乱或过长。
- 某些高级格式或媒体选项可能不受所有设备或平台支持。

# 系统仪表板

仪表板（`/cpms/cpmsDashBoard/indexNew`）是实时调查平台（RT-CPMS）的行政指挥中心和主要登陆页面。

![系统仪表板预览](/images/dashboard_overview.png)

它旨在让调查管理员即时概览活跃项目、快速访问基本工具，并通过集中化枢纽在所有主要平台模块间导航。

## 主要功能

### 1. 项目与表单选择
左侧面板包含**表单和报告**导航器。该区域列出您工作区内的所有活跃调查。
* 通过选择特定调查（例如 *RTA - SURVEY 02*），您可以将仪表板的监控和指标聚焦于该项目。

### 2. 可视化与指标筛选
在项目列表上方，您可以切换多个关键数据视角，以监控实时实地工作进度：
* **按开始时间/结束时间统计**：跟踪调查员何时开始和完成调查会话。
* **按提交日期统计**：监控每日到达服务器的数据总量。
* **按用户名统计**：评估各调查员的生产力和表现。
* **访谈地图**：查看调查回应收集位置的地理（GIS）分布，确保满足空间覆盖要求。

### 3. 应用程序入口
仪表板中央提供了对数据收集界面的即时访问。根据调查员的硬件情况，您可以启动或引导他们使用：
* **网页应用**：用于基于浏览器的数据收集。
* **Android 应用**：链接至 Google Play 商店或 APK。
* **iOS 应用**：链接至 Apple App Store。

### 4. 直接模块快捷方式
三个突出的操作按钮允许快速切换至最常用的运营模块：
* **表单与数据录入**：直接跳转至手动管理已收集数据。
* **分析与报告**：打开商业智能（BI）套件，对调查答案进行交叉制表和图表分析。
* **权限配置**：调整谁有权访问活跃调查及其所持角色。

### 5. 全局导航侧边栏
可折叠的左侧边栏提供对 RT-CPMS 后端模块完整生态系统的访问。您可以从这里深入：
* **设置**：管理员工和活跃设备。
* **实地工作管理**：跟踪调查员的日常活动。
* **质量保证**：实施和审查质量保证规则和标记。
* **最终成果**：将清理后的数据集导出为 CSV、PDF 或 Stata 格式。

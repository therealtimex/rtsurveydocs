XLSForm 和 rtSurvey 中的 geotrace 题目类型使受访者能够在地图上捕获一系列连接的点，创建线条或路径。此功能在绘制路线、边界或空间调查中的线性特征时特别有用。

## 基本 XLSForm 规范

| type     | name        | label                           |
|----------|-------------|--------------------------------|
| geotrace | river_path  | 追踪河流的路径     |

有关基本 geotrace 题目类型的更多详情，请参阅 [XLSForm 规范](https://xlsform.org/en/#question-types)。

## 用途

Geotrace 题目通常用于：

1. 绘制现场调查中经过的路线或路径
2. 追踪道路、河流或边界等线性特征
3. 捕获线性基础设施的范围（例如，管道、电线）
4. 在交通研究中记录行进路径
5. 在生态调查中定义样线

## 最佳实践

1. 确保设备已启用位置服务并授予权限。
2. 提供关于如何追踪路径以及应包含哪些特征的清晰说明。
3. 考虑使用卫星图像或底图来帮助受访者准确追踪路径。
4. 注意追踪的潜在复杂性及其对数据大小和处理的影响。

## 使用示例

以下是您可能在调查中使用 geotrace 题目的示例：

| type     | name           | label                                      | hint                                        |
|----------|----------------|--------------------------------------------|--------------------------------------------|
| geotrace | hiking_trail   | 追踪徒步路径         | 从登山口开始，以山顶结束 |

## rtSurvey 扩展

虽然 geotrace 题目的基本 XLSForm 规范很简单，但 rtSurvey 可能提供额外功能或自定义选项：

1. 与离线地图集成，适用于偏远地区
2. 设置追踪点数最小值和最大值的选项
3. 初始绘制后编辑或细化追踪的能力
4. 支持在移动时以设定间隔自动追踪

## 数据格式

Geotrace 数据通常存储为空格分隔坐标对的字符串，类似于 geoshape 但没有闭合点：

```
lat1 lon1; lat2 lon2; lat3 lon3; ... latN lonN
```

例如：
```
38.253094215699576 21.756382658677467; 38.25021274773806 21.756382658677467; 38.25007793942195 21.763892843919166; 38.25290886154963 21.763935759263404
```

## 分析注意事项

使用 geotrace 题目时，请考虑：

1. 如何可视化和分析地理数据（例如，GIS 软件）
2. 复杂追踪的数据清理或简化的潜在需求
3. 处理详细空间数据的隐私和数据保护措施
4. 与其他空间数据源集成进行综合分析

## 限制

- 在小型移动屏幕上精确追踪路径可能具有挑战性。
- 复杂追踪可能需要大量存储和处理能力。
- 用于自动追踪的持续 GPS 使用会迅速耗尽设备电池。
- 收集详细路径数据可能涉及隐私问题。

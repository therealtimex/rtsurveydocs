**管理质量**模块（可通过仪表板访问）提供实时分析和空间可视化，以监控数据收集进度和调查员表现。它为项目经理提供分屏视图界面，可在各问卷和自定义分析报告之间快速切换。

![管理质量仪表板](/images/manage_quality.png)

## 仪表板概述

管理质量仪表板分为两个主要导航选项卡：**表单**和**报告**。此横向菜单让用户能够高效搜索和选择要分析的特定数据集或报告。

### 表单分析

从列表中选择特定表单时，仪表板提供多个内置可视化工具来跟踪提交质量和频率：

- **按开始时间统计**：显示一段时间内访谈发起频率的条形图。
- **按结束时间统计**：显示访谈完成时间的条形图。
- **按提交日期统计**：跟踪每日同步到服务器的数据量。
- **按用户名统计**：根据总提交数识别表现最佳的调查员的条形图。
- **访谈地图**：基于 Leaflet 的地理散点图，显示每次提交发生位置的 GPS 坐标，让管理员能够核实实地工作位置。

### 自定义报告

**报告**选项卡提供对预配置的 R Markdown 分析设计和其他自定义统计数据的访问。选择报告后，主视图区域通过嵌入式查看器动态加载生成的分析，支持对已收集数据进行更深入的统计核实。

## 搜索和筛选

侧边栏列表上方提供快速搜索栏，允许用户按名称快速查找特定表单或报告。

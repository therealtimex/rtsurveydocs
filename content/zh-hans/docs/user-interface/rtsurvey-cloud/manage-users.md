**管理用户**模块（在"设置"菜单中通常标记为**管理员工**）是处理 CPMS 环境中所有账户的集中目录。它为项目管理员提供入职人员、分配角色和规定地理访问级别所需的工具。

![管理用户界面](/images/manage_users.png)

## 用户网格概述

主界面提供显示所有已注册员工的综合网格。此视图让管理员能够快速搜索、筛选和审查账户状态。

### 主要数据列

网格包含每个用户的以下基本详情：

- **用户名和全名**：员工的主要标识符。
- **邮箱**：与账户关联的联系邮箱。
- **用户角色**：指示授予用户的系统权限（例如管理员、员工、监控员、访客）。
- **组别**：显示员工所属的特定用户组或团队。
- **状态**：指示账户当前是**活跃**还是**非活跃**。
- **创建日期**：账户注册的时间戳。

## 员工管理操作

管理员可通过顶部控制面板访问入职和维护用户账户的工具套件：

- **添加员工**：打开详细创建表单以手动输入新用户的个人资料，包括其角色、指定区域和联系信息。
- **导入员工**：通过上传 Excel 电子表格实现批量账户创建。这对于快速建立大型实地团队特别有用。
- **下载导入模板**：提供批量导入过程所需的标准化 `.xlsx` 模板。
- **导出到 Excel**：生成包含当前网格筛选用户列表及其详情的可下载报告。
- **删除**：从系统中永久删除选定的用户账户。

## 用户个人资料和分配

创建或编辑特定用户时（通过**添加员工**按钮或点击用户名），管理员可以配置详细的个人资料：

- **个人信息**：出生日期、性别、身份证号码和头像字段。
- **联系方式**：手机号码和详细位置信息（省、区、街道、地址）。
- **系统分配**：对于数据安全至关重要，管理员可以将用户链接到特定**区域**并分配精确的**用户角色**。
- **主管配置**：在高级设置中，可以为用户分配特定的监督代码或映射到特定平板设备（设备）。

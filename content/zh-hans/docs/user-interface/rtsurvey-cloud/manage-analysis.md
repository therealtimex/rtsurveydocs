RT-CPMS 中的**管理分析**模块提供全面的工具套件，用于处理和可视化您的调查数据。它分为两个主要部分，可从全局导航侧边栏访问：**分析开发**和**分析与报告**。

![管理分析界面](/images/manage_analysis.png)

## 分析开发

**分析开发**部分是创建和配置新分析设计的集中枢纽。研究人员和数据管理员在此定义如何处理和制表原始调查数据。

### 分析开发的主要功能
- **创建新设计**：使用突出的**新分析 +** 按钮开始构建新的报告模板或分析设计。
- **管理现有设计**：主网格提供所有分析模型的综合概述，显示关键元数据，如：
  - ID 和标题/描述
  - 便于分类的标签
  - 版本跟踪
  - 创建和更新时间戳
  - 作者信息
- **搜索和筛选**：使用每列内置的搜索和筛选工具轻松找到特定设计。
- **快速操作**：直接从网格的操作菜单查看、编辑或删除特定设计。

## 分析与报告

创建并运行分析设计后，**分析与报告**部分是您与生成的商业智能（BI）输出交互的地方。

### 分析与报告的主要功能
- **报告导航侧边栏**：使用专用左侧面板快速切换不同的可用报告。
- **搜索和筛选**：使用搜索栏或"所有分析"下拉筛选器缩小报告列表范围。
- **收藏**：将重要或频繁访问的报告标记为收藏，以便将来更快访问。

## 仪表板集成

为便于快速监控，主**主页仪表板**在主表单跟踪器旁提供专用的**报告**选项卡。此选项卡提供从行政指挥中心直接访问报告的功能，让您能够无缝监控数据收集进度和分析输出。

使用我们的演示账户，从不同角度体验 rtSurvey。每个账户都配置了特定角色，以展示 CAPI 调查项目中各类用户的功能和权限。

### 演示管理员
- **用户名：** admin_demo
- **密码：** AdminRtSurvey
- **角色：** 完全访问所有系统设置、用户管理和项目配置。

### 演示项目经理
- **用户名：** pm_demo
- **密码：** PMRtSurvey
- **角色：** 管理项目、分配任务，并监督调查部署和数据收集。

### 演示调查设计师
- **用户名：** designer_demo
- **密码：** DesignerRtSurvey
- **角色：** 使用 XLSForm 编辑器和 rtSurvey 的可视化表单构建器设计和测试调查。

### 演示现场调查员
- **用户名：** enumerator_demo
- **密码：** EnumeratorRtSurvey
- **角色：** 使用 rtSurvey 移动应用在现场开展调查、收集数据，并与 rtSurvey Cloud 同步。

### 演示数据分析师
- **用户名：** analyst_demo
- **密码：** AnalystRtSurvey
- **角色：** 分析已收集数据、生成报告，并与 Excel、Power BI、Python 和 R 等外部分析工具集成。

## 如何使用演示账户

1. **选择角色：**
   从上述列表中选择您想探索的演示角色。

2. **登录：**
   使用提供的用户名和密码登录 rtSurvey。

3. **探索功能：**
   在平台中浏览，了解所选角色可用的功能。

4. **反馈：**
   我们重视您的意见！请提供您的体验反馈，帮助我们改进 rtSurvey。

## 安全和使用指南

- 这些是共享演示账户，请勿输入任何敏感或个人信息。
- 演示账户访问权限受限，以确保数据安全，防止滥用。
- 演示账户的使用受到监控，以维护系统完整性。

通过使用这些演示账户，您可以全面了解 rtSurvey 在 CAPI 调查项目中如何为不同用户角色提供服务。探索 rtSurvey 如何在调查实施的各个阶段满足您的数据收集和分析需求。

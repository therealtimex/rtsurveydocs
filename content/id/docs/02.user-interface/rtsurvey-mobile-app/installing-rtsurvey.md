rtSurvey tersedia untuk perangkat Android dan iOS, memungkinkan Anda melakukan survei dan mengumpulkan data di berbagai platform mobile. Ikuti langkah-langkah ini untuk memasang rtSurvey di perangkat Anda.

## Persyaratan Sistem

Sebelum memasang, pastikan perangkat Anda memenuhi persyaratan berikut:

- Untuk Android: Android 7.0 atau lebih baru
- Untuk iOS: iOS 11.0 atau lebih baru
- Koneksi internet yang stabil untuk unduhan awal dan pembaruan

## Memasang di Android

1. Buka Google Play Store di perangkat Android Anda.
2. Di bilah pencarian, ketik "rtSurvey" atau gunakan tautan langsung ini: [rtSurvey di Google Play](https://play.google.com/store/apps/details?id=vn.rta.rtsurvey&hl=ln&gl=US)
3. Ketuk aplikasi rtSurvey di hasil pencarian.
4. Tekan tombol "Instal".
5. Tunggu unduhan dan instalasi selesai.
6. Setelah dipasang, Anda dapat membuka aplikasi dari layar beranda atau laci aplikasi perangkat Anda.

## Memasang di iOS

1. Buka App Store di perangkat iOS Anda.
2. Ketuk ikon pencarian dan ketik "rtSurvey" atau gunakan tautan langsung ini: [rtSurvey di App Store](https://apps.apple.com/vn/app/rtsurvey/id1178851547)
3. Ketuk aplikasi rtSurvey di hasil pencarian.
4. Tekan tombol "Dapatkan" atau ikon cloud untuk memulai unduhan.
5. Anda mungkin perlu mengautentikasi dengan Face ID, Touch ID, atau kata sandi Apple ID Anda.
6. Tunggu unduhan dan instalasi selesai.
7. Setelah dipasang, ikon aplikasi akan muncul di layar beranda Anda.

## Pemecahan Masalah Instalasi

Jika Anda mengalami masalah selama instalasi:

1. Periksa koneksi internet Anda dan coba lagi.
2. Pastikan Anda memiliki ruang penyimpanan yang cukup di perangkat Anda.
3. Restart perangkat Anda dan coba instalasi lagi.
4. Untuk Android: Hapus cache dan data Google Play Store di pengaturan perangkat Anda.
5. Untuk iOS: Keluar dari Apple ID dan masuk kembali.

Jika masalah berlanjut, kunjungi situs web dukungan rtSurvey atau hubungi administrator sistem Anda untuk bantuan.

## Memperbarui rtSurvey

Untuk memastikan Anda memiliki fitur dan perbaikan bug terbaru:

- Di Android: Aktifkan pembaruan otomatis di Google Play Store atau perbarui aplikasi secara manual.
- Di iOS: Aktifkan pembaruan otomatis di pengaturan App Store atau perbarui secara manual.

Pembaruan rutin membantu menjaga performa dan keamanan aplikasi.

Sekarang setelah berhasil memasang rtSurvey, Anda siap mulai menggunakannya untuk kebutuhan pengumpulan data Anda. Bagian berikutnya akan memandu Anda untuk menghubungkan aplikasi ke server.

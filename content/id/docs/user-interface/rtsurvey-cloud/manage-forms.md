Modul **Kelola Formulir** berfungsi sebagai pintu gerbang utama untuk mengatur instrumen survei Anda dan mengoordinasikan tugas pekerjaan lapangan. Modul ini menyediakan kontrol terperinci atas aksesibilitas formulir, tampilan data, dan penargetan perangkat.

![Antarmuka Manajemen Formulir](/images/manage_forms.png)

## Ikhtisar Keluarga Formulir

Di bawah menu **Entri Formulir & Data**, bagian **Keluarga Formulir** menampilkan grid komprehensif dari semua formulir yang Anda impor beserta kontrol akses cepat yang penting. Tampilan terpusat ini memungkinkan manajer proyek untuk dengan cepat menerapkan dan mengonfigurasi survei individual.

### Kolom Data Utama & Opsi Konfigurasi

- **Tampilan Data:** Akses catatan yang dikirimkan dan pratinjau dataset secara langsung untuk setiap formulir.
- **Izinkan Edit:** Toggle cepat untuk mengunci atau membuka kunci kemampuan pekerja lapangan untuk mengedit data yang dikirimkan (status Aktif/Tidak Aktif).
- **Visibilitas Publik:** Toggle untuk membuat formulir tersedia secara publik tanpa memerlukan autentikasi enumerator.
- **URL Webform:** Ambil secara instan tautan publik unik untuk berbagi formulir pengumpulan data berbasis browser.
- **Override Pengaturan:** Modal konfigurasi lanjutan (diakses melalui ikon roda gigi) untuk menyesuaikan aturan, nilai, dan menonaktifkan fitur tertentu yang spesifik formulir.
- **Pengidentifikasi Formulir:** Lihat metadata standar, termasuk nama Keluarga Formulir, Kode Keluarga, dan ID Formulir unik.
- **Konfigurasi Geo:** Konfigurasi pemetaan atau geopoint spesifik yang terkait dengan struktur formulir.
- **Kunci Formulir:** Fitur untuk mengunci akses kiriman untuk menyelesaikan fase pengumpulan data.

## Tindakan Formulir dan Navigasi

Panel kontrol atas memfasilitasi operasi batch dan tampilan formulir alternatif:

- **Tindakan ke Perangkat:** Alat dropdown yang canggih memungkinkan manajer proyek untuk menugaskan tugas, mengirim formulir yang ditargetkan, atau mengirimkan tindakan langsung ke perangkat lapangan enumerator tertentu.
- **Tab Formulir XLSX:** Navigasi dengan cepat dari grid manajemen utama ke lingkungan unggah untuk menangani file XLSForm baru.
- **Tab Form Builder:** Akses alat bawaan untuk membangun atau memodifikasi formulir secara visual dan dinamis tanpa menggunakan perangkat lunak spreadsheet eksternal.

rtSurvey est disponible pour les appareils Android et iOS, vous permettant de mener des enquêtes et de collecter des données sur une large gamme de plateformes mobiles. Suivez ces étapes pour installer rtSurvey sur votre appareil.

## Configuration Requise

Avant l'installation, assurez-vous que votre appareil répond aux exigences suivantes :

- Pour Android : Android 7.0 ou version ultérieure
- Pour iOS : iOS 11.0 ou version ultérieure
- Connexion Internet stable pour le téléchargement initial et les mises à jour

## Installation sur Android

1. Ouvrez le Google Play Store sur votre appareil Android.
2. Dans la barre de recherche, tapez "rtSurvey" ou utilisez ce lien direct : [rtSurvey sur Google Play](https://play.google.com/store/apps/details?id=vn.rta.rtsurvey&hl=ln&gl=US)
3. Appuyez sur l'application rtSurvey dans les résultats de recherche.
4. Cliquez sur le bouton "Installer".
5. Attendez que le téléchargement et l'installation soient terminés.
6. Une fois installée, vous pouvez ouvrir l'application depuis l'écran d'accueil ou le menu des applications de votre appareil.

## Installation sur iOS

1. Ouvrez l'App Store sur votre appareil iOS.
2. Appuyez sur l'icône de recherche et tapez "rtSurvey" ou utilisez ce lien direct : [rtSurvey sur l'App Store](https://apps.apple.com/vn/app/rtsurvey/id1178851547)
3. Appuyez sur l'application rtSurvey dans les résultats de recherche.
4. Appuyez sur le bouton "Obtenir" ou sur l'icône de nuage pour lancer le téléchargement.
5. Vous devrez peut-être vous authentifier avec Face ID, Touch ID ou le mot de passe de votre identifiant Apple.
6. Attendez que le téléchargement et l'installation soient terminés.
7. Une fois l'installation terminée, l'icône de l'application apparaîtra sur votre écran d'accueil.

## Dépannage des Problèmes d'Installation

Si vous rencontrez des problèmes lors de l'installation :

1. Vérifiez votre connexion Internet et réessayez.
2. Assurez-vous d'avoir suffisamment d'espace de stockage sur votre appareil.
3. Redémarrez votre appareil et tentez à nouveau l'installation.
4. Pour Android : Effacez le cache et les données du Google Play Store dans les paramètres de votre appareil.
5. Pour iOS : Déconnectez-vous de votre identifiant Apple et reconnectez-vous.

Si les problèmes persistent, visitez le site d'assistance de rtSurvey ou contactez votre administrateur système.

## Mise à jour de rtSurvey

Pour vous assurer de disposer des dernières fonctionnalités et corrections de bugs :

- Sur Android : Activez les mises à jour automatiques dans le Google Play Store ou mettez à jour l'application manuellement.
- Sur iOS : Activez les mises à jour automatiques dans les paramètres de l'App Store ou effectuez la mise à jour manuellement.

Des mises à jour régulières permettent de maintenir les performances et la sécurité de l'application.

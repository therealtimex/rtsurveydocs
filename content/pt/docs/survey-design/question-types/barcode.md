O tipo de pergunta barcode em XLSForms e rtSurvey permite aos utilizadores digitalizar e capturar dados de código de barras diretamente no inquérito. Esta funcionalidade é particularmente útil para gestão de inventário, rastreamento de produtos ou qualquer cenário onde a entrada de dados rápida e precisa de informação codificada seja necessária.

## Especificação XLSForm Básica

| type    | name          | label                   |
|---------|---------------|-------------------------|
| barcode | product_code  | Digitalize o código de barras do produto|

Para mais detalhes sobre o tipo de pergunta barcode básico, consulte a [especificação XLSForm](https://xlsform.org/en/#question-types).

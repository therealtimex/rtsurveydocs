**管理提交**模組（透過表單系列部分的**資料查看**按鈕存取）讓專案管理員和督導可以直接與傳入的原始資料互動。它是一個統一的工作區，用於審查調查員提交內容、追蹤裝置識別碼和執行資料品質操作。

![管理提交介面](/images/manage_submissions.png)

## 資料概覽和欄位

資料網格動態顯示針對特定表單收集的資料。它在兩種主要模式下運作：**官方**（最終記錄）和**工作中**（即時、未最終化記錄）。

### 主要資料欄位

無論表單中定義的自訂問題如何，網格都包含幾個標準元資料欄位以協助稽核：

- **提交來源：** 識別提交的來源平台（例如 FA 代表現場應用程式，WEB 代表網頁表單，RS 代表遠端系統）。
- **詳細：** 開啟聚焦的單一記錄視圖（搜尋圖示），檢查該實例提交的每個變數和答案。
- **內部備注：** 讓督導可以在特定記錄上附加側記或內部評論，而不改變收集的資料本身（以鉛筆圖示表示）。
- **日期欄位：** 指示記錄何時啟動、完成或同步的時間戳。
- **媒體附件：** 調查期間收集的圖片、簽名或檔案的直接縮圖連結。
- **重複群組：** 用於存取父表單內重複問題的巢狀表格的專用連結。

## 提交操作

為了促進主動的資料品質控制，介面提供了一個可在選定記錄上執行的操作指令下拉選單：

- **建立新實例：** 讓管理員可以直接在資料庫中手動輸入新的問卷調查記錄。
- **退回實例：** 拒絕已提交的記錄，並要求調查員重新驗證或重新收集資訊。
- **跟進實例：** 標記需要進一步關注的記錄，通常向現場團隊發送警告以進行澄清。
- **匯出至退回指令檔案/跟進指令套件：** 生成批次匯出（檔案），其中包含專門標記為退回或跟進的資料集。
- **轉換為 XML：** 將結構化資料集轉換回其原始 XML 格式，用於後端分析或系統整合。
- **轉發實例：** （在*工作中*模式下可用）立即將未最終化的資料推送至另一個裝置或使用者。
- **刪除：** 從資料庫中永久刪除選定的實例。

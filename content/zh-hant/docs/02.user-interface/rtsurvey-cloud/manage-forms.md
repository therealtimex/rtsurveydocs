**管理表單**模組是整理您的問卷調查工具和協調現場工作任務的主要入口。它提供對表單可存取性、資料查看和裝置定向的精細控制。

![表單管理介面](/images/manage_forms.png)

## 表單系列概覽

在**表單與資料輸入**選單下，**表單系列**部分顯示所有已匯入表單的全面網格，以及基本的快速存取控制。這個集中化視圖讓專案管理員可以快速部署和設定個別問卷調查。

### 主要資料欄位和設定選項

- **資料查看：** 直接存取每個表單的已提交記錄和資料集預覽。
- **允許編輯：** 快速切換以鎖定或解鎖現場工作人員編輯已提交資料的能力（啟用/停用狀態）。
- **公開可見性：** 切換以使表單無需調查員驗證即可公開使用。
- **網頁表單 URL：** 即時擷取用於分享基於瀏覽器的資料收集表單的唯一公開連結。
- **覆寫設定：** 進階設定模態（透過齒輪圖示存取），用於客製化特定表單的規則、值和停用特定功能。
- **表單識別碼：** 查看標準元資料，包括表單系列名稱、系列代碼和唯一表單 ID。
- **地理設定：** 與表單結構相關的特定地圖或地理點設定。
- **鎖定表單：** 鎖定提交存取以完成資料收集階段的功能。

## 表單操作和導航

頂部控制面板提供批次操作和替代表單視圖：

- **裝置操作：** 強大的下拉工具，讓專案管理員可以指派任務、傳送目標表單或直接向特定調查員的現場裝置發送操作。
- **XLSX 表單標籤：** 從主管理網格快速導航到上傳環境，以處理新的原生 XLSForm 檔案。
- **表單建立器標籤：** 存取內建工具，無需使用外部試算表軟體即可以視覺化方式動態建構或修改表單。

XLSForms 和 rtSurvey 中的 image 問題類型使受訪者能夠拍攝並提交照片作為問卷調查回應的一部分。此功能對於實地調查中收集視覺資料、記錄觀察或提供證據特別有用。

## 基本 XLSForm 規格

| type  | name        | label                           |
|-------|-------------|--------------------------------|
| image | photo       | 拍攝該地點的照片                |

有關基本 image 問題類型的更多詳細資訊，請參閱 [XLSForm 規格](https://xlsform.org/en/#question-types)。

## 用途

圖片問題通常用於：

1. 記錄實地條件或觀察
2. 在研究中捕獲視覺證據
3. 在影響評估中收集前後對比照片
4. 驗證任務完成或到達地點的情況
5. 收集用於遠端分析的視覺資料

## 最佳實踐

1. 提供有關應拍攝什麼的清晰說明。
2. 考慮隱私影響，並告知受訪者其照片將如何使用。
3. 注意文件大小和儲存限制，尤其是在網路連線有限的地區進行問卷調查時。
4. 確保裝置有足夠的儲存空間並已授予相機權限。

## 使用範例

以下是如何在問卷調查中使用圖片問題的範例：

| type  | name           | label                                      | hint                                        |
|-------|----------------|--------------------------------------------|--------------------------------------------|
| image | storefront     | 拍攝商店入口的照片                          | 確保商店名稱清晰可見                       |

## rtSurvey 擴展

雖然 image 問題的基本 XLSForm 規格很簡單，但 rtSurvey 可能提供額外的功能或自訂選項：

1. 圖片品質設定（例如低、中、高解析度）
2. 為圖片添加說明或標籤的選項
3. 單個問題的多圖片擷取
4. 與裝置原生相機應用程式或相冊的整合

（注意：rtSurvey 中針對 image 問題可用的特定擴展需要在此處確認和詳細說明。）

## 資料處理

透過此問題類型收集的圖片通常：

1. 以常見圖片格式（例如 JPG、PNG）儲存
2. 與其他問卷調查資料一起儲存，通常在單獨的媒體資料夾中
3. 可透過問卷調查管理平台查看和分析

## 分析注意事項

使用圖片問題時，請考慮：

1. 圖片將如何分析（例如手動審查、自動圖像分析）
2. 圖片文件所需的額外儲存空間
3. 儲存和處理照片的隱私和資料保護措施
4. 分析階段可能需要的圖片編輯或整理工具

## 限制

- 圖片文件可能很大，這可能會影響資料傳輸和儲存。
- 並非所有裝置都具有高品質相機或足夠的儲存空間。
- 分析大量圖片可能很耗時。
- 在拍攝圖片時（尤其是在公共場所）可能存在隱私問題。

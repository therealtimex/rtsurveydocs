Модуль **Управление отправками** (доступен через кнопку **Просмотр данных** в разделе «Семейство форм») позволяет менеджерам проектов и супервизорам напрямую взаимодействовать с поступающими необработанными данными. Он служит единым рабочим пространством для просмотра отправок интервьюеров, отслеживания идентификаторов устройств и выполнения операций по контролю качества данных.

![Интерфейс управления отправками](/images/manage_submissions.png)

## Обзор данных и столбцы

Сетка данных динамически отображает данные, собранные для конкретной формы. Она работает в двух основных режимах: **Официальный** (финализированные записи) и **Рабочий** (записи в реальном времени, не финализированные).

### Ключевые столбцы данных

Независимо от пользовательских вопросов формы, сетка включает несколько стандартных метаданных-столбцов для аудита:

- **Отправлено через:** Определяет платформу происхождения отправки (например, FA — полевое приложение, WEB — веб-форма, RS — удалённые системы).
- **Детали:** Открывает сфокусированный вид одной записи (значок поиска) для проверки каждой переменной и ответа этого экземпляра.
- **iNote:** Позволяет супервизорам прикреплять боковые заметки или внутренние комментарии к конкретной записи без изменения собранных данных (обозначается значком карандаша).
- **Поля дат:** Временные метки, указывающие, когда запись была инициирована, завершена или синхронизирована.
- **Медиавложения:** Прямые ссылки-миниатюры на изображения, подписи или файлы, собранные во время опроса.
- **Группы повторений:** Специальные ссылки для доступа к вложенным таблицам для повторяющихся вопросов в родительской форме.

## Действия с отправками

Для обеспечения активного контроля качества данных интерфейс предоставляет выпадающее меню выполняемых команд для выбранных записей:

- **Создать новый экземпляр:** Позволяет администраторам вручную вводить новую запись опроса непосредственно в базу данных.
- **Вернуть экземпляр:** Отклоняет отправленную запись и поручает интервьюеру повторно проверить или собрать информацию.
- **Сопроводить экземпляр:** Помечает запись для дальнейшего внимания, обычно отправляя предупреждение полевой группе для уточнения.
- **Экспорт в файл возвращённых команд / пакет команд последующего сопровождения:** Генерирует пакетные экспорты (файлы), содержащие наборы данных, специально отмеченные для возврата или сопровождения.
- **Преобразовать в XML:** Трансформирует структурированный набор данных обратно в исходный формат XML для серверного анализа или системной интеграции.
- **Переслать экземпляры:** (Доступно в *Рабочем* режиме) Немедленно передаёт не финализированные данные другому устройству или пользователю.
- **Удалить:** Безвозвратно удаляет выбранные экземпляры из базы данных.

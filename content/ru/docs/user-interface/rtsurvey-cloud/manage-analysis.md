Модуль **Управление аналитикой** в RT-CPMS предоставляет комплексный набор инструментов для обработки и визуализации данных опросов. Он разделён на два основных раздела, доступных из глобальной боковой панели навигации: **Разработка аналитики** и **Аналитика и отчёты**.

![Интерфейс управления аналитикой](/images/manage_analysis.png)

## Разработка аналитики

Раздел **Разработка аналитики** — это централизованный узел для создания и настройки новых аналитических проектов. Здесь исследователи и менеджеры данных определяют, как должны обрабатываться и сводиться в таблицы исходные данные опросов.

### Ключевые функции разработки аналитики
- **Создание новых проектов:** Используйте кнопку **Новая аналитика +** для создания нового шаблона отчёта или аналитического проекта.
- **Управление существующими проектами:** Основная сетка обеспечивает полный обзор всех аналитических моделей, отображая ключевые метаданные, такие как:
  - Идентификатор и заголовок/описание
  - Теги для удобной категоризации
  - Отслеживание версий
  - Временные метки создания и обновления
  - Информация об авторе
- **Поиск и фильтрация:** Легко находите конкретные проекты с помощью встроенных инструментов поиска и фильтрации по каждому столбцу.
- **Быстрые действия:** Просматривайте, редактируйте или удаляйте конкретные проекты непосредственно из меню действий в сетке.

## Аналитика и отчёты

После создания и запуска аналитического проекта раздел **Аналитика и отчёты** — это место для работы с сгенерированными результатами бизнес-аналитики (BI).

### Ключевые функции аналитики и отчётов
- **Боковая панель навигации по отчётам:** Быстро переключайтесь между различными доступными отчётами с помощью специальной левой панели.
- **Поиск и фильтрация:** Используйте строку поиска или фильтр выпадающего меню «Все аналитики» для сужения списка отчётов.
- **Избранное:** Отмечайте важные или часто используемые отчёты как избранные для более быстрого доступа.

## Интеграция с панелью управления

Для быстрого мониторинга основная **Домашняя панель управления** включает специальную вкладку **Отчёты** рядом с основным трекером форм. Эта вкладка обеспечивает немедленный доступ к отчётам прямо из административного командного центра, позволяя seamlessly отслеживать как ход сбора данных, так и аналитические результаты.

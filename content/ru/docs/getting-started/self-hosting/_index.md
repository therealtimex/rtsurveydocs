Запустите rtCloud на собственной инфраструктуре с помощью Docker Compose. Самостоятельный хостинг обеспечивает полное владение данными, сетью и средой развёртывания — идеально подходит для организаций с требованиями к резидентности данных, изолированными сетями или нестандартными инфраструктурными потребностями.

## Что такое самостоятельный хостинг rtCloud?

Самостоятельный хостинг rtCloud — это официальный образ Docker, упаковывающий всю платформу rtCloud в переносимый набор контейнеров, который можно запустить на любом Linux-сервере. В состав входят:

| Сервис | Описание |
|---------|-------------|
| **rtCloud App** | Веб-приложение Apache 2.4 + PHP 7.4 со встроенной фоновой очередью (Beanstalkd), аналитическим сервером (Shiny) и планировщиком задач |
| **MySQL 8.0** | Реляционная база данных для всех данных приложения и опросов |
| **Keycloak** *(опционально)* | Встроенный сервер единого входа (SSO) для корпоративного управления идентификацией |

## Когда выбирать самостоятельный хостинг

Самостоятельный хостинг — правильный выбор, если вы:

- Требуете **суверенитета данных** — все данные остаются в вашей инфраструктуре
- Работаете в **изолированной или ограниченной сети** без доступа к внешнему облаку
- Имеете **требования соответствия** (GDPR, HIPAA, государственная политика в области данных), предписывающие локальное хранение
- Нуждаетесь в интеграции с **внутренним поставщиком идентификации** (Active Directory, LDAP, SAML)
- Хотите **настроить ресурсы** — CPU, RAM и дисковое пространство по вашим условиям

## Обзор архитектуры

Развёртывание работает как набор Docker-контейнеров, связанных в изолированной сети:

```
┌────────────────────────────────────────┐
│            rtcloud-app                 │
│  Apache 2.4 (port 80)                  │
│  PHP 7.4 application                   │
│  Beanstalkd queue (internal)           │
│  Shiny Server (port 3838)              │
│  Cron scheduler                        │
└─────────────────┬──────────────────────┘
                  │ rtcloud-net (bridge)
┌─────────────────▼──────────────────────┐
│            rtcloud-mysql               │
│  MySQL 8.0 (port 3306, internal only)  │
└────────────────────────────────────────┘
```

При включённом SSO рядом работает третий контейнер:

```
┌─────────────────────────────────────────┐
│            rtcloud-keycloak             │
│  Keycloak (port 8080, internal only)    │
│  Admin UI (port 9000, internal only)    │
└─────────────────────────────────────────┘
```

Все контейнеры взаимодействуют через изолированную мостовую сеть Docker. Хосту открыты только порт веб-приложения и (опционально) порт аналитического сервера Shiny.

После развёртывания формы и назначения перечислителей можно приступать к сбору данных. **rtSurvey** поддерживает беспрепятственный сбор данных как через веб-браузеры, так и через специализированные мобильные приложения, обеспечивая гибкость независимо от того, подключена ли ваша команда к интернету или работает в удалённых офлайн-средах.

## Выбор подходящего метода сбора данных

В зависимости от географии и связи вашего проекта вы можете выбрать оптимальный метод для перечислителей:

- **Веб-браузер (Онлайн):** лучший вариант для колл-центров, офисного ввода данных или самостоятельного заполнения публичных опросов.
- **Мобильное приложение rtWork / rtSurvey (Онлайн и Офлайн):** лучший вариант для полевых операций, отдалённых районов с нестабильным интернетом и опросов, требующих медиавложений (фотографии, GPS-координаты, офлайн-карты).

---

## Метод 1: Сбор данных через веб-браузер

Использование интерфейса Webform позволяет перечислителям немедленно начать сбор данных без установки какого-либо программного обеспечения.

### 1. Доступ к URL Webform
На панели **Управление формами** в Панели управления найдите целевую форму и нажмите кнопку **URL Webform** для создания защищённой ссылки.

### 2. Заполнение формы
- Откройте предоставленный URL в любом современном веб-браузере.
- Если форма требует аутентификации, перечислитель должен войти с помощью учётных данных. Если установлена «Публичная видимость», можно продолжить напрямую.
- Заполните вопросы опроса. Интерфейс автоматически применит логику, шаблоны пропуска и правила валидации.
- **Захват медиафайлов:** если форма включает вопросы с изображениями, аудио или видео, веб-браузер предложит загрузить файл с компьютера или использовать веб-камеру/микрофон устройства (если доступно).

### 3. Отправка
По достижении последней страницы нажмите **Отправить**. Браузеру требуется активное интернет-соединение для завершения отправки. После успешной отправки данные немедленно отразятся в интерфейсе **Управление отправками**.

## Метод 2: Сбор данных через мобильное приложение (Офлайн)

Для надёжного полевого сбора данных мобильные приложения обеспечивают полные офлайн-возможности.

### 1. Установка и аутентификация
- Загрузите приложение **rtWork** (или **rtSurvey**) из Google Play Store или Apple App Store.
- Откройте приложение и войдите с использованием назначенных учётных данных перечислителя.

### 2. Загрузка форм (требует интернета)
- Перейдите в раздел **Формы** или **Задачи** в приложении.
- Нажмите значок **Синхронизация** или **Загрузка** для получения последних дизайнов анкет с сервера. После загрузки формы сохраняются локально на устройстве.

### 3. Сбор данных (Офлайн)
- Откройте загруженную форму и начните интервью.
- Можно безопасно собирать данные полностью офлайн.
- **Захват медиафайлов:** мобильное приложение нативно интегрируется с аппаратным обеспечением вашего устройства. Можно делать фотографии, записывать аудио и видео, фиксировать точные GPS-координаты непосредственно в приложении даже без подключения к интернету.
- Завершив интервью, финализируйте запись. Финализированные записи безопасно помещаются в исходящую очередь приложения.

### 4. Синхронизация отправок (требует интернета)
- Как только перечислитель вернётся в зону с интернетом (Wi-Fi или мобильные данные), необходимо перейти в интерфейс **Исходящая очередь** или **Синхронизация**.
- Дайте приложению команду отправить финализированные формы. Приложение безопасно передаст поставленные в очередь записи и все прикреплённые медиафайлы на сервер, после чего они появятся в таблице данных для проверки.

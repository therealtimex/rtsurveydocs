Тип вопроса geoshape в XLSForm и rtSurvey позволяет респондентам рисовать фигуры (полигоны) на карте, захватывая сложные географические данные. Эта функция особенно полезна для картографирования территорий, определения границ или разметки зон интереса в пространственных опросах.

## Базовая спецификация XLSForm

| type     | name        | label                           |
|----------|-------------|--------------------------------|
| geoshape | field_area  | Нарисуйте границу поля         |

Дополнительную информацию о базовом типе вопроса geoshape см. в [спецификации XLSForm](https://xlsform.org/en/#question-types).

## Применение

Вопросы типа geoshape обычно используются для:

1. Картографирования границ полей в сельскохозяйственных опросах
2. Определения зон экологического воздействия
3. Разметки зон в исследованиях городского планирования
4. Обозначения регионов для геологических исследований
5. Захвата сложных географических объектов для пространственного анализа

## Лучшие практики

1. Убедитесь, что на устройстве включены службы определения местоположения и предоставлены необходимые разрешения.
2. Предоставьте чёткие инструкции по рисованию фигуры и описанию включаемой территории.
3. Рассмотрите использование спутниковых снимков или базовых карт для помощи респондентам в точном рисовании фигур.
4. Учитывайте потенциальную сложность фигур и их влияние на размер и обработку данных.

## Пример использования

Ниже приведён пример использования вопроса типа geoshape в опросе:

| type     | name           | label                                       | hint                                               |
|----------|----------------|---------------------------------------------|----------------------------------------------------|
| geoshape | forest_area    | Обозначьте границу лесного участка          | Используйте не менее 3 точек для создания замкнутой фигуры |

## Расширения rtSurvey

rtSurvey может предлагать дополнительные функции для вопросов типа geoshape:

1. Интеграция с офлайн-картами для отдалённых районов
2. Параметры минимального и максимального количества точек для фигуры
3. Возможность редактирования или уточнения фигур после первоначального рисования
4. Поддержка различных типов фигур (например, прямоугольники, окружности) в дополнение к произвольным полигонам

## Формат данных

Данные геоформы обычно хранятся в виде строки пар координат, разделённых пробелами, заключённой в скобки:

```
(lat1 lon1; lat2 lon2; lat3 lon3; ... latN lonN)
```

Например:
```
(38.253094215699576 21.756382658677467; 38.25021274773806 21.756382658677467; 38.25007793942195 21.763892843919166; 38.25290886154963 21.763935759263404; 38.253094215699576 21.756382658677467)
```

## Соображения для анализа

При использовании вопросов типа geoshape учитывайте:

1. Как будут визуализироваться и анализироваться географические данные (например, в программном обеспечении ГИС)
2. Потенциальную необходимость очистки или упрощения сложных фигур
3. Меры конфиденциальности и защиты данных при обработке детальных пространственных данных
4. Интеграцию с другими пространственными источниками данных для комплексного анализа

## Ограничения

- Точное рисование фигур на небольших мобильных экранах может быть затруднено.
- Сложные фигуры могут требовать значительных ресурсов хранилища и вычислительной мощности.
- Вопросы типа geoshape могут подходить не для всех типов опросов или респондентов.
- С сбором детальных пространственных данных могут быть связаны опасения по поводу конфиденциальности.

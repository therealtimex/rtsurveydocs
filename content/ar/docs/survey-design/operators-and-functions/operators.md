### عوامل المقارنة

{{< table >}}
العامل | العملية      | المثال              | إجابة المثال
-------- | -------------- | -------------------- | --------------
`=`        | يساوي          | ${age} = 25     | true أو false
`!=`       | لا يساوي      | ${age} != 25    | true أو false
`>`        | أكبر من   | ${age} > 25     | true أو false
`>=`       | أكبر من أو يساوي | ${age} >= 25 | true أو false
`<`        | أصغر من      | ${age} < 25     | true أو false
`<=`       | أصغر من أو يساوي | ${age} <= 25  | true أو false
{{< /table >}}

في الأمثلة أعلاه، يمثل ${age} قيمة الحقل الحالي، ويُستخدم العامل لمقارنتها مع القيمة 25. سيتقيّم القيد إما بـ true أو false، اعتماداً على ما إذا كانت المقارنة محققة أم لا.

### العوامل المنطقية

تُستخدم العوامل المنطقية لدمج تعبيرات متعددة في القيود. فيما يلي بعض العوامل المنطقية المستخدمة شائعاً مع عملياتها وأمثلتها:

العامل | العملية      | المثال                                           
-------- | -------------- | --------------------------------------------------
`or`       | يُعيد true إذا كان أي من التعبيرين صحيحاً          | ${age} = 3 or ${age} = 4
`and`      | يُعيد true فقط إذا كان كلا التعبيرين صحيحين    | ${age} > 3 and ${age} < 5
`not()`    | يُعيد true إذا كان التعبير غير صحيح        | not(${age} > 3 and ${age} < 5)

في الأمثلة أعلاه، يمثل ${age} قيمة الحقل الحالي، وتُستخدم العوامل المنطقية لدمج التعبيرات. سيُقيَّم القيد بـ true أو false بناءً على الشروط المحددة.

المثال 1:
{{< alert icon=" " context="info" text="`${age} = 3 or ${age} = 4` سيُعيد `true` إذا كان العمر 3 أو 4." />}}

المثال 2:

المثال 3:

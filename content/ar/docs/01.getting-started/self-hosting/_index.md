شغّل rtCloud على بنيتك التحتية الخاصة باستخدام Docker Compose. تمنحك الاستضافة الذاتية ملكية كاملة لبياناتك وشبكتك وبيئة النشر — مثالية للمنظمات ذات متطلبات إقامة البيانات أو الشبكات المعزولة أو احتياجات البنية التحتية المخصصة.

## ما هي استضافة rtCloud الذاتية؟

استضافة rtCloud الذاتية هي صورة Docker رسمية تحزم منصة rtCloud بالكامل في حزمة حاويات محمولة يمكنك تشغيلها على أي خادم Linux. تشمل الحزمة:

| الخدمة | الوصف |
|---------|-------------|
| **تطبيق rtCloud** | تطبيق ويب Apache 2.4 + PHP 7.4 مع طابور خلفية مدمج (Beanstalkd) وخادم تحليلات (Shiny) ومهام مجدولة |
| **MySQL 8.0** | قاعدة بيانات علائقية لجميع بيانات التطبيق والاستطلاع |
| **Keycloak** *(اختياري)* | خادم Single Sign-On مدمج لإدارة هوية المؤسسات |

## متى تختار الاستضافة الذاتية

الاستضافة الذاتية هي الخيار الصحيح عندما:

- تتطلب **سيادة البيانات** — تبقى جميع البيانات داخل بنيتك التحتية الخاصة
- تعمل في **شبكة معزولة أو مقيدة** دون وصول إلى السحابة الخارجية
- لديك **متطلبات امتثال** (GDPR، HIPAA، سياسات بيانات حكومية) تُلزِم بالتخزين المحلي
- تحتاج إلى التكامل مع **مزود هوية داخلي** (Active Directory، LDAP، SAML)
- تريد **تخصيص الموارد** — تخصيص CPU وذاكرة الوصول العشوائي ومساحة التخزين بشروطك

## نظرة عامة على البنية

يعمل النشر كمجموعة حاويات Docker متصلة عبر شبكة داخلية:

```
┌────────────────────────────────────────┐
│            rtcloud-app                 │
│  Apache 2.4 (port 80)                  │
│  PHP 7.4 application                   │
│  Beanstalkd queue (internal)           │
│  Shiny Server (port 3838)              │
│  Cron scheduler                        │
└─────────────────┬──────────────────────┘
                  │ rtcloud-net (bridge)
┌─────────────────▼──────────────────────┐
│            rtcloud-mysql               │
│  MySQL 8.0 (port 3306, internal only)  │
└────────────────────────────────────────┘
```

عند تفعيل SSO، تعمل حاوية ثالثة جانباً:

```
┌─────────────────────────────────────────┐
│            rtcloud-keycloak             │
│  Keycloak (port 8080, internal only)    │
│  Admin UI (port 9000, internal only)    │
└─────────────────────────────────────────┘
```

تتواصل جميع الحاويات عبر شبكة Docker bridge معزولة. لا يُكشف للمضيف سوى منفذ تطبيق الويب ومنفذ تحليلات Shiny (اختياري).

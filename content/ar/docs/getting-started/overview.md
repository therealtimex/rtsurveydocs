rtSurvey منصة قوية لبناء النماذج وسير العمل لجمع البيانات بكفاءة. مع rtSurvey يمكنك:

1. إنشاء نماذج متطورة تتضمن صوراً ومواقع GPS ومنطق التخطي والحسابات ومجموعات البيانات الخارجية ولغات متعددة والمزيد.
2. جمع البيانات عبر التطبيق المحمول أو واجهة الويب مع مزامنة تلقائية عند توفر اتصال بالإنترنت.
3. تحليل البيانات بسهولة عبر تصديرها بصيغة CSV أو Stata، أو ربط rtSurvey بـ Excel أو Power BI أو Python أو R للحصول على لوحات متابعة تُحدَّث آنياً.

يعتمد الباحثون والفرق الميدانية والمهنيون في مختلف القطاعات على rtSurvey في تلبية احتياجاتهم الحيوية من جمع البيانات. إليك كيفية البدء:

## 1. الوصول إلى rtSurvey Cloud {#getting-started-get-rtCloud}

أسرع طريقة للبدء هي استخدام [rtSurvey Cloud](https://rtsurvey.com/#rtsurvey-cloud)، خدمة الاستضافة المُدارة الرسمية. وهي متاحة عبر موقع rtSurvey ومبنية على بنية تحتية موثوقة وآمنة. وبدلاً من ذلك، يمكنك استضافة rtSurvey على بنيتك التحتية الخاصة إن كنت تفضل ذلك.

## 2. إنشاء نموذج الاستطلاع {#getting-started-create-form}

1. صمّم نموذجك باستخدام `XLSForm` أو جرّب قالب [نموذج All Widgets](https://docs.google.com/spreadsheets/d/1af_Sl8A_L8_EULbhRLHVl8OclCfco09Hq2tqb9CslwQ/edit#gid=0).
2. ارفع XLSForm إلى rtSurvey Cloud وانشره، أو استخدم Form Builder (تجريبي) لتجربة تصميم مرئي.

## 3. تثبيت تطبيق rtSurvey {#getting-started-get-collect}

نزّل تطبيق rtSurvey على جهازك المحمول:

### لأجهزة Android:
1. زر [متجر Google Play](https://play.google.com/store/apps/details?id=vn.rta.rtsurvey).
2. ابحث عن "rtSurvey" واضغط على التطبيق الذي يحمل شعار rtSurvey.
3. انقر على "تثبيت" لتنزيل التطبيق وإعداده.

### لأجهزة iOS:
1. افتح [App Store](https://apps.apple.com/vn/app/rtsurvey/id1178851547) على جهازك.
2. ابحث عن "rtSurvey" وحدد موقع التطبيق الذي يحمل شعار rtSurvey.
3. اضغط على "احصل عليه" لتنزيل التطبيق وتثبيته.

## 4. ربط تطبيق rtSurvey بـ rtSurvey Cloud {#getting-started-connect}

1. أنشئ حساباً:
   - يمكن لمسؤول rtSurvey Cloud إنشاء حسابات للمعدِّين.
   - أو يمكن للمسؤول إنشاء رابط URL للمعدِّين لإنشاء حساباتهم بأنفسهم.
2. افتح تطبيق rtSurvey وسجّل الدخول ببيانات حسابك.

## 5. إجراء الاستطلاع {#getting-started-fill-form}

1. في التطبيق، اختر "ملء نموذج فارغ" لبدء استطلاع جديد.
2. أكمل النموذج ببيانات المستجيب.
3. عند الانتهاء، تتزامن بيانات النموذج تلقائياً مع rtSurvey Cloud عند توفر اتصال بالإنترنت.

## 6. تحليل بياناتك في rtSurvey Cloud {#getting-started-use-data}

1. سجّل الدخول إلى rtSurvey Cloud للوصول إلى بياناتك المجمَّعة.
2. نزّل بياناتك بصيغ مختلفة مثل CSV أو Stata لمزيد من التحليل.
3. استخدم أدوات التحليل المدمجة أو تكامل مع برنامج تحليل البيانات المفضل لديك.

Стовпець `appearance` у rtSurvey дозволяє налаштовувати візуальне представлення та поведінку питань у ваших опитуваннях. Ця функція покращує користувацький досвід і може значно підвищити ефективність збору даних. rtSurvey підтримує стандартні атрибути appearance XLSForm та розширює їх додатковими варіантами.

## Розширення appearance, специфічні для rtSurvey

rtSurvey розширює стандартні параметри appearance такими:

### Налаштування введення часу

Для питань типу `text`, що використовуються для введення часу:

- `appearance:` — Відображає годинник для вибору годин і хвилин
- `appearance: inline` — Відображає годинник як значок
- `appearance: inline-1line` — Відображає годинник в однорядковому форматі
- `appearance: inline-onlyresult` — Відображає значок годинника, зникає після вибору
- `appearance: inline-[FORMAT]` — Налаштовує формат відображення часу (наприклад, `[%H:%M]`, `[%h:%M:%S]`)

### Налаштування кольору

rtSurvey дозволяє налаштування кольору для різних appearance:

- `appearance: inline colors("0099FF")` — Налаштовує колір значка
- `appearance: inline-1line colors("0000FF","FFFF00")` — Налаштовує кольори в однорядковому форматі

### Сітковий макет

rtSurvey вводить сітковий макет для компактних, табличних відображень:

- `appearance: grid` — Застосовується до груп для створення сіткового макету

### Згортувані групи

- `appearance: collapsible` — Створює розгортувані/згортувані групи

## Найкращі практики використання appearance

1. **Послідовність**: Послідовно використовуйте атрибути appearance у вашому опитуванні для однакового вигляду.
2. **Мобільний vs. Веб**: Враховуйте, як appearance відображатиметься на різних пристроях та платформах.
3. **Продуктивність**: Будьте обережні з атрибутами appearance, які можуть уповільнити завантаження форми.
4. **Користувацький досвід**: Вибирайте appearance, що полегшують введення даних для респондентів.
5. **Тестування**: Завжди тестуйте свою форму на цільових пристроях.

## Розширені техніки

### Комбінування appearance

Деякі атрибути appearance можна комбінувати для складніших макетів:

```
| type | name | label | appearance |
|------|------|-------|------------|
| select_one options | choice | Select one: | minimal compact |
```

### Динамічний appearance

rtSurvey дозволяє динамічні зміни appearance на основі логіки форми:

```
| type | name | label | appearance | relevant |
|------|------|-------|------------|----------|
| text | time | Enter time: | inline-[%H:%M] | ${show_time} = 'yes' |
```

## Міркування щодо мобільного додатку

- Деякі appearance (наприклад, `quick`, `signature`) специфічні для мобільних пристроїв.
- Ретельно тестуйте на Android та iOS для забезпечення послідовної поведінки.

## Відомі обмеження

- Складні appearance можуть не відображатися однаково на всіх платформах.
- Деякі розширені appearance rtSurvey можуть не підтримуватися в офлайн-режимі.

## Усунення проблем із appearance

1. **Appearance не застосовано**: Перевірте наявність орфографічних помилок у стовпці appearance.
2. **Непослідовне відображення**: Перевірте сумісність з типом питання та платформою.
3. **Проблеми з продуктивністю**: Розгляньте спрощення складних appearance, особливо для великих опитувань.

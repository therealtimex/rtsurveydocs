Вирази в rtSurvey написані у підмножині **XPath 1.0**, розширеній функціями JavaRosa/ODK та кастомними функціями rtSurvey. Ви використовуєте вирази в стовпцях `calculate`, `constraint`, `relevant`, `required` та `default` вашого XLSForm.

## Посилання на значення полів

Використовуйте `${fieldname}` для посилання на значення іншого поля:

```
${age} > 18
```

Використовуйте `.` (одна крапка) для посилання на **значення поточного поля** — зазвичай використовується у виразах `constraint`:

```
. >= 0 and . <= 100
```

Використовуйте `..` для посилання на батьківську групу (розширене використання у повторах).

## Синтаксис виразів

Вирази дотримуються стандартних правил XPath:

- **Рядки** мають бути в одинарних лапках: `'yes'`
- **Числа** пишуться як є: `42`, `3.14`
- **Boolean** результати використовуються для `relevant`, `required` та `constraint` — будь-яке непорожнє, ненульове значення є істинним
- Пробіли навколо операторів ігноруються

{{% alert icon=" " context="warning" %}}
Завжди використовуйте прямі лапки (`'` або `"`) — ніколи "смарт-лапки" (фігурні лапки). Редактори форматованого тексту часто автоматично перетворюють лапки та зламають ваші вирази.
{{% /alert %}}

## Розділи цієї глави

- **[Оператори](operators)** — оператори порівняння (`=`, `!=`, `>`, `<`, `>=`, `<=`) та логічні оператори (`and`, `or`, `not()`)
- **[Функції](functions)** — рядкові, функції вибору, числові, функції дати/часу, boolean, геофункції та службові функції
- **[Посилання](references)** — як посилатися на поля та контекстні значення

## Швидкі приклади

| Варіант використання | Вираз |
|----------|------------|
| Показати, якщо вік більше 18 | `${age} > 18` |
| Показати лише якщо обрано "yes" | `${consent} = 'yes'` |
| Обов'язково, якщо інше поле не порожнє | `${name} != ''` |
| Обчислити суму | `${adults} + ${children}` |
| Об'єднати ім'я | `concat(${first_name}, ' ', ${last_name})` |
| Сьогоднішня дата | `today()` |
| Перевірити, чи обраний варіант | `selected(${interests}, 'sports')` |

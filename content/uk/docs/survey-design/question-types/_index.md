rtSurvey підтримує всі стандартні типи питань XLSForm, а також кілька розширень. Кожен тип питання контролює, який тип даних збирається і як відображається віджет введення на пристрої.

Щоб встановити тип питання, введіть назву типу у стовпець `type` таблиці **survey** у вашому XLSForm.

## Текстове введення

| Тип | Опис |
|------|-------------|
| [text](text) | Відповідь у вільній формі — дозволені будь-які символи |
| [integer](integer) | Ціле число (без десяткових знаків) |
| [decimal](decimal) | Число з десятковими знаками |
| [range](range) | Число, обране за допомогою повзунка в межах визначеного мін/макс діапазону |

## Вибір

| Тип | Опис |
|------|-------------|
| [select_one listname](select-one) | Вибрати рівно один варіант зі списку |
| [select_multiple listname](select-multiple) | Вибрати один або більше варіантів зі списку |
| [rank listname](rank) | Впорядкувати варіанти за перевагою або пріоритетом |

## Дата та час

| Тип | Опис |
|------|-------------|
| [date](date) | Календарна дата (рік, місяць, день) |
| [time](time) | Час доби (години, хвилини) |
| [datetime](datetime-date-time) | Комбіновані дата та час |

## Розширення rtSurvey

Ці типи є специфічними для rtSurvey і не є частиною стандартної специфікації XLSForm.

| Тип | Опис |
|-----|------|
| [search-autocomplete](search-autocomplete) | Текстове введення з автодоповненням на основі API у реальному часі |
| [mentions](mentions) | Текстове поле з автодоповненням `@`-згадувань для позначення сутностей |
| [texttags](texttags) | Введення тегів — кожен запис стає видаляємим чіпом; зберігається як рядок, розділений пробілами |

Для груп повторення дивіться [Repeats](../advanced-extension/repeats)

## Як type та appearance працюють разом

`type` визначає **які дані збираються**. Стовпець `appearance` контролює **як виглядає віджет**. Багато типів підтримують кілька appearance — наприклад, `select_one` може відображатися як радіокнопки, випадаючий список, шкала Лайкерта або компактна сітка.

Дивіться [Appearance](../appearance) для повного списку варіантів.

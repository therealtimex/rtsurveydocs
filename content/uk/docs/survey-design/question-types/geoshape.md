Тип питання geoshape у XLSForm та rtSurvey дозволяє респондентам малювати форми (полігони) на карті, фіксуючи складні географічні дані. Ця функція особливо корисна для картування областей, визначення меж або позначення регіонів інтересу в просторових опитуваннях.

## Базова специфікація XLSForm

| type     | name        | label                           |
|----------|-------------|--------------------------------|
| geoshape | field_area  | Draw the boundary of the field  |

Для отримання додаткових відомостей про базовий тип питання geoshape дивіться [специфікацію XLSForm](https://xlsform.org/en/#question-types).

## Використання

Питання geoshape зазвичай використовуються для:

1. Картування меж полів в аграрних опитуваннях
2. Визначення областей екологічного впливу
3. Позначення зон у дослідженнях міського планування
4. Окреслення регіонів для геологічних опитувань
5. Фіксування складних географічних об'єктів для просторового аналізу

## Найкращі практики

1. Переконайтеся, що на пристрої увімкнені служби визначення місцезнаходження та надані дозволи.
2. Надавайте чіткі інструкції щодо того, як малювати форму та яку область слід включити.
3. Розгляньте використання супутникових знімків або базових карт для допомоги респондентам у точному малюванні форм.
4. Будьте уважні до потенційної складності форм та їх впливу на розмір і обробку даних.

## Приклад використання

Ось приклад того, як можна використовувати питання geoshape в опитуванні:

| type     | name           | label                                      | hint                                        |
|----------|----------------|--------------------------------------------|--------------------------------------------|
| geoshape | forest_area    | Outline the boundary of the forest patch   | Use at least 3 points to create a closed shape |

## Розширення rtSurvey

Хоча базова специфікація XLSForm для питань geoshape є простою, rtSurvey може пропонувати додаткові функції або налаштування:

1. Інтеграція з офлайн-картами для віддалених районів
2. Параметри для встановлення мінімальної та максимальної кількості точок для форми
3. Можливість редагувати або уточнювати форми після початкового малювання
4. Підтримка різних типів форм (наприклад, прямокутники, кола) на додаток до вільних полігонів

## Формат даних

Дані geoshape зазвичай зберігаються як рядок з розділених пробілами пар координат, укладених у дужки:

```
(lat1 lon1; lat2 lon2; lat3 lon3; ... latN lonN)
```

Наприклад:
```
(38.253094215699576 21.756382658677467; 38.25021274773806 21.756382658677467; 38.25007793942195 21.763892843919166; 38.25290886154963 21.763935759263404; 38.253094215699576 21.756382658677467)
```

## Міркування для аналізу

При використанні питань geoshape врахуйте:

1. Як географічні дані будуть візуалізовані та проаналізовані (наприклад, ПЗ ГІС)
2. Потенційну необхідність очищення або спрощення складних форм
3. Заходи конфіденційності та захисту даних для обробки детальних просторових даних
4. Інтеграція з іншими просторовими джерелами даних для комплексного аналізу

## Обмеження

- Малювання точних форм на маленьких мобільних екранах може бути складним.
- Складні форми можуть вимагати значних ресурсів для зберігання та обробки.
- Питання geoshape можуть бути не підходящими для всіх типів опитувань або респондентів.
- Можуть виникнути проблеми конфіденційності, пов'язані зі збором детальних просторових даних.

Модуль **Управління користувачами** (часто позначений як **Manage Staff** в меню Setting Up) є централізованим каталогом для роботи з усіма обліковими записами у вашому середовищі CPMS. Він надає адміністраторам проектів інструменти для адаптації персоналу, призначення ролей та визначення рівнів географічного доступу.

![Інтерфейс управління користувачами](/images/manage_users.png)

## Огляд таблиці користувачів

Основний інтерфейс містить комплексну таблицю з усіма зареєстрованими членами персоналу. Цей вигляд дозволяє адміністраторам швидко шукати, фільтрувати та переглядати статуси облікових записів.

### Ключові стовпці даних

Таблиця включає такі основні деталі для кожного користувача:

- **Username & Fullname:** Основні ідентифікатори для члена персоналу.
- **Email:** Контактна адреса електронної пошти, пов'язана з обліковим записом.
- **User Role:** Вказує системні дозволи, надані користувачу (наприклад, Адміністратор, Персонал, Монітор, Гість).
- **Group:** Відображає конкретну групу користувачів або команду, до якої належить член персоналу.
- **Status:** Вказує, чи обліковий запис наразі **Активний** або **Неактивний**.
- **Created Date:** Мітка часу, коли обліковий запис був зареєстрований.

## Дії з управління персоналом

Адміністратори мають доступ до набору інструментів для адаптації та підтримки облікових записів користувачів, доступних з верхньої панелі управління:

- **Add Staff:** Відкриває детальну форму створення для ручного введення профілю нового користувача, включаючи його роль, призначені регіони та контактну інформацію.
- **Import Staffs:** Дозволяє масове створення облікових записів шляхом завантаження електронної таблиці Excel. Це особливо корисно для швидкого встановлення великих польових команд.
- **Download import template:** Надає стандартизований шаблон `.xlsx`, необхідний для процесу масового імпорту.
- **Export to Excel:** Генерує звіт для завантаження з поточним відфільтрованим списком користувачів таблиці та їхніми деталями.
- **Delete:** Остаточно видаляє вибрані облікові записи користувачів із системи.

## Профілі та призначення користувачів

При створенні або редагуванні конкретного користувача (через кнопку **Add Staff** або натиснувши на ім'я користувача), адміністратори можуть налаштовувати детальні профілі:

- **Personal Information:** Поля для дати народження, статі, ідентифікаційного номера та аватара.
- **Contact Details:** Номер мобільного телефону та детальна інформація про місцезнаходження (область, район, район, адреса).
- **System Assignments:** Критично важливо для безпеки даних — адміністратори можуть пов'язувати користувачів з конкретними **регіонами** та призначати точні **ролі користувачів**.
- **Supervisor Configuration:** У розширених налаштуваннях користувачам можна призначати специфічні коди нагляду або відображати їх на конкретні планшети (пристрої).

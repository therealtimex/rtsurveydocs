Запускайте rtCloud на власній інфраструктурі за допомогою Docker Compose. Самостійний хостинг надає вам повне право власності на ваші дані, мережу та середовище розгортання — ідеально для організацій з вимогами щодо резидентності даних, ізольованих мереж або потреб у власній інфраструктурі.

## Що таке самостійний хостинг rtCloud?

Самостійний хостинг rtCloud — це офіційний Docker-образ, який пакує всю платформу rtCloud у портативний контейнерний стек, що можна запустити на будь-якому сервері Linux. Стек включає:

| Сервіс | Опис |
|---------|-------------|
| **rtCloud App** | Веб-застосунок Apache 2.4 + PHP 7.4 із вбудованою фоновою чергою (Beanstalkd), аналітичним сервером (Shiny) та запланованими задачами |
| **MySQL 8.0** | Реляційна база даних для всіх даних застосунку та опитувань |
| **Keycloak** *(необов'язково)* | Вбудований сервер єдиного входу (SSO) для управління корпоративними ідентифікаціями |

## Коли обирати самостійний хостинг

Самостійний хостинг — правильний вибір, коли ви:

- Потребуєте **суверенітету даних** — всі дані залишаються у вашій власній інфраструктурі
- Працюєте в **ізольованій або обмеженій мережі** без доступу до зовнішнього хмарного сервісу
- Маєте **вимоги до відповідності** (GDPR, HIPAA, державна політика щодо даних), що вимагають зберігання на власних серверах
- Потребуєте інтеграції з **внутрішнім постачальником ідентифікаційних даних** (Active Directory, LDAP, SAML)
- Хочете **налаштувати ресурси** — виділення CPU, RAM та сховища на власних умовах

## Огляд архітектури

Розгортання виконується як набір Docker-контейнерів, з'єднаних у внутрішній мережі:

```
┌────────────────────────────────────────┐
│            rtcloud-app                 │
│  Apache 2.4 (port 80)                  │
│  PHP 7.4 application                   │
│  Beanstalkd queue (internal)           │
│  Shiny Server (port 3838)              │
│  Cron scheduler                        │
└─────────────────┬──────────────────────┘
                  │ rtcloud-net (bridge)
┌─────────────────▼──────────────────────┐
│            rtcloud-mysql               │
│  MySQL 8.0 (port 3306, internal only)  │
└────────────────────────────────────────┘
```

Коли SSO увімкнено, поруч запускається третій контейнер:

```
┌─────────────────────────────────────────┐
│            rtcloud-keycloak             │
│  Keycloak (port 8080, internal only)    │
│  Admin UI (port 9000, internal only)    │
└─────────────────────────────────────────┘
```

Усі контейнери взаємодіють через ізольовану Docker bridge-мережу. Тільки порт веб-застосунку та (за бажанням) порт аналітики Shiny відкриті для хосту.

rtCloudはrtSurveyエコシステムの堅牢なサーバーコンポーネントで、データ収集、管理、分析を効率化するために設計されています。rtSurvey運営の中核ハブとして、rtCloudは複雑な調査プロジェクトと縦断的研究をサポートする包括的な機能セットを提供します。

## 主な機能

### プロジェクト管理
- 調査プロジェクトのすべての側面を1か所で整理する
- 各プロジェクト内のユーザーロール、フォーム、分析、成果物、権限を管理する

### ユーザー管理とセキュリティ
- ロールベースの権限を持つユーザーアカウントを作成・管理する
- あらゆるレベルでデータセキュリティとアクセス制御を確保する

### フォーム管理
- XLSFormを直接アップロード・管理する
- 軽微な調整から構造的変更まで、フォームバージョンの更新をサポートする
- フォームにマルチメディアや追加データを添付する
- 調査票を完全に制御するための真のフォーム削除機能

### データ収集と送信管理
- rtSurveyモバイルアプリ、Webアプリ、Webフォームとのシームレスな統合
- 認証済みユーザーの送信と匿名の公開リンクの両方をサポートする
- 送信のマルチメディアとデータ添付を処理する
- 素早いインサイトのための送信データのインタラクティブなテーブルプレビュー

### 高度な送信ワークフロー
- さらなる編集や確認のために送信をユーザーのデバイスに返却する
- 共同ワークフローと品質管理を可能にするために他のデバイスに送信を転送する

### 縦断的データ管理
- 繰り返し測定と長期研究を効率的に処理する
- 時間の経過に伴う参加者データの変更と更新を追跡する

### 柔軟な接続性
- rtSurveyモバイルアプリがフォームのダウンロードと送信のアップロードのために接続できるようにする
- 接続が回復したときにシームレスに同期するオフラインデータ収集をサポートする

## rtCloudの特長

他のデータ収集プラットフォームにインスパイアされながらも、rtCloudはユニークな機能で差別化されています：

1. **真のフォーム削除機能**：一部のプラットフォームとは異なり、rtCloudは必要なときにフォームを完全に削除できます。

2. **柔軟な送信ワークフロー**：送信を返却・転送する機能により、複雑なデータレビューと品質管理プロセスが可能になります。

3. **統合プロジェクト管理**：rtCloudはフォームとデータ管理を超えて、調査プロジェクトのすべての側面を整理するツールを提供します。

4. **直接XLSFormサポート**：変換なしでXLSFormを直接アップロードでき、フォーム作成プロセスを効率化します。

5. **包括的な権限システム**：プロジェクト内のユーザーアクセスと機能への詳細なコントロール。

## rtCloudを始める

rtCloudを調査プロジェクトに使用するには：

1. rtCloudサーバーを設定するか、ホスティングソリューションのためにrtSurveyに連絡する。
2. 最初のプロジェクトを作成してチームメンバーを招待する。
3. XLSFormをアップロードしてデータ収集ワークフローを設定する。
4. rtSurveyモバイルアプリを接続してデータ収集を開始する。

rtCloudは研究者、組織、データ収集チームが複雑な調査プロジェクトを簡単に、安全に、柔軟に管理できるようにします。一回限りの調査から複数年にわたる縦断的研究まで、rtCloudは成功に必要なツールを提供します。

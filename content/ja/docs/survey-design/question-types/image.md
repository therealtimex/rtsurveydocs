XLSFormおよびrtSurveyのimage質問タイプは、回答者が調査回答の一部として写真を撮影して送信できます。この機能は、視覚的データの収集、観察の記録、またはフィールド調査での証拠の提供に特に便利です。

## 基本XLSForm仕様

| type  | name        | label                           |
|-------|-------------|--------------------------------|
| image | photo       | 場所の写真を撮影してください    |

基本的なimage質問タイプの詳細については、[XLSForm仕様](https://xlsform.org/en/#question-types)を参照してください。

## 用途

Image質問は一般的に以下に使用されます：

1. フィールド状況や観察の記録
2. 研究調査での視覚的証拠の収集
3. インパクト評価での前後の写真の収集
4. タスクの完了や場所の存在の確認
5. リモート分析のための視覚データの収集

## ベストプラクティス

1. 何を撮影すべきかについて明確な指示を提供してください。
2. プライバシーへの影響を考慮し、写真の使用方法について回答者に通知してください。
3. ファイルサイズとストレージの制限に注意してください。特にインターネット接続が限られた地域での調査では。
4. デバイスに十分なストレージスペースがあり、カメラの権限が付与されていることを確認してください。

## 使用例

調査でimage質問を使用する例を示します：

| type  | name           | label                                      | hint                                        |
|-------|----------------|--------------------------------------------|--------------------------------------------|
| image | storefront     | 店舗の入口の写真を撮影してください       | 店名がはっきり見えるようにしてください    |

## データ処理

この質問タイプで収集された画像は通常：

1. 一般的な画像形式（例：JPG、PNG）で保存される
2. 調査データと一緒に、多くの場合別のメディアフォルダーに保存される
3. 調査管理プラットフォームを通じて表示・分析にアクセス可能

## 分析上の考慮事項

Image質問を使用する場合は以下を考慮してください：

1. 画像をどのように分析するか（例：手動レビュー、自動画像分析）
2. 画像ファイルに必要な追加のストレージスペース
3. 写真の保存と処理のためのプライバシーとデータ保護対策
4. 分析フェーズでの画像編集または整理ツールの潜在的な必要性

## 制限事項

- 画像ファイルは大きくなる可能性があり、データ転送とストレージに影響する場合があります。
- すべてのデバイスに高品質のカメラや十分なストレージスペースがあるわけではありません。
- 大量の画像を分析するのは時間がかかる場合があります。
- 特に公共の場での画像撮影に関連するプライバシーの懸念がある場合があります。

XLSFormおよびrtSurveyのgeoshape質問タイプは、回答者が地図上にシェイプ（ポリゴン）を描き、複雑な地理データを記録できます。この機能は、エリアのマッピング、境界の定義、または空間調査での関心領域のマーキングに特に便利です。

## 基本XLSForm仕様

| type     | name        | label                           |
|----------|-------------|--------------------------------|
| geoshape | field_area  | フィールドの境界を描いてください  |

基本的なgeoshape質問タイプの詳細については、[XLSForm仕様](https://xlsform.org/en/#question-types)を参照してください。

## 用途

Geoshape質問は一般的に以下に使用されます：

1. 農業調査でのフィールド境界のマッピング
2. 環境への影響エリアの定義
3. 都市計画研究でのゾーンのマーキング
4. 地質調査での地域の概要
5. 空間分析のための複雑な地理的特徴の記録

## ベストプラクティス

1. デバイスの位置情報サービスが有効で権限が付与されていることを確認してください。
2. シェイプの描き方と含めるべきエリアについて明確な指示を提供してください。
3. 回答者が正確にシェイプを描けるよう衛星画像やベースマップの使用を検討してください。
4. シェイプの潜在的な複雑さとデータサイズと処理への影響に注意してください。

## 使用例

調査でgeoshape質問を使用する例を示します：

| type     | name           | label                                      | hint                                        |
|----------|----------------|--------------------------------------------|--------------------------------------------|
| geoshape | forest_area    | 森林パッチの境界を描いてください   | 閉じたシェイプを作成するために少なくとも3点を使用してください |

## データ形式

Geoshapeデータは通常、スペース区切りの座標ペアの文字列として括弧で囲まれて保存されます：

```
(lat1 lon1; lat2 lon2; lat3 lon3; ... latN lonN)
```

例：
```
(38.253094215699576 21.756382658677467; 38.25021274773806 21.756382658677467; 38.25007793942195 21.763892843919166; 38.25290886154963 21.763935759263404; 38.253094215699576 21.756382658677467)
```

## 分析上の考慮事項

Geoshape質問を使用する場合は以下を考慮してください：

1. 地理データをどのように視覚化・分析するか（例：GISソフトウェア）
2. 複雑なシェイプのデータクリーニングや単純化の潜在的な必要性
3. 詳細な空間データを処理するためのプライバシーとデータ保護対策
4. 包括的な分析のための他の空間データソースとの統合

## 制限事項

- 小さなモバイル画面で正確なシェイプを描くのは難しい場合があります。
- 複雑なシェイプは大きなストレージと処理能力を必要とする場合があります。
- Geoshape質問はすべての種類の調査や回答者に適しているわけではありません。
- 詳細な空間データの収集に関連するプライバシーの懸念がある場合があります。

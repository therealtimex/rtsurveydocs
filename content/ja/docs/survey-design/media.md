rtSurveyは調査におけるリッチなメディア統合をサポートし、画像、音声、動画でアンケートを強化できます。この機能は回答者体験とデータ収集品質を大幅に改善できます。

## サポートされるメディアタイプ

rtSurveyは以下のメディアタイプをサポートしています：
- 画像（jpg、png、gif）
- 音声（mp3、wav）
- 動画（mp4、webm）

## 調査にメディアを追加する

rtSurveyフォームにメディアを含めるには、XLSFormの以下の列を使用します：

- `image`：画像の表示用
- `audio`：音声ファイルの再生用
- `video`：動画ファイルの再生用

例：

```
| type | name          | label         | image        | audio       | video       |
|------|---------------|---------------|--------------|-------------|-------------|
| note | media_example | メディア例 | example.jpg  | sound.mp3   | clip.mp4    |
```

## メディアファイル管理

### Webベースの調査
Webベースの調査では、rtSurveyはメディアファイルをアップロードして整理できるメディア管理インターフェースを提供します。これらのファイルはその後、調査で自動的に利用可能になります。

### モバイルアプリ
rtSurveyモバイルアプリを使用する場合：
1. デバイスの`/rtSurvey/forms/[form-name]-media/`フォルダにメディアファイルを配置する。
2. XLSFormで正確なファイル名を参照する。

## rtSurvey固有の機能

### 動的メディアロード
rtSurveyは調査回答に基づいた動的なメディアロードをサポートします：

```
| type         | name      | label              | image                    |
|--------------|-----------|--------------------|--------------------------| 
| select_one species | animal | 動物を選択してください | ${animal}.jpg            |
```

### 選択肢でのメディア
rtSurveyは選択質問の選択肢でメディアを使用できます：

```
| type                | name    | label           | media::image |
|---------------------|---------|-----------------|--------------|
| select_one_from_file animals | 動物を選択してください |              |
```

choicesシートでは：
```
| list_name | name  | label | media::image |
|-----------|-------|-------|--------------|
| animals   | dog   | 犬   | dog.jpg      |
| animals   | cat   | 猫   | cat.jpg      |
```

### メディアキャプチャ
rtSurveyはメディアキャプチャ機能でXLSFormを拡張します：

```
| type  | name        | label               |
|-------|-------------|---------------------|
| image | photo       | 写真を撮ってください        |
| audio | voice_note  | 音声メモを録音してください |
| video | video_clip  | 動画を撮影してください      |
```

## メディア使用のベストプラクティス

1. **ファイルサイズを最適化する**：大きなメディアファイルは調査の読み込みと送信を遅くする可能性がある。
2. **適切なフォーマットを使用する**：広くサポートされているフォーマットを使う（画像はjpg、音声はmp3、動画はmp4）。
3. **代替手段を提供する**：アクセシビリティのために常にテストの代替手段を含める。
4. **徹底的にテストする**：すべてのターゲットデバイスでメディアが正しく表示されることを確認する。
5. **オフライン使用を考慮する**：オフラインで実施される可能性のある調査では、すべてのメディアがローカルで利用可能であることを確認する。

## 多言語メディアサポート

rtSurveyは言語固有のメディアをサポートします。`::language`サフィックスを使用する：

```
| type | name  | label    | image::English | image::Japanese (ja) |
|------|-------|----------|----------------|----------------|
| note | intro | ようこそ  | welcome_en.jpg | welcome_ja.jpg |
```

## データエクスポートでのメディア

rtSurveyからデータをエクスポートする場合：
- Webベースの調査では、メディアのURLがエクスポートに含まれる。
- モバイルアプリの調査では、ファイルパスが含まれる。

## モバイルアプリの考慮事項

- メディアが多い調査にはデバイスに十分なストレージスペースを確保する。
- rtSurveyモバイルアプリはオフラインのメディア再生とキャプチャをサポートする。
- 大きなメディアファイルは低スペックのデバイスでアプリのパフォーマンスに影響する場合がある。

## 既知の制限

- 古いブラウザはすべてのメディアフォーマットをサポートしない場合がある。
- 非常に大きな動画ファイルは低帯域幅の状況で問題を引き起こす場合がある。

## メディア問題のトラブルシューティング

1. **メディアが表示されない**：ファイルパスと名前の正確性を確認する。
2. **再生の問題**：メディアフォーマットがターゲットデバイスでサポートされていることを確認する。
3. **読み込みが遅い**：ファイルサイズの最適化またはメディアのプリロードを検討する。

## 高度なメディア機能

### ジオタグ
rtSurveyは調査中にキャプチャされたメディアを自動的にジオタグできます：

```
| type  | name        | label        | appearance |
|-------|-------------|--------------|------------|
| image | photo       | 写真を撮る | geotag     |
```

### メディア注釈
回答者が画像に注釈を付けられるようにする：

```
| type  | name        | label        | appearance |
|-------|-------------|--------------|------------|
| image | photo       | 画像に注釈を付ける | annotate |
```

rtSurveyフォームでメディアを効果的に使用することで、より魅力的で有益かつ正確な調査を作成できます。メディア包含のメリットとパフォーマンスの考慮事項のバランスを保つことを忘れないでください（特にインターネット接続が限られている地域や低スペックのデバイスでデプロイされる調査では）。

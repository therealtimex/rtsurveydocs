양식이 배포되고 조사원이 할당되면 데이터 수집을 시작할 수 있습니다. **rtSurvey**는 웹 브라우저와 전용 모바일 애플리케이션 모두를 통해 원활한 데이터 수집을 지원하여 팀이 인터넷에 연결되어 있거나 원격의 오프라인 환경에서 작업하는 경우 모두 유연성을 제공합니다.

## 적절한 수집 방법 선택

프로젝트의 지리와 연결성에 따라 조사원에게 최적의 방법을 선택할 수 있습니다:

- **웹 브라우저 (온라인):** 콜 센터, 사무실 기반 데이터 입력 또는 응답자가 자체 관리하는 공개 설문에 가장 적합합니다.
- **rtWork / rtSurvey 모바일 앱 (온라인 및 오프라인):** 현장 운영, 불안정한 인터넷이 있는 원격 지역, 그리고 미디어 첨부 파일 (사진, GPS 좌표, 오프라인 지도)이 필요한 설문에 가장 적합합니다.

---

## 방법 1: 웹 브라우저를 통한 데이터 수집

Webform 인터페이스를 사용하면 조사원이 소프트웨어를 설치하지 않고 즉시 데이터 수집을 시작할 수 있습니다.

### 1. Webform URL 접근
제어판의 **양식 관리** 대시보드에서 대상 양식을 찾고 **Webform URL** 버튼을 클릭하여 보안 링크를 생성합니다.

### 2. 양식 입력
- 제공된 URL을 최신 웹 브라우저에서 엽니다.
- 양식에 인증이 필요한 경우 조사원은 자격 증명으로 로그인해야 합니다. "공개 가시성"으로 설정된 경우 직접 진행할 수 있습니다.
- 설문 질문을 작성합니다. 인터페이스는 자동으로 로직, 건너뛰기 패턴 및 유효성 검사 규칙을 적용합니다.
- **미디어 캡처:** 양식에 이미지, 오디오 또는 비디오 질문이 포함된 경우 웹 브라우저는 컴퓨터에서 파일을 업로드하거나 사용 가능한 경우 기기의 웹캠/마이크를 사용하도록 요청합니다.

### 3. 제출
마지막 페이지에 도달하면 **제출**을 클릭합니다. 브라우저는 제출을 마무리하기 위해 활성 인터넷 연결이 필요합니다. 성공하면 데이터가 **제출 관리** 인터페이스에 즉시 반영됩니다.

## 방법 2: 모바일 앱을 통한 데이터 수집 (오프라인)

강력한 현장 데이터 수집을 위해 모바일 애플리케이션은 완전한 오프라인 기능을 제공합니다.

### 1. 설치 및 인증
- Google Play 스토어 또는 Apple App Store에서 **rtWork** (또는 **rtSurvey**) 애플리케이션을 다운로드합니다.
- 앱을 열고 할당된 조사원 자격 증명으로 로그인합니다.

### 2. 양식 다운로드 (인터넷 필요)
- 앱의 **양식** 또는 **작업** 섹션으로 이동합니다.
- **동기화** 또는 **다운로드** 아이콘을 탭하여 서버에서 최신 설문지 설계를 가져옵니다. 다운로드되면 양식은 기기에 로컬로 저장됩니다.

### 3. 데이터 수집 (오프라인)
- 다운로드된 양식을 열고 인터뷰를 시작합니다.
- 완전히 오프라인으로 데이터를 안전하게 수집할 수 있습니다.
- **미디어 캡처:** 모바일 앱은 기기의 하드웨어와 기본적으로 통합됩니다. 인터넷 연결 없이도 앱 내에서 직접 사진 찍기, 오디오 녹음, 비디오 녹화, 정밀한 GPS 좌표 기록이 가능합니다.
- 인터뷰를 완료하면 레코드를 완료합니다. 완료된 레코드는 앱의 발신함에 안전하게 대기합니다.

### 4. 제출 동기화 (인터넷 필요)
- 조사원이 인터넷 접속이 가능한 지역 (Wi-Fi 또는 셀룰러 데이터)으로 돌아오면 **발신함** 또는 **동기화** 인터페이스로 이동해야 합니다.
- 앱에 완료된 양식을 전송하도록 지시합니다. 앱은 대기 중인 레코드와 모든 첨부 미디어 파일을 서버로 안전하게 전송하며, 그 후 데이터 그리드에서 검토를 위해 표시됩니다.

XLSForm 및 rtSurvey의 barcode 질문 유형은 사용자가 설문 내에서 직접 바코드 데이터를 스캔하고 캡처할 수 있게 합니다. 이 기능은 재고 관리, 제품 추적 또는 코드화된 정보의 빠르고 정확한 데이터 입력이 필요한 시나리오에 특히 유용합니다.

## 기본 XLSForm 사양

| type    | name          | label                   |
|---------|---------------|-------------------------|
| barcode | product_code  | 제품 바코드를 스캔하세요 |

## 사용 사례

바코드 질문은 일반적으로 다음 용도로 사용됩니다:

1. 재고 설문에서 제품 식별
2. 현장 작업에서 자산 추적
3. 행사에서 티켓 또는 ID 확인
4. 코드화된 정보의 빠른 데이터 입력

## rtSurvey 확장

rtSurvey는 바코드 질문에 대한 추가 기능을 제공합니다:

1. 여러 바코드 형식 지원 (예: QR 코드, UPC, EAN)
2. 바코드 스캔을 위한 기기 카메라와 통합
3. 바코드가 손상되거나 스캔할 수 없는 경우 수동 입력 옵션

## 모범 사례

1. 정확한 바코드 스캔을 위해 적절한 조명 조건을 확보합니다.
2. 스캔을 위해 기기를 어떻게 위치시키는지에 대한 명확한 지침을 사용자에게 제공합니다.
3. 스캔 어려움에 대한 대안으로 수동 입력 옵션을 포함합니다.
4. 설문을 배포하기 전에 다양한 기기와 바코드 유형으로 바코드 스캔 기능을 테스트합니다.

## 제한 사항

- 바코드 스캔 정확도는 기기의 카메라 품질 및 환경 조건에 따라 달라질 수 있습니다.
- 일부 구형 또는 저사양 기기는 바코드 스캔을 지원하지 않을 수 있습니다.
- 특정 바코드 유형은 구현에 따라 지원되지 않을 수 있습니다.

## 예시 사용

다음은 재고 설문에서 바코드 질문을 사용하는 방법의 예시입니다:

| type    | name          | label                   | hint                                      |
|---------|---------------|-------------------------|-------------------------------------------|
| barcode | product_code  | 제품 바코드를 스캔하세요 | 바코드를 프레임 안에 배치하세요             |
| integer | quantity      | 제품 수량을 입력하세요  |                                           |
| note    | confirmation  | 스캔된 제품: ${product_code}. 수량: ${quantity} |           |

XLSForm 및 rtSurvey의 geotrace 질문 유형은 응답자가 지도에서 연결된 일련의 점을 캡처하여 선 또는 경로를 만들 수 있게 합니다. 이 기능은 공간 설문에서 경로, 경계 또는 선형 특징을 매핑할 때 특히 유용합니다.

## 기본 XLSForm 사양

| type     | name        | label                           |
|----------|-------------|--------------------------------|
| geotrace | river_path  | 강의 경로를 추적하세요     |

기본 geotrace 질문 유형에 대한 자세한 내용은 [XLSForm 사양](https://xlsform.org/en/#question-types)을 참조하세요.

## 용도

Geotrace 질문은 일반적으로 다음 용도로 사용됩니다:

1. 현장 조사 중 경로나 이동 경로 매핑
2. 도로, 강, 경계와 같은 선형 특징 추적
3. 선형 인프라의 범위 캡처 (예: 파이프라인, 전력선)
4. 교통 연구에서 이동 경로 기록
5. 생태 조사에서 구획 정의

## 모범 사례

1. 기기에서 위치 서비스가 활성화되어 있고 권한이 부여되어 있는지 확인합니다.
2. 경로를 추적하는 방법과 어떤 특징을 포함해야 하는지에 대한 명확한 지침을 제공합니다.
3. 응답자가 정확하게 경로를 추적할 수 있도록 위성 이미지 또는 기본 지도 사용을 고려합니다.
4. 추적의 잠재적 복잡성과 데이터 크기 및 처리에 미치는 영향에 주의합니다.

## 예시 사용

설문에서 geotrace 질문을 사용하는 방법의 예시입니다:

| type     | name           | label                                      | hint                                        |
|----------|----------------|--------------------------------------------|--------------------------------------------|
| geotrace | hiking_trail   | 등산로의 경로를 추적하세요         | 등산로 입구에서 시작하여 정상에서 끝내세요 |

## rtSurvey 확장

geotrace 질문에 대한 기본 XLSForm 사양은 간단하지만, rtSurvey는 추가 기능이나 사용자 정의를 제공할 수 있습니다:

1. 원격 지역을 위한 오프라인 지도 통합
2. 추적의 최소 및 최대 점 수 설정 옵션
3. 초기 그리기 후 추적을 편집하거나 수정하는 기능
4. 이동 중 설정 간격으로 자동 추적 지원

## 데이터 형식

Geotrace 데이터는 일반적으로 세미콜론으로 구분된 좌표 쌍 문자열로 저장됩니다 (geoshape와 비슷하지만 종료 점이 없음):

```
lat1 lon1; lat2 lon2; lat3 lon3; ... latN lonN
```

예시:
```
38.253094215699576 21.756382658677467; 38.25021274773806 21.756382658677467; 38.25007793942195 21.763892843919166; 38.25290886154963 21.763935759263404
```

## 분석을 위한 고려 사항

geotrace 질문을 사용할 때는 다음을 고려합니다:

1. 지리 데이터를 시각화하고 분석하는 방법 (예: GIS 소프트웨어)
2. 복잡한 추적의 데이터 정리 또는 단순화의 잠재적 필요성
3. 상세한 공간 데이터 처리를 위한 개인 정보 보호 및 데이터 보호 조치
4. 포괄적인 분석을 위한 다른 공간 데이터 소스와의 통합

## 제한 사항

- 작은 모바일 화면에서 정확한 경로를 추적하는 것은 어려울 수 있습니다.
- 복잡한 추적은 상당한 저장 및 처리 용량이 필요할 수 있습니다.
- 자동 추적을 위한 지속적인 GPS 사용은 기기 배터리를 빠르게 소모할 수 있습니다.
- 상세한 경로 데이터 수집과 관련된 개인 정보 보호 우려가 있을 수 있습니다.

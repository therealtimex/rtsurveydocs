rtSurvey는 어디서든 필요한 데이터를 수집할 수 있는 강력한 양식과 워크플로를 구축할 수 있게 해줍니다. 다음과 같은 작업을 수행할 수 있습니다:

1.  사진, GPS 위치, 건너뛰기 논리, 계산, 외부 데이터셋, 다국어 지원 등을 포함하는 강력한 양식을 구축합니다.
2.  모바일 앱 또는 웹 앱을 통해 오프라인에서 데이터를 수집합니다.
    인터넷 연결이 감지되면 양식과 제출 데이터가 동기화됩니다.
3.  데이터를 CSV로 다운로드하거나, rtSurvey를 Excel, Power BI, Python 또는 R에 연결하여 실시간 업데이트 대시보드를 만들어 손쉽게 분석합니다.

연구자, 현장 팀 및 다양한 전문가들이 rtSurvey를 사용하여 중요한 데이터를 수집합니다. 다음은 시작하는 방법입니다.

## 1. rtSurvey Cloud 이용하기 {#getting-started-rtCloud}

rtSurvey Cloud를 이용하는 가장 빠르고 간단한 방법은 공식 관리형 호스팅 서비스인 [rtSurvey Cloud](https://rtSurvey.com/#rtSurvey-cloud)를 사용하는 것입니다. rtSurvey 웹사이트에서 이용 가능하며 빠르고 안정적이며 안전한 인프라를 기반으로 합니다.

## 2. XLSForm을 rtCloud에 업로드하거나 양식 빌더(베타)로 양식 만들기 {#getting-started-create-form}

1.  `XLSForm`을 사용하여 양식 정의를 만들거나 이 [모든 위젯 양식](https://docs.google.com/spreadsheets/d/1af_Sl8A_L8_EULbhRLHVl8OclCfco09Hq2tqb9CslwQ/edit#gid=0)을 사용해 보세요.
2.  XLSForm을 rtCloud에 업로드하고 게시합니다.

## 3. rtSurvey 앱 다운로드 {#getting-started-get-collect}

rtSurvey 앱을 다운로드하려면 기기에 따라 다음 단계를 따르세요:

### Android 기기의 경우:
1. [Google Play 스토어](https://play.google.com/store/apps/details?id=vn.rta.rtsurvey)를 방문합니다.
2. 검색창에서 "rtSurvey"를 검색합니다.
3. rtSurvey 로고가 있는 앱을 탭합니다.
4. "설치" 버튼을 클릭하여 Android 기기에 앱을 다운로드하고 설치합니다.

### iOS 기기의 경우:
1. iOS 기기에서 [App Store](https://apps.apple.com/vn/app/rtsurvey/id1178851547)를 엽니다.
2. 검색 탭에서 "rtSurvey"를 검색합니다.
3. rtSurvey 로고가 있는 앱을 찾습니다.
4. "받기" 버튼을 탭하여 iOS 기기에 앱을 다운로드하고 설치합니다.

앱이 다운로드 및 설치되면 실행하여 설문 및 분석 서비스에 rtSurvey를 사용할 수 있습니다.

## 4. Collect를 rtCloud에 연결하기 {#getting-started-connect}

1.  rtCloud에서 앱 사용자를 생성하고 해당 사용자에게 양식을 할당합니다.
2.  Collect를 열고, `QR 코드로 구성`을 탭하여 앱 사용자를 위해 생성된 코드를 스캔합니다.

## 5. Collect에서 양식 작성하기 {#getting-started-fill-form}

1.  `빈 양식 작성`을 선택하여 양식을 작성합니다.
2.  양식 데이터는 작성을 완료하면 자동으로 rtCloud로 전송됩니다.

## 6. rtCloud에서 데이터 활용하기 {#getting-started-use-data}

1.  rtCloud에 로그인하여 데이터를 확인합니다.
2.  데이터를 CSV로 다운로드하거나 Power BI에서 시각화합니다.

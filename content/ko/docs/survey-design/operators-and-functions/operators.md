### 비교 연산자

{{< table >}}
연산자 | 연산      | 예시              | 예시 결과
-------- | -------------- | -------------------- | --------------
`=`        | 같음          | ${age} = 25     | true 또는 false
`!=`       | 같지 않음      | ${age} != 25    | true 또는 false
`>`        | 초과   | ${age} > 25     | true 또는 false
`>=`       | 이상 | ${age} >= 25 | true 또는 false
`<`        | 미만      | ${age} < 25     | true 또는 false
`<=`       | 이하 | ${age} <= 25  | true 또는 false
{{< /table >}}

위 예시에서 ${age}는 현재 필드의 값을 나타내고, 연산자는 이를 값 25와 비교하는 데 사용됩니다. 제약 조건은 비교가 충족되는지 여부에 따라 true 또는 false로 평가됩니다.

### 논리 연산자

논리 연산자는 제약 조건에서 여러 표현식을 결합하는 데 사용됩니다. 다음은 일반적으로 사용되는 논리 연산자와 그 연산 및 예시입니다:

연산자 | 연산      | 예시                                           
-------- | -------------- | --------------------------------------------------
`or`       | 두 표현식 중 하나가 true이면 true를 반환          | ${age} = 3 or ${age} = 4
`and`      | 두 표현식이 모두 true인 경우에만 true를 반환    | ${age} > 3 and ${age} < 5
`not()`    | 표현식이 true가 아니면 true를 반환        | not(${age} > 3 and ${age} < 5)

위 예시에서 ${age}는 현재 필드의 값을 나타내고, 논리 연산자는 표현식을 결합하는 데 사용됩니다. 제약 조건은 지정된 조건에 따라 true 또는 false로 평가됩니다.

예시 1:
{{< alert icon=" " context="info" text="`${age} = 3 or ${age} = 4`는 나이가 3 또는 4인 경우 `true`를 반환합니다." />}}

예시 2:
{{< alert icon=" " context="info" text="`${age} > 3 and ${age} < 5`는 나이가 3에서 5 사이인 경우 `true`를 반환합니다." />}}

예시 3:
{{< alert icon=" " context="info" text="`not(${age} > 3 and ${age} < 5)`는 나이가 3에서 5 사이가 아닌 경우 `true`를 반환합니다." />}}

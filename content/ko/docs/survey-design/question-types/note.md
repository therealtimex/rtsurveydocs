XLSForm 및 rtSurvey의 note 질문 유형은 설문 응답자에게 읽기 전용 텍스트 또는 미디어를 표시하는 데 사용됩니다. 답변이 필요한 질문이 아니라 설문 내에서 정보, 지침 또는 맥락을 제공하는 방법입니다.

## 기본 XLSForm 사양

| type | name | label |
|------|------|-------|
| note | info_text | 이 설문은 독서 습관에 관한 것입니다. |

기본 note 질문 유형에 대한 자세한 내용은 [XLSForm 사양](https://xlsform.org/en/#question-types)을 참조하세요.

## 용도

Note 질문은 일반적으로 다음 용도로 사용됩니다:

1. 이후 질문에 대한 지침 또는 맥락 제공
2. 계산된 결과 또는 요약 표시
3. 이미지 또는 기타 미디어 표시
4. 설문의 섹션 구분
5. 이전 응답을 기반으로 피드백 제공

## 모범 사례

1. 응답자의 참여를 유지하기 위해 note 텍스트를 간결하고 명확하게 유지합니다.
2. 중요한 정보를 강조하기 위해 형식 (굵게, 기울임)을 사용합니다.
3. 적절한 경우 이해를 높이기 위해 미디어 (이미지, 오디오) 사용을 고려합니다.
4. 설문을 복잡하게 만들지 않도록 note를 적절히 사용합니다.

## 예시 사용

설문에서 note 질문을 사용하는 방법의 예시입니다:

| type | name | label |
|------|------|-------|
| note | intro | 독서 습관 설문에 오신 것을 환영합니다. 선호도와 독서 빈도에 대해 질문하겠습니다. |
| ... | ... | ... |
| calculate | books_per_month | ${fiction_books} + ${non_fiction_books} |
| note | reading_summary | 귀하는 한 달에 약 ${books_per_month}권의 책을 읽습니다. |

이 예시에서는 설문을 소개하고 계산된 결과의 요약을 제공하기 위해 note를 사용합니다.

## rtSurvey 확장

note 질문에 대한 기본 XLSForm 사양은 간단하지만, rtSurvey는 추가 기능이나 사용자 정의를 제공할 수 있습니다:

1. 리치 텍스트 형식
2. 임베디드 미디어 지원 (이미지, 오디오, 비디오)
3. 이전 응답을 기반으로 한 동적 콘텐츠
4. 사용자 정의 스타일 옵션

## 고급 사용

### 조건부 표시

관련성 표현식을 사용하여 조건부로 note를 표시할 수 있습니다:

| type | name | label | relevant |
|------|------|-------|----------|
| note | high_reader_note | 귀하는 독서를 많이 하는 분이군요! | ${books_per_month} > 5 |

### 계산 포함

Note는 동적 피드백을 제공하기 위해 계산을 포함할 수 있습니다:

| type | name | label |
|------|------|-------|
| note | reading_time | 귀하의 응답을 바탕으로, 한 달에 약 ${books_per_month * 5}시간을 독서에 보냅니다. |

## 제한 사항

- Note는 데이터를 수집하지 않으므로 응답자로부터 정보를 수집해야 할 때는 사용하지 않아야 합니다.
- Note를 과도하게 사용하면 설문이 복잡하거나 지나치게 길어 보일 수 있습니다.
- 일부 고급 형식이나 미디어 옵션은 모든 기기나 플랫폼에서 지원되지 않을 수 있습니다.

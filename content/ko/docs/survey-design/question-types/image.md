XLSForm 및 rtSurvey의 image 질문 유형은 응답자가 설문 응답의 일부로 사진을 캡처하고 제출할 수 있게 합니다. 이 기능은 시각적 데이터를 수집하거나, 관찰을 문서화하거나, 현장 설문에서 증거를 제공할 때 특히 유용합니다.

## 기본 XLSForm 사양

| type  | name        | label                           |
|-------|-------------|--------------------------------|
| image | photo       | 위치 사진을 찍으세요    |

기본 image 질문 유형에 대한 자세한 내용은 [XLSForm 사양](https://xlsform.org/en/#question-types)을 참조하세요.

## 용도

Image 질문은 일반적으로 다음 용도로 사용됩니다:

1. 현장 조건 또는 관찰 문서화
2. 연구 연구에서 시각적 증거 캡처
3. 영향 평가에서 전후 사진 수집
4. 작업 완료 또는 위치에서의 존재 확인
5. 원격 분석을 위한 시각적 데이터 수집

## 모범 사례

1. 무엇을 사진으로 찍어야 하는지에 대한 명확한 지침을 제공합니다.
2. 개인 정보 보호 문제를 고려하고 응답자에게 사진이 어떻게 사용될지 알립니다.
3. 특히 인터넷 연결이 제한된 지역에서 설문을 수행하는 경우 파일 크기와 저장 제한에 주의합니다.
4. 기기에 충분한 저장 공간이 있고 카메라 권한이 부여되어 있는지 확인합니다.

## 예시 사용

설문에서 image 질문을 사용하는 방법의 예시입니다:

| type  | name           | label                                      | hint                                        |
|-------|----------------|--------------------------------------------|--------------------------------------------|
| image | storefront     | 매장 입구 사진을 찍으세요       | 매장 이름이 선명하게 보이도록 하세요    |

## rtSurvey 확장

image 질문에 대한 기본 XLSForm 사양은 간단하지만, rtSurvey는 추가 기능이나 사용자 정의를 제공할 수 있습니다:

1. 이미지 품질 설정 (예: 낮은, 중간, 높은 해상도)
2. 이미지에 캡션 또는 태그를 추가하는 옵션
3. 단일 질문에 대해 여러 이미지 캡처
4. 기기의 기본 카메라 앱 또는 갤러리와 통합

## 데이터 처리

이 질문 유형을 통해 수집된 이미지는 일반적으로 다음과 같이 처리됩니다:

1. 일반적인 이미지 형식으로 저장됨 (예: JPG, PNG)
2. 다른 설문 데이터와 함께, 종종 별도의 미디어 폴더에 저장됨
3. 설문 관리 플랫폼을 통해 보기 및 분석에 액세스 가능

## 분석을 위한 고려 사항

image 질문을 사용할 때는 다음을 고려합니다:

1. 이미지를 분석하는 방법 (예: 수동 검토, 자동 이미지 분석)
2. 이미지 파일에 필요한 추가 저장 공간
3. 사진 저장 및 처리를 위한 개인 정보 보호 및 데이터 보호 조치
4. 분석 단계에서 이미지 편집 또는 정리 도구의 잠재적 필요성

## 제한 사항

- 이미지 파일은 클 수 있어 데이터 전송 및 저장에 영향을 줄 수 있습니다.
- 모든 기기가 고품질 카메라나 충분한 저장 공간을 갖추고 있지 않을 수 있습니다.
- 많은 수의 이미지를 분석하는 것은 시간이 많이 걸릴 수 있습니다.
- 특히 공공장소에서 이미지를 캡처할 때 개인 정보 보호 우려가 있을 수 있습니다.

## rtSurvey 이미지 확장

### watermark()

`watermark()` appearance는 이 필드로 캡처된 사진에 텍스트 워터마크를 오버레이합니다. 워터마크에는 일반적으로 조사원 이름, 날짜/시간 또는 GPS 좌표와 같은 메타데이터가 포함되며, 이미지가 저장되기 전에 이미지에 직접 스탬프됩니다.

| type | name | label | appearance |
|------|------|-------|------------|
| image | site_photo | 현장 사진을 찍으세요 | `watermark("${enumerator_id} ${today()}")` |

`watermark()`의 인수는 캡처 시 평가되는 XPath 표현식입니다. 결과 문자열이 워터마크 텍스트로 렌더링됩니다.

### editable

`editable` appearance는 응답자가 사진을 찍은 후 캡처된 사진에 주석을 달거나 그림을 그릴 수 있게 합니다. 이미지 위에 그리기 도구 모음이 표시됩니다.

| type | name | label | appearance |
|------|------|-------|------------|
| image | annotated_photo | 사진을 찍고 우려 사항 영역을 표시하세요 | editable |

{{% alert icon=" " context="info" %}}
`editable`은 `watermark()`와 결합할 수 있습니다: `appearance: editable watermark("${id}")`
{{% /alert %}}

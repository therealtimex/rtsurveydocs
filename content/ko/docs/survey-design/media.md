rtSurvey는 설문에서 풍부한 미디어 통합을 지원하여 이미지, 오디오, 비디오로 설문지를 향상시킬 수 있습니다. 이 기능은 응답자 경험과 수집된 데이터의 품질을 크게 향상시킬 수 있습니다.

## 지원되는 미디어 유형

rtSurvey는 다음 미디어 유형을 지원합니다:
- 이미지 (jpg, png, gif)
- 오디오 (mp3, wav)
- 비디오 (mp4, webm)

## 설문에 미디어 추가

rtSurvey 양식에 미디어를 포함하려면 XLSForm의 다음 열을 사용합니다:

- `image`: 이미지 표시
- `audio`: 오디오 파일 재생
- `video`: 비디오 파일 재생

예시:

```
| type | name          | label         | image        | audio       | video       |
|------|---------------|---------------|--------------|-------------|-------------|
| note | media_example | 미디어 예시   | example.jpg  | sound.mp3   | clip.mp4    |
```

## 미디어 파일 관리

### 웹 기반 설문
웹 기반 설문의 경우 rtSurvey는 미디어 파일을 업로드하고 구성할 수 있는 미디어 관리 인터페이스를 제공합니다. 이러한 파일은 설문에서 사용할 수 있도록 자동으로 제공됩니다.

### 모바일 앱
rtSurvey 모바일 앱을 사용할 때:
1. 미디어 파일을 기기의 `/rtSurvey/forms/[form-name]-media/` 폴더에 넣습니다.
2. XLSForm에서 정확한 파일명을 참조합니다.

## rtSurvey 특화 기능

### 동적 미디어 로딩
rtSurvey는 설문 응답을 기반으로 한 동적 미디어 로딩을 지원합니다:

```
| type         | name      | label              | image                    |
|--------------|-----------|--------------------|--------------------------| 
| select_one species | animal | 동물 선택 | ${animal}.jpg            |
```

### 선택지 옵션의 미디어
rtSurvey는 선택 질문의 선택지 옵션에서 미디어를 사용할 수 있게 합니다:

```
| type                | name    | label           | media::image |
|---------------------|---------|-----------------|--------------|
| select_one_from_file animals | 동물 선택 |              |
```

choices 시트에서:
```
| list_name | name  | label | media::image |
|-----------|-------|-------|--------------|
| animals   | dog   | 개    | dog.jpg      |
| animals   | cat   | 고양이| cat.jpg      |
```

### 미디어 캡처
rtSurvey는 미디어 캡처 기능으로 XLSForm을 확장합니다:

```
| type  | name        | label               |
|-------|-------------|---------------------|
| image | photo       | 사진 찍기           |
| audio | voice_note  | 음성 메모 녹음      |
| video | video_clip  | 비디오 녹화         |
```

## 미디어 사용 모범 사례

1. **파일 크기 최적화**: 대용량 미디어 파일은 설문 로딩 및 제출 속도를 늦출 수 있습니다.
2. **적절한 형식 사용**: 널리 지원되는 형식 사용 (이미지의 경우 jpg, 오디오의 경우 mp3, 비디오의 경우 mp4).
3. **대안 제공**: 접근성을 위해 항상 텍스트 대안을 포함합니다.
4. **철저히 테스트**: 모든 대상 기기에서 미디어가 올바르게 표시되는지 확인합니다.
5. **오프라인 사용 고려**: 오프라인으로 수행될 수 있는 설문의 경우 모든 미디어가 로컬에서 사용 가능한지 확인합니다.

## 다국어 미디어 지원

rtSurvey는 언어별 미디어를 지원합니다. `::language` 접미사를 사용합니다:

```
| type | name  | label    | image::English | image::Spanish |
|------|-------|----------|----------------|----------------|
| note | intro | 환영합니다| welcome_en.jpg | welcome_es.jpg |
```

## 데이터 내보내기의 미디어

rtSurvey에서 데이터를 내보낼 때:
- 웹 설문의 경우 미디어 URL이 내보내기에 포함됩니다.
- 모바일 앱 설문의 경우 파일 경로가 포함됩니다.

## 모바일 앱 고려 사항

- 미디어가 많은 설문의 경우 기기에 충분한 저장 공간이 있는지 확인합니다.
- rtSurvey 모바일 앱은 오프라인 미디어 재생 및 캡처를 지원합니다.
- 대용량 미디어 파일은 저사양 기기의 앱 성능에 영향을 줄 수 있습니다.

## 알려진 제한 사항

- 일부 구형 브라우저는 모든 미디어 형식을 지원하지 않을 수 있습니다.
- 대용량 비디오 파일은 저대역폭 상황에서 문제를 일으킬 수 있습니다.

## 미디어 문제 해결

1. **미디어가 표시되지 않음**: 파일 경로와 이름이 정확한지 확인합니다.
2. **재생 문제**: 미디어 형식이 대상 기기에서 지원되는지 확인합니다.
3. **느린 로딩**: 파일 크기 최적화 또는 미디어 사전 로딩을 고려합니다.

## 고급 미디어 기능

### 지오태깅
rtSurvey는 설문 중 캡처된 미디어에 자동으로 지오태그를 추가할 수 있습니다:

```
| type  | name        | label        | appearance |
|-------|-------------|--------------|------------|
| image | photo       | 사진 찍기    | geotag     |
```

### 미디어 주석
응답자가 이미지에 주석을 달 수 있게 합니다:

```
| type  | name        | label        | appearance |
|-------|-------------|--------------|------------|
| image | photo       | 이미지에 주석 달기 | annotate |
```

rtSurvey 양식에서 미디어를 효과적으로 사용하면 더 매력적이고 정보가 풍부하며 정확한 설문을 만들 수 있습니다. 특히 인터넷 연결이 제한적이거나 저사양 기기의 지역에서 배포되는 설문의 경우 미디어 포함의 이점과 성능 고려 사항을 균형 있게 맞추는 것을 기억하세요.

rtSurvey는 데이터를 효율적으로 수집하기 위한 양식과 워크플로를 구축할 수 있는 강력한 플랫폼입니다. rtSurvey를 사용하면 다음을 할 수 있습니다:

1. 사진, GPS 위치, 건너뛰기 논리, 계산, 외부 데이터셋, 다국어 지원 등을 포함하는 정교한 양식을 만듭니다.
2. 모바일 앱 또는 웹 인터페이스를 사용하여 데이터를 수집하며, 인터넷 연결 시 자동으로 동기화됩니다.
3. CSV 또는 Stata로 내보내거나, rtSurvey를 Excel, Power BI, Python 또는 R에 연결하여 동적인 실시간 업데이트 대시보드를 만들어 손쉽게 데이터를 분석합니다.

다양한 산업의 연구자, 현장 팀 및 전문가들이 중요한 데이터 수집을 위해 rtSurvey를 사용합니다. 다음은 시작하는 방법입니다:

## 1. rtSurvey Cloud 접속 {#getting-started-get-rtCloud}

시작하는 가장 빠른 방법은 공식 관리형 호스팅 서비스인 [rtSurvey Cloud](https://rtsurvey.com/#rtsurvey-cloud)를 사용하는 것입니다. rtSurvey 웹사이트를 통해 접속할 수 있으며 강력하고 안전한 인프라를 기반으로 합니다. 원하는 경우 자체 인프라에서 rtSurvey를 호스팅할 수도 있습니다.

## 2. 설문 양식 만들기 {#getting-started-create-form}

1. `XLSForm`을 사용하여 양식을 설계하거나 [모든 위젯 양식](https://docs.google.com/spreadsheets/d/1af_Sl8A_L8_EULbhRLHVl8OclCfco09Hq2tqb9CslwQ/edit#gid=0) 템플릿을 실험해 보세요.
2. XLSForm을 rtSurvey Cloud에 업로드하고 게시하거나, 시각적 설계 경험을 위해 양식 빌더(베타)를 사용하세요.

## 3. rtSurvey 앱 설치 {#getting-started-get-collect}

모바일 기기에서 rtSurvey 앱을 다운로드하세요:

### Android 기기의 경우:
1. [Google Play 스토어](https://play.google.com/store/apps/details?id=vn.rta.rtsurvey)를 방문합니다.
2. "rtSurvey"를 검색하고 rtSurvey 로고가 있는 앱을 탭합니다.
3. "설치"를 클릭하여 앱을 다운로드하고 설정합니다.

### iOS 기기의 경우:
1. 기기에서 [App Store](https://apps.apple.com/vn/app/rtsurvey/id1178851547)를 엽니다.
2. "rtSurvey"를 검색하고 rtSurvey 로고가 있는 앱을 찾습니다.
3. "받기"를 탭하여 앱을 다운로드하고 설치합니다.

## 4. rtSurvey 앱을 rtSurvey Cloud에 연결하기 {#getting-started-connect}

1. 계정 만들기:
   - rtSurvey Cloud 관리자가 조사원 계정을 만들 수 있습니다.
   - 또는 관리자가 조사원이 스스로 계정을 만들 수 있는 URL을 생성할 수 있습니다.
2. rtSurvey 앱을 열고 계정 자격 증명으로 로그인합니다.

## 5. 설문 진행 {#getting-started-fill-form}

1. 앱에서 "빈 양식 작성"을 선택하여 새 설문을 시작합니다.
2. 응답자 데이터로 양식을 작성합니다.
3. 완료 후, 인터넷 연결이 가능할 때 양식 데이터가 자동으로 rtSurvey Cloud와 동기화됩니다.

## 6. rtSurvey Cloud에서 데이터 분석 {#getting-started-use-data}

1. rtSurvey Cloud에 로그인하여 수집된 데이터에 접속합니다.
2. 추가 분석을 위해 CSV 또는 Stata 등 다양한 형식으로 데이터를 다운로드합니다.
3. 내장 분석 도구를 활용하거나 선호하는 데이터 분석 소프트웨어와 통합합니다.

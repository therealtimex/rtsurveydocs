Izteiksmes rtSurvey tiek rakstītas **XPath 1.0** apakškopā, paplašinātā ar JavaRosa/ODK funkcijām un pielāgotām rtSurvey funkcijām. Izteiksmes izmantojat kolonnās `calculate`, `constraint`, `relevant`, `required` un `default` jūsu XLSForm.

## Lauku vērtību atsauces

Izmantojiet `${fieldname}`, lai atsauktos uz cita lauka vērtību:

```
${age} > 18
```

Izmantojiet `.` (vienu punktu), lai atsauktos uz **pašreizējā lauka vērtību** — parasti izmanto `constraint` izteiksmēs:

```
. >= 0 and . <= 100
```

Izmantojiet `..`, lai atsauktos uz mātes grupu (uzlabots lietojums atkārtojumos).

## Izteiksmes sintakse

Izteiksmes ievēro standarta XPath noteikumus:

- **Virknes** jāieskauj ar vienpēdiņām: `'yes'`
- **Skaitļi** tiek rakstīti tieši: `42`, `3.14`
- **Boolean** rezultāti tiek izmantoti `relevant`, `required` un `constraint` — jebkura netuša, nenulla vērtība ir patiesa
- Atstarpēs ap operatoriem tiek ignorētas

<Warning>
Vienmēr izmantojiet taisnas pēdiņas (`'` vai `"`) — nekad "viedās pēdiņas" (liekās pēdiņas). Bagātā teksta redaktori bieži automātiski pārveido pēdiņas un sabojās izteiksmes.
</Warning>

## Ātrie piemēri

| Lietojuma gadījums | Izteiksme |
|----------|------------|
| Rādīt, ja vecums ir virs 18 | `${age} > 18` |
| Rādīt tikai, ja atlasīts "jā" | `${consent} = 'yes'` |
| Obligāts, ja cits lauks nav tukšs | `${name} != ''` |
| Aprēķināt kopējo | `${adults} + ${children}` |
| Savienot nosaukumu | `concat(${first_name}, ' ', ${last_name})` |
| Šodienas datums | `today()` |
| Pārbaudīt, vai iespēja atlasīta | `selected(${interests}, 'sports')` |

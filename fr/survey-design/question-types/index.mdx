rtSurvey prend en charge tous les types de questions XLSForm standard, ainsi que plusieurs extensions. Chaque type de question détermine le type de données collectées et la façon dont le widget de saisie est rendu sur l'appareil.

Pour définir le type de question, entrez le nom du type dans la colonne `type` de la feuille de calcul **survey** de votre XLSForm.

## Saisie de texte

| Type | Description |
|------|-------------|
| [text](text) | Réponse en texte libre — tout caractère est accepté |
| [integer](integer) | Nombre entier (sans décimales) |
| [decimal](decimal) | Nombre avec décimales |
| [range](range) | Nombre sélectionné via un curseur dans une plage min/max définie |

## Sélection

| Type | Description |
|------|-------------|
| [select_one listname](select-one) | Choisir exactement une option dans une liste |
| [select_multiple listname](select-multiple) | Choisir une ou plusieurs options dans une liste |
| [select_one_from_file filename](select-one-from-file) | Choisir une option chargée depuis un fichier CSV externe |
| [rank listname](rank) | Classer les choix par préférence ou priorité |

## Date et heure

| Type | Description |
|------|-------------|
| [date](date) | Date calendaire (année, mois, jour) |
| [time](time) | Heure du jour (heures, minutes) |
| [datetime](datetime-date-time) | Date et heure combinées |

## Localisation

| Type | Description |
|------|-------------|
| [geopoint](geopoint) | Coordonnée GPS unique (latitude, longitude, altitude, précision) |
| [geotrace](geotrace) | Un itinéraire — série de points GPS formant une ligne |
| [geoshape](geoshape) | Une zone — polygone fermé de points GPS |

## Médias

| Type | Description |
|------|-------------|
| [image](image) | Capture photo ou téléversement d'image |
| [audio](audio) | Enregistrement audio |
| [video](video) | Enregistrement vidéo |
| [file](file) | Téléversement de fichier général (PDF, document, etc.) |

## Autres

| Type | Description |
|------|-------------|
| [barcode](barcode) | Scanner un code-barres ou QR code |
| [note](note) | Texte d'affichage en lecture seule — affiche des instructions ou des résumés calculés |
| [calculate](calculate) | Champ masqué qui stocke une valeur calculée |
| [hidden](hidden) | Champ masqué qui stocke une valeur statique ou pré-remplie |
| [trigger / acknowledge](trigger) | Une case à cocher que l'enquêteur doit cocher pour confirmer avoir lu une déclaration |
| [meta](meta) | Métadonnées automatiques : horodatages, identifiant de l'appareil, informations sur l'enquêteur |

## Comment type et appearance fonctionnent ensemble

La colonne `type` détermine **quelles données sont collectées**. La colonne `appearance` contrôle **l'apparence du widget**. De nombreux types supportent plusieurs apparences — par exemple `select_one` peut s'afficher sous forme de boutons radio, d'une liste déroulante, d'une échelle de Likert ou d'une grille compacte.

Consultez [Appearance](../appearance) pour la liste complète des options.

Le type de question `geoshape` dans XLSForms et rtSurvey permet aux répondants de dessiner des formes (polygones) sur une carte, capturant ainsi des données géographiques complexes. Cette fonctionnalité est particulièrement utile pour cartographier des zones, définir des limites ou marquer des régions d'intérêt dans le cadre d'enquêtes spatiales.

## Spécification XLSForm de Base

| type     | name        | label                           |
|----------|-------------|--------------------------------|
| geoshape | field_area  | Dessiner la limite de la parcelle |

Pour plus de détails sur le type de question `geoshape` de base, consultez la [spécification XLSForm](https://xlsform.org/en/#question-types).

## Utilisations

Les questions `geoshape` sont couramment utilisées pour :

1. Cartographier les limites de parcelles dans les enquêtes agricoles
2. Définir des zones d'impact environnemental
3. Marquer des zones dans les études d'urbanisme
4. Délimiter des régions pour les prospections géologiques
5. Capturer des caractéristiques géographiques complexes pour l'analyse spatiale

## Meilleures Pratiques

1. Assurez-vous que l'appareil a activé les services de localisation et que les autorisations sont accordées.
2. Fournissez des instructions claires sur la manière de dessiner la forme et sur la zone à inclure.
3. Envisagez d'utiliser l'imagerie satellite ou des cartes de base pour aider les répondants à dessiner les formes avec précision.
4. Soyez conscient de la complexité potentielle des formes et de leur impact sur la taille et le traitement des données.

## Exemple d'Utilisation

Voici un exemple de la manière dont vous pourriez utiliser une question `geoshape` dans une enquête :

| type     | name           | label                                      | hint                                        |
|----------|----------------|--------------------------------------------|--------------------------------------------|
| geoshape | forest_area    | Délimiter le contour de la parcelle forestière | Utilisez au moins 3 points pour créer une forme fermée |

## Extensions rtSurvey

Bien que la spécification XLSForm de base pour les questions `geoshape` soit simple, rtSurvey peut proposer des fonctionnalités ou des personnalisations supplémentaires :

1. Intégration de cartes hors ligne pour les zones reculées
2. Options pour définir un nombre minimum et maximum de points pour la forme
3. Possibilité de modifier ou d'affiner les formes après le dessin initial
4. Prise en charge de différents types de formes (ex : rectangles, cercles) en plus des polygones de forme libre

(Note : Les extensions spécifiques disponibles dans rtSurvey pour les questions `geoshape` devront être confirmées et détaillées ici.)

## Format des Données

Les données `geoshape` sont généralement stockées sous forme d'une chaîne de paires de coordonnées séparées par des espaces, entre parenthèses :

```
(lat1 lon1; lat2 lon2; lat3 lon3; ... latN lonN)
```

Par exemple :
```
(38.253094215699576 21.756382658677467; 38.25021274773806 21.756382658677467; 38.25007793942195 21.763892843919166; 38.25290886154963 21.763935759263404; 38.253094215699576 21.756382658677467)
```

## Considérations pour l'Analyse

Lors de l'utilisation de questions `geoshape`, tenez compte de :

1. La manière dont les données géographiques seront visualisées et analysées (ex : logiciel SIG)
2. Le besoin potentiel de nettoyage ou de simplification des formes complexes
3. Les mesures de confidentialité et de protection des données pour la manipulation des données spatiales détaillées
4. L'intégration avec d'autres sources de données spatiales pour une analyse complète

## Limitations

- Dessiner des formes précises sur de petits écrans mobiles peut être difficile.
- Les formes complexes peuvent nécessiter une capacité de stockage et de traitement importante.
- Les questions `geoshape` peuvent ne pas convenir à tous les types d'enquêtes ou de répondants.
- Des préoccupations en matière de confidentialité peuvent être associées à la collecte de données spatiales détaillées.

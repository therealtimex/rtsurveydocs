---

このページでは、rtSurveyでのリピートグループ（repeat groups）の高度な使用パターンについて説明します。リピートグループの設定の基本については、[グループ化とリピート](../repeats)を参照してください。

---

## 動的なリピートカウント

デフォルトでは、調査員がリピート回数を決定します。`repeat_count`を使用してリピート回数を固定することができます。

| type | name | label | repeat_count |
|------|------|-------|--------------|
| begin_repeat | household_members | 世帯員 | `${num_members}` |
| text | member_name | 氏名 | |
| integer | member_age | 年齢 | |
| end_repeat | | | |

リピートは正確に `${num_members}` 回実行されます。ここで、`num_members` はフォーム内で以前に収集された値です。調査員はインスタンスを追加または削除することはできません。

---

## インデックスによるアクセス: `indexed-repeat()`

リピートグループの**外側**から、`indexed-repeat(repeatedField, repeatGroup, index)` を使用して特定のリピートインスタンスのフィールド値にアクセスします。

| type | name | label | calculation |
|------|------|-------|-------------|
| calculate | first_name | | `indexed-repeat(${member_name}, ${household_members}, 1)` |
| calculate | second_name | | `indexed-repeat(${member_name}, ${household_members}, 2)` |

これは、サマリーフィールドの作成や、リピート終了後に「主要な」メンバーのデータを参照する場合に便利です。

---

## 現在のインスタンスの位置: `index()`

リピートグループ内では、`index()` は現在のインスタンスの1から始まる位置を返します。各リピートにラベルを付けたり、一意の識別子を作成したりするために使用します。

| type | name | label |
|------|------|-------|
| begin_repeat | plots | 区画 |
| note | plot_label | 区画番号 `${index()}` |
| text | plot_id | 区画ID |
| end_repeat | | |

---

## 同一インスタンス内のフィールドの参照

リピート内では、`${fieldname}` を使用して**同じリピートインスタンス内**の別のフィールドを参照します。同じループ内では `indexed-repeat()` を使用する必要はありません。

| type | name | label | relevant |
|------|------|-------|----------|
| begin_repeat | members | メンバー | |
| text | member_name | 名前 | |
| integer | member_age | 年齢 | |
| text | school_name | 学校名 | `${member_age} < 18` |
| end_repeat | | | |

---

## リピート内からの親フィールドの参照

リピートグループの外側（上側）にあるフィールドは、通常通り `${fieldname}` で参照できます。

| type | name | label |
|------|------|-------|
| text | village | 村の名前 |
| begin_repeat | plots | 農区画 |
| note | plot_context | `${village}` 内の区画 |
| end_repeat | | |

---

## リピートデータの集計

リピートグループの**外側**でリピート集計関数を使用して集計を行います。

| 関数 | 例 | 説明 |
|----------|---------|-------------|
| `count(group)` | `count(${household_members})` | インスタンス数 |
| `sum(field)` | `sum(${loan_amount})` | 数値フィールドの合計 |
| `min(field)` | `min(${member_age})` | 最小値 |
| `max(field)` | `max(${member_age})` | 最大値 |
| `join(sep, field)` | `join(', ', ${member_name})` | カンマ区切りのリスト |
| `count-if(group, expr)` | `count-if(${members}, ${member_age} < 18)` | 条件付きカウント |
| `sum-if(field, expr)` | `sum-if(${loan_amount}, ${loan_amount} > 500)` | 条件付き合計 |
| `join-if(sep, field, expr)` | `join-if(', ', ${name}, ${age} >= 18)` | 条件付き結合 |

### 例：世帯サマリー

| type | name | label | calculation |
|------|------|-------|-------------|
| integer | num_members | 何人家族ですか？ | |
| begin_repeat | members | メンバー | `${num_members}` |
| text | member_name | 名前 | |
| integer | member_age | 年齢 | |
| end_repeat | | | |
| calculate | total_members | | `count(${members})` |
| calculate | children_count | | `count-if(${members}, ${member_age} < 18)` |
| calculate | adult_names | | `join-if(', ', ${member_name}, ${member_age} >= 18)` |
| note | summary | `${total_members}` 人のメンバー。`${children_count}` 人が18歳未満。成人： `${adult_names}` | |

## ネストされたリピート

リピートグループの中に別のリピートグループを含めることができます。ネストされたリピートは複雑さを増し、調査員を混乱させる可能性があるため、注意して使用してください。

| type | name | label |
|------|------|-------|
| begin_repeat | households | 世帯 |
| text | hh_id | 世帯ID |
| begin_repeat | hh_members | メンバー |
| text | member_name | メンバー名 |
| end_repeat | | |
| end_repeat | | |

内側のリピートから外側のリピートのフィールドを参照するには、`${fieldname}` を使用します。これは、最も近い一致する祖先を参照します。

`hh_members` リピート内では、`${hh_id}` はすべての世帯ではなく、**現在の**世帯のIDを返します。

---

## リピートグループ内の順位: `rank-index()`

リピート内に `rank` フィールドが存在する場合、外側から `rank-index(instanceNumber, repeatedField)` を使用して、特定のインスタンスの順位を取得します。

| type | name | label | calculation |
|------|------|-------|-------------|
| calculate | top_scorer | | `rank-index(1, ${score})` |

`rank-index(1, ${score})` は、最高スコアのインスタンスインデックスを返します。

---

## `begin_repeat` での `1screen` 外観

`begin_repeat` 行の `appearance` 列に `1screen` を追加すると、各インスタンスのすべての質問が、画面ごとに1つの質問ではなく、1つの画面にまとめて表示されます。

| type | name | label | appearance |
|------|------|-------|------------|
| begin_repeat | household_members | 世帯員 | `1screen` |
| text | member_name | 氏名 | |
| integer | member_age | 年齢 | |
| end_repeat | | | |

`1screen` が設定されており、グループ内に `repeat_count` も `add_repeat` フィールドもない場合、rtSurveyは画面の下部に丸い **+** ボタンを自動的にレンダリングします。これにより、調査員は追加の設定なしで新しいインスタンスを追加できます。

| 外観 | インスタンスごとに1画面 | デフォルトの + ボタン追加 |
|------------|-------------------------|------------------------|
| `1screen` | はい | はい (`add_repeat` 子フィールドがない場合) |
| `field-list` | はい | いいえ |

自動追加ボタンなしでグループ化されたレイアウトが必要な場合は `field-list` を使用します。グループ化されたレイアウトとインスタンスを追加するための組み込み方法の両方が必要な場合は `1screen` を使用します。

---

## `add_repeat` カスタム追加ボタン

リピートグループの**内側**に `appearance: add_repeat` を指定した `note` (または `text`) フィールドを配置すると、全幅の「追加」ボタンとしてレンダリングされます。ボタンのラベルはフィールドの `label` 列から取得されます。`add_repeat` フィールドが存在する場合、(`1screen` による) デフォルトの丸い + ボタンは表示されません。

`add_repeat` フィールドはリピートグループ内の最後のフィールドとして配置してください。

| type | name | label | appearance |
|------|------|-------|------------|
| begin_repeat | members | メンバー | `1screen` |
| text | member_name | 氏名 | |
| integer | member_age | 年齢 | |
| note | btn_add | + メンバーを追加 | `add_repeat` |
| end_repeat | | | |

### 色のカスタマイズ

外観の値の中にカラーコードを指定して、ボタンのスタイルを設定できます。

| 外観の値 | 結果 |
|------------------|--------|
| `add_repeat <#04B404/>` | 緑色の背景、デフォルトのテキスト色 |
| `add_repeat 04B404-ffffff` | 緑色の背景、白色のテキスト |

最初の色は背景色で、2番目の色（ハイフンの後）はテキスト色です。ハイフンで区切られた形式を使用する場合は、`#` を省略してください。

### アイコンバリアント

全幅ボタンの代わりにコンパクトな丸いアイコンボタンをレンダリングするには、`add_repeat icon` (スペースあり) を使用します。

| type | name | label | appearance |
|------|------|-------|------------|
| note | btn_add | + 追加 | `add_repeat icon` |

---

## 削除ボタン: `delete-repeat-current` および `delete-repeat-last`

リピートグループ内の `appearance: delete-repeat-current` または `appearance: delete-repeat-last` を指定した `note` フィールドは、分割された削除ボタンとしてレンダリングされます。

| 外観 | アクション |
|------------|--------|
| `delete-repeat-current` | 現在の（アクティブな）インスタンスを削除 |
| `delete-repeat-last` | リピート内の最後のインスタンスを削除 |

デフォルト（アイコンなし）のボタンは分割ボタンです。左側にゴミ箱アイコン、右側にフィールドのラベルテキストが表示され、画面の全幅に広がります。

### アイコンバリアント

`-icon` を追加すると、コンパクトな丸いゴミ箱アイコンボタンが表示されます。

| 外観 | 結果 |
|------------|--------|
| `delete-repeat-current-icon` | 丸いゴミ箱アイコン、現在のインスタンスを削除 |
| `delete-repeat-last-icon` | 丸いゴミ箱アイコン、最後のインスタンスを削除 |

### 色のカスタマイズ

色の形式は `add_repeat` と同じです。`<#RRGGBB/>` または `RRGGBB-RRGGBB` (背景色-テキスト色) を使用してください。

### 完全なパターン例

以下のリピートは、`1screen`、上部に丸い現在のインスタンス削除ボタン、下部に全幅の追加ボタンを使用しています。

| type | name | label | appearance |
|------|------|-------|------------|
| begin_repeat | members | メンバー | `1screen` |
| note | btn_del | 削除 | `delete-repeat-current-icon` |
| text | member_name | 氏名 | |
| integer | member_age | 年齢 | |
| note | btn_add | + メンバーを追加 | `add_repeat` |
| end_repeat | | | |

## ベストプラクティス

1. リピート回数が事前にわかっている場合は、常に `repeat_count` を使用してください。これにより、調査員が誤ってインスタンスを追加または削除するのを防ぐことができます。
2. リピートグループは焦点を絞ったものにしてください。1インスタンスあたり20以上の質問があるリピートは操作が困難です。
3. リピートグループには分かりやすい名前を付けてください（例： `repeat1` ではなく `household_members`）。この名前は関数呼び出しやエクスポートされたデータに表示されます。
4. パフォーマンスを検証するために、予想される最大インスタンス数でテストしてください。
5. インスタンスごとにすべての質問を1つの画面に表示するには `begin_repeat` で `1screen` を使用し、グループ内に `add_repeat` noteフィールドを組み合わせて、調査員に明確なラベルが付いた「追加」ボタンを提供してください。

---

## 制限事項

- `indexed-repeat()` は有効なインデックス（1からインスタンス数まで）を必要とします。範囲外のインデックスは空を返します。
- 2レベルを超えるネストされたリピートは推奨されず、一部のクライアントで表示の問題が発生する可能性があります。
- 集計関数（`sum`, `count` など）はリピートグループ全体に対して動作します。`*-if` バリアントを使用せずにインスタンスのサブセットを集計することはできません。

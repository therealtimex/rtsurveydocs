音声録音機能を使用すると、調査の特定のセクションで音声をバックグラウンドまたは明示的にキャプチャできます。これは、インタビューの記録、フィールド観察中の環境音、または構造化された回答を補完する口頭での回答を記録するのに役立ちます。

## 仕組み

音声録音は、**マーカー**として機能する2つの`text`フィールドによって制御されます。

- `audio-start`アピアランスを持つフィールドは、調査員がそのフィールドに到達したときに録音を開始します。
- `audio-end`アピアランスを持つフィールドは、録音を停止し、音声ファイルを送信データに保存します。

どちらのマーカーフィールドも`text`タイプです。通常、これらは調査員からは非表示にされます（`relevant = false`を使用するか、非対話的な位置に配置します）が、表示させることも可能です。録音された音声は、`audio-end`フィールドに関連付けられたファイルとして送信データに添付されます。

---

## 基本的な例

| type | name | label | appearance |
|------|------|-------|------------|
| text | audio_s_a1 | | `audio-start` |
| text | q_name | 回答者氏名 | |
| text | q_occupation | 職業 | |
| integer | q_age | 年齢 | |
| text | audio_e_a1 | | `audio-end` |

アプリは調査員が`audio_s_a1`に到達したときに録音を開始し、`audio_e_a1`に到達したときに停止します。2つのマーカー間にあるすべての質問が録音されます。

---

## サイレント録音: `audio-start invisible`

デフォルトでは、モバイルアプリは音声のキャプチャ中に録音インジケーターを表示します。アピアランスに`invisible`を追加すると、このインジケーターが非表示になり、回答者に録音されていることを意識させずに録音を行うことができます。

| type | name | label | appearance |
|------|------|-------|------------|
| text | audio_s_a1 | | `audio-start invisible` |
| text | q_consent | 調査への参加に同意しますか？ | |
| text | q_feedback | フィードバック | |
| text | audio_e_a1 | | `audio-end` |

`invisible`を使用するのは、他の手段（録音セクションの前の別の書面による同意フィールドなど）を通じて開示要件が満たされている場合に限ってください。

## 命名規則

本番用のフォームでは、マーカーフィールドに対して一貫した命名パターンを使用します。

```
audio_s_{section}{n}   — 開始マーカー
audio_e_{section}{n}   — 終了マーカー
```

ここで、`{section}`はフォームセクションの短いラベル、`{n}`はそのセクション内の連番です。

| フィールド名 | 役割 | 意味 |
|------------|------|---------|
| `audio_s_a1` | 開始 | セクションAの最初の録音 |
| `audio_e_a1` | 終了 | セクションAの最初の録音の終了 |
| `audio_s_b1` | 開始 | セクションBの最初の録音 |
| `audio_e_b1` | 終了 | セクションBの最初の録音の終了 |
| `audio_s_a2` | 開始 | セクションAの2番目の録音 |
| `audio_e_a2` | 終了 | セクションAの2番目の録音の終了 |

この規則に従うことで、フォーム定義や送信データを確認する際に、録音の範囲を簡単に特定できるようになります。

## 保存と取得

調査員が`audio-end`フィールドに到達すると、アプリは音声ファイルを確定し、送信データに添付します。ファイルは：

- 送信データの音声添付ファイルとして保存され、`audio-end`フィールド名に関連付けられます。
- rtSurveyのバックエンド送信ビューアで、他のメディア添付ファイルと一緒にアクセスできます。
- 標準の送信データエクスポートを介してダウンロード可能です。音声ファイルは、`audio-end`フィールド名に対応するメディア列に表示されます。

ファイル形式とビットレートは、デバイスとアプリのバージョンによって異なります。

---

## 複数の録音セクション

フォームには、重複しない複数の録音セクションを含めることができます。各`audio-start` / `audio-end`マーカーのペアは完全に完結している必要があり、セクションを入れ子にすることはできません。

| type | name | label | appearance |
|------|------|-------|------------|
| text | audio_s_a1 | | `audio-start` |
| text | q_intro | はじめに | |
| text | audio_e_a1 | | `audio-end` |
| note | section_break | — | |
| text | audio_s_b1 | | `audio-start invisible` |
| text | q_detail | 詳細 | |
| text | audio_e_b1 | | `audio-end` |

各セクションは、それぞれの`audio-end`フィールドに添付される個別の音声ファイルを生成します。

---

## 制限事項

- **モバイルアプリ専用。** この機能はウェブフォームではサポートされていません。ブラウザでは`audio-start`および`audio-end`は無視されます。
- **入れ子不可。** 録音セクションを重複させることはできません。前の`audio-end`マーカーに到達する前に新しい録音を開始することはサポートされていません。
- **フィールドタイプは`text`である必要があります。** 他の質問タイプで`audio-start`または`audio-end`を使用することはサポートされていません。
- **アップロードサイズ。** 長時間の録音はファイルサイズが大きくなります。現場での送信サイズ制限やネットワーク状況に注意してください。
- **録音中の一時停止不可。** 録音は開始マーカーから終了マーカーまで継続的に実行されます。セクション内で一時停止して再開するメカニズムはありません。

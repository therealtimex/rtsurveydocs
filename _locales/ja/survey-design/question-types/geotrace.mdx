---

XLSFormおよびrtSurveyのgeotrace質問タイプは、回答者が地図上に一連の連続した点を記録し、線や経路を作成できます。この機能は、ルートのマッピング、境界の追跡、または空間調査での線形地物の記録に特に便利です。

## 基本XLSForm仕様

| type     | name        | label                           |
|----------|-------------|--------------------------------|
| geotrace | river_path  | 川の経路をなぞってください     |

基本的なgeotrace質問タイプの詳細については、[XLSForm仕様](https://xlsform.org/en/#question-types)を参照してください。

## 用途

Geotrace質問は一般的に以下に使用されます：

1. フィールド調査中のルートや経路のマッピング
2. 道路、川、境界などの線形地物の追跡
3. 線形インフラの範囲の記録（例：パイプライン、電線）
4. 輸送研究での移動経路の記録
5. 生態学的調査でのトランセクトの定義

## ベストプラクティス

1. デバイスの位置情報サービスが有効で権限が付与されていることを確認してください。
2. 経路の追跡方法と含めるべき地物について明確な指示を提供してください。
3. 回答者が正確に経路をなぞれるよう衛星画像やベースマップの使用を検討してください。
4. 追跡の潜在的な複雑さとデータサイズと処理への影響に注意してください。

## 使用例

調査でgeotrace質問を使用する例を示します：

| type     | name           | label                                      | hint                                        |
|----------|----------------|--------------------------------------------|--------------------------------------------|
| geotrace | hiking_trail   | ハイキングコースの経路をなぞってください         | 登山口から始めて山頂で終わってください |

## データ形式

Geotraceデータは通常、geoshapeに似たスペース区切りの座標ペアの文字列として保存されますが、閉じる点はありません：

```
lat1 lon1; lat2 lon2; lat3 lon3; ... latN lonN
```

例：
```
38.253094215699576 21.756382658677467; 38.25021274773806 21.756382658677467; 38.25007793942195 21.763892843919166; 38.25290886154963 21.763935759263404
```

## 分析上の考慮事項

Geotrace質問を使用する場合は以下を考慮してください：

1. 地理データをどのように視覚化・分析するか（例：GISソフトウェア）
2. 複雑な追跡のデータクリーニングや単純化の潜在的な必要性
3. 詳細な空間データを処理するためのプライバシーとデータ保護対策
4. 包括的な分析のための他の空間データソースとの統合

## 制限事項

- 小さなモバイル画面で正確な経路をなぞるのは難しい場合があります。
- 複雑な追跡は大きなストレージと処理能力を必要とする場合があります。
- 自動追跡のための連続的なGPS使用は、デバイスのバッテリーを急速に消費する可能性があります。
- 詳細な経路データの収集に関連するプライバシーの懸念がある場合があります。

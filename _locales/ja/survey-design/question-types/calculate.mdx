`calculate` 質問タイプは、バックグラウンドで数式を静かに実行します。結果を名前付きフィールドに保存し、他の質問から参照できるようにしますが、調査員には入力やラベルを表示しません。値の導出、文字列の結合、条件ロジックの実行、またはフォームの後半で必要になるデータの検索に使用します。

---

## 基本構文

| type | name | label | calculation |
|------|------|-------|-------------|
| calculate | total | | `${price} * ${quantity}` |

- **type**: 常に `calculate`。
- **name**: 一意のフィールド名。他の質問は `${name}` を使用してこれを参照します。
- **label**: 空白のままにします。calculate フィールドは調査員には表示されません。
- **calculation**: 評価する数式。すべての [XLSForm 関数](../operators-and-functions/functions)とフィールド参照をサポートします。

---

## 一般的なパターン

### 算術演算

| type | name | label | calculation |
|------|------|-------|-------------|
| integer | price | Unit price | |
| integer | quantity | Quantity | |
| calculate | total | | `${price} * ${quantity}` |
| note | total_note | Total: `${total}` | |

### 文字列の結合

| type | name | label | calculation |
|------|------|-------|-------------|
| text | first_name | First name | |
| text | last_name | Last name | |
| calculate | full_name | | `concat(${first_name}, ' ', ${last_name})` |

### 条件値

| type | name | label | calculation |
|------|------|-------|-------------|
| integer | score | Score (0–100) | |
| calculate | grade | | `if(${score} >= 90, 'A', if(${score} >= 75, 'B', if(${score} >= 60, 'C', 'F')))` |

### 生年月日から年齢を算出

| type | name | label | calculation |
|------|------|-------|-------------|
| date | dob | Date of birth | |
| calculate | age_years | | `int((today() - ${dob}) div 365.25)` |

---

## `once()` を使用して値をロックする

デフォルトでは、参照されているフィールドが変更されるたびに `calculate` が再評価されます。数式を `once()` で囲むと、最初の読み込み時にのみ評価され、結果が固定されます。

| type | name | label | calculation |
|------|------|-------|-------------|
| calculate | interview_start | | `once(now())` |

タイムスタンプ、初期値、または変更時の再計算が望ましくない場合に `once()` を使用します。

## 外部ソースからのデータのプル

### CSV ファイルから

```
pulldata('staff.csv', 'department', 'name', ${staff_id})
```

詳細は [pulldata()](../operators-and-functions/pulldata) を参照してください。

### 同梱の SQLite データベースから

```
pulldata('rawquery',
  concat(${family_path}, '/locations.db::provinces'),
  'SELECT name FROM provinces WHERE id = ?',
  ${province_id})
```

パス構築の詳細は [ローカルデータベース検索](../advanced-features/local-database-search) を参照してください。

### アプリコンテキストから

```
pulldata('app-api', 'user.username')
pulldata('app-api', 'family_path')
```

利用可能なすべてのキーについては [App API](../app-api) を参照してください。

## relevant および constraint での calculate の使用

他のフィールドは、通常のフィールドと同じように `calculate` の結果を参照できます。

| type | name | label | relevant | constraint |
|------|------|-------|----------|------------|
| calculate | bmi | | | `${weight} div (${height} * ${height}) * 10000` |
| note | bmi_warning | BMI is very high — please verify weight and height. | `${bmi} > 40` | |

## ベストプラクティス

1. calculate フィールドには意味のある名前を付けます。`calc1` よりも `total_cost` の方が明確で、エクスポートでの追跡も容易です。
2. 複雑な数式は、1 つの深くネストされた式にするのではなく、複数の連結された calculate フィールドに分割します。
3. 最初の取得後に値が変更されないように、タイムスタンプや初期スナップショットには `once()` を使用します。
4. `calculate` フィールドは、それを参照する最初の質問の前に配置します。評価順序はフォームの順序に従います。
5. `label` 列は空のままにします。一部のツールはラベルを表示するため、空白のままにすることで混乱を招く出力を避けることができます。

## 制限事項

- calculate フィールドは調査員に直接表示されることはありません。結果を表示するには `note` フィールドを使用してください。
- `calculation` 列は必須です。数式のない `calculate` 行は常に空の文字列を保存します。
- `once()` で囲まれていない限り、フォームが変更されるたびに結果が再評価されます。大規模なフォームで非常に複雑な数式を使用すると、低スペックのデバイスでレンダリングパフォーマンスに影響を与える可能性があります。
- 計算された値は、送信時に文字列として保存されます。算術式や論理式に結果を渡す場合は、`number()`、`int()`、または `boolean()` を使用して型をキャストしてください。

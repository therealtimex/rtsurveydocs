ログインする前に、SSL を構成する必要があります。アプリを初めて開いたときに、SSL セットアップ画面に自動的にリダイレクトされます。

---

## SSL セットアップ オプション

![SSL setup options](/img/ssl-setup/ssl-setup-options.png)

3 つのオプションのいずれかを選択してください：

| オプション | 使用する場合 |
|--------|-------------|
| **無料の rtsurvey.com サブドメイン** *(推奨)* | DNS の設定は不要です。弊社でレコードを作成します。2 〜 5 分で準備が整います。 |
| **自分のドメイン** | すでにドメインを持っており、その DNS がこのサーバーを指している場合。 |
| **手動で証明書をインストールする** | エンタープライズまたはカスタム CA。SSH アクセスが必要です。 |

---

## オプション 1 — 無料の rtsurvey.com サブドメイン *(推奨)*

これは最も速いオプションです。ドメインの登録や DNS の変更は必要ありません。

![HTTPS Setup form](/img/ssl-setup/ssl-setup-form.png)

> **続行する前に:** 無料のサブドメインには、[licenses.rtsurvey.com](https://licenses.rtsurvey.com) でのアクティブなアカウントが必要です。無料プランには 1 つのサブドメイン (`*.rtsurvey.com`) が含まれています。

1. **Free rtsurvey.com subdomain** をクリックしてセクションを展開します。
2. **YOUR SUBDOMAIN** フィールドに希望のサブドメイン名を入力します。

   > 英小文字、数字、ハイフンを使用してください。3 〜 30 文字。
   > 例: `myproject` → `myproject.rtsurvey.com`

3. [licenses.rtsurvey.com](https://licenses.rtsurvey.com) から取得した **rtSurvey DNS Token** をトークン フィールドに貼り付けます。
4. **Create secure subdomain** をクリックします。

送信されると、アプリは証明書のプロビジョニングを開始します：

![Setting up HTTPS progress](/img/ssl-setup/ssl-setup-progress.png)

4 つの手順が自動的に実行されます：
- **DNS レコードのリクエスト** — サブドメインの DNS エントリを作成します。
- **DNS の伝播待ち** — 通常 2 〜 5 分です。
- **SSL 証明書の発行** — Let's Encrypt が証明書に署名します。
- **HTTPS の有効化** — Nginx が新しい証明書で再読み込みされます。

5. 完了すると、新しい HTTPS URL に自動的にリダイレクトされます。



---

## オプション 2 — 自分のドメイン

既存のドメインがあり、その DNS の `A` レコードがすでにこのサーバーの IP を指している場合に使用します。

1. **My own domain** をクリックしてセクションを展開します。
2. 完全なドメイン名を入力します（例: `survey.myorganization.org`）。
3. **Create certificate** をクリックします。



Let's Encrypt がドメインを検証し、証明書を発行します。これには、DNS が最初に正しく設定されている必要があります。そうでない場合、リクエストは失敗します。

---

## オプション 3 — 手動で証明書をインストールする

カスタムまたは内部 CA を使用するエンタープライズ環境向け。SSH 経由でサーバーに証明書ファイルを配置し、アプリでドメインを入力します。

### 前提条件

- サーバーへの SSH アクセス
- ドメインの有効な証明書と秘密鍵（PEM 形式）

### 手順 1 — サーバーに SSH でログインする

```bash
ssh root@<server-ip>
```

### 手順 2 — 証明書ファイルを配置する

ディレクトリを作成し、ファイルをコピーします：

```bash
mkdir -p /etc/letsencrypt/live/<your-domain>
```

以下の正確な名前でファイルをそのディレクトリにコピーします：

| ファイル | 説明 |
|------|-------------|
| `fullchain.pem` | 証明書 + 中間 CA 証明書（連結されたもの） |
| `privkey.pem` | 秘密鍵 |

例：

```bash
# ローカル マシンからコピーします（サーバーではなく、ローカルで実行してください）
scp fullchain.pem root@<server-ip>:/etc/letsencrypt/live/<your-domain>/fullchain.pem
scp privkey.pem  root@<server-ip>:/etc/letsencrypt/live/<your-domain>/privkey.pem
```

正しい権限を設定します：

```bash
chmod 644 /etc/letsencrypt/live/<your-domain>/fullchain.pem
chmod 600 /etc/letsencrypt/live/<your-domain>/privkey.pem
```

### 手順 3 — アプリでドメインを入力する



1. SSL セットアップ画面で、**Install certificate manually** をクリックします。
2. ドメイン名を入力します（証明書の Common Name または SAN と一致する必要があります）。
3. **Apply** をクリックします。

サーバーは証明書を使用して Nginx を構成し、自動的に再読み込みします。

### Funciones de cadena

<Callout type="warning">
Al trabajar με cadenas dentro de expresiones, es importante usar comillas simples ('') para encerrar cadenas literales. Sin embargo, surge una excepción cuando desea incluir comillas simples dentro de una cadena literal. En tales casos, puede usar comillas dobles ("") para encerrar toda la cadena.

Por ejemplo:
- Correcto: if(`${yesno}` = 1, "a string with 'single quotes' in it", "no single quotes here")
- Incorrecto: if(`${yesno}` = 1, 'a string with 'single quotes' in it', 'no single quotes here')

Con respecto a las comillas tipográficas (smart quotes), es crucial ser consciente de su presencia, ya que pueden causar problemas en las expresiones. Muchos editores de texto enriquecido convierten automáticamente las comillas rectas ("" o '') en comillas tipográficas o curvas (“” o ‘’), lo que puede dar lugar a errores de sintaxis o comportamientos inesperados. Para evitar esto, asegúrese de usar comillas rectas ('') de manera consistente en sus expresiones.

¡Por favor, avíseme si tiene más preguntas o necesita ayuda adicional!
</Callout>

rtSurvey admite varias funciones, incluyendo:

1. `string(field)`: Convierte un campo en una cadena.
   - Ejemplo: `string(34.8)` se convertirá en `'34.8'`.

2. `string-length(field)`: Devuelve la longitud de un campo de cadena.
   - Ejemplo: `string-length(.) > 3 and string-length(.) < 10` se puede usar para asegurar que el campo actual tenga entre 3 y 10 caracteres.
   - **Patrón de dependencia en cascada**: `string-length(${province}) >= 0` siempre se evalúa como `true` pero obliga a rtSurvey a volver a evaluar la expresión cada vez que cambia `${province}`. Use esto en `relevant` para activar una actualización en cascada cuando se actualiza un campo principal:
     | type | name | relevant |
     |------|------|----------|
     | select_one | district | `string-length(${province}) >= 0` |
     Esto asegura que la pregunta de distrito vuelva a evaluar su apariencia `search()` o `rawquery` cada vez que cambie la provincia.

3. `substr(fieldorstring, startindex, endindex)`: Devuelve una subcadena que comienza en `startindex` y termina justo antes de `endindex`. Los índices comienzan en 0 para el primer carácter de la cadena.
   - Ejemplo: `substr(${phone}, 0, 3)` devolverá los tres primeros dígitos de un número de teléfono.

4. `concat(a, b, c, ...)`: Concatena campos (y/o cadenas) juntos.
   - Ejemplo: `concat(${firstname}, ' ', ${lastname})` devolverá un nombre completo combinando los valores de los campos `firstname` y `lastname`.

5. `linebreak()`: Devuelve un carácter de salto de línea.
   - Ejemplo: `concat(${field1}, linebreak(), ${field2}, linebreak(), ${field3})` devolverá una lista de tres valores de campo con saltos de línea entre ellos.

6. `lower()`: Convierte una cadena a todos los caracteres en minúscula.
   - Ejemplo: `lower('Street Name')` devolverá "street name".

7. `upper()`: Convierte una cadena a todos los caracteres en mayúscula.
   - Ejemplo: `upper('Street Name')` devolverá "STREET NAME".

### Funciones select_one y select_multiple

1. `count-selected(field)`: Devuelve el número de elementos seleccionados en un campo select_multiple.
   - Ejemplo: `count-selected(.) = 3` se puede usar como una expresión de restricción para asegurar que se seleccionen exactamente tres opciones.

2. `selected(field, value)`: Devuelve true o false dependiendo de si el valor especificado fue seleccionado en el campo select_one o select_multiple.
   - Ejemplo: `selected(${color}, 'Blue')` se puede usar como una expresión de relevancia para mostrar un grupo o campo solo si el encuestado seleccionó "Blue" como su color favorito.
   - Nota: El segundo parámetro siempre debe especificar el valor de la opción, no la etiqueta de la opción. Use el valor de la columna value en la hoja de trabajo choices de la definición del formulario.

3. `selected-at(field, number)`: Devuelve el elemento seleccionado en la posición especificada en un campo select_multiple. Cuando el número pasado es 0, devuelve el primer elemento seleccionado; cuando el número es 1, devuelve el segundo elemento seleccionado, y así sucesivamente.
   - Ejemplo: `selected-at(${fruits}, 0) = 'Apple'` se puede usar como una expresión de relevancia para mostrar un grupo o campo solo si la primera opción seleccionada es "Apple".
   - Nota: El valor devuelto será el valor de la opción, no la etiqueta de la opción. Use el valor de la columna value en la hoja de trabajo choices de la definición del formulario.

4. `choice-label(field, value)`: Devuelve la etiqueta de una opción de campo select_one o select_multiple, tal como se define en la hoja de trabajo choices de la definición del formulario.
   - Ejemplo 1: `choice-label(${country}, ${country})` devolverá la etiqueta de la opción para la opción seleccionada actualmente en el campo llamado `country`.
   - Ejemplo 2: `choice-label(${languages}, selected-at(${languages}, 0))` devolverá la etiqueta de la primera opción seleccionada en el campo llamado `languages`.
   - Nota: Esta función recupera la etiqueta de la opción, no el valor. Utiliza la columna label de la hoja de trabajo choices de la definición del formulario.

### Funciones de campo repetido

En rtSurvey, si desea hacer la(s) misma(s) pregunta(s) varias veces, puede colocar un campo dentro de un grupo repetido (repeat group). Esto da como resultado múltiples instancias del mismo campo. Las siguientes funciones pueden ayudarlo a manejar estos campos repetidos y los datos repetidos que producen. Consulte el tema de ayuda sobre campos repetidos para obtener más detalles.

1. `join(string, repeatedfield)`: Para un campo dentro de un grupo repetido, genera una lista de valores separados por cadenas. El primer parámetro especifica el delimitador que se usará para separar los valores.
   - Ejemplo: `join(', ', ${member_name})` generará una única lista separada por comas de todos los nombres ingresados.

2. `join-if(string, repeatedfield, expression)`: Funciona exactamente igual que `join()`, excepto que verifica cada instancia en el grupo repetido usando la expresión proporcionada. Si la expresión se evalúa como false, el elemento se omitirá de la salida.
   - Ejemplo: `join-if(', ', ${member_name}, ${age} >= 18)` generará una lista de nombres separada por comas de solo los miembros adultos (aquellos con edades de 18 años o más).

3. `count(repeatgroup)`: Devuelve el número actual de veces que se ha repetido un grupo repetido.
   - Ejemplo: `count(${groupname})` devolverá el número de instancias del grupo.

4. `count-if(repeatgroup, expression)`: Funciona exactamente igual que `count()`, excepto que verifica cada instancia en el grupo repetido usando la expresión proporcionada. Si la expresión se evalúa como false, el elemento se omitirá de la salida.
   - Ejemplo: `count-if(${members}, ${age} >= 18)` devolverá el recuento de miembros adultos según el campo de edad dentro del grupo repetido "members".

5. `sum(repeatedfield)`: Para un campo dentro de un grupo repetido, calcula la suma de todos los valores.
   - Ejemplo: `sum(${loan_amount})` devolverá el valor total de todos los préstamos.

6. `sum-if(repeatedfield, expression)`: Funciona exactamente igual que `sum()`, excepto que verifica cada instancia en el grupo repetido usando la expresión proporcionada. Si la expresión se evalúa como false, el elemento se omitirá de la salida.
   - Ejemplo: `sum-if(${loan_amount}, ${loan_amount} > 500)` devolverá el valor total de todos los préstamos que superen los 500. Se ignorarán los préstamos más pequeños.

7. `min(repeatedfield)`: Para un campo dentro de un grupo repetido, calcula el mínimo de todos los valores.
   - Ejemplo: `min(${member_age})` devolverá la edad del miembro más joven del grupo.

8. `min-if(repeatedfield, expression)`: Funciona exactamente igual que `min()`, excepto que verifica cada instancia en el grupo repetido usando la expresión proporcionada. Si la expresión se evalúa como false, el elemento se omitirá de la salida.
   - Ejemplo: `min-if(${member_age}, ${member_age} >= 18)` devolverá la edad del adulto más joven del grupo. Se ignorarán los menores de 18 años.

9. `max(repeatedfield)`: Para un campo dentro de un grupo repetido, calcula el máximo de todos los valores.
   - Ejemplo: `max(${member_age})` devolverá la edad del miembro más viejo del grupo.

10. `max-if(repeatedfield, expression)`: Funciona exactamente igual que `max()`, excepto que verifica cada instancia en el grupo repetido usando la expresión proporcionada. Si la expresión se evalúa como false, el elemento se omitirá de la salida.
    - Ejemplo: `max-if(${member_age}, ${member_age} >= 18)` devolverá la edad del adulto más viejo del grupo. Se ignorarán los menores de 18 años.

11. `index()`: Llamado dentro de un grupo repetido, devuelve el número de índice del grupo o instancia actual.
    - Ejemplo: `index()` cuando se usa dentro de un grupo repetido devolverá 1 para la primera instancia, 2 para la segunda, y así sucesivamente.

12. `indexed-repeat(repeatedfield, repeatgroup, index)`: Hace referencia a un campo o grupo que está dentro de un grupo repetido desde fuera de ese grupo repetido. El primer parámetro especifica el campo o grupo repetido de interés, el segundo especifica el grupo repetido dentro del cual se encuentra el campo o grupo, y el tercero especifica el número de instancia dentro del grupo repetido que se usará.
    - Ejemplo 1: `indexed-repeat(${name}, ${names}, 1)` devolverá el primer nombre disponible cuando el campo de nombre esté dentro de un grupo repetido anterior llamado "names".
    - Ejemplo 2: `indexed-repeat(${name}, ${names}, index())` extraerá el nombre correspondiente al número de instancia del grupo repetido actual.

13. `rank-index(index, repeatedfield)`: Esta función calcula el rango ordinal de la instancia especificada de un campo repetido para su uso fuera del grupo repetido. El rango de 1 se asigna a la instancia con el valor más alto, el rango de 2 a la instancia con el siguiente valor más alto, y así sucesivamente. Si pasa un índice no válido o un índice a una instancia con un valor no numérico, se devolverá un rango de 999.
    - Ejemplo: `rank-index(1, ${random_draw})` calcula el rango de la primera instancia basándose en el valor de su campo `random_draw` en comparación con los valores de otras instancias.

14. `rank-index-if(index, repeatedfield, expression)`: Esta función funciona de manera similar a `rank-index()`, pero verifica cada instancia en el grupo repetido del campo repetido usando la expresión proporcionada. Si la expresión se evalúa como false, el elemento se omitirá del cálculo. El índice utilizado se basa en el conjunto completo de instancias antes de evaluar la expresión para cada instancia. Si pasa un índice para una instancia que fue ignorada debido a que no satisfizo la expresión, se considera un índice no válido y se devolverá un rango de 999.
    - Ejemplo: `rank-index-if(1, ${age}, ${age} >= 18)` calcula el rango de edad dentro del conjunto de adultos, considerando solo las instancias donde la edad es mayor o igual a 18.

### Funciones numéricas

| Operador | Operación | Ejemplo | Respuesta de ejemplo |
|----------|-----------|---------|----------------------|
| `+` | Suma | 1 + 1 | 2 |
| `-` | Resta | 3 - 2 | 1 |
| `*` | Multiplicación | 3 * 2 | 6 |
| `div` | División | 10 div 2 | 5 |
| `mod` | Módulo | 9 mod 2 | 1 |

rtSurvey admite funciones numéricas, que incluyen:
- `number(field)`: Convierte el valor del campo en un número.
  - Ejemplo: `number('34.8')` = 34.8

- `int(field)`: Convierte el valor del campo en un entero.
  - Ejemplo: `int('39.2')` = 39

- `min(field1, ..., fieldx)`: Devuelve el valor mínimo entre los campos pasados.
  - Ejemplo: `min(${father_age}, ${mother_age})` devolverá la edad de la madre o del padre, la que sea menor.

- `max(field1, ..., fieldx)`: Devuelve el valor máximo entre los campos pasados.
  - Ejemplo: `max(${father_age}, ${mother_age})` devolverá la edad de la madre o del padre, la que sea mayor.

- `format-number(field)`: Formatea el valor de un campo entero o decimal de acuerdo con la configuración regional del usuario.
  - Ejemplo: `format-number(${income})` Esta expresión podría formatear "120000" como "120,000".

- `round(field, digits)`: Redondea el valor del campo numérico al número especificado de dígitos después del punto decimal.
  - Ejemplo: `round(${interest_rate}, 2)`

- `abs(number)`: Devuelve el valor absoluto de un número.
  
- `pow(base, exponent)`: Devuelve el valor del primer parámetro elevado a la potencia del segundo parámetro.
  - Cada parámetro puede ser un campo, número o expresión.

- `log10(fieldorvalue)`: Devuelve el logaritmo en base diez del campo o valor pasado.

- `sin(fieldorvalue)`: Devuelve el seno del campo o valor pasado, expresado en radianes.
  
- `cos(fieldorvalue)`: Devuelve el coseno del campo o valor pasado, expresado en radianes.

- `tan(fieldorvalue)`: Devuelve la tangente del campo o valor pasado, expresado en radianes.

- `asin(fieldorvalue)`: Devuelve el arcoseno del campo o valor pasado, expresado en radianes.

- `acos(fieldorvalue)`: Devuelve el arcocoseno del campo o valor pasado, expresado en radianes.

- `atan(fieldorvalue)`: Devuelve el arcotangente del campo o valor pasado, expresado en radianes.

- `atan2(x, y)`: Devuelve el ángulo en radianes subtendido en el origen por el punto con coordenadas (x, y) y el eje x positivo. El resultado está en el rango de -pi() a pi().

- `sqrt(fieldorvalue)`: Devuelve la raíz cuadrada no negativa del campo o valor pasado.

- `exp(x)`: Devuelve el valor de e^x.

- `pi()`: Devuelve el valor de pi.

### Funciones de fecha y hora

<Callout type="warning">
Los valores de fecha en rtSurvey se almacenan como cadenas en formato `YYYY-MM-DD`. Los valores de fecha y hora se almacenan como cadenas ISO 8601 (`YYYY-MM-DDTHH:MM:SS`). Use `decimal-date-time()` para convertir a un número para aritmética (por ejemplo, calcular duraciones).
</Callout>

1. `today()`: Devuelve la fecha de hoy como una cadena en formato `YYYY-MM-DD`. Se evalúa una vez cuando se abre el formulario.
   - Ejemplo: `today()` → `'2024-03-15'`
   - Uso común: columna `default` para completar previamente la fecha de hoy, o en `relevant`/`constraint` para comparar con un campo de fecha.

2. `now()`: Devuelve la fecha y hora actuales como una cadena ISO 8601. Se evalúa cada vez que se calcula la expresión.
   - Ejemplo: `now()` → `'2024-03-15T14:32:00.000+03:00'`
   - Uso común: Registrar la marca de tiempo exacta de un evento específico durante la encuesta.

3. `date(value)`: Convierte un valor (cadena o número) en una cadena de fecha. Útil para obligar a los valores calculados a un tipo de fecha.
   - Ejemplo: `date('2024-03-15')` → `'2024-03-15'`

4. `date-time(value)`: Convierte un valor en una cadena de fecha y hora.
   - Ejemplo: `date-time(${event_timestamp})`

5. `decimal-date-time(value)`: Convierte una cadena de fecha o fecha y hora en un número decimal que representa los milisegundos desde la época Unix divididos por 86400000 (es decir, días fraccionarios desde 1970-01-01). Use esto para realizar operaciones aritméticas en fechas.
   - Ejemplo: Duración en días entre dos fechas:
     `decimal-date-time(${end_date}) - decimal-date-time(${start_date})`
   - Ejemplo: Duración en minutos entre dos fechas y horas:
     `(decimal-date-time(${end_time}) - decimal-date-time(${start_time})) * 1440`

6. `format-date(date, format)`: Formatea un valor de fecha usando una cadena de patrón.
   - Símbolos de formato: `%Y` (año de 4 dígitos), `%y` (año de 2 dígitos), `%m` (mes 01–12), `%d` (día 01–31), `%a` (día de la semana abreviado), `%b` (nombre del mes abreviado)
   - Ejemplo: `format-date(today(), '%d/%m/%Y')` → `'15/03/2024'`
   - Ejemplo: `format-date(${dob}, '%B %d, %Y')` → `'March 15, 1990'`

7. `format-date-time(datetime, format)`: Formatea un valor de fecha y hora usando una cadena de patrón. Admite todos los símbolos de `format-date` más:
   - `%H` (hora 00–23), `%h` (hora 01–12), `%M` (minutos 00–59), `%S` (segundos 00–59), `%3` (milisegundos), `%P` (AM/PM)
   - Ejemplo: `format-date-time(now(), '%d/%m/%Y %H:%M')` → `'15/03/2024 14:32'`
   - Ejemplo: `format-date-time(${event_time}, '%I:%M %p')` → `'02:32 PM'`

8. `STRFTIME(format, datetime)`: Formateo de fecha al estilo SQLite. Disponible dentro de las cadenas SQL pasadas a consultas `rawquery`, **no** disponible en las columnas XLSForm `calculation` o `label`. Utiliza símbolos de formato SQLite (`%Y`, `%m`, `%d`, `%H`, `%M`, `%S`).
   - Ejemplo dentro de una cadena SQL de rawquery: `'SELECT STRFTIME(''%Y-%m'', interview_date) AS month FROM data WHERE id = ?'`
   - Nota: Use `format-date-time()` para el formato de fecha en las expresiones XLSForm. `STRFTIME()` es una función de SQLite disponible solo dentro del SQL pasado a `rawquery`.

### Funciones booleanas

1. `boolean(value)`: Convierte cualquier valor a booleano. Devuelve `true` para cadenas no vacías, números distintos de cero y `true`; devuelve `false` para cadenas vacías, `0` y `false`.
   - Ejemplo: `boolean(${name})` devuelve `true` si `name` no está vacío.

2. `boolean-from-string(string)`: Devuelve `true` si la cadena es `'1'` o `'true'` (insensible a mayúsculas y minúsculas); devuelve `false` de lo contrario.
   - Ejemplo: `boolean-from-string(${enabled_flag})` — útil cuando un campo almacena `'true'`/`'false'` como texto.

3. `true()`: Devuelve el valor booleano `true`.
   - Ejemplo: En la columna `required`, `true()` es equivalente a `yes`.

4. `false()`: Devuelve el valor booleano `false`.
   - Ejemplo: `if(${skip_section} = 'yes', false(), true())` — establecer dinámicamente el campo requerido.

5. `not(expression)`: Devuelve la negación lógica de la expresión. Devuelve `true` si la expresión es false, y viceversa.
   - Ejemplo: `not(${consent} = 'yes')` — mostrar una advertencia cuando NO se dio el consentimiento.
   - Ejemplo: `not(selected(${issues}, 'none'))` — requerir detalles solo si no se seleccionó "ninguno".

### Funciones de cadena adicionales

1. `starts-with(string, prefix)`: Devuelve `true` si `string` comienza con `prefix`.
   - Ejemplo: `starts-with(${phone}, '+254')` verifica si el número de teléfono comienza con el código de país de Kenia.

2. `contains(string, substring)`: Devuelve `true` si `string` contiene `substring`.
   - Ejemplo: `contains(${email}, '@')` verifica que una dirección de correo electrónico tenga un signo `@`.
   - Ejemplo: `contains(${notes}, 'urgent')` activa una pregunta de seguimiento si las notas mencionan "urgente".

3. `substring-before(string, needle)`: Devuelve la parte de `string` que aparece antes de la primera aparición de `needle`.
   - Ejemplo: `substring-before(${full_name}, ' ')` extrae la primera palabra (nombre de pila).

4. `substring-after(string, needle)`: Devuelve la parte de `string` que aparece después de la primera aparición de `needle`.
   - Ejemplo: `substring-after(${email}, '@')` extrae la parte del dominio de una dirección de correo electrónico.

5. `normalize-space(string)`: Elimina los espacios en blanco iniciales y finales y colapsa todas las secuencias de espacios en blanco internas a un solo espacio.
   - Ejemplo: `normalize-space(${name})` — limpia un nombre que puede haber sido escrito con espacios adicionales.

6. `translate(string, search_chars, replace_chars)`: Reemplaza cada carácter en `string` que aparece en `search_chars` con el carácter correspondiente en `replace_chars`. Los caracteres en `search_chars` que no tienen un carácter correspondiente en `replace_chars` se eliminan.
   - Ejemplo: `translate(${code}, 'abcdefghijklmnopqrstuvwxyz', 'ABCDEFGHIJKLMNOPQRSTUVWXYZ')` convierte a mayúsculas (equivalente a `upper()`).
   - Ejemplo: `translate(${phone}, ' -()', '')` elimina espacios, guiones y paréntesis de un número de teléfono.

### Funciones matemáticas adicionales

1. `floor(number)`: Devuelve el entero más grande menor o igual a `number` (redondea hacia el infinito negativo).
   - Ejemplo: `floor(4.9)` = 4, `floor(-2.1)` = -3

2. `ceiling(number)`: Devuelve el entero más pequeño mayor o igual a `number` (redondea hacia el infinito positivo).
   - Ejemplo: `ceiling(4.1)` = 5, `ceiling(-2.9)` = -2

3. `random()`: Devuelve un número decimal aleatorio entre 0.0 (inclusive) y 1.0 (exclusivo). Normalmente se usa en campos `calculate` para asignar valores aleatorios o aleatorizar el orden de las preguntas.
   - Ejemplo: `random()` → p. ej., `0.7341`
   - Ejemplo: `int(random() * 6) + 1` → número aleatorio 1–6 (lanzamiento de dado)

4. `coalesce(a, b)`: Devuelve `a` si `a` no está vacío; de lo contrario, devuelve `b`. Útil como respaldo cuando un campo puede estar vacío.
   - Ejemplo: `coalesce(${preferred_name}, ${full_name})` — usar el nombre preferido si está configurado; de lo contrario, recurrir al nombre completo.

5. `once(value)`: Evalúa `value` y lo almacena, pero solo si el campo actual está **vacío**. Si el campo ya tiene un valor (por ejemplo, se configuró anteriormente), `once()` devuelve el valor existente sin cambios. Esto evita que el recalculo sobrescriba la entrada del usuario.
   - Ejemplo: `once(today())` en la columna `default` establece la fecha de hoy una vez y no se actualiza si el encuestador vuelve a abrir el formulario.
   - Ejemplo: `once(uuid())` genera un UUID una vez y lo mantiene estable en las reediciones.

### Funciones geográficas

1. `area(geoshape_value)`: Calcula el **área en metros cuadrados** encerrada por un valor de geoshape (polígono).
   - El parámetro es el valor de un campo geoshape en el formato `lat1 lon1 0 0; lat2 lon2 0 0; ...`
   - Ejemplo: `area(${field_boundary})` — calcular el área de un campo encuestado en m².
   - Ejemplo: `round(area(${field_boundary}) div 10000, 2)` — convertir a hectáreas.

2. `distance(coordinates)`: Calcula la **longitud total de la trayectoria en metros** de un geotrace (línea), o la distancia entre dos geopuntos.
   - Para un geotrace: `distance(${route})` devuelve la longitud total de la trayectoria en metros.
   - Para dos geopuntos: `distance(concat(${point_a}, ' ', ${point_b}))` devuelve la distancia entre ellos.
   - Ejemplo: `round(distance(${road_trace}) div 1000, 3)` — longitud de la carretera en kilómetros.

### Funciones de validación

1. `regex(value, pattern)`: Devuelve `true` si `value` coincide con la expresión regular `pattern`. Úselo en la columna `constraint` para la validación basada en patrones.
   - El patrón utiliza la sintaxis regex estándar (subconjunto POSIX ERE).
   - Ejemplo: `regex(., '^[0-9]{10}$')` — validar un número de 10 dígitos.
   - Ejemplo: `regex(., '^[A-Z]{2}[0-9]{6}$')` — validar un formato de número de pasaporte (2 letras mayúsculas seguidas de 6 dígitos).
   - Ejemplo: `regex(., '^[^@]+@[^@]+\.[^@]{2,}$')` — comprobación básica del formato de correo electrónico.

2. `checklist(min, max, v1, v2, ...)`: Evalúa una lista de expresiones booleanas y devuelve `true` si el número de valores `true` está entre `min` y `max` (inclusive). Pase `-1` para `min` o `max` para omitir ese límite.
   - Ejemplo: `checklist(2, 3, ${q1} = 'yes', ${q2} = 'yes', ${q3} = 'yes')` — pasa si exactamente 2 o 3 de las tres condiciones son verdaderas.
   - Ejemplo: `checklist(1, -1, ${smoke_alarm}, ${fire_ext}, ${emergency_plan})` — al menos una medida de seguridad debe ser verdadera.

3. `weighted-checklist(min, max, v1, w1, v2, w2, ...)`: Al igual que `checklist()`, pero cada valor tiene un peso. La suma de los pesos de los valores `true` debe estar entre `min` y `max`.
   - Ejemplo: `weighted-checklist(10, -1, ${has_toilet}, 4, ${has_sink}, 3, ${has_shower}, 5)` — la suma de los pesos de las instalaciones presentes debe ser al menos 10.

### Funciones de utilidad

1. `uuid()`: Genera un UUID aleatorio (formato RFC 4122 v4) como una cadena.
   - Ejemplo: `uuid()` → `'a3f8b2c1-4d5e-6f7a-8b9c-0d1e2f3a4b5c'`
   - Normalmente se usa con `once()` para generar un ID único estable: `once(uuid())`

2. `version()`: Devuelve el valor del atributo `version` del formulario tal como se estableció en la hoja de trabajo settings.
   - Ejemplo: `version()` → `'3.1'`
   - Útil en campos `calculate` para incrustar la versión del formulario en los datos exportados.

3. `position()`: Cuando se llama dentro de un **grupo repetido (repeat group)**, devuelve el índice basado en 1 de la instancia de repetición actual.
   - Ejemplo: `position()` en la primera instancia devuelve `1`, en la segunda devuelve `2`, y así sucesivamente.
   - Ver también: `index()` (alias), `indexed-repeat()` para referenciar valores de repetición desde fuera del grupo.

4. `thousandsep(length, separator, value)`: Formatea un número con un separador de miles. `length` es la longitud total mínima de la cadena (rellenada con espacios si es más corta), `separator` es el carácter que se usará (por ejemplo, `','`) y `value` es el número a formatear.
   - Ejemplo: `thousandsep(0, ',', 1234567)` → `'1,234,567'`
   - Ejemplo: `thousandsep(0, '.', ${income})` → formatea los ingresos con un punto como separador de miles.

5. `substr-jsonpath(value, jsonpath)`: Extrae un valor de una cadena JSON utilizando una expresión JSONPath.
   - `value` debe ser una cadena JSON (p. ej., un campo que almacenó una respuesta de API sin procesar usando `callapi(..., 'json:', ...)`).
   - `jsonpath` es una expresión JSONPath (p. ej., `'$.data.name'`, `'$.items[0].id'`).
   - Siempre devuelve una **cadena**: envuélvala en `number()` cuando se use en aritmética.
   - Devuelve una cadena vacía `''` si no se encuentra la ruta o si `value` no es un JSON válido.
   - Ejemplo: `substr-jsonpath(${api_response}, '$.data.name')` — extraer el campo `name`.
   - Ejemplo: `substr-jsonpath(${api_response}, '$.items[0].label')` — primer elemento de una matriz.
   - Ejemplo: `number(substr-jsonpath(${api_response}, '$.price'))` — extraer un valor numérico.
   - Se usa normalmente junto con `callapi(..., 'json:', ...)` para extraer múltiples campos de una respuesta de API. Consulte [Obtención de múltiples valores de una sola llamada a la API](../advanced-features/call-api#fetching-multiple-values-from-one-api-call).

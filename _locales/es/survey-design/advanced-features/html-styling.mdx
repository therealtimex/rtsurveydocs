rtSurvey renderiza el texto de **etiqueta (label)** y **sugerencia (hint)** como HTML en los formularios web. Esto significa que puede usar etiquetas HTML estándar para formatear texto, añadir saltos de línea, crear enlaces y aplicar colores. Esto es especialmente útil para campos de notas, instrucciones de sección y resúmenes dinámicos.

<Callout type="warning">
El HTML en las etiquetas se renderiza en el **formulario web** y en las aplicaciones móviles de rtSurvey. Es posible que no se renderice en todos los clientes compatibles con ODK. Pruebe siempre en su plataforma de destino.
</Callout>

---

## Etiquetas HTML admitidas

### Formato de texto

| Etiqueta | Resultado |
|-----|--------|
| `<strong>texto</strong>` o `<b>texto</b>` | **Texto en negrita** |
| `<em>texto</em>` o `<i>texto</i>` | *Texto en cursiva* |
| `<u>texto</u>` | Texto subrayado |
| `<br>` | Salto de línea |
| `<span style="...">texto</span>` | Estilo en línea |

### Enlaces

```html
<a href="https://example.com" target="_blank">Haga clic aquí</a>
```

Se abre en una pestaña nueva. Úselo para documentos de referencia, directrices o recursos externos que el encuestador deba consultar.

### Colores

Use `<span>` con estilos en línea:

```html
<span style="color: red;">Warning: value is out of range</span>
<span style="color: #009688;">Section completed</span>
```

## Variables de tema de color

rtSurvey admite **tokens de tema de color** que se adaptan al tema configurado de la aplicación. Use la sintaxis `__COLOR_THEME_NAME__`:

```html
<span style="color: var(--color-theme-primary);">Primary color text</span>
```

O usando el atajo del token en el texto de la etiqueta:

```
<font color="var(--COLOR_THEME_PRIMARY)">Important note</font>
```

Esto se convierte automáticamente al equivalente `<span>` con una variable CSS en el momento de la renderización.

---

## Etiquetas multilingües

Envuelva el contenido en etiquetas de idioma para admitir varios idiomas en una sola celda de etiqueta:

```
<en>Enter the household size</en><vi>Nhập quy mô hộ gia đình</vi>
```

rtSurvey extrae el contenido que coincide con el idioma actual de la aplicación. Si no se encuentra ninguna etiqueta de idioma coincidente, se muestra la cadena completa tal cual.

## Ejemplos en campos de notas

### Instrucción de sección con negrita y un salto de línea

| type | name | label |
|------|------|-------|
| note | section_intro | `<strong>Section 3: Land Use</strong><br>Ask all questions in this section to the household head only.` |

### Resumen dinámico con referencia de cálculo

| type | name | label |
|------|------|-------|
| calculate | total | | `${adults} + ${children}` |
| note | summary | `Total household members: <strong>${total}</strong><br><span style="color: gray;">Adults: ${adults} · Children: ${children}</span>` |

### Advertencia en rojo

| type | name | label | relevant |
|------|------|-------|----------|
| note | age_warning | `<span style="color: red;"><strong>Warning:</strong> Age entered (${age}) is unusually high. Please verify.</span>` | `${age} > 100` |

### Enlace a un documento de referencia

| type | name | label |
|------|------|-------|
| note | guidelines_link | `Refer to the <a href="https://docs.example.com/guidelines" target="_blank">Field Guidelines</a> before starting this section.` |

## Etiquetas HTML especiales de rtSurvey

### `<webbox src='url' title='title'>...</webbox>`

Incrusta un botón que abre una URL en un modal dentro del formulario. Consulte [Webbox](webbox) para obtener todos los detalles.

### `<delete-repeat-current>label</delete-repeat-current>`

Renderiza un botón dentro de un grupo de repetición que elimina la instancia de repetición actual cuando se pulsa.

### `<delete-repeat-last>label</delete-repeat-last>`

Renderiza un botón que elimina la última instancia de repetición.

Ejemplo de uso en un grupo de repetición:

| type | name | label |
|------|------|-------|
| note | delete_btn | `<delete-repeat-current>Remove this member</delete-repeat-current>` |

## Resúmenes HTML dinámicos con autopull()

`autopull()` renderiza un bloque de HTML dentro de un campo `note` y **lo vuelve a evaluar en cada cambio de campo** en el formulario. Esto lo hace adecuado para paneles de resumen en vivo, pantallas de revisión antes del envío y totales acumulados que se actualizan a medida que el encuestador completa los datos.

<Callout type="info">
`autopull()` solo funciona en campos de **notas (note)**. Se ignora la columna de etiqueta (label); todo el contenido HTML debe suministrarse a través de la columna de **apariencia (appearance)** mediante `concat()`.
</Callout>

### Sintaxis

Coloque `autopull()` en la columna de **apariencia (appearance)** de un campo `note`:

```
autopull(concat('<html>...</html>'))
```

Las referencias de campo (`${field_name}`) dentro de `concat()` se sustituyen por los valores actuales en vivo y el HTML se vuelve a renderizar en cada cambio.

### Restricción de altura con scroll-view()

Para resúmenes más largos, combine `autopull()` con `scroll-view(N%)` para limitar la altura del panel y hacerlo desplazable:

```
scroll-view(45%) autopull(concat('<html>...</html>'))
```

El valor `N%` es relativo al área visible del formulario. `45%` es un valor predeterminado práctico para un panel de resumen en la mitad de la página.

### Ejemplo completo — resumen de ubicación del hogar

El siguiente campo `note` renderiza una tabla de dos columnas que muestra la provincia, el distrito y la comuna seleccionados. Se actualiza automáticamente cada vez que cambian `${tinh_name}`, `${huyen_name}` o `${xa_name}`.

| type | name | label | appearance |
|------|------|-------|------------|
| note | location_summary | | `scroll-view(45%) autopull(concat('<html><table style="width:100%;border-collapse:collapse"><tr><td style="padding:4px;font-weight:bold">Province:</td><td style="padding:4px">', ${tinh_name}, '</td></tr><tr><td style="padding:4px;font-weight:bold">District:</td><td style="padding:4px">', ${huyen_name}, '</td></tr><tr><td style="padding:4px;font-weight:bold">Commune:</td><td style="padding:4px">', ${xa_name}, '</td></tr></table></html>'))` |

En XLSForm, el valor de apariencia se escribe en una sola celda:

```
scroll-view(45%) autopull(concat(
  '<html><table style="width:100%;border-collapse:collapse">
   <tr><td style="padding:4px;font-weight:bold">Province:</td>
       <td style="padding:4px">', ${tinh_name}, '</td></tr>
   <tr><td style="padding:4px;font-weight:bold">District:</td>
       <td style="padding:4px">', ${huyen_name}, '</td></tr>
   <tr><td style="padding:4px;font-weight:bold">Commune:</td>
       <td style="padding:4px">', ${xa_name}, '</td></tr>
   </table></html>'))
```

### Estilos en línea

Se admiten los atributos `style="..."` en línea en cualquier elemento HTML y son la forma recomendada de aplicar formato visual dentro de los bloques `autopull()`.

Lo siguiente **no** se admite dentro del contenido de `autopull()`:

- Bloques `<style>`
- Etiquetas `<link>` de hojas de estilo externas
- JavaScript (`<script>`)

### Cuándo usar autopull()

| Caso de uso | Notas |
|----------|-------|
| Pantalla de revisión antes del envío | Mostrar todas las respuestas clave en un panel antes de que el encuestador finalice |
| Totales acumulados | Mostrar una suma calculada que se actualiza a medida que se ingresan las cantidades |
| Panel de referencia visible | Mostrar un valor de búsqueda seleccionado (por ejemplo, nombre de la provincia) mientras el encuestador completa los campos secundarios |

## Mejores prácticas

1. Use HTML con moderación: las etiquetas excesivamente formateadas son más difíciles de leer, no más fáciles.
2. Prefiera `<strong>` para negrita y `<em>` para cursiva en lugar de las etiquetas obsoletas `<b>` e `<i>`.
3. Mantenga el uso del color de manera significativa: use el rojo para advertencias, no para decoración.
4. Pruebe siempre la renderización HTML tanto en la aplicación móvil como en el formulario web, ya que la renderización puede diferir ligeramente.
5. Evite las etiquetas `<table>` dentro de las etiquetas: rara vez se renderizan bien en pantallas móviles.
6. No use JavaScript (`<script>`): se eliminará o causará errores.

## Limitaciones

- No se admite HTML complejo (tablas, formularios, scripts) y puede romper la renderización.
- Algunos clientes móviles más antiguos pueden mostrar etiquetas HTML como texto literal; pruebe en todos los dispositivos de destino.
- Los enlaces `<a>` se abren en un navegador o WebView; el encuestador abandona el formulario, lo que puede ser molesto en el móvil.

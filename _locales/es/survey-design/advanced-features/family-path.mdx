`family_path` es un campo de cálculo (calculate) de convención que contiene la ruta al directorio de medios empaquetados del formulario. Cada formulario que realiza búsquedas en bases de datos locales con `rawquery`, `pulldata` o `search()` debe incluir este campo; sin él, las rutas de los archivos no se pueden resolver y las búsquedas devuelven resultados vacíos de forma silenciosa.

---

## El campo calculate

Agregue esta fila cerca de la parte superior de su hoja de encuesta (survey), después de cualquier campo meta y antes de la primera pregunta que utilice un archivo de base de datos:

| type | name | label | calculation |
|---|---|---|---|
| calculate | `family_path` | | `pulldata('app-api', 'family_path')` |

El campo no almacena ningún valor visible y no requiere etiqueta (label). Es un prerrequisito silencioso para toda la construcción de rutas que sigue.

---

## Por qué es necesario

RTSurvey empaqueta los medios del formulario (bases de datos SQLite, imágenes, clips de audio) dentro de un directorio por formulario en el dispositivo. La ruta exacta difiere entre plataformas (Android, iOS, web) y entre dispositivos.

En tiempo de ejecución, la aplicación completa `family_path` automáticamente. Un valor resuelto típico se ve así:

```
resources/familyMedia/Phuong_Person_Test
```

Debido a que la ruta es específica de la plataforma y se determina en el momento del lanzamiento, no se puede codificar de forma fija en el formulario. `pulldata('app-api', 'family_path')` es la única forma confiable de recuperarla.

---

## Cómo usarlo en rutas

Una vez que se define `family_path`, construya una ruta de archivo completa con `concat()`:

```
concat(${family_path}, '/file.db::tableName')
```

El sufijo `::tableName` se elimina cuando la aplicación abre el archivo; el nombre de la tabla se usa solo dentro de su consulta SQL.

---

## Dónde se usa family_path

`family_path` es necesario en el argumento de ruta cada vez que se hace referencia a un archivo empaquetado:

- **Búsqueda en base de datos local**: el argumento `db_path` de `search-autocomplete-noedit-v2('rawquery', ...)` debe construirse con `concat(${family_path}, ...)`. Consulte [Búsqueda en base de datos local](local-database-search) para obtener detalles completos de uso.
- **`pulldata` rawquery**: cualquier llamada a `pulldata('rawquery', ...)` que lea de un archivo `.db` utiliza el mismo patrón `concat()`.
- **`search()` con un archivo local**: las apariencias (appearances) de búsqueda dinámica que se cargan desde un archivo CSV o DB empaquetado también dependen de `family_path` para la referencia del archivo.

---

## Colocación en el formulario

`family_path` debe aparecer **antes del primer campo que haga referencia a él**. La posición recomendada es inmediatamente después del grupo meta:

| type | name | label | calculation |
|---|---|---|---|
| begin_group | meta | | |
| deviceid | deviceid | | |
| start | start | | |
| end | end | | |
| end_group | | | |
| calculate | `family_path` | | `pulldata('app-api', 'family_path')` |
| select_one | province | Province | *(apariencia rawquery que hace referencia a `${family_path}`)* |

<Callout type="warning">
Si `family_path` falta en el formulario, o se coloca después del primer campo `rawquery` / `search()` que hace referencia a él, todas las búsquedas en archivos empaquetados devolverán resultados vacíos de forma silenciosa. No hay ningún mensaje de error: el autocompletado simplemente no muestra resultados.
</Callout>

---

## Múltiples archivos de base de datos

Un solo formulario puede usar varios archivos `.db`. Cada ruta se construye de forma independiente con `concat()`:

```
concat(${family_path}, '/locations.db::externalData')
concat(${family_path}, '/health_facilities.db::facilities')
concat(${family_path}, '/household_list.db::households')
```

Defina `family_path` una vez; haga referencia a él en tantos campos como sea necesario.

---

## Verificación durante el desarrollo

Agregue un campo `note` temporal debajo de `family_path` para inspeccionar el valor resuelto en el dispositivo:

| type | name | label | calculation |
|---|---|---|---|
| calculate | `family_path` | | `pulldata('app-api', 'family_path')` |
| note | family_path_check | `Ruta: ${family_path}` | |

La nota mostrará la ruta resuelta real durante las pruebas. Elimínela antes de implementar el formulario final.

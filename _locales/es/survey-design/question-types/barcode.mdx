title: "Código de Barras"
description: "Las preguntas de código de barras escanean y capturan códigos QR y datos de códigos de barras en su encuesta."
---

El tipo de pregunta `barcode` captura un valor de código escaneando un código QR o un código de barras con la cámara del dispositivo. El modal del escáner también incluye una entrada de texto manual como alternativa cuando el escaneo no es posible.

## Especificación Básica de XLSForm

| type    | name         | label                    |
|---------|--------------|--------------------------|
| barcode | product_code | Escanee el código de barras del producto |
| barcode | ticket_id    | Escanee el ticket          |

Para la especificación estándar, consulte la [documentación de XLSForm](https://xlsform.org/en/#question-types).

---

## Formatos soportados

rtSurvey soporta códigos QR y códigos de barras 1D estándar a través de la cámara del dispositivo, incluyendo:

- Código QR
- UPC-A, UPC-E
- EAN-8, EAN-13
- Código 39, Código 128
- ITF, Codabar

---

## Diseño por defecto

Si no se establece `appearance`, la pregunta renderiza un botón de ancho completo **"OBTENER CÓDIGO DE BARRAS"**. Al tocarlo, se abre el modal del escáner. Después de un escaneo exitoso, el botón cambia a **"REEMPLAZAR CÓDIGO DE BARRAS"** y el valor escaneado aparece debajo como un enlace clicable.

---

## Modal del escáner

El modal del escáner siempre incluye:
- **Vista de cámara en vivo** — escanea automáticamente al detectar; el modal se cierra después de un escaneo exitoso.
- **Entrada de texto manual** — un campo de texto en la parte inferior donde el enumerador puede escribir el código si el escaneo falla.
- **Botón "Hecho"** — envía el valor tecleado manualmente.

Cuando la cámara del dispositivo no está disponible, el modal recurre a una opción **"Subir una imagen"** — el enumerador puede enviar una foto del código de barras para su decodificación.

## Diseño de botón en línea

Añada `inline` para renderizar el escáner como un **botón de icono circular** junto a la etiqueta en lugar de un botón de ancho completo.

```
| type    | name | label     | appearance                              |
|---------|------|-----------|----------------------------------------|
| barcode | code | Escanear artículo | inline display{right}                  |
| barcode | code | Escanear artículo | inline display{left, large}            |
| barcode | code | Escanear artículo | inline display{center, large, <0099FF/>} |
```

**Posición del botón** — `left`, `right` *(por defecto)*, `top`, `center`, `bottom`

**Tamaño del botón** — `small` *(por defecto)*, `medium`, `large`

**Color del botón** — añada un color hexadecimal dentro de `display{}` para anular el color primario:

```
inline display{right, large, <FF5500/>}
```

**Control post-captura — `results{}`:**

| Appearance | Efecto |
|---|---|
| `results{hide(scanner)}` | Oculta el botón de escaneo después de capturar un valor |
| `results{hide(review)}` | Oculta el enlace del valor escaneado después de la captura |
| `results{hide(value)}` | Oculta la visualización del texto del valor escaneado |
| `results{left}` | Mueve el icono a la izquierda después de la captura |

Ejemplo — ocultar el escáner después del primer escaneo:
```
inline display{center, large} results{hide(scanner)}
```

## `inputs{auto-close(N)}` — cerrar automáticamente el escáner

Cierra automáticamente el modal del escáner después de `N` segundos si no se detecta ningún código de barras. Se muestra un temporizador de cuenta regresiva en vivo dentro del modal.

```
inputs{auto-close(10)}     → se cierra después de 10 segundos
inputs{auto-close(5)}      → se cierra después de 5 segundos
```

Combinar con inline:
```
inline display{right} inputs{auto-close(10)}
```

---

## `inputs{floating}` — escáner flotante arrastrable

Muestra un **botón de minimizar** (icono de comprimir ⊞) en el encabezado del modal del escáner. Al tocarlo, el escáner se colapsa a un pequeño icono circular flotante que se puede arrastrar a cualquier parte de la pantalla. Al tocar el icono flotante, se vuelve a abrir el escáner.

```
inputs{floating}
inline display{right} inputs{floating}
```

Útil en flujos de trabajo donde el enumerador necesita ver el formulario mientras el escáner está activo (por ejemplo, escanear elementos en una lista).

---

## `invisible auto-show` — auto-abrir escáner

Oculta el widget de la pregunta del diseño pero abre automáticamente el escáner cuando se carga la página. Útil para incrustar un paso de escaneo silencioso en el flujo del formulario.

```
invisible auto-show
inline invisible auto-show
```

---

## En grupos repetidos

Cuando `barcode` está dentro de un grupo `begin repeat`, un escaneo exitoso avanza automáticamente a la **siguiente instancia repetida** después de registrar el valor. Esto permite un escaneo secuencial rápido sin que el enumerador toque "Añadir" entre elementos.

---

## Suprimir la etiqueta

```
inline text-nolabel display{center, large}
```

## Mejores Prácticas

1. Use `inputs{auto-close(N)}` para evitar que el escáner permanezca abierto indefinidamente — elija un valor que dé a los enumeradores tiempo suficiente para posicionar el código de barras (8–15 segundos es típico).
2. Use `inputs{floating}` cuando el formulario necesite permanecer visible mientras se escanea (por ejemplo, escanear desde una lista donde el enumerador cruza referencias un campo visible).
3. Coloque la pregunta de código de barras dentro de un grupo repetido para un escaneo secuencial rápido — el avance automático de la repetición elimina el paso manual de "Añadir".
4. Incluya siempre la columna `hint` con instrucciones de posicionamiento (por ejemplo, "Mantenga el código de barras a una distancia de 10–30 cm de la cámara, con buena iluminación").
5. La entrada de texto manual en el modal del escáner siempre está disponible — entrene a los enumeradores para que la usen como alternativa para códigos de barras dañados o sucios.

## Limitaciones

- La precisión del escaneo depende de la calidad de la cámara, la iluminación y el estado del código de barras — los códigos dañados o de bajo contraste pueden no escanearse de forma fiable.
- El escáner utiliza la cámara trasera (orientada al entorno); los dispositivos sin cámara trasera recurren a la opción de carga de imagen.
- `invisible auto-show` solo se abre en la primera carga de la página; navegar de vuelta a la página no vuelve a activar la apertura automática.

---
title: "Geoshape"
description: "Las preguntas de geoshape permiten a los encuestados dibujar formas en un mapa, capturando datos geográficos complejos como parte de la encuesta."
---

El tipo de pregunta geoshape en XLSForms y rtSurvey permite a los encuestados dibujar formas (polígonos) en un mapa, capturando datos geográficos complejos. Esta función es particularmente útil para mapear áreas, definir límites o marcar regiones de interés en encuestas espaciales.

## Especificación básica de XLSForm

| type     | name        | label                             |
|----------|-------------|-----------------------------------|
| geoshape | field_area  | Dibujar el límite del campo       |

Para obtener más detalles sobre el tipo de pregunta geoshape básico, consulte la [especificación de XLSForm](https://xlsform.org/en/#question-types).

## Usos

Las preguntas de geoshape se usan comúnmente para:

1. Mapear límites de campos en encuestas agrícolas
2. Definir áreas de impacto ambiental
3. Marcar zonas en estudios de planificación urbana
4. Delinear regiones para encuestas geológicas
5. Capturar características geográficas complejas para análisis espacial

## Mejores prácticas

1. Asegúrese de que el dispositivo tenga los servicios de localización habilitados y los permisos otorgados.
2. Proporcione instrucciones claras sobre cómo dibujar la forma y qué área debe incluirse.
3. Considere usar imágenes satelitales o mapas base para ayudar a los encuestados a dibujar formas con precisión.
4. Sea consciente de la complejidad potencial de las formas y su impacto en el tamaño y procesamiento de datos.

## Ejemplo de uso

He aquí un ejemplo de cómo podría usar una pregunta de geoshape en una encuesta:

| type     | name           | label                                         | hint                                                      |
|----------|----------------|-----------------------------------------------|-----------------------------------------------------------|
| geoshape | forest_area    | Delinear el límite del parche de bosque       | Use al menos 3 puntos para crear una forma cerrada        |

## Extensiones de rtSurvey

Si bien la especificación básica de XLSForm para preguntas de geoshape es sencilla, rtSurvey puede ofrecer características o personalizaciones adicionales:

1. Integración con mapas sin conexión para áreas remotas
2. Opciones para establecer el número mínimo y máximo de puntos para la forma
3. Capacidad para editar o refinar formas después del dibujo inicial
4. Soporte para diferentes tipos de formas (p. ej., rectángulos, círculos) además de polígonos de forma libre

## Formato de datos

Los datos de geoshape se almacenan típicamente como una cadena de pares de coordenadas separados por espacios, encerrados entre paréntesis:

```
(lat1 lon1; lat2 lon2; lat3 lon3; ... latN lonN)
```

## Consideraciones para el análisis

Al usar preguntas de geoshape, considere:

1. Cómo se visualizarán y analizarán los datos geográficos (p. ej., software GIS)
2. La posible necesidad de limpieza o simplificación de datos de formas complejas
3. Medidas de privacidad y protección de datos para manejar datos espaciales detallados
4. Integración con otras fuentes de datos espaciales para análisis completo

## Limitaciones

- Dibujar formas precisas en pantallas móviles pequeñas puede ser un desafío.
- Las formas complejas pueden requerir una capacidad de almacenamiento y procesamiento significativa.
- Las preguntas de geoshape pueden no ser adecuadas para todos los tipos de encuestas o encuestados.
- Puede haber preocupaciones de privacidad asociadas con la recopilación de datos espaciales detallados.

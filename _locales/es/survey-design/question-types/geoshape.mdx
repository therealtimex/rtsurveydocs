---
title: "Geoshape"
description: "Las preguntas de Geoshape capturan un polígono cerrado definido por una secuencia de puntos GPS."
---

El tipo de pregunta `geoshape` captura un polígono cerrado: una serie de coordenadas GPS donde el primer y el último punto son iguales. En el formulario web de rtSurvey, esto se representa como una **entrada de texto** donde el encuestador ingresa o pega la cadena de coordenadas directamente.

## Especificación básica de XLSForm

| type     | name        | label                            |
|----------|-------------|----------------------------------|
| geoshape | field_area  | Dibuje el límite del campo       |
| geoshape | zone        | Registre el límite de la zona    |

Para la especificación estándar, consulte la [documentación de XLSForm](https://xlsform.org/en/#question-types).

---

## Formato de datos

Almacenado como una lista de puntos separados por puntos y coma **sin espacios alrededor de los puntos y coma**. Cada punto son cuatro valores separados por espacios:

```
lat lon alt acc;lat lon alt acc;lat lon alt acc;lat lon alt acc
```

| Component | Description |
|-----------|-------------|
| `lat` | Latitud en grados decimales |
| `lon` | Longitud en grados decimales |
| `alt` | Altitud en metros (`0` si se desconoce) |
| `acc` | Precisión del GPS en metros (`0` si se desconoce) |

**El polígono debe estar cerrado**: el último punto debe ser igual al primero.

**Ejemplo — un polígono de cuatro puntos (triángulo, cerrado):**
```
13.756331 100.501762 0 0;13.758000 100.503000 0 0;13.757000 100.506000 0 0;13.756331 100.501762 0 0
```

Se requiere un mínimo de tres puntos distintos más la repetición de cierre para formar un polígono válido.

---

## Cómo se representa en rtSurvey

En el formulario web de rtSurvey, `geoshape` se representa como un **campo de texto** simple. El encuestador escribe o pega la cadena de coordenadas. No hay un selector de mapa de polígono interactivo incorporado para este tipo en el formulario web actual.

### Recopilación interactiva de puntos de polígono

El patrón recomendado para la recopilación de campo es un **grupo de repetición de preguntas `geopoint`** —cada vértice utiliza el selector de mapa GPS completo— combinado con un `calculate` para producir la cadena geoshape:

| type | name | label | calculation |
|------|------|-------|-------------|
| begin repeat | polygon_points | Registre cada esquina | |
| geopoint | point | Toque para registrar la esquina | |
| end repeat | polygon_points | | |
| calculate | geoshape_value | | `join(';', ${polygon_points/point})` |

Después de unir, agregue el primer punto manualmente para cerrar el polígono, o use un segundo cálculo para concatenarlo.

## Ejemplo de uso

| type | name | label | hint | required |
|------|------|-------|------|----------|
| geoshape | farm_boundary | Registre el límite del campo | Ingrese todas las esquinas separadas por puntos y coma. El primer y el último punto deben ser iguales. | yes |

---

## Mejores prácticas

1. Utilice un grupo de repetición de preguntas `geopoint` para la recopilación interactiva basada en mapas y una los valores; esto les da a los encuestadores un selector GPS para cada vértice.
2. Cierre siempre el polígono (repita el primer punto al final) antes de enviar.
3. Incluya el formato esperado en la columna `hint` cuando se requiera la entrada manual de coordenadas.
4. Requiera al menos 3 puntos de esquina distintos para un polígono válido; imponga esto a través de instrucciones en lugar de restricciones de XLSForm.
5. Utilice `geopoint` para preguntas de una sola ubicación y `geoshape` solo cuando la demarcación del área sea el objetivo real de la encuesta.

## Limitaciones

- No hay un selector de mapa de polígono interactivo incorporado para `geoshape` en el formulario web de rtSurvey.
- El polígono debe cerrarse manualmente; no hay un mecanismo de cierre automático en el modo de entrada de texto.
- La validación de la topología del polígono (p. ej., no autoinsección, área mínima) requiere un procesamiento posterior fuera de las restricciones de XLSForm.
- Los límites largos con muchos vértices producen cadenas de texto grandes.

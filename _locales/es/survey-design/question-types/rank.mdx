---
title: "Clasificación"
description: "Las preguntas de clasificación permiten a los encuestados ordenar un conjunto de opciones por preferencia o prioridad."
---

El tipo de pregunta `rank` presenta una lista de opciones que el encuestado ordena por preferencia o prioridad. Almacena el resultado como una lista de valores de opción separados por espacios en orden clasificado, con la opción de mayor prioridad primero.

> **Formulario web de rtSurvey:** El widget de arrastrar para clasificar no está implementado actualmente. En el formulario web, `rank` se renderiza como una lista de selección. Utilice este tipo cuando se dirija a clientes móviles que admitan el widget de clasificación, o cuando el formato del valor almacenado sea más importante que la interacción de arrastrar para ordenar.

## Especificación básica de XLSForm

| type | name | label |
|------|------|-------|
| rank priorities | main_priority | Clasifique estas necesidades comunitarias de la más a la menos importante |

Las opciones se definen en la **hoja de cálculo de opciones** al igual que `select_one`:

**survey:**

| type | name | label |
|------|------|-------|
| rank priorities | main_priority | Clasifique estas necesidades de la más a la menos importante |

**choices:**

| list_name | name | label |
|-----------|------|-------|
| priorities | water | Agua limpia |
| priorities | health | Atención médica |
| priorities | education | Educación |
| priorities | roads | Carreteras |
| priorities | electricity | Electricidad |

## Formato del valor almacenado

El valor almacenado es una **lista separada por espacios** de valores de opción en orden clasificado (primero = mayor prioridad):

```
water education health roads electricity
```

## Extracción de posiciones clasificadas

Use `selected-at()` para obtener la opción en una clasificación específica:

| type | name | label | calculation |
|------|------|-------|-------------|
| rank priorities | main_priority | Clasificar necesidades comunitarias | |
| calculate | top_priority | | selected-at(`${main_priority}`, 0) |
| calculate | second_priority | | selected-at(`${main_priority}`, 1) |

`selected-at(${main_priority}, 0)` devuelve el valor colocado **primero** (índice 0 = clasificación superior).

## Uso de `rank-index()` con grupos repetidos

Cuando se utiliza `rank` dentro de un grupo repetido, `rank-index()` le permite referenciar el rango ordinal desde fuera de la repetición:

| type | name | label | calculation |
|------|------|-------|-------------|
| calculate | first_ranked | | rank-index(1, `${score}`) |

Consulte [Funciones — Funciones de campos repetidos](../operators-and-functions/functions#repeated-field-functions) para obtener todos los detalles sobre `rank-index()` y `rank-index-if()`.

## Usos

Las preguntas de clasificación se utilizan comúnmente para:

1.  **Clasificación de prioridades**: pedir a las comunidades que clasifiquen las necesidades de desarrollo.
2.  **Ordenación de preferencias**: clasificar las características del producto, los atributos del servicio o las opciones de política.
3.  **Ordenación de elementos de examen**: organizar los pasos de un proceso.
4.  **Selección de los N primeros**: combinado con `selected-at()` para extraer solo las 1, 2 o 3 opciones principales.

## Mejores prácticas

1.  Mantenga la lista corta (3 a 7 elementos); la clasificación se vuelve cognitivamente exigente más allá de las 7 u 8 opciones.
2.  Utilice etiquetas de opción claras y mutuamente excluyentes para evitar confusiones sobre lo que significa "primero".
3.  Agregue texto de pista que explique la dirección de la clasificación (por ejemplo, "Arrastre para ordenar: primero = más importante").
4.  Valide usando `count-selected(.) = x` si necesita asegurarse de que todas las opciones estén clasificadas.

## Limitaciones

-   El widget de arrastrar para clasificar no está implementado en el formulario web de rtSurvey.
-   No puede clasificar parcialmente; todas las opciones deben estar ordenadas.
-   Mantenga las listas de 3 a 7 elementos; las listas más largas se vuelven difíciles de manejar, independientemente del cliente.

El tipo de pregunta `calculate` ejecuta una fórmula silenciosamente en segundo plano. Almacena el resultado en un campo con nombre al que otras preguntas pueden hacer referencia, pero no muestra ninguna entrada ni etiqueta al encuestador. Úselo para derivar valores, concatenar cadenas, ejecutar lógica condicional o buscar datos que necesite más adelante en el formulario.

---

## Sintaxis básica

| type | name | label | calculation |
|------|------|-------|-------------|
| calculate | total | | `${price} * ${quantity}` |

- **type**: Siempre `calculate`.
- **name**: Un nombre de campo único. Otras preguntas hacen referencia a esto con `${name}`.
- **label**: Dejar en blanco; los campos de cálculo nunca se muestran al encuestador.
- **calculation**: La fórmula a evaluar. Admite todas las [funciones de XLSForm](../operators-and-functions/functions) y referencias a campos.

---

## Patrones comunes

### Aritmética

| type | name | label | calculation |
|------|------|-------|-------------|
| integer | price | Unit price | |
| integer | quantity | Quantity | |
| calculate | total | | `${price} * ${quantity}` |
| note | total_note | Total: `${total}` | |

### Concatenación de cadenas

| type | name | label | calculation |
|------|------|-------|-------------|
| text | first_name | First name | |
| text | last_name | Last name | |
| calculate | full_name | | `concat(${first_name}, ' ', ${last_name})` |

### Valor condicional

| type | name | label | calculation |
|------|------|-------|-------------|
| integer | score | Score (0–100) | |
| calculate | grade | | `if(${score} >= 90, 'A', if(${score} >= 75, 'B', if(${score} >= 60, 'C', 'F')))` |

### Edad a partir de la fecha de nacimiento

| type | name | label | calculation |
|------|------|-------|-------------|
| date | dob | Date of birth | |
| calculate | age_years | | `int((today() - ${dob}) div 365.25)` |

## Uso de `once()` para bloquear el valor

Por defecto, `calculate` se vuelve a evaluar cada vez que cambia cualquier campo al que se hace referencia. Envuelva la fórmula en `once()` para evaluarla solo en la primera carga y congelar el resultado:

| type | name | label | calculation |
|------|------|-------|-------------|
| calculate | interview_start | | `once(now())` |

Use `once()` para marcas de tiempo, valores iniciales o cualquier caso en el que no sea deseable recalcular al cambiar.

## Extracción de datos de fuentes externas

### De un archivo CSV

```
pulldata('staff.csv', 'department', 'name', ${staff_id})
```

Consulte [pulldata()](../operators-and-functions/pulldata) para obtener la referencia completa.

### De una base de datos SQLite integrada

```
pulldata('rawquery',
  concat(${family_path}, '/locations.db::provinces'),
  'SELECT name FROM provinces WHERE id = ?',
  ${province_id})
```

Consulte [Búsqueda en base de datos local](../advanced-features/local-database-search) para obtener detalles sobre la construcción de rutas.

### Del contexto de la aplicación

```
pulldata('app-api', 'user.username')
pulldata('app-api', 'family_path')
```

Consulte [App API](../app-api) para conocer todas las claves disponibles.

## Uso de calculate en relevant y constraint

Otros campos pueden hacer referencia a un resultado de `calculate` al igual que a cualquier campo:

| type | name | label | relevant | constraint |
|------|------|-------|----------|------------|
| calculate | bmi | | | `${weight} div (${height} * ${height}) * 10000` |
| note | bmi_warning | BMI is very high — please verify weight and height. | `${bmi} > 40` | |

## Mejores Prácticas

1. Asigne nombres significativos a los campos de cálculo: `total_cost` es más claro que `calc1` y más fácil de rastrear en las exportaciones.
2. Divida las fórmulas complejas en varios campos de cálculo encadenados en lugar de una expresión profundamente anidada.
3. Use `once()` para marcas de tiempo y capturas iniciales para evitar que los valores cambien después de la primera captura.
4. Coloque los campos `calculate` antes de la primera pregunta que haga referencia a ellos: el orden de evaluación sigue el orden del formulario.
5. Mantenga vacía la columna `label`. Algunas herramientas muestran la etiqueta; dejarla en blanco evita resultados confusos.

## Limitaciones

- Los campos de cálculo nunca se muestran directamente al encuestador; use un campo `note` para mostrar el resultado.
- La columna `calculation` es obligatoria; una fila `calculate` sin fórmula siempre almacena una cadena vacía.
- Los resultados se vuelven a evaluar en cada cambio de formulario a menos que estén envueltos en `once()`; las fórmulas muy complejas en formularios grandes pueden afectar el rendimiento de la representación en dispositivos de gama baja.
- Los valores calculados se almacenan como cadenas en el envío. Use `number()`, `int()` o `boolean()` para convertir el tipo al pasar el resultado a expresiones aritméticas o lógicas.

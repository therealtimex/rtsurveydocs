El tipo de pregunta `integer` recopila números enteros (sin decimales). Activa un teclado numérico en dispositivos móviles y bloquea la entrada de puntos decimales. Admite las mismas opciones de apariencia que el tipo `text` para el diseño y el formato.

## Especificación básica de XLSForm

| type | name | label |
|------|------|-------|
| integer | age | Edad del encuestado |
| integer | household_size | Número de personas en el hogar |

Para la especificación estándar, consulte la [documentación de XLSForm](https://xlsform.org/en/#question-types).

---

## Opciones de apariencia

### `number-hspinner` — selector horizontal

Reemplaza la entrada con un selector horizontal **− valor +**. Al tocar menos/más, se decrementa o incrementa el valor en 1 (o un paso personalizado).

```
number-hspinner
```

**Personalice la forma y el paso del botón** usando `hspinner()`:

```
number-hspinner hspinner('left-small-square','right-small-square','5')
```

Parámetros: forma del botón izquierdo, forma del botón derecho, valor del paso (por defecto `1` para entero).

**Colores personalizados** usando `colors()`:

```
number-hspinner colors(0099FF,FFFFFF,FF5500,FFFFFF)
```

Cuatro valores en orden: fondo del botón izquierdo, icono del botón izquierdo, fondo del botón derecho, icono del botón derecho.

---

### `thousandsep` — separador de miles

Formatea el número mostrado con agrupación de comas (por ejemplo, `1.234.567`). El número sin procesar se almacena sin comas. El tipo de entrada se cambia a `"text"` para permitir la visualización formateada.

```
thousandsep
```

---

### `digisep(n, "sep")` — agrupación de dígitos personalizada

Agrupa dígitos en bloques de `n` separados por un separador personalizado. Útil para identificaciones formateadas o códigos de referencia que son numéricos.

```
digisep(4,"-")      → 0912-3456-789
digisep(3," ")      → 012 345 678
```

El tipo de entrada se cambia a `"text"` cuando esta apariencia está activa.

---

### `textonly` — forzar teclado de texto

Fuerza `type="text"` en el elemento de entrada. Esto evita las peculiaridades de entrada de números del navegador (como ocultar ceros iniciales o agregar flechas de giro en los navegadores de escritorio) mientras se sigue recopilando un valor numérico.

```
textonly
```

---

### `floating_hint` — la pista flota como etiqueta

El texto `hint` se renderiza dentro de la entrada como un marcador de posición. Cuando el usuario comienza a escribir, la pista flota sobre el campo como una etiqueta.

```
floating_hint
```

---

### `embed` — pista dentro del límite de entrada

Similar a `floating_hint`: la pista se encuentra dentro del límite de entrada cuando está vacía. No flota cuando el usuario escribe.

```
embed
```

---

### `textpopup` — entrada de diálogo modal

Al tocar el campo, se abre un cuadro de diálogo modal con una entrada más grande en lugar de editar en línea. Útil en pantallas pequeñas donde una entrada de pantalla completa es más fácil.

```
textpopup
```

---

### `charcount` — contador de caracteres en vivo

Muestra un contador de caracteres `(n)` en vivo debajo de la entrada, actualizado a medida que el usuario escribe.

```
charcount
```

---

### `prefix(expr)` — anteponer un prefijo

Antepone una cadena estática o calculada al valor mostrado. El valor almacenado no incluye el prefijo.

```
prefix('Artículo #')        → muestra "Artículo #42", almacena "42"
prefix(${code_prefix})  → prefijo dinámico de otro campo
```

---

### `align_answer` — alineación del texto de entrada

Controla la alineación horizontal del valor escrito dentro de la entrada.

```
align_answer = left
align_answer = right
align_answer = center
```

---

### `inputs{qrscan}` — escaneo de QR / código de barras en el campo

Agrega un botón de escaneo de código QR junto a la entrada. Abre el escáner de la cámara y llena el campo con el valor numérico escaneado.

```
inputs{qrscan}
```

## Restricciones y validación

Utilice restricciones para aplicar rangos de valores. Las restricciones en la columna `constraint` se evalúan después de cada pulsación de botón en el modo `number-hspinner`, no solo al desenfocar.

| type | name | label | constraint | constraint_message |
|------|------|-------|------------|-------------------|
| integer | age | Edad | `. > 0 and . <= 120` | La edad debe estar entre 1 y 120 |
| integer | year | Año de construcción | `. >= 1800 and . <= 2100` | Ingrese un año válido |
| integer | count | Número de artículos | `. >= 0` | No puede ser negativo |

## Ejemplo — encuesta de hogares

| type | name | label | appearance | constraint | constraint_message |
|------|------|-------|------------|------------|-------------------|
| integer | household_size | Personas en el hogar | `number-hspinner` | `. >= 1 and . <= 30` | Debe estar entre 1 y 30 |
| integer | under_5 | Niños menores de 5 años | `number-hspinner` | `. >= 0 and . <= ${household_size}` | No puede exceder el tamaño del hogar |
| integer | year_built | Año de construcción de la casa | `textonly` | `. >= 1800 and . <= 2100` | Ingrese un año válido |

## Mejores prácticas

1.  Utilice `number-hspinner` para recuentos de rango pequeño donde hacer clic en ± es más rápido que escribir (por ejemplo, número de niños, puntuación en una escala de 1 a 10).
2.  Utilice `thousandsep` al mostrar números enteros grandes (población, ingresos) para que los encuestados puedan verificar la magnitud.
3.  Utilice `textonly` cuando los navegadores agreguen una interfaz de usuario de entrada de números no deseada (flechas de giro, desplazamiento táctil) que confunda a los encuestados.
4.  Aplique restricciones de rango en lugar de depender del tipo de teclado móvil; la aplicación del teclado no es universal.

## Limitaciones

-   La entrada de puntos decimales está bloqueada; si necesita valores fraccionarios, use el tipo `decimal`.
-   `number-hspinner` valida la `constraint` en cada pulsación de botón; evite restricciones costosas (por ejemplo, cadenas `if()` complejas) en el modo de selector.
-   `thousandsep` y `digisep()` almacenan el número sin procesar sin formato; no confíe en el valor de visualización formateado en los cálculos.

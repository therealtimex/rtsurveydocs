---
title: "Geotrace"
description: "Las preguntas Geotrace capturan una serie de puntos GPS que forman una línea o ruta."
---

El tipo de pregunta `geotrace` captura una secuencia de coordenadas geográficas que forman una línea o ruta (polilínea). En el formulario web de rtSurvey, esto se representa como una **entrada de texto** donde el encuestador (enumerador) ingresa o pega la cadena de coordenadas directamente.

## Especificación básica de XLSForm

| type     | name        | label                        |
|----------|-------------|------------------------------|
| geotrace | river_path  | Trazar la ruta del río |
| geotrace | road_route  | Registrar la ruta de la carretera |

Para la especificación estándar, consulte la [documentación de XLSForm](https://xlsform.org/en/#question-types).

---

## Formato de datos (Data Format)

Se almacena como una lista de puntos separados por punto y coma **sin espacios alrededor de los puntos y coma**. Cada punto consta de cuatro valores separados por espacios:

```
lat lon alt acc;lat lon alt acc;lat lon alt acc
```

| Component | Description |
|-----------|-------------|
| `lat` | Latitud en grados decimales |
| `lon` | Longitud en grados decimales |
| `alt` | Altitud en metros (`0` si se desconoce) |
| `acc` | Precisión del GPS en metros (`0` si se desconoce) |

**Ejemplo — una ruta de tres puntos:**
```
13.756331 100.501762 15 8;13.758000 100.503000 14 6;13.760000 100.505000 13 5
```

Se requiere un mínimo de dos puntos para formar una ruta válida.

---

## Cómo se representa en rtSurvey

In el formulario web de rtSurvey, `geotrace` se representa como un **campo de texto** simple. El encuestador escribe o pega la cadena de coordenadas. No hay un selector de mapas interactivo incorporado para este tipo en el formulario web actual.

### Recopilación de puntos de forma interactiva

El patrón recomendado para la recopilación de campo es un **grupo de repetición (repeat group) de preguntas `geopoint`** — cada punto utiliza el selector de mapas GPS completo — combinado con un `calculate` para producir la cadena geotrace:

| type | name | label | calculation |
|------|------|-------|-------------|
| begin repeat | path_points | Registrar cada punto de ruta | |
| geopoint | point | Tocar para registrar el punto | |
| end repeat | path_points | | |
| calculate | geotrace_value | | `join(';', ${path_points/point})` |

La cadena calculada se puede almacenar en una pregunta de `text` o utilizarse en `geotrace`.

## Ejemplo de uso

| type | name | label | hint | required |
|------|------|-------|------|----------|
| geotrace | farm_boundary_path | Registrar la ruta de acceso a la granja | Ingrese cada punto de ruta separado por punto y coma | yes |

---

## Mejores prácticas

1. Utilice un grupo de repetición de preguntas `geopoint` para la recopilación interactiva basada en mapas y luego una los valores; esto les da a los encuestadores un selector de GPS para cada punto individual.
2. Incluya el formato esperado en la columna `hint` cuando se requiera la entrada manual de coordenadas.
3. Valide la presencia con `required = yes` cuando la ruta sea obligatoria.
4. Planifique la limpieza de datos: las rutas ingresadas manualmente pueden tener una precisión inconsistente.

## Limitaciones (Limitations)

- No hay un selector de mapas interactivo incorporado para `geotrace` en el formulario web de rtSurvey.
- La cadena de coordenadas puede ser larga para rutas complejas; tenga esto en cuenta para el rendimiento del formulario y el almacenamiento.
- La validación de la topología de la ruta (por ejemplo, recuento mínimo de puntos, autointersección) requiere un procesamiento posterior fuera de las restricciones de XLSForm.

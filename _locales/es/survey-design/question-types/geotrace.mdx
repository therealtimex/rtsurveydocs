---
title: "Geotrace"
description: "Las preguntas de geotrace permiten a los encuestados capturar una serie de puntos conectados en un mapa, creando líneas o trayectos como parte de la encuesta."
---

El tipo de pregunta geotrace en XLSForms y rtSurvey permite a los encuestados capturar una serie de puntos conectados en un mapa, creando líneas o trayectos. Esta función es particularmente útil para mapear rutas, límites o características lineales en encuestas espaciales.

## Especificación básica de XLSForm

| type     | name        | label                          |
|----------|-------------|--------------------------------|
| geotrace | river_path  | Trazar el camino del río       |

Para obtener más detalles sobre el tipo de pregunta geotrace básico, consulte la [especificación de XLSForm](https://xlsform.org/en/#question-types).

## Usos

Las preguntas de geotrace se usan comúnmente para:

1. Mapear rutas o trayectos recorridos durante encuestas de campo
2. Trazar características lineales como carreteras, ríos o límites
3. Capturar la extensión de infraestructura lineal (p. ej., tuberías, líneas eléctricas)
4. Registrar trayectos de viaje en estudios de transporte
5. Definir transectos en encuestas ecológicas

## Mejores prácticas

1. Asegúrese de que el dispositivo tenga los servicios de localización habilitados y los permisos otorgados.
2. Proporcione instrucciones claras sobre cómo trazar el trayecto y qué características deben incluirse.
3. Considere usar imágenes satelitales o mapas base para ayudar a los encuestados a trazar trayectos con precisión.
4. Sea consciente de la complejidad potencial de los trazos y su impacto en el tamaño y procesamiento de datos.

## Ejemplo de uso

He aquí un ejemplo de cómo podría usar una pregunta de geotrace en una encuesta:

| type     | name           | label                                      | hint                                                        |
|----------|----------------|--------------------------------------------|------------------------------------------------------------|
| geotrace | hiking_trail   | Trazar el camino del sendero de senderismo | Comience en el inicio del sendero y termine en la cima     |

## Extensiones de rtSurvey

Si bien la especificación básica de XLSForm para preguntas de geotrace es sencilla, rtSurvey puede ofrecer características o personalizaciones adicionales:

1. Integración con mapas sin conexión para áreas remotas
2. Opciones para establecer el número mínimo y máximo de puntos para el trazo
3. Capacidad para editar o refinar trazos después del dibujo inicial
4. Soporte para trazado automático a intervalos establecidos durante el movimiento

## Formato de datos

Los datos de geotrace se almacenan típicamente como una cadena de pares de coordenadas separados por espacios, similar a geoshape pero sin el punto de cierre:

```
lat1 lon1; lat2 lon2; lat3 lon3; ... latN lonN
```

## Consideraciones para el análisis

Al usar preguntas de geotrace, considere:

1. Cómo se visualizarán y analizarán los datos geográficos (p. ej., software GIS)
2. La posible necesidad de limpieza o simplificación de datos de trazos complejos
3. Medidas de privacidad y protección de datos para manejar datos espaciales detallados
4. Integración con otras fuentes de datos espaciales para análisis completo

## Limitaciones

- Trazar trayectos precisos en pantallas móviles pequeñas puede ser un desafío.
- Los trazos complejos pueden requerir una capacidad de almacenamiento y procesamiento significativa.
- El uso continuo del GPS para trazado automático puede agotar rápidamente la batería del dispositivo.
- Puede haber preocupaciones de privacidad asociadas con la recopilación de datos de trayectos detallados.

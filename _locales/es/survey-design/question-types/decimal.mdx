title: "Decimal"
description: "Tipo de pregunta de entrada de número fraccional en rtSurvey"
---

El tipo de pregunta `decimal` recopila números que pueden incluir una parte fraccionaria (por ejemplo, `3.14`, `72.5`). Activa un teclado numérico en el móvil y admite las mismas opciones de apariencia que el tipo `text` para el diseño y el formato.

## Especificación Básica de XLSForm

| type | name | label |
|------|------|-------|
| decimal | weight_kg | Peso (kg) |
| decimal | height_m | Altura (m) |
| decimal | temperature | Temperatura corporal (°C) |

Para la especificación estándar, consulte la [documentación de XLSForm](https://xlsform.org/en/#question-types).

---

## Opciones de apariencia

### `number-hspinner` — selector horizontal

Reemplaza la entrada con un selector horizontal **− valor +**. Al tocar menos/más, se ajusta el valor según el paso configurado.

```
number-hspinner
```

El valor mostrado se formatea con un decimal (por ejemplo, `3.0`, `72.5`). El paso por defecto es `1`; use `hspinner()` para establecer un paso decimal.

**Personalizar la forma y el paso del botón** usando `hspinner()`:

```
number-hspinner hspinner('left-small-square','right-small-square','0.1')
```

Parámetros: forma del botón izquierdo, forma del botón derecho, valor del paso. Use un paso decimal como `0.5` o `0.1` para un control más preciso.

**Colores personalizados** usando `colors()`:

```
number-hspinner colors(0099FF,FFFFFF,FF5500,FFFFFF)
```

Cuatro valores en orden: fondo del botón izquierdo, icono del botón izquierdo, fondo del botón derecho, icono del botón derecho.

---

### `thousandsep` — separador de miles

Formatea el número mostrado con agrupamiento de comas (por ejemplo, `1,234.56`). El número original se almacena sin comas. El tipo de entrada se cambia a `"text"` para permitir la visualización formateada.

```
thousandsep
```

---

### `digisep(n, "sep")` — agrupamiento de dígitos personalizado

Agrupa los dígitos de la parte entera en bloques de `n` separados por un separador personalizado.

```
digisep(3," ")      → 1 234 567.89
```

El tipo de entrada se cambia a `"text"` cuando esta apariencia está activa.

---

### `textonly` — forzar teclado de texto

Fuerza `type="text"` en el elemento de entrada. Evita las peculiaridades de la entrada de números del navegador (ocultar ceros finales, flechas de giro de escritorio) mientras sigue aceptando valores decimales.

```
textonly
```

---

### `floating_hint` — la pista flota como etiqueta

El texto `hint` se renderiza dentro de la entrada como un marcador de posición. Cuando el usuario comienza a escribir, flota por encima del campo como una etiqueta.

```
floating_hint
```

---

### `embed` — pista dentro del límite de entrada

Similar a `floating_hint` — la pista se encuentra dentro del límite de entrada cuando está vacía. No flota cuando el usuario escribe.

```
embed
```

---

### `textpopup` — entrada de diálogo modal

Al tocar el campo, se abre un diálogo modal con una entrada más grande. Útil en pantallas pequeñas.

```
textpopup
```

---

### `charcount` — contador de caracteres en vivo

Muestra un contador de caracteres `(n)` en vivo debajo de la entrada, actualizado a medida que el usuario escribe.

```
charcount
```

---

### `prefix(expr)` — anteponer un prefijo

Antepone una cadena estática o calculada al valor mostrado. El valor almacenado no incluye el prefijo.

```
prefix('USD ')          → muestra "USD 72.50", almacena "72.50"
prefix(${currency})     → prefijo dinámico de otro campo
```

---

### `align_answer` — alineación del texto de entrada

Controla la alineación horizontal del valor escrito dentro de la entrada.

```
align_answer = left
align_answer = right
align_answer = center
```

---

### `inputs{qrscan}` — escaneo QR / código de barras en el campo

Añade un botón de escaneo de código QR junto a la entrada. Abre la cámara del escáner y rellena el campo con el valor escaneado.

```
inputs{qrscan}
```

## Restricciones y validación

| type | name | label | constraint | constraint_message |
|------|------|-------|------------|-------------------|
| decimal | weight | Peso (kg) | `. > 0 and . <= 500` | Introduzca un valor entre 0 y 500 |
| decimal | height | Altura (m) | `. > 0 and . <= 3` | Introduzca un valor entre 0 y 3 |
| decimal | temp | Temperatura (°C) | `. >= 35 and . <= 42` | Temperatura normal: 35°C–42°C |
| decimal | percentage | Porcentaje | `. >= 0 and . <= 100` | Introduzca un valor entre 0 y 100 |

## Ejemplo — formulario de medición

| type | name | label | appearance | constraint | constraint_message |
|------|------|-------|------------|------------|-------------------|
| decimal | weight_kg | Peso (kg) | `number-hspinner hspinner('left-small-square','right-small-square','0.5')` | `. > 0 and . <= 300` | Introduzca un peso válido |
| decimal | height_m | Altura (m) | `number-hspinner hspinner('left-small-square','right-small-square','0.01')` | `. > 0 and . <= 3` | Introduzca una altura válida |
| calculate | bmi | | | | |

Columna de cálculo de IMC:
```
${weight_kg} div (${height_m} * ${height_m})
```

## Mejores Prácticas

1. Use `number-hspinner hspinner(..., '0.1')` para mediciones que requieren una precisión decimal — el selector se auto-formatea a un decimal, manteniendo los valores consistentes.
2. Use `textonly` cuando los navegadores añaden controles de giro no deseados o truncan ceros finales (por ejemplo, `3.0` mostrado como `3`).
3. Use `thousandsep` para valores financieros grandes para que los encuestados puedan verificar que introdujeron la magnitud correcta.
4. Aplique restricciones de rango en lugar de depender únicamente del tipo de teclado móvil.

## Limitaciones

- El selector siempre muestra un decimal — si necesita más precisión en el valor mostrado, use la entrada simple en su lugar.
- `thousandsep` y `digisep()` almacenan el número original — no lea el valor formateado en los cálculos.

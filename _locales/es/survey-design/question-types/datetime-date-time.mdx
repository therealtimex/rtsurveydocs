---
title: "Fecha y hora, fecha, hora"
description: "Las preguntas de fecha y hora permiten a los encuestados introducir tanto la fecha como la hora en un solo campo."
---

Los tipos de pregunta `date`, `time` y `datetime` capturan valores de fecha y/o hora. rtSurvey los renderiza con varios modos de diseño controlados por la columna `appearance`.

## Especificación Básica de XLSForm

| type     | name           | label                     |
|----------|----------------|---------------------------|
| date     | birth_date     | Fecha de nacimiento       |
| time     | start_time     | ¿A qué hora empezó?       |
| datetime | event_datetime | ¿Cuándo ocurrió el evento? |

Para la especificación estándar, consulte la [documentación de XLSForm](https://xlsform.org/en/#question-types).

## Modos de diseño

### Por defecto — calendario siempre abierto

No se necesita ningún valor en `appearance`. El calendario (y el reloj para `time`/`datetime`) se renderiza directamente en la página — siempre visible, no se requiere ningún botón.

| type | name       | label         | appearance |
|------|------------|---------------|------------|
| date | start_date | Fecha de visita |            |

---

### `inline` — botón circular → modal

Un botón de icono circular (calendario o reloj) flota junto a la etiqueta de la pregunta. Al tocarlo, se abre un modal con el selector. Después de la selección, el valor elegido aparece como texto junto a la etiqueta.

- Fondo del botón: color principal del tema (se puede sobrescribir)
- Forma del botón: círculo completo (`border-radius: 50%`)

```
| type | name       | label         | appearance |
|------|------------|---------------|------------|
| date | start_date | Fecha de visita | inline     |
```

---

### `inline-onlyresult` — el botón desaparece después de la selección

Igual que `inline`, pero el botón se oculta una vez que se selecciona un valor. Útil cuando solo desea que la fecha sea visible después de haberla elegido, sin un icono persistente.

```
inline-onlyresult
```

---

### `inline-1line` — fila de selectores giratorios

Renderiza controles de selector giratorio individuales (▲ valor ▼) en una sola fila horizontal — una columna por componente. Para `date`: mes / día / año. Para `datetime`: mes / día / año / horas / minutos. Para `time`: horas / minutos.

No hay modal ni ventana emergente de calendario — el usuario desplaza cada selector giratorio de forma independiente.

```
inline-1line
```

**Mostrar solo componentes específicos** añadiendo los nombres de los componentes:

```
inline-1line month year      → oculta el selector de día
inline-1line year            → muestra solo el año
```

**Limitar el rango de años:**

```
inline-1line y_range(2000-2030)
```

---

### `box` — entrada de texto

Renderiza un campo de entrada de texto plano. El usuario escribe la fecha directamente usando el formato definido en `appearance`.

```
box(%d/%m/%Y)       → DD/MM/YYYY
box(%Y-%m-%d)       → AAAA-MM-DD
```

---

### `month-year` — solo mes y año

`appearance` estándar de XLSForm. El selector comienza en la vista de año; el usuario selecciona el mes y el año, pero no un día específico.

```
month-year
```

---

### `year` — solo año

`appearance` estándar de XLSForm. El selector comienza en la vista de década; solo se puede seleccionar el año.

```
year
```

---

## Formato de visualización personalizado

Añada `-[formato]` a cualquier `inline` `appearance` para controlar cómo se muestra el valor seleccionado como texto. Utiliza tokens estilo `strftime`.

| Token | Significado | Ejemplo |
|-------|-------------|---------|
| `%d`  | Día (con cero inicial) | 07 |
| `%e`  | Día (sin relleno) | 7 |
| `%m`  | Número de mes | 04 |
| `%n`  | Número de mes (sin relleno) | 4 |
| `%b`  | Abreviatura de mes | Abr |
| `%Y`  | Año de 4 dígitos | 2026 |
| `%y`  | Año de 2 dígitos | 26 |
| `%H`  | Hora (24h) | 14 |
| `%h`  | Hora (sin relleno) | 14 |
| `%M`  | Minuto | 05 |
| `%S`  | Segundo | 00 |
| `%a`  | Abreviatura del día de la semana | Mié |

**Ejemplos:**

```
inline-[%d/%m/%Y]            → 07/04/2026
inline-[%d %b %Y]            → 07 Abr 2026
inline-1line-[%Y-%m-%d]      → entrada del selector giratorio, visualización formateada
inline-[%d/%m/%Y %H:%M]      → 07/04/2026 14:30
```

---

## Personalización del color

Sobrescriba el color del botón de icono usando `colors()`:

```
inline colors("0099FF")                   → fondo del botón #0099FF
inline colors("0099FF","FFFFFF")          → fondo #0099FF, color del icono #FFFFFF
inline-1line colors("0000FF","FFFF00")    → colores de acento del selector giratorio
inline-onlyresult colors("E53935")        → botón rojo
```

---

## Posición del botón con `display{}`

El modificador `display{}` controla dónde aparece el botón de icono en relación con la etiqueta de la pregunta. Se aplica a `inline` y `inline-onlyresult`.

```
display{<alineación>, <tamaño>, <color>}
```

| Parámetro | Valores | Por defecto |
|-----------|--------|-------------|
| Alineación | `left`, `right`, `top`, `center`, `bottom` | `right` |
| Tamaño | `small`, `medium`, `large` | `small` |
| Color | hex ej. `#FF5500` | color principal del tema |

**Comportamiento de alineación:**

| Valor | Diseño |
|-------|--------|
| `right` | Botón a la derecha de la etiqueta |
| `left` | Botón a la izquierda de la etiqueta |
| `top` | Botón encima de la etiqueta, centrado a ancho completo |
| `center` / `bottom` | Botón debajo de la etiqueta, centrado a ancho completo |

**Ejemplos:**

```
inline display{left}
inline display{center, large}
inline display{right, medium, #E53935}
inline-onlyresult display{bottom, large, #0099FF}
```

## Restricción de rango de fechas

Use `inputs{range[...]}` para restringir las fechas seleccionables.

```
inputs{range[dateGt(2024-01-01), dateLt(2024-12-31)]}
```

Parámetros dentro de `range[...]`:

| Parámetro | Descripción |
|-----------|-------------|
| `dateGt(YYYY-MM-DD)` | Fecha mínima seleccionable (mayor o igual) |
| `dateLt(YYYY-MM-DD)` | Fecha máxima seleccionable (menor o igual) |
| `indayTimeGt(HH:MM:SS)` | Hora mínima dentro de un día (solo datetime) |
| `indayTimeLt(HH:MM:SS)` | Hora máxima dentro de un día (solo datetime) |

Se pueden definir múltiples rangos — una fecha es seleccionable si cae dentro de **cualquiera** de los rangos.

---

## Suprimir la etiqueta

Añada `text-nolabel` para ocultar la etiqueta de la pregunta. El botón se renderiza solo.

```
inline text-nolabel display{center, large}
```

## Resumen del diseño

| Appearance | Widget renderizado | Color personalizable |
|---|---|---|
| *(ninguno)* | Calendario siempre abierto | No |
| `inline` | Botón circular → calendario modal | Sí |
| `inline-onlyresult` | Botón circular → modal, se oculta después de la selección | Sí |
| `inline-1line` | Fila de selectores giratorios | Sí |
| `box(%formato%)` | Campo de entrada de texto | No |
| `month-year` | Selector de mes/año | No |
| `year` | Selector solo de año | No |

## Ejemplo de uso

```
| type     | name        | label              | appearance                              |
|----------|-------------|--------------------|-----------------------------------------|
| date     | visit_date  | Fecha de visita    | inline display{right} -[%d/%m/%Y]       |
| date     | birth_date  | Fecha de nacimiento | inline-1line y_range(1940-2026)         |
| time     | start_time  | Hora de inicio     | inline-1line                            |
| datetime | event_time  | Fecha y hora del evento | inline display{center, large} -[%d/%m/%Y %H:%M] |
| date     | report_date | Fecha de informe   | box(%d/%m/%Y)                           |
```

## Mejores Prácticas

1. Use `inline` para formularios compactos — ahorra espacio vertical en comparación con el calendario siempre abierto.
2. Use `inline-1line` cuando los encuestados necesiten ajustar componentes de fecha individuales (por ejemplo, año de nacimiento).
3. Use `box()` solo cuando confíe en que el enumerador escribirá las fechas correctamente — no se muestra ninguna interfaz de usuario de validación.
4. Use `display{center, large}` para hacer el botón más prominente en pantallas móviles.
5. Especifique siempre `-[formato]` cuando la visualización predeterminada `YYYY-MM-DD` pueda confundir a los usuarios locales.
6. Tenga en cuenta las zonas horarias al recopilar datos de fecha y hora en diferentes regiones.

## Limitaciones

- `inline-1line` siempre toma por defecto la fecha actual si no existe ningún valor — use la columna `default` para prellenar una fecha específica.
- El formato `box()` solo controla la visualización; el valor almacenado siempre es ISO 8601.
- La restricción de rango de fechas (`inputs{range[...]}`) no funciona con el diseño `box`.
- Las diferencias de zona horaria pueden complicar el análisis de datos si no se tienen en cuenta adecuadamente.

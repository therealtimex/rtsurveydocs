# Gestión de usuarios del sistema

El módulo de **Usuario del sistema** (`/cpms/cpmsSystemUser/admin`) es una interfaz de gestión integral para controlar quién tiene acceso a su plataforma de Encuesta en Tiempo Real (RT-CPMS) y qué acciones pueden realizar.

![Interfaz de usuario del sistema](/images/system_user.png)

## Enfoque de gestión unificado

En RT-CPMS, un **Encuestador** es simplemente un rol específico asignado a un Usuario del sistema. No existe una base de datos separada de "Encuestadores". Ya sea que un usuario sea un Administrador de alto nivel que monitorea el portal web o un Encuestador de campo que recopila datos a través de la aplicación móvil, todos se gestionan dentro de este marco único y unificado.

## Características principales

### 1. Directorio de usuarios y vista de cuadrícula
La interfaz principal muestra una lista paginada de todos los usuarios conectados al espacio de trabajo. Los atributos clave incluyen:
* **ID y nombre de la organización**: Agrupación lógica de usuarios bajo entidades organizativas específicas (p. ej., `rta`, `partner_org`).
* **Rol**: Especifica el nivel de permiso del usuario (p. ej., `Administrator`, `Leadteam`, `Enumerator`).
* **Grupo**: Asignaciones de agrupación espacial o lógica (p. ej., distritos específicos o equipos operativos).
* **Está sincronizado**: Indica si la cuenta está integrada correctamente con el sistema central de Inicio de sesión único (SSO).
* **Estado**: Indicadores visuales que confirman si una cuenta está `Activa`, `Inactiva`, `Eliminada` o `Bloqueada`.

**Acciones globales:**
* **Agregar usuario del sistema**: Cree manualmente un perfil individual.
* **Importar usuario del sistema**: Cargue cuentas en masa usando una plantilla de Excel. Puede resolver conflictos usando los modos `Omitir` o `Reemplazar` y sincronizar directamente con el SSO.
* **Eliminación masiva**: Soporte de selección múltiple para la eliminación masiva de cuentas.

### 2. Control de acceso y seguridad
Al crear o editar un perfil de usuario, hay varios campos críticos de seguridad y flujo de trabajo disponibles:
* **Código de usuario**: Un identificador único que vincula la cuenta local de CPMS con el repositorio central de SSO.
* **Código de cambio de dispositivo**: Un token de seguridad robusto requerido cuando un encuestador necesita cambiar el dispositivo móvil que está usando para la recopilación de datos.
* **Nivel de poder**: Una escala de prioridad/acceso granular que va de 0 (más bajo) a 20 (más alto).
* **Alternancia de supervisión**: Una casilla de verificación que eleva instantáneamente a un usuario estándar al estado de gestión.
* **Automatización del flujo de trabajo**: Una opción para "Aprobar automáticamente la Solicitud de edición", que agiliza el proceso de limpieza y verificación de datos para usuarios de confianza.

### 3. Gestión de códigos (Incorporación automatizada)
Se encuentra en la subpestaña "Código" y gestiona enlaces de registro e invitación basados en hash, agilizando el proceso de incorporación para equipos grandes.

* **Registro vs. Invitación**: Elija si los usuarios pueden autoregistrarse usando un enlace distribuido o si requieren una invitación directa del administrador.
* **Fechas de vencimiento**: Restrinja la incorporación a ventanas de tiempo específicas.
* **Límites de uso**: Limite el número de usuarios que pueden unirse usando un único código generado.
* **Roles preasignados**: Los usuarios que se unan a través de estos códigos heredarán automáticamente el rol y el nivel de poder predefinidos, asegurando que estén listos para trabajar de inmediato sin intervención manual del administrador.

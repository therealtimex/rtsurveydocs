rtCloud es el robusto componente de servidor del ecosistema rtSurvey, diseñado para agilizar la recopilación, gestión y análisis de datos. Como centro central de las operaciones de rtSurvey, rtCloud ofrece un conjunto completo de características para apoyar proyectos de encuestas complejos y estudios longitudinales.

## Características principales

### Gestión de proyectos
- Organice todos los aspectos de su proyecto de encuesta en un solo lugar
- Gestione roles de usuario, formularios, análisis, entregables y permisos dentro de cada proyecto

### Gestión de usuarios y seguridad
- Cree y gestione cuentas de usuario con permisos basados en roles
- Garantice la seguridad de los datos y el control de acceso en cada nivel

### Gestión de formularios
- Suba y gestione XLSForms directamente
- Soporte para actualizaciones de versiones de formularios, incluidos ajustes menores y cambios estructurales
- Adjunte multimedia o datos adicionales a los formularios
- Capacidad de eliminación real de formularios para un control completo sobre sus instrumentos de encuesta

### Recopilación de datos y gestión de envíos
- Integración perfecta con la aplicación móvil rtSurvey, la aplicación web y el formulario web
- Soporte tanto para envíos de usuarios autenticados como para enlaces públicos anónimos
- Gestión de multimedia e archivos adjuntos de datos de envíos
- Vista previa interactiva en tabla de los datos de envío para obtener información rápida

### Flujos de trabajo de envío avanzados
- Devolver envíos a los dispositivos de los usuarios para mayor edición o verificación
- Reenviar envíos a otros dispositivos, habilitando flujos de trabajo colaborativos y control de calidad

### Gestión de datos longitudinales
- Gestionar eficientemente medidas repetidas y estudios a largo plazo
- Rastrear cambios y actualizaciones en los datos de los participantes a lo largo del tiempo

### Conectividad flexible
- Permitir que la aplicación móvil rtSurvey se conecte para descargar formularios y cargar envíos
- Soporte de recopilación de datos sin conexión con sincronización sin interrupciones cuando se restaura la conectividad

## Cómo se destaca rtCloud

Aunque inspirado en otras plataformas de recopilación de datos, rtCloud ofrece características únicas que lo diferencian:

1. **Eliminación real de formularios**: A diferencia de algunas plataformas, rtCloud permite la eliminación completa de formularios cuando es necesario.

2. **Flujos de trabajo de envío flexibles**: La capacidad de devolver y reenviar envíos permite procesos complejos de revisión de datos y control de calidad.

3. **Gestión de proyectos integrada**: rtCloud va más allá de la gestión de formularios y datos, ofreciendo herramientas para organizar todos los aspectos de su proyecto de encuesta.

4. **Soporte directo de XLSForm**: Suba sus XLSForms directamente sin conversión, agilizando el proceso de creación de formularios.

5. **Sistema de permisos integral**: Control detallado sobre el acceso y las capacidades de los usuarios dentro de los proyectos.

## Primeros pasos con rtCloud

Para comenzar a usar rtCloud para sus proyectos de encuesta:

1. Configure su servidor rtCloud o contacte a rtSurvey para obtener soluciones de alojamiento.
2. Cree su primer proyecto e invite a los miembros del equipo.
3. Suba sus XLSForms y configure sus flujos de trabajo de recopilación de datos.
4. Conecte sus aplicaciones móviles rtSurvey y comience a recopilar datos.

rtCloud capacita a investigadores, organizaciones y equipos de recopilación de datos para gestionar proyectos de encuestas complejos con facilidad, seguridad y flexibilidad. Ya sea que esté realizando una encuesta única o un estudio longitudinal de varios años, rtCloud le proporciona las herramientas que necesita para tener éxito.

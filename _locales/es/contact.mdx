# Contáctenos

## General y Soporte

Envíenos un correo electrónico a **[support@rta.vn](mailto:support@rta.vn)** para preguntas, ayuda con el despliegue o cualquier otra cosa.

Para errores técnicos y solicitudes de funciones, utilice [GitHub Issues](https://github.com/therealtimex/rtsurvey/issues) para que la comunidad pueda beneficiarse del debate.

---

## Empresas y Asociaciones

¿Necesita un despliegue personalizado, soporte SLA o asistencia de integración? Visite **[rtsurvey.com](https://rtsurvey.com)** o envíenos un correo electrónico directamente.

---

## Seguridad

Por favor, **no** abra GitHub Issues públicos para vulnerabilidades de seguridad. Contáctenos de forma privada en [support@rta.vn](mailto:support@rta.vn) con el asunto `[Security]`.

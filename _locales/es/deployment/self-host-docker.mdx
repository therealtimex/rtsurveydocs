description: "Ejecute rtSurvey en cualquier servidor usando la imagen Docker pública — no se requieren scripts de nube."
---

import { Callout, Steps } from 'nextra/components'

Use esta guía si desea ejecutar rtSurvey en su propio servidor (VPS, bare metal o máquina local) usando la imagen Docker pública `rtawebteam/rtcloud:survey-public`.

**No se requiere inicio de sesión en Docker Hub** — la imagen es pública.

El contenedor incluye todo en una sola imagen:
- Apache + PHP (servidor de aplicaciones)
- Shiny Server (paneles de análisis, puerto 3838)
- Beanstalkd (cola de trabajos en segundo plano)

---

## Requisitos

### Servidor

| Recurso | Mínimo | Recomendado |
|---------|--------|-------------|
| RAM | 4 GB | 8 GB |
| Disco | 50 GB | 100 GB SSD |
| CPU | 2 vCPUs | 4 vCPUs |
| SO | Ubuntu 22.04 LTS | Ubuntu 22.04 LTS |

### Software

- **Docker Engine 24.0+** — [guía de instalación](https://docs.docker.com/engine/install/ubuntu/)
- **Docker Compose v2.0+** — incluido con Docker Desktop; en Linux: `apt install docker-compose-plugin`

## Configuración

<Steps>

### Crear un directorio de trabajo

```bash
mkdir -p /opt/rtsurvey && cd /opt/rtsurvey
```

### Crear `docker-compose.yml`

```yaml
services:
  mysql:
    image: mysql:8.0
    container_name: rtsurvey-mysql
    restart: unless-stopped
    command: >
      --default-authentication-plugin=mysql_native_password
      --character-set-server=utf8
      --collation-server=utf8_unicode_ci
      --sql-mode=NO_ENGINE_SUBSTITUTION
    environment:
      MYSQL_ROOT_PASSWORD: ${MYSQL_ROOT_PASSWORD}
      MYSQL_DATABASE: ${MYSQL_DATABASE:-smartsurvey}
      MYSQL_USER: ${MYSQL_USER:-smartsurvey}
      MYSQL_PASSWORD: ${MYSQL_PASSWORD}
      MYSQL_ROOT_HOST: '%'
    volumes:
      - mysql_data:/var/lib/mysql
    networks:
      - rtsurvey-net
    healthcheck:
      test: ["CMD-SHELL", "mysqladmin ping -h localhost -u root -p$$MYSQL_ROOT_PASSWORD"]
      interval: 10s
      timeout: 5s
      retries: 5
      start_period: 30s

  rtsurvey:
    image: rtawebteam/rtcloud:survey-public
    container_name: rtsurvey-app
    restart: unless-stopped
    entrypoint: ["/bin/entrypoint-production.sh"]
    depends_on:
      mysql:
        condition: service_healthy
    ports:
      - "${APP_PORT:-8080}:80"
      - "${SHINY_PORT:-3838}:3838"
    env_file:
      - .env
    volumes:
      - app_uploads:/var/www/html/smartsurvey/uploads
      - app_audios:/var/www/html/smartsurvey/audios
      - app_downloads:/var/www/html/smartsurvey/downloads
      - app_gallery:/var/www/html/smartsurvey/gallery
      - app_tmp:/var/www/html/smartsurvey/tmp
      - app_cache:/var/www/html/smartsurvey/cache
      - app_runtime:/var/www/html/smartsurvey/protected/runtime
      - app_assets:/var/www/html/smartsurvey/assets
      - app_aggregate:/var/www/html/smartsurvey/aggregate
    networks:
      - rtsurvey-net
    healthcheck:
      test: ["CMD", "curl", "-f", "http://localhost/health"]
      interval: 30s
      timeout: 10s
      retries: 3
      start_period: 90s

  # Optional: Embedded Keycloak SSO
  # Start with: docker compose --profile embed-keycloak up -d
  keycloak:
    image: quay.io/keycloak/keycloak:latest
    container_name: rtsurvey-keycloak
    restart: unless-stopped
    profiles:
      - embed-keycloak
    command: start --import-realm
    environment:
      KEYCLOAK_ADMIN: ${KEYCLOAK_ADMIN_USER:-admin}
      KEYCLOAK_ADMIN_PASSWORD: ${KEYCLOAK_ADMIN_PASSWORD}
      KC_HTTP_ENABLED: "true"
      KC_HTTP_RELATIVE_PATH: /auth
      KC_PROXY_HEADERS: xforwarded
      KC_HOSTNAME: ${KC_HOSTNAME}
      KC_HOSTNAME_STRICT: "false"
      KC_DB: mysql
      KC_DB_URL_DATABASE: ${KEYCLOAK_DB:-keycloak}
      KC_DB_URL_HOST: mysql
      KC_DB_USERNAME: ${KEYCLOAK_DB_USER:-keycloak}
      KC_DB_PASSWORD: ${KEYCLOAK_DB_PASSWORD}
    volumes:
      - ./keycloak-import:/opt/keycloak/data/import
    ports:
      - "${KEYCLOAK_PORT:-8091}:8080"
    depends_on:
      mysql:
        condition: service_healthy
    networks:
      - rtsurvey-net
    healthcheck:
      test: ["CMD-SHELL", "curl -f http://localhost:9000/health/ready || exit 1"]
      interval: 30s
      timeout: 10s
      retries: 10
      start_period: 120s

volumes:
  mysql_data:
  app_uploads:
  app_audios:
  app_downloads:
  app_gallery:
  app_tmp:
  app_cache:
  app_runtime:
  app_assets:
  app_aggregate:

networks:
  rtsurvey-net:
    driver: bridge
```

### Crear `.env`

```bash
# Project
PROJECT_ID=mysurvey
PROJECT_TYPE=rtsurvey
PROJECT_URL=your-server-ip-or-domain
HTTP_PROTOCOL=http
TZ=UTC

# Database
MYSQL_HOST=mysql
MYSQL_DATABASE=smartsurvey
MYSQL_USER=smartsurvey
MYSQL_ROOT_PASSWORD=change-this-root-password
MYSQL_PASSWORD=change-this-app-password

# Admin (set before first startup — cannot change via env after DB is created)
ADMIN_PASSWORD=change-this-admin-password

# Runtime
RUN_ENV=prod
RUN_MODE=admin
GII_ENABLED=false
CSRF_VALIDATION_ENABLED=true

# Ports (optional — defaults shown)
APP_PORT=8080
SHINY_PORT=3838
```

<Callout type="warning">
Cambie `MYSQL_ROOT_PASSWORD` y `MYSQL_PASSWORD` antes de iniciar. Use cadenas aleatorias seguras (32+ caracteres) en producción.
</Callout>

### Iniciar el stack

```bash
docker compose up -d
```

El primer inicio tarda aproximadamente 60–90 segundos — MySQL inicializa la base de datos en la primera ejecución.

### Verificar

```bash
# Check all containers are running
docker compose ps

# Check application health
curl http://localhost:8080/health
```

</Steps>

## Primer Inicio de Sesión

Una vez que pase el control de salud, abra su navegador:

```
http://your-server:8080/cpms/cpmsSite/login
```

| Campo | Valor |
|-------|-------|
| Nombre de usuario | `admin` |
| Contraseña | valor de `ADMIN_PASSWORD` en su `.env` (predeterminado: `admin`) |

<Callout type="warning">
Configure `ADMIN_PASSWORD` en su `.env` antes del primer inicio. El entrypoint lo establece en la primera ejecución — cambiarlo después de que se inicialice la base de datos no tiene efecto.
</Callout>

## Variables de Entorno

### Requeridas por el contenedor de la aplicación

El entrypoint se negará a iniciar si falta cualquiera de estas:

| Variable | Descripción |
|----------|-------------|
| `PROJECT_ID` | Identificador único para esta instancia (alfanumérico, sin espacios) |
| `PROJECT_URL` | Dominio o IP donde se accede a la aplicación (sin prefijo `http://`) |
| `MYSQL_HOST` | Hostname de MySQL — use el nombre del servicio Docker (p. ej. `mysql`) |
| `MYSQL_DATABASE` | Nombre de la base de datos |
| `MYSQL_PASSWORD` | Contraseña del usuario de la base de datos |

### Requeridas por el contenedor MySQL

| Variable | Descripción |
|----------|-------------|
| `MYSQL_ROOT_PASSWORD` | Contraseña root de MySQL (usada por el contenedor `mysql`, no por la aplicación) |

### Recomendadas

| Variable | Predeterminado | Descripción |
|----------|---------------|-------------|
| `MYSQL_USER` | `smartsurvey` | Nombre de usuario de la base de datos |
| `ADMIN_PASSWORD` | `admin` | Contraseña inicial del administrador — **configure antes del primer inicio**, no se puede cambiar vía env después de crear la BD |
| `HTTP_PROTOCOL` | `https` | Configure en `http` si no usa SSL |
| `PROJECT_PORT` | `80` | Puerto externo al que se conectan los usuarios (no el puerto Docker interno) |
| `PROJECT_TYPE` | `rtwork` | Tipo de plataforma — use `rtsurvey` para la plataforma de encuestas |
| `TZ` | `UTC` | Zona horaria (p. ej. `Asia/Bangkok`, `America/New_York`) |

### Tiempo de Ejecución

| Variable | Predeterminado | Descripción |
|----------|---------------|-------------|
| `RUN_ENV` | `prod` | Modo de entorno (`prod` o `dev`) |
| `RUN_MODE` | `admin` | Rol del servicio — use `admin` para configuración de servidor único |
| `GII_ENABLED` | `false` | Mantener `false` en producción (generador de código Yii) |
| `CSRF_VALIDATION_ENABLED` | `true` | Protección CSRF — mantener `true` |

### Licencia

| Variable | Predeterminado | Descripción |
|----------|---------------|-------------|
| `REQUIRE_LICENSE` | `false` | Configure en `true` para aplicar validación de licencia |
| `RTCLOUD_LICENSE_KEY` | — | Su clave de licencia — requerida cuando `REQUIRE_LICENSE=true` |

## Persistencia de Datos

Todos los datos de usuario se almacenan en volúmenes Docker con nombre. Sobreviven a reinicios de contenedores y actualizaciones de imagen.

| Volumen | Contenidos |
|---------|-----------|
| `mysql_data` | Base de datos (encuestas, usuarios, respuestas) |
| `app_uploads` | Archivos subidos desde encuestas |
| `app_gallery` | Biblioteca de medios |
| `app_downloads` | Archivos de exportación generados |
| `app_audios` | Grabaciones de audio |
| `app_runtime` | Archivos de sesión y caché de PHP |
| `app_aggregate` | Datos analíticos agregados |

## Operaciones Comunes

### Ver registros

```bash
docker compose logs -f rtsurvey
docker compose logs -f mysql
```

### Reiniciar la aplicación

```bash
docker compose restart rtsurvey
```

### Acceder a un shell

```bash
docker compose exec rtsurvey bash
```

### Ejecutar migraciones de base de datos manualmente

```bash
docker compose exec rtsurvey php /var/www/html/smartsurvey/protected/yiic migrate
```

## Actualizaciones

La imagen tiene la etiqueta `survey-public`. Para actualizar a la última versión:

```bash
docker compose pull
docker compose up -d
```

Las migraciones de base de datos se ejecutan automáticamente al iniciar a través del entrypoint de producción.

## Copia de Seguridad y Restauración

### Copia de seguridad de la base de datos

```bash
docker compose exec mysql \
  mysqldump -u root -p"${MYSQL_ROOT_PASSWORD}" smartsurvey \
  > backup-$(date +%Y%m%d).sql
```

### Restaurar la base de datos

```bash
docker compose exec -T mysql \
  mysql -u root -p"${MYSQL_ROOT_PASSWORD}" smartsurvey \
  < backup-20240101.sql
```

### Copia de seguridad de archivos subidos

```bash
docker run --rm \
  -v rtsurvey_app_uploads:/data \
  -v $(pwd):/backup \
  alpine tar czf /backup/uploads-$(date +%Y%m%d).tar.gz -C /data .
```

## Keycloak Integrado (SSO Opcional)

El archivo compose de producción incluye un contenedor Keycloak opcional para SSO. Comparte la misma instancia MySQL y se activa mediante un perfil de Docker Compose.

<Callout type="info">
Keycloak integrado requiere al menos **4 GB de RAM**. Es opcional — omítalo si no necesita SSO.
</Callout>

### Agregar variables de Keycloak a `.env`

```bash
# Keycloak admin
KEYCLOAK_ADMIN_USER=admin
KEYCLOAK_ADMIN_PASSWORD=change-this-keycloak-password

# Keycloak database (created automatically in the shared MySQL on first run)
KEYCLOAK_DB=keycloak
KEYCLOAK_DB_USER=keycloak
KEYCLOAK_DB_PASSWORD=change-this-keycloak-db-password

# KC_HOSTNAME: full public URL of your server (Keycloak appends /auth automatically)
KC_HOSTNAME=http://your-server:8091

# Port Keycloak listens on (host)
KEYCLOAK_PORT=8091

# Tell the rtCloud app to connect to embedded Keycloak
EMBED_KEYCLOAK=true
KEYCLOAK_URL=http://your-server:8091
KEYCLOAK_REALM=rtsurvey
KEYCLOAK_CLIENT_ID=rtsurvey
KEYCLOAK_CLIENT_SECRET=your-client-secret
```

El servicio `keycloak` ya está incluido en el `docker-compose.yml` anterior (bajo el perfil `embed-keycloak` — no iniciará a menos que use `--profile embed-keycloak`).

Cree el directorio de importación (Keycloak iniciará sin él pero el aprovisionamiento automático de realm no funcionará):

```bash
mkdir -p /opt/rtsurvey/keycloak-import
```

### Iniciar con Keycloak

```bash
docker compose --profile embed-keycloak up -d
```

Para iniciar sin Keycloak (predeterminado):

```bash
docker compose up -d
```

### Consola de administración de Keycloak

Una vez saludable, acceda a la UI de administración de Keycloak en:

```
http://your-server:8091/auth/admin
```

Inicie sesión con `KEYCLOAK_ADMIN_USER` / `KEYCLOAK_ADMIN_PASSWORD`.

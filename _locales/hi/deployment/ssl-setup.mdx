लॉग इन करने से पहले SSL कॉन्फ़िगर किया जाना चाहिए। जब आप पहली बार ऐप खोलते हैं, तो आपको स्वचालित रूप से SSL सेटअप स्क्रीन पर भेज दिया जाएगा।

---

## SSL सेटअप विकल्प

![SSL सेटअप विकल्प](/img/ssl-setup/ssl-setup-options.png)

तीन विकल्पों में से एक चुनें:

| विकल्प | कब उपयोग करें |
|--------|-------------|
| **मुफ़्त rtsurvey.com सबडोमेन** *(अनुशंसित)* | किसी DNS सेटअप की आवश्यकता नहीं है। हम आपके लिए रिकॉर्ड बनाते हैं। 2-5 मिनट में तैयार। |
| **मेरा अपना डोमेन** | आपके पास पहले से ही एक डोमेन है और उसका DNS इस सर्वर की ओर इंगित करता है। |
| **प्रमाण पत्र मैन्युअल रूप से इंस्टॉल करें** | एंटरप्राइज या कस्टम CA। SSH एक्सेस की आवश्यकता है। |

---

## विकल्प 1 — मुफ़्त rtsurvey.com सबडोमेन *(अनुशंसित)*

यह सबसे तेज़ विकल्प है। किसी डोमेन पंजीकरण या DNS परिवर्तन की आवश्यकता नहीं है।

![HTTPS सेटअप फॉर्म](/img/ssl-setup/ssl-setup-form.png)

> **जारी रखने से पहले:** एक मुफ़्त सबडोमेन के लिए [licenses.rtsurvey.com](https://licenses.rtsurvey.com) पर एक सक्रिय खाते की आवश्यकता होती है। मुफ़्त योजना में 1 सबडोमेन (`*.rtsurvey.com`) शामिल है।

1. अनुभाग का विस्तार करने के लिए **मुफ़्त rtsurvey.com सबडोमेन** पर क्लिक करें
2. **आपका सबडोमेन** (YOUR SUBDOMAIN) फ़ील्ड में अपना वांछित सबडोमेन नाम टाइप करें

   > छोटे अक्षरों, संख्याओं और हाइफ़न का उपयोग करें। 3-30 वर्ण।
   > उदाहरण: `myproject` → `myproject.rtsurvey.com`

3. [licenses.rtsurvey.com](https://licenses.rtsurvey.com) से अपना **rtSurvey DNS टोकन** टोकन फ़ील्ड में पेस्ट करें
4. **सुरक्षित सबडोमेन बनाएँ** (Create secure subdomain) पर क्लिक करें

एक बार सबमिट करने के बाद, ऐप आपका प्रमाणपत्र प्रावधान (provisioning) करना शुरू कर देगा:

![HTTPS सेटअप प्रगति](/img/ssl-setup/ssl-setup-progress.png)

चार चरण स्वचालित रूप से चलते हैं:
- **DNS रिकॉर्ड का अनुरोध करना** — आपके सबडोमेन के लिए DNS प्रविष्टि बनाता है
- **DNS प्रचार (propagate) की प्रतीक्षा करना** — आमतौर पर 2-5 मिनट
- **SSL प्रमाणपत्र जारी करना** — Let's Encrypt आपके प्रमाणपत्र पर हस्ताक्षर करता है
- **HTTPS को सक्रिय करना** — Nginx नए प्रमाणपत्र के साथ पुनः लोड होता है

5. एक बार पूरा हो जाने पर, आपको स्वचालित रूप से आपके नए HTTPS URL पर भेज दिया जाएगा।

## विकल्प 2 — मेरा अपना डोमेन

इसका उपयोग तब करें यदि आपके पास एक मौजूदा डोमेन है और उसका DNS `A` रिकॉर्ड पहले से ही इस सर्वर के IP की ओर इंगित करता है।

1. अनुभाग का विस्तार करने के लिए **मेरा अपना डोमेन** पर क्लिक करें
2. अपना पूरा डोमेन नाम दर्ज करें (जैसे `survey.myorganization.org`)
3. **प्रमाणपत्र बनाएँ** (Create certificate) पर क्लिक करें



Let's Encrypt आपके डोमेन को सत्यापित करेगा और प्रमाणपत्र जारी करेगा। इसके लिए पहले DNS को सही ढंग से इंगित करना आवश्यक है — अन्यथा अनुरोध विफल हो जाएगा।

## विकल्प 3 — प्रमाणपत्र मैन्युअल रूप से इंस्टॉल करें

कस्टम या आंतरिक CA का उपयोग करने वाले एंटरप्राइज परिवेशों के लिए। आप SSH के माध्यम से सर्वर पर अपनी प्रमाणपत्र फ़ाइलें रखेंगे, फिर ऐप में अपना डोमेन दर्ज करेंगे।

### पूर्व-आवश्यकताएं

- सर्वर तक SSH पहुंच
- आपके डोमेन के लिए एक वैध प्रमाणपत्र और निजी कुंजी (PEM प्रारूप)

### चरण 1 — सर्वर में SSH करें

```bash
ssh root@<server-ip>
```

### चरण 2 — अपनी प्रमाणपत्र फ़ाइलें रखें

निर्देशिका बनाएँ और अपनी फ़ाइलें कॉपी करें:

```bash
mkdir -p /etc/letsencrypt/live/<your-domain>
```

अपनी फ़ाइलों को उस निर्देशिका में इन सटीक नामों के साथ कॉपी करें:

| फ़ाइल | विवरण |
|------|-------------|
| `fullchain.pem` | आपका प्रमाणपत्र + कोई भी मध्यवर्ती (intermediate) CA प्रमाणपत्र (संयुक्त) |
| `privkey.pem` | आपकी निजी कुंजी |

उदाहरण:

```bash
# अपनी स्थानीय मशीन से कॉपी करें (इसे स्थानीय रूप से चलाएं, सर्वर पर नहीं)
scp fullchain.pem root@<server-ip>:/etc/letsencrypt/live/<your-domain>/fullchain.pem
scp privkey.pem  root@<server-ip>:/etc/letsencrypt/live/<your-domain>/privkey.pem
```

सही अनुमतियाँ सेट करें:

```bash
chmod 644 /etc/letsencrypt/live/<your-domain>/fullchain.pem
chmod 600 /etc/letsencrypt/live/<your-domain>/privkey.pem
```

### चरण 3 — ऐप में अपना डोमेन दर्ज करें



1. SSL सेटअप स्क्रीन में, **प्रमाण पत्र मैन्युअल रूप से इंस्टॉल करें** पर क्लिक करें
2. अपना डोमेन नाम दर्ज करें (प्रमाणपत्र के Common Name या SAN से मेल खाना चाहिए)
3. **लागू करें** (Apply) पर क्लिक करें

सर्वर आपके प्रमाणपत्र के साथ Nginx को कॉन्फ़िगर करेगा और स्वचालित रूप से पुनः लोड होगा।

यह पृष्ठ rtSurvey में रिपीट ग्रुप्स (repeat groups) के साथ काम करने के लिए उन्नत पैटर्न को कवर करता है। रिपीट ग्रुप सेट करने की मूल बातें जानने के लिए, [Grouping and Repeats](../repeats) देखें।

---

## डायनेमिक रिपीट काउंट (Dynamic repeat count)

डिफ़ॉल्ट रूप से, प्रगणक (enumerator) तय करता है कि कितनी बार रिपीट करना है। आप `repeat_count` का उपयोग करके दोहराव की संख्या तय कर सकते हैं:

| type | name | label | repeat_count |
|------|------|-------|--------------|
| begin_repeat | household_members | परिवार का सदस्य | `${num_members}` |
| text | member_name | सदस्य का नाम | |
| integer | member_age | आयु | |
| end_repeat | | | |

रिपीट ठीक `${num_members}` बार चलता है, जहाँ `num_members` फ़ॉर्म में पहले एकत्र किया गया था। प्रगणक इंस्टेंस जोड़ या हटा नहीं सकता है।

---

## अनुक्रमित एक्सेस (Indexed access): `indexed-repeat()`

`indexed-repeat(repeatedField, repeatGroup, index)` का उपयोग करके रिपीट ग्रुप के **बाहर** से एक विशिष्ट रिपीट इंस्टेंस के फ़ील्ड मान तक पहुँचें:

| type | name | label | calculation |
|------|------|-------|-------------|
| calculate | first_name | | `indexed-repeat(${member_name}, ${household_members}, 1)` |
| calculate | second_name | | `indexed-repeat(${member_name}, ${household_members}, 2)` |

यह सारांश फ़ील्ड बनाने या रिपीट के बाद "मुख्य" सदस्य के डेटा को संदर्भित करने के लिए उपयोगी है।

---

## वर्तमान इंस्टेंस की स्थिति (Current instance position): `index()`

एक रिपीट ग्रुप के अंदर, `index()` वर्तमान इंस्टेंस की स्थिति (1-आधारित) लौटाता है। प्रत्येक दोहराव को लेबल करने या विशिष्ट पहचानकर्ता बनाने के लिए इसका उपयोग करें:

| type | name | label |
|------|------|-------|
| begin_repeat | plots | प्लॉट |
| note | plot_label | प्लॉट नंबर `${index()}` |
| text | plot_id | प्लॉट आईडी |
| end_repeat | | |

---

## उसी इंस्टेंस में फ़ील्ड को संदर्भित करना

एक रिपीट के भीतर, **उसी रिपीट इंस्टेंस** में किसी अन्य फ़ील्ड को संदर्भित करने के लिए `${fieldname}` का उपयोग करें। उसी लूप के भीतर `indexed-repeat()` की कोई आवश्यकता नहीं है:

| type | name | label | relevant |
|------|------|-------|----------|
| begin_repeat | members | सदस्य | |
| text | member_name | नाम | |
| integer | member_age | आयु | |
| text | school_name | स्कूल का नाम | `${member_age} < 18` |
| end_repeat | | | |

---

## रिपीट के अंदर से पैरेंट फ़ील्ड को संदर्भित करना

रिपीट ग्रुप के बाहर (ऊपर) फ़ील्ड को सामान्य रूप से `${fieldname}` के साथ संदर्भित किया जा सकता है:

| type | name | label |
|------|------|-------|
| text | village | गाँव का नाम |
| begin_repeat | plots | कृषि प्लॉट |
| note | plot_context | `${village}` में प्लॉट |
| end_repeat | | |

---

## रिपीट डेटा का सारांश (Summarising repeat data)

सारांशित करने के लिए रिपीट ग्रुप के **बाहर** रिपीट एग्रीगेट फ़ंक्शंस का उपयोग करें:

| फ़ंक्शन | उदाहरण | विवरण |
|----------|---------|-------------|
| `count(group)` | `count(${household_members})` | इंस्टेंस की संख्या |
| `sum(field)` | `sum(${loan_amount})` | एक संख्यात्मक फ़ील्ड का योग |
| `min(field)` | `min(${member_age})` | न्यूनतम मान |
| `max(field)` | `max(${member_age})` | अधिकतम मान |
| `join(sep, field)` | `join(', ', ${member_name})` | अल्पविराम से अलग की गई सूची |
| `count-if(group, expr)` | `count-if(${members}, ${member_age} < 18)` | सशर्त गणना |
| `sum-if(field, expr)` | `sum-if(${loan_amount}, ${loan_amount} > 500)` | सशर्त योग |
| `join-if(sep, field, expr)` | `join-if(', ', ${name}, ${age} >= 18)` | सशर्त जुड़ाव |

### उदाहरण: परिवार का सारांश

| type | name | label | calculation |
|------|------|-------|-------------|
| integer | num_members | कितने सदस्य हैं? | |
| begin_repeat | members | सदस्य | `${num_members}` |
| text | member_name | नाम | |
| integer | member_age | आयु | |
| end_repeat | | | |
| calculate | total_members | | `count(${members})` |
| calculate | children_count | | `count-if(${members}, ${member_age} < 18)` |
| calculate | adult_names | | `join-if(', ', ${member_name}, ${member_age} >= 18)` |
| note | summary | `${total_members}` सदस्य; `${children_count}` 18 से कम। वयस्क: `${adult_names}` | |

## नेस्टेड रिपीट (Nested repeats)

एक रिपीट ग्रुप के अंदर दूसरा रिपीट ग्रुप हो सकता है। इसे सावधानी से उपयोग करें — नेस्टेड रिपीट जटिलता बढ़ाते हैं और प्रगणकों के लिए भ्रमित करने वाले हो सकते हैं।

| type | name | label |
|------|------|-------|
| begin_repeat | households | परिवार |
| text | hh_id | परिवार की आईडी |
| begin_repeat | hh_members | सदस्य |
| text | member_name | सदस्य का नाम |
| end_repeat | | |
| end_repeat | | |

इनर रिपीट से आउटर रिपीट में फ़ील्ड को संदर्भित करने के लिए, `${fieldname}` का उपयोग करें — यह निकटतम मेल खाने वाले पूर्वज (ancestor) तक पहुँचता है:

`hh_members` रिपीट के अंदर, `${hh_id}` **वर्तमान** परिवार की आईडी लौटाता है, सभी परिवारों की नहीं।

---

## रिपीट ग्रुप्स के अंदर रैंक (Rank): `rank-index()`

जब रिपीट के अंदर `rank` फ़ील्ड मौजूद हो, तो किसी विशिष्ट इंस्टेंस का ऑर्डिनल रैंक प्राप्त करने के लिए बाहर से `rank-index(instanceNumber, repeatedField)` का उपयोग करें:

| type | name | label | calculation |
|------|------|-------|-------------|
| calculate | top_scorer | | `rank-index(1, ${score})` |

`rank-index(1, ${score})` उच्चतम स्कोर वाले इंस्टेंस का इंडेक्स लौटाता है।

---

## `begin_repeat` पर `1screen` अपीयरेंस

`begin_repeat` रो की `appearance` कॉलम में `1screen` जोड़ने से प्रत्येक इंस्टेंस के लिए सभी प्रश्न प्रति स्क्रीन एक प्रश्न के बजाय एक ही स्क्रीन पर एक साथ प्रदर्शित होते हैं।

| type | name | label | appearance |
|------|------|-------|------------|
| begin_repeat | household_members | परिवार का सदस्य | `1screen` |
| text | member_name | सदस्य का नाम | |
| integer | member_age | आयु | |
| end_repeat | | | |

जब `1screen` सेट किया जाता है और ग्रुप के अंदर कोई `repeat_count` और कोई `add_repeat` फ़ील्ड नहीं होता है, तो rtSurvey स्वचालित रूप से स्क्रीन के नीचे एक गोलाकार **+** बटन रेंडर करता है ताकि प्रगणक बिना किसी अतिरिक्त कॉन्फ़िगरेशन के नए इंस्टेंस जोड़ सकें।

| अपीयरेंस | प्रति इंस्टेंस एक स्क्रीन | डिफ़ॉल्ट + बटन जोड़ा गया |
|------------|-------------------------|------------------------|
| `1screen` | हाँ | हाँ (जब कोई `add_repeat` चाइल्ड न हो) |
| `field-list` | हाँ | नहीं |

जब आप स्वचालित ऐड बटन के बिना समूहीकृत लेआउट चाहते हैं तो `field-list` का उपयोग करें। जब आप समूहीकृत लेआउट और इंस्टेंस जोड़ने का एक अंतर्निहित तरीका दोनों चाहते हैं तो `1screen` का उपयोग करें।

## `add_repeat` कस्टम ऐड बटन

`appearance: add_repeat` के साथ रिपीट ग्रुप के **अंदर** रखा गया `note` (या `text`) फ़ील्ड फ़ुल-विड्थ "Add" बटन के रूप में रेंडर होता है। बटन लेबल फ़ील्ड के `label` कॉलम से आता है। जब एक `add_repeat` फ़ील्ड मौजूद होता है, तो डिफ़ॉल्ट गोलाकार + बटन (`1screen` से) हटा दिया जाता है।

रिपीट ग्रुप के अंदर अंतिम फ़ील्ड के रूप में `add_repeat` फ़ील्ड रखें:

| type | name | label | appearance |
|------|------|-------|------------|
| begin_repeat | members | सदस्य | `1screen` |
| text | member_name | सदस्य का नाम | |
| integer | member_age | आयु | |
| note | btn_add | + सदस्य जोड़ें | `add_repeat` |
| end_repeat | | | |

### रंग अनुकूलन (Color customization)

बटन को स्टाइल करने के लिए अपीयरेंस मान के अंदर एक कलर कोड पास करें:

| अपीयरेंस मान | परिणाम |
|------------------|--------|
| `add_repeat <#04B404/>` | हरा बैकग्राउंड, डिफ़ॉल्ट टेक्स्ट कलर |
| `add_repeat 04B404-ffffff` | हरा बैकग्राउंड, सफेद टेक्स्ट |

पहला रंग बैकग्राउंड है और दूसरा (डैश के बाद) टेक्स्ट कलर है। डैश से अलग किए गए फ़ॉर्म का उपयोग करते समय `#` हटा दें।

### आइकन संस्करण (Icon variant)

फ़ुल-विड्थ बटन के बजाय एक कॉम्पैक्ट गोलाकार आइकन बटन रेंडर करने के लिए `add_repeat icon` (स्पेस के साथ) का उपयोग करें:

| type | name | label | appearance |
|------|------|-------|------------|
| note | btn_add | + जोड़ें | `add_repeat icon` |

## डिलीट बटन (Delete buttons): `delete-repeat-current` और `delete-repeat-last`

`appearance: delete-repeat-current` या `appearance: delete-repeat-last` के साथ रिपीट ग्रुप के अंदर एक `note` फ़ील्ड स्प्लिट डिलीट बटन के रूप में रेंडर होता है।

| अपीयरेंस | क्रिया |
|------------|--------|
| `delete-repeat-current` | वर्तमान (सक्रिय) इंस्टेंस को हटाता है |
| `delete-repeat-last` | रिपीट में अंतिम इंस्टेंस को हटाता है |

डिफ़ॉल्ट (नॉन-आइकन) बटन एक स्प्लिट बटन है: बाईं ओर एक ट्रैश आइकन और दाईं ओर फ़ील्ड का लेबल टेक्स्ट, जो स्क्रीन की पूरी चौड़ाई में फैला होता है।

### आइकन संस्करण (Icon variant)

एक कॉम्पैक्ट गोलाकार ट्रैश आइकन बटन प्राप्त करने के लिए `-icon` जोड़ें:

| अपीयरेंस | परिणाम |
|------------|--------|
| `delete-repeat-current-icon` | गोलाकार ट्रैश आइकन, वर्तमान इंस्टेंस को हटाता है |
| `delete-repeat-last-icon` | गोलाकार ट्रैश आइकन, अंतिम इंस्टेंस को हटाता है |

### रंग अनुकूलन (Color customization)

कलर फ़ॉर्मेट `add_repeat` के समान है: `<#RRGGBB/>` या `RRGGBB-RRGGBB` (बैकग्राउंड-टेक्स्ट) का उपयोग करें।

### पूर्ण पैटर्न उदाहरण

निम्नलिखित रिपीट `1screen`, शीर्ष पर एक गोलाकार डिलीट-करंट बटन, और नीचे एक फ़ुल-विड्थ ऐड बटन का उपयोग करता है:

| type | name | label | appearance |
|------|------|-------|------------|
| begin_repeat | members | सदस्य | `1screen` |
| note | btn_del | निकालें | `delete-repeat-current-icon` |
| text | member_name | सदस्य का नाम | |
| integer | member_age | आयु | |
| note | btn_add | + सदस्य जोड़ें | `add_repeat` |
| end_repeat | | | |

## सर्वोत्तम प्रथाएं (Best Practices)

1. हमेशा `repeat_count` का उपयोग करें जब दोहराव की संख्या पहले से ज्ञात हो — यह प्रगणकों को गलती से इंस्टेंस जोड़ने या हटाने से रोकता है।
2. रिपीट ग्रुप्स को केंद्रित रखें — प्रति इंस्टेंस 20+ प्रश्नों वाला रिपीट नेविगेट करना कठिन होता है।
3. रिपीट ग्रुप्स को स्पष्ट रूप से नाम दें (जैसे, `household_members`, न कि `repeat1`) — नाम फ़ंक्शन कॉल और निर्यात किए गए डेटा में दिखाई देता है।
4. प्रदर्शन को सत्यापित करने के लिए इंस्टेंस की अधिकतम अपेक्षित संख्या के साथ परीक्षण करें।
5. प्रति इंस्टेंस एक स्क्रीन पर सभी प्रश्नों को दिखाने के लिए `begin_repeat` पर `1screen` का उपयोग करें, प्रगणकों को स्पष्ट रूप से लेबल वाला "Add" बटन देने के लिए ग्रुप के अंदर एक `add_repeat` नोट फ़ील्ड के साथ।

## सीमाएं (Limitations)

- `indexed-repeat()` के लिए एक वैध इंडेक्स (1 से इंस्टेंस की संख्या) की आवश्यकता होती है — सीमा से बाहर के इंडेक्स खाली लौटते हैं।
- 2 स्तरों से आगे नेस्टेड रिपीट की अनुशंसा नहीं की जाती है और कुछ क्लाइंट्स पर डिस्प्ले समस्याएँ पैदा कर सकते हैं।
- एग्रीगेट फ़ंक्शंस (`sum`, `count`, आदि) पूरे रिपीट ग्रुप पर काम करते हैं — आप `*-if` संस्करणों के बिना इंस्टेंस के सबसेट को एग्रीगेट नहीं कर सकते।

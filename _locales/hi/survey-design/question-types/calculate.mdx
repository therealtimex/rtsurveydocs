`calculate` प्रश्न प्रकार पृष्ठभूमि में चुपचाप एक सूत्र चलाता है। यह परिणाम को एक नामित फ़ील्ड में संग्रहीत करता है जिसे अन्य प्रश्न संदर्भित कर सकते हैं — लेकिन यह प्रगणक को कोई इनपुट या लेबल नहीं दिखाता है। मान प्राप्त करने, स्ट्रिंग्स को जोड़ने, सशर्त तर्क चलाने, या डेटा देखने के लिए इसका उपयोग करें जिसकी आपको बाद में फ़ॉर्म में आवश्यकता होगी।

---

## मूल सिंटैक्स

| type | name | label | calculation |
|------|------|-------|-------------|
| calculate | total | | `${price} * ${quantity}` |

- **type**: हमेशा `calculate`|
- **name**: एक अद्वितीय फ़ील्ड नाम। अन्य प्रश्न `${name}` के साथ इसे संदर्भित करते हैं।
- **label**: खाली छोड़ दें — calculate फ़ील्ड प्रगणक को कभी नहीं दिखाए जाते हैं।
- **calculation**: मूल्यांकन करने के लिए सूत्र। सभी [XLSForm कार्यों](../operators-and-functions/functions) और फ़ील्ड संदर्भों का समर्थन करता है।

| calculate | total | | `${price} * ${quantity}` |

| type | name | label | calculation |
|------|------|-------|-------------|
| text | first_name | First name | |

| calculate | full_name | | `concat(${first_name}, ' ', ${last_name})` |

### सशर्त मान

| type | name | label | calculation |
|------|------|-------|-------------|
| integer | score | Score (0–100) | |
| calculate | grade | | `if(${score} >= 90, 'A', if(${score} >= 75, 'B', if(${score} >= 60, 'C', 'F')))` |

### जन्म तिथि से आयु

| type | name | label | calculation |
|------|------|-------|-------------|
| date | dob | Date of birth | |

## मान को लॉक करने के लिए `once()` का उपयोग करना

डिफ़ॉल्ट रूप से, जब भी कोई संदर्भित फ़ील्ड बदलता है, `calculate` पुनर्मूल्यांकन करता है। केवल पहले लोड पर मूल्यांकन करने और परिणाम को फ्रीज करने के लिए सूत्र को `once()` में लपेटें:

| type | name | label | calculation |
|------|------|-------|-------------|
| calculate | interview_start | | `once(now())` |

टाइमस्टैम्प, प्रारंभिक मान, या किसी भी मामले में `once()` का उपयोग करें जहां परिवर्तन पर पुनर्गणना अवांछनीय है।

---

## बाहरी स्रोतों से डेटा खींचना

### एक CSV फ़ाइल से

```
pulldata('staff.csv', 'department', 'name', ${staff_id})
```

पूर्ण संदर्भ के लिए [pulldata()](../operators-and-functions/pulldata) देखें।

### एक बंडल SQLite डेटाबेस से

```
pulldata('rawquery',
  concat(${family_path}, '/locations.db::provinces'),
  'SELECT name FROM provinces WHERE id = ?',
  ${province_id})
```

पथ निर्माण विवरण के लिए [स्थानीय डेटाबेस खोज](../advanced-features/local-database-search) देखें।

### ऐप संदर्भ से

```
pulldata('app-api', 'user.username')
pulldata('app-api', 'family_path')
```

सभी उपलब्ध कुंजियों के लिए [App API](../app-api) देखें।

## relevant और constraint में calculate का उपयोग करना

अन्य फ़ील्ड किसी भी फ़ील्ड की तरह `calculate` परिणाम को संदर्भित कर सकते हैं:

| type | name | label | relevant | constraint |
|------|------|-------|----------|------------|
| calculate | bmi | | | `${weight} div (${height} * ${height}) * 10000` |
| note | bmi_warning | BMI is very high — please verify weight and height. | `${bmi} > 40` | |

---

## सर्वोत्तम प्रथाएं

1. गणना फ़ील्ड को सार्थक नाम दें — `total_cost` `calc1` की तुलना में स्पष्ट है और निर्यात में ट्रेस करना आसान है।
2. एक गहरे नेस्टेड अभिव्यक्ति के बजाय जटिल सूत्रों को कई श्रृंखला गणना फ़ील्ड में तोड़ें।
3. पहले कैप्चर के बाद मानों को बदलने से रोकने के लिए टाइमस्टैम्प और प्रारंभिक स्नैपशॉट के लिए `once()` का उपयोग करें।
4. पहले प्रश्न से पहले `calculate` फ़ील्ड रखें जो उन्हें संदर्भित करता है — मूल्यांकन क्रम फ़ॉर्म क्रम का पालन करता है।
5. `label` कॉलम को खाली रखें। कुछ उपकरण लेबल प्रदर्शित करते हैं; इसे खाली छोड़ने से भ्रमित करने वाले आउटपुट से बचा जा सकता है।

## सीमाएं

- गणना फ़ील्ड प्रगणक को सीधे कभी प्रदर्शित नहीं होते हैं — परिणाम दिखाने के लिए `note` फ़ील्ड का उपयोग करें।
- `calculation` कॉलम आवश्यक है; बिना सूत्र वाली `calculate` पंक्ति हमेशा एक खाली स्ट्रिंग संग्रहीत करती है।
- परिणाम हर फ़ॉर्म परिवर्तन पर पुनर्मूल्यांकन करते हैं जब तक कि `once()` में लपेटे न गए हों — बड़े फ़ॉर्म में बहुत जटिल सूत्र लो-एंड डिवाइस पर रेंडरिंग प्रदर्शन को प्रभावित कर सकते हैं।
- गणना किए गए मान सबमिशन में स्ट्रिंग्स के रूप में संग्रहीत किए जाते हैं। अंकगणितीय या तर्क अभिव्यक्तियों में परिणाम पारित करते समय कास्ट करने के लिए `number()`, `int()`, या `boolean()` का उपयोग करें।

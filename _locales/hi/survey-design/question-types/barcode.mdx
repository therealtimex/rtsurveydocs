The `barcode` question type captures a code value by scanning a QR code or barcode with the device camera. The scanner modal also includes a manual text input as a fallback when scanning is not possible.

## मूल XLSForm विनिर्देश

| type    | name         | label                    |
|---------|--------------|--------------------------|
| barcode | product_code | उत्पाद बारकोड स्कैन करें |
| barcode | ticket_id    | टिकट स्कैन करें          |

मानक विनिर्देश के लिए [XLSForm दस्तावेज़](https://xlsform.org/en/#question-types) देखें।

---

## समर्थित प्रारूप

rtSurvey डिवाइस कैमरे के माध्यम से QR कोड और मानक 1D बारकोड का समर्थन करता है, जिसमें शामिल हैं:

- QR Code
- UPC-A, UPC-E
- EAN-8, EAN-13
- Code 39, Code 128
- ITF, Codabar

---

## डिफ़ॉल्ट लेआउट

कोई `appearance` सेट न होने पर, प्रश्न एक पूर्ण-चौड़ाई वाला **"बारकोड प्राप्त करें"** बटन प्रस्तुत करता है। इसे टैप करने से स्कैनर मोडल खुल जाता है। सफल स्कैन के बाद, बटन **"बारकोड बदलें"** में बदल जाता है और स्कैन किया गया मान नीचे एक क्लिक करने योग्य लिंक के रूप में दिखाई देता है।

---

## स्कैनर मोडल

स्कैनर मोडल में हमेशा शामिल होता है:
- **लाइव कैमरा दृश्य** — पहचान पर स्वचालित रूप से स्कैन करता है; सफल स्कैन के बाद मोडल बंद हो जाता है।
- **मैन्युअल टेक्स्ट इनपुट** — नीचे एक टेक्स्ट फ़ील्ड जहाँ प्रगणक स्कैनिंग विफल होने पर कोड टाइप कर सकता है।
- **पूर्ण बटन** — मैन्युअल रूप से टाइप किए गए मान को सबमिट करता है।

जब डिवाइस कैमरा अनुपलब्ध होता है, तो मोडल **"एक छवि अपलोड करें"** विकल्प पर वापस आ जाता है — प्रगणक डिकोडिंग के लिए बारकोड की एक तस्वीर सबमिट कर सकता है।

---

## इनलाइन बटन लेआउट

पूर्ण-चौड़ाई वाले बटन के बजाय लेबल के बगल में स्कैनर को **गोलाकार आइकन बटन** के रूप में प्रस्तुत करने के लिए `inline` जोड़ें।

```
| type    | name | label     | appearance                              |
|---------|------|-----------|----------------------------------------|
| barcode | code | आइटम स्कैन करें | inline display{right}                  |
| barcode | code | आइटम स्कैन करें | inline display{left, large}            |
| barcode | code | आइटम स्कैन करें | inline display{center, large, <0099FF/>} |
```

**बटन की स्थिति** — `left`, `right` *(डिफ़ॉल्ट)*, `top`, `center`, `bottom`

**बटन का आकार** — `small` *(डिफ़ॉल्ट)*, `medium`, `large`

**बटन का रंग** — प्राथमिक रंग को ओवरराइड करने के लिए `display{}` के अंदर एक हेक्स रंग जोड़ें:

```
inline display{right, large, <FF5500/>}
```

**कैप्चर के बाद नियंत्रण — `results{}`:**

| Appearance | प्रभाव |
|---|---|
| `results{hide(scanner)}` | मान कैप्चर होने के बाद स्कैन बटन को छिपाता है |
| `results{hide(review)}` | कैप्चर के बाद स्कैन किए गए मान लिंक को छिपाता है |
| `results{hide(value)}` | स्कैन किए गए मान टेक्स्ट डिस्प्ले को छिपाता है |
| `results{left}` | कैप्चर के बाद आइकन को बाईं ओर ले जाता है |

उदाहरण — पहले स्कैन के बाद स्कैनर छिपाएँ:
```
inline display{center, large} results{hide(scanner)}
```

## `inputs{auto-close(N)}` — स्कैनर को स्वतः बंद करें

`N` सेकंड के बाद स्कैनर मोडल को स्वचालित रूप से बंद कर देता है यदि कोई बारकोड नहीं पता चलता है। मोडल के अंदर एक लाइव उलटी गिनती टाइमर दिखाया जाता है।

```
inputs{auto-close(10)}     → 10 सेकंड के बाद बंद हो जाता है
inputs{auto-close(5)}      → 5 सेकंड के बाद बंद हो जाता है
```

इनलाइन के साथ संयोजन करें:
```
inline display{right} inputs{auto-close(10)}
```

---

## `inputs{floating}` — फ्लोटिंग ड्रैग करने योग्य स्कैनर

स्कैनर मोडल हेडर में एक **कम करें बटन** (संपीड़ित आइकन ⊞) दिखाता है। इसे टैप करने से स्कैनर एक छोटे फ्लोटिंग गोलाकार आइकन में सिकुड़ जाता है जिसे स्क्रीन पर कहीं भी खींचा जा सकता है। फ्लोटिंग आइकन को टैप करने से स्कैनर फिर से खुल जाता है।

```
inputs{floating}
inline display{right} inputs{floating}
```

उन वर्कफ़्लो में उपयोगी जहाँ प्रगणक को स्कैनर सक्रिय होने पर फॉर्म देखने की आवश्यकता होती है (उदाहरण के लिए, सूची में आइटम स्कैन करना)।

---

## `invisible auto-show` — स्कैनर को स्वतः खोलें

लेआउट से प्रश्न विजेट को छिपाता है लेकिन पृष्ठ लोड होने पर स्कैनर को स्वचालित रूप से खोलता है। फॉर्म प्रवाह में एक साइलेंट स्कैन चरण एम्बेड करने के लिए उपयोगी है।

```
invisible auto-show
inline invisible auto-show
```

---

## दोहराए जाने वाले समूहों में

जब `barcode` एक `begin repeat` समूह के अंदर होता है, तो एक सफल स्कैन मान रिकॉर्ड होने के बाद स्वचालित रूप से **अगली दोहराई गई इंस्टेंस** में आगे बढ़ जाता है। यह आइटम के बीच प्रगणक के "जोड़ें" टैप किए बिना तेजी से अनुक्रमिक स्कैनिंग को सक्षम बनाता है।

## सर्वोत्तम अभ्यास

1. स्कैनर को अनिश्चित काल तक खुला रहने से रोकने के लिए `inputs{auto-close(N)}` का उपयोग करें — एक ऐसा मान चुनें जो प्रगणकों को बारकोड को स्थिति में रखने के लिए पर्याप्त समय देता है (आमतौर पर 8-15 सेकंड)।
2. जब स्कैनिंग करते समय फॉर्म को दृश्यमान रहने की आवश्यकता हो (`inputs{floating}`) का उपयोग करें (उदाहरण के लिए, एक सूची से स्कैन करना जहाँ प्रगणक एक दृश्यमान फ़ील्ड को क्रॉस-रेफरेंस करता है)।
3. तीव्र अनुक्रमिक स्कैनिंग के लिए बारकोड प्रश्न को दोहराए जाने वाले समूह के अंदर रखें — स्वचालित दोहराव उन्नति मैन्युअल "जोड़ें" चरण को समाप्त करती है।
4. `hint` कॉलम को हमेशा स्थिति निर्धारण निर्देशों के साथ शामिल करें (उदाहरण के लिए, "बारकोड को कैमरे से 10-30 सेमी के भीतर, अच्छी रोशनी में पकड़ें")।
5. स्कैनर मोडल में मैन्युअल टेक्स्ट इनपुट हमेशा उपलब्ध होता है — प्रगणकों को क्षतिग्रस्त या गंदे बारकोड के लिए इसे एक फ़ॉलबैक के रूप में उपयोग करने के लिए प्रशिक्षित करें।

## सीमाएँ

- स्कैनिंग सटीकता कैमरे की गुणवत्ता, प्रकाश व्यवस्था और बारकोड की स्थिति पर निर्भर करती है — क्षतिग्रस्त या कम-कंट्रास्ट कोड मज़बूती से स्कैन नहीं हो सकते हैं।
- स्कैनर पीछे के (पर्यावरण-सामने वाले) कैमरे का उपयोग करता है; पीछे के कैमरे के बिना डिवाइस छवि अपलोड विकल्प पर वापस आ जाते हैं।
- `invisible auto-show` केवल पहले पृष्ठ लोड पर खुलता है; पृष्ठ पर वापस नेविगेट करने से ऑटो-ओपन फिर से ट्रिगर नहीं होता है।

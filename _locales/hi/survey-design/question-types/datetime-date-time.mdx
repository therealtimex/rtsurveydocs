`date`, `time`, और `datetime` प्रश्न प्रकार दिनांक और/या समय मानों को कैप्चर करते हैं। rtSurvey उन्हें `appearance` कॉलम द्वारा नियंत्रित कई लेआउट मोड के साथ प्रस्तुत करता है।

## मूल XLSForm विनिर्देश

| type     | name           | label                     |
|----------|----------------|---------------------------|
| date     | birth_date     | जन्म तिथि                 |
| time     | start_time     | यह कब शुरू हुआ?            |
| datetime | event_datetime | घटना कब हुई?              |

मानक विनिर्देश के लिए [XLSForm दस्तावेज़](https://xlsform.org/en/#question-types) देखें।

## लेआउट मोड

### डिफ़ॉल्ट — हमेशा खुला कैलेंडर

कोई `appearance` मान आवश्यक नहीं है। कैलेंडर (`time`/`datetime` के लिए घड़ी भी) सीधे पृष्ठ पर प्रस्तुत होता है — हमेशा दिखाई देता है, किसी बटन की आवश्यकता नहीं है।

| type | name       | label         | appearance |
|------|------------|---------------|------------|
| date | start_date | यात्रा की तिथि |            |

---

### `inline` — गोलाकार बटन → मोडल

प्रश्न लेबल के बगल में एक गोलाकार आइकन बटन (कैलेंडर या घड़ी) तैरता है। इसे टैप करने से पिकर के साथ एक मोडल खुलता है। चयन के बाद, चयनित मान लेबल के बगल में टेक्स्ट के रूप में दिखाई देता है।

- बटन पृष्ठभूमि: प्राथमिक थीम रंग (अधिरोपित किया जा सकता है)
- बटन आकार: पूर्ण वृत्त (`border-radius: 50%`)

```
| type | name       | label         | appearance |
|------|------------|---------------|------------|
| date | start_date | यात्रा की तिथि | inline     |
```

---

### `inline-onlyresult` — चयन के बाद बटन गायब हो जाता है

`inline` के समान, लेकिन एक मान चुने जाने के बाद बटन स्वयं को छिपा लेता है। यह तब उपयोगी होता है जब आप चाहते हैं कि दिनांक चुने जाने के बाद ही दिखाई दे, बिना किसी स्थायी आइकन के।

```
inline-onlyresult
```

---

### `inline-1line` — स्पिनर की पंक्ति

एकल क्षैतिज पंक्ति में व्यक्तिगत स्पिनर नियंत्रण (▲ मान ▼) प्रस्तुत करता है — प्रति घटक एक कॉलम। `date` के लिए: महीना / दिन / वर्ष। `datetime` के लिए: महीना / दिन / वर्ष / घंटे / मिनट। `time` के लिए: घंटे / मिनट।

कोई मोडल या कैलेंडर पॉपअप नहीं — उपयोगकर्ता प्रत्येक स्पिनर को स्वतंत्र रूप से स्क्रॉल करता है।

```
inline-1line
```

**केवल विशिष्ट घटकों को दिखाएं** घटक नामों को जोड़कर:

```
inline-1line month year      → दिन स्पिनर छिपाता है
inline-1line year            → केवल वर्ष दिखाता है
```

**वर्ष सीमा सीमित करें:**

```
inline-1line y_range(2000-2030)
```

---

### `box` — टेक्स्ट इनपुट

एक सादा टेक्स्ट इनपुट फ़ील्ड प्रस्तुत करता है। उपयोगकर्ता `appearance` में परिभाषित प्रारूप का उपयोग करके सीधे दिनांक टाइप करता है।

```
box(%d/%m/%Y)       → DD/MM/YYYY
box(%Y-%m-%d)       → YYYY-MM-DD
```

---

### `month-year` — केवल महीना और वर्ष

मानक XLSForm उपस्थिति। पिकर वर्ष दृश्य से शुरू होता है; उपयोगकर्ता महीना और वर्ष चुनता है लेकिन कोई विशिष्ट दिन नहीं।

```
month-year
```

---

### `year` — केवल वर्ष

मानक XLSForm उपस्थिति। पिकर दशक दृश्य से शुरू होता है; केवल वर्ष चयन योग्य है।

```
year
```

## कस्टम प्रदर्शन प्रारूप

चयनित मान को टेक्स्ट के रूप में कैसे प्रदर्शित किया जाए, इसे नियंत्रित करने के लिए किसी भी `inline` उपस्थिति में `-[format]` जोड़ें। स्ट्रफटाइम-शैली टोकन का उपयोग करता है।

| टोकन | अर्थ                | उदाहरण |
|-------|---------------------|---------|
| `%d`  | दिन (शून्य-पैडेड)  | 07      |
| `%e`  | दिन (कोई पैडिंग नहीं) | 7       |
| `%m`  | महीना संख्या        | 04      |
| `%n`  | महीना संख्या (कोई पैडिंग नहीं) | 4       |
| `%b`  | महीने का संक्षिप्त नाम | Apr     |
| `%Y`  | 4-अंकीय वर्ष       | 2026    |
| `%y`  | 2-अंकीय वर्ष       | 26      |
| `%H`  | घंटा (24h)         | 14      |
| `%h`  | घंटा (कोई पैडिंग नहीं) | 14      |
| `%M`  | मिनट                | 05      |
| `%S`  | सेकंड               | 00      |
| `%a`  | दिन का संक्षिप्त नाम | Wed     |

**उदाहरण:**

```
inline-[%d/%m/%Y]            → 07/04/2026
inline-[%d %b %Y]            → 07 Apr 2026
inline-1line-[%Y-%m-%d]      → स्पिनर इनपुट, स्वरूपित प्रदर्शन
inline-[%d/%m/%Y %H:%M]      → 07/04/2026 14:30
```

## रंग अनुकूलन

`colors()` का उपयोग करके आइकन बटन रंग को ओवरराइड करें:

```
inline colors("0099FF")                   → बटन पृष्ठभूमि #0099FF
inline colors("0099FF","FFFFFF")          → पृष्ठभूमि #0099FF, आइकन रंग #FFFFFF
inline-1line colors("0000FF","FFFF00")    → स्पिनर एक्सेंट रंग
inline-onlyresult colors("E53935")        → लाल बटन
```

## `display{}` के साथ बटन की स्थिति

`display{}` संशोधक नियंत्रित करता है कि आइकन बटन प्रश्न लेबल के सापेक्ष कहाँ दिखाई देता है। `inline` और `inline-onlyresult` पर लागू होता है।

```
display{<align>, <size>, <color>}
```

| पैरामीटर  | मान                               | डिफ़ॉल्ट |
|-----------|-----------------------------------|---------|
| संरेखित करें | `left`, `right`, `top`, `center`, `bottom` | `right` |
| आकार      | `small`, `medium`, `large`        | `small` |
| रंग       | हेक्स उदा. `#FF5500`               | प्राथमिक थीम रंग |

**संरेखण व्यवहार:**

| मान      | लेआउट                               |
|-----------|-------------------------------------|
| `right`   | लेबल के दाईं ओर बटन                |
| `left`    | लेबल के बाईं ओर बटन                 |
| `top`     | लेबल के ऊपर बटन, पूर्ण-चौड़ाई केंद्रित |
| `center` / `bottom` | लेबल के नीचे बटन, पूर्ण-चौड़ाई केंद्रित |

**उदाहरण:**

```
inline display{left}
inline display{center, large}
inline display{right, medium, #E53935}
inline-onlyresult display{bottom, large, #0099FF}
```

## दिनांक सीमा प्रतिबंध

किन तिथियों का चयन किया जा सकता है, इसे प्रतिबंधित करने के लिए `inputs{range[...]}` का उपयोग करें।

```
inputs{range[dateGt(2024-01-01), dateLt(2024-12-31)]}
```

`range[...]` के अंदर पैरामीटर:

| पैरामीटर               | विवरण                                 |
|------------------------|---------------------------------------|
| `dateGt(YYYY-MM-DD)`   | न्यूनतम चयन योग्य दिनांक (से अधिक या बराबर) |
| `dateLt(YYYY-MM-DD)`   | अधिकतम चयन योग्य दिनांक (से कम या बराबर) |
| `indayTimeGt(HH:MM:SS)` | दिन के भीतर न्यूनतम समय (केवल दिनांक-समय) |
| `indayTimeLt(HH:MM:SS)` | दिन के भीतर अधिकतम समय (केवल दिनांक-समय) |

कई श्रेणियाँ परिभाषित की जा सकती हैं — एक दिनांक चयन योग्य है यदि वह **किसी भी** श्रेणी के भीतर आती है।

## लेबल को दबाएं

प्रश्न लेबल को छिपाने के लिए `text-nolabel` जोड़ें। बटन अकेला प्रस्तुत होता है।

```
inline text-nolabel display{center, large}
```

## सर्वोत्तम अभ्यास

1. कॉम्पैक्ट फ़ॉर्म के लिए `inline` का उपयोग करें — यह हमेशा खुले कैलेंडर की तुलना में ऊर्ध्वाधर स्थान बचाता है।
2. जब उत्तरदाताओं को व्यक्तिगत दिनांक घटकों (जैसे जन्म का वर्ष) को समायोजित करने की आवश्यकता हो तो `inline-1line` का उपयोग करें।
3. `box()` का उपयोग तभी करें जब आप प्रगणक पर तिथियों को सही ढंग से टाइप करने का भरोसा करते हों — कोई सत्यापन UI नहीं दिखाया गया है।
4. मोबाइल स्क्रीन पर बटन को अधिक प्रमुख बनाने के लिए `display{center, large}` का उपयोग करें।
5. जब डिफ़ॉल्ट `YYYY-MM-DD` प्रदर्शन स्थानीय उपयोगकर्ताओं को भ्रमित कर सकता है, तो हमेशा `-[format]` निर्दिष्ट करें।
6. विभिन्न क्षेत्रों में दिनांक-समय डेटा एकत्र करते समय समय क्षेत्रों का ध्यान रखें।

## सीमाएँ

- `inline-1line` हमेशा डिफ़ॉल्ट रूप से आज की तारीख पर सेट होता है यदि कोई मान मौजूद नहीं है — एक विशिष्ट दिनांक को पहले से भरने के लिए `default` कॉलम का उपयोग करें।
- `box()` प्रारूप केवल प्रदर्शन को नियंत्रित करता है; संग्रहीत मान हमेशा ISO 8601 होता है।
- दिनांक सीमा प्रतिबंध (`inputs{range[...]}`) `box` लेआउट के साथ काम नहीं करता है।
- यदि उचित रूप से ध्यान नहीं दिया गया तो समय क्षेत्र के अंतर डेटा विश्लेषण को जटिल बना सकते हैं।

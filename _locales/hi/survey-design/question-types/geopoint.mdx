`geopoint` प्रश्न प्रकार डिवाइस जीपीएस का उपयोग करके भौगोलिक निर्देशांक (अक्षांश, देशांतर, ऊंचाई, सटीकता) कैप्चर करता है। rtSurvey कई लेआउट मोड के साथ पिकर को रेंडर करता है और `inputs{}` और `outputs{}` पैरामीटर के माध्यम से ऑटोमेशन का समर्थन करता है।

## बुनियादी XLSForm विनिर्देश (Specification)

| type     | name        | label                       |
|----------|-------------|-----------------------------|
| geopoint | location    | वर्तमान स्थान रिकॉर्ड करें |

मानक विनिर्देश के लिए [XLSForm दस्तावेज़](https://xlsform.org/en/#question-types) देखें।

## डेटा फॉर्मेट

चार स्पेस-सेपरेटेड मानों के रूप में संग्रहीत:

```
latitude longitude altitude accuracy
```

उदाहरण: `13.756331 100.501762 15 8`

## लेआउट मोड (Layout modes)

### डिफ़ॉल्ट — आयताकार बटन

एक आयताकार "START GEOPOINT" बटन एक पूर्ण मानचित्र मोडल खोलता है जहाँ गणनाकार एक बिंदु का चयन करता है। कैप्चर के बाद, बटन लेबल बदलकर "View or change geo point" हो जाता है और निर्देशांक नीचे दिखाई देते हैं।

कोई appearance मान आवश्यक नहीं है।

---

### `display{inline-icon}` — गोलाकार क्रॉसहेयर बटन

आयताकार बटन के बजाय एक गोलाकार आइकन बटन (क्रॉसहेयर ⊕) रेंडर करता है। इसे टैप करने पर वही मानचित्र मोडल खुलता है।

```
display{inline-icon}
```

**स्थिति और आकार के साथ संयुक्त:**

```
display{inline-icon, left}           → लेबल के बाईं ओर बटन
display{inline-icon, top}            → लेबल के ऊपर बटन
display{inline-icon, bottom}         → लेबल के नीचे बटन, केंद्रित
display{inline-icon, large}          → बड़ा आइकन (75px)
display{inline-icon, medium}         → मध्यम आइकन (50px)
display{inline-icon, left, large}    → बाईं ओर बड़ा बटन
```

| Size | Icon height/width |
|------|------------------|
| *(default)* | 25px |
| `medium` | 50px |
| `large` | 75px |

---

### `display{thumbnail-square}` — लाइव मानचित्र थंबनेल

बटन के बजाय सीधे प्रश्न पर एक लाइव मानचित्र पूर्वावलोकन (Leaflet) रेंडर करता है। थंबनेल वर्तमान जीपीएस स्थिति और चयनित बिंदु दिखाता है। विस्तार बटन को टैप करने पर पूर्ण मोडल खुलता है।

```
display{thumbnail-square}
```

**कस्टम थंबनेल आकार:**

```
display{thumbnail-square-[WxH]}          → निश्चित पिक्सेल
display{thumbnail-square-[400x200]}      → 400px चौड़ा × 200px लंबा

display{thumbnail-square-[W%xH%]}        → फॉर्म की चौड़ाई का प्रतिशत
display{thumbnail-square-[100%x30%]}     → पूरी चौड़ाई × फॉर्म की चौड़ाई का 30%
```

## `display{}` बनाम `results{}` — कैप्चर से पहले और बाद में

`display{}` उपयोगकर्ता द्वारा स्थान कैप्चर करने से **पहले** लेआउट को नियंत्रित करता है। `results{}` मान मौजूद होने के **बाद** लेआउट को नियंत्रित करता है। उनके अलग-अलग संरेखण (alignments) हो सकते हैं।

```
display{inline-icon, right} results{left}
```

यह कैप्चर से पहले बटन को दाईं ओर रेंडर करता है, फिर एक बार बिंदु रिकॉर्ड होने के बाद इसे बाईं ओर ले जाता है।

### `hide(value)` — निर्देशांक प्रदर्शन को छिपाएं

डिफ़ॉल्ट रूप से, कैप्चर किया गया अक्षांश/देशांतर/सटीकता/ऊंचाई टेक्स्ट बटन के नीचे दिखाया जाता है। इसे इसके साथ छिपाएं:

```
results{hide(value)}
display{inline-icon} results{hide(value)}
```

## `inputs{}` — जीपीएस ऑटोमेशन

### लोड होने पर ऑटो-कैप्चर

जब फॉर्म लोड होता है, तो गणनाकार द्वारा कुछ भी दबाए बिना जीपीएस स्थिति स्वचालित रूप से रिकॉर्ड हो जाती है।

```
inputs{auto-take}
```

XLSForm एक्सप्रेशन का उपयोग करके **सशर्त ऑटो-कैप्चर**:

```
inputs{autotakeGeo(expression(if(${capture_now} = 'yes', true(), false())))}
```

### टेक्स्ट फ़ील्ड से प्री-फिल

किसी ऐसे प्रश्न से जियोपॉइंट भरें जिसमें स्थान का नाम या पता स्ट्रिंग हो। rtSurvey OpenStreetMap Nominatim के माध्यम से स्ट्रिंग को निर्देशांक में रिवर्स-जियोकोड करता है।

```
inputs{question(address_field)}
```

---

## `outputs{}` — टेक्स्ट में रिवर्स जियोकोड

एक बिंदु कैप्चर होने के बाद, मानव-पठनीय पते (निर्देशांक से रिवर्स जियोकोडेड) के साथ स्वचालित रूप से `text` प्रश्न भरें।

```
outputs{question(address_field)}
```

उदाहरण:

| type | name | label | appearance |
|------|------|-------|------------|
| geopoint | location | स्थान रिकॉर्ड करें | `outputs{question(address_text)}` |
| text | address_text | पता | |

---

## `nomap` — मानचित्र के बिना जीपीएस कैप्चर

मानचित्र मोडल को एक सरल संवाद से बदल देता है जो स्थान की अनुमति का अनुरोध करता है और निर्देशांक रिकॉर्ड करता है। कोई मानचित्र प्रदर्शित नहीं होता है। कम-क्षमता वाले उपकरणों पर या जब मानचित्र टाइलें ऑफलाइन उपलब्ध नहीं होती हैं, तब केवल-जीपीएस कैप्चर के लिए उपयोगी है।

```
nomap
```

## सर्वोत्तम प्रथाएं

1. गणनाकार-सत्यापन सर्वेक्षणों के लिए `inputs{auto-take}` का उपयोग करें जहाँ जीपीएस अनिवार्य है — यह मैन्युअल कदम को हटा देता है।
2. `display{thumbnail-square}` का उपयोग तब करें जब आप चाहते हैं कि गणनाकार आगे बढ़ने से पहले चयनित बिंदु की दृष्टि से पुष्टि करें।
3. गणनाकार को रिवर्स-जियोकोडेड पता दिखाने के लिए `outputs{question(...)}` को केवल-पठनीय (read-only) `text` फ़ील्ड के साथ जोड़ें।
4. बिना इंटरनेट कनेक्टिविटी वाले क्षेत्रों में `nomap` का उपयोग करें जहाँ मानचित्र टाइलें लोड नहीं हो सकती हैं।
5. रिकॉर्डिंग से पहले जीपीएस समय को स्थिर होने दें — 10 मीटर से कम की सटीकता आमतौर पर फ़ील्ड सर्वेक्षणों के लिए पर्याप्त है।

## सीमाएं (Limitations)

- `inputs{question(name)}` जियोकोडिंग के लिए इंटरनेट एक्सेस की आवश्यकता होती है — यह OpenStreetMap Nominatim API को कॉल करता है।
- `outputs{question(name)}` रिवर्स जियोकोडिंग के लिए भी इंटरनेट एक्सेस की आवश्यकता होती है।
- मानचित्र थंबनेल (`display{thumbnail-square}`) के लिए टाइल लोडिंग के लिए इंटरनेट की आवश्यकता होती है; निर्देशांक अभी भी ऑफलाइन कैप्चर किए जाते हैं।
- जीपीएस सटीकता डिवाइस और वातावरण के अनुसार भिन्न होती है — इनडोर या शहरी क्षेत्रों में 50 मीटर से अधिक की सटीकता हो सकती है।
- लंबे सर्वेक्षणों के दौरान स्थान डेटा एकत्र करने से डिवाइस की बैटरी लाइफ पर महत्वपूर्ण प्रभाव पड़ सकता है।

`geopoint` प्रश्न प्रकार डिवाइस जीपीएस का उपयोग करके भौगोलिक निर्देशांक (अक्षांश, देशांतर, ऊंचाई, सटीकता) कैप्चर करता है। rtSurvey कई लेआउट मोड के साथ पिकर को प्रस्तुत करता है और `inputs{}` और `outputs{}` पैरामीटर के माध्यम से स्वचालन का समर्थन करता है।

## मूल XLSForm विनिर्देश

| type     | name        | label                       |
|----------|-------------|-----------------------------|
| geopoint | location    | वर्तमान स्थान रिकॉर्ड करें |

मानक विनिर्देश के लिए [XLSForm दस्तावेज़](https://xlsform.org/en/#question-types) देखें।

## डेटा प्रारूप

चार स्पेस-पृथक मानों के रूप में संग्रहीत:

```
latitude longitude altitude accuracy
```

उदाहरण: `13.756331 100.501762 15 8`

## लेआउट मोड

### डिफ़ॉल्ट — आयताकार बटन

एक आयताकार "जियोपॉइंट प्रारंभ करें" बटन एक पूर्ण मानचित्र मोडल खोलता है जहाँ प्रगणक एक बिंदु का चयन करता है। कैप्चर के बाद, बटन लेबल "भू-बिंदु देखें या बदलें" में बदल जाता है और निर्देशांक नीचे दिखाई देते हैं।

कोई उपस्थिति मान आवश्यक नहीं है।

---

### `display{inline-icon}` — गोलाकार क्रॉसहेयर बटन

आयताकार बटन के बजाय एक गोलाकार आइकन बटन (क्रॉसहेयर ⊕) प्रस्तुत करता है। इसे टैप करने से वही मानचित्र मोडल खुलता है।

```
display{inline-icon}
```

**स्थिति और आकार के साथ संयुक्त:**

```
display{inline-icon, left}           → लेबल के बाईं ओर बटन
display{inline-icon, top}            → लेबल के ऊपर बटन
display{inline-icon, bottom}         → लेबल के नीचे बटन, केंद्रित
display{inline-icon, large}          → बड़ा आइकन (75px)
display{inline-icon, medium}         → मध्यम आइकन (50px)
display{inline-icon, left, large}    → बाईं ओर बड़ा बटन
```

| आकार    | आइकन ऊंचाई/चौड़ाई |
|---------|------------------|
| *(डिफ़ॉल्ट)* | 25px             |
| `medium` | 50px             |
| `large` | 75px             |

---

### `display{thumbnail-square}` — लाइव मानचित्र थंबनेल

बटन के बजाय सीधे प्रश्न पर एक लाइव मानचित्र पूर्वावलोकन (लीफलेट) प्रस्तुत करता है। थंबनेल वर्तमान जीपीएस स्थिति और चयनित बिंदु दिखाता है। विस्तार बटन को टैप करने से पूर्ण मोडल खुलता है।

```
display{thumbnail-square}
```

**कस्टम थंबनेल आकार:**

```
display{thumbnail-square-[WxH]}          → निश्चित पिक्सेल
display{thumbnail-square-[400x200]}      → 400px चौड़ा × 200px लंबा

display{thumbnail-square-[W%xH%]}        → फ़ॉर्म चौड़ाई का प्रतिशत
display{thumbnail-square-[100%x30%]}     → पूर्ण चौड़ाई × फ़ॉर्म चौड़ाई का 30%
```

## `display{}` बनाम `results{}` — कैप्चर से पहले और बाद में

`display{}` उपयोगकर्ता द्वारा स्थान कैप्चर करने **से पहले** लेआउट को नियंत्रित करता है। `results{}` मान मौजूद होने **के बाद** लेआउट को नियंत्रित करता है। उनके अलग-अलग संरेखण हो सकते हैं।

```
display{inline-icon, right} results{left}
```

यह कैप्चर से पहले बटन को दाईं ओर प्रस्तुत करता है, फिर एक बिंदु रिकॉर्ड होने के बाद उसे बाईं ओर ले जाता है।

### `hide(value)` — निर्देशांक प्रदर्शन को दबाएं

डिफ़ॉल्ट रूप से, कैप्चर किया गया अक्षांश/देशांतर/सटीकता/ऊंचाई टेक्स्ट बटन के नीचे दिखाया जाता है। इसे इसके साथ छिपाएं:

```
results{hide(value)}
display{inline-icon} results{hide(value)}
```

## `inputs{}` — जीपीएस स्वचालन

### लोड पर स्वतः कैप्चर करें

प्रगणक को कुछ भी दबाए बिना, फ़ॉर्म लोड होने पर जीपीएस स्थिति को स्वचालित रूप से रिकॉर्ड करता है।

```
inputs{auto-take}
```

एक XLSForm अभिव्यक्ति का उपयोग करके **सशर्त स्वतः-कैप्चर**:

```
inputs{autotakeGeo(expression(if(${capture_now} = 'yes', true(), false())))}
```

### एक टेक्स्ट फ़ील्ड से प्री-फिल करें

एक प्रश्न से जियोपॉइंट को भरें जिसमें स्थान का नाम या पता स्ट्रिंग शामिल है। rtSurvey OpenStreetMap Nominatim के माध्यम से स्ट्रिंग को निर्देशांक में रिवर्स-जियोकोड करता है।

```
inputs{question(address_field)}
```

---

## `outputs{}` — टेक्स्ट में रिवर्स जियोकोड

एक बिंदु कैप्चर होने के बाद, मानव-पठनीय पते (निर्देशांक से रिवर्स जियोकोड किया गया) के साथ एक `text` प्रश्न को स्वचालित रूप से भरें।

```
outputs{question(address_field)}
```

उदाहरण:

| type | name | label | appearance |
|------|------|-------|------------|
| geopoint | location | स्थान रिकॉर्ड करें | `outputs{question(address_text)}` |
| text | address_text | पता | |

---

## `nomap` — मानचित्र के बिना जीपीएस कैप्चर

मानचित्र मोडल को एक साधारण डायलॉग से बदल देता है जो स्थान अनुमति का अनुरोध करता है और निर्देशांक रिकॉर्ड करता है। कोई मानचित्र प्रदर्शित नहीं होता है। कम-अंत वाले उपकरणों पर या जब मानचित्र टाइलें ऑफ़लाइन अनुपलब्ध हों तो केवल जीपीएस कैप्चर के लिए उपयोगी।

```
nomap
```

## सर्वोत्तम अभ्यास

1. `inputs{auto-take}` का उपयोग प्रगणक-सत्यापन सर्वेक्षणों के लिए करें जहाँ जीपीएस अनिवार्य है — यह मैन्युअल चरण को हटा देता है।
2. `display{thumbnail-square}` का उपयोग तब करें जब आप चाहते हैं कि प्रगणक आगे बढ़ने से पहले चयनित बिंदु कीB दृश्य रूप से पुष्टि करे।
3. प्रगणक को रिवर्स-जियोकोडेड पता दिखाने के लिए `outputs{question(...)}` को एक रीड-ओनली `text` फ़ील्ड के साथ पेयर करें।
4. उन क्षेत्रों में `nomap` का उपयोग करें जहाँ कोई इंटरनेट कनेक्टिविटी नहीं है जहाँ मानचित्र टाइलें लोड नहीं हो सकती हैं।
5. रिकॉर्डिंग से पहले जीपीएस को स्थिर होने दें — क्षेत्र सर्वेक्षणों के लिए आमतौर पर 10 मीटर से कम की सटीकता पर्याप्त होती है।

## सीमाएँ

- `inputs{question(name)}` जियोकोडिंग के लिए इंटरनेट एक्सेस की आवश्यकता होती है — यह OpenStreetMap Nominatim API को कॉल करता है।
- `outputs{question(name)}` रिवर्स जियोकोडिंग के लिए भी इंटरनेट एक्सेस की आवश्यकता होती है।
- मानचित्र थंबनेल (`display{thumbnail-square}`) को टाइल लोडिंग के लिए इंटरनेट की आवश्यकता होती है; निर्देशांक अभी भी ऑफ़लाइन कैप्चर किए जाते हैं।
- जीपीएस सटीकता डिवाइस और पर्यावरण के अनुसार भिन्न होती है — इनडोर या शहरी घाटी की स्थिति में सटीकता > 50 मीटर हो सकती है।
- लंबी सर्वेक्षणों के दौरान स्थान डेटा एकत्र करने से डिवाइस की बैटरी लाइफ पर महत्वपूर्ण प्रभाव पड़ सकता है।

`geotrace` प्रश्न प्रकार एक रेखा या पथ (polyline) बनाने वाले भौगोलिक निर्देशांकों के एक अनुक्रम को कैप्चर करता है। rtSurvey के वेब फ़ॉर्म में, यह एक **टेक्स्ट इनपुट** के रूप में दिखाई देता है जहाँ गणनाकर्ता (enumerator) सीधे निर्देशांक स्ट्रिंग दर्ज करता है या पेस्ट करता है।

## बुनियादी XLSForm विनिर्देश (Specification)

| type     | name        | label                        |
|----------|-------------|------------------------------|
| geotrace | river_path  | नदी के पथ का पता लगाएं |
| geotrace | road_route  | सड़क मार्ग रिकॉर्ड करें |

मानक विनिर्देश के लिए [XLSForm दस्तावेज़](https://xlsform.org/en/#question-types) देखें।

## डेटा प्रारूप (Data Format)

बिंदुओं की एक सेमीकोलन-अलग सूची के रूप में संग्रहीत किया जाता है जिसमें **सेमीकोलन के आसपास कोई स्थान नहीं होता है**। प्रत्येक बिंदु चार स्थान-अलग मान (space-separated values) होता है:

```
lat lon alt acc;lat lon alt acc;lat lon alt acc
```

| Component | Description |
|-----------|-------------|
| `lat` | दशमलव डिग्री में अक्षांश (Latitude) |
| `lon` | दशमलव डिग्री में देशांतर (Longitude) |
| `alt` | मीटर में ऊंचाई (`0` यदि अज्ञात है) |
| `acc` | मीटर में GPS सटीकता (`0` यदि अज्ञात है) |

**उदाहरण — तीन बिंदुओं वाला पथ:**
```
13.756331 100.501762 15 8;13.758000 100.503000 14 6;13.760000 100.505000 13 5
```

एक मान्य पथ बनाने के लिए कम से कम दो बिंदुओं की आवश्यकता होती है।

## rtSurvey में यह कैसे दिखता है

rtSurvey वेब फ़ॉर्म में, `geotrace` एक सादे **टेक्स्ट फ़ील्ड** के रूप में दिखाई देता है। गणनाकर्ता निर्देशांक स्ट्रिंग टाइप करता है या पेस्ट करता है। वर्तमान वेब फ़ॉर्म में इस प्रकार के लिए कोई अंतर्निहित इंटरैक्टिव मानचित्र चयनकर्ता (map picker) नहीं है।

### बिंदुओं को इंटरैक्टिव रूप से एकत्र करना

फ़ील्ड संग्रह के लिए अनुशंसित पैटर्न `geopoint` प्रश्नों का एक **दोहराव समूह (repeat group)** है — प्रत्येक बिंदु पूर्ण GPS मानचित्र चयनकर्ता का उपयोग करता है — जिसे geotrace स्ट्रिंग उत्पन्न करने के लिए `calculate` के साथ जोड़ा जाता है:

| type | name | label | calculation |
|------|------|-------|-------------|
| begin repeat | path_points | प्रत्येक वेब बिंदु (waypoint) रिकॉर्ड करें | |
| geopoint | point | बिंदु रिकॉर्ड करने के लिए टैप करें | |
| end repeat | path_points | | |
| calculate | geotrace_value | | `join(';', ${path_points/point})` |

परिकलित स्ट्रिंग को तब `text` प्रश्न में संग्रहीत किया जा सकता है या `geotrace` में उपयोग किया जा सकता है।

## सर्वोत्तम प्रथाएं

1. इंटरैक्टिव मानचित्र-आधारित संग्रह के लिए `geopoint` प्रश्नों के दोहराव समूह का उपयोग करें, फिर मानों को जोड़ें — यह गणनाकर्ताओं को प्रत्येक व्यक्तिगत बिंदु के लिए एक GPS चयनकर्ता देता है।
2. जब मैन्युअल निर्देशांक प्रविष्टि की आवश्यकता हो तो `hint` कॉलम में अपेक्षित प्रारूप शामिल करें।
3. जब पथ अनिवार्य हो तो `required = yes` के साथ उपस्थिति सत्यापित करें।
4. डेटा सफाई के लिए योजना बनाएं — मैन्युअल रूप से दर्ज किए गए पथों में असंगत सटीकता हो सकती है।

## सीमाएं (Limitations)

- rtSurvey वेब फ़ॉर्म में `geotrace` के लिए कोई अंतर्निहित इंटरैक्टिव मानचित्र चयनकर्ता नहीं है।
- जटिल पथों के लिए निर्देशांक स्ट्रिंग लंबी हो सकती है — फ़ॉर्म प्रदर्शन और भंडारण के लिए इसे ध्यान में रखें।
- पथ टोपोलॉजी (जैसे, न्यूनतम बिंदु गणना, स्व-प्रतिच्छेदन) को मान्य करने के लिए XLSForm प्रतिबंधों के बाहर पोस्ट-प्रोसेसिंग की आवश्यकता होती है।

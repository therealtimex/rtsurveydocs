`range` प्रश्न प्रकार उत्तरदाताओं को एक निर्धारित न्यूनतम और अधिकतम के भीतर एक संख्या चुनने देता है। rtSurvey के वेब फ़ॉर्म में, यह एक मानक **नंबर इनपुट** के रूप में दिखाई देता है — गणनाकर्ता सीधे मान टाइप करता है। `start`, `end`, और `step` पैरामीटर मान्य श्रेणी को परिभाषित करते हैं और प्रतिबंधों (constraints) के रूप में लागू किए जाते हैं।

## बुनियादी XLSForm विनिर्देश (Specification)

| type | name | label | parameters |
|------|------|-------|------------|
| range | satisfaction | आप सेवा से कितने संतुष्ट हैं? | start=1 end=5 step=1 |

`parameters` कॉलम स्लाइडर की सीमा और स्टेप (step) आकार को परिभाषित करता है:

| Parameter | Description | Default |
|-----------|-------------|---------|
| `start` | न्यूनतम मान (समावेशी) | 0 |
| `end` | अधिकतम मान (समावेशी) | 10 |
| `step` | मान्य मानों के बीच वृद्धि | 1 |

मानक रेंज प्रश्न प्रकार के बारे में अधिक जानकारी के लिए, [XLSForm विनिर्देश](https://xlsform.org/en/#question-types) देखें।

## उपयोग

रेंज प्रश्नों का उपयोग आमतौर पर इनके लिए किया जाता है:

1. संतुष्टि या रेटिंग स्केल (जैसे, 1-5 या 0-10)
2. लिकर्ट-शैली (Likert-style) संख्यात्मक स्केल
3. उन मापों को एकत्र करना जहाँ केवल असतत (discrete) मान मान्य हैं
4. आयु वर्ग या स्कोर श्रेणियां जहाँ एक स्लाइडर टेक्स्ट फ़ील्ड की तुलना में उपयोगिता में सुधार करता है

## उदाहरण उपयोग

### बुनियादी रेटिंग स्केल

| type | name | label | parameters |
|------|------|-------|------------|
| range | overall_rating | कुल रेटिंग (0–10) | start=0 end=10 step=1 |

### दशमलव स्टेप (Decimal step)

| type | name | label | parameters |
|------|------|-------|------------|
| range | weight_kg | वजन (किग्रा) | start=0 end=200 step=0.5 |

### गणना में मान का उपयोग करना

| type | name | label | parameters | calculation |
|------|------|-------|------------|-------------|
| range | score | टेस्ट स्कोर (0–100) | start=0 end=100 step=5 | |
| calculate | grade | | | if(`${score}` >= 90, 'A', if(`${score}` >= 80, 'B', if(`${score}` >= 70, 'C', 'F'))) |
| note | grade_note | आपका ग्रेड है: `${grade}` | | |

## सर्वोत्तम प्रथाएं

1. हमेशा सार्थक `start`, `end`, और `step` मान सेट करें — डिफ़ॉल्ट पर भरोसा न करें।
2. उत्तरदाताओं को संदर्भ देने के लिए `hint` कॉलम में अपने स्केल के सिरों को लेबल करें (जैसे, `संकेत: 0 = बहुत असंतुष्ट, 10 = बहुत संतुष्ट`)।
3. 5-पॉइंट लिकर्ट स्केल के लिए, 0-4 के बजाय `start=1 end=5 step=1` का उपयोग करें, क्योंकि उत्तरदाता "1" का अर्थ न्यूनतम होने की उम्मीद करते हैं।
4. `integer` + प्रतिबंध के बजाय `range` का उपयोग करें जब इनपुट की सीमित प्रकृति प्रश्न डिजाइन का हिस्सा हो (स्लाइडर स्केल को दृश्य रूप से संप्रेषित करता है)।

## सीमाएं (Limitations)

- rtSurvey वेब फ़ॉर्म में कोई स्लाइडर विजेट नहीं है — मान प्रविष्टि एक सादा नंबर इनपुट है। दृश्य स्लाइडर अनुभव के लिए, एक मोबाइल क्लाइंट का उपयोग करें जो रेंज विजेट का समर्थन करता है।
- बहुत विस्तृत श्रेणियों (जैसे, 0-10000) के लिए, प्रतिबंध के साथ एक साधारण `integer` समान रूप से प्रभावी और अधिक उपयोगकर्ता के अनुकूल है।
- बारीक स्टेप मान (जैसे, `step=0.1`) प्रतिबंधों के रूप में काम करते हैं लेकिन वेब फ़ॉर्म में स्लाइडर सटीकता की कोई चिंता नहीं है।

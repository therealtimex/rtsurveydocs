rtSurvey मजबूत बहु-भाषी समर्थन प्रदान करता है, जिससे आप कई भाषाओं में सर्वेक्षण बना सकते हैं। यह विशेषता विविध भाषाई आबादी या बहुभाषी वातावरण में अनुसंधान करने के लिए महत्वपूर्ण है।

## बहु-भाषी सर्वेक्षण स्थापित करना

rtSurvey में एक बहु-भाषी सर्वेक्षण बनाने के लिए, आपको अपने XLSForm में भाषा-विशिष्ट कॉलम जोड़ने होंगे। यहाँ बताया गया है कि कैसे:

1. **लेबल अनुवाद (Label Translations)**: `label::Language (code)` प्रारूप का उपयोग करके प्रत्येक भाषा के लिए कॉलम जोड़ें।
2. **हिंट अनुवाद (Hint Translations)**: हिंट अनुवाद करने के लिए `hint::Language (code)` का उपयोग करें।
3. **मीडिया फ़ाइल अनुवाद (Media File Translations)**: भाषा-विशिष्ट मीडिया के लिए, `media::Language (code)` का उपयोग करें।

उदाहरण:

```
| type    | name | label::English (en) | label::Español (es) | hint::English (en) | hint::Español (es) |
|---------|------|---------------------|---------------------|---------------------|---------------------|
| integer | age  | How old are you?    | ¿Cuántos años tienes?| Enter your age      | Ingrese su edad     |
```

## भाषा कोड

भाषा के नाम के बाद आधिकारिक 2-चरित्र भाषा कोड (subtags) का उपयोग करने की अनुशंसा की जाती है। यह उपयोगकर्ता इंटरफ़ेस भाषा के साथ फ़ॉर्म भाषा के मिलान की सुविधा प्रदान करता है। आप आधिकारिक कोड [यहाँ](https://www.iana.org/assignments/language-subtag-registry/language-subtag-registry) पा सकते हैं।

## डिफ़ॉल्ट भाषा सेट करना

डेटा संग्रह के लिए डिफ़ॉल्ट भाषा सेट करने के लिए, अपने XLSForm में `settings` वर्कशीट का उपयोग करें:

```
| form_id   | version | default_language |
|-----------|---------|-------------------|
| test_form | 101     | French (fr)       |
```

## rtSurvey-विशिष्ट विशेषताएं

### गतिशील भाषा स्विचिंग

rtSurvey उपयोगकर्ताओं को डेटा संग्रह के दौरान गतिशील रूप से भाषाएं बदलने की अनुमति देता है:

- वेब इंटरफ़ेस में, शीर्ष नेविगेशन बार में भाषा ड्रॉपडाउन का उपयोग करें।
- मोबाइल ऐप में, सेटिंग्स मेनू के माध्यम से भाषा विकल्पों तक पहुंचें।

### भाषा-विशिष्ट सत्यापन संदेश

rtSurvey सत्यापन संदेशों तक बहु-भाषी समर्थन का विस्तार करता है:

```
| type    | name | constraint | constraint_message::English (en) | constraint_message::Español (es) |
|---------|------|------------|----------------------------------|----------------------------------|
| integer | age  | . <= 150   | Age must be 150 or less          | La edad debe ser 150 o menos     |
```

### स्थानीयकृत आवश्यक संदेश

जब कोई आवश्यक फ़ील्ड खाली छोड़ दिया जाता है, तो अनुवादित त्रुटि दिखाने के लिए `required_message::Language (code)` का उपयोग करें:

```
| type | name | required | required_message::English (en) | required_message::Tiếng Việt (vi) |
|------|------|----------|-------------------------------|----------------------------------|
| text | name | yes | This field is required | Trường này là bắt buộc |
```

### RTL भाषा समर्थन

अरबी या हिब्रू जैसी दाएं-से-बाएं (RTL) भाषाओं के लिए, rtSurvey स्वचालित रूप से लेआउट समायोजित करता है:

```
| type | name | label::English (en) | label::Arabic (ar) |
|------|------|---------------------|---------------------|
| text | name | Your name           | اسمك                |
```

### भाषा-विशिष्ट उपस्थिति (Appearance)

rtSurvey आपको विभिन्न भाषाओं के लिए अलग-अलग उपस्थिति निर्दिष्ट करने की अनुमति देता है:

```
| type | name | label::English (en) | label::Chinese (zh) | appearance::English (en) | appearance::Chinese (zh) |
|------|------|---------------------|---------------------|--------------------------|---------------------------|
| text | address | Address          | 地址                 | multiline                | textarea                  |
```

## द्विभाषी लेबल में HTML फ़ॉर्मेटिंग

आप एक ही लेबल सेल में भाषा रैपर के साथ HTML टैग्स को जोड़ सकते हैं। rtSurvey सक्रिय-भाषा ब्लॉक निकालता है और शेष HTML रेंडर करता है।

प्रति भाषा बोल्ड और फ़ॉन्ट रंग का उपयोग करने का उदाहरण:

```
<en><big><b>Section 2: Household Income</b></big><br>Ask the household head only.</en><vi><big><b>Phần 2: Thu nhập hộ gia đình</b></big><br>Chỉ hỏi chủ hộ.</vi>
```

भाषा रैपर के अंदर समर्थित इनलाइन टैग्स: `<b>`, `<i>`, `<u>`, `<big>`, `<small>`, `<font color="...">`, `<br>`, `<span style="...">`।

प्रति भाषा रंगीन टेक्स्ट का उदाहरण:

```
<en><font color="red">Required field</font></en><vi><font color="red">Trường bắt buộc</font></vi>
```

## भाषा-जागरूक गणना (Calculations)

जब किसी फ़ॉर्म में `${language_use}` फ़ील्ड (एक `change_language` विज़ेट द्वारा सेट) होता है, तो सक्रिय भाषा में मान वापस करने के लिए `if()` का उपयोग करें:

```
if(${language_use} = 'en', label_en, label_vi)
```

उदाहरण — `pulldata('rawquery', ...)` का उपयोग करके सक्रिय भाषा में लुकअप परिणाम प्रदर्शित करें:

```
| type      | name        | calculation                                                                 |
|-----------|-------------|-----------------------------------------------------------------------------|
| calculate | district_label | if(${language_use} = 'en', pulldata('rawquery', concat(${family_path}, '/locations.db::externalData'), 'SELECT label_en FROM externalData WHERE code = ?', ${district}), pulldata('rawquery', concat(${family_path}, '/locations.db::externalData'), 'SELECT label_vi FROM externalData WHERE code = ?', ${district})) |
```

नोट: `language_use` फ़ील्ड आमतौर पर `change_language` अपीयरेंस विज़ेट द्वारा सेट किया जाता है। Appearance — change_language देखें।

## बहु-भाषी सर्वेक्षणों के लिए सर्वोत्तम अभ्यास

1. **सुसंगत नामकरण**: अपने पूरे फ़ॉर्म में सुसंगत भाषा कोड का उपयोग करें।
2. **पेशेवर अनुवाद**: सर्वेक्षण संदर्भ से परिचित पेशेवर अनुवादकों को नियुक्त करें।
3. **संदर्भ नोट**: सटीक अनुवाद सुनिश्चित करने के लिए अनुवादकों के लिए संदर्भ नोट प्रदान करें।
4. **परीक्षण**: परिनियोजन से पहले सभी भाषाओं में अपने फ़ॉर्म का परीक्षण करें।
5. **यूनिकोड समर्थन**: सुनिश्चित करें कि आपके डेटा संग्रह उपकरण गैर-लैटिन लिपियों के लिए यूनिकोड का समर्थन करते हैं।
6. **भाषा-विशिष्ट मीडिया**: प्रत्येक भाषा के लिए सांस्कृतिक रूप से उपयुक्त छवियों या ऑडियो का उपयोग करें।
7. **छवियों में टेक्स्ट से बचें**: यदि टेक्स्ट वाली छवियों का उपयोग कर रहे हैं, तो प्रत्येक भाषा के लिए अलग चित्र बनाएं।

## विशेष मामलों को संभालना

### मिश्रित भाषा प्रतिक्रियाएं

rtSurvey उत्तरदाताओं को चुनी गई फ़ॉर्म भाषा की परवाह किए बिना किसी भी लिपि में टेक्स्ट इनपुट करने की अनुमति देता है। यह नामों या पतों को उनकी मूल लिपि में कैप्चर करने के लिए उपयोगी है।

### भाषा-विशिष्ट प्रश्न प्रकार

कुछ प्रश्न प्रकार कुछ भाषाओं के लिए अधिक उपयुक्त हो सकते हैं। rtSurvey आपको विभिन्न भाषाओं के लिए विभिन्न प्रश्न प्रकारों का उपयोग करने की अनुमति देता है:

```
| type::English (en) | type::Japanese (ja) | name | label::English (en) | label::Japanese (ja) |
|--------------------|---------------------|------|---------------------|----------------------|
| text               | select_one kanji    | name | Enter your name     | 名前を選んでください    |
```

## बहु-भाषी डेटा निर्यात करना

जब rtSurvey से डेटा निर्यात करते हैं:

- एक विशिष्ट भाषा में निर्यात करना चुनें या सभी भाषा संस्करण शामिल करें।
- भाषा मेटाडेटा निर्यात में शामिल है, जो यह दर्शाता है कि प्रत्येक प्रतिक्रिया के लिए किस भाषा का उपयोग किया गया था।

## मोबाइल ऐप विचार

- rtSurvey मोबाइल ऐप ऑफ़लाइन भाषा स्विचिंग का समर्थन करता है।
- ऑफ़लाइन जाने से पहले सुनिश्चित करें कि सभी आवश्यक भाषा फ़ाइलें डाउनलोड हो गई हैं।

## ज्ञात सीमाएं

- कुछ उन्नत सुविधाएं सभी भाषाओं में उपलब्ध नहीं हो सकती हैं।
- अत्यधिक लंबे अनुवाद छोटी स्क्रीन पर लेआउट को प्रभावित कर सकते हैं।

rtSurvey की बहु-भाषी क्षमताओं का लाभ उठाकर, आप समावेशी, सुलभ सर्वेक्षण बना सकते हैं जो विविध आबादी तक पहुँचते हैं और उच्च-गुणवत्ता वाले, भाषाई रूप से सटीक डेटा प्रदान करते हैं।

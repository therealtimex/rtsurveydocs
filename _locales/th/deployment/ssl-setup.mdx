ต้องกำหนดค่า SSL ก่อนที่คุณจะสามารถเข้าสู่ระบบได้ เมื่อคุณเปิดแอปครั้งแรก คุณจะถูกเปลี่ยนเส้นทางไปยังหน้าจอตั้งค่า SSL โดยอัตโนมัติ

---

## ตัวเลือกการตั้งค่า SSL

![ตัวเลือกการตั้งค่า SSL](/img/ssl-setup/ssl-setup-options.png)

เลือกหนึ่งในสามตัวเลือก:

| ตัวเลือก | เมื่อใดควรใช้ |
|--------|-------------|
| **ซับโดเมน rtsurvey.com ฟรี** *(แนะนำ)* | ไม่ต้องตั้งค่า DNS เราจะสร้างเรคคอร์ดให้คุณ พร้อมใช้งานภายใน 2–5 นาที |
| **โดเมนของฉันเอง** | คุณมีโดเมนอยู่แล้ว และ DNS ของโดเมนนั้นชี้มาที่เซิร์ฟเวอร์นี้ |
| **ติดตั้งใบรับรองด้วยตนเอง** | สำหรับองค์กรหรือ CA แบบกำหนดเอง ต้องมีสิทธิ์เข้าถึง SSH |

---

## ตัวเลือกที่ 1 — ซับโดเมน rtsurvey.com ฟรี *(แนะนำ)*

นี่เป็นตัวเลือกที่เร็วที่สุด ไม่ต้องจดทะเบียนโดเมนหรือเปลี่ยนแปลง DNS

![ฟอร์มการตั้งค่า HTTPS](/img/ssl-setup/ssl-setup-form.png)

> **ก่อนดำเนินการต่อ:** ซับโดเมนฟรีต้องใช้บัญชีที่ใช้งานอยู่บน [licenses.rtsurvey.com](https://licenses.rtsurvey.com) แผนฟรีประกอบด้วย 1 ซับโดเมน (`*.rtsurvey.com`)

1. คลิก **Free rtsurvey.com subdomain** เพื่อขยายส่วนนี้
2. พิมพ์ชื่อซับโดเมนที่ต้องการในช่อง **YOUR SUBDOMAIN**

   > ใช้ตัวอักษรภาษาอังกฤษตัวพิมพ์เล็ก ตัวเลข และไฮเฟน (ขีดกลาง) ความยาว 3–30 ตัวอักษร
   > ตัวอย่าง: `myproject` → `myproject.rtsurvey.com`

3. คัดลอก **rtSurvey DNS Token** ของคุณจาก [licenses.rtsurvey.com](https://licenses.rtsurvey.com) มาวางในช่องโทเค็น
4. คลิก **Create secure subdomain**

เมื่อส่งข้อมูลแล้ว แอปจะเริ่มดำเนินการจัดเตรียมใบรับรองของคุณ:

![ความคืบหน้าการตั้งค่า HTTPS](/img/ssl-setup/ssl-setup-progress.png)

ทั้งสี่ขั้นตอนจะทำงานโดยอัตโนมัติ:
- **Requesting DNS record** — สร้างรายการ DNS สำหรับซับโดเมนของคุณ
- **Waiting for DNS to propagate** — ปกติใช้เวลา 2–5 นาที
- **Issuing SSL certificate** — Let's Encrypt ลงนามในใบรับรองของคุณ
- **Activating HTTPS** — Nginx จะโหลดซ้ำพร้อมกับใบรับรองใหม่

5. เมื่อเสร็จสิ้น คุณจะถูกเปลี่ยนเส้นทางไปยัง URL HTTPS ใหม่ของคุณโดยอัตโนมัติ

## ตัวเลือกที่ 2 — โดเมนของฉันเอง

ใช้ตัวเลือกนี้หากคุณมีโดเมนเดิมอยู่แล้ว และเรคคอร์ด DNS `A` ชี้มาที่ IP ของเซิร์ฟเวอร์นี้แล้ว

1. คลิก **My own domain** เพื่อขยายส่วนนี้
2. ป้อนชื่อโดเมนเต็มของคุณ (เช่น `survey.myorganization.org`)
3. คลิก **Create certificate**



Let's Encrypt จะตรวจสอบโดเมนของคุณและออกใบรับรองให้ ซึ่งกำหนดให้ต้องชี้ DNS ให้ถูกต้องก่อน มิฉะนั้นการร้องขอจะล้มเหลว

---

## ตัวเลือกที่ 3 — ติดตั้งใบรับรองด้วยตนเอง

สำหรับสภาพแวดล้อมระดับองค์กรที่ใช้ CA แบบกำหนดเองหรือภายใน คุณจะวางไฟล์ใบรับรองของคุณบนเซิร์ฟเวอร์ผ่าน SSH จากนั้นจึงป้อนโดเมนของคุณในแอป

### ข้อกำหนดเบื้องต้น

- สิทธิ์เข้าถึง SSH ไปยังเซิร์ฟเวอร์
- ใบรับรองและคีย์ส่วนตัวที่ถูกต้องสำหรับโดเมนของคุณ (รูปแบบ PEM)

### ขั้นตอนที่ 1 — SSH เข้าสู่เซิร์ฟเวอร์

```bash
ssh root@<server-ip>
```

### ขั้นตอนที่ 2 — วางไฟล์ใบรับรองของคุณ

สร้างไดเรกทอรีและคัดลอกไฟล์ของคุณ:

```bash
mkdir -p /etc/letsencrypt/live/<your-domain>
```

คัดลอกไฟล์ของคุณไปยังไดเรกทอรีนั้นด้วยชื่อที่ถูกต้องเหล่านี้:

| ไฟล์ | คำอธิบาย |
|------|-------------|
| `fullchain.pem` | ใบรับรองของคุณ + ใบรับรอง CA ระหว่างกลางใดๆ (รวมกัน) |
| `privkey.pem` | คีย์ส่วนตัวของคุณ |

ตัวอย่าง:

```bash
# คัดลอกจากเครื่องในพื้นที่ของคุณ (รันคำสั่งนี้ที่เครื่องของคุณ ไม่ใช่บนเซิร์ฟเวอร์)
scp fullchain.pem root@<server-ip>:/etc/letsencrypt/live/<your-domain>/fullchain.pem
scp privkey.pem  root@<server-ip>:/etc/letsencrypt/live/<your-domain>/privkey.pem
```

ตั้งค่าสิทธิ์ที่ถูกต้อง:

```bash
chmod 644 /etc/letsencrypt/live/<your-domain>/fullchain.pem
chmod 600 /etc/letsencrypt/live/<your-domain>/privkey.pem
```

### ขั้นตอนที่ 3 — ป้อนโดเมนของคุณในแอป



1. ในหน้าจอตั้งค่า SSL ให้คลิก **Install certificate manually**
2. ป้อนชื่อโดเมนของคุณ (ต้องตรงกับ Common Name หรือ SAN ของใบรับรอง)
3. คลิก **Apply**

เซิร์ฟเวอร์จะกำหนดค่า Nginx ด้วยใบรับรองของคุณและโหลดซ้ำโดยอัตโนมัติ

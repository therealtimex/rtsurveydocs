import { Callout } from 'nextra/components'

rtSurvey เรนเดอร์ข้อความ **label** และ **hint** เป็น HTML บนเว็บฟอร์ม ซึ่งหมายความว่าคุณสามารถใช้แท็ก HTML มาตรฐานเพื่อจัดรูปแบบข้อความ เพิ่มการขึ้นบรรทัด สร้างลิงก์ และใช้สี ซึ่งมีประโยชน์โดยเฉพาะสำหรับฟิลด์ note คำแนะนำส่วน และสรุปแบบไดนามิก

<Callout type="warning">
HTML ใน labels จะเรนเดอร์บน **เว็บฟอร์ม** และแอปมือถือ rtSurvey อาจไม่เรนเดอร์ใน clients ที่เข้ากันได้กับ ODK ทุกตัว ทดสอบบนแพลตฟอร์มเป้าหมายของคุณเสมอ
</Callout>

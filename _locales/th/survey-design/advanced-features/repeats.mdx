หน้านี้ครอบคลุมรูปแบบขั้นสูงสำหรับการทำงานกับกลุ่มการทำซ้ำใน rtSurvey สำหรับพื้นฐานการตั้งค่ากลุ่มการทำซ้ำ โปรดดู [การจัดกลุ่มและการทำซ้ำ](../repeats)

---

## จำนวนการทำซ้ำแบบไดนามิก (Dynamic repeat count)

โดยปกติแล้ว ผู้เก็บรวบรวมข้อมูลจะเป็นผู้ตัดสินใจว่าจะทำซ้ำกี่ครั้ง คุณสามารถกำหนดจำนวนการทำซ้ำให้คงที่ได้โดยใช้ `repeat_count`:

| type | name | label | repeat_count |
|------|------|-------|--------------|
| begin_repeat | household_members | สมาชิกในครัวเรือน | `${num_members}` |
| text | member_name | ชื่อสมาชิก | |
| integer | member_age | อายุ | |
| end_repeat | | | |

การทำซ้ำจะทำงานตามจำนวนครั้งที่ระบุใน `${num_members}` ซึ่งเป็นข้อมูลที่เก็บรวบรวมมาก่อนหน้านี้ในแบบฟอร์ม โดยผู้เก็บรวบรวมข้อมูลจะไม่สามารถเพิ่มหรือลบชุดข้อมูลเองได้

---

## การเข้าถึงแบบระบุลำดับ: `indexed-repeat()`

เข้าถึงค่าของฟิลด์ในชุดการทำซ้ำที่เฉพาะเจาะจงจาก **ภายนอก** กลุ่มการทำซ้ำโดยใช้ `indexed-repeat(repeatedField, repeatGroup, index)`:

| type | name | label | calculation |
|------|------|-------|-------------|
| calculate | first_name | | `indexed-repeat(${member_name}, ${household_members}, 1)` |
| calculate | second_name | | `indexed-repeat(${member_name}, ${household_members}, 2)` |

สิ่งนี้มีประโยชน์สำหรับการสร้างฟิลด์สรุปหรือการอ้างอิงข้อมูลของสมาชิก "คนแรก" หลังจากจบกลุ่มการทำซ้ำ

---

## ตำแหน่งของชุดปัจจุบัน: `index()`

ภายในกลุ่มการทำซ้ำ ฟังก์ชัน `index()` จะคืนค่าตำแหน่งของชุดปัจจุบัน (เริ่มจาก 1) ใช้ฟังก์ชันนี้เพื่อระบุลำดับในแต่ละชุดหรือสร้างรหัสประจำตัวที่ไม่ซ้ำกัน:

| type | name | label |
|------|------|-------|
| begin_repeat | plots | แปลงที่ดิน |
| note | plot_label | แปลงที่ดินลำดับที่ `${index()}` |
| text | plot_id | รหัสแปลงที่ดิน |
| end_repeat | | |

---

## การอ้างอิงฟิลด์ในชุดเดียวกัน

ภายในการทำซ้ำ ให้ใช้ `${fieldname}` เพื่ออ้างอิงฟิลด์อื่น **ในชุดการทำซ้ำเดียวกัน** ไม่จำเป็นต้องใช้ `indexed-repeat()` ภายในวงจรเดียวกัน:

| type | name | label | relevant |
|------|------|-------|----------|
| begin_repeat | members | สมาชิก | |
| text | member_name | ชื่อ | |
| integer | member_age | อายุ | |
| text | school_name | ชื่อโรงเรียน | `${member_age} < 18` |
| end_repeat | | | |

---

## การอ้างอิงฟิลด์หลักจากภายในการทำซ้ำ

ฟิลด์ภายนอก (ด้านบน) กลุ่มการทำซ้ำสามารถอ้างอิงได้ตามปกติด้วย `${fieldname}`:

| type | name | label |
|------|------|-------|
| text | village | ชื่อหมู่บ้าน |
| begin_repeat | plots | แปลงเกษตรกรรม |
| note | plot_context | แปลงในหมู่บ้าน `${village}` |
| end_repeat | | |

## การสรุปข้อมูลการทำซ้ำ

ใช้ฟังก์ชันรวม (aggregate functions) **ภายนอก** กลุ่มการทำซ้ำเพื่อสรุปข้อมูล:

| Function | Example | Description |
|----------|---------|-------------|
| `count(group)` | `count(${household_members})` | จำนวนชุดข้อมูล |
| `sum(field)` | `sum(${loan_amount})` | ผลรวมของฟิลด์ตัวเลข |
| `min(field)` | `min(${member_age})` | ค่าต่ำสุด |
| `max(field)` | `max(${member_age})` | ค่าสูงสุด |
| `join(sep, field)` | `join(', ', ${member_name})` | รายการแยกด้วยคอมมา |
| `count-if(group, expr)` | `count-if(${members}, ${member_age} < 18)` | นับตามเงื่อนไข |
| `sum-if(field, expr)` | `sum-if(${loan_amount}, ${loan_amount} > 500)` | รวมตามเงื่อนไข |
| `join-if(sep, field, expr)` | `join-if(', ', ${name}, ${age} >= 18)` | เชื่อมข้อความตามเงื่อนไข |

### ตัวอย่าง: สรุปข้อมูลครัวเรือน

| type | name | label | calculation |
|------|------|-------|-------------|
| integer | num_members | มีสมาชิกกี่คน? | |
| begin_repeat | members | สมาชิก | `${num_members}` |
| text | member_name | ชื่อ | |
| integer | member_age | อายุ | |
| end_repeat | | | |
| calculate | total_members | | `count(${members})` |
| calculate | children_count | | `count-if(${members}, ${member_age} < 18)` |
| calculate | adult_names | | `join-if(', ', ${member_name}, ${member_age} >= 18)` |
| note | summary | มีสมาชิก `${total_members}` คน; อายุน้อยกว่า 18 ปี `${children_count}` คน. รายชื่อผู้ใหญ่: `${adult_names}` | |

## การทำซ้ำแบบซ้อนกัน (Nested repeats)

กลุ่มการทำซ้ำสามารถประกอบด้วยกลุ่มการทำซ้ำอื่นภายในได้ โปรดใช้ด้วยความระมัดระวัง เพราะการทำซ้ำแบบซ้อนกันจะเพิ่มความซับซ้อนและอาจทำให้ผู้เก็บรวบรวมข้อมูลสับสนได้

| type | name | label |
|------|------|-------|
| begin_repeat | households | ครัวเรือน |
| text | hh_id | รหัสครัวเรือน |
| begin_repeat | hh_members | สมาชิก |
| text | member_name | ชื่อสมาชิก |
| end_repeat | | |
| end_repeat | | |

หากต้องการอ้างอิงฟิลด์ในกลุ่มการทำซ้ำชั้นนอกจากการทำซ้ำชั้นใน ให้ใช้ `${fieldname}` ซึ่งจะค้นหาจากข้อมูลหลักที่ใกล้ที่สุดที่ตรงกัน:

ภายในการทำซ้ำ `hh_members`, `${hh_id}` จะคืนค่ารหัสของครัวเรือน **ปัจจุบัน** ไม่ใช่ของทุกครัวเรือน

---

## ลำดับภายในกลุ่มการทำซ้ำ: `rank-index()`

เมื่อมีฟิลด์ `rank` อยู่ภายในการทำซ้ำ ให้ใช้ `rank-index(instanceNumber, repeatedField)` จากภายนอกเพื่อรับลำดับที่ของชุดที่เฉพาะเจาะจง:

| type | name | label | calculation |
|------|------|-------|-------------|
| calculate | top_scorer | | `rank-index(1, ${score})` |

`rank-index(1, ${score})` จะคืนค่าตำแหน่ง (index) ของชุดที่มีคะแนนสูงสุด

---

## รูปแบบ `1screen` ใน `begin_repeat`

การเพิ่ม `1screen` ในคอลัมน์ `appearance` ของแถว `begin_repeat` จะแสดงคำถามทั้งหมดในแต่ละชุดรวมกันในหน้าจอเดียว แทนที่จะแสดงทีละคำถามต่อหน้าจอ

| type | name | label | appearance |
|------|------|-------|------------|
| begin_repeat | household_members | สมาชิกในครัวเรือน | `1screen` |
| text | member_name | ชื่อสมาชิก | |
| integer | member_age | อายุ | |
| end_repeat | | | |

เมื่อตั้งค่า `1screen` และไม่มีฟิลด์ `repeat_count` รวมถึงไม่มีฟิลด์ `add_repeat` ภายในกลุ่ม rtSurvey จะแสดงปุ่มรูปวงกลมเครื่องหมาย **+** ที่ด้านล่างของหน้าจอโดยอัตโนมัติ เพื่อให้ผู้เก็บรวบรวมข้อมูลสามารถเพิ่มชุดข้อมูลใหม่ได้โดยไม่ต้องตั้งค่าเพิ่มเติม

| Appearance | หนึ่งหน้าจอต่อหนึ่งชุดข้อมูล | เพิ่มปุ่ม + อัตโนมัติ |
|------------|-------------------------|------------------------|
| `1screen` | ใช่ | ใช่ (เมื่อไม่มีฟิลด์ `add_repeat`) |
| `field-list` | ใช่ | ไม่ใช่ |

ใช้ `field-list` เมื่อคุณต้องการจัดวางแบบกลุ่มโดยไม่มีปุ่มเพิ่มอัตโนมัติ ใช้ `1screen` เมื่อคุณต้องการทั้งการจัดวางแบบกลุ่มและวิธีเพิ่มชุดข้อมูลในตัว

## ปุ่มเพิ่มที่กำหนดเอง `add_repeat`

ฟิลด์ `note` (หรือ `text`) ที่วางไว้ **ภายใน** กลุ่มการทำซ้ำพร้อมกำหนด `appearance: add_repeat` จะแสดงเป็นปุ่ม "เพิ่ม (Add)" แบบเต็มความกว้าง ข้อความบนปุ่มมาจากคอลัมน์ `label` ของฟิลด์นั้น เมื่อมีฟิลด์ `add_repeat` อยู่ ปุ่มรูปวงกลมเครื่องหมาย + ปกติ (จาก `1screen`) จะถูกซ่อนไป

วางฟิลด์ `add_repeat` เป็นฟิลด์สุดท้ายภายในกลุ่มการทำซ้ำ:

| type | name | label | appearance |
|------|------|-------|------------|
| begin_repeat | members | สมาชิก | `1screen` |
| text | member_name | ชื่อสมาชิก | |
| integer | member_age | อายุ | |
| note | btn_add | + เพิ่มสมาชิก | `add_repeat` |
| end_repeat | | | |

### การปรับแต่งสี

ใส่รหัสสีภายในการกำหนดค่า appearance เพื่อจัดรูปแบบปุ่ม:

| Appearance value | Result |
|------------------|--------|
| `add_repeat <#04B404/>` | พื้นหลังสีเขียว, สีข้อความตามค่าเริ่มต้น |
| `add_repeat 04B404-ffffff` | พื้นหลังสีเขียว, ข้อความสีขาว |

สีแรกคือพื้นหลัง และสีที่สอง (หลังเครื่องหมายขีด) คือสีข้อความ ไม่ต้องใส่เครื่องหมาย `#` เมื่อใช้รูปแบบที่คั่นด้วยเครื่องหมายขีด

### รูปแบบไอคอน

ใช้ `add_repeat icon` (มีเว้นวรรค) เพื่อแสดงเป็นปุ่มไอคอนรูปวงกลมขนาดกะทัดรัดแทนปุ่มแบบเต็มความกว้าง:

| type | name | label | appearance |
|------|------|-------|------------|
| note | btn_add | + เพิ่ม | `add_repeat icon` |

## ปุ่มลบ: `delete-repeat-current` และ `delete-repeat-last`

ฟิลด์ `note` ภายในกลุ่มการทำซ้ำพร้อมกำหนด `appearance: delete-repeat-current` หรือ `appearance: delete-repeat-last` จะแสดงเป็นปุ่มลบแบบแยกส่วน

| Appearance | Action |
|------------|--------|
| `delete-repeat-current` | ลบชุดข้อมูลปัจจุบัน (ที่เปิดอยู่) |
| `delete-repeat-last` | ลบชุดข้อมูลสุดท้ายในการทำซ้ำ |

ปุ่มเริ่มต้น (ที่ไม่ใช่ไอคอน) จะเป็นปุ่มแบบแยกส่วน: ไอคอนถังขยะทางซ้ายและข้อความป้ายกำกับทางขวา โดยกว้างเต็มหน้าจอ

### รูปแบบไอคอน

ต่อท้ายด้วย `-icon` เพื่อรับปุ่มไอคอนถังขยะรูปวงกลมขนาดกะทัดรัด:

| Appearance | Result |
|------------|--------|
| `delete-repeat-current-icon` | ไอคอนถังขยะรูปวงกลม, ลบชุดข้อมูลปัจจุบัน |
| `delete-repeat-last-icon` | ไอคอนถังขยะรูปวงกลม, ลบชุดข้อมูลสุดท้าย |

### การปรับแต่งสี

รูปแบบสีเหมือนกับ `add_repeat`: ใช้ `<#RRGGBB/>` หรือ `RRGGBB-RRGGBB` (พื้นหลัง-ข้อความ)

### ตัวอย่างรูปแบบเต็ม

การทำซ้ำต่อไปนี้ใช้ `1screen`, ปุ่มลบชุดปัจจุบันรูปวงกลมที่ด้านบน และปุ่มเพิ่มแบบเต็มความกว้างที่ด้านล่าง:

| type | name | label | appearance |
|------|------|-------|------------|
| begin_repeat | members | สมาชิก | `1screen` |
| note | btn_del | ลบออก | `delete-repeat-current-icon` |
| text | member_name | ชื่อสมาชิก | |
| integer | member_age | อายุ | |
| note | btn_add | + เพิ่มสมาชิก | `add_repeat` |
| end_repeat | | | |

## แนวทางปฏิบัติที่แนะนำ (Best Practices)

1. ใช้ `repeat_count` เสมอเมื่อทราบจำนวนการทำซ้ำล่วงหน้า เพื่อป้องกันไม่ให้ผู้เก็บรวบรวมข้อมูลเพิ่มหรือลบชุดข้อมูลโดยไม่ตั้งใจ
2. จัดกลุ่มการทำซ้ำให้กระชับ การทำซ้ำที่มีมากกว่า 20 คำถามต่อชุดจะใช้งานได้ยาก
3. ตั้งชื่อกลุ่มการทำซ้ำให้ชัดเจน (เช่น `household_members` แทนที่จะเป็น `repeat1`) ชื่อนี้จะปรากฏในการเรียกใช้ฟังก์ชันและข้อมูลที่ส่งออก
4. ทดสอบด้วยจำนวนชุดข้อมูลสูงสุดที่คาดไว้เพื่อตรวจสอบประสิทธิภาพการทำงาน
5. ใช้ `1screen` ในแถว `begin_repeat` เพื่อแสดงคำถามทั้งหมดในหน้าจอเดียวต่อหนึ่งชุด ร่วมกับฟิลด์ `add_repeat` ภายในกลุ่มเพื่อให้ผู้เก็บรวบรวมข้อมูลเห็นปุ่ม "เพิ่ม" ที่ชัดเจน

---

## ข้อจำกัด (Limitations)

- `indexed-repeat()` ต้องระบุลำดับ (index) ที่ถูกต้อง (1 ถึงจำนวนชุดทั้งหมด) ลำดับที่อยู่นอกช่วงจะคืนค่าว่าง
- ไม่แนะนำให้ทำซ้ำซ้อนกันเกิน 2 ระดับ เพราะอาจทำให้เกิดปัญหาในการแสดงผลในบางอุปกรณ์
- ฟังก์ชันรวม (`sum`, `count` ฯลฯ) ทำงานกับกลุ่มการทำซ้ำทั้งหมด คุณไม่สามารถรวบรวมข้อมูลเฉพาะบางส่วนได้หากไม่มีรูปแบบที่ลงท้ายด้วย `*-if`

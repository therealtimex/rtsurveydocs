---
title: "Grid-layout"
description: "Grid layout ให้คุณวางฟิลด์ใน CSS grid ภายในกลุ่ม ทำให้สามารถออกแบบแบบฟอร์มหลายคอลัมน์ได้"
---

ฟีเจอร์ **Grid Layout** ให้คุณจัดเรียงคำถามใน **grid หลายคอลัมน์** ภายในกลุ่ม โดยใช้แท็ก appearance `gridformat<>` ซึ่งมีประโยชน์สำหรับแบบฟอร์มป้อนข้อมูลหนาแน่นที่ฟิลด์ที่เกี่ยวข้องหลายฟิลด์ควรปรากฏเคียงข้างกันแทนที่จะเรียงในแนวตั้ง

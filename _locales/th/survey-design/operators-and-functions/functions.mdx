### ฟังก์ชันสตริง (String functions)

<Callout type="warning">
เมื่อทำงานกับสตริงภายในนิพจน์ (expressions) สิ่งสำคัญคือต้องใช้เครื่องหมายอัญประกาศเดี่ยว ('') เพื่อล้อมรอบสตริงที่เป็นข้อความตายตัว (literal strings) อย่างไรก็ตาม มีข้อยกเว้นเมื่อคุณต้องการรวมเครื่องหมายอัญประกาศเดี่ยวไว้ภายในสตริง ในกรณีเช่นนี้ คุณสามารถใช้เครื่องหมายอัญประกาศคู่ ("") เพื่อล้อมรอบสตริงทั้งหมดได้

ตัวอย่างเช่น:
- ถูกต้อง: if(`${yesno}` = 1, "a string with 'single quotes' in it", "no single quotes here")
- ไม่ถูกต้อง: if(`${yesno}` = 1, 'a string with 'single quotes' in it', 'no single quotes here')

เกี่ยวกับเครื่องหมายอัญประกาศแบบอัจฉริยะ (smart quotes) สิ่งสำคัญคือต้องระวังการใช้งาน เนื่องจากอาจทำให้เกิดปัญหาในนิพจน์ได้ โปรแกรมแก้ไขข้อความจำนวนมากจะเปลี่ยนเครื่องหมายอัญประกาศแบบตรง ("" หรือ '') เป็นเครื่องหมายอัญประกาศแบบโค้ง (“” หรือ ‘’) โดยอัตโนมัติ ซึ่งอาจส่งผลให้เกิดข้อผิดพลาดทางไวยากรณ์หรือพฤติกรรมที่ไม่คาดคิด เพื่อหลีกเลี่ยงปัญหานี้ โปรดตรวจสอบให้แน่ใจว่าคุณใช้เครื่องหมายอัญประกาศแบบตรง ('') อย่างสม่ำเสมอในนิพจน์ของคุณ

โปรดแจ้งให้เราทราบหากคุณมีคำถามเพิ่มเติมหรือต้องการความช่วยเหลือ!
</Callout>

rtSurvey รองรับฟังก์ชันต่างๆ มากมาย ดังนี้:

1. `string(field)`: แปลงฟิลด์ให้เป็นสตริง
   - ตัวอย่าง: `string(34.8)` จะถูกแปลงเป็น `'34.8'`

2. `string-length(field)`: คืนค่าความยาวของฟิลด์สตริง
   - ตัวอย่าง: `string-length(.) > 3 and string-length(.) < 10` สามารถใช้เพื่อให้แน่ใจว่าฟิลด์ปัจจุบันมีความยาวระหว่าง 3 ถึง 10 ตัวอักษร
   - **รูปแบบการพึ่งพาแบบลำดับชั้น (Cascade dependency pattern)**: `string-length(${province}) >= 0` จะให้ค่าเป็น `true` เสมอ แต่จะบังคับให้ rtSurvey ประเมินนิพจน์ใหม่ทุกครั้งที่ค่าของ `${province}` เปลี่ยนแปลง ใช้สิ่งนี้ในช่อง `relevant` เพื่อกระตุ้นการรีเฟรชแบบลำดับชั้นเมื่อฟิลด์หลักมีการอัปเดต:
     | type | name | relevant |
     |------|------|----------|
     | select_one | district | `string-length(${province}) >= 0` |
     สิ่งนี้ช่วยให้แน่ใจว่าคำถามเกี่ยวกับอำเภอ (district) จะประเมินค่า appearance แบบ `search()` หรือ `rawquery` ใหม่ทุกครั้งที่จังหวัด (province) เปลี่ยนแปลง

3. `substr(fieldorstring, startindex, endindex)`: คืนค่าสตริงย่อย (substring) โดยเริ่มที่ `startindex` และสิ้นสุดก่อนถึง `endindex` ตำแหน่งดัชนี (Index) เริ่มต้นที่ 0 สำหรับตัวอักษรแรกในสตริง
   - ตัวอย่าง: `substr(${phone}, 0, 3)` จะคืนค่าตัวเลขสามหลักแรกของหมายเลขโทรศัพท์

4. `concat(a, b, c, ...)`: เชื่อมต่อฟิลด์ (และ/หรือสตริง) เข้าด้วยกัน
   - ตัวอย่าง: `concat(${firstname}, ' ', ${lastname})` จะคืนค่าชื่อนามสกุลแบบเต็มโดยการรวมค่าในฟิลด์ `firstname` และ `lastname` เข้าด้วยกัน

5. `linebreak()`: คืนค่าอักขระขึ้นบรรทัดใหม่
   - ตัวอย่าง: `concat(${field1}, linebreak(), ${field2}, linebreak(), ${field3})` จะคืนค่าของทั้งสามฟิลด์พร้อมการขึ้นบรรทัดใหม่คั่นระหว่างกัน

6. `lower()`: แปลงสตริงให้เป็นตัวพิมพ์เล็กทั้งหมด
   - ตัวอย่าง: `lower('Street Name')` จะคืนค่า "street name"

7. `upper()`: แปลงสตริงให้เป็นตัวพิมพ์ใหญ่ทั้งหมด
   - ตัวอย่าง: `upper('Street Name')` จะคืนค่า "STREET NAME"

### ฟังก์ชันสำหรับ select_one และ select_multiple

1. `count-selected(field)`: คืนค่าจำนวนรายการที่ถูกเลือกในฟิลด์ select_multiple
   - ตัวอย่าง: `count-selected(.) = 3` สามารถใช้เป็นนิพจน์ในช่อง `constraint` เพื่อให้แน่ใจว่ามีการเลือกตัวเลือกตรงตาม 3 ตัวเลือกพอดี

2. `selected(field, value)`: คืนค่า true หรือ false ขึ้นอยู่กับว่าค่าที่ระบุนั้นถูกเลือกในฟิลด์ select_one หรือ select_multiple หรือไม่
   - ตัวอย่าง: `selected(${color}, 'Blue')` สามารถใช้เป็นนิพจน์ในช่อง `relevant` เพื่อแสดงกลุ่มหรือฟิลด์เฉพาะในกรณีที่ผู้ตอบเลือก "Blue" เป็นสีที่ชอบ
   - หมายเหตุ: พารามิเตอร์ตัวที่สองควรระบุค่าของตัวเลือก (choice value) เสมอ ไม่ใช่ป้ายชื่อตัวเลือก (choice label) โดยให้ใช้ค่าจากคอลัมน์ value ในเวิร์กชีต choices ของไฟล์นิยามแบบฟอร์ม

3. `selected-at(field, number)`: คืนค่ารายการที่ถูกเลือก ณ ตำแหน่งที่ระบุในฟิลด์ select_multiple เมื่อระบุตัวเลขเป็น 0 จะคืนค่ารายการแรกที่ถูกเลือก เมื่อเป็น 1 จะคืนค่ารายการที่สอง และเป็นเช่นนี้ต่อไป
   - ตัวอย่าง: `selected-at(${fruits}, 0) = 'Apple'` สามารถใช้เป็นนิพจน์ในช่อง `relevant` เพื่อแสดงกลุ่มหรือฟิลด์เฉพาะในกรณีที่ตัวเลือกแรกที่ถูกเลือกคือ "Apple"
   - หมายเหตุ: ค่าที่ส่งกลับมาจะเป็นค่าของตัวเลือก ไม่ใช่ป้ายชื่อตัวเลือก โดยให้ใช้ค่าจากคอลัมน์ value ในเวิร์กชีต choices ของไฟล์นิยามแบบฟอร์ม

4. `choice-label(field, value)`: คืนค่าป้ายชื่อ (label) สำหรับตัวเลือกของฟิลด์ select_one หรือ select_multiple ตามที่กำหนดไว้ในเวิร์กชีต choices ของไฟล์นิยามแบบฟอร์ม
   - ตัวอย่างที่ 1: `choice-label(${country}, ${country})` จะคืนค่าป้ายชื่อตัวเลือกสำหรับตัวเลือกที่เลือกอยู่ในฟิลด์ชื่อ `country`
   - ตัวอย่างที่ 2: `choice-label(${languages}, selected-at(${languages}, 0))` จะคืนค่าป้ายชื่อสำหรับตัวเลือกแรกที่ถูกเลือกในฟิลด์ชื่อ `languages`
   - หมายเหตุ: ฟังก์ชันนี้จะดึงป้ายชื่อตัวเลือกออกมา ไม่ใช่ค่าของตัวเลือก โดยจะใช้คอลัมน์ label จากเวิร์กชีต choices ของไฟล์นิยามแบบฟอร์ม

### ฟังก์ชันสำหรับฟิลด์ที่มีการทำซ้ำ (Repeated field functions)

ใน rtSurvey หากคุณต้องการถามคำถามเดิมซ้ำหลายๆ ครั้ง คุณสามารถใส่ฟิลด์นั้นไว้ภายในกลุ่มทำซ้ำ (repeat group) ซึ่งจะส่งผลให้มีอินสแตนซ์ของฟิลด์เดียวกันเกิดขึ้นหลายรายการ ฟังก์ชันต่อไปนี้สามารถช่วยคุณจัดการกับฟิลด์ที่ทำซ้ำเหล่านี้และข้อมูลที่เกิดขึ้นจากการทำซ้ำได้ ดูรายละเอียดเพิ่มเติมได้ในหัวข้อช่วยเหลือเกี่ยวกับฟิลด์ที่ทำซ้ำ

1. `join(string, repeatedfield)`: สำหรับฟิลด์ภายในกลุ่มทำซ้ำ จะสร้างรายการของค่าต่างๆ ที่แยกด้วยสตริง พารามิเตอร์ตัวแรกระบุตัวคั่น (delimiter) ที่จะใช้ในการแยกแต่ละค่า
   - ตัวอย่าง: `join(', ', ${member_name})` จะสร้างรายการชื่อทั้งหมดที่คั่นด้วยเครื่องหมายจุลภาคเพียงรายการเดียว

2. `join-if(string, repeatedfield, expression)`: ทำงานเหมือนกับ `join()` ทุกประการ เว้นแต่จะมีการตรวจสอบแต่ละอินสแตนซ์ในกลุ่มทำซ้ำโดยใช้นิพจน์ที่ระบุ หากนิพจน์มีค่าเป็น false รายการนั้นจะถูกตัดออกจากการแสดงผล
   - ตัวอย่าง: `join-if(', ', ${member_name}, ${age} >= 18)` จะสร้างรายการชื่อที่แยกด้วยเครื่องหมายจุลภาคเฉพาะสมาชิกที่เป็นผู้ใหญ่เท่านั้น (ผู้ที่มีอายุตั้งแต่ 18 ปีขึ้นไป)

3. `count(repeatgroup)`: คืนค่าจำนวนครั้งปัจจุบันที่มีการทำซ้ำของกลุ่มทำซ้ำ
   - ตัวอย่าง: `count(${groupname})` จะคืนค่าจำนวนอินสแตนซ์ของกลุ่มนั้น

4. `count-if(repeatgroup, expression)`: ทำงานเหมือนกับ `count()` ทุกประการ เว้นแต่จะมีการตรวจสอบแต่ละอินสแตนซ์ในกลุ่มทำซ้ำโดยใช้นิพจน์ที่ระบุ หากนิพจน์มีค่าเป็น false รายการนั้นจะไม่ถูกนับ
   - ตัวอย่าง: `count-if(${members}, ${age} >= 18)` จะคืนค่าจำนวนสมาชิกที่เป็นผู้ใหญ่โดยอิงจากฟิลด์อายุภายในกลุ่มทำซ้ำ "members"

5. `sum(repeatedfield)`: สำหรับฟิลด์ภายในกลุ่มทำซ้ำ จะคำนวณผลรวมของค่าทั้งหมด
   - ตัวอย่าง: `sum(${loan_amount})` จะคืนค่ามูลค่ารวมของสินเชื่อทั้งหมด

6. `sum-if(repeatedfield, expression)`: ทำงานเหมือนกับ `sum()` ทุกประการ เว้นแต่จะมีการตรวจสอบแต่ละอินสแตนซ์ในกลุ่มทำซ้ำโดยใช้นิพจน์ที่ระบุ หากนิพจน์มีค่าเป็น false รายการนั้นจะถูกข้ามไปในการคำนวณผลรวม
   - ตัวอย่าง: `sum-if(${loan_amount}, ${loan_amount} > 500)` จะคืนค่ามูลค่ารวมของสินเชื่อทั้งหมดที่มีมูลค่ามากกว่า 500 ส่วนสินเชื่อที่มีมูลค่าน้อยกว่านั้นจะถูกละเว้น

7. `min(repeatedfield)`: สำหรับฟิลด์ภายในกลุ่มทำซ้ำ จะคำนวณหาค่าต่ำสุดของค่าทั้งหมด
   - ตัวอย่าง: `min(${member_age})` จะคืนค่าอายุของสมาชิกที่อายุน้อยที่สุดในกลุ่ม

8. `min-if(repeatedfield, expression)`: ทำงานเหมือนกับ `min()` ทุกประการ เว้นแต่จะมีการตรวจสอบแต่ละอินสแตนซ์ในกลุ่มทำซ้ำโดยใช้นิพจน์ที่ระบุ หากนิพจน์มีค่าเป็น false รายการนั้นจะถูกข้ามไปในการหาค่าต่ำสุด
   - ตัวอย่าง: `min-if(${member_age}, ${member_age} >= 18)` จะคืนค่าอายุของผู้ใหญ่ที่อายุน้อยที่สุดในกลุ่ม ผู้ที่มีอายุน้อยกว่า 18 ปีจะถูกละเว้น

9. `max(repeatedfield)`: สำหรับฟิลด์ภายในกลุ่มทำซ้ำ จะคำนวณหาค่าสูงสุดของค่าทั้งหมด
   - ตัวอย่าง: `max(${member_age})` จะคืนค่าอายุของสมาชิกที่อายุมากที่สุดในกลุ่ม

10. `max-if(repeatedfield, expression)`: ทำงานเหมือนกับ `max()` ทุกประการ เว้นแต่จะมีการตรวจสอบแต่ละอินสแตนซ์ในกลุ่มทำซ้ำโดยใช้นิพจน์ที่ระบุ หากนิพจน์มีค่าเป็น false รายการนั้นจะถูกข้ามไปในการหาค่าสูงสุด
    - ตัวอย่าง: `max-if(${member_age}, ${member_age} >= 18)` จะคืนค่าอายุของผู้ใหญ่ที่อายุมากที่สุดในกลุ่ม ผู้ที่มีอายุน้อยกว่า 18 ปีจะถูกละเว้น

11. `index()`: เมื่อเรียกใช้ภายในกลุ่มทำซ้ำ จะคืนค่าหมายเลขดัชนีสำหรับกลุ่มหรืออินสแตนซ์ปัจจุบัน
    - ตัวอย่าง: `index()` เมื่อใช้ภายในกลุ่มทำซ้ำจะคืนค่าเป็น 1 สำหรับอินสแตนซ์แรก 2 สำหรับอินสแตนซ์ที่สอง และเป็นเช่นนี้ต่อไป

12. `indexed-repeat(repeatedfield, repeatgroup, index)`: อ้างอิงถึงฟิลด์หรือกลุ่มที่อยู่ภายในกลุ่มทำซ้ำจากภายนอกกลุ่มนั้น พารามิเตอร์ตัวแรกระบุฟิลด์หรือกลุ่มที่ต้องการ พารามิเตอร์ตัวที่สองระบุกลุ่มทำซ้ำที่ฟิลด์หรือกลุ่มนั้นตั้งอยู่ และพารามิเตอร์ตัวที่สามระบุหมายเลขลำดับอินสแตนซ์ภายในกลุ่มทำซ้ำที่ต้องการนำมาใช้
    - ตัวอย่างที่ 1: `indexed-repeat(${name}, ${names}, 1)` จะคืนค่าชื่อแรกที่มีอยู่ในฟิลด์ชื่อซึ่งอยู่ภายในกลุ่มทำซ้ำก่อนหน้าชื่อ "names"
    - ตัวอย่างที่ 2: `indexed-repeat(${name}, ${names}, index())` จะดึงชื่อที่ตรงกับหมายเลขลำดับอินสแตนซ์ของกลุ่มทำซ้ำปัจจุบัน

13. `rank-index(index, repeatedfield)`: ฟังก์ชันนี้จะคำนวณลำดับที่ (ordinal rank) ของอินสแตนซ์ที่ระบุของฟิลด์ที่มีการทำซ้ำเพื่อใช้ภายนอกกลุ่มทำซ้ำ ลำดับที่ 1 จะถูกกำหนดให้กับอินสแตนซ์ที่มีค่าสูงสุด ลำดับที่ 2 สำหรับค่ารองลงมา และเป็นเช่นนี้ต่อไป หากคุณระบุดัชนีที่ไม่ถูกต้องหรือดัชนีไปยังอินสแตนซ์ที่ไม่มีค่าเป็นตัวเลข ระบบจะส่งคืนลำดับที่ 999
    - ตัวอย่าง: `rank-index(1, ${random_draw})` คำนวณลำดับของอินสแตนซ์แรกตามค่าของฟิลด์ `random_draw` เมื่อเทียบกับค่าของอินสแตนซ์อื่นๆ

14. `rank-index-if(index, repeatedfield, expression)`: ฟังก์ชันนี้ทำงานคล้ายกับ `rank-index()` แต่จะตรวจสอบแต่ละอินสแตนซ์ในกลุ่มทำซ้ำของฟิลด์ด้วยนิพจน์ที่ระบุ หากนิพจน์เป็น false รายการนั้นจะถูกตัดออกจากการคำนวณ ดัชนีที่ใช้จะอ้างอิงตามชุดอินสแตนซ์ทั้งหมดก่อนที่จะประเมินนิพจน์สำหรับแต่ละอินสแตนซ์ หากคุณส่งดัชนีสำหรับอินสแตนซ์ที่ถูกละเว้นเนื่องจากไม่เป็นไปตามเงื่อนไขของนิพจน์ จะถือว่าเป็นดัชนีที่ไม่ถูกต้องและจะส่งคืนลำดับที่ 999
    - ตัวอย่าง: `rank-index-if(1, ${age}, ${age} >= 18)` คำนวณลำดับอายุภายในกลุ่มของผู้ใหญ่ โดยพิจารณาเฉพาะอินสแตนซ์ที่มีอายุมากกว่าหรือเท่ากับ 18 ปี

### ฟังก์ชันตัวเลข (Number functions)

| ตัวดำเนินการ | การดำเนินการ | ตัวอย่าง | คำตอบตัวอย่าง |
|----------|-----------|---------|----------------|
| `+` | การบวก | 1 + 1 | 2 |
| `-` | การลบ | 3 - 2 | 1 |
| `*` | การคูณ | 3 * 2 | 6 |
| `div` | การหาร | 10 div 2 | 5 |
| `mod` | มอดูลัส (เศษจากการหาร) | 9 mod 2 | 1 |

rtSurvey รองรับฟังก์ชันตัวเลข ดังนี้:
- `number(field)`: แปลงค่าของฟิลด์ให้เป็นตัวเลข
  - ตัวอย่าง: `number('34.8')` = 34.8

- `int(field)`: แปลงค่าของฟิลด์ให้เป็นจำนวนเต็ม
  - ตัวอย่าง: `int('39.2')` = 39

- `min(field1, ..., fieldx)`: คืนค่าต่ำสุดในบรรดาฟิลด์ที่ระบุ
  - ตัวอย่าง: `min(${father_age}, ${mother_age})` จะคืนค่าอายุของพ่อหรือแม่ คนที่อายุน้อยกว่า

- `max(field1, ..., fieldx)`: คืนค่าสูงสุดในบรรดาฟิลด์ที่ระบุ
  - ตัวอย่าง: `max(${father_age}, ${mother_age})` จะคืนค่าอายุของพ่อหรือแม่ คนที่อายุมากกว่า

- `format-number(field)`: จัดรูปแบบค่าของฟิลด์จำนวนเต็มหรือทศนิยมตามการตั้งค่าภาษา (locale) ของผู้ใช้
  - ตัวอย่าง: `format-number(${income})` นิพจน์นี้อาจจัดรูปแบบ "120000" เป็น "120,000"

- `round(field, digits)`: ปัดเศษค่าฟิลด์ตัวเลขตามจำนวนตำแหน่งทศนิยมที่ระบุ
  - ตัวอย่าง: `round(${interest_rate}, 2)`

- `abs(number)`: คืนค่าสัมบูรณ์ของตัวเลข
  
- `pow(base, exponent)`: คืนค่าของพารามิเตอร์แรกยกกำลังด้วยพารามิเตอร์ที่สอง
  - แต่ละพารามิเตอร์สามารถเป็นฟิลด์ ตัวเลข หรือนิพจน์ได้

- `log10(fieldorvalue)`: คืนค่าลอการิทึมฐานสิบของฟิลด์หรือค่าที่ระบุ

- `sin(fieldorvalue)`: คืนค่าไซน์ของฟิลด์หรือค่าที่ระบุ ในหน่วยเรเดียน (radians)
  
- `cos(fieldorvalue)`: คืนค่าโคไซน์ของฟิลด์หรือค่าที่ระบุ ในหน่วยเรเดียน
  
- `tan(fieldorvalue)`: คืนค่าแทนเจนต์ของฟิลด์หรือค่าที่ระบุ ในหน่วยเรเดียน

- `asin(fieldorvalue)`: คืนค่าอาร์กไซน์ของฟิลด์หรือค่าที่ระบุ ในหน่วยเรเดียน

- `acos(fieldorvalue)`: คืนค่าอาร์กโคไซน์ของฟิลด์หรือค่าที่ระบุ ในหน่วยเรเดียน

- `atan(fieldorvalue)`: คืนค่าอาร์กแทนเจนต์ของฟิลด์หรือค่าที่ระบุ ในหน่วยเรเดียน

- `atan2(x, y)`: คืนค่ามุมในหน่วยเรเดียนที่จุดพิกัด (x, y) กระทำกับจุดกำเนิดและแกน x ฝั่งบวก ผลลัพธ์อยู่ในช่วง -pi() ถึง pi()

- `sqrt(fieldorvalue)`: คืนค่ารากที่สองที่เป็นบวกของฟิลด์หรือค่าที่ระบุ

- `exp(x)`: คืนค่าของ e^x

- `pi()`: คืนค่าพาย (pi)

### ฟังก์ชันวันที่และเวลา (Date and time functions)

<Callout type="warning">
ค่าวันที่ใน rtSurvey จะถูกจัดเก็บเป็นสตริงในรูปแบบ `YYYY-MM-DD` ค่าวันเวลา (Datetime) จะถูกจัดเก็บเป็นสตริง ISO 8601 (`YYYY-MM-DDTHH:MM:SS`) ให้ใช้ `decimal-date-time()` เพื่อแปลงเป็นตัวเลขสำหรับการคำนวณทางคณิตศาสตร์ (เช่น การคำนวณระยะเวลา)
</Callout>

1. `today()`: คืนค่าวันที่ของวันนี้เป็นสตริงในรูปแบบ `YYYY-MM-DD` ประเมินค่าเพียงครั้งเดียวเมื่อเปิดแบบฟอร์ม
   - ตัวอย่าง: `today()` → `'2024-03-15'`
   - การใช้งานทั่วไป: ใช้ในคอลัมน์ `default` เพื่อกรอกวันที่วันนี้ไว้ล่วงหน้า หรือใช้ใน `relevant`/`constraint` เพื่อเปรียบเทียบกับฟิลด์วันที่

2. `now()`: คืนค่าวันที่และเวลาปัจจุบันเป็นสตริง ISO 8601 ประเมินค่าทุกครั้งที่มีการคำนวณนิพจน์
   - ตัวอย่าง: `now()` → `'2024-03-15T14:32:00.000+03:00'`
   - การใช้งานทั่วไป: บันทึกเวลาที่แน่นอนของเหตุการณ์เฉพาะในระหว่างการสำรวจ

3. `date(value)`: แปลงค่า (สตริงหรือตัวเลข) ให้เป็นสตริงวันที่ มีประโยชน์สำหรับการบังคับค่าที่คำนวณได้ให้เป็นประเภทวันที่
   - ตัวอย่าง: `date('2024-03-15')` → `'2024-03-15'`

4. `date-time(value)`: แปลงค่าให้เป็นสตริงวันเวลา (datetime)
   - ตัวอย่าง: `date-time(${event_timestamp})`

5. `decimal-date-time(value)`: แปลงสตริงวันที่หรือวันเวลาให้เป็นตัวเลขทศนิยมที่แสดงถึงจำนวนมิลลิวินาทีนับตั้งแต่ Unix epoch หารด้วย 86400000 (นั่นคือ จำนวนวันรวมเศษทศนิยมนับตั้งแต่ 1970-01-01) ใช้สิ่งนี้เพื่อดำเนินการทางคณิตศาสตร์กับวันที่
   - ตัวอย่าง: ระยะเวลาเป็นจำนวนวันระหว่างสองวันที่:
     `decimal-date-time(${end_date}) - decimal-date-time(${start_date})`
   - ตัวอย่าง: ระยะเวลาเป็นนาทีระหว่างสองวันเวลา:
     `(decimal-date-time(${end_time}) - decimal-date-time(${start_time})) * 1440`

6. `format-date(date, format)`: จัดรูปแบบค่าวันที่โดยใช้สตริงรูปแบบ (pattern string)
   - รหัสรูปแบบ (Format tokens): `%Y` (ปี 4 หลัก), `%y` (ปี 2 หลัก), `%m` (เดือน 01–12), `%d` (วันที่ 01–31), `%a` (ชื่อวันแบบย่อ), `%b` (ชื่อเดือนแบบย่อ)
   - ตัวอย่าง: `format-date(today(), '%d/%m/%Y')` → `'15/03/2024'`
   - ตัวอย่าง: `format-date(${dob}, '%B %d, %Y')` → `'March 15, 1990'`

7. `format-date-time(datetime, format)`: จัดรูปแบบค่าวันเวลาโดยใช้สตริงรูปแบบ รองรับรหัสรูปแบบทั้งหมดของ `format-date` และเพิ่มเติมดังนี้:
   - `%H` (ชั่วโมง 00–23), `%h` (ชั่วโมง 01–12), `%M` (นาที 00–59), `%S` (วินาที 00–59), `%3` (มิลลิวินาที), `%P` (AM/PM)
   - ตัวอย่าง: `format-date-time(now(), '%d/%m/%Y %H:%M')` → `'15/03/2024 14:32'`
   - ตัวอย่าง: `format-date-time(${event_time}, '%I:%M %p')` → `'02:32 PM'`

8. `STRFTIME(format, datetime)`: การจัดรูปแบบวันที่แบบ SQLite ใช้ได้ภายในสตริง SQL ที่ส่งไปยังคำสั่ง `rawquery` — **ไม่** สามารถใช้ในคอลัมน์ `calculation` หรือ `label` ของ XLSForm ได้ ใช้รหัสรูปแบบของ SQLite (`%Y`, `%m`, `%d`, `%H`, `%M`, `%S`)
   - ตัวอย่างภายในสตริง SQL ของ rawquery: `'SELECT STRFTIME(''%Y-%m'', interview_date) AS month FROM data WHERE id = ?'`
   - หมายเหตุ: ให้ใช้ `format-date-time()` สำหรับการจัดรูปแบบวันที่ในนิพจน์ XLSForm โดย `STRFTIME()` เป็นฟังก์ชัน SQLite ที่ใช้ได้เฉพาะภายใน SQL ที่ส่งไปยัง `rawquery` เท่านั้น

### ฟังก์ชันบูลีน (Boolean functions)

1. `boolean(value)`: แปลงค่าใดๆ ให้เป็นค่าบูลีน คืนค่า `true` สำหรับสตริงที่ไม่ว่างเปล่า, ตัวเลขที่ไม่ใช่ศูนย์ และค่า `true`; คืนค่า `false` สำหรับสตริงว่าง, `0` และค่า `false`
   - ตัวอย่าง: `boolean(${name})` คืนค่า `true` หาก `name` ไม่ว่างเปล่า

2. `boolean-from-string(string)`: คืนค่า `true` หากสตริงคือ `'1'` หรือ `'true'` (ไม่คำนึงถึงตัวพิมพ์เล็ก-ใหญ่); คืนค่า `false` ในกรณีอื่นๆ
   - ตัวอย่าง: `boolean-from-string(${enabled_flag})` — มีประโยชน์เมื่อฟิลด์เก็บค่า `'true'`/`'false'` เป็นข้อความ

3. `true()`: คืนค่าบูลีน `true`
   - ตัวอย่าง: ในคอลัมน์ `required`, `true()` มีค่าเทียบเท่ากับ `yes`

4. `false()`: คืนค่าบูลีน `false`
   - ตัวอย่าง: `if(${skip_section} = 'yes', false(), true())` — ตั้งค่า required แบบไดนามิก

5. `not(expression)`: คืนค่าปฏิเสธทางตรรกะของนิพจน์ คืนค่า `true` ถ้านิพจน์เป็น false และในทางกลับกัน
   - ตัวอย่าง: `not(${consent} = 'yes')` — แสดงคำเตือนเมื่อไม่ได้ให้ความยินยอม
   - ตัวอย่าง: `not(selected(${issues}, 'none'))` — กำหนดให้ระบุรายละเอียดเฉพาะในกรณีที่ไม่ได้เลือก "none"

### ฟังก์ชันสตริงเพิ่มเติม (Additional string functions)

1. `starts-with(string, prefix)`: คืนค่า `true` หากสตริงเริ่มต้นด้วยคำนำหน้า (prefix) ที่ระบุ
   - ตัวอย่าง: `starts-with(${phone}, '+254')` ตรวจสอบว่าหมายเลขโทรศัพท์ขึ้นต้นด้วยรหัสประเทศเคนยาหรือไม่

2. `contains(string, substring)`: คืนค่า `true` หากสตริงมีสตริงย่อย (substring) ที่ระบุอยู่ภายใน
   - ตัวอย่าง: `contains(${email}, '@')` ตรวจสอบว่าที่อยู่อีเมลมีเครื่องหมาย `@` หรือไม่
   - ตัวอย่าง: `contains(${notes}, 'urgent')` กระตุ้นคำถามติดตามผลหากมีการระบุคำว่า "urgent" ในบันทึก

3. `substring-before(string, needle)`: คืนค่าส่วนของสตริงที่ปรากฏก่อนการพบ `needle` ครั้งแรก
   - ตัวอย่าง: `substring-before(${full_name}, ' ')` ดึงคำแรกออกมา (ชื่อจริง)

4. `substring-after(string, needle)`: คืนค่าส่วนของสตริงที่ปรากฏหลังการพบ `needle` ครั้งแรก
   - ตัวอย่าง: `substring-after(${email}, '@')` ดึงส่วนของโดเมนจากที่อยู่อีเมลออกมา

5. `normalize-space(string)`: ตัดช่องว่างส่วนหน้าและส่วนท้ายออก และยุบชุดช่องว่างภายในทั้งหมดให้เหลือเพียงช่องว่างเดียว
   - ตัวอย่าง: `normalize-space(${name})` — ล้างข้อมูลชื่อที่อาจพิมพ์ด้วยช่องว่างส่วนเกิน

6. `translate(string, search_chars, replace_chars)`: แทนที่อักขระแต่ละตัวในสตริงที่ปรากฏใน `search_chars` ด้วยอักขระที่สอดคล้องกันใน `replace_chars` อักขระใน `search_chars` ที่ไม่มีอักขระที่สอดคล้องกันใน `replace_chars` จะถูกลบออก
   - ตัวอย่าง: `translate(${code}, 'abcdefghijklmnopqrstuvwxyz', 'ABCDEFGHIJKLMNOPQRSTUVWXYZ')` แปลงเป็นตัวพิมพ์ใหญ่ (เทียบเท่ากับ `upper()`)
   - ตัวอย่าง: `translate(${phone}, ' -()', '')` ลบช่องว่าง ขีดกลาง และวงเล็บออกจากหมายเลขโทรศัพท์

### ฟังก์ชันคณิตศาสตร์เพิ่มเติม (Additional math functions)

1. `floor(number)`: คืนค่าจำนวนเต็มที่มากที่สุดที่น้อยกว่าหรือเท่ากับตัวเลขนั้น (ปัดเศษลงเข้าหาค่าลบอินฟินิตี้)
   - ตัวอย่าง: `floor(4.9)` = 4, `floor(-2.1)` = -3

2. `ceiling(number)`: คืนค่าจำนวนเต็มที่น้อยที่สุดที่มากกว่าหรือเท่ากับตัวเลขนั้น (ปัดเศษขึ้นเข้าหาค่าบวกอินฟินิตี้)
   - ตัวอย่าง: `ceiling(4.1)` = 5, `ceiling(-2.9)` = -2

3. `random()`: คืนค่าตัวเลขทศนิยมแบบสุ่มระหว่าง 0.0 (รวม) และ 1.0 (ไม่รวม) โดยทั่วไปจะใช้ในฟิลด์ `calculate` เพื่อกำหนดค่าสุ่มหรือสุ่มลำดับคำถาม
   - ตัวอย่าง: `random()` → เช่น `0.7341`
   - ตัวอย่าง: `int(random() * 6) + 1` → ตัวเลขสุ่ม 1–6 (การทอยลูกเต๋า)

4. `coalesce(a, b)`: คืนค่า `a` หาก `a` ไม่ว่างเปล่า; มิฉะนั้นจะคืนค่า `b` มีประโยชน์สำหรับใช้เป็นค่าสำรองเมื่อฟิลด์อาจไม่มีข้อมูล
   - ตัวอย่าง: `coalesce(${preferred_name}, ${full_name})` — ใช้ชื่อที่ชอบหากตั้งค่าไว้ มิฉะนั้นให้ใช้ชื่อเต็ม

5. `once(value)`: ประเมินค่าและจัดเก็บไว้ แต่จะทำก็ต่อเมื่อฟิลด์ปัจจุบัน **ว่างเปล่า** เท่านั้น หากฟิลด์มีค่าอยู่แล้ว (เช่น เคยถูกตั้งค่าไว้ก่อนหน้า) `once()` จะคืนค่าเดิมโดยไม่เปลี่ยนแปลง สิ่งนี้ช่วยป้องกันไม่ให้การคำนวณใหม่เขียนทับข้อมูลที่ผู้ใช้ป้อน
   - ตัวอย่าง: `once(today())` ในคอลัมน์ `default` จะตั้งค่าวันที่วันนี้เพียงครั้งเดียว และจะไม่อัปเดตหากผู้สำรวจเปิดแบบฟอร์มขึ้นมาใหม่
   - ตัวอย่าง: `once(uuid())` จะสร้าง UUID เพียงครั้งเดียวและคงค่าไว้แม้จะมีการแก้ไขข้อมูลใหม่

### ฟังก์ชันภูมิศาสตร์ (Geo functions)

1. `area(geoshape_value)`: คำนวณ **พื้นที่เป็นตารางเมตร** ที่ล้อมรอบด้วยค่า geoshape (รูปหลายเหลี่ยม)
   - พารามิเตอร์คือค่าฟิลด์ geoshape ในรูปแบบ `lat1 lon1 0 0; lat2 lon2 0 0; ...`
   - ตัวอย่าง: `area(${field_boundary})` — คำนวณพื้นที่ของแปลงนาที่สำรวจในหน่วย ตร.ม.
   - ตัวอย่าง: `round(area(${field_boundary}) div 10000, 2)` — แปลงเป็นหน่วยเฮกตาร์

2. `distance(coordinates)`: คำนวณ **ระยะทางรวมเป็นเมตร** ของ geotrace (เส้น) หรือระยะห่างระหว่างจุด geopoint สองจุด
   - สำหรับ geotrace: `distance(${route})` คืนค่าระยะทางรวมเป็นเมตร
   - สำหรับ geopoint สองจุด: `distance(concat(${point_a}, ' ', ${point_b}))` คืนค่าระยะห่างระหว่างจุดทั้งสอง
   - ตัวอย่าง: `round(distance(${road_trace}) div 1000, 3)` — ระยะทางถนนเป็นกิโลเมตร

### ฟังก์ชันการตรวจสอบความถูกต้อง (Validation functions)

1. `regex(value, pattern)`: คืนค่า `true` หากค่าตรงตามรูปแบบนิพจน์ปกติ (regular expression pattern) ใช้ในคอลัมน์ `constraint` สำหรับการตรวจสอบตามรูปแบบ
   - รูปแบบใช้ไวยากรณ์ regex มาตรฐาน (POSIX ERE subset)
   - ตัวอย่าง: `regex(., '^[0-9]{10}$')` — ตรวจสอบตัวเลข 10 หลัก
   - ตัวอย่าง: `regex(., '^[A-Z]{2}[0-9]{6}$')` — ตรวจสอบรูปแบบหมายเลขพาสปอร์ต (ตัวพิมพ์ใหญ่ 2 ตัวตามด้วยตัวเลข 6 หลัก)
   - ตัวอย่าง: `regex(., '^[^@]+@[^@]+\.[^@]{2,}$')` — ตรวจสอบรูปแบบอีเมลเบื้องต้น

2. `checklist(min, max, v1, v2, ...)`: ประเมินรายการนิพจน์บูลีนและคืนค่า `true` หากจำนวนค่าที่เป็น `true` อยู่ระหว่าง `min` และ `max` (รวมค่าขอบ) ระบุ `-1` สำหรับ `min` หรือ `max` เพื่อข้ามขอบเขตนั้น
   - ตัวอย่าง: `checklist(2, 3, ${q1} = 'yes', ${q2} = 'yes', ${q3} = 'yes')` — ผ่านหากเงื่อนไข 2 หรือ 3 ข้อเป็นจริง
   - ตัวอย่าง: `checklist(1, -1, ${smoke_alarm}, ${fire_ext}, ${emergency_plan})` — ต้องมีมาตรการความปลอดภัยอย่างน้อยหนึ่งอย่างที่เป็นจริง

3. `weighted-checklist(min, max, v1, w1, v2, w2, ...)`: คล้ายกับ `checklist()` แต่แต่ละค่าจะมีน้ำหนัก (weight) ผลรวมของน้ำหนักสำหรับค่าที่เป็น `true` จะต้องอยู่ระหว่าง `min` และ `max`
   - ตัวอย่าง: `weighted-checklist(10, -1, ${has_toilet}, 4, ${has_sink}, 3, ${has_shower}, 5)` — ผลรวมน้ำหนักของสิ่งอำนวยความสะดวกที่มีอยู่ต้องมีค่าอย่างน้อย 10

### ฟังก์ชันยูทิลิตี้ (Utility functions)

1. `uuid()`: สร้าง UUID แบบสุ่ม (รูปแบบ RFC 4122 v4) ในรูปแบบสตริง
   - ตัวอย่าง: `uuid()` → `'a3f8b2c1-4d5e-6f7a-8b9c-0d1e2f3a4b5c'`
   - โดยทั่วไปจะใช้ร่วมกับ `once()` เพื่อสร้างรหัสเฉพาะที่ไม่เปลี่ยนแปลง: `once(uuid())`

2. `version()`: คืนค่าของแอตทริบิวต์ `version` ของแบบฟอร์มตามที่กำหนดไว้ในเวิร์กชีต settings
   - ตัวอย่าง: `version()` → `'3.1'`
   - มีประโยชน์ในฟิลด์ `calculate` เพื่อฝังเวอร์ชันของแบบฟอร์มลงในข้อมูลที่ส่งออก

3. `position()`: เมื่อเรียกใช้ภายใน **กลุ่มทำซ้ำ**, จะคืนค่าดัชนีของอินสแตนซ์ปัจจุบันโดยเริ่มจาก 1
   - ตัวอย่าง: `position()` ในอินสแตนซ์แรกจะคืนค่า `1`, อินสแตนซ์ที่สองคืนค่า `2` และเป็นเช่นนี้ต่อไป
   - ดูเพิ่มเติม: `index()` (ชื่อเรียกอื่น), `indexed-repeat()` สำหรับการอ้างอิงค่าการทำซ้ำจากภายนอกกลุ่ม

4. `thousandsep(length, separator, value)`: จัดรูปแบบตัวเลขด้วยตัวคั่นหลักพัน `length` คือความยาวรวมขั้นต่ำของสตริง (เติมช่องว่างหากสั้นกว่า), `separator` คืออักขระที่ใช้ (เช่น `','`), และ `value` คือตัวเลขที่จะจัดรูปแบบ
   - ตัวอย่าง: `thousandsep(0, ',', 1234567)` → `'1,234,567'`
   - ตัวอย่าง: `thousandsep(0, '.', ${income})` → จัดรูปแบบรายได้ด้วยจุดเป็นตัวคั่นหลักพัน

5. `substr-jsonpath(value, jsonpath)`: ดึงค่าจากสตริง JSON โดยใช้นิพจน์ JSONPath
   - `value` ต้องเป็นสตริง JSON (เช่น ฟิลด์ที่เก็บข้อมูลตอบกลับแบบดิบจาก API โดยใช้ `callapi(..., 'json:', ...)`)
   - `jsonpath` คือนิพจน์ JSONPath (เช่น `'$.data.name'`, `'$.items[0].id'`)
   - จะคืนค่าเป็น **สตริง** เสมอ — ให้ครอบด้วย `number()` เมื่อนำไปใช้ในการคำนวณทางคณิตศาสตร์
   - คืนค่าสตริงว่าง `''` หากไม่พบเส้นทางที่ระบุหรือ `value` ไม่ใช่ JSON ที่ถูกต้อง
   - ตัวอย่าง: `substr-jsonpath(${api_response}, '$.data.name')` — ดึงข้อมูลฟิลด์ `name`
   - ตัวอย่าง: `substr-jsonpath(${api_response}, '$.items[0].label')` — ดึงสมาชิกตัวแรกของอาร์เรย์
   - ตัวอย่าง: `number(substr-jsonpath(${api_response}, '$.price'))` — ดึงค่าที่เป็นตัวเลข
   - โดยทั่วไปจะใช้ควบคู่กับ `callapi(..., 'json:', ...)` เพื่อดึงข้อมูลหลายฟิลด์จากการตอบกลับของ API เพียงครั้งเดียว ดู [การดึงข้อมูลหลายค่าจากการเรียก API ครั้งเดียว](../advanced-features/call-api#fetching-multiple-values-from-one-api-call)

นิพจน์ใน rtSurvey เขียนในชุดย่อยของ **XPath 1.0** ที่ขยายด้วยฟังก์ชัน JavaRosa/ODK และฟังก์ชันแบบกำหนดเองของ rtSurvey คุณใช้นิพจน์ในคอลัมน์ `calculate`, `constraint`, `relevant`, `required` และ `default` ของ XLSForm

## การอ้างอิงค่าฟิลด์

ใช้ `${fieldname}` เพื่ออ้างอิงค่าของฟิลด์อื่น:

```
${age} > 18
```

ใช้ `.` (จุดเดียว) เพื่ออ้างอิง **ค่าของฟิลด์ปัจจุบัน** — ใช้ทั่วไปในนิพจน์ `constraint`:

```
. >= 0 and . <= 100
```

## ไวยากรณ์นิพจน์

นิพจน์ตามกฎ XPath มาตรฐาน:

- **สตริง** ต้องอยู่ในเครื่องหมายคำพูดเดี่ยว: `'yes'`
- **ตัวเลข** เขียนตามที่เป็น: `42`, `3.14`
- ผลลัพธ์ **Boolean** ใช้สำหรับ `relevant`, `required` และ `constraint`

<Callout type="warning">
ใช้เครื่องหมายคำพูดตรงเสมอ (`'` หรือ `"`) — อย่าใช้ "smart quotes" (เครื่องหมายคำพูดโค้ง) โปรแกรมแก้ไขข้อความ rich text มักแปลงเครื่องหมายคำพูดโดยอัตโนมัติและจะทำให้นิพจน์ของคุณเสียหาย
</Callout>

## ส่วนในบทนี้

- **[ตัวดำเนินการ](operators)** — ตัวดำเนินการเปรียบเทียบ (`=`, `!=`, `>`, `<`, `>=`, `<=`) และตัวดำเนินการเชิงตรรกะ (`and`, `or`, `not()`)
- **[ฟังก์ชัน](functions)** — ฟังก์ชันสตริง การเลือก ตัวเลข วันที่/เวลา boolean ภูมิศาสตร์ และฟังก์ชันอรรถประโยชน์
- **[การอ้างอิง](references)** — วิธีอ้างอิงฟิลด์และค่าบริบท

## ตัวอย่างด่วน

| กรณีใช้งาน | นิพจน์ |
|----------|------------|
| แสดงถ้าอายุมากกว่า 18 | `${age} > 18` |
| แสดงเฉพาะเมื่อเลือก "yes" | `${consent} = 'yes'` |
| กำหนดให้กรอกถ้าฟิลด์อื่นไม่ว่าง | `${name} != ''` |
| คำนวณยอดรวม | `${adults} + ${children}` |
| เชื่อมต่อชื่อ | `concat(${first_name}, ' ', ${last_name})` |
| วันที่วันนี้ | `today()` |
| ตรวจสอบว่าเลือกตัวเลือก | `selected(${interests}, 'sports')` |

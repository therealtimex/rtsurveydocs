คอลัมน์ `appearance` ใน rtSurvey ช่วยให้คุณสามารถปรับแต่งการนำเสนอด้วยภาพและพฤติกรรมของคำถามในแบบสำรวจของคุณ ฟีเจอร์นี้ช่วยยกระดับประสบการณ์ของผู้ใช้และสามารถปรับปรุงประสิทธิภาพการรวบรวมข้อมูลได้อย่างมาก rtSurvey รองรับแอตทริบิวต์รูปลักษณ์มาตรฐานของ XLSForm และขยายขีดความสามารถด้วยตัวเลือกเพิ่มเติม

## แอตทริบิวต์รูปลักษณ์มาตรฐานของ XLSForm

rtSurvey รองรับแอตทริบิวต์รูปลักษณ์มาตรฐานของ XLSForm ดังต่อไปนี้:

| แอตทริบิวต์รูปลักษณ์ (Appearance Attribute) | ประเภทคำถาม | คำอธิบาย |
|----------------------|----------------|-------------|
| multiline | text | สร้างกล่องข้อความแบบหลายบรรทัด (เหมาะสำหรับเว็บคลอนต์) |
| minimal | select_one, select_multiple | แสดงตัวเลือกในเมนูแบบดรอปดาวน์ |
| quick | select_one | เลื่อนไปยังคำถามถัดไปโดยอัตโนมัติหลังจากเลือก (เฉพาะมือถือ) |
| no-calendar | date | ปิดการแสดงปฏิทิน (เฉพาะมือถือ) |
| month-year | date | อนุญาตให้เลือกเฉพาะเดือนและปีเท่านั้น |
| year | date | อนุญาตให้เลือกเฉพาะปีเท่านั้น |
| horizontal-compact | select_one, select_multiple | แสดงตัวเลือกในแนวนอน (เฉพาะเว็บ) |
| horizontal | select_one, select_multiple | แสดงตัวเลือกในแนวนอนแบบแบ่งคอลัมน์ (เฉพาะเว็บ) |
| likert | select_one | นำเสนอตัวเลือกในรูปแบบมาตรวัดของลิเคิร์ท (Likert scale) |
| compact | select_one, select_multiple | แสดงตัวเลือกข้างกันโดยมีระยะห่างเพียงเล็กน้อย |
| quickcompact | select_one | รวมการแสดงผลแบบกะทัดรัดเข้ากับการเลื่อนอัตโนมัติ (เฉพาะมือถือ) |
| field-list | groups | แสดงทั้งกลุ่มในหน้าจอเดียว (เฉพาะมือถือ) |
| label | select_one, select_multiple | แสดงป้ายกำกับตัวเลือกโดยไม่มีช่องให้เลือก |
| list-nolabel | select_one, select_multiple | แสดงช่องให้เลือกโดยไม่มีป้ายกำกับ (ใช้ร่วมกับ `label`) |
| table-list | groups | แสดงคำถามในรูปแบบตาราง |
| signature | image | เปิดใช้งานการเซ็นชื่อ (เฉพาะมือถือ) |
| draw | image | อนุญาตให้วาดภาพด้วยลายเส้นอิสระ (เฉพาะมือถือ) |
| map, quick map | select_one, select_one_from_file | เปิดใช้งานการเลือกจากคุณสมบัติบนแผนที่ |

## แนวทางปฏิบัติที่ดีที่สุดสำหรับการใช้รูปลักษณ์

1. **ความสม่ำเสมอ**: ใช้แอตทริบิวต์รูปลักษณ์อย่างสม่ำเสมอทั่วทั้งแบบสำรวจเพื่อให้มีรูปลักษณ์ที่กลมกลืนกัน
2. **มือถือเทียบกับเว็บ**: พิจารณาว่ารูปลักษณ์จะแสดงผลอย่างไรบนอุปกรณ์และแพลตฟอร์มที่แตกต่างกัน
3. **ประสิทธิภาพ**: ระมัดระวังการใช้แอตทริบิวต์รูปลักษณ์ที่อาจทำให้การโหลดฟอร์มช้าลง (เช่น `table-list` สำหรับกลุ่มขนาดใหญ่)
4. **ประสบการณ์ผู้ใช้**: เลือกรูปลักษณ์ที่ทำให้การกรอกข้อมูลง่ายขึ้นและเข้าใจง่ายสำหรับผู้ตอบแบบสอบถาม
5. **การทดสอบ**: ทดสอบฟอร์มของคุณบนอุปกรณ์เป้าหมายเสมอเพื่อให้แน่ใจว่ารูปลักษณ์ทำงานตามที่คาดไว้

## เทคนิคขั้นสูง

### การรวมรูปลักษณ์เข้าด้วยกัน

แอตทริบิวต์รูปลักษณ์บางอย่างสามารถนำมาใช้ร่วมกันเพื่อให้ได้เลย์เอาต์ที่ซับซ้อนยิ่งขึ้น:

```
| type | name | label | appearance |
|------|------|-------|------------|
| select_one options | choice | กรุณาเลือกหนึ่งรายการ: | minimal compact |
```

### รูปลักษณ์แบบไดนามิก

rtSurvey อนุญาตให้เปลี่ยนรูปลักษณ์แบบไดนามิกตามตรรกะของฟอร์ม:

```
| type | name | label | appearance | relevant |
|------|------|-------|------------|----------|
| text | time | กรุณาระบุเวลา: | inline-[%H:%M] | ${show_time} = 'yes' |
```

## ข้อควรพิจารณาสำหรับแอปมือถือ

- รูปลักษณ์บางอย่าง (เช่น `quick`, `signature`) เป็นฟีเจอร์เฉพาะสำหรับอุปกรณ์มือถือ
- ทดสอบอย่างละเอียดทั้งบน Android และ iOS เพื่อให้แน่ใจว่าพฤติกรรมการทำงานมีความสม่ำเสมอ

## แอตทริบิวต์รูปลักษณ์ส่วนขยายของ rtSurvey

นอกเหนือจากรูปลักษณ์มาตรฐานของ XLSForm แล้ว rtSurvey ยังรองรับตัวเลือกเฉพาะของแพลตฟอร์มดังต่อไปนี้:

### การควบคุมข้อมูลและการแสดงผล

| แอตทริบิวต์รูปลักษณ์ (Appearance Attribute) | ประเภทคำถาม | คำอธิบาย |
|----------------------|----------------|-------------|
| `invisible` | any | ซ่อนฟิลด์จากการมองเห็นในขณะที่ยังคงรวบรวมหรือคำนวณค่าของฟิลด์นั้น แตกต่างจากประเภท `hidden` เนื่องจากฟิลด์นี้ยังคงมีส่วนร่วมในตรรกะ |
| `displaytitle` | any | บังคับให้แสดงป้ายกำกับ/ชื่อของฟิลด์แม้ว่าในสภาวะปกติจะถูกซ่อนไว้ |
| `autopull` | select_one, select_multiple | ดึงข้อมูลภายนอกโดยอัตโนมัติเพื่อเติมตัวเลือกเมื่อโหลดฟอร์มหรือเมื่อฟิลด์เงื่อนไขมีการเปลี่ยนแปลง |
| `floating_hint` | text, integer, decimal | แสดงข้อความคำแนะนำเป็นป้ายกำกับแบบลอยเหนือช่องกรอกข้อมูลแทนที่จะอยู่ด้านล่าง |
| `calculate-button` | calculate | เพิ่มปุ่มที่มองเห็นได้เพื่อกระตุ้นการคำนวณฟิลด์ใหม่เมื่อต้องการ แทนที่จะคำนวณโดยอัตโนมัติ |

### กลุ่มและการนำทาง

| แอตทริบิวต์รูปลักษณ์ (Appearance Attribute) | ประเภทคำถาม | คำอธิบาย |
|----------------------|----------------|-------------|
| `section` | group | แสดงผลกลุ่มเป็นบัตรส่วนที่สามารถพับเก็บได้ หมายเหตุ: เฉพาะแอปมือถือเท่านั้น |
| `toc-hide` | any | ยกเว้นคำถามนี้จากการแสดงในแผงนำทางสารบัญ (TOC) |
| `minilog` | begin_repeat | แสดงรายการที่กรอกแล้วในกลุ่มทำซ้ำเป็นรายการบันทึกย่อขนาดกะทัดรัด แทนที่จะขยายแต่ละรายการออกมาทั้งหมด |

### พฤติกรรมการกรอกข้อมูล

| แอตทริบิวต์รูปลักษณ์ (Appearance Attribute) | ประเภทคำถาม | คำอธิบาย |
|----------------------|----------------|-------------|
| `proper` | text | ปรับอักษรตัวแรกของแต่ละคำให้เป็นตัวพิมพ์ใหญ่โดยอัตโนมัติขณะที่ผู้ตอบแบบสอบถามพิมพ์ (พฤติกรรมแบบ title-case) |
| `text-nolabel` | text, integer, decimal | แสดงผลช่องกรอกข้อมูลโดยไม่มีป้ายกำกับที่มองเห็นได้ |
| `inline-1line` | text | บังคับให้ช่องกรอกข้อความแสดงเป็นบรรทัดเดียวแม้ว่าป้ายกำกับคำถามจะยาวก็ตาม |
| `popup` | any | แสดงผลฟิลด์ภายในหน้าต่างป๊อปอัป / โมดอล แทนที่จะแสดงอยู่บนหน้าเว็บโดยตรง |

### เลย์เอาต์ (Layout)

| แอตทริบิวต์รูปลักษณ์ (Appearance Attribute) | ประเภทคำถาม | คำอธิบาย |
|----------------------|----------------|-------------|
| `1screen` | group | บังคับให้แสดงทั้งกลุ่มในหน้าจอเดียวโดยไม่คำนึงถึงขนาดของกลุ่ม |
| `columns(n)` | select_one, select_multiple | แสดงตัวเลือกแบบแบ่งเป็น `n` คอลัมน์ ตัวอย่าง: `columns(3)` จะแสดงปุ่มตัวเลือกสามคอลัมน์ |
| `gridformat<row=R col=C colspan=S align=center>` | any | วางตำแหน่งฟิลด์ในเลย์เอาต์แบบ CSS-grid ที่แถว `R` คอลัมน์ `C` โดยครอบคลุม `S` คอลัมน์ ใช้ร่วมกับ `advanced-extension/grid-layout` |
| `ignore-simplify` | any | แจ้งให้ตัวแสดงผลฟอร์มข้ามการลดรูปหรือการย่อเลย์เอาต์ของฟิลด์นี้โดยอัตโนมัติ |
| `horizontal(N)` | select_one, select_multiple | กำหนดให้แต่ละตัวเลือกใช้พื้นที่ `N` เปอร์เซ็นต์ของความกว้างแถว ตัวอย่าง: `horizontal(50)` จะวางสองตัวเลือกต่อหนึ่งแถว |
| `scroll-view(N%)` | group, repeat | จำกัดความสูงของคอนเทนเนอร์ให้สูงไม่เกิน `N%` ของหน้าจอ (หรือคอนเทนเนอร์หลัก) และเพิ่มแถบเลื่อนเมื่อเนื้อหาเกินพื้นที่ ตัวอย่าง: `scroll-view(60%)` |

### วิดเจ็ต (Widgets)

| แอตทริบิวต์รูปลักษณ์ (Appearance Attribute) | ประเภทคำถาม | คำอธิบาย |
|----------------------|----------------|-------------|
| `likert` | select_one | นำเสนอตัวเลือกเป็นแถวมาตรวัดลิเคิร์ท (มีอยู่ในตารางมาตรฐานด้านบนแล้ว ยืนยันว่ารองรับ) |
| `distress` | select_one | แสดงผลตัวเลือกเป็นวิดเจ็ตภาพมาตรวัดความเครียดทางจิตวิทยาของ Kessler (K10) พร้อมไอคอนแสดงอารมณ์ |
| `rating_box-fill-{c1}-{c2}-{c3}-{c4}-{c5}` | select_one | แสดงผลตัวเลือกเป็นกล่องให้คะแนนที่มีการจัดรูปแบบพร้อมช่องสีห้าช่อง `c1` = ขอบคอนเทนเนอร์ด้านนอก, `c2` = ขอบขณะไม่ได้เลือก, `c3` = ขอบและการเติมสีขณะเลือก, `c4` = สีข้อความขณะไม่ได้เลือก, `c5` = สีข้อความขณะเลือก ตัวอย่าง: `rating_box-fill-grey-blue-green-black-white` |
| `tagging-choices-noshow-v2-{c1}-{c2}-{c3}-{c4}-{c5}` | select_multiple | แสดงผลตัวเลือกเป็นชิปแท็กสี ช่องสีทั้งห้าช่องเรียงลำดับเหมือนกับ `rating_box-fill` ตัวเลือกที่ถูกเลือกจะถูกไฮไลต์ ส่วนตัวเลือกที่ไม่ถูกเลือกจะถูกซ่อนจากมุมมองสรุป |

### การรวม API (API integration)

| แอตทริบิวต์รูปลักษณ์ (Appearance Attribute) | ประเภทคำถาม | คำอธิบาย |
|----------------------|----------------|-------------|
| `callapi` | text, integer, decimal, select_one | เปิดใช้งานการเรียกใช้งาน API สำหรับฟิลด์นี้ คอลัมน์การคำนวณควรมีนิพจน์ `callapi()` ดูเพิ่มเติมที่ [Call API](advanced-features/call-api) |
| `callapi-verify(params)` | text, integer, decimal | กระตุ้นการเรียกใช้งานการตรวจสอบผ่าน API โดยใช้พารามิเตอร์แบบคงที่ ฟอร์มจะระงับการดำเนินการถัดไปจนกว่า API จะยืนยันค่า |
| `callapi-verify(dynamicParams)` | text, integer, decimal | เหมือนกับ `callapi-verify` แต่ใช้พารามิเตอร์ที่ดึงมาจากค่าของฟิลด์อื่นขณะใช้งาน |

### ตัวสลับภาษา (Language switcher)

| แอตทริบิวต์รูปลักษณ์ (Appearance Attribute) | ประเภทคำถาม | คำอธิบาย |
|----------------------|----------------|-------------|
| `change_language-{colors} default('lang')` | note, text | แสดงผลวิดเจ็ตตัวสลับภาษาที่มีการจัดรูปแบบด้วยรหัสสีที่กำหนด โทเค็น `default('lang')` จะกำหนดภาษาเริ่มต้น (เช่น `default('en')`) โดยจะถูกเขียนใหม่เป็น `rtDefault('lang')` ภายในระหว่างการประมวลผล ตัวอย่าง: `change_language-blue-white default('vi')` |

### รูปแบบวันที่/เวลาแบบอินไลน์ (Inline date/time format)

สำหรับฟิลด์ `date`, `time` และ `datetime` คุณสามารถระบุรูปแบบการแสดงผลที่กำหนดเองได้โดยใช้สตริงรูปแบบต่อท้ายรูปลักษณ์:

```
inline-[%d/%m/%Y]
inline-1line-[%d/%m/%Y %H:%M]
```

โทเค็นรูปแบบจะเหมือนกับ `format-date()` และ `format-date-time()` ดูเพิ่มเติมที่ [Functions — Date and time functions](operators-and-functions/functions#date-and-time-functions)

ตัวอย่าง:

| type | name | label | appearance |
|------|------|-------|------------|
| datetime | event_time | วันที่และเวลาของเหตุการณ์ | inline-[%d/%m/%Y %I:%M %p] |
| date | birth_date | วันเกิด | inline-[%d/%m/%Y] |

### เลย์เอาต์ปุ่มแบบอินไลน์ — `display{}` และ `results{}`

สำหรับประเภทคำถามที่แสดงผลเป็นปุ่มไอคอนแบบอินไลน์ (`date`, `time`, `datetime`, `image`, `audio`, `video`, `file`, `barcode`, `geopoint`) จะมีตัวปรับแต่งรูปลักษณ์สองตัวเพื่อควบคุมตำแหน่งปุ่มและพฤติกรรมหลังการจับภาพ/ข้อมูล

#### `display{...}` — ตำแหน่งปุ่มก่อนการจับข้อมูล

```
display{<align>, <size>, <color>}
```

| พารามิเตอร์ | ค่าที่ใช้ได้ | ค่าเริ่มต้น |
|-----------|--------|---------|
| Align (การจัดวาง) | `left`, `right`, `top`, `center`, `bottom` | `right` |
| Size (ขนาด) | `small`, `medium`, `large` | `small` |
| Color (สี) | รหัสสี hex เช่น `#FF5500` | สีหลักของธีม |
| Flag | `inline-icon` | บังคับให้เป็นโหมดไอคอน |

| ค่า Align | เลย์เอาต์ |
|-------------|--------|
| `right` | ปุ่มอยู่ทางขวาของป้ายกำกับ |
| `left` | ปุ่มอยู่ทางซ้ายของป้ายกำกับ |
| `top` | ปุ่มอยู่เหนือป้ายกำกับ กึ่งกลางเต็มความกว้าง |
| `center` / `bottom` | ปุ่มอยู่ใต้ป้ายกำกับ กึ่งกลางเต็มความกว้าง |

#### `results{...}` — เลย์เอาต์และความชัดเจนหลังการจับข้อมูล

รับการตั้งค่าต่อมาจาก `display{}` ใช้เพื่อย้ายปุ่มหรือซ่อนองค์ประกอบเมื่อมีการจับค่าข้อมูลแล้ว

```
results{<align>, hide(<element>)}
```

| ค่า `hide` | ผลลัพธ์ |
|---|---|
| `hide(capture)` | ซ่อนปุ่มจับข้อมูลเมื่อมีไฟล์หรือค่าข้อมูลแล้ว |
| `hide(review)` | ซ่อนรูปตัวอย่าง / ปุ่มเล่นย้อนหลัง |
| `hide(filename)` | ซ่อนชื่อไฟล์ที่แสดงหลังจากอัปโหลด |
| `hide(camera)` | ซ่อนปุ่มเปิดกล้องหลังจากถ่ายภาพแล้ว |
| `hide(scanner)` | ซ่อนปุ่มสแกนบาร์โค้ดหลังจากสแกนค่าแล้ว |
| `hide(value)` | ซ่อนข้อความค่าที่สแกน (บาร์โค้ด / จุดพิกัดภูมิศาสตร์) |

วิดเจ็ตจะสลับจากเลย์เอาต์ `display{}` เป็น `results{}` โดยอัตโนมัติทันทีที่มีการจับค่าข้อมูล

**ตัวอย่าง:**

```
inline display{right}                                    → ไอคอนทางขวาของป้ายกำกับ
inline display{left, large}                              → ไอคอนขนาดใหญ่ทางซ้าย
inline display{center, large, #FF5500}                   → ไอคอนสีส้มขนาดใหญ่ใต้ป้ายกำกับ
inline display{right} results{left}                      → ไอคอนจะย้ายไปทางซ้ายหลังจากจับข้อมูล
inline display{right} results{hide(capture)}             → ไอคอนจะหายไปหลังจากจับข้อมูล
inline display{center} results{hide(capture), hide(filename)}
```

## ข้อจำกัดที่ทราบ

- รูปลักษณ์ที่ซับซ้อนอาจแสดงผลไม่เหมือนกันในทุกแพลตฟอร์ม
- รูปลักษณ์ระดับสูงของ rtSurvey บางอย่างอาจไม่รองรับในโหมดออฟไลน์

## การแก้ไขปัญหารูปลักษณ์

1. **รูปลักษณ์ไม่แสดงผล**: ตรวจสอบการสะกดผิดในคอลัมน์ appearance
2. **การแสดงผลไม่สม่ำเสมอ**: ตรวจสอบความเข้ากันได้กับประเภทคำถามและแพลตฟอร์ม
3. **ปัญหาประสิทธิภาพ**: พิจารณาลดความซับซ้อนของรูปลักษณ์ โดยเฉพาะสำหรับแบบสำรวจขนาดใหญ่

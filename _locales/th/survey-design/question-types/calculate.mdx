ประเภทคำถาม `calculate` รันสูตรอย่างเงียบๆ ในพื้นหลัง โดยจะจัดเก็บผลลัพธ์ไว้ในฟิลด์ที่กำหนดชื่อซึ่งคำถามอื่นๆ สามารถอ้างอิงได้ — แต่จะไม่แสดงการป้อนข้อมูลหรือป้ายชื่อใดๆ แก่ผู้เก็บข้อมูล ใช้เพื่อคำนวณค่า, เชื่อมต่อข้อความ, รันตรรกะแบบมีเงื่อนไข หรือค้นหาข้อมูลที่คุณต้องการใช้ในภายหลังในแบบฟอร์ม

---

## ไวยากรณ์พื้นฐาน

| type | name | label | calculation |
|------|------|-------|-------------|
| calculate | total | | `${price} * ${quantity}` |

- **type**: เป็น `calculate` เสมอ
- **name**: ชื่อฟิลด์ที่ไม่ซ้ำกัน คำถามอื่นๆ จะอ้างอิงถึงสิ่งนี้ด้วย `${name}`
- **label**: ปล่อยว่างไว้ — ฟิลด์ calculate จะไม่ถูกแสดงต่อผู้เก็บข้อมูล
- **calculation**: สูตรที่จะประเมินผล รองรับ [ฟังก์ชัน XLSForm](../operators-and-functions/functions) และการอ้างอิงฟิลด์ทั้งหมด

---

## รูปแบบทั่วไป

### เลขคณิต

| type | name | label | calculation |
|------|------|-------|-------------|
| integer | price | Unit price | |
| integer | quantity | Quantity | |
| calculate | total | | `${price} * ${quantity}` |
| note | total_note | Total: `${total}` | |

### การเชื่อมต่อข้อความ (String concatenation)

| type | name | label | calculation |
|------|------|-------|-------------|
| text | first_name | First name | |
| text | last_name | Last name | |
| calculate | full_name | | `concat(${first_name}, ' ', ${last_name})` |

### ค่าแบบมีเงื่อนไข

| type | name | label | calculation |
|------|------|-------|-------------|
| integer | score | Score (0–100) | |
| calculate | grade | | `if(${score} >= 90, 'A', if(${score} >= 75, 'B', if(${score} >= 60, 'C', 'F')))` |

### อายุจากวันเกิด

| type | name | label | calculation |
|------|------|-------|-------------|
| date | dob | Date of birth | |
| calculate | age_years | | `int((today() - ${dob}) div 365.25)` |

## การใช้ `once()` เพื่อล็อคค่า

โดยปกติ `calculate` จะประเมินค่าใหม่ทุกครั้งที่ฟิลด์ที่อ้างอิงมีการเปลี่ยนแปลง ให้ครอบสูตรด้วย `once()` เพื่อประเมินค่าในการโหลดครั้งแรกเท่านั้นและคงผลลัพธ์ไว้:

| type | name | label | calculation |
|------|------|-------|-------------|
| calculate | interview_start | | `once(now())` |

ใช้ `once()` สำหรับการบันทึกเวลา (timestamps), ค่าเริ่มต้น หรือกรณีใดก็ตามที่ไม่ต้องการให้มีการคำนวณใหม่เมื่อมีการเปลี่ยนแปลง

## การดึงข้อมูลจากแหล่งภายนอก

### จากไฟล์ CSV

```
pulldata('staff.csv', 'department', 'name', ${staff_id})
```

ดู [pulldata()](../operators-and-functions/pulldata) สำหรับการอ้างอิงทั้งหมด

### จากฐานข้อมูล SQLite ที่รวมมาด้วย

```
pulldata('rawquery',
  concat(${family_path}, '/locations.db::provinces'),
  'SELECT name FROM provinces WHERE id = ?',
  ${province_id})
```

ดู [การค้นหาฐานข้อมูลท้องถิ่น](../advanced-features/local-database-search) สำหรับรายละเอียดการสร้างเส้นทาง (path)

### จากบริบทของแอป (App context)

```
pulldata('app-api', 'user.username')
pulldata('app-api', 'family_path')
```

ดู [App API](../app-api) สำหรับคีย์ทั้งหมดที่มีให้ใช้งาน

## การใช้ calculate ใน relevant และ constraint

ฟิลด์อื่นๆ สามารถอ้างอิงผลลัพธ์ของ `calculate` ได้เหมือนกับฟิลด์ทั่วไป:

| type | name | label | relevant | constraint |
|------|------|-------|----------|------------|
| calculate | bmi | | | `${weight} div (${height} * ${height}) * 10000` |
| note | bmi_warning | BMI is very high — please verify weight and height. | `${bmi} > 40` | |

---

## แนวทางปฏิบัติที่ดีที่สุด

1. ตั้งชื่อฟิลด์ calculate ให้มีความหมาย — `total_cost` ชัดเจนกว่า `calc1` และติดตามได้ง่ายกว่าในการส่งออกข้อมูล
2. แบ่งสูตรที่ซับซ้อนออกเป็นฟิลด์ calculate หลายๆ ฟิลด์ที่เชื่อมต่อกัน แทนที่จะใช้เนพจน์เดียวที่ซ้อนกันลึกๆ
3. ใช้ `once()` สำหรับการบันทึกเวลาและค่าสถานะเริ่มต้น เพื่อป้องกันไม่ให้ค่าเปลี่ยนแปลงหลังจากการบันทึกครั้งแรก
4. วางฟิลด์ `calculate` ไว้ก่อนคำถามแรกที่อ้างอิงถึง — ลำดับการประเมินจะดำเนินไปตามลำดับของแบบฟอร์ม
5. ปล่อยคอลัมน์ `label` ให้ว่าง เครื่องมือบางอย่างจะแสดงป้ายชื่อ การปล่อยว่างไว้จะช่วยหลีกเลี่ยงผลลัพธ์ที่น่าสับสน

## ข้อจำกัด

- ฟิลด์ calculate จะไม่ถูกแสดงต่อผู้เก็บข้อมูลโดยตรง — ให้ใช้ฟิลด์ `note` เพื่อแสดงผลลัพธ์
- คอลัมน์ `calculation` จำเป็นต้องมี; แถว `calculate` ที่ไม่มีสูตรจะจัดเก็บข้อความว่างเสมอ
- ผลลัพธ์จะถูกประเมินใหม่ทุกครั้งที่มีการเปลี่ยนแปลงแบบฟอร์ม เว้นแต่จะครอบด้วย `once()` — สูตรที่ซับซ้อนมากในแบบฟอร์มขนาดใหญ่อาจส่งผลต่อประสิทธิภาพการประมวลผลบนอุปกรณ์รุ่นเก่าหรือรุ่นต่ำ
- ค่าที่คำนวณได้จะถูกจัดเก็บเป็นข้อความ (strings) ในการส่งข้อมูล ใช้ `number()`, `int()` หรือ `boolean()` เพื่อแปลงประเภทข้อมูลเมื่อส่งผลลัพธ์ไปยังนิพจน์ทางคณิตศาสตร์หรือตรรกะ

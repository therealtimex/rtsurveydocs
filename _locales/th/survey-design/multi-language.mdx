rtSurvey ให้การรองรับหลายภาษาที่มีประสิทธิภาพ ช่วยให้คุณสร้างแบบสำรวจในหลายภาษาได้ คุณลักษณะนี้สำคัญอย่างยิ่งสำหรับการทำวิจัยในกลุ่มประชากรที่ใช้ภาษาหลากหลายหรือในสภาพแวดล้อมที่ใช้หลายภาษา

## การตั้งค่าแบบสำรวจหลายภาษา

ในการสร้างแบบสำรวจหลายภาษาใน rtSurvey คุณต้องเพิ่มคอลัมน์เฉพาะสำหรับภาษาใน XLSForm ของคุณ ดังนี้:

1. **การแปลป้ายชื่อ (Label)**: เพิ่มคอลัมน์สำหรับแต่ละภาษาโดยใช้รูปแบบ `label::Language (code)`
2. **การแปลคำแนะนำ (Hint)**: ใช้ `hint::Language (code)` สำหรับการแปลคำแนะนำ
3. **การแปลไฟล์สื่อ**: สำหรับสื่อเฉพาะภาษา ให้ใช้ `media::Language (code)`

ตัวอย่าง:

```
| type    | name | label::English (en) | label::Español (es) | hint::English (en) | hint::Español (es) |
|---------|------|---------------------|---------------------|---------------------|---------------------|
| integer | age  | How old are you?    | ¿Cuántos años tienes?| Enter your age      | Ingrese su edad     |
```

## รหัสภาษา

ขอแนะนำให้ใช้รหัสภาษา 2 ตัวอักษร (subtags) อย่างเป็นทางการต่อท้ายชื่อภาษา เพื่อช่วยในการจับคู่ภาษาของแบบฟอร์มกับภาษาของอินเทอร์เฟซผู้ใช้ คุณสามารถดูรหัสอย่างเป็นทางการได้[ที่นี่](https://www.iana.org/assignments/language-subtag-registry/language-subtag-registry)

## การตั้งค่าภาษาเริ่มต้น

ในการตั้งค่าภาษาเริ่มต้นสำหรับการเก็บข้อมูล ให้ใช้เวิร์กชีต `settings` ใน XLSForm ของคุณ:

```
| form_id   | version | default_language |
|-----------|---------|-------------------|
| test_form | 101     | French (fr)       |
```

## คุณลักษณะเฉพาะของ rtSurvey

### การสลับภาษาแบบไดนามิก

rtSurvey ช่วยให้ผู้ใช้สามารถสลับภาษาได้แบบไดนามิกในระหว่างการเก็บข้อมูล:

- ในอินเทอร์เฟซเว็บ ให้ใช้เมนูแบบเลื่อนลงสำหรับภาษาในแถบนำทางด้านบน
- ในแอปมือถือ ให้เข้าถึงตัวเลือกภาษาผ่านเมนูการตั้งค่า

### ข้อความตรวจสอบเฉพาะภาษา

rtSurvey ขยายการรองรับหลายภาษาไปยังข้อความตรวจสอบ (validation messages):

```
| type    | name | constraint | constraint_message::English (en) | constraint_message::Español (es) |
|---------|------|------------|----------------------------------|----------------------------------|
| integer | age  | . <= 150   | Age must be 150 or less          | La edad debe ser 150 o menos     |
```

### ข้อความแจ้งเตือนฟิลด์ที่จำเป็นในแต่ละภาษา

ใช้ `required_message::Language (code)` เพื่อแสดงข้อความแจ้งเตือนที่แปลแล้วเมื่อเว้นฟิลด์ที่จำเป็นว่างไว้:

```
| type | name | required | required_message::English (en) | required_message::Tiếng Việt (vi) |
|------|------|----------|-------------------------------|----------------------------------|
| text | name | yes | This field is required | Trường này là bắt buộc |
```

### การรองรับภาษาที่เขียนจากขวาไปซ้าย (RTL)

สำหรับภาษาที่เขียนจากขวาไปซ้าย (RTL) เช่น ภาษาอาหรับหรือภาษาฮีบรู rtSurvey จะปรับเลย์เอาต์โดยอัตโนมัติ:

```
| type | name | label::English (en) | label::Arabic (ar) |
|------|------|---------------------|---------------------|
| text | name | Your name           | اسمค                |
```

### รูปแบบการแสดงผล (Appearance) เฉพาะภาษา

rtSurvey ช่วยให้คุณกำหนดรูปแบบการแสดงผลที่แตกต่างกันสำหรับภาษาต่างๆ ได้:

```
| type | name | label::English (en) | label::Chinese (zh) | appearance::English (en) | appearance::Chinese (zh) |
|------|------|---------------------|---------------------|--------------------------|---------------------------|
| text | address | Address          | 地址                 | multiline                | textarea                  |
```

## การจัดรูปแบบ HTML ในป้ายชื่อสองภาษา

คุณสามารถผสมแท็ก HTML กับตัวห่อหุ้มภาษา (language wrappers) ในเซลล์ป้ายชื่อเซลล์เดียวได้ rtSurvey จะดึงบล็อกภาษาที่ใช้งานอยู่และแสดงผล HTML ที่เหลือ

ตัวอย่างการใช้ตัวหนาและสีฟอนต์ตามภาษา:

```
<en><big><b>Section 2: Household Income</b></big><br>Ask the household head only.</en><vi><big><b>Phần 2: Thu nhập hộ gia đình</b></big><br>Chỉ hỏi chủ hộ.</vi>
```

แท็กอินไลน์ที่รองรับภายในตัวห่อหุ้มภาษา: `<b>`, `<i>`, `<u>`, `<big>`, `<small>`, `<font color="...">`, `<br>`, `<span style="...">`

ตัวอย่างข้อความสีตามภาษา:

```
<en><font color="red">Required field</font></en><vi><font color="red">Trường bắt buộc</font></vi>
```

## การคำนวณที่รองรับภาษา

เมื่อแบบฟอร์มมีฟิลด์ `${language_use}` (ตั้งค่าโดยวิดเจ็ต `change_language`) ให้ใช้ `if()` เพื่อคืนค่าในภาษาที่ใช้งานอยู่:

```
if(${language_use} = 'en', label_en, label_vi)
```

ตัวอย่าง — แสดงผลการค้นหาในภาษาที่ใช้งานอยู่โดยใช้ `pulldata('rawquery', ...)`:

```
| type      | name        | calculation                                                                 |
|-----------|-------------|-----------------------------------------------------------------------------|
| calculate | district_label | if(${language_use} = 'en', pulldata('rawquery', concat(${family_path}, '/locations.db::externalData'), 'SELECT label_en FROM externalData WHERE code = ?', ${district}), pulldata('rawquery', concat(${family_path}, '/locations.db::externalData'), 'SELECT label_vi FROM externalData WHERE code = ?', ${district})) |
```

หมายเหตุ: โดยทั่วไปฟิลด์ `language_use` จะถูกตั้งค่าโดยวิดเจ็ตรูปแบบการแสดงผล `change_language` ดูที่ Appearance — change_language

## แนวทางปฏิบัติที่ดีที่สุดสำหรับแบบสำรวจหลายภาษา

1. **การตั้งชื่อที่สอดคล้อง**: ใช้รหัสภาษาที่สอดคล้องกันตลอดทั้งแบบฟอร์มของคุณ
2. **การแปลระดับมืออาชีพ**: จ้างนักแปลมืออาชีพที่คุ้นเคยกับบริบทของแบบสำรวจ
3. **บันทึกบริบท**: ระบุบันทึกบริบทสำหรับนักแปลเพื่อให้แน่ใจว่าการแปลถูกต้อง
4. **การทดสอบ**: ทดสอบแบบฟอร์มของคุณในทุกภาษาก่อนนำไปใช้งานจริง
5. **การรองรับ Unicode**: ตรวจสอบให้แน่ใจว่าอุปกรณ์เก็บข้อมูลของคุณรองรับ Unicode สำหรับอักษรที่ไม่ใช่ละติน
6. **สื่อเฉพาะภาษา**: ใช้รูปภาพหรือเสียงที่เหมาะสมกับวัฒนธรรมสำหรับแต่ละภาษา
7. **หลีกเลี่ยงข้อความในรูปภาพ**: หากใช้รูปภาพที่มีข้อความ ให้สร้างรูปภาพแยกกันสำหรับแต่ละภาษา

## การจัดการกรณีพิเศษ

### การตอบคำถามแบบผสมภาษา

rtSurvey ช่วยให้ผู้ตอบแบบสอบถามสามารถป้อนข้อความในอักษรใดก็ได้ โดยไม่คำนึงถึงภาษาของแบบฟอร์มที่เลือก สิ่งนี้มีประโยชน์สำหรับการบันทึกชื่อหรือที่อยู่ในอักษรต้นฉบับ

### ประเภทคำถามเฉพาะภาษา

ประเภทคำถามบางประเภทอาจเหมาะสมกับบางภาษามากกว่า rtSurvey ช่วยให้คุณใช้ประเภทคำถามที่แตกต่างกันสำหรับภาษาที่แตกต่างกันได้:

```
| type::English (en) | type::Japanese (ja) | name | label::English (en) | label::Japanese (ja) |
|--------------------|---------------------|------|---------------------|----------------------|
| text               | select_one kanji    | name | Enter your name     | 名前を選んでください    |
```

## การส่งออกข้อมูลหลายภาษา

เมื่อส่งออกข้อมูลจาก rtSurvey:

- เลือกส่งออกในภาษาใดภาษาหนึ่งโดยเฉพาะหรือรวมทุกเวอร์ชันภาษา
- ข้อมูลเมตาของภาษาจะรวมอยู่ในการส่งออก เพื่อระบุว่าภาษาใดถูกใช้สำหรับการตอบกลับแต่ละครั้ง

## ข้อควรพิจารณาสำหรับแอปมือถือ

- แอปมือถือ rtSurvey รองรับการสลับภาษาแบบออฟไลน์
- ตรวจสอบให้แน่ใจว่าไฟล์ภาษาที่จำเป็นทั้งหมดถูกดาวน์โหลดแล้วก่อนที่จะออฟไลน์

## ข้อจำกัดที่ทราบ

- คุณลักษณะขั้นสูงบางอย่างอาจไม่พร้อมใช้งานในทุกภาษา
- การแปลที่ยาวมากอาจส่งผลต่อเลย์เอาต์บนหน้าจอขนาดเล็ก

ด้วยการใช้ประโยชน์จากความสามารถหลายภาษาของ rtSurvey คุณสามารถสร้างแบบสำรวจที่ครอบคลุมและเข้าถึงได้ ซึ่งเข้าถึงประชากรที่หลากหลายและให้ข้อมูลที่มีคุณภาพสูงและถูกต้องตามหลักภาษาได้

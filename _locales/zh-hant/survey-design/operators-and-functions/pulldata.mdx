---

import { Callout } from 'nextra/components'

`pulldata()` 函數從附加到表單的 CSV 檔案中檢索值。給定檔名、要返回的列、要匹配的列和鍵值，它將返回匹配行與結果列交叉處的單元格。

```
pulldata('filename.csv', 'result_column', 'key_column', ${key_field})
```

| 位置 | 參數 | 描述 |
|----------|-----------|-------------|
| 1 | 檔名 | CSV 媒體檔案的名稱（與 `select_one_from_file` 中使用的名稱相同） |
| 2 | 結果列 | 您想要返回其值的列 |
| 3 | 鍵列 | 用於匹配的列 |
| 4 | 鍵值 | 要匹配的值 —— 通常是欄位引用，例如 `${field}` |

如果未找到匹配項，該函數將返回一個空字串。

---

## 先決條件

CSV 檔案必須作為**媒體檔案**附加到表單中。`pulldata()` 引用的同一個檔案也可以用作 `select_one_from_file` 的選項列表。

**示例 CSV —— `staff.csv`：**

```
name,id,department,phone
Alice,S001,Health,+1234567890
Bob,S002,Education,+0987654321
Carol,S003,Health,+1122334455
```

---

## 基本示例

根據員工 ID 查詢其部門和電話：

**survey：**

| type | name | label | calculation |
|------|------|-------|-------------|
| select_one_from_file staff.csv | staff_id | Select staff member | |
| calculate | dept | | `pulldata('staff.csv', 'department', 'name', ${staff_id})` |
| calculate | phone | | `pulldata('staff.csv', 'phone', 'name', ${staff_id})` |
| note | dept_note | Department: `${dept}` — Phone: `${phone}` | |

<Callout type="info">
`select_one_from_file` CSV 中的 `name` 列是存儲的值。當調查員選擇 "Alice" 時，`${staff_id}` 的值為 `"Alice"`，`pulldata()` 將其用作鍵來檢索她的部門和電話。
</Callout>

---

## 檢索所選選項的標籤

`select_one_from_file` 問題存儲的是 `name` 值。要顯示人類可讀的 `label`（標籤），請使用 `pulldata()` 進行查詢：

| type | name | label | calculation |
|------|------|-------|-------------|
| select_one_from_file villages.csv | village | Select village | |
| calculate | village_label | | `pulldata('villages.csv', 'label', 'name', ${village})` |
| note | confirm | You selected: `${village_label}` | |

---

## 從一個選擇中進行多次查詢

您可以對同一個檔案多次調用 `pulldata()`，以為同一個選定行檢索不同的列：

| type | name | label | calculation |
|------|------|-------|-------------|
| select_one_from_file facilities.csv | facility | Select facility | |
| calculate | fac_type | | `pulldata('facilities.csv', 'type', 'name', ${facility})` |
| calculate | fac_district | | `pulldata('facilities.csv', 'district', 'name', ${facility})` |
| calculate | fac_beds | | `pulldata('facilities.csv', 'beds', 'name', ${facility})` |

---

## 在 relevant 和 constraint 中使用 pulldata

`pulldata()` 可用於 `relevant`（相關性）和 `constraint`（約束）列，以根據查詢到的值應用邏輯：

| type | name | label | relevant | constraint |
|------|------|-------|----------|------------|
| select_one_from_file facilities.csv | facility | Select facility | | |
| integer | bed_count | Number of beds occupied | | `. <= number(pulldata('facilities.csv', 'beds', 'name', ${facility}))` |

---

## 將 pulldata 與 `once()` 配合使用

要在僅在首次加載時評估 `pulldata()`（防止在初始輸入後鍵欄位更改時重新評估），請將其包裝在 `once()` 中：

| type | name | label | calculation |
|------|------|-------|-------------|
| calculate | initial_dept | | `once(pulldata('staff.csv', 'department', 'name', ${staff_id}))` |

---

## 最佳實踐

1. CSV 中的鍵列必須與 `select_one_from_file` 中使用的 `name` 列匹配 —— 它們必須是相同的值。
2. CSV 中的列名區分大小写 —— `Department` 和 `department` 是不同的列。
3. 如果未找到鍵值，`pulldata()` 返回空字串 —— 使用 `if(${field} != '', pulldata(...), '')` 來防止空選擇。
4. 儘可能保持 CSV 檔案較小 —— 大檔案會增加低頻寬連接下的表單加載時間。
5. 對於在數據收集輪次之間發生變化的數據，通過上傳新的表單版本來更新 CSV 媒體檔案。

## 限制

- `pulldata()` 僅匹配鍵列等於鍵值的**第一行** —— 不支持 CSV 中存在重複的鍵值。
- CSV 檔案必須在部署前附加到表單；無法在運行時從 URL 獲取。
- `pulldata()` 返回的數值是字串 —— 在算術運算中使用時請包裝在 `number()` 中：`number(pulldata(...))`。

<Callout type="info">
rtSurvey 還支持擴展形式的 `pulldata()`，用於讀取設備元數據、JWT 欄位和 JSON 數據。請參閱 [App API](../app-api) 了解 `pulldata('app-api', ...)`，以及 [Call API](../advanced-features/call-api) 頁面了解基於 JSON 的查詢模式。
</Callout>

## 擴展的 pulldata() 變體

除了 CSV 查詢外，`pulldata()` 還通過更改第一個參數來支持多種額外的數據源。

### `pulldata('app-api', key)`

讀取設備元數據、用戶屬性和應用上下文。請參閱 [App API](../app-api) 頁面上的完整參考。

```
pulldata('app-api', 'user.name')
pulldata('app-api', 'serverTime')
pulldata('app-api', 'projectCode')
```

### `pulldata('json', jsonString, jsonpath)`

解析內聯 JSON 字串並使用 JSONPath 表達式提取值。當您在表單中嵌入了 JSON 字面量時非常有用。

```
pulldata('json', '{"status":"active","code":42}', '$.code')
```

以字串形式返回匹配的值，如果未找到則返回空字串。

### `pulldata('jsonpath', fieldRef, jsonpath)`

使用 JSONPath 表達式從存儲在另一個欄位中的 JSON 字串中提取值。這相當於 `substr-jsonpath(${field}, jsonpath)`。

```
pulldata('jsonpath', ${api_raw}, '$.data.id')
```

### `pulldata('jwt', tokenField, claimName)`

解碼存儲在欄位中的 JWT 令牌，並從有效載荷（payload）中返回特定聲明（claim）的值。

```
pulldata('jwt', ${auth_token}, 'sub')
pulldata('jwt', ${auth_token}, 'exp')
```

如果令牌無效或聲明不存在，則返回空字串。

### `pulldata('instanceid')`

返回當前提交的唯一實例 ID。相當於 `instanceID` 元欄位。

```
pulldata('instanceid')
```

### `pulldata('mapping', value, mappingName)`

使用表單配置中定義的命名映射表將一個值映射到另一個值。

```
pulldata('mapping', ${district_code}, 'district_names')
```

返回映射後的值，如果沒有匹配的映射則返回空字串。

### `pulldata('options', optionName)`

按名稱讀取表單配置選項。

```
pulldata('options', 'max_household_size')
```

### `pulldata('rawquery', path, sql, param1, ...)`

針對捆綁的 SQLite `.db` 檔案執行 SQL `SELECT`，並返回第一個匹配行第一列的值。SQL 字串後的參數按順序替換 `?` 占位符。

| 位置 | 參數 | 描述 |
|----------|-----------|-------------|
| 1 | `'rawquery'` | 標識此變體的字面量字串 |
| 2 | path | `concat(${family_path}, '/file.db::tableName')` 格式的檔案路徑 |
| 3 | SQL | 使用 `?` 作為位置占位符的 `SELECT` 語句 |
| 4+ | params | 按順序為每個 `?` 替換的值 —— 通常是欄位引用，例如 `${field}` |

如果沒有任何行匹配，則返回空字串。

**示例 —— 根據 ID 查詢省份名稱：**

```
pulldata('rawquery',
  concat(${family_path}, '/locations.db::provinces'),
  'SELECT name FROM provinces WHERE id = ?',
  ${province_id})
```

**示例 —— 查詢根據省份和地區代碼過濾的鄉鎮名稱：**

```
pulldata('rawquery',
  concat(${family_path}, '/locations.db::wards'),
  'SELECT name FROM wards WHERE province_code = ? AND district_code = ?',
  ${province_code},
  ${district_code})
```

與匹配 CSV 檔案中單個鍵列的标准四參數 `pulldata()` 不同，`rawquery` 變體針對 SQLite 數據庫執行完整的 SQL `SELECT`，允許進行多列 `WHERE` 條件，並可以使用任何列作為返回值。

<Callout type="info">
`rawquery` 通常與自動完成欄位配合使用，進行分層級的位置查詢。有關構建 `.db` 檔案並將其連接到 `pulldata('rawquery', ...)` 的詳細資訊，請參閱 [本地數據庫搜索](../advanced-features/local-database-search)。
</Callout>

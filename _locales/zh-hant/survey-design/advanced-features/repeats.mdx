本頁面介紹了在 rtSurvey 中使用重複組的進階模式。有關設置重複組的基礎知識，請參閱[分組和重複](../repeats)。

---

## 動態重複計數 (Dynamic repeat count)

預設情况下，由調查員決定重複次數。您可以使用 `repeat_count` 固定重複次數：

| type | name | label | repeat_count |
|------|------|-------|--------------|
| begin_repeat | household_members | 家庭成員 | `${num_members}` |
| text | member_name | 成員姓名 | |
| integer | member_age | 年齡 | |
| end_repeat | | | |

重複將運行 `${num_members}` 次，其中 `num_members` 是之前在表單中收集的数据。調查員無法添加或刪除實例。

---

## 索引訪問：`indexed-repeat()`

使用 `indexed-repeat(repeatedField, repeatGroup, index)` 從重複組**外部**訪問特定重複實例的欄位值：

| type | name | label | calculation |
|------|------|-------|-------------|
| calculate | first_name | | `indexed-repeat(${member_name}, ${household_members}, 1)` |
| calculate | second_name | | `indexed-repeat(${member_name}, ${household_members}, 2)` |

這對於構建摘要欄位或在重複結束後引用「主要」成員的數據非常有用。

---

## 當前實例位置：`index()`

在重複組內部，`index()` 返回當前實例的 1-based 位置。使用它來標記每次重複或創建唯一標識符：

| type | name | label |
|------|------|-------|
| begin_repeat | plots | 地塊 |
| note | plot_label | 地塊編號 `${index()}` |
| text | plot_id | 地塊 ID |
| end_repeat | | |

---

## 引用同一實例中的欄位

在重複內部，使用 `${fieldname}` 引用**同一重複實例**中的另一個欄位。在同一重複內不需要使用 `indexed-repeat()`：

| type | name | label | relevant |
|------|------|-------|----------|
| begin_repeat | members | 成員 | |
| text | member_name | 姓名 | |
| integer | member_age | 年齡 | |
| text | school_name | 學校名稱 | `${member_age} < 18` |
| end_repeat | | | |

---

## 從重複內部引用父欄位

重複組外部（上方）的欄位可以正常使用 `${fieldname}` 進行引用：

| type | name | label |
|------|------|-------|
| text | village | 村莊名稱 |
| begin_repeat | plots | 農業地塊 |
| note | plot_context | `${village}` 中的地塊 |
| end_repeat | | |

---

## 匯總重複數據

在重複組**外部**使用重複聚合函數進行匯總：

| Function | Example | Description |
|----------|---------|-------------|
| `count(group)` | `count(${household_members})` | 實例數量 |
| `sum(field)` | `sum(${loan_amount})` | 數值欄位的總和 |
| `min(field)` | `min(${member_age})` | 最小值 |
| `max(field)` | `max(${member_age})` | 最大值 |
| `join(sep, field)` | `join(', ', ${member_name})` | 逗號分隔的列表 |
| `count-if(group, expr)` | `count-if(${members}, ${member_age} < 18)` | 條件計數 |
| `sum-if(field, expr)` | `sum-if(${loan_amount}, ${loan_amount} > 500)` | 條件求和 |
| `join-if(sep, field, expr)` | `join-if(', ', ${name}, ${age} >= 18)` | 條件連接 |

### 示例：家庭摘要

| type | name | label | calculation |
|------|------|-------|-------------|
| integer | num_members | 有多少名成員？ | |
| begin_repeat | members | 成員 | `${num_members}` |
| text | member_name | 姓名 | |
| integer | member_age | 年齡 | |
| end_repeat | | | |
| calculate | total_members | | `count(${members})` |
| calculate | children_count | | `count-if(${members}, ${member_age} < 18)` |
| calculate | adult_names | | `join-if(', ', ${member_name}, ${member_age} >= 18)` |
| note | summary | `${total_members}` 名成員；`${children_count}` 名 18 歲以下。成年人：`${adult_names}` | |

## 嵌套重複 (Nested repeats)

一個重複組可以包含另一個重複組。請謹慎使用——嵌套重複會增加複雜性，並可能令調查員感到困惑。

| type | name | label |
|------|------|-------|
| begin_repeat | households | 家庭 |
| text | hh_id | 家庭 ID |
| begin_repeat | hh_members | 成員 |
| text | member_name | 成員姓名 |
| end_repeat | | |
| end_repeat | | |

要從內部重複引用外部重複中的欄位，請使用 `${fieldname}` — 它會解析為最近的匹配父級：

在 `hh_members` 重複內，`${hh_id}` 返回的是**當前**家庭的 ID，而不是所有家庭的 ID。

## 重複組內部排序：`rank-index()`

當重複內部存在 `rank` 欄位時，使用外部的 `rank-index(instanceNumber, repeatedField)` 來獲取特定實例的序號排名：

| type | name | label | calculation |
|------|------|-------|-------------|
| calculate | top_scorer | | `rank-index(1, ${score})` |

`rank-index(1, ${score})` 返回得分最高實例的索引。

## `begin_repeat` 上的 `1screen` 外觀

在 `begin_repeat` 行的 `appearance` 列中添加 `1screen`，會將每個實例的所有問題顯示在同一個屏幕上，而不是每個屏幕顯示一個問題。

| type | name | label | appearance |
|------|------|-------|------------|
| begin_repeat | household_members | 家庭成員 | `1screen` |
| text | member_name | 成員姓名 | |
| integer | member_age | 年齡 | |
| end_repeat | | | |

當設置了 `1screen` 且組內沒有 `repeat_count` 欄位和 `add_repeat` 欄位時，rtSurvey 會自動在屏幕底部呈現一個圓形的 **+** 按鈕，以便調查員無需任何額外配置即可添加新實例。

| Appearance | 每個實例一個屏幕 | 添加了預設 + 按鈕 |
|------------|-------------------------|------------------------|
| `1screen` | 是 | 是（當沒有 `add_repeat` 子項時） |
| `field-list` | 是 | 否 |

當您需要分組布局但不需要自動添加按鈕時，請使用 `field-list`。當您既需要分組布局又需要内置的添加實例方式時，請使用 `1screen`。

---

## `add_repeat` 自定義添加按鈕

放置在重複組**內部**且帶有 `appearance: add_repeat` 的 `note`（或 `text`）欄位將呈現為全寬的「添加」按鈕。按鈕標籤來自該欄位的 `label` 列。當存在 `add_repeat` 欄位時，預設的圓形 + 按鈕（來自 `1screen`）將被禁用。

將 `add_repeat` 欄位作為重複組內部的最後一個欄位：

| type | name | label | appearance |
|------|------|-------|------------|
| begin_repeat | members | 成員 | `1screen` |
| text | member_name | 成員姓名 | |
| integer | member_age | 年齡 | |
| note | btn_add | + 添加成員 | `add_repeat` |
| end_repeat | | | |

### 顏色自定義

在外觀值中傳遞顏色代碼來設置按鈕樣式：

| Appearance value | Result |
|------------------|--------|
| `add_repeat <#04B404/>` | 綠色背景，預設文本顏色 |
| `add_repeat 04B404-ffffff` | 綠色背景，白色文本 |

第一個顏色是背景，第二個顏色（短橫線後）是文本顏色。使用短橫線分隔形式時，請省略 `#`。

### 圖標變體

使用 `add_repeat icon`（中間有空格）呈現緊湊的圓形圖標按鈕，而不是全寬按鈕：

| type | name | label | appearance |
|------|------|-------|------------|
| note | btn_add | + 添加 | `add_repeat icon` |

## 刪除按鈕：`delete-repeat-current` 和 `delete-repeat-last`

重複組內部帶有 `appearance: delete-repeat-current` 或 `appearance: delete-repeat-last` 的 `note` 欄位將呈現為拆分刪除按鈕。

| Appearance | Action |
|------------|--------|
| `delete-repeat-current` | 刪除當前（活動）實例 |
| `delete-repeat-last` | 刪除重複中的最後一個實例 |

預設（非圖標）按鈕是一個拆分按鈕：左側是垃圾桶圖標，右側是該欄位的標籤文本，跨越屏幕的整個寬度。

### 圖標變体

附加 `-icon` 以獲得緊湊的圓形垃圾桶圖標按鈕：

| Appearance | Result |
|------------|--------|
| `delete-repeat-current-icon` | 圓形垃圾桶圖標，刪除當前實例 |
| `delete-repeat-last-icon` | 圓形垃圾桶圖標，刪除最後一個實例 |

### 顏色自定義

顏色格式與 `add_repeat` 相同：使用 `<#RRGGBB/>` 或 `RRGGBB-RRGGBB`（背景-文本）。

### 完整模式示例

以下重複使用 `1screen`，頂部有一個圓形刪除當前按鈕，底部有一個全寬添加按鈕：

| type | name | label | appearance |
|------|------|-------|------------|
| begin_repeat | members | 成員 | `1screen` |
| note | btn_del | 移除 | `delete-repeat-current-icon` |
| text | member_name | 成員姓名 | |
| integer | member_age | 年齡 | |
| note | btn_add | + 添加成員 | `add_repeat` |
| end_repeat | | | |

## 最佳實踐

1. 當預先知道重複次數時，務必使用 `repeat_count` — 這可以防止調查員意外添加或刪除實例。
2. 保持重複組專注 — 每個實例包含 20 多個問題的重複很難導航。
3. 清晰地命名重複組（例如使用 `household_members`，而不是 `repeat1`） — 該名稱會出現在函數調用和導出的數據中。
4. 使用預期的最大實例數量進行測試，以驗證性能。
5. 在 `begin_repeat` 上使用 `1screen` 以在每個實例的一個屏幕上顯示所有問題，并在組內配合 `add_repeat` note 欄位，為調查員提供一個標記清晰的「添加」按鈕。

---

## 限制

- `indexed-repeat()` 需要有效的索引（1 到實例總數） — 超出範圍的索引將返回空值。
- 不建議嵌套重複超過 2 層，這可能會在某些客戶端上導致顯示問題。
- 聚合函數（`sum`、`count` 等）對整個重複組起作用 — 如果沒有 `*-if` 變体，您無法聚合實例的一個子集。

title: "媒體"

rtSurvey 支援問卷調查中豐富的媒體整合，讓您可以使用圖像、音頻和視頻增強問卷。此功能可以顯著改善受訪者體驗和收集資料的品質。

## 支援的媒體類型

rtSurvey 支援以下媒體類型：
- 圖像（jpg、png、gif）
- 音頻（mp3、wav）
- 視頻（mp4、webm）

## 在問卷調查中添加媒體

要在您的 rtSurvey 表單中包含媒體，請在 XLSForm 中使用以下欄位：

- `image`：用於顯示圖像
- `audio`：用於播放音頻文件
- `video`：用於播放視頻文件

範例：

```
| type | name          | label         | image        | audio       | video       |
|------|---------------|---------------|--------------|-------------|-------------|
| note | media_example | Media example | example.jpg  | sound.mp3   | clip.mp4    |
```

## 媒體文件管理

### 基於網頁的問卷調查
對於基於網頁的問卷調查，rtSurvey 提供媒體管理介面，您可以上傳和組織媒體文件。這些文件隨後自動可在您的問卷調查中使用。

### 行動應用程式
使用 rtSurvey 行動應用程式時：
1. 將您的媒體文件放在裝置上的 `/rtSurvey/forms/[form-name]-media/` 資料夾中。
2. 在 XLSForm 中參考確切的文件名稱。

## rtSurvey 特定功能

### 動態媒體載入
rtSurvey 支援根據問卷調查回應動態載入媒體：

```
| type         | name      | label              | image                    |
|--------------|-----------|--------------------|--------------------------| 
| select_one species | animal | Select an animal | ${animal}.jpg            |
```

### 選項中的媒體
rtSurvey 允許您在選擇問題的選項中使用媒體：

```
| type                | name    | label           | media::image |
|---------------------|---------|-----------------|--------------|
| select_one_from_file animals | Choose an animal |              |
```

在選項工作表中：
```
| list_name | name  | label | media::image |
|-----------|-------|-------|--------------|
| animals   | dog   | Dog   | dog.jpg      |
| animals   | cat   | Cat   | cat.jpg      |
```

### 媒體擷取
rtSurvey 使用媒體擷取功能擴展 XLSForm：

```
| type  | name        | label               |
|-------|-------------|---------------------|
| image | photo       | Take a photo        |
| audio | voice_note  | Record a voice note |
| video | video_clip  | Record a video      |
```

## 使用媒體的最佳實踐

1. **最佳化文件大小**：大型媒體文件可能會減慢問卷調查載入和提交速度。
2. **使用適當的格式**：堅持使用廣泛支援的格式（圖像用 jpg、音頻用 mp3、視頻用 mp4）。
3. **提供替代方案**：始終包含文字替代方案以提高無障礙存取性。
4. **徹底測試**：確保媒體在所有目標裝置上正確顯示。
5. **考慮離線使用**：對於可能離線進行的問卷調查，確保所有媒體在本地可用。

## 多語言媒體支援

rtSurvey 支援特定語言的媒體。使用 `::language` 後綴：

```
| type | name  | label    | image::English | image::Spanish |
|------|-------|----------|----------------|----------------|
| note | intro | Welcome  | welcome_en.jpg | welcome_es.jpg |
```

## 資料匯出中的媒體

從 rtSurvey 匯出資料時：
- 對於網頁問卷調查，媒體 URL 包含在匯出中。
- 對於行動應用程式問卷調查，包含文件路徑。

## 行動應用程式注意事項

- 確保裝置有足夠的儲存空間用於媒體密集的問卷調查。
- rtSurvey 行動應用程式支援離線媒體播放和擷取。
- 大型媒體文件可能會影響低端裝置上的應用程式效能。

## 已知限制

- 某些舊版瀏覽器可能不支援所有媒體格式。
- 非常大的視頻文件在低頻寬情況下可能會導致問題。

## 媒體問題疑難排解

1. **媒體未顯示**：檢查文件路徑和名稱的準確性。
2. **播放問題**：確保媒體格式被目標裝置支援。
3. **載入緩慢**：考慮最佳化文件大小或預載入媒體。

## 進階媒體功能

### 地理標記
rtSurvey 可以自動為問卷調查期間擷取的媒體添加地理標記：

```
| type  | name        | label        | appearance |
|-------|-------------|--------------|------------|
| image | photo       | Take a photo | geotag     |
```

### 媒體註解
允許受訪者在圖像上進行標記：

```
| type  | name        | label        | appearance |
|-------|-------------|--------------|------------|
| image | photo       | Annotate the image | annotate |
```

透過在 rtSurvey 表單中有效使用媒體，您可以建立更具吸引力、資訊豐富和準確的問卷調查。請記得在媒體包含帶來的好處與效能考量之間取得平衡，特別是對於在網際網路連接有限或低端裝置上部署的問卷調查。

---
title: "地理點"
description: "地理點問題捕獲地理座標（緯度、經度、海拔和精度）作為問卷調查的一部分。"
---

XLSForms 和 rtSurvey 中的 geopoint 問題類型使用裝置的 GPS 或其他定位服務收集地理座標。此功能對於地圖標記問卷調查回應、追蹤實地活動或將資料與特定位置關聯特別有用。

## 基本 XLSForm 規格

| type     | name        | label                           |
|----------|-------------|--------------------------------|
| geopoint | location    | 記錄當前位置                    |

有關基本 geopoint 問題類型的更多詳細資訊，請參閱 [XLSForm 規格](https://xlsform.org/en/#question-types)。

## 用途

地理點問題通常用於：

1. 地理標記問卷調查回應
2. 驗證實地活動的位置
3. 追蹤調查員的路線
4. 將環境或社會資料與特定位置關聯
5. 在地理分析中計算距離或面積

## 最佳實踐

1. 確保裝置已啟用定位服務並已授予權限。
2. 允許足夠的時間讓 GPS 獲取準確定位。
3. 考慮隱私影響，並告知受訪者位置資料的收集。
4. 與其他問題類型結合使用，為位置資料提供上下文。

## 使用範例

以下是如何在問卷調查中使用地理點問題的範例：

| type     | name           | label                                      | hint                                        |
|----------|----------------|--------------------------------------------|--------------------------------------------|
| geopoint | sample_location| 記錄樣本採集的位置                          | 站在開闊地帶以獲得更好的 GPS 訊號          |

## rtSurvey 擴展

雖然 geopoint 問題的基本 XLSForm 規格很簡單，但 rtSurvey 可能提供額外的功能或自訂選項：

1. 地圖整合以視覺確認捕獲的位置
2. 精度閾值設定
3. 手動輸入座標的選項
4. 與離線地圖整合以適用於偏遠地區

（注意：rtSurvey 中針對 geopoint 問題可用的特定擴展需要在此處確認和詳細說明。）

## 資料格式

地理點資料通常儲存為四個以空格分隔的值字串：

```
latitude longitude altitude accuracy
```

例如：
```
41.40338 2.17403 30.5 10
```

## 分析注意事項

使用地理點問題時，請考慮：

1. 如何將地理資料視覺化（例如製圖軟體）
2. 收集座標的精度及其對分析的影響
3. 處理位置資料的隱私和資料保護措施
4. 與 GIS（地理資訊系統）工具的潛在整合

## 限制

- 精度可能因裝置和環境條件而異。
- GPS 訊號在室內或有障礙物的地區可能較弱或無法使用。
- 收集位置資料可能會顯著影響裝置電池壽命。
- 收集精確位置資料可能存在隱私問題。

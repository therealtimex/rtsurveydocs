`calculate` 問題類型在背景靜默運行公式。它將結果存儲在一個命名的欄位中，其他問題可以引用該欄位，但它不向枚舉員顯示任何輸入或標籤。使用它來派生值、連接字串、運行條件邏輯或查找以後在表單中需要的數據。

---

## 基本語法

| type | name | label | calculation |
|------|------|-------|-------------|
| calculate | total | | `${price} * ${quantity}` |

- **type**: 始終為 `calculate`。
- **name**: 唯一的欄位名稱。其他問題使用 `${name}` 引用此欄位。
- **label**: 留空 — calculate 欄位永遠不會顯示給枚舉員。
- **calculation**: 要計算的公式。支持所有 [XLSForm 函數](../operators-and-functions/functions)和欄位引用。

---

## 常用模式

### 算術運算

| type | name | label | calculation |
|------|------|-------|-------------|
| integer | price | Unit price | |
| integer | quantity | Quantity | |
| calculate | total | | `${price} * ${quantity}` |
| note | total_note | Total: `${total}` | |

### 字串連接

| type | name | label | calculation |
|------|------|-------|-------------|
| text | first_name | First name | |
| text | last_name | Last name | |
| calculate | full_name | | `concat(${first_name}, ' ', ${last_name})` |

### 條件值

| type | name | label | calculation |
|------|------|-------|-------------|
| integer | score | Score (0–100) | |
| calculate | grade | | `if(${score} >= 90, 'A', if(${score} >= 75, 'B', if(${score} >= 60, 'C', 'F')))` |

### 根據出生日期計算年齡

| type | name | label | calculation |
|------|------|-------|-------------|
| date | dob | Date of birth | |
| calculate | age_years | | `int((today() - ${dob}) div 365.25)` |

## 使用 `once()` 鎖定值

默認情況下，每當引用的任何欄位發生更改時，`calculate` 都會重新計算。將公式包裝在 `once()` 中，以便僅在首次加載時計算並凍結結果：

| type | name | label | calculation |
|------|------|-------|-------------|
| calculate | interview_start | | `once(now())` |

對於時間戳、初始值或任何不希望在更改時重新計算的情況，請使用 `once()`。

## 從外部源提取數據

### 從 CSV 文件

```
pulldata('staff.csv', 'department', 'name', ${staff_id})
```

有關完整參考，請參閱 [pulldata()](../operators-and-functions/pulldata)。

### 從綁定的 SQLite 數據庫

```
pulldata('rawquery',
  concat(${family_path}, '/locations.db::provinces'),
  'SELECT name FROM provinces WHERE id = ?',
  ${province_id})
```

有關路徑構造的詳細信息，請參閱[本地數據庫搜索](../advanced-features/local-database-search)。

### 從應用程序上下文

```
pulldata('app-api', 'user.username')
pulldata('app-api', 'family_path')
```

有關所有可用鍵，請參閱 [App API](../app-api)。

## 在 relevant 和 constraint 中使用 calculate

其他欄位可以像引用任何欄位一樣引用 `calculate` 結果：

| type | name | label | relevant | constraint |
|------|------|-------|----------|------------|
| calculate | bmi | | | `${weight} div (${height} * ${height}) * 10000` |
| note | bmi_warning | BMI is very high — please verify weight and height. | `${bmi} > 40` | |

---

## 最佳實踐

1. 給 calculate 欄位起有意義的名字 — `total_cost` 比 `calc1` 更清晰，且在導出中更容易追踪。
2. 將複雜的公式拆分為多個鏈式 calculate 欄位，而不是使用一個深層嵌套的表達式。
3. 對時間戳和初始快照使用 `once()`，以防止值在首次捕獲後發生更改。
4. 將 `calculate` 欄位放在第一個引用它們的問題之前 — 計算順序遵循表單順序。
5. 保持 `label` 欄位為空。某些工具會顯示標籤；留空可以避免令人困惑的輸出。

## 限制

- Calculate 欄位永遠不會直接顯示給枚舉員 — 使用 `note` 欄位來顯示結果。
- `calculation` 欄位是必需的；沒有公式的 `calculate` 行始終存儲空字串。
- 除非包裝在 `once()` 中，否則結果會在每次表單更改時重新計算 — 大型表單中非常複雜的公式可能會影響低端設備的渲染性能。
- 計算出的值在提交時存儲為字串。將結果傳遞給算術或邏輯表達式時，請使用 `number()`、`int()` 或 `boolean()` 進行類型轉換。

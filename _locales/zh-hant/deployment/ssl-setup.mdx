在登錄之前必須配置 SSL。當您第一次打開應用程序時，您將被自動重定向到 SSL 設置屏幕。

---

## SSL 設置選項

![SSL setup options](/img/ssl-setup/ssl-setup-options.png)

選擇以下三個選項之一：

| 選項 | 何時使用 |
|------|----------|
| **免費 rtsurvey.com 子域名** *(推薦)* | 無需 DNS 設置。我們為您創建記錄。2–5 分鐘內就緒。 |
| **我自己的域名** | 您已經擁有一個域名，且其 DNS 已指向此服務器。 |
| **手動安裝證書** | 企業或自定義 CA。需要 SSH 訪問權限。 |

---

## 選項 1 — 免費 rtsurvey.com 子域名 *(推薦)*

這是最快的選項。無需域名註冊或 DNS 更改。

![HTTPS Setup form](/img/ssl-setup/ssl-setup-form.png)

> **在繼續之前：** 免費子域名需要在 [licenses.rtsurvey.com](https://licenses.rtsurvey.com) 擁有一個活動帳戶。免費計劃包含 1 個子域名 (`*.rtsurvey.com`)。

1. 點擊 **免費 rtsurvey.com 子域名** 以展開該部分
2. 在 **YOUR SUBDOMAIN** 字段中輸入您想要的子域名名稱

   > 使用小寫字母、數字和連字符。3–30 個字符。
   > 示例：`myproject` → `myproject.rtsurvey.com`

3. 將您從 [licenses.rtsurvey.com](https://licenses.rtsurvey.com) 獲取的 **rtSurvey DNS Token** 粘貼到令牌字段中
4. 點擊 **Create secure subdomain**

提交後，應用程序將開始為您配置證書：

![Setting up HTTPS progress](/img/ssl-setup/ssl-setup-progress.png)

四個步驟將自動運行：
- **Requesting DNS record** — 為您的子域名創建 DNS 條目
- **Waiting for DNS to propagate** — 通常需要 2–5 分鐘
- **Issuing SSL certificate** — Let's Encrypt 對您的證書進行簽名
- **Activating HTTPS** — Nginx 使用新證書重新加載

5. 完成後，您將被自動重定向到您的新 HTTPS URL

---

## 選項 2 — 我自己的域名

如果您擁有現有域名且其 DNS `A` 記錄已指向此服務器的 IP，請使用此選項。

1. 點擊 **我自己的域名** 以展開該部分
2. 輸入您的完整域名（例如 `survey.myorganization.org`）
3. 點擊 **Create certificate**

Let's Encrypt 將驗證您的域名並頒發證書。這需要先正確指向 DNS，否則請求將失敗。

---

## 選項 3 — 手動安裝證書

適用於使用自定義或內部 CA 的企業環境。您將通過 SSH 將證書文件放置在服務器上，然後在應用程序中輸入您的域名。

### 先決條件

- 服務器的 SSH 訪問權限
- 域名的有效證書和私鑰（PEM 格式）

### 第 1 步 — 通過 SSH 登錄服務器

```bash
ssh root@<server-ip>
```

### 第 2 步 — 放置您的證書文件

創建目錄並複製您的文件：

```bash
mkdir -p /etc/letsencrypt/live/<your-domain>
```

將您的文件複製到該目錄中，並使用以下確切名稱：

| 文件 | 描述 |
|------|------|
| `fullchain.pem` | 您的證書 + 任何中間 CA 證書（已合併） |
| `privkey.pem` | 您的私鑰 |

示例：

```bash
# 從您的本地計算機複製（在本地運行此命令，而不是在服務器上）
scp fullchain.pem root@<server-ip>:/etc/letsencrypt/live/<your-domain>/fullchain.pem
scp privkey.pem  root@<server-ip>:/etc/letsencrypt/live/<your-domain>/privkey.pem
```

設置正確的權限：

```bash
chmod 644 /etc/letsencrypt/live/<your-domain>/fullchain.pem
chmod 600 /etc/letsencrypt/live/<your-domain>/privkey.pem
```

### 第 3 步 — 在應用程序中輸入您的域名

1. 在 SSL 設置屏幕中，點擊 **手動安裝證書**
2. 輸入您的域名（必須與證書的 Common Name 或 SAN 匹配）
3. 點擊 **Apply**

服務器將配置 Nginx 使用您的證書並自動重新加載。

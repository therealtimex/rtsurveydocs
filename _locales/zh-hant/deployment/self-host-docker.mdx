import { Callout, Steps } from 'nextra/components'

如果您想使用公開 Docker 映像檔 `rtawebteam/rtcloud:survey-public` 在自己的伺服器（VPS、裸機或本機）上執行 rtSurvey，請使用本指南。

**無需 Docker Hub 登入** — 映像檔是公開的。

該容器將所有內容打包在單一映像檔中：
- Apache + PHP（應用程式伺服器）
- Shiny Server（分析儀表板，連接埠 3838）
- Beanstalkd（背景任務佇列）

---

## 需求

### 伺服器

| 資源 | 最低 | 建議 |
|------|------|------|
| 記憶體 | 4 GB | 8 GB |
| 磁碟 | 50 GB | 100 GB SSD |
| CPU | 2 vCPU | 4 vCPU |
| 作業系統 | Ubuntu 22.04 LTS | Ubuntu 22.04 LTS |

### 軟體

- **Docker Engine 24.0+** — [安裝指南](https://docs.docker.com/engine/install/ubuntu/)
- **Docker Compose v2.0+** — 隨 Docker Desktop 提供；Linux 上：`apt install docker-compose-plugin`

## 設定

<Steps>

### 建立工作目錄

```bash
mkdir -p /opt/rtsurvey && cd /opt/rtsurvey
```

### 建立 `docker-compose.yml`

```yaml
services:
  mysql:
    image: mysql:8.0
    container_name: rtsurvey-mysql
    restart: unless-stopped
    command: >
      --default-authentication-plugin=mysql_native_password
      --character-set-server=utf8
      --collation-server=utf8_unicode_ci
      --sql-mode=NO_ENGINE_SUBSTITUTION
    environment:
      MYSQL_ROOT_PASSWORD: ${MYSQL_ROOT_PASSWORD}
      MYSQL_DATABASE: ${MYSQL_DATABASE:-smartsurvey}
      MYSQL_USER: ${MYSQL_USER:-smartsurvey}
      MYSQL_PASSWORD: ${MYSQL_PASSWORD}
      MYSQL_ROOT_HOST: '%'
    volumes:
      - mysql_data:/var/lib/mysql
    networks:
      - rtsurvey-net
    healthcheck:
      test: ["CMD-SHELL", "mysqladmin ping -h localhost -u root -p$$MYSQL_ROOT_PASSWORD"]
      interval: 10s
      timeout: 5s
      retries: 5
      start_period: 30s

  rtsurvey:
    image: rtawebteam/rtcloud:survey-public
    container_name: rtsurvey-app
    restart: unless-stopped
    entrypoint: ["/bin/entrypoint-production.sh"]
    depends_on:
      mysql:
        condition: service_healthy
    ports:
      - "${APP_PORT:-8080}:80"
      - "${SHINY_PORT:-3838}:3838"
    env_file:
      - .env
    volumes:
      - app_uploads:/var/www/html/smartsurvey/uploads
      - app_audios:/var/www/html/smartsurvey/audios
      - app_downloads:/var/www/html/smartsurvey/downloads
      - app_gallery:/var/www/html/smartsurvey/gallery
      - app_tmp:/var/www/html/smartsurvey/tmp
      - app_cache:/var/www/html/smartsurvey/cache
      - app_runtime:/var/www/html/smartsurvey/protected/runtime
      - app_assets:/var/www/html/smartsurvey/assets
      - app_aggregate:/var/www/html/smartsurvey/aggregate
    networks:
      - rtsurvey-net
    healthcheck:
      test: ["CMD", "curl", "-f", "http://localhost/health"]
      interval: 30s
      timeout: 10s
      retries: 3
      start_period: 90s

  # 可選：嵌入式 Keycloak SSO
  # 啟動方式：docker compose --profile embed-keycloak up -d
  keycloak:
    image: quay.io/keycloak/keycloak:latest
    container_name: rtsurvey-keycloak
    restart: unless-stopped
    profiles:
      - embed-keycloak
    command: start --import-realm
    environment:
      KEYCLOAK_ADMIN: ${KEYCLOAK_ADMIN_USER:-admin}
      KEYCLOAK_ADMIN_PASSWORD: ${KEYCLOAK_ADMIN_PASSWORD}
      KC_HTTP_ENABLED: "true"
      KC_HTTP_RELATIVE_PATH: /auth
      KC_PROXY_HEADERS: xforwarded
      KC_HOSTNAME: ${KC_HOSTNAME}
      KC_HOSTNAME_STRICT: "false"
      KC_DB: mysql
      KC_DB_URL_DATABASE: ${KEYCLOAK_DB:-keycloak}
      KC_DB_URL_HOST: mysql
      KC_DB_USERNAME: ${KEYCLOAK_DB_USER:-keycloak}
      KC_DB_PASSWORD: ${KEYCLOAK_DB_PASSWORD}
    volumes:
      - ./keycloak-import:/opt/keycloak/data/import
    ports:
      - "${KEYCLOAK_PORT:-8091}:8080"
    depends_on:
      mysql:
        condition: service_healthy
    networks:
      - rtsurvey-net
    healthcheck:
      test: ["CMD-SHELL", "curl -f http://localhost:9000/health/ready || exit 1"]
      interval: 30s
      timeout: 10s
      retries: 10
      start_period: 120s

volumes:
  mysql_data:
  app_uploads:
  app_audios:
  app_downloads:
  app_gallery:
  app_tmp:
  app_cache:
  app_runtime:
  app_assets:
  app_aggregate:

networks:
  rtsurvey-net:
    driver: bridge
```

### 建立 `.env`

```bash
# Project
PROJECT_ID=mysurvey
PROJECT_TYPE=rtsurvey
PROJECT_URL=your-server-ip-or-domain
HTTP_PROTOCOL=http
TZ=UTC

# Database
MYSQL_HOST=mysql
MYSQL_DATABASE=smartsurvey
MYSQL_USER=smartsurvey
MYSQL_ROOT_PASSWORD=change-this-root-password
MYSQL_PASSWORD=change-this-app-password

# Admin (set before first startup — cannot change via env after DB is created)
ADMIN_PASSWORD=change-this-admin-password

# Runtime
RUN_ENV=prod
RUN_MODE=admin
GII_ENABLED=false
CSRF_VALIDATION_ENABLED=true

# Ports (optional — defaults shown)
APP_PORT=8080
SHINY_PORT=3838
```

<Callout type="warning">
啟動前請更改 `MYSQL_ROOT_PASSWORD` 和 `MYSQL_PASSWORD`。正式環境中使用強隨機字串（32+ 個字元）。
</Callout>

### 啟動服務堆疊

```bash
docker compose up -d
```

首次啟動需要約 60–90 秒 — MySQL 在首次執行時初始化資料庫。

### 驗證

```bash
# 檢查所有容器是否正在執行
docker compose ps

# 檢查應用程式健康狀態
curl http://localhost:8080/health
```

</Steps>

## 首次登入

健康檢查通過後，開啟瀏覽器：

```
http://your-server:8080/cpms/cpmsSite/login
```

| 欄位 | 值 |
|------|----|
| 使用者名稱 | `admin` |
| 密碼 | `.env` 中 `ADMIN_PASSWORD` 的值（預設為 `admin`） |

<Callout type="warning">
在首次啟動前在 `.env` 中設定 `ADMIN_PASSWORD`。入口點在首次執行時設定該值 — 資料庫初始化後更改無效。
</Callout>

## 環境變數

### 應用程式容器必要變數

如果缺少以下任何變數，入口點將拒絕啟動：

| 變數 | 說明 |
|------|------|
| `PROJECT_ID` | 此執行個體的唯一識別碼（英數字元，無空格） |
| `PROJECT_URL` | 存取應用程式的網域或 IP（無 `http://` 前綴） |
| `MYSQL_HOST` | MySQL 主機名稱 — 使用 Docker 服務名稱（如 `mysql`） |
| `MYSQL_DATABASE` | 資料庫名稱 |
| `MYSQL_PASSWORD` | 資料庫使用者密碼 |

### MySQL 容器必要變數

| 變數 | 說明 |
|------|------|
| `MYSQL_ROOT_PASSWORD` | MySQL root 密碼（由 `mysql` 容器使用，非應用程式） |

### 建議變數

| 變數 | 預設值 | 說明 |
|------|--------|------|
| `MYSQL_USER` | `smartsurvey` | 資料庫使用者名稱 |
| `ADMIN_PASSWORD` | `admin` | 初始管理員密碼 — **首次啟動前設定**，資料庫建立後無法透過 env 更改 |
| `HTTP_PROTOCOL` | `https` | 不使用 SSL 時設為 `http` |
| `PROJECT_PORT` | `80` | 使用者連接的外部連接埠（非內部 Docker 連接埠） |
| `PROJECT_TYPE` | `rtwork` | 平台類型 — 問卷平台使用 `rtsurvey` |
| `TZ` | `UTC` | 時區（如 `Asia/Bangkok`、`America/New_York`） |

### 執行時期變數

| 變數 | 預設值 | 說明 |
|------|--------|------|
| `RUN_ENV` | `prod` | 環境模式（`prod` 或 `dev`） |
| `RUN_MODE` | `admin` | 服務角色 — 單伺服器設定使用 `admin` |
| `GII_ENABLED` | `false` | 正式環境保持 `false`（Yii 程式碼產生器） |
| `CSRF_VALIDATION_ENABLED` | `true` | CSRF 保護 — 保持 `true` |

### 授權變數

| 變數 | 預設值 | 說明 |
|------|--------|------|
| `REQUIRE_LICENSE` | `false` | 設為 `true` 以強制授權驗證 |
| `RTCLOUD_LICENSE_KEY` | — | 您的授權金鑰 — `REQUIRE_LICENSE=true` 時必要 |

## 資料持久化

所有使用者資料儲存在具名 Docker 磁碟區中。這些磁碟區在容器重新啟動和映像檔更新後依然保留。

| 磁碟區 | 內容 |
|--------|------|
| `mysql_data` | 資料庫（問卷、使用者、回應） |
| `app_uploads` | 問卷中的檔案上傳 |
| `app_gallery` | 媒體庫 |
| `app_downloads` | 產生的匯出檔案 |
| `app_audios` | 錄音檔案 |
| `app_runtime` | PHP 工作階段和快取檔案 |
| `app_aggregate` | 彙總分析資料 |

映像檔標記為 `survey-public`。更新至最新版本：

```bash
docker compose pull
docker compose up -d
```

資料庫遷移透過正式入口點在啟動時自動執行。

## 備份與還原

### 備份資料庫

```bash
docker compose exec mysql \
  mysqldump -u root -p"${MYSQL_ROOT_PASSWORD}" smartsurvey \
  > backup-$(date +%Y%m%d).sql
```

### 還原資料庫

```bash
docker compose exec -T mysql \
  mysql -u root -p"${MYSQL_ROOT_PASSWORD}" smartsurvey \
  < backup-20240101.sql
```

### 備份上傳檔案

```bash
docker run --rm \
  -v rtsurvey_app_uploads:/data \
  -v $(pwd):/backup \
  alpine tar czf /backup/uploads-$(date +%Y%m%d).tar.gz -C /data .
```

## 嵌入式 Keycloak（可選 SSO）

正式 compose 檔案包含一個用於 SSO 的可選 Keycloak 容器。它共用同一個 MySQL 執行個體，透過 Docker Compose profile 啟用。

<Callout type="info">
嵌入式 Keycloak 至少需要 **4 GB 記憶體**。這是可選的 — 如果不需要 SSO 可跳過。
</Callout>

### 將 Keycloak 變數新增至 `.env`

```bash
# Keycloak admin
KEYCLOAK_ADMIN_USER=admin
KEYCLOAK_ADMIN_PASSWORD=change-this-keycloak-password

# Keycloak database (created automatically in the shared MySQL on first run)
KEYCLOAK_DB=keycloak
KEYCLOAK_DB_USER=keycloak
KEYCLOAK_DB_PASSWORD=change-this-keycloak-db-password

# KC_HOSTNAME: full public URL of your server (Keycloak appends /auth automatically)
KC_HOSTNAME=http://your-server:8091

# Port Keycloak listens on (host)
KEYCLOAK_PORT=8091

# Tell the rtCloud app to connect to embedded Keycloak
EMBED_KEYCLOAK=true
KEYCLOAK_URL=http://your-server:8091
KEYCLOAK_REALM=rtsurvey
KEYCLOAK_CLIENT_ID=rtsurvey
KEYCLOAK_CLIENT_SECRET=your-client-secret
```

`keycloak` 服務已包含在上述 `docker-compose.yml` 中（在 `embed-keycloak` profile 下 — 除非使用 `--profile embed-keycloak` 否則不會啟動）。

建立匯入目錄（Keycloak 沒有它也能啟動，但領域自動佈建將無法運作）：

```bash
mkdir -p /opt/rtsurvey/keycloak-import
```

### 使用 Keycloak 啟動

```bash
docker compose --profile embed-keycloak up -d
```

不使用 Keycloak 啟動（預設）：

```bash
docker compose up -d
```

### Keycloak 管理主控台

就緒後，存取 Keycloak 管理介面：

```
http://your-server:8091/auth/admin
```

使用 `KEYCLOAK_ADMIN_USER` / `KEYCLOAK_ADMIN_PASSWORD` 登入。

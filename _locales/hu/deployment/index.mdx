Futtassa az rtCloud-ot saját infrastruktúrán Docker Compose segítségével. A saját üzemeltetés teljes tulajdonjogot biztosít adatai, hálózata és telepítési környezete felett — ideális azoknak a szervezeteknek, amelyeknek adatrezidens, légréses hálózati vagy egyedi infrastrukturális igényeik vannak.

## Mi az rtCloud saját üzemeltetése?

Az rtCloud saját üzemeltetése egy hivatalos Docker-képfájl, amely az egész rtCloud platformot hordozható konténer-halmazba csomagolja, amelyet bármely Linux-kiszolgálón futtathat. A halmaz a következőket tartalmazza:

| Szolgáltatás | Leírás |
|---------|-------------|
| **rtCloud alkalmazás** | Apache 2.4 + PHP 7.4 webalkalmazás beépített háttérsorral (Beanstalkd), elemzési szerverrel (Shiny) és ütemezett feladatokkal |
| **MySQL 8.0** | Relációs adatbázis az összes alkalmazás- és felmérési adathoz |
| **Keycloak** *(opcionális)* | Beágyazott egyszeri bejelentkezési (SSO) szerver vállalati identitáskezeléshez |

## Mikor érdemes saját üzemeltetést választani?

A saját üzemeltetés a megfelelő választás, ha:

- **Adatszuverenitást** igényel — az összes adat saját infrastruktúráján marad
- **Légréses vagy korlátozott hálózaton** működik, külső felhőhozzáférés nélkül
- **Megfelelési követelményei** vannak (GDPR, HIPAA, kormányzati adatpolitikák), amelyek helyi tárolást írnak elő
- Integrálni kell egy **belső identitásszolgáltatóval** (Active Directory, LDAP, SAML)
- **Erőforrásokat szeretne testreszabni** — CPU, RAM és tárhelyfoglalás saját feltételek szerint

## Architektúra áttekintése

A telepítés Docker-konténerek halmazaként fut, amelyek egy belső hálózaton kapcsolódnak egymáshoz:

```
┌────────────────────────────────────────┐
│            rtcloud-app                 │
│  Apache 2.4 (80-as port)               │
│  PHP 7.4 alkalmazás                    │
│  Beanstalkd sor (belső)                │
│  Shiny Server (3838-as port)           │
│  Cron ütemező                          │
└─────────────────┬──────────────────────┘
                  │ rtcloud-net (híd)
┌─────────────────▼──────────────────────┐
│            rtcloud-mysql               │
│  MySQL 8.0 (3306-os port, csak belső)  │
└────────────────────────────────────────┘
```

SSO engedélyezésekor egy harmadik konténer fut mellette:

```
┌─────────────────────────────────────────┐
│            rtcloud-keycloak             │
│  Keycloak (8080-as port, csak belső)    │
│  Admin felület (9000-es port, csak belső)|
└─────────────────────────────────────────┘
```

Minden konténer egy izolált Docker-hídhalózaton kommunikál. Csak a webalkalmazás portja és (opcionálisan) a Shiny elemzési port érhető el a gazdagépen.

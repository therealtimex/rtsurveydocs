A bejelentkezés előtt be kell állítani az SSL-t. Az alkalmazás első megnyitásakor automatikusan az SSL beállítási képernyőre irányítjuk.

---

## SSL beállítási lehetőségek

![SSL beállítási lehetőségek](/img/ssl-setup/ssl-setup-options.png)

Válasszon egyet a három lehetőség közül:

| Opció | Mikor használjam |
|--------|-------------|
| **Ingyenes rtsurvey.com aldomain** *(Ajánlott)* | Nincs szükség DNS beállításra. Létrehozzuk a rekordot Önnek. 2–5 perc alatt kész. |
| **Saját domain** | Már rendelkezik domainnel, és annak DNS-e erre a szerverre mutat. |
| **Tanúsítvány manuális telepítése** | Vállalati vagy egyedi CA. SSH hozzáférés szükséges. |

---

## 1. opció — Ingyenes rtsurvey.com aldomain *(Ajánlott)*

Ez a leggyorsabb lehetőség. Nincs szükség domain regisztrációra vagy DNS módosításra.

![HTTPS beállítási űrlap](/img/ssl-setup/ssl-setup-form.png)

> **Mielőtt folytatná:** Az ingyenes aldomainhez aktív fiók szükséges a [licenses.rtsurvey.com](https://licenses.rtsurvey.com) oldalon. Az ingyenes csomag 1 aldomaint (`*.rtsurvey.com`) tartalmaz.

1. Kattintson az **Ingyenes rtsurvey.com aldomain** gombra a szakasz kibontásához
2. Írja be a kívánt aldomain nevet a **YOUR SUBDOMAIN** mezőbe

   > Kisbetűket, számokat és kötőjeleket használjon. 3–30 karakter.
   > Példa: `myproject` → `myproject.rtsurvey.com`

3. Illessze be az **rtSurvey DNS Token**-t a [licenses.rtsurvey.com](https://licenses.rtsurvey.com) oldalról a token mezőbe
4. Kattintson a **Create secure subdomain** gombra

A beküldés után az alkalmazás megkezdi a tanúsítvány kiállítását:

![HTTPS beállítás folyamatban](/img/ssl-setup/ssl-setup-progress.png)

A négy lépés automatikusan lefut:
- **DNS rekord kérése** — létrehozza a DNS bejegyzést az aldomainhez
- **Várakozás a DNS propagációra** — általában 2–5 perc
- **SSL tanúsítvány kiállítása** — a Let's Encrypt aláírja a tanúsítványt
- **HTTPS aktiválása** — az Nginx újraindul az új tanúsítvánnyal

5. Ha kész, automatikusan átirányítjuk az új HTTPS URL-re.

## 2. opció — Saját domain

Használja ezt, ha meglévő domainnel rendelkezik, és annak DNS `A` rekordja már a szerver IP-címére mutat.

1. Kattintson a **Saját domain** gombra a szakasz kibontásához
2. Adja meg a teljes domain nevét (pl. `survey.myorganization.org`)
3. Kattintson a **Create certificate** gombra



A Let's Encrypt ellenőrzi a domaint és kiállítja a tanúsítványt. Ehhez szükséges, hogy a DNS előzetesen megfelelően legyen beállítva — ellenkező esetben a kérés sikertelen lesz.

---

## 3. opció — Tanúsítvány manuális telepítése

Vállalati környezetekhez, ahol egyedi vagy belső CA-t használnak. A tanúsítványfájlokat SSH-n keresztül kell a szerverre másolnia, majd meg kell adnia a domaint az alkalmazásban.

### Előfeltételek

- SSH hozzáférés a szerverhez
- Érvényes tanúsítvány és privát kulcs a domainhez (PEM formátum)

### 1. lépés — Belépés SSH-n keresztül

```bash
ssh root@<server-ip>
```

### 2. lépés — Tanúsítványfájlok elhelyezése

Hozza létre a könyvtárat és másolja oda a fájlokat:

```bash
mkdir -p /etc/letsencrypt/live/<your-domain>
```

Másolja a fájlokat ebbe a könyvtárba a következő pontos nevekkel:

| Fájl | Leírás |
|------|-------------|
| `fullchain.pem` | A tanúsítvány + az esetleges köztes CA tanúsítványok (összefűzve) |
| `privkey.pem` | A privát kulcs |

Példa:

```bash
# Másolás a helyi gépről (ezt helyileg futtassa, ne a szerveren)
scp fullchain.pem root@<server-ip>:/etc/letsencrypt/live/<your-domain>/fullchain.pem
scp privkey.pem  root@<server-ip>:/etc/letsencrypt/live/<your-domain>/privkey.pem
```

Megfelelő jogosultságok beállítása:

```bash
chmod 644 /etc/letsencrypt/live/<your-domain>/fullchain.pem
chmod 600 /etc/letsencrypt/live/<your-domain>/privkey.pem
```

### 3. lépés — Domain megadása az alkalmazásban



1. Az SSL beállítási képernyőn kattintson a **Tanúsítvány manuális telepítése** gombra
2. Adja meg a domain nevét (meg kell egyeznie a tanúsítvány Common Name vagy SAN értékével)
3. Kattintson az **Apply** gombra

A szerver konfigurálja az Nginx-et a tanúsítvánnyal, és automatikusan újraindul.

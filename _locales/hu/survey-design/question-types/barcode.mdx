---
title: "Vonalkód"
description: "A vonalkód kérdések beolvassák és rögzítik a QR-kódokat és vonalkód adatokat a felmérésben."
---

A `barcode` kérdéstípus egy kódértéket rögzít QR-kód vagy vonalkód beolvasásával az eszköz kamerájával. A szkenner modál tartalmaz egy kézi szöveges beviteli lehetőséget is, mint tartalékot, ha a beolvasás nem lehetséges.

## Alapvető XLSForm specifikáció

| type    | name         | label                    |
|---------|--------------|--------------------------|
| barcode | product_code | Szkennelje be a termék vonalkódját |
| barcode | ticket_id    | Szkennelje be a jegyet |

A szabványos specifikációt lásd az [XLSForm dokumentációban](https://xlsform.org/en/#question-types).

---

## Támogatott formátumok

Az rtSurvey támogatja a QR-kódokat és a szabványos 1D vonalkódokat az eszköz kamerájával, beleértve:

- QR Code
- UPC-A, UPC-E
- EAN-8, EAN-13
- Code 39, Code 128
- ITF, Codabar

---

## Alapértelmezett elrendezés

Ha nincs `appearance` beállítva, a kérdés egy teljes szélességű **"BARCODE BEOLVASÁSA"** gombot jelenít meg. Ennek megérintésével megnyílik a szkenner modál. Sikeres beolvasás után a gomb **"BARKÓD CSERÉJE"**-re változik, és a beolvasott érték alatta kattintható linkként jelenik meg.

---

## Szkenner modál

A szkenner modál mindig tartalmazza:
- **Élő kamera nézet** — automatikusan beolvas érzékeléskor; a modál sikeres beolvasás után bezáródik.
- **Kézi szöveges bevitel** — egy szövegmező alul, ahol az összeíró begépelheti a kódot, ha a beolvasás nem sikerül.
- **Kész gomb** — elküldi a manuálisan beírt értéket.

Ha az eszköz kamerája nem elérhető, a modál visszatér az **"Kép feltöltése"** opcióra — az összeíró feltölthet egy fényképet a vonalkódról a dekódoláshoz.

---

## Beágyazott gombelrendezés

Adjon hozzá `inline` értéket, hogy a szkennert **kör alakú ikon gombként** jelenítse meg a címke mellett, a teljes szélességű gomb helyett.

```
| type    | name | label     | appearance                              |
|---------|------|-----------|----------------------------------------|
| barcode | code | Elem beolvasása | inline display{right}                  |
| barcode | code | Elem beolvasása | inline display{left, large}            |
| barcode | code | Elem beolvasása | inline display{center, large, <0099FF/>} |
```

**Gomb pozíciója** — `left`, `right` *(alapértelmezett)*, `top`, `center`, `bottom`

**Gomb mérete** — `small` *(alapértelmezett)*, `medium`, `large`

**Gomb színe** — adjon hozzá egy hexadecimális színt a `display{}` belsejébe az elsődleges szín felülírásához:

```
inline display{right, large, <FF5500/>}
```

**Felvétel utáni vezérlés — `results{}`:**

| Appearance | Effect |
|---|---|
| `results{hide(scanner)}` | Elrejti a szkennelés gombot, miután egy érték rögzítésre került |
| `results{hide(review)}` | Elrejti a beolvasott érték linkjét a rögzítés után |
| `results{hide(value)}` | Elrejti a beolvasott érték szöveges megjelenítését |
| `results{left}` | Az ikont balra mozgatja a rögzítés után |

Példa – a szkenner elrejtése az első szkennelés után:
```
inline display{center, large} results{hide(scanner)}
```

---

## `inputs{auto-close(N)}` — szkenner automatikus bezárása

Automatikusan bezárja a szkenner modált `N` másodperc után, ha nem észlel vonalkódot. Élő visszaszámláló jelenik meg a modálban.

```
inputs{auto-close(10)}     → 10 másodperc után bezáródik
inputs{auto-close(5)}      → 5 másodperc után bezáródik
```

Kombinálja az inline-nal:
```
inline display{right} inputs{auto-close(10)}
```

---

## `inputs{floating}` — lebegő, húzható szkenner

Megjelenít egy **minimalizáló gombot** (összenyomó ikon ⊞) a szkenner modál fejlécében. Ennek megérintésével a szkenner egy kis lebegő kör alakú ikonná zsugorodik, amely a képernyő bármely pontjára húzható. A lebegő ikon megérintésével újra megnyílik a szkenner.

```
inputs{floating}
inline display{right} inputs{floating}
```

Hasznos olyan munkafolyamatokban, ahol az összeírónak látnia kell az űrlapot, miközben a szkenner aktív (pl. elemek szkennelése egy listában).

---

## `invisible auto-show` — szkenner automatikus megnyitása

Elrejti a kérdés widgetjét az elrendezésből, de automatikusan megnyitja a szkennert, amikor az oldal betöltődik. Hasznos egy néma szkennelési lépés beágyazásához az űrlapfolyamba.

```
invisible auto-show
inline invisible auto-show
```

---

## Ismétlődő csoportokban

Amikor a `barcode` egy `begin repeat` csoporton belül van, a sikeres szkennelés automatikusan a **következő ismétlődő példányra** lép, miután az érték rögzítésre került. Ez lehetővé teszi a gyors, szekvenciális szkennelést anélkül, hogy az összeírónak minden elem között meg kellene érintenie az "Hozzáadás" gombot.

---

## A címke elrejtése

```
inline text-nolabel display{center, large}
```

## Bevált gyakorlatok

1. Használja az `inputs{auto-close(N)}` lehetőséget, hogy megakadályozza a szkenner korlátlan nyitva maradását – válasszon egy értéket, amely elegendő időt biztosít az összeíróknak a vonalkód elhelyezésére (jellemzően 8–15 másodperc).
2. Használja az `inputs{floating}` lehetőséget, amikor az űrlapnak láthatónak kell maradnia szkennelés közben (pl. egy listából történő szkennelés, ahol az összeíró egy látható mezőhöz viszonyít).
3. Helyezze a vonalkód kérdést ismétlődő csoportba a gyors, szekvenciális szkenneléshez – az automatikus ismétlődés előrehaladás kiküszöböli a kézi "Hozzáadás" lépést.
4. Mindig tartalmazza a `hint` oszlopot a pozicionálási utasításokkal (pl. "Tartsa a vonalkódot 10–30 cm távolságra a kamerától, jó fényviszonyok között").
5. A szkenner modálban található kézi szöveges bevitel mindig elérhető – képezze ki az összeírókat, hogy használják tartalékként sérült vagy piszkos vonalkódok esetén.

## Korlátozások

- A szkennelés pontossága a kamera minőségétől, a megvilágítástól és a vonalkód állapotától függ – a sérült vagy alacsony kontrasztú kódok nem biztos, hogy megbízhatóan szkennelhetők.
- A szkenner a hátsó (környezet felé néző) kamerát használja; a hátsó kamera nélküli eszközök visszatérnek a képfeltöltési opcióhoz.
- Az `invisible auto-show` csak az első oldalbetöltéskor nyílik meg; az oldalra való visszanavigálás nem indítja újra az automatikus megnyitást.

---

A `geotrace` kérdéstípus földrajzi koordináták sorozatát rögzíti, amelyek egy vonalat vagy útvonalat (polyline) alkotnak. Az rtSurvey webes űrlapján ez egy **szöveges beviteli mezőként** jelenik meg, ahová az adatgyűjtő (enumerator) közvetlenül írja be vagy másolja be a koordináta-karakterláncot.

## Alapvető XLSForm specifikáció

| type     | name        | label                        |
|----------|-------------|------------------------------|
| geotrace | river_path  | Kövesse a folyó útvonalát |
| geotrace | road_route  | Rögzítse az út útvonalát |

A szabványos specifikációt az [XLSForm dokumentációjában](https://xlsform.org/en/#question-types) találja.

---

## Adatformátum (Data Format)

Pontosvesszővel elválasztott pontlistaként tárolódik, a **pontosvesszők körül szóközök nélkül**. Minden pont négy, szóközzel elválasztott értékből áll:

```
lat lon alt acc;lat lon alt acc;lat lon alt acc
```

| Component | Description |
|-----------|-------------|
| `lat` | Szélességi fok tizedes fokokban |
| `lon` | Hosszúsági fok tizedes fokokban |
| `alt` | Magasság méterben (`0`, ha ismeretlen) |
| `acc` | GPS pontosság méterben (`0`, ha ismeretlen) |

**Példa — egy hárompontos útvonal:**
```
13.756331 100.501762 15 8;13.758000 100.503000 14 6;13.760000 100.505000 13 5
```

Egy érvényes útvonal kialakításához legalább két pont szükséges.

---

## Hogyan jelenik meg az rtSurvey-ben

Az rtSurvey webes űrlapján a `geotrace` egyszerű **szöveges mezőként** jelenik meg. Az adatgyűjtő begépeli vagy bemásolja a koordináta-karakterláncot. A jelenlegi webes űrlapon nincs beépített interaktív térképes választó ehhez a típushoz.

### Pontok rögzítése interaktívan

A terepi adatgyűjtéshez ajánlott minta a **`geopoint` kérdések ismétlődő csoportja (repeat group)** — minden pont a teljes GPS térképválasztót használja —, kombinálva egy `calculate` mezővel a geotrace karakterlánc előállításához:

| type | name | label | calculation |
|------|------|-------|-------------|
| begin repeat | path_points | Rögzítsen minden útvonalpontot | |
| geopoint | point | Érintse meg a pont rögzítéséhez | |
| end repeat | path_points | | |
| calculate | geotrace_value | | `join(';', ${path_points/point})` |

A kiszámított karakterlánc ezután tárolható egy `text` kérdésben, vagy felhasználható a `geotrace` típusban.

## Példa a használatra

| type | name | label | hint | required |
|------|------|-------|------|----------|
| geotrace | farm_boundary_path | Rögzítse a gazdasághoz vezető utat | Adja meg az egyes útvonalpontokat pontosvesszővel elválasztva | yes |

---

## Legjobb gyakorlatok

1. Használjon `geopoint` kérdésekből álló ismétlődő csoportot az interaktív térképalapú gyűjtéshez, majd kapcsolja össze az értékeket — ez az adatgyűjtőknek GPS-választót biztosít minden egyes ponthoz.
2. Adja meg az elvárt formátumot a `hint` oszlopban, ha kézi koordináta-bevitelre van szükség.
3. Ellenőrizze a jelenlétet a `required = yes` beállítással, ha az útvonal kötelező.
4. Tervezze meg az adattisztítást — a manuálisan megadott útvonalak pontossága következetlen lehet.

## Korlátozások (Limitations)

- Az rtSurvey webes űrlapján nincs beépített interaktív térképes választó a `geotrace` típushoz.
- A koordináta-karakterlánc hosszú lehet összetett útvonalak esetén — ezt tartsa szem előtt az űrlap teljesítménye és a tárhely szempontjából.
- Az útvonal topológiájának ellenőrzése (pl. minimális pontszám, önmetszés) az XLSForm korlátozásain kívüli utófeldolgozást igényel.

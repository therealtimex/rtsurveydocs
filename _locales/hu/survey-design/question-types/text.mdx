A `text` kérdéstípus szabad szöveges karakterláncot gyűjt. Ez a legrugalmasabb beviteli típus, és számos megjelenési változatot támogat, amelyek megváltoztatják a bevitel megjelenítését — az egyszerű egysoros mezőtől a beszédfelismerésig, felugró párbeszédpanelekig, gazdag szövegszerkesztőkig és numerikus számlálókig.

## Alapvető XLSForm specifikáció

| type | name | label |
|------|------|-------|
| text | respondent_name | Válaszadó teljes neve |
| text | address | Lakcím |

A szabványos specifikációért lásd az [XLSForm documentation](https://xlsform.org/en/#question-types).

---

## Elrendezési módok

### Alapértelmezett — egysoros bevitel

Nincs szükség megjelenésre. Egy szabványos `<input type="text">` mezőt renderel.

---

### `multiline` — szövegmező

Többsoros szövegmezőt renderel. A felhasználó gépeléssel bővítheti; automatikusan növekszik.

```
multiline
```

**Sor magasságának szabályozása a `[initRows, maxRows]` hozzáfűzésével:**

```
multiline [3,8]     → starts at 3 rows, expands up to 8
multiline [5]       → fixed at 5 rows
```

Az alapértelmezett 1 sor, maximum nélkül. Shift+Enter soremelést szúr be; Enter a következő kérdésre lép.

---

### `floating_hint` — tipp címkeként lebeg

A `hint` szöveg helykitöltőként jelenik meg a beviteli mezőben. Amikor a felhasználó elkezd gépelni, a súgó címkeként lebeg a mező felett.

```
floating_hint
```

---

### `embed` — tipp a beviteli mezőn belül

Hasonló a `floating_hint`-hez — a súgó a beviteli mezőn belül jelenik meg, amikor a mező üres. Nem lebeg gépelés közben.

```
embed
```

---

### `textpopup` — modális párbeszédpanel bevitele

A mező megérintése egy SweetAlert modális párbeszédpanelt nyit meg egy nagy beviteli mezővel, ahelyett, hogy inline szerkesztené. Hasznos mobilon, hogy több képernyőterületet biztosítson a gépeléshez.

```
textpopup
```

---

### `richtext` — WYSIWYG szerkesztő

Teljes gazdag szövegszerkesztőt (Monaco / Draft.js) renderel. A válaszadó félkövéren, dőlten írhat, listákat adhat hozzá stb. A tárolt érték HTML.

```
richtext
richtext(30%)       → editor height 30% of viewport
```

---

### `charcount` — élő karakter számláló

Élő `(n)` karakterszámláló kijelzőt ad a beviteli mező alá, amely a felhasználó gépelése közben frissül.

```
charcount
multiline charcount
```

---

## Numerikus beviteli változatok

Ezek a megjelenések `text` típuson működnek, hogy számokat gyűjtsenek speciális formázással vagy interakciós mintákkal.

### `numbers` — numerikus billentyűzet

Az HTML beviteli típust `number`-re kényszeríti, mobilon numerikus billentyűzetet indít.

```
numbers
```

### `thousandsep` — ezres elválasztó

Vesszővel csoportosítva jeleníti meg a számot (pl. `1,234,567`), miközben tárolja a nyers számot. A beviteli típus `text`-re kényszerül, hogy lehetővé tegye a vesszők megjelenítését.

```
thousandsep
```

### `digisep(n, "sep")` — egyéni számjegycsoportosítás

Számjegyeket csoportosít `n` blokkokba, egyéni karakterrel elválasztva. Hasznos telefonszámokhoz, azonosító számokhoz stb.

```
digisep(4,"-")      → 0912-3456-789
digisep(3," ")      → 012 345 678
```

### `number-hspinner` — vízszintes számláló

Kicseréli a beviteli mezőt egy vízszintes **− érték +** számlálóra. A felhasználó a mínusz/plusz gombok megérintésével csökkenti vagy növeli az értéket. `int` és `decimal` típusokkal is működik.

```
number-hspinner
```

**Gomb megjelenésének testreszabása a `hspinner()` használatával:**

```
number-hspinner hspinner('left-small-square','right-small-square','1')
```

Paraméterek: bal gomb alakja, jobb gomb alakja, lépésköz.

**Egyéni színek a `colors()` használatával:**

```
number-hspinner colors(0099FF,FFFFFF,FF5500,FFFFFF)
```

Négy színérték: bal-háttér, bal-ikon, jobb-háttér, jobb-ikon.

### `prefix(expr)` — előtag hozzáadása

Kiszámított vagy statikus karakterláncot illeszt a megjelenített érték elé. A tárolt érték nem tartalmazza az előtagot.

```
prefix('USD ')      → displays "USD 100", stores "100"
prefix(${currency}) → dynamic prefix from another field
```

### `textonly` — szöveges beviteli típus kényszerítése

`type="text"` értéket kényszerít akkor is, ha a mező `integer` vagy `decimal`. Hasznos a böngésző numerikus beviteli sajátosságainak elkerülésére.

```
textonly
```

## Szöveg átalakítás

Ezek a megjelenések automatikusan átalakítják az értéket, ahogy a felhasználó gépel.

| Appearance | Effect | Example input → stored |
|---|---|---|
| `upper` | Nagybetűssé alakít | `hello` → `HELLO` |
| `lower` | Kisbetűssé alakít | `HELLO` → `hello` |
| `proper` | Nagy kezdőbetűssé alakít | `john doe` → `John Doe` |

## Bevitel rögzítési segédek

### `inputs{stt}` — beszéd szöveggé

Mikrofon gombot ad a beviteli mező mellé. Megérintve elindítja a böngésző beszédfelismerését (Web Speech API). Az átírt szöveg hozzáfűződik a mezőhöz.

```
inputs{stt}
```

Nem támogatott a Safarin. Mikrofon engedély szükséges.

### `inputs{qrscan}` — QR / vonalkód olvasó

QR-kód beolvasó gombot ad a beviteli mező mellé. Megnyitja a kamera szkennelő modális ablakát, és feltölti a mezőt a beolvasott értékkel.

```
inputs{qrscan}
```

**Tokenizálás** (beolvasott értékek hozzáfűzése csere helyett):

```
inputs{qrscan} append(${separator})
```

### `inputs{stt,qrscan}` — beszéd és beolvasás is

A mikrofon és a QR beolvasás gombokat is egymás mellett rendereli.

```
inputs{stt,qrscan}
inputs{qrscan,stt}
```

## Kiválasztáshoz kapcsolt változatok

Ezek a megjelenések egy szövegmezőt egy `select_one` választási listához kapcsolnak, lehetővé téve a felhasználó számára, hogy a listából válasszon, vagy szabadon gépeljen.

### `selection_one_hide` — legördülő választó

A szöveges bevitelt legördülő nyíllal rendereli. A nyílra koppintva megjelennek a kapcsolt `search()` listából származó választások. Egy választás kiválasztása kitölti a beviteli mezőt és zárolja azt (✕-et mutat a törléshez).

```
selection_one_hide
```

### `selection_one_show` — rádió lista alább

A szöveges bevitelt rádiógombokkal rendereli alatta. Egy rádiógomb kiválasztása kitölti és zárolja a beviteli mezőt.

```
selection_one_show
```

Mindkét változatnak szüksége van egy `search()` kifejezésre a `calculation` oszlopban a választási lista definiálásához.

---

## Válasz igazítása

Szabályozza a beírt szöveg vízszintes igazítását a beviteli mezőn belül.

```
align_answer = left
align_answer = right
align_answer = center
```

## Időbevitel widget (beágyazott óra)

Az rtSurvey kiterjeszti a `text` típust egy óra választó widgettel. Ezek a megjelenések egy óra ikont jelenítenek meg, amelyet az összeíró megérintve kiválaszt egy időértéket. Az érték egyszerű szövegként tárolódik a kiválasztott formátumban.

### Megjelenések

| Appearance | Description |
|---|---|
| `inline` | Óra ikon gomb a mező mellett, modális ablakot nyit meg |
| `inline-onlyresult` | Óra ikon eltűnik a kiválasztás után |
| `inline-1line` | Kompakt egysoros idő számláló |
| `inline colors("RRGGBB")` | Óra ikon egyéni színnel |
| `inline-1line colors("RRGGBB","RRGGBB")` | Számláló két hangsúlyos színnel |

### Formátum tokenek

Fűzze hozzá a `-[format]`-et, hogy szabályozza, mely időösszetevők jelenjenek meg és tárolódjanak:

| Format | Displays |
|---|---|
| `inline-[%H:%M]` | Órák : Percek (24h) |
| `inline-[%h:%M]` | Órák : Percek (12h) |
| `inline-[%H:%M:%S]` | Órák : Percek : Másodpercek (24h) |
| `inline-[%M:%S]` | Percek : Másodpercek |
| `inline-[%H:%M:%3]` | Órák : Percek : Ezredmásodpercek |
| `inline-[%S]` | Csak másodpercek |
| `inline-[%3]` | Csak ezredmásodpercek |
| `inline-[%H]` | Csak órák (24h) |

### Gomb pozíciója `display{}`

Ugyanaz, mint más inline típusoknál — az óra gomb pozícióját és méretét szabályozza:

```
inline display{right}
inline display{center, large}
inline-onlyresult display{left, medium, #0099FF}
```

## Korlátozások és érvényesítés

Alkalmazzon korlátozásokat a formátum, a hossz vagy a minta kikényszerítésére:

| type | name | label | constraint | constraint_message |
|------|------|-------|------------|-------------------|
| text | name | Teljes név | `string-length(.) >= 2` | Legalább 2 karakter szükséges |
| text | code | Hivatkozási kód | `regex(., '^[A-Z]{2}[0-9]{4}$')` | 2 nagybetű + 4 számjegy |
| text | phone | Telefonszám | `regex(., '^[0-9]{9,15}$')` | Adjon meg érvényes telefonszámot |

---

## Ajánlott Gyakorlatok

1. Használjon specifikusabb típusokat (`integer`, `decimal`, `date`), ha az adatoknak ismert struktúrájuk van — ez megakadályozza az érvénytelen bejegyzéseket.
2. Használja a `multiline [3,8]`-at a nyitott kérdésekhez, hogy a válaszadók számára helyet biztosítson az íráshoz anélkül, hogy túlterhelnék a képernyőt.
3. Használja a `thousandsep`-et vagy `digisep()`-et `numbers` helyett, ha formázott megjelenítésre van szüksége — a `numbers` önmagában csak a billentyűzetet változtatja meg.
4. Használja az `inputs{qrscan}`-t a kódok, azonosítók és sorozatszámok kézi gépelési hibáinak kiküszöbölésére.
5. Használja a `floating_hint`-et, ha a súgó fontos kontextus, amelynek láthatónak kell maradnia gépelés közben — a szabványos súgók eltűnnek a kis képernyőkről.
6. Használja a `charcount`-ot a hosszkorláttal rendelkező kérdéseken, hogy a válaszadók önellenőrzést végezhessenek.

## Korlátok

- Az `inputs{stt}`-hez olyan böngésző szükséges, amely támogatja a Web Speech API-t. A Chrome a legmegbízhatóbb; a Safari nem támogatott.
- A `richtext` HTML-t tárol — tervezze meg az HTML eltávolítását vagy szanálását az elemzési pipeline-ban, ha egyszerű szöveg várható.
- A `selection_one_hide` és `selection_one_show` `search()` kifejezést igényel, és csak a webes kliensen támogatottak.
- A `number-hspinner` minden gombnyomásra ellenőrzi a `constraint` oszlopot, nem csak a fókusz elvesztésekor — ennek megfelelően tervezze meg a korlátozásokat.

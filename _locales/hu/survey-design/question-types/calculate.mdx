A `calculate` kérdéstípus csendben, a háttérben futtat egy képletet. Az eredményt egy elnevezett mezőben tárolja, amelyre más kérdések hivatkozhatnak — de nem jelenít meg beviteli mezőt vagy címkét a számlálónak. Használja értékek származtatására, karakterláncok összefűzésére, feltételes logika futtatására vagy olyan adatok kikeresésére, amelyekre később szüksége lesz az űrlapon.

---

## Alapvető szintaxis

| type | name | label | calculation |
|------|------|-------|-------------|
| calculate | total | | `${price} * ${quantity}` |

- **type**: Mindig `calculate`.
- **name**: Egyedi mezőnév. Más kérdések erre hivatkoznak a `${name}` használatával.
- **label**: Hagyja üresen — a calculate mezők soha nem láthatók a számláló számára.
- **calculation**: A kiértékelendő képlet. Támogatja az összes [XLSForm függvényt](../operators-and-functions/functions) és mezőhivatkozást.

## Gyakori minták

### Aritmetika

| type | name | label | calculation |
|------|------|-------|-------------|
| integer | price | Unit price | |
| integer | quantity | Quantity | |
| calculate | total | | `${price} * ${quantity}` |
| note | total_note | Total: `${total}` | |

### Karakterláncok összefűzése

| type | name | label | calculation |
|------|------|-------|-------------|
| text | first_name | First name | |
| text | last_name | Last name | |
| calculate | full_name | | `concat(${first_name}, ' ', ${last_name})` |

### Feltételes érték

| type | name | label | calculation |
|------|------|-------|-------------|
| integer | score | Score (0–100) | |
| calculate | grade | | `if(${score} >= 90, 'A', if(${score} >= 75, 'B', if(${score} >= 60, 'C', 'F')))` |

### Életkor születési dátumból

| type | name | label | calculation |
|------|------|-------|-------------|
| date | dob | Date of birth | |
| calculate | age_years | | `int((today() - ${dob}) div 365.25)` |

## Az `once()` használata az érték rögzítésére

Alapértelmezés szerint a `calculate` újraértékelődik, valahányszor bármely hivatkozott mező megváltozik. Csomagolja a képletet `once()` függvénybe, hogy csak az első betöltéskor értékelődjön ki, és az eredmény rögzüljön:

| type | name | label | calculation |
|------|------|-------|-------------|
| calculate | interview_start | | `once(now())` |

Használja az `once()` függvényt időbélyegekhez, kezdeti értékekhez vagy minden olyan esethez, ahol a változáskor történő újraszámítás nem kívánatos.

## Adatok lekérése külső forrásokból

### CSV fájlból

```
pulldata('staff.csv', 'department', 'name', ${staff_id})
```

A teljes hivatkozást lásd: [pulldata()](../operators-and-functions/pulldata).

### Csomagolt SQLite adatbázisból

```
pulldata('rawquery',
  concat(${family_path}, '/locations.db::provinces'),
  'SELECT name FROM provinces WHERE id = ?',
  ${province_id})
```

Az útvonal felépítésének részleteit lásd: [Helyi adatbázis keresés](../advanced-features/local-database-search).

### Alkalmazás kontextusból

```
pulldata('app-api', 'user.username')
pulldata('app-api', 'family_path')
```

Az összes elérhető kulcsot lásd: [App API](../app-api).

## A calculate használata relevant és constraint mezőkben

Más mezők hivatkozhatnak a `calculate` eredményére, mint bármely más mezőre:

| type | name | label | relevant | constraint |
|------|------|-------|----------|------------|
| calculate | bmi | | | `${weight} div (${height} * ${height}) * 10000` |
| note | bmi_warning | BMI is very high — please verify weight and height. | `${bmi} > 40` | |

## Legjobb gyakorlatok

1. Adjon értelmes neveket a calculate mezőknek — a `total_cost` egyértelműbb, mint a `calc1`, és könnyebb nyomon követni az exportokban.
2. Bontsa a komplex képleteket több láncolt calculate mezőre egyetlen mélyen beágyazott kifejezés helyett.
3. Használja az `once()` függvényt időbélyegekhez és kezdeti pillanatképekhez, hogy megakadályozza az értékek megváltozását az első rögzítés után.
4. Helyezze a `calculate` mezőket az első rájuk hivatkozó kérdés elé — a kiértékelési sorrend követi az űrlap sorrendjét.
5. Tartsa üresen a `label` oszlopot. Egyes eszközök megjelenítik a címkét; üresen hagyva elkerülhető a zavaró kimenet.

## Korlátozások

- A Calculate mezők soha nem jelennek meg közvetlenül a számláló számára — használjon `note` mezőt az eredmény megjelenítéséhez.
- A `calculation` oszlop kötelező; a képlet nélküli `calculate` sor mindig üres karakterláncot tárol.
- Az eredmények minden űrlapváltozáskor újraértékelődnek, hacsak nincsenek `once()` függvénybe csomagolva — a nagyméretű űrlapokon lévő nagyon összetett képletek befolyásolhatják a megjelenítési teljesítményt az alacsony kategóriájú eszközökön.
- A számított értékek karakterláncként tárolódnak a beküldésben. Használja a `number()`, `int()` vagy `boolean()` függvényeket a típusátalakításhoz, amikor az eredményt aritmetikai vagy logikai kifejezéseknek adja át.

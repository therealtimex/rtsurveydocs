title: "Geoshape"
description: "A geoshape kérdések egy GPS-pontok sorozatával meghatározott zárt poligont rögzítenek."
---

A `geoshape` kérdéstípus egy zárt poligont rögzít — GPS-koordináták sorozatát, ahol az első és az utolsó pont megegyezik. Az rtSurvey webes űrlapján ez **szöveges beviteli mezőként** jelenik meg, ahol a kérdező közvetlenül írja be vagy illeszti be a koordinátasort.

## Alapvető XLSForm specifikáció

| type     | name        | label                            |
|----------|-------------|----------------------------------|
| geoshape | field_area  | Rajzolja meg a terület határát   |
| geoshape | zone        | Rögzítse a zóna határát          |

A szabványos specifikációért tekintse meg az [XLSForm dokumentációját](https://xlsform.org/en/#question-types).

---

## Adatformátum

Pontosvesszővel elválasztott pontlistaként tárolódik, a **pontosvesszők körül szóközök nélkül**. Minden pont négy, szóközzel elválasztott értékből áll:

```
lat lon alt acc;lat lon alt acc;lat lon alt acc;lat lon alt acc
```

| Összetevő | Leírás |
|-----------|-------------|
| `lat` | Szélességi fok tizedes fokban |
| `lon` | Hosszúsági fok tizedes fokban |
| `alt` | Magasság méterben (`0`, ha ismeretlen) |
| `acc` | GPS pontosság méterben (`0`, ha ismeretlen) |

**A poligonnak zártnak kell lennie** — az utolsó pontnak meg kell egyeznie az elsővel.

**Példa — egy négypontos poligon (háromszög, zárt):**
```
13.756331 100.501762 0 0;13.758000 100.503000 0 0;13.757000 100.506000 0 0;13.756331 100.501762 0 0
```

Legalább három különböző pont és a záró ismétlés szükséges egy érvényes poligon létrehozásához.

## Megjelenítés az rtSurvey-ben

Az rtSurvey webes űrlapján a `geoshape` egyszerű **szöveges mezőként** jelenik meg. A kérdező begépeli vagy beilleszti a koordinátasort. A jelenlegi webes űrlapon ehhez a típushoz nincs beépített interaktív poligon-választó térkép.

### Poligonpontok interaktív gyűjtése

A terepi adatgyűjtés javasolt mintája egy **`geopoint` kérdésekből álló ismétlődő csoport (repeat group)** — minden csúcspont a teljes GPS-térképválasztót használja —, kombinálva egy `calculate` mezővel a geoshape karakterlánc előállításához:

| type | name | label | calculation |
|------|------|-------|-------------|
| begin repeat | polygon_points | Rögzítse az összes sarkot | |
| geopoint | point | Érintse meg a sarok rögzítéséhez | |
| end repeat | polygon_points | | |
| calculate | geoshape_value | | `join(';', ${polygon_points/point})` |

Az egyesítés után manuálisan adja hozzá az első pontot a poligon bezárásához, vagy használjon egy második számítást (`calculate`) a konkatenáláshoz.

## Példa a használatra

| type | name | label | hint | required |
|------|------|-------|------|----------|
| geoshape | farm_boundary | Rögzítse a tábla határát | Adja meg az összes sarkot pontosvesszővel elválasztva. Az első és az utolsó pontnak meg kell egyeznie. | yes |

---

## Legjobb gyakorlatok

1. Interaktív, térkép alapú gyűjtéshez használjon egy `geopoint` kérdésekből álló ismétlődő csoportot, majd egyesítse az értékeket — ez GPS-választót biztosít a kérdezőknek minden egyes csúcsponthoz.
2. Beküldés előtt mindig zárja le a poligont (ismételje meg az első pontot a végén).
3. Tüntesse fel az elvárt formátumot a `hint` oszlopban, ha manuális koordináta-bevitelre van szükség.
4. Érvényes poligonhoz legalább 3 különböző sarokpontot követeljen meg — ezt inkább utasításokkal kényszerítse ki, mintsem XLSForm korlátozásokkal.
5. Használja a `geopoint` típust egyetlen helyszín rögzítéséhez, és csak akkor alkalmazza a `geoshape` típust, ha a terület lehatárolása a felmérés tényleges célja.

## Korlátozások

- Az rtSurvey webes űrlapján nincs beépített interaktív poligon-választó térkép a `geoshape` típushoz.
- A poligont manuálisan kell bezárni — a szövegbeviteli módban nincs automatikus záró mechanizmus.
- A poligon-topológia validálása (pl. önmetszés mentesség, minimális terület) az XLSForm korlátozásokon kívüli utófeldolgozást igényel.
- A sok csúcsponttal rendelkező hosszú határok nagy szöveges karakterláncokat eredményeznek.

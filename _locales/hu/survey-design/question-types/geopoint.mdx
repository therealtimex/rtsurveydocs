---
title: "Geopont"
description: "A geopont kérdések földrajzi koordinátákat (szélesség, hosszúság, magasság és pontosság) rögzítenek a felmérés részeként."
---

A `geopoint` kérdéstípus földrajzi koordinátákat (szélesség, hosszúság, magasság, pontosság) rögzít az eszköz GPS-ének segítségével. Az rtSurvey többféle elrendezési móddal jeleníti meg a választót, és támogatja az automatizálást az `inputs{}` és `outputs{}` paraméterekkel.

## Alapvető XLSForm specifikáció

| type     | name        | label                       |
|----------|-------------|-----------------------------|
| geopoint | location    | Rögzítse az aktuális helyet |

A szabványos specifikációt lásd az [XLSForm dokumentációban](https://xlsform.org/en/#question-types).

## Adatformátum

Négy szóközzel elválasztott értékként tárolódik:

```
szélesség hosszúság magasság pontosság
```

Példa: `13.756331 100.501762 15 8`

---

## Elrendezési módok

### Alapértelmezett — téglalap alakú gomb

Egy téglalap alakú "GEOPOONT INDÍTÁSA" gomb nyit meg egy teljes térkép modált, ahol az összeíró kiválaszt egy pontot. Rögzítés után a gomb felirata "Geopont megtekintése vagy módosítása"-ra változik, és a koordináták alatta jelennek meg.

Nincs szükség megjelenítési értékre.

---

### `display{inline-icon}` — kör alakú célkereszt gomb

Kör alakú ikon gombot (célkereszt ⊕) jelenít meg a téglalap alakú gomb helyett. Ennek megérintésével ugyanaz a térkép modál nyílik meg.

```
display{inline-icon}
```

**Pozícióval és mérettel kombinálva:**

```
display{inline-icon, left}           → gomb a címkétől balra
display{inline-icon, top}            → gomb a címke felett
display{inline-icon, bottom}         → gomb a címke alatt, középre igazítva
display{inline-icon, large}          → nagy ikon (75px)
display{inline-icon, medium}         → közepes ikon (50px)
display{inline-icon, left, large}    → nagy gomb bal oldalon
```

| Méret | Ikon magasság/szélesség |
|------|-----------------------|
| *(alapértelmezett)* | 25px |
| `medium` | 50px |
| `large` | 75px |

---

### `display{thumbnail-square}` — élő térkép miniatűr

Élő térkép előnézetet (Leaflet) jelenít meg közvetlenül a kérdésen egy gomb helyett. A miniatűr az aktuális GPS pozíciót és a kiválasztott pontot mutatja. Az expand gomb megérintésével megnyílik a teljes modál.

```
display{thumbnail-square}
```

**Egyéni miniatűr méret:**

```
display{thumbnail-square-[SxM]}          → rögzített képpontokban
display{thumbnail-square-[400x200]}      → 400px széles × 200px magas

display{thumbnail-square-[Sz%xM%]}        → az űrlap szélességének százaléka
display{thumbnail-square-[100%x30%]}     → teljes szélesség × az űrlap szélességének 30%-a
```

---

## `display{}` vs `results{}` — rögzítés előtt és után

A `display{}` a elrendezést vezérli a hely rögzítése **előtt**. A `results{}` a elrendezést vezérli, **miután** egy érték létezik. Különböző igazításokat is tartalmazhatnak.

```
display{inline-icon, right} results{left}
```

Ez a gombot jobbra jeleníti meg rögzítés előtt, majd balra mozgatja, miután egy pont rögzítésre került.

### `hide(value)` — koordináták megjelenítésének elrejtése

Alapértelmezés szerint a rögzített szélesség/hosszúság/pontosság/magasság szöveg a gomb alatt jelenik meg. Elrejtheti a következővel:

```
results{hide(value)}
display{inline-icon} results{hide(value)}
```

---

## `inputs{}` — GPS automatizálás

### Automatikus rögzítés betöltéskor

Automatikusan rögzíti a GPS pozíciót az űrlap betöltésekor, anélkül, hogy az összeírónak bármit meg kellene nyomnia.

```
inputs{auto-take}
```

**Feltételes automatikus rögzítés** XLSForm kifejezéssel:

```
inputs{autotakeGeo(expression(if(${capture_now} = 'yes', true(), false())))}
```

### Előzetes kitöltés szövegmezőből

Töltse fel a geopontot egy kérdésből, amely helynevet vagy cím karakterláncot tartalmaz. Az rtSurvey visszafelé geokódolja a karakterláncot koordinátákká az OpenStreetMap Nominatim segítségével.

```
inputs{question(address_field)}
```

---

## `outputs{}` — visszafelé geokódolás szöveggé

Miután egy pontot rögzítettek, automatikusan töltse fel egy `text` kérdést az emberileg olvasható címmel (a koordinátákból visszafelé geokódolva).

```
outputs{question(address_field)}
```

Példa:

| type | name | label | appearance |
|------|------|-------|------------|
| geopoint | location | Hely rögzítése | `outputs{question(address_text)}` |
| text | address_text | Cím | |

---

## `nomap` — GPS rögzítés térkép nélkül

A térkép modált egy egyszerű párbeszédpanellel helyettesíti, amely helymeghatározási engedélyt kér, és rögzíti a koordinátákat. Nincs térkép megjelenítve. Hasznos csak GPS rögzítéshez alacsony kategóriás eszközökön vagy ha a térkép csempék offline nem elérhetők.

```
nomap
```

|------|------|-------|------------|

## Bevált gyakorlatok

1. Használja az `inputs{auto-take}`-t az összeírói ellenőrzési felmérésekhez, ahol a GPS kötelező – ez eltávolítja a kézi lépést.
2. Használja a `display{thumbnail-square}`-t, amikor azt szeretné, hogy az összeíró vizuálisan erősítse meg a kiválasztott pontot a folytatás előtt.
3. Párosítsa az `outputs{question(...)}`-t egy írásvédett `text` mezővel, hogy megjelenítse a visszafelé geokódolt címet az összeírónak.
4. Használja a `nomap`-t olyan területeken, ahol nincs internetkapcsolat, és a térkép csempék nem tölthetők be.
5. Hagyjon elegendő időt a GPS stabilizálódására a rögzítés előtt – a 10m alatti pontosság általában elegendő a helyszíni felmérésekhez.

## Korlátozások

- Az `inputs{question(name)}` geokódoláshoz internetkapcsolat szükséges – az OpenStreetMap Nominatim API-t hívja meg.
- Az `outputs{question(name)}` visszafelé geokódoláshoz szintén internetkapcsolat szükséges.
- A térkép miniatűr (`display{thumbnail-square}`) internetet igényel a csempék betöltéséhez; a koordináták továbbra is rögzítésre kerülnek offline.
- A GPS pontosság eszköztől és környezettől függően változik – beltéri vagy városi kanyon körülmények között 50m feletti pontosság is előfordulhat.
- A helyadatok gyűjtése jelentősen befolyásolhatja az eszköz akkumulátor élettartamát hosszú felmérések során.

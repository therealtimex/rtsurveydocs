---

A `file` kérdéstípus lehetővé teszi a válaszadók számára, hogy **bármilyen fájlt feltöltsenek** az eszközükről – dokumentumokat, táblázatokat, PDF-eket vagy más fájltípusokat. Az `image`, `audio` és `video` típusokkal ellentétben, amelyek specifikus rögzítő eszközöket indítanak, a `file` egy általános fájlválasztót nyit meg.

## Alapvető XLSForm specifikáció

| type | name      | label                        |
|------|-----------|------------------------------|
| file | document  | Kérjük, töltse fel dokumentumát |

A szabványos fájl kérdéstípus részleteiről lásd az [XLSForm specifikációt](https://xlsform.org/en/#question-types).

## Használat

A fájl kérdéseket általában a következőkre használják:

1. Kiegészítő dokumentumok gyűjtése (nyugták, tanúsítványok, szerződések, jelentések)
2. Beolvasott, kitöltött papír alapú űrlapok feltöltése
3. Táblázatok vagy adatexportok gyűjtése más rendszerekből
4. Bármely digitális fájltípus, amelyet kép/hang/videó nem fed le

## Adatformátum

A feltöltött fájlok bináris mellékletekként kerülnek tárolásra:

- **Formátum:** Eredeti formátumban megőrizve (PDF, XLSX, DOCX, stb.)
- **Elnevezés:** `{instanceID}-{fieldname}.{extension}`
- **Tárolás:** Feltöltve a szerver média mappájába a beküldés mellett
- **Hozzáférés:** Letölthető a beküldéskezelő felületen keresztül

## rtSurvey kiterjesztések

### Elfogadott fájltípusok

Használja a `parameters` oszlopot a választható fájltípusok korlátozására:

| type | name | label | parameters |
|------|------|-------|------------|
| file | report | Töltse fel az ellenőrzési jelentést | `accept=.pdf` |
| file | spreadsheet | Töltse fel az adatfájlt | `accept=.xlsx,.csv` |

Az `accept` paraméter szabványos fájlkiterjesztés szintaxist használ (vesszővel elválasztva).

### Fájlméret útmutató

Az rtSurvey nem kényszerít ki szigorú fájlméret-korlátot a kérdés szintjén, de a szerver feltöltési korlátja érvényesül. Használja a `hint`-et az elvárások közlésére az összeíróval:

| type | name | label | hint |
|------|------|-------|------|
| file | receipt | Töltse fel a fizetési bizonylatot | Elfogadott: PDF vagy kép. Maximális fájlméret: 5 MB |

### Integráció az eszköz fájlrendszerével és felhőtárhellyel

Androidon és iOS-en a `file` kérdés megnyitja az eszköz natív fájlválasztóját, amely hozzáférést biztosíthat a következőkhöz:
- Helyi eszköz tárhely
- SD kártya (Android)
- iCloud Drive (iOS)
- Google Drive, Dropbox (ha telepítve van)

Weben a böngésző szabványos fájlfeltöltési párbeszédpaneljét nyitja meg.

### Beágyazott gombelrendezés

Adjon hozzá `inline` értéket, hogy a feltöltést **kör alakú ikon gombként** jelenítse meg a címke mellett a teljes szélességű fájlválasztó helyett.

```
| type | name | label           | appearance                              |
|------|------|-----------------|-----------------------------------------|
| file | doc  | Dokumentum feltöltése | inline display{right}                   |
| file | doc  | Dokumentum feltöltése | inline display{left, large}             |
| file | doc  | Dokumentum feltöltése | inline display{center, large, <0099FF/>} |
```

**Gomb pozíciója** — `left`, `right` *(alapértelmezett)*, `top`, `center`, `bottom`

**Gomb mérete** — `small` *(alapértelmezett)*, `medium`, `large`

**Gomb színe** — adjon hozzá egy hexadecimális színt a `display{}` belsejébe az elsődleges szín felülírásához:

```
inline display{right, large, <FF5500/>}
```

**Felvétel utáni vezérlés — `results{}`:**

| Appearance | Effect |
|---|---|
| `results{hide(capture)}` | Elrejti a feltöltés gombot, miután egy fájl csatolva lett |
| `results{hide(review)}` | Elrejti az áttekintés/előnézet gombot feltöltés után |
| `results{hide(filename)}` | Elrejti a fájlnevet feltöltés után |
| `results{left}` | Az ikont balra mozgatja feltöltés után |

Példa – a feltöltés gomb elrejtése a fájl csatolása után:
```
inline display{right} results{hide(capture)}
```

### A címke elrejtése

```
inline text-nolabel display{center, large}
```

## Bevált gyakorlatok

1. Használja az `accept`-t a fájltípusok korlátozására – ez megakadályozza, hogy az összeírók véletlenül rossz fájlokat töltsenek fel.
2. Mindig tüntessen fel méret- és formátumra vonatkozó útmutatót a `hint` oszlopban.
3. Fényképek és képek esetén használja az `image` típust – jobb tömörítést és konzisztens formátumkezelést kínál.
4. Nagy felmérések esetén, fájlmellékletekkel, tervezze meg megfelelően az adattárolást és a letöltési sávszélességet.
5. Tesztelje a fájlválasztót a cél eszköz típusán (Android vs. iOS vs. web) a telepítés előtt – a felhőalapú meghajtókhoz való hozzáférés változó.

## Adatkezelési megfontolások

- A fájlok eredeti formátumban kerülnek tárolásra; az rtSurvey nem konvertálja vagy tömöríti őket.
- A fájlokat letöltés után elemezze – az rtSurvey nem von ki vagy indexel fájltartalmakat.
- A nagyméretű fájlmellékletek jelentősen megnövelik a teljes adatkészlet letöltéséhez szükséges időt.

## Korlátozások

- A fájl kérdések nem érvényesítik a fájltartalmakat – csak a fájlkiterjesztés ellenőrzése az `accept` segítségével érvényesül a felhasználói felület szintjén.
- Nagyon nagy fájlok (100 MB+) feltöltésénél időtúllépés léphet fel gyenge hálózati kapcsolattal rendelkező környezetekben.
- Az offline összeírók csatolhatnak fájlokat, de azok csak a kapcsolat helyreállítása után töltődnek fel.
- Egyes eszközkonfigurációk korlátozzák bizonyos tárolási helyekhez való hozzáférést (pl. vállalati MDM irányelvek).

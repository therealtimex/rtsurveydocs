A `file` kérdéstípus lehetővé teszi a válaszadók számára, hogy **bármilyen fájlt feltöltsenek** eszközükről — dokumentumokat, táblázatokat, PDF-eket vagy egyéb fájltípusokat. Az `image`, `audio` és `video` típusokkal ellentétben, amelyek specifikus rögzítőeszközöket indítanak el, a `file` egy általános célú fájlválasztót nyit meg.

## Alapvető XLSForm specifikáció

| type | name      | label                        |
|------|-----------|------------------------------|
| file | document  | Kérjük, töltse fel a dokumentumát |

A szabványos fájl kérdéstípussal kapcsolatos további részletekért tekintse meg az [XLSForm specifikációját](https://xlsform.org/en/#question-types).

## Felhasználási területek

A fájl típusú kérdéseket gyakran használják a következőkre:

1. Alátámasztó dokumentumok gyűjtése (nyugták, igazolások, szerződések, jelentések)
2. Kitöltött, beszkennelt papíralapú űrlapok feltöltése
3. Táblázatok vagy más rendszerekből származó adatexportok gyűjtése
4. Bármilyen digitális fájltípus, amelyet a kép/hang/videó típus nem fed le

## Adatformátum

A feltöltött fájlok bináris mellékletként kerülnek tárolásra:

- **Formátum:** Eredeti formátumban megőrizve (PDF, XLSX, DOCX stb.)
- **Névadás:** `{instanceID}-{fieldname}.{extension}`
- **Tárolás:** A beküldéssel együtt a szerver média mappájába kerül feltöltésre
- **Hozzáférés:** Letölthető a beküldéskezelő felületről

## rtSurvey kiterjesztések

### Elfogadott fájltípusok

Használja a `parameters` oszlopot a választható fájltípusok korlátozására:

| type | name | label | parameters |
|------|------|-------|------------|
| file | report | Töltse fel a vizsgálati jelentést | `accept=.pdf` |
| file | spreadsheet | Töltse fel az adatfájlt | `accept=.xlsx,.csv` |

Az `accept` paraméter a szabványos fájlkiterjesztés-szintaxist használja (vesszővel elválasztva).

### Fájlméretre vonatkozó útmutatás

Az rtSurvey nem kényszerít ki szigorú fájlméret-korlátot kérdés szinten, de a szerver feltöltési korlátja érvényes. Használja a `hint` oszlopot az elvárások közlésére a kérdezővel:

| type | name | label | hint |
|------|------|-------|------|
| file | receipt | Töltse fel a fizetési bizonylatot | Elfogadott: PDF vagy kép. Maximális fájlméret: 5 MB |

### Integráció az eszköz fájlrendszerével és a felhőalapú tárolással

Androidon és iOS-en a `file` kérdés az eszköz natív fájlválasztóját nyitja meg, amely hozzáférést biztosíthat a következőkhöz:
- Helyi eszköztárhely
- SD kártya (Android)
- iCloud Drive (iOS)
- Google Drive, Dropbox (ha telepítve van)

Weben a böngésző szabványos fájlfeltöltési párbeszédpanelét nyitja meg.

### Beágyazott gomb elrendezés (Inline)

Adja hozzá az `inline` értéket a feltöltés **kör alakú ikongombként** való megjelenítéséhez a címke mellett, a teljes szélességű fájlválasztó helyett.

```
| type | name | label           | appearance                              |
|------|------|-----------------|-----------------------------------------|
| file | doc  | Dokumentum feltöltése | inline display{right}                   |
| file | doc  | Dokumentum feltöltése | inline display{left, large}             |
| file | doc  | Dokumentum feltöltése | inline display{center, large, <0099FF/>} |
```

**Gomb pozíciója** — `left`, `right` *(alapértelmezett)*, `top`, `center`, `bottom`

**Gomb mérete** — `small` *(alapértelmezett)*, `medium`, `large`

**Gomb színe** — adjon meg egy hex színt a `display{}`-ben az elsődleges szín felülbírálásához:

```
inline display{right, large, <FF5500/>}
```

**Rögzítés utáni vezérlés — `results{}`:**

| Appearance | Effect |
|---|---|
| `results{hide(capture)}` | Elrejti a feltöltés gombot a fájl csatolása után |
| `results{hide(review)}` | Elrejti az ellenőrzés/előnézet gombot feltöltés után |
| `results{hide(filename)}` | Elrejti a feltöltés után megjelenő fájlnevet |
| `results{left}` | Az ikont balra mozgatja feltöltés után |

Példa — feltöltés gomb elrejtése a fájl csatolása után:
```
inline display{right} results{hide(capture)}
```

### Címke elrejtése

```
inline text-nolabel display{center, large}
```

## Legjobb gyakorlatok

1. Használja az `accept` paramétert a fájltípusok korlátozására — ez megakadályozza, hogy a kérdezők véletlenül rossz fájlokat töltsenek fel.
2. Mindig tüntesse fel a méretre és formátumra vonatkozó útmutatást a `hint` oszlopban.
3. Fotók és képek esetén használja inkább az `image` típust — az jobb tömörítést és konzisztens formátumkezelést kínál.
4. Fájlmellékleteket tartalmazó nagy felmérések esetén tervezze meg megfelelően az adattárolást és a letöltési sávszélességet.
5. Telepítés előtt tesztelje a fájlválasztót a cél eszköztípuson (Android vs. iOS vs. web) — a felhőalapú meghajtókhoz való hozzáférés eltérő lehet.

## Adatkezelési megfontolások

- A fájlok eredeti formátumukban kerülnek tárolásra; az rtSurvey nem konvertálja vagy tömöríti azokat.
- A fájlokat letöltés után elemezze — az rtSurvey nem emeli ki és nem indexeli a fájlok tartalmát.
- A nagy fájlmellékletek jelentősen megnövelik a teljes adatkészlet letöltéséhez szükséges időt.

## Korlátozások

- A fájl kérdések nem ellenőrzik a fájlok tartalmát — a felhasználói felületen csak az `accept` paraméterrel megadott fájlkiterjesztés-ellenőrzés érvényesül.
- A nagyon nagy fájlok (100 MB+) feltöltése időtúllépéshez vezethet gyenge internetkapcsolat esetén.
- Az offline kérdezők csatolhatnak fájlokat, de azok nem töltődnek fel, amíg a kapcsolat helyre nem áll.
- Egyes eszközkonfigurációk korlátozhatják a hozzáférést bizonyos tárolási helyekhez (pl. vállalati MDM-irányelvek).

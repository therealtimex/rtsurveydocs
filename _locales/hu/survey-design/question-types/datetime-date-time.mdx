---

A `date` (dátum), `time` (idő) és `datetime` (dátum és idő) kérdéstípusok dátum- és/vagy időértékeket rögzítenek. Az rtSurvey ezeket többféle elrendezési módban jeleníti meg, amelyeket az `appearance` (megjelenés) oszlop vezérel.

## Alapvető XLSForm specifikáció

| type     | name           | label                         |
|----------|----------------|-------------------------------|
| date     | birth_date     | Születési idő                 |
| time     | start_time     | Mikor kezdődött?              |
| datetime | event_datetime | Mikor történt az esemény?     |

A szabványos specifikációt az [XLSForm dokumentációjában](https://xlsform.org/en/#question-types) találja.

## Elrendezési módok

### Alapértelmezett — mindig nyitott naptár

Nincs szükség megjelenési értékre. A naptár (és a `time`/`datetime` esetén az óra) közvetlenül az oldalon jelenik meg – mindig látható, nincs szükség gombra.

| type | name       | label         | appearance |
|------|------------|---------------|------------|
| date | start_date | Látogatás dátuma |            |

---

### `inline` — kör alakú gomb → modális ablak

Egy kör alakú ikongomb (naptár vagy óra) jelenik meg a kérdés felirata mellett. Megérintésével egy modális ablak nyílik meg a választóval. A kiválasztás után a választott érték szövegként jelenik meg a felirat mellett.

- Gomb háttere: az elsődleges témaszín (felülírható)
- Gomb alakja: teljes kör (`border-radius: 50%`)

```
| type | name       | label         | appearance |
|------|------------|---------------|------------|
| date | start_date | Látogatás dátuma | inline     |
```

---

### `inline-onlyresult` — a gomb eltűnik a kiválasztás után

Ugyanaz, mint az `inline`, de a gomb elrejtőzik, amint kiválasztottak egy értéket. Akkor hasznos, ha azt szeretné, hogy a dátum csak a kiválasztás után legyen látható, állandó ikon nélkül.

```
inline-onlyresult
```

---

### `inline-1line` — görgetős választók sora (spinners)

Egyetlen vízszintes sorban jeleníti meg az egyes görgetős vezérlőket (▲ érték ▼) – összetevőnként egy oszlopot. `date` esetén: hónap / nap / év. `datetime` esetén: hónap / nap / év / óra / perc. `time` esetén: óra / perc.

Nincs modális ablak vagy felugró naptár – a felhasználó minden választót függetlenül görget.

```
inline-1line
```

**Csak bizonyos összetevők megjelenítése** az összetevők nevének hozzáadásával:

```
inline-1line month year      → elrejti a nap választót
inline-1line year            → csak az évet mutatja
```

**Évtartomány korlátozása:**

```
inline-1line y_range(2000-2030)
```

---

### `box` — szöveges bevitel

Egy egyszerű szöveges beviteli mezőt jelenít meg. A felhasználó közvetlenül írja be a dátumot a megjelenésben meghatározott formátum használatával.

```
box(%d/%m/%Y)       → NN/HH/ÉÉÉÉ
box(%Y-%m-%d)       → ÉÉÉÉ-HH-NN
```

---

### `month-year` — csak hónap és év

Szabványos XLSForm megjelenés. A választó az év nézettel indul; a felhasználó hónapot és évet választ, de konkrét napot nem.

```
month-year
```

---

### `year` — csak év

Szabványos XLSForm megjelenés. A választó az évtized nézettel indul; csak az év választható ki.

```
year
```

---

## Egyedi megjelenítési formátum

Bármely `inline` megjelenéshez fűzze hozzá a `-[format]` jelölést a kiválasztott érték szöveges megjelenítésének vezérléséhez. Strftime-stílusú tokeneket használ.

| Token | Jelentés | Példa |
|-------|---------|---------|
| `%d`  | Nap (vezető nullával) | 07 |
| `%e`  | Nap (kitöltés nélkül) | 7 |
| `%m`  | Hónap száma | 04 |
| `%n`  | Hónap száma (kitöltés nélkül) | 4 |
| `%b`  | Hónap rövidítése | ápr |
| `%Y`  | 4 jegyű év | 2026 |
| `%y`  | 2 jegyű év | 26 |
| `%H`  | Óra (24 órás) | 14 |
| `%h`  | Óra (kitöltés nélkül) | 14 |
| `%M`  | Perc | 05 |
| `%S`  | Másodperc | 00 |
| `%a`  | Nap nevének rövidítése | sze |

**Példák:**

```
inline-[%d/%m/%Y]            → 07/04/2026
inline-[%d %b %Y]            → 07 ápr 2026
inline-1line-[%Y-%m-%d]      → görgetős bevitel, formázott megjelenítés
inline-[%d/%m/%Y %H:%M]      → 07/04/2026 14:30
```

## Szín testreszabása

Az ikongomb színének felülírása a `colors()` használatával:

```
inline colors("0099FF")                   → gomb háttere #0099FF
inline colors("0099FF","FFFFFF")          → háttér #0099FF, ikon színe #FFFFFF
inline-1line colors("0000FF","FFFF00")    → görgető kiemelő színei
inline-onlyresult colors("E53935")        → piros gomb
```

---

## Gomb pozíciója a `display{}` használatával

A `display{}` módosító szabályozza, hogy az ikongomb hol jelenjen meg a kérdés feliratához képest. Az `inline` és az `inline-onlyresult` típusokra vonatkozik.

```
display{<align>, <size>, <color>}
```

| Paraméter | Értékek | Alapértelmezett |
|-----------|--------|---------|
| Align (igazítás) | `left`, `right`, `top`, `center`, `bottom` | `right` |
| Size (méret) | `small`, `medium`, `large` | `small` |
| Color (szín) | hex pl. `#FF5500` | az elsődleges témaszín |

**Igazítási viselkedés:**

| Érték | Elrendezés |
|-------|--------|
| `right` | Gomb a felirattól jobbra |
| `left` | Gomb a felirattól balra |
| `top` | Gomb a felirat felett, teljes szélességben középre zárva |
| `center` / `bottom` | Gomb a felirat alatt, teljes szélességben középre zárva |

**Példák:**

```
inline display{left}
inline display{center, large}
inline display{right, medium, #E53935}
inline-onlyresult display{bottom, large, #0099FF}
```

## Dátumtartomány korlátozása

Az `inputs{range[...]}` használatával korlátozhatja a kiválasztható dátumokat.

```
inputs{range[dateGt(2024-01-01), dateLt(2024-12-31)]}
```

Paraméterek a `range[...]` belsejében:

| Paraméter | Leírás |
|-----------|-------------|
| `dateGt(YYYY-MM-DD)` | Legkisebb kiválasztható dátum (nagyobb vagy egyenlő) |
| `dateLt(YYYY-MM-DD)` | Legnagyobb kiválasztható dátum (kisebb vagy egyenlő) |
| `indayTimeGt(HH:MM:SS)` | Minimális idő egy napon belül (csak datetime esetén) |
| `indayTimeLt(HH:MM:SS)` | Maximális idő egy napon belül (csak datetime esetén) |

Több tartomány is meghatározható – egy dátum akkor választható ki, ha **bármelyik** tartományba beleesik.

## Felirat elrejtése

Adja hozzá a `text-nolabel` értéket a kérdés feliratának elrejtéséhez. A gomb önmagában jelenik meg.

```
inline text-nolabel display{center, large}
```

## Legjobb gyakorlatok

1. Használja az `inline` megjelenést a kompakt űrlapokhoz – függőleges helyet takarít meg a mindig nyitott naptárhoz képest.
2. Használja az `inline-1line` megjelenést, ha a válaszadóknak az egyes dátumösszetevőket (pl. születési évet) kell módosítaniuk.
3. A `box()` megjelenést csak akkor használja, ha bízik abban, hogy a kérdező megfelelően gépeli be a dátumokat – nem jelenik meg ellenőrző felület.
4. Használja a `display{center, large}` beállítást, hogy a gomb hangsúlyosabb legyen a mobilképernyőkön.
5. Mindig adja meg a `-[format]` jelölést, ha az alapértelmezett `YYYY-MM-DD` megjelenítés megzavarná a helyi felhasználókat.
6. Legyen körültekintő az időzónákkal kapcsolatban, amikor különböző régiókban gyűjt dátum-idő adatokat.

## Korlátozások

- Az `inline-1line` mindig a mai dátumot veszi alapul, ha nincs érték – használja a `default` oszlopot egy adott dátum előre kitöltéséhez.
- A `box()` formátum csak a megjelenítést szabályozza; a tárolt érték mindig ISO 8601.
- A dátumtartomány korlátozása (`inputs{range[...]}`) nem működik a `box` elrendezéssel.
- Az időzóna-különbségek bonyolíthatják az adatelemzést, ha nem veszik figyelembe őket megfelelően.

---

A `date`, `time`, és `datetime` kérdéstípusok dátum és/vagy idő értékeket rögzítenek. Az rtSurvey többféle elrendezési móddal jeleníti meg őket, amelyet az `appearance` oszlop vezérel.

## Alapvető XLSForm specifikáció

| type     | name           | label                     |
|----------|----------------|---------------------------|
| date     | birth_date     | Születési dátum           |
| time     | start_time     | Mikor kezdődött?          |
| datetime | event_datetime | Mikor történt az esemény? |

A szabványos specifikációt lásd az [XLSForm dokumentációban](https://xlsform.org/en/#question-types).

## Elrendezési módok

### Alapértelmezett — mindig nyitott naptár

Nincs szükség appearance értékre. A naptár (és az óra a `time`/`datetime` esetén) közvetlenül az oldalon jelenik meg – mindig látható, nincs szükség gombra.

| type | name       | label         | appearance |
|------|------------|---------------|------------|
| date | start_date | Látogatás dátuma |            |

---

### `inline` — kör alakú gomb → modál

Egy kör alakú ikon gomb (naptár vagy óra) lebeg a kérdés címkéje mellett. Megérintésével megnyílik egy modál a választóval. Kiválasztás után a kiválasztott érték szövegként jelenik meg a címke mellett.

- Gomb háttér: elsődleges téma szín (felülírható)
- Gomb alakja: teljes kör (`border-radius: 50%`)

```
| type | name       | label         | appearance |
|------|------------|---------------|------------|
| date | start_date | Látogatás dátuma | inline     |
```

---

### `inline-onlyresult` — a gomb eltűnik kiválasztás után

Ugyanaz, mint az `inline`, de a gomb elrejti magát, miután egy értéket kiválasztottak. Hasznos, ha csak a dátumot szeretné látni, miután kiválasztották, anélkül, hogy egy állandó ikon is megjelenne.

```
inline-onlyresult
```

---

### `inline-1line` — pörgetők sora

Egyedi pörgető vezérlőket (▲ érték ▼) jelenít meg egyetlen vízszintes sorban – egy oszlop komponenstenként. `date` esetén: hónap / nap / év. `datetime` esetén: hónap / nap / év / óra / perc. `time` esetén: óra / perc.

Nincs modál vagy naptár felugró ablak – a felhasználó minden pörgetőt külön görget.

```
inline-1line
```

**Csak bizonyos komponensek megjelenítése** a komponens nevek hozzáadásával:

```
inline-1line month year      → elrejti a nap pörgetőt
inline-1line year            → csak az évet mutatja
```

**Korlátozza az évtartományt:**

```
inline-1line y_range(2000-2030)
```

---

### `box` — szövegbeviteli mező

Egyszerű szövegbeviteli mezőt jelenít meg. A felhasználó közvetlenül beírja a dátumot az `appearance`-ben meghatározott formátumot használva.

```
box(%d/%m/%Y)       → DD/MM/YYYY
box(%Y-%m-%d)       → YYYY-MM-DD
```

---

### `month-year` — csak hónap és év

Standard XLSForm megjelenés. A választó év nézetben indul; a felhasználó hónapot és évet választ, de nem konkrét napot.

```
month-year
```

---

### `year` — csak év

Standard XLSForm megjelenés. A választó évtized nézetben indul; csak az év választható.

```
year
```

---

## Egyéni megjelenítési formátum

Fűzzön `-[formátum]`-ot bármelyik `inline` megjelenéshez, hogy szabályozza, hogyan jelenik meg a kiválasztott érték szövegként. Használja az strftime-szerű tokeneket.

| Token | Jelentés | Példa |
|-------|---------|---------|
| `%d`  | Nap (nullával kitöltve) | 07 |
| `%e`  | Nap (nincs kitöltés) | 7 |
| `%m`  | Hónap száma | 04 |
| `%n`  | Hónap száma (nincs kitöltés) | 4 |
| `%b`  | Hónap rövidítése | Ápr |
| `%Y`  | 4 jegyű év | 2026 |
| `%y`  | 2 jegyű év | 26 |
| `%H`  | Óra (24h) | 14 |
| `%h`  | Óra (nincs kitöltés) | 14 |
| `%M`  | Perc | 05 |
| `%S`  | Másodperc | 00 |
| `%a`  | Nap neve rövidítése | Sze |

**Példák:**

```
inline-[%d/%m/%Y]            → 07/04/2026
inline-[%d %b %Y]            → 07 Ápr 2026
inline-1line-[%Y-%m-%d]      → pörgető bevitel, formázott megjelenítés
inline-[%d/%m/%Y %H:%M]      → 07/04/2026 14:30
```

## Szín testreszabása

Írja felül az ikon gomb színét a `colors()` segítségével:

```
inline colors("0099FF")                   → gomb háttér #0099FF
inline colors("0099FF","FFFFFF")          → háttér #0099FF, ikon szín #FFFFFF
inline-1line colors("0000FF","FFFF00")    → pörgető kiemelő színek
inline-onlyresult colors("E53935")        → piros gomb
```

---

## Gomb pozíciója a `display{}` segítségével

A `display{}` módosító vezérli, hogy az ikon gomb hol jelenik meg a kérdés címkéjéhez képest. Az `inline` és `inline-onlyresult` esetén alkalmazható.

```
display{<igazítás>, <méret>, <szín>}
```

| Paraméter | Értékek | Alapértelmezett |
|-----------|--------|---------|
| Igazítás | `left`, `right`, `top`, `center`, `bottom` | `right` |
| Méret | `small`, `medium`, `large` | `small` |
| Szín | hex pl. `#FF5500` | elsődleges téma szín |

**Igazítási viselkedés:**

| Érték | Elrendezés |
|-------|--------|
| `right` | Gomb a címke jobb oldalán |
| `left` | Gomb a címke bal oldalán |
| `top` | Gomb a címke felett, teljes szélességben középre igazítva |
| `center` / `bottom` | Gomb a címke alatt, teljes szélességben középre igazítva |

**Példák:**

```
inline display{left}
inline display{center, large}
inline display{right, medium, #E53935}
inline-onlyresult display{bottom, large, #0099FF}
```

## Dátumtartomány korlátozás

Használja az `inputs{range[...]}`-t a választható dátumok korlátozására.

```
inputs{range[dateGt(2024-01-01), dateLt(2024-12-31)]}
```

Paraméterek a `range[...]` belsejében:

| Paraméter | Leírás |
|-----------|-------------|
| `dateGt(YYYY-MM-DD)` | Minimum választható dátum (nagyobb vagy egyenlő) |
| `dateLt(YYYY-MM-DD)` | Maximum választható dátum (kisebb vagy egyenlő) |
| `indayTimeGt(HH:MM:SS)` | Minimum idő a napon belül (csak datetime) |
| `indayTimeLt(HH:MM:SS)` | Maximum idő a napon belül (csak datetime) |

Több tartomány is definiálható – egy dátum akkor választható, ha bármelyik tartományba beleesik.

## A címke elrejtése

Adja hozzá a `text-nolabel`-t a kérdés címkéjének elrejtéséhez. A gomb önmagában jelenik meg.

```
inline text-nolabel display{center, large}
```

## Bevált gyakorlatok

1. Használja az `inline`-t kompakt űrlapokhoz – függőlegesen kevesebb helyet foglal, mint a mindig nyitott naptár.
2. Használja az `inline-1line`-t, ha a válaszadóknak egyedi dátumkomponenseket kell beállítaniuk (pl. születési év).
3. Csak akkor használja a `box()`-t, ha megbízik az összeíróban, hogy helyesen írja be a dátumokat – nincs megjelenített érvényesítési felület.
4. Használja a `display{center, large}`-t, hogy a gomb kiemelkedőbb legyen a mobil képernyőkön.
5. Mindig adja meg a `-[formátum]`-ot, ha az alapértelmezett `YYYY-MM-DD` megjelenítés zavaró lenne a helyi felhasználók számára.
6. Legyen figyelemmel az időzónákra, amikor különböző régiókban gyűjt adatokat.

## Korlátozások

- Az `inline-1line` mindig az aktuális dátumra áll be, ha nincs érték – használja a `default` oszlopot egy specifikus dátum előzetes kitöltésére.
- A `box()` formátum csak a megjelenítést vezérli; a tárolt érték mindig ISO 8601.
- A dátumtartomány korlátozás (`inputs{range[...]}`) nem működik a `box` elrendezéssel.
- Az időzóna-különbségek bonyolíthatják az adatelemzést, ha nem kezelik megfelelően.

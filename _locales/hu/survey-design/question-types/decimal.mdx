A `decimal` kérdéstípus olyan számokat gyűjt össze, amelyek tartalmazhatnak tört részt is (pl. `3.14`, `72.5`). Mobileszközökön numerikus billentyűzetet jelenít meg, és ugyanazokat a megjelenési lehetőségeket támogatja az elrendezéshez és formázáshoz, mint a `text` típus.

## Alapvető XLSForm specifikáció

| type | name | label |
|------|------|-------|
| decimal | weight_kg | Súly (kg) |
| decimal | height_m | Magasság (m) |
| decimal | temperature | Testhőmérséklet (°C) |

A szabványos specifikációért tekintse meg az [XLSForm dokumentációját](https://xlsform.org/en/#question-types).

---

## Megjelenési lehetőségek (Appearance options)

### `number-hspinner` — vízszintes léptető

A beviteli mezőt egy vízszintes **− érték +** léptetővel helyettesíti. A mínusz/plusz gombok megérintése a beállított lépésközzel módosítja az értéket.

```
number-hspinner
```

A megjelenített érték egy tizedesjegyre van formázva (pl. `3.0`, `72.5`). Az alapértelmezett lépésköz `1`; tizedes lépésköz beállításához használja a `hspinner()` függvényt.

**Gombforma és lépésköz testreszabása** a `hspinner()` használatával:

```
number-hspinner hspinner('left-small-square','right-small-square','0.1')
```

Paraméterek: bal oldali gomb formája, jobb oldali gomb formája, lépésköz értéke. A finomhangoláshoz használjon tizedes lépésközt, például `0.5` vagy `0.1`.

**Egyedi színek** a `colors()` használatával:

```
number-hspinner colors(0099FF,FFFFFF,FF5500,FFFFFF)
```

Négy érték sorrendben: bal gomb háttere, bal gomb ikonja, jobb gomb háttere, jobb gomb ikonja.

---

### `thousandsep` — ezres elválasztó

A megjelenített számot vesszős csoportosítással formázza (pl. `1,234.56`). A nyers szám vesszők nélkül kerül tárolásra. A beviteli típus `"text"`-re vált a formázott megjelenítés lehetővé tétele érdekében.

```
thousandsep
```

---

### `digisep(n, "sep")` — egyedi számjegy-csoportosítás

Az egész részt `n` hosszúságú blokkokba csoportosítja, amelyeket egy egyedi elválasztó választ el.

```
digisep(3," ")      → 1 234 567.89
```

A beviteli típus `"text"`-re vált, ha ez a megjelenés aktív.

---

### `textonly` — szöveges billentyűzet kényszerítése

A beviteli elemen a `type="text"` értéket kényszeríti. Megelőzi a böngészők számbeviteli furcsaságait (záró nullák elrejtése, asztali léptető nyilak), miközben továbbra is elfogad tizedes értékeket.

```
textonly
```

---

### `floating_hint` — címkeként lebegő tipp

A `hint` szöveg helykitöltőként (placeholder) jelenik meg a beviteli mezőben. Amikor a felhasználó gépelni kezd, címkeként (label) a mező fölé úszik.

```
floating_hint
```

---

### `embed` — tipp a beviteli mezőn belül

Hasonló a `floating_hint`-hez — a tipp a beviteli mezőn belül marad, ha az üres. Gépeléskor nem úszik fel.

```
embed
```

---

### `textpopup` — modális ablakos bevitel

A mező megérintésekor egy nagyobb beviteli mezőt tartalmazó modális ablak nyílik meg. Kis képernyőkön hasznos.

```
textpopup
```

---

### `charcount` — élő karakterszámláló

Élő `(n)` karakterszámlálót jelenít meg a beviteli mező alatt, amely gépelés közben frissül.

```
charcount
```

---

### `prefix(expr)` — előtag hozzáadása

Egy statikus vagy számított karakterláncot illeszt a megjelenített érték elé. A tárolt érték nem tartalmazza az előtagot.

```
prefix('USD ')          → "USD 72.50"-et jelenít meg, "72.50"-et tárol
prefix(${currency})     → dinamikus előtag egy másik mezőből
```

---

### `align_answer` — beviteli szöveg igazítása

A beviteli mezőben lévő gépelt érték vízszintes igazítását szabályozza.

```
align_answer = left
align_answer = right
align_answer = center
```

---

### `inputs{qrscan}` — QR / vonalkód beolvasása a mezőbe

Egy QR-kód beolvasó gombot ad a beviteli mező mellé. Megnyitja a kamera-szkennert, és beilleszti a beolvasott értéket a mezőbe.

```
inputs{qrscan}
```

## Korlátozások és validáció

| type | name | label | constraint | constraint_message |
|------|------|-------|------------|-------------------|
| decimal | weight | Súly (kg) | `. > 0 and . <= 500` | Adjon meg egy értéket 0 és 500 között |
| decimal | height | Magasság (m) | `. > 0 and . <= 3` | Adjon meg egy értéket 0 és 3 között |
| decimal | temp | Hőmérséklet (°C) | `. >= 35 and . <= 42` | Normál hőmérséklet: 35°C–42°C |
| decimal | percentage | Százalék | `. >= 0 and . <= 100` | Adjon meg egy értéket 0 és 100 között |

## Példa — mérési űrlap

| type | name | label | appearance | constraint | constraint_message |

```

```

## Legjobb gyakorlatok

1. Használja a `number-hspinner hspinner(..., '0.1')` beállítást egy tizedesjegy pontosságot igénylő mérésekhez — a léptető automatikusan egy tizedesjegyre formáz, konzisztensen tartva az értékeket.
2. Használja a `textonly` beállítást, ha a böngészők nem kívánt léptetőket adnak hozzá, vagy levágják a záró nullákat (pl. a `3.0` értéket `3`-ként jelenítik meg).
3. Használja a `thousandsep` beállítást nagy pénzügyi értékeknél, hogy a válaszadók ellenőrizhessék, a megfelelő nagyságrendet adták-e meg.
4. Kényszerítsen tartománykorlátozásokat (constraints), ahelyett, hogy kizárólag a mobil billentyűzet típusára hagyatkozna.

## Korlátozások

- A léptető mindig egy tizedesjegyet jelenít meg — ha nagyobb pontosságra van szüksége a megjelenített értékben, használja helyette a sima beviteli mezőt.
- A `thousandsep` és a `digisep()` a nyers számot tárolja — a számítások során ne a formázott megjelenített értéket olvassa ki.

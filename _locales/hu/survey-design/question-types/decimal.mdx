A `decimal` kérdéstípus olyan számokat gyűjt, amelyek tört részt is tartalmazhatnak (pl. `3.14`, `72.5`). Mobiltelefonon numerikus billentyűzetet indít el, és ugyanazokat az appearance opciókat támogatja, mint a `text` típus az elrendezéshez és formázáshoz.

## Alapvető XLSForm specifikáció

| type | name | label |
|------|------|-------|
| decimal | weight_kg | Súly (kg) |
| decimal | height_m | Magasság (m) |
| decimal | temperature | Testhőmérséklet (°C) |

A szabványos specifikációt lásd az [XLSForm dokumentációban](https://xlsform.org/en/#question-types).

---

## Megjelenítési beállítások

### `number-hspinner` — vízszintes pörgető

A beviteli mezőt vízszintes **− érték +** pörgetőre cseréli. A mínusz/plusz gombok megérintésével a konfigurált lépéssel állítja be az értéket.

```
number-hspinner
```

A megjelenített érték egy tizedes pontossággal van formázva (pl. `3.0`, `72.5`). Az alapértelmezett lépés `1`; használja a `hspinner()`-t a tizedes lépés beállításához.

**Testreszabhatja a gomb alakját és lépését** a `hspinner()` segítségével:

```
number-hspinner hspinner('left-small-square','right-small-square','0.1')
```

Paraméterek: bal gomb alakja, jobb gomb alakja, lépés értéke. Használjon tizedes lépést, mint `0.5` vagy `0.1` a pontosabb vezérléshez.

**Egyéni színek** a `colors()` segítségével:

```
number-hspinner colors(0099FF,FFFFFF,FF5500,FFFFFF)
```

Négy érték sorrendben: bal gomb háttérszíne, bal gomb ikonja, jobb gomb háttérszíne, jobb gomb ikonja.

---

### `thousandsep` — ezres elválasztó

A megjelenített számot vesszővel csoportosítva formázza (pl. `1,234.56`). A nyers szám vesszők nélkül kerül tárolásra. A beviteli típus "text"-re vált, hogy lehetővé tegye a formázott megjelenítést.

```
thousandsep
```

---

### `digisep(n, "sep")` — egyéni számjegycsoportosítás

Az egészrész számjegyeit `n` blokkokba csoportosítja egyéni elválasztóval.

```
digisep(3," ")      → 1 234 567.89
```

A beviteli típus "text"-re vált, ha ez az appearance aktív.

---

### `textonly` — szöveges billentyűzet kényszerítése

`type="text"`-t kényszerít a beviteli elemen. Megakadályozza a böngésző szám-bevitel furcsaságait (nullák elrejtése, asztali pörgető nyilak), miközben továbbra is elfogadja a tizedes értékeket.

```
textonly
```

---

### `floating_hint` — súgó lebeg címkeként

A `hint` szöveg helykitöltőként jelenik meg a beviteli mezőben. Amikor a felhasználó gépelni kezd, címkeként lebeg a mező felett.

```
floating_hint
```

---

### `embed` — súgó a beviteli mezőn belül

Hasonló a `floating_hint`-hez – a súgó a beviteli mezőn belül helyezkedik el üresen. Nem lebeg, amikor a felhasználó gépel.

```
embed
```

---

### `textpopup` — modális párbeszédpanel bevitel

A mező megérintésekor egy modális párbeszédpanel nyílik meg nagyobb beviteli mezővel. Hasznos kis képernyőkön.

```
textpopup
```

---

### `charcount` — élő karakter számláló

Élő `(n)` karakter számlálót jelenít meg a beviteli mező alatt, amely frissül, ahogy a felhasználó gépel.

```
charcount
```

---

### `prefix(expr)` — előtag hozzáadása

Statikus vagy számított karakterláncot illeszt a megjelenített érték elé. A tárolt érték nem tartalmazza az előtagot.

```
prefix('USD ')          → "USD 72.50" megjelenítése, "72.50" tárolása
prefix(${currency})     → dinamikus előtag egy másik mezőből
```

---

### `align_answer` — beviteli szöveg igazítása

Vezérli a beírt érték vízszintes igazítását a beviteli mezőben.

```
align_answer = left
align_answer = right
align_answer = center
```

---

### `inputs{qrscan}` — QR / vonalkód beolvasása a mezőbe

QR-kód beolvasó gombot ad a beviteli mező mellé. Megnyitja a kamera szkennert, és kitölti a mezőt a beolvasott értékkel.

```
inputs{qrscan}
```

## Bevált gyakorlatok

1. Használja a `number-hspinner hspinner(..., '0.1')`-t olyan mérésekhez, amelyek egy tizedes pontosságot igényelnek – a pörgető automatikusan egy tizedes pontossággal formáz, így az értékek konzisztensek maradnak.
2. Használja a `textonly`-t, amikor a böngészők nem kívánt pörgető vezérlőket adnak hozzá, vagy levágják a nulla értékű tizedeseket (pl. `3.0` helyett `3`-at jelenít meg).
3. Használja a `thousandsep`-t nagy pénzügyi értékekhez, hogy a válaszadók ellenőrizhessék, helyes nagyságrendű értéket adtak-e meg.
4. Érvényesítse a tartománykorlátozásokat, ahelyett, hogy csak a mobil billentyűzet típusára támaszkodna.

## Korlátozások

- A pörgető mindig egy tizedes pontossággal jelenít meg – ha nagyobb pontosságra van szüksége a megjelenített értékben, használja helyette az egyszerű beviteli mezőt.
- A `thousandsep` és `digisep()` a nyers számot tárolja – ne olvassa be a formázott megjelenített értéket a számításokban.

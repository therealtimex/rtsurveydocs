A `range` kérdéstípus lehetővé teszi a válaszadók számára, hogy egy definiált minimum és maximum érték közötti számot válasszanak. Az rtSurvey webes űrlapján ez szabványos **numerikus beviteli mezőként** jelenik meg — a felmérő közvetlenül beír egy értéket. A `start`, `end` és `step` paraméterek határozzák meg az érvényes tartományt, és korlátozásként érvényesülnek.

## Alap XLSForm specifikáció

| type | name | label | parameters |
|------|------|-------|------------|
| range | satisfaction | Mennyire elégedett a szolgáltatással? | start=1 end=5 step=1 |

A `parameters` oszlop definiálja a csúszka határait és a lépésméretet:

| Paraméter | Leírás | Alapértelmezett |
|-----------|-------------|---------|
| `start` | Minimális érték (beleértve) | 0 |
| `end` | Maximális érték (beleértve) | 10 |
| `step` | Érvényes értékek közötti növekmény | 1 |

A standard tartománykérdés-típusról további részleteket az [XLSForm specifikációban](https://xlsform.org/en/#question-types) talál.

## Felhasználási területek

A tartománykérdéseket gyakran használják:

1. Elégedettségi vagy értékelési skálák (pl. 1–5 vagy 0–10)
2. Likert-típusú numerikus skálák
3. Mérések gyűjtése, ahol csak diszkrét értékek érvényesek
4. Korosztályok vagy pontszámtartományok, ahol a csúszka javítja a használhatóságot a szöveges mezőhöz képest

## Példa használat

### Alapértékelési skála

| type | name | label | parameters |
|------|------|-------|------------|
| range | overall_rating | Összesített értékelés (0–10) | start=0 end=10 step=1 |

### Tizedes lépés

| type | name | label | parameters |
|------|------|-------|------------|
| range | weight_kg | Súly (kg) | start=0 end=200 step=0.5 |

### Az érték felhasználása számításban

| type | name | label | parameters | calculation |
|------|------|-------|------------|-------------|
| range | score | Teszteredmény (0–100) | start=0 end=100 step=5 | |
| calculate | grade | | | if(`${score}` >= 90, 'A', if(`${score}` >= 80, 'B', if(`${score}` >= 70, 'C', 'F'))) |
| note | grade_note | Az Ön osztályzata: `${grade}` | | |

## Bevált gyakorlatok

1. Mindig állítson be értelmes `start`, `end` és `step` értékeket — ne hagyatkozzon az alapértelmezettekre.
2. Címkézze fel a skála végeit a `hint` oszlopban (pl. `hint: 0 = Nagyon elégedetlen, 10 = Nagyon elégedett), hogy a válaszadók számára kontextust biztosítson.`
3. Az 5 pontos Likert-skálákhoz használja a `start=1 end=5 step=1` beállítást a 0–4 helyett, mivel a válaszadók azt várják, hogy az "1" jelenti a legalacsonyabbat.
4. Használja a `range` típust az `integer` + korlátozás helyett, amikor a bemenet korlátos jellege a kérdés tervezésének része (a csúszka vizuálisan kommunikálja a skálát).

## Korlátok

- Az rtSurvey webes űrlapban nincs csúszka widget — az értékbevitel egyszerű numerikus beviteli mező. Vizuális csúszkaélményhez használjon olyan mobil klienst, amely támogatja a tartomány widgetet.
- Nagyon széles tartományok (pl. 0–10000) esetén egy egyszerű `integer` korlátozással éppolyan hatékony és felhasználóbarát.
- A finom lépésértékek (pl. `step=0.1`) korlátozásként működnek, de a webes űrlapon nincs csúszka pontosságukra vonatkozó aggodalom.

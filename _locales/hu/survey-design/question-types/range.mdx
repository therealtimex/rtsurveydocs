A `range` kérdéstípus lehetővé teszi a válaszadók számára, hogy egy számot válasszanak egy meghatározott minimum és maximum érték között. Az rtSurvey webes űrlapján ez egy szabványos **számbeviteli mezőként** jelenik meg – az adatgyűjtő közvetlenül beírja az értéket. A `start`, `end` és `step` paraméterek határozzák meg az érvényes tartományt, és kényszerként érvényesülnek.

## Alapvető XLSForm specifikáció

| type | name | label | parameters |
|------|------|-------|------------|
| range | satisfaction | Mennyire elégedett a szolgáltatással? | start=1 end=5 step=1 |

A `parameters` oszlop határozza meg a csúszka határait és a lépésméretet:

| Paraméter | Leírás | Alapértelmezett |
|-----------|-------------|---------|
| `start` | Minimum érték (beleértve) | 0 |
| `end` | Maximum érték (beleértve) | 10 |
| `step` | Növekmény az érvényes értékek között | 1 |

A szabványos tartományi kérdéstípusról bővebben az [XLSForm specifikációban](https://xlsform.org/en/#question-types) olvashat.

## Felhasználás

A tartományi kérdéseket gyakran használják:

1. Elégedettségi vagy értékelési skálák (pl. 1–5 vagy 0–10)
2. Likert-típusú numerikus skálák
3. Mérések gyűjtésére, ahol csak diszkrét értékek érvényesek
4. Korosztályok vagy pontszám-tartományok, ahol egy csúszka javítja a használhatóságot egy szöveges mezőhöz képest

## Példa használat

### Alapvető értékelési skála

| type | name | label | parameters |
|------|------|-------|------------|
| range | overall_rating | Összértékelés (0–10) | start=0 end=10 step=1 |

### Tizedes lépés

| type | name | label | parameters |
|------|------|-------|------------|
| range | weight_kg | Súly (kg) | start=0 end=200 step=0.5 |

### Az érték felhasználása egy számításban

| type | name | label | parameters | calculation |
|------|------|-------|------------|-------------|
| range | score | Tesztpontszám (0–100) | start=0 end=100 step=5 | |
| calculate | grade | | | if(`${score}` >= 90, 'A', if(`${score}` >= 80, 'B', if(`${score}` >= 70, 'C', 'F'))) |
| note | grade_note | Az Ön osztályzata: `${grade}` | | |

## Legjobb gyakorlatok

1. Mindig állítson be értelmes `start`, `end` és `step` értékeket – ne támaszkodjon az alapértelmezettekre.
2. Címkézze fel a skála végeit a `hint` oszlopban (pl. `hint: 0 = Nagyon elégedetlen, 10 = Nagyon elégedett), hogy kontextust biztosítson a válaszadóknak.
3. 5 pontos Likert-skálák esetén használja a `start=1 end=5 step=1` beállítást a 0–4 helyett, mivel a válaszadók az "1"-et a legalacsonyabbnak várják.
4. Használja a `range`-t az `integer` + korlát helyett, ha a bevitel korlátozott jellege a kérdés tervezésének része (a csúszka vizuálisan kommunikálja a skálát).

## Korlátok

- Az rtSurvey webes űrlapján nincs csúszka widget – az értékbeviteli mező egy egyszerű számbeviteli mező. Vizuális csúszkaélményhez használjon olyan mobil klienst, amely támogatja a tartományi widgetet.
- Nagyon széles tartományok esetén (pl. 0–10000) egy egyszerű `integer` korláttal ugyanolyan hatékony és felhasználóbarátabb.
- A finom lépésértékek (pl. `step=0.1`) korlátként működnek, de a webes űrlapon nincs csúszka pontossági aggály.

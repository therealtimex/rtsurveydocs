Az XLSFormokban és az rtSurveyben található képkérdés-típus lehetővé teszi a válaszadók számára, hogy fényképeket készítsenek és küldjenek be felmérésük részeként. Ez a funkció különösen hasznos vizuális adatok gyűjtéséhez, megfigyelések dokumentálásához vagy terepi felmérésekben bizonyítékok szolgáltatásához.

## Alap XLSForm specifikáció

| type  | name        | label                           |
|-------|-------------|--------------------------------|
| image | photo       | Készítsen fotót a helyszínről    |

Az alapvető képkérdés-típusról további részleteket az [XLSForm specifikációban](https://xlsform.org/en/#question-types) talál.

## Felhasználási területek

A képkérdéseket gyakran használják:

1. Terepi körülmények vagy megfigyelések dokumentálása
2. Vizuális bizonyítékok rögzítése kutatásokban
3. Előtte-utána fotók gyűjtése hatástanulmányokban
4. Feladatok teljesítésének vagy helyszíni jelenlét igazolása
5. Vizuális adatok gyűjtése távoli elemzéshez

## Bevált gyakorlatok

1. Adjon egyértelmű utasításokat arra vonatkozóan, hogy mit kell fényképezni.
2. Vegye figyelembe az adatvédelmi vonatkozásokat, és tájékoztassa a válaszadókat arról, hogyan használják fel fotóikat.
3. Ügyeljen a fájlméretekre és a tárolási korlátokra, különösen korlátozott internet-kapcsolattal rendelkező területeken végzett felmérések esetén.
4. Győződjön meg arról, hogy az eszköz elegendő tárhellyel rendelkezik, és a kameraengedélyek megadottak.

## Példa használat

Íme egy példa arra, hogyan használhat képkérdést egy felmérésben:

| type  | name           | label                                      | hint                                        |
|-------|----------------|--------------------------------------------|--------------------------------------------|
| image | storefront     | Készítsen fotót az üzlet bejáratáról       | Győződjön meg arról, hogy az üzlet neve jól látható    |

## rtSurvey kiterjesztések

### Beágyazott gombelrendezés

Adja hozzá az `inline` megjelenést a `appearance` oszlophoz, hogy a kamera **kör alakú ikon gombként** jelenjen meg a címke mellett, teljes szélességű rögzítési terület helyett. Erre koppintva egy modális ablak nyílik meg.

```
| type  | name  | label        | appearance                          |
|-------|-------|--------------|-------------------------------------|
| image | photo | Készítsen fotót | inline display{right}               |
| image | photo | Készítsen fotót | inline display{center, large}       |
```

**Gomb pozíciója — `display{}`:**

| Value | Layout |
|-------|--------|
| `right` *(alapértelmezett)* | Ikon a címke jobb oldalán |
| `left` | Ikon a címke bal oldalán |
| `top` | Ikon a címke felett, középen |
| `center` / `bottom` | Ikon a címke alatt, középen |

**Gomb mérete:**

| Value | Size |
|-------|------|
| `small` *(alapértelmezett)* | Kis kör |
| `medium` | Közepes kör |
| `large` | Nagy kör |

**Gomb színe** — adjon meg egy hexadecimális színt a `display{}`-ben az elsődleges szín felülírásához:

```
inline display{right, large, <FF5500/>}
inline display{center, medium, <0099FF/>}
```

**Rögzítés utáni vezérlés — `results{}`:**

| Appearance | Effect |
|---|---|
| `results{hide(capture)}` | Elrejti a kamera gombot a fénykép elkészítése után |
| `results{hide(camera)}` | Ugyanaz, mint a `hide(capture)` — alias kép típushoz |
| `results{hide(review)}` | Elrejti az előnézeti bélyegképet a rögzítés után |
| `results{hide(filename)}` | Elrejti a feltöltés után megjelenő fájlnevet |
| `results{left}` | Az ikont balra mozgatja a rögzítés után |

Példa — nagy középre igazított gomb, kamera elrejtése rögzítés után:
```
inline display{center, large} results{hide(capture)}
```

### `invisible auto-show` — automatikus kamera megnyitás

Elrejti a kérdés-widgetet az elrendezésből, de automatikusan megnyitja a kamerát az oldal betöltésekor. Hasznos csendes rögzítési lépés beágyazásához egy űrlapfolyamatba.

```
invisible auto-show
inline invisible auto-show
```

### Aláírás és rajzolás

| Appearance | Description |
|---|---|
| `signature` | Teljes képernyős aláírópad modális ablak |
| `signature display{quick}` | Beágyazott gyors rajz aláírópad — nincs modális ablak |
| `draw` | Szabadkézi rajzvászon |

### Vízjel

Adjon hozzá szöveges vagy képi vízjelet a rögzített fényképekhez:

```
watermark(text, "Survey ID: ${id}", bottom-right, 0.5)
watermark(file, logo.png, top-left, 1.0, 20%)
```

### Címke elrejtése

```
inline text-nolabel display{center, large}
```

## Adatkezelés

Az ezen a kérdéstípuson keresztül gyűjtött képek jellemzően:

1. Közös képformátumban mentve (pl. JPG, PNG)
2. Együtt tárolva más felmérési adatokkal, gyakran külön média mappában
3. Megtekinthetők és elemezhetők a felméréskezelő platformon keresztül

## Elemzési szempontok

Képkérdések használatakor vegye figyelembe:

1. Hogyan elemzik a képeket (pl. kézi felülvizsgálat, automatizált képelemzés)
2. A képfájlokhoz szükséges további tárhely
3. Adatvédelmi és adatbiztonsági intézkedések a fotók tárolására és kezelésére
4. A képszerkesztő vagy -szervező eszközök potenciális szükségessége az elemzési fázisban

## Korlátok

- A képfájlok nagyok lehetnek, ami befolyásolhatja az adatátvitelt és a tárolást.
- Nem minden eszköz rendelkezik kiváló minőségű kamerával vagy elegendő tárhellyel.
- Nagy mennyiségű kép elemzése időigényes lehet.
- Adatvédelmi aggályok merülhetnek fel képek rögzítésekor, különösen nyilvános helyeken.

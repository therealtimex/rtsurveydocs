Az rtSurvey robusztus többnyelvű támogatást nyújt, lehetővé téve a felmérések több nyelven történő elkészítését. Ez a funkció kulcsfontosságú a különböző nyelvi populációk körében végzett kutatásokhoz vagy többnyelvű környezetben.

## Többnyelvű felmérések beállítása

Többnyelvű felmérés létrehozásához az rtSurvey-ben nyelvspecifikus oszlopokat kell hozzáadnia az XLSFormhoz. Így teheti meg:

1. **Címkefordítások**: Adjon hozzá oszlopokat minden nyelvhez a `label::Language (code)` formátumban.
2. **Tippek fordítása**: Használja a `hint::Language (code)` formátumot a tippek fordításához.
3. **Médiafájl-fordítások**: Nyelvspecifikus médiához használja a `media::Language (code)` formátumot.

Példa:

```
| type    | name | label::English (en) | label::Español (es) | hint::English (en) | hint::Español (es) |
|---------|------|---------------------|---------------------|---------------------|---------------------|
| integer | age  | How old are you?    | ¿Cuántos años tienes?| Enter your age      | Ingrese su edad     |
```

## Nyelvkódok

Javasoljuk, hogy a nyelv neve után használja a hivatalos 2 karakteres nyelvkódokat (szubtageket). Ez megkönnyíti az űrlap nyelvének és a felhasználói felület nyelvének összehangolását. A hivatalos kódokat [itt](https://www.iana.org/assignments/language-subtag-registry/language-subtag-registry) találja.

## Alapértelmezett nyelv beállítása

Az adatgyűjtés alapértelmezett nyelvének beállításához használja az XLSForm `settings` munkalapját:

```
| form_id   | version | default_language |
|-----------|---------|-------------------|
| test_form | 101     | French (fr)       |
```

## rtSurvey-specifikus funkciók

### Dinamikus nyelvváltás

Az rtSurvey lehetővé teszi a felhasználók számára a nyelvek dinamikus váltását az adatgyűjtés során:

- A webes felületen használja a felső navigációs sávban található nyelvválasztó legördülő menüt.
- A mobilalkalmazásban a beállítások menüben érheti el a nyelvi opciókat.

### Nyelvspecifikus érvényesítési üzenetek

Az rtSurvey kiterjeszti a többnyelvű támogatást az érvényesítési üzenetekre:

```
| type    | name | constraint | constraint_message::English (en) | constraint_message::Español (es) |
|---------|------|------------|----------------------------------|----------------------------------|
| integer | age  | . <= 150   | Age must be 150 or less          | La edad debe ser 150 o menos     |
```

### Lokalizált kötelező üzenetek

Használja a `required_message::Language (code)`-ot, hogy lefordított hibaüzenetet jelenítsen meg, ha egy kötelező mező üresen marad:

```
| type | name | required | required_message::English (en) | required_message::Tiếng Việt (vi) |
|------|------|----------|-------------------------------|----------------------------------|
| text | name | yes | This field is required | Trường này là bắt buộc |
```

### RTL nyelvi támogatás

Az olyan jobbról balra (RTL) írt nyelvek esetében, mint az arab vagy a héber, az rtSurvey automatikusan igazítja az elrendezést:

```
| type | name | label::English (en) | label::Arabic (ar) |
|------|------|---------------------|---------------------|
| text | name | Your name           | اسمك                |
```

### Nyelvspecifikus megjelenés

Az rtSurvey lehetővé teszi a különböző megjelenések (appearance) megadását a különböző nyelvekhez:

```
| type | name | label::English (en) | label::Chinese (zh) | appearance::English (en) | appearance::Chinese (zh) |
|------|------|---------------------|---------------------|--------------------------|---------------------------|
| text | address | Address          | 地址                 | multiline                | textarea                  |
```

## HTML formázás kétnyelvű címkékben

Kombinálhatja a HTML tageket nyelvi csomagolókkal (wrapper) egyetlen címke cellában. Az rtSurvey kinyeri az aktív nyelvi blokkot, és megjeleníti a maradék HTML-t.

Példa félkövér betűtípusra és betűszínre nyelvenként:

```
<en><big><b>Section 2: Household Income</b></big><br>Ask the household head only.</en><vi><big><b>Phần 2: Thu nhập hộ gia đình</b></big><br>Chỉ hỏi chủ hộ.</vi>
```

Támogatott inline tagek a nyelvi csomagolókon belül: `<b>`, `<i>`, `<u>`, `<big>`, `<small>`, `<font color="...">`, `<br>`, `<span style="...">`.

Színes szöveg példa nyelvenként:

```
<en><font color="red">Required field</font></en><vi><font color="red">Trường bắt buộc</font></vi>
```

## Nyelvtudatos számítások

Ha egy űrlap rendelkezik `${language_use}` mezővel (amelyet egy `change_language` widget állít be), használja az `if()` függvényt az értékek visszaadásához az aktív nyelven:

```
if(${language_use} = 'en', label_en, label_vi)
```

Példa — egy kikeresési eredmény megjelenítése az aktív nyelven a `pulldata('rawquery', ...)` használatával:

```
| type      | name        | calculation                                                                 |
|-----------|-------------|-----------------------------------------------------------------------------|
| calculate | district_label | if(${language_use} = 'en', pulldata('rawquery', concat(${family_path}, '/locations.db::externalData'), 'SELECT label_en FROM externalData WHERE code = ?', ${district}), pulldata('rawquery', concat(${family_path}, '/locations.db::externalData'), 'SELECT label_vi FROM externalData WHERE code = ?', ${district})) |
```

Megjegyzés: A `language_use` mezőt általában egy `change_language` megjelenési widget állítja be. Lásd: Appearance — change_language.

## Bevált módszerek többnyelvű felmérésekhez

1. **Következetes elnevezés**: Használjon következetes nyelvkódokat az egész űrlapon.
2. **Professzionális fordítás**: Alkalmazzon professzionális fordítókat, akik ismerik a felmérés kontextusát.
3. **Kontextus megjegyzések**: Adjon kontextus megjegyzéseket a fordítóknak a pontos fordítás biztosítása érdekében.
4. **Tesztelés**: Tesztelje az űrlapot minden nyelven a közzététel előtt.
5. **Unicode támogatás**: Győződjön meg arról, hogy az adatgyűjtő eszközök támogatják az Unicode-ot a nem latin betűs írásmódokhoz.
6. **Nyelvspecifikus média**: Használjon kulturálisan megfelelő képeket vagy hangokat minden nyelvhez.
7. **Kerülje a szöveget a képeken**: Ha szöveges képeket használ, hozzon létre külön képeket minden nyelvhez.

## Különleges esetek kezelése

### Vegyes nyelvű válaszok

Az rtSurvey lehetővé teszi a válaszadók számára, hogy bármilyen írásmóddal szöveget írjanak be, függetlenül a választott űrlapnyelvtől. Ez hasznos nevek vagy címek rögzítéséhez az eredeti írásmódjukban.

### Nyelvspecifikus kérdéstípusok

Bizonyos kérdéstípusok megfelelőbbek lehetnek bizonyos nyelvekhez. Az rtSurvey lehetővé teszi a különböző kérdéstípusok használatát a különböző nyelvekhez:

```
| type::English (en) | type::Japanese (ja) | name | label::English (en) | label::Japanese (ja) |
|--------------------|---------------------|------|---------------------|----------------------|
| text               | select_one kanji    | name | Enter your name     | 名前を選んでください    |
```

## Többnyelvű adatok exportálása

Adatok exportálásakor az rtSurvey-ből:

- Választhatja az exportálást egy adott nyelven, vagy tartalmazhatja az összes nyelvi verziót.
- A nyelvi metaadatok szerepelnek az exportban, jelezve, hogy melyik nyelvet használták az egyes válaszokhoz.

## Mobilalkalmazással kapcsolatos szempontok

- Az rtSurvey mobilalkalmazás támogatja az offline nyelvváltást.
- Győződjön meg arról, hogy minden szükséges nyelvi fájl le van töltve, mielőtt offline módba lépne.

## Ismert korlátozások

- Előfordulhat, hogy egyes speciális funkciók nem érhetők el minden nyelven.
- A rendkívül hosszú fordítások befolyásolhatják az elrendezést a kisebb képernyőkön.

Az rtSurvey többnyelvű képességeinek kihasználásával befogadó, hozzáférhető felméréseket hozhat létre, amelyek különféle populációkat érnek el, és kiváló minőségű, nyelvileg pontos adatokat szolgáltatnak.

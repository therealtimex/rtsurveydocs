Az rtSurvey a **label** (címke) és **hint** (tipp) szövegeket HTML-ként jeleníti meg a webes űrlapokon. Ez azt jelenti, hogy szabványos HTML tageket használhat a szöveg formázására, sortörések hozzáadására, linkek létrehozására és színek alkalmazására. Ez különösen hasznos megjegyzés mezők, szakaszutasítások és dinamikus összefoglalók esetén.

<Callout type="warning">
A címkékben lévő HTML a **webes űrlapon** és az rtSurvey mobilalkalmazásokban jelenik meg. Előfordulhat, hogy nem minden ODK-kompatibilis kliensben jelenik meg. Mindig tesztelje a célplatformon.
</Callout>

## Támogatott HTML tagek

### Szövegformázás

| Tag | Eredmény |
|-----|--------|
| `<strong>szöveg</strong>` vagy `<b>szöveg</b>` | **Félkövér szöveg** |
| `<em>szöveg</em>` vagy `<i>szöveg</i>` | *Dőlt szöveg* |
| `<u>szöveg</u>` | Aláhúzott szöveg |
| `<br>` | Sortörés |
| `<span style="...">szöveg</span>` | Beágyazott stílus |

### Linkek

```html
<a href="https://example.com" target="_blank">Kattintson ide</a>
```

Új lapon nyílik meg. Használja referenciadokumentumokhoz, irányelvekhez vagy külső forrásokhoz, amelyeket a kérdezőnek konzultálnia kell.

### Színek

Használja a `<span>` taget beágyazott stílusokkal:

```html
<span style="color: red;">Figyelem: az érték tartományon kívül esik</span>
<span style="color: #009688;">Szakasz befejezve</span>
```

## Színtéma változók

Az rtSurvey támogatja a **színtéma tokeneket**, amelyek alkalmazkodnak az alkalmazás beállított témájához. Használja a `__COLOR_THEME_NAME__` szintaxist:

```html
<span style="color: var(--color-theme-primary);">Elsődleges színű szöveg</span>
```

Vagy a token rövidítését a címke szövegében:

```
<font color="var(--COLOR_THEME_PRIMARY)">Fontos megjegyzés</font>
```

Ez automatikusan átalakul az egyenértékű `<span>` tagre egy CSS változóval a megjelenítéskor.

## Többnyelvű címkék

Csomagolja a tartalmat nyelvi tagekbe, hogy több nyelvet támogasson egyetlen címke cellában:

```
<en>Enter the household size</en><hu>Adja meg a háztartás méretét</hu>
```

Az rtSurvey kinyeri az alkalmazás aktuális nyelvének megfelelő tartalmat. Ha nem található megfelelő nyelvi tag, a teljes karakterlánc változatlanul jelenik meg.

## Speciális rtSurvey HTML tagek

### `<webbox src='url' title='title'>...</webbox>`

Beágyaz egy gombot, amely egy URL-t nyit meg egy űrlapon belüli modális ablakban. Lásd a [Webbox](webbox) oldalt a részletekért.

### `<delete-repeat-current>label</delete-repeat-current>`

Egy gombot jelenít meg egy ismétlődő csoporton belül, amely megérintésekor törli az aktuális ismétlődést.

### `<delete-repeat-last>label</delete-repeat-last>`

Egy gombot jelenít meg, amely törli az utolsó ismétlődést.

Példa használat ismétlődő csoportban:

| type | name | label |
|------|------|-------|
| note | delete_btn | `<delete-repeat-current>Tag eltávolítása</delete-repeat-current>` |

## Dinamikus HTML összefoglalók az autopull() függvénnyel

Az `autopull()` egy HTML blokkot jelenít meg egy `note` mezőben, és **minden mezőváltozáskor újraértékeli** az űrlapon. Ez alkalmassá teszi élő összefoglaló panelekhez, beküldés előtti ellenőrző képernyőkhöz és folyamatosan frissülő összegekhez, ahogy a kérdező kitölti az adatokat.

<Callout type="info">
Az `autopull()` csak **note** mezőkön működik. A label oszlopot figyelmen kívül hagyja — minden HTML tartalmat az **appearance** oszlopon keresztül kell megadni a `concat()` függvénnyel.
</Callout>

### Szintaxis

Helyezze az `autopull()` függvényt egy `note` mező **appearance** oszlopába:

```
autopull(concat('<html>...</html>'))
```

A `concat()` függvényen belüli mezőhivatkozások (`${field_name}`) helyére az aktuális élő értékek kerülnek, és a HTML minden változáskor újramegjelenik.

### Magasság korlátozása a scroll-view() függvénnyel

Hosszabb összefoglalók esetén kombinálja az `autopull()`-t a `scroll-view(N%)` függvénnyel a panel magasságának korlátozásához és görgethetővé tételéhez:

```
scroll-view(45%) autopull(concat('<html>...</html>'))
```

Az `N%` érték a látható űrlapterülethez viszonyítva értendő. A `45%` praktikus alapértelmezés egy oldal közepén lévő összefoglaló panelhez.

### Teljes példa — háztartás helyszínének összefoglalója

A következő `note` mező egy kétoszlopos táblázatot jelenít meg, amely mutatja a kiválasztott tartományt, járást és községet. Automatikusan frissül, amikor a `${tinh_name}`, `${huyen_name}` vagy `${xa_name}` értéke megváltozik.

| type | name | label | appearance |
|------|------|-------|------------|
| note | location_summary | | `scroll-view(45%) autopull(concat('<html><table style="width:100%;border-collapse:collapse"><tr><td style="padding:4px;font-weight:bold">Province:</td><td style="padding:4px">', ${tinh_name}, '</td></tr><tr><td style="padding:4px;font-weight:bold">District:</td><td style="padding:4px">', ${huyen_name}, '</td></tr><tr><td style="padding:4px;font-weight:bold">Commune:</td><td style="padding:4px">', ${xa_name}, '</td></tr></table></html>'))` |

XLSFormban az appearance érték egyetlen cellába kerül:

```
scroll-view(45%) autopull(concat(
  '<html><table style="width:100%;border-collapse:collapse">
   <tr><td style="padding:4px;font-weight:bold">Province:</td>
       <td style="padding:4px">', ${tinh_name}, '</td></tr>
   <tr><td style="padding:4px;font-weight:bold">District:</td>
       <td style="padding:4px">', ${huyen_name}, '</td></tr>
   <tr><td style="padding:4px;font-weight:bold">Commune:</td>
       <td style="padding:4px">', ${xa_name}, '</td></tr>
   </table></html>'))
```

### Beágyazott stílusok

A beágyazott `style="..."` attribútumok bármely HTML elemen támogatottak, és ezek a javasolt módszerek a vizuális formázás alkalmazására az `autopull()` blokkokon belül.

A következők **nem** támogatottak az `autopull()` tartalomban:

- `<style>` blokkok
- Külső stíluslap `<link>` tagek
- JavaScript (`<script>`)

### Mikor használjuk az autopull()-t?

| Felhasználási eset | Megjegyzések |
|----------|-------|
| Beküldés előtti ellenőrző képernyő | Mutassa meg az összes kulcsfontosságú választ egy panelen, mielőtt a kérdező befejezné |
| Folyamatos összegek | Jelenítsen meg egy számított összeget, amely a mennyiségek megadásával frissül |
| Látható referencia panel | Mutasson meg egy kiválasztott keresési értéket (pl. tartomány neve), miközben a kérdező a gyermekmezőket tölti ki |

## Legjobb gyakorlatok

1. Takarékosan használja a HTML-t — a túlzottan formázott címkék nehezebben olvashatók.
2. Részesítse előnyben a `<strong>` taget a félkövérhez és az `<em>` taget a dőlthöz az elavult `<b>` és `<i>` helyett.
3. A színhasználat legyen jelentőségteljes — pirosat a figyelmeztetésekhez használjon, ne díszítésre.
4. Mindig tesztelje a HTML megjelenítését mobilalkalmazáson és webes űrlapon is, mivel a megjelenítés kismértékben eltérhet.
5. Kerülje a `<table>` tageket a címkéken belül — ritkán jelennek meg jól a mobilképernyőkön.
6. Ne használjon JavaScriptet (`<script>`) — el lesz távolítva, vagy hibákat okozhat.

## Korlátozások

- A komplex HTML (táblázatok, űrlapok, skriptek) nem támogatott, és tönkreteheti a megjelenítést.
- Néhány régebbi mobil kliens a HTML tageket szó szerinti szövegként jelenítheti meg — tesztelje az összes célkészüléken.
- Az `<a>` linkek böngészőben vagy WebView-ban nyílnak meg — a kérdező elhagyja az űrlapot, ami zavaró lehet mobilon.

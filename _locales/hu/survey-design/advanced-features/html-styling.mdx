import { Callout } from 'nextra/components'

Az rtSurvey a webes űrlapokon a **label** (címke) és a **hint** (súgó) szövegeket HTML-ként jeleníti meg. Ez azt jelenti, hogy szabványos HTML tageket használhat a szöveg formázásához, soremelések hozzáadásához, linkek létrehozásához és színek alkalmazásához. Ez különösen hasznos megjegyzés mezőknél, szakasz utasításoknál és dinamikus összefoglalóknál.

<Callout type="warning">
A címkékben lévő HTML a **webes űrlapon** és az rtSurvey mobilalkalmazásokban jelenik meg. Előfordulhat, hogy nem minden ODK-kompatibilis kliensben jelenik meg. Mindig tesztelje a célplatformon.
</Callout>

## Támogatott HTML tagek

### Szöveg formázása

| Tag | Eredmény |
|-----|--------|
| `<strong>text</strong>` vagy `<b>text</b>` | **Félkövér szöveg** |
| `<em>text</em>` vagy `<i>text</i>` | *Dőlt szöveg* |
| `<u>text</u>` | Aláhúzott szöveg |
| `<br>` | Soremelés |
| `<span style="...">text</span>` | Beágyazott stílus |

### Linkek

```html
<a href="https://example.com" target="_blank">Click here</a>
```

Új lapon nyílik meg. Használja referenciadokumentumokhoz, irányelvekhez vagy külső forrásokhoz, amelyeket a kérdezőnek meg kell néznie.

### Színek

Használja a `<span>` taget beágyazott stílusokkal:

```html
<span style="color: red;">Warning: value is out of range</span>
<span style="color: #009688;">Section completed</span>
```

## Színvilág változók

Az rtSurvey támogatja a **színvilág tokeneket**, amelyek alkalmazkodnak az alkalmazás beállított témájához. Használja a `__COLOR_THEME_NAME__` szintaxist:

```html
<span style="color: var(--color-theme-primary);">Primary color text</span>
```

Vagy használja a token rövidítést a címkeszövegben:

```
<font color="var(--COLOR_THEME_PRIMARY)">Important note</font>
```

Ez a megjelenítéskor automatikusan átalakul az egyenértékű, CSS-változóval ellátott `<span>` taggé.

## Többnyelvű címkék

Csomagolja a tartalmat nyelvi tagekbe a több nyelv támogatásához egyetlen címke cellában:

```
<en>Enter the household size</en><vi>Nhập quy mô hộ gia đình</vi>
```

Az rtSurvey kinyeri az alkalmazás aktuális nyelvének megfelelő tartalmat. Ha nem található megfelelő nyelvi tag, a teljes karakterlánc változatlanul jelenik meg.

## Speciális rtSurvey HTML tagek

### `<webbox src='url' title='title'>...</webbox>`

Beágyaz egy gombot, amely megnyit egy URL-t egy űrlapon belüli modális ablakban. A részletekért lásd a [Webbox](webbox) oldalt.

### `<delete-repeat-current>label</delete-repeat-current>`

Megjelenít egy gombot egy ismétlődő csoporton belül, amely megérintésekor törli az aktuális ismétlődési példányt.

### `<delete-repeat-last>label</delete-repeat-last>`

Megjelenít egy gombot, amely törli az utolsó ismétlődési példányt.

Példa használatra egy ismétlődő csoportban:

| type | name | label |
|------|------|-------|
| note | delete_btn | `<delete-repeat-current>Remove this member</delete-repeat-current>` |

## Dinamikus HTML összefoglalók az autopull() függvénnyel

Az `autopull()` egy HTML blokkot jelenít meg egy `note` mezőben, és az űrlap **minden mezőváltozásakor újraértékeli**. Ez alkalmassá teszi élő összefoglaló panelekhez, beküldés előtti áttekintő képernyőkhöz és folyamatosan frissülő összesítésekhez, miközben a kérdező kitölti az adatokat.

<Callout type="info">
Az `autopull()` csak **note** mezőkön működik. A címke (label) oszlopot figyelmen kívül hagyja — minden HTML tartalmat az **appearance** oszlopon keresztül kell megadni a `concat()` függvény használatával.
</Callout>

### Szintaxis

Helyezze az `autopull()`-t egy `note` mező **appearance** oszlopába:

```
autopull(concat('<html>...</html>'))
```

A `concat()`-on belüli mezőhivatkozások (`${field_name}`) helyére az aktuális élő értékek kerülnek, és a HTML minden változáskor újramegjelenik.

### Magasság korlátozása a scroll-view() függvénnyel

Hosszabb összefoglalók esetén kombinálja az `autopull()`-t a `scroll-view(N%)`-el a panel magasságának korlátozásához és görgethetővé tételééhez:

```
scroll-view(45%) autopull(concat('<html>...</html>'))
```

Az `N%` érték a látható űrlapterülethez viszonyított. A `45%` praktikus alapértelmezett érték egy oldal közepi összefoglaló panelhez.

### Teljes példa — háztartás helyének összefoglalója

A következő `note` mező egy kétoszlopos táblázatot jelenít meg, amely a kiválasztott tartományt, körzetet és községet mutatja. Automatikusan frissül, valahányszor a `${tinh_name}`, `${huyen_name}` vagy `${xa_name}` megváltozik.

| type | name | label | appearance |
|------|------|-------|------------|
| note | location_summary | | `scroll-view(45%) autopull(concat('<html><table style="width:100%;border-collapse:collapse"><tr><td style="padding:4px;font-weight:bold">Province:</td><td style="padding:4px">', ${tinh_name}, '</td></tr><tr><td style="padding:4px;font-weight:bold">District:</td><td style="padding:4px">', ${huyen_name}, '</td></tr><tr><td style="padding:4px;font-weight:bold">Commune:</td><td style="padding:4px">', ${xa_name}, '</td></tr></table></html>'))` |

XLSForm-ban a megjelenési érték egyetlen cellába van írva:

```
scroll-view(45%) autopull(concat(
  '<html><table style="width:100%;border-collapse:collapse">
   <tr><td style="padding:4px;font-weight:bold">Province:</td>
       <td style="padding:4px">', ${tinh_name}, '</td></tr>
   <tr><td style="padding:4px;font-weight:bold">District:</td>
       <td style="padding:4px">', ${huyen_name}, '</td></tr>
   <tr><td style="padding:4px;font-weight:bold">Commune:</td>
       <td style="padding:4px">', ${xa_name}, '</td></tr>
   </table></html>'))
```

### Beágyazott stílusok

A tetszőleges HTML-elemen belüli beágyazott `style="..."` attribútumok támogatottak, és ez a javasolt módszer a vizuális formázás alkalmazására az `autopull()` blokkokon belül.

A következők **nem** támogatottak az `autopull()` tartalmakban:

- `<style>` blokkok
- Külső stíluslap `<link>` tagek
- JavaScript (`<script>`)

### Mikor használjuk az autopull()-t

| Felhasználási eset | Megjegyzések |
|----------|-------|
| Beküldés előtti áttekintő képernyő | Az összes fontos válasz megjelenítése egyetlen panelen, mielőtt a kérdező befejezné |
| Folyamatos összesítések | Egy kiszámított összeg megjelenítése, amely a mennyiségek megadásakor frissül |
| Látható referenciapanel | Egy kiválasztott keresési érték (pl. tartomány neve) megjelenítése, miközben a kérdező kitölti a gyermek mezőket |

## Legjobb gyakorlatok

1. Takarékosan használja a HTML-t — a túlzottan formázott címkéket nehezebb olvasni, nem könnyebb.
2. Részesítse előnyben a `<strong>`-ot a félkövérhez és az `<em>`-et a dőlthöz az elavult `<b>` és `<i>` helyett.
3. A színhasználat legyen értelmes — a pirosat figyelmeztetésekre használja, ne díszítésre.
4. Mindig tesztelje a HTML megjelenítést mind a mobilalkalmazásban, mind a webes űrlapon, mivel a megjelenítés kismértékben eltérhet.
5. Kerülje a `<table>` tageket a címkéken belül — mobilképernyőkön ritkán jelennek meg jól.
6. Ne használjon JavaScriptet (`<script>`) — el lesz távolítva, vagy hibákat okoz.

## Korlátozások

- Az összetett HTML (táblázatok, űrlapok, szkriptek) nem támogatott, és tönkreteheti a megjelenítést.
- Egyes régebbi mobilkliensek a HTML tageket szó szerinti szövegként jeleníthetik meg — tesztelje az összes célkészüléken.
- Az `<a>` linkek böngészőben vagy WebView-ban nyílnak meg — a kérdező elhagyja az űrlapot, ami zavaró lehet mobilon.

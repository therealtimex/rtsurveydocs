在登录之前必须配置 SSL。当您第一次打开应用程序时，您将被自动重定向到 SSL 设置屏幕。

---

## SSL 设置选项

![SSL setup options](/img/ssl-setup/ssl-setup-options.png)

选择以下三个选项之一：

| 选项 | 何时使用 |
|------|----------|
| **免费 rtsurvey.com 子域名** *(推荐)* | 无需 DNS 设置。我们为您创建记录。2–5 分钟内就绪。 |
| **我自己的域名** | 您已经拥有一个域名，且其 DNS 已指向此服务器。 |
| **手动安装证书** | 企业或自定义 CA。需要 SSH 访问权限。 |

---

## 选项 1 — 免费 rtsurvey.com 子域名 *(推荐)*

这是最快的选项。无需域名注册或 DNS 更改。

![HTTPS Setup form](/img/ssl-setup/ssl-setup-form.png)

> **在继续之前：** 免费子域名需要在 [licenses.rtsurvey.com](https://licenses.rtsurvey.com) 拥有一个活动账户。免费计划包含 1 个子域名 (`*.rtsurvey.com`)。

1. 点击 **免费 rtsurvey.com 子域名** 以展开该部分
2. 在 **YOUR SUBDOMAIN** 字段中输入您想要的子域名名称

   > 使用小写字母、数字和连字符。3–30 个字符。
   > 示例：`myproject` → `myproject.rtsurvey.com`

3. 将您从 [licenses.rtsurvey.com](https://licenses.rtsurvey.com) 获取的 **rtSurvey DNS Token** 粘贴到令牌字段中
4. 点击 **Create secure subdomain**

提交后，应用程序将开始为您配置证书：

![Setting up HTTPS progress](/img/ssl-setup/ssl-setup-progress.png)

四个步骤将自动运行：
- **Requesting DNS record** — 为您的子域名创建 DNS 条目
- **Waiting for DNS to propagate** — 通常需要 2–5 分钟
- **Issuing SSL certificate** — Let's Encrypt 对您的证书进行签名
- **Activating HTTPS** — Nginx 使用新证书重新加载

5. 完成后，您将被自动重定向到您的新 HTTPS URL

---

## 选项 2 — 我自己的域名

如果您拥有现有域名且其 DNS `A` 记录已指向此服务器的 IP，请使用此选项。

1. 点击 **我自己的域名** 以展开该部分
2. 输入您的完整域名（例如 `survey.myorganization.org`）
3. 点击 **Create certificate**

Let's Encrypt 将验证您的域名并颁发证书。这需要先正确指向 DNS，否则请求将失败。

---

## 选项 3 — 手动安装证书

适用于使用自定义或内部 CA 的企业环境。您将通过 SSH 将证书文件放置在服务器上，然后在应用程序中输入您的域名。

### 先决条件

- 服务器的 SSH 访问权限
- 域名的有效证书和私钥（PEM 格式）

### 第 1 步 — 通过 SSH 登录服务器

```bash
ssh root@<server-ip>
```

### 第 2 步 — 放置您的证书文件

创建目录并复制您的文件：

```bash
mkdir -p /etc/letsencrypt/live/<your-domain>
```

将您的文件复制到该目录中，并使用以下确切名称：

| 文件 | 描述 |
|------|------|
| `fullchain.pem` | 您的证书 + 任何中间 CA 证书（已合并） |
| `privkey.pem` | 您的私钥 |

示例：

```bash
# 从您的本地计算机复制（在本地运行此命令，而不是在服务器上）
scp fullchain.pem root@<server-ip>:/etc/letsencrypt/live/<your-domain>/fullchain.pem
scp privkey.pem  root@<server-ip>:/etc/letsencrypt/live/<your-domain>/privkey.pem
```

设置正确的权限：

```bash
chmod 644 /etc/letsencrypt/live/<your-domain>/fullchain.pem
chmod 600 /etc/letsencrypt/live/<your-domain>/privkey.pem
```

### 第 3 步 — 在应用程序中输入您的域名

1. 在 SSL 设置屏幕中，点击 **手动安装证书**
2. 输入您的域名（必须与证书的 Common Name 或 SAN 匹配）
3. 点击 **Apply**

服务器将配置 Nginx 使用您的证书并自动重新加载。

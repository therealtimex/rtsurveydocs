# 联系我们

## 常规与支持

如有问题、部署帮助或其他事项，请发送电子邮件至 **[support@rta.vn](mailto:support@rta.vn)**。

对于技术漏洞和功能请求，请使用 [GitHub Issues](https://github.com/therealtimex/rtsurvey/issues)，以便社区从讨论中受益。

---

## 企业与合作

需要自定义部署、SLA 支持或集成协助？请访问 **[rtsurvey.com](https://rtsurvey.com)** 或直接给我们发送电子邮件。

---

## 安全

请**不要**在 GitHub Issues 上公开报告安全漏洞。请通过 [support@rta.vn](mailto:support@rta.vn) 私下联系我们，主题行使用 `[Security]`。

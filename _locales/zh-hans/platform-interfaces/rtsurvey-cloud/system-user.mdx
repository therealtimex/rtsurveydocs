# 系统用户管理

**系统用户**模块（`/cpms/cpmsSystemUser/admin`）是一个综合管理界面，用于控制谁有权访问您的实时调查平台（RT-CPMS）以及他们可以执行哪些操作。

![系统用户界面](/images/system_user.png)

## 统一管理方式

在 RT-CPMS 中，**调查员**只是分配给系统用户的特定角色。不存在独立的"调查员"数据库。无论用户是通过网页门户监控的高级管理员，还是通过移动应用收集数据的现场调查员，他们都在这个统一的框架内进行管理。

## 主要功能

### 1. 用户目录和网格视图
主界面显示连接到工作区的所有用户的分页列表。关键属性包括：
* **组织 ID 和名称**：将用户按特定组织实体逻辑分组（例如 `rta`、`partner_org`）。
* **角色**：指定用户的权限级别（例如 `Administrator`、`Leadteam`、`Enumerator`）。
* **组别**：空间或逻辑分组分配（例如特定地区或运营团队）。
* **是否已同步**：指示账户是否成功与中央单点登录（SSO）系统集成。
* **状态**：确认账户是否为 `Active`（活跃）、`Inactive`（非活跃）、`Deleted`（已删除）或 `Blocked`（已封禁）的视觉指示器。

**全局操作：**
* **添加系统用户**：手动创建单个用户配置文件。
* **导入系统用户**：使用 Excel 模板批量上传账户。您可以使用 `Skip`（跳过）或 `Replace`（替换）模式解决冲突，并直接与 SSO 同步。
* **批量删除**：支持多选以批量删除账户。

### 2. 访问控制和安全性
创建或编辑用户配置文件时，可以使用几个关键的安全和工作流字段：
* **用户代码**：将本地 CPMS 账户链接到中央 SSO 存储库的唯一标识符。
* **更换设备代码**：当调查员需要更换用于数据收集的移动设备时所需的安全令牌。
* **权限级别**：从 0（最低）到 20（最高）的细粒度优先级/访问权限刻度。
* **主管切换**：一个复选框，可立即将普通用户提升为管理状态。
* **工作流自动化**：一个"自动批准编辑请求"选项，可为受信任用户简化数据清理和验证流程。

### 3. 代码管理（自动化入职）
在"代码"子选项卡下，此功能管理基于哈希的注册和邀请链接，简化大型团队的入职流程。

* **注册与邀请**：选择用户是否可以通过分发的链接自行注册，或是否需要管理员直接邀请。
* **有效期**：将入职限制在特定时间窗口内。
* **使用限制**：限制可以使用单个生成代码加入的用户数量。
* **预分配角色**：通过这些代码加入的用户自动继承预定义的角色和权限级别，确保他们无需管理员手动干预即可立即开始工作。

`calculate` 问题类型在后台静默运行公式。它将结果存储在一个命名的字段中，其他问题可以引用该字段，但它不向枚举员显示任何输入或标签。使用它来派生值、连接字符串、运行条件逻辑或查找以后在表单中需要的数据。

---

## 基本语法

| type | name | label | calculation |
|------|------|-------|-------------|
| calculate | total | | `${price} * ${quantity}` |

- **type**: 始终为 `calculate`。
- **name**: 唯一的字段名称。其他问题使用 `${name}` 引用此字段。
- **label**: 留空 — calculate 字段永远不会显示给枚举员。
- **calculation**: 要计算的公式。支持所有 [XLSForm 函数](../operators-and-functions/functions)和字段引用。

---

## 常用模式

### 算术运算

| type | name | label | calculation |
|------|------|-------|-------------|
| integer | price | Unit price | |
| integer | quantity | Quantity | |
| calculate | total | | `${price} * ${quantity}` |
| note | total_note | Total: `${total}` | |

### 字符串连接

| type | name | label | calculation |
|------|------|-------|-------------|
| text | first_name | First name | |
| text | last_name | Last name | |
| calculate | full_name | | `concat(${first_name}, ' ', ${last_name})` |

### 条件值

| type | name | label | calculation |
|------|------|-------|-------------|
| integer | score | Score (0–100) | |
| calculate | grade | | `if(${score} >= 90, 'A', if(${score} >= 75, 'B', if(${score} >= 60, 'C', 'F')))` |

### 根据出生日期计算年龄

| type | name | label | calculation |
|------|------|-------|-------------|
| date | dob | Date of birth | |
| calculate | age_years | | `int((today() - ${dob}) div 365.25)` |

## 使用 `once()` 锁定值

默认情况下，每当引用的任何字段发生更改时，`calculate` 都会重新计算。将公式包装在 `once()` 中，以便仅在首次加载时计算并冻结结果：

| type | name | label | calculation |
|------|------|-------|-------------|
| calculate | interview_start | | `once(now())` |

对于时间戳、初始值或任何不希望在更改时重新计算的情况，请使用 `once()`。

## 从外部源提取数据

### 从 CSV 文件

```
pulldata('staff.csv', 'department', 'name', ${staff_id})
```

有关完整参考，请参阅 [pulldata()](../operators-and-functions/pulldata)。

### 从绑定的 SQLite 数据库

```
pulldata('rawquery',
  concat(${family_path}, '/locations.db::provinces'),
  'SELECT name FROM provinces WHERE id = ?',
  ${province_id})
```

有关路径构造的详细信息，请参阅[本地数据库搜索](../advanced-features/local-database-search)。

### 从应用程序上下文

```
pulldata('app-api', 'user.username')
pulldata('app-api', 'family_path')
```

有关所有可用键，请参阅 [App API](../app-api)。

## 在 relevant 和 constraint 中使用 calculate

其他字段可以像引用任何字段一样引用 `calculate` 结果：

| type | name | label | relevant | constraint |
|------|------|-------|----------|------------|
| calculate | bmi | | | `${weight} div (${height} * ${height}) * 10000` |
| note | bmi_warning | BMI is very high — please verify weight and height. | `${bmi} > 40` | |

## 最佳实践

1. 给 calculate 字段起有意义的名字 — `total_cost` 比 `calc1` 更清晰，且在导出中更容易追踪。
2. 将复杂的公式拆分为多个链式 calculate 字段，而不是使用一个深层嵌套的表达式。
3. 对时间戳和初始快照使用 `once()`，以防止值在首次捕获后发生更改。
4. 将 `calculate` 字段放在第一个引用它们的问题之前 — 计算顺序遵循表单顺序。
5. 保持 `label` 列为空。某些工具会显示标签；留空可以避免令人困惑的输出。

## 限制

- Calculate 字段永远不会直接显示给枚举员 — 使用 `note` 字段来显示结果。
- `calculation` 列是必需的；没有公式的 `calculate` 行始终存储空字符串。
- 除非包装在 `once()` 中，否则结果会在每次表单更改时重新计算 — 大型表单中非常复杂的公式可能会影响低端设备的渲染性能。
- 计算出的值在提交时存储为字符串。将结果传递给算术或逻辑表达式时，请使用 `number()`、`int()` 或 `boolean()` 进行类型转换。

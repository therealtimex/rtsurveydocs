XLSForm 和 rtSurvey 中的 image 题目类型使受访者能够拍摄并提交照片作为调查回答的一部分。此功能在需要收集视觉数据、记录观察或在现场调查中提供证据时特别有用。

## 基本 XLSForm 规范

| type  | name        | label                           |
|-------|-------------|--------------------------------|
| image | photo       | 拍摄该地点的照片    |

有关基本 image 题目类型的更多详情，请参阅 [XLSForm 规范](https://xlsform.org/en/#question-types)。

## 用途

图片题目通常用于：

1. 记录现场条件或观察
2. 在研究中捕获视觉证据
3. 在影响评估中收集前后对比照片
4. 验证任务完成情况或在特定地点的存在
5. 为远程分析收集视觉数据

## 最佳实践

1. 提供关于应拍摄什么的清晰说明。
2. 考虑隐私影响并告知受访者照片的使用方式。
3. 注意文件大小和存储限制，尤其是在网络连接有限的地区进行调查。
4. 确保设备有足够的存储空间并授予摄像头权限。

## 使用示例

以下是您可能在调查中使用图片题目的示例：

| type  | name           | label                                      | hint                                        |
|-------|----------------|--------------------------------------------|--------------------------------------------|
| image | storefront     | 拍摄店铺入口的照片       | 确保店铺名称清晰可见    |

## rtSurvey 扩展

虽然 image 题目的基本 XLSForm 规范很简单，但 rtSurvey 可能提供额外功能或自定义选项：

1. 图像质量设置（例如，低、中、高分辨率）
2. 为图像添加说明或标签的选项
3. 单个题目的多图像捕获
4. 与设备原生相机应用或图库集成

## 数据处理

通过此题目类型收集的图像通常：

1. 以常见图像格式保存（例如，JPG、PNG）
2. 与其他调查数据一起存储，通常在单独的媒体文件夹中
3. 可通过调查管理平台查看和分析

## 分析注意事项

使用图片题目时，请考虑：

1. 如何分析图像（例如，人工审查、自动图像分析）
2. 图像文件所需的额外存储空间
3. 存储和处理照片的隐私和数据保护措施
4. 分析阶段可能需要的图像编辑或组织工具

## 限制

- 图像文件可能很大，影响数据传输和存储。
- 并非所有设备都有高质量摄像头或足够的存储空间。
- 分析大量图像可能耗时。
- 在公共场所拍摄图像时可能存在隐私问题。

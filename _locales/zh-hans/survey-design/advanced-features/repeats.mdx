本页面介绍了在 rtSurvey 中使用循环组的高级模式。有关设置循环组的基础知识，请参阅[分组和循环](../repeats)。

---

## 动态循环计数 (Dynamic repeat count)

默认情况下，由调查员决定循环次数。您可以使用 `repeat_count` 固定循环次数：

| type | name | label | repeat_count |
|------|------|-------|--------------|
| begin_repeat | household_members | 家庭成员 | `${num_members}` |
| text | member_name | 成员姓名 | |
| integer | member_age | 年龄 | |
| end_repeat | | | |

循环将运行 `${num_members}` 次，其中 `num_members` 是之前在表单中收集的数据。调查员无法添加或删除实例。

---

## 索引访问：`indexed-repeat()`

使用 `indexed-repeat(repeatedField, repeatGroup, index)` 从循环组**外部**访问特定循环实例的字段值：

| type | name | label | calculation |
|------|------|-------|-------------|
| calculate | first_name | | `indexed-repeat(${member_name}, ${household_members}, 1)` |
| calculate | second_name | | `indexed-repeat(${member_name}, ${household_members}, 2)` |

这对于构建摘要字段或在循环结束后引用“主要”成员的数据非常有用。

---

## 当前实例位置：`index()`

在循环组内部，`index()` 返回当前实例的 1-based 位置。使用它来标记每次循环或创建唯一标识符：

| type | name | label |
|------|------|-------|
| begin_repeat | plots | 地块 |
| note | plot_label | 地块编号 `${index()}` |
| text | plot_id | 地块 ID |
| end_repeat | | |

---

## 引用同一实例中的字段

在循环内部，使用 `${fieldname}` 引用**同一循环实例**中的另一个字段。在同一循环内不需要使用 `indexed-repeat()`：

| type | name | label | relevant |
|------|------|-------|----------|
| begin_repeat | members | 成员 | |
| text | member_name | 姓名 | |
| integer | member_age | 年龄 | |
| text | school_name | 学校名称 | `${member_age} < 18` |
| end_repeat | | | |

---

## 从循环内部引用父字段

循环组外部（上方）的字段可以正常使用 `${fieldname}` 进行引用：

| type | name | label |
|------|------|-------|
| text | village | 村庄名称 |
| begin_repeat | plots | 农业地块 |
| note | plot_context | `${village}` 中的地块 |
| end_repeat | | |

---

## 汇总循环数据

在循环组**外部**使用循环聚合函数进行汇总：

| Function | Example | Description |
|----------|---------|-------------|
| `count(group)` | `count(${household_members})` | 实例数量 |
| `sum(field)` | `sum(${loan_amount})` | 数值字段的总和 |
| `min(field)` | `min(${member_age})` | 最小值 |
| `max(field)` | `max(${member_age})` | 最大值 |
| `join(sep, field)` | `join(', ', ${member_name})` | 逗号分隔的列表 |
| `count-if(group, expr)` | `count-if(${members}, ${member_age} < 18)` | 条件计数 |
| `sum-if(field, expr)` | `sum-if(${loan_amount}, ${loan_amount} > 500)` | 条件求和 |
| `join-if(sep, field, expr)` | `join-if(', ', ${name}, ${age} >= 18)` | 条件连接 |

### 示例：家庭摘要

| type | name | label | calculation |
|------|------|-------|-------------|
| integer | num_members | 有多少名成员？ | |
| begin_repeat | members | 成员 | `${num_members}` |
| text | member_name | 姓名 | |
| integer | member_age | 年龄 | |
| end_repeat | | | |
| calculate | total_members | | `count(${members})` |
| calculate | children_count | | `count-if(${members}, ${member_age} < 18)` |
| calculate | adult_names | | `join-if(', ', ${member_name}, ${member_age} >= 18)` |
| note | summary | `${total_members}` 名成员；`${children_count}` 名 18 岁以下。成年人：`${adult_names}` | |

## 嵌套循环 (Nested repeats)

一个循环组可以包含另一个循环组。请谨慎使用——嵌套循环会增加复杂性，并可能令调查员感到困惑。

| type | name | label |
|------|------|-------|
| begin_repeat | households | 家庭 |
| text | hh_id | 家庭 ID |
| begin_repeat | hh_members | 成员 |
| text | member_name | 成员姓名 |
| end_repeat | | |
| end_repeat | | |

要从内部循环引用外部循环中的字段，请使用 `${fieldname}`——它会解析为最近的匹配父级：

在 `hh_members` 循环内，`${hh_id}` 返回的是**当前**家庭的 ID，而不是所有家庭的 ID。

---

## 循环组内部排序：`rank-index()`

当循环内部存在 `rank` 字段时，使用外部的 `rank-index(instanceNumber, repeatedField)` 来获取特定实例的序号排名：

| type | name | label | calculation |
|------|------|-------|-------------|
| calculate | top_scorer | | `rank-index(1, ${score})` |

`rank-index(1, ${score})` 返回得分最高实例的索引。

## `begin_repeat` 上的 `1screen` 外观

在 `begin_repeat` 行的 `appearance` 列中添加 `1screen`，会将每个实例的所有问题显示在同一个屏幕上，而不是每个屏幕显示一个问题。

| type | name | label | appearance |
|------|------|-------|------------|
| begin_repeat | household_members | 家庭成员 | `1screen` |
| text | member_name | 成员姓名 | |
| integer | member_age | 年龄 | |
| end_repeat | | | |

当设置了 `1screen` 且组内没有 `repeat_count` 字段和 `add_repeat` 字段时，rtSurvey 会自动在屏幕底部呈现一个圆形的 **+** 按钮，以便调查员无需任何额外配置即可添加新实例。

| Appearance | 每个实例一个屏幕 | 添加了默认 + 按钮 |
|------------|-------------------------|------------------------|
| `1screen` | 是 | 是（当没有 `add_repeat` 子项时） |
| `field-list` | 是 | 否 |

当您需要分组布局但不需要自动添加按钮时，请使用 `field-list`。当您既需要分组布局又需要内置的添加实例方式时，请使用 `1screen`。

---

## `add_repeat` 自定义添加按钮

放置在循环组**内部**且带有 `appearance: add_repeat` 的 `note`（或 `text`）字段将呈现为全宽的“添加”按钮。按钮标签来自该字段的 `label` 列。当存在 `add_repeat` 字段时，默认的圆形 + 按钮（来自 `1screen`）将被禁用。

将 `add_repeat` 字段作为循环组内部的最后一个字段：

| type | name | label | appearance |
|------|------|-------|------------|
| begin_repeat | members | 成员 | `1screen` |
| text | member_name | 成员姓名 | |
| integer | member_age | 年龄 | |
| note | btn_add | + 添加成员 | `add_repeat` |
| end_repeat | | | |

### 颜色自定义

在外观值中传递颜色代码来设置按钮样式：

| Appearance value | Result |
|------------------|--------|
| `add_repeat <#04B404/>` | 绿色背景，默认文本颜色 |
| `add_repeat 04B404-ffffff` | 绿色背景，白色文本 |

第一个颜色是背景，第二个颜色（短横线后）是文本颜色。使用短横线分隔形式时，请省略 `#`。

### 图标变体

使用 `add_repeat icon`（中间有空格）呈现紧凑的圆形图标按钮，而不是全宽按钮：

| type | name | label | appearance |
|------|------|-------|------------|
| note | btn_add | + 添加 | `add_repeat icon` |

## 删除按钮：`delete-repeat-current` 和 `delete-repeat-last`

循环组内部带有 `appearance: delete-repeat-current` 或 `appearance: delete-repeat-last` 的 `note` 字段将呈现为拆分删除按钮。

| Appearance | Action |
|------------|--------|
| `delete-repeat-current` | 删除当前（活动）实例 |
| `delete-repeat-last` | 删除循环中的最后一个实例 |

默认（非图标）按钮是一个拆分按钮：左侧是垃圾桶图标，右侧是该字段的标签文本，跨越屏幕的整个宽度。

### 图标变体

附加 `-icon` 以获得紧凑的圆形垃圾桶图标按钮：

| Appearance | Result |
|------------|--------|
| `delete-repeat-current-icon` | 圆形垃圾桶图标，删除当前实例 |
| `delete-repeat-last-icon` | 圆形垃圾桶图标，删除最后一个实例 |

### 颜色自定义

颜色格式与 `add_repeat` 相同：使用 `<#RRGGBB/>` 或 `RRGGBB-RRGGBB`（背景-文本）。

### 完整模式示例

以下循环使用 `1screen`，顶部有一个圆形删除当前按钮，底部有一个全宽添加按钮：

| type | name | label | appearance |
|------|------|-------|------------|
| begin_repeat | members | 成员 | `1screen` |
| note | btn_del | 移除 | `delete-repeat-current-icon` |
| text | member_name | 成员姓名 | |
| integer | member_age | 年龄 | |
| note | btn_add | + 添加成员 | `add_repeat` |
| end_repeat | | | |

## 最佳实践

1. 当预先知道循环次数时，务必使用 `repeat_count`——这可以防止调查员意外添加或删除实例。
2. 保持循环组专注——每个实例包含 20 多个问题的循环很难导航。
3. 清晰地命名循环组（例如使用 `household_members`，而不是 `repeat1`）——该名称会出现在函数调用和导出的数据中。
4. 使用预期的最大实例数量进行测试，以验证性能。
5. 在 `begin_repeat` 上使用 `1screen` 以在每个实例的一个屏幕上显示所有问题，并在组内配合 `add_repeat` note 字段，为调查员提供一个标记清晰的“添加”按钮。

---

## 限制

- `indexed-repeat()` 需要有效的索引（1 到实例总数）——超出范围的索引将返回空值。
- 不建议嵌套循环超过 2 层，这可能会在某些客户端上导致显示问题。
- 聚合函数（`sum`、`count` 等）对整个循环组起作用——如果没有 `*-if` 变体，您无法聚合实例的一个子集。

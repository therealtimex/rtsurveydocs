### 字符串函数

<Callout type="warning">
在表达式中处理字符串时，务必使用单引号 ('') 来包围字面字符串。但是，如果您想在字面字符串中包含单引号，则会出现例外。在这种情况下，您可以使用双引号 ("") 来包围整个字符串。

例如：
- 正确：if(`${yesno}` = 1, "a string with 'single quotes' in it", "no single quotes here")
- 错误：if(`${yesno}` = 1, 'a string with 'single quotes' in it', 'no single quotes here')

关于智能引号，了解它们的存在至关重要，因为它们可能会在表达式中引起问题。许多富文本编辑器会自动将直引号 ("" 或 '') 转换为智能引号或弯引号 (“” 或 ‘’)，这可能会导致语法错误或意外行为。为避免这种情况，请确保在表达式中始终如一地使用直引号 ('')。

如果您有任何进一步的问题或需要其他帮助，请随时告诉我！
</Callout>

rtSurvey 支持各种函数，包括：

1. `string(field)`：将字段转换为字符串。
   - 例如：`string(34.8)` 将被转换为 `'34.8'`。

2. `string-length(field)`：返回字符串字段的长度。
   - 例如：`string-length(.) > 3 and string-length(.) < 10` 可用于确保当前字段介于 3 到 10 个字符之间。
   - **级联依赖模式**：`string-length(${province}) >= 0` 始终计算为 `true`，但每当 `${province}` 发生变化时，它都会强制 rtSurvey 重新评估表达式。在 `relevant` 中使用它，可以在父字段更新时触发级联刷新：
     | type | name | relevant |
     |------|------|----------|
     | select_one | district | `string-length(${province}) >= 0` |
     这可以确保每当省份变化时，地区问题都会重新评估其 `search()` 或 `rawquery` 外观。

3. `substr(fieldorstring, startindex, endindex)`：返回从 `startindex` 开始，到 `endindex` 之前结束的子字符串。索引从 0 开始表示字符串中的第一个字符。
   - 例如：`substr(${phone}, 0, 3)` 将返回电话号码的前三位数字。

4. `concat(a, b, c, ...)`：将字段（和/或字符串）连接在一起。
   - 例如：`concat(${firstname}, ' ', ${lastname})` 将通过组合 `firstname` 和 `lastname` 字段中的值来返回全名。

5. `linebreak()`：返回换行符。
   - 例如：`concat(${field1}, linebreak(), ${field2}, linebreak(), ${field3})` 将返回一个包含三个字段值的列表，它们之间带有换行符。

6. `lower()`：将字符串转换为全小写字符。
   - 例如：`lower('Street Name')` 将返回 "street name"。

7. `upper()`：将字符串转换为全大写字符。
   - 例如：`upper('Street Name')` 将返回 "STREET NAME"。

### select_one 和 select_multiple 函数

1. `count-selected(field)`：返回 select_multiple 字段中选择的项目数量。
   - 例如：`count-selected(.) = 3` 可用作约束表达式，以确保恰好选择了三个选项。

2. `selected(field, value)`：根据在 select_one 或 select_multiple 字段中是否选择了指定值，返回 true 或 false。
   - 例如：`selected(${color}, 'Blue')` 可用作关联表达式，仅当受访者选择“Blue”作为其最喜欢的颜色时，才显示组或字段。
   - 注意：第二个参数应始终指定选项值（value），而不是选项标签（label）。请使用表单定义中 choices 工作表的 value 列中的值。

3. `selected-at(field, number)`：返回 select_multiple 字段中指定位置的选择项。当传入数字为 0 时，它返回第一个选择项；当数字为 1 时，它返回第二个选择项，依此类推。
   - 例如：`selected-at(${fruits}, 0) = 'Apple'` 可用作关联表达式，仅当第一个选择项是“Apple”时，才显示组或字段。
   - 注意：返回的值将是选项值（value），而不是选项标签（label）。请使用表单定义中 choices 工作表的 value 列中的值。

4. `choice-label(field, value)`：返回表单定义中 choices 工作表定义的 select_one 或 select_multiple 字段选项的标签（label）。
   - 示例 1：`choice-label(${country}, ${country})` 将返回名为 `country` 的字段中当前所选选项的选项标签。
   - 示例 2：`choice-label(${languages}, selected-at(${languages}, 0))` 将返回名为 `languages` 的字段中第一个所选选项的标签。
   - 注意：此函数检索的是选项标签（label），而不是值（value）。它使用表单定义中 choices 工作表中的 label 列。

### 重复字段函数

在 rtSurvey 中，如果您想多次询问相同的问题，可以将字段放在重复组（repeat group）内。这将产生同一字段的多个实例。以下函数可以帮助您处理这些重复字段及其生成的数据。有关更多详细信息，请参阅关于重复字段的帮助主题。

1. `join(string, repeatedfield)`：对于重复组内的字段，生成一个由字符串分隔的值列表。第一个参数指定用于分隔值的定界符。
   - 例如：`join(', ', ${member_name})` 将从所有输入的名称生成一个逗号分隔的列表。

2. `join-if(string, repeatedfield, expression)`：功能与 `join()` 完全相同，不同之处在于它使用提供的表达式检查重复组中的每个实例。如果表达式计算为 false，该项目将从输出中省略。
   - 例如：`join-if(', ', ${member_name}, ${age} >= 18)` 将仅生成成年成员（年龄 18 岁及以上）姓名的逗号分隔列表。

3. `count(repeatgroup)`：返回重复组当前的重复次数。
   - 例如：`count(${groupname})` 将返回该组的实例数量。

4. `count-if(repeatgroup, expression)`：功能与 `count()` 完全相同，不同之处在于它使用提供的表达式检查重复组中的每个实例。如果表达式计算为 false，该项目将从输出中省略。
   - 例如：`count-if(${members}, ${age} >= 18)` 将根据 “members” 重复组内的 age 字段返回成年成员的数量。

5. `sum(repeatedfield)`：对于重复组内的字段，计算所有值的总和。
   - 例如：`sum(${loan_amount})` 将返回所有贷款的总价值。

6. `sum-if(repeatedfield, expression)`：功能与 `sum()` 完全相同，不同之处在于它使用提供的表达式检查重复组中的每个实例。如果表达式计算为 false，该项目将从输出中省略。
   - 例如：`sum-if(${loan_amount}, ${loan_amount} > 500)` 将返回所有超过 500 的贷款的总价值。较小的贷款将被忽略。

7. `min(repeatedfield)`：对于重复组内的字段，计算所有值中的最小值。
   - 例如：`min(${member_age})` 将返回组内最年轻成员的年龄。

8. `min-if(repeatedfield, expression)`：功能与 `min()` 完全相同，不同之处在于它使用提供的表达式检查重复组中的每个实例。如果表达式计算为 false，该项目将从输出中省略。
   - 例如：`min-if(${member_age}, ${member_age} >= 18)` 将返回组内最年轻成年人的年龄。小于 18 岁的人将被忽略。

9. `max(repeatedfield)`：对于重复组内的字段，计算所有值中的最大值。
   - 例如：`max(${member_age})` 将返回组内年龄最大成员的年龄。

10. `max-if(repeatedfield, expression)`：功能与 `max()` 完全相同，不同之处在于它使用提供的表达式检查重复组中的每个实例。如果表达式计算为 false，该项目将从输出中省略。
    - 例如：`max-if(${member_age}, ${member_age} >= 18)` 将返回组内年龄最大成年人的年龄。小于 18 岁的人将被忽略。

11. `index()`：在重复组内调用，返回当前组或实例的索引号。
    - 例如：在重复组内使用时，`index()` 将为第一个实例返回 1，为第二个实例返回 2，依此类推。

12. `indexed-repeat(repeatedfield, repeatgroup, index)`：从重复组外部引用该重复组内的字段或组。第一个参数指定感兴趣的重复字段或组，第二个参数指定该字段或组所在的重复组，第三个参数指定要使用的重复组内的实例编号。
    - 示例 1：当 name 字段位于名为 “names” 的先前重复组内时，`indexed-repeat(${name}, ${names}, 1)` 将返回第一个可用的姓名。
    - 示例 2：`indexed-repeat(${name}, ${names}, index())` 将提取与当前重复组的实例编号相对应的姓名。

13. `rank-index(index, repeatedfield)`：此函数计算重复字段指定实例的序数排名，供重复组外部使用。排名 1 分配给值最高的实例，排名 2 分配给值次高的实例，依此类推。如果您传递了无效的索引或传递了非数值实例的索引，将返回排名 999。
    - 例如：`rank-index(1, ${random_draw})` 基于第一个实例的 `random_draw` 字段值与其他实例值的比较，计算其排名。

14. `rank-index-if(index, repeatedfield, expression)`：此函数的工作原理与 `rank-index()` 类似，但它使用提供的表达式检查重复字段的重复组中的每个实例。如果表达式计算为 false，该项将从计算中省略。所使用的索引是基于评估每个实例表达式之前的完整实例集。如果您为因不满足表达式而被忽略的实例传递索引，则将其视为无效索引，并将返回排名 999。
    - 例如：`rank-index-if(1, ${age}, ${age} >= 18)` 在成年人群组中计算年龄排名，仅考虑年龄大于或等于 18 岁的实例。

### 数字函数 

| 运算符 | 操作 | 示例 | 示例答案 |
|----------|-----------|---------|----------------|
| `+` | 加法 | 1 + 1 | 2 |
| `-` | 减法 | 3 - 2 | 1 |
| `*` | 乘法 | 3 * 2 | 6 |
| `div` | 除法 | 10 div 2 | 5 |
| `mod` | 取模 | 9 mod 2 | 1 |

rtSurvey 支持数字函数，包括：
- `number(field)`：将字段的值转换为数字。
  - 例如：`number('34.8')` = 34.8

- `int(field)`：将字段的值转换为整数。
  - 例如：`int('39.2')` = 39

- `min(field1, ..., fieldx)`：返回所传递字段中的最小值。
  - 例如：`min(${father_age}, ${mother_age})` 将返回母亲或父亲中较小的年龄。

- `max(field1, ..., fieldx)`：返回所传递字段中的最大值。
  - 例如：`max(${father_age}, ${mother_age})` 将返回母亲或父亲中较大的年龄。

- `format-number(field)`：根据用户的语言环境设置格式化整数或小数（decimal）字段的值。
  - 例如：`format-number(${income})` 此表达式可能会将 "120000" 格式化为 "120,000"。

- `round(field, digits)`：将数值字段值舍入到小数点后指定的位数。
  - 例如：`round(${interest_rate}, 2)`

- `abs(number)`：返回数字的绝对值。
  
- `pow(base, exponent)`：返回第一个参数的第二个参数次幂的值。
  - 每个参数可以是字段、数字或表达式。

- `log10(fieldorvalue)`：返回传入字段或值的以 10 为底的对数。

- `sin(fieldorvalue)`：返回传入字段或值的正弦值，以弧度表示。
  
- `cos(fieldorvalue)`：返回传入字段或值的余弦值，以弧度表示。

- `tan(fieldorvalue)`：返回传入字段或值的正切值，以弧度表示。

- `asin(fieldorvalue)`：返回传入字段或值的反正弦值，以弧度表示。

- `acos(fieldorvalue)`：返回传入字段或值的反余弦值，以弧度表示。

- `atan(fieldorvalue)`：返回传入字段或值的反正切值，以弧度表示。

- `atan2(x, y)`：返回由坐标为 (x, y) 的点与原点以及正 x 轴所夹角的弧度。结果在 -pi() 到 pi() 的范围内。

- `sqrt(fieldorvalue)`：返回传入字段或值的非负平方根。

- `exp(x)`：返回 e^x 的值。

- `pi()`：返回 pi 的值。

### 日期和时间函数

<Callout type="warning">
rtSurvey 中的日期值以 `YYYY-MM-DD` 格式的字符串存储。日期时间值以 ISO 8601 字符串（`YYYY-MM-DDTHH:MM:SS`）存储。使用 `decimal-date-time()` 将其转换为数字以进行算术运算（例如，计算持续时间）。
</Callout>

1. `today()`：以 `YYYY-MM-DD` 格式的字符串返回今天的日期。表单打开时计算一次。
   - 例如：`today()` → `'2024-03-15'`
   - 常见用途：在 `default` 列中预填今天的日期，或在 `relevant`/`constraint` 中与日期字段进行比较。

2. `now()`：以 ISO 8601 字符串形式返回当前日期和时间。每次计算表达式时都会进行评估。
   - 例如：`now()` → `'2024-03-15T14:32:00.000+03:00'`
   - 常见用途：在调查期间记录特定事件的确切时间戳。

3. `date(value)`：将值（字符串或数字）转换为日期字符串。对于将计算出的值强制转换为日期类型非常有用。
   - 例如：`date('2024-03-15')` → `'2024-03-15'`

4. `date-time(value)`：将值转换为日期时间（datetime）字符串。
   - 例如：`date-time(${event_timestamp})`

5. `decimal-date-time(value)`：将日期或日期时间字符串转换为十进制数字，表示自 Unix 纪元以来的毫秒数除以 86400000（即自 1970-01-01 以来的分数天数）。使用此功能对日期进行算术运算。
   - 例如：两个日期之间相隔的天数：
     `decimal-date-time(${end_date}) - decimal-date-time(${start_date})`
   - 例如：两个日期时间之间相隔的分钟数：
     `(decimal-date-time(${end_time}) - decimal-date-time(${start_time})) * 1440`

6. `format-date(date, format)`：使用模式字符串格式化日期值。
   - 格式标记：`%Y`（4 位年份）、`%y`（2 位年份）、`%m`（月份 01–12）、`%d`（日期 01–31）、`%a`（工作日简写）、`%b`（月份名称简写）
   - 例如：`format-date(today(), '%d/%m/%Y')` → `'15/03/2024'`
   - 例如：`format-date(${dob}, '%B %d, %Y')` → `'March 15, 1990'`

7. `format-date-time(datetime, format)`：使用模式字符串格式化日期时间（datetime）值。接受所有 `format-date` 标记以及：
   - `%H`（小时 00–23）、`%h`（小时 01–12）、`%M`（分钟 00–59）、`%S`（秒 00–59）、`%3`（毫秒）、`%P`（AM/PM）
   - 例如：`format-date-time(now(), '%d/%m/%Y %H:%M')` → `'15/03/2024 14:32'`
   - 例如：`format-date-time(${event_time}, '%I:%M %p')` → `'02:32 PM'`

8. `STRFTIME(format, datetime)`：SQLite 风格的日期格式化。在传递给 `rawquery` 查询的 SQL 字符串内部可用 —— 在 XLSForm 的 `calculation` 或 `label` 列中 **不可用**。使用 SQLite 格式标记（`%Y`、`%m`、`%d`、`%H`、`%M`、`%S`）。
   - 在 rawquery SQL 字符串内部的示例：`'SELECT STRFTIME(''%Y-%m'', interview_date) AS month FROM data WHERE id = ?'`
   - 注意：在 XLSForm 表达式中进行日期格式化请使用 `format-date-time()`。`STRFTIME()` 是一个 SQLite 函数，仅在传递给 `rawquery` 的 SQL 中可用。

### 布尔函数

1. `boolean(value)`：将任何值转换为布尔值。对于非空字符串、非零数字和 `true` 返回 `true`；对于空字符串、`0` 和 `false` 返回 `false`。
   - 例如：如果 `name` 不为空，则 `boolean(${name})` 返回 `true`。

2. `boolean-from-string(string)`：如果字符串是 `'1'` 或 `'true'`（不区分大小写），则返回 `true`；否则返回 `false`。
   - 例如：`boolean-from-string(${enabled_flag})` —— 当字段以文本形式存储 `'true'`/`'false'` 时非常有用。

3. `true()`：返回布尔值 `true`。
   - 例如：在 `required` 列中，`true()` 等同于 `yes`。

4. `false()`：返回布尔值 `false`。
   - 例如：`if(${skip_section} = 'yes', false(), true())` —— 动态设置必填。

5. `not(expression)`：返回表达式的逻辑否定。如果表达式为 false，则返回 `true`，反之亦然。
   - 例如：`not(${consent} = 'yes')` —— 当未给予同意时显示警告。
   - 例如：`not(selected(${issues}, 'none'))` —— 仅当未选择 “none” 时才需要详细信息。

### 附加字符串函数

1. `starts-with(string, prefix)`：如果 `string` 以 `prefix` 开头，则返回 `true`。
   - 例如：`starts-with(${phone}, '+254')` 检查电话号码是否以肯尼亚国家代码开头。

2. `contains(string, substring)`：如果 `string` 包含 `substring`，则返回 `true`。
   - 例如：`contains(${email}, '@')` 检查电子邮件地址是否含有 `@` 符号。
   - 例如：如果备注（notes）中提到 “urgent”，则 `contains(${notes}, 'urgent')` 会触发后续问题。

3. `substring-before(string, needle)`：返回 `string` 中在第一次出现 `needle` 之前的部分。
   - 例如：`substring-before(${full_name}, ' ')` 提取第一个单词（名字）。

4. `substring-after(string, needle)`：返回 `string` 中在第一次出现 `needle` 之后的部分。
   - 例如：`substring-after(${email}, '@')` 提取电子邮件地址的域名部分。

5. `normalize-space(string)`：去除首尾空格，并将所有内部连续空格折叠为单个空格。
   - 例如：`normalize-space(${name})` —— 清理可能输入了多余空格的姓名。

6. `translate(string, search_chars, replace_chars)`：将 `string` 中出现在 `search_chars` 中的每个字符替换为 `replace_chars` 中对应的字符。`search_chars` 中没有对应 `replace_chars` 字符的字符将被删除。
   - 例如：`translate(${code}, 'abcdefghijklmnopqrstuvwxyz', 'ABCDEFGHIJKLMNOPQRSTUVWXYZ')` 转换为大写（等同于 `upper()`）。
   - 例如：`translate(${phone}, ' -()', '')` 删除电话号码中的空格、连字符和括号。

### 附加数学函数

1. `floor(number)`：返回小于或等于 `number` 的最大整数（向负无穷方向舍入）。
   - 例如：`floor(4.9)` = 4，`floor(-2.1)` = -3

2. `ceiling(number)`：返回大于或等于 `number` 的最小整数（向正无穷方向舍入）。
   - 例如：`ceiling(4.1)` = 5，`ceiling(-2.9)` = -2

3. `random()`：返回一个介于 0.0（含）和 1.0（不含）之间的随机小数。通常在 `calculate` 字段中用于分配随机值或随机化问题顺序。
   - 例如：`random()` → 例如 `0.7341`
   - 例如：`int(random() * 6) + 1` → 1-6 之间的随机数（掷骰子）

4. `coalesce(a, b)`：如果 `a` 不为空，则返回 `a`；否则返回 `b`。在字段可能为空时作为备选方案非常有用。
   - 例如：`coalesce(${preferred_name}, ${full_name})` —— 如果设置了首选姓名，则使用它，否则回退到全名。

5. `once(value)`：评估 `value` 并存储它，但仅当当前字段为 **空** 时。如果该字段已有值（例如，之前已设置），则 `once()` 返回现有的值而不做更改。这可以防止重新计算覆盖用户输入。
   - 例如：在 `default` 列中使用 `once(today())` 会设置一次今天的日期，并且如果调查员重新打开表单，该日期也不会更新。
   - 例如：`once(uuid())` 生成一次 UUID，并在重新编辑时保持稳定。

### 地理函数

1. `area(geoshape_value)`：计算由 geoshape（多边形）值包围的 **面积（以平方米为单位）**。
   - 参数是一个格式为 `lat1 lon1 0 0; lat2 lon2 0 0; ...` 的 geoshape 字段值。
   - 例如：`area(${field_boundary})` —— 计算调查土地的面积（平方米）。
   - 例如：`round(area(${field_boundary}) div 10000, 2)` —— 转换为公顷。

2. `distance(coordinates)`：计算 geotrace（线）的 **总路径长度（以米为单位）**，或两个 geopoint（地理点）之间的距离。
   - 对于 geotrace：`distance(${route})` 返回总路径长度（米）。
   - 对于两个 geopoint：`distance(concat(${point_a}, ' ', ${point_b}))` 返回它们之间的距离。
   - 例如：`round(distance(${road_trace}) div 1000, 3)` —— 道路长度（公里）。

---

### 验证函数

1. `regex(value, pattern)`：如果 `value` 匹配正则表达式 `pattern`，则返回 `true`。在 `constraint` 列中用于基于模式的验证。
   - 该模式使用标准正则表达式语法（POSIX ERE 子集）。
   - 例如：`regex(., '^[0-9]{10}$')` —— 验证 10 位数字。
   - 例如：`regex(., '^[A-Z]{2}[0-9]{6}$')` —— 验证护照号码格式（2 位大写字母后跟 6 位数字）。
   - 例如：`regex(., '^[^@]+@[^@]+\\.[^@]{2,}$')` —— 基本电子邮件格式检查。

2. `checklist(min, max, v1, v2, ...)`：评估布尔表达式列表，如果 `true` 值的数量在 `min` 和 `max` 之间（含），则返回 `true`。传递 `-1` 给 `min` 或 `max` 可跳过该边界。
   - 例如：`checklist(2, 3, ${q1} = 'yes', ${q2} = 'yes', ${q3} = 'yes')` —— 如果三个条件中恰好有 2 个或 3 个为真，则通过。
   - 例如：`checklist(1, -1, ${smoke_alarm}, ${fire_ext}, ${emergency_plan})` —— 至少一个安全措施必须为真。

3. `weighted-checklist(min, max, v1, w1, v2, w2, ...)`：类似于 `checklist()`，但每个值都有一个权重。`true` 值的权重总和必须在 `min` 和 `max` 之间。
   - 例如：`weighted-checklist(10, -1, ${has_toilet}, 4, ${has_sink}, 3, ${has_shower}, 5)` —— 现有设施的权重总和必须至少为 10。

### 实用函数

1. `uuid()`：生成随机 UUID（RFC 4122 v4 格式）字符串。
   - 例如：`uuid()` → `'a3f8b2c1-4d5e-6f7a-8b9c-0d1e2f3a4b5c'`
   - 通常与 `once()` 结合使用以生成稳定的唯一 ID：`once(uuid())`

2. `version()`：返回在 settings 工作表中设置的表单 `version` 属性的值。
   - 例如：`version()` → `'3.1'`
   - 在 `calculate` 字段中非常有用，可将表单版本嵌入导出的数据中。

3. `position()`：在 **重复组（repeat group）** 内部调用时，返回当前重复实例的从 1 开始的索引。
   - 例如：在第一个实例中 `position()` 返回 `1`，在第二个实例中返回 `2`，依此类推。
   - 另请参阅：`index()`（别名），以及用于从重复组外部引用重复值的 `indexed-repeat()`。

4. `thousandsep(length, separator, value)`：使用千位分隔符格式化数字。`length` 是最小总字符串长度（如果较短则用空格填充），`separator` 是要使用的字符（例如 `','`），`value` 是要格式化的数字。
   - 例如：`thousandsep(0, ',', 1234567)` → `'1,234,567'`
   - 例如：`thousandsep(0, '.', ${income})` —— 使用句点作为千位分隔符格式化收入。

5. `substr-jsonpath(value, jsonpath)`：使用 JSONPath 表达式从 JSON 字符串中提取值。
   - `value` 必须是 JSON 字符串（例如，使用 `callapi(..., 'json:', ...)` 存储原始 API 响应的字段）。
   - `jsonpath` 是 JSONPath 表达式（例如 `'$.data.name'`、`'$.items[0].id'`）。
   - 始终返回 **字符串** —— 用于算术运算时请用 `number()` 包裹。
   - 如果找不到路径或 `value` 不是有效的 JSON，则返回空字符串 `''`。
   - 例如：`substr-jsonpath(${api_response}, '$.data.name')` —— 提取 `name` 字段。
   - 例如：`substr-jsonpath(${api_response}, '$.items[0].label')` —— 数组的第一个元素。
   - 例如：`number(substr-jsonpath(${api_response}, '$.price'))` —— 提取数值。
   - 通常与 `callapi(..., 'json:', ...)` 一起使用，从一个 API 响应中提取多个字段。请参阅 [从一个 API 调用中获取多个值](../advanced-features/call-api#fetching-multiple-values-from-one-api-call)。

rtSurvey 中的表达式以 **XPath 1.0** 的一个子集编写，通过 JavaRosa/ODK 函数和自定义 rtSurvey 函数进行扩展。您可以在 XLSForm 的 `calculate`、`constraint`、`relevant`、`required` 和 `default` 列中使用表达式。

## 引用字段值

使用 `${fieldname}` 引用另一个字段的值：

```
${age} > 18
```

使用 `.`（单个点）引用**当前字段的值**——常在 `constraint` 表达式中使用：

```
. >= 0 and . <= 100
```

使用 `..` 引用父组（在重复中的高级用法）。

## 表达式语法

表达式遵循标准 XPath 规则：

- **字符串**必须用单引号括起来：`'yes'`
- **数字**直接写：`42`、`3.14`
- **Boolean** 结果用于 `relevant`、`required` 和 `constraint`——任何非空、非零值都为真
- 运算符周围的空格被忽略

<Callout type="warning">
始终使用直引号（`'` 或 `"`）——不要使用"智能引号"（弯引号）。富文本编辑器通常会自动转换引号，这会破坏您的表达式。
</Callout>

## 快速示例

| 使用场景 | 表达式 |
|----------|------------|
| 如果年龄超过 18 则显示 | `${age} > 18` |
| 仅在选择了"yes"时显示 | `${consent} = 'yes'` |
| 如果另一个字段不为空则必填 | `${name} != ''` |
| 计算总数 | `${adults} + ${children}` |
| 连接姓名 | `concat(${first_name}, ' ', ${last_name})` |
| 今天的日期 | `today()` |
| 检查是否选择了某选项 | `selected(${interests}, 'sports')` |

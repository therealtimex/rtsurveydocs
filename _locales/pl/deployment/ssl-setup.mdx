SSL musi zostać skonfigurowany przed zalogowaniem. Przy pierwszym otwarciu aplikacji zostaniesz automatycznie przekierowany do ekranu konfiguracji SSL.

---

## Opcje konfiguracji SSL

![Opcje konfiguracji SSL](/img/ssl-setup/ssl-setup-options.png)

Wybierz jedną z trzech opcji:

| Opcja | Kiedy użyć |
|--------|-------------|
| **Darmowa subdomena rtsurvey.com** *(Zalecane)* | Konfiguracja DNS nie jest wymagana. Utworzymy rekord za Ciebie. Gotowe w 2–5 minut. |
| **Moja własna domena** | Masz już domenę, a jej rekord DNS wskazuje na ten serwer. |
| **Zainstaluj certyfikat ręcznie** | Rozwiązanie korporacyjne lub niestandardowy urząd certyfikacji (CA). Wymaga dostępu przez SSH. |

---

## Opcja 1 — Darmowa subdomena rtsurvey.com *(Zalecane)*

To najszybsza opcja. Rejestracja domeny ani zmiany w DNS nie są wymagane.

![Formularz konfiguracji HTTPS](/img/ssl-setup/ssl-setup-form.png)

> **Zanim przejdziesz dalej:** Darmowa subdomena wymaga aktywnego konta na [licenses.rtsurvey.com](https://licenses.rtsurvey.com). Darmowy plan obejmuje 1 subdomenę (`*.rtsurvey.com`).

1. Kliknij **Darmowa subdomena rtsurvey.com**, aby rozwinąć sekcję.
2. Wpisz wybraną nazwę subdomeny w polu **TWOJA SUBDOMENA**.

   > Używaj małych liter, cyfr i myślników. Od 3 do 30 znaków.
   > Przykład: `mojprojekt` → `mojprojekt.rtsurvey.com`

3. Wklej swój **rtSurvey DNS Token** z [licenses.rtsurvey.com](https://licenses.rtsurvey.com) w pole tokenu.
4. Kliknij **Utwórz bezpieczną subdomenę**.

Po przesłaniu aplikacja rozpocznie proces przygotowywania certyfikatu:

![Postęp konfiguracji HTTPS](/img/ssl-setup/ssl-setup-progress.png)

Cztery kroki wykonywane są automatycznie:
- **Żądanie rekordu DNS** — tworzy wpis DNS dla Twojej subdomeny.
- **Oczekiwanie na propagację DNS** — zazwyczaj trwa to 2–5 minut.
- **Wystawianie certyfikatu SSL** — Let's Encrypt podpisuje Twój certyfikat.
- **Aktywacja HTTPS** — Nginx przeładowuje się z nowym certyfikatem.

5. Po zakończeniu zostaniesz automatycznie przekierowany na swój nowy adres URL HTTPS.

## Opcja 2 — Moja własna domena

Użyj tej opcji, jeśli masz istniejącą domenę, a jej rekord DNS `A` wskazuje już na adres IP tego serwera.

1. Kliknij **Moja własna domena**, aby rozwinąć sekcję.
2. Wpisz swoją pełną nazwę domeny (np. `ankieta.mojaorganizacja.org`).
3. Kliknij **Utwórz certyfikat**.



Let's Encrypt zweryfikuje Twoją domenę i wystawi certyfikat. Wymaga to wcześniejszego prawidłowego skierowania DNS — w przeciwnym razie żądanie zakończy się niepowodzeniem.

## Opcja 3 — Zainstaluj certyfikat ręcznie

Dla środowisk korporacyjnych korzystających z niestandardowego lub wewnętrznego urzędu certyfikacji (CA). Pliki certyfikatów umieścisz na serwerze przez SSH, a następnie wpiszesz swoją domenę w aplikacji.

### Wymagania wstępne

- Dostęp przez SSH do serwera.
- Prawidłowy certyfikat i klucz prywatny dla Twojej domeny (format PEM).

### Krok 1 — Połącz się z serwerem przez SSH

```bash
ssh root@<server-ip>
```

### Krok 2 — Umieść pliki certyfikatu

Utwórz katalog i skopiuj swoje pliki:

```bash
mkdir -p /etc/letsencrypt/live/<your-domain>
```

Skopiuj swoje pliki do tego katalogu, zachowując dokładnie te nazwy:

| Plik | Opis |
|------|-------------|
| `fullchain.pem` | Twój certyfikat + wszelkie certyfikaty pośrednie CA (połączone) |
| `privkey.pem` | Twój klucz prywatny |

Przykład:

```bash
# Skopiuj z lokalnej maszyny (uruchom to lokalnie, nie na serwerze)
scp fullchain.pem root@<server-ip>:/etc/letsencrypt/live/<your-domain>/fullchain.pem
scp privkey.pem  root@<server-ip>:/etc/letsencrypt/live/<your-domain>/privkey.pem
```

Ustaw odpowiednie uprawnienia:

```bash
chmod 644 /etc/letsencrypt/live/<your-domain>/fullchain.pem
chmod 600 /etc/letsencrypt/live/<your-domain>/privkey.pem
```

### Krok 3 — Wpisz swoją domenę w aplikacji



1. Na ekranie konfiguracji SSL kliknij **Zainstaluj certyfikat ręcznie**.
2. Wpisz swoją nazwę domeny (musi być zgodna z Common Name lub SAN certyfikatu).
3. Kliknij **Zastosuj**.

Serwer skonfiguruje Nginx z Twoim certyfikatem i automatycznie go przeładuje.

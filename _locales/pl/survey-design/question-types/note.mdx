title: "Note"
description: "Pytania note wyświetlają tekst lub media tylko do odczytu, dostarczając informacji lub instrukcji w ankiecie."
---

Typ pytania `note` wyświetla tekst tylko do odczytu lub media — używany do dostarczania instrukcji, podsumowań lub komunikatów nie wymagających danych wejściowych.

## Podstawowa specyfikacja XLSForm

| type | name    | label                              |
|------|---------|------------------------------------|
| note | intro   | Witamy w ankiecie. Odpowiedz szczerze. |

## Typowe zastosowania

- Instrukcje dla ankietera lub respondenta
- Podsumowania obliczonych wartości
- Separatory sekcji
- Komunikaty ostrzegawcze lub warunkowe

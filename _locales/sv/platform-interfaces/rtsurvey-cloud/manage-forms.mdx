Modulen **Hantera formulär** fungerar som den primära ingångspunkten för att organisera dina undersökningsinstrument och samordna fältarbetsuppgifter. Den ger detaljerad kontroll över formulärtillgänglighet, datavisning och enhetsmålstyrning.

![Gränssnitt för formulärhantering](/images/manage_forms.png)

## Formulärfamiljöversikt

Under menyn **Formulär och datainmatning** visar avsnittet **Formulärfamilj** ett heltäckande rutnät av alla dina importerade formulär tillsammans med viktiga snabbåtkomstkontroller. Denna centraliserade vy låter projektledare snabbt driftsätta och konfigurera enskilda undersökningar.

### Viktiga datakolumner och konfigurationsalternativ

- **Datavy:** Öppna inskickade poster och datauppsättningsförhandsvisningar direkt för varje formulär.
- **Tillåt redigering:** En snabbväxling för att låsa eller låsa upp möjligheten för fältarbetare att redigera sina inskickade data (aktiva/inaktiva statusar).
- **Offentlig synlighet:** En växling för att göra ett formulär offentligt tillgängligt utan att kräva intervjuarautentisering.
- **Webbformulärets URL:** Hämta omedelbart den unika publika länken för att dela webbläsarbaserade datainsamlingsformulär.
- **Åsidosätt inställningar:** En avancerad konfigurationsmodal (nås via kugghjulsikonen) för att anpassa formulärspecifika regler, värden och inaktivera specifika funktioner.
- **Formuläridentifierare:** Visa standardmetadata, inklusive formulärfamiljens namn, familjekod och ett unikt formulär-ID.
- **Geokonfiguration:** Specifika kartor eller geopunkt-konfigurationer kopplade till formulärstrukturen.
- **Lås formulär:** Funktion för att låsa inlämningsåtkomst för att slutföra datainsamlingsfasen.

## Formuläråtgärder och navigering

Den övre kontrollpanelen underlättar batchoperationer och alternativa formulärvyer:

- **Åtgärd till enhet:** Ett kraftfullt rullgardinsmenyverktyg som gör det möjligt för projektledare att tilldela uppgifter, skicka riktade formulär eller skicka åtgärder direkt till specifika intervjuares fältenheter.
- **XLSX-formulärflik:** Navigera snabbt från det huvudsakliga hanteringsrutnätet till uppladdningsmiljöer för hantering av nya inbyggda XLSForm-filer.
- **Form Builder-flik:** Öppna det inbyggda verktyget för att visuellt konstruera eller modifiera formulär dynamiskt utan att använda extern kalkylbladsprogramvara.

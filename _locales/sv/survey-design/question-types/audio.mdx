Frågtypen `audio` gör det möjligt för respondenter att **spela in ljud** eller ladda upp en befintlig ljudfil som en del av deras undersökningssvar. Det är användbart för att fånga muntliga berättelser, miljöljud, vittnesmål eller information som förmedlas bättre genom röst än text.

## Grundläggande XLSForm-specifikation

| type  | name        | label                              |
|-------|-------------|-------------------------------------|
| audio | voice_note  | Vänligen spela in dina kommentarer  |

För mer detaljer om standardfrågtypen audio, se [XLSForm-specifikationen](https://xlsform.org/en/#question-types).

## Användningsområden

Ljudfrågor används vanligtvis för:

1. Fånga öppna muntliga svar för att minska räknarens skrivbörda
2. Spela in vittnesmål, personliga berättelser eller muntliga historier
3. Dokumentera miljöljud (t.ex. bullernivåer nära infrastruktur)
4. Samla in röstprover för lingvistisk eller medicinsk forskning
5. Tillåta respondenter att lägga till muntliga förtydliganden till numeriska eller urvalssvar

## Dataformat

Ljudfiler lagras som binära bilagor tillsammans med formulärsinlämningen, vanligtvis:

- **Format:** MP3 eller AAC (mobil inspelning); WAV (högkvalitetsinspelning)
- **Namngivning:** `{instanceID}-{fieldname}.mp3` (eller motsvarande)
- **Lagring:** Uppladdas till serverns mediamapp och länkas till inlämningsposten
- **Åtkomst:** Spelbar och nedladdningsbar från inlämningshanteringsgränssnittet

## rtSurvey-tillägg

### Maximal varaktighet

Använd kolumnen `parameters` för att begränsa inspelningslängden:

| type | name | label | parameters |
|------|------|-------|------------|
| audio | interview | Spela in intervjun | `max-duration=120` |

`max-duration` anges i sekunder. Inspelaren stannar automatiskt vid gränsen.

### Kvalitetsinställningar

Inspelningskvaliteten kan ställas in via `parameters`:

| type | name | label | parameters |
|------|------|-------|------------|
| audio | feedback | Spela in återkoppling | `quality=normal` |

Stödda värden: `low`, `normal` (standard), `voice-only`. `voice-only` optimerar för talljud med brusreducering.

### Uppspelning innan inlämning

På mobil kan räknaren spela upp det inspelade klippet innan de fortsätter. Detta är aktiverat som standard.

### Integration med nativ inspelning

På Android och iOS startar `audio` enhetens inbyggda inspelningsapp. På webben används webbläsarens inbyggda MediaRecorder API.

## Exempelanvändning

### Med maximal varaktighet och tips

| type | name | label | hint | parameters |
|------|------|-------|------|------------|
| audio | story | Berätta om incidenten med egna ord | Tala tydligt. Inspelningen stannar efter 3 minuter. | `max-duration=180` |

### Villkorligt ljud — bara om ett problem rapporterades

| type | name | label | relevant | required |
|------|------|-------|----------|----------|
| select_one yesno | issue_found | Hittades ett problem? | | |
| audio | issue_audio | Spela in en beskrivning av problemet | `${issue_found} = 'yes'` | `${issue_found} = 'yes'` |

## Bästa praxis

1. Ange tydligt i `label` eller `hint` vad räknaren ska säga och hur länge.
2. Använd `max-duration` för att förhindra alltför stora filer i områden med låg uppladdningshastighet.
3. Informera respondenter innan inspelningen startar — oväntad inspelning kan väcka integritetsfrågor.
4. Testa inspelning på målenheten och nätverksförhållandena innan driftsättning.
5. Ange `quality=voice-only` för intervjustilade inspelningar för att minska filstorleken utan att förlora förståelighet.

## Begränsningar

- Ljudfiler kan vara stora (en 2-minuters inspelning i normal kvalitet är ca 2–4 MB).
- Inte alla webbläsare stöder MediaRecorder API — Chrome och Firefox fungerar tillförlitligt.
- Transkribering av ljudsvar kräver ytterligare efterbearbetning.
- Integritetslagar kan begränsa röstinspelning — verifiera lokala dataskyddskrav.

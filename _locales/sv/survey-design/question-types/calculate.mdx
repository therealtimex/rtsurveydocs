Frågetypen `calculate` kör en formel tyst i bakgrunden. Den lagrar resultatet i ett namngivet fält som andra frågor kan referera till — men den visar ingen inmatning eller etikett för intervjuaren. Använd den för att härleda värden, sammanfoga strängar, köra villkorlig logik eller slå upp data som du behöver senare i formuläret.

---

## Grundläggande syntax

| type | name | label | calculation |
|------|------|-------|-------------|
| calculate | total | | `${price} * ${quantity}` |

- **type**: Alltid `calculate`.
- **name**: Ett unikt fältnamn. Andra frågor refererar till detta med `${name}`.
- **label**: Lämna tomt — calculate-fält visas aldrig för intervjuaren.
- **calculation**: Formeln som ska utvärderas. Stöder alla [XLSForm-funktioner](../operators-and-functions/functions) och fältreferenser.

---

## Vanliga mönster

### Aritmetik

| type | name | label | calculation |
|------|------|-------|-------------|
| integer | price | Unit price | |
| integer | quantity | Quantity | |
| calculate | total | | `${price} * ${quantity}` |
| note | total_note | Total: `${total}` | |

### Sammanfogning av strängar (String concatenation)

| type | name | label | calculation |
|------|------|-------|-------------|
| text | first_name | First name | |
| text | last_name | Last name | |
| calculate | full_name | | `concat(${first_name}, ' ', ${last_name})` |

### Villkorligt värde

| type | name | label | calculation |
|------|------|-------|-------------|
| integer | score | Score (0–100) | |
| calculate | grade | | `if(${score} >= 90, 'A', if(${score} >= 75, 'B', if(${score} >= 60, 'C', 'F')))` |

### Ålder från födelsedatum

| type | name | label | calculation |
|------|------|-------|-------------|
| date | dob | Date of birth | |
| calculate | age_years | | `int((today() - ${dob}) div 365.25)` |

## Använda `once()` för att låsa värdet

Som standard omvärderas `calculate` närhelst ett refererat fält ändras. Inneslut formeln i `once()` för att utvärdera endast vid första laddningen och låsa resultatet:

| type | name | label | calculation |
|------|------|-------|-------------|
| calculate | interview_start | | `once(now())` |

Använd `once()` för tidsstämplar, initialvärden eller i alla fall där omberäkning vid ändring är oönskad.

## Hämta data från externa källor

### Från en CSV-fil

```
pulldata('staff.csv', 'department', 'name', ${staff_id})
```

Se [pulldata()](../operators-and-functions/pulldata) för den fullständiga referensen.

### Från en medföljande SQLite-databas

```
pulldata('rawquery',
  concat(${family_path}, '/locations.db::provinces'),
  'SELECT name FROM provinces WHERE id = ?',
  ${province_id})
```

Se [Lokal databassökning](../advanced-features/local-database-search) för detaljer om sökvägskonstruktion.

### Från app-kontext

```
pulldata('app-api', 'user.username')
pulldata('app-api', 'family_path')
```

Se [App API](../app-api) för alla tillgängliga nycklar.

## Använda calculate i relevant och constraint

Andra fält kan referera till ett `calculate`-resultat precis som vilket fält som helst:

| type | name | label | relevant | constraint |
|------|------|-------|----------|------------|
| calculate | bmi | | | `${weight} div (${height} * ${height}) * 10000` |
| note | bmi_warning | BMI is very high — please verify weight and height. | `${bmi} > 40` | |

## Bästa praxis

1. Ge calculate-fält meningsfulla namn — `total_cost` är tydligare än `calc1` och lättare att spåra i exporter.
2. Dela upp komplexa formler i flera länkade calculate-fält istället för ett djupt nästlat uttryck.
3. Använd `once()` för tidsstämplar och initiala snapshots för att förhindra att värden ändras efter första insamlingen.
4. Placera `calculate`-fält före den första frågan som refererar till dem — utvärderingsordningen följer formulärets ordning.
5. Håll kolumnen `label` tom. Vissa verktyg visar etiketten; att lämna den blank undviker förvirrande utdata.

## Begränsningar

- Calculate-fält visas aldrig direkt för intervjuaren — använd ett `note`-fält för att visa resultatet.
- Kolumnen `calculation` är obligatorisk; en `calculate`-rad utan formel lagrar alltid en tom sträng.
- Resultaten omvärderas vid varje formulärändring om de inte är inneslutna i `once()` — mycket komplexa formler i stora formulär kan påverka renderingsprestandan på enheter med lägre prestanda.
- Beräknade värden lagras som strängar i inskickningen. Använd `number()`, `int()` eller `boolean()` för att typkonvertera när du skickar resultatet till aritmetiska uttryck eller logiska uttryck.

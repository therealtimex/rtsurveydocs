Den här sidan täcker avancerade mönster för att arbeta med upprepningsgrupper (repeats) i rtSurvey. För grunderna i hur man ställer in en upprepningsgrupp, se [Gruppering och upprepningar](../repeats).

---

## Dynamiskt antal upprepningar

Som standard bestämmer intervjuaren hur många gånger en grupp ska upprepas. Du kan fixera antalet upprepningar med `repeat_count`:

| type | name | label | repeat_count |
|------|------|-------|--------------|
| begin_repeat | household_members | Hushållsmedlem | `${num_members}` |
| text | member_name | Medlemmens namn | |
| integer | member_age | Ålder | |
| end_repeat | | | |

Upprepningen körs exakt `${num_members}` gånger, där `num_members` samlades in tidigare i formuläret. Intervjuaren kan inte lägga till eller ta bort instanser.

---

## Indexerad åtkomst: `indexed-repeat()`

Kom åt ett fältvärde för en specifik upprepningsinstans **utanför** upprepningsgruppen med `indexed-repeat(repeatedField, repeatGroup, index)`:

| type | name | label | calculation |
|------|------|-------|-------------|
| calculate | first_name | | `indexed-repeat(${member_name}, ${household_members}, 1)` |
| calculate | second_name | | `indexed-repeat(${member_name}, ${household_members}, 2)` |

Detta är användbart för att bygga sammanfattningsfält eller referera till data för den "primära" medlemmen efter upprepningen.

---

## Aktuell instansposition: `index()`

Inuti en upprepningsgrupp returnerar `index()` den 1-baserade positionen för den aktuella instansen. Använd den för att märka varje upprepning eller skapa unika identifierare:

| type | name | label |
|------|------|-------|
| begin_repeat | plots | Tomt |
| note | plot_label | Tomt nummer `${index()}` |
| text | plot_id | Tomt-ID |
| end_repeat | | |

---

## Referera till fält i samma instans

Inuti en upprepning, använd `${fieldname}` för att referera till ett annat fält **i samma upprepningsinstans**. Det finns inget behov av `indexed-repeat()` inuti samma loop:

| type | name | label | relevant |
|------|------|-------|----------|
| begin_repeat | members | Medlem | |
| text | member_name | Namn | |
| integer | member_age | Ålder | |
| text | school_name | Skolans namn | `${member_age} < 18` |
| end_repeat | | | |

---

## Referera till föräldrafält inifrån en upprepning

Fält utanför (ovanför) upprepningsgruppen kan refereras normalt med `${fieldname}`:

| type | name | label |
|------|------|-------|
| text | village | Byns namn |
| begin_repeat | plots | Jordbrukslott |
| note | plot_context | Lotter i `${village}` |
| end_repeat | | |

## Sammanfatta upprepningsdata

Använd aggregationsfunktioner för upprepningar **utanför** upprepningsgruppen för att sammanfatta:

| Function | Example | Description |
|----------|---------|-------------|
| `count(group)` | `count(${household_members})` | Antal instanser |
| `sum(field)` | `sum(${loan_amount})` | Summa av ett numeriskt fält |
| `min(field)` | `min(${member_age})` | Minsta värde |
| `max(field)` | `max(${member_age})` | Största värde |
| `join(sep, field)` | `join(', ', ${member_name})` | Kommaseparerad lista |
| `count-if(group, expr)` | `count-if(${members}, ${member_age} < 18)` | Villkorligt antal |
| `sum-if(field, expr)` | `sum-if(${loan_amount}, ${loan_amount} > 500)` | Villkorlig summa |
| `join-if(sep, field, expr)` | `join-if(', ', ${name}, ${age} >= 18)` | Villkorlig sammanfogning |

### Exempel: Hushållssammanfattning

| type | name | label | calculation |
|------|------|-------|-------------|
| integer | num_members | Hur många medlemmar? | |
| begin_repeat | members | Medlem | `${num_members}` |
| text | member_name | Namn | |
| integer | member_age | Ålder | |
| end_repeat | | | |
| calculate | total_members | | `count(${members})` |
| calculate | children_count | | `count-if(${members}, ${member_age} < 18)` |
| calculate | adult_names | | `join-if(', ', ${member_name}, ${member_age} >= 18)` |
| note | summary | `${total_members}` medlemmar; `${children_count}` under 18 år. Vuxna: `${adult_names}` | |

## Nästlade upprepningar

En upprepningsgrupp kan innehålla en annan upprepningsgrupp. Använd detta försiktigt — nästlade upprepningar ökar komplexiteten och kan vara förvirrande för intervjuare.

| type | name | label |
|------|------|-------|
| begin_repeat | households | Hushåll |
| text | hh_id | Hushålls-ID |
| begin_repeat | hh_members | Medlem |
| text | member_name | Medlemmens namn |
| end_repeat | | |
| end_repeat | | |

För att referera till ett fält i en yttre upprepning från den inre upprepningen, använd `${fieldname}` — det letar upp den närmaste matchande föräldern:

Inuti `hh_members`-upprepningen returnerar `${hh_id}` ID:t för det **aktuella** hushållet, inte alla hushåll.

## Rankning inuti upprepningsgrupper: `rank-index()`

När ett `rank`-fält finns inuti en upprepning, använd `rank-index(instanceNumber, repeatedField)` från utsidan för att få ordningsrankningen för en specifik instans:

| type | name | label | calculation |
|------|------|-------|-------------|
| calculate | top_scorer | | `rank-index(1, ${score})` |

`rank-index(1, ${score})` returnerar instansindexet för det högsta resultatet.

## `1screen`-utseende på `begin_repeat`

Genom att lägga till `1screen` i kolumnen `appearance` för en `begin_repeat`-rad visas alla frågor för varje instans tillsammans på en enda skärm, istället för en fråga per skärm.

| type | name | label | appearance |
|------|------|-------|------------|
| begin_repeat | household_members | Hushållsmedlem | `1screen` |
| text | member_name | Medlemmens namn | |
| integer | member_age | Ålder | |
| end_repeat | | | |

När `1screen` är inställt och det inte finns något `repeat_count`-fält och inget `add_repeat`-fält inuti gruppen, renderar rtSurvey automatiskt en cirkulär **+**-knapp längst ner på skärmen så att intervjuare kan lägga till nya instanser utan extra konfiguration.

| Appearance | En skärm per instans | Standard-+-knapp tillagd |
|------------|----------------------|--------------------------|
| `1screen` | Ja | Ja (när inget `add_repeat`-barn finns) |
| `field-list` | Ja | Nej |

Använd `field-list` när du vill ha den grupperade layouten utan den automatiska lägg till-knappen. Använd `1screen` när du vill ha både den grupperade layouten och ett inbyggt sätt att lägga till instanser.

---

## `add_repeat` anpassad lägg till-knapp

Ett `note`- (eller `text`-) fält placerat **inuti** upprepningsgruppen med `appearance: add_repeat` renderas som en "Lägg till"-knapp i full bredd. Knappens etikett kommer från fältets `label`-kolumn. När ett `add_repeat`-fält finns, undertrycks den runda standard-+-knappen (från `1screen`).

Placera `add_repeat`-fältet som det sista fältet inuti upprepningsgruppen:

| type | name | label | appearance |
|------|------|-------|------------|
| begin_repeat | members | Medlem | `1screen` |
| text | member_name | Medlemmens namn | |
| integer | member_age | Ålder | |
| note | btn_add | + Lägg till medlem | `add_repeat` |
| end_repeat | | | |

### Färgjustering

Ange en färgkod inuti utseendevärdet (appearance) för att styla knappen:

| Appearance value | Result |
|------------------|--------|
| `add_repeat <#04B404/>` | Grön bakgrund, standardfärg på text |
| `add_repeat 04B404-ffffff` | Grön bakgrund, vit text |

Den första färgen är bakgrunden och den andra (efter bindestrecket) är textfärgen. Uteslut `#` när du använder den bindestrecksseparerade formen.

### Ikonvariant

Använd `add_repeat icon` (med ett mellanslag) för att rendera en kompakt cirkulär ikonknapp istället för knappen i full bredd:

| type | name | label | appearance |
|------|------|-------|------------|
| note | btn_add | + Lägg till | `add_repeat icon` |

## Radera-knappar: `delete-repeat-current` och `delete-repeat-last`

Ett `note`-fält inuti upprepningsgruppen med `appearance: delete-repeat-current` eller `appearance: delete-repeat-last` renderas som en delad radera-knapp.

| Appearance | Action |
|------------|--------|
| `delete-repeat-current` | Raderar den aktuella (aktiva) instansen |
| `delete-repeat-last` | Raderar den sista instansen i upprepningen |

Standardknappen (utan ikon) är en delad knapp: en papperskorgsikon till vänster och fältets etiketttext till höger, som sträcker sig över hela skärmens bredd.

### Ikonvariant

Lägg till `-icon` för att få en kompakt cirkulär papperskorgsikonknapp:

| Appearance | Result |
|------------|--------|
| `delete-repeat-current-icon` | Cirkulär papperskorgsikon, raderar aktuell instans |
| `delete-repeat-last-icon` | Cirkulär papperskorgsikon, raderar sista instansen |

### Färgjustering

Färgformatet är identiskt med `add_repeat`: använd `<#RRGGBB/>` eller `RRGGBB-RRGGBB` (bakgrund-text).

### Exempel på fullständigt mönster

Följande upprepning använder `1screen`, en cirkulär delete-current-knapp längst upp och en lägg till-knapp i full bredd längst ner:

| type | name | label | appearance |
|------|------|-------|------------|
| begin_repeat | members | Medlem | `1screen` |
| note | btn_del | Ta bort | `delete-repeat-current-icon` |
| text | member_name | Medlemmens namn | |
| integer | member_age | Ålder | |
| note | btn_add | + Lägg till medlem | `add_repeat` |
| end_repeat | | | |

## Bästa praxis

1. Använd alltid `repeat_count` när antalet upprepningar är känt i förväg — det förhindrar att intervjuare av misstag lägger till eller tar bort instanser.
2. Håll upprepningsgrupper fokuserade — en upprepning med 20+ frågor per instans är svår att navigera i.
3. Namnge upprepningsgrupper tydligt (t.ex. `household_members`, inte `repeat1`) — namnet visas i funktionsanrop och exporterad data.
4. Testa med det maximala förväntade antalet instanser för att verifiera prestanda.
5. Använd `1screen` på `begin_repeat` för att visa alla frågor på en skärm per instans, parat med ett `add_repeat`-anteckningsfält inuti gruppen för att ge intervjuare en tydligt märkt "Lägg till"-knapp.

---

## Begränsningar

- `indexed-repeat()` kräver ett giltigt index (1 till antal instanser) — index utanför intervallet returnerar tomt.
- Nästlade upprepningar bortom 2 nivåer rekommenderas inte och kan orsaka visningsproblem på vissa klienter.
- Aggregationsfunktioner (`sum`, `count`, etc.) fungerar på hela upprepningsgruppen — du kan inte aggregera en delmängd av instanser utan `*-if`-varianter.

import { Callout, Steps } from 'nextra/components'

Използвайте това ръководство, ако искате да стартирате rtSurvey на собствения си сървър (VPS, bare metal или локална машина), използвайки публичния Docker образ `rtawebteam/rtcloud:survey-public`.

**Не е необходим Docker Hub вход** — образът е публичен.

Контейнерът включва всичко в един образ:
- Apache + PHP (сървър на приложения)
- Shiny Server (аналитични табла, порт 3838)
- Beanstalkd (опашка за фонови задачи)

---

## Изисквания

### Сървър

| Ресурс | Минимум | Препоръчителен |
|----------|---------|-------------|
| RAM | 4 GB | 8 GB |
| Диск | 50 GB | 100 GB SSD |
| CPU | 2 vCPUs | 4 vCPUs |
| ОС | Ubuntu 22.04 LTS | Ubuntu 22.04 LTS |

### Софтуер

- **Docker Engine 24.0+** — [ръководство за инсталация](https://docs.docker.com/engine/install/ubuntu/)
- **Docker Compose v2.0+** — включен с Docker Desktop; на Linux: `apt install docker-compose-plugin`

## Настройка

<Steps>

### Създайте работна директория

```bash
mkdir -p /opt/rtsurvey && cd /opt/rtsurvey
```

### Създайте `docker-compose.yml`

```yaml
services:
  mysql:
    image: mysql:8.0
    container_name: rtsurvey-mysql
    restart: unless-stopped
    command: >
      --default-authentication-plugin=mysql_native_password
      --character-set-server=utf8
      --collation-server=utf8_unicode_ci
      --sql-mode=NO_ENGINE_SUBSTITUTION
    environment:
      MYSQL_ROOT_PASSWORD: ${MYSQL_ROOT_PASSWORD}
      MYSQL_DATABASE: ${MYSQL_DATABASE:-smartsurvey}
      MYSQL_USER: ${MYSQL_USER:-smartsurvey}
      MYSQL_PASSWORD: ${MYSQL_PASSWORD}
      MYSQL_ROOT_HOST: '%'
    volumes:
      - mysql_data:/var/lib/mysql
    networks:
      - rtsurvey-net
    healthcheck:
      test: ["CMD-SHELL", "mysqladmin ping -h localhost -u root -p$$MYSQL_ROOT_PASSWORD"]
      interval: 10s
      timeout: 5s
      retries: 5
      start_period: 30s

  rtsurvey:
    image: rtawebteam/rtcloud:survey-public
    container_name: rtsurvey-app
    restart: unless-stopped
    entrypoint: ["/bin/entrypoint-production.sh"]
    depends_on:
      mysql:
        condition: service_healthy
    ports:
      - "${APP_PORT:-8080}:80"
      - "${SHINY_PORT:-3838}:3838"
    env_file:
      - .env
    volumes:
      - app_uploads:/var/www/html/smartsurvey/uploads
      - app_audios:/var/www/html/smartsurvey/audios
      - app_downloads:/var/www/html/smartsurvey/downloads
      - app_gallery:/var/www/html/smartsurvey/gallery
      - app_tmp:/var/www/html/smartsurvey/tmp
      - app_cache:/var/www/html/smartsurvey/cache
      - app_runtime:/var/www/html/smartsurvey/protected/runtime
      - app_assets:/var/www/html/smartsurvey/assets
      - app_aggregate:/var/www/html/smartsurvey/aggregate
    networks:
      - rtsurvey-net
    healthcheck:
      test: ["CMD", "curl", "-f", "http://localhost/health"]
      interval: 30s
      timeout: 10s
      retries: 3
      start_period: 90s

  # По избор: Вграден Keycloak SSO
  # Стартирайте с: docker compose --profile embed-keycloak up -d
  keycloak:
    image: quay.io/keycloak/keycloak:latest
    container_name: rtsurvey-keycloak
    restart: unless-stopped
    profiles:
      - embed-keycloak
    command: start --import-realm
    environment:
      KEYCLOAK_ADMIN: ${KEYCLOAK_ADMIN_USER:-admin}
      KEYCLOAK_ADMIN_PASSWORD: ${KEYCLOAK_ADMIN_PASSWORD}
      KC_HTTP_ENABLED: "true"
      KC_HTTP_RELATIVE_PATH: /auth
      KC_PROXY_HEADERS: xforwarded
      KC_HOSTNAME: ${KC_HOSTNAME}
      KC_HOSTNAME_STRICT: "false"
      KC_DB: mysql
      KC_DB_URL_DATABASE: ${KEYCLOAK_DB:-keycloak}
      KC_DB_URL_HOST: mysql
      KC_DB_USERNAME: ${KEYCLOAK_DB_USER:-keycloak}
      KC_DB_PASSWORD: ${KEYCLOAK_DB_PASSWORD}
    volumes:
      - ./keycloak-import:/opt/keycloak/data/import
    ports:
      - "${KEYCLOAK_PORT:-8091}:8080"
    depends_on:
      mysql:
        condition: service_healthy
    networks:
      - rtsurvey-net
    healthcheck:
      test: ["CMD-SHELL", "curl -f http://localhost:9000/health/ready || exit 1"]
      interval: 30s
      timeout: 10s
      retries: 10
      start_period: 120s

volumes:
  mysql_data:
  app_uploads:
  app_audios:
  app_downloads:
  app_gallery:
  app_tmp:
  app_cache:
  app_runtime:
  app_assets:
  app_aggregate:

networks:
  rtsurvey-net:
    driver: bridge
```

### Създайте `.env`

```bash
# Проект
PROJECT_ID=mysurvey
PROJECT_TYPE=rtsurvey
PROJECT_URL=your-server-ip-or-domain
HTTP_PROTOCOL=http
TZ=UTC

# База данни
MYSQL_HOST=mysql
MYSQL_DATABASE=smartsurvey
MYSQL_USER=smartsurvey
MYSQL_ROOT_PASSWORD=change-this-root-password
MYSQL_PASSWORD=change-this-app-password

# Администратор (задайте преди първото стартиране — не може да се промени чрез env след създаване на БД)
ADMIN_PASSWORD=change-this-admin-password

# Среда на изпълнение
RUN_ENV=prod
RUN_MODE=admin
GII_ENABLED=false
CSRF_VALIDATION_ENABLED=true

# Портове (по избор — показани са стойностите по подразбиране)
APP_PORT=8080
SHINY_PORT=3838
```

<Callout type="warning">
Променете `MYSQL_ROOT_PASSWORD` и `MYSQL_PASSWORD` преди стартиране. Използвайте силни произволни низове (32+ знака) в продукция.
</Callout>

### Стартирайте стека

```bash
docker compose up -d
```

Първото стартиране отнема около 60–90 секунди — MySQL инициализира базата данни при първото стартиране.

### Проверете

```bash
# Проверете дали всички контейнери работят
docker compose ps

# Проверете здравето на приложението
curl http://localhost:8080/health
```

</Steps>

## Първи вход

След като провет на здравето премине, отворете браузъра:

```
http://your-server:8080/cpms/cpmsSite/login
```

| Поле | Стойност |
|-------|-------|
| Потребителско име | `admin` |
| Парола | стойността на `ADMIN_PASSWORD` във вашия `.env` (по подразбиране `admin`) |

<Callout type="warning">
Задайте `ADMIN_PASSWORD` в `.env` преди първото стартиране. Входната точка го задава при първото стартиране — промяната му след инициализиране на базата данни няма ефект.
</Callout>

## Променливи на средата

### Изисквани от контейнера на приложението

Входната точка ще откаже стартиране, ако някоя от тях липсва:

| Променлива | Описание |
|----------|-------------|
| `PROJECT_ID` | Уникален идентификатор за тази инстанция (буквено-цифров, без интервали) |
| `PROJECT_URL` | Домейн или IP, където се достъпва приложението (без префикс `http://`) |
| `MYSQL_HOST` | MySQL хостнейм — използвайте Docker service name (напр. `mysql`) |
| `MYSQL_DATABASE` | Име на базата данни |
| `MYSQL_PASSWORD` | Парола на потребителя на базата данни |

### Изисквани от MySQL контейнера

| Променлива | Описание |
|----------|-------------|
| `MYSQL_ROOT_PASSWORD` | MySQL root парола (използва се от контейнера `mysql`, не от приложението) |

### Препоръчителни

| Променлива | По подразбиране | Описание |
|----------|---------|-------------|
| `MYSQL_USER` | `smartsurvey` | Потребителско име на базата данни |
| `ADMIN_PASSWORD` | `admin` | Начална администраторска парола — **задайте преди първото стартиране**, не може да се промени чрез env след създаване на БД |
| `HTTP_PROTOCOL` | `https` | Задайте на `http`, ако не използвате SSL |
| `PROJECT_PORT` | `80` | Външен порт, към който потребителите се свързват (не вътрешния Docker порт) |
| `PROJECT_TYPE` | `rtwork` | Тип платформа — използвайте `rtsurvey` за survey платформата |
| `TZ` | `UTC` | Часова зона (напр. `Asia/Bangkok`, `America/New_York`) |

### Среда на изпълнение

| Променлива | По подразбиране | Описание |
|----------|---------|-------------|
| `RUN_ENV` | `prod` | Режим на средата (`prod` или `dev`) |
| `RUN_MODE` | `admin` | Роля на услугата — използвайте `admin` за настройка с един сървър |
| `GII_ENABLED` | `false` | Оставете `false` в продукция (Yii генератор на код) |
| `CSRF_VALIDATION_ENABLED` | `true` | CSRF защита — оставете `true` |

### Лиценз

| Променлива | По подразбиране | Описание |
|----------|---------|-------------|
| `REQUIRE_LICENSE` | `false` | Задайте на `true` за налагане на валидиране на лиценза |
| `RTCLOUD_LICENSE_KEY` | — | Вашият лицензен ключ — изисква се когато `REQUIRE_LICENSE=true` |

## Запазване на данни

Всички потребителски данни се съхраняват в именувани Docker томове. Те оцеляват при рестартиране на контейнери и актуализации на образи.

| Том | Съдържание |
|--------|----------|
| `mysql_data` | База данни (анкети, потребители, отговори) |
| `app_uploads` | Качени файлове от анкети |
| `app_gallery` | Медийна библиотека |
| `app_downloads` | Генерирани файлове за експорт |
| `app_audios` | Аудио записи |
| `app_runtime` | PHP сесия и кеш файлове |
| `app_aggregate` | Агрегирани аналитични данни |

```bash
docker compose logs -f rtsurvey
```

### Рестартиране на приложението

```bash
docker compose restart rtsurvey
```

```bash
docker compose exec rtsurvey bash
```


## Актуализации

Образът е маркиран с `survey-public`. За актуализиране до последната версия:

```bash
docker compose pull
docker compose up -d
```

## Резервно копие и възстановяване

### Резервно копие на базата данни

```bash
docker compose exec mysql \
  mysqldump -u root -p"${MYSQL_ROOT_PASSWORD}" smartsurvey \
  > backup-$(date +%Y%m%d).sql
```

### Възстановяване на базата данни

```bash
docker compose exec -T mysql \
  mysql -u root -p"${MYSQL_ROOT_PASSWORD}" smartsurvey \
  < backup-20240101.sql
```

### Резервно копие на качени файлове

```bash
docker run --rm \
  -v rtsurvey_app_uploads:/data \
  -v $(pwd):/backup \
  alpine tar czf /backup/uploads-$(date +%Y%m%d).tar.gz -C /data .
```

## Вграден Keycloak (По избор SSO)

Production compose файлът включва опционален Keycloak контейнер за SSO. Той споделя същата MySQL инстанция и се активира чрез Docker Compose профил.

<Callout type="info">
Вграденият Keycloak изисква поне **4 GB RAM**. Той е опционален — пропуснете го, ако не ви трябва SSO.
</Callout>

### Добавете Keycloak променливи към `.env`

```bash
# Keycloak администратор
KEYCLOAK_ADMIN_USER=admin
KEYCLOAK_ADMIN_PASSWORD=change-this-keycloak-password

# База данни на Keycloak (създава се автоматично в споделения MySQL при първото стартиране)
KEYCLOAK_DB=keycloak
KEYCLOAK_DB_USER=keycloak
KEYCLOAK_DB_PASSWORD=change-this-keycloak-db-password

# KC_HOSTNAME: пълният публичен URL на вашия сървър (Keycloak добавя /auth автоматично)
KC_HOSTNAME=http://your-server:8091

# Порт, на който слуша Keycloak (хост)
KEYCLOAK_PORT=8091

# Кажете на rtCloud приложението да се свърже с вградения Keycloak
EMBED_KEYCLOAK=true
KEYCLOAK_URL=http://your-server:8091
KEYCLOAK_REALM=rtsurvey
KEYCLOAK_CLIENT_ID=rtsurvey
KEYCLOAK_CLIENT_SECRET=your-client-secret
```

Услугата `keycloak` вече е включена в `docker-compose.yml` по-горе (под профила `embed-keycloak` — няма да стартира освен ако не използвате `--profile embed-keycloak`).

Създайте директорията за импорт (Keycloak ще стартира без нея, но автоматичното предоставяне на realm няма да работи):

```bash
mkdir -p /opt/rtsurvey/keycloak-import
```

### Стартиране с Keycloak

```bash
docker compose --profile embed-keycloak up -d
```

За стартиране без Keycloak (по подразбиране):

```bash
docker compose up -d
```

### Администраторска конзола на Keycloak

След като е здрав, достъпете административния UI на Keycloak на:

```
http://your-server:8091/auth/admin
```

Влезте с `KEYCLOAK_ADMIN_USER` / `KEYCLOAK_ADMIN_PASSWORD`.

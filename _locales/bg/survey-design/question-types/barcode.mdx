Типът въпрос `barcode` улавя стойността на кода чрез сканиране на QR код или баркод с камерата на устройството. Модалният прозорец на скенера включва и ръчно въвеждане на текст като резервен вариант, когато сканирането не е възможно.

## Basic XLSForm Specification

| type    | name         | label                    |
|---------|--------------|--------------------------|
| barcode | product_code | Scan the product barcode |
| barcode | ticket_id    | Scan the ticket          |

За стандартната спецификация вижте [XLSForm документацията](https://xlsform.org/en/#question-types).

---

## Supported formats

rtSurvey поддържа QR кодове и стандартни 1D баркодове чрез камерата на устройството, включително:

- QR Code
- UPC-A, UPC-E
- EAN-8, EAN-13
- Code 39, Code 128
- ITF, Codabar

---

## Default layout

Когато не е зададено `appearance`, въпросът изобразява бутон с пълна ширина **"GET BARCODE"**. Докосването му отваря модалния прозорец на скенера. След успешно сканиране бутонът се променя на **"REPLACE BARCODE"** и сканираната стойност се появява отдолу като връзка, върху която може да се кликне.

---

## Scanner modal

Модалният прозорец на скенера винаги включва:
- **Изглед от камерата на живо (Live camera view)** — сканира автоматично при откриване; модалният прозорец се затваря след успешно сканиране.
- **Ръчно въвеждане на текст (Manual text input)** — текстово поле в долната част, където анкетьорът може да въведе кода, ако сканирането е неуспешно.
- **Бутон "Готово" (Done button)** — изпраща ръчно въведената стойност.

Когато камерата на устройството не е налична, модалният прозорец преминава към опция **"Upload an image"** — анкетьорът може да изпрати снимка на баркода за декодиране.

## Inline button layout

Добавете `inline`, за да изобразите скенера като **кръгъл бутон с икона** до етикета (label) вместо бутон с пълна ширина.

```
| type    | name | label     | appearance                              |
|---------|------|-----------|----------------------------------------|
| barcode | code | Scan item | inline display{right}                  |
| barcode | code | Scan item | inline display{left, large}            |
| barcode | code | Scan item | inline display{center, large, <0099FF/>} |
```

**Позиция на бутона** — `left`, `right` *(по подразбиране)*, `top`, `center`, `bottom`

**Размер на бутона** — `small` *(по подразбиране)*, `medium`, `large`

**Цвят на бутона** — добавете хексадесетичен цвят в `display{}`, за да презапишете основния цвят:

```
inline display{right, large, <FF5500/>}
```

**Контрол след улавяне — `results{}`:**

| Appearance | Ефект |
|---|---|
| `results{hide(scanner)}` | Скрива бутона за сканиране след улавяне на стойност |
| `results{hide(review)}` | Скрива връзката към сканираната стойност след улавяне |
| `results{hide(value)}` | Скрива показването на текста на сканираната стойност |
| `results{left}` | Премества иконата наляво след улавяне |

Пример — скриване на скенера след първото сканиране:
```
inline display{center, large} results{hide(scanner)}
```

## `inputs{auto-close(N)}` — автоматично затваряне на скенера

Автоматично затваря модалния прозорец на скенера след `N` секунди, ако не бъде открит баркод. В модалния прозорец се показва таймер за обратно отброяване на живо.

```
inputs{auto-close(10)}     → затваря се след 10 секунди
inputs{auto-close(5)}      → затваря се след 5 секунди
```

Комбиниране с inline:
```
inline display{right} inputs{auto-close(10)}
```

---

## `inputs{floating}` — плаващ подвижен скенер

Показва **бутон за минимизиране** (икона за свиване ⊞) в заглавната част на модалния прозорец на скенера. Докосването му свива скенера до малка плаваща кръгла икона, която може да се плъзга навсякъде по екрана. Докосването на плаващата икона отваря скенера отново.

```
inputs{floating}
inline display{right} inputs{floating}
```

Полезно при работни процеси, при които анкетьорът трябва да вижда формата, докато скенерът е активен (напр. сканиране на артикули в списък).

---

## `invisible auto-show` — автоматично отваряне на скенера

Скрива уиджета на въпроса от оформлението, но автоматично отваря скенера при зареждане на страницата. Полезно за вграждане на стъпка на скрито сканиране в потока на формата.

```
invisible auto-show
inline invisible auto-show
```

---

## В групи с повторение (In repeat groups)

Когато `barcode` е в група `begin repeat`, успешното сканиране автоматично преминава към **следващия екземпляр на повторение**, след като стойността бъде записана. Това позволява бързо последователно сканиране, без анкетьорът да докосва "Добавяне" (Add) между артикулите.

---

## Потискане на етикета (Suppress the label)

```
inline text-nolabel display{center, large}
```

## Най-добри практики

1. Използвайте `inputs{auto-close(N)}`, за да предотвратите безкрайното отваряне на скенера — изберете стойност, която дава на анкетьорите достатъчно време да позиционират баркода (обикновено 8–15 секунди).
2. Използвайте `inputs{floating}`, когато формата трябва да остане видима по време на сканиране (напр. сканиране от списък, където анкетьорът прави справка с видимо поле).
3. Поставете въпроса за баркод в група с повторение за бързо последователно сканиране — автоматичното преминаване към следващото повторение елиминира ръчната стъпка "Добавяне".
4. Винаги включвайте колоната `hint` с инструкции за позициониране (напр. "Дръжте баркода на разстояние 10–30 см от камерата, при добра светлина").
5. Ръчното въвеждане на текст в модалния прозорец на скенера е винаги налично — обучете анкетьорите да го използват като резервен вариант при повредени или замърсени баркодове.

## Ограничения

- Точността на сканиране зависи от качеството на камерата, осветлението и състоянието на баркода — повредени или кодове с нисък контраст може да не се сканират надеждно.
- Скенерът използва задната камера (обърната към околната среда); устройства без задна камера преминават към опцията за качване на изображение.
- `invisible auto-show` се отваря само при първото зареждане на страницата; навигацията обратно към страницата не задейства повторно автоматичното отваряне.

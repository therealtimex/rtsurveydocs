title: "Баркод"

---

Типът въпрос `barcode` улавя стойност на код чрез сканиране на QR код или баркод с камерата на устройството. Модалният прозорец за скенер също така включва ръчно въвеждане на текст като резервен вариант, когато сканирането не е възможно.

## Основна XLSForm спецификация

| type    | name         | label                    |
|---------|--------------|--------------------------|
| barcode | product_code | Сканирайте баркода на продукта |
| barcode | ticket_id    | Сканирайте билета          |

За стандартната спецификация вижте [XLSForm документацията](https://xlsform.org/en/#question-types).

---

## Поддържани формати

rtSurvey поддържа QR кодове и стандартни 1D баркодове чрез камерата на устройството, включително:

- QR Code
- UPC-A, UPC-E
- EAN-8, EAN-13
- Code 39, Code 128
- ITF, Codabar

---

## Разположение по подразбиране

Без зададен `appearance`, въпросът изобразява бутон **"ВЗЕМИ БАРКОД"** на цялата ширина. Докосването му отваря модалния прозорец на скенера. След успешно сканиране, бутонът се променя на **"ЗАМЕНИ БАРКОД"** и сканираната стойност се появява отдолу като връзка, върху която може да се кликне.

## Модален прозорец на скенера

Модалният прозорец на скенера винаги включва:
- **Изглед на камерата на живо** — сканира автоматично при откриване; модалният прозорец се затваря след успешно сканиране.
- **Ръчно въвеждане на текст** — текстово поле в долната част, където анкетьорът може да въведе кода, ако сканирането е неуспешно.
- **Бутон "Готово"** — изпраща ръчно въведената стойност.

Когато камерата на устройството е недостъпна, модалният прозорец се връща към опцията **"Качи изображение"** — анкетьорът може да изпрати снимка на баркода за декодиране.

## Разположение на вграден бутон

Добавете `inline`, за да изобразите скенера като **кръгъл иконен бутон** до етикета, вместо бутон на цялата ширина.

```
| type    | name | label     | appearance                              |
|---------|------|-----------|----------------------------------------|
| barcode | code | Сканирай артикул | inline display{right}                  |
| barcode | code | Сканирай артикул | inline display{left, large}            |
| barcode | code | Сканирай артикул | inline display{center, large, <0099FF/>} |
```

**Позиция на бутона** — `left`, `right` *(по подразбиране)*, `top`, `center`, `bottom`

**Размер на бутона** — `small` *(по подразбиране)*, `medium`, `large`

**Цвят на бутона** — добавете шестнадесетичен цвят вътре в `display{}` за да промените основния цвят:

```
inline display{right, large, <FF5500/>}
```

**Контрол след заснемане — `results{}`:**

| Appearance | Ефект |
|---|---|
| `results{hide(scanner)}` | Скрива бутона за сканиране, след като стойността е уловена |
| `results{hide(review)}` | Скрива връзката към сканираната стойност след заснемане |
| `results{hide(value)}` | Скрива текстовото показване на сканираната стойност |
| `results{left}` | Премества иконата наляво след заснемане |

Пример — скриване на скенера след първо сканиране:
```
inline display{center, large} results{hide(scanner)}
```

## `inputs{auto-close(N)}` — автоматично затваряне на скенера

Автоматично затваря модалния прозорец на скенера след `N` секунди, ако не бъде открит баркод. В модалния прозорец се показва таймер за обратно броене на живо.

```
inputs{auto-close(10)}     → затваря се след 10 секунди
inputs{auto-close(5)}      → затваря се след 5 секунди
```

Комбинирайте с `inline`:
```
inline display{right} inputs{auto-close(10)}
```

---

## `inputs{floating}` — плаващ подвижен скенер

Показва **бутон за минимизиране** (икона за компресиране ⊞) в заглавната част на модалния прозорец на скенера. Докосването му свива скенера до малка плаваща кръгла икона, която може да бъде плъзгана навсякъде по екрана. Докосването на плаващата икона отново отваря скенера.

```
inputs{floating}
inline display{right} inputs{floating}
```

Полезно в работни процеси, където анкетьорът трябва да вижда формата, докато скенерът е активен (напр. сканиране на елементи в списък).

---

## `invisible auto-show` — автоматично отваряне на скенера

Скрива уиджета на въпроса от оформлението, но автоматично отваря скенера, когато страницата се зареди. Полезно за вграждане на стъпка за безшумно сканиране в потока на формата.

```
invisible auto-show
inline invisible auto-show
```

---

## В повтарящи се групи

Когато `barcode` е вътре в група `begin repeat`, успешното сканиране автоматично преминава към **следващата повтаряща се инстанция**, след като стойността бъде записана. Това позволява бързо последователно сканиране, без анкетьорът да докосва "Добави" между елементите.

## Примери за употреба

### Сканиране на инвентар

| type | name | label | appearance | required |
|------|------|-------|------------|----------|
| barcode | item_code | Сканирай баркод на артикул | `inline display{right}` | yes |
| integer | quantity | Количество | | yes |
| note | confirm | Артикул: `${item_code}` — Кол: `${quantity}` | | |

### Бързо сканиране на много артикули (повтаряща се група)

| type | name | label | appearance |
|------|------|-------|------------|
| begin repeat | items | | |
| barcode | code | Сканирай следващ артикул | `inline display{right} inputs{auto-close(8)}` |
| end repeat | items | | |

### Безшумно автоматично сканиране при зареждане на страницата

| type | name | label | appearance |
|------|------|-------|------------|
| barcode | entry_code | | `invisible auto-show` |

## Най-добри практики

1. Използвайте `inputs{auto-close(N)}`, за да предотвратите безкрайно отваряне на скенера — изберете стойност, която дава достатъчно време на анкетьорите да позиционират баркода (обикновено 8–15 секунди).
2. Използвайте `inputs{floating}`, когато формата трябва да остане видима по време на сканиране (напр. сканиране от списък, където анкетьорът препраща към видимо поле).
3. Поставете въпроса за баркода в повтаряща се група за бързо последователно сканиране — автоматичното преминаване на повторения елиминира ръчната стъпка "Добави".
4. Винаги включвайте колоната `hint` с инструкции за позициониране (напр. "Дръжте баркода на 10–30 см от камерата, при добра светлина").
5. Ръчното въвеждане на текст в модалния прозорец на скенера винаги е налично — обучете анкетьорите да го използват като резервен вариант за повредени или замърсени баркодове.

## Ограничения

- Точността на сканиране зависи от качеството на камерата, осветлението и състоянието на баркода — повредени или нискоконтрастни кодове може да не се сканират надеждно.
- Скенерът използва задната (обърната към околната среда) камера; устройства без задна камера се връщат към опцията за качване на изображение.
- `invisible auto-show` се отваря само при първо зареждане на страницата; навигирането обратно към страницата не задейства повторно автоматичното отваряне.

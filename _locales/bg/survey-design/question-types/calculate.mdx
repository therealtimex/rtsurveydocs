Типът въпрос `calculate` изпълнява формула тихомълком във фонов режим. Той съхранява резултата в именовано поле, към което други въпроси могат да се реферират — но не показва вход или етикет на анкетьора. Използвайте го за извеждане на стойности, конкатениране на низове, изпълнение на условна логика или търсене на данни, които ще ви трябват по-късно във формата.

---

## Основен синтаксис

| type | name | label | calculation |
|------|------|-------|-------------|
| calculate | total | | `${price} * ${quantity}` |

- **type**: Винаги `calculate`.
- **name**: Уникално име на поле. Други въпроси се реферират към него с `${name}`.
- **label**: Оставете празно — полетата calculate никога не се показват на анкетьора.
- **calculation**: Формулата за оценяване. Поддържа всички [XLSForm функции](../operators-and-functions/functions) и референции към полета.

---

## Общи модели

### Аритметика

| type | name | label | calculation |
|------|------|-------|-------------|
| integer | price | Unit price | |
| integer | quantity | Quantity | |
| calculate | total | | `${price} * ${quantity}` |
| note | total_note | Total: `${total}` | |

### Конкатенация на низове

| type | name | label | calculation |
|------|------|-------|-------------|
| text | first_name | First name | |
| text | last_name | Last name | |
| calculate | full_name | | `concat(${first_name}, ' ', ${last_name})` |

### Условна стойност

| type | name | label | calculation |
|------|------|-------|-------------|
| integer | score | Score (0–100) | |
| calculate | grade | | `if(${score} >= 90, 'A', if(${score} >= 75, 'B', if(${score} >= 60, 'C', 'F')))` |

### Възраст от дата на раждане

| type | name | label | calculation |
|------|------|-------|-------------|
| date | dob | Date of birth | |
| calculate | age_years | | `int((today() - ${dob}) div 365.25)` |

## Използване на `once()` за заключване на стойността

По подразбиране `calculate` се преоценява винаги, когато някое реферирано поле се промени. Обвийте формулата в `once()`, за да се оцени само при първото зареждане и да се замрази резултатът:

| type | name | label | calculation |
|------|------|-------|-------------|
| calculate | interview_start | | `once(now())` |

Използвайте `once()` за времеви отпечатъци, начални стойности или всеки случай, в който преизчисляването при промяна е нежелателно.

## Извличане на данни от външни източници

### От CSV файл

```
pulldata('staff.csv', 'department', 'name', ${staff_id})
```

Вижте [pulldata()](../operators-and-functions/pulldata) за пълната справка.

### От пакетна SQLite база данни

```
pulldata('rawquery',
  concat(${family_path}, '/locations.db::provinces'),
  'SELECT name FROM provinces WHERE id = ?',
  ${province_id})
```

Вижте [Локално търсене в база данни](../advanced-features/local-database-search) за подробности относно изграждането на пътя.

### От контекста на приложението

```
pulldata('app-api', 'user.username')
pulldata('app-api', 'family_path')
```

Вижте [App API](../app-api) за всички налични ключове.

## Използване на calculate в relevant и constraint

Други полета могат да се реферират към резултат от `calculate` точно както всяко друго поле:

| type | name | label | relevant | constraint |
|------|------|-------|----------|------------|
| calculate | bmi | | | `${weight} div (${height} * ${height}) * 10000` |
| note | bmi_warning | BMI is very high — please verify weight and height. | `${bmi} > 40` | |

## Най-добри практики

1. Дайте на полетата calculate смислени имена — `total_cost` е по-ясно от `calc1` и по-лесно за проследяване при експортиране.
2. Разделете сложните формули на няколко верижни полета calculate, вместо на един дълбоко вложен израз.
3. Използвайте `once()` за времеви отпечатъци и първоначални снимки, за да предотвратите промяната на стойностите след първото заснемане.
4. Поставете полетата `calculate` преди първия въпрос, който се реферира към тях — редът на оценяване следва реда на формата.
5. Оставете колоната `label` празна. Някои инструменти показват етикета; оставянето му празно избягва объркващ изход.

## Ограничения

- Полетата Calculate никога не се показват директно на анкетьора — използвайте поле `note`, за да покажете резултата.
- Колоната `calculation` е задължителна; ред `calculate` без формула винаги съхранява празен низ.
- Резултатите се преоценяват при всяка промяна във формата, освен ако не са обвити в `once()` — много сложни формули в големи форми могат да повлияят на производителността на изобразяване на устройства от нисък клас.
- Изчислените стойности се съхраняват като низове в подаването. Използвайте `number()`, `int()` или `boolean()`, за да конвертирате типа, когато предавате резултата към аритметични или логически изрази.

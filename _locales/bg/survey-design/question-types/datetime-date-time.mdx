---

Типовете въпроси `date`, `time` и `datetime` улавят стойности за дата и/или час. rtSurvey ги изобразява с няколко режима на оформление, контролирани от колоната `appearance`.

## Основна XLSForm спецификация

| type     | name           | label                     |
|----------|----------------|---------------------------|
| date     | birth_date     | Дата на раждане           |
| time     | start_time     | В колко часа започна?     |
| datetime | event_datetime | Кога се случи събитието?  |

За стандартната спецификация вижте [документацията на XLSForm](https://xlsform.org/en/#question-types).

## Режими на оформление

### По подразбиране — винаги отворен календар

Не е необходима стойност за външен вид. Календарът (и часовникът за `time`/`datetime`) се изобразяват директно на страницата — винаги видими, не е необходим бутон.

| type | name       | label            | appearance |
|------|------------|------------------|------------|
| date | start_date | Дата на посещение|            |

---

### `inline` — кръгъл бутон → модален прозорец

Кръгъл бутон с икона (календар или часовник) плава до етикета на въпроса. Докосването му отваря модален прозорец с инструмента за избор. След избор избраната стойност се появява като текст до етикета.

- Фон на бутона: основен цвят на темата (може да се презаписва)
- Форма на бутона: пълен кръг (`border-radius: 50%`)

```
| type | name       | label            | appearance |
|------|------------|------------------|------------|
| date | start_date | Дата на посещение| inline     |
```

---

### `inline-onlyresult` — бутонът изчезва след избор

Същото като `inline`, но бутонът се скрива, след като бъде избрана стойност. Полезно, когато искате само датата да се вижда, след като е била избрана, без постоянен символ.

```
inline-onlyresult
```

---

### `inline-1line` — ред от контролери за превъртане (spinners)

Изобразява индивидуални контролери за превъртане (▲ стойност ▼) в един хоризонтален ред — по една колона за компонент. За `date`: месец / ден / година. За `datetime`: месец / ден / година / часове / минути. За `time`: часове / минути.

Няма модален прозорец или изскачащ календар — потребителят превърта всеки контролер независимо.

```
inline-1line
```

**Показване само на специфични компоненти** чрез добавяне на имената на компонентите:

```
inline-1line month year      → скрива контролера за ден
inline-1line year            → показва само годината
```

**Ограничаване на диапазона на годината:**

```
inline-1line y_range(2000-2030)
```

---

### `box` — въвеждане на текст

Изобразява поле за въвеждане на обикновен текст. Потребителят въвежда датата директно, като използва формата, дефиниран във външния вид.

```
box(%d/%m/%Y)       → DD/MM/YYYY
box(%Y-%m-%d)       → YYYY-MM-DD
```

---

### `month-year` — само месец и година

Стандартен външен вид на XLSForm. Инструментът за избор започва от изглед на година; потребителят избира месец и година, но не и конкретен ден.

```
month-year
```

---

### `year` — само година

Стандартен външен вид на XLSForm. Инструментът за избор започва от изглед на десетилетие; може да се избира само годината.

```
year
```

---

## Персонализиран формат на дисплея

Добавете `-[format]` към всеки `inline` външен вид, за да контролирате как избраната стойност се показва като текст. Използва токени в стил strftime.

| Токен | Значение | Пример |
|-------|---------|---------|
| `%d`  | Ден (с водеща нула) | 07 |
| `%e`  | Ден (без подложка) | 7 |
| `%m`  | Номер на месеца | 04 |
| `%n`  | Номер на месеца (без подложка) | 4 |
| `%b`  | Съкращение на месеца | Apr |
| `%Y`  | 4-цифрена година | 2026 |
| `%y`  | 2-цифрена година | 26 |
| `%H`  | Час (24ч) | 14 |
| `%h`  | Час (без подложка) | 14 |
| `%M`  | Минута | 05 |
| `%S`  | Секунда | 00 |
| `%a`  | Съкращение на името на деня | Wed |

**Примери:**

```
inline-[%d/%m/%Y]            → 07/04/2026
inline-[%d %b %Y]            → 07 Apr 2026
inline-1line-[%Y-%m-%d]      → въвеждане чрез контролер, форматиран дисплей
inline-[%d/%m/%Y %H:%M]      → 07/04/2026 14:30
```

## Персонализиране на цветовете

Презапишете цвета на бутона с иконата, като използвате `colors()`:

```
inline colors("0099FF")                   → фон на бутона #0099FF
inline colors("0099FF","FFFFFF")          → фон #0099FF, цвят на иконата #FFFFFF
inline-1line colors("0000FF","FFFF00")    → акцентни цветове на контролера за превъртане
inline-onlyresult colors("E53935")        → червен бутон
```

---

## Позиция на бутона с `display{}`

Модификаторът `display{}` контролира къде се появява бутонът с иконата спрямо етикета на въпроса. Прилага се за `inline` и `inline-onlyresult`.

```
display{<align>, <size>, <color>}
```

| Параметър | Стойности | По подразбиране |
|-----------|--------|---------|
| Align | `left`, `right`, `top`, `center`, `bottom` | `right` |
| Size | `small`, `medium`, `large` | `small` |
| Color | hex напр. `#FF5500` | основен цвят на темата |

**Поведение при подравняване:**

| Стойност | Оформление |
|-------|--------|
| `right` | Бутон вдясно от етикета |
| `left` | Бутон вляво от етикета |
| `top` | Бутон над етикета, центриран с пълна ширина |
| `center` / `bottom` | Бутон под етикета, центриран с пълна ширина |

**Примери:**

```
inline display{left}
inline display{center, large}
inline display{right, medium, #E53935}
inline-onlyresult display{bottom, large, #0099FF}
```

## Ограничение на диапазона от дати

Използвайте `inputs{range[...]}` за ограничаване на това кои дати могат да бъдат избрани.

```
inputs{range[dateGt(2024-01-01), dateLt(2024-12-31)]}
```

Параметри в рамките на `range[...]`:

| Параметър | Описание |
|-----------|-------------|
| `dateGt(YYYY-MM-DD)` | Минимална избираема дата (по-голяма или равна на) |
| `dateLt(YYYY-MM-DD)` | Максимална избираема дата (по-малка или равна на) |
| `indayTimeGt(HH:MM:SS)` | Минимално време в рамките на деня (само за datetime) |
| `indayTimeLt(HH:MM:SS)` | Максимално време в рамките на деня (само за datetime) |

Могат да бъдат дефинирани множество диапазони — дата е избираема, ако попада в **някой** от диапазоните.

## Скриване на етикета

Добавете `text-nolabel`, за да скриете етикета на въпроса. Бутонът се изобразява самостоятелно.

```
inline text-nolabel display{center, large}
```

## Резюме на оформлението

| Външен вид | Изобразен уиджет | Възможност за персонализиране на цвета |
|---|---|---|
| *(няма)* | Винаги отворен календар | Не |
| `inline` | Кръгъл бутон → модален календар | Да |
| `inline-onlyresult` | Кръгъл бутон → модален, скрива се след избор | Да |
| `inline-1line` | Ред от контролери за превъртане | Да |
| `box(%format%)` | Поле за въвеждане на текст | Не |
| `month-year` | Инструмент за избор на месец/година | Не |
| `year` | Инструмент за избор само на година | Не |

```
| type     | name        | label              | appearance                              |
|----------|-------------|--------------------|-----------------------------------------|
| date     | visit_date  | Дата на посещение  | inline display{right} -[%d/%m/%Y]       |
| date     | birth_date  | Дата на раждане    | inline-1line y_range(1940-2026)         |
| time     | start_time  | Начален час        | inline-1line                            |
| datetime | event_time  | Дата и час на събитието | inline display{center, large} -[%d/%m/%Y %H:%M] |
| date     | report_date | Дата на отчитане   | box(%d/%m/%Y)                           |
```

## Най-добри практики

1. Използвайте `inline` за компактни форми — спестява вертикално пространство в сравнение с винаги отворения календар.
2. Използвайте `inline-1line`, когато респондентите трябва да коригират индивидуални компоненти на датата (напр. година на раждане).
3. Използвайте `box()` само когато имате доверие на анкетьора, че ще въведе датите правилно — не се показва потребителски интерфейс за валидиране.
4. Използвайте `display{center, large}`, за да направите бутона по-виден на мобилни екрани.
5. Винаги посочвайте `-[format]`, когато показването по подразбиране `YYYY-MM-DD` би объркало местните потребители.
6. Внимавайте с часовите зони, когато събирате данни за дата и час в различни региони.

## Ограничения

- `inline-1line` винаги приема днешната дата по подразбиране, ако няма стойност — използвайте колона `default` за предварително попълване на конкретна дата.
- Форматът на `box()` контролира само показването; съхранената стойност винаги е ISO 8601.
- Ограничението на диапазона от дати (`inputs{range[...]}`) не работи с оформлението `box`.
- Разликите в часовите зони могат да усложнят анализа на данните, ако не са правилно отчетени.

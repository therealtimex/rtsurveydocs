---

Типовете въпроси `date`, `time` и `datetime` улавят стойности за дата и/или час. rtSurvey ги изобразява с няколко режима на оформление, контролирани от колоната `appearance`.

## Основна XLSForm спецификация

| type     | name           | label                     |
|----------|----------------|---------------------------|
| date     | birth_date     | Дата на раждане           |
| time     | start_time     | В колко часа започна?     |
| datetime | event_datetime | Кога се случи събитието? |

За стандартната спецификация вижте [XLSForm документацията](https://xlsform.org/en/#question-types).

## Режими на оформление

### По подразбиране — винаги отворен календар

Не е необходима стойност за `appearance`. Календарът (и часовникът за `time`/`datetime`) се изобразява директно на страницата — винаги видим, не е необходим бутон.

| type | name       | label         | appearance |
|------|------------|---------------|------------|
| date | start_date | Дата на посещение |            |

---

### `inline` — кръгъл бутон → модален прозорец

Кръгъл иконен бутон (календар или часовник) се носи до етикета на въпроса. Докосването му отваря модален прозорец с избирача. След избор, избраната стойност се появява като текст до етикета.

- Фон на бутона: основен цвят на темата (може да се променя)
- Форма на бутона: пълен кръг (`border-radius: 50%`)

```
| type | name       | label         | appearance |
|------|------------|---------------|------------|
| date | start_date | Дата на посещение | inline     |
```

---

### `inline-onlyresult` — бутонът изчезва след избор

Същото като `inline`, но бутонът се скрива, след като бъде избрана стойност. Полезно, когато искате само датата да е видима, след като е била избрана, без постоянна икона.

```
inline-onlyresult
```

---

### `inline-1line` — ред от спинъри

Изобразява индивидуални контроли за въртене (▲ стойност ▼) в един хоризонтален ред — една колона на компонент. За `date`: месец / ден / година. За `datetime`: месец / ден / година / часове / минути. За `time`: часове / минути.

Няма модален прозорец или изскачащ календар — потребителят превърта всеки спинър независимо.

```
inline-1line
```

**Показване само на конкретни компоненти** чрез добавяне на имената на компонентите:

```
inline-1line month year      → скрива спинъра за деня
inline-1line year            → показва само годината
```

**Ограничаване на диапазона от години:**

```
inline-1line y_range(2000-2030)
```

---

### `box` — текстово поле за въвеждане

Изобразява обикновено текстово поле за въвеждане. Потребителят въвежда датата директно, използвайки формата, дефиниран във `appearance`.

```
box(%d/%m/%Y)       → DD/MM/YYYY
box(%Y-%m-%d)       → YYYY-MM-DD
```

---

### `month-year` — само месец и година

Стандартен XLSForm `appearance`. Избирачът започва от изглед за година; потребителят избира месец и година, но не конкретен ден.

```
month-year
```

---

### `year` — само година

Стандартен XLSForm `appearance`. Избирачът започва от изглед за десетилетие; избира се само годината.

```
year
```

---

## Персонализиран формат на показване

Добавете `-[format]` към всеки `inline` `appearance`, за да контролирате как избраната стойност се показва като текст. Използва токени в стил `strftime`.

| Token | Значение | Пример |
|-------|---------|---------|
| `%d`  | Ден (с водещи нули) | 07 |
| `%e`  | Ден (без водещи нули) | 7 |
| `%m`  | Номер на месец | 04 |
| `%n`  | Номер на месец (без водещи нули) | 4 |
| `%b`  | Съкращение на месеца | Апр |
| `%Y`  | 4-цифрена година | 2026 |
| `%y`  | 2-цифрена година | 26 |
| `%H`  | Час (24ч) | 14 |
| `%h`  | Час (без водещи нули) | 14 |
| `%M`  | Минута | 05 |
| `%S`  | Секунда | 00 |
| `%a`  | Съкращение на име на ден | Сря |

**Примери:**

```
inline-[%d/%m/%Y]            → 07/04/2026
inline-[%d %b %Y]            → 07 Апр 2026
inline-1line-[%Y-%m-%d]      → въвеждане със спинър, форматирано показване
inline-[%d/%m/%Y %H:%M]      → 07/04/2026 14:30
```

## Персонализиране на цвета

Презапишете цвета на иконния бутон, използвайки `colors()`:

```
inline colors("0099FF")                   → фон на бутона #0099FF
inline colors("0099FF","FFFFFF")          → фон #0099FF, цвят на иконата #FFFFFF
inline-1line colors("0000FF","FFFF00")    → акцентни цветове на спинъра
inline-onlyresult colors("E53935")        → червен бутон
```

---

## Позиция на бутона с `display{}`

Модификаторът `display{}` контролира къде се появява иконният бутон спрямо етикета на въпроса. Прилага се към `inline` и `inline-onlyresult`.

```
display{<align>, <size>, <color>}
```

| Параметър | Стойности | По подразбиране |
|-----------|--------|---------|
| Align | `left`, `right`, `top`, `center`, `bottom` | `right` |
| Size | `small`, `medium`, `large` | `small` |
| Color | hex напр. `#FF5500` | основен цвят на темата |

**Поведение на `Align`:**

| Стойност | Оформление |
|-------|--------|
| `right` | Бутон отдясно на етикета |
| `left` | Бутон отляво на етикета |
| `top` | Бутон над етикета, центриран на цялата ширина |
| `center` / `bottom` | Бутон под етикета, центриран на цялата ширина |

**Примери:**

```
inline display{left}
inline display{center, large}
inline display{right, medium, #E53935}
inline-onlyresult display{bottom, large, #0099FF}
```

## Ограничение на диапазона от дати

Използвайте `inputs{range[...]}` за да ограничите кои дати могат да бъдат избрани.

```
inputs{range[dateGt(2024-01-01), dateLt(2024-12-31)]}
```

Параметри вътре в `range[...]`:

| Параметър | Описание |
|-----------|-------------|
| `dateGt(YYYY-MM-DD)` | Минимална избираема дата (по-голяма или равна) |
| `dateLt(YYYY-MM-DD)` | Максимална избираема дата (по-малка или равна) |
| `indayTimeGt(HH:MM:SS)` | Минимално време в рамките на деня (само за `datetime`) |
| `indayTimeLt(HH:MM:SS)` | Максимално време в рамките на деня (само за `datetime`) |

Могат да бъдат дефинирани множество диапазони — датата е избираема, ако попада в **който и да е** от диапазоните.

## Потискане на етикета

Добавете `text-nolabel`, за да скриете етикета на въпроса. Бутонът се изобразява сам.

```
inline text-nolabel display{center, large}
```

## Обобщение на оформлението

| Appearance | Изобразен уиджет | Възможност за персонализиране на цвета |
|---|---|---|
| *(няма)* | Винаги отворен календар | Не |
| `inline` | Кръгъл бутон → модален календар | Да |
| `inline-onlyresult` | Кръгъл бутон → модален, скрива се след избор | Да |
| `inline-1line` | Ред от спинъри | Да |
| `box(%format%)` | Текстово поле за въвеждане | Не |
| `month-year` | Избирач за месец/година | Не |
| `year` | Избирач само за година | Не |

```
|----------|-------------|--------------------|-----------------------------------------|

```

## Най-добри практики

1. Използвайте `inline` за компактни форми — спестява вертикално пространство в сравнение с винаги отворения календар.
2. Използвайте `inline-1line`, когато анкетираните трябва да коригират отделни компоненти на датата (напр. година на раждане).
3. Използвайте `box()` само когато вярвате на анкетьора, че ще въведе дати правилно — не се показва потребителски интерфейс за валидиране.
4. Използвайте `display{center, large}`, за да направите бутона по-виден на мобилни екрани.
5. Винаги указвайте `-[format]`, когато стандартният дисплей `YYYY-MM-DD` би объркал местните потребители.
6. Внимавайте за часовите зони, когато събирате данни за дата и час в различни региони.

## Ограничения

- `inline-1line` винаги по подразбиране е днешна дата, ако няма стойност — използвайте колона `default` за предварително попълване на конкретна дата.
- Форматът `box()` контролира само показването; съхранената стойност винаги е ISO 8601.
- Ограничението на диапазона от дати (`inputs{range[...]}`) не работи с оформлението `box`.
- Разликите в часовите зони могат да усложнят анализа на данните, ако не са правилно отчетени.

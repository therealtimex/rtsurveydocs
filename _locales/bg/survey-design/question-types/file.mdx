title: "Файл"
description: "Въпросите за файл позволяват на анкетираните да качват документи и други файлове като част от отговорите си в проучването."
---

Типът въпрос `file` позволява на анкетираните да **качват произволен файл** от устройството си — документи, електронни таблици, PDF файлове или други типове файлове. За разлика от `image`, `audio` и `video`, които стартират специфични инструменти за заснемане, `file` отваря общ файлoв селектор.

## Основна XLSForm спецификация

| type | name      | label                        |
|------|-----------|------------------------------|
| file | document  | Моля, качете документа си  |

За повече подробности относно стандартния тип въпрос за файл, вижте [XLSForm спецификацията](https://xlsform.org/en/#question-types).

## Употреба

Въпросите за файл обикновено се използват за:

1. Събиране на подкрепящи документи (разписки, сертификати, договори, доклади)
2. Качване на попълнени хартиени формуляри, които са били сканирани
3. Събиране на електронни таблици или експорти на данни от други системи
4. Всякакъв тип цифров файл, който `image`/`audio`/`video` не покриват

## Формат на данните

Качените файлове се съхраняват като двоични прикачени файлове:

- **Формат:** Запазен в оригинален формат (PDF, XLSX, DOCX и др.)
- **Именуване:** `{instanceID}-{fieldname}.{extension}`
- **Съхранение:** Качени в медийната папка на сървъра заедно с подадените данни
- **Достъп:** Изтегляеми от интерфейса за управление на подадените данни

## rtSurvey разширения

### Приети типове файлове

Използвайте колоната `parameters`, за да ограничите кои типове файлове могат да бъдат избрани:

| type | name | label | parameters |
|------|------|-------|------------|
| file | report | Качете доклада от инспекцията | `accept=.pdf` |
| file | spreadsheet | Качете файла с данни | `accept=.xlsx,.csv` |

Параметърът `accept` използва стандартен синтаксис за файлово разширение (разделени със запетая).

### Указания за размера на файла

rtSurvey не налага твърдо ограничение за размера на файла на ниво въпрос, но се прилага ограничението за качване на сървъра. Използвайте `hint`, за да комуникирате очакванията на анкетьора:

| type | name | label | hint |
|------|------|-------|------|
| file | receipt | Качете разписката за плащане | Приема се: PDF или изображение. Максимален размер на файла: 5 MB |

### Интеграция с файловата система на устройството и облачно съхранение

На Android и iOS въпросът `file` отваря родния файлoв селектор на устройството, който може да включва достъп до:
- Локално хранилище на устройството
- SD карта (Android)
- iCloud Drive (iOS)
- Google Drive, Dropbox (ако са инсталирани)

В мрежата той отваря стандартния диалогов прозорец за качване на файлове на браузъра.

### Разположение на вграден бутон

Добавете `inline`, за да изобразите качването като **кръгъл иконен бутон** до етикета, вместо файлoв селектор на цялата ширина.

```
| type | name | label           | appearance                              |
|------|------|-----------------|-----------------------------------------|
| file | doc  | Качи документ | inline display{right}                   |
| file | doc  | Качи документ | inline display{left, large}             |
| file | doc  | Качи документ | inline display{center, large, <0099FF/>} |
```

**Позиция на бутона** — `left`, `right` *(по подразбиране)*, `top`, `center`, `bottom`

**Размер на бутона** — `small` *(по подразбиране)*, `medium`, `large`

**Цвят на бутона** — добавете шестнадесетичен цвят вътре в `display{}` за да промените основния цвят:

```
inline display{right, large, <FF5500/>}
```

**Контрол след заснемане — `results{}`:**

| Appearance | Ефект |
|---|---|
| `results{hide(capture)}` | Скрива бутона за качване, след като файлът е прикачен |
| `results{hide(review)}` | Скрива бутона за преглед/предварителен преглед след качване |
| `results{hide(filename)}` | Скрива името на файла, показано след качване |
| `results{left}` | Премества иконата наляво след качване |

Пример — скриване на бутона за качване, след като файлът е прикачен:
```
inline display{right} results{hide(capture)}
```

### Потискане на етикета

```
inline text-nolabel display{center, large}
```

## Примери за употреба

### Задължително качване на PDF

| type | name | label | hint | required | required_message |
|------|------|-------|------|----------|-----------------|
| file | signed_consent | Качете подписания формуляр за съгласие | Само PDF, макс. 2MB | yes | Изисква се формуляр за съгласие |

### Условно качване на документ

| type | name | label | relevant |
|------|------|-------|----------|
| select_one yesno | has_land_title | Домакинството има ли нотариален акт? | |
| file | land_title_doc | Качете снимка или сканиран нотариален акт | `${has_land_title} = 'yes'` |

## Най-добри практики

1. Използвайте `accept`, за да ограничите типовете файлове — това предотвратява случайно качване на грешни файлове от анкетираните.
2. Винаги включвайте указания за размер и формат в колоната `hint`.
3. За снимки и изображения използвайте тип `image` — той предлага по-добро компресиране и последователно обработване на формата.
4. За големи проучвания с файлови прикачени файлове, планирайте съхранението на данни и честотната лента за изтегляне съответно.
5. Тествайте файлoвия селектор на целевия тип устройство (Android срещу iOS срещу уеб) преди внедряване — достъпът до облачни устройства варира.

## Съображения за обработка на данни

- Файловете се съхраняват в оригиналния си формат; те не се конвертират или компресират от rtSurvey.
- Анализирайте файловете след изтегляне — rtSurvey не извлича или индексира съдържанието на файловете.
- Големите файлови прикачени файлове значително увеличават времето, необходимо за изтегляне на пълен набор от данни.

## Ограничения

- Въпросите за файл не валидират съдържанието на файловете — само проверката на файловото разширение чрез `accept` се прилага на ниво потребителски интерфейс.
- Много големи файлове (100 MB+) могат да изтекат по време на качване в среди с ниска свързаност.
- Офлайн анкетьорите могат да прикачват файлове, но те няма да се качат, докато не се възстанови свързаността.
- Някои конфигурации на устройства ограничават достъпа до определени места за съхранение (напр. корпоративни MDM политики).

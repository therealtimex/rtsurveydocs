---

Типът въпрос `decimal` събира числа, които могат да включват дробна част (напр. `3.14`, `72.5`). Той задейства цифрова клавиатура на мобилни устройства и поддържа същите опции за `appearance` като типа `text` за оформление и форматиране.

## Основна XLSForm спецификация

| type | name | label |
|------|------|-------|
| decimal | weight_kg | Тегло (кг) |
| decimal | height_m | Височина (м) |
| decimal | temperature | Температура на тялото (°C) |

За стандартната спецификация вижте [XLSForm документацията](https://xlsform.org/en/#question-types).

---

## Опции за `appearance`

### `number-hspinner` — хоризонтален спинър

Заменя въвеждането с хоризонтален спинър **− стойност +**. Докосването на минус/плюс регулира стойността със зададената стъпка.

```
number-hspinner
```

Показаната стойност е форматирана с една десетична запетая (напр. `3.0`, `72.5`). Стъпката по подразбиране е `1`; използвайте `hspinner()` за да зададете десетична стъпка.

**Персонализиране на формата на бутона и стъпката** с `hspinner()`:

```
number-hspinner hspinner('left-small-square','right-small-square','0.1')
```

Параметри: форма на левия бутон, форма на десния бутон, стойност на стъпката. Използвайте десетична стъпка като `0.5` или `0.1` за прецизен контрол.

**Персонализирани цветове** с `colors()`:

```
number-hspinner colors(0099FF,FFFFFF,FF5500,FFFFFF)
```

Четири стойности в ред: фон на левия бутон, икона на левия бутон, фон на десния бутон, икона на десния бутон.

---

### `thousandsep` — разделител на хиляди

Форматира показаното число с групиране по запетаи (напр. `1,234.56`). Суровото число се съхранява без запетаи. Типът на въвеждане се превключва на `"text"`, за да позволи форматираното показване.

```
thousandsep
```

---

### `digisep(n, "sep")` — персонализирано групиране на цифри

Групира цифрите на цялата част в блокове от `n`, разделени от персонализиран разделител.

```
digisep(3," ")      → 1 234 567.89
```

Типът на въвеждане се превключва на `"text"`, когато тази `appearance` е активна.

---

### `textonly` — принудителна текстова клавиатура

Принуждава `type="text"` на входния елемент. Предотвратява странностите на браузъра при въвеждане на числа (скриване на крайни нули, стрелки за завъртане на десктоп), като същевременно приема десетични стойности.

```
textonly
```

---

### `floating_hint` — подсказка, която се носи като етикет

Текстът на `hint` се изобразява вътре във входа като заместител. Когато потребителят започне да пише, той се носи над полето като етикет.

```
floating_hint
```

---

### `embed` — подсказка в границите на въвеждането

Подобно на `floating_hint` — подсказката стои в границите на въвеждането, когато е празно. Тя не се носи, когато потребителят пише.

```
embed
```

---

### `textpopup` — въвеждане чрез модален диалогов прозорец

Докосването на полето отваря модален диалогов прозорец с по-голям вход. Полезно на малки екрани.

```
textpopup
```

---

### `charcount` — брояч на символи на живо

Показва брояч на символи `(n)` на живо под входа, който се актуализира докато потребителят пише.

```
charcount
```

---

### `prefix(expr)` — добавяне на префикс

Добавя статичен или изчислен низ към показаната стойност. Съхранената стойност не включва префикса.

```
prefix('USD ')          → показва "USD 72.50", съхранява "72.50"
prefix(${currency})     → динамичен префикс от друго поле
```

---

### `align_answer` — подравняване на текста за въвеждане

Контролира хоризонталното подравняване на въведения текст във входа.

```
align_answer = left
align_answer = right
align_answer = center
```

---

### `inputs{qrscan}` — сканиране на QR / баркод в полето

Добавя бутон за сканиране на QR код до входа. Отваря скенера на камерата и попълва полето със сканираната стойност.

```
inputs{qrscan}
```

## Кратка справка за `appearance`

| Appearance | Изобразен уиджет |
|---|---|
| *(няма)* | Въвеждане на число (`type="number"`) — цифрова клавиатура на мобилни устройства |
| `number-hspinner` | Хоризонтален спинър − стойност +, показва се една десетична запетая |
| `number-hspinner hspinner(...)` | Спинър с персонализиран вид на бутона и стъпка |
| `number-hspinner colors(...)` | Спинър с персонализирани цветове на бутоните |
| `thousandsep` | Показване на число, групирано със запетаи |
| `digisep(n,"sep")` | Персонализирано групиране на цифри |
| `textonly` | Принудителна текстова клавиатура |
| `floating_hint` | Подсказка, която се носи над полето докато пишете |
| `embed` | Подсказка в границите на въвеждането |
| `textpopup` | Докоснете за отваряне на модален диалогов прозорец |
| `charcount` | Брояч на символи на живо под входа |
| `prefix(expr)` | Добавяне на статичен или динамичен префикс |
| `align_answer = left/right/center` | Подравняване на текста за въвеждане |
| `inputs{qrscan}` | Бутон за сканиране на QR/баркод |

## Ограничения и валидиране

| type | name | label | constraint | constraint_message |
|------|------|-------|------------|-------------------|
| decimal | weight | Тегло (кг) | `. > 0 and . <= 500` | Въведете стойност между 0 и 500 |
| decimal | height | Височина (м) | `. > 0 and . <= 3` | Въведете стойност между 0 и 3 |
| decimal | temp | Температура (°C) | `. >= 35 and . <= 42` | Нормална температура: 35°C–42°C |
| decimal | percentage | Процент | `. >= 0 and . <= 100` | Въведете стойност между 0 и 100 |

## Пример — формуляр за измерване

| type | name | label | appearance | constraint | constraint_message |
|------|------|-------|------------|------------|-------------------|
| decimal | weight_kg | Тегло (кг) | `number-hspinner hspinner('left-small-square','right-small-square','0.5')` | `. > 0 and . <= 300` | Въведете валидно тегло |
| decimal | height_m | Височина (м) | `number-hspinner hspinner('left-small-square','right-small-square','0.01')` | `. > 0 and . <= 3` | Въведете валидна височина |
| calculate | bmi | | | | |

Колона за изчисляване на BMI:
```
${weight_kg} div (${height_m} * ${height_m})
```

## Най-добри практики

1. Използвайте `number-hspinner hspinner(..., '0.1')` за измервания, изискващи една десетична точност — спинърът автоматично форматира до една десетична запетая, поддържайки стойностите последователни.
2. Използвайте `textonly`, когато браузърите добавят нежелани контроли за завъртане или съкращават крайни нули (напр. `3.0` показано като `3`).
3. Използвайте `thousandsep` за големи финансови стойности, така че анкетираните да могат да проверят дали са въвели правилната величина.
4. Прилагайте ограничения за диапазон, вместо да разчитате само на типа мобилна клавиатура.

## Ограничения

- Спинърът винаги показва една десетична запетая — ако имате нужда от по-голяма точност в показаната стойност, използвайте обикновения вход.
- `thousandsep` и `digisep()` съхраняват суровото число — не четете форматираната стойност при изчисления.

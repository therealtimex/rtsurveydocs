title: "Десетично число"
description: "Тип въпрос за въвеждане на дробно число в rtSurvey"
---

Типът въпрос `decimal` събира числа, които могат да включват дробна част (напр. `3.14`, `72.5`). Той активира цифрова клавиатура на мобилни устройства и поддържа същите опции за външен вид като типа `text` за оформление и форматиране.

## Основна спецификация на XLSForm

| type | name | label |
|------|------|-------|
| decimal | weight_kg | Тегло (кг) |
| decimal | height_m | Височина (м) |
| decimal | temperature | Телесна температура (°C) |

За стандартната спецификация вижте [документацията на XLSForm](https://xlsform.org/en/#question-types).

---

## Опции за външен вид

### `number-hspinner` — хоризонтален спинър

Заменя полето за въвеждане с хоризонтален спинър **− стойност +**. Докосването на минус/плюс коригира стойността със конфигурираната стъпка.

```
number-hspinner
```

Показаната стойност е форматирана с един десетичен знак (напр. `3.0`, `72.5`). Стъпката по подразбиране е `1`; използвайте `hspinner()`, за да зададете десетична стъпка.

**Персонализиране на формата на бутона и стъпката** чрез `hspinner()`:

```
number-hspinner hspinner('left-small-square','right-small-square','0.1')
```

Параметри: форма на левия бутон, форма на десния бутон, стойност на стъпката. Използвайте десетична стъпка като `0.5` или `0.1` за прецизен контрол.

**Персонализирани цветове** чрез `colors()`:

```
number-hspinner colors(0099FF,FFFFFF,FF5500,FFFFFF)
```

Четири стойности в ред: фон на левия бутон, икона на левия бутон, фон на десния бутон, икона на десния бутон.

---

### `thousandsep` — разделител на хилядите

Форматира показаното число с групиране чрез запетая (напр. `1,234.56`). Необработеното число се съхранява без запетаи. Типът на въвеждане се превключва на `"text"`, за да се позволи форматираното показване.

```
thousandsep
```

---

### `digisep(n, "sep")` — персонализирано групиране на цифри

Групира цифрите на цялата част в блокове от `n`, разделени от персонализиран разделител.

```
digisep(3," ")      → 1 234 567.89
```

Типът на въвеждане се превключва на `"text"`, когато този външен вид е активен.

---

### `textonly` — принудителна текстова клавиатура

Принуждава `type="text"` на елемента за въвеждане. Предотвратява странностите при въвеждане на числа в браузъра (скриване на крайни нули, стрелки за превъртане на десктоп), докато все още приема десетични стойности.

```
textonly
```

---

### `floating_hint` — подсказката плава като етикет

Текстът на подсказката (`hint`) се изобразява вътре в полето като placeholder. Когато потребителят започне да пише, тя изплува над полето като етикет (label).

```
floating_hint
```

---

### `embed` — подсказка вътре в границата на полето

Подобно на `floating_hint` — подсказката стои вътре в границата на полето, когато е празно. Тя не изплува, когато потребителят пише.

```
embed
```

---

### `textpopup` — модален диалогов прозорец за въвеждане

Докосването на полето отваря модален диалогов прозорец с по-голямо поле за въвеждане. Полезно за малки екрани.

```
textpopup
```

---

### `charcount` — брояч на символи в реално време

Показва броя на символите `(n)` в реално време под полето, който се актуализира, докато потребителят пише.

```
charcount
```

---

### `prefix(expr)` — добавяне на префикс

Добавя статичен или изчислен низ пред показаната стойност. Съхранената стойност не включва префикса.

```
prefix('USD ')          → показва "USD 72.50", съхранява "72.50"
prefix(${currency})     → динамичен префикс от друго поле
```

---

### `align_answer` — подравняване на текста за въвеждане

Контролира хоризонталното подравняване на въведената стойност вътре в полето.

```
align_answer = left
align_answer = right
align_answer = center
```

---

### `inputs{qrscan}` — сканиране на QR / баркод в полето

Добавя бутон за сканиране на QR код до полето. Отваря скенера на камерата и попълва полето със сканираната стойност.

```
inputs{qrscan}
```

## Бърза справка за външния вид

| Appearance | Widget rendered |
|---|---|
| *(none)* | Въвеждане на число (`type="number"`) — цифрова клавиатура на мобилни устройства |
| `number-hspinner` | Хоризонтален спинър − стойност +, показан един десетичен знак |
| `number-hspinner hspinner(...)` | Спинър с персонализирана форма на бутона и стъпка |
| `number-hspinner colors(...)` | Спинър с персонализирани цветове на бутоните |
| `thousandsep` | Показване на число с групиране чрез запетая |
| `digisep(n,"sep")` | Персонализирано групиране на цифри |
| `textonly` | Принудителна текстова клавиатура |
| `floating_hint` | Подсказката плава над полето по време на писане |
| `embed` | Подсказка вътре в границата на полето |
| `textpopup` | Докоснете, за да отворите модален диалогов прозорец |
| `charcount` | Брояч на символи в реално време под полето |
| `prefix(expr)` | Добавяне на статичен или динамичен префикс |
| `align_answer = left/right/center` | Подравняване на текста за въвеждане |
| `inputs{qrscan}` | Бутон за сканиране на QR/баркод |

## Ограничения и валидация

| type | name | label | constraint | constraint_message |
|------|------|-------|------------|-------------------|
| decimal | weight | Тегло (кг) | `. > 0 and . <= 500` | Въведете стойност между 0 и 500 |
| decimal | height | Височина (м) | `. > 0 and . <= 3` | Въведете стойност между 0 и 3 |
| decimal | temp | Температура (°C) | `. >= 35 and . <= 42` | Нормална температура: 35°C–42°C |
| decimal | percentage | Процент | `. >= 0 and . <= 100` | Въведете стойност между 0 и 100 |

## Пример — форма за измерване

| type | name | label | appearance | constraint | constraint_message |
|------|------|-------|------------|------------|-------------------|
| decimal | weight_kg | Тегло (кг) | `number-hspinner hspinner('left-small-square','right-small-square','0.5')` | `. > 0 and . <= 300` | Въведете валидно тегло |
| decimal | height_m | Височина (м) | `number-hspinner hspinner('left-small-square','right-small-square','0.01')` | `. > 0 and . <= 3` | Въведете валидна височина |
| calculate | bmi | | | | |

Колона за изчисляване на BMI:
```
${weight_kg} div (${height_m} * ${height_m})
```

## Най-добри практики

1. Използвайте `number-hspinner hspinner(..., '0.1')` за измервания, изискващи един десетичен знак прецизност — спинърът автоматично форматира до един десетичен знак, поддържайки стойностите последователни.
2. Използвайте `textonly`, когато браузърите добавят нежелани контроли за превъртане или отрязват крайните нули (напр. `3.0`, показано като `3`).
3. Използвайте `thousandsep` за големи финансови стойности, така че респондентите да могат да проверят дали са въвели правилната величина.
4. Налагайте ограничения на диапазона, вместо да разчитате само на типа мобилна клавиатура.

## Ограничения

- Спинърът винаги показва един десетичен знак — ако се нуждаете от повече прецизност в показаната стойност, използвайте обикновеното поле за въвеждане вместо това.
- `thousandsep` и `digisep()` съхраняват необработеното число — не четете форматираната стойност на дисплея в изчисленията.

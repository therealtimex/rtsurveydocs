Kjo faqe mbulon modele të avancuara për punën me grupet e përsëritjes në rtSurvey. Për bazat e konfigurimit të një grupi përsëritjeje, shihni [Grupimi dhe Përsëritjet](../repeats).

---

## Numërimi dinamik i përsëritjes

Si parazgjedhje, numëruesi vendos se sa herë do të përsëritet. Ju mund të fiksoni numrin e përsëritjeve duke përdorur `repeat_count`:

| type | name | label | repeat_count |
|------|------|-------|--------------|
| begin_repeat | household_members | Anëtar i familjes | `${num_members}` |
| text | member_name | Emri i anëtarit | |
| integer | member_age | Mosha | |
| end_repeat | | | |

Përsëritja ekzekutohet saktësisht `${num_members}` herë, ku `num_members` është mbledhur më herët në formular. Numëruesi nuk mund të shtojë ose heqë instanca.

---

## Aksesi i indeksuar: `indexed-repeat()`

Aksedoni vlerën e një fushe të një instance specifike përsëritjeje nga **jashtë** grupit të përsëritjes duke përdorur `indexed-repeat(repeatedField, repeatGroup, index)`:

| type | name | label | calculation |
|------|------|-------|-------------|
| calculate | first_name | | `indexed-repeat(${member_name}, ${household_members}, 1)` |
| calculate | second_name | | `indexed-repeat(${member_name}, ${household_members}, 2)` |

Kjo është e dobishme për ndërtimin e fushave përmbledhëse ose referimin e të dhënave të anëtarit "kryesor" pas përsëritjes.

---

## Pozicioni i instancës aktuale: `index()`

Brenda një grupi përsëritjeje, `index()` kthen pozicionin e bazuar në 1 të instancës aktuale. Përdoreni atë për të emërtuar çdo përsëritje ose për të krijuar identifikues unikë:

| type | name | label |
|------|------|-------|
| begin_repeat | plots | Parcela |
| note | plot_label | Parcela numër `${index()}` |
| text | plot_id | ID-ja e parcelës |
| end_repeat | | |

---

## Referimi i fushave në të njëjtën instancë

Brenda një përsëritjeje, përdorni `${fieldname}` për të referuar një fushë tjetër **në të njëjtën instancë përsëritjeje**. Nuk ka nevojë për `indexed-repeat()` brenda të njëjtit cikël:

| type | name | label | relevant |
|------|------|-------|----------|
| begin_repeat | members | Anëtar | |
| text | member_name | Emri | |
| integer | member_age | Mosha | |
| text | school_name | Emri i shkollës | `${member_age} < 18` |
| end_repeat | | | |

---

## Referimi i fushave prind nga brenda një përsëritjeje

Fushat jashtë (mbi) grupit të përsëritjes mund të referohen normalisht me `${fieldname}`:

| type | name | label |
|------|------|-------|
| text | village | Emri i fshatit |
| begin_repeat | plots | Parcela bujqësore |
| note | plot_context | Parcela në `${village}` |
| end_repeat | | |

## Përmbledhja e të dhënave të përsëritjes

Përdorni funksionet agregate të përsëritjes **jashtë** grupit të përsëritjes për të përmbledhur:

| Function | Example | Description |
|----------|---------|-------------|
| `count(group)` | `count(${household_members})` | Numri i instancave |
| `sum(field)` | `sum(${loan_amount})` | Shuma e një fushe numerike |
| `min(field)` | `min(${member_age})` | Vlera minimale |
| `max(field)` | `max(${member_age})` | Vlera maksimale |
| `join(sep, field)` | `join(', ', ${member_name})` | Listë e ndarë me presje |
| `count-if(group, expr)` | `count-if(${members}, ${member_age} < 18)` | Numërimi me kusht |
| `sum-if(field, expr)` | `sum-if(${loan_amount}, ${loan_amount} > 500)` | Shuma me kusht |
| `join-if(sep, field, expr)` | `join-if(', ', ${name}, ${age} >= 18)` | Bashkimi me kusht |

### Shembull: Përmbledhja e familjes

| type | name | label | calculation |
|------|------|-------|-------------|
| integer | num_members | Sa anëtarë? | |
| begin_repeat | members | Anëtar | `${num_members}` |
| text | member_name | Emri | |
| integer | member_age | Mosha | |
| end_repeat | | | |
| calculate | total_members | | `count(${members})` |
| calculate | children_count | | `count-if(${members}, ${member_age} < 18)` |
| calculate | adult_names | | `join-if(', ', ${member_name}, ${member_age} >= 18)` |
| note | summary | `${total_members}` anëtarë; `${children_count}` nën 18 vjeç. Të rritur: `${adult_names}` | |

## Përsëritjet e ndërthurura

Një grup përsëritjeje mund të përmbajë një grup tjetër përsëritjeje. Përdoreni këtë me kujdes — përsëritjet e ndërthurura shtojnë kompleksitet dhe mund të jenë konfuze për numëruesit.

| type | name | label |
|------|------|-------|
| begin_repeat | households | Familja |
| text | hh_id | ID-ja e familjes |
| begin_repeat | hh_members | Anëtar |
| text | member_name | Emri i anëtarit |
| end_repeat | | |
| end_repeat | | |

Për të referuar një fushë në një përsëritje të jashtme nga përsëritja e brendshme, përdorni `${fieldname}` — ai zgjidhet te paraardhësi më i afërt që përputhet:

Brenda përsëritjes `hh_members`, `${hh_id}` kthen ID-në e familjes **aktuale**, jo të gjitha familjeve.

## Renditja brenda grupeve të përsëritjes: `rank-index()`

Kur ekziston një fushë `rank` brenda një përsëritjeje, përdorni `rank-index(instanceNumber, repeatedField)` nga jashtë për të marrë renditjen e një instance specifike:

| type | name | label | calculation |
|------|------|-------|-------------|
| calculate | top_scorer | | `rank-index(1, ${score})` |

`rank-index(1, ${score})` kthen indeksin e instancës me rezultatin më të lartë.

## Pamja `1screen` në `begin_repeat`

Shtimi i `1screen` në kolonën `appearance` të një rreshti `begin_repeat` shfaq të gjitha pyetjet për çdo instancë së bashku në një ekran të vetëm, në vend të një pyetjeje për ekran.

| type | name | label | appearance |
|------|------|-------|------------|
| begin_repeat | household_members | Anëtar i familjes | `1screen` |
| text | member_name | Emri i anëtarit | |
| integer | member_age | Mosha | |
| end_repeat | | | |

Kur është vendosur `1screen` dhe nuk ka fushë `repeat_count` dhe asnjë fushë `add_repeat` brenda grupit, rtSurvey paraqet automatikisht një buton rrethor **+** në fund të ekranit në mënyrë që numëruesit të mund të shtojnë instanca të reja pa ndonjë konfigurim shtesë.

| Appearance | Një ekran për instancë | Butoni + i parazgjedhur i shtuar |
|------------|-------------------------|------------------------|
| `1screen` | Po | Po (kur nuk ka pasardhës `add_repeat`) |
| `field-list` | Po | Jo |

Përdorni `field-list` kur dëshironi paraqitjen e grupuar pa butonin e shtimit automatik. Përdorni `1screen` kur dëshironi si paraqitjen e grupuar ashtu edhe një mënyrë të integruar për të shtuar instanca.

## Butoni i personalizuar i shtimit `add_repeat`

Një fushë `note` (ose `text`) e vendosur **brenda** grupit të përsëritjes me `appearance: add_repeat` paraqitet si një buton "Shto" me gjerësi të plotë. Etiketa e butonit vjen nga kolona `label` e fushës. Kur një fushë `add_repeat` është e pranishme, butoni rrethor i parazgjedhur + (nga `1screen`) hiqet.

Vendoseni fushën `add_repeat` si fushën e fundit brenda grupit të përsëritjes:

| type | name | label | appearance |
|------|------|-------|------------|
| begin_repeat | members | Anëtar | `1screen` |
| text | member_name | Emri i anëtarit | |
| integer | member_age | Mosha | |
| note | btn_add | + Shto anëtar | `add_repeat` |
| end_repeat | | | |

### Personalizimi i ngjyrave

Kaloni një kod ngjyre brenda vlerës së pamjes për të stiluar butonin:

| Appearance value | Result |
|------------------|--------|
| `add_repeat <#04B404/>` | Sfond i gjelbër, ngjyra e parazgjedhur e tekstit |
| `add_repeat 04B404-ffffff` | Sfond i gjelbër, tekst i bardhë |

Ngjyra e parë është sfondi dhe e dyta (pas vizës) është ngjyra e tekstit. Hiqni `#` kur përdorni formën e ndarë me vizë.

### Varianti me ikonë

Përdorni `add_repeat icon` (me një hapësirë) për të paraqitur një buton kompakt rrethor me ikonë në vend të butonit me gjerësi të plotë:

| type | name | label | appearance |
|------|------|-------|------------|
| note | btn_add | + Shto | `add_repeat icon` |

## Butonat e fshirjes: `delete-repeat-current` dhe `delete-repeat-last`

Një fushë `note` brenda grupit të përsëritjes me `appearance: delete-repeat-current` ose `appearance: delete-repeat-last` paraqitet si një buton i ndarë fshirjeje.

| Appearance | Action |
|------------|--------|
| `delete-repeat-current` | Fshin instancën aktuale (aktive) |
| `delete-repeat-last` | Fshin instancën e fundit në përsëritje |

Butoni i parazgjedhur (pa ikonë) është një buton i ndarë: një ikonë kosh mbeturinash në të majtë dhe teksti i etiketës së fushës në të djathtë, duke u shtrirë në të gjithë gjerësinë e ekranit.

### Varianti me ikonë

Shtoni `-icon` për të marrë një buton kompakt rrethor me ikonë kosh mbeturinash:

| Appearance | Result |
|------------|--------|
| `delete-repeat-current-icon` | Ikonë rrethore koshi, fshin instancën aktuale |
| `delete-repeat-last-icon` | Ikonë rrethore koshi, fshin instancën e fundit |

### Personalizimi i ngjyrave

Formati i ngjyrës është identik me `add_repeat`: përdorni `<#RRGGBB/>` ose `RRGGBB-RRGGBB` (sfond-tekst).

### Shembull i modelit të plotë

Përsëritja e mëposhtme përdor `1screen`, një buton rrethor delete-current në krye dhe një buton shto me gjerësi të plotë në fund:

| type | name | label | appearance |
|------|------|-------|------------|
| begin_repeat | members | Anëtar | `1screen` |
| note | btn_del | Hiq | `delete-repeat-current-icon` |
| text | member_name | Emri i anëtarit | |
| integer | member_age | Mosha | |
| note | btn_add | + Shto anëtar | `add_repeat` |
| end_repeat | | | |

## Praktikat më të mira

1. Përdorni gjithmonë `repeat_count` kur numri i përsëritjeve dihet paraprakisht — kjo parandalon numëruesit nga shtimi ose heqja aksidentale e instancave.
2. Mbajini grupet e përsëritjes të fokusuara — një përsëritje me mbi 20 pyetje për instancë është e vështirë për t'u lundruar.
3. Emërtoni grupet e përsëritjes qartë (p.sh., `household_members`, jo `repeat1`) — emri shfaqet në thirrjet e funksioneve dhe të dhënat e eksportuara.
4. Testoni me numrin maksimal të pritshëm të instancave për të verifikuar performancën.
5. Përdorni `1screen` në `begin_repeat` për të shfaqur të gjitha pyetjet në një ekran për instancë, të çiftuar me një fushë note `add_repeat` brenda grupit për t'u dhënë numëruesve një buton "Shto" të etiketuar qartë.

---

## Kufizimet

- `indexed-repeat()` kërkon një indeks të vlefshëm (1 deri në numrin e instancave) — indekset jashtë rrezes kthejnë bosh.
- Përsëritjet e ndërthurura përtej 2 niveleve nuk rekomandohen dhe mund të shkaktojnë probleme shfaqjeje në disa klientë.
- Funksionet agregate (`sum`, `count`, etj.) operojnë në të gjithë grupin e përsëritjes — nuk mund të agregoni një nënbashkësi instancash pa variantet `*-if`.

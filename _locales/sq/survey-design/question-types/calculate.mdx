Lloji i pyetjes `calculate` ekzekuton një formulë në heshtje në sfond. Ai e ruan rezultatin në një fushë të emërtuar të cilës pyetjet e tjera mund t'i referohen — por nuk shfaq asnjë hyrje apo etiketë për anketuesin. Përdoreni atë për të nxjerrë vlera, për të bashkuar vargje, për të ekzekutuar logjikë të kushtëzuar ose për të kërkuar të dhëna që do t'ju nevojiten më vonë në formular.

---

## Sintaksa bazë

| type | name | label | calculation |
|------|------|-------|-------------|
| calculate | total | | `${price} * ${quantity}` |

- **type**: Gjithmonë `calculate`.
- **name**: Një emër unik i fushës. Pyetjet e tjera i referohen kësaj me `${name}`.
- **label**: Lëreni bosh — fushat calculate nuk shfaqen kurrë për anketuesin.
- **calculation**: Formula për t'u vlerësuar. Mbështet të gjitha [funksionet XLSForm](../operators-and-functions/functions) dhe referencat e fushave.

---

## Modelet e zakonshme

### Aritmetika

| type | name | label | calculation |
|------|------|-------|-------------|
| integer | price | Unit price | |
| integer | quantity | Quantity | |
| calculate | total | | `${price} * ${quantity}` |
| note | total_note | Total: `${total}` | |

### Bashkimi i vargjeve (String concatenation)

| type | name | label | calculation |
|------|------|-------|-------------|
| text | first_name | First name | |
| text | last_name | Last name | |
| calculate | full_name | | `concat(${first_name}, ' ', ${last_name})` |

### Vlera e kushtëzuar

| type | name | label | calculation |
|------|------|-------|-------------|
| integer | score | Score (0–100) | |
| calculate | grade | | `if(${score} >= 90, 'A', if(${score} >= 75, 'B', if(${score} >= 60, 'C', 'F')))` |

### Mosha nga data e lindjes

| type | name | label | calculation |
|------|------|-------|-------------|
| date | dob | Date of birth | |
| calculate | age_years | | `int((today() - ${dob}) div 365.25)` |

## Përdorimi i `once()` për të kyçur vlerën

Si parazgjedhje, `calculate` rivlerësohet sa herë që ndryshon ndonjë fushë e referuar. Mbështillni formulën në `once()` për ta vlerësuar vetëm në ngarkimin e parë dhe për të ngrirë rezultatin:

| type | name | label | calculation |
|------|------|-------|-------------|
| calculate | interview_start | | `once(now())` |

Përdorni `once()` për vulat kohore (timestamps), vlerat fillestare ose çdo rast ku rilogaritja me ndryshimin është e padëshirueshme.

## Tërheqja e të dhënave nga burimet e jashtme

### Nga një skedar CSV

```
pulldata('staff.csv', 'department', 'name', ${staff_id})
```

Shihni [pulldata()](../operators-and-functions/pulldata) për referencën e plotë.

### Nga një bazë të dhënash SQLite e bashkëngjitur

```
pulldata('rawquery',
  concat(${family_path}, '/locations.db::provinces'),
  'SELECT name FROM provinces WHERE id = ?',
  ${province_id})
```

Shihni [Kërkimi në bazën e të dhënave lokale](../advanced-features/local-database-search) për detajet e ndërtimit të rrugës.

### Nga konteksti i aplikacionit

```
pulldata('app-api', 'user.username')
pulldata('app-api', 'family_path')
```

Shihni [App API](../app-api) për të gjithë çelësat e disponueshëm.

## Përdorimi i calculate në relevant dhe constraint

Fushat e tjera mund t'i referohen një rezultati `calculate` ashtu si çdo fushë:

| type | name | label | relevant | constraint |
|------|------|-------|----------|------------|
| calculate | bmi | | | `${weight} div (${height} * ${height}) * 10000` |
| note | bmi_warning | BMI is very high — please verify weight and height. | `${bmi} > 40` | |

## Praktikat më të mira

1. Jepuni fushave calculate emra kuptimplotë — `total_cost` është më e qartë se `calc1` dhe më e lehtë për t'u gjurmuar në eksporte.
2. Ndani formulat komplekse në disa fusha calculate të lidhura në vend të një shprehjeje të vetme thellësisht të ndërfutur.
3. Përdorni `once()` për vulat kohore dhe pamjet e para (snapshots) për të parandaluar ndryshimin e vlerave pas kapjes së parë.
4. Vendosni fushat `calculate` përpara pyetjes së parë që u referohet atyre — rendi i vlerësimit ndjek rendin e formularit.
5. Mbajeni kolonën `label` bosh. Disa mjete shfaqin etiketën; lënia e saj bosh shmang prodhimin konfuz.

## Kufizimet

- Fushat calculate nuk shfaqen kurrë drejtpërdrejt për anketuesin — përdorni një fushë `note` për të treguar rezultatin.
- Kolona `calculation` kërkohet; një rresht `calculate` pa formulë ruan gjithmonë një varg bosh.
- Rezultatet rivlerësohen në çdo ndryshim të formularit përveç nëse janë mbështjellë në `once()` — formulat shumë komplekse në formularë të mëdhenj mund të ndikojnë në performancën e paraqitjes në pajisjet me cilësi të ulët.
- Vlerat e llogaritura ruhen si vargje në dorëzim. Përdorni `number()`, `int()` ose `boolean()` për të konvertuar llojin kur kaloni rezultatin në shprehje aritmetike ose logjike.

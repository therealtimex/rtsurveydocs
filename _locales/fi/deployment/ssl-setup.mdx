SSL on määritettävä ennen kuin voit kirjautua sisään. Kun avaat sovelluksen ensimmäisen kerran, sinut ohjataan automaattisesti SSL-asetusnäkymään.

---

## SSL-asetusvaihtoehdot

![SSL-asetusvaihtoehdot](/img/ssl-setup/ssl-setup-options.png)

Valitse yksi kolmesta vaihtoehdosta:

| Vaihtoehto | Milloin käyttää |
|------------|-----------------|
| **Ilmainen rtsurvey.com-aliverkkotunnus** *(Suositus)* | DNS-asetuksia ei tarvita. Luomme tietueen puolestasi. Valmis 2–5 minuutissa. |
| **Oma verkkotunnus** | Sinulla on jo verkkotunnus, ja sen DNS osoittaa tälle palvelimelle. |
| **Asenna varmenne manuaalisesti** | Yrityksen tai oma varmentaja (CA). Vaatii SSH-yhteyden. |

---

## Vaihtoehto 1 — Ilmainen rtsurvey.com-aliverkkotunnus *(Suositus)*

Tämä on nopein vaihtoehto. Verkkotunnuksen rekisteröintiä tai DNS-muutoksia ei tarvita.

![HTTPS-asetuslomake](/img/ssl-setup/ssl-setup-form.png)

> **Ennen jatkamista:** Ilmainen aliverkkotunnus vaatii aktiivisen tilin osoitteessa [licenses.rtsurvey.com](https://licenses.rtsurvey.com). Ilmainen tilaus sisältää yhden aliverkkotunnuksen (`*.rtsurvey.com`).

1. Klikkaa **Ilmainen rtsurvey.com-aliverkkotunnus** laajentaaksesi osion
2. Kirjoita haluamasi aliverkkotunnus kenttään **ALIVERKKOTUNNUKSESI**

   > Käytä pieniä kirjaimia, numeroita ja yhdysmerkkejä. 3–30 merkkiä.
   > Esimerkki: `minunprojekti` → `minunprojekti.rtsurvey.com`

3. Liitä **rtSurvey DNS Token** osoitteesta [licenses.rtsurvey.com](https://licenses.rtsurvey.com) token-kenttään
4. Klikkaa **Luo suojattu aliverkkotunnus**

Kun lomake on lähetetty, sovellus aloittaa varmenteen valmistelun:

![HTTPS-asetusten edistyminen](/img/ssl-setup/ssl-setup-progress.png)

Neljä vaihetta suoritetaan automaattisesti:
- **DNS-tietueen pyytäminen** — luo DNS-merkinnän aliverkkotunnuksellesi
- **DNS-levityksen odottaminen** — kestää yleensä 2–5 minuuttia
- **SSL-varmenteen myöntäminen** — Let's Encrypt allekirjoittaa varmenteesi
- **HTTPS:n aktivointi** — Nginx käynnistyy uudelleen uuden varmenteen kanssa

5. Kun valmista, sinut ohjataan automaattisesti uudelle HTTPS-osoitteellesi



---

## Vaihtoehto 2 — Oma verkkotunnus

Käytä tätä, jos sinulla on olemassa oleva verkkotunnus ja sen DNS `A`-tietue osoittaa jo tämän palvelimen IP-osoitteeseen.

1. Klikkaa **Oma verkkotunnus** laajentaaksesi osion
2. Syötä koko verkkotunnuksesi (esim. `survey.minunorganisaatio.org`)
3. Klikkaa **Luo varmenne**



Let's Encrypt vahvistaa verkkotunnuksesi ja myöntää varmenteen. Tämä edellyttää, että DNS osoittaa oikein etukäteen – muuten pyyntö epäonnistuu.

## Vaihtoehto 3 — Asenna varmenne manuaalisesti

Yritysympäristöihin, joissa käytetään omaa tai sisäistä varmentajaa (CA). Sijoitat varmennetiedostosi palvelimelle SSH-yhteyden kautta ja syötät sitten verkkotunnuksesi sovellukseen.

### Esivaatimukset

- SSH-yhteys palvelimelle
- Voimassa oleva varmenne ja yksityinen avain verkkotunnuksellesi (PEM-muodossa)

### Vaihe 1 — Kirjaudu palvelimelle SSH:lla

```bash
ssh root@<palvelimen-ip>
```

### Vaihe 2 — Sijoita varmennetiedostosi

Luo hakemisto ja kopioi tiedostosi:

```bash
mkdir -p /etc/letsencrypt/live/<sinun-verkkotunnus>
```

Kopioi tiedostosi tähän hakemistoon täsmälleen näillä nimillä:

| Tiedosto | Kuvaus |
|----------|--------|
| `fullchain.pem` | Varmenne + mahdolliset välitason CA-varmenteet (yhdistettynä) |
| `privkey.pem` | Yksityinen avaimesi |

Esimerkki:

```bash
# Kopioi paikalliselta koneeltasi (suorita tämä paikallisesti, ei palvelimella)
scp fullchain.pem root@<palvelimen-ip>:/etc/letsencrypt/live/<sinun-verkkotunnus>/fullchain.pem
scp privkey.pem  root@<palvelimen-ip>:/etc/letsencrypt/live/<sinun-verkkotunnus>/privkey.pem
```

Aseta oikeat käyttöoikeudet:

```bash
chmod 644 /etc/letsencrypt/live/<sinun-verkkotunnus>/fullchain.pem
chmod 600 /etc/letsencrypt/live/<sinun-verkkotunnus>/privkey.pem
```

### Vaihe 3 — Syötä verkkotunnuksesi sovellukseen



1. Klikkaa SSL-asetusnäkymässä **Asenna varmenne manuaalisesti**
2. Syötä verkkotunnuksesi (on vastattava varmenteen Common Name- tai SAN-nimeä)
3. Klikkaa **Käytä**

Palvelin määrittää Nginxin varmenteesi kanssa ja lataa asetukset automaattisesti.

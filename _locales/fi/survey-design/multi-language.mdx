rtSurvey tarjoaa vankan monikielisen tuen, jonka avulla voit luoda kyselyitä useilla kielillä. Tämä ominaisuus on ratkaisevan tärkeä tutkittaessa kielellisesti erilaisia väestöryhmiä tai toimittaessa monikielisissä ympäristöissä.

## Monikielisten kyselyiden määrittäminen

Luo monikielinen kysely rtSurveyssä lisäämällä kielikohtaisia sarakkeita XLSForm-lomakkeeseen. Toimi näin:

1. **Otsikoiden käännökset (Label Translations)**: Lisää sarakkeita jokaiselle kielelle muodossa `label::Kieli (koodi)`.
2. **Vihjeiden käännökset (Hint Translations)**: Käytä muotoa `hint::Kieli (koodi)` vihjeiden kääntämiseen.
3. **Mediatiedostojen käännökset (Media File Translations)**: Käytä kielikohtaiselle medialle muotoa `media::Kieli (koodi)`.

Esimerkki:

```
| type    | name | label::English (en) | label::Español (es) | hint::English (en) | hint::Español (es) |
|---------|------|---------------------|---------------------|---------------------|---------------------|
| integer | age  | How old are you?    | ¿Cuántos años tienes?| Enter your age      | Ingrese su edad     |
```

## Kielikoodit

On suositeltavaa käyttää virallisia 2-merkkisiä kielikoodeja (subtags) kielen nimen jälkeen. Tämä helpottaa lomakkeen kielen yhdistämistä käyttöliittymän kieleen. Löydät viralliset koodit [täältä](https://www.iana.org/assignments/language-subtag-registry/language-subtag-registry).

## Oletuskielen asettaminen

Aseta tiedonkeruun oletuskieli XLSForm-lomakkeen `settings`-välilehdellä:

```
| form_id   | version | default_language |
|-----------|---------|-------------------|
| test_form | 101     | French (fr)       |
```

## rtSurvey-kohtaiset ominaisuudet

### Dynaaminen kielen vaihtaminen

rtSurvey antaa käyttäjien vaihtaa kieltä dynaamisesti tiedonkeruun aikana:

- Käytä verkkokäyttöliittymässä ylänavigointipalkin kielenvalintavalikkoa.
- Mobiilisovelluksessa pääset kielivaihtoehtoihin asetusvalikon kautta.

### Kielikohtaiset vahvistusviestit

rtSurvey laajentaa monikielisen tuen myös vahvistusviesteihin:

```
| type    | name | constraint | constraint_message::English (en) | constraint_message::Español (es) |
|---------|------|------------|----------------------------------|----------------------------------|
| integer | age  | . <= 150   | Age must be 150 or less          | La edad debe ser 150 o menos     |
```

### Lokaloidut pakollisuuden virheilmoitukset

Käytä muotoa `required_message::Kieli (koodi)` näyttääksesi käännetyn virheen, kun pakollinen kenttä jätetään tyhjäksi:

```
| type | name | required | required_message::English (en) | required_message::Tiếng Việt (vi) |
|------|------|----------|-------------------------------|----------------------------------|
| text | name | yes | This field is required | Trường này là bắt buộc |
```

### RTL-kielten tuki

Oikealta vasemmalle (RTL) luettaville kielille, kuten arabialle tai heprealle, rtSurvey säätää asettelun automaattisesti:

```
| type | name | label::English (en) | label::Arabic (ar) |
|------|------|---------------------|---------------------|
| text | name | Your name           | اسمك                |
```

### Kielikohtainen ulkoasu (Appearance)

rtSurvey antaa sinun määrittää erilaisia ulkoasuja eri kielille:

```
| type | name | label::English (en) | label::Chinese (zh) | appearance::English (en) | appearance::Chinese (zh) |
|------|------|---------------------|---------------------|--------------------------|---------------------------|
| text | address | Address          | 地址                 | multiline                | textarea                  |
```

## HTML-muotoilu kaksikielisissä otsikoissa

Voit yhdistää HTML-tageja ja kielikääreitä yhdessä otsikkosolussa. rtSurvey poimii aktiivisen kielen lohkon ja renderöi loput HTML:stä.

Esimerkki lihavoinnin ja fontin värin käytöstä kieltä kohden:

```
<en><big><b>Section 2: Household Income</b></big><br>Ask the household head only.</en><vi><big><b>Phần 2: Thu nhập hộ gia đình</b></big><br>Chỉ hỏi chủ hộ.</vi>
```

Tuetut rivinsisäiset tagit kielikääreiden sisällä: `<b>`, `<i>`, `<u>`, `<big>`, `<small>`, `<font color="...">`, `<br>`, `<span style="...">`.

Värillisen tekstin esimerkki kieltä kohden:

```
<en><font color="red">Required field</font></en><vi><font color="red">Trường bắt buộc</font></vi>
```

## Kielitietoiset laskεννά (Calculations)

Kun lomakkeella on `${language_use}`-kenttä (jonka asettaa `change_language`-widget), käytä `if()`-funktiota palauttamaan arvoja aktiivisella kielellä:

```
if(${language_use} = 'en', label_en, label_vi)
```

Esimerkki — hakutuloksen näyttäminen aktiivisella kielellä `pulldata('rawquery', ...)`-funktiolla:

```
| type      | name        | calculation                                                                 |
|-----------|-------------|-----------------------------------------------------------------------------|
| calculate | district_label | if(${language_use} = 'en', pulldata('rawquery', concat(${family_path}, '/locations.db::externalData'), 'SELECT label_en FROM externalData WHERE code = ?', ${district}), pulldata('rawquery', concat(${family_path}, '/locations.db::externalData'), 'SELECT label_vi FROM externalData WHERE code = ?', ${district})) |
```

Huomautus: `language_use`-kenttä asetetaan yleensä `change_language`-ulkoasuwidgetillä. Katso Appearance — change_language.

## Parhaat käytännöt monikielisille kyselyille

1. **Johdonmukainen nimeäminen**: Käytä johdonmukaisia kielikoodeja koko lomakkeessasi.
2. **Ammattimainen käännös**: Käytä kyselyn asiayhteyden tuntevia ammattikääntäjiä.
3. **Kontekstihuomautukset**: Anna kääntäjille kontekstihuomautuksia tarkkojen käännösten varmistamiseksi.
4. **Testaus**: Testaa lomakkeesi kaikilla kielillä ennen käyttöönottoa.
5. **Unicode-tuki**: Varmista, että tiedonkeruulaitteesi tukevat Unicodea muille kuin latinalaisille kirjaimistoille.
6. **Kielikohtainen media**: Käytä kullekin kielelle kulttuurisesti sopivia kuvia tai ääntä.
7. **Vältä tekstiä kuvissa**: Jos käytät kuvia, joissa on tekstiä, luo erilliset kuvat jokaiselle kielelle.

## Erikoistapausten käsittely

### Sekakieliset vastaukset

rtSurvey antaa vastaajien syöttää tekstiä millä tahansa kirjaimistolla riippumatta valitusta lomakkeen kielestä. Tämä on hyödyllistä esimerkiksi nimien tai osoitteiden tallentamisessa niiden alkuperäisessä muodossa.

### Kielikohtaiset kysymystyypit

Jotkut kysymystyypit voivat olla sopivampia tietyille kielille. rtSurvey antaa sinun käyttää eri kysymystyyppejä eri kielille:

```
| type::English (en) | type::Japanese (ja) | name | label::English (en) | label::Japanese (ja) |
|--------------------|---------------------|------|---------------------|----------------------|
| text               | select_one kanji    | name | Enter your name     | 名前を選んでください    |
```

## Monikielisen tiedon vienti (Export)

Viedessäsi tietoa rtSurveystä:

- Valitse vienti tietyllä kielellä tai sisällytä kaikki kieliversiot.
- Kielen metatiedot sisältyvät vientiin osoittaen, mitä kieltä kussakin vastauksessa käytettiin.

## Mobiilisovelluksen huomiot

- rtSurvey-mobiilisovellus tukee kielen vaihtamista offline-tilassa.
- Varmista, että kaikki tarvittavat kielitiedostot on ladattu ennen offline-tilaan siirtymistä.

## Tunnetut rajoitukset

- Jotkut edistyneet ominaisuudet eivät välttämättä ole saatavilla kaikilla kielillä.
- Erittäin pitkät käännökset voivat vaikuttaa asetteluun pienemmillä näytöillä.

Hyödyntämällä rtSurveyn monikielisiä ominaisuuksia voit luoda osallistavia, saavutettavia kyselyitä, jotka tavoittavat erilaisia väestöryhmiä ja tarjoavat korkealaatuista, kielellisesti tarkkaa tietoa.

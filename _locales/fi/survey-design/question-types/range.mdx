title: "Alue"
description: "Aluekysymysten avulla vastaajat voivat valita numeron vetämällä liukusäädintä määritellyn minimi- ja maksimiarvon välillä."
---

`range`-kysymystyyppi antaa vastaajille mahdollisuuden valita numeron määritellyn minimi- ja maksimiarvon välillä. rtSurveyn verkkolomakkeessa tämä renderöityy tavalliseksi **numerokentäksi** — luetteloinnin tekijä kirjoittaa arvon suoraan. `start`-, `end`- ja `step`-parametrit määrittelevät kelvollisen alueen ja ne pakotetaan rajoituksina.

## XLSFormin peruserittely

| type | name | label | parameters |
|------|------|-------|------------|
| range | satisfaction | Kuinka tyytyväinen olet palveluun? | start=1 end=5 step=1 |

`parameters`-sarake määrittelee liukusäätimen rajat ja askelkoon:

| Parameter | Description | Default |
|-----------|-------------|---------|
| `start` | Minimiarvo (sisältäen) | 0 |
| `end` | Maksimiarvo (sisältäen) | 10 |
| `step` | Kasvatus kelvollisten arvojen välillä | 1 |

Lisätietoja standardin aluekysymystyypistä on [XLSFormin dokumentaatiossa](https://xlsform.org/en/#question-types).

## Käyttötarkoitukset

Aluekysymyksiä käytetään yleisesti:

1.  Tyytyväisyys- tai arviointiasteikkoihin (esim. 1–5 tai 0–10)
2.  Likert-tyyppisiin numeerisiin asteikkoihin
3.  Mittausten keräämiseen, joissa vain diskreetit arvot ovat kelvollisia
4.  Ikäryhmiin tai pistealueisiin, joissa liukusäädin parantaa käytettävyyttä tekstikentän sijaan

## Käyttöesimerkki

### Perusluokitusasteikko

| type | name | label | parameters |
|------|------|-------|------------|
| range | overall_rating | Kokonaisarvio (0–10) | start=0 end=10 step=1 |

### Desimaaliaskel

| type | name | label | parameters |
|------|------|-------|------------|
| range | weight_kg | Paino (kg) | start=0 end=200 step=0.5 |

### Arvon käyttäminen laskennassa

| type | name | label | parameters | calculation |
|------|------|-------|------------|-------------|
| range | score | Testipisteet (0–100) | start=0 end=100 step=5 | |
| calculate | grade | | | if(`${score}` >= 90, 'A', if(`${score}` >= 80, 'B', if(`${score}` >= 70, 'C', 'F'))) |
| note | grade_note | Arvosanasi on: `${grade}` | | |

## Parhaat käytännöt

1.  Aseta aina merkitykselliset `start`-, `end`- ja `step`-arvot — älä luota oletusarvoihin.
2.  Nimeä asteikon päät `hint`-sarakkeessa (esim. `hint: 0 = Erittäin tyytymätön, 10 = Erittäin tyytyväinen`) antaaksesi vastaajille kontekstia.
3.  Käytä 5-pisteen Likert-asteikoissa `start=1 end=5 step=1` mieluummin kuin 0–4, koska vastaajat odottavat "1":n tarkoittavan alinta.
4.  Käytä `range`-tyyppiä `integer` + rajoituksen sijaan, kun syötteen rajoitettu luonne on osa kysymyksen suunnittelua (liukusäädin viestii asteikon visuaalisesti).

## Rajoitukset

-   rtSurveyn verkkolomakkeessa ei ole liukusäädin-widgettiä — arvon syöttö on pelkkä numerokenttä. Visuaalisen liukusäädinkokemuksen saamiseksi käytä mobiiliasiakasta, joka tukee alue-widgettiä.
-   Hyvin laajoilla alueilla (esim. 0–10000) pelkkä `integer` rajoituksella on yhtä tehokas ja käyttäjäystävällisempi.
-   Tarkat askelarvot (esim. `step=0.1`) toimivat rajoituksina, mutta niillä ei ole liukusäätimen tarkkuuteen liittyvää huolta verkkolomakkeessa.

---
title: "Geopoint"
description: "Geopoint-kysymykset tallentavat maantieteelliset koordinaatit (leveysaste, pituusaste, korkeus ja tarkkuus) osana kyselyä."
---

`geopoint`-kysymystyyppi tallentaa maantieteelliset koordinaatit (leveysaste, pituusaste, korkeus, tarkkuus) laitteen GPS:n avulla. rtSurvey renderöi valitsimen useilla ulkoasutiloilla ja tukee automaatiota `inputs{}`- ja `outputs{}`-parametrien kautta.

## XLSFormin perusmäärittely

| type     | name        | label                       |
|----------|-------------|-----------------------------|
| geopoint | location    | Tallenna nykyinen sijainti |

Standardimäärittelystä katso [XLSForm-dokumentaatio](https://xlsform.org/en/#question-types).

## Datan muoto

Tallennetaan neljänä välilyönneillä erotettuna arvona:

```
leveysaste pituusaste korkeus tarkkuus
```

Esimerkki: `13.756331 100.501762 15 8`

---

## Ulkoasutilat

### Oletus – suorakaiteen muotoinen painike

Suorakaiteen muotoinen "ALOITA GEOPOINT" -painike avaa täyden karttamodaalin, jossa kyselyn suorittaja valitsee pisteen. Tallennuksen jälkeen painikkeen teksti muuttuu "Näytä tai muuta geopointtia" ja koordinaatit ilmestyvät alapuolelle.

Ei vaadita `appearance`-arvoa.

---

### `display{inline-icon}` – pyöreä ristikuvakkeen painike

Renderöi pyöreän kuvakepainikkeen (ristit ⊕) suorakaiteen muotoisen painikkeen sijaan. Sitä napauttamalla avautuu sama karttamodaali.

```
display{inline-icon}
```

**Yhdistettynä sijaintiin ja kokoon:**

```
display{inline-icon, left}           → painike etiketin vasemmalla puolella
display{inline-icon, top}            → painike etiketin yläpuolella
display{inline-icon, bottom}         → painike etiketin alapuolella, keskitetty
display{inline-icon, large}          → suuri kuvake (75px)
display{inline-icon, medium}         → keskikokoinen kuvake (50px)
display{inline-icon, left, large}    → suuri painike vasemmalla
```

| Koko | Kuvakkeen korkeus/leveys |
|------|------------------|
| *(oletus)* | 25px |
| `medium` | 50px |
| `large` | 75px |

---

### `display{thumbnail-square}` – live-kartan pikkukuva

Renderöi live-kartan esikatselun (Leaflet) suoraan kysymykseen painikkeen sijaan. Pikkukuva näyttää nykyisen GPS-sijainnin ja valitun pisteen. Laajennuspainikkeen napauttaminen avaa koko modaalin.

```
display{thumbnail-square}
```

**Mukautettu pikkukuvakoko:**

```
display{thumbnail-square-[WxH]}          → kiinteät pikselit
display{thumbnail-square-[400x200]}      → 400px leveä × 200px korkea

display{thumbnail-square-[W%xH%]}        → prosenttiosuus lomakkeen leveydestä
display{thumbnail-square-[100%x30%]}     → koko leveys × 30% lomakkeen leveydestä
```

---

## `display{}` vs `results{}` – ennen ja jälkeen tallennuksen

`display{}` ohjaa ulkoasua **ennen** kuin käyttäjä tallentaa sijainnin. `results{}` ohjaa ulkoasua **arvon ollessa olemassa**. Niillä voi olla eri kohdistukset.

```
display{inline-icon, right} results{left}
```

Tämä renderöi painikkeen oikealle ennen tallennusta, sitten siirtää sen vasemmalle, kun piste on tallennettu.

### `hide(value)` – piilota koordinaattien näyttö

Oletusarvoisesti tallennetut lat/lon/tarkkuus/korkeus-teksti näkyy painikkeen alapuolella. Piilota se seuraavasti:

```
results{hide(value)}
display{inline-icon} results{hide(value)}
```

---

## `inputs{}` – GPS-automaatio

### Automaattinen tallennus latauksen yhteydessä

Tallentaa GPS-sijainnin automaattisesti lomakkeen latautuessa ilman, että kyselyn suorittaja painaa mitään.

```
inputs{auto-take}
```

**Ehdollinen automaattinen tallennus** XLSForm-lausekkeella:

```
inputs{autotakeGeo(expression(if(${capture_now} = 'yes', true(), false())))}
```

### Esitäytä tekstikentästä

Täytä geopoint-kenttä kysymyksestä, joka sisältää paikannimen tai osoite-merkkijonon. rtSurvey muuntaa merkkijonon koordinaateiksi OpenStreetMap Nominatim -palvelun kautta.

```
inputs{question(address_field)}
```

---

## `outputs{}` – käänteinen geokoodaus tekstiksi

Kun piste on tallennettu, täytä `text`-kysymys automaattisesti ihmisen luettavalla osoitteella (käänteisesti geokoodattu koordinaateista).

```
outputs{question(address_field)}
```

Esimerkki:

| type | name | label | appearance |
|------|------|-------|------------|
| geopoint | location | Tallenna sijainti | `outputs{question(address_text)}` |
| text | address_text | Osoite | |

---

## `nomap` – GPS-tallennus ilman karttaa

Korvaa karttamodaalin yksinkertaisella dialogilla, joka pyytää sijaintilupaa ja tallentaa koordinaatit. Karttaa ei näytetä. Hyödyllinen vain GPS-tallennukseen edullisilla laitteilla tai kun karttalaatat eivät ole saatavilla offline-tilassa.

```
nomap
```

## Parhaat käytännöt

1. Käytä `inputs{auto-take}` kyselyn suorittajan varmennuskyselyissä, joissa GPS on pakollinen – se poistaa manuaalisen vaiheen.
2. Käytä `display{thumbnail-square}`, kun haluat, että kyselyn suorittaja vahvistaa valitun pisteen visuaalisesti ennen jatkamista.
3. Yhdistä `outputs{question(...)}` vain luku -tyyppiseen `text`-kenttään näyttääksesi käänteisesti geokoodatun osoitteen kyselyn suorittajalle.
4. Käytä `nomap` alueilla, joilla ei ole internetyhteyttä ja karttalaattoja ei voida ladata.
5. Anna GPS:n vakiintua ennen tallennusta – alle 10 metrin tarkkuus riittää yleensä kenttätutkimuksiin.

## Rajoitukset

- `inputs{question(name)}`-geokoodaus vaatii internetyhteyden – se kutsuu OpenStreetMap Nominatim API:a.
- `outputs{question(name)}`-käänteinen geokoodaus vaatii myös internetyhteyden.
- Kartan pikkukuva (`display{thumbnail-square}`) vaatii internetin laattojen lataamiseen; koordinaatit tallennetaan silti offline-tilassa.
- GPS-tarkkuus vaihtelee laitteen ja ympäristön mukaan – sisätiloissa tai kaupunkikanjonissa tarkkuus voi olla yli 50 metriä.
- Sijaintitietojen kerääminen voi vaikuttaa merkittävästi laitteen akunkestoon pitkien kyselyjen aikana.

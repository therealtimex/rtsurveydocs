---
title: "Geopoint"
description: "Geopoint-kysymykset tallentavat maantieteelliset koordinaatit (leveysaste, pituusaste, korkeus ja tarkkuus) osana kyselyä."
---

`geopoint`-kysymystyyppi tallentaa maantieteelliset koordinaatit (leveysaste, pituusaste, korkeus, tarkkuus) laitteen GPS:n avulla. rtSurvey renderöi valitsimen useilla asettelutiloilla ja tukee automaatiota `inputs{}`- ja `outputs{}`-parametrien kautta.

## Basic XLSForm Specification

| type     | name        | label                       |
|----------|-------------|-----------------------------|
| geopoint | location    | Tallenna nykyinen sijainti |

Katso vakiospesifikaatio [XLSForm-dokumentaatiosta](https://xlsform.org/en/#question-types).

## Data Format

Tallennetaan neljänä välilyönneillä erotettuna arvona:

```
latitude longitude altitude accuracy
```

Esimerkki: `13.756331 100.501762 15 8`

## Layout modes

### Oletus — suorakaiteen muotoinen painike

Suorakaiteen muotoinen "START GEOPOINT" -painike avaa koko kartan modaalin, jossa haastattelija valitsee pisteen. Tallennuksen jälkeen painikkeen teksti muuttuu muotoon "View or change geo point" ja koordinaatit näkyvät alla.

Appearance-arvoa ei vaadita.

---

### `display{inline-icon}` — pyöreä hiusristikkopainike

Renderöi pyöreän ikonipainikkeen (hiusristikko ⊕) suorakaiteen muotoisen painikkeen sijaan. Sen napauttaminen avaa saman karttamodaalin.

```
display{inline-icon}
```

**Yhdistettynä sijaintiin ja kokoon:**

```
display{inline-icon, left}           → painike etiketin vasemmalla puolella
display{inline-icon, top}            → painike etiketin yläpuolella
display{inline-icon, bottom}         → painike etiketin alapuolella, keskitettynä
display{inline-icon, large}          → suuri ikoni (75px)
display{inline-icon, medium}         → keskikokoinen ikoni (50px)
display{inline-icon, left, large}    → suuri painike vasemmalla
```

| Size | Icon height/width |
|------|------------------|
| *(default)* | 25px |
| `medium` | 50px |
| `large` | 75px |

---

### `display{thumbnail-square}` — live-kartan pikkukuva

Renderöi live-kartan esikatselun (Leaflet) suoraan kysymykseen painikkeen sijaan. Pikkukuva näyttää nykyisen GPS-sijainnin ja valitun pisteen. Laajennuspainikkeen napauttaminen avaa koko modaalin.

```
display{thumbnail-square}
```

**Mukautettu pikkukuvan koko:**

```
display{thumbnail-square-[WxH]}          → kiinteät pikselit
display{thumbnail-square-[400x200]}      → 400px leveä × 200px korkea

display{thumbnail-square-[W%xH%]}        → prosenttiosuus lomakkeen leveydestä
display{thumbnail-square-[100%x30%]}     → täysi leveys × 30% lomakkeen leveydestä
```

---

## `display{}` vs `results{}` — ennen ja jälkeen tallennuksen

`display{}` ohjaa asettelua **ennen** kuin käyttäjä tallentaa sijainnin. `results{}` ohjaa asettelua **sen jälkeen**, kun arvo on olemassa. Niillä voi olla eri tasaukset.

```
display{inline-icon, right} results{left}
```

Tämä renderöi painikkeen oikealle ennen tallennusta ja siirtää sen sitten vasemmalle, kun piste on tallennettu.

### `hide(value)` — piilota koordinaattien näyttö

Oletusarvoisesti tallennettu lat/lon/tarkkuus/korkeus-teksti näytetään painikkeen alla. Piilota se käyttämällä:

```
results{hide(value)}
display{inline-icon} results{hide(value)}
```

## `inputs{}` — GPS-automaatio

### Automaattinen tallennus ladattaessa

Tallentaa GPS-sijainnin automaattisesti, kun lomake latautuu, ilman että haastattelijan tarvitsee painaa mitään.

```
inputs{auto-take}
```

**Ehdollinen automaattinen tallennus** XLSForm-lausekkeen avulla:

```
inputs{autotakeGeo(expression(if(${capture_now} = 'yes', true(), false())))}
```

### Esitäyttö tekstikentästä

Täytä geopoint kysymyksestä, joka sisältää paikan nimen tai osoitemerkkijonon. rtSurvey geokoodaa merkkijonon koordinaateiksi OpenStreetMap Nominatimin kautta.

```
inputs{question(address_field)}
```

---

## `outputs{}` — käänteinen geokoodaus tekstiksi

Kun piste on tallennettu, täytä automaattisesti `text`-kysymys ihmisen luettavissa olevalla osoitteella (koordinaateista käänteisesti geokoodattu).

```
outputs{question(address_field)}
```

Esimerkki:

| type | name | label | appearance |
|------|------|-------|------------|
| geopoint | location | Tallenna sijainti | `outputs{question(address_text)}` |
| text | address_text | Osoite | |

---

## `nomap` — GPS-tallennus ilman karttaa

Korvaa karttamodaalin yksinkertaisella valintaikkunalla, joka pyytää sijaintilupaa ja tallentaa koordinaatit. Karttaa ei näytetä. Hyödyllinen vain GPS-tallennukseen halvemmilla laitteilla tai kun karttatiilet eivät ole saatavilla offline-tilassa.

```
nomap
```

## Best Practices

1. Käytä `inputs{auto-take}` -ominaisuutta haastattelijan vahvistamissa kyselyissä, joissa GPS on pakollinen — se poistaa manuaalisen vaiheen.
2. Käytä `display{thumbnail-square}` -ominaisuutta, kun haluat haastattelijan vahvistavan valitun pisteen visuaalisesti ennen jatkamista.
3. Yhdistä `outputs{question(...)}` vain luku -muotoiseen `text`-kenttään näyttääksesi käänteisesti geokoodatun osoitteen haastattelijalle.
4. Käytä `nomap`-asetusta alueilla, joilla ei ole internetyhteyttä ja joilla karttatiilet eivät lataudu.
5. Anna GPS-ajan vakiintua ennen tallennusta — alle 10 metrin tarkkuus on yleensä riittävä kenttätutkimuksiin.

## Limitations

- `inputs{question(name)}` geokoodaus vaatii internetyhteyden — se kutsuu OpenStreetMap Nominatim API:a.
- `outputs{question(name)}` käänteinen geokoodaus vaatii myös internetyhteyden.
- Kartan pikkukuva (`display{thumbnail-square}`) vaatii internetin tiilien lataamiseen; koordinaatit tallennetaan silti offline-tilassa.
- GPS-tarkkuus vaihtelee laitteen ja ympäristön mukaan — sisätilat tai urbaanit "kanjonit" voivat aiheuttaa yli 50 metrin epätarkkuuden.
- Sijaintitietojen kerääminen voi vaikuttaa merkittävästi laitteen akun kestoon pitkien kyselyjen aikana.

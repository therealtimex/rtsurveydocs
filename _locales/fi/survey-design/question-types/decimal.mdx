`decimal`-kysymystyyppi kerää lukuja, jotka voivat sisältää murtoluvun (esim. `3.14`, `72.5`). Se käynnistää numeerisen näppäimistön mobiililaitteissa ja tukee samoja ulkoasuasetuksia kuin `text`-tyyppi ulkoasun ja muotoilun osalta.

## XLSFormin perusmäärittely

| type | name | label |
|------|------|-------|
| decimal | weight_kg | Paino (kg) |
| decimal | height_m | Pituus (m) |
| decimal | temperature | Kehon lämpötila (°C) |

Standardimäärittelystä katso [XLSForm-dokumentaatio](https://xlsform.org/en/#question-types).

---

## Ulkoasuasetukset

### `number-hspinner` – vaakasuora pyöritin

Korvaa syötteen vaakasuoralla **− arvo +** -pyörittimellä. Miinus-/plus-painikkeiden napautus säätää arvoa määritetyllä askeleella.

```
number-hspinner
```

Näytetty arvo on muotoiltu yhdellä desimaalilla (esim. `3.0`, `72.5`). Oletusaskel on `1`; käytä `hspinner()`-funktiota desimaaliaskeleen asettamiseen.

**Mukauta painikkeen muotoa ja askelta** käyttämällä `hspinner()`-funktiota:

```
number-hspinner hspinner('left-small-square','right-small-square','0.1')
```

Parametrit: vasemman painikkeen muoto, oikean painikkeen muoto, askelarvo. Käytä desimaaliaskelta, kuten `0.5` tai `0.1`, tarkempaa hallintaa varten.

**Mukautetut värit** käyttämällä `colors()`-funktiota:

```
number-hspinner colors(0099FF,FFFFFF,FF5500,FFFFFF)
```

Neljä arvoa järjestyksessä: vasemman painikkeen tausta, vasemman painikkeen kuvake, oikean painikkeen tausta, oikean painikkeen kuvake.

---

### `thousandsep` – tuhansien erotin

Muotoilee näytetyn numeron pilkulla ryhmitettynä (esim. `1,234.56`). Raaka numero tallennetaan ilman pilkkuja. Syöteen tyyppi vaihdetaan `"text"`-tyyppiin, jotta muotoiltu näyttö on mahdollinen.

```
thousandsep
```

---

### `digisep(n, "sep")` – mukautettu numeroryhmittely

Ryhmittää kokonaisluvun osan numerot `n`:n lohkoihin, jotka erotellaan mukautetulla erottimella.

```
digisep(3," ")      → 1 234 567.89
```

Syötteen tyyppi vaihdetaan `"text"`-tyyppiin, kun tämä ulkoasu on aktiivinen.

---

### `textonly` – pakota tekstinäppäimistö

Pakottaa syötekentän `type="text"` -tyyppiseksi. Estää selaimen numero-syötteen oikkuja (piilottaa loppunollat, työpöydän pyöritysnuolet), mutta hyväksyy silti desimaaliarvot.

```
textonly
```

---

### `floating_hint` – vihje kelluu etikettinä

`hint`-teksti renderöityy syötekentän sisään paikkamerkkinä. Kun käyttäjä alkaa kirjoittaa, se kelluu kentän yläpuolella etikettinä.

```
floating_hint
```

---

### `embed` – vihje syötekentän rajojen sisällä

Samankaltainen kuin `floating_hint` – vihje sijaitsee syötekentän rajojen sisällä, kun kenttä on tyhjä. Se ei kellu, kun käyttäjä kirjoittaa.

```
embed
```

---

### `textpopup` – modaalisen dialogin syöte

Kenttää napauttamalla avautuu modaalinen dialogi, jossa on suurempi syötekenttä. Hyödyllinen pienillä näytöillä.

```
textpopup
```

---

### `charcount` – reaaliaikainen merkkilaskuri

Näyttää reaaliaikaisen `(n)`-merkkilaskurin syötekentän alapuolella, päivittyen käyttäjän kirjoittaessa.

```
charcount
```

---

### `prefix(expr)` – etuliitteen lisääminen

Lisää staattisen tai lasketun merkkijonon näytetyn arvon eteen. Tallennusarvo ei sisällä etuliitettä.

```
prefix('USD ')          → näyttää "USD 72.50", tallentaa "72.50"
prefix(${currency})     → dynaaminen etuliite toisesta kentästä
```

---

### `align_answer` – syötteen tekstin tasaus

Ohjaa syötetyn arvon vaakasuoraa tasausta syötekentän sisällä.

```
align_answer = left
align_answer = right
align_answer = center
```

---

### `inputs{qrscan}` – QR / viivakoodin skannaus kenttään

Lisää QR-koodin skannauspainikkeen syötekentän viereen. Avaa kameraskannerin ja täyttää kentän skannatulla arvolla.

```
inputs{qrscan}
```

## Rajoitukset ja validointi

| type | name | label | constraint | constraint_message |
|------|------|-------|------------|-------------------|
| decimal | weight | Paino (kg) | `. > 0 and . <= 500` | Anna arvo väliltä 0 ja 500 |
| decimal | height | Pituus (m) | `. > 0 and . <= 3` | Anna arvo väliltä 0 ja 3 |
| decimal | temp | Lämpötila (°C) | `. >= 35 and . <= 42` | Normaali lämpötila: 35°C–42°C |
| decimal | percentage | Prosenttiosuus | `. >= 0 and . <= 100` | Anna arvo väliltä 0 ja 100 |

| type | name | label | appearance | constraint | constraint_message |

```

```

## Parhaat käytännöt

1. Käytä `number-hspinner hspinner(..., '0.1')` mittauksiin, jotka vaativat yhden desimaalin tarkkuutta – pyöritin muotoilee automaattisesti yhden desimaalin tarkkuudella, pitäen arvot johdonmukaisina.
2. Käytä `textonly`-asetusta, kun selaimet lisäävät ei-toivottuja pyöritysohjaimia tai katkaisevat loppunollat (esim. `3.0` näytetään `3`:na).
3. Käytä `thousandsep`-asetusta suurille rahallisille arvoille, jotta vastaajat voivat varmistaa syöttäneensä oikean suuruusluokan.
4. Pakota alueen rajoitukset sen sijaan, että luottaisit pelkästään mobiilinäppäimistön tyyppiin.

## Rajoitukset

- Pyöritin näyttää aina yhden desimaalin – jos tarvitset enemmän tarkkuutta näytetyssä arvossa, käytä sen sijaan tavallista syötettä.
- `thousandsep` ja `digisep()` tallentavat raa'an numeron – älä lue muotoiltua näyttöarvoa laskelmissa.

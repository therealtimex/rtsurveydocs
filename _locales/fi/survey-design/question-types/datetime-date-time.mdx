`date`-, `time`- ja `datetime`-kysymystyypit tallentavat päivämäärä- ja/tai aikatietoja. rtSurvey renderöi ne useilla ulkoasutiloilla, joita ohjataan `appearance`-sarakkeella.

## XLSFormin perusmäärittely

| type     | name           | label                     |
|----------|----------------|---------------------------|
| date     | birth_date     | Syntymäaika               |
| time     | start_time     | Mihin aikaan se alkoi?    |
| datetime | event_datetime | Milloin tapahtuma sattui? |

Standardimäärittelystä katso [XLSForm-dokumentaatio](https://xlsform.org/en/#question-types).

## Ulkoasutilat

### Oletus – aina auki oleva kalenteri

Ei tarvita `appearance`-arvoa. Kalenteri (ja kello `time`/`datetime`-tyypeille) renderöityy suoraan sivulle – aina näkyvissä, ei tarvita painiketta.

| type | name       | label         | appearance |
|------|------------|---------------|------------|
| date | start_date | Käyntipäivä   |            |

---

### `inline` – pyöreä painike → modaali

Pyöreä kuvakepainike (kalenteri tai kello) kelluu kysymyksen etiketin vieressä. Sitä napauttamalla avautuu modaali, jossa on valitsin. Valinnan jälkeen valittu arvo näkyy tekstinä etiketin vieressä.

- Painikkeen tausta: ensisijainen teeman väri (muokattavissa)
- Painikkeen muoto: täysi ympyrä (`border-radius: 50%`)

```
| type | name       | label         | appearance |
|------|------------|---------------|------------|
| date | start_date | Käyntipäivä   | inline     |
```

---

### `inline-onlyresult` – painike katoaa valinnan jälkeen

Sama kuin `inline`, mutta painike piiloutuu itsestään, kun arvo on valittu. Hyödyllinen, kun haluat päivämäärän näkyvän vasta sen jälkeen, kun se on valittu, ilman pysyvää kuvaketta.

```
inline-onlyresult
```

---

### `inline-1line` – rivi pyörittimiä

Renderöi yksittäiset pyöritinsäätimet (▲ arvo ▼) yhdelle vaakasuoralle riville – yksi sarake per komponentti. `date`: kuukausi / päivä / vuosi. `datetime`: kuukausi / päivä / vuosi / tunnit / minuutit. `time`: tunnit / minuutit.

Ei modaalia tai kalenterin ponnahdusikkunaa – käyttäjä vierittää kutakin pyöritintä itsenäisesti.

```
inline-1line
```

**Näytä vain tietyt komponentit** lisäämällä komponenttien nimet:

```
inline-1line month year      → piilottaa päiväpyörittimen
inline-1line year            → näyttää vain vuoden
```

**Rajoita vuosilukuväliä:**

```
inline-1line y_range(2000-2030)
```

---

### `box` – tekstisyöte

Renderöi tavallisen tekstinsyöttökentän. Käyttäjä kirjoittaa päivämäärän suoraan käyttäen `appearance`-sarakkeessa määritettyä muotoa.

```
box(%d/%m/%Y)       → PP/KK/VVVV
box(%Y-%m-%d)       → VVVV-KK-PP
```

---

### `month-year` – vain kuukausi ja vuosi

Standardi XLSForm-ulkoasu. Valitsin alkaa vuosinäkymästä; käyttäjä valitsee kuukauden ja vuoden, mutta ei tiettyä päivää.

```
month-year
```

---

### `year` – vain vuosi

Standardi XLSForm-ulkoasu. Valitsin alkaa vuosikymmennäkymästä; vain vuosi on valittavissa.

```
year
```

---

## Mukautettu näyttömuoto

Lisää `-[muoto]` mihin tahansa `inline`-ulkoasuun ohjataksesi, miten valittu arvo näytetään tekstinä. Käyttää strftime-tyyppisiä tunnuksia.

| Tunnus | Merkitys | Esimerkki |
|-------|---------|---------|
| `%d`  | Päivä (nollalla täytetty) | 07 |
| `%e`  | Päivä (ei täyttöä) | 7 |
| `%m`  | Kuukauden numero | 04 |
| `%n`  | Kuukauden numero (ei täyttöä) | 4 |
| `%b`  | Kuukauden lyhenne | Huhti |
| `%Y`  | 4-numeroinen vuosi | 2026 |
| `%y`  | 2-numeroinen vuosi | 26 |
| `%H`  | Tunti (24h) | 14 |
| `%h`  | Tunti (ei täyttöä) | 14 |
| `%M`  | Minuutti | 05 |
| `%S`  | Sekunti | 00 |
| `%a`  | Viikonpäivän lyhenne | Ke |

**Esimerkkejä:**

```
inline-[%d/%m/%Y]            → 07/04/2026
inline-[%d %b %Y]            → 07 huhti 2026
inline-1line-[%Y-%m-%d]      → pyöritinsyöte, muotoiltu näyttö
inline-[%d/%m/%Y %H:%M]      → 07/04/2026 14:30
```

## Värin mukauttaminen

Ohita kuvakepainikkeen väri `colors()`:lla:

```
inline colors("0099FF")                   → painikkeen tausta #0099FF
inline colors("0099FF","FFFFFF")          → tausta #0099FF, kuvakkeen väri #FFFFFF
inline-1line colors("0000FF","FFFF00")    → pyörittimen korostusvärit
inline-onlyresult colors("E53935")        → punainen painike
```

## Painikkeen sijainti `display{}`:n kanssa

`display{}`-muokkaaja ohjaa, missä kuvakepainike ilmestyy kysymyksen etikettiin nähden. Koskee `inline`- ja `inline-onlyresult`-tyyppejä.

```
display{<kohdistus>, <koko>, <väri>}
```

| Parametri | Arvot | Oletus |
|-----------|--------|---------|
| Kohdistus | `left`, `right`, `top`, `center`, `bottom` | `right` |
| Koko | `small`, `medium`, `large` | `small` |
| Väri | hex esim. `#FF5500` | ensisijainen teeman väri |

**Kohdistuksen käyttäytyminen:**

| Arvo | Asettelu |
|-------|--------|
| `right` | Painike etiketin oikealla puolella |
| `left` | Painike etiketin vasemmalla puolella |
| `top` | Painike etiketin yläpuolella, koko leveyden keskitetty |
| `center` / `bottom` | Painike etiketin alapuolella, koko leveyden keskitetty |

**Esimerkkejä:**

```
inline display{left}
inline display{center, large}
inline display{right, medium, #E53935}
inline-onlyresult display{bottom, large, #0099FF}
```

## Päivämääräalueen rajoitus

Käytä `inputs{range[...]}` -asetusta rajoittaaksesi valittavissa olevia päivämääriä.

```
inputs{range[dateGt(2024-01-01), dateLt(2024-12-31)]}
```

Parametrit `range[...]`-sisällä:

| Parametri | Kuvaus |
|-----------|-------------|
| `dateGt(VVVV-KK-PP)` | Pienin valittavissa oleva päivämäärä (suurempi tai yhtä suuri) |
| `dateLt(VVVV-KK-PP)` | Suurin valittavissa oleva päivämäärä (pienempi tai yhtä suuri) |
| `indayTimeGt(HH:MM:SS)` | Pienin aika päivän aikana (vain datetime) |
| `indayTimeLt(HH:MM:SS)` | Suurin aika päivän aikana (vain datetime) |

Useita alueita voidaan määrittää – päivämäärä on valittavissa, jos se kuuluu **mihin tahansa** alueeseen.

## Piilota etiketti

Lisää `text-nolabel` piilottaaksesi kysymyksen etiketin. Painike renderöityy yksin.

```
inline text-nolabel display{center, large}
```

## Asettelun yhteenveto

| Appearance | Widget rendered | Väri muokattavissa |
|---|---|---|
| *(ei mitään)* | Aina auki oleva kalenteri | Ei |
| `inline` | Pyöreä painike → modaalikalenteri | Kyllä |
| `inline-onlyresult` | Pyöreä painike → modaali, katoaa valinnan jälkeen | Kyllä |
| `inline-1line` | Pyörittimien rivi | Kyllä |
| `box(%format%)` | Tekstinsyöttökenttä | Ei |
| `month-year` | Kuukausi/vuosi-valitsin | Ei |
| `year` | Vain vuosi-valitsin | Ei |

## Parhaat käytännöt

1. Käytä `inline`-asetusta kompakteissa lomakkeissa – se säästää pystysuuntaista tilaa verrattuna aina auki olevaan kalenteriin.
2. Käytä `inline-1line`-asetusta, kun vastaajien on säädettävä yksittäisiä päivämäärän komponentteja (esim. syntymävuosi).
3. Käytä `box()`-asetusta vain, kun luotat kyselyn suorittajan syöttävän päivämäärät oikein – validointikäyttöliittymää ei näytetä.
4. Käytä `display{center, large}` -asetusta, jotta painike on näkyvämpi mobiilinäytöillä.
5. Määritä aina `-[muoto]`, kun oletusarvoinen `VVVV-KK-PP`-näyttö hämmentäisi paikallisia käyttäjiä.
6. Ole tietoinen aikavyöhykkeistä kerätessäsi datetime-dataa eri alueilla.

## Rajoitukset

- `inline-1line` oletusarvoisesti aina nykyiseen päivämäärään, jos arvoa ei ole – käytä `default`-saraketta esitäyttääksesi tietyn päivämäärän.
- `box()`-muoto ohjaa vain näyttöä; tallennettu arvo on aina ISO 8601.
- Päivämääräalueen rajoitus (`inputs{range[...]}`) ei toimi `box`-ulkoasun kanssa.
- Aikavyöhyke-erot voivat monimutkaistaa data-analyysiä, jos niitä ei oteta asianmukaisesti huomioon.

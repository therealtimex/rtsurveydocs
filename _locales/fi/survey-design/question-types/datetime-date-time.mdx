Kysymystyypit `date`, `time` ja `datetime` keräävät päivämäärä- ja/tai aikaviisumit. rtSurvey esittää ne useilla eri asettelutiloilla, joita ohjataan `appearance`-sarakkeella.

## XLSForm-perusmäärittely

| type     | name           | label                         |
|----------|----------------|-------------------------------|
| date     | birth_date     | Syntymäaika                   |
| time     | start_time     | Mihin aikaan se alkoi?        |
| datetime | event_datetime | Milloin tapahtuma sattui?     |

Katso vakiomäärittelyt [XLSForm-dokumentaatiosta](https://xlsform.org/en/#question-types).

## Aettelutilat

### Oletus — aina avoin kalenteri

Ulkoasuarvoa (appearance) ei tarvita. Kalenteri (ja kello `time`/`datetime`-tyypeille) näkyy suoraan sivulla — aina näkyvissä, painiketta ei tarvita.

| type | name       | label         | appearance |
|------|------------|---------------|------------|
| date | start_date | Käyntipäivä   |            |

---

### `inline` — pyöreä painike → modaali

Kysymyksen otsikon vieressä on pyöreä ikonipainike (kalenteri tai kello). Sen napauttaminen avaa modaali-ikkunan valitsimella. Valinnan jälkeen valittu arvo näkyy tekstinä otsikon vieressä.

- Painikkeen tausta: teeman ensisijainen väri (ylitettävissä)
- Painikkeen muoto: täysi ympyrä (`border-radius: 50%`)

```
| type | name       | label         | appearance |
|------|------------|---------------|------------|
| date | start_date | Käyntipäivä   | inline     |
```

---

### `inline-onlyresult` — painike katoaa valinnan jälkeen

Sama kuin `inline`, mutta painike piiloutuu, kun arvo on valittu. Hyödyllinen, kun haluat päivämäärän olevan näkyvissä vasta valinnan jälkeen ilman pysyvää kuvaketta.

```
inline-onlyresult
```

---

### `inline-1line` — rullavalitsinrivi (spinners)

Esittää yksittäiset rullavalitsimet (▲ arvo ▼) yhdessä vaakasuorassa rivissä — yksi sarake kullekin osalle. `date`: kuukausi / päivä / vuosi. `datetime`: kuukausi / päivä / vuosi / tunnit / minuutit. `time`: tunnit / minuutit.

Ei modaalia tai kalenteria — käyttäjä rullaa kutakin valitsinta itsenäisesti.

```
inline-1line
```

**Näytä vain tietyt osat** lisäämällä osien nimet:

```
inline-1line month year      → piilottaa päivävalitsimen
inline-1line year            → näyttää vain vuoden
```

**Rajoita vuosiväliä:**

```
inline-1line y_range(2000-2030)
```

---

### `box` — tekstinsyöttö

Esittää tavallisen tekstinsyöttökentän. Käyttäjä kirjoittaa päivämäärän suoraan käyttämällä ulkoasussa määritettyä muotoa.

```
box(%d/%m/%Y)       → PP/KK/VVVV
box(%Y-%m-%d)       → VVVV-KK-PP
```

---

### `month-year` — vain kuukausi ja vuosi

Vakio XLSForm-ulkoasu. Valitsin alkaa vuosinäkymästä; käyttäjä valitsee kuukauden ja vuoden, mutta ei tiettyä päivää.

```
month-year
```

---

### `year` — vain vuosi

Vakio XLSForm-ulkoasu. Valitsin alkaa vuosikymmennäkymästä; vain vuosi on valittavissa.

```
year
```

---

## Mukautettu näyttömuoto

Lisää `-[muoto]` mihin tahansa `inline`-ulkoasuun hallitaksesi sitä, miten valittu arvo näytetään tekstinä. Käyttää strftime-tyylisiä merkkejä.

| Merkki | Merkitys | Esimerkki |
|-------|---------|---------|
| `%d`  | Päivä (nollalla täytetty) | 07 |
| `%e`  | Päivä (ilman nollaa) | 7 |
| `%m`  | Kuukauden numero | 04 |
| `%n`  | Kuukauden numero (ilman nollaa) | 4 |
| `%b`  | Kuukauden lyhenne | huhti |
| `%Y`  | 4-numeroinen vuosi | 2026 |
| `%y`  | 2-numeroinen vuosi | 26 |
| `%H`  | Tunti (24h) | 14 |
| `%h`  | Tunti (ilman nollaa) | 14 |
| `%M`  | Minuutti | 05 |
| `%S`  | Sekunti | 00 |
| `%a`  | Viikonpäivän lyhenne | ke |

**Esimerkkejä:**

```
inline-[%d.%m.%Y]            → 07.04.2026
inline-[%d %b %Y]            → 07 huhti 2026
inline-1line-[%Y-%m-%d]      → rullavalitsinsyöttö, muotoiltu näyttö
inline-[%d.%m.%Y %H:%M]      → 07.04.2026 14:30
```

## Värien mukauttaminen

Ylitä ikonipainikkeen väri käyttämällä `colors()`-funktiota:

```
inline colors("0099FF")                   → painikkeen tausta #0099FF
inline colors("0099FF","FFFFFF")          → tausta #0099FF, ikonin väri #FFFFFF
inline-1line colors("0000FF","FFFF00")    → rullavalitsimen korostusvärit
inline-onlyresult colors("E53935")        → punainen painike
```

## Painikkeen sijainti `display{}`-määritteellä

`display{}`-määrite ohjaa sitä, missä ikonipainike näkyy suhteessa kysymyksen otsikkoon. Koskee `inline`- ja `inline-onlyresult`-tyyppejä.

```
display{<align>, <size>, <color>}
```

| Parametri | Arvot | Oletus |
|-----------|--------|---------|
| Align | `left`, `right`, `top`, `center`, `bottom` | `right` |
| Size | `small`, `medium`, `large` | `small` |
| Color | hex esim. `#FF5500` | teeman ensisijainen väri |

**Sijaintikäyttäytyminen:**

| Arvo | Asettelu |
|-------|--------|
| `right` | Painike otsikon oikealla puolella |
| `left` | Painike otsikon vasemmalla puolella |
| `top` | Painike otsikon yläpuolella, koko leveys keskellä |
| `center` / `bottom` | Painike otsikon alapuolella, koko leveys keskellä |

**Esimerkkejä:**

```
inline display{left}
inline display{center, large}
inline display{right, medium, #E53935}
inline-onlyresult display{bottom, large, #0099FF}
```

## Päivämäärävälin rajoitus

Käytä `inputs{range[...]}`-määritettä rajoittamaan valittavissa olevia päivämääriä.

```
inputs{range[dateGt(2024-01-01), dateLt(2024-12-31)]}
```

Parametrit `range[...]`-määritteen sisällä:

| Parametri | Kuvaus |
|-----------|-------------|
| `dateGt(YYYY-MM-DD)` | Pienin valittavissa oleva päivämäärä (suurempi tai yhtä suuri kuin) |
| `dateLt(YYYY-MM-DD)` | Suurin valittavissa oleva päivämäärä (pienempi tai yhtä suuri kuin) |
| `indayTimeGt(HH:MM:SS)` | Päivän sisäinen vähimmäisaika (vain datetime) |
| `indayTimeLt(HH:MM:SS)` | Päivän sisäinen enimmäisaika (vain datetime) |

Voidaan määritellä useita välejä — päivämäärä on valittavissa, jos se osuu **mihin tahansa** väleistä.

## Otsikon piilottaminen

Lisää `text-nolabel` piilottaaksesi kysymyksen otsikon. Painike näkyy yksinään.

```
inline text-nolabel display{center, large}
```

## Parhaat käytännöt

1. Käytä `inline`-ulkoasua tiiviissä lomakkeissa — se säästää pystysuoraa tilaa verrattuna aina avoimeen kalenteriin.
2. Käytä `inline-1line`-ulkoasua, kun vastaajien on säädettävä yksittäisiä päivämäärän osia (esim. syntymävuosi).
3. Käytä `box()`-ulkoasua vain, kun luotat siihen, että tiedonkerääjä kirjoittaa päivämäärät oikein — validointikäyttöliittymää ei näytetä.
4. Käytä `display{center, large}` -määritettä tehdäksesi painikkeesta näkyvämmän mobiilinäytöillä.
5. Määritä aina `-[muoto]`, jos oletusarvoinen `YYYY-MM-DD`-näyttö hämmentäisi paikallisia käyttäjiä.
6. Huomioi aikavyöhykkeet, kun keräät datetime-tietoja eri alueilta.

## Rajoitukset

- `inline-1line` käyttää oletuksena aina tämän päivän päivämäärää, jos arvoa ei ole — käytä `default`-saraketta esitäyttääksesi tietyn päivämäärän.
- `box()`-muoto hallitsee vain näyttöä; tallennettu arvo on aina ISO 8601.
- Päivämäärävälin rajoitus (`inputs{range[...]}`) ei toimi `box`-asettelun kanssa.
- Aikavyöhyke-erot voivat monimutkaistaa data-analyysia, jos niitä ei oteta asianmukaisesti huomioon.

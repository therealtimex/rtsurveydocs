`calculate`-kysymystyyppi suorittaa kaavan hiljaa taustalla. Se tallentaa tuloksen nimettyyn kenttään, johon muut kysymykset voivat viitata — mutta se ei näytä haastattelijalle syöttökenttää tai otsikkoa. Käytä sitä arvojen johtamiseen, merkkijonojen yhdistämiseen, ehdollisen logiikan suorittamiseen tai tietojen hakemiseen, joita tarvitset myöhemmin lomakkeessa.

---

## Perussyntaksi

| type | name | label | calculation |
|------|------|-------|-------------|
| calculate | total | | `${price} * ${quantity}` |

- **type**: Aina `calculate`.
- **name**: Yksilöllinen kentän nimi. Muut kysymykset viittaavat tähän `${name}`-muodossa.
- **label**: Jätä tyhjäksi — calculate-kenttiä ei koskaan näytetä haastattelijalle.
- **calculation**: Arvioitava kaava. Tukee kaikkia [XLSForm-funktioita](../operators-and-functions/functions) ja kenttäviittauksia.

## Yleisiä malleja

### Aritmetiikka

| type | name | label | calculation |
|------|------|-------|-------------|
| integer | price | Unit price | |
| integer | quantity | Quantity | |
| calculate | total | | `${price} * ${quantity}` |
| note | total_note | Total: `${total}` | |

### Merkkijonojen yhdistäminen

| type | name | label | calculation |
|------|------|-------|-------------|
| text | first_name | First name | |
| text | last_name | Last name | |
| calculate | full_name | | `concat(${first_name}, ' ', ${last_name})` |

### Ehdollinen arvo

| type | name | label | calculation |
|------|------|-------|-------------|
| integer | score | Score (0–100) | |
| calculate | grade | | `if(${score} >= 90, 'A', if(${score} >= 75, 'B', if(${score} >= 60, 'C', 'F')))` |

### Ikä syntymäajasta

| type | name | label | calculation |
|------|------|-------|-------------|
| date | dob | Date of birth | |
| calculate | age_years | | `int((today() - ${dob}) div 365.25)` |

## `once()`-funktion käyttö arvon lukitsemiseen

Oletusarvoisesti `calculate` lasketaan uudelleen aina, kun jokin viitattu kenttä muuttuu. Kääri kaava `once()`-funktioon, jotta se lasketaan vain ensimmäisellä latauskerralla ja tulos lukitaan:

| type | name | label | calculation |
|------|------|-------|-------------|
| calculate | interview_start | | `once(now())` |

Käytä `once()`-funktiota aikaleimoihin, alkuarvoihin tai mihin tahansa tapaukseen, jossa uudelleenlaskenta muutoksen yhteydessä ei ole toivottavaa.

## Tiedon haku ulkoisista lähteistä

### CSV-tiedostosta

```
pulldata('staff.csv', 'department', 'name', ${staff_id})
```

Katso koko viite kohdasta [pulldata()](../operators-and-functions/pulldata).

### Mukana tulevasta SQLite-tietokannasta

```
pulldata('rawquery',
  concat(${family_path}, '/locations.db::provinces'),
  'SELECT name FROM provinces WHERE id = ?',
  ${province_id})
```

Katso polun muodostamisen tiedot kohdasta [Paikallinen tietokantahaku](../advanced-features/local-database-search).

### Sovelluksen kontekstista

```
pulldata('app-api', 'user.username')
pulldata('app-api', 'family_path')
```

Katso kaikki saatavilla olevat avaimet kohdasta [App API](../app-api).

## Calculate-kentän käyttö relevant- ja constraint-ehdoissa

Muut kentät voivat viitata `calculate`-tulokseen aivan kuten mihin tahansa kenttään:

| type | name | label | relevant | constraint |
|------|------|-------|----------|------------|
| calculate | bmi | | | `${weight} div (${height} * ${height}) * 10000` |
| note | bmi_warning | BMI is very high — please verify weight and height. | `${bmi} > 40` | |

## Parhaat käytännöt

1. Anna calculate-kentille merkitykselliset nimet — `total_cost` on selkeämpi kuin `calc1` ja helpompi seurata vienneissä.
2. Jaa monimutkaiset kaavat useisiin ketjutettuihin calculate-kenttiin yhden syvälle sisäkkäisen lausekkeen sijaan.
3. Käytä `once()`-funktiota aikaleimoihin ja alkutilanteisiin estääksesi arvojen muuttumisen ensimmäisen tallennuksen jälkeen.
4. Sijoita `calculate`-kentät ennen ensimmäistä niihin viittaavaa kysymystä — laskentajärjestys noudattaa lomakkeen järjestystä.
5. Pidä `label`-sarake tyhjänä. Jotkut työkalut näyttävät otsikon; sen jättäminen tyhjäksi välttää hämmentävän tulosteen.

## Rajoitukset

- Calculate-kenttiä ei koskaan näytetä suoraan haastattelijalle — käytä `note`-kenttää tuloksen näyttämiseen.
- `calculation`-sarake on pakollinen; `calculate`-rivi ilman kaavaa tallentaa aina tyhjän merkkijonon.
- Tulokset lasketaan uudelleen jokaisen lomakemuutoksen yhteydessä, ellei niitä ole kääritty `once()`-funktioon — erittäin monimutkaiset kaavat suurissa lomakkeissa voivat vaikuttaa suorituskykyyn halvemmissa laitteissa.
- Lasketut arvot tallennetaan merkkijonoina lähetyksessä. Käytä `number()`-, `int()`- tai `boolean()`-funktioita tyypin muuntamiseen, kun välität tuloksen aritmeettisiin tai loogisiin lausekkeisiin.

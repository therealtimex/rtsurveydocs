`file`-kysymystyyppi antaa vastaajille mahdollisuuden **ladata minkä tahansa tiedoston** laitteeltaan — dokumentteja, taulukkolaskentatiedostoja, PDF-tiedostoja tai muita tiedostotyyppejä. Toisin kuin `image`-, `audio`- ja `video`-tyypit, jotka avaavat tiettyjä tallennustyökaluja, `file` avaa yleiskäyttöisen tiedostonvalitsimen.

## XLSForm-perusmäärittely

| type | name      | label                        |
|------|-----------|------------------------------|
| file | document  | Ole hyvä ja lataa tiedostosi |

Katso lisätietoja vakiomuotoisesta tiedostokysymystyypistä [XLSForm-määrittelystä](https://xlsform.org/en/#question-types).

## Käyttötarkoitukset

Tiedostokysymyksiä käytetään yleensä seuraaviin tarkoituksiin:

1. Tukidokumenttien kerääminen (kuitit, todistukset, sopimukset, raportit)
2. Täytettyjen ja skannattujen paperilomakkeiden lataaminen
3. Taulukkolaskentatiedostojen tai dataexporttien kerääminen muista järjestelmistä
4. Mitkä tahansa digitaaliset tiedostotyypit, joita kuva/ääni/video ei kata

## Tietomuoto

Ladatut tiedostot tallennetaan binaarisina liitteinä:

- **Muoto:** Säilytetään alkuperäisessä muodossa (PDF, XLSX, DOCX jne.)
- **Nimeäminen:** `{instanceID}-{fieldname}.{extension}`
- **Tallennus:** Ladataan palvelimen mediakansioon vastauksen mukana
- **Käyttö:** Ladattavissa vastausten hallintaliittymästä

## rtSurvey-laajennukset

### Hyväksytyt tiedostotyypit

Käytä `parameters`-saraketta rajoittaaksesi, mitä tiedostotyyppejä voidaan valita:

| type | name | label | parameters |
|------|------|-------|------------|
| file | report | Lataa tarkastusraportti | `accept=.pdf` |
| file | spreadsheet | Lataa datatiedosto | `accept=.xlsx,.csv` |

`accept`-parametri käyttää vakiomuotoista tiedostopäätteen syntaksia (pilkulla erotettu).

### Tiedostokoon ohjeistus

rtSurvey ei aseta tiukkaa tiedostokohtaisesta rajoitusta kysymystasolla, mutta palvelimen latausrajoitus on voimassa. Käytä `hint`-saraketta viestiäksesi odotukset haastattelijalle (enumerator):

| type | name | label | hint |
|------|------|-------|------|
| file | receipt | Lataa maksukuitti | Hyväksytyt: PDF tai kuva. Tiedoston enimmäiskoko: 5 MB |

### Integraatio laitteen tiedostojärjestelmään ja pilvitallennukseen

Androidilla ja iOS:llä `file`-kysymys avaa laitteen oman tiedostonvalitsimen, joka voi sisältää pääsyn seuraaviin:
- Laitteen paikallinen tallennustila
- SD-kortti (Android)
- iCloud Drive (iOS)
- Google Drive, Dropbox (jos asennettu)

Verkkoselaimessa se avaa selaimen vakiomuotoisen tiedostonlatausikkunan.

### Inline-painikeasettelu (Inline button layout)

Lisää `inline` runderoidaksesi latauksen **pyöreänä kuvakepainikkeena** etiketin vieressä koko leveyden tiedostonvalitsimen sijaan.

```
| type | name | label           | appearance                              |
|------|------|-----------------|-----------------------------------------|
| file | doc  | Lataa tiedosto  | inline display{right}                   |
| file | doc  | Lataa tiedosto  | inline display{left, large}             |
| file | doc  | Lataa tiedosto  | inline display{center, large, <0099FF/>} |
```

**Painikkeen sijainti** — `left`, `right` *(oletus)*, `top`, `center`, `bottom`

**Painikkeen koko** — `small` *(oletus)*, `medium`, `large`

**Painikkeen väri** — lisää hex-väri `display{}`-määritteen sisään korvataksesi ensisijaisen värin:

```
inline display{right, large, <FF5500/>}
```

**Tallennuksen jälkeinen hallinta — `results{}`:**

| Appearance | Effect |
|---|---|
| `results{hide(capture)}` | Piilottaa latauspainikkeen, kun tiedosto on liitetty |
| `results{hide(review)}` | Piilottaa tarkastelu/esikatselupainikkeen latauksen jälkeen |
| `results{hide(filename)}` | Piilottaa latauksen jälkeen näkyvän tiedostonimen |
| `results{left}` | Siirtää kuvakkeen vasemmalle latauksen jälkeen |

Esimerkki — piilota latauspainike tiedoston liittämisen jälkeen:
```
inline display{right} results{hide(capture)}
```

### Etiketin piilottaminen (Suppress the label)

```
inline text-nolabel display{center, large}
```

## Parhaat käytännöt

1. Käytä `accept`-rajoitusta — tämä estää haastattelijoita lataamasta vahingossa vääriä tiedostoja.
2. Sisällytä aina koko- ja muoto-ohjeet `hint`-sarakkeeseen.
3. Käytä valokuville ja kuville mieluummin `image`-tyyppiä — se tarjoaa paremman pakkauksen ja johdonmukaisen muodon käsittelyn.
4. Suunnittele tiedostoliitteitä sisältävissä suurissa kyselyissä tallennustila ja latauskaistan tarve etukäteen.
5. Testaa tiedostonvalitsin kohdelaitteella (Android vs. iOS vs. verkko) ennen käyttöönottoa — pääsy pilvipalveluihin vaihtelee.

## Tietojen käsittelyyn liittyvät huomiot

- Tiedostot tallennetaan alkuperäisessä muodossaan; rtSurvey ei muunna tai pakkaa niitä.
- Analysoi tiedostot latauksen jälkeen — rtSurvey ei pura tai indeksoi tiedostojen sisältöä.
- Suuret tiedostoliitteet pidentävät merkittävästi koko aineiston lataamiseen kuluvaa aikaa.

## Rajoitukset (Limitations)

- Tiedostokysymykset eivät validoi tiedoston sisältöä — vain tiedostopäätteen tarkistus `accept`-määritteen kautta on voimassa käyttöliittymätasolla.
- Erittäin suuret tiedostot (100 MB+) saattavat aikakatkaista latauksen heikoissa yhteysolosuhteissa.
- Offline-tilassa olevat haastattelijat voivat liittää tiedostoja, mutta ne latautuvat vasta, kun yhteys palautuu.
- Jotkut laitekokoonpanot rajoittavat pääsyä tiettyihin tallennuspaikkoihin (esim. yritysten MDM-käytännöt).

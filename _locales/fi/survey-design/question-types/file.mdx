`file`-kysymystyyppi antaa vastaajille mahdollisuuden **ladata minkä tahansa tiedoston** laitteestaan – dokumentteja, taulukkolaskentatiedostoja, PDF-tiedostoja tai muita tiedostotyyppejä. Toisin kuin `image`-, `audio`- ja `video`-tyypit, jotka käynnistävät tietyt tallennustyökalut, `file` avaa yleiskäyttöisen tiedostonvalitsimen.

## XLSFormin perusmäärittely

| type | name      | label                      |
|------|-----------|----------------------------|
| file | document  | Ole hyvä ja lataa asiakirjasi |

Lisätietoja standardista tiedostokysymystyypistä löytyy [XLSFormin määrittelystä](https://xlsform.org/en/#question-types).

## Käyttötarkoitukset

Tiedostokysymyksiä käytetään yleisesti:

1. Tukidokumenttien keräämiseen (kuitit, todistukset, sopimukset, raportit)
2. Skannattujen valmiiden paperilomakkeiden lataamiseen
3. Taulukkolaskentatiedostojen tai datan vientien keräämiseen muista järjestelmistä
4. Muiden digitaalisten tiedostotyyppien, joita kuva/ääni/video ei kata

## Datan formaatti

Ladattavat tiedostot tallennetaan binaariliitteinä:

- **Formaatti:** Säilytetään alkuperäisessä muodossa (PDF, XLSX, DOCX jne.)
- **Nimeäminen:** `{instanceID}-{fieldname}.{extension}`
- **Tallennus:** Ladataan palvelimen mediakansioon lähetystietueen rinnalle
- **Käyttö:** Ladattavissa lähetysten hallintaliittymästä

## rtSurvey-laajennukset

### Hyväksytyt tiedostotyypit

Käytä `parameters`-saraketta rajoittaaksesi valittavissa olevia tiedostotyyppejä:

| type | name | label | parameters |
|------|------|-------|------------|
| file | report | Lataa tarkastusraportti | `accept=.pdf` |
| file | spreadsheet | Lataa datatiedosto | `accept=.xlsx,.csv` |

`accept`-parametri käyttää standardia tiedostopäätteen syntaksia (pilkulla eroteltuna).

### Tiedostokoon ohjeistus

rtSurvey ei pakota kiinteää tiedostokokorajoitusta kysymystasolla, mutta palvelimen latausraja on voimassa. Käytä `hint`-saraketta ilmoittaaksesi odotukset kyselyn suorittajalle:

| type | name | label | hint |
|------|------|-------|------|
| file | receipt | Lataa maksukuitti | Hyväksytyt: PDF tai kuva. Suurin tiedostokoko: 5 MB |

### Integrointi laitteen tiedostojärjestelmään ja pilvitallennukseen

Androidilla ja iOS:llä `file`-kysymys avaa laitteen natiivin tiedostonvalitsimen, joka voi sisältää pääsyn:
- Paikalliseen laitetallennustilaan
- SD-kortille (Android)
- iCloud Driveen (iOS)
- Google Driveen, Dropboxiin (jos asennettu)

Verkossa se avaa selaimen standardin tiedoston latausdialogin.

### Inline-painikkeen asettelu

Lisää `inline` renderöimään latauksen **pyöreäksi kuvakepainikkeeksi** etiketin viereen koko leveyden tiedostonvalitsimen sijaan.

```
| type | name | label           | appearance                              |
|------|------|-----------------|-----------------------------------------|
| file | doc  | Lataa asiakirja | inline display{right}                   |
| file | doc  | Lataa asiakirja | inline display{left, large}             |
| file | doc  | Lataa asiakirja | inline display{center, large, <0099FF/>} |
```

**Painikkeen sijainti** — `left`, `right` *(oletus)*, `top`, `center`, `bottom`

**Painikkeen koko** — `small` *(oletus)*, `medium`, `large`

**Painikkeen väri** — lisää heksaväri `display{}`-sisään ohittaaksesi ensisijaisen värin:

```
inline display{right, large, <FF5500/>}
```

**Tallennuksen jälkeinen hallinta — `results{}`:**

| Appearance | Vaikutus |
|---|---|
| `results{hide(capture)}` | Piilottaa latauspainikkeen tiedoston liittämisen jälkeen |
| `results{hide(review)}` | Piilottaa tarkistus/esikatselupainikkeen latauksen jälkeen |
| `results{hide(filename)}` | Piilottaa ladatun tiedoston nimen |
| `results{left}` | Siirtää kuvakkeen vasemmalle latauksen jälkeen |

Esimerkki – piilota latauspainike tiedoston liittämisen jälkeen:
```
inline display{right} results{hide(capture)}
```

### Piilota etiketti

```
inline text-nolabel display{center, large}
```

## Parhaat käytännöt

1. Käytä `accept`-asetusta rajoittaaksesi tiedostotyyppejä – tämä estää kyselyn suorittajia vahingossa lataamasta vääriä tiedostoja.
2. Sisällytä aina koko- ja muoto-ohjeet `hint`-sarakkeeseen.
3. Valokuville ja kuville käytä sen sijaan `image`-tyyppiä – se tarjoaa paremman pakkauksen ja johdonmukaisen muodon käsittelyn.
4. Suurissa kyselyissä, joissa on tiedostoliitteitä, suunnittele tiedontallennus ja latauskaistanleveys vastaavasti.
5. Testaa tiedostonvalitsin kohdelaitetyypillä (Android vs. iOS vs. web) ennen käyttöönottoa – pääsy pilviasemiin vaihtelee.

## Datan käsittelyn näkökohdat

- Tiedostot tallennetaan alkuperäisessä muodossaan; rtSurvey ei muunna tai pakkaa niitä.
- Analysoi tiedostot latauksen jälkeen – rtSurvey ei pura tai indeksoi tiedoston sisältöä.
- Suuret tiedostoliitteet lisäävät merkittävästi koko datajoukon lataamiseen tarvittavaa aikaa.

## Rajoitukset

- Tiedostokysymykset eivät validoi tiedoston sisältöä – vain tiedostopäätteen tarkistus `accept`-asetuksen kautta pakotetaan käyttöliittymätasolla.
- Erittäin suuret tiedostot (yli 100 Mt) voivat aiheuttaa latauksen aikakatkaisun heikon yhteyden ympäristöissä.
- Offline-kyselyn suorittajat voivat liittää tiedostoja, mutta ne eivät lataudu, ennen kuin yhteys palautuu.
- Jotkin laitekonfiguraatiot rajoittavat pääsyä tietyille tallennuspaikoille (esim. yrityksen MDM-käytännöt).

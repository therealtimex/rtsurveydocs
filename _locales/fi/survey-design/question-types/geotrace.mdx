---
title: "Geotrace"
description: "Geotrace-kysymykset tallentavat sarjan GPS-pisteitä, jotka muodostavat viivan tai polun."
---

Kysymystyyppi `geotrace` tallentaa maantieteellisten koordinaattien sarjan, joka muodostaa viivan tai polun (polyline). rtSurveyn verkkolomakkeella tämä näkyy **tekstikenttänä**, johon tiedonkerääjä (enumerator) kirjoittaa tai liittää koordinaattimerkkijonon suoraan.

## XLSForm-perusmäärittely

| type     | name        | label                        |
|----------|-------------|------------------------------|
| geotrace | river_path  | Seuraa joen kulkua |
| geotrace | road_route  | Tallenna tien reitti |

Katso standardimäärittely [XLSForm-dokumentaatiosta](https://xlsform.org/en/#question-types).

---

## Tietomuoto (Data Format)

Tallennetaan puolipisteellä eroteltuna pisteluettelona **ilman välilyöntejä puolipisteiden ympärillä**. Jokainen piste koostuu neljästä välilyönnillä erotetusta arvosta:

```
lat lon alt acc;lat lon alt acc;lat lon alt acc
```

| Component | Description |
|-----------|-------------|
| `lat` | Leveysaste desimaaliasteina |
| `lon` | Pituusaste desimaaliasteina |
| `alt` | Korkeus metreinä (`0`, jos tuntematon) |
| `acc` | GPS-tarkkuus metreinä (`0`, jos tuntematon) |

**Esimerkki — kolmipisteinen polku:**
```
13.756331 100.501762 15 8;13.758000 100.503000 14 6;13.760000 100.505000 13 5
```

Kelvollisen polun muodostamiseen tarvitaan vähintään kaksi pistettä.

---

## Miten se näkyy rtSurveyssä

rtSurveyn verkkolomakkeella `geotrace` näkyy tavallisena **tekstikenttänä**. Tiedonkerääjä kirjoittaa tai liittää koordinaattimerkkijonon. Tälle tyypille ei ole nykyisessä verkkolomakkeessa sisäänrakennettua interaktiivista karttavalitsinta.

### Pisteiden kerääminen interaktiivisesti

Suositeltu malli kenttäkeruuseen on **`geopoint`-kysymysten toistoryhmä (repeat group)** — kukin piste käyttää täyttä GPS-karttavalitsinta — yhdistettynä `calculate`-toimintoon geotrace-merkkijonon tuottamiseksi:

| type | name | label | calculation |
|------|------|-------|-------------|
| begin repeat | path_points | Tallenna kukin reittipiste | |
| geopoint | point | Tallenna piste napauttamalla | |
| end repeat | path_points | | |
| calculate | geotrace_value | | `join(';', ${path_points/point})` |

Laskettu merkkijono voidaan sitten tallentaa `text`-kysymykseen tai käyttää `geotrace`-tyypissä.

## Esimerkkikäyttö

| type | name | label | hint | required |
|------|------|-------|------|----------|
| geotrace | farm_boundary_path | Tallenna kulkureitti tilalle | Syötä kukin reittipiste puolipisteillä eroteltuna | yes |

---

## Parhaat käytännöt

1. Käytä `geopoint`-kysymysten toistoryhmää interaktiiviseen karttapohjaiseen keräämiseen ja yhdistä sitten arvot — tämä antaa tiedonkerääjille GPS-valitsimen kullekin yksittäiselle pisteelle.
2. Sisällytä odotettu muoto `hint`-sarakkeeseen, kun koordinaattien manuaalinen syöttö on tarpeen.
3. Varmista läsnäolo merkinnällä `required = yes`, kun polku on pakollinen.
4. Suunnittele tietojen puhdistus — manuaalisesti syötettyjen polkujen tarkkuus voi vaihdella.

## Rajoitukset (Limitations)

- rtSurveyn verkkolomakkeessa ei ole sisäänrakennettua interaktiivista karttavalitsinta `geotrace`-tyypille.
- Koordinaattimerkkijono voi olla pitkä monimutkaisilla poluilla — pidä tämä mielessä lomakkeen suorituskyvyn ja tallennustilan kannalta.
- Polun topologian validointi (esim. pisteiden vähimmäismäärä, itse-leikkaavuus) vaatii jälkikäsittelyä XLSForm-rajoitteiden ulkopuolella.

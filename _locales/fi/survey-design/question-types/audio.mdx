Kysymystyyppi `audio` mahdollistaa vastaajien **äänen tallentamisen** tai olemassa olevan äänitiedoston lataamisen osana heidän kyselyvastaustaan. Se on hyödyllinen suullisten kertomusten, ympäristön äänien, todistusten tai sellaisten tietojen keräämiseen, jotka välittyvät paremmin äänen kuin tekstin avulla.

## XLSForm-perusmäärittely

| type  | name        | label                        |
|-------|-------------|------------------------------|
| audio | voice_note  | Ole hyvä ja tallenna kommenttisi |

Lisätietoja standardista äänikysymystyypistä on [XLSForm-määrittelyssä](https://xlsform.org/en/#question-types).

## Käyttökohteet

Äänikysymyksiä käytetään yleisesti seuraaviin tarkoituksiin:

1. Avoimien suullisten vastausten kerääminen haastattelijan kirjoitustaakan vähentämiseksi
2. Todistusten, henkilökohtaisten tarinoiden tai suullisen historian tallentaminen
3. Ympäristön äänien dokumentointi (esim. melutasot infrastruktuurin lähellä)
4. Ääninäytteiden kerääminen kielellistä tai terveystutkimusta varten
5. Vastaajien mahdollisuus lisätä suullisia selvennyksiä numeerisiin tai valintavastauksiin

## Tietomuoto

Äänitiedostot tallennetaan binaarisina liitteinä lomakkeen lähetyksen yhteydessä, yleensä seuraavasti:

- **Muoto:** MP3 tai AAC (mobiilitallennus); WAV (korkealaatuinen tallennus)
- **Nimeäminen:** `{instanceID}-{fieldname}.mp3` (tai vastaava)
- **Tallennus:** Ladattu palvelimen mediakansioon ja linkitetty lähetystietueeseen
- **Pääsy:** Toistettavissa ja ladattavissa lähetysten hallintaliittymästä

## rtSurvey-laajennukset

### Maksimikesto

Käytä `parameters`-saraketta rajoittaaksesi tallennuksen pituutta:

| type | name | label | parameters |
|------|------|-------|------------|
| audio | interview | Tallenna haastattelu | `max-duration=120` |

`max-duration` on sekunteina. Tallennin pysähtyy automaattisesti rajan kohdalla.

### Laatunasetukset

Tallennuslaatu voidaan asettaa `parameters`-sarakkeen kautta:

| type | name | label | parameters |
|------|------|-------|------------|
| audio | feedback | Tallenna palaute | `quality=normal` |

Tuetut arvot: `low`, `normal` (oletus), `voice-only`. `voice-only` optimoi puheäänen taustamelun vaimennuksella.

### Toisto ennen lähetystä

Mobiililaitteella haastattelija voi toistaa tallennetun pätkän ennen jatkamista. Tämä on käytössä oletuksena — asetuksia ei tarvita.

### Integrointi natiiviin tallentimeen

Androidilla ja iOS:llä `audio` käynnistää laitteen natiivin tallennussovelluksen. Verkossa se käyttää selaimen sisäänrakennettua MediaRecorder-rajapintaa.

### Inline-painikeasettelu

Lisää `inline` renderöidäksesi mikrofonin **pyöreänä ikonipainikkeena** etiketin viereen.

```
| type  | name | label        | appearance                    |
|-------|------|--------------|-------------------------------|
| audio | clip | Tallenna ääni | inline display{right}         |
| audio | clip | Tallenna ääni | inline display{left, large}   |
```

**Painikkeen sijainti** — `left`, `right` *(oletus)*, `top`, `center`, `bottom`

**Painikkeen koko** — `small` *(oletus)*, `medium`, `large`

**Painikkeen väri** — lisää hex-väri `display{}`-kohdan sisään korvataksesi ensisijaisen värin:

```
inline display{right, large, <FF5500/>}
```

**Tallennuksen jälkeinen hallinta — `results{}`:**

| Appearance | Effect |
|---|---|
| `results{hide(capture)}` | Piilottaa tallennuspainikkeen äänen tallentamisen jälkeen |
| `results{hide(review)}` | Piilottaa toistopainikkeen |
| `results{hide(filename)}` | Piilottaa tiedostonimen ja keston |
| `results{left}` | Siirtää ikonin vasemmalle tallennuksen jälkeen |

Esimerkki — piilota tallennuspainike tallennuksen jälkeen, säilytä toisto:
```
inline display{right} results{hide(capture)}
```

## Esimerkkikäyttö

### Maksimikestolla ja vihjeellä

| type | name | label | hint | parameters |
|------|------|-------|------|------------|
| audio | story | Kerro meille tapahtumasta omin sanoin | Puhu selkeästi. Tallennus pysähtyy 3 minuutin kuluttua. | `max-duration=180` |

### Ehdollinen ääni — vain jos ongelmasta ilmoitettiin

| type | name | label | relevant | required |
|------|------|-------|----------|----------|
| select_one yesno | issue_found | Löytyikö ongelma? | | |
| audio | issue_audio | Tallenna kuvaus ongelmasta | `${issue_found} = 'yes'` | `${issue_found} = 'yes'` |

## Parhaat käytännöt

1. Ilmoita selkeästi `label`- tai `hint`-kohdassa, mitä haastattelijan tulee sanoa ja kuinka kauan.
2. Käytä `max-duration`-asetusta estääksesi liian suurten tiedostojen syntymisen alueilla, joilla on hidas lähetysnopeus.
3. Informoi vastaajia ennen tallennuksen aloittamista — odottamaton tallennus voi herättää tietosuojaan liittyviä huolenaiheita.
4. Testaa tallennusta kohdelaitteella ja verkko-olosuhteissa ennen käyttöönottoa.
5. Aseta `quality=voice-only` haastattelutyyppisille tallenteille tiedostokoon pienentämiseksi ymmärrettävyyden kärsimättä.

## Rajoitukset

- Äänitiedostot voivat olla suuria (2 minuutin tallenne normaalilaadulla on noin 2–4 MB) — ota tämä huomioon tietoliikennesuunnitelmassasi ja lähetysaikojen arvioinnissa.
- Kaikki selaimet eivät tue MediaRecorder-rajapintaa — Chrome ja Firefox toimivat luotettavasti; Safarissa vanhemmilla iOS-versioilla voi olla ongelmia.
- Äänivastausten tekstittäminen vaatii ylimääräistä jälkikäsittelyä (manuaalinen tai automaattinen puheesta tekstiksi -muunnos).
- Tietosuoja-asetukset voivat rajoittaa äänien tallentamista — tarkista paikalliset tietosuojavaatimukset.

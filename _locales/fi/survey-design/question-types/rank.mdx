---
title: "Järjestys"
description: "Järjestyskysymysten avulla vastaajat voivat järjestää joukon valintoja mieltymystensä tai prioriteettiensa mukaan."
---

`rank`-kysymystyyppi esittää luettelon valinnoista, jotka vastaaja järjestää mieltymystensä tai prioriteettiensa mukaan. Se tallentaa tuloksen välilyönneillä erotettuna luettelona valintojen arvoista järjestetyssä järjestyksessä, korkeimman prioriteetin valinta ensin.

> **rtSurvey-verkkolomake:** Raahaa ja järjestä -widgettiä ei ole tällä hetkellä toteutettu. Verkkolomakkeessa `rank` renderöityy valintalistana. Käytä tätä tyyppiä, kun kohdistat mobiiliasiakkaita, jotka tukevat rank-widgettiä, tai kun tallennetun arvon muoto on tärkeämpi kuin raahaa ja järjestä -vuorovaikutus.

## XLSFormin peruserittely

| type | name | label |
|------|------|-------|
| rank priorities | main_priority | Järjestä nämä yhteisön tarpeet tärkeimmästä vähiten tärkeään |

Valinnat määritellään **valintatyöarkissa** aivan kuten `select_one`:

**survey:**

| type | name | label |
|------|------|-------|
| rank priorities | main_priority | Järjestä nämä tarpeet tärkeimmästä vähiten tärkeään |

**choices:**

| list_name | name | label |
|-----------|------|-------|
| priorities | water | Puhdas vesi |
| priorities | health | Terveydenhuolto |
| priorities | education | Koulutus |
| priorities | roads | Tiet |
| priorities | electricity | Sähkö |

## Tallennetun arvon muoto

Tallennettu arvo on **välilyönneillä erotettu luettelo** valintojen arvoista järjestetyssä järjestyksessä (ensimmäinen = korkein prioriteetti):

```
water education health roads electricity
```

## Järjestettyjen sijaintien poimiminen

Käytä `selected-at()`-funktiota saadaksesi valinnan tietyssä järjestyksessä:

| type | name | label | calculation |
|------|------|-------|-------------|
| rank priorities | main_priority | Järjestä yhteisön tarpeet | |
| calculate | top_priority | | selected-at(`${main_priority}`, 0) |
| calculate | second_priority | | selected-at(`${main_priority}`, 1) |

`selected-at(${main_priority}, 0)` palauttaa **ensimmäiseksi** asetetun arvon (indeksi 0 = korkein sijoitus).

## `rank-index()`-funktion käyttäminen toistuvien ryhmien kanssa

Kun `rank`-funktiota käytetään toistuvan ryhmän sisällä, `rank-index()`-funktion avulla voit viitata järjestysnumeroon toiston ulkopuolelta:

| type | name | label | calculation |
|------|------|-------|-------------|
| calculate | first_ranked | | rank-index(1, `${score}`) |

Katso [Funktiot — Toistuvien kenttien funktiot](../operators-and-functions/functions#repeated-field-functions) saadaksesi täydelliset tiedot `rank-index()`- ja `rank-index-if()`-funktioista.

## Käyttötarkoitukset

Järjestyskysymyksiä käytetään yleisesti:

1.  **Prioriteettien järjestäminen** – yhteisöjen pyytäminen järjestämään kehitystarpeet
2.  **Mieltymysten järjestäminen** – tuoteominaisuuksien, palvelun ominaisuuksien tai politiikkavaihtoehtojen järjestäminen
3.  **Koearvojen järjestäminen** – prosessin vaiheiden järjestäminen
4.  **Top-N valinta** – yhdistettynä `selected-at()`-funktioon poimiakseen vain 1, 2 tai 3 parasta valintaa

## Parhaat käytännöt

1.  Pidä lista lyhyenä (3–7 kohdetta) – järjestäminen muuttuu kognitiivisesti raskaaksi yli 7–8 vaihtoehdon jälkeen.
2.  Käytä selkeitä, toisensa poissulkevia valintamerkintöjä välttääksesi sekaannuksen siitä, mitä "ensimmäinen" tarkoittaa.
3.  Lisää vihjeteksti, joka selittää järjestyssuunnan (esim. "Vedä järjestääksesi: ensimmäinen = tärkein").
4.  Validoi käyttämällä `count-selected(.) = x`, jos haluat varmistaa, että kaikki valinnat on järjestetty.

## Rajoitukset

-   Raahaa ja järjestä -widgettiä ei ole toteutettu rtSurvey-verkkolomakkeessa.
-   Et voi osittain järjestää – kaikki valinnat on järjestettävä.
-   Pidä listat 3–7 kohteessa; pidemmät listat muuttuvat hankaliksi asiakkaasta riippumatta.

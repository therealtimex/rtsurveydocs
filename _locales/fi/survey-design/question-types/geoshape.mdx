`geoshape`-kysymystyyppi tallentaa suljetun monikulmion — sarjan GPS-koordinaatteja, joissa ensimmäinen ja viimeinen piste ovat samat. rtSurveyn verkkolomakkeessa tämä näkyy **tekstikenttänä**, johon haastattelija syöttää tai liittää koordinaattijonon suoraan.

## XLSForm-perusmäärittely

| type     | name        | label                            |
|----------|-------------|----------------------------------|
| geoshape | field_area  | Piirrä pellon raja               |
| geoshape | zone        | Tallenna vyöhykkeen raja         |

Katso vakiomäärittelyt [XLSForm-dokumentaatiosta](https://xlsform.org/en/#question-types).

---

## Tietomuoto

Tallennetaan puolipisteellä erotettuna pisteluettelona, jossa **puolipisteiden ympärillä ei ole välilyöntejä**. Jokainen piste koostuu neljästä välilyönnillä erotetusta arvosta:

```
lat lon alt acc;lat lon alt acc;lat lon alt acc;lat lon alt acc
```

| Component | Description |
|-----------|-------------|
| `lat` | Leveysaste desimaaliasteina |
| `lon` | Pituusaste desimaaliasteina |
| `alt` | Korkeus metreinä (`0` jos tuntematon) |
| `acc` | GPS-tarkkuus metreinä (`0` jos tuntematon) |

**Monikulmion on oltava suljettu** — viimeisen pisteen on oltava sama kuin ensimmäisen.

**Esimerkki — neljän pisteen monikulmio (kolmio, suljettu):**
```
13.756331 100.501762 0 0;13.758000 100.503000 0 0;13.757000 100.506000 0 0;13.756331 100.501762 0 0
```

Vähintään kolme erillistä pistettä plus sulkeva piste vaaditaan kelvollisen monikulmion muodostamiseen.

---

## Miten se näkyy rtSurveyssä

rtSurveyn verkkolomakkeessa `geoshape` näkyy tavallisena **tekstikenttänä**. Haastattelija kirjoittaa tai liittää koordinaattijonon. Nykyisessä verkkolomakkeessa ei ole sisäänrakennettua interaktiivista monikulmiovalitsinta tälle tyypille.

### Monikulmion pisteiden kerääminen interaktiivisesti

Suositeltu tapa kenttäkeruuseen on **`geopoint`-kysymysten toistoryhmä** — kukin piste käyttää täyttä GPS-karttavalitsinta — yhdistettynä `calculate`-toimintoon, joka tuottaa geoshape-jonon:

| type | name | label | calculation |
|------|------|-------|-------------|
| begin repeat | polygon_points | Tallenna jokainen kulma | |
| geopoint | point | Napauta tallentaaksesi kulma | |
| end repeat | polygon_points | | |
| calculate | geoshape_value | | `join(';', ${polygon_points/point})` |

Yhdistämisen jälkeen lisää ensimmäinen piste manuaalisesti sulkeaksesi monikulmion, tai käytä toista calculate-toimintoa sen liittämiseen.

## Parhaat käytännöt

1. Käytä `geopoint`-kysymysten toistoryhmää interaktiiviseen karttapohjaiseen keruuseen ja yhdistä arvot — tämä antaa haastattelijoille GPS-valitsimen jokaiselle kulmalle.
2. Sulje monikulmio aina (toista ensimmäinen piste lopussa) ennen lähettämistä.
3. Sisällytä odotettu muoto `hint`-sarakkeeseen, kun koordinaattien manuaalinen syöttö on tarpeen.
4. Vaadi vähintään 3 erillistä kulmapistettä kelvolliseen monikulmioon — toteuta tämä ohjeiden avulla XLSForm-rajoitusten sijaan.
5. Käytä `geopoint`-tyyppiä yksittäisiin sijaintikysymyksiin ja `geoshape`-tyyppiä vain silloin, kun alueen rajaaminen on kyselyn todellinen tavoite.

## Rajoitukset (Limitations)

- rtSurveyn verkkolomakkeessa ei ole sisäänrakennettua interaktiivista monikulmiovalitsinta `geoshape`-tyypille.
- Monikulmio on suljettava manuaalisesti — tekstinsyöttötilassa ei ole automaattista sulkemismekanismia.
- Monikulmion topologian validointi (esim. ei itseään leikkaava, vähimmäispinta-ala) vaatii jälkikäsittelyä XLSForm-rajoitusten ulkopuolella.
- Pitkät rajat monilla kulmapisteillä tuottavat suuria tekstijonoja.

---

`barcode`-kysymystyyppi tallentaa koodiarvon skannaamalla QR-koodin tai viivakoodin laitteen kameralla. Skannerimodaalissa on myös manuaalinen tekstisyöte vararatkaisuna, kun skannaus ei ole mahdollista.

## XLSFormin perusmäärittely

| type    | name         | label                    |
|---------|--------------|--------------------------|
| barcode | product_code | Skannaa tuotteen viivakoodi |
| barcode | ticket_id    | Skannaa lippu            |

Standardimäärittelystä katso [XLSForm-dokumentaatio](https://xlsform.org/en/#question-types).

---

## Tuetut formaatit

rtSurvey tukee QR-koodeja ja standardeja 1D-viivakoodeja laitteen kameran kautta, mukaan lukien:

- QR-koodi
- UPC-A, UPC-E
- EAN-8, EAN-13
- Code 39, Code 128
- ITF, Codabar

---

## Oletusasetukset

Kun `appearance`-asetusta ei ole, kysymys renderöi koko leveyden **"HAE VIIVAKOODI"** -painikkeen. Sitä napauttamalla avautuu skannerimodaali. Onnistuneen skannauksen jälkeen painike muuttuu **"VAIHDA VIIVAKOODI"** -muotoon ja skannattu arvo näkyy alla napsautettavana linkkinä.

---

## Skannerimodaali

Skannerimodaali sisältää aina:
- **Live-kameranäkymä** — skannaa automaattisesti havaitsemisen yhteydessä; modaali sulkeutuu onnistuneen skannauksen jälkeen.
- **Manuaalinen tekstisyöte** — tekstikenttä alareunassa, johon kyselyn suorittaja voi kirjoittaa koodin, jos skannaus epäonnistuu.
- **Valmis-painike** — lähettää manuaalisesti syötetyn arvon.

Kun laitteen kamera ei ole käytettävissä, modaali palautuu **"Lataa kuva"** -vaihtoehtoon — kyselyn suorittaja voi lähettää viivakoodin kuvan dekoodattavaksi.

---

## Inline-painikkeen asettelu

Lisää `inline` renderöimään skannerin **pyöreäksi kuvakepainikkeeksi** etiketin viereen koko leveyden painikkeen sijaan.

```
| type    | name | label     | appearance                              |
|---------|------|-----------|----------------------------------------|
| barcode | code | Skannaa tuote | inline display{right}                  |
| barcode | code | Skannaa tuote | inline display{left, large}            |
| barcode | code | Skannaa tuote | inline display{center, large, <0099FF/>} |
```

**Painikkeen sijainti** — `left`, `right` *(oletus)*, `top`, `center`, `bottom`

**Painikkeen koko** — `small` *(oletus)*, `medium`, `large`

**Painikkeen väri** — lisää heksaväri `display{}`-sisään ohittaaksesi ensisijaisen värin:

```
inline display{right, large, <FF5500/>}
```

**Tallennuksen jälkeinen hallinta — `results{}`:**

| Appearance | Vaikutus |
|---|---|
| `results{hide(scanner)}` | Piilottaa skannauspainikkeen arvon tallennuksen jälkeen |
| `results{hide(review)}` | Piilottaa skannatun arvon linkin tallennuksen jälkeen |
| `results{hide(value)}` | Piilottaa skannatun arvon tekstinäytön |
| `results{left}` | Siirtää kuvakkeen vasemmalle tallennuksen jälkeen |

Esimerkki – piilota skanneri ensimmäisen skannauksen jälkeen:
```
inline display{center, large} results{hide(scanner)}
```

## `inputs{auto-close(N)}` — automaattinen skannerin sulkeminen

Sulkee skannerimodaalin automaattisesti `N` sekunnin kuluttua, jos viivakoodia ei havaita. Modaalin sisällä näytetään live-alaslaskuri.

```
inputs{auto-close(10)}     → sulkeutuu 10 sekunnin kuluttua
inputs{auto-close(5)}      → sulkeutuu 5 sekunnin kuluttua
```

Yhdistä inline-asetukseen:
```
inline display{right} inputs{auto-close(10)}
```

---

## `inputs{floating}` — kelluva, raahattava skanneri

Näyttää **minimointipainikkeen** (pakkaa kuvake ⊞) skannerimodaalin otsikossa. Sitä napauttamalla skanneri kutistuu pieneksi kelluvaksi pyöreäksi kuvakkeeksi, jota voi vetää mihin tahansa näytöllä. Kelluvaa kuvaketta napauttamalla skanneri avautuu uudelleen.

```
inputs{floating}
inline display{right} inputs{floating}
```

Hyödyllinen työnkuluissa, joissa kyselyn suorittajan on nähtävä lomake skannerin ollessa aktiivinen (esim. kohteiden skannaus luettelosta).

---

## `invisible auto-show` — automaattinen skannerin avaaminen

Piilottaa kysymyswidgetin asettelusta, mutta avaa skannerin automaattisesti sivun latautuessa. Hyödyllinen hiljaisen skannausvaiheen upottamiseen lomakkeen kulkuun.

```
invisible auto-show
inline invisible auto-show
```

---

## Toistuvissa ryhmissä

Kun `barcode` on `begin repeat` -ryhmän sisällä, onnistunut skannaus siirtyy automaattisesti **seuraavaan toistuvaan instanssiin** arvon tallentamisen jälkeen. Tämä mahdollistaa nopean peräkkäisen skannauksen ilman, että kyselyn suorittaja napauttaa "Lisää"-painiketta kohteiden välillä.

---

## Piilota etiketti

```
inline text-nolabel display{center, large}
```

## Parhaat käytännöt

1. Käytä `inputs{auto-close(N)}` -asetusta estääksesi skannerin jäämästä auki määräämättömäksi ajaksi – valitse arvo, joka antaa kyselyn suorittajille riittävästi aikaa asettaa viivakoodi (8–15 sekuntia on tyypillistä).
2. Käytä `inputs{floating}` -asetusta, kun lomakkeen on pysyttävä näkyvissä skannauksen aikana (esim. skannattaessa luettelosta, jossa kyselyn suorittaja tarkistaa näkyvän kentän).
3. Aseta viivakoodikysymys toistuvan ryhmän sisään nopeaa peräkkäistä skannausta varten – automaattinen toistumisen eteneminen poistaa manuaalisen "Lisää"-vaiheen.
4. Sisällytä aina `hint`-sarake, jossa on ohjeet sijoittelusta (esim. "Pidä viivakoodia 10–30 cm etäisyydellä kamerasta, hyvässä valossa").
5. Manuaalinen tekstisyöte skannerimodaalissa on aina käytettävissä – kouluta kyselyn suorittajia käyttämään sitä vararatkaisuna vaurioituneiden tai likaisten viivakoodien tapauksessa.

## Rajoitukset

- Skannauksen tarkkuus riippuu kameran laadusta, valaistuksesta ja viivakoodin kunnosta – vaurioituneet tai huonokontrastiset koodit eivät välttämättä skannaa luotettavasti.
- Skanneri käyttää takakameraa (ympäristöön suuntautuvaa); laitteet, joissa ei ole takakameraa, palautuvat kuvan latausvaihtoehtoon.
- `invisible auto-show` avautuu vain ensimmäisellä sivun latauksella; takaisin sivulle navigointi ei käynnistä automaattista avausta uudelleen.

rtSurveyn `appearance`-sarake mahdollistaa kysymysten visuaalisen esitystavan ja käyttäytymisen mukauttamisen kyselyissäsi. Tämä ominaisuus parantaa käyttäjäkokemusta ja voi merkittävästi tehostaa tiedonkeruuta. rtSurvey tukee standardeja XLSForm-ulkoasuattribuutteja ja laajentaa niitä lisävaihtoehdoilla.

## Standardit XLSForm-ulkoasuattribuutit

rtSurvey tukee seuraavia standardeja XLSForm-ulkoasuattribuutteja:

| Ulkoasuattribuutti (Appearance Attribute) | Kysymystyypit (Question Types) | Kuvaus |
|----------------------|----------------|-------------|
| multiline | text | Luo monirivisen tekstikentän (paras verkkoselaimille) |
| minimal | select_one, select_multiple | Näyttää vaihtoehdot pudotusvalikossa |
| quick | select_one | Siirtyy automaattisesti seuraavaan kysymykseen valinnan jälkeen (vain mobiili) |
| no-calendar | date | Estää kalenterin näkyvyyden (vain mobiili) |
| month-year | date | Sallii vain kuukauden ja vuoden valinnan |
| year | date | Sallii vain vuoden valinnan |
| horizontal-compact | select_one, select_multiple | Näyttää vaihtoehdot vaakasuunnassa (vain verkko) |
| horizontal | select_one, select_multiple | Näyttää vaihtoehdot vaakasuunnassa sarakkeissa (vain verkko) |
| likert | select_one | Esittää vaihtoehdot Likert-asteikkona |
| compact | select_one, select_multiple | Näyttää vaihtoehdot rinnakkain minimaalisella tyhjällä tilalla |
| quickcompact | select_one | Yhdistää tiiviin näytön ja automaattisen siirtymisen (vain mobiili) |
| field-list | groups | Näyttää koko ryhmän yhdellä näytöllä (vain mobiili) |
| label | select_one, select_multiple | Näyttää vaihtoehtojen otsikot ilman valintaruutuja |
| list-nolabel | select_one, select_multiple | Näyttää valintaruudut ilman otsikoita (käytä yhdessä `label`-attribuutin kanssa) |
| table-list | groups | Näyttää kysymykset taulukkomuodossa |
| signature | image | Mahdollistaa allekirjoituksen tallentamisen (vain mobiili) |
| draw | image | Sallii vapaalla kädellä piirtämisen (vain mobiili) |
| map, quick map | select_one, select_one_from_file | Mahdollistaa valinnan karttaominaisuuksista |

## Parhaat käytännöt ulkoasun (Appearance) käyttöön

1. **Johdonmukaisuus**: Käytä ulkoasuattribuutteja johdonmukaisesti koko kyselyssä yhtenäisen ilmeen saavuttamiseksi.
2. **Mobiili vs. Verkko**: Huomioi, miten ulkoasut näkyvät eri laitteilla ja alustoilla.
3. **Suorituskyky**: Ole varovainen sellaisten ulkoasuattribuuttien kanssa, jotka saattavat hidastaa lomakkeen latautumista (esim. `table-list` suurille ryhmille).
4. **Käyttäjäkokemus**: Valitse ulkoasuja, jotka tekevät tietojen syöttämisestä helpompaa ja intuitiivisempaa vastaajille.
5. **Testaus**: Testaa lomake aina kohdelaitteilla varmistaaksesi, että ulkoasut toimivat odotetulla tavalla.

## Edistyneet tekniikat

### Ulkoasujen yhdistäminen

Joitakin ulkoasuattribuutteja voidaan yhdistää monimutkaisempien asettelujen luomiseksi:

```
| type | name | label | appearance |
|------|------|-------|------------|
| select_one options | choice | Valitse yksi: | minimal compact |
```

### Dynaamiset ulkoasut

rtSurvey mahdollistaa dynaamiset ulkoasumuutokset lomakkeen logiikan perusteella:

```
| type | name | label | appearance | relevant |
|------|------|-------|------------|----------|
| text | time | Syötä aika: | inline-[%H:%M] | ${show_time} = 'yes' |
```

## Mobiilisovellusta koskevat huomiot

- Jotkin ulkoasut (esim. `quick`, `signature`) ovat ominaisia mobiililaitteille.
- Testaa perusteellisesti sekä Android- että iOS-laitteilla varmistaaksesi johdonmukaisen toiminnan.

## rtSurveyn laajennetut ulkoasuattribuutit

Standardien XLSForm-ulkoasujen lisäksi rtSurvey tukee seuraavia alustakohtaisia vaihtoehtoja:

### Tiedon ja näytön hallinta

| Ulkoasuattribuutti (Appearance Attribute) | Kysymystyypit (Question Types) | Kuvaus |
|----------------------|----------------|-------------|
| `invisible` | any | Piilottaa kentän näkyvistä, vaikka sen arvoa kerätään tai lasketaan edelleen. Eroaa `hidden`-tyypistä — kenttä osallistuu edelleen logiikkaan. |
| `displaytitle` | any | Pakottaa kentän otsikon näkyviin silloinkin, kun se muuten olisi piilotettu. |
| `autopull` | select_one, select_multiple | Noutaa automaattisesti ulkoista dataa valintojen täyttämiseksi, kun lomake latautuu tai liipaisinkenttä muuttuu. |
| `floating_hint` | text, integer, decimal | Näyttää vihjetekstin (hint) kelluvana otsikkona syöttökentän yläpuolella sen alapuolen sijaan. |
| `calculate-button` | calculate | Lisää näkyvän painikkeen, joka käynnistää kentän uudelleenlaskennan pyynnöstä automaattisen laskennan sijaan. |

### Ryhmä ja navigointi

| Ulkoasuattribuutti (Appearance Attribute) | Kysymystyypit (Question Types) | Kuvaus |
|----------------------|----------------|-------------|
| `section` | group | Esittää ryhmän kokoon taitettavana osiokorttina. Huom: vain mobiilisovellus. |
| `toc-hide` | any | Jättää kysymyksen pois sisällysluettelon (TOC) navigointipaneelista. |
| `minilog` | begin_repeat | Näyttää täytetyt toistomerkinnät tiiviinä mini-log-listana sen sijaan, että jokainen merkintä laajennettaisiin riville. |

### Syöttökäyttäytyminen

| Ulkoasuattribuutti (Appearance Attribute) | Kysymystyypit (Question Types) | Kuvaus |
|----------------------|----------------|-------------|
| `proper` | text | Muuttaa automaattisesti jokaisen sanan ensimmäisen kirjaimen suuraakkoseksi vastaajan kirjoittaessa (otsikkotyylinen käyttäytyminen). |
| `text-nolabel` | text, integer, decimal | Esittää syöttökentän ilman näkyvää otsikkoa. |
| `inline-1line` | text | Pakottaa tekstin syötön näkyviin yhdellä rivillä, vaikka kysymyksen otsikko olisi pitkä. |
| `popup` | any | Esittää kentän ponnahdusikkunassa / modaalisessa kerroksessa sivun sijaan. |

### Asettelu (Layout)

| Ulkoasuattribuutti (Appearance Attribute) | Kysymystyypit (Question Types) | Kuvaus |
|----------------------|----------------|-------------|
| `1screen` | group | Pakottaa koko ryhmän näkyviin yhdellä näytöllä ryhmän koosta riippumatta. |
| `columns(n)` | select_one, select_multiple | Näyttää vaihtoehdot `n`:ssä sarakkeessa. Esimerkki: `columns(3)` näyttää kolme saraketta valintapainikkeita (radio buttons). |
| `gridformat<row=R col=C colspan=S align=center>` | any | Sijoittaa kentän CSS-grid-asetteluun riville `R`, sarakkeeseen `C`, ulottuen `S` sarakkeen leveydelle. Käytetään `advanced-extension/grid-layout`-laajennuksen kanssa. |
| `ignore-simplify` | any | Ohjeistaa lomakkeen piirtäjää ohittamaan tämän kentän asettelun automaattisen yksinkertaistamisen tai tiivistämisen. |
| `horizontal(N)` | select_one, select_multiple | Asettaa jokaisen valinnan viemään `N` prosenttia rivin leveydestä. Esimerkki: `horizontal(50)` asettaa kaksi valintaa riviä kohden. |
| `scroll-view(N%)` | group, repeat | Rajoittaa säiliön enimmäiskorkeuden `N%`:iin näkymästä (tai ylemmästä tasosta) ja lisää vierityspalkin, kun sisältö ylittää tilan. Esimerkki: `scroll-view(60%)`. |

### Widgetit

| Ulkoasuattribuutti (Appearance Attribute) | Kysymystyypit (Question Types) | Kuvaus |
|----------------------|----------------|-------------|
| `likert` | select_one | Esittää vaihtoehdot Likert-asteikkorivinä (jo standarditaulukossa yllä; tuki vahvistettu). |
| `distress` | select_one | Esittää vaihtoehdot Kessler Psychological Distress Scale (K10) -asteikon visuaalisena widgettinä tunnekuvakkeilla. |
| `rating_box-fill-{c1}-{c2}-{c3}-{c4}-{c5}` | select_one | Esittää vaihtoehdot tyyliteltyinä arvostelulaatikoina viidellä väripaikalla. `c1` = säiliön ulkoreuna, `c2` = valitsematon reuna, `c3` = valittu reuna ja täyttö, `c4` = valitsematon tekstin väri, `c5` = valittu tekstin väri. Esimerkki: `rating_box-fill-grey-blue-green-black-white`. |
| `tagging-choices-noshow-v2-{c1}-{c2}-{c3}-{c4}-{c5}` | select_multiple | Esittää vaihtoehdot väritettyinä tunnisteina (tag chips). Viisi väripaikkaa noudattavat samaa järjestystä kuin `rating_box-fill`. Valitut vaihtoehdot korostetaan; valitsemattomat vaihtoehdot jätetään pois yhteenvetonäkymästä. |

### API-integraatio

| Ulkoasuattribuutti (Appearance Attribute) | Kysymystyypit (Question Types) | Kuvaus |
|----------------------|----------------|-------------|
| `callapi` | text, integer, decimal, select_one | Mahdollistaa API-kutsun integroinnin tälle kentälle. Laskenta-sarakkeen (calculation) tulee sisältää `callapi()`-lauseke. Katso [Call API](advanced-features/call-api). |
| `callapi-verify(params)` | text, integer, decimal | Käynnistää API-varmistuskutsun käyttäen staattisia parametreja. Lomake estää etenemisen, kunnes API vahvistaa arvon. |
| `callapi-verify(dynamicParams)` | text, integer, decimal | Sama kuin `callapi-verify`, mutta parametrit johdetaan muista kenttien arvoista suoritusaikana. |

### Kielivalitsin (Language switcher)

| Ulkoasuattribuutti (Appearance Attribute) | Kysymystyypit (Question Types) | Kuvaus |
|----------------------|----------------|-------------|
| `change_language-{colors} default('lang')` | note, text | Esittää kielivalitsinwidgetin tyyliteltynä annetuilla värikoodeilla. `default('lang')`-tunniste asettaa alkukielen (esim. `default('en')`); se kirjoitetaan sisäisesti muotoon `rtDefault('lang')` jäsennyksen aikana. Esimerkki: `change_language-blue-white default('vi')`. |

### Inline päivämäärä-/aikamuoto

`date`-, `time`- ja `datetime`-kentille voit määrittää mukautetun näyttömuodon käyttämällä ulkoasuun lisättyä muotoilujonoa:

```
inline-[%d/%m/%Y]
inline-1line-[%d/%m/%Y %H:%M]
```

Muotoilutunnisteet ovat samat kuin `format-date()` ja `format-date-time()` -funktioissa. Katso [Funktiot — Päivämäärä- ja aikafunktiot](operators-and-functions/functions#date-and-time-functions).

Esimerkki:

| tyyppi (type) | nimi (name) | otsikko (label) | ulkoasu (appearance) |
|------|------|-------|------------|
| datetime | event_time | Tapahtuman päivämäärä ja aika | inline-[%d/%m/%Y %I:%M %p] |
| date | birth_date | Syntymäaika | inline-[%d/%m/%Y] |

### Inline-painikeasettelu — `display{}` ja `results{}`

Kysymystyypeille, jotka esitetään inline-kuvakepainikkeena (`date`, `time`, `datetime`, `image`, `audio`, `video`, `file`, `barcode`, `geopoint`), kaksi ulkoasumuunninta ohjaa painikkeen sijaintia ja käyttäytymistä tallennuksen jälkeen.

#### `display{...}` — painikkeen sijainti ennen tallennusta

```
display{<align>, <size>, <color>}
```

| Parametri | Arvot | Oletus |
|-----------|--------|---------|
| Tasaus (Align) | `left`, `right`, `top`, `center`, `bottom` | `right` |
| Koko (Size) | `small`, `medium`, `large` | `small` |
| Väri (Color) | hex esim. `#FF5500` | teeman ensisijainen väri |
| Lippu (Flag) | `inline-icon` | pakottaa kuvaketilan |

| Tasausarvo (Align) | Asettelu |
|-------------|--------|
| `right` | Painike otsikon oikealla puolella |
| `left` | Painike otsikon vasemmalla puolella |
| `top` | Painike otsikon yläpuolella, keskitetty koko leveydelle |
| `center` / `bottom` | Painike otsikon alapuolella, keskitetty koko leveydelle |

#### `results{...}` — asettelu ja näkyvyys tallennuksen jälkeen

Perii `display{}`-asetukset. Käytä painikkeen siirtämiseen tai elementtien piilottamiseen, kun arvo on tallennettu.

```
results{<align>, hide(<element>)}
```

| `hide`-arvo | Vaikutus |
|---|---|
| `hide(capture)` | Piilottaa tallennuspainikkeen, kun tiedosto/arvo on olemassa |
| `hide(review)` | Piilottaa esikatselukuvan / toistopainikkeen |
| `hide(filename)` | Piilottaa latauksen jälkeen näkyvän tiedostonimen |
| `hide(camera)` | Piilottaa kameran laukaisinpainikkeen tallennuksen jälkeen |
| `hide(scanner)` | Piilottaa viivakoodin skannauspainikkeen, kun arvo on skannattu |
| `hide(value)` | Piilottaa skannatun arvon tekstin (viivakoodi / geopiste) |

Widget vaihtaa automaattisesti `display{}`-asettelusta `results{}`-asetteluun heti, kun arvo tallennetaan.

**Esimerkkejä:**

```
inline display{right}                                    → kuvake otsikon oikealla puolella
inline display{left, large}                              → suuri kuvake vasemmalla
inline display{center, large, #FF5500}                   → suuri oranssi kuvake otsikon alla
inline display{right} results{left}                      → kuvake siirtyy vasemmalle tallennuksen jälkeen
inline display{right} results{hide(capture)}             → kuvake katoaa tallennuksen jälkeen
inline display{center} results{hide(capture), hide(filename)}
```

## Tunnetut rajoitukset

- Monimutkaiset ulkoasut eivät välttämättä näy identtisinä kaikilla alustoilla.
- Joitakin rtSurveyn edistyneitä ulkoasuja ei välttämättä tueta offline-tilassa.

## Ulkoasuongelmien vianmääritys

1. **Ulkoasua ei sovelleta**: Tarkista kirjoitusvirheet appearance-sarakkeessa.
2. **Epäjohdonmukainen piirtyminen**: Varmista yhteensopivuus kysymystyypin ja alustan kanssa.
3. **Suorituskykyongelmat**: Harkitse monimutkaisten ulkoasujen yksinkertaistamista, erityisesti suurissa kyselyissä.

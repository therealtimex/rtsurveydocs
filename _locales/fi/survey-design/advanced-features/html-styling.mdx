rtSurvey esittää **label**- ja **hint**-tekstit HTML-muodossa verkkolomakkeilla. Tämä tarkoittaa, että voit käyttää tavallisia HTML-tageja tekstin muotoiluun, rivinvaihtojen lisäämiseen, linkkien luomiseen ja värien käyttämiseen. Tämä on erityisen hyödyllistä huomautuskentissä, osio-ohjeissa ja dynaamisissa yhteenvedoissa.

<Callout type="warning">
Otsikoiden HTML esitetään **verkkolomakkeella** ja rtSurvey-mobiilisovelluksissa. Se ei välttämättä näy kaikissa ODK-yhteensopivissa sovelluksissa. Testaa aina kohdealustallasi.
</Callout>

## Tuetut HTML-tagit

### Tekstin muotoilu

| Tag | Result |
|-----|--------|
| `<strong>text</strong>` tai `<b>text</b>` | **Lihavoitu teksti** |
| `<em>text</em>` tai `<i>text</i>` | *Kursivoitu teksti* |
| `<u>text</u>` | Alleviivattu teksti |
| `<br>` | Rivinvaihto |
| `<span style="...">text</span>` | Rivinsisäinen muotoilu |

### Linkit

```html
<a href="https://example.com" target="_blank">Klikkaa tästä</a>
```

Avautuu uudessa välilehdessä. Käytä viiteasiakirjoihin, ohjeisiin tai ulkoisiin resursseihin, joita haastattelijan tulee tarkastella.

### Värit

Käytä `<span>`-tagia ja rivinsisäisiä tyylejä:

```html
<span style="color: red;">Varoitus: arvo on sallitun alueen ulkopuolella</span>
<span style="color: #009688;">Osio valmis</span>
```

## Väriteeman muuttujat

rtSurvey tukee **väriteeman tunnisteita**, jotka mukautuvat sovelluksen asetettuun teemaan. Käytä syntaksia `__COLOR_THEME_NAME__`:

```html
<span style="color: var(--color-theme-primary);">Ensisijaisen värin teksti</span>
```

Tai käyttämällä tunnisteen lyhennettä otsikkotekstissä:

```
<font color="var(--COLOR_THEME_PRIMARY)">Tärkeä huomautus</font>
```

Tämä muutetaan automaattisesti vastaavaksi `<span>`-tagiksi CSS-muuttujalla esitysvaiheessa.

## Monikieliset otsikot

Kääri sisältö kielitunnisteisiin tukeaksesi useita kieliä yhdessä otsikkosolussa:

```
<en>Enter the household size</en><fi>Syötä kotitalouden koko</fi>
```

rtSurvey poimii sisällön, joka vastaa sovelluksen nykyistä kieltä. Jos vastaavaa kielitunnistetta ei löydy, koko merkkijono näytetään sellaisenaan.

## rtSurveyn erityiset HTML-tagit

### `<webbox src='url' title='title'>...</webbox>`

Upottaa painikkeen, joka avaa URL-osoitteen lomakkeen sisäisessä modaali-ikkunassa. Katso [Webbox](webbox) lisätietoja varten.

### `<delete-repeat-current>label</delete-repeat-current>`

Luo toistoryhmän sisälle painikkeen, joka poistaa nykyisen toistokerran napautettaessa.

### `<delete-repeat-last>label</delete-repeat-last>`

Luo painikkeen, joka poistaa viimeisimmän toistokerran.

Esimerkki käytöstä toistoryhmässä:

| type | name | label |
|------|------|-------|
| note | delete_btn | `<delete-repeat-current>Poista tämä jäsen</delete-repeat-current>` |

## Dynaamiset HTML-yhteenvedot autopull()-toiminnolla

`autopull()` esittää HTML-lohkon `note`-kentän sisällä ja **päivittää sen jokaisen kenttämuutoksen yhteydessä** lomakkeella. Tämä tekee siitä sopivan reaaliaikaisiin yhteenvetopaneeleihin, tarkista-ennen-lähetystä-näkymiin ja päivittyviin summiin haastattelijan täyttäessä tietoja.

<Callout type="info">
`autopull()` toimii vain **note**-kentissä. Otsikkosaraketta ei huomioida — kaikki HTML-sisältö on annettava **appearance**-sarakkeen kautta `concat()`-funktiolla.
</Callout>

### Syntaksi

Sijoita `autopull()` `note`-kentän **appearance**-sarakkeeseen:

```
autopull(concat('<html>...</html>'))
```

Kenttäviittaukset (`${field_name}`) `concat()`-funktion sisällä korvataan nykyisillä reaaliaikaisilla arvoilla, ja HTML päivitetään jokaisen muutoksen yhteydessä.

### Korkeuden rajoittaminen scroll-view()-toiminnolla

Pidemmissä yhteenvedoissa voit yhdistää `autopull()`- ja `scroll-view(N%)`-toiminnot rajoittaaksesi paneelin korkeutta ja tehdäksesi siitä vieritettävän:

```
scroll-view(45%) autopull(concat('<html>...</html>'))
```

`N%`-arvo on suhteessa lomakkeen näkyvään alueeseen. `45%` on käytännöllinen oletusarvo sivun keskellä olevalle yhteenvetopaneelille.

### Täydellinen esimerkki — kotitalouden sijaintiyhteenveto

Seuraava `note`-kenttä esittää kaksisarakkeisen taulukon, joka näyttää valitun maakunnan, piirin ja kunnan. Se päivittyy automaattisesti aina, kun `${tinh_name}`, `${huyen_name}` tai `${xa_name}` muuttuvat.

| type | name | label | appearance |
|------|------|-------|------------|
| note | location_summary | | `scroll-view(45%) autopull(concat('<html><table style="width:100%;border-collapse:collapse"><tr><td style="padding:4px;font-weight:bold">Province:</td><td style="padding:4px">', ${tinh_name}, '</td></tr><tr><td style="padding:4px;font-weight:bold">District:</td><td style="padding:4px">', ${huyen_name}, '</td></tr><tr><td style="padding:4px;font-weight:bold">Commune:</td><td style="padding:4px">', ${xa_name}, '</td></tr></table></html>'))` |

XLSFormissa appearance-arvo kirjoitetaan yhteen soluun:

```
scroll-view(45%) autopull(concat(
  '<html><table style="width:100%;border-collapse:collapse">
   <tr><td style="padding:4px;font-weight:bold">Province:</td>
       <td style="padding:4px">', ${tinh_name}, '</td></tr>
   <tr><td style="padding:4px;font-weight:bold">District:</td>
       <td style="padding:4px">', ${huyen_name}, '</td></tr>
   <tr><td style="padding:4px;font-weight:bold">Commune:</td>
       <td style="padding:4px">', ${xa_name}, '</td></tr>
   </table></html>'))
```

### Rivinsisäiset tyylit

Rivinsisäiset `style="..."`-attribuutit ovat tuettuja kaikissa HTML-elementeissä ja ovat suositeltu tapa visuaaliseen muotoiluun `autopull()`-lohkojen sisällä.

Seuraavia **ei** tueta `autopull()`-sisällössä:

- `<style>`-lohkot
- Ulkoiset tyylitiedostot (`<link>`)
- JavaScript (`<script>`)

### Milloin autopull()-toimintoa tulisi käyttää

| Käyttötapaus | Huomautukset |
|--------------|--------------|
| Tarkista-ennen-lähetystä-näkymä | Näytä kaikki tärkeät vastaukset yhdellä paneelilla ennen kuin haastattelija lopettaa |
| Juoksevat summat | Näytä laskettu summa, joka päivittyy määrien syöttämisen myötä |
| Näkyvä viitepaneeli | Näytä valittu hakuarvo (esim. maakunnan nimi) haastattelijan täyttäessä alikenttiä |

## Parhaat käytännöt

1. Käytä HTML-koodia säästeliäästi — liian monimutkaisesti muotoillut otsikot ovat vaikealukuisempia.
2. Käytä mieluummin `<strong>`-tagia lihavointiin ja `<em>`-tagia kursivointiin kuin vanhentuneita `<b>`- ja `<i>`-tageja.
3. Käytä värejä merkityksellisesti — käytä punaista varoituksiin, älä koristeena.
4. Testaa aina HTML-esitystä sekä mobiilisovelluksessa että verkkolomakkeella, sillä esitystapa voi poiketa hieman.
5. Vältä `<table>`-tageja otsikoiden sisällä — ne näkyvät harvoin hyvin mobiilinäytöillä.
6. Älä käytä JavaScriptiä (`<script>`) — se poistetaan tai se aiheuttaa virheitä.

## Rajoitukset

- Monimutkaista HTML-koodia (taulukot, lomakkeet, skriptit) ei tueta ja se voi rikkoa esityksen.
- Jotkut vanhemmat mobiilisovellukset saattavat näyttää HTML-tagit pelkkänä tekstinä — testaa kaikilla kohdelaitteilla.
- `<a>`-linkit avautuvat selaimessa tai WebView-näkymässä — haastattelija poistuu lomakkeelta, mikä voi olla häiritsevää mobiililaitteella.

rtSurvey renderöi **label** (otsikko) ja **hint** (vihje) -tekstit HTML-muodossa verkkolomakkeilla. Tämä tarkoittaa, että voit käyttää standardeja HTML-tageja tekstin muotoiluun, rivinvaihtojen lisäämiseen, linkkien luomiseen ja värien käyttämiseen. Tämä on erityisen hyödyllistä huomautuskentissä, osioiden ohjeissa ja dynaamisissa yhteenvedoissa.

<Callout type="warning">
Otsikoiden HTML renderöidään **verkkolomakkeella** ja rtSurveyn mobiilisovelluksissa. Se ei välttämättä renderöidy kaikissa ODK-yhteensopivissa asiakasohjelmissa. Testaa aina kohdealustallasi.
</Callout>

## Tuetut HTML-tagit

### Tekstin muotoilu

| Tagi | Tulos |
|-----|--------|
| `<strong>text</strong>` tai `<b>text</b>` | **Lihavoitu teksti** |
| `<em>text</em>` tai `<i>text</i>` | *Kursivoitu teksti* |
| `<u>text</u>` | Alleviivattu teksti |
| `<br>` | Rivinvaihto |
| `<span style="...">text</span>` | Rivinsisäinen tyylitys |

### Linkit

```html
<a href="https://example.com" target="_blank">Click here</a>
```

Avautuu uuteen välilehteen. Käytä viiteasiakirjoihin, ohjeisiin tai ulkoisiin resursseihin, joita haastattelijan tulisi konsultoida.

### Värit

Käytä `<span>`-tagia rivinsisäisillä tyyleillä:

```html
<span style="color: red;">Warning: value is out of range</span>
<span style="color: #009688;">Section completed</span>
```

## Väriteeman muuttujat

rtSurvey tukee **väriteeman tunnisteita** (tokens), jotka mukautuvat sovelluksen määritettyyn teemaan. Käytä `__COLOR_THEME_NAME__`-syntaksia:

```html
<span style="color: var(--color-theme-primary);">Primary color text</span>
```

Tai käyttämällä tunnisteen lyhennettä otsikkotekstissä:

```
<font color="var(--COLOR_THEME_PRIMARY)">Important note</font>
```

Tämä muunnetaan automaattisesti vastaavaksi `<span>`-tagiksi CSS-muuttujalla renderöintivaiheessa.

## Monikieliset otsikot

Kääri sisältö kielitgeihin tukeaksesi useita kieliä yhdessä otsikkosolussa:

```
<en>Enter the household size</en><vi>Nhập quy mô hộ gia đình</vi>
```

rtSurvey poimii sisällön, joka vastaa sovelluksen nykyistä kieltä. Jos vastaavaa kielitagia ei löydy, koko merkkijono näytetään sellaisenaan.

## rtSurveyn erityiset HTML-tagit

### `<webbox src='url' title='title'>...</webbox>`

Upottaa painikkeen, joka avaa URL-osoitteen lomakkeen sisäisessä modaali-ikkunassa. Katso [Webbox](webbox) lisätietoja varten.

### `<delete-repeat-current>label</delete-repeat-current>`

Renderöi toistoryhmän sisälle painikkeen, joka poistaa nykyisen toistokerran, kun sitä napautetaan.

### `<delete-repeat-last>label</delete-repeat-last>`

Renderöi painikkeen, joka poistaa viimeisimmän toistokerran.

Esimerkki käytöstä toistoryhmässä:

| type | name | label |
|------|------|-------|
| note | delete_btn | `<delete-repeat-current>Remove this member</delete-repeat-current>` |

## Dynaamiset HTML-yhteenvedot autopull()-funktiolla

`autopull()` renderöi HTML-lohkon `note`-kentän sisällä ja **arvioi sen uudelleen jokaisen kenttämuutoksen yhteydessä** lomakkeella. Tämä tekee siitä sopivan live-yhteenvetopaneeleihin, tarkistusnäyttöihin ennen lähettämistä ja juokseviin summiin, jotka päivittyvät haastattelijan täyttäessä tietoja.

<Callout type="info">
`autopull()` toimii vain **note**-kentissä. Otsikkosaraketta (label) ei huomioida — kaikki HTML-sisältö on annettava **appearance**-sarakkeen kautta käyttämällä `concat()`-funktiota.
</Callout>

### Syntaksi

Aseta `autopull()` `note`-kentän **appearance**-sarakkeeseen:

```
autopull(concat('<html>...</html>'))
```

`concat()`-funktion sisällä olevat kenttäviittaukset (`${field_name}`) korvataan nykyisillä live-arvoilla ja HTML renderöidään uudelleen jokaisen muutoksen yhteydessä.

### Korkeuden rajoittaminen scroll-view()-funktiolla

Pidemmissä yhteenvedoissa voit yhdistää `autopull()`-funktion `scroll-view(N%)`-funktioon paneelin korkeuden rajoittamiseksi ja sen tekemiseksi vieritettäväksi:

```
scroll-view(45%) autopull(concat('<html>...</html>'))
```

`N%`-arvo on suhteessa lomakkeen näkyvään alueeseen. `45%` on käytännöllinen oletusarvo sivun keskivaiheilla olevalle yhteenvetopaneelille.

### Täysi esimerkki — kotitalouden sijainnin yhteenveto

Seuraava `note`-kenttä renderöi kaksisarakkeisen taulukon, joka näyttää valitun maakunnan, piirin ja kunnan. Se päivittyy automaattisesti aina, kun `${tinh_name}`, `${huyen_name}` tai `${xa_name}` muuttuvat.

| type | name | label | appearance |
|------|------|-------|------------|
| note | location_summary | | `scroll-view(45%) autopull(concat('<html><table style="width:100%;border-collapse:collapse"><tr><td style="padding:4px;font-weight:bold">Province:</td><td style="padding:4px">', ${tinh_name}, '</td></tr><tr><td style="padding:4px;font-weight:bold">District:</td><td style="padding:4px">', ${huyen_name}, '</td></tr><tr><td style="padding:4px;font-weight:bold">Commune:</td><td style="padding:4px">', ${xa_name}, '</td></tr></table></html>'))` |

XLSFormissa appearance-arvo kirjoitetaan yhteen soluun:

```
scroll-view(45%) autopull(concat(
  '<html><table style="width:100%;border-collapse:collapse">
   <tr><td style="padding:4px;font-weight:bold">Province:</td>
       <td style="padding:4px">', ${tinh_name}, '</td></tr>
   <tr><td style="padding:4px;font-weight:bold">District:</td>
       <td style="padding:4px">', ${huyen_name}, '</td></tr>
   <tr><td style="padding:4px;font-weight:bold">Commune:</td>
       <td style="padding:4px">', ${xa_name}, '</td></tr>
   </table></html>'))
```

### Rivinsisäiset tyylit

Rivinsisäisiä `style="..."`-attribuutteja tuetaan kaikissa HTML-elementeissä, ja ne ovat suositeltu tapa käyttää visuaalista muotoilua `autopull()`-lohkojen sisällä.

Seuraavia **ei** tueta `autopull()`-sisällössä:

- `<style>`-lohkot
- Ulkoiset tyylitiedostot (`<link>`)
- JavaScript (`<script>`)

### Milloin autopull()-funktiota kannattaa käyttää

| Käyttötapaus | Huomautukset |
|----------|-------|
| Tarkistusnäyttö ennen lähettämistä | Näytä kaikki tärkeimmät vastaukset yhdessä paneelissa ennen kuin haastattelija lopettaa |
| Juoksevat summat | Näytä laskettu summa, joka päivittyy määrien syöttämisen myötä |
| Näkyvä viitepaneeli | Näytä valittu hakuarvo (esim. maakunnan nimi), kun haastattelija täyttää alikenttiä |

## Parhaat käytännöt

1. Käytä HTML:ää säästeliäästi — liian muotoiltuja otsikoita on vaikeampi lukea.
2. Suosi `<strong>`-tagia lihavointiin ja `<em>`-tagia kursivointiin vanhentuneiden `<b>`- ja `<i>`-tagien sijaan.
3. Käytä värejä merkityksellisesti — käytä punaista varoituksiin, älä koristeeksi.
4. Testaa HTML-renderöinti aina sekä mobiilisovelluksessa että verkkolomakkeella, sillä renderöinti voi vaihdella hieman.
5. Vältä `<table>`-tageja otsikoiden sisällä — ne renderöityvät harvoin hyvin mobiilinäytöillä.
6. Älä käytä JavaScriptiä (`<script>`) — se poistetaan tai se aiheuttaa virheitä.

## Rajoitukset

- Monimutkaista HTML-koodia (taulukot, lomakkeet, skriptit) ei tueta, ja se voi rikkoa renderöinnin.
- Jotkut vanhemmat mobiiliohjelmat saattavat näyttää HTML-tagit tekstinä — testaa kaikilla kohdelaitteilla.
- `<a>`-linkit avautuvat selaimessa tai WebViews-näkymässä — haastattelija poistuu lomakkeelta, mikä voi olla häiritsevää mobiililaitteella.

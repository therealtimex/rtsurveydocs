Tämä sivu käsittelee edistyneitä malleja toistoryhmien käyttöön rtSurveyssä. Perusasiat toistoryhmän asettamisesta löydät sivulta [Ryhmittely ja toistot](../repeats).

---

## Dynaaminen toistojen määrä

Oletusarvoisesti haastattelija päättää, kuinka monta kertaa toistetaan. Voit kiinnittää toistojen määrän käyttämällä `repeat_count`-saraketta:

| type | name | label | repeat_count |
|------|------|-------|--------------|
| begin_repeat | household_members | Kotitalouden jäsen | `${num_members}` |
| text | member_name | Jäsenen nimi | |
| integer | member_age | Ikä | |
| end_repeat | | | |

Toisto suoritetaan tasan `${num_members}` kertaa, missä `num_members` on kerätty aiemmin lomakkeella. Haastattelija ei voi lisätä tai poistaa esiintymiä.

---

## Indeksoitu haku: `indexed-repeat()`

Hae tietyn toistoesiintymän kentän arvo toistoryhmän **ulkopuolelta** käyttämällä funktiota `indexed-repeat(repeatedField, repeatGroup, index)`:

| type | name | label | calculation |
|------|------|-------|-------------|
| calculate | first_name | | `indexed-repeat(${member_name}, ${household_members}, 1)` |
| calculate | second_name | | `indexed-repeat(${member_name}, ${household_members}, 2)` |

Tämä on hyödyllistä yhteenvetokenttien rakentamisessa tai viittaamisessa "pääjäsenen" tietoihin toiston jälkeen.

---

## Nykyisen esiintymän sijainti: `index()`

Toistoryhmän sisällä `index()` palauttaa nykyisen esiintymän sijainnin (alkaen numerosta 1). Käytä sitä kunkin toiston nimeämiseen tai yksilöllisten tunnisteiden luomiseen:

| type | name | label |
|------|------|-------|
| begin_repeat | plots | Palsta |
| note | plot_label | Palsta numero `${index()}` |
| text | plot_id | Palstan tunnus |
| end_repeat | | |

---

## Kenttiin viittaaminen samassa esiintymässä

Käytä toiston sisällä merkintää `${fieldname}` viittaamaan toiseen kenttään **samassa toistoesiintymässä**. `indexed-repeat()`-funktiota ei tarvita saman silmukan sisällä:

| type | name | label | relevant |
|------|------|-------|----------|
| begin_repeat | members | Jäsen | |
| text | member_name | Nimi | |
| integer | member_age | Ikä | |
| text | school_name | Koulun nimi | `${member_age} < 18` |
| end_repeat | | | |

---

## Yläkenttiin viittaaminen toiston sisältä

Toistoryhmän ulkopuolisiin (yläpuolella oleviin) kenttiin voidaan viitata normaalisti merkinnällä `${fieldname}`:

| type | name | label |
|------|------|-------|
| text | village | Kylän nimi |
| begin_repeat | plots | Viljelypalsta |
| note | plot_context | Palstat kylässä `${village}` |
| end_repeat | | |

---

## Toistotietojen yhteenveto

Käytä toistojen koontifunktioita toistoryhmän **ulkopuolella** yhteenvedon tekemiseen:

| Funktio | Esimerkki | Kuvaus |
|----------|---------|-------------|
| `count(group)` | `count(${household_members})` | Esiintymien määrä |
| `sum(field)` | `sum(${loan_amount})` | Numeerisen kentän summa |
| `min(field)` | `min(${member_age})` | Minimiarvo |
| `max(field)` | `max(${member_age})` | Maksimiarvo |
| `join(sep, field)` | `join(', ', ${member_name})` | Pilkulla erotettu lista |
| `count-if(group, expr)` | `count-if(${members}, ${member_age} < 18)` | Ehdollinen määrä |
| `sum-if(field, expr)` | `sum-if(${loan_amount}, ${loan_amount} > 500)` | Ehdollinen summa |
| `join-if(sep, field, expr)` | `join-if(', ', ${name}, ${age} >= 18)` | Ehdollinen yhdistäminen |

### Esimerkki: Kotitalouden yhteenveto

| type | name | label | calculation |
|------|------|-------|-------------|
| integer | num_members | Kuinka monta jäsentä? | |
| begin_repeat | members | Jäsen | `${num_members}` |
| text | member_name | Nimi | |
| integer | member_age | Ikä | |
| end_repeat | | | |
| calculate | total_members | | `count(${members})` |
| calculate | children_count | | `count-if(${members}, ${member_age} < 18)` |
| calculate | adult_names | | `join-if(', ', ${member_name}, ${member_age} >= 18)` |
| note | summary | `${total_members}` jäsentä; `${children_count}` alle 18-vuotiasta. Aikuiset: `${adult_names}` | |

## Sisäkkäiset toistot

Toistoryhmä voi sisältää toisen toistoryhmän. Käytä tätä varoen – sisäkkäiset toistot lisäävät monimutkaisuutta ja voivat olla hämmentäviä haastattelijoille.

| type | name | label |
|------|------|-------|
| begin_repeat | households | Kotitalous |
| text | hh_id | Kotitalouden tunnus |
| begin_repeat | hh_members | Jäsen |
| text | member_name | Jäsenen nimi |
| end_repeat | | |
| end_repeat | | |

Viitataksesi ulomman toiston kenttään sisemmästä toistosta, käytä merkintää `${fieldname}` – se hakee lähimmän vastaavan yläelementin:

Toiston `hh_members` sisällä `${hh_id}` palauttaa **nykyisen** kotitalouden tunnuksen, ei kaikkien kotitalouksien tunnuksia.

## Järjestys toistoryhmissä: `rank-index()`

Kun toiston sisällä on `rank`-kenttä, käytä toistoryhmän ulkopuolelta funktiota `rank-index(instanceNumber, repeatedField)` saadaksesi tietyn esiintymän järjestysnumeron:

| type | name | label | calculation |
|------|------|-------|-------------|
| calculate | top_scorer | | `rank-index(1, ${score})` |

`rank-index(1, ${score})` palauttaa korkeimman pistemäärän saaneen esiintymän indeksin.

## `1screen`-ulkoasu `begin_repeat`-rivillä

Lisäämällä `1screen` `appearance`-sarakkeeseen `begin_repeat`-riville, kaikki kunkin esiintymän kysymykset näytetään yhdessä yhdellä näytöllä sen sijaan, että näytettäisiin yksi kysymys kerrallaan.

| type | name | label | appearance |
|------|------|-------|------------|
| begin_repeat | household_members | Kotitalouden jäsen | `1screen` |
| text | member_name | Jäsenen nimi | |
| integer | member_age | Ikä | |
| end_repeat | | | |

Kun `1screen` on käytössä eikä ryhmän sisällä ole `repeat_count`- tai `add_repeat`-kenttää, rtSurvey lisää automaattisesti pyöreän **+**-painikkeen näytön alareunaan, jotta haastattelijat voivat lisätä uusia esiintymiä ilman erillisiä määrityksiä.

| Ulkoasu | Yksi näyttö per esiintymä | Oletusarvoinen +-painike lisätty |
|------------|-------------------------|------------------------|
| `1screen` | Kyllä | Kyllä (kun ei `add_repeat`-lapsikenttää) |
| `field-list` | Kyllä | Ei |

Käytä `field-list`-asetusta, kun haluat ryhmitellyn asettelun ilman automaattista lisäyspainiketta. Käytä `1screen`-asetusta, kun haluat sekä ryhmitellyn asettelun että sisäänrakennetun tavan lisätä esiintymiä.

---

## `add_repeat`-muokattu lisäyspainike

Toistoryhmän **sisälle** sijoitettu `note`- (tai `text`-) kenttä, jolla on `appearance: add_repeat`, näytetään koko näytön levyisenä "Lisää"-painikkeena. Painikkeen teksti tulee kentän `label`-sarakkeesta. Kun `add_repeat`-kenttä on käytössä, oletusarvoinen pyöreä +-painike (joka tulee `1screen`-asetuksesta) piilotetaan.

Sijoita `add_repeat`-kenttä viimeiseksi kentäksi toistoryhmän sisälle:

| type | name | label | appearance |
|------|------|-------|------------|
| begin_repeat | members | Jäsen | `1screen` |
| text | member_name | Jäsenen nimi | |
| integer | member_age | Ikä | |
| note | btn_add | + Lisää jäsen | `add_repeat` |
| end_repeat | | | |

### Värien muokkaaminen

Voit tyylitellä painikkeen lisäämällä värikoodin ulkoasuarvon sisään:

| Ulkoasuarvo | Tulos |
|------------------|--------|
| `add_repeat <#04B404/>` | Vihreä tausta, oletustekstiväri |
| `add_repeat 04B404-ffffff` | Vihreä tausta, valkoinen teksti |

Ensimmäinen väri on taustaväri ja toinen (viivan jälkeen) on tekstin väri. Jätä `#`-merkki pois, kun käytät viivalla erotettua muotoa.

### Ikonivariantti

Käytä `add_repeat icon` -asetusta (välilyönnillä) näyttääksesi pienen pyöreän ikonipainikkeen koko näytön levyisen painikkeen sijaan:

| type | name | label | appearance |
|------|------|-------|------------|
| note | btn_add | + Lisää | `add_repeat icon` |

---

## Poistopainikkeet: `delete-repeat-current` ja `delete-repeat-last`

Toistoryhmän sisällä oleva `note`-kenttä, jolla on `appearance: delete-repeat-current` tai `appearance: delete-repeat-last`, näkyy jaettuna poistopainikkeena.

| Ulkoasu | Toiminto |
|------------|--------|
| `delete-repeat-current` | Poistaa nykyisen (aktiivisen) esiintymän |
| `delete-repeat-last` | Poistaa toiston viimeisen esiintymän |

Oletusarvoinen (ei-ikoni) painike on jaettu painike: roskakori-ikoni vasemmalla ja kentän otsikkoteksti oikealla, täyttäen koko näytön leveyden.

### Ikonivariantti

Lisää `-icon`-pääte saadaksesi pienen pyöreän roskakori-ikonipainikkeen:

| Ulkoasu | Tulos |
|------------|--------|
| `delete-repeat-current-icon` | Pyöreä roskakori-ikoni, poistaa nykyisen esiintymän |
| `delete-repeat-last-icon` | Pyöreä roskakori-ikoni, poistaa viimeisen esiintymän |

### Värien muokkaaminen

Värimuoto on identtinen `add_repeat`-asetuksen kanssa: käytä `<#RRGGBB/>` tai `RRGGBB-RRGGBB` (tausta-teksti).

### Esimerkki kokonaisesta mallista

Seuraava toisto käyttää `1screen`-asetusta, pyöreää poista-nykyinen-painiketta ylhäällä ja koko näytön levyistä lisäyspainiketta alhaalla:

| type | name | label | appearance |
|------|------|-------|------------|
| begin_repeat | members | Jäsen | `1screen` |
| note | btn_del | Poista | `delete-repeat-current-icon` |
| text | member_name | Jäsenen nimi | |
| integer | member_age | Ikä | |
| note | btn_add | + Lisää jäsen | `add_repeat` |
| end_repeat | | | |

## Parhaat käytännöt

1. Käytä aina `repeat_count`-asetusta, kun toistojen määrä on tiedossa etukäteen – se estää haastattelijoita lisäämästä tai poistamasta esiintymiä vahingossa.
2. Pidä toistoryhmät selkeinä – toisto, jossa on yli 20 kysymystä per esiintymä, on vaikea hallita.
3. Nimeä toistoryhmät selkeästi (esim. `household_members`, ei `repeat1`) – nimi näkyy funktiokutsuissa ja viedyissä tiedoissa.
4. Testaa lomake suurimmalla odotetulla esiintymien määrällä suorituskyvyn varmistamiseksi.
5. Käytä `1screen`-asetusta `begin_repeat`-rivillä näyttääksesi kaikki kysymykset yhdellä näytöllä esiintymää kohden, ja käytä `add_repeat`-huomautuskenttää ryhmän sisällä tarjotaksesi haastattelijoille selkeän "Lisää"-painikkeen.

---

## Rajoitukset

- `indexed-repeat()` vaatii kelvollisen indeksin (1:stä esiintymien määrään) – rajojen ulkopuoliset indeksit palauttavat tyhjän arvon.
- Yli 2-tasoisia sisäkkäisiä toistoja ei suositella, ja ne voivat aiheuttaa näyttöongelmia joillakin laitteilla.
- Koontifunktiot (`sum`, `count` jne.) toimivat koko toistoryhmässä – et voi tehdä koontia esiintymien osajoukosta ilman `*-if`-variantteja.

ఈ పేజీ rtSurveyలో రిపీట్ గ్రూపులతో పని చేయడానికి అవసరమైన అడ్వాన్స్‌డ్ ప్యాటర్న్‌లను కవర్ చేస్తుంది. రిపీట్ గ్రూపును సెటప్ చేయడానికి సంబంధించిన ప్రాథమిక అంశాల కోసం, [గ్రూపింగ్ మరియు రిపీట్స్](../repeats) చూడండి.

---

## డైనమిక్ రిపీట్ కౌంట్ (Dynamic repeat count)

డిఫాల్ట్‌గా, ఎన్నిసార్లు రిపీట్ చేయాలో ఎన్యూమరేటర్ నిర్ణయిస్తారు. మీరు `repeat_count`ని ఉపయోగించి రిపీట్‌ల సంఖ్యను స్థిరంగా ఉంచవచ్చు:

| type | name | label | repeat_count |
|------|------|-------|--------------|
| begin_repeat | household_members | ఇంటి సభ్యుడు | `${num_members}` |
| text | member_name | సభ్యుని పేరు | |
| integer | member_age | వయస్సు | |
| end_repeat | | | |

ఫారమ్‌లో ముందే సేకరించిన `num_members` సంఖ్యకు అనుగుణంగా రిపీట్ ఖచ్చితంగా `${num_members}` సార్లు రన్ అవుతుంది. ఎన్యూమరేటర్ కొత్త వాటిని జోడించలేరు లేదా ఉన్నవాటిని తొలగించలేరు.

## ఇండెక్స్డ్ యాక్సెస్: `indexed-repeat()`

రిపీట్ గ్రూప్ **బయట** నుండి ఒక నిర్దిష్ట రిపీట్ ఇన్‌స్టాన్స్ యొక్క ఫీల్డ్ విలువను యాక్సెస్ చేయడానికి `indexed-repeat(repeatedField, repeatGroup, index)`ని ఉపయోగించండి:

| type | name | label | calculation |
|------|------|-------|-------------|
| calculate | first_name | | `indexed-repeat(${member_name}, ${household_members}, 1)` |
| calculate | second_name | | `indexed-repeat(${member_name}, ${household_members}, 2)` |

సమ్మరీ ఫీల్డ్‌లను రూపొందించడానికి లేదా రిపీట్ తర్వాత "ప్రధాన" సభ్యుని డేటాను రిఫరెన్స్ చేయడానికి ఇది ఉపయోగపడుతుంది.

---

## ప్రస్తుత ఇన్‌స్టాన్స్ పొజిషన్: `index()`

రిపీట్ గ్రూప్ లోపల, `index()` ప్రస్తుత ఇన్‌స్టాన్స్ యొక్క పొజిషన్‌ను (1 నుండి ప్రారంభించి) తెలియజేస్తుంది. ప్రతి రిపీట్‌ను లేబుల్ చేయడానికి లేదా ప్రత్యేక ఐడెంటిఫైయర్‌లను రూపొందించడానికి దీన్ని ఉపయోగించండి:

| type | name | label |
|------|------|-------|
| begin_repeat | plots | ప్లాట్ |
| note | plot_label | ప్లాట్ నంబర్ `${index()}` |
| text | plot_id | ప్లాట్ ID |
| end_repeat | | |

---

## ఒకే ఇన్‌స్టాన్స్‌లోని ఫీల్డ్‌లను రిఫరెన్స్ చేయడం

రిపీట్ లోపల, **అదే రిపీట్ ఇన్‌స్టాన్స్‌లోని** మరొక ఫీల్డ్‌ను రిఫరెన్స్ చేయడానికి `${fieldname}`ని ఉపయోగించండి. ఒకే లూప్ లోపల `indexed-repeat()`ని ఉపయోగించాల్సిన అవసరం లేదు:

| type | name | label | relevant |
|------|------|-------|----------|
| begin_repeat | members | సభ్యుడు | |
| text | member_name | పేరు | |
| integer | member_age | వయస్సు | |
| text | school_name | పాఠశాల పేరు | `${member_age} < 18` |
| end_repeat | | | |

---

## రిపీట్ లోపలి నుండి పేరెంట్ ఫీల్డ్‌లను రిఫరెన్స్ చేయడం

రిపీట్ గ్రూప్ బయట (పైన) ఉన్న ఫీల్డ్‌లను `${fieldname}`తో సాధారణంగా రిఫరెన్స్ చేయవచ్చు:

| type | name | label |
|------|------|-------|
| text | village | గ్రామం పేరు |
| begin_repeat | plots | వ్యవసాయ ప్లాట్ |
| note | plot_context | `${village}` లోని ప్లాట్లు |
| end_repeat | | |

---

## రిపీట్ డేటాను సమ్మరైజ్ చేయడం

సారాంశం (Summary) కోసం రిపీట్ గ్రూప్ **బయట** రిపీట్ అగ్రిగేట్ ఫంక్షన్‌లను ఉపయోగించండి:

| Function | Example | Description |
|----------|---------|-------------|
| `count(group)` | `count(${household_members})` | ఇన్‌స్టాన్స్‌ల సంఖ్య |
| `sum(field)` | `sum(${loan_amount})` | సంఖ్యా ఫీల్డ్ యొక్క మొత్తం |
| `min(field)` | `min(${member_age})` | కనిష్ట విలువ |
| `max(field)` | `max(${member_age})` | గరిష్ట విలువ |
| `join(sep, field)` | `join(', ', ${member_name})` | కామాలతో వేరు చేయబడిన జాబితా |
| `count-if(group, expr)` | `count-if(${members}, ${member_age} < 18)` | కండిషనల్ కౌంట్ |
| `sum-if(field, expr)` | `sum-if(${loan_amount}, ${loan_amount} > 500)` | కండిషనల్ మొత్తం |
| `join-if(sep, field, expr)` | `join-if(', ', ${name}, ${age} >= 18)` | కండిషనల్ జాయిన్ |

### ఉదాహరణ: ఇంటి సభ్యుల సారాంశం (Household summary)

| type | name | label | calculation |
|------|------|-------|-------------|
| integer | num_members | ఎంతమంది సభ్యులు? | |
| begin_repeat | members | సభ్యుడు | `${num_members}` |
| text | member_name | పేరు | |
| integer | member_age | వయస్సు | |
| end_repeat | | | |
| calculate | total_members | | `count(${members})` |
| calculate | children_count | | `count-if(${members}, ${member_age} < 18)` |
| calculate | adult_names | | `join-if(', ', ${member_name}, ${member_age} >= 18)` |
| note | summary | `${total_members}` సభ్యులు; 18 ఏళ్ల లోపు వారు `${children_count}`. పెద్దలు: `${adult_names}` | |

## నెస్టెడ్ రిపీట్స్ (Nested repeats)

ఒక రిపీట్ గ్రూప్ లోపల మరొక రిపీట్ గ్రూప్ ఉండవచ్చు. దీన్ని జాగ్రత్తగా ఉపయోగించండి — నెస్టెడ్ రిపీట్స్ క్లిష్టతను పెంచుతాయి మరియు ఎన్యూమరేటర్లకు గందరగోళంగా ఉండవచ్చు.

| type | name | label |
|------|------|-------|
| begin_repeat | households | ఇల్లు |
| text | hh_id | ఇంటి ID |
| begin_repeat | hh_members | సభ్యుడు |
| text | member_name | సభ్యుని పేరు |
| end_repeat | | |
| end_repeat | | |

లోపలి రిపీట్ నుండి బయటి రిపీట్‌లోని ఫీల్డ్‌ను రిఫరెన్స్ చేయడానికి, `${fieldname}`ని ఉపయోగించండి — ఇది సమీపంలోని మ్యాచింగ్ ఆన్సెస్టర్‌ను (ancestor) తీసుకుంటుంది:

`hh_members` రిపీట్ లోపల, `${hh_id}` అనేది అన్ని ఇళ్ల ఐడిలను కాకుండా **ప్రస్తుత** ఇంటి ఐడిని మాత్రమే తెలియజేస్తుంది.

---

## రిపీట్ గ్రూపుల లోపల ర్యాంక్: `rank-index()`

రిపీట్ లోపల ఒక `rank` ఫీల్డ్ ఉన్నప్పుడు, ఒక నిర్దిష్ట ఇన్‌స్టాన్స్ యొక్క ఆర్డినల్ ర్యాంక్‌ను పొందడానికి బయటి నుండి `rank-index(instanceNumber, repeatedField)`ని ఉపయోగించండి:

| type | name | label | calculation |
|------|------|-------|-------------|
| calculate | top_scorer | | `rank-index(1, ${score})` |

`rank-index(1, ${score})` అత్యధిక స్కోరు సాధించిన ఇన్‌స్టాన్స్ ఇండెక్స్‌ను తెలియజేస్తుంది.

## `begin_repeat` పై `1screen` అప్పియరెన్స్

`begin_repeat` వరుస యొక్క `appearance` కాలమ్‌లో `1screen`ని జోడించడం వల్ల, ప్రతి ఇన్‌స్టాన్స్ కోసం అన్ని ప్రశ్నలు ఒకే స్క్రీన్‌పై కనిపిస్తాయి, ఒక్కో స్క్రీన్‌పై ఒక ప్రశ్న కాకుండా.

| type | name | label | appearance |
|------|------|-------|------------|
| begin_repeat | household_members | ఇంటి సభ్యుడు | `1screen` |
| text | member_name | సభ్యుని పేరు | |
| integer | member_age | వయస్సు | |
| end_repeat | | | |

`1screen` సెట్ చేయబడి, గ్రూప్ లోపల `repeat_count` మరియు `add_repeat` ఫీల్డ్‌లు లేనప్పుడు, ఎన్యూమరేటర్లు అదనపు కాన్ఫిగరేషన్ లేకుండా కొత్త ఇన్‌స్టాన్స్‌లను జోడించడానికి rtSurvey స్క్రీన్ దిగువన స్వయంచాలకంగా ఒక వృత్తాకార **+** బటన్‌ను చూపిస్తుంది.

| Appearance | ఒక్కో ఇన్‌స్టాన్స్‌కు ఒక స్క్రీన్ | డిఫాల్ట్ + బటన్ జోడించబడింది |
|------------|-------------------------|------------------------|
| `1screen` | అవును | అవును (`add_repeat` లేనప్పుడు) |
| `field-list` | అవును | లేదు |

ఆటోమేటిక్ యాడ్ బటన్ లేకుండా కేవలం గ్రూప్ లేఅవుట్ కావాలనుకున్నప్పుడు `field-list`ని ఉపయోగించండి. గ్రూప్ లేఅవుట్ మరియు ఇన్‌స్టాన్స్‌లను జోడించడానికి బిల్ట్-ఇన్ మార్గం రెండూ కావాలనుకున్నప్పుడు `1screen`ని ఉపయోగించండి.

## `add_repeat` కస్టమ్ యాడ్ బటన్

`appearance: add_repeat` తో రిపీట్ గ్రూప్ **లోపల** ఉంచిన `note` (లేదా `text`) ఫీల్డ్ పూర్తి-వెడల్పు గల "Add" బటన్‌గా కనిపిస్తుంది. బటన్ లేబుల్ ఫీల్డ్ యొక్క `label` కాలమ్ నుండి వస్తుంది. `add_repeat` ఫీల్డ్ ఉన్నప్పుడు, `1screen` నుండి వచ్చే డిఫాల్ట్ వృత్తాకార + బటన్ కనిపించదు.

రిపీట్ గ్రూప్ లోపల చివరి ఫీల్డ్‌గా `add_repeat` ఫీల్డ్‌ను ఉంచండి:

| type | name | label | appearance |
|------|------|-------|------------|
| begin_repeat | members | సభ్యుడు | `1screen` |
| text | member_name | సభ్యుని పేరు | |
| integer | member_age | వయస్సు | |
| note | btn_add | + సభ్యుడిని జోడించు | `add_repeat` |
| end_repeat | | | |

### రంగు అనుకూలీకరణ (Color customization)

బటన్‌ను స్టైల్ చేయడానికి అప్పియరెన్స్ విలువ లోపల కలర్ కోడ్‌ను పాస్ చేయండి:

| Appearance value | Result |
|------------------|--------|
| `add_repeat <#04B404/>` | గ్రీన్ బ్యాక్‌గ్రౌండ్, డిఫాల్ట్ టెక్స్ట్ కలర్ |
| `add_repeat 04B404-ffffff` | గ్రీన్ బ్యాక్‌గ్రౌండ్, వైట్ టెక్స్ట్ |

మొదటి రంగు బ్యాక్‌గ్రౌండ్ మరియు రెండవది (డాష్ తర్వాత) టెక్స్ట్ కలర్. డాష్‌తో వేరు చేయబడిన ఫారమ్‌ను ఉపయోగిస్తున్నప్పుడు `#`ని వదిలివేయండి.

### ఐకాన్ వేరియంట్

పూర్తి-వెడల్పు బటన్‌కు బదులుగా కాంపాక్ట్ వృత్తాకార ఐకాన్ బటన్‌ను చూపించడానికి `add_repeat icon` (స్పేస్‌తో) ని ఉపయోగించండి:

| type | name | label | appearance |
|------|------|-------|------------|
| note | btn_add | + జోడించు | `add_repeat icon` |

## డిలీట్ బటన్లు: `delete-repeat-current` మరియు `delete-repeat-last`

`appearance: delete-repeat-current` లేదా `appearance: delete-repeat-last` తో రిపీట్ గ్రూప్ లోపల ఉన్న `note` ఫీల్డ్ స్ప్లిట్ డిలీట్ బటన్‌గా కనిపిస్తుంది.

| Appearance | Action |
|------------|--------|
| `delete-repeat-current` | ప్రస్తుత (యాక్టివ్) ఇన్‌స్టాన్స్‌ను డిలీట్ చేస్తుంది |
| `delete-repeat-last` | రిపీట్‌లోని చివరి ఇన్‌స్టాన్స్‌ను డిలీట్ చేస్తుంది |

డిఫాల్ట్ (ఐకాన్ లేని) బటన్ అనేది స్ప్లిట్ బటన్: ఎడమవైపు ట్రాష్ ఐకాన్ మరియు కుడివైపు ఫీల్డ్ లేబుల్ టెక్స్ట్ ఉండి, స్క్రీన్ పూర్తి వెడల్పును ఆక్రమిస్తుంది.

### ఐకాన్ వేరియంట్

కాంపాక్ట్ వృత్తాకార ట్రాష్ ఐకాన్ బటన్‌ను పొందడానికి `-icon` ని జోడించండి:

| Appearance | Result |
|------------|--------|
| `delete-repeat-current-icon` | వృత్తాకార ట్రాష్ ఐకాన్, ప్రస్తుత ఇన్‌స్టాన్స్‌ను డిలీట్ చేస్తుంది |
| `delete-repeat-last-icon` | వృత్తాకార ట్రాష్ ఐకాన్, చివరి ఇన్‌స్టాన్స్‌ను డిలీట్ చేస్తుంది |

### రంగు అనుకూలీకరణ (Color customization)

రంగు ఫార్మాట్ `add_repeat` లాగానే ఉంటుంది: `<#RRGGBB/>` లేదా `RRGGBB-RRGGBB` (బ్యాక్‌గ్రౌండ్-టెక్స్ట్) ఉపయోగించండి.

## ఉత్తమ పద్ధతులు (Best Practices)

1. రిపీట్‌ల సంఖ్య ముందే తెలిసినప్పుడు ఎల్లప్పుడూ `repeat_count`ని ఉపయోగించండి — ఇది ఎన్యూమరేటర్లు అనుకోకుండా ఇన్‌స్టాన్స్‌లను జోడించడం లేదా తొలగించడం చేయకుండా నిరోధిస్తుంది.
2. రిపీట్ గ్రూపులను పరిమితంగా ఉంచండి — ఒక్కో ఇన్‌స్టాన్స్‌కు 20 కంటే ఎక్కువ ప్రశ్నలు ఉన్న రిపీట్ గ్రూప్‌లో నావిగేట్ చేయడం కష్టం.
3. రిపీట్ గ్రూపులకు స్పష్టమైన పేర్లు ఇవ్వండి (ఉదా. `household_members`, `repeat1` అని కాదు) — ఈ పేరు ఫంక్షన్ కాల్‌లు మరియు ఎగుమతి చేసిన డేటాలో కనిపిస్తుంది.
4. పనితీరును ధృవీకరించడానికి గరిష్ట సంఖ్యలో ఇన్‌స్టాన్స్‌లతో టెస్ట్ చేయండి.
5. ఒక్కో ఇన్‌స్టాన్స్‌కు ఒకే స్క్రీన్‌పై అన్ని ప్రశ్నలను చూపించడానికి `begin_repeat` పై `1screen` ని ఉపయోగించండి మరియు ఎన్యూమరేటర్లకు స్పష్టమైన లేబుల్ ఉన్న "Add" బటన్‌ను ఇవ్వడానికి గ్రూప్ లోపల `add_repeat` నోట్ ఫీల్డ్‌ను ఉపయోగించండి.

## పరిమితులు (Limitations)

- `indexed-repeat()` కి సరైన ఇండెక్స్ (1 నుండి ఇన్‌స్టాన్స్‌ల సంఖ్య వరకు) అవసరం — పరిధి వెలుపల ఉన్న ఇండెక్స్‌లు ఖాళీగా వస్తాయి.
- 2 స్థాయిల కంటే ఎక్కువ నెస్టెడ్ రిపీట్స్ సిఫార్సు చేయబడవు మరియు కొన్ని క్లయింట్‌లలో డిస్‌ప్లే సమస్యలను కలిగించవచ్చు.
- అగ్రిగేట్ ఫంక్షన్లు (`sum`, `count`, మొదలైనవి) మొత్తం రిపీట్ గ్రూప్ పై పనిచేస్తాయి — మీరు `*-if` వేరియంట్లు లేకుండా ఇన్‌స్టాన్స్‌ల సబ్‌సెట్‌ను అగ్రిగేట్ చేయలేరు.

rtSurveyలో `appearance` కాలమ్ మీ సర్వేలలోని ప్రశ్నల విజువల్ ప్రెజెంటేషన్ మరియు ప్రవర్తనను అనుకూలీకరించడానికి మిమ్మల్ని అనుమతిస్తుంది. ఈ ఫీచర్ వినియోగదారు అనుభవాన్ని మెరుగుపరుస్తుంది మరియు డేటా సేకరణ సామర్థ్యాన్ని గణనీయంగా పెంచుతుంది. rtSurvey ప్రామాణిక XLSForm ప్రదర్శన లక్షణాలను (appearance attributes) సపోర్ట్ చేస్తుంది మరియు వాటిని అదనపు ఎంపికలతో విస్తరిస్తుంది.

## ప్రామాణిక XLSForm ప్రదర్శన లక్షణాలు (Appearance Attributes)

rtSurvey కింది ప్రామాణిక XLSForm ప్రదర్శన లక్షణాలను సపోర్ట్ చేస్తుంది:

| ప్రదర్శన లక్షణం (Appearance Attribute) | ప్రశ్న రకాలు | వివరణ |
|----------------------|----------------|-------------|
| multiline | text | బహుళ-లైన్ టెక్స్ట్ బాక్స్‌ను సృష్టిస్తుంది (వెబ్ క్లయింట్‌లకు ఉత్తమమైనది) |
| minimal | select_one, select_multiple | ఎంపికలను డ్రాప్‌డౌన్ మెనూలో ప్రదర్శిస్తుంది |
| quick | select_one | ఎంపిక చేసిన తర్వాత స్వయంచాలకంగా తదుపరి ప్రశ్నకు వెళుతుంది (మొబైల్ మాత్రమే) |
| no-calendar | date | క్యాలెండర్ ప్రదర్శనను నిలిపివేస్తుంది (మొబైల్ మాత్రమే) |
| month-year | date | నెల మరియు సంవత్సరం మాత్రమే ఎంపిక చేసుకోవడానికి అనుమతిస్తుంది |
| year | date | సంవత్సరం మాత్రమే ఎంపిక చేసుకోవడానికి అనుమతిస్తుంది |
| horizontal-compact | select_one, select_multiple | ఎంపికలను అడ్డంగా ప్రదర్శిస్తుంది (వెబ్ మాత్రమే) |
| horizontal | select_one, select_multiple | ఎంపికలను కాలమ్‌లలో అడ్డంగా ప్రదర్శిస్తుంది (వెబ్ మాత్రమే) |
| likert | select_one | ఎంపికలను లైకర్ట్ స్కేల్‌గా (Likert scale) ప్రదర్శిస్తుంది |
| compact | select_one, select_multiple | కనీస ప్యాడింగ్‌తో ఎంపికలను పక్కపక్కనే ప్రదర్శిస్తుంది |
| quickcompact | select_one | కాంపాక్ట్ డిస్‌ప్లేను ఆటో-అడ్వాన్స్‌తో కలుపుతుంది (మొబైల్ మాత్రమే) |
| field-list | groups | మొత్తం సమూహాన్ని ఒకే స్క్రీన్‌పై ప్రదర్శిస్తుంది (మొబైల్ మాత్రమే) |
| label | select_one, select_multiple | ఇన్‌పుట్‌లు లేకుండా ఎంపిక లేబుల్‌లను చూపుతుంది |
| list-nolabel | select_one, select_multiple | లేబుల్‌లు లేకుండా ఇన్‌పుట్‌లను చూపుతుంది (`label`తో ఉపయోగించండి) |
| table-list | groups | ప్రశ్నలను టేబుల్ ఫార్మాట్‌లో ప్రదర్శిస్తుంది |
| signature | image | సంతకం సేకరణను అనుమతిస్తుంది (మొబైల్ మాత్రమే) |
| draw | image | ఫ్రీహ్యాండ్ డ్రాయింగ్‌ను అనుమతిస్తుంది (మొబైల్ మాత్రమే) |
| map, quick map | select_one, select_one_from_file | మ్యాప్ ఫీచర్ల నుండి ఎంపికను అనుమతిస్తుంది |

## ప్రదర్శనను ఉపయోగించడం కోసం ఉత్తమ పద్ధతులు

1. **స్థిరత్వం**: ఏకరీతి రూపం కోసం మీ సర్వే అంతటా ప్రదర్శన లక్షణాలను స్థిరంగా ఉపయోగించండి.
2. **మొబైల్ వర్సెస్ వెబ్**: వివిధ పరికరాలు మరియు ప్లాట్‌ఫారమ్‌లలో ప్రదర్శనలు ఎలా కనిపిస్తాయో పరిశీలించండి.
3. **పనితీరు**: ఫారమ్ లోడింగ్‌ను నెమ్మదింపజేసే ప్రదర్శన లక్షణాల విషయంలో జాగ్రత్తగా ఉండండి (ఉదా., పెద్ద సమూహాల కోసం `table-list`).
4. **వినియోగదారు అనుభవం**: ప్రతివాదులకు డేటా నమోదును సులభతరం చేసే మరియు స్పష్టంగా ఉండే ప్రదర్శనలను ఎంచుకోండి.
5. **పరీక్షించడం**: ప్రదర్శనలు ఆశించిన విధంగా పనిచేస్తున్నాయని నిర్ధారించుకోవడానికి మీ ఫారమ్‌ను ఎల్లప్పుడూ లక్ష్య పరికరాలలో పరీక్షించండి.

## అధునాతన పద్ధతులు

### ప్రదర్శనలను కలపడం

మరింత క్లిష్టమైన లేఅవుట్‌ల కోసం కొన్ని ప్రదర్శన లక్షణాలను కలపవచ్చు:

```
| type | name | label | appearance |
|------|------|-------|------------|
| select_one options | choice | ఒకదానిని ఎంచుకోండి: | minimal compact |
```

### డైనమిక్ ప్రదర్శనలు

ఫారమ్ లాజిక్ ఆధారంగా డైనమిక్ ప్రదర్శన మార్పులను rtSurvey అనుమతిస్తుంది:

```
| type | name | label | appearance | relevant |
|------|------|-------|------------|----------|
| text | time | సమయాన్ని నమోదు చేయండి: | inline-[%H:%M] | ${show_time} = 'yes' |
```

## మొబైల్ యాప్ పరిగణనలు

- కొన్ని ప్రదర్శనలు (ఉదా., `quick`, `signature`) మొబైల్ పరికరాలకు మాత్రమే ప్రత్యేకం.
- స్థిరమైన ప్రవర్తనను నిర్ధారించడానికి Android మరియు iOS రెండింటిలోనూ క్షుణ్ణంగా పరీక్షించండి.

## rtSurvey విస్తరించిన ప్రదర్శన లక్షణాలు (Extended Appearance Attributes)

ప్రామాణిక XLSForm ప్రదర్శనలతో పాటు, rtSurvey కింది ప్లాట్‌ఫారమ్-నిర్దిష్ట ఎంపికలను సపోర్ట్ చేస్తుంది:

### డేటా మరియు ప్రదర్శన నియంత్రణ

| ప్రదర్శన లక్షణం (Appearance Attribute) | ప్రశ్న రకాలు | వివరణ |
|----------------------|----------------|-------------|
| `invisible` | any | ఫీల్డ్ విలువను సేకరిస్తున్నప్పుడు లేదా లెక్కిస్తున్నప్పుడు దానిని చూపు నుండి దాచిపెడుతుంది. `hidden` రకానికి భిన్నంగా — ఫీల్డ్ ఇప్పటికీ లాజిక్‌లో పాల్గొంటుంది. |
| `displaytitle` | any | ఫీల్డ్ లేబుల్/శీర్షిక సాధారణంగా అణిచివేయ్యబడినప్పుడు కూడా దానిని బలవంతంగా ప్రదర్శిస్తుంది. |
| `autopull` | select_one, select_multiple | ఫారమ్ లోడ్ అయినప్పుడు లేదా ట్రిగ్గర్ ఫీల్డ్ మారినప్పుడు ఎంపికలను పూరించడానికి బాహ్య డేటాను స్వయంచాలకంగా పొందుతుంది. |
| `floating_hint` | text, integer, decimal | సూచన టెక్స్ట్‌ను ఇన్‌పుట్ ఫీల్డ్ కింద కాకుండా పైన ఫ్లోటింగ్ లేబుల్‌గా చూపుతుంది. |
| `calculate-button` | calculate | స్వయంచాలకంగా లెక్కించడానికి బదులుగా, డిమాండ్‌పై ఫీల్డ్ యొక్క పునఃలెక్కింపును ప్రేరేపించే కనిపించే బటన్‌ను జోడిస్తుంది. |

### సమూహం మరియు నావిగేషన్

| ప్రదర్శన లక్షణం (Appearance Attribute) | ప్రశ్న రకాలు | వివరణ |
|----------------------|----------------|-------------|
| `section` | group | సమూహాన్ని కుదించదగిన సెక్షన్ కార్డ్‌గా మారుస్తుంది. గమనిక: మొబైల్ యాప్ మాత్రమే. |
| `toc-hide` | any | టేబుల్-ఆఫ్-కంటెంట్స్ (TOC) నావిగేషన్ ప్యానెల్ నుండి ప్రశ్నను మినహాయిస్తుంది. |
| `minilog` | begin_repeat | ప్రతి ఎంట్రీని ఇన్‌లైన్‌లో విస్తరించడానికి బదులుగా, పూర్తయిన రిపీట్ ఎంట్రీలను కాంపాక్ట్ మినీ-లాగ్ లిస్ట్‌గా ప్రదర్శిస్తుంది. |

### ఇన్‌పుట్ ప్రవర్తన

| ప్రదర్శన లక్షణం (Appearance Attribute) | ప్రశ్న రకాలు | వివరణ |
|----------------------|----------------|-------------|
| `proper` | text | ప్రతివాది టైప్ చేస్తున్నప్పుడు ప్రతి పదం యొక్క మొదటి అక్షరాన్ని స్వయంచాలకంగా క్యాపిటలైజ్ చేస్తుంది (title-case ప్రవర్తన). |
| `text-nolabel` | text, integer, decimal | కనిపించే లేబుల్ లేకుండా ఇన్‌పుట్ ఫీల్డ్‌ను మారుస్తుంది. |
| `inline-1line` | text | ప్రశ్న లేబుల్ పొడవుగా ఉన్నప్పటికీ టెక్స్ట్ ఇన్‌పుట్‌ను ఒకే లైన్‌గా ప్రదర్శించేలా చేస్తుంది. |
| `popup` | any | ఫీల్డ్‌ను పేజీలో ఇన్‌లైన్‌కు బదులుగా పాపప్ / మోడల్ ఓవర్‌లే లోపల మారుస్తుంది. |

### లేఅవుట్

| ప్రదర్శన లక్షణం (Appearance Attribute) | ప్రశ్న రకాలు | వివరణ |
|----------------------|----------------|-------------|
| `1screen` | group | సమూహం పరిమాణంతో సంబంధం లేకుండా మొత్తం సమూహాన్ని ఒకే స్క్రీన్‌పై ప్రదర్శించేలా చేస్తుంది. |
| `columns(n)` | select_one, select_multiple | ఎంపికలను `n` కాలమ్‌లలో ప్రదర్శిస్తుంది. ఉదాహరణ: `columns(3)` రేడియో బటన్ల మూడు కాలమ్‌లను చూపుతుంది. |
| `gridformat<row=R col=C colspan=S align=center>` | any | `R` రో, `C` కాలమ్‌లో, `S` కాలమ్‌ల వరకు విస్తరించి ఉన్న CSS-గ్రిడ్ లేఅవుట్‌లో ఫీల్డ్‌ను ఉంచుతుంది. `advanced-extension/grid-layout`తో ఉపయోగించబడుతుంది. |
| `ignore-simplify` | any | ఈ ఫీల్డ్ లేఅవుట్ యొక్క స్వయంచాలక సరళీకరణ లేదా కుదింపును దాటవేయమని ఫారమ్ రెండరర్‌ను నిర్దేశిస్తుంది. |
| `horizontal(N)` | select_one, select_multiple | ప్రతి ఎంపిక రో వెడల్పులో `N` శాతం ఆక్రమించేలా సెట్ చేస్తుంది. ఉదాహరణ: `horizontal(50)` ఒక రోకి రెండు ఎంపికలను ఉంచుతుంది. |
| `scroll-view(N%)` | group, repeat | కంటైనర్‌ను వ్యూపోర్ట్ (లేదా పేరెంట్) యొక్క గరిష్టంగా `N%` ఎత్తుకు పరిమితం చేస్తుంది, కంటెంట్ ఓవర్‌ఫ్లో అయినప్పుడు స్క్రోల్ బార్‌ను జోడిస్తుంది. ఉదాహరణ: `scroll-view(60%)`. |

### విడ్జెట్‌లు (Widgets)

| ప్రదర్శన లక్షణం (Appearance Attribute) | ప్రశ్న రకాలు | వివరణ |
|----------------------|----------------|-------------|
| `likert` | select_one | ఎంపికలను లైకర్ట్ స్కేల్ రోగా ప్రదర్శిస్తుంది (ఇప్పటికే పై టేబుల్‌లో ఉంది; సపోర్ట్ నిర్ధారించబడింది). |
| `distress` | select_one | ఎంపికలను ఎమోషనల్ ఐకాన్‌లతో కెస్లర్ సైకలాజికల్ డిస్ట్రెస్ స్కేల్ (K10) విజువల్ విడ్జెట్‌గా మారుస్తుంది. |
| `rating_box-fill-{c1}-{c2}-{c3}-{c4}-{c5}` | select_one | ఐదు కలర్ స్లాట్‌లతో స్టైల్ చేసిన రేటింగ్ బాక్స్‌లుగా ఎంపికలను మారుస్తుంది. `c1` = బాహ్య కంటైనర్ బోర్డర్, `c2` = ఎంపిక చేయని బోర్డర్, `c3` = ఎంపిక చేసిన బోర్డర్ మరియు ఫిల్, `c4` = ఎంపిక చేయని టెక్స్ట్ రంగు, `c5` = ఎంపిక చేసిన టెక్స్ట్ రంగు. ఉదాహరణ: `rating_box-fill-grey-blue-green-black-white`. |
| `tagging-choices-noshow-v2-{c1}-{c2}-{c3}-{c4}-{c5}` | select_multiple | ఎంపికలను రంగుల ట్యాగ్ చిప్స్‌గా మారుస్తుంది. ఐదు కలర్ స్లాట్‌లు `rating_box-fill` వలె అదే క్రమాన్ని అనుసరిస్తాయి. ఎంచుకున్న ఎంపికలు హైలైట్ చేయబడతాయి; ఎంచుకోని ఎంపికలు సారాంశం వీక్షణ నుండి అణిచివేయబడతాయి. |

### భాష మార్పిడి (Language switcher)

| ప్రదర్శన లక్షణం (Appearance Attribute) | ప్రశ్న రకాలు | వివరణ |
|----------------------|----------------|-------------|
| `change_language-{colors} default('lang')` | note, text | ఇచ్చిన రంగు కోడ్‌లతో స్టైల్ చేసిన లాంగ్వేజ్-స్విచ్చర్ విడ్జెట్‌ను మారుస్తుంది. `default('lang')` టోకెన్ ప్రారంభ భాషను సెట్ చేస్తుంది (ఉదా. `default('en')`); ఇది పార్సింగ్ సమయంలో అంతర్గతంగా `rtDefault('lang')`గా తిరిగి వ్రాయబడుతుంది. ఉదాహరణ: `change_language-blue-white default('vi')`. |

### ఇన్‌లైన్ తేదీ/సమయ ఫార్మాట్

`date`, `time`, మరియు `datetime` ఫీల్డ్‌ల కోసం, మీరు ప్రదర్శనకు జోడించిన ఫార్మాట్ స్ట్రింగ్‌ను ఉపయోగించి అనుకూల ప్రదర్శన ఫార్మాట్‌ను పేర్కొనవచ్చు:

```
inline-[%d/%m/%Y]
inline-1line-[%d/%m/%Y %H:%M]
```

ఫార్మాట్ టోకెన్లు `format-date()` మరియు `format-date-time()` వలె ఉంటాయి. [Functions — Date and time functions](operators-and-functions/functions#date-and-time-functions) చూడండి.

ఉదాహరణ:

| type | name | label | appearance |
|------|------|-------|------------|
| datetime | event_time | ఈవెంట్ తేదీ మరియు సమయం | inline-[%d/%m/%Y %I:%M %p] |
| date | birth_date | పుట్టిన తేదీ | inline-[%d/%m/%Y] |

### ఇన్‌లైన్ బటన్ లేఅవుట్ — `display{}` మరియు `results{}`

ఇన్‌లైన్ ఐకాన్ బటన్‌గా రెండర్ అయ్యే ప్రశ్న రకాల కోసం (`date`, `time`, `datetime`, `image`, `audio`, `video`, `file`, `barcode`, `geopoint`), రెండు ప్రదర్శన సవరణలు (appearance modifiers) బటన్ స్థానం మరియు క్యాప్చర్ తర్వాత ప్రవర్తనను నియంత్రిస్తాయి.

#### `display{...}` — క్యాప్చర్ ముందు బటన్ స్థానం

```
display{<align>, <size>, <color>}
```

| పరామితి (Parameter) | విలువలు | డిఫాల్ట్ |
|-----------|--------|---------|
| Align | `left`, `right`, `top`, `center`, `bottom` | `right` |
| Size | `small`, `medium`, `large` | `small` |
| Color | hex ఉదా. `#FF5500` | ప్రాథమిక థీమ్ రంగు |
| Flag | `inline-icon` | ఐకాన్ మోడ్‌ను బలవంతం చేస్తుంది |

| Align విలువ | లేఅవుట్ |
|-------------|--------|
| `right` | లేబుల్‌కు కుడివైపున బటన్ |
| `left` | లేబుల్‌కు ఎడమవైపున బటన్ |
| `top` | లేబుల్ పైన బటన్, పూర్తి వెడల్పుతో మధ్యలో |
| `center` / `bottom` | లేబుల్ కింద బటన్, పూర్తి వెడల్పుతో మధ్యలో |

#### `results{...}` — క్యాప్చర్ తర్వాత లేఅవుట్ మరియు దృశ్యమానత

`display{}` సెట్టింగ్‌లను వారసత్వంగా పొందుతుంది. విలువ క్యాప్చర్ చేయబడిన తర్వాత బటన్‌ను తరలించడానికి లేదా మూలకాలను దాచడానికి ఉపయోగించండి.

```
results{<align>, hide(<element>)}
```

| `hide` విలువ | ప్రభావం |
|---|---|
| `hide(capture)` | ఫైల్/విలువ ఉన్న తర్వాత క్యాప్చర్ బటన్‌ను దాచిపెడుతుంది |
| `hide(review)` | రివ్యూ థంబ్‌నెయిల్ / ప్లేబ్యాక్ బటన్‌ను దాచిపెడుతుంది |
| `hide(filename)` | అప్‌లోడ్ తర్వాత చూపబడే ఫైల్ పేరును దాచిపెడుతుంది |
| `hide(camera)` | క్యాప్చర్ తర్వాత కెమెరా ట్రిగ్గర్ బటన్‌ను దాచిపెడుతుంది |
| `hide(scanner)` | విలువ స్కాన్ చేసిన తర్వాత బార్‌కోడ్ స్కాన్ బటన్‌ను దాచిపెడుతుంది |
| `hide(value)` | స్కాన్ చేసిన విలువ టెక్స్ట్‌ను దాచిపెడుతుంది (బార్‌కోడ్ / జియోపాయింట్) |

విలువ క్యాప్చర్ చేయబడిన క్షణంలో విడ్జెట్ స్వయంచాలకంగా `display{}` నుండి `results{}` లేఅవుట్‌కు మారుతుంది.

**ఉదాహరణలు:**

```
inline display{right}                                    → లేబుల్‌కు కుడివైపు ఐకాన్
inline display{left, large}                              → ఎడమవైపు పెద్ద ఐకాన్
inline display{center, large, #FF5500}                   → లేబుల్ కింద పెద్ద ఆరెంజ్ ఐకాన్
inline display{right} results{left}                      → క్యాప్చర్ తర్వాత ఐకాన్ ఎడమవైపుకు మారుతుంది
inline display{right} results{hide(capture)}             → క్యాప్చర్ తర్వాత ఐకాన్ అదృశ్యమవుతుంది
inline display{center} results{hide(capture), hide(filename)}
```

## ప్రదర్శన సమస్యల పరిష్కారం

1. **ప్రదర్శన వర్తించలేదు**: ప్రదర్శన కాలమ్‌లో స్పెల్లింగ్ తప్పుల కోసం తనిఖీ చేయండి.
2. **అస్థిరమైన రెండరింగ్**: ప్రశ్న రకం మరియు ప్లాట్‌ఫారమ్‌తో అనుకూలతను ధృవీకరించండి.
3. **పనితీరు సమస్యలు**: ముఖ్యంగా పెద్ద సర్వేల కోసం సంక్లిష్టమైన ప్రదర్శనలను సరళీకరించడం పరిగణించండి.

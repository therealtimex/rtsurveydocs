rtSurvey బలమైన బహుళ-భాషా మద్దతును అందిస్తుంది, ఇది బహుళ భాషల్లో సర్వేలను రూపొందించడానికి మిమ్మల్ని అనుమతిస్తుంది. విభిన్న భాషా జనాభాలో లేదా బహుభాషా పరిసరాలలో పరిశోధన చేయడానికి ఈ ఫీచర్ కీలకం.

## బహుళ-భాషా సర్వేలను సెటప్ చేయడం

rtSurveyలో బహుళ-భాషా సర్వేను రూపొందించడానికి, మీరు మీ XLSFormకి భాషా-నిర్దిష్ట నిలువు వరుసలను (columns) జోడించాలి. ఎలాగంటే:

1. **లేబుల్ అనువాదాలు (Label Translations)**: `label::Language (code)` ఫార్మాట్‌ని ఉపయోగించి ప్రతి భాషకు నిలువు వరుసలను జోడించండి.
2. **హింట్ అనువాదాలు (Hint Translations)**: హింట్‌లను అనువదించడానికి `hint::Language (code)` ఉపయోగించండి.
3. **మీడియా ఫైల్ అనువాదాలు**: భాషా-నిర్దిష్ట మీడియా కోసం, `media::Language (code)` ఉపయోగించండి.

ఉదాహరణ:

```
| type    | name | label::English (en) | label::Español (es) | hint::English (en) | hint::Español (es) |
|---------|------|---------------------|---------------------|---------------------|---------------------|
| integer | age  | How old are you?    | ¿Cuántos años tienes?| Enter your age      | Ingrese su edad     |
```

## భాషా కోడ్‌లు

భాష పేరు తర్వాత అధికారిక 2-అక్షరాల భాషా కోడ్‌లను (subtags) ఉపయోగించమని సిఫార్సు చేయబడింది. ఇది ఫారమ్ భాషను వినియోగదారు ఇంటర్‌ఫేస్ భాషతో సరిపోల్చడాన్ని సులభతరం చేస్తుంది. మీరు అధికారిక కోడ్‌లను [ఇక్కడ](https://www.iana.org/assignments/language-subtag-registry/language-subtag-registry) కనుగొనవచ్చు.

## డిఫాల్ట్ భాషను సెట్ చేయడం

డేటా సేకరణ కోసం డిఫాల్ట్ భాషను సెట్ చేయడానికి, మీ XLSFormలోని `settings` వర్క్‌షీట్‌ను ఉపయోగించండి:

```
| form_id   | version | default_language |
|-----------|---------|-------------------|
| test_form | 101     | French (fr)       |
```

## rtSurvey-నిర్దిష్ట ఫీచర్లు

### డైనమిక్ భాషా మార్పిడి

డేటా సేకరణ సమయంలో వినియోగదారులు డైనమిక్‌గా భాషలను మార్చుకోవడానికి rtSurvey అనుమతిస్తుంది:

- వెబ్ ఇంటర్‌ఫేస్‌లో, ఎగువ నావిగేషన్ బార్‌లోని భాషా డ్రాప్‌డౌన్‌ను ఉపయోగించండి.
- మొబైల్ యాప్‌లో, సెట్టింగ్‌ల మెనూ ద్వారా భాషా ఎంపికలను యాక్సెస్ చేయండి.

### భాషా-నిర్దిష్ట ధృవీకరణ సందేశాలు

rtSurvey ధృవీకరణ సందేశాలకు కూడా బహుళ-భాషా మద్దతును అందిస్తుంది:

```
| type    | name | constraint | constraint_message::English (en) | constraint_message::Español (es) |
|---------|------|------------|----------------------------------|----------------------------------|
| integer | age  | . <= 150   | Age must be 150 or less          | La edad debe ser 150 o menos     |
```

### స్థానికీకరించిన అవసరమైన (required) సందేశాలు

అవసరమైన ఫీల్డ్ ఖాళీగా ఉన్నప్పుడు అనువదించబడిన ఎర్రర్‌ను చూపించడానికి `required_message::Language (code)`ని ఉపయోగించండి:

```
| type | name | required | required_message::English (en) | required_message::Tiếng Việt (vi) |
|------|------|----------|-------------------------------|----------------------------------|
| text | name | yes | This field is required | Trường này là bắt buộc |
```

### RTL భాషా మద్దతు

అరబిక్ లేదా హీబ్రూ వంటి కుడి నుండి ఎడమకు (RTL) ఉండే భాషల కోసం, rtSurvey ఆటోమేటిక్‌గా లేఅవుట్‌ని సర్దుబాటు చేస్తుంది:

```
| type | name | label::English (en) | label::Arabic (ar) |
|------|------|---------------------|---------------------|
| text | name | Your name           | اسمك                |
```

### భాషా-నిర్దిష్ట ప్రదర్శన (Appearance)

వివిధ భాషల కోసం వేర్వేరు ప్రదర్శనలను (appearances) పేర్కొనడానికి rtSurvey మిమ్మల్ని అనుమతిస్తుంది:

```
| type | name | label::English (en) | label::Chinese (zh) | appearance::English (en) | appearance::Chinese (zh) |
|------|------|---------------------|---------------------|--------------------------|---------------------------|
| text | address | Address          | 地址                 | multiline                | textarea                  |
```

## ద్విభాషా లేబుల్స్‌లో HTML ఫార్మాటింగ్

మీరు ఒకే లేబుల్ సెల్‌లో భాషా వ్రాపర్లతో HTML ట్యాగ్‌లను కలపవచ్చు. rtSurvey యాక్టివ్-లాంగ్వేజ్ బ్లాక్‌ను సంగ్రహించి మిగిలిన HTMLని రెండర్ చేస్తుంది.

ప్రతి భాషకు బోల్డ్ మరియు ఫాంట్ రంగును ఉపయోగించే ఉదాహరణ:

```
<en><big><b>Section 2: Household Income</b></big><br>Ask the household head only.</en><vi><big><b>Phần 2: Thu nhập hộ gia đình</b></big><br>Chỉ hỏi chủ hộ.</vi>
```

భాషా వ్రాపర్ల లోపల మద్దతు ఉన్న ఇన్లైన్ ట్యాగ్‌లు: `<b>`, `<i>`, `<u>`, `<big>`, `<small>`, `<font color="...">`, `<br>`, `<span style="...">`.

ప్రతి భాషకు రంగు వచనం (colored text) ఉదాహరణ:

```
<en><font color="red">Required field</font></en><vi><font color="red">Trường bắt buộc</font></vi>
```

## భాషా-అవగాహన గణనలు

ఫారమ్‌లో `${language_use}` ఫీల్డ్ ఉన్నప్పుడు (`change_language` విడ్జెట్ ద్వారా సెట్ చేయబడుతుంది), యాక్టివ్ భాషలో విలువలను తిరిగి ఇవ్వడానికి `if()`ని ఉపయోగించండి:

```
if(${language_use} = 'en', label_en, label_vi)
```

ఉదాహరణ — `pulldata('rawquery', ...)`ని ఉపయోగించి యాక్టివ్ భాషలో లుక్అప్ ఫలితాన్ని ప్రదర్శించడం:

```
| type      | name        | calculation                                                                 |
|-----------|-------------|-----------------------------------------------------------------------------|
| calculate | district_label | if(${language_use} = 'en', pulldata('rawquery', concat(${family_path}, '/locations.db::externalData'), 'SELECT label_en FROM externalData WHERE code = ?', ${district}), pulldata('rawquery', concat(${family_path}, '/locations.db::externalData'), 'SELECT label_vi FROM externalData WHERE code = ?', ${district})) |
```

గమనిక: `language_use` ఫీల్డ్ సాధారణంగా `change_language` అప్పీయరెన్స్ విడ్జెట్ ద్వారా సెట్ చేయబడుతుంది. Appearance — change_language చూడండి.

## బహుళ-భాషా సర్వేల కోసం ఉత్తమ పద్ధతులు

1. **స్థిరమైన నామకరణం**: మీ ఫారమ్ అంతటా స్థిరమైన భాషా కోడ్‌లను ఉపయోగించండి.
2. **ప్రొఫెషనల్ అనువాదం**: సర్వే సందర్భం తెలిసిన ప్రొఫెషనల్ అనువాదకులను నియమించుకోండి.
3. **సందర్భ గమనికలు**: ఖచ్చితమైన అనువాదాలను నిర్ధారించడానికి అనువాదకులకు సందర్భ గమనికలను అందించండి.
4. **పరీక్షించడం**: విస్తరణకు ముందు అన్ని భాషల్లో మీ ఫారమ్‌ను పరీక్షించండి.
5. **యూనికోడ్ మద్దతు**: లాటిన్ యేతర స్క్రిప్ట్‌ల కోసం మీ డేటా సేకరణ పరికరాలు యూనికోడ్‌కు మద్దతు ఇస్తున్నాయని నిర్ధారించుకోండి.
6. **భాషా-నిర్దిష్ట మీడియా**: ప్రతి భాషకు సాంస్కృతికంగా తగిన చిత్రాలు లేదా ఆడియోను ఉపయోగించండి.
7. **చిత్రాలలో వచనాన్ని నివారించండి**: వచనంతో కూడిన చిత్రాలను ఉపయోగిస్తుంటే, ప్రతి భాషకు వేర్వేరు చిత్రాలను సృష్టించండి.

## ప్రత్యేక కేసులను నిర్వహించడం

### మిశ్రమ భాషా ప్రతిస్పందనలు

ఎంచుకున్న ఫారమ్ భాషతో సంబంధం లేకుండా ఏ స్క్రిప్ట్‌లోనైనా వచనాన్ని ఇన్‌పుట్ చేయడానికి rtSurvey ప్రతిస్పందనదారులను అనుమతిస్తుంది. పేర్లు లేదా చిరునామాలను వాటి అసలు స్క్రిప్ట్‌లో క్యాప్చర్ చేయడానికి ఇది ఉపయోగపడుతుంది.

### భాషా-నిర్దిష్ట ప్రశ్న రకాలు

కొన్ని ప్రశ్న రకాలు నిర్దిష్ట భాషలకు మరింత సముచితంగా ఉండవచ్చు. వివిధ భాషల కోసం వేర్వేరు ప్రశ్న రకాలను ఉపయోగించడానికి rtSurvey మిమ్మల్ని అనుమతిస్తుంది:

```
| type::English (en) | type::Japanese (ja) | name | label::English (en) | label::Japanese (ja) |
|--------------------|---------------------|------|---------------------|----------------------|
| text               | select_one kanji    | name | Enter your name     | 名前を選んでください    |
```

## బహుళ-భాషా డేటాను ఎగుమతి చేయడం

rtSurvey నుండి డేటాను ఎగుమతి చేస్తున్నప్పుడు:

- నిర్దిష్ట భాషలో ఎగుమతి చేయడానికి ఎంచుకోండి లేదా అన్ని భాషా వెర్షన్‌లను చేర్చండి.
- ఎగుమతిలో భాషా మెటాడేటా చేర్చబడుతుంది, ప్రతి ప్రతిస్పందనకు ఏ భాష ఉపయోగించబడిందో సూచిస్తుంది.

## మొబైల్ యాప్ పరిగణనలు

- rtSurvey మొబైల్ యాప్ ఆఫ్‌లైన్ భాషా మార్పిడికి మద్దతు ఇస్తుంది.
- ఆఫ్‌లైన్‌లోకి వెళ్లే ముందు అవసరమైన అన్ని భాషా ఫైల్‌లు డౌన్‌లోడ్ చేయబడ్డాయని నిర్ధారించుకోండి.

## తెలిసిన పరిమితులు

- కొన్ని అధునాతన ఫీచర్లు అన్ని భాషల్లో అందుబాటులో ఉండకపోవచ్చు.
- చాలా పొడవైన అనువాదాలు చిన్న స్క్రీన్‌లపై లేఅవుట్‌ను ప్రభవితం చేయవచ్చు.

rtSurvey యొక్క బహుళ-భాషా సామర్థ్యాలను ఉపయోగించడం ద్వారా, మీరు విభిన్న జనాభాను చేరుకునే మరియు అధిక-నాణ్యత, భాషాపరంగా ఖచ్చితమైన డేటాను అందించే సమగ్రమైన, ప్రాప్యత చేయగల సర్వేలను సృష్టించవచ్చు.

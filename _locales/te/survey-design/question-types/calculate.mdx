`calculate` ప్రశ్న రకం బ్యాక్‌గ్రౌండ్‌లో నిశ్శబ్దంగా ఒక సూత్రాన్ని అమలు చేస్తుంది. ఇది ఫలితాన్ని ఇతర ప్రశ్నలు సూచించగల ఒక పేరున్న ఫీల్డ్‌లో నిల్వ చేస్తుంది — కానీ ఇది ఎన్యూమరేటర్‌కు ఎటువంటి ఇన్‌పుట్ లేదా లేబుల్‌ను చూపదు. విలువలను పొందడానికి, స్ట్రింగ్‌లను కలపడానికి, కండిషనల్ లాజిక్‌ను అమలు చేయడానికి లేదా ఫారమ్‌లో మీకు తర్వాత అవసరమయ్యే డేటాను వెతకడానికి దీన్ని ఉపయోగించండి.

---

## ప్రాథమిక సింటాక్స్

| type | name | label | calculation |
|------|------|-------|-------------|
| calculate | total | | `${price} * ${quantity}` |

- **type**: ఎల్లప్పుడూ `calculate`.
- **name**: ఒక ప్రత్యేకమైన ఫీల్డ్ పేరు. ఇతర ప్రశ్నలు `${name}`తో దీన్ని సూచిస్తాయి.
- **label**: ఖాళీగా వదిలేయండి — calculate ఫీల్డ్‌లు ఎన్యూమరేటర్‌కు ఎప్పుడూ కనిపించవు.
- **calculation**: మూల్యాంకనం చేయాల్సిన సూత్రం. అన్ని [XLSForm ఫంక్షన్‌లు](../operators-and-functions/functions) మరియు ఫీల్డ్ రిఫరెన్స్‌లకు మద్దతు ఇస్తుంది.

## విలువను లాక్ చేయడానికి `once()`ని ఉపయోగించడం

డిఫాల్ట్‌గా, సూచించిన ఫీల్డ్ మారినప్పుడల్లా `calculate` తిరిగి మూల్యాంకనం చేయబడుతుంది. మొదటి లోడ్‌లో మాత్రమే మూల్యాంకనం చేయడానికి మరియు ఫలితాన్ని స్తంభింపజేయడానికి సూత్రాన్ని `once()`లో చుట్టండి:

| type | name | label | calculation |
|------|------|-------|-------------|
| calculate | interview_start | | `once(now())` |

టైమ్‌స్టాంప్‌లు, ప్రారంభ విలువలు లేదా మార్పు జరిగినప్పుడు తిరిగి లెక్కించడం అవసరం లేని సందర్భాల్లో `once()`ని ఉపయోగించండి.

## బాహ్య మూలాల నుండి డేటాను లాగడం

### CSV ఫైల్ నుండి

```
pulldata('staff.csv', 'department', 'name', ${staff_id})
```

పూర్తి రిఫరెన్స్ కోసం [pulldata()](../operators-and-functions/pulldata) చూడండి.

### బండిల్ చేయబడిన SQLite డేటాబేస్ నుండి

```
pulldata('rawquery',
  concat(${family_path}, '/locations.db::provinces'),
  'SELECT name FROM provinces WHERE id = ?',
  ${province_id})
```

పాత్ నిర్మాణ వివరాల కోసం [లోకల్ డేటాబేస్ సెర్చ్](../advanced-features/local-database-search) చూడండి.

### యాప్ కాంటెక్స్ట్ నుండి

```
pulldata('app-api', 'user.username')
pulldata('app-api', 'family_path')
```

అందుబాటులో ఉన్న అన్ని కీల కోసం [App API](../app-api) చూడండి.

## relevant మరియు constraintలో calculateని ఉపయోగించడం

ఇతర ఫీల్డ్‌లు ఏదైనా ఫీల్డ్ లాగానే `calculate` ఫలితాన్ని సూచించగలవు:

| type | name | label | relevant | constraint |
|------|------|-------|----------|------------|
| calculate | bmi | | | `${weight} div (${height} * ${height}) * 10000` |
| note | bmi_warning | BMI is very high — please verify weight and height. | `${bmi} > 40` | |

---

## ఉత్తమ పద్ధతులు

1. calculate ఫీల్డ్‌లకు అర్థవంతమైన పేర్లను ఇవ్వండి — `total_cost` అనేది `calc1` కంటే స్పష్టంగా ఉంటుంది మరియు ఎగుమతులలో గుర్తించడం సులభం.
2. ఒకే లోతైన నెస్టెడ్ ఎక్స్‌ప్రెషన్‌కు బదులుగా సంక్లిష్టమైన సూత్రాలను బహుళ గొలుసుకట్టు calculate ఫీల్డ్‌లుగా విభజించండి.
3. మొదటి క్యాప్చర్ తర్వాత విలువలు మారకుండా నిరోధించడానికి టైమ్‌స్టాంప్‌లు మరియు ప్రారంభ స్నాప్‌షాట్‌ల కోసం `once()`ని ఉపయోగించండి.
4. `calculate` ఫీల్డ్‌లను వాటిని సూచించే మొదటి ప్రశ్నకు ముందు ఉంచండి — మూల్యాంకన క్రమం ఫారమ్ క్రమాన్ని అనుసరిస్తుంది.
5. `label` నిలువు వరుసను ఖాళీగా ఉంచండి. కొన్ని సాధనాలు లేబుల్‌ను ప్రదర్శిస్తాయి; దాన్ని ఖాళీగా ఉంచడం వల్ల గందరగోళం కలగదు.

## పరిమితులు

- Calculate ఫీల్డ్‌లు ఎన్యూమరేటర్‌కు నేరుగా ప్రదర్శించబడవు — ఫలితాన్ని చూపించడానికి `note` ఫీల్డ్‌ను ఉపయోగించండి.
- `calculation` నిలువు వరుస తప్పనిసరి; సూత్రం లేని `calculate` అడ్డు వరుస ఎల్లప్పుడూ ఖాళీ స్ట్రింగ్‌ను నిల్వ చేస్తుంది.
- `once()`లో చుట్టబడితే తప్ప ప్రతి ఫారమ్ మార్పుపై ఫలితాలు తిరిగి మూల్యాంకనం చేయబడతాయి — పెద్ద ఫారమ్‌లలో చాలా సంక్లిష్టమైన సూత్రాలు తక్కువ-ముగింపు పరికరాలలో రెండరింగ్ పనితీరును ప్రభావితం చేయవచ్చు.
- లెక్కించిన విలువలు సబ్మిషన్‌లో స్ట్రింగ్‌లుగా నిల్వ చేయబడతాయి. ఫలితాన్ని అంకగణిత లేదా లాజిక్ ఎక్స్‌ప్రెషన్‌లకు పంపేటప్పుడు రకాన్ని మార్చడానికి (cast) `number()`, `int()`, లేదా `boolean()`ని ఉపయోగించండి.

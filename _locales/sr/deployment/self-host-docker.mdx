import { Callout, Steps } from 'nextra/components'

Koristite ovaj vodič ako želite da pokrenete rtSurvey na svom serveru (VPS, golo gvožđe ili lokalna mašina) koristeći javnu Docker sliku `rtawebteam/rtcloud:survey-public`.

**Nije potrebna prijava na Docker Hub** — slika je javna.

Kontejner sadrži sve u jednoj slici:
- Apache + PHP (aplikacioni server)
- Shiny Server (analitičke kontrolne table, port 3838)
- Beanstalkd (red čekanja pozadinskih poslova)

---

## Zahtevi

### Server

| Resurs | Minimum | Preporučeno |
|----------|---------|-------------|
| RAM | 4 GB | 8 GB |
| Disk | 50 GB | 100 GB SSD |
| CPU | 2 vCPU | 4 vCPU |
| OS | Ubuntu 22.04 LTS | Ubuntu 22.04 LTS |

### Softver

- **Docker Engine 24.0+** — [vodič za instalaciju](https://docs.docker.com/engine/install/ubuntu/)
- **Docker Compose v2.0+** — uključen sa Docker Desktop; na Linux-u: `apt install docker-compose-plugin`

## Podešavanje

<Steps>

### Kreirajte radni direktorijum

```bash
mkdir -p /opt/rtsurvey && cd /opt/rtsurvey
```

### Kreirajte `docker-compose.yml`

```yaml
services:
  mysql:
    image: mysql:8.0
    container_name: rtsurvey-mysql
    restart: unless-stopped
    command: >
      --default-authentication-plugin=mysql_native_password
      --character-set-server=utf8
      --collation-server=utf8_unicode_ci
      --sql-mode=NO_ENGINE_SUBSTITUTION
    environment:
      MYSQL_ROOT_PASSWORD: ${MYSQL_ROOT_PASSWORD}
      MYSQL_DATABASE: ${MYSQL_DATABASE:-smartsurvey}
      MYSQL_USER: ${MYSQL_USER:-smartsurvey}
      MYSQL_PASSWORD: ${MYSQL_PASSWORD}
      MYSQL_ROOT_HOST: '%'
    volumes:
      - mysql_data:/var/lib/mysql
    networks:
      - rtsurvey-net
    healthcheck:
      test: ["CMD-SHELL", "mysqladmin ping -h localhost -u root -p$$MYSQL_ROOT_PASSWORD"]
      interval: 10s
      timeout: 5s
      retries: 5
      start_period: 30s

  rtsurvey:
    image: rtawebteam/rtcloud:survey-public
    container_name: rtsurvey-app
    restart: unless-stopped
    entrypoint: ["/bin/entrypoint-production.sh"]
    depends_on:
      mysql:
        condition: service_healthy
    ports:
      - "${APP_PORT:-8080}:80"
      - "${SHINY_PORT:-3838}:3838"
    env_file:
      - .env
    volumes:
      - app_uploads:/var/www/html/smartsurvey/uploads
      - app_audios:/var/www/html/smartsurvey/audios
      - app_downloads:/var/www/html/smartsurvey/downloads
      - app_gallery:/var/www/html/smartsurvey/gallery
      - app_tmp:/var/www/html/smartsurvey/tmp
      - app_cache:/var/www/html/smartsurvey/cache
      - app_runtime:/var/www/html/smartsurvey/protected/runtime
      - app_assets:/var/www/html/smartsurvey/assets
      - app_aggregate:/var/www/html/smartsurvey/aggregate
    networks:
      - rtsurvey-net
    healthcheck:
      test: ["CMD", "curl", "-f", "http://localhost/health"]
      interval: 30s
      timeout: 10s
      retries: 3
      start_period: 90s

  # Optional: Embedded Keycloak SSO
  # Start with: docker compose --profile embed-keycloak up -d
  keycloak:
    image: quay.io/keycloak/keycloak:latest
    container_name: rtsurvey-keycloak
    restart: unless-stopped
    profiles:
      - embed-keycloak
    command: start --import-realm
    environment:
      KEYCLOAK_ADMIN: ${KEYCLOAK_ADMIN_USER:-admin}
      KEYCLOAK_ADMIN_PASSWORD: ${KEYCLOAK_ADMIN_PASSWORD}
      KC_HTTP_ENABLED: "true"
      KC_HTTP_RELATIVE_PATH: /auth
      KC_PROXY_HEADERS: xforwarded
      KC_HOSTNAME: ${KC_HOSTNAME}
      KC_HOSTNAME_STRICT: "false"
      KC_DB: mysql
      KC_DB_URL_DATABASE: ${KEYCLOAK_DB:-keycloak}
      KC_DB_URL_HOST: mysql
      KC_DB_USERNAME: ${KEYCLOAK_DB_USER:-keycloak}
      KC_DB_PASSWORD: ${KEYCLOAK_DB_PASSWORD}
    volumes:
      - ./keycloak-import:/opt/keycloak/data/import
    ports:
      - "${KEYCLOAK_PORT:-8091}:8080"
    depends_on:
      mysql:
        condition: service_healthy
    networks:
      - rtsurvey-net
    healthcheck:
      test: ["CMD-SHELL", "curl -f http://localhost:9000/health/ready || exit 1"]
      interval: 30s
      timeout: 10s
      retries: 10
      start_period: 120s

volumes:
  mysql_data:
  app_uploads:
  app_audios:
  app_downloads:
  app_gallery:
  app_tmp:
  app_cache:
  app_runtime:
  app_assets:
  app_aggregate:

networks:
  rtsurvey-net:
    driver: bridge
```

### Kreirajte `.env`

```bash
# Project
PROJECT_ID=mysurvey
PROJECT_TYPE=rtsurvey
PROJECT_URL=your-server-ip-or-domain
HTTP_PROTOCOL=http
TZ=UTC

# Database
MYSQL_HOST=mysql
MYSQL_DATABASE=smartsurvey
MYSQL_USER=smartsurvey
MYSQL_ROOT_PASSWORD=change-this-root-password
MYSQL_PASSWORD=change-this-app-password

# Admin (set before first startup — cannot change via env after DB is created)
ADMIN_PASSWORD=change-this-admin-password

# Runtime
RUN_ENV=prod
RUN_MODE=admin
GII_ENABLED=false
CSRF_VALIDATION_ENABLED=true

# Ports (optional — defaults shown)
APP_PORT=8080
SHINY_PORT=3838
```

<Callout type="warning">
Promenite `MYSQL_ROOT_PASSWORD` i `MYSQL_PASSWORD` pre pokretanja. Koristite jake nasumične nizove (32+ karaktera) u produkciji.
</Callout>

### Pokrenite stek

```bash
docker compose up -d
```

Prvo pokretanje traje oko 60–90 sekundi — MySQL inicijalizuje bazu podataka pri prvom pokretanju.

### Verifikujte

```bash
# Check all containers are running
docker compose ps

# Check application health
curl http://localhost:8080/health
```

</Steps>

## Prva Prijava

Kada provera ispravnosti prođe, otvorite pregledač:

```
http://your-server:8080/cpms/cpmsSite/login
```

| Polje | Vrednost |
|-------|-------|
| Korisničko ime | `admin` |
| Lozinka | vrednost `ADMIN_PASSWORD` u vašem `.env` (podrazumevano je `admin`) |

<Callout type="warning">
Postavite `ADMIN_PASSWORD` u svom `.env` pre prvog pokretanja. Ulazna tačka ga postavlja pri prvom pokretanju — promena nakon inicijalizacije baze podataka nema efekta.
</Callout>

## Promenljive Okruženja

### Potrebne od strane kontejnera aplikacije

Ulazna tačka će odbiti da se pokrene ako bilo koja od njih nedostaje:

| Promenljiva | Opis |
|----------|-------------|
| `PROJECT_ID` | Jedinstveni identifikator za ovu instancu (alfanumerički, bez razmaka) |
| `PROJECT_URL` | Domen ili IP gde se pristupa aplikaciji (bez prefiksa `http://`) |
| `MYSQL_HOST` | MySQL naziv hosta — koristite naziv Docker servisa (npr. `mysql`) |
| `MYSQL_DATABASE` | Naziv baze podataka |
| `MYSQL_PASSWORD` | Lozinka korisnika baze podataka |

### Potrebne od strane MySQL kontejnera

| Promenljiva | Opis |
|----------|-------------|
| `MYSQL_ROOT_PASSWORD` | MySQL root lozinka (koristi je kontejner `mysql`, ne aplikacija) |

### Preporučeno

| Promenljiva | Podrazumevano | Opis |
|----------|---------|-------------|
| `MYSQL_USER` | `smartsurvey` | Korisničko ime baze podataka |
| `ADMIN_PASSWORD` | `admin` | Inicijalna admin lozinka — **postavite pre prvog pokretanja**, ne može se promeniti putem env nakon kreiranja DB |
| `HTTP_PROTOCOL` | `https` | Postavite na `http` ako ne koristite SSL |
| `PROJECT_PORT` | `80` | Eksterni port na koji se korisnici povezuju (ne interni Docker port) |
| `PROJECT_TYPE` | `rtwork` | Tip platforme — koristite `rtsurvey` za platformu ankete |
| `TZ` | `UTC` | Vremenska zona (npr. `Asia/Bangkok`, `America/New_York`) |

### Runtime

| Promenljiva | Podrazumevano | Opis |
|----------|---------|-------------|
| `RUN_ENV` | `prod` | Mod okruženja (`prod` ili `dev`) |
| `RUN_MODE` | `admin` | Uloga servisa — koristite `admin` za podešavanje sa jednim serverom |
| `GII_ENABLED` | `false` | Zadržite `false` u produkciji (Yii generator koda) |
| `CSRF_VALIDATION_ENABLED` | `true` | CSRF zaštita — zadržite `true` |

### Licenca

| Promenljiva | Podrazumevano | Opis |
|----------|---------|-------------|
| `REQUIRE_LICENSE` | `false` | Postavite na `true` da biste primenili validaciju licence |
| `RTCLOUD_LICENSE_KEY` | — | Vaš ključ licence — potreban kada je `REQUIRE_LICENSE=true` |

## Trajnost Podataka

Svi korisnički podaci se čuvaju u imenovanim Docker volumenima. Oni preživljavaju restartovanje kontejnera i ažuriranja slika.

| Volumen | Sadržaj |
|--------|----------|
| `mysql_data` | Baza podataka (ankete, korisnici, odgovori) |
| `app_uploads` | Otpremanja fajlova iz anketa |
| `app_gallery` | Medijska biblioteka |
| `app_downloads` | Generisani fajlovi za izvoz |
| `app_audios` | Audio snimci |
| `app_runtime` | PHP sesija i keš fajlovi |
| `app_aggregate` | Agregirani analitički podaci |

## Uobičajene Operacije

### Pregledajte logove

```bash
docker compose logs -f rtsurvey
docker compose logs -f mysql
```

### Restartujte aplikaciju

```bash
docker compose restart rtsurvey
```

### Pristupite shell-u

```bash
docker compose exec rtsurvey bash
```

### Ručno pokrenite migracije baze podataka

```bash
docker compose exec rtsurvey php /var/www/html/smartsurvey/protected/yiic migrate
```

## Nadogradnje

Slika je označena `survey-public`. Za ažuriranje na najnoviju verziju:

```bash
docker compose pull
docker compose up -d
```

Migracije baze podataka se automatski pokreću pri pokretanju putem produkcijske ulazne tačke.

## Backup i Obnova

### Backup baze podataka

```bash
docker compose exec mysql \
  mysqldump -u root -p"${MYSQL_ROOT_PASSWORD}" smartsurvey \
  > backup-$(date +%Y%m%d).sql
```

### Obnova baze podataka

```bash
docker compose exec -T mysql \
  mysql -u root -p"${MYSQL_ROOT_PASSWORD}" smartsurvey \
  < backup-20240101.sql
```

### Backup otpremljenih fajlova

```bash
docker run --rm \
  -v rtsurvey_app_uploads:/data \
  -v $(pwd):/backup \
  alpine tar czf /backup/uploads-$(date +%Y%m%d).tar.gz -C /data .
```

## Ugrađeni Keycloak (Opcionalni SSO)

Produkcijski compose fajl uključuje opcioni Keycloak kontejner za SSO. Deli isti MySQL instance i aktivira se putem Docker Compose profila.

<Callout type="info">
Ugrađeni Keycloak zahteva najmanje **4 GB RAM**. Opcionalan je — preskočite ovo ako vam nije potreban SSO.
</Callout>

### Dodajte Keycloak promenljive u `.env`

```bash
# Keycloak admin
KEYCLOAK_ADMIN_USER=admin
KEYCLOAK_ADMIN_PASSWORD=change-this-keycloak-password

# Keycloak database (created automatically in the shared MySQL on first run)
KEYCLOAK_DB=keycloak
KEYCLOAK_DB_USER=keycloak
KEYCLOAK_DB_PASSWORD=change-this-keycloak-db-password

# KC_HOSTNAME: full public URL of your server (Keycloak appends /auth automatically)
KC_HOSTNAME=http://your-server:8091

# Port Keycloak listens on (host)
KEYCLOAK_PORT=8091

# Tell the rtCloud app to connect to embedded Keycloak
EMBED_KEYCLOAK=true
KEYCLOAK_URL=http://your-server:8091
KEYCLOAK_REALM=rtsurvey
KEYCLOAK_CLIENT_ID=rtsurvey
KEYCLOAK_CLIENT_SECRET=your-client-secret
```

Servis `keycloak` je već uključen u `docker-compose.yml` iznad (pod profilom `embed-keycloak` — neće se pokrenuti osim ako ne koristite `--profile embed-keycloak`).

Kreirajte direktorijum za uvoz (Keycloak će se pokrenuti bez njega, ali automatsko provizioniranje realma neće raditi):

```bash
mkdir -p /opt/rtsurvey/keycloak-import
```

### Pokrenite sa Keycloak-om

```bash
docker compose --profile embed-keycloak up -d
```

Za pokretanje bez Keycloak-a (podrazumevano):

```bash
docker compose up -d
```

### Keycloak admin konzola

Kada je zdrav, pristupite Keycloak admin UI na:

```
http://your-server:8091/auth/admin
```

Prijavite se sa `KEYCLOAK_ADMIN_USER` / `KEYCLOAK_ADMIN_PASSWORD`.

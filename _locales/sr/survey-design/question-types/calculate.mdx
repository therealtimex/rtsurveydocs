Tip pitanja `calculate` tiho pokreće formulu u pozadini. Rezultat čuva u imenovanom polju na koje se druga pitanja mogu referisati — ali anketaru ne prikazuje nikakav unos niti oznaku. Koristite ga za izvođenje vrednosti, spajanje niski, pokretanje uslovne logike ili traženje podataka koji će vam trebati kasnije u obrascu.

---

## Osnovna sintaksa

| type | name | label | calculation |
|------|------|-------|-------------|
| calculate | total | | `${price} * ${quantity}` |

- **type**: Uvek `calculate`.
- **name**: Jedinstveno ime polja. Druga pitanja se referišu na ovo pomoću `${name}`.
- **label**: Ostavite prazno — polja calculate se nikada ne prikazuju anketaru.
- **calculation**: Formula koju treba proceniti. Podržava sve [XLSForm funkcije](../operators-and-functions/functions) i reference polja.

---

## Uobičajeni obrasci

### Aritmetika

| type | name | label | calculation |
|------|------|-------|-------------|
| integer | price | Unit price | |
| integer | quantity | Quantity | |
| calculate | total | | `${price} * ${quantity}` |
| note | total_note | Total: `${total}` | |

### Spajanje niski (String concatenation)

| type | name | label | calculation |
|------|------|-------|-------------|
| text | first_name | First name | |
| text | last_name | Last name | |
| calculate | full_name | | `concat(${first_name}, ' ', ${last_name})` |

### Uslovna vrednost

| type | name | label | calculation |
|------|------|-------|-------------|
| integer | score | Score (0–100) | |
| calculate | grade | | `if(${score} >= 90, 'A', if(${score} >= 75, 'B', if(${score} >= 60, 'C', 'F')))` |

### Starost na osnovu datuma rođenja

| type | name | label | calculation |
|------|------|-------|-------------|
| date | dob | Date of birth | |
| calculate | age_years | | `int((today() - ${dob}) div 365.25)` |

## Korišćenje `once()` za zaključavanje vrednosti

Podrazumevano, `calculate` se ponovo procenjuje kad god se promeni bilo koje polje na koje se referiše. Umotajte formulu u `once()` da biste je procenili samo pri prvom učitavanju i zamrznuli rezultat:

| type | name | label | calculation |
|------|------|-------|-------------|
| calculate | interview_start | | `once(now())` |

Koristite `once()` za vremenske oznake (timestamps), početne vrednosti ili bilo koji slučaj gde je ponovno izračunavanje pri promeni nepoželjno.

## Izvlačenje podataka iz spoljnih izvora

### Iz CSV datoteke

```
pulldata('staff.csv', 'department', 'name', ${staff_id})
```

Pogledajte [pulldata()](../operators-and-functions/pulldata) za punu referencu.

### Iz upakovane SQLite baze podataka

```
pulldata('rawquery',
  concat(${family_path}, '/locations.db::provinces'),
  'SELECT name FROM provinces WHERE id = ?',
  ${province_id})
```

Pogledajte [Lokalna pretraga baze podataka](../advanced-features/local-database-search) za detalje o konstrukciji putanje.

### Iz konteksta aplikacije

```
pulldata('app-api', 'user.username')
pulldata('app-api', 'family_path')
```

Pogledajte [App API](../app-api) za sve dostupne ključeve.

## Korišćenje calculate u relevant i constraint poljima

Druga polja se mogu referisati na rezultat `calculate` baš kao i na bilo koje drugo polje:

| type | name | label | relevant | constraint |
|------|------|-------|----------|------------|
| calculate | bmi | | | `${weight} div (${height} * ${height}) * 10000` |
| note | bmi_warning | BMI is very high — please verify weight and height. | `${bmi} > 40` | |

## Najbolje prakse

1. Dajte poljima calculate smislena imena — `total_cost` je jasnije od `calc1` i lakše ga je pratiti u izvozima.
2. Razbijte složene formule na više povezanih calculate polja umesto jednog duboko ugnježdenog izraza.
3. Koristite `once()` za vremenske oznake i početne snimke stanja kako biste sprečili promenu vrednosti nakon prvog snimanja.
4. Postavite polja `calculate` pre prvog pitanja koje se na njih referiše — redosled procene prati redosled obrasca.
5. Držite kolonu `label` praznom. Neki alati prikazuju oznaku; ostavljajući je praznom izbegavate zbunjujući izlaz.

## Ograničenja

- Polja Calculate se nikada ne prikazuju direktno anketaru — koristite polje `note` da biste prikazali rezultat.
- Kolona `calculation` je obavezna; red `calculate` bez formule uvek čuva praznu nisku.
- Rezultati se ponovo procenjuju pri svakoj promeni obrasca osim ako nisu umotani u `once()` — veoma složene formule u velikim obrascima mogu uticati na performanse prikazivanja na uređajima slabijih specifikacija.
- Izračunate vrednosti se čuvaju kao niske u podnesku. Koristite `number()`, `int()` ili `boolean()` za promenu tipa (casting) kada prosleđujete rezultat aritmetičkim ili logičkim izrazima.

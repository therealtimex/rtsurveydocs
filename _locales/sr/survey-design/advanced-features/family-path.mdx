`family_path` je konvenciono računsko polje koje čuva putanju do direktorijuma priloženih medija obrasca. Svaki obrazac koji vrši pretragu lokalne baze podataka pomoću `rawquery`, `pulldata` ili `search()` mora uključiti ovo polje — bez njega, putanje do datoteka se ne mogu razrešiti i pretrage tiho vraćaju prazan rezultat.

---

## Računsko polje (calculate)

Dodajte ovaj red blizu vrha vašeg survey lista, nakon bilo kojih meta polja i pre prvog pitanja koje koristi datoteku baze podataka:

| type | name | label | calculation |
|---|---|---|---|
| calculate | `family_path` | | `pulldata('app-api', 'family_path')` |

Polje ne čuva vidljivu vrednost i ne zahteva oznaku (label). To je tihi preduslov za svu konstrukciju putanja koja sledi.

---

## Zašto je potrebno

RTSurvey pakuje medije obrasca — SQLite baze podataka, slike, audio snimke — unutar direktorijuma po obrascu na uređaju. Tačna putanja se razlikuje između platformi (Android, iOS, web) i između uređaja.

U vreme izvršavanja aplikacija automatski popunjava `family_path`. Tipična razrešena vrednost izgleda ovako:

```
resources/familyMedia/Phuong_Person_Test
```

Pošto je putanja specifična za platformu i određuje se u vreme pokretanja, ne može biti fiksno kodirana u obrascu. `pulldata('app-api', 'family_path')` je jedini pouzdan način da se ona dobije.

---

## Kako ga koristiti u putanjama

Kada je `family_path` definisan, izgradite punu putanju datoteke pomoću `concat()`:

```
concat(${family_path}, '/file.db::tableName')
```

Sufiks `::tableName` se uklanja kada aplikacija otvori datoteku; ime tabele se koristi samo unutar vašeg SQL upita.

---

## Gde se family_path koristi

`family_path` je neophodan u argumentu putanje kad god se pozivate na priloženu datoteku:

- **Pretraga lokalne baze podataka** — `db_path` argument funkcije `search-autocomplete-noedit-v2('rawquery', ...)` mora biti izgrađen pomoću `concat(${family_path}, ...)`. Pogledajte [Pretraga lokalne baze podataka](local-database-search) za pune detalje o korišćenju.
- **`pulldata` rawquery** — bilo koji poziv `pulldata('rawquery', ...)` koji čita iz `.db` datoteke koristi isti `concat()` obrazac.
- **`search()` sa lokalnom datotekom** — izgledi (appearances) za dinamičku pretragu koji se učitavaju iz priložene CSV ili DB datoteke takođe se oslanjaju na `family_path` za referencu datoteke.

---

## Postavljanje u obrascu

`family_path` se mora pojaviti **pre prvog polja koje ga referencira**. Preporučena pozicija je odmah nakon meta grupe:

| type | name | label | calculation |
|---|---|---|---|
| begin_group | meta | | |
| deviceid | deviceid | | |
| start | start | | |
| end | end | | |
| end_group | | | |
| calculate | `family_path` | | `pulldata('app-api', 'family_path')` |
| select_one | province | Province | *(rawquery izgled koji referencira `${family_path}`)* |

<Callout type="warning">
Ako `family_path` nedostaje u obrascu, ili je postavljen nakon prvog `rawquery` / `search()` polja koje ga referencira, sve pretrage priloženih datoteka će tiho vratiti prazan rezultat. Ne postoji poruka o grešci — automatsko popunjavanje jednostavno ne prikazuje rezultate.
</Callout>

---

## Više datoteka baze podataka

Jedan obrazac može koristiti nekoliko `.db` datoteka. Svaka putanja se konstruiše nezavisno pomoću `concat()`:

```
concat(${family_path}, '/locations.db::externalData')
concat(${family_path}, '/health_facilities.db::facilities')
concat(${family_path}, '/household_list.db::households')
```

Definišite `family_path` jednom; referencirajte ga u onoliko polja koliko je potrebno.

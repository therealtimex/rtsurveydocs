rtSurvey palaiko turtingą medijos integraciją apklausose, leidžiančią papildyti jūsų klausimynus vaizdais, garso ir vaizdo įrašais. Ši funkcija gali žymiai pagerinti respondentų patirtį ir surinktų duomenų kokybę.

## Palaikomi medijos tipai

rtSurvey palaiko šiuos medijos tipus:
- Vaizdai (jpg, png, gif)
- Garsas (mp3, wav)
- Vaizdo įrašai (mp4, webm)

## Medijos pridėjimas į apklausą

Norėdami įtraukti mediją į savo rtSurvey formą, naudokite šiuos stulpelius XLSForm:

- `image`: vaizdams rodyti
- `audio`: garso failams groti
- `video`: vaizdo failams groti

Pavyzdys:

```
| type | name          | label         | image        | audio       | video       |
|------|---------------|---------------|--------------|-------------|-------------|
| note | media_example | Medijos pavyzdys | example.jpg | sound.mp3  | clip.mp4    |
```

## Medijos failų valdymas

### Žiniatinklio apklausos
Žiniatinklio apklausoms rtSurvey suteikia medijos valdymo sąsają, kurioje galite įkelti ir tvarkyti savo medijos failus. Šie failai tada automatiškai tampa prieinami naudoti jūsų apklausose.

### Mobilioji programa
Naudojant rtSurvey mobiliąją programą:
1. Padėkite savo medijos failus į aplanką `/rtSurvey/forms/[formos-pavadinimas]-media/` savo įrenginyje.
2. Nurodykite tikslų failo pavadinimą savo XLSForm.

## rtSurvey specifinės funkcijos

### Dinaminis medijos įkėlimas
rtSurvey palaiko dinaminį medijos įkėlimą pagal apklausos atsakymus:

```
| type         | name      | label              | image                    |
|--------------|-----------|--------------------|--------------------------| 
| select_one species | animal | Pasirinkite gyvūną | ${animal}.jpg            |
```

### Medija pasirinkimų parinktyse
rtSurvey leidžia naudoti mediją pasirinkimų parinktyse pasirinkimo klausimams:

```
| type                | name    | label           | media::image |
|---------------------|---------|-----------------|--------------|
| select_one_from_file animals | Pasirinkite gyvūną |         |
```

Pasirinkimų lape:
```
| list_name | name  | label  | media::image |
|-----------|-------|--------|--------------|
| animals   | dog   | Šuo    | dog.jpg      |
| animals   | cat   | Katė   | cat.jpg      |
```

### Medijos fiksavimas
rtSurvey išplečia XLSForm medijos fiksavimo galimybėmis:

```
| type  | name        | label               |
|-------|-------------|---------------------|
| image | photo       | Nufotografuokite    |
| audio | voice_note  | Įrašykite balso pastabą |
| video | video_clip  | Įrašykite vaizdo įrašą |
```

## Geriausios medijos naudojimo praktikos

1. **Optimizuokite failų dydžius**: dideli medijos failai gali sulėtinti apklausos įkėlimą ir pateikimą.
2. **Naudokite tinkamus formatus**: laikykitės plačiai palaikomų formatų (jpg vaizdams, mp3 garsui, mp4 vaizdo įrašams).
3. **Pateikite alternatyvas**: visada įtraukite teksto alternatyvas prieinamumui.
4. **Išsamiai testuokite**: užtikrinkite, kad medija tinkamai rodoma visuose tikslinių įrenginiuose.
5. **Apsvarstykite neprisijungusio veikimo naudojimą**: apklausoms, kurios gali būti vykdomos neprisijungus, užtikrinkite, kad visa medija būtų prieinama lokaliai.

## Daugiakalbė medijos palaikymas

rtSurvey palaiko kalbai specifinę mediją. Naudokite `::kalba` priesagą:

```
| type | name  | label     | image::English | image::Spanish |
|------|-------|-----------|----------------|----------------|
| note | intro | Sveiki    | welcome_en.jpg | welcome_es.jpg |
```

## Medija duomenų eksporte

Eksportuojant duomenis iš rtSurvey:
- Žiniatinklio apklausoms į eksportą įtraukiami medijos URL.
- Mobiliosios programos apklausoms įtraukiami failų keliai.

## Mobiliosios programos svarstymai

- Užtikrinkite pakankamą saugyklos vietą įrenginiuose, skirtuose mediją naudojančioms apklausoms.
- rtSurvey mobilioji programa palaiko neprisijungusio veikimo medijos atkūrimą ir fiksavimą.
- Dideli medijos failai gali turėti įtakos programos našumui žemesnės klasės įrenginiuose.

## Žinomos apribojimai

- Kai kurios senesnės naršyklės gali nepalaikyti visų medijos formatų.
- Labai dideli vaizdo failai gali sukelti problemų mažo pralaidumo situacijose.

## Medijos problemų šalinimas

1. **Medija nerodoma**: patikrinkite failų kelius ir pavadinimus dėl tikslumo.
2. **Atkūrimo problemos**: užtikrinkite, kad medijos formatas yra palaikomas tikslinių įrenginių.
3. **Lėtas įkėlimas**: apsvarstykite galimybę optimizuoti failų dydžius arba iš anksto įkelti mediją.

## Pažangios medijos funkcijos

### Geomarks
rtSurvey gali automatiškai pažymėti mediją geografinėmis koordinatėmis apklausų metu:

```
| type  | name        | label        | appearance |
|-------|-------------|--------------|------------|
| image | photo       | Nufotografuokite | geotag |
```

### Medijos anotacijos
Leiskite respondentams anotuoti vaizdus:

```
| type  | name        | label        | appearance |
|-------|-------------|--------------|------------|
| image | photo       | Anotuokite vaizdą | annotate |
```

Efektyviai naudodami mediją savo rtSurvey formose, galite kurti patrauklesnes, informatyvesnes ir tikslesnes apklausas. Nepamirškite subalansuoti medijos įtraukimo privalumų su našumo svarstymais, ypač apklausoms, vykdomoms vietovėse su ribotos interneto prieigos arba žemesnės klasės įrenginiuose.

Klausimo tipas `calculate` tyliai fone vykdo formulę. Jis išsaugo rezultatą nurodytame lauke, į kurį gali nuorodas daryti kiti klausimai, tačiau apklausėjui nerodoma jokia įvestis ar etiketė. Naudokite jį vertėms išvesti, eilutėms sujungti, sąlyginei logikai vykdyti arba duomenims, kurių prireiks vėliau formoje, ieškoti.

---

## Bazinė sintaksė

| type | name | label | calculation |
|------|------|-------|-------------|
| calculate | total | | `${price} * ${quantity}` |

- **type**: Visada `calculate`.
- **name**: Unikalus lauko pavadinimas. Kiti klausimai į jį nurodo naudodami `${name}`.
- **label**: Palikite tuščią — calculate laukai apklausėjui niekada nerodomi.
- **calculation**: Formulė, kurią reikia įvertinti. Palaiko visas [XLSForm funkcijas](../operators-and-functions/functions) ir nuorodas į laukus.

---

## Dažni modeliai

### Aritmetika

| type | name | label | calculation |
|------|------|-------|-------------|
| integer | price | Unit price | |
| integer | quantity | Quantity | |
| calculate | total | | `${price} * ${quantity}` |
| note | total_note | Total: `${total}` | |

### Eilučių sujungimas (String concatenation)

| type | name | label | calculation |
|------|------|-------|-------------|
| text | first_name | First name | |
| text | last_name | Last name | |
| calculate | full_name | | `concat(${first_name}, ' ', ${last_name})` |

### Sąlyginė vertė

| type | name | label | calculation |
|------|------|-------|-------------|
| integer | score | Score (0–100) | |
| calculate | grade | | `if(${score} >= 90, 'A', if(${score} >= 75, 'B', if(${score} >= 60, 'C', 'F')))` |

### Amžius pagal gimimo datą

| type | name | label | calculation |
|------|------|-------|-------------|
| date | dob | Date of birth | |
| calculate | age_years | | `int((today() - ${dob}) div 365.25)` |

## `once()` naudojimas vertės užfiksavimui

Pagal numatytuosius nustatymus `calculate` yra peržiūrimas iš naujo kiekvieną kartą, kai pasikeičia bet kuris nurodytas laukas. Apgaubkite formulę `once()`, kad ji būtų įvertinta tik per pirmąjį įkėlimą, o rezultatas būtų užfiksuotas:

| type | name | label | calculation |
|------|------|-------|-------------|
| calculate | interview_start | | `once(now())` |

Naudokite `once()` laiko žymoms, pradinėms vertėms arba bet kokiam atvejui, kai perskaičiavimas pasikeitus yra nepageidaujamas.

## Duomenų traukimas iš išorinių šaltinių

### Iš CSV failo

```
pulldata('staff.csv', 'department', 'name', ${staff_id})
```

Visą informaciją rasite [pulldata()](../operators-and-functions/pulldata).

### Iš pridėtos SQLite duomenų bazės

```
pulldata('rawquery',
  concat(${family_path}, '/locations.db::provinces'),
  'SELECT name FROM provinces WHERE id = ?',
  ${province_id})
```

Išsamią informaciją apie kelio kūrimą rasite [Vietinė duomenų bazės paieška](../advanced-features/local-database-search).

### Iš programėlės konteksto

```
pulldata('app-api', 'user.username')
pulldata('app-api', 'family_path')
```

Visus galimus raktus rasite [App API](../app-api).

## calculate naudojimas relevant ir constraint laukuose

Kiti laukai gali nurodyti į `calculate` rezultatą lygiai taip pat, kaip į bet kurį kitą lauką:

| type | name | label | relevant | constraint |
|------|------|-------|----------|------------|
| calculate | bmi | | | `${weight} div (${height} * ${height}) * 10000` |
| note | bmi_warning | BMI is very high — please verify weight and height. | `${bmi} > 40` | |

## Geriausia praktika

1. Suteikite calculate laukams prasmingus pavadinimus — `total_cost` yra aiškiau nei `calc1` ir lengviau atsekti eksportuojant duomenis.
2. Skaidykite sudėtingas formules į kelis sujungtus calculate laukus, užuot naudoję vieną giliai įdėtinę išraišką.
3. Naudokite `once()` laiko žymoms ir pradinėms nuotraukoms, kad vertės nepasikeistų po pirmojo užfiksavimo.
4. Padėkite `calculate` laukus prieš pirmąjį klausimą, kuris į juos nurodo — vertinimo tvarka atitinka formos tvarką.
5. Palikite `label` stulpelį tuščią. Kai kurie įrankiai rodo etiketę; palikus ją tuščią, išvengiama painios išvesties.

## Apribojimai

- Calculate laukai niekada nerodomi tiesiogiai apklausėjui — rezultatui parodyti naudokite `note` lauką.
- Stulpelis `calculation` yra privalomas; `calculate` eilutė be formulės visada išsaugo tuščią eilutę.
- Rezultatai perskaičiuojami kaskart pasikeitus formai, nebent jie yra apgaubti `once()` — labai sudėtingos formulės didelėse formose gali turėti įtakos atvaizdavimo našumui žemesnės klasės įrenginiuose.
- Apskaičiuotos vertės pateiktoje formoje saugomos kaip eilutės. Naudokite `number()`, `int()` arba `boolean()`, kad pakeistumėte tipą, kai perduodate rezultatą aritmetinėms ar loginėms išraiškoms.

import { Callout } from 'nextra/components'

`family_path` yra sutartinis calculate laukas, kuriame saugomas kelias į formos pridėtą medijos katalogą. Kiekviena forma, atliekanti vietines duomenų bazių paieškas naudojant `rawquery`, `pulldata` arba `search()`, privalo įtraukti šį lauką – be jo failų keliai negali būti išspręsti, o paieškos tyliai grąžina tuščius rezultatus.

---

## calculate laukas

Pridėkite šią eilutę prie survey lapo viršaus, po bet kokių meta laukų ir prieš pirmąjį klausimą, kuriame naudojamas duomenų bazės failas:

| type | name | label | calculation |
|---|---|---|---|
| calculate | `family_path` | | `pulldata('app-api', 'family_path')` |

Lauke nesaugoma jokia matoma vertė ir jam nereikia label. Tai yra tyli išankstinė sąlyga visoms vėliau sudaromoms kelio konstrukcijoms.

---

## Kodėl jo reikia

RTSurvey formos mediją – „SQLite“ duomenų bazes, vaizdus, garso įrašus – supakuoja į kiekvienos formos katalogą įrenginyje. Tikslus kelias skiriasi priklausomai nuo platformos („Android“, „iOS“, žiniatinklis) ir įrenginių.

Vykdymo metu programėlė automatiškai užpildo `family_path`. Įprasta išspręsta vertė atrodo taip:

```
resources/familyMedia/Phuong_Person_Test
```

Kadangi kelias priklauso nuo platformos ir nustatomas paleidimo metu, jo negalima įrašyti į formą kaip pastovaus kodo. `pulldata('app-api', 'family_path')` yra vienintelis patikimas būdas jį gauti.

---

## Kaip jį naudoti keliuose

Apibrėžę `family_path`, sukurkite visą failo kelią naudodami `concat()`:

```
concat(${family_path}, '/file.db::tableName')
```

Priesaga `::tableName` pašalinama, kai programėlė atidaro failą; lentelės pavadinimas naudojamas tik jūsų SQL užklausoje.

---

## Kur naudojamas family_path

`family_path` reikalingas kelio argumente kaskart, kai nurodote pridėtą failą:

- **Vietinė duomenų bazės paieška** – `search-autocomplete-noedit-v2('rawquery', ...)` argumentas `db_path` turi būti sudarytas naudojant `concat(${family_path}, ...)`. Išsamios informacijos apie naudojimą ieškokite skyriuje [Vietinė duomenų bazės paieška](local-database-search).
- **`pulldata` rawquery** – bet koks `pulldata('rawquery', ...)` iškvietimas, nuskaitantis duomenis iš `.db` failo, naudoja tą patį `concat()` šabloną.
- **`search()` su vietiniu failu** – dinaminės paieškos išvaizdos (appearances), kurios įkeliamos iš pridėto CSV arba DB failo, taip pat priklauso nuo `family_path` nurodant failą.

## Vieta formoje

`family_path` turi atsirasti **prieš pirmąjį lauką, kuris jį nurodo**. Rekomenduojama pozicija yra iškart po meta grupės:

| type | name | label | calculation |
|---|---|---|---|
| begin_group | meta | | |
| deviceid | deviceid | | |
| start | start | | |
| end | end | | |
| end_group | | | |
| calculate | `family_path` | | `pulldata('app-api', 'family_path')` |
| select_one | province | Provincija | *(rawquery appearance, nurodanti `${family_path}`)* |

<Callout type="warning">
Jei formoje trūksta `family_path` arba jis yra po pirmojo jį nurodančio `rawquery` / `search()` lauko, visos paieškos pridėtuose failuose tyliai grąžins tuščius rezultatus. Klaidos pranešimo nėra – automatinis užbaigimas tiesiog nerodo jokių rezultatų.
</Callout>

## Keli duomenų bazių failai

Viena forma gali naudoti kelis `.db` failus. Kiekvienas kelias sudaromas atskirai naudojant `concat()`:

```
concat(${family_path}, '/locations.db::externalData')
concat(${family_path}, '/health_facilities.db::facilities')
concat(${family_path}, '/household_list.db::households')
```

Apibrėžkite `family_path` vieną kartą; nurodykite jį tiek laukų, kiek reikia.

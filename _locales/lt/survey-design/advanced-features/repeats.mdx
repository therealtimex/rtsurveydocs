Šiame puslapyje aprašomi pažangūs darbo su kartojimo grupėmis (repeat groups) šablonai „rtSurvey“ sistemoje. Pagrindinę informaciją apie kartojimo grupės nustatymą rasite puslapyje [Grupavimas ir kartojimai](../repeats).

---

## Dinaminis kartojimų skaičius

Pagal numatytuosius nustatymus apklausos vykdytojas nusprendžia, kiek kartų kartoti. Galite užfiksuoti kartojimų skaičių naudodami `repeat_count`:

| type | name | label | repeat_count |
|------|------|-------|--------------|
| begin_repeat | household_members | Namų ūkio narys | `${num_members}` |
| text | member_name | Nario vardas | |
| integer | member_age | Amžius | |
| end_repeat | | | |

Kartojimas vykdomas tiksliai `${num_members}` kartų, kur `num_members` reikšmė buvo surinkta anksčiau formoje. Apklausos vykdytojas negali pridėti ar pašalinti egzempliorių.

---

## Indeksuota prieiga: `indexed-repeat()`

Pasiekite konkretaus kartojimo egzemplioriaus lauko reikšmę iš **išorės** naudodami `indexed-repeat(repeatedField, repeatGroup, index)`:

| type | name | label | calculation |
|------|------|-------|-------------|
| calculate | first_name | | `indexed-repeat(${member_name}, ${household_members}, 1)` |
| calculate | second_name | | `indexed-repeat(${member_name}, ${household_members}, 2)` |

Tai naudinga kuriant suvestinės laukus arba nurodant „pagrindinio“ nario duomenis po kartojimo ciklo.

---

## Dabartinio egzemplioriaus pozicija: `index()`

Kartojimo grupės viduje `index()` grąžina dabartinio egzemplioriaus poziciją (nuo 1). Naudokite tai kiekvienam kartojimui paženklinti arba unikaliems identifikatoriams sukurti:

| type | name | label |
|------|------|-------|
| begin_repeat | plots | Sklypas |
| note | plot_label | Sklypo numeris `${index()}` |
| text | plot_id | Sklypo ID |
| end_repeat | | |

---

## Nuorodos į tos pačios iteracijos laukus

Kartojimo viduje naudokite `${fieldname}`, norėdami nurodyti kitą lauką **tame pačiame kartojimo egzemplioriuje**. Tam pačiam ciklui `indexed-repeat()` naudoti nereikia:

| type | name | label | relevant |
|------|------|-------|----------|
| begin_repeat | members | Narys | |
| text | member_name | Vardas | |
| integer | member_age | Amžius | |
| text | school_name | Mokyklos pavadinimas | `${member_age} < 18` |
| end_repeat | | | |

---

## Nuorodos į tėvinius laukus iš kartojimo vidaus

Laukus, esančius už kartojimo grupės ribų (virš jos), galima nurodyti įprastai naudojant `${fieldname}`:

| type | name | label |
|------|------|-------|
| text | village | Kaimo pavadinimas |
| begin_repeat | plots | Žemės ūkio sklypas |
| note | plot_context | Sklypai kaime: `${village}` |
| end_repeat | | |

---

## Kartojimo duomenų apibendrinimas

Norėdami apibendrinti duomenis, naudokite kartojimo agregavimo funkcijas **už** kartojimo grupės ribų:

| Funkcija | Pavyzdys | Aprašymas |
|----------|---------|-------------|
| `count(group)` | `count(${household_members})` | Egzempliorių skaičius |
| `sum(field)` | `sum(${loan_amount})` | Skaitinio lauko suma |
| `min(field)` | `min(${member_age})` | Minimali reikšmė |
| `max(field)` | `max(${member_age})` | Maksimali reikšmė |
| `join(sep, field)` | `join(', ', ${member_name})` | Kableliais atskirtas sąrašas |
| `count-if(group, expr)` | `count-if(${members}, ${member_age} < 18)` | Sąlyginis skaičiavimas |
| `sum-if(field, expr)` | `sum-if(${loan_amount}, ${loan_amount} > 500)` | Sąlyginė suma |
| `join-if(sep, field, expr)` | `join-if(', ', ${name}, ${age} >= 18)` | Sąlyginis sujungimas |

### Pavyzdys: Namų ūkio suvestinė

| type | name | label | calculation |
|------|------|-------|-------------|
| integer | num_members | Kiek iš viso narių? | |
| begin_repeat | members | Narys | `${num_members}` |
| text | member_name | Vardas | |
| integer | member_age | Amžius | |
| end_repeat | | | |
| calculate | total_members | | `count(${members})` |
| calculate | children_count | | `count-if(${members}, ${member_age} < 18)` |
| calculate | adult_names | | `join-if(', ', ${member_name}, ${member_age} >= 18)` |
| note | summary | `${total_members}` nariai; `${children_count}` jaunesni nei 18 m. Suaugusieji: `${adult_names}` | |

## Įterptieji kartojimai

Kartojimo grupėje gali būti kita kartojimo grupė. Naudokite tai atsargiai – įterptieji kartojimai didina sudėtingumą ir gali klaidinti apklausos vykdytojus.

| type | name | label |
|------|------|-------|
| begin_repeat | households | Namų ūkis |
| text | hh_id | Namų ūkio ID |
| begin_repeat | hh_members | Narys |
| text | member_name | Nario vardas |
| end_repeat | | |
| end_repeat | | |

Norėdami iš vidinio kartojimo nurodyti lauką išoriniame kartojime, naudokite `${fieldname}` – bus nurodomas artimiausias atitinkamas protėvis:

Kartojimo `hh_members` viduje `${hh_id}` grąžina **dabartinio** namų ūkio ID, o ne visų namų ūkių ID.

---

## Rangas kartojimo grupėse: `rank-index()`

Jei kartojimo viduje yra laukas `rank`, naudokite `rank-index(instanceNumber, repeatedField)` iš išorės, kad gautumėte konkretaus egzemplioriaus eilės rangą:

| type | name | label | calculation |
|------|------|-------|-------------|
| calculate | top_scorer | | `rank-index(1, ${score})` |

`rank-index(1, ${score})` grąžina egzemplioriaus indeksą su didžiausiu balu.

## `1screen` išvaizda `begin_repeat` eilutėje

Pridėjus `1screen` prie `begin_repeat` eilutės stulpelio `appearance`, visi kiekvienos iteracijos klausimai rodomi kartu viename ekrane, o ne po vieną klausimą kiekviename ekrane.

| type | name | label | appearance |
|------|------|-------|------------|
| begin_repeat | household_members | Namų ūkio narys | `1screen` |
| text | member_name | Nario vardas | |
| integer | member_age | Amžius | |
| end_repeat | | | |

Kai nustatyta `1screen` ir grupės viduje nėra nei `repeat_count`, nei `add_repeat` lauko, „rtSurvey“ ekrano apačioje automatiškai parodo apvalų **+** mygtuką, kad apklausos vykdytojai galėtų pridėti naujų egzempliorių be papildomos konfigūracijos.

| Išvaizda | Vienas ekranas egzemplioriui | Pridedamas numatytasis + mygtukas |
|------------|-------------------------|------------------------|
| `1screen` | Taip | Taip (kai nėra vaikinio `add_repeat` lauko) |
| `field-list` | Taip | Ne |

Naudokite `field-list`, kai norite grupuoto išdėstymo be automatinio pridėjimo mygtuko. Naudokite `1screen`, kai norite ir grupuoto išdėstymo, ir integruoto būdo pridėti egzempliorius.

---

## `add_repeat` pasirinktinis pridėjimo mygtukas

Laukas `note` (arba `text`), esantis **kartojimo grupės viduje** su nustatyta išvaizda `appearance: add_repeat`, rodomas kaip viso pločio mygtukas „Pridėti“. Mygtuko etiketė paimama iš lauko stulpelio `label`. Kai yra laukas `add_repeat`, numatytasis apvalus + mygtukas (iš `1screen`) yra paslepiamas.

Lauką `add_repeat` įdėkite kaip paskutinį lauką kartojimo grupės viduje:

| type | name | label | appearance |
|------|------|-------|------------|
| begin_repeat | members | Narys | `1screen` |
| text | member_name | Nario vardas | |
| integer | member_age | Amžius | |
| note | btn_add | + Pridėti narį | `add_repeat` |
| end_repeat | | | |

### Spalvų pritaikymas

Į išvaizdos reikšmę įrašykite spalvos kodą, kad pakeistumėte mygtuko stilių:

| Išvaizdos reikšmė | Rezultatas |
|------------------|--------|
| `add_repeat <#04B404/>` | Žalias fonas, numatytoji teksto spalva |
| `add_repeat 04B404-ffffff` | Žalias fonas, baltas tekstas |

Pirmoji spalva yra fonas, o antroji (po brūkšnio) – teksto spalva. Nenaudokite `#` ženklo, kai naudojate formatą su brūkšniu.

### Ikonos variantas

Naudokite `add_repeat icon` (su tarpu), kad būtų rodomas kompaktiškas apvalus ikonos mygtukas vietoj viso pločio mygtuko:

| type | name | label | appearance |
|------|------|-------|------------|
| note | btn_add | + Pridėti | `add_repeat icon` |

---

## Ištrynimo mygtukai: `delete-repeat-current` ir `delete-repeat-last`

Laukas `note` kartojimo grupės viduje su nustatyta išvaizda `appearance: delete-repeat-current` arba `appearance: delete-repeat-last` rodomas kaip padalintas ištrynimo mygtukas.

| Išvaizda | Veiksmas |
|------------|--------|
| `delete-repeat-current` | Ištrina dabartinį (aktyvų) egzempliorių |
| `delete-repeat-last` | Ištrina paskutinį egzempliorių kartojimo cikle |

Numatytasis mygtukas yra padalintas: kairėje pusėje šiukšliadėžės piktograma, o dešinėje – lauko etiketės tekstas, užimantis visą ekrano plotį.

### Ikonos variantas

Pridėkite `-icon` galūnę, kad gautumėte kompaktišką apvalų šiukšliadėžės piktogramos mygtuką:

| Išvaizda | Rezultatas |
|------------|--------|
| `delete-repeat-current-icon` | Apvali šiukšliadėžės piktograma, ištrina dabartinį egzempliorių |
| `delete-repeat-last-icon` | Apvali šiukšliadėžės piktograma, ištrina paskutinį egzempliorių |

### Spalvų pritaikymas

Spalvų formatas yra toks pat kaip ir `add_repeat`: naudokite `<#RRGGBB/>` arba `RRGGBB-RRGGBB` (fonas-tekstas).

### Pilno šablono pavyzdys

Šiame kartojime naudojama `1screen` išvaizda, viršuje – apvalus dabartinio egzemplioriaus ištrynimo mygtukas, o apačioje – viso pločio pridėjimo mygtukas:

| type | name | label | appearance |
|------|------|-------|------------|
| begin_repeat | members | Narys | `1screen` |
| note | btn_del | Pašalinti | `delete-repeat-current-icon` |
| text | member_name | Nario vardas | |
| integer | member_age | Amžius | |
| note | btn_add | + Pridėti narį | `add_repeat` |
| end_repeat | | | |

## Geriausia praktika

1. Visada naudokite `repeat_count`, kai kartojimų skaičius žinomas iš anksto – tai apsaugo nuo atsitiktinio egzempliorių pridėjimo ar pašalinimo.
2. Kartojimo grupės turėtų būti tikslingos – kartojimą su daugiau nei 20 klausimų vienoje iteracijoje sudėtinga naudoti.
3. Kartojimo grupes vadinkite aiškiai (pvz., `household_members`, o ne `repeat1`) – šis pavadinimas matomas funkcijų kvietimuose ir eksportuojamuose duomenyse.
4. Išbandykite formą su didžiausiu tikėtinu egzempliorių skaičiumi, kad patikrintumėte veikimo greitį.
5. Naudokite `1screen` parametruose `begin_repeat`, kad visi iteracijos klausimai būtų rodomi viename ekrane, ir pridėkite `add_repeat` pastabos lauką grupės viduje, kad apklausos vykdytojai turėtų aiškiai pažymėtą mygtuką „Pridėti“.

---

## Apribojimai

- Funkcijai `indexed-repeat()` reikalingas galiojantis indeksas (nuo 1 iki egzempliorių skaičiaus) – nurodžius indeksą už rėžių ribų, grąžinama tuščia reikšmė.
- Nerekomenduojama naudoti daugiau nei 2 lygių įterptųjų kartojimų, nes kai kuriuose įrenginiuose gali kilti rodymo problemų.
- Agregavimo funkcijos (`sum`, `count` ir kt.) veikia visai kartojimo grupei – negalite agreguoti tik dalies egzempliorių nenaudodami `*-if` variantų.

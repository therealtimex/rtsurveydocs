Paleiskite rtCloud savo infrastruktūroje naudodami „Docker Compose". Savarankiškas prieglobos valdymas suteikia visišką jūsų duomenų, tinklo ir diegimo aplinkos nuosavybę – tai idealu organizacijoms, turinčioms duomenų buvimo vietos reikalavimus, izoliuotus tinklus ar pasirinktinės infrastruktūros poreikius.

## Kas yra rtCloud savarankiškas prieglobos valdymas?

rtCloud savarankiškas prieglobos valdymas yra oficialus „Docker" vaizdas, kuris supakuoja visą rtCloud platformą į nešiojamą konteinerių rinkinį, kurį galite paleisti bet kuriame „Linux" serveryje. Rinkinyje yra:

| Paslauga | Aprašymas |
|---------|-------------|
| **rtCloud programa** | „Apache 2.4" + PHP 7.4 žiniatinklio programa su integruota foninės eilės paslauga (Beanstalkd), analizės serveriu (Shiny) ir suplanuotomis užduotimis |
| **MySQL 8.0** | Reliacinė duomenų bazė visiems programos ir apklausos duomenims |
| **Keycloak** *(neprivaloma)* | Integruotas vieningo prisijungimo serveris įmonės tapatybės valdymui |

## Kada rinktis savarankišką prieglobos valdymą

Savarankiškas prieglobos valdymas yra tinkamas pasirinkimas, kai:

- Reikalingas **duomenų suverenumas** – visi duomenys lieka jūsų infrastruktūroje
- Dirbate **izoliuotame arba ribotame tinkle** be išorinės debesijos prieigos
- Turite **atitikties reikalavimų** (BDAR, HIPAA, valstybinės duomenų politikos), įpareigojančių saugoti duomenis vietoje
- Reikia integruoti su **vidiniu tapatybės teikėju** (Active Directory, LDAP, SAML)
- Norite **pritaikyti išteklius** – procesoriaus, RAM ir saugyklos paskirstymą savo sąlygomis

## Architektūros apžvalga

Diegimas vykdomas kaip „Docker" konteinerių rinkinys, sujungtas vidiniu tinklu:

```
┌────────────────────────────────────────┐
│            rtcloud-app                 │
│  Apache 2.4 (port 80)                  │
│  PHP 7.4 application                   │
│  Beanstalkd queue (internal)           │
│  Shiny Server (port 3838)              │
│  Cron scheduler                        │
└─────────────────┬──────────────────────┘
                  │ rtcloud-net (bridge)
┌─────────────────▼──────────────────────┐
│            rtcloud-mysql               │
│  MySQL 8.0 (port 3306, internal only)  │
└────────────────────────────────────────┘
```

Kai SSO įjungtas, kartu veikia trečias konteineris:

```
┌─────────────────────────────────────────┐
│            rtcloud-keycloak             │
│  Keycloak (port 8080, internal only)    │
│  Admin UI (port 9000, internal only)    │
└─────────────────────────────────────────┘
```

Visi konteineriai komunikuoja per izoliuotą „Docker" tilto tinklą. Tik žiniatinklio programos prievadas ir (neprivaloma) Shiny analizės prievadas yra atidaryti į pagrindinį kompiuterį.

import { Callout, Steps } from 'nextra/components'

Naudokite šį vadovą, jei norite paleisti rtSurvey savo serveryje (VPS, bare metal arba vietiniame kompiuteryje) naudodami viešą Docker vaizdą `rtawebteam/rtcloud:survey-public`.

**Docker Hub prisijungimas nereikalingas** — vaizdas yra viešas.

Konteineris sujungia viską viename vaizde:
- Apache + PHP (programos serveris)
- Shiny Server (analizės prietaisų skydeliai, prievadas 3838)
- Beanstalkd (foninių užduočių eilė)

---

## Reikalavimai

### Serveris

| Išteklius | Minimalus | Rekomenduojamas |
|----------|---------|-------------|
| RAM | 4 GB | 8 GB |
| Diskas | 50 GB | 100 GB SSD |
| CPU | 2 vCPU | 4 vCPU |
| OS | Ubuntu 22.04 LTS | Ubuntu 22.04 LTS |

### Programinė įranga

- **Docker Engine 24.0+** — [diegimo vadovas](https://docs.docker.com/engine/install/ubuntu/)
- **Docker Compose v2.0+** — įtraukta į Docker Desktop; Linux: `apt install docker-compose-plugin`

## Sąranka

<Steps>

### Sukurkite darbo katalogą

```bash
mkdir -p /opt/rtsurvey && cd /opt/rtsurvey
```

### Sukurkite `docker-compose.yml`

```yaml
services:
  mysql:
    image: mysql:8.0
    container_name: rtsurvey-mysql
    restart: unless-stopped
    command: >
      --default-authentication-plugin=mysql_native_password
      --character-set-server=utf8
      --collation-server=utf8_unicode_ci
      --sql-mode=NO_ENGINE_SUBSTITUTION
    environment:
      MYSQL_ROOT_PASSWORD: ${MYSQL_ROOT_PASSWORD}
      MYSQL_DATABASE: ${MYSQL_DATABASE:-smartsurvey}
      MYSQL_USER: ${MYSQL_USER:-smartsurvey}
      MYSQL_PASSWORD: ${MYSQL_PASSWORD}
      MYSQL_ROOT_HOST: '%'
    volumes:
      - mysql_data:/var/lib/mysql
    networks:
      - rtsurvey-net
    healthcheck:
      test: ["CMD-SHELL", "mysqladmin ping -h localhost -u root -p$$MYSQL_ROOT_PASSWORD"]
      interval: 10s
      timeout: 5s
      retries: 5
      start_period: 30s

  rtsurvey:
    image: rtawebteam/rtcloud:survey-public
    container_name: rtsurvey-app
    restart: unless-stopped
    entrypoint: ["/bin/entrypoint-production.sh"]
    depends_on:
      mysql:
        condition: service_healthy
    ports:
      - "${APP_PORT:-8080}:80"
      - "${SHINY_PORT:-3838}:3838"
    env_file:
      - .env
    volumes:
      - app_uploads:/var/www/html/smartsurvey/uploads
      - app_audios:/var/www/html/smartsurvey/audios
      - app_downloads:/var/www/html/smartsurvey/downloads
      - app_gallery:/var/www/html/smartsurvey/gallery
      - app_tmp:/var/www/html/smartsurvey/tmp
      - app_cache:/var/www/html/smartsurvey/cache
      - app_runtime:/var/www/html/smartsurvey/protected/runtime
      - app_assets:/var/www/html/smartsurvey/assets
      - app_aggregate:/var/www/html/smartsurvey/aggregate
    networks:
      - rtsurvey-net
    healthcheck:
      test: ["CMD", "curl", "-f", "http://localhost/health"]
      interval: 30s
      timeout: 10s
      retries: 3
      start_period: 90s

  # Optional: Embedded Keycloak SSO
  # Start with: docker compose --profile embed-keycloak up -d
  keycloak:
    image: quay.io/keycloak/keycloak:latest
    container_name: rtsurvey-keycloak
    restart: unless-stopped
    profiles:
      - embed-keycloak
    command: start --import-realm
    environment:
      KEYCLOAK_ADMIN: ${KEYCLOAK_ADMIN_USER:-admin}
      KEYCLOAK_ADMIN_PASSWORD: ${KEYCLOAK_ADMIN_PASSWORD}
      KC_HTTP_ENABLED: "true"
      KC_HTTP_RELATIVE_PATH: /auth
      KC_PROXY_HEADERS: xforwarded
      KC_HOSTNAME: ${KC_HOSTNAME}
      KC_HOSTNAME_STRICT: "false"
      KC_DB: mysql
      KC_DB_URL_DATABASE: ${KEYCLOAK_DB:-keycloak}
      KC_DB_URL_HOST: mysql
      KC_DB_USERNAME: ${KEYCLOAK_DB_USER:-keycloak}
      KC_DB_PASSWORD: ${KEYCLOAK_DB_PASSWORD}
    volumes:
      - ./keycloak-import:/opt/keycloak/data/import
    ports:
      - "${KEYCLOAK_PORT:-8091}:8080"
    depends_on:
      mysql:
        condition: service_healthy
    networks:
      - rtsurvey-net
    healthcheck:
      test: ["CMD-SHELL", "curl -f http://localhost:9000/health/ready || exit 1"]
      interval: 30s
      timeout: 10s
      retries: 10
      start_period: 120s

volumes:
  mysql_data:
  app_uploads:
  app_audios:
  app_downloads:
  app_gallery:
  app_tmp:
  app_cache:
  app_runtime:
  app_assets:
  app_aggregate:

networks:
  rtsurvey-net:
    driver: bridge
```

### Sukurkite `.env`

```bash
# Project
PROJECT_ID=mysurvey
PROJECT_TYPE=rtsurvey
PROJECT_URL=your-server-ip-or-domain
HTTP_PROTOCOL=http
TZ=UTC

# Database
MYSQL_HOST=mysql
MYSQL_DATABASE=smartsurvey
MYSQL_USER=smartsurvey
MYSQL_ROOT_PASSWORD=change-this-root-password
MYSQL_PASSWORD=change-this-app-password

# Admin (set before first startup — cannot change via env after DB is created)
ADMIN_PASSWORD=change-this-admin-password

# Runtime
RUN_ENV=prod
RUN_MODE=admin
GII_ENABLED=false
CSRF_VALIDATION_ENABLED=true

# Ports (optional — defaults shown)
APP_PORT=8080
SHINY_PORT=3838
```

<Callout type="warning">
Prieš pradedant pakeiskite `MYSQL_ROOT_PASSWORD` ir `MYSQL_PASSWORD`. Gamyboje naudokite stiprias atsitiktines eilutes (32+ simboliai).
</Callout>

### Paleiskite paketą

```bash
docker compose up -d
```

Pirmasis paleidimas užtrunka apie 60–90 sekundžių — MySQL inicializuoja duomenų bazę pirmą kartą.

### Patikrinkite

```bash
# Check all containers are running
docker compose ps

# Check application health
curl http://localhost:8080/health
```

</Steps>

## Pirmasis prisijungimas

Kai sveikatos patikra praeis, atidarykite naršyklę:

```
http://your-server:8080/cpms/cpmsSite/login
```

| Laukas | Reikšmė |
|-------|-------|
| Vartotojo vardas | `admin` |
| Slaptažodis | `ADMIN_PASSWORD` reikšmė jūsų `.env` (numatytasis `admin`) |

<Callout type="warning">
Prieš pirmąjį paleidimą nustatykite `ADMIN_PASSWORD` savo `.env`. Įėjimo taškas nustato jį pirmojo paleidimo metu — pakeitus po duomenų bazės inicializacijos tai neturi jokio poveikio.
</Callout>

## Aplinkos kintamieji

### Reikalingi programos konteineriui

Jei kurių nors trūksta, įėjimo taškas atsisakys paleisti:

| Kintamasis | Aprašymas |
|----------|-------------|
| `PROJECT_ID` | Unikalus šio egzemplioriaus identifikatorius (raidžių ir skaitmenų, be tarpų) |
| `PROJECT_URL` | Domenas arba IP, iš kurio pasiekiama programa (be `http://` priešdėlio) |
| `MYSQL_HOST` | MySQL pagrindinio kompiuterio pavadinimas — naudokite Docker paslaugos pavadinimą (pvz., `mysql`) |
| `MYSQL_DATABASE` | Duomenų bazės pavadinimas |
| `MYSQL_PASSWORD` | Duomenų bazės vartotojo slaptažodis |

### Reikalingi MySQL konteineriui

| Kintamasis | Aprašymas |
|----------|-------------|
| `MYSQL_ROOT_PASSWORD` | MySQL šakninis slaptažodis (naudojamas `mysql` konteinerio, ne programos) |

### Rekomenduojami

| Kintamasis | Numatytasis | Aprašymas |
|----------|---------|-------------|
| `MYSQL_USER` | `smartsurvey` | Duomenų bazės vartotojo vardas |
| `ADMIN_PASSWORD` | `admin` | Pradinis administratoriaus slaptažodis — **nustatykite prieš pirmąjį paleidimą**, po DB sukūrimo negalima keisti per env |
| `HTTP_PROTOCOL` | `https` | Nustatykite `http` jei nenaudojate SSL |
| `PROJECT_PORT` | `80` | Išorinis prievadas, prie kurio jungiasi vartotojai (ne vidinis Docker prievadas) |
| `PROJECT_TYPE` | `rtwork` | Platformos tipas — apklausų platformai naudokite `rtsurvey` |
| `TZ` | `UTC` | Laiko juosta (pvz., `Asia/Bangkok`, `America/New_York`) |

### Vykdymo laikas

| Kintamasis | Numatytasis | Aprašymas |
|----------|---------|-------------|
| `RUN_ENV` | `prod` | Aplinkos režimas (`prod` arba `dev`) |
| `RUN_MODE` | `admin` | Paslaugos vaidmuo — vieno serverio sąrankai naudokite `admin` |
| `GII_ENABLED` | `false` | Gamyboje palaikykite `false` (Yii kodo generatorius) |
| `CSRF_VALIDATION_ENABLED` | `true` | CSRF apsauga — palaikykite `true` |

### Licencija

| Kintamasis | Numatytasis | Aprašymas |
|----------|---------|-------------|
| `REQUIRE_LICENSE` | `false` | Nustatykite `true` licencijos tikrinimui užtikrinti |
| `RTCLOUD_LICENSE_KEY` | — | Jūsų licencijos raktas — reikalingas kai `REQUIRE_LICENSE=true` |

## Duomenų išlikimas

Visi vartotojo duomenys saugomi pavadintose Docker apimtyse. Jie išlieka po konteinerio paleidimų iš naujo ir vaizdo atnaujinimų.

| Apimtis | Turinys |
|--------|----------|
| `mysql_data` | Duomenų bazė (apklausos, vartotojai, atsakymai) |
| `app_uploads` | Failų įkėlimai iš apklausų |
| `app_gallery` | Medijos biblioteka |
| `app_downloads` | Sugeneruoti eksporto failai |
| `app_audios` | Garso įrašai |
| `app_runtime` | PHP seanso ir talpyklos failai |
| `app_aggregate` | Suvestiniai analizės duomenys |

## Įprastos operacijos

### Peržiūrėti žurnalus

```bash
docker compose logs -f rtsurvey
docker compose logs -f mysql
```

### Iš naujo paleisti programą

```bash
docker compose restart rtsurvey
```

### Prieiga prie apvalkalo

```bash
docker compose exec rtsurvey bash
```

### Rankiniu būdu paleisti duomenų bazės migracijas

```bash
docker compose exec rtsurvey php /var/www/html/smartsurvey/protected/yiic migrate
```

## Atnaujinimai

Vaizdas pažymėtas `survey-public`. Norėdami atnaujinti iki naujausios versijos:

```bash
docker compose pull
docker compose up -d
```

Duomenų bazės migracijos paleidžiamos automatiškai paleidžiant per gamybos įėjimo tašką.

## Atsarginis kopijavimas ir atkūrimas

### Atsarginė duomenų bazės kopija

```bash
docker compose exec mysql \
  mysqldump -u root -p"${MYSQL_ROOT_PASSWORD}" smartsurvey \
  > backup-$(date +%Y%m%d).sql
```

### Atkurti duomenų bazę

```bash
docker compose exec -T mysql \
  mysql -u root -p"${MYSQL_ROOT_PASSWORD}" smartsurvey \
  < backup-20240101.sql
```

### Atsarginė įkeltų failų kopija

```bash
docker run --rm \
  -v rtsurvey_app_uploads:/data \
  -v $(pwd):/backup \
  alpine tar czf /backup/uploads-$(date +%Y%m%d).tar.gz -C /data .
```

## Įdėtasis Keycloak (pasirinktinis SSO)

Gamybos sudarymo faile yra pasirinktinis Keycloak konteineris SSO. Jis dalinasi ta pačia MySQL egzemplioriaus ir suaktyvinamas per Docker Compose profilį.

<Callout type="info">
Įdėtajam Keycloak reikia mažiausiai **4 GB RAM**. Tai neprivaloma — praleiskite, jei jums nereikia SSO.
</Callout>

### Pridėkite Keycloak kintamuosius į `.env`

```bash
# Keycloak admin
KEYCLOAK_ADMIN_USER=admin
KEYCLOAK_ADMIN_PASSWORD=change-this-keycloak-password

# Keycloak database (created automatically in the shared MySQL on first run)
KEYCLOAK_DB=keycloak
KEYCLOAK_DB_USER=keycloak
KEYCLOAK_DB_PASSWORD=change-this-keycloak-db-password

# KC_HOSTNAME: full public URL of your server (Keycloak appends /auth automatically)
KC_HOSTNAME=http://your-server:8091

# Port Keycloak listens on (host)
KEYCLOAK_PORT=8091

# Tell the rtCloud app to connect to embedded Keycloak
EMBED_KEYCLOAK=true
KEYCLOAK_URL=http://your-server:8091
KEYCLOAK_REALM=rtsurvey
KEYCLOAK_CLIENT_ID=rtsurvey
KEYCLOAK_CLIENT_SECRET=your-client-secret
```

`keycloak` paslauga jau įtraukta į aukščiau pateiktą `docker-compose.yml` (pagal `embed-keycloak` profilį — ji nepaleis, nebent naudosite `--profile embed-keycloak`).

Sukurkite importo katalogą (Keycloak paleis be jo, bet automatinis srities parengimas neveiks):

```bash
mkdir -p /opt/rtsurvey/keycloak-import
```

### Paleiskite su Keycloak

```bash
docker compose --profile embed-keycloak up -d
```

Paleisti be Keycloak (numatytasis):

```bash
docker compose up -d
```

### Keycloak administravimo konsolė

Kai bus sveikas, pasiekite Keycloak administravimo UI adresu:

```
http://your-server:8091/auth/admin
```

Prisijunkite su `KEYCLOAK_ADMIN_USER` / `KEYCLOAK_ADMIN_PASSWORD`.

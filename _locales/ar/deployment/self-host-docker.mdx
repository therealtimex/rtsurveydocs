import { Callout, Steps } from 'nextra/components'

استخدم هذا الدليل إذا كنت تريد تشغيل rtSurvey على خادمك الخاص (VPS أو خادم مادي أو جهاز محلي) باستخدام صورة Docker العامة `rtawebteam/rtcloud:survey-public`.

**لا يلزم تسجيل الدخول إلى Docker Hub** — الصورة عامة.

يحزم الحاوية كل شيء في صورة واحدة:
- Apache + PHP (خادم التطبيق)
- Shiny Server (لوحات تحليلات، المنفذ 3838)
- Beanstalkd (قائمة انتظار المهام في الخلفية)

---

## المتطلبات

### الخادم

| المورد | الحد الأدنى | موصى به |
|----------|---------|-------------|
| RAM | 4 GB | 8 GB |
| القرص | 50 GB | 100 GB SSD |
| CPU | 2 vCPUs | 4 vCPUs |
| نظام التشغيل | Ubuntu 22.04 LTS | Ubuntu 22.04 LTS |

### البرمجيات

- **Docker Engine 24.0+** — [دليل التثبيت](https://docs.docker.com/engine/install/ubuntu/)
- **Docker Compose v2.0+** — مضمن مع Docker Desktop؛ على Linux: `apt install docker-compose-plugin`

## الإعداد

<Steps>

### إنشاء دليل عمل

```bash
mkdir -p /opt/rtsurvey && cd /opt/rtsurvey
```

### إنشاء `docker-compose.yml`

```yaml
services:
  mysql:
    image: mysql:8.0
    container_name: rtsurvey-mysql
    restart: unless-stopped
    command: >
      --default-authentication-plugin=mysql_native_password
      --character-set-server=utf8
      --collation-server=utf8_unicode_ci
      --sql-mode=NO_ENGINE_SUBSTITUTION
    environment:
      MYSQL_ROOT_PASSWORD: ${MYSQL_ROOT_PASSWORD}
      MYSQL_DATABASE: ${MYSQL_DATABASE:-smartsurvey}
      MYSQL_USER: ${MYSQL_USER:-smartsurvey}
      MYSQL_PASSWORD: ${MYSQL_PASSWORD}
      MYSQL_ROOT_HOST: '%'
    volumes:
      - mysql_data:/var/lib/mysql
    networks:
      - rtsurvey-net
    healthcheck:
      test: ["CMD-SHELL", "mysqladmin ping -h localhost -u root -p$$MYSQL_ROOT_PASSWORD"]
      interval: 10s
      timeout: 5s
      retries: 5
      start_period: 30s

  rtsurvey:
    image: rtawebteam/rtcloud:survey-public
    container_name: rtsurvey-app
    restart: unless-stopped
    entrypoint: ["/bin/entrypoint-production.sh"]
    depends_on:
      mysql:
        condition: service_healthy
    ports:
      - "${APP_PORT:-8080}:80"
      - "${SHINY_PORT:-3838}:3838"
    env_file:
      - .env
    volumes:
      - app_uploads:/var/www/html/smartsurvey/uploads
      - app_audios:/var/www/html/smartsurvey/audios
      - app_downloads:/var/www/html/smartsurvey/downloads
      - app_gallery:/var/www/html/smartsurvey/gallery
      - app_tmp:/var/www/html/smartsurvey/tmp
      - app_cache:/var/www/html/smartsurvey/cache
      - app_runtime:/var/www/html/smartsurvey/protected/runtime
      - app_assets:/var/www/html/smartsurvey/assets
      - app_aggregate:/var/www/html/smartsurvey/aggregate
    networks:
      - rtsurvey-net
    healthcheck:
      test: ["CMD", "curl", "-f", "http://localhost/health"]
      interval: 30s
      timeout: 10s
      retries: 3
      start_period: 90s

  # اختياري: Keycloak SSO مدمج
  # ابدأ بـ: docker compose --profile embed-keycloak up -d
  keycloak:
    image: quay.io/keycloak/keycloak:latest
    container_name: rtsurvey-keycloak
    restart: unless-stopped
    profiles:
      - embed-keycloak
    command: start --import-realm
    environment:
      KEYCLOAK_ADMIN: ${KEYCLOAK_ADMIN_USER:-admin}
      KEYCLOAK_ADMIN_PASSWORD: ${KEYCLOAK_ADMIN_PASSWORD}
      KC_HTTP_ENABLED: "true"
      KC_HTTP_RELATIVE_PATH: /auth
      KC_PROXY_HEADERS: xforwarded
      KC_HOSTNAME: ${KC_HOSTNAME}
      KC_HOSTNAME_STRICT: "false"
      KC_DB: mysql
      KC_DB_URL_DATABASE: ${KEYCLOAK_DB:-keycloak}
      KC_DB_URL_HOST: mysql
      KC_DB_USERNAME: ${KEYCLOAK_DB_USER:-keycloak}
      KC_DB_PASSWORD: ${KEYCLOAK_DB_PASSWORD}
    volumes:
      - ./keycloak-import:/opt/keycloak/data/import
    ports:
      - "${KEYCLOAK_PORT:-8091}:8080"
    depends_on:
      mysql:
        condition: service_healthy
    networks:
      - rtsurvey-net
    healthcheck:
      test: ["CMD-SHELL", "curl -f http://localhost:9000/health/ready || exit 1"]
      interval: 30s
      timeout: 10s
      retries: 10
      start_period: 120s

volumes:
  mysql_data:
  app_uploads:
  app_audios:
  app_downloads:
  app_gallery:
  app_tmp:
  app_cache:
  app_runtime:
  app_assets:
  app_aggregate:

networks:
  rtsurvey-net:
    driver: bridge
```

### إنشاء `.env`

```bash
# المشروع
PROJECT_ID=mysurvey
PROJECT_TYPE=rtsurvey
PROJECT_URL=your-server-ip-or-domain
HTTP_PROTOCOL=http
TZ=UTC

# قاعدة البيانات
MYSQL_HOST=mysql
MYSQL_DATABASE=smartsurvey
MYSQL_USER=smartsurvey
MYSQL_ROOT_PASSWORD=change-this-root-password
MYSQL_PASSWORD=change-this-app-password

# المشرف (اضبطه قبل أول تشغيل — لا يمكن تغييره عبر env بعد إنشاء قاعدة البيانات)
ADMIN_PASSWORD=change-this-admin-password

# وقت التشغيل
RUN_ENV=prod
RUN_MODE=admin
GII_ENABLED=false
CSRF_VALIDATION_ENABLED=true

# المنافذ (اختياري — القيم الافتراضية موضحة)
APP_PORT=8080
SHINY_PORT=3838
```

<Callout type="warning">
غيّر `MYSQL_ROOT_PASSWORD` و`MYSQL_PASSWORD` قبل البدء. استخدم سلاسل عشوائية قوية (32+ حرفاً) في الإنتاج.
</Callout>

### تشغيل المجموعة

```bash
docker compose up -d
```

يستغرق أول تشغيل حوالي 60–90 ثانية — تهيئ MySQL قاعدة البيانات في أول تشغيل.

### التحقق

```bash
# تحقق من تشغيل جميع الحاويات
docker compose ps

# تحقق من صحة التطبيق
curl http://localhost:8080/health
```

</Steps>

## أول تسجيل دخول

بمجرد اجتياز فحص الصحة، افتح المتصفح:

```
http://your-server:8080/cpms/cpmsSite/login
```

| الحقل | القيمة |
|-------|-------|
| اسم المستخدم | `admin` |
| كلمة المرور | قيمة `ADMIN_PASSWORD` في ملف `.env` (الافتراضي `admin`) |

<Callout type="warning">
اضبط `ADMIN_PASSWORD` في ملف `.env` قبل أول تشغيل. تضبطه نقطة الدخول عند التشغيل الأول — تغييرها بعد تهيئة قاعدة البيانات لا يؤثر.
</Callout>

## متغيرات البيئة

### مطلوبة من حاوية التطبيق

ستрафية نقطة الدخول التشغيل إذا كان أي منها مفقوداً:

| المتغير | الوصف |
|----------|-------------|
| `PROJECT_ID` | معرف فريد لهذه النسخة (أبجدي رقمي، بدون مسافات) |
| `PROJECT_URL` | النطاق أو IP حيث يتم الوصول للتطبيق (بدون بادئة `http://`) |
| `MYSQL_HOST` | اسم مضيف MySQL — استخدم اسم خدمة Docker (مثل `mysql`) |
| `MYSQL_DATABASE` | اسم قاعدة البيانات |
| `MYSQL_PASSWORD` | كلمة مرور مستخدم قاعدة البيانات |

### مطلوبة من حاوية MySQL

| المتغير | الوصف |
|----------|-------------|
| `MYSQL_ROOT_PASSWORD` | كلمة مرور MySQL الجذرية (تستخدمها حاوية `mysql`، ليس التطبيق) |

### موصى به

| المتغير | الافتراضي | الوصف |
|----------|---------|-------------|
| `MYSQL_USER` | `smartsurvey` | اسم مستخدم قاعدة البيانات |
| `ADMIN_PASSWORD` | `admin` | كلمة مرور المشرف الأولية — **اضبط قبل أول تشغيل**، لا يمكن التغيير عبر env بعد إنشاء قاعدة البيانات |
| `HTTP_PROTOCOL` | `https` | اضبط على `http` إذا لم تستخدم SSL |
| `PROJECT_PORT` | `80` | المنفذ الخارجي الذي يتصل به المستخدمون (ليس منفذ Docker الداخلي) |
| `PROJECT_TYPE` | `rtwork` | نوع المنصة — استخدم `rtsurvey` لمنصة الاستبيان |
| `TZ` | `UTC` | المنطقة الزمنية (مثل `Asia/Bangkok`، `America/New_York`) |

### وقت التشغيل

| المتغير | الافتراضي | الوصف |
|----------|---------|-------------|
| `RUN_ENV` | `prod` | وضع البيئة (`prod` أو `dev`) |
| `RUN_MODE` | `admin` | دور الخدمة — استخدم `admin` لإعداد خادم واحد |
| `GII_ENABLED` | `false` | أبق `false` في الإنتاج (مولد كود Yii) |
| `CSRF_VALIDATION_ENABLED` | `true` | حماية CSRF — أبق `true` |

### الترخيص

| المتغير | الافتراضي | الوصف |
|----------|---------|-------------|
| `REQUIRE_LICENSE` | `false` | اضبط على `true` لتطبيق التحقق من الترخيص |
| `RTCLOUD_LICENSE_KEY` | — | مفتاح ترخيصك — مطلوب عندما `REQUIRE_LICENSE=true` |

## استمرارية البيانات

جميع بيانات المستخدم مخزنة في وحدات تخزين Docker المسماة. تنجو من إعادة تشغيل الحاوية وتحديثات الصورة.

| الوحدة | المحتويات |
|--------|----------|
| `mysql_data` | قاعدة البيانات (الاستبيانات والمستخدمون والردود) |
| `app_uploads` | ملفات الرفع من الاستبيانات |
| `app_gallery` | مكتبة الوسائط |
| `app_downloads` | ملفات التصدير المُنشأة |
| `app_audios` | التسجيلات الصوتية |
| `app_runtime` | ملفات جلسة PHP والتخزين المؤقت |
| `app_aggregate` | بيانات التحليلات المجمعة |

## العمليات الشائعة

### عرض السجلات

```bash
docker compose logs -f rtsurvey
docker compose logs -f mysql
```

### إعادة تشغيل التطبيق

```bash
docker compose restart rtsurvey
```

### الوصول إلى shell

```bash
docker compose exec rtsurvey bash
```

### تشغيل ترحيلات قاعدة البيانات يدوياً

```bash
docker compose exec rtsurvey php /var/www/html/smartsurvey/protected/yiic migrate
```

## النسخ الاحتياطي والاستعادة

### نسخ احتياطي لقاعدة البيانات

```bash
docker compose exec mysql \
  mysqldump -u root -p"${MYSQL_ROOT_PASSWORD}" smartsurvey \
  > backup-$(date +%Y%m%d).sql
```

### استعادة قاعدة البيانات

```bash
docker compose exec -T mysql \
  mysql -u root -p"${MYSQL_ROOT_PASSWORD}" smartsurvey \
  < backup-20240101.sql
```

### نسخ احتياطي للملفات المرفوعة

```bash
docker run --rm \
  -v rtsurvey_app_uploads:/data \
  -v $(pwd):/backup \
  alpine tar czf /backup/uploads-$(date +%Y%m%d).tar.gz -C /data .
```

## Keycloak المدمج (SSO اختياري)

يتضمن ملف compose للإنتاج حاوية Keycloak اختيارية لـ SSO. تشارك نفس نسخة MySQL ويتم تفعيلها عبر ملف تعريف Docker Compose.

<Callout type="info">
يتطلب Keycloak المدمج على الأقل **4 GB RAM**. إنه اختياري — تخطاه إذا لم تحتج إلى SSO.
</Callout>

### إضافة متغيرات Keycloak إلى `.env`

```bash
# مشرف Keycloak
KEYCLOAK_ADMIN_USER=admin
KEYCLOAK_ADMIN_PASSWORD=change-this-keycloak-password

# قاعدة بيانات Keycloak (تُنشأ تلقائياً في MySQL المشتركة عند أول تشغيل)
KEYCLOAK_DB=keycloak
KEYCLOAK_DB_USER=keycloak
KEYCLOAK_DB_PASSWORD=change-this-keycloak-db-password

# KC_HOSTNAME: عنوان URL العام الكامل لخادمك (يُضيف Keycloak /auth تلقائياً)
KC_HOSTNAME=http://your-server:8091

# المنفذ الذي يستمع عليه Keycloak (المضيف)
KEYCLOAK_PORT=8091

# أخبر تطبيق rtCloud بالاتصال بـ Keycloak المدمج
EMBED_KEYCLOAK=true
KEYCLOAK_URL=http://your-server:8091
KEYCLOAK_REALM=rtsurvey
KEYCLOAK_CLIENT_ID=rtsurvey
KEYCLOAK_CLIENT_SECRET=your-client-secret
```

خدمة `keycloak` مضمنة بالفعل في `docker-compose.yml` أعلاه (ضمن ملف التعريف `embed-keycloak` — لن تبدأ إلا إذا استخدمت `--profile embed-keycloak`).

أنشئ دليل الاستيراد (سيبدأ Keycloak بدونه لكن التوفير التلقائي للنطاق لن يعمل):

```bash
mkdir -p /opt/rtsurvey/keycloak-import
```

### البدء مع Keycloak

```bash
docker compose --profile embed-keycloak up -d
```

للبدء بدون Keycloak (الافتراضي):

```bash
docker compose up -d
```

### لوحة تحكم مشرف Keycloak

بمجرد أن يكون بصحة جيدة، اوصل إلى واجهة مشرف Keycloak على:

```
http://your-server:8091/auth/admin
```

سجّل الدخول بـ `KEYCLOAK_ADMIN_USER` / `KEYCLOAK_ADMIN_PASSWORD`.

## الخطوات التالية

- **HTTPS** — ضع nginx أو Caddy أمامه واتبع دليل [إعداد SSL](ssl-setup)

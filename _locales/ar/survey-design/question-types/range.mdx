يتيح نوع السؤال `range` للمستجيبين اختيار رقم ضمن حد أدنى وحد أقصى محددين. في نموذج الويب الخاص بـ rtSurvey، يتم عرض ذلك كـ **إدخال رقمي** قياسي — حيث يكتب جامع البيانات القيمة مباشرة. تحدد المعلمات `start` و `end` و `step` النطاق الصالح ويتم فرضها كقيود.

## مواصفات XLSForm الأساسية

| type | name | label | parameters |
|------|------|-------|------------|
| range | satisfaction | ما مدى رضاك عن الخدمة؟ | start=1 end=5 step=1 |

يحدد عمود `parameters` حدود شريط التمرير وحجم الخطوة:

| Parameter | Description | Default |
|-----------|-------------|---------|
| `start` | الحد الأدنى للقيمة (شامل) | 0 |
| `end` | الحد الأقصى للقيمة (شامل) | 10 |
| `step` | الزيادة بين القيم الصالحة | 1 |

لمزيد من التفاصيل حول نوع سؤال النطاق القياسي، راجع [مواصفات XLSForm](https://xlsform.org/en/#question-types).

## الاستخدامات

تشيع استخدام أسئلة النطاق في:

1. مقاييس الرضا أو التقييم (مثلاً، 1–5 أو 0–10)
2. المقاييس الرقمية بأسلوب ليكرت (Likert-style)
3. جمع القياسات حيث تكون القيم المنفصلة فقط صالحة
4. الفئات العمرية أو نطاقات الدرجات حيث يعمل شريط التمرير على تحسين سهولة الاستخدام مقارنة بحقل نصي

## أمثلة على الاستخدام

### مقياس تقييم أساسي

| type | name | label | parameters |
|------|------|-------|------------|
| range | overall_rating | التقييم العام (0–10) | start=0 end=10 step=1 |

### خطوة عشرية

| type | name | label | parameters |
|------|------|-------|------------|
| range | weight_kg | الوزن (كجم) | start=0 end=200 step=0.5 |

### استخدام القيمة في عملية حسابية

| type | name | label | parameters | calculation |
|------|------|-------|------------|-------------|
| range | score | درجة الاختبار (0–100) | start=0 end=100 step=5 | |
| calculate | grade | | | if(`${score}` >= 90, 'A', if(`${score}` >= 80, 'B', if(`${score}` >= 70, 'C', 'F'))) |
| note | grade_note | درجتك هي: `${grade}` | | |

## أفضل الممارسات

1. قم دائمًا بضبط قيم `start` و `end` و `step` ذات مغزى — لا تعتمد على القيم الافتراضية.
2. ضع تسميات لنهايات المقياس في عمود `hint` (مثلاً، `تلميح: 0 = غير راضٍ تمامًا، 10 = راضٍ تمامًا`) لمنح المستجيبين سياقًا.
3. لمقاييس ليكرت المكونة من 5 نقاط، استخدم `start=1 end=5 step=1` بدلاً من 0–4، حيث يتوقع المستجيبون أن تعني "1" أدنى مستوى.
4. استخدم `range` بدلاً من `integer` + القيد (constraint) عندما تكون الطبيعة المحدودة للإدخال جزءًا من تصميم السؤال (يوصل شريط التمرير المقياس بصريًا).

## القيود (Limitations)

- لا توجد أداة شريط تمرير (slider widget) في نموذج الويب الخاص بـ rtSurvey — إدخال القيمة هو إدخال رقمي عادي. لتجربة شريط تمرير مرئي، استخدم عميل الهاتف المحمول الذي يدعم أداة النطاق.
- بالنسبة للنطاقات الواسعة جدًا (مثل 0–10000)، يكون نوع `integer` البسيط مع قيد فعالاً بنفس القدر وأكثر سهولة في الاستخدام.
- تعمل قيم الخطوات الدقيقة (مثل `step=0.1`) كقيود ولكن ليس لها أي تأثير على دقة شريط التمرير في نموذج الويب.

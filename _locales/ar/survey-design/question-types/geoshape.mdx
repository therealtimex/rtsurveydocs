يجمع نوع السؤال `geoshape` مضلعًا مغلقًا - وهو سلسلة من إحداثيات نظام تحديد المواقع العالمي (GPS) حيث تكون النقطة الأولى والأخيرة متطابقة. في نموذج ويب rtSurvey، يظهر هذا كـ **إدخال نصي** حيث يقوم المُعدّ بإدخال سلسلة الإحداثيات أو لصقها مباشرةً.

## مواصفات XLSForm الأساسية

| type     | name        | label                            |
|----------|-------------|----------------------------------|
| geoshape | field_area  | ارسم حدود الحقل                   |
| geoshape | zone        | سجل حدود المنطقة                 |

للاطلاع على المواصفات القياسية، راجع [وثائق XLSForm](https://xlsform.org/en/#question-types).

---

## تنسيق البيانات

يتم تخزينها كقائمة من النقاط مفصولة بفاصلة منقوطة **بدون مسافات حول الفواصل المنقوطة**. تتكون كل نقطة من أربع قيم مفصولة بمسافات:

```
lat lon alt acc;lat lon alt acc;lat lon alt acc;lat lon alt acc
```

| المكون    | الوصف                          |
|-----------|--------------------------------|
| `lat`     | خط العرض بالدرجات العشرية     |
| `lon`     | خط الطول بالدرجات العشرية     |
| `alt`     | الارتفاع بالأمتار (`0` إذا كان غير معروف) |
| `acc`     | دقة GPS بالأمتار (`0` إذا كانت غير معروفة) |

**يجب أن يكون المضلع مغلقًا** - يجب أن تكون النقطة الأخيرة مساوية للنقطة الأولى.

**مثال - مضلع رباعي النقاط (مثلث، مغلق):**
```
13.756331 100.501762 0 0;13.758000 100.503000 0 0;13.757000 100.506000 0 0;13.756331 100.501762 0 0
```

مطلوب ما لا يقل عن ثلاث نقاط مميزة بالإضافة إلى التكرار الختامي لتشكيل مضلع صالح.

## كيفية عرضها في rtSurvey

في نموذج ويب rtSurvey، يظهر `geoshape` كـ **حقل نصي** عادي. يقوم المُعدّ بكتابة سلسلة الإحداثيات أو لصقها. لا يوجد منتقي خرائط مضلع تفاعلي مدمج لهذا النوع في نموذج الويب الحالي.

### جمع نقاط المضلع بشكل تفاعلي

النمط الموصى به للجمع الميداني هو **مجموعة متكررة من أسئلة `geopoint`** - تستخدم كل قمة منتقي خريطة GPS الكامل - مدمجة مع `calculate` لإنتاج سلسلة الشكل الجغرافي:

| type | name | label | calculation |
|------|------|-------|-------------|
| begin repeat | polygon_points | سجل كل زاوية | |
| geopoint | point | انقر لتسجيل الزاوية | |
| end repeat | polygon_points | | |
| calculate | geoshape_value | | `join(';', ${polygon_points/point})` |

بعد الانضمام، أضف النقطة الأولى يدويًا لإغلاق المضلع، أو استخدم `calculate` ثانية لدمجها.

## أفضل الممارسات

1. استخدم مجموعة متكررة من أسئلة `geopoint` للجمع التفاعلي القائم على الخرائط وربط القيم - يمنح هذا المُعدّين منتقي GPS لكل رأس.
2. أغلق المضلع دائمًا (كرر النقطة الأولى في النهاية) قبل الإرسال.
3. قم بتضمين التنسيق المتوقع في عمود `hint` عند الحاجة إلى إدخال إحداثيات يدوية.
4. اطلب ما لا يقل عن 3 نقاط زاوية مميزة لمضلع صالح - فرض ذلك من خلال التعليمات بدلاً من قيود XLSForm.
5. استخدم `geopoint` لأسئلة الموقع الفردي و`geoshape` فقط عندما يكون تحديد المنطقة هو الهدف الفعلي للمسح.

## القيود

- لا يوجد منتقي خرائط مضلع تفاعلي مدمج لـ `geoshape` في نموذج ويب rtSurvey.
- يجب إغلاق المضلع يدويًا - لا توجد آلية إغلاق تلقائية في وضع إدخال النص.
- تتطلب مصادقة طوبولوجيا المضلع (مثل عدم التقاطع الذاتي، والحد الأدنى للمساحة) معالجة لاحقة خارج قيود XLSForm.
- تنتج الحدود الطويلة التي تحتوي على العديد من الرؤوس سلاسل نصية كبيرة.

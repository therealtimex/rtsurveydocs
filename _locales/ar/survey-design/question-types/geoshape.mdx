يلتقط نوع السؤال `geoshape` مضلعًا مغلقًا — سلسلة من إحداثيات GPS حيث تكون النقطة الأولى والأخيرة هي نفسها. في نموذج ويب rtSurvey، يتم عرض هذا كـ **إدخال نصي** حيث يقوم جامع البيانات بإدخال أو لصق سلسلة الإحداثيات مباشرة.

## مواصفات XLSForm الأساسية

| type     | name        | label                            |
|----------|-------------|----------------------------------|
| geoshape | field_area  | ارسم حدود الحقل   |
| geoshape | zone        | سجل حدود المنطقة         |

للاطلاع على المواصفات القياسية، راجع [وثائق XLSForm](https://xlsform.org/en/#question-types).

---

## تنسيق البيانات

يتم تخزينها كقائمة نقاط مفصولة بفاصلة منقوطة مع **عدم وجود مسافات حول الفواصل المنقوطة**. كل نقطة عبارة عن أربع قيم مفصولة بمسافات:

```
lat lon alt acc;lat lon alt acc;lat lon alt acc;lat lon alt acc
```

| Component | Description |
|-----------|-------------|
| `lat` | خط العرض بالدرجات العشرية |
| `lon` | خط الطول بالدرجات العشرية |
| `alt` | الارتفاع بالأمتار (`0` إذا كان غير معروف) |
| `acc` | دقة GPS بالأمتار (`0` إذا كانت غير معروفة) |

**يجب أن يكون المضلع مغلقًا** — يجب أن تساوي النقطة الأخيرة النقطة الأولى.

**مثال — مضلع من أربع نقاط (مثلث، مغلق):**
```
13.756331 100.501762 0 0;13.758000 100.503000 0 0;13.757000 100.506000 0 0;13.756331 100.501762 0 0
```

مطلوب حد أدنى من ثلاث نقاط متميزة بالإضافة إلى تكرار الإغلاق لتشكيل مضلع صالح.

---

## كيف يتم عرضه في rtSurvey

في نموذج ويب rtSurvey، يتم عرض `geoshape` كـ **حقل نصي** عادي. يقوم جامع البيانات بكتابة أو لصق سلسلة الإحداثيات. لا يوجد منتقي خريطة مضلع تفاعلي مدمج لهذا النوع في نموذج الويب الحالي.

### جمع نقاط المضلع بشكل تفاعلي

النمط الموصى به للجمع الميداني هو **مجموعة تكرار من أسئلة `geopoint`** — يستخدم كل رأس منتقي خريطة GPS الكامل — مدمجًا مع `calculate` لإنتاج سلسلة geoshape:

| type | name | label | calculation |
|------|------|-------|-------------|
| begin repeat | polygon_points | سجل كل ركن | |
| geopoint | point | اضغط لتسجيل الركن | |
| end repeat | polygon_points | | |
| calculate | geoshape_value | | `join(';', ${polygon_points/point})` |

بعد الانضمام، أضف النقطة الأولى يدويًا لإغلاق المضلع، أو استخدم عملية حساب ثانية لدمجها.

## أفضل الممارسات

1. استخدم مجموعة تكرار من أسئلة `geopoint` للجمع التفاعلي المستند إلى الخريطة وانضم إلى القيم — وهذا يمنح جامعي البيانات منتقي GPS لكل رأس.
2. قم دائمًا بإغلاق المضلع (كرر النقطة الأولى في النهاية) قبل الإرسال.
3. قم بتضمين التنسيق المتوقع في عمود `hint` عندما يكون إدخال الإحداثيات يدويًا مطلوبًا.
4. اطلب ما لا يقل عن 3 نقاط ركن متميزة لمضلع صالح — فرض ذلك من خلال التعليمات بدلاً من قيود XLSForm.
5. استخدم `geopoint` لأسئلة الموقع الفردي و `geoshape` فقط عندما يكون ترسيم المنطقة هو الهدف الفعلي للاستبيان.

## القيود (Limitations)

- لا يوجد منتقي خريطة مضلع تفاعلي مدمج لـ `geoshape` في نموذج ويب rtSurvey.
- يجب إغلاق المضلع يدويًا — لا توجد آلية إغلاق تلقائية في وضع إدخال النص.
- يتطلب التحقق من طبولوجيا المضلع (مثل عدم التقاطع الذاتي، والحد الأدنى للمساحة) معالجة لاحقة خارج قيود XLSForm.
- تنتج الحدود الطويلة مع العديد من الرؤوس سلاسل نصية كبيرة.

---

يلتقط نوع السؤال `geopoint` الإحداثيات الجغرافية (خط العرض، خط الطول، الارتفاع، الدقة) باستخدام نظام تحديد المواقع العالمي (GPS) الخاص بالجهاز. يعرض rtSurvey أداة الاختيار بعدة أوضاع تخطيط ويدعم الأتمتة من خلال معلمتي `inputs{}` و `outputs{}`.

## مواصفات XLSForm الأساسية

| type     | name        | label                       |
|----------|-------------|-----------------------------|
| geopoint | location    | سجل الموقع الحالي           |

للحصول على المواصفات القياسية، راجع [وثائق XLSForm](https://xlsform.org/en/#question-types).

## تنسيق البيانات

تُخزن كأربع قيم مفصولة بمسافات:

```
latitude longitude altitude accuracy
```

مثال: `13.756331 100.501762 15 8`

---

## أوضاع التخطيط

### الافتراضي - زر مستطيل

يفتح زر "بدء النقطة الجغرافية" المستطيل نموذج خريطة كاملًا حيث يحدد المُحصي نقطة. بعد الالتقاط، يتغير تسمية الزر إلى "عرض أو تغيير النقطة الجغرافية" وتظهر الإحداثيات أدناه.

لا توجد قيمة `appearance` مطلوبة.

---

### `display{inline-icon}` - زر دائري متقاطع

يعرض زر أيقونة دائري (علامة التصويب ⊕) بدلاً من الزر المستطيل. يؤدي النقر عليه إلى فتح نموذج الخريطة نفسه.

```
display{inline-icon}
```

**مدمج مع الموضع والحجم:**

```
display{inline-icon, left}           → الزر على يسار التسمية
display{inline-icon, top}            → الزر فوق التسمية
display{inline-icon, bottom}         → الزر أسفل التسمية، في المنتصف
display{inline-icon, large}          → أيقونة كبيرة (75 بكسل)
display{inline-icon, medium}         → أيقونة متوسطة (50 بكسل)
display{inline-icon, left, large}    → زر كبير على اليسار
```

| الحجم | ارتفاع/عرض الأيقونة |
|------|--------------------|
| *(افتراضي)* | 25 بكسل |
| `medium` | 50 بكسل |
| `large` | 75 بكسل |

---

### `display{thumbnail-square}` - صورة مصغرة لخريطة حية

يعرض معاينة خريطة حية (Leaflet) مباشرة على السؤال بدلاً من الزر. تعرض الصورة المصغرة موقع GPS الحالي والنقطة المحددة. يؤدي النقر على زر التوسيع إلى فتح النموذج الكامل.

```
display{thumbnail-square}
```

**حجم الصورة المصغرة المخصص:**

```
display{thumbnail-square-[WxH]}          → بكسلات ثابتة
display{thumbnail-square-[400x200]}      → 400 بكسل عرض × 200 بكسل ارتفاع

display{thumbnail-square-[W%xH%]}        → نسبة مئوية من عرض النموذج
display{thumbnail-square-[100%x30%]}     → عرض كامل × 30% من عرض النموذج
```

## `display{}` مقابل `results{}` - قبل وبعد الالتقاط

يتحكم `display{}` في التخطيط **قبل** أن يلتقط المستخدم موقعًا. يتحكم `results{}` في التخطيط **بعد** وجود قيمة. يمكن أن يكون لهما محاذاة مختلفة.

```
display{inline-icon, right} results{left}
```

يعرض هذا الزر على اليمين قبل الالتقاط، ثم ينقله إلى اليسار بمجرد تسجيل نقطة.

### `hide(value)` - إخفاء عرض الإحداثيات

بشكل افتراضي، يتم عرض نص خط العرض/خط الطول/الدقة/الارتفاع الملتقط أسفل الزر. قم بإخفائه باستخدام:

```
results{hide(value)}
display{inline-icon} results{hide(value)}
```

---

## `inputs{}` - أتمتة نظام تحديد المواقع العالمي (GPS)

### الالتقاط التلقائي عند التحميل

يسجل موقع GPS تلقائيًا عند تحميل النموذج، دون أن يضغط المُحصي على أي شيء.

```
inputs{auto-take}
```

**الالتقاط التلقائي المشروط** باستخدام تعبير XLSForm:

```
inputs{autotakeGeo(expression(if(${capture_now} = 'yes', true(), false())))}
```

### التعبئة المسبقة من حقل نصي

املأ النقطة الجغرافية من سؤال يحتوي على اسم مكان أو سلسلة عنوان. يقوم rtSurvey بتحويل السلسلة إلى إحداثيات عبر OpenStreetMap Nominatim.

```
inputs{question(address_field)}
```

---

## `outputs{}` - تحويل عكسي إلى نص

بعد التقاط نقطة، املأ سؤال `text` تلقائيًا بالعنوان المقروء من قبل الإنسان (المحول عكسيًا من الإحداثيات).

```
outputs{question(address_field)}
```

مثال:

| type | name | label | appearance |
|------|------|-------|------------|
| geopoint | location | سجل الموقع | `outputs{question(address_text)}` |
| text | address_text | العنوان | |

---

## `nomap` - التقاط نظام تحديد المواقع العالمي (GPS) بدون خريطة

يستبدل نموذج الخريطة بمربع حوار بسيط يطلب إذن الموقع ويسجل الإحداثيات. لا يتم عرض أي خريطة. مفيد لالتقاط GPS فقط على الأجهزة منخفضة التكلفة أو عندما تكون خرائط الطرق غير متوفرة دون اتصال.

```
nomap
```

## أمثلة على الاستخدام

| type | name | label | appearance |
|------|------|-------|------------|
| geopoint | field_loc | سجل موقع الحقل | `display{inline-icon, right, large}` |
| geopoint | site | موقع الموقع | `display{thumbnail-square-[100%x30%]}` |
| geopoint | auto_loc | الموضع الحالي | `inputs{auto-take} display{inline-icon} results{hide(value)}` |
| geopoint | mapped_loc | الموقع المعين | `display{inline-icon} outputs{question(address)}` |
| geopoint | gps_only | نقطة GPS | `nomap` |

## أفضل الممارسات

1. استخدم `inputs{auto-take}` للاستبيانات التي تتطلب التحقق من المُحصي حيث يكون GPS إلزاميًا - فهو يزيل الخطوة اليدوية.
2. استخدم `display{thumbnail-square}` عندما تريد أن يؤكد المُحصي بصريًا النقطة المحددة قبل المتابعة.
3. قم بإقران `outputs{question(...)}` بحقل `text` للقراءة فقط لعرض العنوان المحول عكسيًا إلى المُحصي.
4. استخدم `nomap` في المناطق التي لا يوجد بها اتصال بالإنترنت حيث لا يمكن تحميل خرائط الطرق.
5. اسمح لوقت GPS بالاستقرار قبل التسجيل - عادةً ما تكون الدقة الأقل من 10 أمتار كافية للمسوحات الميدانية.

## القيود

- يتطلب تحويل `inputs{question(name)}` إلى إحداثيات الوصول إلى الإنترنت - فهو يستدعي OpenStreetMap Nominatim API.
- يتطلب التحويل العكسي لـ `outputs{question(name)}` أيضًا الوصول إلى الإنترنت.
- تتطلب الصورة المصغرة للخريطة (`display{thumbnail-square}`) الإنترنت لتحميل خرائط الطرق؛ لا تزال الإحداثيات تُسجل دون اتصال.
- تختلف دقة GPS حسب الجهاز والبيئة - قد تؤدي الظروف الداخلية أو الحضرية إلى دقة تزيد عن 50 مترًا.
- قد يؤثر جمع بيانات الموقع بشكل كبير على عمر بطارية الجهاز خلال المسوحات الطويلة.

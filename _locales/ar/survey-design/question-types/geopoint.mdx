---

يلتقط نوع السؤال `geopoint` الإحداثيات الجغرافية (خط العرض، خط الطول، الارتفاع، الدقة) باستخدام نظام GPS الخاص بالجهاز. يقوم rtSurvey بعرض لاقط الموقع مع عدة أوضاع للتخطيط ويدعم الأتمتة من خلال معلمتي `inputs{}` و `outputs{}`.

## مواصفات XLSForm الأساسية

| type     | name        | label                       |
|----------|-------------|-----------------------------|
| geopoint | location    | تسجيل الموقع الحالي |

للاطلاع على المواصفات القياسية، راجع [وثائق XLSForm](https://xlsform.org/en/#question-types).

## تنسيق البيانات

يتم تخزينها كأربع قيم مفصولة بمسافات:

```
latitude longitude altitude accuracy
```

مثال: `13.756331 100.501762 15 8`

## أوضاع التخطيط (Layout modes)

### الافتراضي — زر مستطيل

يفتح زر مستطيل "START GEOPOINT" نافذة خريطة منبثقة كاملة حيث يختار الباحث نقطة. بعد الالتقاط، يتغير نص الزر إلى "View or change geo point" وتظهر الإحداثيات أدناه.

لا توجد قيمة مظهر (appearance) مطلوبة.

---

### `display{inline-icon}` — زر متقاطع دائري

يعرض زر أيقونة دائري (⊕) بدلاً من الزر المستطيل. يؤدي الضغط عليه إلى فتح نفس نافذة الخريطة المنبثقة.

```
display{inline-icon}
```

**بالاشتراك مع الموقع والحجم:**

```
display{inline-icon, left}           → الزر يسار العنوان
display{inline-icon, top}            → الزر فوق العنوان
display{inline-icon, bottom}         → الزر تحت العنوان، في المنتصف
display{inline-icon, large}          → أيقونة كبيرة (75 بكسل)
display{inline-icon, medium}         → أيقونة متوسطة (50 بكسل)
display{inline-icon, left, large}    → زر كبير على اليسار
```

| Size | Icon height/width |
|------|------------------|
| *(default)* | 25px |
| `medium` | 50px |
| `large` | 75px |

---

### `display{thumbnail-square}` — مصغر خريطة مباشر

يعرض معاينة خريطة مباشرة (Leaflet) مباشرة على السؤال بدلاً من الزر. يعرض المصغر موقع GPS الحالي والنقطة المختارة. يؤدي الضغط على زر التوسيع إلى فتح النافذة المنبثقة الكاملة.

```
display{thumbnail-square}
```

**حجم مصغر مخصص:**

```
display{thumbnail-square-[WxH]}          → بكسل ثابتة
display{thumbnail-square-[400x200]}      → 400 بكسل عرض × 200 بكسل ارتفاع

display{thumbnail-square-[W%xH%]}        → نسبة مئوية من عرض النموذج
display{thumbnail-square-[100%x30%]}     → العرض الكامل × 30% من عرض النموذج
```

## `display{}` مقابل `results{}` — قبل وبعد الالتقاط

تتحكم `display{}` في التخطيط **قبل** أن يلتقط المستخدم الموقع. تتحكم `results{}` في التخطيط **بعد** وجود قيمة. يمكن أن يكون لهما محاذاة مختلفة.

```
display{inline-icon, right} results{left}
```

هذا يعرض الزر على اليمين قبل الالتقاط، ثم ينقله إلى اليسار بمجرد تسجيل نقطة.

### `hide(value)` — إخفاء عرض الإحداثيات

بشكل افتراضي، يتم عرض نص خط العرض/خط الطول/الدقة/الارتفاع الملتقط أسفل الزر. قم بإخفائه باستخدام:

```
results{hide(value)}
display{inline-icon} results{hide(value)}
```

---

## `inputs{}` — أتمتة نظام GPS

### التقاط تلقائي عند التحميل

يسجل موقع GPS تلقائيًا عند تحميل النموذج، دون أن يضغط الباحث على أي شيء.

```
inputs{auto-take}
```

**التقاط تلقائي مشروط** باستخدام تعبير XLSForm:

```
inputs{autotakeGeo(expression(if(${capture_now} = 'yes', true(), false())))}
```

### ملء مسبق من حقل نصي

قم بتعبئة geopoint من سؤال يحتوي على اسم مكان أو سلسلة عنوان. يقوم rtSurvey بترميز السلسلة جغرافياً عكسياً إلى إحداثيات عبر OpenStreetMap Nominatim.

```
inputs{question(address_field)}
```

---

## `outputs{}` — ترميز جغرافي عكسي إلى نص

بعد التقاط نقطة، قم تلقائيًا بتعبئة سؤال `text` بالعنوان المقروء بشريًا (المرمز جغرافيًا عكسيًا من الإحداثيات).

```
outputs{question(address_field)}
```

مثال:

| type | name | label | appearance |
|------|------|-------|------------|
| geopoint | location | تسجيل الموقع | `outputs{question(address_text)}` |
| text | address_text | العنوان | |

---

## `nomap` — التقاط GPS بدون خريطة

يستبدل نافذة الخريطة المنبثقة بحوار بسيط يطلب إذن الموقع ويسجل الإحداثيات. لا يتم عرض خريطة. مفيد لالتقاط GPS فقط على الأجهزة منخفضة المواصفات أو عند عدم توفر مربعات الخريطة دون اتصال بالإنترنت.

```
nomap
```

## أمثلة على الاستخدام

| type | name | label | appearance |
|------|------|-------|------------|
| geopoint | field_loc | تسجيل موقع الحقل | `display{inline-icon, right, large}` |
| geopoint | site | موقع الموقع | `display{thumbnail-square-[100%x30%]}` |
| geopoint | auto_loc | الموقع الحالي | `inputs{auto-take} display{inline-icon} results{hide(value)}` |
| geopoint | mapped_loc | الموقع | `display{inline-icon} outputs{question(address)}` |
| geopoint | gps_only | نقطة GPS | `nomap` |

## أفضل الممارسات

1. استخدم `inputs{auto-take}` لمسوح التحقق التي يقوم بها الباحثون حيث يكون نظام GPS إلزاميًا — فهو يزيل الخطوة اليدوية.
2. استخدم `display{thumbnail-square}` عندما تريد أن يؤكد الباحث بصريًا النقطة المختارة قبل المتابعة.
3. قم بإقران `outputs{question(...)}` بحقل `text` للقراءة فقط لعرض العنوان المرمز جغرافياً عكسياً للباحث.
4. استخدم `nomap` في المناطق التي لا يوجد بها اتصال بالإنترنت حيث لا يمكن تحميل مربعات الخريطة.
5. اسمح لوقت نظام GPS بالاستقرار قبل التسجيل — الدقة الأقل من 10 أمتار كافية عادةً للمسوحات الميدانية.

## القيود (Limitations)

- يتطلب الترميز الجغرافي `inputs{question(name)}` الوصول إلى الإنترنت — فهو يتصل بـ OpenStreetMap Nominatim API.
- يتطلب الترميز الجغرافي العكسي `outputs{question(name)}` أيضًا الوصول إلى الإنترنت.
- يتطلب مصغر الخريطة (`display{thumbnail-square}`) الإنترنت لتحميل المربعات؛ لا تزال الإحداثيات تلتقط دون اتصال بالإنترنت.
- تختلف دقة نظام GPS حسب الجهاز والبيئة — قد تؤدي الظروف الداخلية أو الأخاديد الحضرية إلى دقة أكبر من 50 مترًا.
- قد يؤثر جمع بيانات الموقع بشكل كبير على عمر بطارية الجهاز أثناء المسوح الطويلة.

---

يلتقط نوع السؤال `geopoint` الإحداثيات الجغرافية (خط العرض، خط الطول، الارتفاع، الدقة) باستخدام نظام تحديد المواقع العالمي (GPS) بالجهاز. يعرض rtSurvey أداة الاختيار بعدة أوضاع تخطيط ويدعم الأتمتة من خلال معلمات `inputs{}` و `outputs{}`.

## مواصفات XLSForm الأساسية

| type     | name        | label                       |
|----------|-------------|-----------------------------|
| geopoint | location    | سجل الموقع الحالي |

للاطلاع على المواصفات القياسية، راجع [وثائق XLSForm](https://xlsform.org/en/#question-types).

## تنسيق البيانات

تُخزن كأربع قيم مفصولة بمسافات:

```
latitude longitude altitude accuracy
```

مثال: `13.756331 100.501762 15 8`

---

## أوضاع التخطيط

### الافتراضي — زر مستطيل

يفتح زر مستطيل "بدء النقطة الجغرافية" نموذج خريطة كاملاً حيث يحدد المُعد نقطة. بعد الالتقاط، يتغير تسمية الزر إلى "عرض أو تغيير النقطة الجغرافية" وتظهر الإحداثيات أدناه.

لا تتطلب قيمة للمظهر.

---

### `display{inline-icon}` — زر دائري بشكل متقاطع

يعرض زر أيقونة دائري (متصالب ⊕) بدلاً من الزر المستطيل. يؤدي النقر عليه إلى فتح نفس نموذج الخريطة.

```
display{inline-icon}
```

**مدمج مع الموضع والحجم:**

```
display{inline-icon, left}           → button left of label
display{inline-icon, top}            → button above label
display{inline-icon, bottom}         → button below label, centered
display{inline-icon, large}          → large icon (75px)
display{inline-icon, medium}         → medium icon (50px)
display{inline-icon, left, large}    → large button on the left
```

| Size | Icon height/width |
|------|------------------|
| *(افتراضي)* | 25 بكسل |
| `medium` | 50 بكسل |
| `large` | 75 بكسل |

---

### `display{thumbnail-square}` — صورة مصغرة لخريطة مباشرة

يعرض معاينة خريطة مباشرة (Leaflet) مباشرة على السؤال بدلاً من الزر. تُظهر الصورة المصغرة موقع GPS الحالي والنقطة المختارة. يؤدي النقر على زر التوسيع إلى فتح النموذج الكامل.

```
display{thumbnail-square}
```

**حجم الصورة المصغرة المخصص:**

```
display{thumbnail-square-[WxH]}          → fixed pixels
display{thumbnail-square-[400x200]}      → 400px wide × 200px tall

display{thumbnail-square-[W%xH%]}        → percentage of form width
display{thumbnail-square-[100%x30%]}     → full width × 30% of form width
```

---

## `display{}` vs `results{}` — قبل وبعد الالتقاط

تتحكم `display{}` في التخطيط **قبل** أن يلتقط المستخدم موقعًا. تتحكم `results{}` في التخطيط **بعد** وجود قيمة. يمكن أن يكون لها محاذاة مختلفة.

```
display{inline-icon, right} results{left}
```

يعرض هذا الزر على اليمين قبل الالتقاط، ثم ينقله إلى اليسار بمجرد تسجيل نقطة.

### `hide(value)` — إخفاء عرض الإحداثيات

افتراضيًا، يتم عرض نص خط العرض/خط الطول/الدقة/الارتفاع الملتقط أسفل الزر. إخفائه باستخدام:

```
results{hide(value)}
display{inline-icon} results{hide(value)}
```

## `inputs{}` — أتمتة GPS

### التقاط تلقائي عند التحميل

يسجل موقع GPS تلقائيًا عند تحميل النموذج، دون أن يضغط المُعد على أي شيء.

```
inputs{auto-take}
```

**التقاط تلقائي مشروط** باستخدام تعبير XLSForm:

```
inputs{autotakeGeo(expression(if(${capture_now} = 'yes', true(), false())))}
```

### ملء مسبق من حقل نصي

ملء النقطة الجغرافية من سؤال يحتوي على اسم مكان أو سلسلة عنوان. يقوم rtSurvey بتحويل السلسلة عكسيًا إلى إحداثيات عبر OpenStreetMap Nominatim.

```
inputs{question(address_field)}
```

---

## `outputs{}` — تحويل الإحداثيات إلى نص

بعد التقاط نقطة، قم بملء سؤال `text` تلقائيًا بالعنوان المقروء بشريًا (المحول عكسيًا من الإحداثيات).

```
outputs{question(address_field)}
```

مثال:

| type | name | label | appearance |
|------|------|-------|------------|
| geopoint | location | سجل الموقع | `outputs{question(address_text)}` |
| text | address_text | العنوان | |

---

## `nomap` — التقاط GPS بدون خريطة

يستبدل نموذج الخريطة بمربع حوار بسيط يطلب إذن الموقع ويسجل الإحداثيات. لا يتم عرض أي خريطة. مفيد لالتقاط GPS فقط على الأجهزة منخفضة التكلفة أو عندما تكون مربعات الخريطة غير متوفرة دون اتصال بالإنترنت.

```
nomap
```

## أمثلة الاستخدام

| type | name | label | appearance |
|------|------|-------|------------|
| geopoint | field_loc | سجل موقع الحقل | `display{inline-icon, right, large}` |
| geopoint | site | موقع الموقع | `display{thumbnail-square-[100%x30%]}` |
| geopoint | auto_loc | الموضع الحالي | `inputs{auto-take} display{inline-icon} results{hide(value)}` |
| geopoint | mapped_loc | الموقع | `display{inline-icon} outputs{question(address)}` |
| geopoint | gps_only | نقطة GPS | `nomap` |

## أفضل الممارسات

1. استخدم `inputs{auto-take}` للاستبيانات التي تتطلب تحقق المُعد حيث يكون GPS إلزاميًا — فهو يلغي الخطوة اليدوية.
2. استخدم `display{thumbnail-square}` عندما تريد من المُعد تأكيد النقطة المختارة بصريًا قبل المتابعة.
3. قم بإقران `outputs{question(...)}` بحقل `text` للقراءة فقط لعرض العنوان المعكوس جغرافيًا للمُعد.
4. استخدم `nomap` في المناطق التي لا يوجد بها اتصال بالإنترنت حيث لا يمكن تحميل مربعات الخريطة.
5. اسمح لوقت GPS بالاستقرار قبل التسجيل — عادةً ما تكون الدقة أقل من 10 أمتار كافية للمسوح الميدانية.

## القيود

- يتطلب تحديد الموقع الجغرافي `inputs{question(name)}` الوصول إلى الإنترنت — فهو يستدعي واجهة برمجة تطبيقات OpenStreetMap Nominatim.
- يتطلب تحويل الإحداثيات إلى نص `outputs{question(name)}` الوصول إلى الإنترنت أيضًا.
- تتطلب الصورة المصغرة للخريطة (`display{thumbnail-square}`) الإنترنت لتحميل المربعات؛ لا تزال الإحداثيات تُسجل دون اتصال بالإنترنت.
- تختلف دقة GPS حسب الجهاز والبيئة — قد تؤدي الظروف الداخلية أو الوديان الحضرية إلى دقة > 50 مترًا.
- قد يؤثر جمع بيانات الموقع بشكل كبير على عمر بطارية الجهاز أثناء الاستبيانات الطويلة.

يجمع نوع السؤال `text` سلسلة نصية حرة. وهو أكثر أنواع الإدخال مرونة ويدعم عدداً كبيراً من متغيرات المظهر التي تغير كيفية عرض الإدخال — من حقل بسيط سطر واحد إلى تحويل الكلام إلى نص، ونوافذ منبثقة، ومحررات نصوص غنية، وأشرطة تمرير رقمية.

## مواصفات XLSForm الأساسية

| type | name | label |
|------|------|-------|
| text | respondent_name | الاسم الكامل للمستجيب |
| text | address | عنوان السكن |

للاطلاع على المواصفات القياسية، راجع [وثائق XLSForm](https://xlsform.org/en/#question-types).

---

## أنماط التخطيط (Layout modes)

### الافتراضي — إدخال سطر واحد

لا يلزم مظهر خاص. يعرض حقل `<input type="text">` قياسي.

---

### `multiline` — منطقة نص

يعرض منطقة نص متعددة الأسطر. يمكن للمستخدم توسيعها عن طريق الكتابة؛ حيث تنمو تلقائياً.

```
multiline
```

**التحكم في ارتفاع الأسطر** بإضافة `[initRows, maxRows]`:

```
multiline [3,8]     → يبدأ بـ 3 أسطر، ويتوسع حتى 8
multiline [5]       → ثابت عند 5 أسطر
```

الافتراضي هو سطر واحد بدون حد أقصى. يقوم Shift+Enter بإدراج فاصل سطر؛ بينما ينتقل Enter إلى السؤال التالي.

---

### `floating_hint` — التلميح يطفو كعنوان

يتم عرض نص `hint` داخل حقل الإدخال كـ placeholder. عندما يبدأ المستخدم في الكتابة، يطفو التلميح للأعلى فوق الحقل كعنوان.

```
floating_hint
```

---

### `embed` — التلميح داخل الإدخال

مشابه لـ `floating_hint` — يتم عرض التلميح داخل حدود الإدخال عندما يكون الحقل فارغاً. لا يطفو عند الكتابة.

```
embed
```

---

### `textpopup` — إدخال عبر نافذة مشروطة

يفتح الضغط على الحقل نافذة مشروطة (SweetAlert) مع إدخال كبير بدلاً من التحرير في نفس السطر. مفيد على الهاتف المحمول لإعطاء مساحة شاشة أكبر للكتابة.

```
textpopup
```

---

### `richtext` — محرر WYSIWYG

يعرض محرر نصوص غنية كاملاً (Monaco / Draft.js). يمكن للمستجيب جعل النص عريضاً، مائلاً، إضافة قوائم، إلخ. القيمة المخزنة هي HTML.

```
richtext
richtext(30%)       → ارتفاع المحرر 30% من مساحة العرض
```

---

### `charcount` — عداد أحرف مباشر

يضيف عرض عداد أحرف `(n)` أسفل الإدخال، يتم تحديثه أثناء كتابة المستخدم.

```
charcount
multiline charcount
```

---

## متغيرات الإدخال الرقمي

تعمل هذه المظاهر على نوع `text` لجمع الأرقام بتنسيقات خاصة أو أنماط تفاعل.

### `numbers` — لوحة مفاتيح رقمية

يفرض نوع إدخال HTML ليكون `number` مما يفعل لوحة مفاتيح رقمية على الهاتف المحمول.

```
numbers
```

### `thousandsep` — فاصل الآلاف

يعرض الرقم مع تجميع الفواصل (مثل `1,234,567`) مع تخزين الرقم الخام. يتم فرض نوع الإدخال ليكون `text` للسماح بعرض الفواصل.

```
thousandsep
```

### `digisep(n, "sep")` — تجميع أرقام مخصص

يجمع الأرقام في كتل من `n` مفصولة بفاصل مخصص. مفيد لأرقام الهواتف، أرقام الهوية، إلخ.

```
digisep(4,"-")      → 0912-3456-789
digisep(3," ")      → 012 345 678
```

### `number-hspinner` — شريط تمرير أفقي

يستبدل الإدخال بشريط تمرير أفقي **− القيمة +**. يقوم المستخدم بالضغط على أزرار الناقص/الزائد لإنقاص أو زيادة القيمة. يعمل مع أنواع `int` و `decimal`.

```
number-hspinner
```

**تخصيص مظهر الزر** باستخدام `hspinner()`:

```
number-hspinner hspinner('left-small-square','right-small-square','1')
```

المعلمات: شكل الزر الأيسر، شكل الزر الأيمن، قيمة الخطوة.

**ألوان مخصصة** باستخدام `colors()`:

```
number-hspinner colors(0099FF,FFFFFF,FF5500,FFFFFF)
```

أربع قيم ألوان: خلفية-اليسار، أيقونة-اليسار، خلفية-اليمين، أيقونة-اليمين.

### `prefix(expr)` — إضافة بادئة

يضيف سلسلة نصية محسوبة أو ثابتة قبل القيمة المعروضة. لا تتضمن القيمة المخزنة البادئة.

```
prefix('USD ')      → displays "USD 100", stores "100"
prefix(${currency}) → dynamic prefix from another field
```

### `textonly` — فرض نوع إدخال نصي

يفرض `type="text"` حتى عندما يكون الحقل `integer` أو `decimal`. مفيد لتجنب تقلبات إدخال الأرقام في المتصفح.

```
textonly
```

## تحويل النص (Text transformation)

تقوم هذه المظاهر بتحويل القيمة تلقائياً أثناء كتابة المستخدم.

| Appearance | Effect | Example input → stored |
|---|---|---|
| `upper` | يحول إلى أحرف كبيرة | `hello` → `HELLO` |
| `lower` | يحول إلى أحرف صغيرة | `HELLO` → `hello` |
| `proper` | يحول إلى حالة الأحرف الأولى الكبيرة | `john doe` → `John Doe` |

## مساعدات التقاط الإدخال

### `inputs{stt}` — تحويل الكلام إلى نص

يضيف زر ميكروفون بجوار الإدخال. يؤدي الضغط عليه إلى بدء التعرف على الكلام في المتصفح (Web Speech API). يتم إلحاق النص المنسوخ بالحقل.

```
inputs{stt}
```

غير مدعوم على Safari. يتطلب إذن الميكروفون.

### `inputs{qrscan}` — ماسح QR / باركود

يضيف زر مسح رمز QR بجوار الإدخال. يفتح نافذة ماسح الكاميرا ويملأ الحقل بالقيمة الممسوحة ضوئيًا.

```
inputs{qrscan}
```

**الترميز (Tokenize)** (إلحاق القيم الممسوحة بدلاً من استبدالها):

```
inputs{qrscan} append(${separator})
```

### `inputs{stt,qrscan}` — كلام ومسح معاً

يعرض كلا زري الميكروفون ومسح QR جنباً إلى جنب.

```
inputs{stt,qrscan}
inputs{qrscan,stt}
```

## المتغيرات المرتبطة بالاختيار (Selection-linked variants)

تربط هذه المظاهر حقلاً نصياً بقائمة خيارات `select_one` مما يتيح للمستخدم إما الاختيار من القائمة أو الكتابة بحرية.

### `selection_one_hide` — منتقي القائمة المنسدلة

يعرض الإدخال النصي مع سهم منسدل. يظهر الضغط على السهم الخيارات من قائمة `search()` المرتبطة. اختيار خيار يملأ الإدخال ويقفله (يظهر ✕ للمسح).

```
selection_one_hide
```

### `selection_one_show` — قائمة راديو بالأسفل

يعرض الإدخال النصي مع أزرار راديو أسفله. اختيار زر راديو يملأ الإدخال ويقفله.

```
selection_one_show
```

كلا المتغيرين يتطلبان تعبير `search()` في عمود `calculation` لتعريف قائمة الخيارات.

## محاذاة الإجابة

يتحكم في المحاذاة الأفقية للنص المكتوب داخل الإدخال.

```
align_answer = left
align_answer = right
align_answer = center
```

## أداة إدخال الوقت (ساعة مدمجة)

يوسع rtSurvey نوع `text` بأداة منتقي الساعة. تعرض هذه المظاهر أيقونة ساعة يضغط عليها جامع البيانات لاختيار قيمة الوقت. يتم تخزين القيمة كنص عادي بالتنسيق المختار.

### المظاهر (Appearances)

| Appearance | Description |
|---|---|
| `inline` | زر أيقونة ساعة بجوار الحقل، يفتح نافذة مشروطة |
| `inline-onlyresult` | تختفي أيقونة الساعة بعد الاختيار |
| `inline-1line` | شريط تمرير وقت مدمج سطر واحد |
| `inline colors("RRGGBB")` | أيقونة ساعة بلون مخصص |
| `inline-1line colors("RRGGBB","RRGGBB")` | شريط تمرير بلونين مميزين |

### رموز التنسيق (Format tokens)

ألحق `-[format]` للتحكم في مكونات الوقت التي يتم عرضها وتخزينها:

| Format | Displays |
|---|---|
| `inline-[%H:%M]` | ساعات : دقائق (24 ساعة) |
| `inline-[%h:%M]` | ساعات : دقائق (12 ساعة) |
| `inline-[%H:%M:%S]` | ساعات : دقائق : ثواني (24 ساعة) |
| `inline-[%M:%S]` | دقائق : ثواني |
| `inline-[%H:%M:%3]` | ساعات : دقائق : أجزاء من الثانية |
| `inline-[%S]` | ثواني فقط |
| `inline-[%3]` | أجزاء من الثانية فقط |
| `inline-[%H]` | ساعات فقط (24 ساعة) |

### موقع الزر مع `display{}`

نفس أنواع "inline" الأخرى — يتحكم في موقع وحجم زر الساعة:

```
inline display{right}
inline display{center, large}
inline-onlyresult display{left, medium, #0099FF}
```

## القيود والتحقق من الصحة (Constraints and validation)

طبق القيود لفرض التنسيق أو الطول أو النمط:

| type | name | label | constraint | constraint_message |
|------|------|-------|------------|-------------------|
| text | name | الاسم الكامل | `string-length(.) >= 2` | يلزم وجود حرفين على الأقل |
| text | code | الكود المرجعي | `regex(., '^[A-Z]{2}[0-9]{4}$')` | حرفان كبيران + 4 أرقام |
| text | phone | رقم الهاتف | `regex(., '^[0-9]{9,15}$')` | أدخل رقم هاتف صحيح |

## أفضل الممارسات

1. استخدم أنواعاً أكثر تحديداً (`integer` ، `decimal` ، `date`) عندما يكون للبيانات هيكل معروف — فهذا يمنع الإدخالات غير الصالحة.
2. استخدم `multiline [3,8]` للأسئلة المفتوحة لمنح المستجيبين مساحة للكتابة دون إثقال الشاشة.
3. استخدم `thousandsep` أو `digisep()` بدلاً من `numbers` عندما تحتاج إلى عرض منسق — فـ `numbers` وحدها تغير لوحة المفاتيح فقط.
4. استخدم `inputs{qrscan}` للتخلص من أخطاء الكتابة اليدوية للأكواد، والمعرفات، والأرقام التسلسلية.
5. استخدم `floating_hint` عندما يكون التلميح سياقاً مهماً يجب أن يظل مرئياً أثناء الكتابة — التلميحات القياسية تختفي من العرض على الشاشات الصغيرة.
6. استخدم `charcount` في الأسئلة ذات قيود الطول حتى يتمكن المستجيبون من مراقبة أنفسهم.

## القيود (Limitations)

- يتطلب `inputs{stt}` متصفحاً يدعم Web Speech API. يعد Chrome الأكثر موثوقية؛ Safari غير مدعوم.
- يقوم `richtext` بتخزين HTML — خطط لتجريد أو تعقيم HTML في خط معالجة التحليل إذا كان من المتوقع الحصول على نص عادي.
- يتطلب `selection_one_hide` و `selection_one_show` تعبير `search()` وهما مدعومان فقط في عميل الويب.
- يتحقق `number-hspinner` من صحة عمود `constraint` عند كل ضغطة زر، وليس فقط عند فقدان التركيز (blur) — صمم القيود وفقاً لذلك.

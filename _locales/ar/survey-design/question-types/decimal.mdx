يلتقط نوع السؤال `decimal` الأرقام التي قد تتضمن جزءًا كسريًا (مثل `3.14`، `72.5`). يقوم بتشغيل لوحة مفاتيح رقمية على الهاتف المحمول ويدعم نفس خيارات المظهر مثل نوع `text` للتخطيط والتنسيق.

## مواصفات XLSForm الأساسية

| type | name | label |
|------|------|-------|
| decimal | weight_kg | الوزن (كجم) |
| decimal | height_m | الطول (م) |
| decimal | temperature | درجة حرارة الجسم (درجة مئوية) |

للاطلاع على المواصفات القياسية، راجع [وثائق XLSForm](https://xlsform.org/en/#question-types).

---

## خيارات المظهر

### `number-hspinner` — أداة تدوير أفقية

يستبدل الإدخال بأداة تدوير أفقية **− قيمة +**. يؤدي النقر على علامة الطرح/الجمع إلى ضبط القيمة بالخطوة المكونة.

```
number-hspinner
```

يتم تنسيق القيمة المعروضة بفاصلة عشرية واحدة (على سبيل المثال `3.0`، `72.5`). الخطوة الافتراضية هي `1`؛ استخدم `hspinner()` لتعيين خطوة عشرية.

**تخصيص شكل الزر والخطوة** باستخدام `hspinner()`:

```
number-hspinner hspinner('left-small-square','right-small-square','0.1')
```

المعلمات: شكل الزر الأيسر، شكل الزر الأيمن، قيمة الخطوة. استخدم خطوة عشرية مثل `0.5` أو `0.1` للتحكم الدقيق.

**ألوان مخصصة** باستخدام `colors()`:

```
number-hspinner colors(0099FF,FFFFFF,FF5500,FFFFFF)
```

أربع قيم بالترتيب: خلفية الزر الأيسر، أيقونة الزر الأيسر، خلفية الزر الأيمن، أيقونة الزر الأيمن.

---

### `thousandsep` — فاصل الآلاف

ينسق الرقم المعروض بتجميع الفواصل (مثل `1,234.56`). يتم تخزين الرقم الخام بدون فواصل. يتم تبديل نوع الإدخال إلى `"text"` للسماح بالعرض المنسق.

```
thousandsep
```

---

### `digisep(n, "sep")` — تجميع الأرقام المخصص

يجمع أرقام الجزء الصحيح في كتل من `n` مفصولة بفاصل مخصص.

```
digisep(3," ")      → 1 234 567.89
```

يتم تبديل نوع الإدخال إلى `"text"` عندما يكون هذا المظهر نشطًا.

---

### `textonly` — فرض لوحة المفاتيح النصية

يفرض `type="text"` على عنصر الإدخال. يمنع مشاكل إدخال الأرقام في المتصفح (إخفاء الأصفار الزائدة، أسهم التدوير لسطح المكتب) مع الاستمرار في قبول القيم العشرية.

```
textonly
```

---

### `floating_hint` — تلميح يطفو كتسمية

يظهر نص `hint` داخل الإدخال كعنصر نائب. عندما يبدأ المستخدم في الكتابة، يطفو فوق الحقل كتسمية.

```
floating_hint
```

---

### `embed` — تلميح داخل حدود الإدخال

مشابه لـ `floating_hint` — يجلس التلميح داخل حدود الإدخال عندما يكون فارغًا. لا يطفو عندما يكتب المستخدم.

```
embed
```

---

### `textpopup` — إدخال مربع حوار منبثق

يؤدي النقر على الحقل إلى فتح مربع حوار منبثق بإدخال أكبر. مفيد على الشاشات الصغيرة.

```
textpopup
```

---

### `charcount` — عداد الأحرف المباشر

يعرض عدد الأحرف المباشر `(n)` أسفل الإدخال، يتم تحديثه أثناء كتابة المستخدم.

```
charcount
```

---

### `prefix(expr)` — إضافة بادئة

يضيف سلسلة ثابتة أو محسوبة إلى القيمة المعروضة. القيمة المخزنة لا تتضمن البادئة.

```
prefix('USD ')          → displays "USD 72.50", stores "72.50"
prefix(${currency})     → dynamic prefix from another field
```

---

### `align_answer` — محاذاة نص الإدخال

يتحكم في المحاذاة الأفقية للقيمة المكتوبة داخل الإدخال.

```
align_answer = left
align_answer = right
align_answer = center
```

---

### `inputs{qrscan}` — مسح QR / باركود إلى الحقل

يضيف زر مسح رمز QR بجانب الإدخال. يفتح ماسح الكاميرا ويملأ الحقل بالقيمة الممسوحة ضوئيًا.

```
inputs{qrscan}
```

## القيود والتحقق من الصحة

| type | name | label | constraint | constraint_message |
|------|------|-------|------------|-------------------|
| decimal | weight | الوزن (كجم) | `. > 0 and . <= 500` | أدخل قيمة بين 0 و 500 |
| decimal | height | الطول (م) | `. > 0 and . <= 3` | أدخل قيمة بين 0 و 3 |
| decimal | temp | درجة الحرارة (درجة مئوية) | `. >= 35 and . <= 42` | درجة حرارة عادية: 35 درجة مئوية - 42 درجة مئوية |
| decimal | percentage | النسبة المئوية | `. >= 0 and . <= 100` | أدخل قيمة بين 0 و 100 |

## مثال — نموذج القياس

| type | name | label | appearance | constraint | constraint_message |
|------|------|-------|------------|------------|-------------------|
| decimal | weight_kg | الوزن (كجم) | `number-hspinner hspinner('left-small-square','right-small-square','0.5')` | `. > 0 and . <= 300` | أدخل وزنًا صالحًا |
| decimal | height_m | الطول (م) | `number-hspinner hspinner('left-small-square','right-small-square','0.01')` | `. > 0 and . <= 3` | أدخل طولًا صالحًا |
| calculate | bmi | | | | |

عمود حساب مؤشر كتلة الجسم:
```
${weight_kg} div (${height_m} * ${height_m})
```

## أفضل الممارسات

1. استخدم `number-hspinner hspinner(..., '0.1')` للقياسات التي تتطلب دقة منزلة عشرية واحدة — تقوم أداة التدوير بالتنسيق التلقائي إلى منزلة عشرية واحدة، مما يحافظ على اتساق القيم.
2. استخدم `textonly` عندما تضيف المتصفحات عناصر تحكم دوارة غير مرغوب فيها أو تقطع الأصفار الزائدة (مثل `3.0` المعروضة كـ `3`).
3. استخدم `thousandsep` للقيم المالية الكبيرة حتى يتمكن المستجيبون من التحقق من إدخالهم المقدار الصحيح.
4. فرض قيود النطاق بدلاً من الاعتماد على نوع لوحة المفاتيح المحمولة فقط.

## القيود

- تعرض أداة التدوير دائمًا منزلة عشرية واحدة — إذا كنت بحاجة إلى مزيد من الدقة في القيمة المعروضة، فاستخدم الإدخال العادي بدلاً من ذلك.
- `thousandsep` و `digisep()` يخزنان الرقم الخام — لا تقرأ قيمة العرض المنسقة في العمليات الحسابية.

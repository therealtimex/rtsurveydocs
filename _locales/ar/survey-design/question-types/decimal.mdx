يجمع نوع السؤال `decimal` الأرقام التي قد تتضمن جزءًا كسريًا (مثل `3.14` و `72.5`). وهو يقوم بتفعيل لوحة مفاتيح رقمية على الهاتف المحمول ويدعم نفس خيارات المظهر (appearance) مثل نوع `text` للتخطيط والتنسيق.

## مواصفات XLSForm الأساسية

| type | name | label |
|------|------|-------|
| decimal | weight_kg | الوزن (كجم) |
| decimal | height_m | الطول (متر) |
| decimal | temperature | درجة حرارة الجسم (درجة مئوية) |

للاطلاع على المواصفات القياسية، راجع [وثائق XLSForm](https://xlsform.org/en/#question-types).

---

## خيارات المظهر (Appearance options)

### `number-hspinner` — شريط تمرير أفقي

يستبدل الإدخال بشريط تمرير أفقي **− القيمة +**. يؤدي الضغط على ناقص/زائد إلى تعديل القيمة حسب الخطوة (step) المكونة.

```
number-hspinner
```

يتم تنسيق القيمة المعروضة بمنزلة عشرية واحدة (مثل `3.0` و `72.5`). الخطوة الافتراضية هي `1`؛ استخدم `hspinner()` لضبط خطوة عشرية.

**تخصيص شكل الزر والخطوة** باستخدام `hspinner()`:

```
number-hspinner hspinner('left-small-square','right-small-square','0.1')
```

المعلمات: شكل الزر الأيسر، شكل الزر الأيمن، قيمة الخطوة. استخدم خطوة عشرية مثل `0.5` أو `0.1` للتحكم الدقيق.

**ألوان مخصصة** باستخدام `colors()`:

```
number-hspinner colors(0099FF,FFFFFF,FF5500,FFFFFF)
```

أربع قيم بالترتيب: خلفية الزر الأيسر، أيقونة الزر الأيسر، خلفية الزر الأيمن، أيقونة الزر الأيمن.

---

### `thousandsep` — فاصل الآلاف

ينسق الرقم المعروض مع تجميع الفواصل (مثل `1,234.56`). يتم تخزين الرقم الخام بدون فواصل. يتم تبديل نوع الإدخال إلى `"text"` للسماح بالعرض المنسق.

```
thousandsep
```

---

### `digisep(n, "sep")` — تجميع أرقام مخصص

يجمع أرقام الجزء الصحيح في كتل من `n` مفصولة بفاصل مخصص.

```
digisep(3," ")      → 1 234 567.89
```

يتم تبديل نوع الإدخال إلى `"text"` عندما يكون هذا المظهر نشطًا.

---

### `textonly` — فرض لوحة مفاتيح نصية

يفرض `type="text"` على عنصر الإدخال. يمنع تقلبات إدخال الأرقام في المتصفح (إخفاء الأصفار اللاحقة، أسهم التمرير على سطح المكتب) مع الاستمرار في قبول القيم العشرية.

```
textonly
```

---

### `floating_hint` — التلميح يطفو كعنوان

يتم عرض نص `hint` داخل الإدخال كـ placeholder. عندما يبدأ المستخدم في الكتابة، يطفو فوق الحقل كعنوان (label).

```
floating_hint
```

---

### `embed` — التلميح داخل حدود الإدخال

مشابه لـ `floating_hint` — يستقر التلميح داخل حدود الإدخال عندما يكون فارغًا. لا يطفو عندما يكتب المستخدم.

```
embed
```

---

### `textpopup` — إدخال عبر نافذة مشروطة

يفتح الضغط على الحقل نافذة مشروطة (modal dialog) مع إدخال أكبر. مفيد على الشاشات الصغيرة.

```
textpopup
```

---

### `charcount` — عداد أحرف مباشر

يعرض عداد أحرف مباشر `(n)` أسفل الإدخال، يتم تحديثه أثناء كتابة المستخدم.

```
charcount
```

---

### `prefix(expr)` — إضافة بادئة

يضيف سلسلة نصية ثابتة أو محسوبة قبل القيمة المعروضة. لا تتضمن القيمة المخزنة البادئة.

```
prefix('USD ')          → displays "USD 72.50", stores "72.50"
prefix(${currency})     → dynamic prefix from another field
```

---

### `align_answer` — محاذاة نص الإدخال

يتحكم في المحاذاة الأفقية للقيمة المكتوبة داخل الإدخال.

```
align_answer = left
align_answer = right
align_answer = center
```

---

### `inputs{qrscan}` — مسح QR / باركود داخل الحقل

يضيف زر مسح رمز QR بجوار الإدخال. يفتح ماسح الكاميرا ويملأ الحقل بالقيمة الممسوحة ضوئيًا.

```
inputs{qrscan}
```

## القيود والتحقق من الصحة (Constraints and validation)

| type | name | label | constraint | constraint_message |
|------|------|-------|------------|-------------------|
| decimal | weight | الوزن (كجم) | `. > 0 and . <= 500` | أدخل قيمة بين 0 و 500 |
| decimal | height | الطول (متر) | `. > 0 and . <= 3` | أدخل قيمة بين 0 و 3 |
| decimal | temp | درجة الحرارة (درجة مئوية) | `. >= 35 and . <= 42` | درجة الحرارة الطبيعية: 35 درجة مئوية - 42 درجة مئوية |
| decimal | percentage | النسبة المئوية | `. >= 0 and . <= 100` | أدخل قيمة بين 0 و 100 |

| type | name | label | appearance | constraint | constraint_message |
|------|------|-------|------------|------------|-------------------|

```
${weight_kg} div (${height_m} * ${height_m})
```

## أفضل الممارسات

1. استخدم `number-hspinner hspinner(..., '0.1')` للقياسات التي تتطلب دقة منزلة عشرية واحدة — يقوم شريط التمرير بتنسيق تلقائي لمنزلة عشرية واحدة، مما يحافظ على اتساق القيم.
2. استخدم `textonly` عندما تضيف المتصفحات عناصر تحكم في التمرير غير مرغوب فيها أو تقتطع الأصفار اللاحقة (مثل عرض `3.0` كـ `3`).
3. استخدم `thousandsep` للقيم المالية الكبيرة حتى يتمكن المستجيبون من التحقق من أنهم أدخلوا المقدار الصحيح.
4. فرض قيود النطاق بدلاً من الاعتماد على نوع لوحة مفاتيح الهاتف المحمول وحدها.

## القيود (Limitations)

- يعرض شريط التمرير دائمًا منزلة عشرية واحدة — إذا كنت بحاجة إلى مزيد من الدقة في القيمة المعروضة، فاستخدم الإدخال العادي بدلاً من ذلك.
- تقوم `thousandsep` و `digisep()` بتخزين الرقم الخام — لا تقرأ قيمة العرض المنسقة في الحسابات.

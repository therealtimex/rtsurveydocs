يلتقط نوع السؤال `decimal` الأرقام التي قد تتضمن جزءًا كسريًا (على سبيل المثال `3.14`، `72.5`). يؤدي إلى ظهور لوحة مفاتيح رقمية على الهاتف المحمول ويدعم نفس خيارات المظهر مثل نوع `text` للتخطيط والتنسيق.

## مواصفات XLSForm الأساسية

| type | name | label |
|------|------|-------|
| decimal | weight_kg | الوزن (كجم) |
| decimal | height_m | الطول (م) |
| decimal | temperature | درجة حرارة الجسم (مئوية) |

للحصول على المواصفات القياسية، راجع [وثائق XLSForm](https://xlsform.org/en/#question-types).

---

## خيارات المظهر

### `number-hspinner` - دوار أفقي

يستبدل الإدخال بدوار أفقي **− قيمة +**. يؤدي النقر على علامة ناقص/زائد إلى ضبط القيمة بالخطوة المكونة.

```
number-hspinner
```

يتم تنسيق القيمة المعروضة بمنزلة عشرية واحدة (على سبيل المثال `3.0`، `72.5`). الخطوة الافتراضية هي `1`؛ استخدم `hspinner()` لتعيين خطوة عشرية.

**تخصيص شكل الزر والخطوة** باستخدام `hspinner()`:

```
number-hspinner hspinner('left-small-square','right-small-square','0.1')
```

المعلمات: شكل الزر الأيسر، شكل الزر الأيمن، قيمة الخطوة. استخدم خطوة عشرية مثل `0.5` أو `0.1` للتحكم الدقيق.

**ألوان مخصصة** باستخدام `colors()`:

```
number-hspinner colors(0099FF,FFFFFF,FF5500,FFFFFF)
```

أربع قيم بالترتيب: خلفية الزر الأيسر، أيقونة الزر الأيسر، خلفية الزر الأيمن، أيقونة الزر الأيمن.

---

### `thousandsep` - فاصل الآلاف

ينسق الرقم المعروض مع تجميع الفواصل (على سبيل المثال `1,234.56`). يتم تخزين الرقم الخام بدون فواصل. يتم تبديل نوع الإدخال إلى `"text"` للسماح بالعرض المنسق.

```
thousandsep
```

---

### `digisep(n, "sep")` - تجميع مخصص للأرقام

يجمع أرقام الجزء الصحيح في كتل من `n` مفصولة بفاصل مخصص.

```
digisep(3," ")      → 1 234 567.89
```

يتم تبديل نوع الإدخال إلى `"text"` عندما يكون هذا المظهر نشطًا.

---

### `textonly` - فرض لوحة مفاتيح نصية

يفرض `type="text"` على عنصر الإدخال. يمنع تقلبات إدخال الأرقام في المتصفح (إخفاء الأصفار الزائدة، أسهم التدوير على سطح المكتب) مع الاستمرار في قبول القيم العشرية.

```
textonly
```

---

### `floating_hint` - تلميح يطفو كتسمية

يتم عرض نص `hint` داخل الإدخال كعنصر نائب. عندما يبدأ المستخدم في الكتابة، يطفو فوق الحقل كتسمية.

```
floating_hint
```

---

### `embed` - تلميح داخل حدود الإدخال

يشبه `floating_hint` - يجلس التلميح داخل حدود الإدخال عندما يكون فارغًا. لا يطفو عندما يكتب المستخدم.

```
embed
```

---

### `textpopup` - إدخال مربع حوار منبثق

يؤدي النقر على الحقل إلى فتح مربع حوار منبثق بإدخال أكبر. مفيد على الشاشات الصغيرة.

```
textpopup
```

---

### `charcount` - عداد الأحرف المباشر

يعرض عداد أحرف مباشر `(n)` أسفل الإدخال، يتم تحديثه أثناء كتابة المستخدم.

```
charcount
```

---

### `prefix(expr)` - إضافة بادئة

يضيف سلسلة ثابتة أو محسوبة إلى القيمة المعروضة. لا تتضمن القيمة المخزنة البادئة.

```
prefix('USD ')          → يعرض "USD 72.50"، ويخزن "72.50"
prefix(${currency})     → بادئة ديناميكية من حقل آخر
```

---

### `align_answer` - محاذاة نص الإدخال

يتحكم في المحاذاة الأفقية للقيمة المكتوبة داخل الإدخال.

```
align_answer = left
align_answer = right
align_answer = center
```

---

### `inputs{qrscan}` - مسح QR / باركود في الحقل

يضيف زر مسح رمز QR بجوار الإدخال. يفتح ماسح الكاميرا ويملأ الحقل بالقيمة الممسوحة.

```
inputs{qrscan}
```

## القيود والتحقق من الصحة

| type | name | label | constraint | constraint_message |
|------|------|-------|------------|-------------------|
| decimal | weight | الوزن (كجم) | `. > 0 and . <= 500` | أدخل قيمة بين 0 و 500 |
| decimal | height | الطول (م) | `. > 0 and . <= 3` | أدخل قيمة بين 0 و 3 |
| decimal | temperature | درجة الحرارة (مئوية) | `. >= 35 and . <= 42` | درجة الحرارة العادية: 35 درجة مئوية - 42 درجة مئوية |
| decimal | percentage | النسبة المئوية | `. >= 0 and . <= 100` | أدخل قيمة بين 0 و 100 |

## مثال - نموذج القياس

| type | name | label | appearance | constraint | constraint_message |
|------|------|-------|------------|------------|-------------------|
| decimal | weight_kg | الوزن (كجم) | `number-hspinner hspinner('left-small-square','right-small-square','0.5')` | `. > 0 and . <= 300` | أدخل وزنًا صحيحًا |
| decimal | height_m | الطول (م) | `number-hspinner hspinner('left-small-square','right-small-square','0.01')` | `. > 0 and . <= 3` | أدخل طولًا صحيحًا |
| calculate | bmi | | | | |

عمود حساب مؤشر كتلة الجسم:
```
${weight_kg} div (${height_m} * ${height_m})
```

## أفضل الممارسات

1. استخدم `number-hspinner hspinner(..., '0.1')` للقياسات التي تتطلب دقة عشرية واحدة - يقوم الدوار بالتنسيق التلقائي إلى منزلة عشرية واحدة، مما يحافظ على اتساق القيم.
2. استخدم `textonly` عندما تضيف المتصفحات عناصر تحكم دوران غير مرغوبة أو تقطع الأصفار الزائدة (على سبيل المثال `3.0` معروضًا كـ `3`).
3. استخدم `thousandsep` للقيم المالية الكبيرة حتى يتمكن المستجيبون من التحقق من أنهم أدخلوا الحجم الصحيح.
4. فرض قيود النطاق بدلاً من الاعتماد على نوع لوحة المفاتيح المحمولة وحدها.

## القيود

- يعرض الدوار دائمًا منزلة عشرية واحدة - إذا كنت بحاجة إلى مزيد من الدقة في القيمة المعروضة، فاستخدم الإدخال العادي بدلاً من ذلك.
- يخزن `thousandsep` و `digisep()` الرقم الخام - لا تقرأ قيمة العرض المنسقة في العمليات الحسابية.

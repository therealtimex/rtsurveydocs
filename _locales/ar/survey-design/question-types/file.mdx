يتيح نوع سؤال `file` للمستجيبين **تحميل أي ملف** من أجهزتهم — مستندات وجداول بيانات وملفات PDF وأنواع أخرى. بخلاف `image` و`audio` و`video` التي تُطلق أدوات التقاط محددة، يفتح `file` أداة اختيار ملفات للأغراض العامة.

## مواصفة XLSForm الأساسية

| type | name      | label                        |
|------|-----------|------------------------------|
| file | document  | Please upload your document  |

## الاستخدامات

تُستخدم أسئلة الملفات شائعاً لـ:

1. جمع المستندات الداعمة (إيصالات، شهادات، عقود، تقارير)
2. تحميل النماذج الورقية المكتملة التي تم مسحها ضوئياً
3. جمع جداول البيانات أو صادرات البيانات من أنظمة أخرى
4. أي نوع ملف رقمي لا يغطيه image/audio/video

## امتدادات rtSurvey

### أنواع الملفات المقبولة

استخدم عمود `parameters` لتقييد أنواع الملفات القابلة للتحديد:

| type | name | label | parameters |
|------|------|-------|------------|
| file | report | Upload the inspection report | `accept=.pdf` |
| file | spreadsheet | Upload the data file | `accept=.xlsx,.csv` |

## أفضل الممارسات

1. استخدم `accept` لتقييد أنواع الملفات — يمنع هذا المعدِّدين من تحميل ملفات خاطئة عن طريق الخطأ.
2. أدرج دائماً إرشادات الحجم والتنسيق في عمود `hint`.
3. للصور، استخدم نوع `image` بدلاً منه — يوفر ضغطاً أفضل ومعالجة تنسيق متسقة.

## القيود

- لا تتحقق أسئلة الملفات من محتويات الملفات — يتم تطبيق التحقق من امتداد الملف فقط عبر `accept` على مستوى واجهة المستخدم.
- قد تنتهي مهلة تحميل الملفات الكبيرة جداً (100 ميغابايت+) في البيئات ذات الاتصال المنخفض.

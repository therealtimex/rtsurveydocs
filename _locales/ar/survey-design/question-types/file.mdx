يتيح نوع السؤال `file` للمستجيبين **تحميل أي ملف** من أجهزتهم — مستندات، جداول بيانات، ملفات PDF، أو أنواع ملفات أخرى. على عكس `image` و `audio` و `video` التي تطلق أدوات التقاط محددة، يفتح `file` أداة اختيار ملفات للأغراض العامة.

## مواصفات XLSForm الأساسية

| type | name      | label                        |
|------|-----------|------------------------------|
| file | document  | يرجى تحميل مستندك  |

لمزيد من التفاصيل حول نوع سؤال الملف القياسي، راجع [مواصفات XLSForm](https://xlsform.org/en/#question-types).

## الاستخدامات

تُستخدم أسئلة الملف بشكل شائع من أجل:

1. جمع المستندات الداعمة (الإيصالات، الشهادات، العقود، التقارير)
2. تحميل النماذج الورقية المكتملة التي تم مسحها ضوئيًا
3. جمع جداول البيانات أو صادرات البيانات من أنظمة أخرى
4. أي نوع ملف رقمي لا تغطيه الصور/الصوت/الفيديو

## تنسيق البيانات

يتم تخزين الملفات المحملة كمرفقات ثنائية:

- **التنسيق:** يتم الحفاظ عليه في التنسيق الأصلي (PDF، XLSX، DOCX، إلخ.)
- **التسمية:** `{instanceID}-{fieldname}.{extension}`
- **التخزين:** يتم تحميلها إلى مجلد وسائط الخادم جنبًا إلى جنب مع الإرسال
- **الوصول:** يمكن تنزيلها من واجهة إدارة الإرسال

## امتدادات rtSurvey

### أنواع الملفات المقبولة

استخدم عمود `parameters` لتقييد أنواع الملفات التي يمكن تحديدها:

| type | name | label | parameters |
|------|------|-------|------------|
| file | report | تحميل تقرير الفحص | `accept=.pdf` |
| file | spreadsheet | تحميل ملف البيانات | `accept=.xlsx,.csv` |

تستخدم معلمة `accept` صيغة امتداد الملف القياسية (مفصولة بفواصل).

### إرشادات حجم الملف

لا يفرض rtSurvey حدًا صارمًا لحجم الملف على مستوى السؤال، ولكن ينطبق حد تحميل الخادم. استخدم `hint` لتوصيل التوقعات للمُعد:

| type | name | label | hint |
|------|------|-------|------|
| file | receipt | تحميل إيصال الدفع | مقبول: PDF أو صورة. الحد الأقصى لحجم الملف: 5 ميجابايت |

### التكامل مع نظام ملفات الجهاز والتخزين السحابي

على Android و iOS، يفتح سؤال `file` منتقي الملفات الأصلي للجهاز، والذي قد يتضمن الوصول إلى:
- تخزين الجهاز المحلي
- بطاقة SD (أندرويد)
- iCloud Drive (iOS)
- Google Drive, Dropbox (إذا تم تثبيتهما)

على الويب، يفتح مربع حوار تحميل الملفات القياسي للمتصفح.

### تخطيط الزر المضمّن

أضف `inline` لعرض التحميل كـ **زر أيقونة دائري** بجانب التسمية بدلاً من منتقي ملفات بعرض كامل.

```
| type | name | label           | appearance                              |
|------|------|-----------------|-----------------------------------------|
| file | doc  | Upload document | inline display{right}                   |
| file | doc  | Upload document | inline display{left, large}             |
| file | doc  | Upload document | inline display{center, large, <0099FF/>} |
```

**موضع الزر** — `left`, `right` *(افتراضي)*, `top`, `center`, `bottom`

**حجم الزر** — `small` *(افتراضي)*, `medium`, `large`

**لون الزر** — أضف لونًا سداسيًا داخل `display{}` لتجاوز اللون الأساسي:

```
inline display{right, large, <FF5500/>}
```

**التحكم بعد الالتقاط — `results{}`:**

| Appearance | Effect |
|---|---|
| `results{hide(capture)}` | يخفي زر التحميل بعد إرفاق ملف |
| `results{hide(review)}` | يخفي زر المراجعة/المعاينة بعد التحميل |
| `results{hide(filename)}` | يخفي اسم الملف المعروض بعد التحميل |
| `results{left}` | ينقل الأيقونة إلى اليسار بعد التحميل |

مثال — إخفاء زر التحميل بعد إرفاق الملف:
```
inline display{right} results{hide(capture)}
```

### إخفاء التسمية

```
inline text-nolabel display{center, large}
```

## أفضل الممارسات

1. استخدم `accept` لتقييد أنواع الملفات — وهذا يمنع المُعدين من تحميل ملفات خاطئة عن طريق الخطأ.
2. قم دائمًا بتضمين إرشادات الحجم والتنسيق في عمود `hint`.
3. بالنسبة للصور، استخدم نوع `image` بدلاً من ذلك — فهو يوفر ضغطًا أفضل ومعالجة متسقة للتنسيق.
4. بالنسبة للاستبيانات الكبيرة ذات المرفقات، خطط لتخزين بياناتك وعرض النطاق الترددي للتنزيل وفقًا لذلك.
5. اختبر منتقي الملفات على نوع الجهاز المستهدف (Android مقابل iOS مقابل الويب) قبل النشر — يختلف الوصول إلى محركات الأقراص السحابية.

## اعتبارات معالجة البيانات

- يتم تخزين الملفات بتنسيقها الأصلي؛ لا يتم تحويلها أو ضغطها بواسطة rtSurvey.
- حلل الملفات بعد التنزيل — لا يستخرج rtSurvey محتويات الملفات أو يفهرسها.
- تزيد مرفقات الملفات الكبيرة بشكل كبير من الوقت اللازم لتنزيل مجموعة بيانات كاملة.

## القيود

- لا تتحقق أسئلة الملف من محتويات الملف — يتم فرض التحقق من امتداد الملف عبر `accept` على مستوى واجهة المستخدم فقط.
- قد تنتهي مهلة تحميل الملفات الكبيرة جدًا (100 ميجابايت+) في بيئات الاتصال المنخفض.
- يمكن للمُعدين غير المتصلين بالإنترنت إرفاق ملفات ولكنها لن تُحمّل حتى يتم استعادة الاتصال.
- تقيد بعض تهيئات الجهاز الوصول إلى مواقع تخزين معينة (مثل سياسات MDM للشركات).

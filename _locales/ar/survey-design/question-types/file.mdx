يتيح نوع السؤال `file` للمستجيبين **تحميل أي ملف** من أجهزتهم — المستندات أو جداول البيانات أو ملفات PDF أو أنواع الملفات الأخرى. على عكس `image` و `audio` و `video` التي تطلق أدوات التقاط محددة، يفتح `file` منتقي ملفات للأغراض العامة.

## مواصفات XLSForm الأساسية

| type | name      | label                        |
|------|-----------|------------------------------|
| file | document  | يرجى تحميل المستند الخاص بك  |

لمزيد من التفاصيل حول نوع سؤال الملف القياسي، راجع [مواصفات XLSForm](https://xlsform.org/en/#question-types).

## الاستخدامات

تشيع استخدامات أسئلة الملف من أجل:

1. جمع المستندات الداعمة (الإيصالات، الشهادات، العقود، التقارير)
2. تحميل النماذج الورقية المكتملة التي تم مسحها ضوئيًا
3. جمع جداول البيانات أو عمليات تصدير البيانات من أنظمة أخرى
4. أي نوع ملف رقمي لا تغطيه الصور/الصوت/الفيديو

## تنسيق البيانات

يتم تخزين الملفات المحملة كمرفقات ثنائية (binary attachments):

- **التنسيق:** يتم الحفاظ عليه بالتنسيق الأصلي (PDF، XLSX، DOCX، إلخ.)
- **التسمية:** `{instanceID}-{fieldname}.{extension}`
- **التخزين:** يتم تحميله إلى مجلد الوسائط بالخادم جنبًا إلى جنب مع الإرسال
- **الوصول:** قابل للتنزيل من واجهة إدارة الإرسالات

## امتدادات rtSurvey

### أنواع الملفات المقبولة

استخدم عمود `parameters` لتقييد أنواع الملفات التي يمكن اختيارها:

| type | name | label | parameters |
|------|------|-------|------------|
| file | report | تحميل تقرير التفتيش | `accept=.pdf` |
| file | spreadsheet | تحميل ملف البيانات | `accept=.xlsx,.csv` |

تستخدم المعلمة `accept` بناء جملة امتداد الملف القياسي (مفصولة بفاصلة).

### إرشادات حجم الملف

لا يفرض rtSurvey حداً أقصى لحجم الملف على مستوى السؤال، ولكن ينطبق حد تحميل الخادم. استخدم `hint` لإبلاغ التوقعات لجامع البيانات (enumerator):

| type | name | label | hint |
|------|------|-------|------|
| file | receipt | تحميل إيصال الدفع | المقبول: PDF أو صورة. الحد الأقصى لحجم الملف: 5 ميجابايت |

### التكامل مع نظام ملفات الجهاز والتخزين السحابي

في نظامي Android و iOS، يفتح سؤال `file` منتقي الملفات الأصلي للجهاز، والذي قد يتضمن الوصول إلى:
- تخزين الجهاز المحلي
- بطاقة الذاكرة SD (أندرويد)
- iCloud Drive (iOS)
- Google Drive و Dropbox (إذا كانت مثبتة)

على الويب، يفتح مربع حوار تحميل الملفات القياسي للمتصفح.

### تخطيط الزر المضمن (Inline button layout)

أضف `inline` لعرض التحميل كـ **زر أيقونة دائري** بجوار العنوان بدلاً من منتقي ملفات بكامل العرض.

```
| type | name | label           | appearance                              |
|------|------|-----------------|-----------------------------------------|
| file | doc  | تحميل المستند | inline display{right}                   |
| file | doc  | تحميل المستند | inline display{left, large}             |
| file | doc  | تحميل المستند | inline display{center, large, <0099FF/>} |
```

**موقع الزر** — `left`, `right` *(افتراضي)*, `top`, `center`, `bottom`

**حجم الزر** — `small` *(افتراضي)*, `medium`, `large`

**لون الزر** — أضف لون hex داخل `display{}` لتجاوز اللون الأساسي:

```
inline display{right, large, <FF5500/>}
```

**التحكم بعد الالتقاط — `results{}`:**

| Appearance | Effect |
|---|---|
| `results{hide(capture)}` | يخفي زر التحميل بعد إرفاق ملف |
| `results{hide(review)}` | يخفي زر المراجعة/المعاينة بعد التحميل |
| `results{hide(filename)}` | يخفي اسم الملف المعروض بعد التحميل |
| `results{left}` | ينقل الأيقونة إلى اليسار بعد التحميل |

مثال — إخفاء زر التحميل بعد إرفاق الملف:
```
inline display{right} results{hide(capture)}
```

### إخفاء العنوان (Suppress the label)

```
inline text-nolabel display{center, large}
```

## أفضل الممارسات

1. استخدم `accept` لتقييد أنواع الملفات — وهذا يمنع جامعي البيانات من تحميل ملفات خاطئة عن طريق الخطأ.
2. قم دائمًا بتضمين إرشادات الحجم والتنسيق في عمود `hint`.
3. للصور، استخدم نوع `image` بدلاً من ذلك — فهو يوفر ضغطًا أفضل ومعالجة متسقة للتنسيق.
4. للاستبيانات الكبيرة التي تحتوي على مرفقات ملفات، خطط لتخزين بياناتك ونطاق تحميل النطاق الترددي وفقًا لذلك.
5. اختبر منتقي الملفات على نوع الجهاز المستهدف (أندرويد مقابل iOS مقابل الويب) قبل النشر — يختلف الوصول إلى محركات الأقراص السحابية.

## اعتبارات معالجة البيانات

- يتم تخزين الملفات في تنسيقها الأصلي؛ لا يتم تحويلها أو ضغطها بواسطة rtSurvey.
- تحليل الملفات بعد التنزيل — لا يقوم rtSurvey باستخراج أو فهرسة محتويات الملفات.
- تزيد مرفقات الملفات الكبيرة بشكل كبير من الوقت المطلوب لتنزيل مجموعة بيانات كاملة.

## القيود (Limitations)

- لا تتحقق أسئلة الملف من محتويات الملف — يتم فرض فحص امتداد الملف فقط عبر `accept` على مستوى واجهة المستخدم.
- قد تنتهي مهلة الملفات الكبيرة جدًا (100 ميجابايت+) عند التحميل في بيئات الاتصال الضعيفة.
- يمكن لجامعي البيانات غير المتصلين بالإنترنت إرفاق ملفات ولكن لن يتم تحميلها حتى يتم استعادة الاتصال.
- تقيد بعض تكوينات الأجهزة الوصول إلى مواقع تخزين معينة (مثل سياسات MDM للشركات).

---

يلتقط نوع السؤال `geotrace` تسلسلاً من الإحداثيات الجغرافية التي تشكل خطًا أو مسارًا (polyline). في نموذج الويب الخاص بـ rtSurvey، يتم عرض ذلك كـ **إدخال نصي** حيث يقوم جامع البيانات بإدخال أو لصق سلسلة الإحداثيات مباشرة.

## مواصفات XLSForm الأساسية

| type     | name        | label                        |
|----------|-------------|------------------------------|
| geotrace | river_path  | تتبع مسار النهر |
| geotrace | road_route  | تسجيل مسار الطريق |

للاطلاع على المواصفات القياسية، راجع [وثائق XLSForm](https://xlsform.org/en/#question-types).

---

## تنسيق البيانات (Data Format)

يتم تخزينها كقائمة من النقاط مفصولة بفاصلة منقوطة مع **عدم وجود مسافات حول الفواصل المنقوطة**. كل نقطة عبارة عن أربع قيم مفصولة بمسافات:

```
lat lon alt acc;lat lon alt acc;lat lon alt acc
```

| Component | Description |
|-----------|-------------|
| `lat` | خط العرض بالدرجات العشرية |
| `lon` | خط الطول بالدرجات العشرية |
| `alt` | الارتفاع بالأمتار (`0` إذا كان غير معروف) |
| `acc` | دقة GPS بالأمتار (`0` إذا كانت غير معروفة) |

**مثال — مسار مكون من ثلاث نقاط:**
```
13.756331 100.501762 15 8;13.758000 100.503000 14 6;13.760000 100.505000 13 5
```

يلزم وجود نقطتين على الأقل لتشكيل مسار صالح.

---

## كيف يتم عرضه في rtSurvey

في نموذج الويب الخاص بـ rtSurvey، يتم عرض `geotrace` كـ **حقل نصي** عادي. يقوم جامع البيانات بكتابة أو لصق سلسلة الإحداثيات. لا يوجد منتقي خرائط تفاعلي مدمج لهذا النوع في نموذج الويب الحالي.

### جمع النقاط بشكل تفاعلي

النمط الموصى به للجمع الميداني هو **مجموعة تكرار (repeat group) لأسئلة `geopoint`** — تستخدم كل نقطة منتقي خرائط GPS الكامل — مدمجة مع `calculate` لإنتاج سلسلة geotrace:

| type | name | label | calculation |
|------|------|-------|-------------|
| begin repeat | path_points | تسجيل كل نقطة طريق | |
| geopoint | point | اضغط لتسجيل النقطة | |
| end repeat | path_points | | |
| calculate | geotrace_value | | `join(';', ${path_points/point})` |

يمكن بعد ذلك تخزين السلسلة المحسوبة في سؤال `text` أو استخدامها في `geotrace`.

## مثال على الاستخدام

| type | name | label | hint | required |
|------|------|-------|------|----------|
| geotrace | farm_boundary_path | تسجيل مسار الوصول إلى المزرعة | أدخل كل نقطة طريق مفصولة بفاصلة منقوطة | yes |

---

## أفضل الممارسات

1. استخدم مجموعة تكرار لأسئلة `geopoint` للجمع التفاعلي القائم على الخريطة، ثم قم بدمج القيم — وهذا يعطي جامعي البيانات منتقي GPS لكل نقطة على حدة.
2. قم بتضمين التنسيق المتوقع في عمود `hint` عندما يكون الإدخال اليدوي للإحداثيات مطلوبًا.
3. تحقق من الوجود باستخدام `required = yes` عندما يكون المسار إلزاميًا.
4. خطط لتنظيف البيانات — قد يكون للمسارات التي يتم إدخالها يدويًا دقة غير متسقة.

## القيود (Limitations)

- لا يوجد منتقي خرائط تفاعلي مدمج لـ `geotrace` في نموذج الويب الخاص بـ rtSurvey.
- يمكن أن تكون سلسلة الإحداثيات طويلة للمسارات المعقدة — ضع ذلك في الاعتبار عند أداء النموذج والتخزين.
- يتطلب التحقق من صحة طوبولوجيا المسار (مثل الحد الأدنى لعدد النقاط، والتقاطع الذاتي) معالجة لاحقة خارج قيود XLSForm.

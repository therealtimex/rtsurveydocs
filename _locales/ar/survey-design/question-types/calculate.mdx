يقوم نوع السؤال `calculate` بتشغيل صيغة بصمت في الخلفية. ويقوم بتخزين النتيجة في حقل محدد يمكن للأسئلة الأخرى الرجوع إليه - ولكنه لا يظهر أي مدخل أو تسمية للعداد. استخدمه لاستخلاص القيم، أو دمج السلاسل، أو تشغيل المنطق الشرطي، أو البحث عن البيانات التي ستحتاج إليها لاحقًا في النموذج.

---

## بناء الجملة الأساسي

| type | name | label | calculation |
|------|------|-------|-------------|
| calculate | total | | `${price} * ${quantity}` |

- **type**: دائماً `calculate`.
- **name**: اسم حقل فريد. تشير الأسئلة الأخرى إلى هذا باستخدام `${name}`.
- **label**: اتركه فارغاً - حقول calculate لا تظهر أبداً للعداد.
- **calculation**: الصيغة المطلوب تقييمها. تدعم جميع [وظائف XLSForm](../operators-and-functions/functions) ومراجع الحقول.

## الأنماط الشائعة

### الحساب

| type | name | label | calculation |
|------|------|-------|-------------|
| integer | price | Unit price | |
| integer | quantity | Quantity | |
| calculate | total | | `${price} * ${quantity}` |
| note | total_note | Total: `${total}` | |

### دمج السلاسل

| type | name | label | calculation |
|------|------|-------|-------------|
| text | first_name | First name | |
| text | last_name | Last name | |
| calculate | full_name | | `concat(${first_name}, ' ', ${last_name})` |

### القيمة الشرطية

| type | name | label | calculation |
|------|------|-------|-------------|
| integer | score | Score (0–100) | |
| calculate | grade | | `if(${score} >= 90, 'A', if(${score} >= 75, 'B', if(${score} >= 60, 'C', 'F')))` |

### العمر من تاريخ الميلاد

| type | name | label | calculation |
|------|------|-------|-------------|
| date | dob | Date of birth | |
| calculate | age_years | | `int((today() - ${dob}) div 365.25)` |

## استخدام `once()` لقفل القيمة

افتراضياً، يقوم `calculate` بإعادة التقييم كلما تغير أي حقل مشار إليه. قم بلف الصيغة في `once()` للتقييم عند التحميل الأول فقط وتجميد النتيجة:

| type | name | label | calculation |
|------|------|-------|-------------|
| calculate | interview_start | | `once(now())` |

استخدم `once()` للطوابع الزمنية، أو القيم الأولية، أو أي حالة لا يكون فيها إعادة الحساب عند التغيير مرغوباً.

## سحب البيانات من مصادر خارجية

### من ملف CSV

```
pulldata('staff.csv', 'department', 'name', ${staff_id})
```

راجع [pulldata()](../operators-and-functions/pulldata) للحصول على المرجع الكامل.

### من قاعدة بيانات SQLite مدمجة

```
pulldata('rawquery',
  concat(${family_path}, '/locations.db::provinces'),
  'SELECT name FROM provinces WHERE id = ?',
  ${province_id})
```

راجع [البحث في قاعدة البيانات المحلية](../advanced-features/local-database-search) للحصول على تفاصيل بناء المسار.

### من سياق التطبيق

```
pulldata('app-api', 'user.username')
pulldata('app-api', 'family_path')
```

راجع [App API](../app-api) لجميع المفاتيح المتاحة.

## استخدام calculate في relevant و constraint

يمكن للحقول الأخرى الرجوع إلى نتيجة `calculate` تماماً مثل أي حقل:

| type | name | label | relevant | constraint |
|------|------|-------|----------|------------|
| calculate | bmi | | | `${weight} div (${height} * ${height}) * 10000` |
| note | bmi_warning | BMI is very high — please verify weight and height. | `${bmi} > 40` | |

## أفضل الممارسات

1. امنح حقول calculate أسماء ذات معنى - `total_cost` أوضح من `calc1` وأسهل في التتبع في الصادرات.
2. قم بتقسيم الصيغ المعقدة إلى حقول calculate متعددة متسلسلة بدلاً من تعبير واحد متداخل بعمق.
3. استخدم `once()` للطوابع الزمنية واللقطات الأولية لمنع القيم من التغيير بعد الالتقاط الأول.
4. ضع حقول `calculate` قبل السؤال الأول الذي يشير إليها - يتبع ترتيب التقييم ترتيب النموذج.
5. حافظ على عمود `label` فارغاً. تعرض بعض الأدوات التسمية؛ تركه فارغاً يتجنب المخرجات المربكة.

## القيود

- لا يتم عرض حقول Calculate أبداً للعداد بشكل مباشر - استخدم حقل `note` لإظهار النتيجة.
- عمود `calculation` مطلوب؛ يقوم صف `calculate` بدون صيغة دائماً بتخزين سلسلة فارغة.
- يتم إعادة تقييم النتائج عند كل تغيير في النموذج ما لم يتم لفها في `once()` - يمكن أن تؤثر الصيغ المعقدة للغاية في النماذج الكبيرة على أداء العرض على الأجهزة منخفضة المواصفات.
- يتم تخزين القيم المحسوبة كسلاسل في الإرسال. استخدم `number()` أو `int()` أو `boolean()` للتحويل عند تمرير النتيجة إلى تعبيرات حسابية أو منطقية.

يمكّن نوع سؤال الصورة في XLSForms و rtSurvey المستجيبين من التقاط الصور وإرسالها كجزء من ردودهم على الاستطلاع. هذه الميزة مفيدة بشكل خاص لجمع البيانات المرئية، أو توثيق الملاحظات، أو تقديم الأدلة في الاستطلاعات الميدانية.

## مواصفات XLSForm الأساسية

| type  | name        | label                           |
|-------|-------------|--------------------------------|
| image | photo       | التقط صورة للموقع |

لمزيد من التفاصيل حول نوع سؤال الصورة الأساسي، راجع [مواصفات XLSForm](https://xlsform.org/en/#question-types).

## الاستخدامات

تشيع استخدام أسئلة الصور في:

1. توثيق الظروف الميدانية أو الملاحظات
2. التقاط الأدلة المرئية في الدراسات البحثية
3. جمع صور "قبل وبعد" في تقييمات الأثر
4. التحقق من إكمال المهام أو التواجد في المواقع
5. جمع البيانات المرئية للتحليل عن بعد

## أفضل الممارسات

1. قدم تعليمات واضحة حول ما يجب تصويره.
2. ضع في اعتبارك الآثار المتعلقة بالخصوصية وأبلغ المستجيبين بكيفية استخدام صورهم.
3. كن منتبهاً لأحجام الملفات وقيود التخزين، خاصة للاستطلاعات في المناطق ذات الاتصال المحدود بالإنترنت.
4. تأكد من أن الجهاز يحتوي على مساحة تخزين كافية ومن منح أذونات الكاميرا.

## مثال على الاستخدام

إليك مثال على كيفية استخدام سؤال الصورة في الاستطلاع:

| type  | name           | label                                      | hint                                        |
|-------|----------------|--------------------------------------------|--------------------------------------------|
| image | storefront     | التقط صورة لمدخل المتجر | تأكد من أن اسم المتجر واضح للعيان |

## إضافات rtSurvey

### تخزين زر الكاميرا المدمج (Inline button layout)

أضف `inline` إلى عمود `appearance` لعرض الكاميرا كـ **زر أيقونة دائري** بجوار العنوان بدلاً من منطقة التقاط كاملة العرض. يؤدي الضغط عليه إلى فتح نافذة منبثقة.

```
| type  | name  | label        | appearance                          |
|-------|-------|--------------|-------------------------------------|
| image | photo | التقاط صورة | inline display{right}               |
| image | photo | التقاط صورة | inline display{center, large}       |
```

**موقع الزر — `display{}`:**

| Value | Layout |
|-------|--------|
| `right` *(default)* | الأيقونة يمين العنوان |
| `left` | الأيقونة يسار العنوان |
| `top` | الأيقونة فوق العنوان، متمركزة |
| `center` / `bottom` | الأيقونة تحت العنوان، متمركزة |

**حجم الزر:**

| Value | Size |
|-------|------|
| `small` *(default)* | دائرة صغيرة |
| `medium` | دائرة متوسطة |
| `large` | دائرة كبيرة |

**لون الزر** — أضف لون سداسي (hex) داخل `display{}` لتجاوز اللون الأساسي:

```
inline display{right, large, <FF5500/>}
inline display{center, medium, <0099FF/>}
```

**التحكم ما بعد الالتقاط — `results{}`:**

| Appearance | Effect |
|---|---|
| `results{hide(capture)}` | يخفي زر الكاميرا بعد التقاط الصورة |
| `results{hide(camera)}` | نفس مفعول `hide(capture)` — بديل لنوع الصورة |
| `results{hide(review)}` | يخفي معاينة الصورة المصغرة بعد الالتقاط |
| `results{hide(filename)}` | يخفي اسم الملف المعروض بعد الرفع |
| `results{left}` | ينقل الأيقونة إلى اليسار بعد الالتقاط |

مثال — زر كبير متمركز، إخفاء الكاميرا بعد الالتقاط:
```
inline display{center, large} results{hide(capture)}
```

### `invisible auto-show` — فتح الكاميرا تلقائياً

يخفي أداة السؤال من التخطيط ولكنه يفتح الكاميرا تلقائياً عند تحميل الصفحة. مفيد لتضمين خطوة التقاط صامتة في تدفق النموذج.

```
invisible auto-show
inline invisible auto-show
```

### التوقيع والرسم (Signature and drawing)

| Appearance | Description |
|---|---|
| `signature` | لوحة توقيع بملء الشاشة |
| `signature display{quick}` | لوحة توقيع سريعة مدمجة — بدون نافذة منبثقة |
| `draw` | لوحة رسم يدوي |

### العلامة المائية (Watermark)

أضف علامة مائية نصية أو صورية للصور الملتقطة:

```
watermark(text, "Survey ID: ${id}", bottom-right, 0.5)
watermark(file, logo.png, top-left, 1.0, 20%)
```

### إخفاء العنوان

```
inline text-nolabel display{center, large}
```

## معالجة البيانات

عادة ما تكون الصور التي يتم جمعها من خلال نوع السؤال هذا:

1. محفوظة بتنسيق صور شائع (مثل JPG، PNG)
2. مخزنة بجانب بيانات الاستطلاع الأخرى، غالباً في مجلد وسائط منفصل
3. يمكن الوصول إليها للعرض والتحليل من خلال منصة إدارة الاستطلاع

## اعتبارات التحليل

عند استخدام أسئلة الصور، ضع في اعتبارك:

1. كيف سيتم تحليل الصور (مثل المراجعة اليدوية، التحليل الآلي للصور)
2. مساحة التخزين الإضافية المطلوبة لملفات الصور
3. تدابير الخصوصية وحماية البيانات لتخزين الصور ومعالجتها
4. الحاجة المحتملة لأدوات تحرير الصور أو تنظيمها في مرحلة التحليل

## القيود (Limitations)

- يمكن أن تكون ملفات الصور كبيرة، مما قد يؤثر على نقل البيانات وتخزينها.
- قد لا تحتوي جميع الأجهزة على كاميرات عالية الجودة أو مساحة تخزين كافية.
- يمكن أن يستغرق تحليل الأعداد الكبيرة من الصور وقتاً طويلاً.
- قد تكون هناك مخاوف تتعلق بالخصوصية عند التقاط الصور، خاصة في الأماكن العامة.

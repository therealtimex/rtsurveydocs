تلتقط أنواع الأسئلة `date` و `time` و `datetime` قيم التاريخ و/أو الوقت. يقوم rtSurvey بعرضها بعدة أوضاع تخطيط يتم التحكم فيها بواسطة عمود `appearance`.

## مواصفات XLSForm الأساسية

| type     | name           | label                     |
|----------|----------------|---------------------------|
| date     | birth_date     | تاريخ الميلاد             |
| time     | start_time     | ما هو وقت البدء؟          |
| datetime | event_datetime | متى وقع الحدث؟           |

للمواصفات القياسية، راجع [وثائق XLSForm](https://xlsform.org/en/#question-types).

## أوضاع التخطيط

### الافتراضي — تقويم مفتوح دائمًا

لا يلزم وجود قيمة في عمود `appearance`. يتم عرض التقويم (والساعة لـ `time`/`datetime`) مباشرة على الصفحة — مرئي دائمًا، ولا يلزم وجود زر.

| type | name       | label         | appearance |
|------|------------|---------------|------------|
| date | start_date | تاريخ الزيارة |            |

---

### `inline` — زر دائري ← نافذة منبثقة

يطفو زر أيقونة دائري (تقويم أو ساعة) بجوار تسمية السؤال. يؤدي النقر عليه إلى فتح نافذة منبثقة مع أداة الاختيار. بعد الاختيار، تظهر القيمة المختارة كنص بجوار التسمية.

- خلفية الزر: لون السمة الأساسي (قابل للتجاوز)
- شكل الزر: دائرة كاملة (`border-radius: 50%`)

```
| type | name       | label         | appearance |
|------|------------|---------------|------------|
| date | start_date | تاريخ الزيارة | inline     |
```

---

### `inline-onlyresult` — يختفي الزر بعد الاختيار

نفس `inline` ولكن الزر يخفي نفسه بمجرد اختيار القيمة. مفيد عندما تريد أن يكون التاريخ مرئيًا فقط بعد اختياره، بدون أيقونة مستمرة.

```
inline-onlyresult
```

---

### `inline-1line` — صف من أدوات الاختيار الدوارة (Spinners)

يعرض ضوابط دوارة فردية (▲ قيمة ▼) في صف أفقي واحد — عمود واحد لكل مكون. لـ `date`: شهر / يوم / سنة. لـ `datetime`: شهر / يوم / سنة / ساعات / دقائق. لـ `time`: ساعات / دقائق.

لا توجد نافذة منبثقة أو تقويم — يقوم المستخدم بتمرير كل أداة دوارة بشكل مستقل.

```
inline-1line
```

**إظهار مكونات محددة فقط** عن طريق إضافة أسماء المكونات:

```
inline-1line month year      → يخفي أداة اختيار اليوم
inline-1line year            → يظهر السنة فقط
```

**تحديد نطاق السنة:**

```
inline-1line y_range(2000-2030)
```

---

### `box` — إدخال نصي

يعرض حقل إدخال نصي عادي. يكتب المستخدم التاريخ مباشرة باستخدام التنسيق المحدد في عمود `appearance`.

```
box(%d/%m/%Y)       → DD/MM/YYYY
box(%Y-%m-%d)       → YYYY-MM-DD
```

---

### `month-year` — الشهر والسنة فقط

مظهر XLSForm القياسي. تبدأ أداة الاختيار في عرض السنة؛ يختار المستخدم الشهر والسنة ولكن ليس يومًا محددًا.

```
month-year
```

---

### `year` — السنة فقط

مظهر XLSForm القياسي. تبدأ أداة الاختيار في عرض العقد؛ السنة فقط قابلة للاختيار.

```
year
```

## تنسيق العرض المخصص

أضف `-[format]` إلى أي مظهر `inline` للتحكم في كيفية عرض القيمة المختارة كنص. يستخدم رموزًا بنمط strftime.

| الرمز | المعنى | مثال |
|-------|---------|---------|
| `%d`  | اليوم (مع أصفار بادئة) | 07 |
| `%e`  | اليوم (بدون أصفار بادئة) | 7 |
| `%m`  | رقم الشهر | 04 |
| `%n`  | رقم الشهر (بدون أصفار بادئة) | 4 |
| `%b`  | اختصار اسم الشهر | Apr |
| `%Y`  | السنة (4 أرقام) | 2026 |
| `%y`  | السنة (رقمان) | 26 |
| `%H`  | الساعة (24 ساعة) | 14 |
| `%h`  | الساعة (بدون أصفار بادئة) | 14 |
| `%M`  | الدقيقة | 05 |
| `%S`  | الثانية | 00 |
| `%a`  | اختصار اسم اليوم | Wed |

**أمثلة:**

```
inline-[%d/%m/%Y]            → 07/04/2026
inline-[%d %b %Y]            → 07 Apr 2026
inline-1line-[%Y-%m-%d]      → إدخال عبر أداة دوارة، عرض منسق
inline-[%d/%m/%Y %H:%M]      → 07/04/2026 14:30
```

## تخصيص الألوان

تجاوز لون زر الأيقونة باستخدام `colors()`:

```
inline colors("0099FF")                   → خلفية الزر #0099FF
inline colors("0099FF","FFFFFF")          → الخلفية #0099FF، لون الأيقونة #FFFFFF
inline-1line colors("0000FF","FFFF00")    → ألوان تمييز أداة الاختيار الدوارة
inline-onlyresult colors("E53935")        → زر أحمر
```

---

## موضع الزر مع `display{}`

يتحكم معدل `display{}` في مكان ظهور زر الأيقونة بالنسبة لتسمية السؤال. ينطبق على `inline` و `inline-onlyresult`.

```
display{<align>, <size>, <color>}
```

| المعلمة | القيم | الافتراضي |
|-----------|--------|---------|
| Align | `left`, `right`, `top`, `center`, `bottom` | `right` |
| Size | `small`, `medium`, `large` | `small` |
| Color | hex e.g. `#FF5500` | لون السمة الأساسي |

**سلوك المحاذاة:**

| القيمة | التخطيط |
|-------|--------|
| `right` | الزر على يمين التسمية |
| `left` | الزر على يسار التسمية |
| `top` | الزر فوق التسمية، ممركز بعرض كامل |
| `center` / `bottom` | الزر تحت التسمية، ممركز بعرض كامل |

**أمثلة:**

```
inline display{left}
inline display{center, large}
inline display{right, medium, #E53935}
inline-onlyresult display{bottom, large, #0099FF}
```

## تقييد نطاق التاريخ

استخدم `inputs{range[...]}` لتقييد التواريخ القابلة للاختيار.

```
inputs{range[dateGt(2024-01-01), dateLt(2024-12-31)]}
```

المعلمات داخل `range[...]`:

| المعلمة | الوصف |
|-----------|-------------|
| `dateGt(YYYY-MM-DD)` | الحد الأدنى للتاريخ القابل للاختيار (أكبر من أو يساوي) |
| `dateLt(YYYY-MM-DD)` | الحد الأقصى للتاريخ القابل للاختيار (أقل من أو يساوي) |
| `indayTimeGt(HH:MM:SS)` | الحد الأدنى للوقت خلال اليوم (لـ datetime فقط) |
| `indayTimeLt(HH:MM:SS)` | الحد الأقصى للوقت خلال اليوم (لـ datetime فقط) |

يمكن تعريف نطاقات متعددة — يكون التاريخ قابلاً للاختيار إذا وقع ضمن **أي** من النطاقات.

## إخفاء التسمية

أضف `text-nolabel` لإخفاء تسمية السؤال. يتم عرض الزر بمفرده.

```
inline text-nolabel display{center, large}
```

## ملخص التخطيط

| المظهر | الأداة المعروضة | قابلة لتخصيص الألوان |
|---|---|---|
| *(بدون)* | تقويم مفتوح دائمًا | لا |
| `inline` | زر دائري ← تقويم نافذة منبثقة | نعم |
| `inline-onlyresult` | زر دائري ← نافذة منبثقة، يختفي بعد الاختيار | نعم |
| `inline-1line` | صف من أدوات الاختيار الدوارة | نعم |
| `box(%format%)` | حقل إدخال نصي | لا |
| `month-year` | أداة اختيار الشهر/السنة | لا |
| `year` | أداة اختيار السنة فقط | لا |

## أفضل الممارسات

1. استخدم `inline` للنماذج المدمجة — فهو يوفر مساحة رأسية مقارنة بالتقويم المفتوح دائمًا.
2. استخدم `inline-1line` عندما يحتاج المستجيبون إلى تعديل مكونات التاريخ الفردية (مثل سنة الميلاد).
3. استخدم `box()` فقط عندما تثق في أن جامع البيانات سيكتب التواريخ بشكل صحيح — حيث لا يتم عرض واجهة تحقق.
4. استخدم `display{center, large}` لجعل الزر أكثر وضوحًا على شاشات الأجهزة المحمولة.
5. حدد دائمًا `-[format]` عندما يؤدي عرض `YYYY-MM-DD` الافتراضي إلى إرباك المستخدمين المحليين.
6. كن حذرًا من المناطق الزمنية عند جمع بيانات التاريخ والوقت عبر مناطق مختلفة.

## القيود

- يعود `inline-1line` دائمًا إلى تاريخ اليوم إذا لم تكن هناك قيمة موجودة — استخدم عمود `default` لملء تاريخ محدد مسبقًا.
- يتحكم تنسيق `box()` في العرض فقط؛ القيمة المخزنة هي دائمًا ISO 8601.
- لا يعمل تقييد نطاق التاريخ (`inputs{range[...]}`) مع تخطيط `box`.
- يمكن أن تؤدي فروق التوقيت المحلي إلى تعقيد تحليل البيانات إذا لم يتم حسابها بشكل صحيح.

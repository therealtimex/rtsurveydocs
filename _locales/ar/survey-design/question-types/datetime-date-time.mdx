تتيح أنواع الأسئلة `date` و `time` و `datetime` التقاط قيم التاريخ و/أو الوقت. يعرضها rtSurvey بعدة أوضاع تخطيط يتم التحكم فيها بواسطة عمود `appearance`.

## مواصفات XLSForm الأساسية

| type     | name           | label                     |
|----------|----------------|---------------------------|
| date     | birth_date     | تاريخ الميلاد             |
| time     | start_time     | متى بدأت؟                 |
| datetime | event_datetime | متى وقع الحدث؟             |

للحصول على المواصفات القياسية، راجع [وثائق XLSForm](https://xlsform.org/en/#question-types).

## أوضاع التخطيط

### الافتراضي - تقويم مفتوح دائمًا

لا حاجة لقيمة `appearance`. يتم عرض التقويم (والساعة لـ `time`/`datetime`) مباشرة على الصفحة - مرئي دائمًا، لا يتطلب زرًا.

| type | name       | label         | appearance |
|------|------------|---------------|------------|
| date | start_date | تاريخ الزيارة |            |

---

### `inline` - زر دائري ← نافذة منبثقة

يطفو زر أيقونة دائري (تقويم أو ساعة) بجوار تسمية السؤال. يؤدي النقر عليه إلى فتح نافذة منبثقة مع أداة الاختيار. بعد التحديد، تظهر القيمة المختارة كنص بجانب التسمية.

- خلفية الزر: لون السمة الأساسي (يمكن تجاوزه)
- شكل الزر: دائرة كاملة (`border-radius: 50%`)

```
| type | name       | label         | appearance |
|------|------------|---------------|------------|
| date | start_date | تاريخ الزيارة | inline     |
```

---

### `inline-onlyresult` - يختفي الزر بعد التحديد

مثل `inline` ولكن الزر يخفي نفسه بمجرد تحديد قيمة. مفيد عندما تريد أن يكون التاريخ مرئيًا فقط بعد اختياره، بدون أيقونة ثابتة.

```
inline-onlyresult
```

---

### `inline-1line` - صف من أدوات التدوير

يعرض عناصر تحكم فردية لأداة التدوير (▲ value ▼) في صف أفقي واحد - عمود واحد لكل مكون. لـ `date`: الشهر / اليوم / السنة. لـ `datetime`: الشهر / اليوم / السنة / الساعات / الدقائق. لـ `time`: الساعات / الدقائق.

لا يوجد نموذج منبثق أو تقويم - يقوم المستخدم بتمرير كل أداة تدوير بشكل مستقل.

```
inline-1line
```

**عرض مكونات محددة فقط** عن طريق إضافة أسماء المكونات:

```
inline-1line month year      → يخفي أداة تدوير اليوم
inline-1line year            → يعرض السنة فقط
```

**تقييد نطاق السنة:**

```
inline-1line y_range(2000-2030)
```

---

### `box` - إدخال نص

يعرض حقل إدخال نص عادي. يقوم المستخدم بكتابة التاريخ مباشرة باستخدام التنسيق المحدد في المظهر.

```
box(%d/%m/%Y)       → DD/MM/YYYY
box(%Y-%m-%d)       → YYYY-MM-DD
```

---

### `month-year` - الشهر والسنة فقط

مظهر XLSForm قياسي. تبدأ أداة الاختيار من عرض السنة؛ يختار المستخدم الشهر والسنة ولكن ليس يومًا محددًا.

```
month-year
```

---

### `year` - السنة فقط

مظهر XLSForm قياسي. تبدأ أداة الاختيار من عرض العقد؛ يمكن تحديد السنة فقط.

```
year
```

## تنسيق العرض المخصص

أضف `-[format]` إلى أي مظهر `inline` للتحكم في كيفية عرض القيمة المحددة كنص. يستخدم رموزًا بنمط strftime.

| Token | Meaning | Example |
|-------|---------|---------|
| `%d`  | Day (zero-padded) | 07 |
| `%e`  | Day (no padding) | 7 |
| `%m`  | Month number | 04 |
| `%n`  | Month number (no padding) | 4 |
| `%b`  | Month abbreviation | Apr |
| `%Y`  | 4-digit year | 2026 |
| `%y`  | 2-digit year | 26 |
| `%H`  | Hour (24h) | 14 |
| `%h`  | Hour (no padding) | 14 |
| `%M`  | Minute | 05 |
| `%S`  | Second | 00 |
| `%a`  | Day name abbreviation | Wed |

**أمثلة:**

```
inline-[%d/%m/%Y]            → 07/04/2026
inline-[%d %b %Y]            → 07 Apr 2026
inline-1line-[%Y-%m-%d]      → إدخال أداة التدوير، عرض منسق
inline-[%d/%m/%Y %H:%M]      → 07/04/2026 14:30
```

## تخصيص اللون

تجاوز لون زر الأيقونة باستخدام `colors()`:

```
inline colors("0099FF")                   → خلفية الزر #0099FF
inline colors("0099FF","FFFFFF")          → خلفية #0099FF، لون الأيقونة #FFFFFF
inline-1line colors("0000FF","FFFF00")    → ألوان تمييز أداة التدوير
inline-onlyresult colors("E53935")        → زر أحمر
```

---

## موضع الزر مع `display{}`

يتحكم معدّل `display{}` في مكان ظهور زر الأيقونة بالنسبة لتسمية السؤال. ينطبق على `inline` و `inline-onlyresult`.

```
display{<align>, <size>, <color>}
```

| Parameter | Values | Default |
|-----------|--------|---------|
| Align | `left`, `right`, `top`, `center`, `bottom` | `right` |
| Size | `small`, `medium`, `large` | `small` |
| Color | hex e.g. `#FF5500` | لون السمة الأساسي |

**سلوك المحاذاة:**

| Value | Layout |
|-------|--------|
| `right` | الزر على يمين التسمية |
| `left` | الزر على يسار التسمية |
| `top` | الزر فوق التسمية، توسيط بعرض كامل |
| `center` / `bottom` | الزر أسفل التسمية، توسيط بعرض كامل |

**أمثلة:**

```
inline display{left}
inline display{center, large}
inline display{right, medium, #E53935}
inline-onlyresult display{bottom, large, #0099FF}
```

## قيود نطاق التاريخ

استخدم `inputs{range[...]}` لتقييد التواريخ التي يمكن تحديدها.

```
inputs{range[dateGt(2024-01-01), dateLt(2024-12-31)]}
```

المعلمات داخل `range[...]`:

| Parameter | Description |
|-----------|-------------|
| `dateGt(YYYY-MM-DD)` | الحد الأدنى للتاريخ القابل للتحديد (أكبر من أو يساوي) |
| `dateLt(YYYY-MM-DD)` | الحد الأقصى للتاريخ القابل للتحديد (أقل من أو يساوي) |
| `indayTimeGt(HH:MM:SS)` | الحد الأدنى للوقت خلال اليوم (تاريخ ووقت فقط) |
| `indayTimeLt(HH:MM:SS)` | الحد الأقصى للوقت خلال اليوم (تاريخ ووقت فقط) |

يمكن تعريف نطاقات متعددة - يمكن تحديد تاريخ إذا كان يقع ضمن **أي** من النطاقات.

## إخفاء التسمية

أضف `text-nolabel` لإخفاء تسمية السؤال. يتم عرض الزر وحده.

```
inline text-nolabel display{center, large}
```

## أفضل الممارسات

1. استخدم `inline` للنماذج المدمجة - فهو يوفر مساحة رأسية مقارنة بالتقويم المفتوح دائمًا.
2. استخدم `inline-1line` عندما يحتاج المستجيبون إلى تعديل مكونات التاريخ الفردية (على سبيل المثال، سنة الميلاد).
3. استخدم `box()` فقط عندما تثق في المُحصي لكتابة التواريخ بشكل صحيح - لا يتم عرض واجهة مستخدم التحقق من الصحة.
4. استخدم `display{center, large}` لجعل الزر أكثر بروزًا على شاشات الهاتف المحمول.
5. حدد دائمًا `-[format]` عندما يؤدي العرض الافتراضي `YYYY-MM-DD` إلى إرباك المستخدمين المحليين.
6. انتبه إلى المناطق الزمنية عند جمع بيانات التاريخ والوقت عبر مناطق مختلفة.

## القيود

- `inline-1line` يعود دائمًا إلى تاريخ اليوم إذا لم تكن هناك قيمة موجودة - استخدم عمود `default` لملء تاريخ معين مسبقًا.
- يتحكم تنسيق `box()` فقط في العرض؛ القيمة المخزنة دائمًا بتنسيق ISO 8601.
- لا يعمل تقييد نطاق التاريخ (`inputs{range[...]}`) مع تخطيط `box`.
- يمكن أن تؤدي فروق التوقيت إلى تعقيد تحليل البيانات إذا لم يتم أخذها في الاعتبار بشكل صحيح.

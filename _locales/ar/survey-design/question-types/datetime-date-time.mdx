تلتقط أنواع الأسئلة `date` و `time` و `datetime` قيم التاريخ و/أو الوقت. يعرضها rtSurvey بعدة أوضاع تخطيط يتم التحكم فيها بواسطة عمود `appearance`.

## مواصفات XLSForm الأساسية

| type     | name           | label                     |
|----------|----------------|---------------------------|
| date     | birth_date     | تاريخ الميلاد             |
| time     | start_time     | في أي وقت بدأت؟   |
| datetime | event_datetime | متى وقع الحدث؟ |

للاطلاع على المواصفات القياسية، راجع [وثائق XLSForm](https://xlsform.org/en/#question-types).

## أوضاع التخطيط

### الافتراضي — تقويم مفتوح دائمًا

لا يلزم قيمة للمظهر. يتم عرض التقويم (والساعة لـ `time`/`datetime`) مباشرة على الصفحة — مرئي دائمًا، لا يتطلب زرًا.

| type | name       | label         | appearance |
|------|------------|---------------|------------|
| date | start_date | تاريخ الزيارة |            |

---

### `inline` — زر دائري → نافذة منبثقة

يزر أيقونة دائري (تقويم أو ساعة) يطفو بجانب تسمية السؤال. يؤدي النقر عليه إلى فتح نافذة منبثقة مع أداة الاختيار. بعد الاختيار، تظهر القيمة المختارة كنص بجانب التسمية.

- خلفية الزر: لون السمة الأساسي (قابل للتجاوز)
- شكل الزر: دائرة كاملة (`border-radius: 50%`)

```
| type | name       | label         | appearance |
|------|------------|---------------|------------|
| date | start_date | Date of visit | inline     |
```

---

### `inline-onlyresult` — الزر يختفي بعد الاختيار

نفس `inline` ولكن الزر يختفي بمجرد اختيار قيمة. مفيد عندما تريد فقط أن يكون التاريخ مرئيًا بعد اختياره، بدون أيقونة دائمة.

```
inline-onlyresult
```

---

### `inline-1line` — صف من أدوات التدوير

يعرض عناصر تحكم دوارة فردية (▲ قيمة ▼) في صف أفقي واحد — عمود واحد لكل مكون. لـ `date`: الشهر / اليوم / السنة. لـ `datetime`: الشهر / اليوم / السنة / الساعات / الدقائق. لـ `time`: الساعات / الدقائق.

لا توجد نافذة منبثقة أو تقويم — يقوم المستخدم بالتمرير في كل أداة تدوير بشكل مستقل.

```
inline-1line
```

**إظهار مكونات محددة فقط** عن طريق إضافة أسماء المكونات:

```
inline-1line month year      → hides day spinner
inline-1line year            → shows only year
```

**تحديد نطاق السنوات:**

```
inline-1line y_range(2000-2030)
```

---

### `box` — إدخال نص

يعرض حقل إدخال نص عادي. يقوم المستخدم بكتابة التاريخ مباشرة باستخدام التنسيق المحدد في المظهر.

```
box(%d/%m/%Y)       → DD/MM/YYYY
box(%Y-%m-%d)       → YYYY-MM-DD
```

---

### `month-year` — الشهر والسنة فقط

مظهر XLSForm القياسي. تبدأ أداة الاختيار بعرض السنة؛ يختار المستخدم الشهر والسنة ولكن ليس يومًا محددًا.

```
month-year
```

---

### `year` — السنة فقط

مظهر XLSForm القياسي. تبدأ أداة الاختيار بعرض العقد؛ يمكن اختيار السنة فقط.

```
year
```

---

## تنسيق العرض المخصص

أضف `-[format]` إلى أي مظهر `inline` للتحكم في كيفية عرض القيمة المختارة كنص. يستخدم رموزًا بنمط strftime.

| Token | Meaning | Example |
|-------|---------|---------|
| `%d`  | اليوم (مع بادئة صفرية) | 07 |
| `%e`  | اليوم (بدون حشوة) | 7 |
| `%m`  | رقم الشهر | 04 |
| `%n`  | رقم الشهر (بدون حشوة) | 4 |
| `%b`  | اختصار الشهر | Apr |
| `%Y`  | سنة من 4 أرقام | 2026 |
| `%y`  | سنة من رقمين | 26 |
| `%H`  | الساعة (24 ساعة) | 14 |
| `%h`  | الساعة (بدون حشوة) | 14 |
| `%M`  | الدقيقة | 05 |
| `%S`  | الثانية | 00 |
| `%a`  | اختصار اسم اليوم | Wed |

**أمثلة:**

```
inline-[%d/%m/%Y]            → 07/04/2026
inline-[%d %b %Y]            → 07 Apr 2026
inline-1line-[%Y-%m-%d]      → spinner input, formatted display
inline-[%d/%m/%Y %H:%M]      → 07/04/2026 14:30
```

## تخصيص اللون

تجاوز لون زر الأيقونة باستخدام `colors()`:

```
inline colors("0099FF")                   → button background #0099FF
inline colors("0099FF","FFFFFF")          → background #0099FF, icon color #FFFFFF
inline-1line colors("0000FF","FFFF00")    → spinner accent colors
inline-onlyresult colors("E53935")        → red button
```

---

## موضع الزر باستخدام `display{}`

يتحكم المُعدّل `display{}` في مكان ظهور زر الأيقونة بالنسبة لتسمية السؤال. ينطبق على `inline` و `inline-onlyresult`.

```
display{<align>, <size>, <color>}
```

| Parameter | Values | Default |
|-----------|--------|---------|
| محاذاة | `left`, `right`, `top`, `center`, `bottom` | `right` |
| الحجم | `small`, `medium`, `large` | `small` |
| اللون | سداسي عشري مثل `#FF5500` | لون السمة الأساسي |

**سلوك المحاذاة:**

| Value | Layout |
|-------|--------|
| `right` | الزر إلى يمين التسمية |
| `left` | الزر إلى يسار التسمية |
| `top` | الزر فوق التسمية، بملء العرض ومتمركز |
| `center` / `bottom` | الزر أسفل التسمية، بملء العرض ومتمركز |

**أمثلة:**

```
inline display{left}
inline display{center, large}
inline display{right, medium, #E53935}
inline-onlyresult display{bottom, large, #0099FF}
```

## تقييد نطاق التاريخ

استخدم `inputs{range[...]}` لتقييد التواريخ التي يمكن اختيارها.

```
inputs{range[dateGt(2024-01-01), dateLt(2024-12-31)]}
```

المعلمات داخل `range[...]`:

| Parameter | Description |
|-----------|-------------|
| `dateGt(YYYY-MM-DD)` | الحد الأدنى للتاريخ القابل للاختيار (أكبر من أو يساوي) |
| `dateLt(YYYY-MM-DD)` | الحد الأقصى للتاريخ القابل للاختيار (أقل من أو يساوي) |
| `indayTimeGt(HH:MM:SS)` | الحد الأدنى للوقت خلال اليوم (datetime فقط) |
| `indayTimeLt(HH:MM:SS)` | الحد الأقصى للوقت خلال اليوم (datetime فقط) |

يمكن تحديد نطاقات متعددة — يمكن اختيار التاريخ إذا كان يقع ضمن **أي** من النطاقات.

## إخفاء التسمية

أضف `text-nolabel` لإخفاء تسمية السؤال. يتم عرض الزر وحده.

```
inline text-nolabel display{center, large}
```

## أفضل الممارسات

1. استخدم `inline` للنماذج المدمجة — فهو يوفر مساحة رأسية مقارنة بالتقويم المفتوح دائمًا.
2. استخدم `inline-1line` عندما يحتاج المستجيبون إلى تعديل مكونات التاريخ الفردية (مثل سنة الميلاد).
3. استخدم `box()` فقط عندما تثق في أن المُعد سيكتب التواريخ بشكل صحيح — لا يتم عرض واجهة مستخدم للتحقق من الصحة.
4. استخدم `display{center, large}` لجعل الزر أكثر بروزًا على شاشات الهاتف المحمول.
5. حدد دائمًا `-[format]` عندما قد يؤدي العرض الافتراضي `YYYY-MM-DD` إلى إرباك المستخدمين المحليين.
6. كن واعيًا بالمناطق الزمنية عند جمع بيانات التاريخ والوقت عبر مناطق مختلفة.

## القيود

- `inline-1line` دائمًا ما يعود إلى تاريخ اليوم إذا لم تكن هناك قيمة موجودة — استخدم عمود `default` لملء تاريخ معين مسبقًا.
- يتحكم تنسيق `box()` في العرض فقط؛ القيمة المخزنة هي دائمًا ISO 8601.
- لا يعمل تقييد نطاق التاريخ (`inputs{range[...]}`) مع تخطيط `box`.
- يمكن أن تعقّد اختلافات المنطقة الزمنية تحليل البيانات إذا لم يتم أخذها في الاعتبار بشكل صحيح.

title: "الباركود"
description: "تقوم أسئلة الباركود بمسح والتقاط رموز QR وبيانات الباركود في استبيانك."
---

يلتقط نوع السؤال `barcode` قيمة رمز عن طريق مسح رمز QR أو باركود باستخدام كاميرا الجهاز. يتضمن نموذج الماسح الضوئي أيضًا إدخال نص يدوي كبديل عندما يكون المسح غير ممكن.

## مواصفات XLSForm الأساسية

| type    | name         | label                    |
|---------|--------------|--------------------------|
| barcode | product_code | امسح باركود المنتج       |
| barcode | ticket_id    | امسح التذكرة              |

للحصول على المواصفات القياسية، راجع [وثائق XLSForm](https://xlsform.org/en/#question-types).

---

## التنسيقات المدعومة

يدعم rtSurvey رموز QR والباركود أحادي الأبعاد القياسية عبر كاميرا الجهاز، بما في ذلك:

- QR Code
- UPC-A, UPC-E
- EAN-8, EAN-13
- Code 39, Code 128
- ITF, Codabar

---

## التخطيط الافتراضي

بدون تعيين `appearance`، يعرض السؤال زرًا بعرض كامل **"الحصول على الباركود"**. يؤدي النقر عليه إلى فتح نموذج الماسح الضوئي. بعد مسح ناجح، يتغير الزر إلى **"استبدال الباركود"** وتظهر القيمة الممسوحة ضوئيًا بالأسفل كرابط قابل للنقر.

---

## نموذج الماسح الضوئي

يتضمن نموذج الماسح الضوئي دائمًا:
- **عرض الكاميرا المباشر** - يقوم بالمسح تلقائيًا عند الكشف؛ يغلق النموذج بعد مسح ناجح.
- **إدخال نص يدوي** - حقل نص في الأسفل حيث يمكن للمُحصي كتابة الرمز إذا فشل المسح.
- **زر تم** - يرسل القيمة المكتوبة يدويًا.

عندما تكون كاميرا الجهاز غير متاحة، يعود النموذج إلى خيار **"تحميل صورة"** - يمكن للمُحصي إرسال صورة للباركود لفك تشفيره.

---

## تخطيط الزر الداخلي

أضف `inline` لعرض الماسح الضوئي كـ **زر أيقونة دائري** بجانب التسمية بدلاً من زر بعرض كامل.

```
| type    | name | label     | appearance                              |
|---------|------|-----------|----------------------------------------|
| barcode | code | امسح العنصر | inline display{right}                  |
| barcode | code | امسح العنصر | inline display{left, large}            |
| barcode | code | امسح العنصر | inline display{center, large, <0099FF/>} |
```

**موضع الزر** - `left`، `right` *(افتراضي)*، `top`، `center`، `bottom`

**حجم الزر** - `small` *(افتراضي)*، `medium`، `large`

**لون الزر** - أضف لونًا سداسيًا داخل `display{}` لتجاوز اللون الأساسي:

```
inline display{right, large, <FF5500/>}
```

**التحكم بعد الالتقاط - `results{}`:**

| Appearance | Effect |
|---|---|
| `results{hide(scanner)}` | يخفي زر المسح بعد التقاط قيمة |
| `results{hide(review)}` | يخفي رابط القيمة الممسوحة بعد الالتقاط |
| `results{hide(value)}` | يخفي عرض نص القيمة الممسوحة |
| `results{left}` | ينقل الأيقونة إلى اليسار بعد الالتقاط |

مثال - إخفاء الماسح الضوئي بعد المسح الأول:
```
inline display{center, large} results{hide(scanner)}
```

---

## `inputs{auto-close(N)}` - إغلاق الماسح الضوئي تلقائيًا

يغلق نموذج الماسح الضوئي تلقائيًا بعد `N` ثانية إذا لم يتم الكشف عن باركود. يتم عرض مؤقت للعد التنازلي المباشر داخل النموذج.

```
inputs{auto-close(10)}     → يغلق بعد 10 ثوانٍ
inputs{auto-close(5)}      → يغلق بعد 5 ثوانٍ
```

اجمع مع inline:
```
inline display{right} inputs{auto-close(10)}
```

---

## `inputs{floating}` - ماسح ضوئي عائم قابل للسحب

يعرض **زر تصغير** (أيقونة ضغط ⊞) في رأس نموذج الماسح الضوئي. يؤدي النقر عليه إلى طي الماسح الضوئي إلى أيقونة دائرية عائمة صغيرة يمكن سحبها إلى أي مكان على الشاشة. يؤدي النقر على الأيقونة العائمة إلى إعادة فتح الماسح الضوئي.

```
inputs{floating}
inline display{right} inputs{floating}
```

مفيد في سير العمل حيث يحتاج المُحصي إلى رؤية النموذج أثناء تنشيط الماسح الضوئي (على سبيل المثال، مسح العناصر في قائمة).

---

## `invisible auto-show` - فتح الماسح الضوئي تلقائيًا بشكل غير مرئي

يخفي عنصر واجهة مستخدم السؤال من التخطيط ولكنه يفتح الماسح الضوئي تلقائيًا عند تحميل الصفحة. مفيد لتضمين خطوة مسح صامتة في تدفق النموذج.

```
invisible auto-show
inline invisible auto-show
```

---

## في المجموعات المتكررة

عندما يكون `barcode` داخل مجموعة `begin repeat`، فإن المسح الناجح ينتقل تلقائيًا إلى **التكرار التالي** بعد تسجيل القيمة. يتيح ذلك المسح التسلسلي السريع دون أن ينقر المُحصي على "إضافة" بين العناصر.

---

## إخفاء التسمية

```
inline text-nolabel display{center, large}
```

## أفضل الممارسات

1. استخدم `inputs{auto-close(N)}` لمنع الماسح الضوئي من البقاء مفتوحًا إلى أجل غير مسمى - اختر قيمة تمنح المُحصين وقتًا كافيًا لوضع الباركود (من 8 إلى 15 ثانية هو المعتاد).
2. استخدم `inputs{floating}` عندما يحتاج النموذج إلى البقاء مرئيًا أثناء المسح (على سبيل المثال، المسح من قائمة حيث يرجع المُحصي إلى حقل مرئي).
3. ضع سؤال الباركود داخل مجموعة متكررة للمسح التسلسلي السريع - يؤدي التقدم التلقائي للتكرار إلى إلغاء خطوة "الإضافة" اليدوية.
4. قم دائمًا بتضمين عمود `hint` مع تعليمات تحديد المواقع (على سبيل المثال، "ضع الباركود على بعد 10-30 سم من الكاميرا، في إضاءة جيدة").
5. إدخال النص اليدوي في نموذج الماسح الضوئي متاح دائمًا - قم بتدريب المُحصين على استخدامه كبديل للباركود التالف أو المتسخ.

## القيود

- تعتمد دقة المسح على جودة الكاميرا والإضاءة وحالة الباركود - قد لا يتم مسح الرموز التالفة أو ذات التباين المنخفض بشكل موثوق.
- يستخدم الماسح الضوئي الكاميرا الخلفية (المواجهة للبيئة)؛ الأجهزة التي لا تحتوي على كاميرا خلفية تعود إلى خيار تحميل الصورة.
- `invisible auto-show` يفتح فقط عند تحميل الصفحة لأول مرة؛ لا يؤدي التنقل مرة أخرى إلى الصفحة إلى إعادة تشغيل الفتح التلقائي.

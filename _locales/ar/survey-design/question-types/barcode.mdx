title: "الباركود"
description: "تقوم أسئلة الباركود بمسح والتقاط رموز QR وبيانات الباركود في استبيانك."
---

يلتقط نوع السؤال `barcode` قيمة رمز عن طريق مسح رمز QR أو باركود باستخدام كاميرا الجهاز. يتضمن نموذج الماسح الضوئي أيضًا إدخالًا نصيًا يدويًا كخيار احتياطي عندما لا يكون المسح ممكنًا.

## مواصفات XLSForm الأساسية

| type    | name         | label                    |
|---------|--------------|--------------------------|
| barcode | product_code | امسح باركود المنتج |
| barcode | ticket_id    | امسح التذكرة |

للاطلاع على المواصفات القياسية، راجع [وثائق XLSForm](https://xlsform.org/en/#question-types).

---

## التنسيقات المدعومة

يدعم rtSurvey رموز QR والباركود أحادي الأبعاد القياسي عبر كاميرا الجهاز، بما في ذلك:

- QR Code
- UPC-A, UPC-E
- EAN-8, EAN-13
- Code 39, Code 128
- ITF, Codabar

---

## التخطيط الافتراضي

عند عدم تعيين `appearance`، يعرض السؤال زرًا بعرض كامل **"الحصول على باركود"**. يؤدي النقر عليه إلى فتح نموذج الماسح الضوئي. بعد مسح ناجح، يتغير الزر إلى **"استبدال باركود"** وتظهر القيمة الممسوحة ضوئيًا أدناه كرابط قابل للنقر.

---

## نموذج الماسح الضوئي

يتضمن نموذج الماسح الضوئي دائمًا:
- **عرض الكاميرا المباشر** — يقوم بالمسح تلقائيًا عند الكشف؛ يغلق النموذج بعد مسح ناجح.
- **إدخال نص يدوي** — حقل نصي في الأسفل حيث يمكن للمُعد كتابة الرمز إذا فشل المسح.
- **زر تم** — يرسل القيمة المكتوبة يدويًا.

عندما تكون كاميرا الجهاز غير متاحة، يعود النموذج إلى خيار **"تحميل صورة"** — يمكن للمُعد إرسال صورة للباركود لفك تشفيره.

---

## تخطيط الزر المضمّن

أضف `inline` لعرض الماسح الضوئي كـ **زر أيقونة دائري** بجانب التسمية بدلاً من زر بعرض كامل.

```
| type    | name | label     | appearance                              |
|---------|------|-----------|----------------------------------------|
| barcode | code | Scan item | inline display{right}                  |
| barcode | code | Scan item | inline display{left, large}            |
| barcode | code | Scan item | inline display{center, large, <0099FF/>} |
```

**موضع الزر** — `left`, `right` *(افتراضي)*, `top`, `center`, `bottom`

**حجم الزر** — `small` *(افتراضي)*, `medium`, `large`

**لون الزر** — أضف لونًا سداسيًا داخل `display{}` لتجاوز اللون الأساسي:

```
inline display{right, large, <FF5500/>}
```

**التحكم بعد الالتقاط — `results{}`:**

| Appearance | Effect |
|---|---|
| `results{hide(scanner)}` | يخفي زر المسح بعد التقاط قيمة |
| `results{hide(review)}` | يخفي رابط القيمة الممسوحة ضوئيًا بعد الالتقاط |
| `results{hide(value)}` | يخفي عرض نص القيمة الممسوحة ضوئيًا |
| `results{left}` | ينقل الأيقونة إلى اليسار بعد الالتقاط |

مثال — إخفاء الماسح الضوئي بعد المسح الأول:
```
inline display{center, large} results{hide(scanner)}
```

---

## `inputs{auto-close(N)}` — إغلاق الماسح الضوئي تلقائيًا

يغلق نموذج الماسح الضوئي تلقائيًا بعد `N` ثانية إذا لم يتم اكتشاف باركود. يتم عرض مؤقت للعد التنازلي المباشر داخل النموذج.

```
inputs{auto-close(10)}     → closes after 10 seconds
inputs{auto-close(5)}      → closes after 5 seconds
```

دمج مع inline:
```
inline display{right} inputs{auto-close(10)}
```

---

## `inputs{floating}` — ماسح ضوئي عائم قابل للسحب

يعرض **زر تصغير** (أيقونة الضغط ⊞) في رأس نموذج الماسح الضوئي. يؤدي النقر عليه إلى تصغير الماسح الضوئي إلى أيقونة دائرية صغيرة عائمة يمكن سحبها إلى أي مكان على الشاشة. يؤدي النقر على الأيقونة العائمة إلى إعادة فتح الماسح الضوئي.

```
inputs{floating}
inline display{right} inputs{floating}
```

مفيد في سير العمل حيث يحتاج المُعد إلى رؤية النموذج أثناء نشاط الماسح الضوئي (مثل مسح العناصر في قائمة).

---

## `invisible auto-show` — فتح الماسح الضوئي تلقائيًا

يخفي أداة السؤال من التخطيط ولكنه يفتح الماسح الضوئي تلقائيًا عند تحميل الصفحة. مفيد لدمج خطوة مسح صامتة في تدفق النموذج.

```
invisible auto-show
inline invisible auto-show
```

---

## في المجموعات المتكررة

عندما يكون `barcode` داخل مجموعة `begin repeat`، فإن المسح الناجح ينتقل تلقائيًا إلى **التكرار التالي** بعد تسجيل القيمة. يتيح ذلك المسح التسلسلي السريع دون الحاجة إلى النقر على "إضافة" بين العناصر.

---

## إخفاء التسمية

```
inline text-nolabel display{center, large}
```

## أفضل الممارسات

1. استخدم `inputs{auto-close(N)}` لمنع الماسح الضوئي من البقاء مفتوحًا إلى أجل غير مسمى — اختر قيمة تمنح المُعدين وقتًا كافيًا لوضع الباركود (8-15 ثانية هو النمط الشائع).
2. استخدم `inputs{floating}` عندما يحتاج النموذج إلى البقاء مرئيًا أثناء المسح (مثل المسح من قائمة حيث يرجع المُعد إلى حقل مرئي).
3. ضع سؤال الباركود داخل مجموعة متكررة للمسح التسلسلي السريع — التقدم التلقائي للتكرار يلغي خطوة "إضافة" اليدوية.
4. قم دائمًا بتضمين عمود `hint` مع تعليمات تحديد الموضع (مثل، "امسك الباركود على بعد 10-30 سم من الكاميرا، في إضاءة جيدة").
5. الإدخال النصي اليدوي في نموذج الماسح الضوئي متاح دائمًا — قم بتدريب المُعدين على استخدامه كخيار احتياطي للباركود التالف أو المتسخ.

## القيود

- تعتمد دقة المسح على جودة الكاميرا والإضاءة وحالة الباركود — قد لا يتم مسح الرموز التالفة أو ذات التباين المنخفض بشكل موثوق.
- يستخدم الماسح الضوئي الكاميرا الخلفية (المواجهة للبيئة)؛ الأجهزة التي لا تحتوي على كاميرا خلفية تعود إلى خيار تحميل الصورة.
- `invisible auto-show` يفتح فقط عند تحميل الصفحة لأول مرة؛ لا يؤدي التنقل إلى الصفحة مرة أخرى إلى إعادة تشغيل الفتح التلقائي.

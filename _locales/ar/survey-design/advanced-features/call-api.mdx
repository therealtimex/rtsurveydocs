---

تتيح ميزة **استدعاء API** لحقل الاستبيان إجراء طلب HTTP إلى خدمة خارجية واستخدام الاستجابة لملء قيمة محسوبة أو التحقق من صحة إدخال المستخدم. يتيح ذلك عمليات البحث في الوقت الفعلي، والتحقق من الهوية، وعمليات البحث عن الرمز الشريطي، وأي فحص آخر من جانب الخادم أثناء جمع البيانات.

توجد دالتان:

-   `callapi()` - تستحضر قيمة من API وتخزنها في حقل `calculate` أو `text`
-   `callapi-verify()` - تستدعي API وتمنع التقدم إذا لم تتطابق الاستجابة مع القيمة المتوقعة (تستخدم في `constraint`)

---

## `callapi()` — استحضار وتخزين استجابة API

### الصيغة

ضع `callapi()` في عمود **`calculation`** لحقل `calculate` أو `text`:

```
callapi(method, url, allowed_auto, max_retry, no_overwrite, extract_expr, timeout, lifetime, response_q, call_type, post_body)
```

### المعلمات

| # | المعلمة         | الوصف                                                |
|---|-----------------|------------------------------------------------------|
| 1 | `method`        | طريقة HTTP: `'GET'` أو `'POST'`                         |
| 2 | `url`           | عنوان URL لنقطة نهاية API                               |
| 3 | `allowed_auto`  | `1` للاستدعاء تلقائيًا عند الوصول إلى الحقل؛ `0` لطلب زر تشغيل يدوي |
| 4 | `max_retry`     | الحد الأقصى لعدد محاولات إعادة المحاولة عند الفشل         |
| 5 | `no_overwrite`  | `1` للاحتفاظ بالقيمة الموجودة إذا كان الحقل يحتوي عليها بالفعل؛ `0` للكتابة فوقها دائمًا |
| 6 | `extract_expr`  | تعبير JSONPath لاستخراج القيمة المطلوبة من الاستجابة (على سبيل المثال، `$.data.name`) |
| 7 | `timeout`       | مهلة الطلب بالمللي ثانية                                |
| 8 | `lifetime`      | المدة (بالمللي ثانية) التي تظل فيها الاستجابة المخزنة مؤقتًا صالحة قبل إعادة الاستحضار |
| 9 | `response_q`    | اسم حقل لتخزين رمز استجابة HTTP الخام (على سبيل المثال، `${response_status}`) |
| 10 | `call_type`    | *(اختياري)* وضع استدعاء خاص: `'lazy-upload'` أو `'lazy-upload-multiple'` |
| 11 | `post_body`    | *(اختياري)* سلسلة نص POST. ارجع إلى حقول النموذج باستخدام `##fieldname##` |

### مثال: طلب GET للبحث عن أسرة باستخدام المعرف

| type | name | label | appearance | calculation |
|------|-------|------------|------------|-----------------------------------------------------------------------------------------|
| text | household_id | معرف الأسرة | | |
| calculate | hh_name | | callapi | `callapi('GET', concat('https://api.example.com/households/', ${household_id}), 1, 3, 0, '$.name', 10000, 0, '')` |
| note | hh_display | الأسرة: `${hh_name}` | | |

### مثال: طلب POST مع نص JSON

```
callapi('POST', 'https://api.example.com/lookup', 1, 2, 0, '$.result.value', 15000, 0, '', '', '{"id": "##household_id##"}')
```

في `post_body`، استخدم `##fieldname##` لإدخال القيمة الحالية لأي حقل نموذج.

### المظهر: `callapi`

أضف `callapi` إلى عمود `appearance` للحقل لتمكين تكامل استدعاء API:

| type | name | label | appearance | calculation |
|------|-------|------------|------------|---------------------|
| calculate | api_result | | callapi | `callapi('GET', ...)` |

عندما تكون `allowed_auto` تساوي `0`، يعرض rtSurvey **زر "استحضار"** الذي ينقر عليه المُعدّ يدويًا.

## `callapi-verify()` — التحقق من صحة قيمة مقابل API

`callapi-verify()` يمنع إرسال حقل حتى يؤكد API أن القيمة المدخلة صالحة. استخدمها في عمود **`constraint`**.

### الصيغة

```
callapi-verify(method, url, extract_expr, match_expr, timeout, constraint_mode, post_body, message)
```

### المعلمات

| # | المعلمة             | الوصف                                                |
|---|---------------------|------------------------------------------------------|
| 1 | `method`            | طريقة HTTP: `'GET'` أو `'POST'`                         |
| 2 | `url`               | نقطة نهاية API للتحقق                                   |
| 3 | `extract_expr`      | JSONPath لاستخراج القيمة المتوقعة من الاستجابة         |
| 4 | `match_expr`        | تعبير يقارن القيمة المستخرجة بقيمة الحقل (على سبيل المثال، `$.status = 'valid'`) |
| 5 | `timeout`           | مهلة الطلب بالمللي ثانية                                |
| 6 | `constraint_mode`   | `'soft'` للتحذير فقط؛ `'hard'` لمنع التقدم              |
| 7 | `post_body`         | *(اختياري)* نص POST مع استبدالات `##fieldname##`         |
| 8 | `message`           | *(اختياري)* رسالة خطأ. تدعم لغات متعددة: `<en>Invalid!</en><vi>Không hợp lệ!</vi>` |

### مثال: التحقق من رمز شريطي مقابل سجل الأصول

| type | name | label | appearance | constraint | constraint_message |
|------|-------|------------|------------------|---------------------------------------------------------------------------------------------------------------|-----------------------------|
| barcode | asset_code | امسح الرمز الشريطي للأصل | callapi-verify | `callapi-verify('POST', 'https://api.example.com/assets/verify', '$.valid', ". = 'true'", 10000, 'hard', '{"code": "##asset_code##"}')` | الأصل غير موجود في السجل |

### المظهر: `callapi-verify(...)`

يجب أن يحتوي عمود `appearance` في حقل به `callapi-verify()` في القيد على `callapi-verify(params)` أو `callapi-verify(dynamicParams)` للإشارة إلى rtSurvey أن هذا الحقل يستخدم التحقق من API.

## استخدام بيانات App API جنبًا إلى جنب مع callapi

اجمع `callapi()` مع `pulldata('app-api', 'user.token')` لإدخال رمز المستخدم المصادق عليه في طلب API الخاص بك:

```
callapi('POST', 'https://api.example.com/data', 1, 2, 0, '$.value', 10000, 0, '', '',
  concat('{"token":"', pulldata('app-api','user.token'), '","id":"##item_id##"}'))
```

## أفضل الممارسات

1.  عيّن دائمًا `timeout` معقولاً (5000-15000 مللي ثانية) - لا تستخدم 0 أو قيمًا عالية جدًا.
2.  عيّن `allowed_auto=0` لعمليات التحقق التي يجب أن يقوم بها المُعدّ بوعي (على سبيل المثال، فحوصات الهوية).
3.  عيّن `no_overwrite=1` عندما يمكن تحرير الحقل لاحقًا ولا تريد أن تؤدي إعادة الاستحضار إلى الكتابة فوق التصحيحات اليدوية.
4.  استخدم `extract_expr` مع JSONPath محدد بدلاً من الاعتماد على نص الاستجابة الخام.
5.  اختبر استدعاءات API في وضع عدم الاتصال - سيفشل callapi بأمان ويعرض خطأ، ولكن يجب أن يظل النموذج قابلاً للإكمال للحقول غير الحرجة.

## القيود

-   يتطلب اتصال شبكة في وقت الاستدعاء - ستفشل الاستدعاءات عندما يكون الجهاز غير متصل بالإنترنت.
-   يجب أن تكون استجابات API بتنسيق JSON - تتطلب استجابات XML أو النص العادي تحليلًا إضافيًا.
-   يمكن أن يؤدي التردد العالي للاستدعاء (على سبيل المثال، استدعاء API واحد لكل مثيل متكرر) إلى إبطاء التنقل في النموذج.

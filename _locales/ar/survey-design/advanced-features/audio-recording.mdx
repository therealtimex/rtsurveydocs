يتيح تسجيل الصوت للنموذج التقاط الصوت بصمت أو بشكل مرئي خلال جزء من المسح. إنه مفيد لتسجيل المقابلات، أو الصوت المحيط أثناء الملاحظات الميدانية، أو الاستجابات المنطوقة التي تكمل الإجابات المنظمة.

---

<Callout type="warning">
**تطبيق الهاتف المحمول فقط.** يتطلب تسجيل الصوت تطبيق rtSurvey للهاتف المحمول. في نموذج الويب، يتم تجاهل مظاهر `audio-start` و `audio-end` بصمت — لا يتم التسجيل ولا يتم عرض أي خطأ. اختبر دائماً على الجهاز عندما يكون تسجيل الصوت مطلوباً.

## كيف يعمل

يتم التحكم في تسجيل الصوت بواسطة حقلين من نوع `text` يعملان **كعلامات**:

- يبدأ الحقل الذي يحتوي على مظهر `audio-start` التسجيل عندما يصل العداد إليه.
- يوقف الحقل الذي يحتوي على مظهر `audio-end` التسجيل ويحفظ ملف الصوت في الإرسال.

كلا حقلي العلامات هما من نوع `text`. عادة ما يكونان مخفيين عن العداد (باستخدام `relevant = false` أو وضعهما في موضع غير تفاعلي)، على الرغم من أنه يمكن أن يكونا مرئيين. يتم إرفاق الصوت المسجل بالإرسال كملف مرتبط بحقل `audio-end`.

---

## مثال أساسي

| type | name | label | appearance |
|------|------|-------|------------|
| text | audio_s_a1 | | `audio-start` |
| text | q_name | Respondent name | |
| text | q_occupation | Occupation | |
| integer | q_age | Age | |
| text | audio_e_a1 | | `audio-end` |

يبدأ التطبيق التسجيل عندما يصل العداد إلى `audio_s_a1` ويتوقف عندما يصل إلى `audio_e_a1`. يتم تسجيل جميع الأسئلة بين العلامتين.

---

## التسجيل الصامت: `audio-start invisible`

بشكل افتراضي، يعرض تطبيق الهاتف المحمول مؤشر تسجيل أثناء التقاط الصوت. تؤدي إضافة `invisible` إلى المظهر إلى إخفاء هذا المؤشر، بحيث يتم التسجيل دون أي تنبيه مرئي للمستجيب.

| type | name | label | appearance |
|------|------|-------|------------|
| text | audio_s_a1 | | `audio-start invisible` |
| text | q_consent | Do you agree to participate? | |
| text | q_feedback | Your feedback | |
| text | audio_e_a1 | | `audio-end` |

استخدم `invisible` فقط عندما يتم استيفاء متطلبات الإفصاح من خلال وسائل أخرى (على سبيل المثال، حقل موافقة كتابي منفصل قبل قسم التسجيل).

---

## اتفاقية التسمية

تستخدم نماذج الإنتاج نمط تسمية ثابت لحقول العلامات:

```
audio_s_{section}{n}   — علامة البداية
audio_e_{section}{n}   — علامة النهاية
```

حيث يكون `{section}` عبارة عن تسمية قصيرة لقسم النموذج و `{n}` هو رقم تسلسلي داخل ذلك القسم.

| Field name | Role | Meaning |
|------------|------|---------|
| `audio_s_a1` | Start | First recording in section A |
| `audio_e_a1` | End | End of first recording in section A |
| `audio_s_b1` | Start | First recording in section B |
| `audio_e_b1` | End | End of first recording in section B |
| `audio_s_a2` | Start | Second recording in section A |
| `audio_e_a2` | End | End of second recording in section A |

يؤدي اتباع هذا التقليد إلى تسهيل تحديد حدود التسجيل عند مراجعة تعريفات النموذج وبيانات الإرسال.

---

## التخزين والاسترجاع

عندما يصل العداد إلى حقل `audio-end` ، يقوم التطبيق بإنهاء ملف الصوت وإرفاقه بالإرسال. الملف هو:

- يتم تخزينه كمرفق صوتي في الإرسال، مرتبطاً باسم حقل `audio-end`.
- يمكن الوصول إليه في عارض إرسال الواجهة الخلفية لـ rtSurvey جنباً إلى جنب مع مرفقات الوسائط الأخرى.
- قابل للتنزيل عبر تصدير الإرسال القياسي — تظهر ملفات الصوت في عمود الوسائط المقابل لاسم حقل `audio-end`.

يعتمد تنسيق الملف ومعدل البت على الجهاز وإصدار التطبيق.

---

## أقسام تسجيل متعددة

يمكن أن يحتوي النموذج على عدة أقسام تسجيل غير متداخلة. يجب احتواء كل زوج من علامات `audio-start` / `audio-end` بالكامل — يجب ألا تتداخل الأقسام.

| type | name | label | appearance |
|------|------|-------|------------|
| text | audio_s_a1 | | `audio-start` |
| text | q_intro | Introduction | |
| text | audio_e_a1 | | `audio-end` |
| note | section_break | — | |
| text | audio_s_b1 | | `audio-start invisible` |
| text | q_detail | Details | |
| text | audio_e_b1 | | `audio-end` |

ينتج كل قسم ملف صوت منفصل مرفق بحقل `audio-end` المقابل له.

---

## القيود

- **تطبيق الهاتف المحمول فقط.** هذه الميزة غير مدعومة في نموذج الويب. يتم تجاهل `audio-start` و `audio-end` بصمت في المتصفح.
- **لا تداخل.** لا يمكن أن تتداخل أقسام التسجيل. بدء تسجيل جديد قبل الوصول إلى علامة `audio-end` السابقة غير مدعوم.
- **يجب أن يكون نوع الحقل `text`.** استخدام `audio-start` أو `audio-end` في أي نوع سؤال آخر غير مدعوم.
- **حجم الرفع.** التسجيلات الطويلة تنتج ملفات كبيرة. كن على دراية بحدود حجم الإرسال وظروف الشبكة في الميدان.
- **لا يوجد إيقاف مؤقت في منتصف التسجيل.** يعمل التسجيل بشكل مستمر من علامة البداية إلى علامة النهاية؛ لا توجد آلية للإيقاف المؤقت والاستئناف داخل القسم.

يقوم rtSurvey بتقديم نص **التسمية (label)** و**التلميح (hint)** كـ HTML على نماذج الويب. هذا يعني أنه يمكنك استخدام علامات HTML القياسية لتنسيق النص، وإضافة فواصل الأسطر، وإنشاء الروابط، وتطبيق الألوان. هذا مفيد بشكل خاص لحقول الملاحظات، وتعليمات الأقسام، والملخصات الديناميكية.

<Callout type="warning">
يتم عرض HTML في التسميات على **نموذج الويب** وتطبيقات rtSurvey للهواتف المحمولة. قد لا يتم عرضه في جميع العملاء المتوافقين مع ODK. اختبر دائماً على منصتك المستهدفة.
</Callout>

## علامات HTML المدعومة

### تنسيق النص

| العلامة | النتيجة |
|-----|--------|
| `<strong>text</strong>` أو `<b>text</b>` | **نص عريض** |
| `<em>text</em>` أو `<i>text</i>` | *نص مائل* |
| `<u>text</u>` | نص تحته خط |
| `<br>` | فاصل أسطر |
| `<span style="...">text</span>` | تنسيق مضمن |

### الروابط

```html
<a href="https://example.com" target="_blank">Click here</a>
```

يفتح في علامة تبويب جديدة. استخدمه للمستندات المرجعية، أو الإرشادات، أو الموارد الخارجية التي يجب على الباحث استشارتها.

### الألوان

استخدم `<span>` مع الأنماط المضمنة:

```html
<span style="color: red;">Warning: value is out of range</span>
<span style="color: #009688;">Section completed</span>
```

## متغيرات سمة اللون

يدعم rtSurvey **رموز سمات الألوان** التي تتكيف مع السمة المكونة للتطبيق. استخدم بناء الجملة `__COLOR_THEME_NAME__`:

```html
<span style="color: var(--color-theme-primary);">Primary color text</span>
```

أو استخدام اختصار الرمز في نص التسمية:

```
<font color="var(--COLOR_THEME_PRIMARY)">Important note</font>
```

يتم تحويل هذا تلقائياً إلى ما يعادل `<span>` مع متغير CSS في وقت العرض.

## التسميات متعددة اللغات

قم بلف المحتوى في علامات اللغة لدعم لغات متعددة في خلية تسمية واحدة:

```
<en>Enter the household size</en><vi>Nhập quy mô hộ gia đình</vi>
```

يستخرج rtSurvey المحتوى المطابق للغة التطبيق الحالية. إذا لم يتم العثور على علامة لغة مطابقة، يتم عرض السلسلة الكاملة كما هي.

### تعليمات القسم مع نص عريض وفاصل أسطر

| type | name | label |
|------|------|-------|
| note | section_intro | `<strong>Section 3: Land Use</strong><br>Ask all questions in this section to the household head only.` |

### ملخص ديناميكي مع مرجع حسابي

| type | name | label |
|------|------|-------|
| calculate | total | | `${adults} + ${children}` |
| note | summary | `Total household members: <strong>${total}</strong><br><span style="color: gray;">Adults: ${adults} · Children: ${children}</span>` |

| type | name | label | relevant |
|------|------|-------|----------|

| type | name | label |
|------|------|-------|

## علامات HTML الخاصة بـ rtSurvey

### `<webbox src='url' title='title'>...</webbox>`

يضمن زراً يفتح عنوان URL في نافذة منبثقة داخل النموذج. انظر [Webbox](webbox) للحصول على التفاصيل الكاملة.

### `<delete-repeat-current>label</delete-repeat-current>`

يعرض زراً داخل مجموعة تكرار يحذف مثيل التكرار الحالي عند النقر عليه.

### `<delete-repeat-last>label</delete-repeat-last>`

يعرض زراً يحذف آخر مثيل تكرار.

مثال على الاستخدام في مجموعة تكرار:

| type | name | label |
|------|------|-------|
| note | delete_btn | `<delete-repeat-current>Remove this member</delete-repeat-current>` |

## ملخصات HTML الديناميكية باستخدام autopull()

يقوم `autopull()` بعرض كتلة من HTML داخل حقل `note` و**يعيد تقييمها عند كل تغيير في الحقل** في النموذج. وهذا يجعله مناسباً للوحات الملخص المباشرة، وشاشات المراجعة قبل الإرسال، والمجاميع الجارية التي يتم تحديثها بينما يقوم الباحث بملء البيانات.

<Callout type="info">
يعمل `autopull()` فقط على حقول **الملاحظات (note)**. يتم تجاهل عمود التسمية (label) — يجب توفير جميع محتويات HTML من خلال عمود **المظهر (appearance)** باستخدام `concat()`.
</Callout>

### بناء الجملة

ضع `autopull()` في عمود **المظهر (appearance)** لحقل `note`:

```
autopull(concat('<html>...</html>'))
```

يتم استبدال مراجع الحقول (`${field_name}`) داخل `concat()` بالقيم المباشرة الحالية ويتم إعادة عرض HTML عند كل تغيير.

### تقييد الارتفاع باستخدام scroll-view()

للملخصات الأطول، ادمج `autopull()` مع `scroll-view(N%)` لتحديد ارتفاع اللوحة وجعلها قابلة للتمرير:

```
scroll-view(45%) autopull(concat('<html>...</html>'))
```

قيمة `N%` نسبية لمنطقة النموذج المرئية. `45%` هو افتراضي عملي للوحة ملخص في منتصف الصفحة.

### مثال كامل — ملخص موقع الأسرة المعيشية

يعرض حقل `note` التالي جدولاً من عمودين يوضح المقاطعة والمنطقة والكوميونة المختارة. يتم تحديثه تلقائياً عندما يتغير `${tinh_name}` أو `${huyen_name}` أو `${xa_name}`.

| type | name | label | appearance |
|------|------|-------|------------|
| note | location_summary | | `scroll-view(45%) autopull(concat('<html><table style="width:100%;border-collapse:collapse"><tr><td style="padding:4px;font-weight:bold">Province:</td><td style="padding:4px">', ${tinh_name}, '</td></tr><tr><td style="padding:4px;font-weight:bold">District:</td><td style="padding:4px">', ${huyen_name}, '</td></tr><tr><td style="padding:4px;font-weight:bold">Commune:</td><td style="padding:4px">', ${xa_name}, '</td></tr></table></html>'))` |

في XLSForm يتم كتابة قيمة المظهر عبر خلية واحدة:

```
scroll-view(45%) autopull(concat(
  '<html><table style="width:100%;border-collapse:collapse">
   <tr><td style="padding:4px;font-weight:bold">Province:</td>
       <td style="padding:4px">', ${tinh_name}, '</td></tr>
   <tr><td style="padding:4px;font-weight:bold">District:</td>
       <td style="padding:4px">', ${huyen_name}, '</td></tr>
   <tr><td style="padding:4px;font-weight:bold">Commune:</td>
       <td style="padding:4px">', ${xa_name}, '</td></tr>
   </table></html>'))
```

### الأنماط المضمنة

يتم دعم سمات `style="..."` المضمنة في أي عنصر HTML وهي الطريقة الموصى بها لتطبيق التنسيق المرئي داخل كتل `autopull()`.

ما يلي **غير** مدعوم داخل محتوى `autopull()`:

- كتل `<style>`
- علامات `<link>` لصفحات الأنماط الخارجية
- JavaScript (`<script>`)

### متى تستخدم autopull()

| حالة الاستخدام | ملاحظات |
|----------|-------|
| شاشة المراجعة قبل الإرسال | عرض جميع الإجابات الرئيسية في لوحة واحدة قبل أن ينتهي الباحث |
| المجاميع الجارية | عرض مجموع محسوب يتم تحديثه عند إدخال الكميات |
| لوحة مرجعية مرئية | عرض قيمة بحث مختارة (مثل اسم المقاطعة) بينما يقوم الباحث بملء الحقول التابعة |

## أفضل الممارسات

1. استخدم HTML باعتدال — التسميات المنسقة بشكل مفرط يصعب قراءتها.
2. فضل `<strong>` للخط العريض و `<em>` للخط المائل على `<b>` و `<i>` المهجورة.
3. اجعل استخدام الألوان ذا معنى — استخدم اللون الأحمر للتحذيرات، وليس للزينة.
4. اختبر دائماً عرض HTML على كل من تطبيق الهاتف المحمول ونموذج الويب، حيث قد يختلف العرض قليلاً.
5. تجنب علامات `<table>` داخل التسميات — نادراً ما يتم عرضها بشكل جيد على شاشات الهاتف المحمول.
6. لا تستخدم JavaScript (`<script>`) — سيتم تجريده أو يسبب أخطاء.

## القيود

- HTML المعقد (الجداول، النماذج، البرامج النصية) غير مدعوم وقد يكسر العرض.
- قد تعرض بعض الأجهزة المحمولة القديمة علامات HTML كنص حرفي — اختبر على جميع الأجهزة المستهدفة.
- تفتح روابط `<a>` في متصفح أو WebView — يغادر الباحث النموذج، مما قد يكون مزعجاً على الهاتف المحمول.

تغطي هذه الصفحة الأنماط المتقدمة للعمل مع مجموعات التكرار في rtSurvey. للحصول على أساسيات إعداد مجموعة تكرار، راجع [التجميع والتكرارات](../repeats).

---

## عدد تكرار ديناميكي

بشكل افتراضي، يقرر الباحث عدد مرات التكرار. يمكنك تثبيت عدد التكرارات باستخدام `repeat_count`:

| type | name | label | repeat_count |
|------|------|-------|--------------|
| begin_repeat | household_members | فرد الأسرة | `${num_members}` |
| text | member_name | اسم الفرد | |
| integer | member_age | العمر | |
| end_repeat | | | |

يتم تشغيل التكرار بالضبط `${num_members}` مرة، حيث تم جمع `num_members` في وقت سابق من النموذج. لا يمكن للباحث إضافة أو إزالة حالات.

---

## الوصول المفهرس: `indexed-repeat()`

الوصول إلى قيمة حقل حالة تكرار محددة من **خارج** مجموعة التكرار باستخدام `indexed-repeat(repeatedField, repeatGroup, index)`:

| type | name | label | calculation |
|------|------|-------|-------------|
| calculate | first_name | | `indexed-repeat(${member_name}, ${household_members}, 1)` |
| calculate | second_name | | `indexed-repeat(${member_name}, ${household_members}, 2)` |

هذا مفيد لبناء حقول ملخص أو الإشارة إلى بيانات العضو "الأساسي" بعد التكرار.

---

## موضع الحالة الحالية: `index()`

داخل مجموعة تكرار، يعيد `index()` الموضع القائم على 1 للحالة الحالية. استخدمه لتسمية كل تكرار أو إنشاء معرفات فريدة:

| type | name | label |
|------|------|-------|
| begin_repeat | plots | قطعة أرض |
| note | plot_label | قطعة أرض رقم `${index()}` |
| text | plot_id | معرف قطعة الأرض |
| end_repeat | | |

---

## الإشارة إلى الحقول في نفس الحالة

داخل التكرار، استخدم `${fieldname}` للإشارة إلى حقل آخر **في نفس حالة التكرار**. ليست هناك حاجة لـ `indexed-repeat()` داخل نفس الحلقة:

| type | name | label | relevant |
|------|------|-------|----------|
| begin_repeat | members | عضو | |
| text | member_name | الاسم | |
| integer | member_age | العمر | |
| text | school_name | اسم المدرسة | `${member_age} < 18` |
| end_repeat | | | |

---

## الإشارة إلى الحقول الأب من داخل التكرار

يمكن الإشارة إلى الحقول خارج (فوق) مجموعة التكرار بشكل طبيعي باستخدام `${fieldname}`:

| type | name | label |
|------|------|-------|
| text | village | اسم القرية |
| begin_repeat | plots | قطعة أرض زراعية |
| note | plot_context | قطع الأراضي في `${village}` |
| end_repeat | | |

## تلخيص بيانات التكرار

استخدم دوال تجميع التكرار **خارج** مجموعة التكرار للتلخيص:

| دالة | مثال | وصف |
|----------|---------|-------------|
| `count(group)` | `count(${household_members})` | عدد الحالات |
| `sum(field)` | `sum(${loan_amount})` | مجموع حقل رقمي |
| `min(field)` | `min(${member_age})` | الحد الأدنى للقيمة |
| `max(field)` | `max(${member_age})` | الحد الأقصى للقيمة |
| `join(sep, field)` | `join(', ', ${member_name})` | قائمة مفصولة بفواصل |
| `count-if(group, expr)` | `count-if(${members}, ${member_age} < 18)` | عد مشروط |
| `sum-if(field, expr)` | `sum-if(${loan_amount}, ${loan_amount} > 500)` | جمع مشروط |
| `join-if(sep, field, expr)` | `join-if(', ', ${name}, ${age} >= 18)` | دمج مشروط |

### مثال: ملخص الأسرة

| type | name | label | calculation |
|------|------|-------|-------------|
| integer | num_members | كم عدد الأعضاء؟ | |
| begin_repeat | members | عضو | `${num_members}` |
| text | member_name | الاسم | |
| integer | member_age | العمر | |
| end_repeat | | | |
| calculate | total_members | | `count(${members})` |
| calculate | children_count | | `count-if(${members}, ${member_age} < 18)` |
| calculate | adult_names | | `join-if(', ', ${member_name}, ${member_age} >= 18)` |
| note | summary | `${total_members}` أعضاء؛ `${children_count}` تحت 18. البالغون: `${adult_names}` | |

## التكرارات المتداخلة

يمكن أن تحتوي مجموعة التكرار على مجموعة تكرار أخرى. استخدم هذا بعناية — تضيف التكرارات المتداخلة تعقيداً ويمكن أن تكون مربكة للباحثين.

| type | name | label |
|------|------|-------|
| begin_repeat | households | أسرة |
| text | hh_id | معرف الأسرة |
| begin_repeat | hh_members | عضو |
| text | member_name | اسم العضو |
| end_repeat | | |
| end_repeat | | |

للإشارة إلى حقل في تكرار خارجي من التكرار الداخلي، استخدم `${fieldname}` — حيث يتم حله إلى أقرب سلف مطابق:

داخل تكرار `hh_members` ، يعيد `${hh_id}` المعرف الخاص بالأسرة **الحالية** ، وليس كل الأسر.

## الرتبة داخل مجموعات التكرار: `rank-index()`

عند وجود حقل `rank` داخل التكرار، استخدم `rank-index(instanceNumber, repeatedField)` من الخارج للحصول على الرتبة الترتيبية لحالة محددة:

| type | name | label | calculation |
|------|------|-------|-------------|
| calculate | top_scorer | | `rank-index(1, ${score})` |

يعيد `rank-index(1, ${score})` فهرس الحالة ذات أعلى درجة.

## مظهر `1screen` على `begin_repeat`

يؤدي إضافة `1screen` إلى عمود `appearance` لصف `begin_repeat` إلى عرض جميع الأسئلة لكل حالة معاً في شاشة واحدة، بدلاً من سؤال واحد لكل شاشة.

| type | name | label | appearance |
|------|------|-------|------------|
| begin_repeat | household_members | فرد الأسرة | `1screen` |
| text | member_name | اسم الفرد | |
| integer | member_age | العمر | |
| end_repeat | | | |

عند تعيين `1screen` وعدم وجود حقل `repeat_count` ولا حقل `add_repeat` داخل المجموعة، يقوم rtSurvey تلقائياً بعرض زر **+** دائري في أسفل الشاشة حتى يتمكن الباحثون من إضافة حالات جديدة دون أي تكوين إضافي.

| المظهر | شاشة واحدة لكل حالة | تمت إضافة زر + الافتراضي |
|------------|-------------------------|------------------------|
| `1screen` | نعم | نعم (عند عدم وجود ابن `add_repeat`) |
| `field-list` | نعم | لا |

استخدم `field-list` عندما تريد التخطيط المجمع بدون زر الإضافة التلقائي. استخدم `1screen` عندما تريد كل من التخطيط المجمع وطريقة مدمجة لإضافة الحالات.

---

## زر إضافة مخصص `add_repeat`

حقل `note` (أو `text`) يوضع **داخل** مجموعة التكرار مع `appearance: add_repeat` يظهر كزر "إضافة" بعرض كامل. تسمية الزر تأتي من عمود `label` للحقل. عند وجود حقل `add_repeat` ، يتم إخفاء زر + الدائري الافتراضي (من `1screen`).

ضع حقل `add_repeat` كآخر حقل داخل مجموعة التكرار:

| type | name | label | appearance |
|------|------|-------|------------|
| begin_repeat | members | عضو | `1screen` |
| text | member_name | اسم الفرد | |
| integer | member_age | العمر | |
| note | btn_add | + إضافة عضو | `add_repeat` |
| end_repeat | | | |

### تخصيص اللون

مرر رمز لون داخل قيمة المظهر لتنسيق الزر:

| قيمة المظهر | النتيجة |
|------------------|--------|
| `add_repeat <#04B404/>` | خلفية خضراء، لون النص الافتراضي |
| `add_repeat 04B404-ffffff` | خلفية خضراء، نص أبيض |

اللون الأول هو الخلفية والثاني (بعد الشرطة) هو لون النص. احذف `#` عند استخدام التنسيق المفصول بشرطة.

### نوع الأيقونة

استخدم `add_repeat icon` (مع مسافة) لعرض زر أيقونة دائري مضغوط بدلاً من الزر كامل العرض:

| type | name | label | appearance |
|------|------|-------|------------|
| note | btn_add | + إضافة | `add_repeat icon` |

## أزرار الحذف: `delete-repeat-current` و `delete-repeat-last`

حقل `note` داخل مجموعة التكرار مع `appearance: delete-repeat-current` أو `appearance: delete-repeat-last` يظهر كزر حذف منقسم.

| المظهر | الإجراء |
|------------|--------|
| `delete-repeat-current` | يحذف الحالة الحالية (النشطة) |
| `delete-repeat-last` | يحذف الحالة الأخيرة في التكرار |

الزر الافتراضي (بدون أيقونة) هو زر منقسم: أيقونة سلة المهملات على اليسار ونص تسمية الحقل على اليمين، ويمتد على العرض الكامل للشاشة.

### نوع الأيقونة

أضف `-icon` للحصول على زر أيقونة سلة مهملات دائري مضغوط:

| المظهر | النتيجة |
|------------|--------|
| `delete-repeat-current-icon` | أيقونة سلة مهملات دائرية، يحذف الحالة الحالية |
| `delete-repeat-last-icon` | أيقونة سلة مهملات دائرية، يحذف الحالة الأخيرة |

### تخصيص اللون

تنسيق اللون مطابق لـ `add_repeat`: استخدم `<#RRGGBB/>` أو `RRGGBB-RRGGBB` (خلفية-نص).

### مثال النمط الكامل

يستخدم التكرار التالي `1screen` ، وزر حذف الحالة الحالية الدائري في الأعلى، وزر إضافة كامل العرض في الأسفل:

| type | name | label | appearance |
|------|------|-------|------------|
| begin_repeat | members | عضو | `1screen` |
| note | btn_del | إزالة | `delete-repeat-current-icon` |
| text | member_name | اسم الفرد | |
| integer | member_age | العمر | |
| note | btn_add | + إضافة عضو | `add_repeat` |
| end_repeat | | | |

## أفضل الممارسات

1. استخدم دائماً `repeat_count` عندما يكون عدد التكرارات معروفاً مسبقاً — فهذا يمنع الباحثين من إضافة أو إزالة الحالات عن طريق الخطأ.
2. حافظ على تركيز مجموعات التكرار — يصعب التنقل في تكرار يحتوي على أكثر من 20 سؤالاً لكل حالة.
3. سمِّ مجموعات التكرار بوضوح (مثلاً، `household_members` ، وليس `repeat1`) — يظهر الاسم في استدعاءات الدوال والبيانات المصدرة.
4. اختبر مع الحد الأقصى المتوقع لعدد الحالات للتحقق من الأداء.
5. استخدم `1screen` في `begin_repeat` لعرض جميع الأسئلة في شاشة واحدة لكل حالة، مقترنة بحقل ملاحظة `add_repeat` داخل المجموعة لمنح الباحثين زر "إضافة" مصنف بوضوح.

---

## القيود

- يتطلب `indexed-repeat()` فهرساً صالحاً (من 1 إلى عدد الحالات) — الفهارس خارج النطاق تعيد قيمة فارغة.
- لا يوصى بالتكرارات المتداخلة التي تتجاوز مستويين وقد تسبب مشكلات في العرض على بعض العملاء.
- تعمل دوال التجميع (`sum` ، `count` ، إلخ) على مجموعة التكرار بأكملها — لا يمكنك تجميع مجموعة فرعية من الحالات بدون متغيرات `*-if`.

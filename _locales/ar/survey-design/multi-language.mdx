يوفر rtSurvey دعماً قوياً للغات المتعددة، مما يتيح لك إنشاء استطلاعات بلغات متنوعة. هذه الميزة حيوية لإجراء الأبحاث عبر مجموعات سكانية لغوية متنوعة أو في بيئات متعددة اللغات.

## إعداد الاستطلاعات متعددة اللغات

لإنشاء استطلاع متعدد اللغات في rtSurvey، تحتاج إلى إضافة أعمدة خاصة بكل لغة إلى ملف XLSForm الخاص بك. إليك الطريقة:

1. **ترجمة التسميات (Labels)**: أضف أعمدة لكل لغة باستخدام التنسيق `label::Language (code)`.
2. **ترجمة التلميحات (Hints)**: استخدم `hint::Language (code)` لترجمة التلميحات.
3. **ترجمة ملفات الوسائط**: بالنسبة للوسائط الخاصة بلغة معينة، استخدم `media::Language (code)`.

مثال:

```
| type    | name | label::English (en) | label::Arabic (ar) | hint::English (en) | hint::Arabic (ar) |
|---------|------|---------------------|---------------------|---------------------|---------------------|
| integer | age  | How old are you?    | ما هو عمرك؟         | Enter your age      | أدخل عمرك           |
```

## رموز اللغات

يُنصح باستخدام رموز اللغات الرسمية المكونة من حرفين (الرموز الفرعية) بعد اسم اللغة. هذا يسهل مطابقة لغة النموذج مع لغة واجهة المستخدم. يمكنك العثور على الرموز الرسمية [هنا](https://www.iana.org/assignments/language-subtag-registry/language-subtag-registry).

## تعيين لغة افتراضية

لتعيين لغة افتراضية لجمع البيانات، استخدم ورقة العمل `settings` في ملف XLSForm الخاص بك:

```
| form_id   | version | default_language |
|-----------|---------|-------------------|
| test_form | 101     | Arabic (ar)       |
```

## ميزات rtSurvey الخاصة

### التبديل الديناميكي للغة

يتيح rtSurvey للمستخدمين تبديل اللغات ديناميكياً أثناء جمع البيانات:

- في واجهة الويب، استخدم القائمة المنسدلة للغة في شريط التنقل العلوي.
- في تطبيق الهاتف المحمول، يمكنك الوصول إلى خيارات اللغة من خلال قائمة الإعدادات.

### رسائل التحقق الخاصة باللغة

يمد rtSurvey دعم اللغات المتعددة ليشمل رسائل التحقق:

```
| type    | name | constraint | constraint_message::English (en) | constraint_message::Arabic (ar) |
|---------|------|------------|----------------------------------|----------------------------------|
| integer | age  | . <= 150   | Age must be 150 or less          | يجب أن يكون العمر 150 أو أقل    |
```

### رسائل الحقول المطلوبة المترجمة

استخدم `required_message::Language (code)` لإظهار خطأ مترجم عندما يُترك حقل مطلوب فارغاً:

```
| type | name | required | required_message::English (en) | required_message::Arabic (ar) |
|------|------|----------|-------------------------------|----------------------------------|
| text | name | yes      | This field is required        | هذا الحقل مطلوب                  |
```

### دعم لغات RTL (من اليمين إلى اليسار)

بالنسبة للغات التي تُكتب من اليمين إلى اليسار (RTL) مثل العربية أو العبرية، يقوم rtSurvey تلقائياً بتعديل التنسيق:

```
| type | name | label::English (en) | label::Arabic (ar) |
|------|------|---------------------|---------------------|
| text | name | Your name           | اسمك                |
```

### المظهر الخاص باللغة

يتيح لك rtSurvey تحديد مظاهر مختلفة للغات المختلفة:

```
| type | name | label::English (en) | label::Chinese (zh) | appearance::English (en) | appearance::Chinese (zh) |
|------|------|---------------------|---------------------|--------------------------|---------------------------|
| text | address | Address          | 地址                 | multiline                | textarea                  |
```

## تنسيق HTML في التسميات ثنائية اللغة

يمكنك دمج علامات HTML مع أغلفة اللغة في خلية تسمية واحدة. يقوم rtSurvey باستخراج كتلة اللغة النشطة وعرض تنسيق HTML المتبقي.

مثال باستخدام الخط العريض ولون الخط لكل لغة:

```
<en><big><b>Section 2: Household Income</b></big><br>Ask the household head only.</en><ar><big><b>القسم 2: دخل الأسرة</b></big><br>اسأل رئيس الأسرة فقط.</ar>
```

العلامات المضمنة المدعومة داخل أغلفة اللغة: `<b>`, `<i>`, `<u>`, `<big>`, `<small>`, `<font color="...">`, `<br>`, `<span style="...">`.

مثال لنص ملون لكل لغة:

```
<en><font color="red">Required field</font></en><ar><font color="red">حقل مطلوب</font></ar>
```

## الحسابات المدركة للغة

عندما يحتوي النموذج على حقل `${language_use}` (يتم تعيينه بواسطة أداة `change_language`)، استخدم `if()` لإرجاع القيم باللغة النشطة:

```
if(${language_use} = 'en', label_en, label_ar)
```

مثال — عرض نتيجة بحث باللغة النشطة باستخدام `pulldata('rawquery', ...)`:

```
| type      | name        | calculation                                                                 |
|-----------|-------------|-----------------------------------------------------------------------------|
| calculate | district_label | if(${language_use} = 'en', pulldata('rawquery', concat(${family_path}, '/locations.db::externalData'), 'SELECT label_en FROM externalData WHERE code = ?', ${district}), pulldata('rawquery', concat(${family_path}, '/locations.db::externalData'), 'SELECT label_ar FROM externalData WHERE code = ?', ${district})) |
```

ملاحظة: يتم تعيين حقل `language_use` عادةً بواسطة أداة مظهر `change_language`. راجع Appearance — change_language.

## أفضل الممارسات للاستطلاعات متعددة اللغات

1. **اتساق التسمية**: استخدم رموز لغة متسقة عبر النموذج الخاص بك.
2. **الترجمة الاحترافية**: استعن بمترجمين محترفين مطلعين على سياق الاستطلاع.
3. **ملاحظات السياق**: قدم ملاحظات سياقية للمترجمين لضمان ترجمة دقيقة.
4. **الاختبار**: اختبر النموذج الخاص بك بجميع اللغات قبل النشر.
5. **دعم Unicode**: تأكد من أن أجهزة جمع البيانات الخاصة بك تدعم Unicode للنصوص غير اللاتينية.
6. **الوسائط الخاصة باللغة**: استخدم صوراً أو أصواتاً مناسبة ثقافياً لكل لغة.
7. **تجنب النصوص في الصور**: إذا كنت تستخدم صوراً تحتوي على نصوص، فأنشئ صوراً منفصلة لكل لغة.

## التعامل مع الحالات الخاصة

### الاستجابات بلغات مختلطة

يتيح rtSurvey للمستجيبين إدخال نص بأي نص، بغض النظر عن لغة النموذج المختارة. هذا مفيد لالتقاط الأسماء أو العناوين بنصها الأصلي.

### أنواع الأسئلة الخاصة باللغة

قد تكون بعض أنواع الأسئلة أكثر ملاءمة للغات معينة. يتيح لك rtSurvey استخدام أنواع أسئلة مختلفة للغات مختلفة:

```
| type::English (en) | type::Japanese (ja) | name | label::English (en) | label::Japanese (ja) |
|--------------------|---------------------|------|---------------------|----------------------|
| text               | select_one kanji    | name | Enter your name     | 名前を選んでください    |
```

## تصدير البيانات متعددة اللغات

عند تصدير البيانات من rtSurvey:

- اختر التصدير بلغة معينة أو قم بتضمين جميع إصدارات اللغة.
- يتم تضمين البيانات الوصفية للغة في التصدير، مما يشير إلى اللغة التي تم استخدامها لكل استجابة.

## اعتبارات تطبيق الهاتف المحمول

- يدعم تطبيق rtSurvey للهواتف المحمولة تبديل اللغة في وضع عدم الاتصال.
- تأكد من تنزيل جميع ملفات اللغة المطلوبة قبل الانتقال إلى وضع عدم الاتصال.

## القيود المعروفة

- قد لا تتوفر بعض الميزات المتقدمة بجميع اللغات.
- قد تؤثر الترجمات الطويلة جداً على التخطيط في الشاشات الصغيرة.

من خلال الاستفادة من إمكانات rtSurvey متعددة اللغات، يمكنك إنشاء استطلاعات شاملة وسهلة الوصول تصل إلى مجموعات سكانية متنوعة وتوفر بيانات عالية الجودة ودقيقة لغوياً.

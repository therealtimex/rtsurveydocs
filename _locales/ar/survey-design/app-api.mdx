تسمح واجهة برمجة تطبيقات التطبيق (AppAPI) للمستخدمين بتحميل البيانات الوصفية للنظام من التطبيق باستخدام طرق مختلفة في FormEngine و DMView. توفر الوصول إلى مفاتيح بيانات متنوعة لاسترداد معلومات محددة من التطبيق.

في xlsform، يمكنك استخدام الدالة `pulldata()` بالصيغة التالية:

<Callout>pulldata('app-api', 'data-key')</Callout>

-   `'app-api'`: تخبر هذه الكلمة المفتاحية FormEngine بتحميل البيانات من واجهة برمجة تطبيقات التطبيق.
-   `'data-key'`: هذا هو مفتاح البيانات التي تريد تحميلها من واجهة برمجة تطبيقات التطبيق.
-   إذا كان مفتاح البيانات غير صالح أو غير مدعوم، فسيعيد الحساب "n/a".

فيما يلي مفاتيح البيانات المدعومة التي يمكنك استخدامها مع واجهة برمجة تطبيقات التطبيق:

`osPlatform`: يعيد اسم نظام التشغيل الحالي (Android أو iOS) وإصدار نظام التشغيل. ستعيد منصات الويب قيمة فارغة.

`appPlatform`: يعيد اسم منصة التطبيق، وهو `rtSurvey`.

`appVersion`: يعيد اسم إصدار التطبيق.

`getDisplayWidth`: يعيد عرض شاشة الجهاز بالبكسل.

`getDisplayHeight`: يعيد ارتفاع شاشة الجهاز بالبكسل.

`getScreenSize`: يعيد حجم شاشة الجهاز بالبوصة.

`projectCode`: يعيد رمز المشروع الحالي للموقع الذي يقوم المستخدم بتسجيل الدخول إليه.

`projectURL`: يعيد عنوان URL للمشروع الحالي للموقع الذي يقوم المستخدم بتسجيل الدخول إليه. القيمة الافتراضية/الاحتياطية هي نص فارغ ("").

`startingPoint`: يعيد مسار النقطة التي تبدأ النموذج. ارجع إلى "نقطة بدء النموذج" لمزيد من التفاصيل.

`serverTime`: يعيد أفضل تقريب متاح للتاريخ والوقت على الخادم.

`user.[attribute]`: يعيد سمات المستخدم الحالي بناءً على مفتاح السمة المحدد. ارجع إلى جدول "سمات المستخدم" لمفاتيح السمات المتاحة.

اجمع مفاتيح السمات أدناه مع "user." في معلمات `pulldata()` لاسترداد معلومات المستخدم الحالية. على سبيل المثال، استخدم `user.username`، `user.email`، إلخ.

| مفتاح السمة          | الوصف                             |
|---------------------|-----------------------------------|
| `username`          | اسم المستخدم                       |
| `name`              | الاسم الكامل للمستخدم             |
| `staffCode`         | رمز الموظف للمستخدم               |
| `phone`             | رقم هاتف المستخدم                 |
| `email`             | عنوان البريد الإلكتروني للمستخدم  |
| `description`       | نص الوصف في معلومات المستخدم      |
| `organization_id`   | معرف المنظمة التي ينتمي إليها المستخدم |
| `organization_name` | اسم المنظمة التي ينتمي إليها المستخدم |
| `team_id`           | معرف الفريق الذي ينتمي إليه المستخدم  |
| `supervisor_id`     | معرف مشرف المستخدم               |
| `is_supervisor`     | 1 إذا كان المستخدم مشرفًا، 0 إذا لم يكن |

`instancePath`: يعيد مسار مجلد المثيل الحالي.

`appLanguage`: يعيد لغة التطبيق الحالية المحددة في إعدادات التطبيق (على سبيل المثال، vi, en).

`openArgs.[attribute]`: يعيد وسيطة النموذج المفتوح التي تم تمريرها من ActionButton (act_fill_form, act_get_instance). القيمة الافتراضية/الاحتياطية هي نص فارغ ("").

`primaryAppColor`: يسترد اللون الأساسي للتطبيق.

## أمثلة على الاستخدام

### تخزين اسم المستخدم والمنظمة للمُعدّ

| type | name | label | calculation |
|------|-------|------------|---------------------------------------------|
| calculate | enumerator_name | | `pulldata('app-api', 'user.name')` |
| calculate | enumerator_org | | `pulldata('app-api', 'user.organization_name')` |
| calculate | enumerator_email | | `pulldata('app-api', 'user.email')` |

استخدم هذه في تسميات الملاحظات لأغراض التدقيق:
```
note | interviewer_info | المُعدّ: ${enumerator_name} (${enumerator_org})
```

### معلومات الجهاز والشاشة

| type | name | label | calculation |
|------|-------|------------|---------------------------------------------|
| calculate | device_platform | | `pulldata('app-api', 'osPlatform')` |
| calculate | app_ver | | `pulldata('app-api', 'appVersion')` |
| calculate | screen_w | | `pulldata('app-api', 'getDisplayWidth')` |

مفيدة لاستكشاف الأخطاء وإصلاحها: قم بتصدير `device_platform` و `app_ver` جنبًا إلى جنب مع بياناتك لتحديد إصدار الجهاز الذي تم استخدامه لكل إرسال.

### وقت الخادم بدلاً من وقت الجهاز

قد تكون ساعات الجهاز غير صحيحة. استخدم `serverTime` للحصول على طابع زمني أكثر موثوقية:

| type | name | label | calculation |
|------|-------|------------|---------------------------------------------|
| calculate | server_ts | | `pulldata('app-api', 'serverTime')` |

### منطق شرطي بناءً على دور المستخدم

إظهار قسم خاص بالمشرفين فقط للمشرفين:

| type | name | label | relevant |
|------|-------|------------|---------------------------------------------|
| calculate | is_supervisor | | `pulldata('app-api', 'user.is_supervisor')` |
| begin_group | supervisor_section | مراجعة المشرف | `${is_supervisor} = '1'` |
| text | supervisor_notes | ملاحظات المشرف | |
| end_group | | | |

### تمرير الوسائط من زر الإجراء

عند تشغيل النموذج من زر إجراء `act_fill_form` مع وسائط مخصصة:

| type | name | label | calculation |
|------|-------|------------|---------------------------------------------|
| calculate | passed_hh_id | | `pulldata('app-api', 'openArgs.household_id')` |
| calculate | passed_task | | `pulldata('app-api', 'openArgs.task_code')` |

يجب أن يمرر زر الإجراء الوسائط بمفاتيح مطابقة (على سبيل المثال، `household_id`، `task_code`).

### استخدام معلومات المشروع

| type | name | label | calculation |
|------|-------|------------|---------------------------------------------|
| calculate | project | | `pulldata('app-api', 'projectCode')` |
| calculate | project_url | | `pulldata('app-api', 'projectURL')` |

## ملاحظات

-   يتم تقييم جميع استدعاءات `pulldata('app-api', ...)` عند فتح النموذج ولا يتم إعادة تقييمها ديناميكيًا أثناء الجلسة (باستثناء `serverTime` و `now()`).
-   إذا كان المفتاح غير مدعوم أو البيانات غير متاحة، فستعيد الدالة `'n/a'` (ليست سلسلة فارغة - اختبر باستخدام `!= 'n/a'` بدلاً من `!= ''`).
-   تتوفر قيم `openArgs` فقط عندما يتم تشغيل النموذج من زر إجراء؛ وإلا فإنها تعيد سلسلة فارغة.

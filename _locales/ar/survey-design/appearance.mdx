يسمح لك العمود `appearance` في rtSurvey بتخصيص العرض المرئي وسلوك الأسئلة في استطلاعاتك. تعزز هذه الميزة تجربة المستخدم ويمكن أن تحسن كفاءة جمع البيانات بشكل كبير. يدعم rtSurvey سمات المظهر القياسية لـ XLSForm ويوسعها بخيارات إضافية.

## سمات مظهر XLSForm القياسية

يدعم rtSurvey سمات مظهر XLSForm القياسية التالية:

| Appearance Attribute | Question Types | الوصف |
|----------------------|----------------|-------------|
| multiline | text | ينشئ مربع نص متعدد الأسطر (الأفضل لعملاء الويب) |
| minimal | select_one, select_multiple | يعرض الخيارات في قائمة منسدلة |
| quick | select_one | يتقدم تلقائياً إلى السؤال التالي بعد الاختيار (للجوال فقط) |
| no-calendar | date | يمنع عرض التقويم (للجوال فقط) |
| month-year | date | يسمح باختيار الشهر والسنة فقط |
| year | date | يسمح باختيار السنة فقط |
| horizontal-compact | select_one, select_multiple | يعرض الخيارات أفقياً (لويب فقط) |
| horizontal | select_one, select_multiple | يعرض الخيارات أفقياً في أعمدة (لويب فقط) |
| likert | select_one | يقدم الخيارات كمقياس ليكرت (Likert scale) |
| compact | select_one, select_multiple | يعرض الخيارات جنباً إلى جنب مع حد أدنى من الحشو |
| quickcompact | select_one | يجمع بين العرض المدمج والتقدم التلقائي (للجوال فقط) |
| field-list | groups | يعرض المجموعة بأكملها على شاشة واحدة (للجوال فقط) |
| label | select_one, select_multiple | يظهر تسميات الخيارات بدون مدخلات |
| list-nolabel | select_one, select_multiple | يظهر المدخلات بدون تسميات (يستخدم مع `label`) |
| table-list | groups | يعرض الأسئلة في تنسيق جدول |
| signature | image | يتيح التقاط التوقيع (للجوال فقط) |
| draw | image | يسمح بالرسم الحر (للجوال فقط) |
| map, quick map | select_one, select_one_from_file | يتيح الاختيار من ميزات الخريطة |

## أفضل الممارسات لاستخدام المظهر

1. **الاتساق**: استخدم سمات المظهر بشكل متسق عبر استطلاعك للحصول على مظهر موحد.
2. **الجوال مقابل الويب**: ضع في اعتبارك كيف سيتم عرض المظاهر على أجهزة ومنصات مختلفة.
3. **الأداء**: كن حذراً مع سمات المظهر التي قد تبطئ تحميل النموذج (مثل `table-list` للمجموعات الكبيرة).
4. **تجربة المستخدم**: اختر المظاهر التي تجعل إدخال البيانات أسهل وأكثر بديهية للمستجيبين.
5. **الاختبار**: اختبر نموذجك دائماً على الأجهزة المستهدفة لضمان عمل المظاهر كما هو متوقع.

## تقنيات متقدمة

### الجمع بين المظاهر

يمكن دمج بعض سمات المظهر للحصول على تخطيطات أكثر تعقيداً:

```
| type | name | label | appearance |
|------|------|-------|------------|
| select_one options | choice | Select one: | minimal compact |
```

### المظاهر الديناميكية

يسمح rtSurvey بتغييرات المظهر الديناميكية بناءً على منطق النموذج:

```
| type | name | label | appearance | relevant |
|------|------|-------|------------|----------|
| text | time | Enter time: | inline-[%H:%M] | ${show_time} = 'yes' |
```

## اعتبارات تطبيق الجوال

- بعض المظاهر (مثل `quick` و `signature`) خاصة بأجهزة الجوال.
- اختبر بدقة على كل من Android و iOS لضمان سلوك متسق.

## سمات المظهر الموسعة لـ rtSurvey

بالإضافة إلى مظاهر XLSForm القياسية، يدعم rtSurvey الخيارات التالية الخاصة بالمنصة:

### التحكم في البيانات والعرض

| Appearance Attribute | Question Types | الوصف |
|----------------------|----------------|-------------|
| `invisible` | any | يخفي الحقل من العرض بينما لا يزال يجمع أو يحسب قيمته. يختلف عن النوع `hidden` — لا يزال الحقل يشارك في المنطق. |
| `displaytitle` | any | يفرض عرض تسمية/عنوان الحقل حتى عندما يتم كتمه بخلاف ذلك. |
| `autopull` | select_one, select_multiple | يجلب البيانات الخارجية تلقائياً لملء الخيارات عند تحميل النموذج أو تغير حقل التحفيز. |
| `floating_hint` | text, integer, decimal | يظهر نص التلميح (hint) كتسمية عائمة فوق حقل الإدخال بدلاً من أسفله. |
| `calculate-button` | calculate | يضيف زراً مرئياً يحفز إعادة حساب الحقل عند الطلب، بدلاً من الحساب تلقائياً. |

### التخطيط

| Appearance Attribute | Question Types | الوصف |
|----------------------|----------------|-------------|
| `1screen` | group | يفرض عرض المجموعة بأكملها على شاشة واحدة بغض النظر عن حجم المجموعة. |
| `columns(n)` | select_one, select_multiple | يعرض الخيارات في `n` من الأعمدة. مثال: `columns(3)` يظهر ثلاثة أعمدة من أزرار الاختيار (radio buttons). |
| `gridformat<row=R col=C colspan=S align=center>` | any | يضع الحقل في تخطيط CSS-grid عند الصف `R` والعمود `C` ويمتد عبر `S` من الأعمدة. يستخدم مع `advanced-extension/grid-layout`. |
| `ignore-simplify` | any | يوجه معالج النماذج لتخطي التبسيط التلقائي أو تكثيف تخطيط هذا الحقل. |

### الأدوات (Widgets)

| Appearance Attribute | Question Types | الوصف |
|----------------------|----------------|-------------|
| `likert` | select_one | يقدم الخيارات كصف بمقياس ليكرت (موجود بالفعل في الجدول القياسي أعلاه؛ تم تأكيد دعمه). |
| `distress` | select_one | يعرض الخيارات كأداة بصرية لمقياس كيسلر للضيق النفسي (Kessler Psychological Distress Scale - K10) مع أيقونات عاطفية. |

### تكامل API

| Appearance Attribute | Question Types | الوصف |
|----------------------|----------------|-------------|
| `callapi` | text, integer, decimal, select_one | يتيح تكامل استدعاء API لهذا الحقل. يجب أن يحتوي عمود الحساب على تعبير `callapi()`. انظر [Call API](advanced-features/call-api). |
| `callapi-verify(params)` | text, integer, decimal | يحفز استدعاء تحقق API باستخدام معلمات ثابتة. يمنع النموذج التقدم حتى يؤكد API القيمة. |
| `callapi-verify(dynamicParams)` | text, integer, decimal | نفس `callapi-verify` ولكن مع معلمات مشتقة من قيم حقول أخرى في وقت التشغيل. |

### تنسيق التاريخ/الوقت المضمن

بالنسبة لحقول `date` و `time` و `datetime` ، يمكنك تحديد تنسيق عرض مخصص باستخدام سلسلة تنسيق ملحقة بالمظهر:

```
inline-[%d/%m/%Y]
inline-1line-[%d/%m/%Y %H:%M]
```

رموز التنسيق هي نفسها المستخدمة في `format-date()` و `format-date-time()`. انظر [الوظائف — وظائف التاريخ والوقت](operators-and-functions/functions#date-and-time-functions).

مثال:

| type | name | label | appearance |
|------|------|-------|------------|
| datetime | event_time | تاريخ ووقت الحدث | inline-[%d/%m/%Y %I:%M %p] |
| date | birth_date | تاريخ الميلاد | inline-[%d/%m/%Y] |

### تخطيط الأزرار المضمنة — `display{}` و `results{}`

بالنسبة لأنواع الأسئلة التي يتم عرضها كزر أيقونة مضمن (`date`, `time`, `datetime`, `image`, `audio`, `video`, `file`, `barcode`, `geopoint`) ، يتحكم معدلان للمظهر في موضع الزر وسلوك ما بعد الالتقاط.

#### `display{...}` — موضع الزر قبل الالتقاط

```
display{<align>, <size>, <color>}
```

| المعلمة | القيم | الافتراضي |
|-----------|--------|---------|
| Align | `left`, `right`, `top`, `center`, `bottom` | `right` |
| Size | `small`, `medium`, `large` | `small` |
| Color | hex e.g. `#FF5500` | لون السمة الأساسي |
| Flag | `inline-icon` | يفرض وضع الأيقونة |

| قيمة Align | التخطيط |
|-------------|--------|
| `right` | الزر إلى يمين التسمية |
| `left` | الزر إلى يسار التسمية |
| `top` | الزر فوق التسمية، موسط بعرض كامل |
| `center` / `bottom` | الزر تحت التسمية، موسط بعرض كامل |

#### `results{...}` — التخطيط والبروز بعد الالتقاط

يرث إعدادات `display{}`. استخدمه لتحريك الزر أو إخفاء العناصر بمجرد التقاط القيمة.

```
results{<align>, hide(<element>)}
```

| قيمة `hide` | التأثير |
|---|---|
| `hide(capture)` | يخفي زر الالتقاط بمجرد وجود ملف/قيمة |
| `hide(review)` | يخفي الصورة المصغرة للمراجعة / زر التشغيل |
| `hide(filename)` | يخفي اسم الملف المعروض بعد الرفع |
| `hide(camera)` | يخفي زر تشغيل الكاميرا بعد الالتقاط |
| `hide(scanner)` | يخفي زر مسح الباركود بعد مسح القيمة |
| `hide(value)` | يخفي نص القيمة الممسوحة (barcode / geopoint) |

تنتقل الأداة تلقائياً من تخطيط `display{}` إلى تخطيط `results{}` في اللحظة التي يتم فيها التقاط القيمة.

**أمثلة:**

```
inline display{right}                                    → أيقونة يمين التسمية
inline display{left, large}                              → أيقونة كبيرة على اليسار
inline display{center, large, #FF5500}                   → أيقونة برتقالية كبيرة تحت التسمية
inline display{right} results{left}                      → تنتقل الأيقونة لليسار بعد الالتقاط
inline display{right} results{hide(capture)}             → تختفي الأيقونة بعد الالتقاط
inline display{center} results{hide(capture), hide(filename)}
```

## القيود المعروفة

- قد لا يتم عرض المظاهر المعقدة بشكل متطابق عبر جميع المنصات.
- قد لا يتم دعم بعض مظاهر rtSurvey المتقدمة في وضع عدم الاتصال (offline mode).

## استكشاف أخطاء المظهر وإصلاحها

1. **المظهر لم يطبق**: تحقق من وجود أخطاء مطبعية في عمود appearance.
2. **عرض غير متسق**: تحقق من التوافق مع نوع السؤال والمنصة.
3. **مشكلات الأداء**: فكر في تبسيط المظاهر المعقدة، خاصة بالنسبة للاستطلاعات الكبيرة.

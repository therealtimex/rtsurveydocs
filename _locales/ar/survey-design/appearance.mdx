يسمح لك عمود `appearance` في rtSurvey بتخصيص العرض المرئي وسلوك الأسئلة في استبياناتك. تعمل هذه الميزة على تحسين تجربة المستخدم ويمكن أن تحسن كفاءة جمع البيانات بشكل كبير. يدعم rtSurvey سمات المظهر القياسية لـ XLSForm ويوسعها بخيارات إضافية.

## سمات المظهر القياسية لـ XLSForm

يدعم rtSurvey سمات المظهر القياسية التالية لـ XLSForm:

| سمة المظهر       | أنواع الأسئلة           | الوصف                                            |
|-------------------|--------------------------|--------------------------------------------------|
| `multiline`       | `text`                   | ينشئ مربع نص متعدد الأسطر (الأفضل لعملاء الويب) |
| `minimal`         | `select_one`, `select_multiple` | يعرض الخيارات في قائمة منسدلة                    |
| `quick`           | `select_one`             | يتقدم تلقائيًا إلى السؤال التالي بعد الاختيار (للهاتف المحمول فقط) |
| `no-calendar`     | `date`                   | يمنع عرض التقويم (للهاتف المحمول فقط)            |
| `month-year`      | `date`                   | يسمح باختيار الشهر والسنة فقط                     |
| `year`            | `date`                   | يسمح باختيار السنة فقط                           |
| `horizontal-compact` | `select_one`, `select_multiple` | يعرض الخيارات أفقيًا (للويب فقط)                   |
| `horizontal`      | `select_one`, `select_multiple` | يعرض الخيارات أفقيًا في أعمدة (للويب فقط)          |
| `likert`          | `select_one`             | يعرض الخيارات كمقياس ليكرت                       |
| `compact`         | `select_one`, `select_multiple` | يعرض الخيارات جنبًا إلى جنب بأقل مساحة بادئة    |
| `quickcompact`    | `select_one`             | يجمع بين العرض المدمج والتقدم التلقائي (للهاتف المحمول فقط) |
| `field-list`      | `groups`                 | يعرض المجموعة بأكملها على شاشة واحدة (للهاتف المحمول فقط) |
| `label`           | `select_one`, `select_multiple` | يعرض تسميات الاختيار بدون مدخلات                 |
| `list-nolabel`    | `select_one`, `select_multiple` | يعرض المدخلات بدون تسميات (يستخدم مع `label`)    |
| `table-list`      | `groups`                 | يعرض الأسئلة بتنسيق جدول                          |
| `signature`       | `image`                  | يتيح التقاط التوقيع (للهاتف المحمول فقط)           |
| `draw`            | `image`                  | يسمح بالرسم الحر (للهاتف المحمول فقط)             |
| `map`, `quick map` | `select_one`, `select_one_from_file` | يتيح الاختيار من ميزات الخريطة                    |

## أفضل الممارسات لاستخدام المظهر

1.  **الاتساق**: استخدم سمات المظهر باستمرار عبر استبيانك للحصول على مظهر موحد.
2.  **الهاتف المحمول مقابل الويب**: ضع في اعتبارك كيفية عرض المظاهر على الأجهزة والمنصات المختلفة.
3.  **الأداء**: كن حذرًا مع سمات المظهر التي قد تبطئ تحميل النموذج (مثل `table-list` للمجموعات الكبيرة).
4.  **تجربة المستخدم**: اختر المظاهر التي تجعل إدخال البيانات أسهل وأكثر سهولة للمستجيبين.
5.  **الاختبار**: اختبر نموذجك دائمًا على الأجهزة المستهدفة لضمان عمل المظاهر كما هو متوقع.

## التقنيات المتقدمة

### دمج المظاهر

يمكن دمج بعض سمات المظهر لتخطيطات أكثر تعقيدًا:

```
| type | name | label | appearance |
|------|-------|------------|-------------|
| select_one options | choice | اختر واحد: | minimal compact |
```

### المظاهر الديناميكية

يسمح rtSurvey بتغييرات المظهر الديناميكية بناءً على منطق النموذج:

```
| type | name | label | appearance | relevant |
|------|-------|------------|-----------------|-----------|
| text | time | أدخل الوقت: | inline-[%H:%M] | ${show_time} = 'yes' |
```

## اعتبارات تطبيق الهاتف المحمول

-   بعض المظاهر (مثل `quick`، `signature`) خاصة بأجهزة الهاتف المحمول.
-   اختبر بدقة على كل من Android و iOS لضمان سلوك متسق.

## سمات المظهر الموسعة لـ rtSurvey

بالإضافة إلى مظاهر XLSForm القياسية، يدعم rtSurvey الخيارات التالية الخاصة بالمنصة:

### التحكم في البيانات والعرض

| سمة المظهر           | أنواع الأسئلة | الوصف                                                    |
|-----------------------|----------------|----------------------------------------------------------|
| `invisible`           | أي             | يخفي الحقل من العرض مع الاستمرار في جمع أو حساب قيمته. يختلف عن نوع `hidden` - لا يزال الحقل يشارك في المنطق. |
| `displaytitle`        | أي             | يجبر عرض تسمية/عنوان الحقل حتى عندما يتم كبته بخلاف ذلك. |
| `autopull`            | `select_one`, `select_multiple` | يجلب البيانات الخارجية تلقائيًا لملء الاختيارات عند تحميل النموذج أو تغيير حقل المشغل. |
| `floating_hint`       | `text`, `integer`, `decimal` | يعرض نص التلميح كتسمية عائمة فوق حقل الإدخال بدلاً من أسفله. |
| `calculate-button`    | `calculate`    | يضيف زرًا مرئيًا يقوم بتشغيل إعادة حساب الحقل عند الطلب، بدلاً من الحساب تلقائيًا. |

### التخطيط

| سمة المظهر           | أنواع الأسئلة | الوصف                                                    |
|-----------------------|----------------|----------------------------------------------------------|
| `1screen`             | `group`        | يجبر المجموعة بأكملها على العرض على شاشة واحدة بغض النظر عن حجم المجموعة. |
| `columns(n)`          | `select_one`, `select_multiple` | يعرض الخيارات في `n` أعمدة. مثال: `columns(3)` يعرض ثلاثة أعمدة من أزرار الراديو. |
| `gridformat<row=R col=C colspan=S align=center>` | أي             | يضع الحقل في تخطيط شبكة CSS عند الصف `R` والعمود `C`، ويمتد على `S` أعمدة. يستخدم مع `advanced-extension/grid-layout`. |
| `ignore-simplify`     | أي             | يوجه عارض النموذج لتخطي التبسيط التلقائي أو تكثيف تخطيط هذا الحقل. |

### الأدوات (Widgets)

| سمة المظهر           | أنواع الأسئلة | الوصف                                                    |
|-----------------------|----------------|----------------------------------------------------------|
| `likert`              | `select_one`   | يعرض الخيارات كصف مقياس ليكرت (موجود بالفعل في الجدول القياسي أعلاه؛ تم تأكيد دعمه). |
| `distress`            | `select_one`   | يعرض الخيارات كأداة بصرية لمقياس كيلر للضيق النفسي (K10) مع أيقونات عاطفية. |

### تكامل API

| سمة المظهر           | أنواع الأسئلة | الوصف                                                    |
|-----------------------|----------------|----------------------------------------------------------|
| `callapi`             | `text`, `integer`, `decimal`, `select_one` | يتيح تكامل استدعاء API لهذا الحقل. يجب أن يحتوي عمود `calculation` على تعبير `callapi()`. انظر [استدعاء API](advanced-features/call-api). |
| `callapi-verify(params)` | `text`, `integer`, `decimal` | يقوم بتشغيل استدعاء تحقق API باستخدام معلمات ثابتة. يمنع النموذج التقدم حتى يؤكد API القيمة. |
| `callapi-verify(dynamicParams)` | `text`, `integer`, `decimal` | مثل `callapi-verify` ولكن مع معلمات مستمدة من قيم حقول أخرى في وقت التشغيل. |

### تنسيق التاريخ/الوقت المضمّن

بالنسبة لحقول `date` و`time` و`datetime`، يمكنك تحديد تنسيق عرض مخصص باستخدام سلسلة تنسيق ملحقة بالمظهر:

```
inline-[%d/%m/%Y]
inline-1line-[%d/%m/%Y %H:%M]
```

رموز التنسيق هي نفسها في `format-date()` و`format-date-time()`. انظر [الدوال - دوال التاريخ والوقت](operators-and-functions/functions#date-and-time-functions).

مثال:

| type | name | label | appearance |
|------|------|-------|------------|
| datetime | event_time | تاريخ ووقت الحدث | inline-[%d/%m/%Y %I:%M %p] |
| date | birth_date | تاريخ الميلاد | inline-[%d/%m/%Y] |

### تخطيط الزر المضمن — `display{}` و`results{}`

لأنواع الأسئلة التي تظهر كزر أيقونة مضمن (`date`، `time`، `datetime`، `image`، `audio`، `video`، `file`، `barcode`، `geopoint`)، يتحكم معدّلا المظهر في موضع الزر والسلوك بعد الالتقاط.

#### `display{...}` — موضع الزر قبل الالتقاط

```
display{<align>, <size>, <color>}
```

| المعلمة | القيم | الافتراضي |
|---------|--------|----------|
| المحاذاة | `left`, `right`, `top`, `center`, `bottom` | `right`    |
| الحجم    | `small`, `medium`, `large` | `small`    |
| اللون    | سداسي عشري مثل `#FF5500` | لون السمة الأساسي |
| العلم    | `inline-icon` | يفرض وضع الأيقونة |

| قيمة المحاذاة | التخطيط                   |
|---------------|----------------------------|
| `right`       | الزر إلى يمين التسمية     |
| `left`        | الزر إلى يسار التسمية      |
| `top`         | الزر فوق التسمية، عرض كامل ومُتَوَسِّط |
| `center` / `bottom` | الزر أسفل التسمية، عرض كامل ومُتَوَسِّط |

#### `results{...}` — التخطيط والرؤية بعد الالتقاط

يرث إعدادات `display{}`. يستخدم لتحريك الزر أو إخفاء العناصر بمجرد التقاط قيمة.

```
results{<align>, hide(<element>)}
```

| قيمة `hide`  | التأثير                                 |
|--------------|------------------------------------------|
| `hide(capture)` | يخفي زر الالتقاط بمجرد وجود ملف/قيمة   |
| `hide(review)` | يخفي الصورة المصغرة للمراجعة / زر التشغيل |
| `hide(filename)` | يخفي اسم الملف الذي يظهر بعد التحميل     |
| `hide(camera)` | يخفي زر تشغيل الكاميرا بعد الالتقاط       |
| `hide(scanner)` | يخفي زر مسح الباركود بعد مسح القيمة      |
| `hide(value)`  | يخفي نص القيمة الممسوحة (باركود / نقطة جغرافية) |

تتحول الأداة تلقائيًا من تخطيط `display{}` إلى تخطيط `results{}` لحظة التقاط القيمة.

**أمثلة:**

```
inline display{right}                                    → أيقونة يمين التسمية
inline display{left, large}                              → أيقونة كبيرة على اليسار
inline display{center, large, #FF5500}                   → أيقونة برتقالية كبيرة أسفل التسمية
inline display{right} results{left}                      → تنتقل الأيقونة إلى اليسار بعد الالتقاط
inline display{right} results{hide(capture)}             → تختفي الأيقونة بعد الالتقاط
inline display{center} results{hide(capture), hide(filename)}
```

## قيود معروفة

-   قد لا يتم عرض المظاهر المعقدة بشكل متطابق عبر جميع المنصات.
-   قد لا تكون بعض مظاهر rtSurvey المتقدمة مدعومة في وضع عدم الاتصال.

## استكشاف أخطاء المظهر وإصلاحها

1.  **المظهر غير مطبق**: تحقق من الأخطاء الإملائية في عمود المظهر.
2.  **العرض غير المتسق**: تحقق من التوافق مع نوع السؤال والمنصة.
3.  **مشكلات الأداء**: فكر في تبسيط المظاهر المعقدة، خاصة للاستبيانات الكبيرة.

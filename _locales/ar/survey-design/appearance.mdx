يسمح لك عمود `appearance` في rtSurvey بتخصيص العرض المرئي وسلوك الأسئلة في استطلاعاتك. تعزز هذه الميزة تجربة المستخدم ويمكن أن تحسن كفاءة جمع البيانات بشكل كبير. يدعم rtSurvey سمات المظهر القياسية لـ XLSForm ويوسعها بخيارات إضافية.

## سمات المظهر القياسية لـ XLSForm

يدعم rtSurvey سمات المظهر القياسية لـ XLSForm التالية:

| سمة المظهر (Appearance Attribute) | أنواع الأسئلة (Question Types) | الوصف |
|----------------------|----------------|-------------|
| multiline | text | ينشئ مربع نص متعدد الأسطر (الأفضل لعملاء الويب) |
| minimal | select_one, select_multiple | يعرض الخيارات في قائمة منسدلة |
| quick | select_one | ينتقل تلقائيًا إلى السؤال التالي بعد التحديد (للهاتف المحمول فقط) |
| no-calendar | date | يمنع عرض التقويم (للهاتف المحمول فقط) |
| month-year | date | يسمح باختيار الشهر والسنة فقط |
| year | date | يسمح باختيار السنة فقط |
| horizontal-compact | select_one, select_multiple | يعرض الخيارات أفقيًا (للويد فقط) |
| horizontal | select_one, select_multiple | يعرض الخيارات أفقيًا في أعمدة (للويد فقط) |
| likert | select_one | يعرض الخيارات كمقياس ليكرت (Likert scale) |
| compact | select_one, select_multiple | يعرض الخيارات جنبًا إلى جنب مع حد أدنى من الهوامش |
| quickcompact | select_one | يجمع بين العرض المدمج والانتقال التلقائي (للهاتف المحمول فقط) |
| field-list | groups | يعرض المجموعة بأكملها على شاشة واحدة (للهاتف المحمول فقط) |
| label | select_one, select_multiple | يظهر تسميات الخيارات بدون مدخلات |
| list-nolabel | select_one, select_multiple | يظهر المدخلات بدون تسميات (يستخدم مع `label`) |
| table-list | groups | يعرض الأسئلة بتنسيق جدول |
| signature | image | يتيح التقاط التوقيع (للهاتف المحمول فقط) |
| draw | image | يسمح بالرسم اليدوي (للهاتف المحمول فقط) |
| map, quick map | select_one, select_one_from_file | يتيح الاختيار من ميزات الخريطة |

## أفضل الممارسات لاستخدام المظهر

1. **الاتساق**: استخدم سمات المظهر باستمرار عبر استطلاعك للحصول على مظهر موحد.
2. **الهاتف المحمول مقابل الويب**: ضع في اعتبارك كيف سيتم عرض المظاهر على أجهزة ومنصات مختلفة.
3. **الأداء**: كن حذرًا مع سمات المظهر التي قد تؤدي إلى إبطاء تحميل النموذج (مثل `table-list` للمجموعات الكبيرة).
4. **تجربة المستخدم**: اختر المظاهر التي تجعل إدخال البيانات أسهل وأكثر سهولة للمستجيبين.
5. **الاختبار**: اختبر دائمًا نموذجك على الأجهزة المستهدفة لضمان عمل المظاهر كما هو متوقع.

## تقنيات متقدمة

### الجمع بين المظاهر

يمكن دمج بعض سمات المظهر لتخطيطات أكثر تعقيدًا:

```
| type | name | label | appearance |
|------|------|-------|------------|
| select_one options | choice | اختر واحداً: | minimal compact |
```

### المظاهر الديناميكية

يسمح rtSurvey بتغييرات المظهر الديناميكية بناءً على منطق النموذج:

```
| type | name | label | appearance | relevant |
|------|------|-------|------------|----------|
| text | time | أدخل الوقت: | inline-[%H:%M] | ${show_time} = 'yes' |
```

## اعتبارات تطبيق الهاتف المحمول

- بعض المظاهر (مثل `quick` و `signature`) خاصة بأجهزة الهاتف المحمول.
- اختبر بدقة على كل من Android و iOS لضمان سلوك متسق.

## سمات المظهر الموسعة لـ rtSurvey

بالإضافة إلى مظاهر XLSForm القياسية، يدعم rtSurvey الخيارات التالية الخاصة بالمنصة:

### التحكم في البيانات والعرض

| سمة المظهر (Appearance Attribute) | أنواع الأسئلة (Question Types) | الوصف |
|----------------------|----------------|-------------|
| `invisible` | any | يخفي الحقل من العرض بينما يستمر في جمع أو حساب قيمته. يختلف عن نوع `hidden` - لا يزال الحقل يشارك في المنطق. |
| `displaytitle` | any | يفرض عرض تسمية/عنوان الحقل حتى عندما يتم كتمه بخلاف ذلك. |
| `autopull` | select_one, select_multiple | يجلب البيانات الخارجية تلقائيًا لملء الخيارات عند تحميل النموذج أو عند تغير حقل التشغيل. |
| `floating_hint` | text, integer, decimal | يظهر نص التلميح (hint) كتسمية عائمة فوق حقل الإدخال بدلاً من أسفله. |
| `calculate-button` | calculate | يضيف زرًا مرئيًا يؤدي إلى إعادة حساب الحقل عند الطلب، بدلاً من الحساب تلقائيًا. |

### المجموعة والتنقل

| سمة المظهر (Appearance Attribute) | أنواع الأسئلة (Question Types) | الوصف |
|----------------------|----------------|-------------|
| `section` | group | يعرض المجموعة كبطاقة قسم قابلة للطي. ملاحظة: لتطبيق الهاتف المحمول فقط. |
| `toc-hide` | any | يستبعد السؤال من لوحة التنقل الخاصة بجدول المحتويات (TOC). |
| `minilog` | begin_repeat | يعرض مدخلات التكرار المكتملة كقائمة سجل مصغرة مدمجة بدلاً من توسيع كل إدخال بشكل مضمن. |

### سلوك الإدخال

| سمة المظهر (Appearance Attribute) | أنواع الأسئلة (Question Types) | الوصف |
|----------------------|----------------|-------------|
| `proper` | text | يقوم بتكبير الحرف الأول من كل كلمة تلقائيًا أثناء كتابة المستجيب (سلوك حالة العنوان). |
| `text-nolabel` | text, integer, decimal | يعرض حقل الإدخال بدون تسمية مرئية. |
| `inline-1line` | text | يفرض عرض مدخلات النص كسطر واحد حتى عندما تكون تسمية السؤال طويلة. |
| `popup` | any | يعرض الحقل داخل نافذة منبثقة / غطاء مشروط بدلاً من عرضه مضمناً في الصفحة. |

### التخطيط

| سمة المظهر (Appearance Attribute) | أنواع الأسئلة (Question Types) | الوصف |
|----------------------|----------------|-------------|
| `1screen` | group | يفرض عرض المجموعة بأكملها على شاشة واحدة بغض النظر عن حجم المجموعة. |
| `columns(n)` | select_one, select_multiple | يعرض الخيارات في `n` من الأعمدة. مثال: `columns(3)` يعرض ثلاثة أعمدة من أزرار الاختيار (radio buttons). |
| `gridformat<row=R col=C colspan=S align=center>` | any | يضع الحقل في تخطيط شبكة CSS عند الصف `R` والعمود `C` ، ويمتد عبر `S` من الأعمدة. يستخدم مع `advanced-extension/grid-layout`. |
| `ignore-simplify` | any | يوجه معالج النموذج لتخطي التبسيط التلقائي أو تكثيف تخطيط هذا الحقل. |
| `horizontal(N)` | select_one, select_multiple | يحدد كل خيار ليشغل `N` بالمائة من عرض الصف. مثال: `horizontal(50)` يضع خيارين في كل صف. |
| `scroll-view(N%)` | group, repeat | يقيد الحاوية بحد أقصى للارتفاع يبلغ `N%` من نافذة العرض (أو الأصل)، مع إضافة شريط تمرير عندما يفيض المحتوى. مثال: `scroll-view(60%)`. |

### الأدوات (Widgets)

| سمة المظهر (Appearance Attribute) | أنواع الأسئلة (Question Types) | الوصف |
|----------------------|----------------|-------------|
| `likert` | select_one | يعرض الخيارات كصف بمقياس ليكرت (موجود بالفعل في الجدول القياسي أعلاه؛ تم تأكيد دعمه). |
| `distress` | select_one | يعرض الخيارات كأداة مرئية لمقياس كيسلر للضيق النفسي (K10) مع أيقونات عاطفية. |
| `rating_box-fill-{c1}-{c2}-{c3}-{c4}-{c5}` | select_one | يعرض الخيارات كصناديق تقييم منسقة مع خمس فتحات للألوان. `c1` = حدود الحاوية الخارجية، `c2` = الحدود غير المحددة، `c3` = الحدود المحددة والتعبئة، `c4` = لون النص غير المحدد، `c5` = لون النص المحدد. مثال: `rating_box-fill-grey-blue-green-black-white`. |
| `tagging-choices-noshow-v2-{c1}-{c2}-{c3}-{c4}-{c5}` | select_multiple | يعرض الخيارات كرقائق وسوم ملونة. تتبع فتحات الألوان الخمس نفس ترتيب `rating_box-fill`. يتم تمييز الخيارات المحددة؛ ويتم إخفاء الخيارات غير المحددة من عرض الملخص. |

### تكامل واجهة برمجة التطبيقات (API)

| سمة المظهر (Appearance Attribute) | أنواع الأسئلة (Question Types) | الوصف |
|----------------------|----------------|-------------|
| `callapi` | text, integer, decimal, select_one | يتيح تكامل استدعاء واجهة برمجة التطبيقات لهذا الحقل. يجب أن يحتوي عمود الحساب على تعبير `callapi()`. انظر [استدعاء واجهة برمجة التطبيقات (Call API)](advanced-features/call-api). |
| `callapi-verify(params)` | text, integer, decimal | يؤدي إلى استدعاء التحقق من واجهة برمجة التطبيقات باستخدام معلمات ثابتة. يمنع النموذج التقدم حتى تؤكد واجهة برمجة التطبيقات القيمة. |
| `callapi-verify(dynamicParams)` | text, integer, decimal | نفس `callapi-verify` ولكن مع معلمات مشتقة من قيم حقول أخرى في وقت التشغيل. |

### مبدل اللغة

| سمة المظهر (Appearance Attribute) | أنواع الأسئلة (Question Types) | الوصف |
|----------------------|----------------|-------------|
| `change_language-{colors} default('lang')` | note, text | يعرض أداة مبدل اللغة المنسقة بأكواد الألوان المحددة. يحدد رمز `default('lang')` اللغة الأولية (مثل `default('en')`)؛ ويتم إعادة كتابته إلى `rtDefault('lang')` داخليًا أثناء التحليل. مثال: `change_language-blue-white default('vi')`. |

### تنسيق التاريخ/الوقت المضمن

بالنسبة لحقول `date` و `time` و `datetime` ، يمكنك تحديد تنسيق عرض مخصص باستخدام سلسلة تنسيق ملحقة بالمظهر:

```
inline-[%d/%m/%Y]
inline-1line-[%d/%m/%Y %H:%M]
```

رموز التنسيق هي نفسها المستخدمة في `format-date()` و `format-date-time()`. انظر [الوظائف - وظائف التاريخ والوقت](operators-and-functions/functions#date-and-time-functions).

مثال:

| النوع (type) | الاسم (name) | التسمية (label) | المظهر (appearance) |
|------|------|-------|------------|
| datetime | event_time | تاريخ ووقت الحدث | inline-[%d/%m/%Y %I:%M %p] |
| date | birth_date | تاريخ الميلاد | inline-[%d/%m/%Y] |

### تخطيط الأزرار المضمن — `display{}` و `results{}`

بالنسبة لأنواع الأسئلة التي يتم عرضها كزر أيقونة مضمن (`date`, `time`, `datetime`, `image`, `audio`, `video`, `file`, `barcode`, `geopoint`) ، يتحكم معدلان للمظهر في موضع الزر وسلوك ما بعد الالتقاط.

#### `display{...}` — موضع الزر قبل الالتقاط

```
display{<align>, <size>, <color>}
```

| المعلمة (Parameter) | القيم (Values) | الافتراضي (Default) |
|-----------|--------|---------|
| المحاذاة (Align) | `left`, `right`, `top`, `center`, `bottom` | `right` |
| الحجم (Size) | `small`, `medium`, `large` | `small` |
| اللون (Color) | hex مثلاً `#FF5500` | لون السمة الأساسي |
| العلامة (Flag) | `inline-icon` | يفرض وضع الأيقونة |

| قيمة المحاذاة (Align) | التخطيط |
|-------------|--------|
| `right` | الزر على يمين التسمية |
| `left` | الزر على يسار التسمية |
| `top` | الزر فوق التسمية، موسط بعرض كامل |
| `center` / `bottom` | الزر أسفل التسمية، موسط بعرض كامل |

#### `results{...}` — التخطيط والبروز بعد الالتقاط

يرث إعدادات `display{}`. يستخدم لتحريك الزر أو إخفاء العناصر بمجرد التقاط القيمة.

```
results{<align>, hide(<element>)}
```

| قيمة `hide` | التأثير |
|---|---|
| `hide(capture)` | يخفي زر الالتقاط بمجرد وجود ملف/قيمة |
| `hide(review)` | يخفي الصورة المصغرة للمراجعة / زر التشغيل |
| `hide(filename)` | يخفي اسم الملف المعروض بعد الرفع |
| `hide(camera)` | يخفي زر تشغيل الكاميرا بعد الالتقاط |
| `hide(scanner)` | يخفي زر مسح الرمز الشريطي بعد مسح القيمة |
| `hide(value)` | يخفي نص القيمة الممسوحة (الرمز الشريطي / نقطة جغرافية) |

تنتقل الأداة تلقائيًا من تخطيط `display{}` إلى تخطيط `results{}` في اللحظة التي يتم فيها التقاط القيمة.

**أمثلة:**

```
inline display{right}                                    → أيقونة على يمين التسمية
inline display{left, large}                              → أيقونة كبيرة على اليسار
inline display{center, large, #FF5500}                   → أيقونة برتقالية كبيرة أسفل التسمية
inline display{right} results{left}                      → الأيقونة تنتقل لليسار بعد الالتقاط
inline display{right} results{hide(capture)}             → الأيقونة تختفي بعد الالتقاط
inline display{center} results{hide(capture), hide(filename)}
```

## القيود المعروفة

- قد لا يتم عرض المظاهر المعقدة بشكل متطابق عبر جميع المنصات.
- قد لا يتم دعم بعض مظاهر rtSurvey المتقدمة في وضع عدم الاتصال (offline mode).

## استكشاف أخطاء المظهر وإصلاحها

1. **المظهر لم يتم تطبيقه**: تحقق من وجود أخطاء مطبعية في عمود المظهر (appearance).
2. **عرض غير متسق**: تحقق من التوافق مع نوع السؤال والمنصة.
3. **مشكلات الأداء**: فكر في تبسيط المظاهر المعقدة، خاصة بالنسبة للاستطلاعات الكبيرة.

title: "Datetime, date, time"
description: "Datetime-spørgsmål giver respondenter mulighed for at indtaste både dato og tid i et enkelt felt."
---

Spørgsmålstyperne `date`, `time` og `datetime` fanger dato- og/eller tidsværdier. rtSurvey gengiver dem med flere layouttilstande styret af `appearance`-kolonnen.

## Grundlæggende XLSForm-specifikation

| type | name | label |
|---|---|---|
| date | birth_date | Fødselsdato |
| time | start_time | Hvad tid startede det? |
| datetime | event_datetime | Hvornår fandt begivenheden sted? |

For standard specifikationen se [XLSForm documentation](https://xlsform.org/en/#question-types).

## Layouttilstande

### Standard — altid åben kalender

Ingen appearance-værdi er nødvendig. Kalenderen (og uret for `time`/`datetime`) gengives direkte på siden — altid synlig, ingen knap påkrævet.

| type | name | label | appearance |
|---|---|---|---|
| date | start_date | Dato for besøg | |

---

### `inline` — cirkulær knap → modal

En cirkulær ikonknap (kalender eller ur) svæver ved siden af spørgsmålets etiket. Ved at trykke på den åbnes en modal med vælgeren. Efter valg vises den valgte værdi som tekst ved siden af etiketten.

- Knapbaggrund: primær temafarve (kan tilsidesættes)
- Knapform: fuld cirkel (`border-radius: 50%`)

```
| type | name | label | appearance |
|---|---|---|---|
| date | start_date | Dato for besøg | inline |
```

---

### `inline-onlyresult` — knappen forsvinder efter valg

Samme som `inline`, men knappen skjuler sig selv, når en værdi er valgt. Nyttigt, når du kun ønsker datoen synlig, efter den er valgt, uden et vedvarende ikon.

```
inline-onlyresult
```

---

### `inline-1line` — række af spinnere

Gengiver individuelle spinner-kontroller (▲ værdi ▼) i en enkelt vandret række — en kolonne pr. komponent. For `date`: måned / dag / år. For `datetime`: måned / dag / år / timer / minutter. For `time`: timer / minutter.

Ingen modal eller kalender-popup — brugeren ruller hver spinner uafhængigt.

```
inline-1line
```

**Vis kun specifikke komponenter** ved at tilføje komponentnavnene:

```
inline-1line month year      → skjuler dag-spinner
inline-1line year            → viser kun år
```

**Begræns årstallet:**

```
inline-1line y_range(2000-2030)
```

---

### `box` — tekstinput

Gengiver et almindeligt tekstinputfelt. Brugeren indtaster datoen direkte ved hjælp af det format, der er defineret i appearance.

```
box(%d/%m/%Y)       → DD/MM/YYYY
box(%Y-%m-%d)       → YYYY-MM-DD
```

---

### `month-year` — kun måned og år

Standard XLSForm appearance. Vælgeren starter i årsvisning; brugeren vælger måned og år, men ikke en specifik dag.

```
month-year
```

---

### `year` — kun år

Standard XLSForm appearance. Vælgeren starter i tiårs-visning; kun året kan vælges.

```
year
```

---

## Brugerdefineret visningsformat

Tilføj `-[format]` til enhver `inline` appearance for at styre, hvordan den valgte værdi vises som tekst. Bruger strftime-lignende tokens.

| Token | Betydning | Eksempel |
|---|---|---|
| `%d` | Dag (nul-polstret) | 07 |
| `%e` | Dag (ingen polstring) | 7 |
| `%m` | Måned nummer | 04 |
| `%n` | Måned nummer (ingen polstring) | 4 |
| `%b` | Måned forkortelse | Apr |
| `%Y` | 4-cifret år | 2026 |
| `%y` | 2-cifret år | 26 |
| `%H` | Time (24h) | 14 |
| `%h` | Time (ingen polstring) | 14 |
| `%M` | Minut | 05 |
| `%S` | Sekund | 00 |
| `%a` | Dag navneforkortelse | Ons |

**Eksempler:**

```
inline-[%d/%m/%Y]            → 07/04/2026
inline-[%d %b %Y]            → 07 Apr 2026
inline-1line-[%Y-%m-%d]      → spinner input, formateret visning
inline-[%d/%m/%Y %H:%M]      → 07/04/2026 14:30
```

## Farvetilpasning

Tilsidesæt ikonknappens farve ved hjælp af `colors()`:

```
inline colors("0099FF")                   → knapbaggrund #0099FF
inline colors("0099FF","FFFFFF")          → baggrund #0099FF, ikonfarve #FFFFFF
inline-1line colors("0000FF","FFFF00")    → spinner accentfarver
inline-onlyresult colors("E53935")        → rød knap
```

---

## Knapposition med `display{}`

Modifikator `display{}` styrer, hvor ikonknappen vises i forhold til spørgsmålets etiket. Gælder for `inline` og `inline-onlyresult`.

```
display{<align>, <size>, <color>}
```

| Parameter | Værdier | Standard |
|---|---|---|
| Align | `left`, `right`, `top`, `center`, `bottom` | `right` |
| Size | `small`, `medium`, `large` | `small` |
| Color | hex f.eks. `#FF5500` | primær temafarve |

**Justeringsadfærd:**

| Værdi | Layout |
|---|---|
| `right` | Knap til højre for etiketten |
| `left` | Knap til venstre for etiketten |
| `top` | Knap over etiketten, fuld bredde centreret |
| `center` / `bottom` | Knap under etiketten, fuld bredde centreret |

**Eksempler:**

```
inline display{left}
inline display{center, large}
inline display{right, medium, #E53935}
inline-onlyresult display{bottom, large, #0099FF}
```

## Datointervalbegrænsning

Brug `inputs{range[...]}` til at begrænse, hvilke datoer der kan vælges.

```
inputs{range[dateGt(2024-01-01), dateLt(2024-12-31)]}
```

Parametre inde i `range[...]`:

| Parameter | Beskrivelse |
|---|---|
| `dateGt(YYYY-MM-DD)` | Minimum valgbar dato (større end eller lig med) |
| `dateLt(YYYY-MM-DD)` | Maksimum valgbar dato (mindre end eller lig med) |
| `indayTimeGt(HH:MM:SS)` | Minimum tid inden for en dag (kun datetime) |
| `indayTimeLt(HH:MM:SS)` | Maksimum tid inden for en dag (kun datetime) |

Flere intervaller kan defineres — en dato kan vælges, hvis den falder inden for **ethvert** af intervallerne.

---

## Undertryk etiketten

Tilføj `text-nolabel` for at skjule spørgsmålets etiket. Knappen gengives alene.

```
inline text-nolabel display{center, large}
```

## Layout oversigt

| Appearance | Widget gengivet | Farve kan tilpasses |
|---|---|---|
| *(ingen)* | Altid åben kalender | Nej |
| `inline` | Cirkulær knap → modal kalender | Ja |
| `inline-onlyresult` | Cirkulær knap → modal, skjules efter valg | Ja |
| `inline-1line` | Række af spinnere | Ja |
| `box(%format%)` | Tekstinputfelt | Nej |
| `month-year` | Måned/år vælger | Nej |
| `year` | Kun år vælger | Nej |

## Bedste praksis

1. Brug `inline` til kompakte formularer — det sparer lodret plads sammenlignet med den altid åbne kalender.
2. Brug `inline-1line`, når respondenter skal justere individuelle datokomponenter (f.eks. fødselsår).
3. Brug `box()` kun når du stoler på, at intervieweren indtaster datoer korrekt — ingen validerings-UI vises.
4. Brug `display{center, large}` for at gøre knappen mere fremtrædende på mobile skærme.
5. Angiv altid `-[format]`, når standard `YYYY-MM-DD`-visningen ville forvirre lokale brugere.
6. Vær opmærksom på tidszoner, når du indsamler datetime-data på tværs af forskellige regioner.

## Begrænsninger

- `inline-1line` standardindstilles altid til dags dato, hvis ingen værdi eksisterer — brug `default`-kolonnen til at forudfylde en specifik dato.
- `box()`-formatet styrer kun visningen; den gemte værdi er altid ISO 8601.
- Datointervalbegrænsning (`inputs{range[...]}`) fungerer ikke med `box`-layoutet.
- Tidszonedifferencer kan komplicere dataanalyse, hvis der ikke tages korrekt højde for dem.

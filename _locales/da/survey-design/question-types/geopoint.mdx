---
title: "Geopoint"
description: "Geopoint-spørgsmål indfanger geografiske koordinater (breddegrad, længdegrad, højde og nøjagtighed) som en del af undersøgelsen."
---

`geopoint`-spørgsmålstypen indfanger geografiske koordinater (breddegrad, længdegrad, højde, nøjagtighed) ved hjælp af enhedens GPS. rtSurvey renderer vælgeren med flere layout-tilstande og understøtter automatisering via parametrene `inputs{}` og `outputs{}`.

## Grundlæggende XLSForm-specifikation

| type     | name        | label                       |
|----------|-------------|-----------------------------|
| geopoint | location    | Registrer den nuværende placering |

For standard specifikation se [XLSForm dokumentation](https://xlsform.org/en/#question-types).

## Dataformat

Gemt som fire mellemrumsseparerede værdier:

```
latitude longitude altitude accuracy
```

Eksempel: `13.756331 100.501762 15 8`

---

## Layout-tilstande (Layout modes)

### Standard — rektangulær knap

En rektangulær "START GEOPOINT"-knap åbner en fuld kort-modal, hvor intervieweren vælger et punkt. Efter indfangning ændres knapteksten til "View or change geo point", og koordinaterne vises nedenfor.

Ingen appearance-værdi påkrævet.

---

### `display{inline-icon}` — cirkulær trådkors-knap

Renderer en cirkulær ikon-knap (trådkors ⊕) i stedet for den rektangulære knap. Et tryk på den åbner den samme kort-modal.

```
display{inline-icon}
```

**Kombineret med position og størrelse:**

```
display{inline-icon, left}           → knap til venstre for etiketten
display{inline-icon, top}            → knap over etiketten
display{inline-icon, bottom}         → knap under etiketten, centreret
display{inline-icon, large}          → stort ikon (75px)
display{inline-icon, medium}         → mellemstort ikon (50px)
display{inline-icon, left, large}    → stor knap til venstre
```

| Size | Icon height/width |
|------|------------------|
| *(default)* | 25px |
| `medium` | 50px |
| `large` | 75px |

---

### `display{thumbnail-square}` — live kort-miniature

Renderer en live kort-forhåndsvisning (Leaflet) direkte på spørgsmålet i stedet for en knap. Miniaturen viser den aktuelle GPS-position og det valgte punkt. Ved at trykke på udvid-knappen åbnes den fulde modal.

```
display{thumbnail-square}
```

**Brugerdefineret miniaturestørrelse:**

```
display{thumbnail-square-[WxH]}          → faste pixels
display{thumbnail-square-[400x200]}      → 400px bred × 200px høj

display{thumbnail-square-[W%xH%]}        → procentdel af formularbredden
display{thumbnail-square-[100%x30%]}     → fuld bredde × 30% af formularbredden
```

---

## `display{}` vs `results{}` — før og efter indfangning

`display{}` styrer layoutet **før** brugeren indfanger en placering. `results{}` styrer layoutet **efter** en værdi eksisterer. De kan have forskellige justeringer.

```
display{inline-icon, right} results{left}
```

Dette renderer knappen til højre før indfangning og flytter den derefter til venstre, når et punkt er registreret.

### `hide(value)` — skjul koordinatvisning

Som standard vises den indfangede lat/lon/nøjagtighed/højde-tekst under knappen. Skjul den med:

```
results{hide(value)}
display{inline-icon} results{hide(value)}
```

## `inputs{}` — GPS-automatisering

### Auto-indfangning ved indlæsning

Registrerer automatisk GPS-positionen, når formularen indlæses, uden at intervieweren skal trykke på noget.

```
inputs{auto-take}
```

**Betinget auto-indfangning** ved hjælp af et XLSForm-udtryk:

```
inputs{autotakeGeo(expression(if(${capture_now} = 'yes', true(), false())))}
```

### Forudfyldning fra et tekstfelt

Udfyld geopoint fra et spørgsmål, der indeholder et stednavn eller en adressestreng. rtSurvey omvendt-geokoder strengen til koordinater via OpenStreetMap Nominatim.

```
inputs{question(address_field)}
```

---

## `outputs{}` — omvendt geokodning til tekst

Når et punkt er indfanget, udfyldes automatisk et `text`-spørgsmål med den menneskeligt læsbare adresse (omvendt geokodet fra koordinaterne).

```
outputs{question(address_field)}
```

Eksempel:

| type | name | label | appearance |
|------|------|-------|------------|
| geopoint | location | Registrer placering | `outputs{question(address_text)}` |
| text | address_text | Adresse | |

---

## `nomap` — GPS-indfangning uden kort

Erstatter kort-modalen med en simpel dialogboks, der anmoder om placeringstilladelse og registrerer koordinater. Der vises intet kort. Nyttigt til kun-GPS-indfangning på lavpris-enheder, eller når kortfliser ikke er tilgængelige offline.

```
nomap
```

Brug `styleButton()` til at anvende brugerdefineret CSS på den rektangulære standardknap:

```
styleButton({"backgroundColor":"#1976D2","color":"#ffffff","borderRadius":"8px"})

text-nolabel display{inline-icon, center, large}
```

## Best Practices

1. Brug `inputs{auto-take}` til undersøgelser med interviewer-verifikation, hvor GPS er obligatorisk — det fjerner det manuelle trin.
2. Brug `display{thumbnail-square}`, når du ønsker, at intervieweren visuelt skal bekræfte det valgte punkt, før der fortsættes.
3. Par `outputs{question(...)}` med et skrivebeskyttet `text`-felt for at vise den omvendt geokodede adresse til intervieweren.
4. Brug `nomap` i områder uden internetforbindelse, hvor kortfliser ikke kan indlæses.
5. Giv GPS-tiden tid til at stabilisere sig før registrering — en nøjagtighed under 10m er typisk tilstrækkelig til feltundersøgelser.

## Begrænsninger (Limitations)

- `inputs{question(name)}` geokodning kræver internetadgang — det kalder OpenStreetMap Nominatim API.
- `outputs{question(name)}` omvendt geokodning kræver også internetadgang.
- Kort-miniature (`display{thumbnail-square}`) kræver internet til indlæsning af fliser; koordinater indfanges stadig offline.
- GPS-nøjagtighed varierer afhængigt af enhed og miljø — indendørs forhold eller bymiljøer kan give en nøjagtighed > 50m.
- Indsamling af placeringsdata kan have en væsentlig indvirkning på enhedens batterilevetid under lange undersøgelser.

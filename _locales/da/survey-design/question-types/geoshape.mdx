---
title: "Geoshape"
description: "Geoshape-spørgsmål fanger en lukket polygon defineret af en sekvens af GPS-punkter."
---

Spørgsmålstypen `geoshape` fanger en lukket polygon — en række GPS-koordinater, hvor det første og det sidste punkt er det samme. I rtSurveys webformular runderes dette som et **tekstindtastningsfelt**, hvor tælleren (enumerator) indtaster eller indsætter koordinatstrengen direkte.

## Grundlæggende XLSForm-specifikation

| type     | name        | label                            |
|----------|-------------|----------------------------------|
| geoshape | field_area  | Tegn markens grænse              |
| geoshape | zone        | Registrer zonens grænse          |

For standard-specifikationen, se [XLSForm-dokumentationen](https://xlsform.org/en/#question-types).

---

## Datatransformat

Gemmes som en semikolonsepareret liste over punkter med **ingen mellemrum omkring semikolonerne**. Hvert punkt består af fire mellemrumsseparerede værdier:

```
lat lon alt acc;lat lon alt acc;lat lon alt acc;lat lon alt acc
```

| Component | Description |
|-----------|-------------|
| `lat` | Breddegrad i decimalgrader |
| `lon` | Længdegrad i decimalgrader |
| `alt` | Højde i meter (`0` hvis ukendt) |
| `acc` | GPS-præcision i meter (`0` hvis ukendt) |

**Polygonen skal være lukket** — det sidste punkt skal være lig med det første punkt.

**Eksempel — en polygon med fire punkter (trekant, lukket):**
```
13.756331 100.501762 0 0;13.758000 100.503000 0 0;13.757000 100.506000 0 0;13.756331 100.501762 0 0
```

Der kræves minimum tre forskellige punkter plus den afsluttende gentagelse for at danne en gyldig polygon.

---

## Hvordan det runderes i rtSurvey

I rtSurveys webformular runderes `geoshape` som et almindeligt **tekstfelt**. Tælleren skriver eller indsætter koordinatstrengen. Der er ingen indbygget interaktiv polygon-kortvælger til denne type i den nuværende webformular.

### Indsamling af polygonpunkter interaktivt

Det anbefalede mønster til feltindsamling er en **gentagelsesgruppe af `geopoint`-spørgsmål** — hvert toppunkt bruger den fulde GPS-kortvælger — kombineret med en `calculate` til at producere geoshape-strengen:

| type | name | label | calculation |
|------|------|-------|-------------|
| begin repeat | polygon_points | Registrer hvert hjørne | |
| geopoint | point | Tryk for at registrere hjørne | |
| end repeat | polygon_points | | |
| calculate | geoshape_value | | `join(';', ${polygon_points/point})` |

Efter sammenføjning skal du tilføje det første punkt manuelt for at lukke polygonen, eller bruge en anden calculate til at sammenkæde det.

## Best Practices

1. Brug en gentagelsesgruppe af `geopoint`-spørgsmål til interaktiv kortbaseret indsamling og sammenføj værdierne — dette giver tællere en GPS-vælger til hvert toppunkt.
2. Luk altid polygonen (gentag det første punkt til sidst) før indsendelse.
3. Inkluder det forventede format i kolonnen `hint`, når manuel koordinatindtastning er påkrævet.
4. Kræv mindst 3 forskellige hjørnepunkter for en gyldig polygon — gennemtving dette via instruktioner snarere end XLSForm-begrænsninger (constraints).
5. Brug `geopoint` til enkelt-lokationsspørgsmål og `geoshape` kun, når afgrænsning af et område er det faktiske formål med undersøgelsen.

## Begrænsninger (Limitations)

- Der er ingen indbygget interaktiv polygon-kortvælger til `geoshape` i rtSurveys webformular.
- Polygonen skal lukkes manuelt — der er ingen automatisk lukkemekanisme i tekstindtastningstilstand.
- Validering af polygontopologi (f.eks. ingen selv-skæring, minimumsareal) kræver efterbehandling uden for XLSForm-begrænsninger.
- Lange grænser med mange toppunkter producerer store tekststrenge.

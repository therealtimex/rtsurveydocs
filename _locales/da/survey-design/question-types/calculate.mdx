Spørgsmålstypen `calculate` kører en formel lydløst i baggrunden. Den gemmer resultatet i et navngivet felt, som andre spørgsmål kan referere til — men den viser intet input eller label til intervieweren. Brug den til at aflede værdier, sammensætte strenge, køre betinget logik eller slå data op, som du har brug for senere i formularen.

---

## Grundlæggende syntaks

| type | name | label | calculation |
|------|------|-------|-------------|
| calculate | total | | `${price} * ${quantity}` |

- **type**: Altid `calculate`.
- **name**: Et unikt feltnavn. Andre spørgsmål refererer til dette med `${name}`.
- **label**: Lad den være tom — calculate-felter vises aldrig for intervieweren.
- **calculation**: Formlen der skal evalueres. Understøtter alle [XLSForm-funktioner](../operators-and-functions/functions) og feltreferencer.

## Almindelige mønstre

### Aritmetik

| type | name | label | calculation |
|------|------|-------|-------------|
| integer | price | Unit price | |
| integer | quantity | Quantity | |
| calculate | total | | `${price} * ${quantity}` |
| note | total_note | Total: `${total}` | |

### Streng-sammensætning

| type | name | label | calculation |
|------|------|-------|-------------|
| text | first_name | First name | |
| text | last_name | Last name | |
| calculate | full_name | | `concat(${first_name}, ' ', ${last_name})` |

### Betinget værdi

| type | name | label | calculation |
|------|------|-------|-------------|
| integer | score | Score (0–100) | |
| calculate | grade | | `if(${score} >= 90, 'A', if(${score} >= 75, 'B', if(${score} >= 60, 'C', 'F')))` |

### Alder fra fødselsdato

| type | name | label | calculation |
|------|------|-------|-------------|
| date | dob | Date of birth | |
| calculate | age_years | | `int((today() - ${dob}) div 365.25)` |

## Brug af `once()` til at låse værdien

Som standard genberegnes `calculate`, hver gang et refereret felt ændres. Indpak formlen i `once()` for kun at evaluere ved første indlæsning og fastfryse resultatet:

| type | name | label | calculation |
|------|------|-------|-------------|
| calculate | interview_start | | `once(now())` |

Brug `once()` til tidsstempler, startværdier eller ethvert tilfælde, hvor genberegning ved ændring er uønsket.

## Træk data fra eksterne kilder

### Fra en CSV-fil

```
pulldata('staff.csv', 'department', 'name', ${staff_id})
```

Se [pulldata()](../operators-and-functions/pulldata) for den fulde reference.

### Fra en bundled SQLite-database

```
pulldata('rawquery',
  concat(${family_path}, '/locations.db::provinces'),
  'SELECT name FROM provinces WHERE id = ?',
  ${province_id})
```

Se [Local Database Search](../advanced-features/local-database-search) for detaljer om konstruktion af stier.

### Fra app-kontekst

```
pulldata('app-api', 'user.username')
pulldata('app-api', 'family_path')
```

Se [App API](../app-api) for alle tilgængelige nøgler.

## Brug af calculate i relevant og constraint

Andre felter kan referere til et `calculate`-resultat ligesom ethvert andet felt:

| type | name | label | relevant | constraint |
|------|------|-------|----------|------------|
| calculate | bmi | | | `${weight} div (${height} * ${height}) * 10000` |
| note | bmi_warning | BMI is very high — please verify weight and height. | `${bmi} > 40` | |

## Best Practices

1. Giv calculate-felter meningsfulde navne — `total_cost` er tydeligere end `calc1` og lettere at spore i eksporter.
2. Opdel komplekse formler i flere sammenkædede calculate-felter i stedet for ét dybt indlejret udtryk.
3. Brug `once()` til tidsstempler og indledende snapshots for at forhindre værdier i at ændre sig efter første registrering.
4. Placer `calculate`-felter før det første spørgsmål, der refererer til dem — evalueringsrækkefølgen følger formularens rækkefølge.
5. Hold `label`-kolonnen tom. Nogle værktøjer viser labelen; at lade den være tom undgår forvirrende output.

## Begrænsninger

- Calculate-felter vises aldrig direkte for intervieweren — brug et `note`-felt til at vise resultatet.
- Kolonnen `calculation` er påkrævet; en `calculate`-række uden formel gemmer altid en tom streng.
- Resultater genberegnes ved hver ændring af formularen, medmindre de er indpakket i `once()` — meget komplekse formler i store formularer kan påvirke gengivelsesydelsen på low-end enheder.
- Beregnede værdier gemmes som strenge i indsendelsen. Brug `number()`, `int()` eller `boolean()` til at caste, når resultatet sendes til aritmetiske eller logiske udtryk.

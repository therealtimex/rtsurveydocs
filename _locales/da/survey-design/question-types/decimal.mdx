---

Spørgsmålstypen `decimal` indsamler tal, der kan indeholde en brøkdel (f.eks. `3.14`, `72.5`). Den udløser et numerisk tastatur på mobilenheder og understøtter de samme visningsmuligheder (appearance options) som typen `text` til layout og formatering.

## Grundlæggende XLSForm-specifikation

| type | name | label |
|------|------|-------|
| decimal | weight_kg | Vægt (kg) |
| decimal | height_m | Højde (m) |
| decimal | temperature | Kropstemperatur (°C) |

For standard-specifikationen, se [XLSForm-dokumentationen](https://xlsform.org/en/#question-types).

---

## Visningsmuligheder (Appearance options)

### `number-hspinner` — horisontal spinner

Erstatter inputfeltet med en horisontal **− værdi +** spinner. Ved at trykke på minus/plus justeres værdien med det konfigurerede trin (step).

```
number-hspinner
```

Den viste værdi formateres med én decimal (f.eks. `3.0`, `72.5`). Standardtrin er `1`; brug `hspinner()` til at angive et decimaltrin.

**Tilpas knapform og trin** ved hjælp af `hspinner()`:

```
number-hspinner hspinner('left-small-square','right-small-square','0.1')
```

Parametre: venstre knapform, højre knapform, trinværdi. Brug et decimaltrin som `0.5` eller `0.1` for finmasket kontrol.

**Brugerdefinerede farver** ved hjælp af `colors()`:

```
number-hspinner colors(0099FF,FFFFFF,FF5500,FFFFFF)
```

Fire værdier i rækkefølge: venstre knaps baggrund, venstre knaps ikon, højre knaps baggrund, højre knaps ikon.

---

### `thousandsep` — tusindtalsseparator

Formaterer det viste tal med tusindtalsseparering (f.eks. `1,234.56`). Råtallet gemmes uden kommaer. Inputtypen skifter til `"text"` for at tillade den formaterede visning.

```
thousandsep
```

---

### `digisep(n, "sep")` — brugerdefineret talkombination

Grupperer cifre i heltalsdelen i blokke af `n` adskilt af en brugerdefineret separator.

```
digisep(3," ")      → 1 234 567.89
```

Inputtypen skifter til `"text"`, når denne visningsmulighed er aktiv.

---

### `textonly` — gennemtving teksttastatur

Gennemtvinger `type="text"` på input-elementet. Forhindrer browserens tal-input-særheder (skjuler efterfølgende nuller, desktop-pile) mens decimalværdier stadig accepteres.

```
textonly
```

---

### `floating_hint` — hint svæver som label

`hint`-teksten vises inde i inputfeltet som en pladsholder (placeholder). Når brugeren begynder at skrive, svæver den over feltet som en label.

```
floating_hint
```

---

### `embed` — hint inde i inputfeltets kant

Svarer til `floating_hint` — hintet sidder inde i inputfeltets kant, når det er tomt. Det svæver ikke, når brugeren skriver.

```
embed
```

---

### `textpopup` — modal dialog-indtastning

Ved at trykke på feltet åbnes en modal dialog med et større indtastningsfelt. Nyttigt på små skærme.

```
textpopup
```

---

### `charcount` — live tegntæller

Viser en live `(n)` tegntæller under feltet, som opdateres mens brugeren skriver.

```
charcount
```

---

### `prefix(expr)` — tilføj præfiks

Tilføjer en statisk eller beregnet streng foran den viste værdi. Den gemte værdi inkluderer ikke præfikset.

```
prefix('USD ')          → viser "USD 72.50", gemmer "72.50"
prefix(${currency})     → dynamisk præfiks fra et andet felt
```

---

### `align_answer` — justering af inputtekst

Styrer den horisontale justering af den indtastede værdi inde i feltet.

```
align_answer = left
align_answer = right
align_answer = center
```

---

### `inputs{qrscan}` — QR / stregkodescan til feltet

Tilføjer en QR-kodescanningsknap ved siden af feltet. Åbner kamera-scanneren og udfylder feltet med den scannede værdi.

```
inputs{qrscan}
```

## Begrænsninger og validering

| type | name | label | constraint | constraint_message |
|------|------|-------|------------|-------------------|
| decimal | weight | Vægt (kg) | `. > 0 and . <= 500` | Indtast en værdi mellem 0 og 500 |
| decimal | height | Højde (m) | `. > 0 and . <= 3` | Indtast en værdi mellem 0 og 3 |
| decimal | temp | Temperatur (°C) | `. >= 35 and . <= 42` | Normal temperatur: 35°C–42°C |
| decimal | percentage | Procent | `. >= 0 and . <= 100` | Indtast en værdi mellem 0 og 100 |

## Eksempel — måleskema

| type | name | label | appearance | constraint | constraint_message |
|------|------|-------|------------|------------|-------------------|
| decimal | weight_kg | Vægt (kg) | `number-hspinner hspinner('left-small-square','right-small-square','0.5')` | `. > 0 and . <= 300` | Indtast en gyldig vægt |

Søjle til BMI-beregning:
```

```

## Best Practices

1. Brug `number-hspinner hspinner(..., '0.1')` til målinger, der kræver én decimals præcision — spinneren formaterer automatisk til én decimal, hvilket holder værdierne konsistente.
2. Brug `textonly` når browsere tilføjer uønskede spinner-kontroller eller fjerner efterfølgende nuller (f.eks. `3.0` vist som `3`).
3. Brug `thousandsep` til store økonomiske værdier, så respondenterne kan bekræfte, at de har indtastet den korrekte størrelsesorden.
4. Gennemfør intervalbegrænsninger (constraints) i stedet for kun at stole på mobiltastaturtypen.

## Begrænsninger (Limitations)

- Spinneren viser altid én decimal — hvis du har brug for mere præcision i den viste værdi, skal du bruge det almindelige inputfelt i stedet.
- `thousandsep` og `digisep()` gemmer råtallet — læs ikke den formaterede visningsværdi i beregningar.

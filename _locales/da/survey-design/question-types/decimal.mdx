Spørgsmålstypen `decimal` indsamler tal, der kan inkludere en brøkdel (f.eks. `3.14`, `72.5`). Den udløser et numerisk tastatur på mobil og understøtter de samme appearance-muligheder som `text`-typen for layout og formatering.

## Grundlæggende XLSForm-specifikation

| type | name | label |
|---|---|---|
| decimal | weight_kg | Vægt (kg) |
| decimal | height_m | Højde (m) |
| decimal | temperature | Kropstemperatur (°C) |

For standard specifikationen se [XLSForm documentation](https://xlsform.org/en/#question-types).

---

## Appearance-muligheder

### `number-hspinner` — horisontal spinner

Erstatter inputfeltet med en horisontal **− værdi +** spinner. Ved at trykke på minus/plus justeres værdien med det konfigurerede trin.

```
number-hspinner
```

Den viste værdi formateres med én decimal (f.eks. `3.0`, `72.5`). Standardtrin er `1`; brug `hspinner()` til at indstille et decimaltrin.

**Tilpas knapform og trin** ved hjælp af `hspinner()`:

```
number-hspinner hspinner('left-small-square','right-small-square','0.1')
```

Parametre: venstre knapform, højre knapform, trinværdi. Brug et decimaltrin som `0.5` eller `0.1` for finjusteret kontrol.

**Brugerdefinerede farver** ved hjælp af `colors()`:

```
number-hspinner colors(0099FF,FFFFFF,FF5500,FFFFFF)
```

Fire værdier i rækkefølge: venstre-knap baggrund, venstre-knap ikon, højre-knap baggrund, højre-knap ikon.

---

### `thousandsep` — tusindtalsseparator

Formaterer det viste tal med komma-gruppering (f.eks. `1,234.56`). Det rå tal gemmes uden kommaer. Inputtypen skiftes til `"text"` for at tillade den formaterede visning.

```
thousandsep
```

---

### `digisep(n, "sep")` — brugerdefineret ciffergruppering

Grupperer hele tal-cifre i blokke af `n` adskilt af en brugerdefineret separator.

```
digisep(3," ")      → 1 234 567.89
```

Inputtypen skiftes til `"text"`, når denne appearance er aktiv.

---

### `textonly` — tving teksttastatur

Tvinger `type="text"` på inputelementet. Forhindrer browserens nummertastatur-særheder (skjule efterfølgende nuller, desktop-spinpile), samtidig med at den stadig accepterer decimalværdier.

```
textonly
```

---

### `floating_hint` — hint flyder som etiket

`hint`-teksten gengives inde i inputfeltet som en pladsholder. Når brugeren begynder at skrive, flyder den over feltet som en etiket.

```
floating_hint
```

---

### `embed` — hint inde i inputfeltets grænse

Ligner `floating_hint` — hintet sidder inde i inputfeltets grænse, når det er tomt. Det flyder ikke, når brugeren skriver.

```
embed
```

---

### `textpopup` — modal dialog input

Ved at trykke på feltet åbnes en modal dialog med et større input. Nyttigt på små skærme.

```
textpopup
```

---

### `charcount` — live tegntæller

Viser en live `(n)` tegntæller under inputfeltet, der opdateres, når brugeren skriver.

```
charcount
```

---

### `prefix(expr)` — tilføj et præfiks

Tilføjer en statisk eller beregnet streng foran den viste værdi. Den gemte værdi inkluderer ikke præfikset.

```
prefix('USD ')          → viser "USD 72.50", gemmer "72.50"
prefix(${currency})     → dynamisk præfiks fra et andet felt
```

---

### `align_answer` — justering af inputtekst

Styrer den vandrette justering af den indtastede værdi inde i inputfeltet.

```
align_answer = left
align_answer = right
align_answer = center
```

---

### `inputs{qrscan}` — QR / stregkode scanning til felt

Tilføjer en QR-kode scanningsknap ved siden af inputfeltet. Åbner kamera-scanneren og udfylder feltet med den scannede værdi.

```
inputs{qrscan}
```

## Begrænsninger og validering

| type | name | label | constraint | constraint_message |
|---|---|---|---|---|
| decimal | weight | Vægt (kg) | `. > 0 and . <= 500` | Indtast en værdi mellem 0 og 500 |
| decimal | height | Højde (m) | `. > 0 and . <= 3` | Indtast en værdi mellem 0 og 3 |
| decimal | temp | Temperatur (°C) | `. >= 35 and . <= 42` | Normal temperatur: 35°C–42°C |
| decimal | percentage | Procent | `. >= 0 and . <= 100` | Indtast en værdi mellem 0 og 100 |

## Bedste praksis

1. Brug `number-hspinner hspinner(..., '0.1')` til målinger, der kræver én decimals præcision — spinneren formaterer automatisk til én decimal, hvilket holder værdierne konsistente.
2. Brug `textonly` når browsere tilføjer uønskede spin-kontroller eller afkorter efterfølgende nuller (f.eks. `3.0` vist som `3`).
3. Brug `thousandsep` for store finansielle værdier, så respondenter kan verificere, at de indtastede den korrekte størrelsesorden.
4. Håndhæv intervalbegrænsninger i stedet for kun at stole på mobilens tastaturtype.

## Begrænsninger

- Spinneren viser altid én decimal — hvis du har brug for mere præcision i den viste værdi, skal du bruge den almindelige inputfelt i stedet.
- `thousandsep` og `digisep()` gemmer det rå tal — læs ikke den formaterede visningsværdi i beregninger.

`appearance`-kolonnen i rtSurvey giver dig mulighed for at tilpasse den visuelle præsentation og adfærd for spørgsmål i dine undersøgelser. Denne funktion forbedrer brugeroplevelsen og kan betydeligt forbedre effektiviteten af dataindsamling. rtSurvey understøtter standard XLSForm-udseendeattributter og udvider dem med yderligere muligheder.

## Standard XLSForm-udseendeattributter

rtSurvey understøtter følgende standard XLSForm-udseendeattributter:

| Appearance Attribute | Question Types            | Beskrivelse                                                     |
|----------------------|---------------------------|-----------------------------------------------------------------|
| `multiline`            | `text`                    | Opretter en tekstboks med flere linjer (bedst til webklienter)    |
| `minimal`              | `select_one`, `select_multiple` | Viser valg i en rullemenu                                       |
| `quick`                | `select_one`              | Går automatisk videre til næste spørgsmål efter valg (kun mobil) |
| `no-calendar`          | `date`                    | Undertrykker kalendervisningen (kun mobil)                      |
| `month-year`           | `date`                    | Tillader kun valg af måned og år                                |
| `year`                 | `date`                    | Tillader kun valg af år                                         |
| `horizontal-compact`   | `select_one`, `select_multiple` | Viser valg vandret (kun web)                                    |
| `horizontal`           | `select_one`, `select_multiple` | Viser valg vandret i kolonner (kun web)                         |
| `likert`               | `select_one`              | Præsenterer valg som en Likert-skala                           |
| `compact`              | `select_one`, `select_multiple` | Viser valg side om side med minimal afstand                     |
| `quickcompact`         | `select_one`              | Kombinerer kompakt visning med automatisk fremrykning (kun mobil) |
| `field-list`           | `groups`                  | Viser hele gruppen på én skærm (kun mobil)                     |
| `label`                | `select_one`, `select_multiple` | Viser valgmuligheders etiketter uden inputfelter                |
| `list-nolabel`         | `select_one`, `select_multiple` | Viser inputfelter uden etiketter (bruges med `label`)          |
| `table-list`           | `groups`                  | Viser spørgsmål i tabelformat                                   |
| `signature`            | `image`                   | Aktiverer underskriftfangst (kun mobil)                         |
| `draw`                 | `image`                   | Tillader frihåndstegning (kun mobil)                            |
| `map`, `quick map`     | `select_one`, `select_one_from_file` | Aktiverer valg fra kortfunktioner                               |

## Bedste praksis for brug af udseende

1.  **Konsistens**: Brug udseendeattributter konsekvent på tværs af din undersøgelse for et ensartet udseende.
2.  **Mobil vs. Web**: Overvej, hvordan udseende vil gengives på forskellige enheder og platforme.
3.  **Ydeevne**: Vær forsigtig med udseendeattributter, der kan bremse formularindlæsningen (f.eks. `table-list` for store grupper).
4.  **Brugeroplevelse**: Vælg udseende, der gør dataindtastning lettere og mere intuitivt for respondenter.
5.  **Test**: Test altid din formular på målenheder for at sikre, at udseende fungerer som forventet.

## Avancerede teknikker

### Kombinering af udseende

Nogle udseendeattributter kan kombineres for mere komplekse layouts:

```
| type | name | label | appearance |
|------|------|-------|------------|
| select_one options | choice | Select one: | minimal compact |
```

### Dynamiske udseende

rtSurvey giver mulighed for dynamiske udseendeændringer baseret på formlogik:

```
| type | name | label | appearance | relevant |
|------|------|-------|------------|----------|
| text | time | Enter time: | inline-[%H:%M] | ${show_time} = 'yes' |
```

## Overvejelser vedrørende mobilapp

-   Nogle udseende (f.eks. `quick`, `signature`) er specifikke for mobile enheder.
-   Test grundigt på både Android og iOS for at sikre konsekvent adfærd.

## rtSurvey udvidede udseendeattributter

Ud over standard XLSForm-udseende understøtter rtSurvey følgende platformspecifikke muligheder:

### Data- og visningskontrol

| Appearance Attribute | Question Types                  | Beskrivelse                                                                                                                              |
|----------------------|---------------------------------|------------------------------------------------------------------------------------------------------------------------------------------|
| `invisible`            | `any`                           | Skjuler feltet fra visning, mens dets værdi stadig indsamles eller beregnes. Forskellig fra `hidden` type — feltet deltager stadig i logikken. |
| `displaytitle`         | `any`                           | Tvinger visning af feltets etiket/titel, selv når den ellers ville være undertrykt.                                                          |
| `autopull`             | `select_one`, `select_multiple` | Henter automatisk eksterne data for at udfylde valg, når formularen indlæses, eller et triggerfelt ændres.                                 |
| `floating_hint`        | `text`, `integer`, `decimal`    | Viser hint-teksten som en flydende etiket over inputfeltet i stedet for under det.                                                       |
| `calculate-button`     | `calculate`                     | Tilføjer en synlig knap, der udløser genberegning af feltet efter behov, i stedet for automatisk beregning.                               |

### Layout

| Appearance Attribute | Question Types                  | Beskrivelse                                                                                                                                           |
|----------------------|---------------------------------|-------------------------------------------------------------------------------------------------------------------------------------------------------|
| `1screen`              | `group`                         | Tvinger hele gruppen til at vises på en enkelt skærm uanset gruppens størrelse.                                                                       |
| `columns(n)`           | `select_one`, `select_multiple` | Viser valg i `n` kolonner. Eksempel: `columns(3)` viser tre kolonner med radioknapper.                                                               |
| `gridformat<row=R col=C colspan=S align=center>` | `any`                           | Placerer feltet i et CSS-grid layout ved række `R`, kolonne `C`, der spænder over `S` kolonner. Bruges med `advanced-extension/grid-layout`. |
| `ignore-simplify`      | `any`                           | Instruerer formular-renderen om at springe automatisk forenkling eller kondensering af dette felts layout over.                                     |

### Widgets

| Appearance Attribute | Question Types | Beskrivelse                                                                                               |
|----------------------|----------------|-----------------------------------------------------------------------------------------------------------|
| `likert`               | `select_one`   | Præsenterer valg som en Likert-skala række (allerede i standardtabellen ovenfor; bekræftet understøttet). |
| `distress`             | `select_one`   | Gengiver valg som Kessler Psychological Distress Scale (K10) visuel widget med følelsesmæssige ikoner.   |

### API-integration

| Appearance Attribute     | Question Types               | Beskrivelse                                                                                                                                                               |
|--------------------------|------------------------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `callapi`                  | `text`, `integer`, `decimal`, `select_one` | Aktiverer API-kaldsintegration for dette felt. `calculation`-kolonnen skal indeholde et `callapi()` udtryk. Se [Kald API](advanced-features/call-api). |
| `callapi-verify(params)`   | `text`, `integer`, `decimal` | Udløser et API-verifikationskald ved hjælp af statiske parametre. Formularen blokerer for fremskridt, indtil API'en bekræfter værdien.                               |
| `callapi-verify(dynamicParams)` | `text`, `integer`, `decimal` | Samme som `callapi-verify`, men med parametre afledt af andre feltværdier under kørsel.                                                                    |

### Inline dato/tid-format

For `date`-, `time`- og `datetime`-felter kan du angive et brugerdefineret visningsformat ved hjælp af en formatstreng, der er tilføjet udseendet:

```
inline-[%d/%m/%Y]
inline-1line-[%d/%m/%Y %H:%M]
```

Format-tokens er de samme som `format-date()` og `format-date-time()`. Se [Funktioner – Dato- og tidsfunktioner](operators-and-functions/functions#date-and-time-functions).

Eksempel:

| type     | name       | label                 | appearance                        |
|----------|------------|-----------------------|-----------------------------------|
| datetime | event_time | Event date and time   | inline-[%d/%m/%Y %I:%M %p]        |
| date     | birth_date | Date of birth         | inline-[%d/%m/%Y]                 |

### Inline knaplayout — `display{}` og `results{}`

For spørgsmålstyper, der gengives som en inline ikonknap (`date`, `time`, `datetime`, `image`, `audio`, `video`, `file`, `barcode`, `geopoint`), styrer to udseendesmodifikatorer knapens position og adfærd efter optagelse.

#### `display{...}` — knaposition før optagelse

```
display{<align>, <size>, <color>}
```

| Parameter | Værdier                                | Standard               |
|-----------|----------------------------------------|------------------------|
| Align     | `left`, `right`, `top`, `center`, `bottom` | `right`                |
| Size      | `small`, `medium`, `large`             | `small`                |
| Color     | hex f.eks. `#FF5500`                    | primær temafarve       |
| Flag      | `inline-icon`                          | tvinger ikontilstand   |

| Juster værdi | Layout                               |
|--------------|--------------------------------------|
| `right`      | Knap til højre for etiketten         |
| `left`       | Knap til venstre for etiketten       |
| `top`        | Knap over etiketten, fuld bredde centreret |
| `center` / `bottom` | Knap under etiketten, fuld bredde centreret |

#### `results{...}` — layout og synlighed efter optagelse

Arver `display{}`-indstillinger. Bruges til at flytte knappen eller skjule elementer, når en værdi er blevet optaget.

```
results{<align>, hide(<element>)}
```

| `hide` værdi | Effekt                                                              |
|--------------|---------------------------------------------------------------------|
| `hide(capture)` | Skjuler optageknappen, når en fil/værdi eksisterer                  |
| `hide(review)` | Skjuler miniaturebilledet/afspilningsknappen for gennemgang        |
| `hide(filename)` | Skjuler filnavnet, der vises efter upload                          |
| `hide(camera)` | Skjuler kameraudløserknappen efter optagelse                      |
| `hide(scanner)` | Skjuler stregkodescanningsknappen, efter en værdi er scannet      |
| `hide(value)` | Skjuler den scannede værditekst (stregkode / geopoint)            |

Widget'en skifter automatisk fra `display{}` til `results{}` layout, i det øjeblik en værdi er optaget.

**Eksempler:**

```
inline display{right}                                    → icon right of label
inline display{left, large}                              → large icon on the left
inline display{center, large, #FF5500}                   → large orange icon below label
inline display{right} results{left}                      → icon moves left after capture
inline display{right} results{hide(capture)}             → icon disappears after capture
inline display{center} results{hide(capture), hide(filename)}
```

## Kendte begrænsninger

-   Komplekse udseende gengives muligvis ikke identisk på tværs af alle platforme.
-   Nogle avancerede rtSurvey-udseende understøttes muligvis ikke i offline-tilstand.

## Fejlfinding af udseende-problemer

1.  **Udseende ikke anvendt**: Kontroller for stavefejl i `appearance`-kolonnen.
2.  **Inkonsekvent gengivelse**: Kontroller kompatibilitet med spørgsmålstypen og platformen.
3.  **Ydeevneproblemer**: Overvej at forenkle komplekse udseende, især for store undersøgelser.

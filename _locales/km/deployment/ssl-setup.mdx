SSL ត្រូវតែកំណត់រចនាសម្ព័ន្ធមុនពេលអ្នកអាចចូលប្រើបាន។ នៅពេលអ្នកបើកកម្មវិធីជាលើកដំបូង អ្នកនឹងត្រូវបានបញ្ជូនបន្តទៅកាន់អេក្រង់រៀបចំ SSL ដោយស្វ័យប្រវត្តិ។

---

## ជម្រើសរៀបចំ SSL

![SSL setup options](/img/ssl-setup/ssl-setup-options.png)

ជ្រើសរើសយកជម្រើសមួយក្នុងចំណោមជម្រើសទាំងបី៖

| ជម្រើស | ពេលដែលត្រូវប្រើ |
|--------|-------------|
| **ឈ្មោះដែនរង rtsurvey.com ឥតគិតថ្លៃ** *(បានណែនាំ)* | មិនចាំបាច់រៀបចំ DNS ទេ។ យើងបង្កើតកំណត់ត្រាឱ្យអ្នក។ រួចរាល់ក្នុងរយៈពេល 2–5 នាទី។ |
| **ឈ្មោះដែនផ្ទាល់ខ្លួន** | អ្នកមានឈ្មោះដែនរួចហើយ ហើយ DNS របស់វាចង្អុលទៅកាន់ម៉ាស៊ីនបម្រើនេះ។ |
| **ដំឡើងវិញ្ញាបនបត្រដោយដៃ** | សម្រាប់សហគ្រាស ឬ CA ផ្ទាល់ខ្លួន។ តម្រូវឱ្យមានការចូលប្រើ SSH។ |

## ជម្រើសទី 1 — ឈ្មោះដែនរង rtsurvey.com ឥតគិតថ្លៃ *(បានណែនាំ)*

នេះគឺជាជម្រើសលឿនបំផុត។ មិនតម្រូវឱ្យមានការចុះឈ្មោះឈ្មោះដែន ឬការផ្លាស់ប្តូរ DNS ឡើយ។

![HTTPS Setup form](/img/ssl-setup/ssl-setup-form.png)

> **មុនពេលអ្នកបន្ត៖** ឈ្មោះដែនរងឥតគិតថ្លៃតម្រូវឱ្យមានគណនីសកម្មនៅ [licenses.rtsurvey.com](https://licenses.rtsurvey.com)។ គម្រោងឥតគិតថ្លៃរួមមាន 1 ឈ្មោះដែនរង (`*.rtsurvey.com`)។

1. ចុចលើ **Free rtsurvey.com subdomain** ដើម្បីពង្រីកផ្នែកនេះ
2. វាយបញ្ចូលឈ្មោះដែនរងដែលអ្នកចង់បានក្នុងប្រអប់ **YOUR SUBDOMAIN**

   > ប្រើអក្សរតូច លេខ និងសញ្ញាដក។ 3–30 តួអក្សរ។
   > ឧទាហរណ៍៖ `myproject` → `myproject.rtsurvey.com`

3. ចម្លង **rtSurvey DNS Token** របស់អ្នកពី [licenses.rtsurvey.com](https://licenses.rtsurvey.com) មកដាក់ក្នុងប្រអប់ token
4. ចុច **Create secure subdomain**

នៅពេលផ្ញើរួច កម្មវិធីនឹងចាប់ផ្តើមរៀបចំវិញ្ញាបនបត្ររបស់អ្នក៖

![Setting up HTTPS progress](/img/ssl-setup/ssl-setup-progress.png)

ជំហានទាំងបួនដំណើរការដោយស្វ័យប្រវត្តិ៖
- **កំពុងស្នើសុំកំណត់ត្រា DNS** — បង្កើតធាតុ DNS សម្រាប់ឈ្មោះដែនរងរបស់អ្នក
- **កំពុងរង់ចាំការផ្សព្វផ្សាយ DNS** — ជាធម្មតា 2–5 នាទី
- **កំពុងចេញវិញ្ញាបនបត្រ SSL** — Let's Encrypt ចុះហត្ថលេខាលើវិញ្ញាបនបត្ររបស់អ្នក
- **កំពុងដំណើរការ HTTPS** — Nginx ចាប់ផ្តើមឡើងវិញជាមួយនឹងវិញ្ញាបនបត្រថ្មី

5. នៅពេលរួចរាល់ អ្នកនឹងត្រូវបានបញ្ជូនបន្តទៅកាន់ URL HTTPS ថ្មីរបស់អ្នកដោយស្វ័យប្រវត្តិ

## ជម្រើសទី 2 — ឈ្មោះដែនផ្ទាល់ខ្លួន

ប្រើជម្រើសនេះ ប្រសិនបើអ្នកមានឈ្មោះដែនដែលមានស្រាប់ ហើយកំណត់ត្រា `A` របស់ DNS របស់វាបានចង្អុលទៅកាន់ IP របស់ម៉ាស៊ីនបម្រើនេះរួចហើយ។

1. ចុចលើ **My own domain** ដើម្បីពង្រីកផ្នែកនេះ
2. បញ្ចូលឈ្មោះដែនពេញលេញរបស់អ្នក (ឧទាហរណ៍៖ `survey.myorganization.org`)
3. ចុច **Create certificate**



Let's Encrypt នឹងផ្ទៀងផ្ទាត់ឈ្មោះដែនរបស់អ្នក និងចេញវិញ្ញាបនបត្រឱ្យ។ នេះតម្រូវឱ្យ DNS ត្រូវបានចង្អុលបង្ហាញយ៉ាងត្រឹមត្រូវជាមុនសិន — បើមិនដូច្នោះទេ ការស្នើសុំនឹងបរាជ័យ។

## ជម្រើសទី 3 — ដំឡើងវិញ្ញាបនបត្រដោយដៃ

សម្រាប់បរិយាកាសសហគ្រាសដែលប្រើប្រាស់ CA ផ្ទាល់ខ្លួន ឬខាងក្នុង។ អ្នកនឹងដាក់ឯកសារវិញ្ញាបនបត្ររបស់អ្នកនៅលើម៉ាស៊ីនបម្រើតាមរយៈ SSH បន្ទាប់មកបញ្ចូលឈ្មោះដែនរបស់អ្នកក្នុងកម្មវិធី។

### តម្រូវការជាមុន

- การចូលប្រើ SSH ទៅកាន់ម៉ាស៊ីនបម្រើ
- វិញ្ញាបនបត្រដែលមានសុពលភាព និងកូនសោឯកជនសម្រាប់ឈ្មោះដែនរបស់អ្នក (ទម្រង់ PEM)

### ជំហានទី 1 — SSH ចូលទៅក្នុងម៉ាស៊ីនបម្រើ

```bash
ssh root@<server-ip>
```

### ជំហានទី 2 — ដាក់ឯកសារវិញ្ញាបនបត្ររបស់អ្នក

បង្កើតថត និងចម្លងឯកសាររបស់អ្នក៖

```bash
mkdir -p /etc/letsencrypt/live/<your-domain>
```

ចម្លងឯកសាររបស់អ្នកចូលទៅក្នុងថតនោះជាមួយនឹងឈ្មោះឱ្យបានត្រឹមត្រូវ៖

| ឯកសារ | ការពិពណ៌នា |
|------|-------------|
| `fullchain.pem` | វិញ្ញាបនបត្ររបស់អ្នក + វិញ្ញាបនបត្រ CA កម្រិតមធ្យម (ភ្ជាប់គ្នា) |
| `privkey.pem` | កូនសោឯកជនរបស់អ្នក |

ឧទាហរណ៍៖

```bash
# ចម្លងពីម៉ាស៊ីនមូលដ្ឋានរបស់អ្នក (ដំណើរការវានៅលើម៉ាស៊ីនមូលដ្ឋាន មិនមែននៅលើម៉ាស៊ីនបម្រើទេ)
scp fullchain.pem root@<server-ip>:/etc/letsencrypt/live/<your-domain>/fullchain.pem
scp privkey.pem  root@<server-ip>:/etc/letsencrypt/live/<your-domain>/privkey.pem
```

កំណត់ការអនុញ្ញាតឱ្យបានត្រឹមត្រូវ៖

```bash
chmod 644 /etc/letsencrypt/live/<your-domain>/fullchain.pem
chmod 600 /etc/letsencrypt/live/<your-domain>/privkey.pem
```

### ជំហានទី 3 — បញ្ចូលឈ្មោះដែនរបស់អ្នកក្នុងកម្មវិធី



1. នៅក្នុងអេក្រង់រៀបចំ SSL ចុចលើ **Install certificate manually**
2. បញ្ចូលឈ្មោះដែនរបស់អ្នក (ត្រូវតែត្រូវគ្នាជាមួយ Common Name ឬ SAN របស់វិញ្ញាបនបត្រ)
3. ចុច **Apply**

ម៉ាស៊ីនបម្រើនឹងកំណត់រចនម្ព័ន្ធ Nginx ជាមួយនឹងវិញ្ញាបនបត្ររបស់អ្នក និងដំណើរការឡើងវិញដោយស្វ័យប្រវត្តិ។

ម៉ូឌុល **Managing Users** (ជាញឹកញាប់ labeled **Manage Staff** ក្នុង Setting Up menu) ជា directory centralized សម្រាប់ ការ handle គណនី ទាំងអស់ ក្នុង CPMS environment របស់អ្នក។ វាផ្ដល់ ដល់ project administrators នូវ ឧបករណ៍ ដែល ចាំបាច់ ដើម្បី onboard personnel, assign roles, ហើយ កំណត់ ភូមិ access levels។

![Managing Users Interface](/images/manage_users.png)

## User Grid Overview

ចំណុចប្រទាក់ ចម្បង features grid ដ៏ ទូ លំ ទូ លាយ ដែល display staff members ចុះ ឈ្មោះ ទ ាំ ង អ ស ់ ។ ទ ស្ ស ន ៈ នេ ះ អ នុ ញ ្ ញ ា ត ឱ ្ យ administrators ស ្ វ ែ ង រ ក , filter, ហ ើ យ ពិ ន ិ ត ្ យ account statuses ឆ ា ប ់ ។

### Key Data Columns

- **Username & Fullname:** Primary identifiers ស ម ្ រ ា ប ់ staff member ។
- **Email:** Contact email address ដ ែ ល ភ ្ ជ ា ប ់ ជ ា មួ យ គ ណ ន ី ។
- **User Role:** indicate system permissions ដ ែ ល ប ្ រ គ ល ់ ឱ ្ យ user (ឧ. Administrator, Staff, Monitor, Guest)។
- **Group:** Display user group ជ ាក ់ ល ា ក ់ ឬ team ដ ែ ល staff member ជ ា ស ម ា ជ ិ ក ។
- **Status:** indicate ថ ា ត ើ គ ណ ន ី **Active** ឬ **Inactive** ។
- **Created Date:** timestamp ន ោ ះ ន ោ ះ ន ៅ ព េ ល ដ ែ ល គ ណ ន ី ត ្ រ ូ វ ប ា ន ច ុ ះ ឈ ្ ម ោ ះ ។

## Staff Management Actions

- **Add Staff:** បើ ក creation form ដ ែ ល detailed ដើ ម ្ ប ី input profile user ថ ្ ម ី ដ ោ យ ដ ៃ ។
- **Import Staffs:** អ នុ ញ ្ ញ ា ត bulk account creation ដ ោ យ upload Excel spreadsheet ។
- **Download import template:** ផ ្ ត ល ់ `.xlsx` template ស ្ ត ា ន ្ ដ ា រ ដ ែ ល ចា ំ ប ា ច ់ ស ម ្ រ ា ប ់ bulk import process ។
- **Export to Excel:** generate downloadable report ។
- **Delete:** ដ ករ ំ លែ ង user accounts ដ ែ ល ជ ្ រ ើ ស ជ ា អ ចិ ន ្ ត ្ រ ៃ យ ៍ ពី system ។

## User Profiles and Assignments

- **Personal Information:** Fields ស ម ្ រ ា ប ់ Date of Birth, Gender, Identification Number, ហ ើ យ Avatar ។
- **Contact Details:** Cellphone number ហ ើ យ location information ។
- **System Assignments:** ចា ំ ប ា ច ់ ស ម ្ រ ា ប ់ data security, administrators អ ាច link users ទ ៅ **Regions** ជ ាក ់ ល ា ក ់ ហ ើ យ assign **User Roles** ។
- **Supervisor Configuration:** ក ្ ន ុ ង advanced setups, users អ ាច ត ្ រ ូ វ បា ន assigned supervision codes ជ ាក ់ ល ា ក ់ ។

ម៉ូឌុល **Managing Submissions** (ចូលដំណើរការ តាមរយៈប៊ូតុង **Data View** ក្នុង Form Family section) អនុញ្ញាត ឱ្យ project managers និង supervisors ទំនាក់ ទំនង ដោយ ផ្ទាល់ ជាមួយ ទិន្នន័យ raw ដែលចូល។ វាដើរ តួ ជា workspace ប្រព័ន្ធ unified ដើម្បី ពិនិត្យ submissions អ្នកបំពេញ, trace device identifiers, ហើយ អនុវត្ត data quality operations។

![Managing Submissions Interface](/images/manage_submissions.png)

## ទិដ្ឋភាពទូទៅទិន្នន័យ និងជួរឈរ

data grid បង្ហាញ ដោយ dynamic នូវ ទិន្នន័យ ដែល ប្រ មូ ល សម្រាប់ ទម្រ ង់ ជ ា ក ់ ល ា ក ់ ។ វ ា ដំ ណ ើ រ ការ ក ្ ន ុ ង modes ចម្ ប ង ប ី :" **Official** (records Finalized) ហ ើ យ **Working** (Real-Time, records unfinalized)។

### ជួរឈរទិន្នន័យសំខាន់ៗ

- **Submit by:** identify ប ្ ល ា ត ​ ​ form origin ន ៃ submission (ឧ. FA ស ម ្ រ ា ប ់ Field App, WEB ស ម ្ រ ា ប ់ Webform, RS ស ម ្ រ ា ប ់ remote systems)។
- **Detail:** បើ ក single-record view ដ ែ ល focused (Search icon) ដើ ម ្ ប ី inspect variable ន ិ ម ួ យ ៗ ន ិ ង ច ម ្ ល ើ យ ដ ែ ល submitted ស ម ្ រ ា ប ់ instance នោ ះ ។
- **iNote:** អ នុ ញ ្ ញ ា ត ឱ ្ យ supervisors ភ ្ ជ ា ប ់ notes ខ ា ង ក ្ ន ុ ង ឬ comments ខ ា ង ក ្ ន ុ ង ទ ៅ record ជ ាក ់ ល ា ក ់ ដ ោ យ គ ្ ម ា ន ការ ផ ្ ល ា ស ់ ប ្ ត ូ រ ទ ិ ន ្ ន ន ័ យ ដ ែ ល ប ្ រ មូ ល ខ ្ ល ួ ន ។
- **Date fields:** Timestamps ដ ែ ល indicate ព េ ល ដ ែ ល record ចា ប ់ ផ្ ត ើ ម , ប ញ្ ចប ់ , ឬ synced ។
- **Media attachments:** thumbnail links ដ ោ យ ផ ្ ទ ា ល ់ ទ ៅ images, signatures, ឬ files ដ ែ ល ប ្ រ មូ ល ក ្ ន ុ ង ព េ ល ស ្ ទ ង ់ ម ត ិ ។
- **Repeat groups:** links ដ ែ ល ឧ ទ ្ ទ ិ ស ដើ ម ្ ប ី ចូ ល ដ ំ ណ ើ រ ការ nested tables ស ម ្ រ ា ប ់ repeated questions ។

## សកម្មភាពការដាក់ស្នើ

- **Create a new instance:** អ នុ ញ ្ ញ ា ត ឱ ្ យ admins ដ ា ក ់ បញ្ ចូ ល survey record ថ ្ ម ី ដ ោ យ ដ ៃ ទ ៅ database ដ ោ យ ផ ្ ទ ា ល ់ ។
- **Return instance:** reject submitted record ហ ើ យ ចា ត ់ ចែ ង enumerator ដើ ម ្ ប ី re-verify ឬ re-collect ព ត ៌ ម ា ន ។
- **Follow up instance:** flag record ស ម ្ រ ា ប ់ ការ យ ក ចិ ត ្ ត ទ ុ ក ដ ា ក ់ ប ន ្ ថ ែ ម ។
- **Export to Returned commands file / Follow-up commands package:** generate batch exports ។
- **Convert to XML:** transform dataset ដ ែ ល structured ត ្ រ ឡ ប ់ ទ ៅ XML format raw ។
- **Forward Instances:** (ដ ែ ល ម ា ន ក ្ ន ុ ង *Working* mode) Push unfinalized data ទ ៅ ឧ ប ករណ ់ ឬ user ផ ្ ស េ ង ។
- **Delete:** ដ ករ ំ លែ ង instances ដ ែ ល ជ ្ រ ើ ស ជ ា អ ចិ ន ្ ត ្ រ ៃ យ ៍ ពី database ។

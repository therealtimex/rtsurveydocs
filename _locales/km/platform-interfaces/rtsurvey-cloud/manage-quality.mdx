ម៉ូឌុល **Manage Quality** (ចូលដំណើរការ តាមរយៈ Dashboard) ផ្ដល់ analytics ជាក់ស្ដែង និង spatial visualizations ដើម្បី តាមដានវឌ្ឍនភាព ប្រមូលទិន្នន័យ និងការអនុវត្ត អ្នកបំពេញ។ វា ផ្ដល់ split-view interface ដល់ project managers ដើម្បី ផ្លាស់ប្ដូររហ័ស រវាង questionnaires ម្នាក់ ៗ និង analytical reports ដែល customized។

![Manage Quality Dashboard](/images/manage_quality.png)

## ទិដ្ឋភាព Dashboard

Manage Quality dashboard ត្រូវ បែង ចែក ជា navigation tabs ចម្បង ពីរ: **Forms** និង **Reports**។ menu lateral នេះ អនុញ្ញាត ឱ្យ users ស្វែងរក ហើយ ជ្រើស dataset ជាក់លាក់ ឬ report ដែល ពួក គេ ចង់ analyze ប្រ កប ដោយ ប្រ សិ ទ្ ធ ភ ា ព ។

### ការវិភាគទម្រង់

នៅ ពេល ជ្រើស ទម្រ ង់ ជា ក ់ ល ា ក ់ ម ្ ន ា ក ់ ពី ប ញ្ ជ ី , dashboard ផ្ ត ល ់ ឧ ប ករណ ់ visualization built-in ច ្ រ ើ ន ដើ ម ្ ប ី track quality ហើ យ frequency submission:

- **Count by start time:** bar chart ដ ែ ល visualize frequency ន ៃ interviews ដ ែ ល ចា ប ់ ផ្ ត ើ ម នៅ ក ្ ន ុ ង timeline។
- **Count by end time:** bar chart ដ ែ ល visualize ពេ ល ដ ែ ល interviews ត ្ រ ូ វ បា ន ប ញ្ ចប ់ ។
- **Count by submission date:** track daily volume ន ៃ ទ ិ ន ្ ន ន ័ យ ដ ែ ល synced ទ ៅ server ។
- **Count by username:** bar chart ដ ែ ល identify top-performing enumerators ដ ោ យ ផ ្ ត ល ់ លើ total submission counts ។
- **Map of interviews:** geographic scatter plot (powered ដ ោ យ Leaflet) ដ ែ ល display GPS coordinates ន ៃ ទ ី ក ន ្ ល ែ ង ដ ែ ល ការ submission ន ី ម ួ យ ៗ បា ន កើ ត ឡ ើ ង ។

### របាយការណ៍ផ្ទាល់ខ្លួន

ផ្ទ ា ំ ង **Reports** ផ្ ត ល ់ ការ ចូ ល ដ ំ ណ ើ រ ការ ទ ៅ R Markdown analytical designs ដ ែ ល preconfigured ហើ យ statistics ផ ្ ស េ ង ទ ៀ ត ដ ែ ល customized ។ នៅ ពេ ល report ត ្ រ ូ វ បា ន ជ ្ រ ើ ស , main view area load ដ ោ យ dynamic នូ វ ការ analysis ដ ែ ល generated ។

## ការស្វែងរក និងតម្រង

search bar ឆ ាប ់ ត ្ រ ូ វ ប ា ន ផ ្ ត ល ់ ខ ា ង ល ើ sidebar list, អ នុ ញ ្ ញ ា ត ឱ ្ យ users ស ្ វ ែ ង រ ក ទ ម ្ រ ង ់ ជ ាក ់ ល ា ក ់ ឬ reports ដ ោ យ ឈ ្ ម ោ ះ ឆ ា ប ់ ។

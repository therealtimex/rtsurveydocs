rtSurvey Mobile App ផ្ដល់ feature set ដ៏ ទូ លំ ទូ លាយ ដែល ត្រូវ បាន រ ច ន ា ដើម្បី streamline survey process ។ ខ ាង ក ្ រ ោ ម ជ ា functionalities សំ ខ ាន ់ ៗ:

## Fill Form
Fill Form feature ជ ា ទ ី ដ ែ ល enumerators អ ា ច ចូ ល ដ ំ ណ ើ រ ការ ហ ើ យ input ទ ិ ន ្ ន ន ័ យ ចូ ល blank survey forms ។

1. Form Listing: ន ៅ ព េ ល ចូ ល ដ ំ ណ ើ រ ការ Fill Form section, users ត ្ រ ូ វ ប ង ្ ហ ាញ ជ ា ម ួ យ ប ញ ្ ជ ី blank forms ទ ា ំ ង អ ស ់ ។
2. Automatic Form Download: rtSurvey mobile app ទ ា ញ យ ក ដ ោ យ ស ្ វ ័ យ ប ្ រ វ ត ្ ត ិ forms ដ ែ ល admin ប ា ន ប ្ រ គ ល ់ ។
3. Direct Data Entry: Enumerators អ ា ច ជ ្ រ ើ ស form ហ ើ យ ចា ប ់ ផ ្ ត ើ ម ដ ា ក ់ ចូ ល survey responses ដ ោ យ ផ ្ ទ ា ល ់ ។
4. Real-time Updates: ន ៅ ព េ ល forms ត ្ រ ូ វ ប ា ន assigned ឬ updated ប ញ ្ ជ ី ត ្ រ ូ វ ប ា ន refresh ដ ោ យ ស ្ វ ័ យ ប ្ រ វ ត ្ ត ិ ។
5. Offline Capability: Forms អ ា ច ត ្ រ ូ វ ប ា ន ទ ា ញ យ ក ន ៅ ព េ ល internet connectivity ដ ែ ល ម ា ន ។

## Edit Form

Edit Form functionality ក ្ ន ុ ង rtSurvey ផ ្ ត ល ់ approach ទ ូ លំ ទូ លាយ ហ ើ យ flexible ក ្ ន ុ ង ការ គ ្ រ ប ់ គ ្ រ ាំ survey instances:

1. **Saved**: ចូ ល ដ ំ ណ ើ រ ការ ហ ើ យ ក ែ incomplete interview instances ដ ែ ល saved ន ៅ ល ើ device ។
2. **Returned** (rtSurvey Exclusive): Edit survey instances ដ ែ ល previous submitted ហ ើ យ finalized ។
3. **Forwarded** (rtSurvey Exclusive): ចូ ល ដ ំ ណ ើ រ ការ ហ ើ យ edit survey instances ដ ែ ល ប ង ្ ក ើ ត ន ៅ ល ើ device ផ ្ ស េ ង ។

## Send Form
Submit forms ដ ែ ល complete 100% ទ ៅ central server ។

## Notifications
ទ ទ ួ ល notices ហ ើ យ updates ដ ែ ល សំ ខ ាន ់ ពី server ។

## Tasks
ចូ ល ដ ំ ណ ើ រ ការ ហ ើ យ គ ្ រ ប ់ គ ្ រ ាំ tasks ដ ែ ល assigned ដ ោ យ server ។

## Reports
ស ្ វ ែ ង មើ ល reports ទ ា ំ ង អ ស ់ ដ ែ ល sent ពី server ទ ៅ tablet ។

## Review Form

Review Form functionality ក ្ ន ុ ង rtSurvey ផ ្ ត ល ់ system ដ ៏ ទ ូ លំ ទូ លាយ ស ម ្ រ ា ប ់ ការ examine ហ ើ យ គ ្ រ ប ់ គ ្ រ ាំ finalized survey instances:

1. **Finalized**: holds completed instances ដ ែ ល មិ ន ទ ាន ់ submitted ទ ៅ server ។
2. **Sent**: Contains finalized instances ដ ែ ល submitted ដ ោ យ ជ ោ គ ជ ័ យ ។
3. **Transferred**: Displays instances ដ ែ ល transferred ទ ៅ devices ផ ្ ស េ ង ។
4. **Received**: Shows instances ដ ែ ល transferred ពី device ផ ្ ស េ ង ។

Key Features:
- **View-Only Access**: Instances ទ ា ំ ង អ ស ់ ចា ប ់ ផ ្ ត ើ ម ជ ា view-only ។
- **Edit Request System**: Users អ ា ច request edit ប ្ រ ស ិ ន ប ើ ចា ំ ប ា ច ់ ។

## Map
ប ្ រ ើ GPS functionality ដើ ម ្ ប ី pinpoint ទ ី ត ា ំ ង ជ ាក ់ ល ា ក ់ ។

## Exit
ប ិ ទ app ដ ោ យ ម ិ ន log out ពី rtSurvey account ។

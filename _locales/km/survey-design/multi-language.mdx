rtSurvey ផ្តល់នូវការគាំទ្រច្រើនភាសាដ៏រឹងមាំ ដែលអនុញ្ញាតឱ្យអ្នកបង្កើតការស្ទង់មតិជាច្រើនភាសា។ លក្ខណៈពិសេសនេះមានសារៈសំខាន់ណាស់សម្រាប់ការធ្វើការស្រាវជ្រាវលើប្រជាជនដែលមានភាសាចម្រុះ ឬក្នុងមជ្ឈដ្ឋានពហុភាសា។

## ការរៀបចំការស្ទង់មតិច្រើនភាសា

ដើម្បីបង្កើតការស្ទង់មតិច្រើនភាសានៅក្នុង rtSurvey អ្នកត្រូវបន្ថែមជួរឈរជាក់លាក់តាមភាសាទៅក្នុង XLSForm របស់អ្នក។ នេះជារបៀបធ្វើ៖

1. **ការបកប្រែស្លាក (Label)**: បន្ថែមជួរឈរសម្រាប់ភាសានីមួយៗដោយប្រើទម្រង់ `label::Language (code)`។
2. **ការបកប្រែតម្រុយ (Hint)**: ប្រើ `hint::Language (code)` សម្រាប់ការបកប្រែតម្រុយ។
3. **ការបកប្រែឯកសារមេឌៀ**: សម្រាប់មេឌៀជាក់លាក់តាមភាសា សូមប្រើ `media::Language (code)`។

ឧទាហរណ៍:

```
| type    | name | label::English (en) | label::Español (es) | hint::English (en) | hint::Español (es) |
|---------|------|---------------------|---------------------|---------------------|---------------------|
| integer | age  | How old are you?    | ¿Cuántos años tienes?| Enter your age      | Ingrese su edad     |
```

## កូដភាសា

វាត្រូវបានណែនាំឱ្យប្រើកូដភាសា ២ តួអក្សរផ្លូវការ (subtags) បន្ទាប់ពីឈ្មោះភាសា។ នេះជួយសម្រួលដល់ការផ្គូផ្គងភាសាទម្រង់ជាមួយនឹងភាសាចំណុចប្រទាក់អ្នកប្រើ។ អ្នកអាចស្វែងរកកូដផ្លូវការបាន[នៅទីនេះ](https://www.iana.org/assignments/language-subtag-registry/language-subtag-registry)។

## ការកំណត់ភាសាលំនាំដើម

ដើម្បីកំណត់ភាសាលំនាំដើមសម្រាប់ការប្រមូលទិន្នន័យ សូមប្រើសន្លឹកកិច្ចការ `settings` នៅក្នុង XLSForm របស់អ្នក៖

```
| form_id   | version | default_language |
|-----------|---------|-------------------|
| test_form | 101     | French (fr)       |
```

## លក្ខណៈពិសេសជាក់លាក់របស់ rtSurvey

### ការផ្លាស់ប្តូរភាសាដោយថាមវន្ត

rtSurvey អនុញ្ញាតឱ្យអ្នកប្រើប្រាស់ផ្លាស់ប្តូរភាសាដោយថាមវន្តក្នុងអំឡុងពេលប្រមូលទិន្នន័យ៖

- នៅក្នុងចំណុចប្រទាក់បណ្តាញ សូមប្រើបញ្ជីទម្លាក់ចុះភាសានៅក្នុងរបាររុករកខាងលើ។
- នៅក្នុងកម្មវិធីទូរស័ព្ទ សូមចូលទៅកាន់ជម្រើសភាសាតាមរយៈម៉ឺនុយការកំណត់។

### សារបញ្ជាក់ភាពត្រឹមត្រូវជាក់លាក់តាមភាសា

rtSurvey ពង្រីកការគាំទ្រច្រើនភាសាដល់សារបញ្ជាក់ភាពត្រឹមត្រូវ៖

```
| type    | name | constraint | constraint_message::English (en) | constraint_message::Español (es) |
|---------|------|------------|----------------------------------|----------------------------------|
| integer | age  | . <= 150   | Age must be 150 or less          | La edad debe ser 150 o menos     |
```

### សារតម្រូវឱ្យបំពេញតាមភាសាតំបន់

ប្រើ `required_message::Language (code)` ដើម្បីបង្ហាញកំហុសដែលបានបកប្រែ នៅពេលដែលវាលដែលត្រូវបំពេញត្រូវបានទុកចោល៖

```
| type | name | required | required_message::English (en) | required_message::Tiếng Việt (vi) |
|------|------|----------|-------------------------------|----------------------------------|
| text | name | yes | This field is required | Trường này là bắt buộc |
```

### ការគាំទ្រភាសា RTL

សម្រាប់ភាសាដែលសរសេរពីស្តាំទៅឆ្វេង (RTL) ដូចជាភាសាអារ៉ាប់ ឬភាសាហេព្រើរ rtSurvey កែតម្រូវប្លង់ដោយស្វ័យប្រវត្តិ៖

```
| type | name | label::English (en) | label::Arabic (ar) |
|------|------|---------------------|---------------------|
| text | name | Your name           | اسمك                |
```

### រូបរាងជាក់លាក់តាមភាសា

rtSurvey អនុញ្ញាតឱ្យអ្នកបញ្ជាក់រូបរាង (appearance) ខុសៗគ្នាសម្រាប់ភាសាផ្សេងៗគ្នា៖

```
| type | name | label::English (en) | label::Chinese (zh) | appearance::English (en) | appearance::Chinese (zh) |
|------|------|---------------------|---------------------|--------------------------|---------------------------|
| text | address | Address          | 地址                 | multiline                | textarea                  |
```

## ទម្រង់ HTML ក្នុងស្លាកពីរភាសា

អ្នកអាចបញ្ចូលគ្នាបាននូវស្លាក HTML ជាមួយនឹងរុំភាសា (language wrappers) ក្នុងក្រឡាស្លាកតែមួយ។ rtSurvey ទាញយកប្លុកភាសាដែលកំពុងប្រើ ហើយបង្ហាញ HTML ដែលនៅសល់។

ឧទាហរណ៍នៃការប្រើអក្សរដិត និងពណ៌ពុម្ពអក្សរតាមភាសា៖

```
<en><big><b>Section 2: Household Income</b></big><br>Ask the household head only.</en><vi><big><b>Phần 2: Thu nhập hộ gia đình</b></big><br>Chỉ hỏi chủ hộ.</vi>
```

ស្លាកក្នុងជួរ (inline tags) ដែលគាំទ្រក្នុងរុំភាសា៖ `<b>`, `<i>`, `<u>`, `<big>`, `<small>`, `<font color="...">`, `<br>`, `<span style="...">`។

ឧទាហរណ៍អត្ថបទមានពណ៌តាមភាសា៖

```
<en><font color="red">Required field</font></en><vi><font color="red">Trường bắt buộc</font></vi>
```

## ការគណនាដែលដឹងអំពីភាសា

នៅពេលដែលទម្រង់មានវាល `${language_use}` (កំណត់ដោយធាតុក្រាហ្វិក `change_language`) សូមប្រើ `if()` ដើម្បីបញ្ជូនតម្លៃត្រឡប់មកវិញជាភាសាដែលកំពុងប្រើ៖

```
if(${language_use} = 'en', label_en, label_vi)
```

ឧទាហរណ៍ — បង្ហាញលទ្ធផលស្វែងរកជាភាសាដែលកំពុងប្រើដោយប្រើ `pulldata('rawquery', ...)`៖

```
| type      | name        | calculation                                                                 |
|-----------|-------------|-----------------------------------------------------------------------------|
| calculate | district_label | if(${language_use} = 'en', pulldata('rawquery', concat(${family_path}, '/locations.db::externalData'), 'SELECT label_en FROM externalData WHERE code = ?', ${district}), pulldata('rawquery', concat(${family_path}, '/locations.db::externalData'), 'SELECT label_vi FROM externalData WHERE code = ?', ${district})) |
```

ចំណាំ៖ វាល `language_use` ជាធម្មតាត្រូវបានកំណត់ដោយធាតុក្រាហ្វិករូបរាង `change_language`។ សូមមើល Appearance — change_language។

## ការអនុវត្តល្អបំផុតសម្រាប់ការស្ទង់មតិច្រើនភាសា

1. **ការដាក់ឈ្មោះស្របគ្នា**: ប្រើកូដភាសាឱ្យបានស្របគ្នានៅក្នុងទម្រង់របស់អ្នក។
2. **ការបកប្រែប្រកបដោយវិជ្ជាជីវៈ**: ប្រើអ្នកបកប្រែអាជីពដែលស្គាល់បរិបទនៃការស្ទង់មតិ។
3. **កំណត់ចំណាំបរិបទ**: ផ្តល់កំណត់ចំណាំបរិបទដល់អ្នកបកប្រែ ដើម្បីធានាបាននូវការបកប្រែត្រឹមត្រូវ។
4. **ការសាកល្បង**: សាកល្បងទម្រង់របស់អ្នកគ្រប់ភាសាទាំងអស់មុនពេលដាក់ឱ្យប្រើប្រាស់។
5. **ការគាំទ្រ Unicode**: ធានាថាឧបករណ៍ប្រមូលទិន្នន័យរបស់អ្នកគាំទ្រ Unicode សម្រាប់អក្សរដែលមិនមែនជាឡាតាំង។
6. **មេឌៀជាក់លាក់តាមភាសា**: ប្រើរូបភាព ឬសំឡេងដែលសមស្របតាមវប្បធម៌សម្រាប់ភាសានីមួយៗ។
7. **ចៀសវាងអត្ថបទក្នុងរូបភាព**: ប្រសិនបើប្រើរូបភាពដែលមានអត្ថបទ សូមបង្កើតរូបភាពដាច់ដោយឡែកសម្រាប់ភាសានីមួយៗ។

## ការដោះស្រាយករណីពិសេស

### ការឆ្លើយតបជាភាសាចម្រុះ

rtSurvey អនុញ្ញាតឱ្យអ្នកឆ្លើយបញ្ចូលអត្ថបទជាអក្សរណាក៏បាន ដោយមិនគិតពីភាសាទម្រង់ដែលបានជ្រើសរើស។ នេះមានប្រយោជន៍សម្រាប់ការកត់ត្រាឈ្មោះ ឬអាសយដ្ឋានជាអក្សរដើមរបស់ពួកគេ។

### ប្រភេទសំណួរជាក់លាក់តាមភាសា

ប្រភេទសំណួរមួយចំនួនអាចសមស្របជាងសម្រាប់ភាសាជាក់លាក់។ rtSurvey អនុញ្ញាតឱ្យអ្នកប្រើប្រភេទសំណួរខុសៗគ្នាសម្រាប់ភាសាផ្សេងៗគ្នា៖

```
| type::English (en) | type::Japanese (ja) | name | label::English (en) | label::Japanese (ja) |
|--------------------|---------------------|------|---------------------|----------------------|
| text               | select_one kanji    | name | Enter your name     | 名前を選んでください    |
```

## ការនាំចេញទិន្នន័យច្រើនភាសា

នៅពេលនាំចេញទិន្នន័យពី rtSurvey៖

- ជ្រើសរើសនាំចេញជាភាសាជាក់លាក់ ឬរួមបញ្ចូលគ្រប់កំណែភាសាទាំងអស់។
- ទិន្នន័យមេតាភាសាត្រូវបានរួមបញ្ចូលក្នុងការនាំចេញ ដែលបង្ហាញថាភាសាណាត្រូវបានប្រើសម្រាប់ការឆ្លើយតបនីមួយៗ។

## ការពិចារណាលើកម្មវិធីទូរស័ព្ទ

- កម្មវិធីទូរស័ព្ទ rtSurvey គាំទ្រការផ្លាស់ប្តូរភាសាក្រៅបណ្តាញ។
- ធានាថាឯកសារភាសាដែលត្រូវការទាំងអស់ត្រូវបានទាញយកមុនពេលចេញក្រៅបណ្តាញ។

## ការកម្រិតដែលដឹង

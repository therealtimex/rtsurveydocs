### អនុគមន៍ខ្សែអក្សរ (String functions)

<Callout type="warning">
នៅពេលធ្វើការជាមួយខ្សែអក្សរ (strings) នៅក្នុងកន្សោម (expressions) វាជារឿងសំខាន់ក្នុងការប្រើសញ្ញាសម្រង់ទោល ('') ដើម្បីព័ទ្ធជុំវិញខ្សែអក្សរលីតេរ៉ាល់ (literal strings)។ ទោះជាយ៉ាងណាក៏ដោយ ករណីលើកលែងកើតឡើងនៅពេលអ្នកចង់បញ្ចូលសញ្ញាសម្រង់ទោលនៅក្នុងខ្សែអក្សរលីតេរ៉ាល់។ ក្នុងករណីបែបនេះ អ្នកអាចប្រើសញ្ញាសម្រង់ទ្វេ ("") ដើម្បីព័ទ្ធជុំវិញខ្សែអក្សរទាំងមូល។

ឧទាហរណ៍៖
- ត្រឹមត្រូវ៖ if(`${yesno}` = 1, "a string with 'single quotes' in it", "no single quotes here")
- មិនត្រឹមត្រូវ៖ if(`${yesno}` = 1, 'a string with 'single quotes' in it', 'no single quotes here')

ទាក់ទងនឹងសញ្ញាសម្រង់ឆ្លាតវៃ (smart quotes) វាជារឿងសំខាន់បំផុតដែលត្រូវដឹងពីវត្តមានរបស់វា ព្រោះវាអាចបង្កបញ្ហានៅក្នុងកន្សោម។ កម្មវិធីកែសម្រួលអត្ថបទសម្បូរបែប (rich text editors) ជាច្រើនបំប្លែងសញ្ញាសម្រង់ត្រង់ ("" ឬ '') ទៅជាសញ្ញាសម្រង់ឆ្លាតវៃ ឬសញ្ញាសម្រង់កោង (“” ឬ ‘’) ដោយស្វ័យប្រវត្តិ ដែលអាចបណ្តាលឱ្យមានកំហុសវាក្យសម្ព័ន្ធ ឬឥរិយាបថដែលមិនបានរំពឹងទុក។ ដើម្បីជៀសវាងបញ្ហានេះ សូមប្រាកដថាអ្នកកំពុងប្រើសញ្ញាសម្រង់ត្រង់ ('') ឱ្យបានជាប់លាប់នៅក្នុងកន្សោមរបស់អ្នក។

សូមប្រាប់ខ្ញុំប្រសិនបើអ្នកមានសំណួរបន្ថែម ឬត្រូវការជំនួយបន្ថែម!
</Callout>

rtSurvey គាំទ្រអនុគមន៍ផ្សេងៗ រួមមាន៖

1. `string(field)`៖ បំប្លែងវាល (field) ទៅជាខ្សែអក្សរ។
   - ឧទាហរណ៍៖ `string(34.8)` នឹងត្រូវបានបំប្លែងទៅជា `'34.8'`។

2. `string-length(field)`៖ បញ្ជូនមកវិញនូវប្រវែងនៃវាលខ្សែអក្សរ។
   - ឧទាហរណ៍៖ `string-length(.) > 3 and string-length(.) < 10` អាចត្រូវបានប្រើដើម្បីធានាថាវាលបច្ចុប្បន្នមានចន្លោះពី 3 ទៅ 10 តួអក្សរ។
   - **Cascade dependency pattern**៖ `string-length(${province}) >= 0` តែងតែមានតម្លៃ `true` ប៉ុន្តែបង្ខំឱ្យ rtSurvey វាយតម្លៃកន្សោមឡើងវិញរាល់ពេលដែល `${province}` ផ្លាស់ប្តូរ។ ប្រើវាឡើយក្នុង `relevant` ដើម្បីជំរុញការធ្វើឱ្យស្រស់ជាបន្តបន្ទាប់ (cascade refresh) នៅពេលដែលវាលមេ (parent field) ធ្វើបច្ចុប្បន្នភាព៖
     | type | name | relevant |
     |------|------|----------|
     | select_one | district | `string-length(${province}) >= 0` |
     នេះធានាថាសំណួរស្រុក (district) វាយតម្លៃឡើងវិញនូវលក្ខណៈបង្ហាញ (appearance) `search()` ឬ `rawquery` របស់វា រាល់ពេលដែលខេត្ត (province) ផ្លាស់ប្តូរ។

3. `substr(fieldorstring, startindex, endindex)`៖ បញ្ជូនមកវិញនូវខ្សែអក្សររង (substring) ចាប់ផ្តើមត្រង់ `startindex` និងបញ្ចប់មុន `endindex` បន្តិច។ សន្ទស្សន៍ (Indexes) ចាប់ផ្តើមពី 0 សម្រាប់តួអក្សរដំបូងក្នុងខ្សែអក្សរ។
   - ឧទាហរណ៍៖ `substr(${phone}, 0, 3)` នឹងបញ្ជូនមកវិញនូវលេខបីខ្ទង់ដំបូងនៃលេខទូរស័ព្ទ។

4. `concat(a, b, c, ...)`៖ ភ្ជាប់វាល (និង/ឬខ្សែអក្សរ) ចូលគ្នា។
   - ឧទាហរណ៍៖ `concat(${firstname}, ' ', ${lastname})` នឹងបញ្ជូនមកវិញនូវឈ្មោះពេញដោយបញ្ចូលតម្លៃក្នុងវាល `firstname` និង `lastname` បញ្ចូលគ្នា។

5. `linebreak()`៖ បញ្ជូនមកវិញនូវតួអក្សរចុះបន្ទាត់។
   - ឧទាហរណ៍៖ `concat(${field1}, linebreak(), ${field2}, linebreak(), ${field3})` នឹងបញ្ជូនមកវិញនូវបញ្ជីតម្លៃវាលបីដែលមានការចុះបន្ទាត់នៅចន្លោះពួកវា។

6. `lower()`៖ បំប្លែងខ្សែអក្សរទៅជាតួអក្សរតូចទាំងអស់។
   - ឧទាហរណ៍៖ `lower('Street Name')` នឹងបញ្ជូនមកវិញនូវ "street name"។

7. `upper()`៖ បំប្លែងខ្សែអក្សរទៅជាតួអក្សរធំទាំងអស់។
   - ឧទាហរណ៍៖ `upper('Street Name')` នឹងបញ្ជូនមកវិញនូវ "STREET NAME"។

### អនុគមន៍ select_one និង select_multiple

1. `count-selected(field)`៖ បញ្ជូនមកវិញនូវចំនួនធាតុដែលបានជ្រើសរើសនៅក្នុងវាល select_multiple។
   - ឧទាហរណ៍៖ `count-selected(.) = 3` អាចត្រូវបានប្រើជាកន្សោមលក្ខខណ្ឌបង្ខំ (constraint expression) ដើម្បីធានាថាជម្រើសចំបង្អស់ចំនួនបីត្រូវបានជ្រើសរើស។

2. `selected(field, value)`៖ បញ្ជូនមកវិញនូវ true ឬ false អាស្រ័យលើថាតើតម្លៃដែលបានបញ្ជាក់ត្រូវបានជ្រើសរើសនៅក្នុងវាល select_one ឬ select_multiple ឬអត់។
   - ឧទាហរណ៍៖ `selected(${color}, 'Blue')` អាចត្រូវបានប្រើជាកន្សោមទាក់ទង (relevance expression) ដើម្បីបង្ហាញក្រុម ឬវាល លុះត្រាតែអ្នកឆ្លើយសំណួរបានជ្រើសរើស "Blue" ជាពណ៌ដែលពួកគេចូលចិត្ត។
   - ចំណាំ៖ ប៉ារ៉ាម៉ែត្រទីពីរគួរតែបញ្ជាក់ពីតម្លៃជម្រើស (choice value) ជានិច្ច មិនមែនស្លាកជម្រើស (choice label) ទេ។ ប្រើតម្លៃពីជួរឈរ value នៅក្នុងសន្លឹកកិច្ចការ choices នៃនិយមន័យទម្រង់។

3. `selected-at(field, number)`៖ បញ្ជូនមកវិញនូវធាតុដែលបានជ្រើសរើសនៅទីតាំងដែលបានបញ្ជាក់នៅក្នុងវាល select_multiple។ នៅពេលលេខដែលបានបញ្ជូនគឺ 0 វានឹងបញ្ជូនមកវិញនូវធាតុដែលបានជ្រើសរើសដំបូងគេ។ នៅពេលលេខគឺ 1 វានឹងបញ្ជូនមកវិញនូវធាតុដែលបានជ្រើសរើសទីពីរ និងបន្តបន្ទាប់ទៀត។
   - ឧទាហរណ៍៖ `selected-at(${fruits}, 0) = 'Apple'` អាចត្រូវបានប្រើជាកន្សោមទាក់ទង ដើម្បីបង្ហាញក្រុម ឬវាល លុះត្រាតែជម្រើសដែលបានជ្រើសរើសដំបូងគេគឺ "Apple"។
   - ចំណាំ៖ តម្លៃដែលបញ្ជូនមកវិញនឹងជាតម្លៃជម្រើស មិនមែនស្លាកជម្រើសទេ។ ប្រើតម្លៃពីជួរឈរ value នៅក្នុងសន្លឹកកិច្ចការ choices នៃនិយមន័យទម្រង់។

4. `choice-label(field, value)`៖ បញ្ជូនមកវិញនូវស្លាក (label) សម្រាប់ជម្រើសវាល select_one ឬ select_multiple ដូចដែលបានកំណត់នៅក្នុងសន្លឹកកិច្ចការ choices នៃនិយមន័យទម្រង់។
   - ឧទាហរណ៍ ១៖ `choice-label(${country}, ${country})` នឹងបញ្ជូនមកវិញនូវស្លាកជម្រើសសម្រាប់ជម្រើសដែលបានជ្រើសរើសបច្ចុប្បន្ននៅក្នុងវាលដែលមានឈ្មោះថា `country`។
   - ឧទាហរណ៍ ២៖ `choice-label(${languages}, selected-at(${languages}, 0))` នឹងបញ្ជូនមកវិញនូវស្លាកសម្រាប់ជម្រើសដែលបានជ្រើសរើសដំបូងគេនៅក្នុងវាលដែលមានឈ្មោះថា `languages`។
   - ចំណាំ៖ អនុគមន៍នេះទាញយកស្លាកជម្រើស មិនមែនតម្លៃទេ។ វាប្រើជួរឈរ label ពីសន្លឹកកិច្ចការ choices នៃនិយមន័យទម្រង់។

### អនុគមន៍វាលដែលកើតឡើងដដែលៗ (Repeated field functions)

នៅក្នុង rtSurvey ប្រសិនបើអ្នកចង់សួរសំណួរដដែលៗច្រើនដង អ្នកអាចដាក់វាលនៅក្នុងក្រុមដដែលៗ (repeat group)។ នេះបណ្តាលឱ្យមានវាលដដែលៗច្រើនដងកើតឡើង។ អនុគមន៍ខាងក្រោមអាចជួយអ្នកក្នុងការដោះស្រាយវាលដែលកើតឡើងដដែលៗទាំងនេះ និងទិន្នន័យដដែលៗដែលពួកវាបង្កើត។ សូមមើលប្រធានបទជំនួយស្តីពីវាលដែលកើតឡើងដដែលៗសម្រាប់ព័ត៌មានលម្អិតបន្ថែម។

1. `join(string, repeatedfield)`៖ សម្រាប់វាលនៅក្នុងក្រុមដដែលៗ បង្កើតបញ្ជីតម្លៃដែលបំបែកដោយខ្សែអក្សរ។ ប៉ារ៉ាម៉ែត្រដំបូងបញ្ជាក់ពីសញ្ញាបំបែក (delimiter) ដែលត្រូវប្រើដើម្បីបំបែកតម្លៃទាំងនោះ។
   - ឧទាហរណ៍៖ `join(', ', ${member_name})` នឹងបង្កើតបញ្ជីតែមួយដែលបំបែកដោយសញ្ញាក្បៀសពីឈ្មោះដែលបានបញ្ចូលទាំងអស់។

2. `join-if(string, repeatedfield, expression)`៖ ដំណើរការដូចអនុគមន៍ `join()` ដែរ លើកលែងតែវាពិនិត្យមើលរាល់ករណីនីមួយៗនៅក្នុងក្រុមដដែលៗដោយប្រើកន្សោមដែលបានផ្តល់ឱ្យ។ ប្រសិនបើកន្សោមមានតម្លៃ false ធាតុនោះនឹងត្រូវបានលុបចេញពីលទ្ធផល។
   - ឧទាហរណ៍៖ `join-if(', ', ${member_name}, ${age} >= 18)` នឹងបង្កើតបញ្ជីឈ្មោះដែលបំបែកដោយសញ្ញាក្បៀសសម្រាប់តែសមាជិកដែលពេញវ័យ (អ្នកដែលមានអាយុចាប់ពី 18 ឆ្នាំឡើងទៅ)។

3. `count(repeatgroup)`៖ បញ្ជូនមកវិញនូវចំនួនដងបច្ចុប្បន្នដែលក្រុមដដែលៗបានធ្វើឡើង។
   - ឧទាហរណ៍៖ `count(${groupname})` នឹងបញ្ជូនមកវិញនូវចំនួននៃក្រុមនោះ។

4. `count-if(repeatgroup, expression)`៖ ដំណើរការដូចអនុគមន៍ `count()` ដែរ លើកលែងតែវាពិនិត្យមើលរាល់ករណីនីមួយៗនៅក្នុងក្រុមដដែលៗដោយប្រើកន្សោមដែលបានផ្តល់ឱ្យ។ ប្រសិនបើកន្សោមមានតម្លៃ false ធាតុនោះនឹងត្រូវបានលុបចេញពីការរាប់។
   - ឧទាហរណ៍៖ `count-if(${members}, ${age} >= 18)` នឹងបញ្ជូនមកវិញនូវចំនួនសមាជិកពេញវ័យដោយផ្អែកលើវាល age នៅក្នុងក្រុមដដែលៗ "members"។

5. `sum(repeatedfield)`៖ សម្រាប់វាលនៅក្នុងក្រុមដដែលៗ គណនាផលបូកនៃតម្លៃទាំងអស់។
   - ឧទាហរណ៍៖ `sum(${loan_amount})` នឹងបញ្ជូនមកវិញនូវតម្លៃសរុបនៃប្រាក់កម្ចីទាំងអស់។

6. `sum-if(repeatedfield, expression)`៖ ដំណើរការដូចអនុគមន៍ `sum()` ដែរ លើកលែងតែវាពិនិត្យមើលរាល់ករណីនីមួយៗនៅក្នុងក្រុមដដែលៗដោយប្រើកន្សោមដែលបានផ្តល់ឱ្យ។ ប្រសិនបើកន្សោមមានតម្លៃ false ធាតុនោះនឹងត្រូវបានលុបចេញពីលទ្ធផល។
   - ឧទាហរណ៍៖ `sum-if(${loan_amount}, ${loan_amount} > 500)` នឹងបញ្ជូនមកវិញនូវតម្លៃសរុបនៃប្រាក់កម្ចីទាំងអស់ដែលមានចំនួនលើសពី 500។ ប្រាក់កម្ចីតូចៗនឹងត្រូវបានរំលង។

7. `min(repeatedfield)`៖ សម្រាប់វាលនៅក្នុងក្រុមដដែលៗ គណនាតម្លៃអប្បបរមានៃតម្លៃទាំងអស់។
   - ឧទាហរណ៍៖ `min(${member_age})` នឹងបញ្ជូនមកវិញនូវអាយុរបស់សមាជិកដែលក្មេងជាងគេក្នុងក្រុម។

8. `min-if(repeatedfield, expression)`៖ ដំណើរការដូចអនុគមន៍ `min()` ដែរ លើកលែងតែវាពិនិត្យមើលរាល់ករណីនីមួយៗនៅក្នុងក្រុមដដែលៗដោយប្រើកន្សោមដែលបានផ្តល់ឱ្យ។ ប្រសិនបើកន្សោមមានតម្លៃ false ធាតុនោះនឹងត្រូវបានលុបចេញពីការគណនាអប្បបរមា។
   - ឧទាហរណ៍៖ `min-if(${member_age}, ${member_age} >= 18)` នឹងបញ្ជូនមកវិញនូវអាយុរបស់មនុស្សពេញវ័យដែលក្មេងជាងគេក្នុងក្រុម។ អ្នកដែលមានអាយុតិចជាង 18 ឆ្នាំនឹងត្រូវបានរំលង។

9. `max(repeatedfield)`៖ សម្រាប់វាលនៅក្នុងក្រុមដដែលៗ គណនាតម្លៃអតិបរមានៃតម្លៃទាំងអស់។
   - ឧទាហរណ៍៖ `max(${member_age})` នឹងបញ្ជូនមកវិញនូវអាយុរបស់សមាជិកដែលចាស់ជាងគេក្នុងក្រុម។

10. `max-if(repeatedfield, expression)`៖ ដំណើរការដូចអនុគមន៍ `max()` ដែរ លើកលែងតែវាពិនិត្យមើលរាល់ករណីនីមួយៗនៅក្នុងក្រុមដដែលៗដោយប្រើកន្សោមដែលបានផ្តល់ឱ្យ។ ប្រសិនបើកន្សោមមានតម្លៃ false ធាតុនោះនឹងត្រូវបានលុបចេញពីការគណនាអតិបរមា។
    - ឧទាហរណ៍៖ `max-if(${member_age}, ${member_age} >= 18)` នឹងបញ្ជូនមកវិញនូវអាយុរបស់មនុស្សពេញវ័យដែលចាស់ជាងគេក្នុងក្រុម។ អ្នកដែលមានអាយុតិចជាង 18 ឆ្នាំនឹងត្រូវបានរំលង។

11. `index()`៖ ត្រូវបានហៅនៅក្នុងក្រុមដដែលៗ បញ្ជូនមកវិញនូវលេខសន្ទស្សន៍សម្រាប់ក្រុម ឬករណីបច្ចុប្បន្ន។
    - ឧទាហរណ៍៖ `index()` នៅពេលប្រើក្នុងក្រុមដដែលៗនឹងបញ្ជូនមកវិញនូវ 1 សម្រាប់ករណីដំបូង 2 សម្រាប់ករណីទីពីរ និងបន្តបន្ទាប់ទៀត។

12. `indexed-repeat(repeatedfield, repeatgroup, index)`៖ យោងទៅវាល ឬក្រុមដែលស្ថិតនៅក្នុងក្រុមដដែលៗ ពីខាងក្រៅក្រុមដដែលៗនោះ។ ប៉ារ៉ាម៉ែត្រដំបូងបញ្ជាក់ពីវាល ឬក្រុមដដែលៗដែលចង់បាន ទីពីរបញ្ជាក់ពីក្រុមដដែលៗដែលវាល ឬក្រុមនោះស្ថិតនៅ និងទីបីបញ្ជាក់ពីលេខករណីនៅក្នុងក្រុមដដែលៗដែលត្រូវប្រើ។
    - ឧទាហរណ៍ ១៖ `indexed-repeat(${name}, ${names}, 1)` នឹងបញ្ជូនមកវិញនូវឈ្មោះដំបូងដែលមាន នៅពេលដែលវាល name ស្ថិតនៅក្នុងក្រុមដដែលៗមុនដែលមានឈ្មោះថា "names"។
    - ឧទាហរណ៍ ២៖ `indexed-repeat(${name}, ${names}, index())` នឹងទាញយកឈ្មោះដែលត្រូវនឹងលេខករណីនៃក្រុមដដែលៗបច្ចុប្បន្ន។

13. `rank-index(index, repeatedfield)`៖ អនុគមន៍នេះគណនាចំណាត់ថ្នាក់តាមលំដាប់ (ordinal rank) នៃករណីដែលបានបញ្ជាក់នៃវាលដែលកើតឡើងដដែលៗ សម្រាប់ប្រើនៅខាងក្រៅក្រុមដដែលៗ។ ចំណាត់ថ្នាក់ទី 1 ត្រូវបានផ្តល់ឱ្យករណីដែលមានតម្លៃខ្ពស់បំផុត ចំណាត់ថ្នាក់ទី 2 សម្រាប់ករណីដែលមានតម្លៃខ្ពស់បន្ទាប់ និងបន្តបន្ទាប់ទៀត។ ប្រសិនបើអ្នកបញ្ជូនសន្ទស្សន៍ដែលមិនត្រឹមត្រូវ ឬសន្ទស្សន៍ទៅករណីដែលមានតម្លៃមិនមែនជាលេខ នោះចំណាត់ថ្នាក់ 999 នឹងត្រូវបានបញ្ជូនមកវិញ។
    - ឧទាហរណ៍៖ `rank-index(1, ${random_draw})` គណនាចំណាត់ថ្នាក់នៃករណីទីមួយដោយផ្អែកលើតម្លៃនៃវាល `random_draw` របស់វា បើធៀបនឹងតម្លៃនៃករណីផ្សេងទៀត។

14. `rank-index-if(index, repeatedfield, expression)`៖ អនុគមន៍នេះដំណើរការស្រដៀងទៅនឹង `rank-index()` ដែរ ប៉ុន្តែវាពិនិត្យមើលរាល់ករណីនីមួយៗនៅក្នុងក្រុមដដែលៗនៃវាលដែលកើតឡើងដដែលៗដោយប្រើកន្សោមដែលបានផ្តល់ឱ្យ។ ប្រសិនបើកន្សោមមានតម្លៃ false ធាតុនោះនឹងត្រូវបានលុបចេញពីការគណនា។ សន្ទស្សន៍ដែលប្រើគឺផ្អែកលើសំណុំពេញលេញនៃករណី មុនពេលវាយតម្លៃកន្សោមសម្រាប់ករណីនីមួយៗ។ ប្រសិនបើអ្នកបញ្ជូនសន្ទស្សន៍សម្រាប់ករណីដែលត្រូវបានរំលងដោយសារតែមិនបំពេញតាមកន្សោម វានឹងត្រូវបានចាត់ទុកថាជាសន្ទស្សន៍មិនត្រឹមត្រូវ ហើយចំណាត់ថ្នាក់ 999 នឹងត្រូវបានបញ្ជូនមកវិញ។
    - ឧទាហរណ៍៖ `rank-index-if(1, ${age}, ${age} >= 18)` គណនាចំណាត់ថ្នាក់អាយុក្នុងចំណោមមនុស្សពេញវ័យ ដោយពិចារណាតែករណីដែលអាយុធំជាង ឬស្មើនឹង 18 ប៉ុណ្ណោះ។

### អនុគមន៍លេខ (Number functions)

| ប្រតិបត្តិករ | ប្រតិបត្តិការ | ឧទាហរណ៍ | ចម្លើយឧទាហរណ៍ |
|----------|-----------|---------|----------------|
| `+` | បូក | 1 + 1 | 2 |
| `-` | ដក | 3 - 2 | 1 |
| `*` | គុណ | 3 * 2 | 6 |
| `div` | ចែក | 10 div 2 | 5 |
| `mod` | សំណល់នៃការចែក | 9 mod 2 | 1 |

rtSurvey គាំទ្រអនុគមន៍លេខ រួមមាន៖
- `number(field)`៖ បំប្លែងតម្លៃនៃវាលទៅជាលេខ។
  - ឧទាហរណ៍៖ `number('34.8')` = 34.8

- `int(field)`៖ បំប្លែងតម្លៃនៃវាលទៅជាចំនួនគត់ (integer)។
  - ឧទាហរណ៍៖ `int('39.2')` = 39

- `min(field1, ..., fieldx)`៖ បញ្ជូនមកវិញនូវតម្លៃអប្បបរមាក្នុងចំណោមវាលដែលបានបញ្ជូន។
  - ឧទាហរណ៍៖ `min(${father_age}, ${mother_age})` នឹងបញ្ជូនមកវិញនូវអាយុរបស់ម្តាយ ឬឪពុក អាស្រ័យលើម្នាក់ណាដែលតូចជាង។

- `max(field1, ..., fieldx)`៖ បញ្ជូនមកវិញនូវតម្លៃអតិបរមាក្នុងចំណោមវាលដែលបានបញ្ជូន។
  - ឧទាហរណ៍៖ `max(${father_age}, ${mother_age})` នឹងបញ្ជូនមកវិញនូវអាយុរបស់ម្តាយ ឬឪពុក អាស្រ័យលើម្នាក់ណាដែលធំជាង។

- `format-number(field)`៖ រៀបចំទម្រង់តម្លៃនៃវាលចំនួនគត់ ឬទសភាគតាមការកំណត់តំបន់ (locale settings) របស់អ្នកប្រើប្រាស់។
  - ឧទាហរណ៍៖ `format-number(${income})` កន្សោមនេះអាចនឹងរៀបចំទម្រង់ "120000" ជា "120,000"។

- `round(field, digits)`៖ បង្គត់តម្លៃវាលលេខទៅតាមចំនួនខ្ទង់ដែលបានបញ្ជាក់បន្ទាប់ពីក្បៀស។
  - ឧទាហរណ៍៖ `round(${interest_rate}, 2)`

- `abs(number)`៖ បញ្ជូនមកវិញនូវតម្លៃដាច់ខាត (absolute value) នៃលេខមួយ។
  
- `pow(base, exponent)`៖ បញ្ជូនមកវិញនូវតម្លៃនៃប៉ារ៉ាម៉ែត្រទីមួយស្វ័យគុណនឹងប៉ារ៉ាម៉ែត្រទីពីរ។
  - ប៉ារ៉ាម៉ែត្រនីមួយៗអាចជាវាល លេខ ឬកន្សោម។

- `log10(fieldorvalue)`៖ បញ្ជូនមកវិញនូវលោការីតគោលដប់ (base-ten logarithm) នៃវាល ឬតម្លៃដែលបានបញ្ជូន។

- `sin(fieldorvalue)`៖ បញ្ជូនមកវិញនូវស៊ីនុស (sine) នៃវាល ឬតម្លៃដែលបានបញ្ជូន គិតជា រ៉ាដ្យង់ (radians)។
  
- `cos(fieldorvalue)`៖ បញ្ជូនមកវិញនូវកូស៊ីនុស (cosine) នៃវាល ឬតម្លៃដែលបានបញ្ជូន គិតជា រ៉ាដ្យង់។

- `tan(fieldorvalue)`៖ បញ្ជូនមកវិញនូវតង់ហ្សង់ (tangent) នៃវាល ឬតម្លៃដែលបានបញ្ជូន គិតជា រ៉ាដ្យង់។

- `asin(fieldorvalue)`៖ បញ្ជូនមកវិញនូវអាកស៊ីនុស (arcsine) នៃវាល ឬតម្លៃដែលបានបញ្ជូន គិតជា រ៉ាដ្យង់។

- `acos(fieldorvalue)`៖ បញ្ជូនមកវិញនូវអាកកូស៊ីនុស (arccosine) នៃវាល ឬតម្លៃដែលបានបញ្ជូន គិតជា រ៉ាដ្យង់។

- `atan(fieldorvalue)`៖ បញ្ជូនមកវិញនូវអាកតង់ហ្សង់ (arctangent) នៃវាល ឬតម្លៃដែលបានបញ្ជូន គិតជា រ៉ាដ្យង់។

- `atan2(x, y)`៖ បញ្ជូនមកវិញនូវមុំគិតជារ៉ាដ្យង់ដែលកើតឡើងនៅគល់អ័ក្សដោយចំណុចដែលមានកូអរដោនេ (x, y) និងអ័ក្ស x វិជ្ជមាន។ លទ្ធផលគឺស្ថិតក្នុងចន្លោះ -pi() ទៅ pi()។

- `sqrt(fieldorvalue)`៖ បញ្ជូនមកវិញនូវឫសការ៉េមិនអវិជ្ជមាននៃវាល ឬតម្លៃដែលបានបញ្ជូន។

- `exp(x)`៖ បញ្ជូនមកវិញនូវតម្លៃនៃ e^x។

- `pi()`៖ បញ្ជូនមកវិញនូវតម្លៃនៃ pi។

### អនុគមន៍កាលបរិច្ឆេទ និងពេលវេលា

<Callout type="warning">
តម្លៃកាលបរិច្ឆេទនៅក្នុង rtSurvey ត្រូវបានរក្សាទុកជាខ្សែអក្សរក្នុងទម្រង់ `YYYY-MM-DD`។ តម្លៃពេលវេលា (Datetime) ត្រូវបានរក្សាទុកជាខ្សែអក្សរ ISO 8601 (`YYYY-MM-DDTHH:MM:SS`)។ ប្រើ `decimal-date-time()` ដើម្បីបំប្លែងទៅជាលេខសម្រាប់ការគណនាលេខនព្វន្ត (ឧទាហរណ៍ ការគណនារយៈពេល)។
</Callout>

1. `today()`៖ បញ្ជូនមកវិញនូវកាលបរិច្ឆេទថ្ងៃនេះជាខ្សែអក្សរក្នុងទម្រង់ `YYYY-MM-DD`។ វាយតម្លៃម្តងនៅពេលបើកទម្រង់។
   - ឧទាហរណ៍៖ `today()` → `'2024-03-15'`
   - ការប្រើប្រាស់ទូទៅ៖ ជួរឈរ `default` ដើម្បីបំពេញកាលបរិច្ឆេទថ្ងៃនេះជាមុន ឬនៅក្នុង `relevant`/`constraint` ដើម្បីប្រៀបធៀបជាមួយវាលកាលបរិច្ឆេទ។

2. `now()`៖ បញ្ជូនមកវិញនូវកាលបរិច្ឆេទ និងពេលវេលាបច្ចុប្បន្នជាខ្សែអក្សរ ISO 8601។ វាយតម្លៃរាល់ពេលដែលកន្សោមត្រូវបានគណនា។
   - ឧទាហរណ៍៖ `now()` → `'2024-03-15T14:32:00.000+03:00'`
   - ការប្រើប្រាស់ទូទៅ៖ ការកត់ត្រាត្រាពេលវេលា (timestamp) ច្បាស់លាស់នៃព្រឹត្តិការណ៍ជាក់លាក់ណាមួយអំឡុងពេលអង្កេត។

3. `date(value)`៖ បំប្លែងតម្លៃ (ខ្សែអក្សរ ឬលេខ) ទៅជាខ្សែអក្សរកាលបរិច្ឆេទ។ មានសារៈសំខាន់សម្រាប់ការបង្ខំតម្លៃដែលបានគណនាឱ្យទៅជាប្រភេទកាលបរិច្ឆេទ។
   - ឧទាហរណ៍៖ `date('2024-03-15')` → `'2024-03-15'`

4. `date-time(value)`៖ បំប្លែងតម្លៃទៅជាខ្សែអក្សរពេលវេលា (datetime string)។
   - ឧទាហរណ៍៖ `date-time(${event_timestamp})`

5. `decimal-date-time(value)`៖ បំប្លែងខ្សែអក្សរកាលបរិច្ឆេទ ឬពេលវេលាទៅជាលេខទសភាគដែលតំណាងឱ្យមីលីវិនាទីចាប់តាំងពី Unix epoch ចែកនឹង 86400000 (ពោលគឺ ចំនួនថ្ងៃជាប្រភាគចាប់តាំងពី 1970-01-01)។ ប្រើវាដើម្បីអនុវត្តលេខនព្វន្តលើកាលបរិច្ឆេទ។
   - ឧទាហរណ៍៖ រយៈពេលជាថ្ងៃរវាងកាលបរិច្ឆេទពីរ៖
     `decimal-date-time(${end_date}) - decimal-date-time(${start_date})`
   - ឧទាហរណ៍៖ រយៈពេលជាទីនាទីរវាងពេលវេលាពីរ៖
     `(decimal-date-time(${end_time}) - decimal-date-time(${start_time})) * 1440`

6. `format-date(date, format)`៖ រៀបចំទម្រង់តម្លៃកាលបរិច្ឆេទដោយប្រើខ្សែអក្សរគំរូ (pattern string)។
   - ថូខឹនទម្រង់ (Format tokens)៖ `%Y` (ឆ្នាំ ៤ ខ្ទង់), `%y` (ឆ្នាំ ២ ខ្ទង់), `%m` (ខែ 01–12), `%d` (ថ្ងៃ 01–31), `%a` (ឈ្មោះថ្ងៃសង្ខេប), `%b` (ឈ្មោះខែសង្ខេប)
   - ឧទាហរណ៍៖ `format-date(today(), '%d/%m/%Y')` → `'15/03/2024'`
   - ឧទាហរណ៍៖ `format-date(${dob}, '%B %d, %Y')` → `'March 15, 1990'`

7. `format-date-time(datetime, format)`៖ រៀបចំទម្រង់តម្លៃពេលវេលាដោយប្រើខ្សែអក្សរគំរូ។ គាំទ្ររាល់ថូខឹនរបស់ `format-date` រួមជាមួយ៖
   - `%H` (ម៉ោង 00–23), `%h` (ម៉ោង 01–12), `%M` (នាទី 00–59), `%S` (វិនាទី 00–59), `%3` (មីលីវិនាទី), `%P` (AM/PM)
   - ឧទាហរណ៍៖ `format-date-time(now(), '%d/%m/%Y %H:%M')` → `'15/03/2024 14:32'`
   - ឧទាហរណ៍៖ `format-date-time(${event_time}, '%I:%M %p')` → `'02:32 PM'`

8. `STRFTIME(format, datetime)`៖ ការរៀបចំទម្រង់កាលបរិច្ឆេទបែប SQLite។ អាចប្រើបាននៅក្នុងខ្សែអក្សរ SQL ដែលបញ្ជូនទៅកម្រងសំណួរ `rawquery` — **មិនអាច** ប្រើបាននៅក្នុងជួរឈរ `calculation` ឬ `label` របស់ XLSForm ឡើយ។ ប្រើថូខឹនទម្រង់របស់ SQLite (`%Y`, `%m`, `%d`, `%H`, `%M`, `%S`)។
   - ឧទាហរណ៍នៅក្នុងខ្សែអក្សរ SQL របស់ rawquery៖ `'SELECT STRFTIME(''%Y-%m'', interview_date) AS month FROM data WHERE id = ?'`
   - ចំណាំ៖ ប្រើ `format-date-time()` សម្រាប់ការរៀបចំទម្រង់កាលបរិច្ឆេទនៅក្នុងកន្សោម XLSForm។ `STRFTIME()` គឺជាអនុគមន៍ SQLite ដែលមានសម្រាប់តែនៅក្នុង SQL ដែលបញ្ជូនទៅ `rawquery` ប៉ុណ្ណោះ។

### អនុគមន៍ប៊ូលីន (Boolean functions)

1. `boolean(value)`៖ បំប្លែងតម្លៃណាមួយទៅជាប៊ូលីន។ បញ្ជូនមកវិញនូវ `true` សម្រាប់ខ្សែអក្សរដែលមិនទទេ លេខដែលមិនមែនសូន្យ និង `true`។ បញ្ជូនមកវិញនូវ `false` សម្រាប់ខ្សែអក្សរទទេ `0` និង `false`។
   - ឧទាហរណ៍៖ `boolean(${name})` បញ្ជូនមកវិញនូវ `true` ប្រសិនបើ `name` មិនទទេ។

2. `boolean-from-string(string)`៖ បញ្ជូនមកវិញនូវ `true` ប្រសិនបើខ្សែអក្សរគឺជា `'1'` ឬ `'true'` (មិនប្រកាន់អក្សរតូចធំ)។ បញ្ជូនមកវិញនូវ `false` ក្នុងករណីផ្សេងពីនេះ។
   - ឧទាហរណ៍៖ `boolean-from-string(${enabled_flag})` — មានប្រយោជន៍នៅពេលវាលរក្សាទុក `'true'`/`'false'` ជាអត្ថបទ។

3. `true()`៖ បញ្ជូនមកវិញនូវតម្លៃប៊ូលីន `true`។
   - ឧទាហរណ៍៖ នៅក្នុងជួរឈរ `required` អនុគមន៍ `true()` គឺស្មើនឹង `yes`។

4. `false()`៖ បញ្ជូនមកវិញនូវតម្លៃប៊ូលីន `false`។
   - ឧទាហរណ៍៖ `if(${skip_section} = 'yes', false(), true())` — កំណត់ភាពចាំបាច់ (required) ដោយថាមវន្ត។

5. `not(expression)`៖ បញ្ជូនមកវិញនូវបដិសេធន៍តក្កវិជ្ជានៃកន្សោម។ បញ្ជូនមកវិញនូវ `true` ប្រសិនបើកន្សោមមានតម្លៃ false និងផ្ទុយមកវិញ។
   - ឧទាហរណ៍៖ `not(${consent} = 'yes')` — បង្ហាញការព្រមាននៅពេលដែលការយល់ព្រមមិនត្រូវបានផ្តល់ឱ្យ។
   - ឧទាហរណ៍៖ `not(selected(${issues}, 'none'))` — តម្រូវឱ្យមានព័ត៌មានលម្អិតលុះត្រាតែ "none" មិនត្រូវបានជ្រើសរើស។

---

### អនុគមន៍ខ្សែអក្សរបន្ថែម

1. `starts-with(string, prefix)`៖ បញ្ជូនមកវិញនូវ `true` ប្រសិនបើ `string` ចាប់ផ្តើមដោយ `prefix`។
   - ឧទាហរណ៍៖ `starts-with(${phone}, '+254')` ពិនិត្យមើលថាតើលេខទូរស័ព្ទចាប់ផ្តើមដោយលេខកូដប្រទេសកេនយ៉ាដែរឬទេ។

2. `contains(string, substring)`៖ បញ្ជូនមកវិញនូវ `true` ប្រសិនបើ `string` មាន `substring`។
   - ឧទាហរណ៍៖ `contains(${email}, '@')` ពិនិត្យមើលថាអាសយដ្ឋានអ៊ីមែលមានសញ្ញា `@`។
   - ឧទាហរណ៍៖ `contains(${notes}, 'urgent')` ជំរុញឱ្យមានសំណួរបន្ត ប្រសិនបើចំណាំមានបញ្ជាក់ថា "urgent" (បន្ទាន់)។

3. `substring-before(string, needle)`៖ បញ្ជូនមកវិញនូវផ្នែកនៃ `string` ដែលបង្ហាញមុនការកើតឡើងដំបូងនៃ `needle`។
   - ឧទាហរណ៍៖ `substring-before(${full_name}, ' ')` ទាញយកពាក្យដំបូង (នាមខ្លួន)។

4. `substring-after(string, needle)`៖ បញ្ជូនមកវិញនូវផ្នែកនៃ `string` ដែលបង្ហាញបន្ទាប់ពីការកើតឡើងដំបូងនៃ `needle`។
   - ឧទាហរណ៍៖ `substring-after(${email}, '@')` ទាញយកផ្នែកដែន (domain) នៃអាសយដ្ឋានអ៊ីមែល។

5. `normalize-space(string)`៖ លុបចន្លោះទទេនៅខាងដើម និងខាងចុង ហើយបង្រួមចន្លោះទទេខាងក្នុងទាំងអស់ឱ្យមកនៅត្រឹមចន្លោះទតែមួយ។
   - ឧទាហរណ៍៖ `normalize-space(${name})` — សម្អាតឈ្មោះដែលអាចត្រូវបានវាយបញ្ចូលដោយមានចន្លោះទទេលើស។

6. `translate(string, search_chars, replace_chars)`៖ ជំនួសរាល់តួអក្សរនៅក្នុង `string` ដែលបង្ហាញក្នុង `search_chars` ជាមួយនឹងតួអក្សរដែលត្រូវគ្នានៅក្នុង `replace_chars`។ តួអក្សរនៅក្នុង `search_chars` ដែលគ្មានតួអក្សរត្រូវគ្នានៅក្នុង `replace_chars` នឹងត្រូវបានលុបចេញ។
   - ឧទាហរណ៍៖ `translate(${code}, 'abcdefghijklmnopqrstuvwxyz', 'ABCDEFGHIJKLMNOPQRSTUVWXYZ')` បំប្លែងទៅជាអក្សរធំ (ស្មើនឹង `upper()`)។
   - ឧទាហរណ៍៖ `translate(${phone}, ' -()', '')` លុបចន្លោះទទេ សញ្ញាដាច់ និងវង់ក្រចកចេញពីលេខទូរស័ព្ទ។

---

### អនុគមន៍គណិតវិទ្យាបន្ថែម

1. `floor(number)`៖ បញ្ជូនមកវិញនូវចំនួនគត់ធំបំផុតដែលតូចជាង ឬស្មើនឹង `number` (បង្គត់ទៅរកអវិជ្ជមានអនន្ត)។
   - ឧទាហរណ៍៖ `floor(4.9)` = 4, `floor(-2.1)` = -3

2. `ceiling(number)`៖ បញ្ជូនមកវិញនូវចំនួនគត់តូចបំផុតដែលធំជាង ឬស្មើនឹង `number` (បង្គត់ទៅរកវិជ្ជមានអនន្ត)។
   - ឧទាហរណ៍៖ `ceiling(4.1)` = 5, `ceiling(-2.9)` = -2

3. `random()`៖ បញ្ជូនមកវិញនូវលេខទសភាគចៃដន្យរវាង 0.0 (រាប់បញ្ចូល) និង 1.0 (មិនរាប់បញ្ចូល)។ ជាទូទៅត្រូវបានប្រើក្នុងវាល `calculate` ដើម្បីផ្តល់តម្លៃចៃដន្យ ឬធ្វើឱ្យលំដាប់សំណួរមានលក្ខណៈចៃដន្យ។
   - ឧទាហរណ៍៖ `random()` → ឧទាហរណ៍ `0.7341`
   - ឧទាហរណ៍៖ `int(random() * 6) + 1` → លេខចៃដន្យពី 1–6 (ការបោះគ្រាប់ឡុកឡាក់)

4. `coalesce(a, b)`៖ បញ្ជូនមកវិញនូវ `a` ប្រសិនបើ `a` មិនទទេ បើមិនដូច្នោះទេនឹងបញ្ជូនមកវិញនូវ `b`។ មានប្រយោជន៍ជាជម្រើសបម្រុងនៅពេលវាលណាមួយអាចនឹងទទេ។
   - ឧទាហរណ៍៖ `coalesce(${preferred_name}, ${full_name})` — ប្រើឈ្មោះដែលចូលចិត្តប្រសិនបើមានកំណត់ បើមិនដូច្នោះទេត្រឡប់ទៅប្រើឈ្មោះពេញវិញ។

5. `once(value)`៖ វាយតម្លៃ `value` ហើយរក្សាទុកវា ប៉ុន្តែក្នុងករណីដែលវាលបច្ចុប្បន្ន **ទទេ** ប៉ុណ្ណោះ។ ប្រសិនបើវាលមានតម្លៃរួចហើយ (ឧទាហរណ៍ ត្រូវបានកំណត់ពីមុន) អនុគមន៍ `once()` នឹងបញ្ជូនមកវិញនូវតម្លៃដែលមានស្រាប់ដោយមិនផ្លាស់ប្តូរ។ នេះរារាំងការគណនាឡើងវិញពីការសរសេរជាន់លើការបញ្ចូលរបស់អ្នកប្រើប្រាស់។
   - ឧទាហរណ៍៖ `once(today())` នៅក្នុងជួរឈរ `default` កំណត់កាលបរិច្ឆេទថ្ងៃនេះតែម្តងគត់ ហើយមិនធ្វើបច្ចុប្បន្នភាពទេ ប្រសិនបើអ្នកសម្ភាសន៍បើកទម្រង់ឡើងវិញ។
   - ឧទាហរណ៍៖ `once(uuid())` បង្កើត UUID តែម្តងគត់ និងរក្សាវាឱ្យនៅដដែលទោះបីជាមានការកែសម្រួលឡើងវិញក៏ដោយ។

### អនុគមន៍ភូមិសាស្ត្រ (Geo functions)

1. `area(geoshape_value)`៖ គណនា **ផ្ទៃក្រឡាជាម៉ែត្រការ៉េ** ដែលព័ទ្ធជុំវិញដោយតម្លៃភូមិសាស្ត្រពហុកោណ (geoshape)។
   - ប៉ារ៉ាម៉ែត្រគឺជាតម្លៃវាល geoshape ក្នុងទម្រង់ `lat1 lon1 0 0; lat2 lon2 0 0; ...`
   - ឧទាហរណ៍៖ `area(${field_boundary})` — គណនាផ្ទៃក្រឡានៃដីដែលបានវាស់វែងគិតជា ម៉ែត្រការ៉េ។
   - ឧទាហរណ៍៖ `round(area(${field_boundary}) div 10000, 2)` — បំប្លែងទៅជាហិកតា។

2. `distance(coordinates)`៖ គណនា **ប្រវែងផ្លូវសរុបជាម៉ែត្រ** នៃខ្សែភូមិសាស្ត្រ (geotrace) ឬចម្ងាយរវាងចំណុចភូមិសាស្ត្រ (geopoints) ពីរ។
   - សម្រាប់ geotrace៖ `distance(${route})` បញ្ជូនមកវិញនូវប្រវែងផ្លូវសរុបគិតជាម៉ែត្រ។
   - សម្រាប់ geopoints ពីរ៖ `distance(concat(${point_a}, ' ', ${point_b}))` បញ្ជូនមកវិញនូវចម្ងាយរវាងពួកវា។
   - ឧទាហរណ៍៖ `round(distance(${road_trace}) div 1000, 3)` — ប្រវែងផ្លូវគិតជាគីឡូម៉ែត្រ។

### អនុគមន៍ផ្ទៀងផ្ទាត់ (Validation functions)

1. `regex(value, pattern)`៖ បញ្ជូនមកវិញនូវ `true` ប្រសិនបើ `value` ត្រូវគ្នានឹងកន្សោមនិយត (regular expression) `pattern`។ ប្រើក្នុងជួរឈរ `constraint` សម្រាប់ការផ្ទៀងផ្ទាត់ផ្អែកលើគំរូ (pattern)។
   - គំរូប្រើវាក្យសម្ព័ន្ធ regex ស្តង់ដារ (សំណុំរង POSIX ERE)។
   - ឧទាហរណ៍៖ `regex(., '^[0-9]{10}$')` — ផ្ទៀងផ្ទាត់លេខ 10 ខ្ទង់។
   - ឧទាហរណ៍៖ `regex(., '^[A-Z]{2}[0-9]{6}$')` — ផ្ទៀងផ្ទាត់ទម្រង់លេខលិខិតឆ្លងដែន (អក្សរធំ 2 ខ្ទង់ តាមដោយលេខ 6 ខ្ទង់)។
   - ឧទាហរណ៍៖ `regex(., '^[^@]+@[^@]+\.[^@]{2,}$')` — ការពិនិត្យទម្រង់អ៊ីមែលមូលដ្ឋាន។

2. `checklist(min, max, v1, v2, ...)`៖ វាយតម្លៃបញ្ជីនៃកន្សោមប៊ូលីន ហើយបញ្ជូនមកវិញនូវ `true` ប្រសិនបើចំនួនតម្លៃ `true` ស្ថិតនៅចន្លោះ `min` និង `max` (រាប់បញ្ចូល)។ បញ្ជូន `-1` សម្រាប់ `min` ឬ `max` ដើម្បីរំលងដែនកំណត់នោះ។
   - ឧទាហរណ៍៖ `checklist(2, 3, ${q1} = 'yes', ${q2} = 'yes', ${q3} = 'yes')` — ជាប់ប្រសិនបើលក្ខខណ្ឌចំនួន 2 ឬ 3 ក្នុងចំណោមលក្ខខណ្ឌទាំងបីគឺជាការពិត។
   - ឧទាហរណ៍៖ `checklist(1, -1, ${smoke_alarm}, ${fire_ext}, ${emergency_plan})` — យ៉ាងហោចណាស់វិធានការសុវត្ថិភាពមួយត្រូវតែជាការពិត។

3. `weighted-checklist(min, max, v1, w1, v2, w2, ...)`៖ ដូចអនុគមន៍ `checklist()` ដែរ ប៉ុន្តែតម្លៃនីមួយៗមានទម្ងន់។ ផលបូកនៃទម្ងន់សម្រាប់តម្លៃ `true` ត្រូវតែស្ថិតនៅចន្លោះ `min` និង `max`។
   - ឧទាហរណ៍៖ `weighted-checklist(10, -1, ${has_toilet}, 4, ${has_sink}, 3, ${has_shower}, 5)` — ផលបូកនៃទម្ងន់សម្រាប់សម្ភារៈដែលមានស្រាប់ត្រូវតែយ៉ាងហោចណាស់ 10។

### អនុគមន៍ឧបករណ៍ប្រើប្រាស់ (Utility functions)

1. `uuid()`៖ បង្កើត UUID ចៃដន្យ (ទម្រង់ RFC 4122 v4) ជាខ្សែអក្សរ។
   - ឧទាហរណ៍៖ `uuid()` → `'a3f8b2c1-4d5e-6f7a-8b9c-0d1e2f3a4b5c'`
   - ជាទូទៅត្រូវបានប្រើជាមួយ `once()` ដើម្បីបង្កើតលេខសម្គាល់តែមួយគត់ដែលមានស្ថេរភាព៖ `once(uuid())`

2. `version()`៖ បញ្ជូនមកវិញនូវតម្លៃនៃគុណលក្ខណៈ `version` របស់ទម្រង់ ដូចដែលមានកំណត់ក្នុងសន្លឹកកិច្ចការ settings។
   - ឧទាហរណ៍៖ `version()` → `'3.1'`
   - មានប្រយោជន៍ក្នុងវាល `calculate` ដើម្បីបញ្ចូលកំណែទម្រង់ទៅក្នុងទិន្នន័យដែលបាននាំចេញ។

3. `position()`៖ នៅពេលត្រូវបានហៅនៅក្នុង **ក្រុមដដែលៗ** បញ្ជូនមកវិញនូវសន្ទស្សន៍ដែលចាប់ផ្តើមពី 1 នៃករណីដដែលៗបច្ចុប្បន្ន។
   - ឧទាហរណ៍៖ `position()` ក្នុងករណីដំបូងបញ្ជូនមកវិញនូវ `1` ក្នុងករណីទីពីរបញ្ជូនមកវិញនូវ `2` និងបន្តបន្ទាប់ទៀត។
   - សូមមើលផងដែរ៖ `index()` (ឈ្មោះហៅក្រៅ), `indexed-repeat()` សម្រាប់យោងតម្លៃដដែលៗពីខាងក្រៅក្រុម។

4. `thousandsep(length, separator, value)`៖ រៀបចំទម្រង់លេខដែលមានសញ្ញាបំបែកខ្ទង់ពាន់។ `length` គឺជាប្រវែងខ្សែអក្សរសរុបអប្បបរមា (បំពេញដោយចន្លោះទទេប្រសិនបើខ្លីជាង), `separator` គឺជាតួអក្សរដែលត្រូវប្រើ (ឧទាហរណ៍ `','`), និង `value` គឺជាលេខដែលត្រូវរៀបចំទម្រង់។
   - ឧទាហរណ៍៖ `thousandsep(0, ',', 1234567)` → `'1,234,567'`
   - ឧទាហរណ៍៖ `thousandsep(0, '.', ${income})` — រៀបចំទម្រង់ប្រាក់ចំណូលដោយមានសញ្ញាចុចជាសញ្ញាបំបែកខ្ទង់ពាន់។

5. `substr-jsonpath(value, jsonpath)`៖ ទាញយកតម្លៃពីខ្សែអក្សរ JSON ដោយប្រើកន្សោម JSONPath។
   - `value` ត្រូវតែជាខ្សែអក្សរ JSON (ឧទាហរណ៍ វាលដែលរក្សាទុកការឆ្លើយតប API ឆៅដោយប្រើ `callapi(..., 'json:', ...)` )។
   - `jsonpath` គឺជាកន្សោម JSONPath (ឧទាហរណ៍ `'$.data.name'`, `'$.items[0].id'`)។
   - តែងតែបញ្ជូនមកវិញនូវ **ខ្សែអក្សរ** — ព័ទ្ធជុំវិញដោយ `number()` នៅពេលប្រើក្នុងការគណនាលេខនព្វន្ត។
   - បញ្ជូនមកវិញនូវខ្សែអក្សរទទេ `''` ប្រសិនបើរកមិនឃើញផ្លូវ ឬ `value` មិនមែនជា JSON ត្រឹមត្រូវ។
   - ឧទាហរណ៍៖ `substr-jsonpath(${api_response}, '$.data.name')` — ទាញយកវាល `name`។
   - ឧទាហរណ៍៖ `substr-jsonpath(${api_response}, '$.items[0].label')` — ធាតុដំបូងនៃអារេ (array)។
   - ឧទាហរណ៍៖ `number(substr-jsonpath(${api_response}, '$.price'))` — ទាញយកតម្លៃលេខ។
   - ជាទូទៅត្រូវបានប្រើជាមួយ `callapi(..., 'json:', ...)` ដើម្បីទាញយកវាលច្រើនពីការឆ្លើយតប API តែមួយ។ សូមមើល [ការទាញយកតម្លៃច្រើនពីការហៅ API តែមួយ](../advanced-features/call-api#fetching-multiple-values-from-one-api-call)។

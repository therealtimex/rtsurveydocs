## ហេតុអ្វីបានជាវាត្រូវការ

RTSurvey ខ្ចប់មេឌៀទម្រង់ — មូលដ្ឋានទិន្នន័យ SQLite, រូបភាព, ឈុតសំឡេង — នៅក្នុងថតឯកសារតាមទម្រង់នីមួយៗនៅលើឧបករណ៍។ ផ្លូវពិតប្រាកដគឺខុសគ្នារវាងវេទិកា (Android, iOS, web) និងរវាងឧបករណ៍។

នៅពេលដំណើរការ កម្មវិធីបំពេញ `family_path` ដោយស្វ័យប្រវត្តិ។ តម្លៃដែលបានដោះស្រាយជាទូទៅមើលទៅដូចជា៖

```
resources/familyMedia/Phuong_Person_Test
```

ដោយសារតែផ្លូវគឺជាក់លាក់សម្រាប់វេទិកា និងត្រូវបានកំណត់នៅពេលចាប់ផ្តើមដំណើរការ វាមិនអាចត្រូវបានសរសេរកូដរឹងនៅក្នុងទម្រង់នោះទេ។ `pulldata('app-api', 'family_path')` គឺជាមធ្យោបាយតែមួយគត់ដែលអាចទុកចិត្តបានក្នុងការទាញយកវា។

## របៀបប្រើវានៅក្នុងផ្លូវ

នៅពេលដែល `family_path` ត្រូវបានកំណត់ សូមបង្កើតផ្លូវឯកសារពេញលេញជាមួយ `concat()`៖

```
concat(${family_path}, '/file.db::tableName')
```

បច្ច័យ `::tableName` ត្រូវបានដកចេញនៅពេលដែលកម្មវិធីបើកឯកសារ។ ឈ្មោះតារាងត្រូវបានប្រើតែនៅក្នុងសំណួរ SQL របស់អ្នកប៉ុណ្ណោះ។

## កន្លែងដែល family_path ត្រូវបានប្រើ

`family_path` ត្រូវបានទាមទារនៅក្នុងអាគុយម៉ង់ផ្លូវនៅពេលណាដែលអ្នកយោងទៅឯកសារដែលបានខ្ចប់៖

- **ការស្វែងរកមូលដ្ឋានទិន្នន័យក្នុងស្រុក** — អាគុយម៉ង់ `db_path` នៃ `search-autocomplete-noedit-v2('rawquery', ...)` ត្រូវតែត្រូវបានបង្កើតឡើងជាមួយ `concat(${family_path}, ...)`។ សូមមើល [ការស្វែងរកមូលដ្ឋានទិន្នន័យក្នុងស្រុក](local-database-search) សម្រាប់ព័ត៌មានលម្អិតអំពីការប្រើប្រាស់ពេញលេញ។
- **`pulldata` rawquery** — រាល់ការហៅ `pulldata('rawquery', ...)` ដែលអានពីឯកសារ `.db` ប្រើលំនាំ `concat()` ដូចគ្នា។
- **`search()` ជាមួយឯកសារក្នុងស្រុក** — រូបរាងស្វែងរកថាមវន្ត (dynamic-search appearances) ដែលផ្ទុកពីឯកសារ CSV ឬ DB ដែលបានខ្ចប់ ក៏ពឹងផ្អែកលើ `family_path` សម្រាប់ឯកសារយោងផងដែរ។

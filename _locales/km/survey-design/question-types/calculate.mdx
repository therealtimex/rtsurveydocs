ប្រភេទសំណួរ `calculate` ដំណើរការរូបមន្តដោយស្ងាត់ស្ងៀមនៅផ្ទៃខាងក្រោយ។ វាផ្ុកទុកលទ្ធផលក្នុងវាល (field) ដែលមានឈ្មោះ ដែលសំណួរផ្សេងទៀតអាចយោងទៅបាន — ប៉ុន្តែវាមិនបង្ហាញការបញ្ចូលទិន្នន័យ ឬស្លាក (label) ទៅកាន់អ្នកប្រមូលទិន្នន័យឡើយ។ ប្រើវាដើម្បីទាញយកតម្លៃ, ភ្ជាប់ខ្សែអក្សរ (strings), ដំណើរការតក្កវិជ្ជាមានលក្ខខណ្ឌ, ឬស្វែងរកទិន្នន័យដែលអ្នកត្រូវការនៅពេលក្រោយក្នុងទម្រង់បែបបទ។

---

## វាក្យសម្ព័ន្ធមូលដ្ឋាន

| type | name | label | calculation |
|------|------|-------|-------------|
| calculate | total | | `${price} * ${quantity}` |

- **type**: ជានិច្ចកាលគឺ `calculate`។
- **name**: ឈ្មោះវាលតែមួយគត់។ សំណួរផ្សេងទៀតយោងទៅវាលនេះជាមួយ `${name}`។
- **label**: ទុកឱ្យនៅទំនេរ — វាល calculate មិនដែលត្រូវបានបង្ហាញទៅកាន់អ្នកប្រមូលទិន្នន័យឡើយ។
- **calculation**: រូបមន្តសម្រាប់វាយតម្លៃ។ គាំទ្រ [មុខងារ XLSForm](../operators-and-functions/functions) ទាំងអស់ និងការយោងវាល។

## លំនាំទូទៅ

### នព្វន្ត (Arithmetic)

| type | name | label | calculation |
|------|------|-------|-------------|
| integer | price | Unit price | |
| integer | quantity | Quantity | |
| calculate | total | | `${price} * ${quantity}` |
| note | total_note | Total: `${total}` | |

### ការភ្ជាប់ខ្សែអក្សរ (String concatenation)

| type | name | label | calculation |
|------|------|-------|-------------|
| text | first_name | First name | |
| text | last_name | Last name | |
| calculate | full_name | | `concat(${first_name}, ' ', ${last_name})` |

### តម្លៃមានលក្ខខណ្ឌ

| type | name | label | calculation |
|------|------|-------|-------------|
| integer | score | Score (0–100) | |
| calculate | grade | | `if(${score} >= 90, 'A', if(${score} >= 75, 'B', if(${score} >= 60, 'C', 'F')))` |

### អាយុពីថ្ងៃខែឆ្នាំកំណើត

| type | name | label | calculation |
|------|------|-------|-------------|
| date | dob | Date of birth | |
| calculate | age_years | | `int((today() - ${dob}) div 365.25)` |

## ការប្រើប្រាស់ `once()` ដើម្បីចាក់សោតម្លៃ

តាមលំនាំដើម `calculate` វាយតម្លៃឡើងវិញរាល់ពេលដែលវាលដែលបានយោងផ្លាស់ប្តូរ។ ខ្ចប់រូបមន្តក្នុង `once()` ដើម្បីវាយតម្លៃតែនៅពេលផ្ទុកដំបូង និងរក្សាលទ្ធផលឱ្យនៅដដែល៖

| type | name | label | calculation |
|------|------|-------|-------------|
| calculate | interview_start | | `once(now())` |

ប្រើ `once()` សម្រាប់ត្រាពេលវេលា (timestamps), តម្លៃដំបូង, ឬករណីណាមួយដែលការគណនាឡើងវិញនៅពេលផ្លាស់ប្តូរគឺមិនចង់បាន។

---

## ការទាញយកទិន្នន័យពីប្រភពខាងក្រៅ

### ពីឯកសារ CSV

```
pulldata('staff.csv', 'department', 'name', ${staff_id})
```

សូមមើល [pulldata()](../operators-and-functions/pulldata) សម្រាប់ឯកសារយោងពេញលេញ។

### ពីមូលដ្ឋានទិន្នន័យ SQLite ដែលបានភ្ជាប់មកជាមួយ

```
pulldata('rawquery',
  concat(${family_path}, '/locations.db::provinces'),
  'SELECT name FROM provinces WHERE id = ?',
  ${province_id})
```

សូមមើល [ការស្វែងរកមូលដ្ឋានទិន្នន័យមូលដ្ឋាន](../advanced-features/local-database-search) សម្រាប់ព័ត៌មានលម្អិតអំពីការសាងសង់ផ្លូវ (path construction)។

### ពីបរិបទកម្មវិធី (App context)

```
pulldata('app-api', 'user.username')
pulldata('app-api', 'family_path')
```

សូមមើល [App API](../app-api) សម្រាប់សោ (keys) ដែលមានទាំងអស់។

## ការប្រើប្រាស់ calculate ក្នុង relevant និង constraint

វាលផ្សេងទៀតអាចយោងទៅលទ្ធផល `calculate` ដូចជាវាលណាមួយដែរ៖

| type | name | label | relevant | constraint |
|------|------|-------|----------|------------|
| calculate | bmi | | | `${weight} div (${height} * ${height}) * 10000` |
| note | bmi_warning | BMI is very high — please verify weight and height. | `${bmi} > 40` | |

---

## ការអនុវត្តល្អបំផុត

1. ផ្តល់ឈ្មោះដែលមានអត្ថន័យដល់វាល calculate — `total_cost` គឺច្បាស់ជាង `calc1` និងងាយស្រួលក្នុងការតាមដាននៅក្នុងការនាំចេញទិន្នន័យ។
2. បំបែករូបមន្តស្មុគស្មាញទៅជាវាល calculate ជាច្រើនដែលតភ្ជាប់គ្នា ជំនួសឱ្យការប្រើកន្សោមដែលបង្កប់យ៉ាងជ្រៅតែមួយ។
3. ប្រើ `once()` សម្រាប់ត្រាពេលវេលា និងរូបភាពដំបូងដើម្បីការពារកុំឱ្យតម្លៃផ្លាស់ប្តូរបន្ទាប់ពីការចាប់យកដំបូង។
4. ដាក់វាល `calculate` មុនសំណួរដំបូងដែលយោងទៅពួកវា — លំដាប់វាយតម្លៃធ្វើតាមលំដាប់ទម្រង់បែបបទ។
5. រក្សាជួរឈរ `label` ឱ្យនៅទំនេរ។ ឧបករណ៍មួយចំនួនបង្ហាញស្លាក; ការទុកវាឱ្យនៅទំនេរជួយជៀសវាងលទ្ធផលដែលនាំឱ្យមានការភាន់ច្រឡំ។

## កម្រិតកំណត់

- វាល Calculate មិនដែលត្រូវបានបង្ហាញដោយផ្ទាល់ទៅកាន់អ្នកប្រមូលទិន្នន័យឡើយ — ប្រើវាល `note` ដើម្បីបង្ហាញលទ្ធផល។
- ជួរឈរ `calculation` គឺចាំបាច់; ជួរដេក `calculate` ដែលគ្មានរូបមន្តតែងតែរក្សាទុកខ្សែអក្សរទទេ (empty string)។
- លទ្ធផលវាយតម្លៃឡើងវិញរាល់ពេលផ្លាស់ប្តូរទម្រង់បែបបទ លើកលែងតែត្រូវបានខ្ចប់ក្នុង `once()` — រូបមន្តដែលស្មុគស្មាញខ្លាំងនៅក្នុងទម្រង់បែបបទធំៗអាចប៉ះពាល់ដល់ដំណើរការបង្ហាញនៅលើឧបករណ៍ដែលមានលក្ខណៈបច្ចេកទេសទាប។
- តម្លៃដែលបានគណនាត្រូវបានរក្សាទុកជាខ្សែអក្សរនៅក្នុងការបញ្ជូន។ ប្រើ `number()`, `int()`, ឬ `boolean()` ដើម្បីប្តូរប្រភេទនៅពេលបញ្ជូនលទ្ធផលទៅកាន់កន្សោមនព្វន្ត ឬតក្កវិជ្ជា។

## XLSForm ជា អ្វី?
rtSurvey ប្រើ version ដែល extended នៃ ស្ដង់ដារ [XLSForm](https://xlsform.org/) សម្រាប់ ការ រចនា ទម្រង់ ។ ជាមួយ XLSForms, អ្នក អាច author forms ក្នុង format ដែល human-readable ដោយប្រើ Excel ។

## XLSForm Structure
XLSForm ជាទូទៅ រួមមាន worksheets ចម្បង ពីរ:

1. **survey**: កំណត់ structure និង content នៃ form ។
2. **choices**: បញ្ជាក់ answer choices សម្រាប់ multiple-choice questions ។

worksheet **settings** ស្រេចចិត្ត អាច ផ្ដល់ form specifications បន្ថែម ។

### The survey worksheet
**survey worksheet** ជា កន្លែង ដែល អ្នក កំណត់ structure នៃ form ។ columns ខាងក្រោម ចាំបាច់:

- `type`: បញ្ជាក់ ប្រភេទ entry ។
- `name`: បញ្ជាក់ variable name តែមួយគត់ ។
- `label`: មាន text ដែល អ្នក ឃើញ សម្រាប់ question ។

| type                | name     | label                |
| ------------------- | -------- | -------------------- |
| today               | today    |                      |
| select_one gender   | gender   | Respondent's gender? |
| integer             | age      | Respondent's age?    |

### The choices worksheet
**`choices`** worksheet ប្រើ ដើម្បី បញ្ជាក់ answer choices ។ columns ខាងក្រោម ចាំបាច់:

- **`list_name`**: ដាក់ជាក្រុម answer choices ។
- **`name`**: variable name តែមួយគត់ ។
- **`label`**: ចំណងជើង answer choice ។

| list_name           | name        | label                |
| ------------------- | ----------- | -------------------- |
| gender              | transgender | Transgender          |
| gender              | female      | Female               |
| gender              | male        | Male                 |
| gender              | other       | Other                |

### The settings worksheet

| Column | ការពិពណ៌នា |
|--------|-------------|
| form_title | ចំណងជើង form ដូចជា ដែល បង្ហាញ ដល់ users |
| form_id | identifier តែ មួយ គត់ សម្រាប់ form |
| default_language | language code default (ឧ. 'en' សម្រាប់ English) |
| version | version number |
| instance_name | Expression ដើម្បី generate name តែ មួយ គត់ |

## ប្រភេទ Questions សំខាន់ ៗ

| ប្រភេទ questions          | Input ចម្លើយ                                                                 |
| ------------------------- | ---------------------------------------------------------------------------- |
| integer                   | Input integer (ចំនួនគត់) ។                                                   |
| decimal                   | Input decimal ។                                                              |
| text                      | ចម្លើយ text ។                                                                |
| select_one [options]      | Multiple choice; ជ្រើស មួយ ចម្លើយ ប៉ុណ្ណោះ ។                               |
| select_multiple [options] | Multiple choice; ចម្លើយ ច្រើន ។                                             |
| geopoint                  | ប្រមូល GPS coordinate ។                                                      |
| date                      | Input Date ។                                                                 |
| image                     | ថតរូប ឬ upload image ។                                                       |
| calculate                 | ធ្វើ calculation ។                                                           |
| note                      | បង្ហាញ note ។                                                               |

## Components សំខាន់ ៗ

| Component | ការពិពណ៌នា |
|-----------|-------------|
| type | ប្រភេទ question (ឧ. text, integer, select_one) |
| name | identifier តែ មួយ គត់ |
| label | text ដែល បង្ហាញ ដល់ respondent |
| hint | ការ ណែ នាំ បន្ថែម |
| appearance | ប្ដូរ ការ បង្ហាញ question |
| relevant | logic skip |
| constraint | validate ចម្លើយ |
| calculation | គណនា values |
| required | fields ចាំបាច់ |

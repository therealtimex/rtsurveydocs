## ការអនុវត្តល្អបំផុតសម្រាប់ការប្រើប្រាស់រូបរាង

១. **ភាពស៊ីសង្វាក់គ្នា**៖ ប្រើគុណលក្ខណៈរូបរាងឱ្យបានស៊ីសង្វាក់គ្នាពេញការស្ទង់មតិរបស់អ្នកសម្រាប់រូបរាងឯកសណ្ឋាន។
២. **ទូរស័ព្ទ និងបណ្ដាញ**៖ ពិចារណាពីរបៀបដែលរូបរាងនឹងបង្ហាញនៅលើឧបករណ៍ និងប្រព័ន្ធផ្សេងៗគ្នា។
៣. **ប្រសិទ្ធភាព**៖ ប្រុងប្រយ័ត្នជាមួយគុណលក្ខណៈរូបរាងដែលអាចធ្វើឱ្យការផ្ទុកទម្រង់យឺត (ឧទាហរណ៍៖ `table-list` សម្រាប់ក្រុមធំ)។
៤. **បទពិសោធន៍អ្នកប្រើប្រាស់**៖ ជ្រើសរើសរូបរាងដែលធ្វើឱ្យការបញ្ចូលទិន្នន័យកាន់តែងាយស្រួល និងកាន់តែយល់ច្បាស់សម្រាប់អ្នកឆ្លើយសំណួរ។
៥. **ការសាកល្បង**៖ សាកល្បងទម្រង់របស់អ្នកជានិច្ចនៅលើឧបករណ៍គោលដៅ ដើម្បីប្រាកដថារូបរាងដំណើរការដូចការរំពឹងទុក។

## បច្ចេកទេសកម្រិតខ្ពស់

### ការរួមបញ្ចូលរូបរាង

គុណលក្ខណៈរូបរាងមួយចំនួនអាចត្រូវបានរួមបញ្ចូលគ្នាសម្រាប់ប្លង់ដែលស្មុគស្មាញជាងនេះ៖

```
| type | name | label | appearance |
|------|------|-------|------------|
| select_one options | choice | Select one: | minimal compact |
```

### រូបរាងថាមវន្ត

rtSurvey អនុញ្ញាតឱ្យមានការផ្លាស់ប្តូររូបរាងថាមវន្តដោយផ្អែកលើតក្កវិជ្ជារបស់ទម្រង់៖

```
| type | name | label | appearance | relevant |
|------|------|-------|------------|----------|
| text | time | Enter time: | inline-[%H:%M] | ${show_time} = 'yes' |
```

## ការពិចារណាសម្រាប់កម្មវិធីទូរស័ព្ទ

- រូបរាងមួយចំនួន (ឧទាហរណ៍៖ `quick`, `signature`) គឺជាក់លាក់សម្រាប់ឧបករណ៍ទូរស័ព្ទ។
- សាកល្បងឱ្យបានហ្មត់ចត់លើទាំង Android និង iOS ដើម្បីធានាបាននូវឥរិយាបថស៊ីសង្វាក់គ្នា។

## គុណលក្ខណៈរូបរាងបន្ថែមរបស់ rtSurvey

| `scroll-view(N%)` | group, repeat | កម្រិតកម្ពស់អតិបរមានៃធុងផ្ទុកត្រឹម `N%` នៃផ្ទៃមើល (ឬធុងមេ) ដោយបន្ថែមរបាររំកិលនៅពេលមាតិកាហៀរចេញ។ ឧទាហរណ៍៖ `scroll-view(60%)`។ |

### ទម្រង់កាលបរិច្ឆេទ/ម៉ោងតាមជួរ (Inline)

សម្រាប់វាល `date`, `time` និង `datetime` អ្នកអាចបញ្ជាក់ទម្រង់បង្ហាញផ្ទាល់ខ្លួនដោយប្រើខ្សែអក្សរទម្រង់ដែលភ្ជាប់ទៅនឹងរូបរាង៖

```
inline-[%d/%m/%Y]
inline-1line-[%d/%m/%Y %H:%M]
```

សញ្ញាសម្គាល់ទម្រង់គឺដូចគ្នាទៅនឹង `format-date()` និង `format-date-time()`។ សូមមើល [មុខងារ — មុខងារកាលបរិច្ឆេទ និងម៉ោង](operators-and-functions/functions#date-and-time-functions)។

ឧទាហរណ៍៖

| type | name | label | appearance |
|------|------|-------|------------|
| datetime | event_time | កាលបរិច្ឆេទ និងម៉ោងព្រឹត្តិការណ៍ | inline-[%d/%m/%Y %I:%M %p] |
| date | birth_date | ថ្ងៃខែឆ្នាំកំណើត | inline-[%d/%m/%Y] |

### ប្លង់ប៊ូតុងតាមជួរ (Inline) — `display{}` និង `results{}`

សម្រាប់ប្រភេទសំណួរដែលបង្ហាញជាប៊ូតុងរូបតំណាងតាមជួរ (`date`, `time`, `datetime`, `image`, `audio`, `video`, `file`, `barcode`, `geopoint`) ឧបករណ៍កែប្រែរូបរាងពីរកំណត់ទីតាំងប៊ូតុង និងឥរិយាបថបន្ទាប់ពីផ្តិតយក។

#### `display{...}` — ទីតាំងប៊ូតុងមុនពេលផ្តិតយក

```
display{<align>, <size>, <color>}
```

| ប៉ារ៉ាម៉ែត្រ | តម្លៃ | លំនាំដើម |
|-----------|--------|---------|
| តម្រឹម (Align) | `left`, `right`, `top`, `center`, `bottom` | `right` |
| ទំហំ (Size) | `small`, `medium`, `large` | `small` |
| ពណ៌ (Color) | hex ឧទាហរណ៍ `#FF5500` | ពណ៌ប្រធានបទចម្បង |
| ទង់ (Flag) | `inline-icon` | បង្ខំឱ្យប្រើរបៀបរូបតំណាង |

| តម្លៃតម្រឹម | ប្លង់ |
|-------------|--------|
| `right` | ប៊ូតុងនៅខាងស្តាំស្លាក |
| `left` | ប៊ូតុងនៅខាងឆ្វេងស្លាក |
| `top` | ប៊ូតុងនៅខាងលើស្លាក កណ្តាលពេញទទឹង |
| `center` / `bottom` | ប៊ូតុងនៅខាងក្រោមស្លាក កណ្តាលពេញទទឹង |

#### `results{...}` — ប្លង់ និងភាពមើលឃើញបន្ទាប់ពីផ្តិតយក

ទទួលមរតកនូវការកំណត់ `display{}`។ ប្រើដើម្បីផ្លាស់ទីប៊ូតុង ឬលាក់ធាតុនៅពេលតម្លៃត្រូវបានផ្តិតយក។

```
results{<align>, hide(<element>)}
```

| តម្លៃ `hide` | ប្រសិទ្ធភាព |
|---|---|
| `hide(capture)` | លាក់ប៊ូតុងផ្តិតយកនៅពេលមានឯកសារ/តម្លៃ |
| `hide(review)` | លាក់រូបភាពតូចពិនិត្យឡើងវិញ / ប៊ូតុងចាក់ឡើងវិញ |
| `hide(filename)` | លាក់ឈ្មោះឯកសារដែលបង្ហាញបន្ទាប់ពីបង្ហោះ |
| `hide(camera)` | លាក់ប៊ូតុងកេះកាមេរ៉ាបន្ទាប់ពីផ្តិតយក |
| `hide(scanner)` | លាក់ប៊ូតុងស្កេនបាកូដបន្ទាប់ពីតម្លៃត្រូវបានស្កេន |
| `hide(value)` | លាក់អត្ថបទតម្លៃដែលបានស្កេន (បាកូដ / geopoint) |

ឧបករណ៍នឹងប្តូរដោយស្វ័យប្រវត្តិពីប្លង់ `display{}` ទៅប្លង់ `results{}` នៅខណៈពេលដែលតម្លៃត្រូវបានផ្តិតយក។

**ឧទាហរណ៍៖**

```
inline display{right}                                    → រូបតំណាងនៅខាងស្តាំស្លាក
inline display{left, large}                              → រូបតំណាងធំនៅខាងឆ្វេង
inline display{center, large, #FF5500}                   → រូបតំណាងពណ៌ទឹកក្រូចធំនៅខាងក្រោមស្លាក
inline display{right} results{left}                      → រូបតំណាងផ្លាស់ទីទៅឆ្វេងបន្ទាប់ពីផ្តិតយក
inline display{right} results{hide(capture)}             → រូបតំណាងបាត់បន្ទាប់ពីផ្តិតយក
inline display{center} results{hide(capture), hide(filename)}
```

## ដែនកំណត់ដែលគេស្គាល់

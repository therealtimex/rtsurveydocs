SSL muss konfiguriert werden, bevor Sie sich anmelden können. Wenn Sie die App zum ersten Mal öffnen, werden Sie automatisch zur SSL-Einrichtungsseite weitergeleitet.

---

## SSL-Einrichtungsoptionen

![SSL-Einrichtungsoptionen](/img/ssl-setup/ssl-setup-options.png)

Wählen Sie eine von drei Optionen:

| Option | Verwendung |
|--------|------------|
| **Kostenlose rtsurvey.com-Subdomain** *(Empfohlen)* | Keine DNS-Einrichtung erforderlich. Wir erstellen den Eintrag für Sie. Bereit in 2–5 Minuten. |
| **Eigene Domain** | Sie haben bereits eine Domain und deren DNS zeigt auf diesen Server. |
| **Zertifikat manuell installieren** | Unternehmens- oder benutzerdefinierte CA. Erfordert SSH-Zugriff. |

---

## Option 1 — Kostenlose rtsurvey.com-Subdomain *(Empfohlen)*

Dies ist die schnellste Option. Keine Domainregistrierung oder DNS-Änderungen erforderlich.

![HTTPS-Einrichtungsformular](/img/ssl-setup/ssl-setup-form.png)

> **Bevor Sie fortfahren:** Eine kostenlose Subdomain erfordert ein aktives Konto bei [licenses.rtsurvey.com](https://licenses.rtsurvey.com). Der kostenlose Plan beinhaltet 1 Subdomain (`*.rtsurvey.com`).

1. Klicken Sie auf **Kostenlose rtsurvey.com-Subdomain**, um den Abschnitt zu erweitern
2. Geben Sie Ihren gewünschten Subdomain-Namen in das Feld **IHRE SUBDOMAIN** ein

   > Verwenden Sie Kleinbuchstaben, Zahlen und Bindestriche. 3–30 Zeichen.
   > Beispiel: `meinprojekt` → `meinprojekt.rtsurvey.com`

3. Fügen Sie Ihr **rtSurvey DNS Token** von [licenses.rtsurvey.com](https://licenses.rtsurvey.com) in das Token-Feld ein
4. Klicken Sie auf **Sichere Subdomain erstellen**

Sobald das Formular abgeschickt wurde, beginnt die App mit der Bereitstellung Ihres Zertifikats:

![HTTPS-Einrichtungsfortschritt](/img/ssl-setup/ssl-setup-progress.png)

Die vier Schritte laufen automatisch ab:
- **DNS-Eintrag anfordern** — erstellt den DNS-Eintrag für Ihre Subdomain
- **Warten auf DNS-Propagierung** — dauert normalerweise 2–5 Minuten
- **SSL-Zertifikat ausstellen** — Let's Encrypt signiert Ihr Zertifikat
- **HTTPS aktivieren** — Nginx wird mit dem neuen Zertifikat neu geladen

5. Sobald der Vorgang abgeschlossen ist, werden Sie automatisch zu Ihrer neuen HTTPS-URL weitergeleitet



---

## Option 2 — Eigene Domain

Verwenden Sie diese Option, wenn Sie eine bestehende Domain haben und deren DNS `A`-Eintrag bereits auf die IP dieses Servers zeigt.

1. Klicken Sie auf **Eigene Domain**, um den Abschnitt zu erweitern
2. Geben Sie Ihren vollständigen Domainnamen ein (z. B. `survey.meineorganisation.org`)
3. Klicken Sie auf **Zertifikat erstellen**



Let's Encrypt wird Ihre Domain verifizieren und ein Zertifikat ausstellen. Dies setzt voraus, dass der DNS-Eintrag zuerst korrekt gesetzt wurde — andernfalls schlägt die Anfrage fehl.

## Option 3 — Zertifikat manuell installieren

Für Unternehmensumgebungen, die eine benutzerdefinierte oder interne CA verwenden. Sie hinterlegen Ihre Zertifikatsdateien via SSH auf dem Server und geben dann Ihre Domain in der App ein.

### Voraussetzungen

- SSH-Zugriff auf den Server
- Ein gültiges Zertifikat und ein privater Schlüssel für Ihre Domain (PEM-Format)

### Schritt 1 — Per SSH auf den Server verbinden

```bash
ssh root@<server-ip>
```

### Schritt 2 — Zertifikatsdateien hinterlegen

Erstellen Sie das Verzeichnis und kopieren Sie Ihre Dateien:

```bash
mkdir -p /etc/letsencrypt/live/<ihre-domain>
```

Kopieren Sie Ihre Dateien mit genau diesen Namen in dieses Verzeichnis:

| Datei | Beschreibung |
|-------|--------------|
| `fullchain.pem` | Ihr Zertifikat + alle Zwischenzertifikate der CA (aneinandergehängt) |
| `privkey.pem` | Ihr privater Schlüssel |

Beispiel:

```bash
# Von Ihrem lokalen Rechner kopieren (lokal ausführen, nicht auf dem Server)
scp fullchain.pem root@<server-ip>:/etc/letsencrypt/live/<ihre-domain>/fullchain.pem
scp privkey.pem  root@<server-ip>:/etc/letsencrypt/live/<ihre-domain>/privkey.pem
```

Korrekte Berechtigungen setzen:

```bash
chmod 644 /etc/letsencrypt/live/<ihre-domain>/fullchain.pem
chmod 600 /etc/letsencrypt/live/<ihre-domain>/privkey.pem
```

### Schritt 3 — Domain in der App eingeben



1. Klicken Sie im SSL-Einrichtungsbildschirm auf **Zertifikat manuell installieren**
2. Geben Sie Ihren Domainnamen ein (muss mit dem Common Name oder SAN des Zertifikats übereinstimmen)
3. Klicken Sie auf **Anwenden**

Der Server wird Nginx mit Ihrem Zertifikat konfigurieren und automatisch neu laden.

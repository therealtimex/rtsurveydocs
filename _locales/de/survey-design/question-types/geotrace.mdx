---
title: "Geotrace"
description: "Geotrace-Fragen erfassen eine Reihe von GPS-Punkten, die eine Linie oder einen Pfad bilden."
---

Der Fragetyp `geotrace` erfasst eine Sequenz geografischer Koordinaten, die eine Linie oder einen Pfad (Polyline) bilden. Im rtSurvey-Webformular wird dies als **Texteingabefeld** dargestellt, in das der Interviewer (Enumerator) die Koordinatenzeichenfolge direkt eingibt oder einfügt.

## Grundlegende XLSForm-Spezifikation

| type     | name        | label                        |
|----------|-------------|------------------------------|
| geotrace | river_path  | Verfolgen Sie den Pfad des Flusses |
| geotrace | road_route  | Erfassen Sie die Straßenroute |

Die Standard-Spezifikation finden Sie in der [XLSForm-Dokumentation](https://xlsform.org/en/#question-types).

---

## Datenformat (Data Format)

Wird als semikolon-separierte Liste von Punkten gespeichert, wobei **keine Leerzeichen um die Semikolons** stehen dürfen. Jeder Punkt besteht aus vier durch Leerzeichen getrennten Werten:

```
lat lon alt acc;lat lon alt acc;lat lon alt acc
```

| Component | Description |
|-----------|-------------|
| `lat` | Breitengrad in Dezimalgrad |
| `lon` | Längengrad in Dezimalgrad |
| `alt` | Höhe in Metern (`0`, wenn unbekannt) |
| `acc` | GPS-Genauigkeit in Metern (`0`, wenn unbekannt) |

**Beispiel — ein Pfad mit drei Punkten:**
```
13.756331 100.501762 15 8;13.758000 100.503000 14 6;13.760000 100.505000 13 5
```

Es sind mindestens zwei Punkte erforderlich, um einen gültigen Pfad zu bilden.

---

## Darstellung in rtSurvey

Im rtSurvey-Webformular wird `geotrace` als einfaches **Textfeld** dargestellt. Der Interviewer tippt oder fügt die Koordinatenzeichenfolge ein. Für diesen Typ gibt es im aktuellen Webformular keine integrierte interaktive Kartenauswahl.

### Interaktive Erfassung von Punkten

Das empfohlene Muster für die Datenerfassung im Feld ist eine **Wiederholungsgruppe (repeat group) von `geopoint`-Fragen** — jeder Punkt verwendet die vollständige GPS-Kartenauswahl —, kombiniert mit einer `calculate`-Frage, um die Geotrace-Zeichenfolge zu erzeugen:

| type | name | label | calculation |
|------|------|-------|-------------|
| begin repeat | path_points | Erfassen Sie jeden Wegpunkt | |
| geopoint | point | Tippen, um Punkt zu erfassen | |
| end repeat | path_points | | |
| calculate | geotrace_value | | `join(';', ${path_points/point})` |

Die berechnete Zeichenfolge kann dann in einer `text`-Frage gespeichert oder in `geotrace` verwendet werden.

## Beispiel für die Verwendung

| type | name | label | hint | required |
|------|------|-------|------|----------|
| geotrace | farm_boundary_path | Erfassen Sie den Zugangsweg zum Hof | Geben Sie jeden Wegpunkt getrennt durch Semikolons ein | yes |

---

## Best Practices

1. Verwenden Sie eine Wiederholungsgruppe von `geopoint`-Fragen für eine interaktive, kartenbasierte Erfassung und verbinden Sie dann die Werte — dies ermöglicht den Interviewern die Nutzung einer GPS-Auswahl für jeden einzelnen Punkt.
2. Geben Sie das erwartete Format in der Spalte `hint` an, wenn eine manuelle Koordinateneingabe erforderlich ist.
3. Überprüfen Sie das Vorhandensein mit `required = yes`, wenn der Pfad obligatorisch ist.
4. Planen Sie die Datenbereinigung ein — manuell eingegebene Pfade können eine uneinheitliche Präzision aufweisen.

## Einschränkungen (Limitations)

- Es gibt keine integrierte interaktive Kartenauswahl für `geotrace` im rtSurvey-Webformular.
- Die Koordinatenzeichenfolge kann bei komplexen Pfaden lang werden — berücksichtigen Sie dies bei der Formularleistung und der Speicherung.
- Die Validierung der Pfadtopologie (z. B. Mindestanzahl an Punkten, Selbstüberschneidung) erfordert eine Nachbearbeitung außerhalb der XLSForm-Beschränkungen.

---
title: "Ganzzahl"
description: "Fragetyp für die Eingabe von Ganzzahlen in rtSurvey"
---

Der Fragetyp `integer` sammelt ganze Zahlen (keine Dezimalstellen). Er löst auf Mobilgeräten eine numerische Tastatur aus und blockiert die Eingabe von Dezimalpunkten. Er unterstützt dieselben Darstellungsoptionen wie der Typ `text` für Layout und Formatierung.

## Grundlegende XLSForm-Spezifikation

| type | name | label |
|------|------|-------|
| integer | age | Alter des Befragten |
| integer | household_size | Anzahl der Personen im Haushalt |

Weitere Einzelheiten zur Standardspezifikation finden Sie in der [XLSForm-Dokumentation](https://xlsform.org/en/#question-types).

---

## Darstellungsoptionen (Appearance)

### `number-hspinner` — Horizontaler Spinner

Ersetzt die Eingabe durch einen horizontalen **− Wert +** Spinner. Das Antippen von Minus/Plus verringert oder erhöht den Wert um 1 (oder einen benutzerdefinierten Schritt).

```
number-hspinner
```

**Anpassung von Buttonform und Schrittweite** mit `hspinner()`:

```
number-hspinner hspinner('left-small-square','right-small-square','5')
```

Parameter: linke Buttonform, rechte Buttonform, Schrittweite (Standardwert `1` für Ganzzahlen).

**Benutzerdefinierte Farben** mit `colors()`:

```
number-hspinner colors(0099FF,FFFFFF,FF5500,FFFFFF)
```

Vier Werte in der Reihenfolge: Hintergrund linker Button, Icon linker Button, Hintergrund rechter Button, Icon rechter Button.

---

### `thousandsep` — Tausendertrennzeichen

Formatiert die angezeigte Zahl mit Komma-Gruppierung (z. B. `1,234,567`). Die Rohzahl wird ohne Kommas gespeichert. Der Eingabetyp wird auf `"text"` umgeschaltet, um die formatierte Anzeige zu ermöglichen.

```
thousandsep
```

---

### `digisep(n, "sep")` — Benutzerdefinierte Zifferngruppierung

Gruppiert Ziffern in Blöcken von `n`, die durch ein benutzerdefiniertes Trennzeichen getrennt sind. Nützlich für formatierte IDs oder Referenzcodes, die numerisch sind.

```
digisep(4,"-")      → 0912-3456-789
digisep(3," ")      → 012 345 678
```

Der Eingabetyp wird auf `"text"` umgeschaltet, wenn diese Darstellung aktiv ist.

---

### `textonly` — Text-Tastatur erzwingen

Erzwingt `type="text"` für das Eingabeelement. Dies verhindert Eigenheiten der Browser-Zahleneingabe (wie das Ausblenden führender Nullen oder das Hinzufügen von Drehreglern in Desktop-Browsern), während weiterhin ein numerischer Wert gesammelt wird.

```
textonly
```

---

### `floating_hint` — Hinweis schwebt als Beschriftung

Der `hint`-Text wird innerhalb der Eingabe als Platzhalter angezeigt. Wenn der Benutzer zu tippen beginnt, schwebt er als Beschriftung über das Feld.

```
floating_hint
```

---

### `embed` — Hinweis innerhalb der Eingabebegrenzung

Ähnlich wie `floating_hint` — der Hinweis befindet sich innerhalb der Eingabebegrenzung, wenn das Feld leer ist. Er schwebt nicht, wenn der Benutzer tippt.

```
embed
```

---

### `textpopup` — Modaler Dialog zur Eingabe

Das Antippen des Feldes öffnet einen modalen Dialog mit einer größeren Eingabe anstelle der Inline-Bearbeitung. Nützlich auf kleinen Bildschirmen, wo eine Vollbild-Eingabe einfacher ist.

```
textpopup
```

---

### `charcount` — Live-Zeichenzähler

Zeigt einen Live-Zeichenzähler `(n)` unter der Eingabe an, der beim Tippen des Benutzers aktualisiert wird.

```
charcount
```

---

### `prefix(expr)` — Präfix voranstellen

Stellt dem angezeigten Wert eine statische oder berechnete Zeichenfolge voran. Der gespeicherte Wert enthält das Präfix nicht.

```
prefix('Artikel #')      → zeigt "Artikel #42" an, speichert "42"
prefix(${code_prefix})  → dynamisches Präfix aus einem anderen Feld
```

---

### `align_answer` — Ausrichtung des Eingabetextes

Steuert die horizontale Ausrichtung des getippten Wertes innerhalb der Eingabe.

```
align_answer = left
align_answer = right
align_answer = center
```

---

### `inputs{qrscan}` — QR / Barcode in das Feld scannen

Fügt neben der Eingabe einen Button zum Scannen von QR-Codes hinzu. Öffnet den Kamerascanner und füllt das Feld mit dem gescannten numerischen Wert.

```
inputs{qrscan}
```

## Einschränkungen und Validierung

Verwenden Sie Einschränkungen (Constraints), um Wertebereiche zu erzwingen. Einschränkungen in der Spalte `constraint` werden im Modus `number-hspinner` nach jedem Tastendruck ausgewertet, nicht erst beim Verlassen des Feldes (Blur).

| type | name | label | constraint | constraint_message |
|------|------|-------|------------|-------------------|
| integer | age | Alter | `. > 0 and . <= 120` | Das Alter muss zwischen 1 und 120 liegen |
| integer | year | Baujahr | `. >= 1800 and . <= 2100` | Geben Sie ein gültiges Jahr ein |
| integer | count | Anzahl der Artikel | `. >= 0` | Darf nicht negativ sein |

---

## Beispiel — Haushaltserhebung

| type | name | label | appearance | constraint | constraint_message |
|------|------|-------|------------|------------|-------------------|
| integer | household_size | Personen im Haushalt | `number-hspinner` | `. >= 1 and . <= 30` | Muss zwischen 1 und 30 liegen |
| integer | under_5 | Kinder unter 5 | `number-hspinner` | `. >= 0 and . <= ${household_size}` | Darf die Haushaltsgröße nicht überschreiten |
| integer | year_built | Baujahr des Hauses | `textonly` | `. >= 1800 and . <= 2100` | Geben Sie ein gültiges Jahr ein |

## Best Practices

1. Verwenden Sie `number-hspinner` für Zählungen in kleinen Bereichen, bei denen das Klicken auf ± schneller ist als das Tippen (z. B. Anzahl der Kinder, Bewertung auf einer Skala von 1–10).
2. Verwenden Sie `thousandsep` bei der Anzeige großer Ganzzahlen (Bevölkerung, Einkommen), damit die Befragten die Größenordnung selbst überprüfen können.
3. Verwenden Sie `textonly`, wenn Browser unerwünschte UI für die Zahleneingabe hinzufügen (Drehpfeile, Touch-Scroll), die Befragte verwirren.
4. Erzwingen Sie Bereichsbeschränkungen, anstatt sich auf den Tastaturtyp des Mobilgeräts zu verlassen — die Durchsetzung der Tastatur ist nicht universell.

## Einschränkungen

- Die Eingabe von Dezimalpunkten ist blockiert — wenn Sie Bruchwerte benötigen, verwenden Sie den Typ `decimal`.
- `number-hspinner` validiert die `constraint` bei jedem Tastendruck — vermeiden Sie aufwendige Einschränkungen (z. B. komplexe `if()`-Ketten) im Spinner-Modus.
- `thousandsep` und `digisep()` speichern die Rohzahl ohne Formatierung — verlassen Sie sich bei Berechnungen nicht auf den formatierten Anzeigewert.

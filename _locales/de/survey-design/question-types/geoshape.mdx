title: "Geoshape"
description: "Geoshape-Fragen erfassen ein geschlossenes Polygon, das durch eine Folge von GPS-Punkten definiert ist."
---

Der Frage-Typ `geoshape` erfasst ein geschlossenes Polygon — eine Reihe von GPS-Koordinaten, bei denen der erste und der letzte Punkt identisch sind. Im Webformular von rtSurvey wird dies als **Texteingabe** dargestellt, in die der Datenerheber (enumerator) die Koordinatenzeichenfolge direkt eingibt oder einfügt.

## Grundlegende XLSForm-Spezifikation

| type     | name        | label                            |
|----------|-------------|----------------------------------|
| geoshape | field_area  | Zeichnen Sie die Grenze des Feldes |
| geoshape | zone        | Gebietsgrenze aufzeichnen         |

Die Standard-Spezifikation finden Sie in der [XLSForm-Dokumentation](https://xlsform.org/en/#question-types).

---

## Datenformat

Gespeichert als eine durch Semikolons getrennte Liste von Punkten **ohne Leerzeichen um die Semikolons**. Jeder Punkt besteht aus vier durch Leerzeichen getrennten Werten:

```
lat lon alt acc;lat lon alt acc;lat lon alt acc;lat lon alt acc
```

| Component | Description |
|-----------|-------------|
| `lat` | Breitengrad in Dezimalgrad |
| `lon` | Längengrad in Dezimalgrad |
| `alt` | Höhe in Metern (`0` wenn unbekannt) |
| `acc` | GPS-Genauigkeit in Metern (`0` wenn unbekannt) |

**Das Polygon muss geschlossen sein** — der letzte Punkt muss dem ersten entsprechen.

**Beispiel — ein Polygon mit vier Punkten (Dreieck, geschlossen):**
```
13.756331 100.501762 0 0;13.758000 100.503000 0 0;13.757000 100.506000 0 0;13.756331 100.501762 0 0
```

Um ein gültiges Polygon zu bilden, sind mindestens drei verschiedene Punkte plus die schließende Wiederholung erforderlich.

## Darstellung in rtSurvey

Im Webformular von rtSurvey wird `geoshape` als einfaches **Textfeld** dargestellt. Der Datenerheber tippt die Koordinatenzeichenfolge ein oder fügt sie ein. Im aktuellen Webformular gibt es keinen integrierten interaktiven Polygon-Karten-Picker für diesen Typ.

### Erfassung von Polygonpunkten auf interaktive Weise

Das empfohlene Muster für die Datenerfassung im Feld ist eine **Wiederholungsgruppe von `geopoint`-Fragen** — jeder Eckpunkt verwendet den vollständigen GPS-Karten-Picker — kombiniert mit einer Berechnung (`calculate`), um die Geoshape-Zeichenfolge zu erzeugen:

| type | name | label | calculation |
|------|------|-------|-------------|
| begin repeat | polygon_points | Jeden Eckpunkt aufzeichnen | |
| geopoint | point | Tippen zum Aufzeichnen des Eckpunkts | |
| end repeat | polygon_points | | |
| calculate | geoshape_value | | `join(';', ${polygon_points/point})` |

Fügen Sie nach dem Zusammenfügen den ersten Punkt manuell hinzu, um das Polygon zu schließen, oder verwenden Sie eine zweite Berechnung, um ihn zu verketten.

## Best Practices

1. Verwenden Sie eine Wiederholungsgruppe von `geopoint`-Fragen für die interaktive kartenbasierte Erfassung und fügen Sie die Werte zusammen — dies bietet den Datenerhebern einen GPS-Picker für jeden Eckpunkt.
2. Schließen Sie das Polygon immer (wiederholen Sie den ersten Punkt am Ende), bevor Sie es absenden.
3. Geben Sie das erwartete Format in der Spalte `hint` an, wenn eine manuelle Koordinateneingabe erforderlich ist.
4. Verlangen Sie mindestens 3 verschiedene Eckpunkte für ein gültiges Polygon — setzen Sie dies durch Anweisungen und nicht durch XLSForm-Beschränkungen (constraints) durch.
5. Verwenden Sie `geopoint` für Fragen zu einem einzelnen Standort und `geoshape` nur dann, wenn die Gebietsabgrenzung das eigentliche Ziel der Umfrage ist.

## Einschränkungen (Limitations)

- Im Webformular von rtSurvey gibt es keinen integrierten interaktiven Polygon-Karten-Picker für `geoshape`.
- Das Polygon muss manuell geschlossen werden — im Texteingabemodus gibt es keinen automatischen Schließmechanismus.
- Die Validierung der Polygon-Topologie (z. B. keine Selbstüberschneidung, Mindestfläche) erfordert eine Nachbearbeitung außerhalb der XLSForm-Beschränkungen.
- Lange Grenzen mit vielen Eckpunkten erzeugen große Textzeichenfolgen.

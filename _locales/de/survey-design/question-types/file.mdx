title: "Datei"
description: "Dateifragen ermöglichen es Befragten, Dokumente und andere Dateien als Teil ihrer Umfrageantworten hochzuladen."
---

Der Fragetyp `file` ermöglicht es Befragten, **jede Datei** von ihrem Gerät hochzuladen – Dokumente, Tabellen, PDFs oder andere Dateitypen. Im Gegensatz zu `image`, `audio` und `video`, die spezifische Erfassungstools starten, öffnet `file` einen allgemeinen Dateiauswahldialog.

## Grundlegende XLSForm Spezifikation

| type | name      | label                        |
|------|-----------|------------------------------|
| file | document  | Bitte laden Sie Ihr Dokument hoch |

Weitere Details zum Standard-Dateifragetyp finden Sie in der [XLSForm Spezifikation](https://xlsform.org/en/#question-types).

## Verwendung

Dateifragen werden häufig verwendet für:

1.  Sammeln von Belegdokumenten (Quittungen, Zertifikate, Verträge, Berichte)
2.  Hochladen von ausgefüllten, gescannten Papierformularen
3.  Erfassen von Tabellen oder Datenexporten aus anderen Systemen
4.  Jeder digitale Dateityp, der nicht von Bild/Audio/Video abgedeckt wird

## Datenformat

Hochgeladene Dateien werden als binäre Anhänge gespeichert:

-   **Format:** Im Originalformat erhalten (PDF, XLSX, DOCX usw.)
-   **Benennung:** `{instanceID}-{fieldname}.{extension}`
-   **Speicherung:** Wird zusammen mit der Übermittlung in den Medienserverordner hochgeladen
-   **Zugriff:** Herunterladbar über die Verwaltungsoberfläche für Übermittlungen

## rtSurvey Erweiterungen

### Akzeptierte Dateitypen

Verwenden Sie die Spalte `parameters`, um einzuschränken, welche Dateitypen ausgewählt werden können:

| type | name | label | parameters |
|------|------|-------|------------|
| file | report | Inspektionsbericht hochladen | `accept=.pdf` |
| file | spreadsheet | Datendatei hochladen | `accept=.xlsx,.csv` |

Der Parameter `accept` verwendet die Standard-Dateierweiterungssyntax (durch Kommas getrennt).

### Anleitung zur Dateigröße

rtSurvey erzwingt kein hartes Dateigrößenlimit auf Fragen-Ebene, aber das Server-Upload-Limit gilt. Verwenden Sie `hint`, um die Erwartungen an den Interviewer zu kommunizieren:

| type | name | label | hint |
|------|------|-------|------|
| file | receipt | Zahlungsbeleg hochladen | Akzeptiert: PDF oder Bild. Maximale Dateigröße: 5 MB |

### Integration mit Gerätedateisystem und Cloud-Speicher

Auf Android und iOS öffnet die `file`-Frage den nativen Dateiauswahldialog des Geräts, der Zugriff auf folgende Bereiche bieten kann:
-   Lokaler Gerätespeicher
-   SD-Karte (Android)
-   iCloud Drive (iOS)
-   Google Drive, Dropbox (falls installiert)

Im Web wird der Standard-Dateiupload-Dialog des Browsers geöffnet.

### Inline-Button-Layout

Fügen Sie `inline` hinzu, um den Upload als **kreisförmige Icon-Schaltfläche** neben dem Label anstelle eines Dateiauswahldialogs über die volle Breite darzustellen.

```
| type | name | label           | appearance                              |
|------|------|-----------------|-----------------------------------------|
| file | doc  | Dokument hochladen | inline display{right}                   |
| file | doc  | Dokument hochladen | inline display{left, large}             |
| file | doc  | Dokument hochladen | inline display{center, large, <0099FF/>} |
```

**Schaltflächenposition** — `left`, `right` *(Standard)*, `top`, `center`, `bottom`

**Schaltflächengröße** — `small` *(Standard)*, `medium`, `large`

**Schaltflächenfarbe** — Fügen Sie eine Hex-Farbe in `display{}` hinzu, um die Primärfarbe zu überschreiben:

```
inline display{right, large, <FF5500/>}
```

**Steuerung nach der Aufnahme — `results{}`:**

| Appearance              | Effekt                                      |
|-------------------------|---------------------------------------------|
| `results{hide(capture)}` | Blendet die Upload-Schaltfläche nach dem Anhängen einer Datei aus |
| `results{hide(review)}` | Blendet die Überprüfungs-/Vorschau-Schaltfläche nach dem Upload aus |
| `results{hide(filename)}` | Blendet den nach dem Upload angezeigten Dateinamen aus |
| `results{left}`         | Verschiebt das Symbol nach dem Upload nach links |

Beispiel – Upload-Schaltfläche nach dem Anhängen der Datei ausblenden:
```
inline display{right} results{hide(capture)}
```

### Label unterdrücken

```
inline text-nolabel display{center, large}
```

## Best Practices

1.  Verwenden Sie `accept`, um Dateitypen einzuschränken – dies verhindert, dass Interviewer versehentlich falsche Dateien hochladen.
2.  Fügen Sie immer Größen- und Formatierungsrichtlinien in die Spalte `hint` ein.
3.  Für Fotos und Bilder verwenden Sie stattdessen den Typ `image` – dieser bietet eine bessere Komprimierung und konsistente Formatbehandlung.
4.  Planen Sie bei großen Umfragen mit Dateianhängen Ihren Datenspeicher und die Download-Bandbreite entsprechend.
5.  Testen Sie den Dateiauswahldialog auf dem Zielgerätetyp (Android vs. iOS vs. Web) vor der Bereitstellung – der Zugriff auf Cloud-Laufwerke variiert.

## Überlegungen zur Datenverarbeitung

-   Dateien werden in ihrem Originalformat gespeichert; sie werden von rtSurvey nicht konvertiert oder komprimiert.
-   Analysieren Sie Dateien nach dem Download – rtSurvey extrahiert oder indiziert keine Dateiinhalte.
-   Große Dateianhänge erhöhen die zum Herunterladen eines vollständigen Datensatzes erforderliche Zeit erheblich.

## Einschränkungen

-   Dateifragen validieren keine Dateiinhalte – nur die Dateierweiterungsprüfung über `accept` wird auf UI-Ebene erzwungen.
-   Sehr große Dateien (100 MB+) können beim Hochladen in Umgebungen mit geringer Konnektivität eine Zeitüberschreitung verursachen.
-   Offline-Interviewer können Dateien anhängen, diese werden jedoch erst hochgeladen, wenn die Konnektivität wiederhergestellt ist.
-   Einige Gerätekonfigurationen schränken den Zugriff auf bestimmte Speicherorte ein (z. B. MDM-Richtlinien von Unternehmen).

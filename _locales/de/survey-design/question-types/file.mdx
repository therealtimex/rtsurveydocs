title: "Datei"
description: "Dateifragen ermöglichen es den Befragten, Dokumente und andere Dateien als Teil ihrer Umfrageantworten hochzuladen."
---

Der Frage-Typ `file` ermöglicht es den Befragten, **beliebige Dateien** von ihrem Gerät hochzuladen — Dokumente, Tabellenkalkulationen, PDFs oder andere Dateitypen. Im Gegensatz zu `image`, `audio` und `video`, die spezifische Aufnahmewerkzeuge starten, öffnet `file` eine allgemeine Dateiauswahl.

## Grundlegende XLSForm-Spezifikation

| type | name      | label                        |
|------|-----------|------------------------------|
| file | document  | Bitte laden Sie Ihr Dokument hoch |

Weitere Details zum Standard-Dateifrage-Typ finden Sie in der [XLSForm-Spezifikation](https://xlsform.org/en/#question-types).

## Verwendungszwecke

Dateifragen werden häufig verwendet für:

1. Sammeln von unterstützenden Dokumenten (Quittungen, Zertifikate, Verträge, Berichte)
2. Hochladen ausgefüllter Papierformulare, die gescannt wurden
3. Erfassen von Tabellenkalkulationen oder Datenexporten aus anderen Systemen
4. Jeder digitale Dateityp, der nicht durch Bild/Audio/Video abgedeckt ist

## Datenformat

Hochgeladene Dateien werden als binäre Anhänge gespeichert:

- **Format:** Beibehalten im Originalformat (PDF, XLSX, DOCX usw.)
- **Benennung:** `{instanceID}-{fieldname}.{extension}`
- **Speicherung:** Hochgeladen in den Medienordner des Servers zusammen mit der Einreichung
- **Zugriff:** Herunterladbar über die Verwaltungsoberfläche für Einreichungen

## rtSurvey-Erweiterungen

### Akzeptierte Dateitypen

Verwenden Sie die Spalte `parameters`, um einzuschränken, welche Dateitypen ausgewählt werden können:

| type | name | label | parameters |
|------|------|-------|------------|
| file | report | Laden Sie den Inspektionsbericht hoch | `accept=.pdf` |
| file | spreadsheet | Laden Sie die Datendatei hoch | `accept=.xlsx,.csv` |

Der Parameter `accept` verwendet die Standard-Dateierweiterungssyntax (kommagetrennt).

### Anleitung zur Dateigröße

rtSurvey erzwingt kein hartes Limit für die Dateigröße auf Frage-Ebene, aber das Upload-Limit des Servers gilt. Verwenden Sie `hint`, um Erwartungen an den Datenerheber (enumerator) zu kommunizieren:

| type | name | label | hint |
|------|------|-------|------|
| file | receipt | Laden Sie den Zahlungsbeleg hoch | Akzeptiert: PDF oder Bild. Maximale Dateigröße: 5 MB |

### Integration mit dem Dateisystem des Geräts und Cloud-Speicher

Unter Android und iOS öffnet die Frage `file` die native Dateiauswahl des Geräts, die Zugriff beinhalten kann auf:
- Lokaler Gerätespeicher
- SD-Karte (Android)
- iCloud Drive (iOS)
- Google Drive, Dropbox (falls installiert)

Im Web wird der Standard-Datei-Upload-Dialog des Browsers geöffnet.

### Inline-Schaltflächen-Layout (Inline button layout)

Fügen Sie `inline` hinzu, um den Upload als **kreisförmige Symbolschaltfläche** neben dem Label anstelle einer Dateiauswahl in voller Breite darzustellen.

```
| type | name | label           | appearance                              |
|------|------|-----------------|-----------------------------------------|
| file | doc  | Dokument hochladen | inline display{right}                   |
| file | doc  | Dokument hochladen | inline display{left, large}             |
| file | doc  | Dokument hochladen | inline display{center, large, <0099FF/>} |
```

**Schaltflächenposition** — `left`, `right` *(Standard)*, `top`, `center`, `bottom`

**Schaltflächengröße** — `small` *(Standard)*, `medium`, `large`

**Schaltflächenfarbe** — fügen Sie eine Hex-Farbe innerhalb von `display{}` hinzu, um die Primärfarbe zu überschreiben:

```
inline display{right, large, <FF5500/>}
```

**Steuerung nach der Aufnahme — `results{}`:**

| Appearance | Effect |
|---|---|
| `results{hide(capture)}` | Blendet die Upload-Schaltfläche aus, nachdem eine Datei angehängt wurde |
| `results{hide(review)}` | Blendet die Schaltfläche zum Überprüfen/Vorschauen nach dem Upload aus |
| `results{hide(filename)}` | Blendet den nach dem Upload angezeigten Dateinamen aus |
| `results{left}` | Verschiebt das Symbol nach dem Upload nach links |

Beispiel — Upload-Schaltfläche ausblenden, nachdem eine Datei angehängt wurde:
```
inline display{right} results{hide(capture)}
```

### Unterdrücken des Labels (Suppress the label)

```
inline text-nolabel display{center, large}
```

## Best Practices

1. Verwenden Sie `accept`, um Dateitypen einzuschränken — dies verhindert, dass Datenerheber versehentlich falsche Dateien hochladen.
2. Geben Sie immer Hinweise zu Größe und Format in der Spalte `hint` an.
3. Verwenden Sie für Fotos und Bilder stattdessen den Typ `image` — dieser bietet eine bessere Komprimierung und eine konsistente Handhabung von Formaten.
4. Planen Sie bei großen Umfragen mit Dateianhängen Ihren Datenspeicher und Ihre Download-Bandbreite entsprechend.
5. Testen Sie die Dateiauswahl auf dem Zielgerätetyp (Android vs. iOS vs. Web) vor der Bereitstellung — der Zugriff auf Cloud-Laufwerke variiert.

## Überlegungen zur Datenverarbeitung

- Dateien werden in ihrem Originalformat gespeichert; sie werden von rtSurvey nicht konvertiert oder komprimiert.
- Analysieren Sie Dateien nach dem Herunterladen — rtSurvey extrahiert oder indiziert keine Dateiinhalte.
- Große Dateianhänge erhöhen die Zeit zum Herunterladen eines vollständigen Datensatzes erheblich.

## Einschränkungen (Limitations)

- Dateifragen validieren keine Dateiinhalte — nur die Dateierweiterungsprüfung über `accept` wird auf UI-Ebene erzwungen.
- Sehr große Dateien (100 MB+) können beim Upload in Umgebungen mit geringer Konnektivität zu Zeitüberschreitungen führen.
- Offline-Datenerheber können Dateien anhängen, diese werden jedoch erst hochgeladen, wenn die Verbindung wiederhergestellt ist.
- Einige Gerätekonfigurationen beschränken den Zugriff auf bestimmte Speicherorte (z. B. MDM-Richtlinien von Unternehmen).

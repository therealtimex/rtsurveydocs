Der Fragetyp `calculate` führt eine Formel lautlos im Hintergrund aus. Er speichert das Ergebnis in einem benannten Feld, auf das andere Fragen verweisen können – dem Interviewer wird jedoch kein Eingabefeld oder Label angezeigt. Verwenden Sie ihn, um Werte abzuleiten, Zeichenfolgen zu verketten, bedingte Logik auszuführen oder Daten nachzuschlagen, die Sie später im Formular benötigen.

---

## Grundlegende Syntax

| type | name | label | calculation |
|------|------|-------|-------------|
| calculate | total | | `${price} * ${quantity}` |

- **type**: Immer `calculate`.
- **name**: Ein eindeutiger Feldname. Andere Fragen beziehen sich darauf mit `${name}`.
- **label**: Leer lassen – Berechnungsfelder werden dem Interviewer nie angezeigt.
- **calculation**: Die auszuwertende Formel. Unterstützt alle [XLSForm-Funktionen](../operators-and-functions/functions) und Feldreferenzen.

---

## Häufige Muster

### Arithmetik

| type | name | label | calculation |
|------|------|-------|-------------|
| integer | price | Unit price | |
| integer | quantity | Quantity | |
| calculate | total | | `${price} * ${quantity}` |
| note | total_note | Total: `${total}` | |

### Zeichenfolgenverkettung

| type | name | label | calculation |
|------|------|-------|-------------|
| text | first_name | First name | |
| text | last_name | Last name | |
| calculate | full_name | | `concat(${first_name}, ' ', ${last_name})` |

### Bedingter Wert

| type | name | label | calculation |
|------|------|-------|-------------|
| integer | score | Score (0–100) | |
| calculate | grade | | `if(${score} >= 90, 'A', if(${score} >= 75, 'B', if(${score} >= 60, 'C', 'F')))` |

### Alter aus Geburtsdatum

| type | name | label | calculation |
|------|------|-------|-------------|
| date | dob | Date of birth | |
| calculate | age_years | | `int((today() - ${dob}) div 365.25)` |

## Verwendung von `once()`, um den Wert zu sperren

Standardmäßig wird `calculate` neu ausgewertet, wenn sich ein referenziertes Feld ändert. Umschließen Sie die Formel mit `once()`, damit sie nur beim ersten Laden ausgewertet wird und das Ergebnis eingefroren wird:

| type | name | label | calculation |
|------|------|-------|-------------|
| calculate | interview_start | | `once(now())` |

Verwenden Sie `once()` für Zeitstempel, Initialwerte oder alle Fälle, in denen eine Neuberechnung bei Änderungen unerwünscht ist.

## Abrufen von Daten aus externen Quellen

### Aus einer CSV-Datei

```
pulldata('staff.csv', 'department', 'name', ${staff_id})
```

Die vollständige Referenz finden Sie unter [pulldata()](../operators-and-functions/pulldata).

### Aus einer gebündelten SQLite-Datenbank

```
pulldata('rawquery',
  concat(${family_path}, '/locations.db::provinces'),
  'SELECT name FROM provinces WHERE id = ?',
  ${province_id})
```

Details zur Pfadkonstruktion finden Sie unter [Lokale Datenbanksuche](../advanced-features/local-database-search).

### Aus dem App-Kontext

```
pulldata('app-api', 'user.username')
pulldata('app-api', 'family_path')
```

Alle verfügbaren Schlüssel finden Sie unter [App API](../app-api).

## Verwendung von calculate in relevant und constraint

Andere Felder können auf ein `calculate`-Ergebnis wie auf jedes andere Feld verweisen:

| type | name | label | relevant | constraint |
|------|------|-------|----------|------------|
| calculate | bmi | | | `${weight} div (${height} * ${height}) * 10000` |
| note | bmi_warning | BMI is very high — please verify weight and height. | `${bmi} > 40` | |

## Best Practices

1. Geben Sie Berechnungsfeldern aussagekräftige Namen – `total_cost` ist klarer als `calc1` und in Exporten leichter nachzuverfolgen.
2. Teilen Sie komplexe Formeln in mehrere verkettete Berechnungsfelder auf, anstatt einen tief verschachtelten Ausdruck zu verwenden.
3. Verwenden Sie `once()` für Zeitstempel und erste Snapshots, um zu verhindern, dass sich Werte nach der ersten Erfassung ändern.
4. Platzieren Sie `calculate`-Felder vor der ersten Frage, die auf sie verweist – die Auswertungsreihenfolge folgt der Formularreihenfolge.
5. Lassen Sie die Spalte `label` leer. Einige Tools zeigen das Label an; wenn es leer bleibt, werden verwirrende Ausgaben vermieden.

## Einschränkungen

- Berechnungsfelder werden dem Interviewer nie direkt angezeigt – verwenden Sie ein `note`-Feld, um das Ergebnis anzuzeigen.
- Die Spalte `calculation` ist erforderlich; eine `calculate`-Zeile ohne Formel speichert immer eine leere Zeichenfolge.
- Ergebnisse werden bei jeder Formularänderung neu ausgewertet, es sei denn, sie sind in `once()` eingeschlossen – sehr komplexe Formeln in großen Formularen können die Rendering-Leistung auf Low-End-Geräten beeinträchtigen.
- Berechnete Werte werden in der Übermittlung als Zeichenfolgen gespeichert. Verwenden Sie `number()`, `int()` oder `boolean()` für die Typumwandlung, wenn Sie das Ergebnis an arithmetische oder logische Ausdrücke übergeben.

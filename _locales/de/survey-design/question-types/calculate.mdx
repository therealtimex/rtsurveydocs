Der Fragetyp `calculate` führt eine Formel lautlos im Hintergrund aus. Er speichert das Ergebnis in einem benannten Feld, auf das andere Fragen verweisen können – dem Interviewer wird jedoch kein Eingabefeld oder Label angezeigt. Verwenden Sie ihn, um Werte abzuleiten, Zeichenfolgen zu verketten, bedingte Logik auszuführen oder Daten nachzuschlagen, die Sie später im Formular benötigen.

---

## Grundlegende Syntax

| type | name | label | calculation |
|------|------|-------|-------------|
| calculate | total | | `${price} * ${quantity}` |

- **type**: Immer `calculate`.
- **name**: Ein eindeutiger Feldname. Andere Fragen verweisen darauf mit `${name}`.
- **label**: Leer lassen – calculate-Felder werden dem Interviewer nie angezeigt.
- **calculation**: Die zu berechnende Formel. Unterstützt alle [XLSForm-Funktionen](../operators-and-functions/functions) und Feldverweise.

---

## Gängige Muster

### Arithmetik

| type | name | label | calculation |
|------|------|-------|-------------|
| integer | price | Unit price | |
| integer | quantity | Quantity | |
| calculate | total | | `${price} * ${quantity}` |
| note | total_note | Total: `${total}` | |

### Zeichenfolgenverkettung (String Concatenation)

| type | name | label | calculation |
|------|------|-------|-------------|
| text | first_name | First name | |
| text | last_name | Last name | |
| calculate | full_name | | `concat(${first_name}, ' ', ${last_name})` |

### Bedingter Wert

| type | name | label | calculation |
|------|------|-------|-------------|
| integer | score | Score (0–100) | |
| calculate | grade | | `if(${score} >= 90, 'A', if(${score} >= 75, 'B', if(${score} >= 60, 'C', 'F')))` |

### Alter aus Geburtsdatum berechnen

| type | name | label | calculation |
|------|------|-------|-------------|
| date | dob | Date of birth | |
| calculate | age_years | | `int((today() - ${dob}) div 365.25)` |

## `once()` verwenden, um den Wert einzufrieren

Standardmäßig wird ein `calculate`-Feld neu berechnet, wenn sich ein referenziertes Feld ändert. Schließen Sie die Formel in `once()` ein, um sie nur beim ersten Laden auszuwerten und das Ergebnis einzufrieren:

| type | name | label | calculation |
|------|------|-------|-------------|
| calculate | interview_start | | `once(now())` |

Verwenden Sie `once()` für Zeitstempel, Initialwerte oder in allen Fällen, in denen eine Neuberechnung bei Änderungen unerwünscht ist.

## Daten aus externen Quellen abrufen

### Aus einer CSV-Datei

```
pulldata('staff.csv', 'department', 'name', ${staff_id})
```

Siehe [pulldata()](../operators-and-functions/pulldata) für die vollständige Referenz.

### Aus einer gebündelten SQLite-Datenbank

```
pulldata('rawquery',
  concat(${family_path}, '/locations.db::provinces'),
  'SELECT name FROM provinces WHERE id = ?',
  ${province_id})
```

Siehe [Lokale Datenbanksuche](../advanced-features/local-database-search) für Details zur Pfadkonstruktion.

### Aus dem App-Kontext

```
pulldata('app-api', 'user.username')
pulldata('app-api', 'family_path')
```

Siehe [App API](../app-api) für alle verfügbaren Schlüssel.

## Verwendung von calculate in relevant und constraint

Andere Felder können auf ein `calculate`-Ergebnis wie auf jedes andere Feld verweisen:

| type | name | label | relevant | constraint |
|------|------|-------|----------|------------|
| calculate | bmi | | | `${weight} div (${height} * ${height}) * 10000` |
| note | bmi_warning | BMI is very high — please verify weight and height. | `${bmi} > 40` | |

## Best Practices

1. Geben Sie calculate-Feldern aussagekräftige Namen – `total_cost` ist klarer als `calc1` und in Exporten leichter nachzuverfolgen.
2. Zerlegen Sie komplexe Formeln in mehrere verkettete calculate-Felder anstatt in einen einzigen, tief verschachtelten Ausdruck.
3. Verwenden Sie `once()` für Zeitstempel und anfängliche Snapshots, um zu verhindern, dass sich Werte nach der ersten Erfassung ändern.
4. Platzieren Sie `calculate`-Felder vor der ersten Frage, die auf sie verweist – die Auswertungsreihenfolge folgt der Formularreihenfolge.
5. Lassen Sie die Spalte `label` leer. Einige Tools zeigen das Label an; wenn es leer bleibt, werden verwirrende Ausgaben vermieden.

## Einschränkungen

- Calculate-Felder werden dem Interviewer nie direkt angezeigt – verwenden Sie ein `note`-Feld, um das Ergebnis anzuzeigen.
- Die Spalte `calculation` ist erforderlich; eine `calculate`-Zeile ohne Formel speichert immer eine leere Zeichenfolge.
- Ergebnisse werden bei jeder Formularänderung neu berechnet, es sei denn, sie sind in `once()` eingeschlossen – sehr komplexe Formeln in großen Formularen können die Rendering-Leistung auf Low-End-Geräten beeinträchtigen.
- Berechnete Werte werden in der Übermittlung als Zeichenfolgen (Strings) gespeichert. Verwenden Sie `number()`, `int()` oder `boolean()` zur Typumwandlung, wenn Sie das Ergebnis an arithmetische oder logische Ausdrücke übergeben.

---
title: "Geopoint"
description: "Geopoint-Fragen erfassen geografische Koordinaten (Breitengrad, Längengrad, Höhe und Genauigkeit) als Teil der Umfrage."
---

Der Fragetyp `geopoint` erfasst geografische Koordinaten (Breitengrad, Längengrad, Höhe, Genauigkeit) mithilfe des Geräte-GPS. rtSurvey stellt den Picker mit verschiedenen Layout-Modi dar und unterstützt die Automatisierung durch `inputs{}` und `outputs{}` Parameter.

## Grundlegende XLSForm Spezifikation

| type     | name        | label                       |
|----------|-------------|-----------------------------|
| geopoint | location    | Aktuellen Standort aufzeichnen |

Die Standard-Spezifikation finden Sie in der [XLSForm Dokumentation](https://xlsform.org/en/#question-types).

## Datenformat

Gespeichert als vier durch Leerzeichen getrennte Werte:

```
Breitengrad Längengrad Höhe Genauigkeit
```

Beispiel: `13.756331 100.501762 15 8`

---

## Layout-Modi

### Standard – rechteckige Schaltfläche

Eine rechteckige Schaltfläche „START GEOPOINT“ öffnet einen vollständigen Karten-Modal, in dem der Interviewer einen Punkt auswählt. Nach der Erfassung ändert sich das Schaltflächen-Label in „Geo-Punkt anzeigen oder ändern“ und die Koordinaten erscheinen darunter.

Kein Erscheinungsbild-Wert erforderlich.

---

### `display{inline-icon}` – kreisförmige Fadenkreuz-Schaltfläche

Stellt stattdessen eine kreisförmige Icon-Schaltfläche (Fadenkreuz ⊕) dar. Durch Antippen öffnet sich derselbe Karten-Modal.

```
display{inline-icon}
```

**Kombiniert mit Position und Größe:**

```
display{inline-icon, left}           → Schaltfläche links vom Label
display{inline-icon, top}            → Schaltfläche über dem Label
display{inline-icon, bottom}         → Schaltfläche unter dem Label, zentriert
display{inline-icon, large}          → großes Symbol (75px)
display{inline-icon, medium}         → mittleres Symbol (50px)
display{inline-icon, left, large}    → große Schaltfläche links
```

| Größe       | Symbolhöhe/-breite |
|-------------|--------------------|
| *(Standard)* | 25px               |
| `medium`    | 50px               |
| `large`     | 75px               |

---

### `display{thumbnail-square}` – Live-Karten-Vorschaubild

Rendert eine Live-Karten-Vorschau (Leaflet) direkt auf der Frage anstelle einer Schaltfläche. Das Vorschaubild zeigt die aktuelle GPS-Position und den ausgewählten Punkt. Durch Antippen der Erweiterungsschaltfläche wird der vollständige Modal geöffnet.

```
display{thumbnail-square}
```

**Benutzerdefinierte Thumbnail-Größe:**

```
display{thumbnail-square-[BxH]}          → feste Pixel
display{thumbnail-square-[400x200]}      → 400px breit × 200px hoch

display{thumbnail-square-[B%xH%]}        → Prozentsatz der Formularbreite
display{thumbnail-square-[100%x30%]}     → volle Breite × 30% der Formularbreite
```

---

## `display{}` vs `results{}` – vor und nach der Erfassung

`display{}` steuert das Layout **bevor** der Benutzer einen Standort erfasst. `results{}` steuert das Layout **nachdem** ein Wert vorhanden ist. Sie können unterschiedliche Ausrichtungen haben.

```
display{inline-icon, right} results{left}
```

Dies rendert die Schaltfläche vor der Erfassung rechts und verschiebt sie nach der Erfassung eines Punkts nach links.

### `hide(value)` – Anzeige der Koordinaten unterdrücken

Standardmäßig wird der erfasste Lat/Lon/Genauigkeit/Höhe-Text unter der Schaltfläche angezeigt. Blenden Sie ihn aus mit:

```
results{hide(value)}
display{inline-icon} results{hide(value)}
```

## `inputs{}` – GPS-Automatisierung

### Automatische Erfassung beim Laden

Erfasst automatisch die GPS-Position beim Laden des Formulars, ohne dass der Interviewer etwas drücken muss.

```
inputs{auto-take}
```

**Bedingte automatische Erfassung** mithilfe eines XLSForm-Ausdrucks:

```
inputs{autotakeGeo(expression(if(${capture_now} = 'yes', true(), false())))}
```

### Vorab aus einem Textfeld füllen

Füllen Sie den Geopunkt aus einer Frage, die einen Ortsnamen oder eine Adresszeichenfolge enthält. rtSurvey geocodiert die Zeichenfolge über OpenStreetMap Nominatim in Koordinaten um.

```
inputs{question(address_field)}
```

---

## `outputs{}` – Rückwärts-Geocodierung in Text

Nachdem ein Punkt erfasst wurde, füllt ein `text`-Feld automatisch mit der menschenlesbaren Adresse (rückwärts geocodiert aus den Koordinaten).

```
outputs{question(address_field)}
```

Beispiel:

| type     | name      | label               | appearance                          |
|----------|-----------|---------------------|-------------------------------------|
| geopoint | location  | Standort aufzeichnen | `outputs{question(address_text)}`   |
| text     | address_text | Adresse             |                                     |

---

## `nomap` – GPS-Erfassung ohne Karte

Ersetzt den Karten-Modal durch einen einfachen Dialog, der die Standortberechtigung anfordert und Koordinaten aufzeichnet. Es wird keine Karte angezeigt. Nützlich für die reine GPS-Erfassung auf Geräten der unteren Preisklasse oder wenn Kartenkacheln offline nicht verfügbar sind.

```
nomap
```

## Benutzerdefinierter Schaltflächenstil

Verwenden Sie `styleButton()`, um benutzerdefiniertes CSS auf die standardmäßige rechteckige Schaltfläche anzuwenden:

```
styleButton({"backgroundColor":"#1976D2","color":"#ffffff","borderRadius":"8px"})
```

## Anwendungsbeispiele

| type     | name        | label                   | appearance                                  |
|----------|-------------|-------------------------|---------------------------------------------|
| geopoint | field_loc   | Standort des Feldes aufzeichnen | `display{inline-icon, right, large}`        |
| geopoint | site        | Standort                   | `display{thumbnail-square-[100%x30%]}`      |
| geopoint | auto_loc    | Aktuelle Position       | `inputs{auto-take} display{inline-icon} results{hide(value)}` |
| geopoint | mapped_loc  | Standort                   | `display{inline-icon} outputs{question(address)}` |
| geopoint | gps_only    | GPS-Punkt                 | `nomap`                                     |

## Best Practices

1.  Verwenden Sie `inputs{auto-take}` für Interviewer-Verifikationsumfragen, bei denen GPS obligatorisch ist – es entfällt der manuelle Schritt.
2.  Verwenden Sie `display{thumbnail-square}`, wenn Sie möchten, dass der Interviewer den ausgewählten Punkt visuell bestätigt, bevor er fortfährt.
3.  Kombinieren Sie `outputs{question(...)}` mit einem schreibgeschützten `text`-Feld, um dem Interviewer die rückwärts geocodierte Adresse anzuzeigen.
4.  Verwenden Sie `nomap` in Gebieten ohne Internetverbindung, wo Kartenkacheln nicht geladen werden können.
5.  Lassen Sie dem GPS Zeit zur Stabilisierung, bevor Sie aufzeichnen – eine Genauigkeit unter 10 m ist für Feldvermessungen typischerweise ausreichend.

## Einschränkungen

-   `inputs{question(name)}` Geokodierung erfordert Internetzugang – es wird die OpenStreetMap Nominatim API aufgerufen.
-   `outputs{question(name)}` Rückwärts-Geokodierung erfordert ebenfalls Internetzugang.
-   Karten-Vorschaubild (`display{thumbnail-square}`) erfordert Internet zum Laden von Kacheln; Koordinaten werden jedoch offline erfasst.
-   Die GPS-Genauigkeit variiert je nach Gerät und Umgebung – in Innenräumen oder in städtischen Häuserschluchten kann die Genauigkeit > 50 m betragen.
-   Das Sammeln von Standortdaten kann die Akkulaufzeit des Geräts bei langen Umfragen erheblich beeinträchtigen.

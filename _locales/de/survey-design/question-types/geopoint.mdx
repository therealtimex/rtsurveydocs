---
title: "Geopoint"
description: "Geopoint-Fragen erfassen geografische Koordinaten (Breitengrad, Längengrad, Höhe und Genauigkeit) als Teil der Umfrage."
---

Der Fragetyp `geopoint` erfasst geografische Koordinaten (Breitengrad, Längengrad, Höhe, Genauigkeit) mithilfe des Geräte-GPS. rtSurvey rendert den Picker mit verschiedenen Layout-Modi und unterstützt die Automatisierung über die Parameter `inputs{}` und `outputs{}`.

## Grundlegende XLSForm-Spezifikation

| type     | name        | label                       |
|----------|-------------|-----------------------------|
| geopoint | location    | Aktuellen Standort aufzeichnen |

Die Standard-Spezifikation finden Sie in der [XLSForm-Dokumentation](https://xlsform.org/en/#question-types).

## Datenformat

Gespeichert als vier durch Leerzeichen getrennte Werte:

```
latitude longitude altitude accuracy
```

Beispiel: `13.756331 100.501762 15 8`

---

## Layout-Modi

### Standard — rechteckige Schaltfläche

Eine rechteckige Schaltfläche „START GEOPOINT“ öffnet ein vollständiges Karten-Modal, in dem der Enumerator einen Punkt auswählt. Nach der Erfassung ändert sich die Beschriftung der Schaltfläche in „View or change geo point“ und die Koordinaten werden darunter angezeigt.

Kein Appearance-Wert erforderlich.

---

### `display{inline-icon}` — kreisförmige Fadenkreuz-Schaltfläche

Rendert eine kreisförmige Symbolschaltfläche (Fadenkreuz ⊕) anstelle der rechteckigen Schaltfläche. Das Antippen öffnet dasselbe Karten-Modal.

```
display{inline-icon}
```

**Kombiniert mit Position und Größe:**

```
display{inline-icon, left}           → Schaltfläche links vom Label
display{inline-icon, top}            → Schaltfläche über dem Label
display{inline-icon, bottom}         → Schaltfläche unter dem Label, zentriert
display{inline-icon, large}          → großes Symbol (75px)
display{inline-icon, medium}         → mittleres Symbol (50px)
display{inline-icon, left, large}    → große Schaltfläche auf der linken Seite
```

| Size | Icon height/width |
|------|------------------|
| *(default)* | 25px |
| `medium` | 50px |
| `large` | 75px |

---

### `display{thumbnail-square}` — Live-Karten-Thumbnail

Rendert eine Live-Kartenvorschau (Leaflet) direkt in der Frage anstelle einer Schaltfläche. Das Thumbnail zeigt die aktuelle GPS-Position und den ausgewählten Punkt an. Das Antippen der Schaltfläche zum Erweitern öffnet das vollständige Modal.

```
display{thumbnail-square}
```

**Benutzerdefinierte Thumbnail-Größe:**

```
display{thumbnail-square-[WxH]}          → feste Pixel
display{thumbnail-square-[400x200]}      → 400px breit × 200px hoch

display{thumbnail-square-[W%xH%]}        → Prozentsatz der Formularbreite
display{thumbnail-square-[100%x30%]}     → volle Breite × 30 % der Formularbreite
```

---

## `display{}` vs. `results{}` — vor und nach der Erfassung

`display{}` steuert das Layout, **bevor** der Benutzer einen Standort erfasst. `results{}` steuert das Layout, **nachdem** ein Wert vorhanden ist. Sie können unterschiedliche Ausrichtungen haben.

```
display{inline-icon, right} results{left}
```

Dies rendert die Schaltfläche vor der Erfassung rechts und verschiebt sie nach der Aufzeichnung eines Punktes nach links.

### `hide(value)` — Koordinatenanzeige unterdrücken

Standardmäßig wird der erfasste Text für Breitengrad/Längengrad/Genauigkeit/Höhe unter der Schaltfläche angezeigt. Verbergen Sie ihn mit:

```
results{hide(value)}
display{inline-icon} results{hide(value)}
```

## `inputs{}` — GPS-Automatisierung

### Automatische Erfassung beim Laden

Zeichnet die GPS-Position automatisch auf, wenn das Formular geladen wird, ohne dass der Enumerator etwas drücken muss.

```
inputs{auto-take}
```

**Bedingte automatische Erfassung** mithilfe eines XLSForm-Ausdrucks:

```
inputs{autotakeGeo(expression(if(${capture_now} = 'yes', true(), false())))}
```

### Vorbefüllung aus einem Textfeld

Füllen Sie den Geopoint aus einer Frage aus, die einen Ortsnamen oder eine Adresszeichenfolge enthält. rtSurvey geocodiert die Zeichenfolge über OpenStreetMap Nominatim umgekehrt in Koordinaten.

```
inputs{question(address_field)}
```

---

## `outputs{}` — Reverse-Geocodierung in Text

Nachdem ein Punkt erfasst wurde, wird automatisch eine `text`-Frage mit der für Menschen lesbaren Adresse (umgekehrt geocodiert aus den Koordinaten) ausgefüllt.

```
outputs{question(address_field)}
```

Beispiel:

| type | name | label | appearance |
|------|------|-------|------------|
| geopoint | location | Standort aufzeichnen | `outputs{question(address_text)}` |
| text | address_text | Adresse | |

---

## `nomap` — GPS-Erfassung ohne Karte

Ersetzt das Karten-Modal durch einen einfachen Dialog, der die Standortberechtigung anfordert und Koordinaten aufzeichnet. Es wird keine Karte angezeigt. Nützlich für die reine GPS-Erfassung auf Low-End-Geräten oder wenn Kartenkacheln offline nicht verfügbar sind.

```
nomap
```

## Best Practices

1. Verwenden Sie `inputs{auto-take}` für Verifizierungsumfragen durch Enumeratoren, bei denen GPS obligatorisch ist — dies macht den manuellen Schritt überflüssig.
2. Verwenden Sie `display{thumbnail-square}`, wenn Sie möchten, dass der Enumerator den ausgewählten Punkt visuell bestätigt, bevor er fortfährt.
3. Koppeln Sie `outputs{question(...)}` mit einem schreibgeschützten `text`-Feld, um dem Enumerator die umgekehrt geocodierte Adresse anzuzeigen.
4. Verwenden Sie `nomap` in Gebieten ohne Internetverbindung, in denen Kartenkacheln nicht geladen werden können.
5. Lassen Sie der GPS-Zeit Zeit, sich zu stabilisieren, bevor Sie aufzeichnen — eine Genauigkeit von weniger als 10 m ist für Feldumfragen in der Regel ausreichend.

## Einschränkungen

- Das Geocoding von `inputs{question(name)}` erfordert Internetzugang — es ruft die OpenStreetMap Nominatim API auf.
- Die Reverse-Geocodierung von `outputs{question(name)}` erfordert ebenfalls Internetzugang.
- Das Karten-Thumbnail (`display{thumbnail-square}`) erfordert Internet zum Laden der Kacheln; Koordinaten werden weiterhin offline erfasst.
- Die GPS-Genauigkeit variiert je nach Gerät und Umgebung — Bedingungen in Innenräumen oder in Schluchten von Städten können eine Genauigkeit von > 50 m zur Folge haben.
- Das Sammeln von Standortdaten kann die Akkulaufzeit des Geräts während langer Umfragen erheblich beeinträchtigen.

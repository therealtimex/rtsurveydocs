title: "Datetime, date, time"
description: "Datetime-Fragen ermöglichen es Befragten, Datum und Uhrzeit in einem einzigen Feld einzugeben."
---

Die Fragetypen `date`, `time` und `datetime` erfassen Datums- und/oder Zeitwerte. rtSurvey stellt sie mit verschiedenen Layout-Modi dar, die durch die Spalte `appearance` gesteuert werden.

## Grundlegende XLSForm Spezifikation

| type     | name           | label                     |
|----------|----------------|---------------------------|
| date     | birth_date     | Geburtsdatum              |
| time     | start_time     | Wann begann es?           |
| datetime | event_datetime | Wann fand das Ereignis statt? |

Die Standard-Spezifikation finden Sie in der [XLSForm Dokumentation](https://xlsform.org/en/#question-types).

## Layout-Modi

### Standard – immer geöffneter Kalender

Kein `appearance`-Wert erforderlich. Der Kalender (und die Uhr für `time`/`datetime`) wird direkt auf der Seite angezeigt – immer sichtbar, keine Schaltfläche erforderlich.

| type | name       | label         | appearance |
|------|------------|---------------|------------|
| date | start_date | Besuchsdatum  |            |

---

### `inline` – kreisförmige Schaltfläche → Modal

Eine kreisförmige Icon-Schaltfläche (Kalender oder Uhr) schwebt neben dem Fragen-Label. Durch Antippen öffnet sich ein Modal mit dem Picker. Nach der Auswahl erscheint der gewählte Wert als Text neben dem Label.

-   Schaltflächenhintergrund: primäre Designfarbe (überschreibbar)
-   Schaltflächenform: voller Kreis (`border-radius: 50%`)

```
| type | name       | label         | appearance |
|------|------------|---------------|------------|
| date | start_date | Besuchsdatum  | inline     |
```

---

### `inline-onlyresult` – Schaltfläche verschwindet nach Auswahl

Gleich wie `inline`, aber die Schaltfläche blendet sich aus, sobald ein Wert ausgewählt wurde. Nützlich, wenn Sie das Datum nach der Auswahl nur sichtbar haben möchten, ohne ein persistentes Icon.

```
inline-onlyresult
```

---

### `inline-1line` – Reihe von Drehfeldern

Stellt einzelne Drehfelder (▲ Wert ▼) in einer einzigen horizontalen Reihe dar – eine Spalte pro Komponente. Für `date`: Monat / Tag / Jahr. Für `datetime`: Monat / Tag / Jahr / Stunden / Minuten. Für `time`: Stunden / Minuten.

Kein Modal oder Kalender-Popup – der Benutzer scrollt jedes Drehfeld unabhängig.

```
inline-1line
```

**Zeigen Sie nur bestimmte Komponenten an**, indem Sie die Komponentennamen hinzufügen:

```
inline-1line month year      → verbirgt das Tages-Drehfeld
inline-1line year            → zeigt nur das Jahr
```

**Begrenzen Sie den Jahresbereich:**

```
inline-1line y_range(2000-2030)
```

---

### `box` – Texteingabe

Stellt ein einfaches Texteingabefeld dar. Der Benutzer gibt das Datum direkt im in der Erscheinung definierten Format ein.

```
box(%d/%m/%Y)       → TT/MM/JJJJ
box(%Y-%m-%d)       → JJJJ-MM-TT
```

---

### `month-year` – nur Monat und Jahr

Standard XLSForm-Erscheinung. Der Picker startet in der Jahresansicht; der Benutzer wählt Monat und Jahr, aber keinen bestimmten Tag.

```
month-year
```

---

### `year` – nur Jahr

Standard XLSForm-Erscheinung. Der Picker startet in der Dekadenansicht; nur das Jahr ist wählbar.

```
year
```

---

## Benutzerdefiniertes Anzeigeformat

Fügen Sie `-[format]` an jede `inline`-Erscheinung an, um zu steuern, wie der ausgewählte Wert als Text angezeigt wird. Verwendet strftime-ähnliche Token.

| Token | Bedeutung               | Beispiel |
|-------|-------------------------|----------|
| `%d`  | Tag (mit führender Null) | 07       |
| `%e`  | Tag (ohne führende Null) | 7        |
| `%m`  | Monatsnummer            | 04       |
| `%n`  | Monatsnummer (ohne führende Null) | 4 |
| `%b`  | Monatsabkürzung         | Apr      |
| `%Y`  | 4-stellige Jahreszahl   | 2026     |
| `%y`  | 2-stellige Jahreszahl   | 26       |
| `%H`  | Stunde (24h)            | 14       |
| `%h`  | Stunde (ohne führende Null) | 14     |
| `%M`  | Minute                  | 05       |
| `%S`  | Sekunde                 | 00       |
| `%a`  | Abkürzung des Wochentags | Mi       |

**Beispiele:**

```
inline-[%d/%m/%Y]            → 07/04/2026
inline-[%d %b %Y]            → 07 Apr 2026
inline-1line-[%Y-%m-%d]      → Drehfeld-Eingabe, formatiertes Display
inline-[%d/%m/%Y %H:%M]      → 07/04/2026 14:30
```

## Farbanpassung

Überschreiben Sie die Farbe der Icon-Schaltfläche mit `colors()`:

```
inline colors("0099FF")                   → Schaltflächenhintergrund #0099FF
inline colors("0099FF","FFFFFF")          → Hintergrund #0099FF, Icon-Farbe #FFFFFF
inline-1line colors("0000FF","FFFF00")    → Akzentfarben des Drehfelds
inline-onlyresult colors("E53935")        → rote Schaltfläche
```

---

## Schaltflächenposition mit `display{}`

Der `display{}`-Modifikator steuert, wo die Icon-Schaltfläche relativ zum Fragen-Label erscheint. Gilt für `inline` und `inline-onlyresult`.

```
display{<Ausrichtung>, <Größe>, <Farbe>}
```

| Parameter | Werte                               | Standard |
|-----------|-------------------------------------|----------|
| Ausrichtung | `left`, `right`, `top`, `center`, `bottom` | `right` |
| Größe     | `small`, `medium`, `large`          | `small`  |
| Farbe     | Hex z.B. `#FF5500`                  | primäre Themenfarbe |

**Ausrichtungsverhalten:**

| Wert          | Layout                                     |
|---------------|--------------------------------------------|
| `right`       | Schaltfläche rechts neben dem Label        |
| `left`        | Schaltfläche links neben dem Label         |
| `top`         | Schaltfläche über dem Label, mittig, volle Breite |
| `center` / `bottom` | Schaltfläche unter dem Label, mittig, volle Breite |

**Beispiele:**

```
inline display{left}
inline display{center, large}
inline display{right, medium, #E53935}
inline-onlyresult display{bottom, large, #0099FF}
```

## Datumsbereichs-Beschränkung

Verwenden Sie `inputs{range[...]}`, um die auswählbaren Daten zu beschränken.

```
inputs{range[dateGt(2024-01-01), dateLt(2024-12-31)]}
```

Parameter innerhalb von `range[...]`:

| Parameter              | Beschreibung                                 |
|------------------------|----------------------------------------------|
| `dateGt(JJJJ-MM-TT)`   | Minimal wählbares Datum (größer oder gleich) |
| `dateLt(JJJJ-MM-TT)`   | Maximal wählbares Datum (kleiner oder gleich) |
| `indayTimeGt(HH:MM:SS)` | Minimalzeit innerhalb eines Tages (nur Datum und Uhrzeit) |
| `indayTimeLt(HH:MM:SS)` | Maximalzeit innerhalb eines Tages (nur Datum und Uhrzeit) |

Es können mehrere Bereiche definiert werden – ein Datum ist wählbar, wenn es in **einem beliebigen** der Bereiche liegt.

## Label unterdrücken

Fügen Sie `text-nolabel` hinzu, um das Fragen-Label auszublenden. Die Schaltfläche wird dann alleine gerendert.

```
inline text-nolabel display{center, large}
```

## Layout-Zusammenfassung

| Erscheinung        | Gerendertes Widget           | Farbe anpassbar |
|-------------------|-----------------------------|-----------------|
| *(keine)*         | Immer geöffneter Kalender   | Nein            |
| `inline`          | Kreisförmige Schaltfläche → Modal-Kalender | Ja              |
| `inline-onlyresult` | Kreisförmige Schaltfläche → Modal, blendet sich nach Auswahl aus | Ja |
| `inline-1line`    | Reihe von Drehfeldern       | Ja              |
| `box(%format%)`   | Texteingabefeld             | Nein            |
| `month-year`      | Monats-/Jahres-Picker       | Nein            |
| `year`            | Nur-Jahr-Picker             | Nein            |

```
| type     | name        | label              | appearance                              |
|----------|-------------|--------------------|-----------------------------------------|
| date     | visit_date  | Besuchsdatum       | inline display{right} -[%d/%m/%Y]       |

| time     | start_time  | Startzeit          | inline-1line                            |
| datetime | event_time  | Ereignisdatum & -zeit | inline display{center, large} -[%d/%m/%Y %H:%M] |
| date     | report_date | Berichtsdatum      | box(%d/%m/%Y)                           |
```

## Best Practices

1.  Verwenden Sie `inline` für kompakte Formulare – es spart vertikalen Platz im Vergleich zum immer geöffneten Kalender.
2.  Verwenden Sie `inline-1line`, wenn die Befragten einzelne Datumskomponenten anpassen müssen (z. B. Geburtsjahr).
3.  Verwenden Sie `box()` nur, wenn Sie dem Interviewer vertrauen, dass er Daten korrekt eingibt – es wird keine Validierungs-UI angezeigt.
4.  Verwenden Sie `display{center, large}`, um die Schaltfläche auf mobilen Bildschirmen prominenter zu machen.
5.  Geben Sie immer `-[format]` an, wenn die Standardanzeige `JJJJ-MM-TT` lokale Benutzer verwirren würde.
6.  Berücksichtigen Sie Zeitzonen bei der Erfassung von Datums-/Zeitdaten in verschiedenen Regionen.

## Einschränkungen

-   `inline-1line` verwendet immer das heutige Datum als Standard, wenn kein Wert vorhanden ist – verwenden Sie die Spalte `default`, um ein bestimmtes Datum vorab auszufüllen.
-   Das `box()`-Format steuert nur die Anzeige; der gespeicherte Wert ist immer ISO 8601.
-   Die Datumsbereichs-Beschränkung (`inputs{range[...]}`) funktioniert nicht mit dem `box`-Layout.
-   Zeitzonenunterschiede können die Datenanalyse erschweren, wenn sie nicht richtig berücksichtigt werden.

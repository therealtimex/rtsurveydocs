---
title: "Bereich"
description: "Bereichsfragen ermöglichen es den Befragten, eine Zahl auszuwählen, indem sie einen Schieberegler zwischen einem definierten Minimum und Maximum bewegen."
---

Der Fragetyp `range` ermöglicht es den Befragten, eine Zahl innerhalb eines definierten Minimums und Maximums auszuwählen. Im Webformular von rtSurvey wird dies als standardmäßige **Zahleneingabe** dargestellt – der Enumerator gibt einen Wert direkt ein. Die Parameter `start`, `end` und `step` definieren den gültigen Bereich und werden als Einschränkungen (Constraints) erzwungen.

## Grundlegende XLSForm-Spezifikation

| type | name | label | parameters |
|------|------|-------|------------|
| range | satisfaction | Wie zufrieden sind Sie mit dem Service? | start=1 end=5 step=1 |

Die Spalte `parameters` definiert die Grenzen des Schiebereglers und die Schrittweite:

| Parameter | Beschreibung | Standardwert |
|-----------|-------------|---------|
| `start` | Minimalwert (inklusive) | 0 |
| `end` | Maximalwert (inklusive) | 10 |
| `step` | Inkrement zwischen gültigen Werten | 1 |

Weitere Einzelheiten zum standardmäßigen Fragetyp „Range“ finden Sie in der [XLSForm-Spezifikation](https://xlsform.org/en/#question-types).

## Anwendungen

Bereichsfragen werden häufig verwendet für:

1. Zufriedenheits- oder Bewertungsskalen (z. B. 1–5 oder 0–10)
2. Numerische Skalen im Likert-Stil
3. Sammeln von Messwerten, bei denen nur diskrete Werte gültig sind
4. Altersgruppen oder Punktebereiche, bei denen ein Schieberegler die Benutzerfreundlichkeit gegenüber einem Textfeld verbessert

## Beispielhafte Verwendung

### Grundlegende Bewertungsskala

| type | name | label | parameters |
|------|------|-------|------------|
| range | overall_rating | Gesamtbewertung (0–10) | start=0 end=10 step=1 |

### Dezimalschritt

| type | name | label | parameters |
|------|------|-------|------------|
| range | weight_kg | Gewicht (kg) | start=0 end=200 step=0.5 |

### Verwendung des Wertes in einer Berechnung

| type | name | label | parameters | calculation |
|------|------|-------|------------|-------------|
| range | score | Testergebnis (0–100) | start=0 end=100 step=5 | |
| calculate | grade | | | if(`${score}` >= 90, 'A', if(`${score}` >= 80, 'B', if(`${score}` >= 70, 'C', 'F'))) |
| note | grade_note | Deine Note ist: `${grade}` | | |

## Best Practices

1. Legen Sie immer aussagekräftige Werte für `start`, `end` und `step` fest – verlassen Sie sich nicht auf Standardwerte.
2. Beschriften Sie die Enden Ihrer Skala in der Spalte `hint` (z. B. `hint: 0 = Sehr unzufrieden, 10 = Sehr zufrieden`), um den Befragten Kontext zu geben.
3. Verwenden Sie für 5-stufige Likert-Skalen `start=1 end=5 step=1` anstelle von 0–4, da Befragte erwarten, dass „1“ den niedrigsten Wert bedeutet.
4. Verwenden Sie `range` anstelle von `integer` + Einschränkung, wenn die begrenzte Natur der Eingabe Teil des Fragendesigns ist (der Schieberegler kommuniziert die Skala visuell).

## Einschränkungen

- Im Webformular von rtSurvey gibt es kein Schieberegler-Widget – die Werteingabe erfolgt über ein einfaches Zahlenfeld. Verwenden Sie für ein visuelles Schieberegler-Erlebnis einen mobilen Client, der das Range-Widget unterstützt.
- Für sehr große Bereiche (z. B. 0–10000) ist eine einfache `integer`-Frage mit einer Einschränkung ebenso effektiv und benutzerfreundlicher.
- Feine Schrittwerte (z. B. `step=0.1`) funktionieren als Einschränkungen, spielen aber im Webformular mangels Schieberegler-Präzision keine Rolle.

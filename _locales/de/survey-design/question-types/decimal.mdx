---
title: "Decimal"
description: "Frage-Typ für die Eingabe von Dezimalzahlen in rtSurvey"
---

Der Frage-Typ `decimal` erfasst Zahlen, die einen Bruchteil enthalten können (z. B. `3.14`, `72.5`). Er löst auf Mobilgeräten eine numerische Tastatur aus und unterstützt dieselben Darstellungsoptionen wie der Typ `text` für Layout und Formatierung.

## Grundlegende XLSForm-Spezifikation

| type | name | label |
|------|------|-------|
| decimal | weight_kg | Gewicht (kg) |
| decimal | height_m | Größe (m) |
| decimal | temperature | Körpertemperatur (°C) |

Die Standard-Spezifikation finden Sie in der [XLSForm-Dokumentation](https://xlsform.org/en/#question-types).

---

## Darstellungsoptionen (Appearance options)

### `number-hspinner` — Horizontaler Spinner

Ersetzt die Eingabe durch einen horizontalen **− Wert +** Spinner. Tippen auf Minus/Plus passt den Wert um den konfigurierten Schritt (step) an.

```
number-hspinner
```

Der angezeigte Wert wird mit einer Dezimalstelle formatiert (z. B. `3.0`, `72.5`). Der Standardschritt ist `1`; verwenden Sie `hspinner()`, um einen Dezimalschritt festzulegen.

**Anpassen der Schaltflächenform und des Schritts** mit `hspinner()`:

```
number-hspinner hspinner('left-small-square','right-small-square','0.1')
```

Parameter: Form der linken Schaltfläche, Form der rechten Schaltfläche, Schrittwert. Verwenden Sie einen Dezimalschritt wie `0.5` oder `0.1` für eine feingliedrige Steuerung.

**Benutzerdefinierte Farben** mit `colors()`:

```
number-hspinner colors(0099FF,FFFFFF,FF5500,FFFFFF)
```

Vier Werte in der Reihenfolge: Hintergrund linke Schaltfläche, Symbol linke Schaltfläche, Hintergrund rechte Schaltfläche, Symbol rechte Schaltfläche.

---

### `thousandsep` — Tausendertrennzeichen

Formatiert die angezeigte Zahl mit Tausender-Gruppierung (z. B. `1,234.56`). Die Rohzahl wird ohne Kommas gespeichert. Der Eingabetyp wird auf `"text"` umgeschaltet, um die formatierte Anzeige zu ermöglichen.

```
thousandsep
```

---

### `digisep(n, "sep")` — Benutzerdefinierte Zifferngruppierung

Gruppiert Ziffern des Ganzzahlteils in Blöcke von `n`, getrennt durch ein benutzerdefiniertes Trennzeichen.

```
digisep(3," ")      → 1 234 567.89
```

Der Eingabetyp wird auf `"text"` umgeschaltet, wenn diese Darstellung aktiv ist.

---

### `textonly` — Text-Tastatur erzwingen

Erzwingt `type="text"` für das Eingabeelement. Verhindert Eigenheiten der Browser-Zahleneingabe (Ausblenden von Nachkommanullen, Desktop-Pfeile), während weiterhin Dezimalwerte akzeptiert werden.

```
textonly
```

---

### `floating_hint` — Hinweis schwebt als Label

Der `hint`-Text wird innerhalb der Eingabe als Platzhalter angezeigt. Wenn der Benutzer mit der Eingabe beginnt, schwebt er als Label über dem Feld.

```
floating_hint
```

---

### `embed` — Hinweis innerhalb der Eingabebegrenzung

Ähnlich wie `floating_hint` — der Hinweis befindet sich innerhalb der Eingabebegrenzung, wenn das Feld leer ist. Er schwebt nicht, wenn der Benutzer tippt.

```
embed
```

---

### `textpopup` — Modaler Dialog zur Eingabe

Tippen auf das Feld öffnet einen modalen Dialog mit einer größeren Eingabe. Nützlich auf kleinen Bildschirmen.

```
textpopup
```

---

### `charcount` — Live-Zeichenzähler

Zeigt einen Live-Zeichenzähler `(n)` unter der Eingabe an, der beim Tippen aktualisiert wird.

```
charcount
```

---

### `prefix(expr)` — Präfix voranstellen

Stellt der angezeigten Zahl eine statische oder berechnete Zeichenfolge voran. Der gespeicherte Wert enthält das Präfix nicht.

```
prefix('USD ')          → zeigt "USD 72.50", speichert "72.50"
prefix(${currency})     → dynamisches Präfix aus einem anderen Feld
```

---

### `align_answer` — Ausrichtung des Eingabetextes

Steuert die horizontale Ausrichtung des eingegebenen Wertes innerhalb der Eingabe.

```
align_answer = left
align_answer = right
align_answer = center
```

---

### `inputs{qrscan}` — QR- / Barcode-Scan in das Feld

Fügt eine Schaltfläche zum Scannen von QR-Codes neben der Eingabe hinzu. Öffnet den Kamera-Scanner und füllt das Feld mit dem gescannten Wert.

```
inputs{qrscan}
```

## Einschränkungen und Validierung

| type | name | label | constraint | constraint_message |
|------|------|-------|------------|-------------------|
| decimal | weight | Gewicht (kg) | `. > 0 and . <= 500` | Geben Sie einen Wert zwischen 0 und 500 ein |
| decimal | height | Größe (m) | `. > 0 and . <= 3` | Geben Sie einen Wert zwischen 0 und 3 ein |
| decimal | temp | Temperatur (°C) | `. >= 35 and . <= 42` | Normale Temperatur: 35°C–42°C |
| decimal | percentage | Prozentsatz | `. >= 0 and . <= 100` | Geben Sie einen Wert zwischen 0 und 100 ein |

## Best Practices

1. Verwenden Sie `number-hspinner hspinner(..., '0.1')` für Messungen, die eine Dezimalstelle Genauigkeit erfordern — der Spinner formatiert automatisch auf eine Dezimalstelle, was die Werte konsistent hält.
2. Verwenden Sie `textonly`, wenn Browser unerwünschte Spinner-Steuerelemente hinzufügen oder Nachkommanullen abschneiden (z. B. `3.0` als `3` angezeigt).
3. Verwenden Sie `thousandsep` für große Finanzwerte, damit die Befragten überprüfen können, ob sie die richtige Größenordnung eingegeben haben.
4. Setzen Sie Bereichsbeschränkungen (constraints) durch, anstatt sich nur auf den Tastaturtyp des Mobilgeräts zu verlassen.

## Einschränkungen (Limitations)

- Der Spinner zeigt immer eine Dezimalstelle an — wenn Sie mehr Präzision im angezeigten Wert benötigen, verwenden Sie stattdessen die einfache Eingabe.
- `thousandsep` und `digisep()` speichern die Rohzahl — verwenden Sie den formatierten Anzeigewert nicht in Berechnungen.

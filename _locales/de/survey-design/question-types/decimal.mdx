Der Fragetyp `decimal` erfasst Zahlen, die einen Bruchteil enthalten können (z. B. `3.14`, `72.5`). Er öffnet eine numerische Tastatur auf Mobilgeräten und unterstützt die gleichen Erscheinungsbildoptionen wie der `text`-Typ für Layout und Formatierung.

## Grundlegende XLSForm Spezifikation

| type    | name        | label                     |
|---------|-------------|---------------------------|
| decimal | weight_kg   | Gewicht (kg)              |
| decimal | height_m    | Größe (m)                 |
| decimal | temperature | Körpertemperatur (°C)     |

Die Standard-Spezifikation finden Sie in der [XLSForm Dokumentation](https://xlsform.org/en/#question-types).

---

## Erscheinungsbildoptionen

### `number-hspinner` – horizontaler Spinner

Ersetzt die Eingabe durch einen horizontalen **− Wert +** Spinner. Durch Tippen auf Minus/Plus wird der Wert um den konfigurierten Schritt angepasst.

```
number-hspinner
```

Der angezeigte Wert wird mit einer Dezimalstelle formatiert (z. B. `3.0`, `72.5`). Der Standardschritt ist `1`; verwenden Sie `hspinner()`, um einen Dezimalschritt einzustellen.

**Schaltflächenform und -schritt anpassen** mit `hspinner()`:

```
number-hspinner hspinner('left-small-square','right-small-square','0.1')
```

Parameter: Form der linken Schaltfläche, Form der rechten Schaltfläche, Schrittwert. Verwenden Sie einen Dezimalschritt wie `0.5` oder `0.1` für eine präzise Steuerung.

**Benutzerdefinierte Farben** mit `colors()`:

```
number-hspinner colors(0099FF,FFFFFF,FF5500,FFFFFF)
```

Vier Werte in der Reihenfolge: Hintergrund der linken Schaltfläche, Icon der linken Schaltfläche, Hintergrund der rechten Schaltfläche, Icon der rechten Schaltfläche.

---

### `thousandsep` – Tausender-Trennzeichen

Formatiert die angezeigte Zahl mit Komma-Gruppierung (z. B. `1,234.56`). Die Rohzahl wird ohne Kommas gespeichert. Der Eingabetyp wird auf `"text"` umgestellt, um die formatierte Anzeige zu ermöglichen.

```
thousandsep
```

---

### `digisep(n, "sep")` – benutzerdefinierte Zifferngruppierung

Gruppiert ganzzahlige Ziffern in Blöcke von `n`, getrennt durch ein benutzerdefiniertes Trennzeichen.

```
digisep(3," ")      → 1 234 567.89
```

Der Eingabetyp wird auf `"text"` umgestellt, wenn dieses Erscheinungsbild aktiv ist.

---

### `textonly` – Texttastatur erzwingen

Erzwingt `type="text"` für das Eingabeelement. Verhindert Browser-Probleme bei der Zahleneingabe (Ausblenden von Nullen am Ende, Desktop-Drehpfeile), während Dezimalwerte weiterhin akzeptiert werden.

```
textonly
```

---

### `floating_hint` – Hinweis schwebt als Label

Der `hint`-Text wird als Platzhalter im Eingabefeld gerendert. Wenn der Benutzer mit der Eingabe beginnt, schwebt er über dem Feld als Label.

```
floating_hint
```

---

### `embed` – Hinweis innerhalb der Eingabebegrenzung

Ähnlich wie `floating_hint` – der Hinweis befindet sich im leeren Zustand innerhalb der Eingabebegrenzung. Er schwebt nicht, wenn der Benutzer tippt.

```
embed
```

---

### `textpopup` – Modaldialog-Eingabe

Durch Tippen auf das Feld öffnet sich ein Modaldialog mit einer größeren Eingabe. Nützlich auf kleinen Bildschirmen.

```
textpopup
```

---

### `charcount` – Live-Zeichenzähler

Zeigt einen Live-Zeichenzähler `(n)` unter der Eingabe an, der aktualisiert wird, während der Benutzer tippt.

```
charcount
```

---

### `prefix(expr)` – Präfix voranstellen

Stellt einen statischen oder berechneten String dem angezeigten Wert voran. Der gespeicherte Wert enthält das Präfix nicht.

```
prefix('USD ')          → zeigt "USD 72.50", speichert "72.50"
prefix(${currency})     → dynamisches Präfix aus einem anderen Feld
```

---

### `align_answer` – Textausrichtung der Eingabe

Steuert die horizontale Ausrichtung des eingegebenen Wertes im Eingabefeld.

```
align_answer = left
align_answer = right
align_answer = center
```

---

### `inputs{qrscan}` – QR-/Barcode-Scan in das Feld

Fügt eine QR-Code-Scan-Schaltfläche neben der Eingabe hinzu. Öffnet den Kamerascaner und füllt das Feld mit dem gescannten Wert.

```
inputs{qrscan}
```

## Einschränkungen und Validierung

| type    | name       | label                     | constraint               | constraint_message             |
|---------|------------|---------------------------|--------------------------|--------------------------------|
| decimal | weight     | Gewicht (kg)              | `. > 0 and . <= 500`     | Geben Sie einen Wert zwischen 0 und 500 ein |
| decimal | height     | Größe (m)                 | `. > 0 and . <= 3`       | Geben Sie einen Wert zwischen 0 und 3 ein |
| decimal | temp       | Temperatur (°C)           | `. >= 35 and . <= 42`    | Normaltemperatur: 35°C–42°C    |
| decimal | percentage | Prozentsatz               | `. >= 0 and . <= 100`    | Geben Sie einen Wert zwischen 0 und 100 ein |

## Best Practices

1.  Verwenden Sie `number-hspinner hspinner(..., '0.1')` für Messungen, die eine Dezimalstelle Genauigkeit erfordern – der Spinner formatiert automatisch auf eine Dezimalstelle und hält die Werte konsistent.
2.  Verwenden Sie `textonly`, wenn Browser unerwünschte Drehfelder hinzufügen oder Nullen am Ende abschneiden (z. B. `3.0` als `3` angezeigt wird).
3.  Verwenden Sie `thousandsep` für große Finanzwerte, damit die Befragten überprüfen können, ob sie die richtige Größenordnung eingegeben haben.
4.  Erzwingen Sie Bereichseinschränkungen, anstatt sich allein auf den mobilen Tastaturtyp zu verlassen.

## Einschränkungen

-   Der Spinner zeigt immer eine Dezimalstelle an – wenn Sie mehr Präzision im angezeigten Wert benötigen, verwenden Sie stattdessen die normale Eingabe.
-   `thousandsep` und `digisep()` speichern die Rohzahl – lesen Sie nicht den formatierten Anzeigewert in Berechnungen.

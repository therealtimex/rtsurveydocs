rtSurvey bietet eine robuste mehrsprachige Unterstützung, die es Ihnen ermöglicht, Umfragen in mehreren Sprachen zu erstellen. Diese Funktion ist entscheidend für die Durchführung von Forschung in verschiedenen sprachlichen Populationen oder in mehrsprachigen Umgebungen.

## Einrichten mehrsprachiger Umfragen

Um eine mehrsprachige Umfrage in rtSurvey zu erstellen, müssen Sie sprachspezifische Spalten zu Ihrer XLSForm hinzufügen. So geht's:

1. **Übersetzungen von Beschriftungen (Labels)**: Fügen Sie Spalten für jede Sprache im Format `label::Language (code)` hinzu.
2. **Übersetzungen von Hinweisen (Hints)**: Verwenden Sie `hint::Language (code)` für die Übersetzung von Hinweisen.
3. **Übersetzungen von Mediendateien**: Verwenden Sie für sprachspezifische Medien `media::Language (code)`.

Beispiel:

```
| type    | name | label::English (en) | label::German (de) | hint::English (en) | hint::German (de) |
|---------|------|---------------------|--------------------|---------------------|-------------------|
| integer | age  | How old are you?    | Wie alt sind Sie?  | Enter your age      | Geben Sie Ihr Alter ein |
```

## Sprachcodes

Es wird empfohlen, die offiziellen 2-Zeichen-Sprachcodes (Subtags) nach dem Sprachnamen zu verwenden. Dies erleichtert den Abgleich der Formularsprache mit der Sprache der Benutzeroberfläche. Die offiziellen Codes finden Sie [hier](https://www.iana.org/assignments/language-subtag-registry/language-subtag-registry).

## Festlegen einer Standardsprache

Um eine Standardsprache für die Datenerfassung festzulegen, verwenden Sie das Arbeitsblatt `settings` in Ihrer XLSForm:

```
| form_id   | version | default_language |
|-----------|---------|-------------------|
| test_form | 101     | German (de)       |
```

## rtSurvey-spezifische Funktionen

### Dynamischer Sprachwechsel

rtSurvey ermöglicht es Benutzern, die Sprache während der Datenerfassung dynamisch zu wechseln:

- Verwenden Sie in der Web-Oberfläche das Sprach-Dropdown in der oberen Navigationsleiste.
- Greifen Sie in der Mobil-App über das Einstellungsmenü auf die Sprachoptionen zu.

### Sprachspezifische Validierungsmeldungen

rtSurvey erweitert die mehrsprachige Unterstützung auf Validierungsmeldungen:

```
| type    | name | constraint | constraint_message::English (en) | constraint_message::German (de) |
|---------|------|------------|----------------------------------|---------------------------------|
| integer | age  | . <= 150   | Age must be 150 or less          | Das Alter muss 150 oder weniger sein |
```

### Lokalisierte Meldungen für Pflichtfelder

Verwenden Sie `required_message::Language (code)`, um eine übersetzte Fehlermeldung anzuzeigen, wenn ein Pflichtfeld leer gelassen wird:

```
| type | name | required | required_message::English (en) | required_message::German (de) |
|------|------|----------|-------------------------------|-------------------------------|
| text | name | yes      | This field is required        | Dieses Feld ist ein Pflichtfeld |
```

### RTL-Sprachunterstützung

Für von rechts nach links (RTL) geschriebene Sprachen wie Arabisch oder Hebräisch passt rtSurvey das Layout automatisch an:

```
| type | name | label::English (en) | label::Arabic (ar) |
|------|------|---------------------|---------------------|
| text | name | Your name           | اسمك                |
```

### Sprachspezifisches Erscheinungsbild (Appearance)

rtSurvey ermöglicht es Ihnen, unterschiedliche Darstellungsformen für verschiedene Sprachen festzulegen:

```
| type | name | label::English (en) | label::Chinese (zh) | appearance::English (en) | appearance::Chinese (zh) |
|------|------|---------------------|---------------------|--------------------------|---------------------------|
| text | address | Address          | 地址                 | multiline                | textarea                  |
```

## HTML-Formatierung in zweisprachigen Beschriftungen

Sie können HTML-Tags mit Sprach-Wrappern in einer einzigen Beschriftungszelle kombinieren. rtSurvey extrahiert den Block der aktiven Sprache und rendert das verbleibende HTML.

Beispiel mit Fettdruck und Schriftfarbe pro Sprache:

```
<en><big><b>Section 2: Household Income</b></big><br>Ask the household head only.</en><de><big><b>Abschnitt 2: Haushaltseinkommen</b></big><br>Fragen Sie nur das Haushaltsvorstand.</de>
```

Unterstützte Inline-Tags innerhalb von Sprach-Wrappern: `<b>`, `<i>`, `<u>`, `<big>`, `<small>`, `<font color="...">`, `<br>`, `<span style="...">`.

Beispiel für farbigen Text pro Sprache:

```
<en><font color="red">Required field</font></en><de><font color="red">Pflichtfeld</font></de>
```

## Sprachabhängige Berechnungen

Wenn ein Formular ein Feld `${language_use}` hat (festgelegt durch ein `change_language`-Widget), verwenden Sie `if()`, um Werte in der aktiven Sprache zurückzugeben:

```
if(${language_use} = 'en', label_en, label_de)
```

Beispiel — Anzeige eines Suchergebnisses in der aktiven Sprache mit `pulldata('rawquery', ...)`:

```
| type      | name        | calculation                                                                 |
|-----------|-------------|-----------------------------------------------------------------------------|
| calculate | district_label | if(${language_use} = 'en', pulldata('rawquery', concat(${family_path}, '/locations.db::externalData'), 'SELECT label_en FROM externalData WHERE code = ?', ${district}), pulldata('rawquery', concat(${family_path}, '/locations.db::externalData'), 'SELECT label_de FROM externalData WHERE code = ?', ${district})) |
```

Hinweis: Das Feld `language_use` wird normalerweise durch ein `change_language`-Erscheinungsbild-Widget festgelegt. Siehe Appearance — change_language.

## Best Practices für mehrsprachige Umfragen

1. **Konsistente Benennung**: Verwenden Sie konsistente Sprachcodes in Ihrem gesamten Formular.
2. **Professionelle Übersetzung**: Beauftragen Sie professionelle Übersetzer, die mit dem Kontext der Umfrage vertraut sind.
3. **Kontexthinweise**: Geben Sie den Übersetzern Kontexthinweise, um genaue Übersetzungen zu gewährleisten.
4. **Testen**: Testen Sie Ihr Formular in allen Sprachen vor dem Einsatz.
5. **Unicode-Unterstützung**: Stellen Sie sicher, dass Ihre Datenerfassungsgeräte Unicode für nicht-lateinische Schriften unterstützen.
6. **Sprachspezifische Medien**: Verwenden Sie kulturell angemessene Bilder oder Audio für jede Sprache.
7. **Text in Bildern vermeiden**: Wenn Sie Bilder mit Text verwenden, erstellen Sie separate Bilder für jede Sprache.

## Umgang mit Sonderfällen

### Gemischtsprachige Antworten

rtSurvey ermöglicht es Befragten, Text in jedem beliebigen Alphabet einzugeben, unabhängig von der gewählten Formularsprache. Dies ist nützlich für die Erfassung von Namen oder Adressen in ihrer Originalschrift.

### Sprachspezifische Fragetypen

Einige Fragetypen sind für bestimmte Sprachen möglicherweise besser geeignet. rtSurvey ermöglicht es Ihnen, je nach Sprache unterschiedliche Fragetypen zu verwenden:

```
| type::English (en) | type::Japanese (ja) | name | label::English (en) | label::Japanese (ja) |
|--------------------|---------------------|------|---------------------|----------------------|
| text               | select_one kanji    | name | Enter your name     | 名前を選んでください    |
```

## Exportieren mehrsprachiger Daten

Beim Exportieren von Daten aus rtSurvey:

- Wählen Sie den Export in einer bestimmten Sprache oder schließen Sie alle Sprachversionen ein.
- Sprachmetadaten sind im Export enthalten und geben an, welche Sprache für jede Antwort verwendet wurde.

## Überlegungen zur mobilen App

- Die rtSurvey-Mobil-App unterstützt den Offline-Sprachwechsel.
- Stellen Sie sicher, dass alle erforderlichen Sprachdateien vor dem Offline-Gang heruntergeladen wurden.

## Bekannte Einschränkungen

- Einige fortgeschrittene Funktionen sind möglicherweise nicht in allen Sprachen verfügbar.
- Extrem lange Übersetzungen können das Layout auf kleinen Bildschirmen beeinträchtigen.

Durch die Nutzung der mehrsprachigen Funktionen von rtSurvey können Sie inklusive, barrierefreie Umfragen erstellen, die diverse Bevölkerungsgruppen erreichen und qualitativ hochwertige, linguistisch präzise Daten liefern.

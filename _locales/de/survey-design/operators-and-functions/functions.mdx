### String-Funktionen

<Callout type="warning">
Bei der Arbeit mit Zeichenfolgen (Strings) innerhalb von Ausdrücken ist es wichtig, einfache Anführungszeichen ('') zu verwenden, um literale Zeichenfolgen einzuschließen. Eine Ausnahme besteht jedoch, wenn Sie einfache Anführungszeichen innerhalb einer literalen Zeichenfolge einschließen möchten. In solchen Fällen können Sie doppelte Anführungszeichen ("") verwenden, um die gesamte Zeichenfolge einzuschließen.

Zum Beispiel:
- Richtig: if(`${yesno}` = 1, "a string with 'single quotes' in it", "no single quotes here")
- Falsch: if(`${yesno}` = 1, 'a string with 'single quotes' in it', 'no single quotes here')

In Bezug auf "Smart Quotes" (typografische Anführungszeichen) ist es wichtig, auf deren Vorhandensein zu achten, da sie Probleme in Ausdrücken verursachen können. Viele Rich-Text-Editoren konvertieren gerade Anführungszeichen ("" oder '') automatisch in typografische Anführungszeichen („“ oder ‚‘), was zu Syntaxfehlern oder unerwartetem Verhalten führen kann. Um dies zu vermeiden, stellen Sie sicher, dass Sie in Ihren Ausdrücken konsequent gerade Anführungszeichen ('') verwenden.

Bitte lassen Sie mich wissen, wenn Sie weitere Fragen haben oder zusätzliche Hilfe benötigen!
</Callout>

rtSurvey unterstützt verschiedene Funktionen, darunter:

1. `string(field)`: Konvertiert ein Feld in eine Zeichenfolge.
   - Beispiel: `string(34.8)` wird in `'34.8'` konvertiert.

2. `string-length(field)`: Gibt die Länge eines String-Feldes zurück.
   - Beispiel: `string-length(.) > 3 and string-length(.) < 10` kann verwendet werden, um sicherzustellen, dass das aktuelle Feld zwischen 3 und 10 Zeichen lang ist.
   - **Kaskaden-Abhängigkeitsmuster (Cascade dependency pattern)**: `string-length(${province}) >= 0` wird immer als `true` ausgewertet, zwingt rtSurvey dazu, den Ausdruck jedes Mal neu auszuwerten, wenn sich `${province}` ändert. Verwenden Sie dies in `relevant`, um eine Kaskadenaktualisierung auszulösen, wenn ein übergeordnetes Feld aktualisiert wird:
     | type | name | relevant |
     |------|------|----------|
     | select_one | district | `string-length(${province}) >= 0` |
     Dies stellt sicher, dass die Distriktfrage ihr `search()`- oder `rawquery`-Erscheinungsbild neu auswertet, wann immer sich die Provinz ändert.

3. `substr(fieldorstring, startindex, endindex)`: Gibt einen Teilstring zurück, der bei `startindex` beginnt und kurz vor `endindex` endet. Indizes beginnen bei 0 für das erste Zeichen im String.
   - Beispiel: `substr(${phone}, 0, 3)` gibt die ersten drei Ziffern einer Telefonnummer zurück.

4. `concat(a, b, c, ...)`: Verknüpft Felder (und/oder Strings) miteinander.
   - Beispiel: `concat(${firstname}, ' ', ${lastname})` gibt einen vollständigen Namen zurück, indem die Werte in den Feldern `firstname` und `lastname` kombiniert werden.

5. `linebreak()`: Gibt ein Zeilenumbruchzeichen zurück.
   - Beispiel: `concat(${field1}, linebreak(), ${field2}, linebreak(), ${field3})` gibt eine Liste von drei Feldwerten mit Zeilenumbrüchen dazwischen zurück.

6. `lower()`: Konvertiert einen String in Kleinbuchstaben.
   - Beispiel: `lower('Street Name')` gibt "street name" zurück.

7. `upper()`: Konvertiert einen String in Großbuchstaben.
   - Beispiel: `upper('Street Name')` gibt "STREET NAME" zurück.

### Funktionen für select_one und select_multiple

1. `count-selected(field)`: Gibt die Anzahl der in einem select_multiple-Feld ausgewählten Elemente zurück.
   - Beispiel: `count-selected(.) = 3` kann als Einschränkungsausdruck (constraint) verwendet werden, um sicherzustellen, dass genau drei Optionen ausgewählt werden.

2. `selected(field, value)`: Gibt true oder false zurück, je nachdem, ob der angegebene Wert im select_one- oder select_multiple-Feld ausgewählt wurde.
   - Beispiel: `selected(${color}, 'Blue')` kann als Relevanzausdruck (relevance) verwendet werden, um eine Gruppe oder ein Feld nur dann anzuzeigen, wenn der Befragte "Blau" als seine Lieblingsfarbe ausgewählt hat.
   - Hinweis: Der zweite Parameter sollte immer den Auswahlwert (choice value) angeben, nicht die Auswahlbeschriftung (choice label). Verwenden Sie den Wert aus der Spalte `value` im Arbeitsblatt `choices` der Formulardefinition.

3. `selected-at(field, number)`: Gibt das ausgewählte Element an der angegebenen Position in einem select_multiple-Feld zurück. Wenn die übergebene Zahl 0 ist, wird das erste ausgewählte Element zurückgegeben; wenn die Zahl 1 ist, wird das zweite ausgewählte Element zurückgegeben und so weiter.
   - Beispiel: `selected-at(${fruits}, 0) = 'Apple'` kann als Relevanzausdruck verwendet werden, um eine Gruppe oder ein Feld nur anzuzeigen, wenn die erste getroffene Auswahl "Apfel" ist.
   - Hinweis: Der zurückgegebene Wert ist der Auswahlwert, nicht die Auswahlbeschriftung. Verwenden Sie den Wert aus der Spalte `value` im Arbeitsblatt `choices` der Formulardefinition.

4. `choice-label(field, value)`: Gibt die Beschriftung für eine Auswahl in einem select_one- oder select_multiple-Feld zurück, wie im Arbeitsblatt `choices` der Formulardefinition definiert.
   - Beispiel 1: `choice-label(${country}, ${country})` gibt die Auswahlbeschriftung für die aktuell ausgewählte Option im Feld namens `country` zurück.
   - Beispiel 2: `choice-label(${languages}, selected-at(${languages}, 0))` gibt die Beschriftung für die erste ausgewählte Option im Feld namens `languages` zurück.
   - Hinweis: Diese Funktion ruft die Auswahlbeschriftung ab, nicht den Wert. Sie verwendet die Spalte `label` aus dem Arbeitsblatt `choices` der Formulardefinition.

### Funktionen für wiederholte Felder

In rtSurvey können Sie eine Frage mehrmals stellen, indem Sie ein Feld in eine Wiederholungsgruppe (repeat group) platzieren. Dies führt zu mehreren Instanzen desselben Feldes. Die folgenden Funktionen können Ihnen helfen, mit diesen wiederholten Feldern und den von ihnen erzeugten wiederholten Daten umzugehen. Weitere Einzelheiten finden Sie im Hilfethema zu wiederholten Feldern.

1. `join(string, repeatedfield)`: Erzeugt für ein Feld innerhalb einer Wiederholungsgruppe eine durch eine Zeichenfolge getrennte Liste von Werten. Der erste Parameter gibt das Trennzeichen an, das zur Trennung der Werte verwendet werden soll.
   - Beispiel: `join(', ', ${member_name})` erzeugt eine einzelne, durch Kommas getrennte Liste aus allen eingegebenen Namen.

2. `join-if(string, repeatedfield, expression)`: Funktioniert genau wie `join()`, außer dass jede Instanz in der Wiederholungsgruppe anhand des angegebenen Ausdrucks überprüft wird. Wenn der Ausdruck als false ausgewertet wird, wird das Element in der Ausgabe weggelassen.
   - Beispiel: `join-if(', ', ${member_name}, ${age} >= 18)` erzeugt eine durch Kommas getrennte Liste der Namen von nur erwachsenen Mitgliedern (solche im Alter von 18 Jahren und älter).

3. `count(repeatgroup)`: Gibt die aktuelle Anzahl der Wiederholungen einer Wiederholungsgruppe zurück.
   - Beispiel: `count(${groupname})` gibt die Anzahl der Instanzen der Gruppe zurück.

4. `count-if(repeatgroup, expression)`: Funktioniert genau wie `count()`, außer dass jede Instanz in der Wiederholungsgruppe anhand des angegebenen Ausdrucks überprüft wird. Wenn der Ausdruck als false ausgewertet wird, wird das Element in der Ausgabe weggelassen.
   - Beispiel: `count-if(${members}, ${age} >= 18)` gibt die Anzahl der erwachsenen Mitglieder basierend auf dem Altersfeld innerhalb der Wiederholungsgruppe "members" zurück.

5. `sum(repeatedfield)`: Berechnet für ein Feld innerhalb einer Wiederholungsgruppe die Summe aller Werte.
   - Beispiel: `sum(${loan_amount})` gibt den Gesamtwert aller Kredite zurück.

6. `sum-if(repeatedfield, expression)`: Funktioniert genau wie `sum()`, außer dass jede Instanz in der Wiederholungsgruppe anhand des angegebenen Ausdrucks überprüft wird. Wenn der Ausdruck als false ausgewertet wird, wird das Element in der Ausgabe weggelassen.
   - Beispiel: `sum-if(${loan_amount}, ${loan_amount} > 500)` gibt den Gesamtwert aller Kredite zurück, die über 500 liegen. Kleinere Kredite werden ignoriert.

7. `min(repeatedfield)`: Berechnet für ein Feld innerhalb einer Wiederholungsgruppe das Minimum aller Werte.
   - Beispiel: `min(${member_age})` gibt das Alter des jüngsten Mitglieds in der Gruppe zurück.

8. `min-if(repeatedfield, expression)`: Funktioniert genau wie `min()`, außer dass jede Instanz in der Wiederholungsgruppe anhand des angegebenen Ausdrucks überprüft wird. Wenn der Ausdruck als false ausgewertet wird, wird das Element in der Ausgabe weggelassen.
   - Beispiel: `min-if(${member_age}, ${member_age} >= 18)` gibt das Alter des jüngsten Erwachsenen in der Gruppe zurück. Personen unter 18 Jahren werden ignoriert.

9. `max(repeatedfield)`: Berechnet für ein Feld innerhalb einer Wiederholungsgruppe das Maximum aller Werte.
   - Beispiel: `max(${member_age})` gibt das Alter des ältesten Mitglieds in der Gruppe zurück.

10. `max-if(repeatedfield, expression)`: Funktioniert genau wie `max()`, außer dass jede Instanz in der Wiederholungsgruppe anhand des angegebenen Ausdrucks überprüft wird. Wenn der Ausdruck als false ausgewertet wird, wird das Element in der Ausgabe weggelassen.
    - Beispiel: `max-if(${member_age}, ${member_age} >= 18)` gibt das Alter des ältesten Erwachsenen in der Gruppe zurück. Personen unter 18 Jahren werden ignoriert.

11. `index()`: Gibt innerhalb einer Wiederholungsgruppe aufgerufen die Indexnummer für die aktuelle Gruppe oder Instanz zurück.
    - Beispiel: `index()` gibt bei Verwendung innerhalb einer Wiederholungsgruppe 1 für die erste Instanz, 2 für die zweite usw. zurück.

12. `indexed-repeat(repeatedfield, repeatgroup, index)`: Referenziert ein Feld oder eine Gruppe, die sich innerhalb einer Wiederholungsgruppe befindet, von außerhalb dieser Wiederholungsgruppe. Der erste Parameter gibt das wiederholte Feld oder die Gruppe von Interesse an, der zweite die Wiederholungsgruppe, in der sich das Feld oder die Gruppe befindet, und der dritte die zu verwendende Instanznummer innerhalb der Wiederholungsgruppe.
    - Beispiel 1: `indexed-repeat(${name}, ${names}, 1)` gibt den ersten verfügbaren Namen zurück, wenn sich das Namensfeld innerhalb einer vorherigen Wiederholungsgruppe namens "names" befindet.
    - Beispiel 2: `indexed-repeat(${name}, ${names}, index())` ruft den Namen ab, der der Instanznummer der aktuellen Wiederholungsgruppe entspricht.

13. `rank-index(index, repeatedfield)`: Diese Funktion berechnet den ordinalen Rang der angegebenen Instanz eines wiederholten Feldes zur Verwendung außerhalb der Wiederholungsgruppe. Der Rang 1 wird der Instanz mit dem höchsten Wert zugewiesen, der Rang 2 der Instanz mit dem nächsthöheren Wert und so weiter. Wenn Sie einen ungültigen Index oder einen Index für eine Instanz mit einem nicht numerischen Wert übergeben, wird der Rang 999 zurückgegeben.
    - Beispiel: `rank-index(1, ${random_draw})` berechnet den Rang der ersten Instanz basierend auf dem Wert ihres Feldes `random_draw` im Vergleich zu den Werten anderer Instanzen.

14. `rank-index-if(index, repeatedfield, expression)`: Diese Funktion arbeitet ähnlich wie `rank-index()`, prüft jedoch jede Instanz in der Wiederholungsgruppe des wiederholten Feldes mit dem angegebenen Ausdruck. Wenn der Ausdruck als false ausgewertet wird, wird das Element von der Berechnung ausgeschlossen. Der verwendete Index basiert auf der vollständigen Menge der Instanzen vor der Auswertung des Ausdrucks für jede Instanz. Wenn Sie einen Index für eine Instanz übergeben, die ignoriert wurde, weil sie den Ausdruck nicht erfüllt, wird dies als ungültiger Index betrachtet und der Rang 999 wird zurückgegeben.
    - Beispiel: `rank-index-if(1, ${age}, ${age} >= 18)` berechnet den Altersrang innerhalb der Gruppe der Erwachsenen, wobei nur Instanzen berücksichtigt werden, in denen das Alter größer oder gleich 18 ist.

### Zahlenfunktionen

| Operator | Operation | Beispiel | Beispielantwort |
|----------|-----------|---------|----------------|
| `+` | Addition | 1 + 1 | 2 |
| `-` | Subtraktion | 3 - 2 | 1 |
| `*` | Multiplikation | 3 * 2 | 6 |
| `div` | Division | 10 div 2 | 5 |
| `mod` | Modulo | 9 mod 2 | 1 |

rtSurvey unterstützt Zahlenfunktionen, darunter:
- `number(field)`: Konvertiert den Wert des Feldes in eine Zahl.
  - Beispiel: `number('34.8')` = 34.8

- `int(field)`: Konvertiert den Wert des Feldes in eine Ganzzahl.
  - Beispiel: `int('39.2')` = 39

- `min(field1, ..., fieldx)`: Gibt den Minimalwert unter den übergebenen Feldern zurück.
  - Beispiel: `min(${father_age}, ${mother_age})` gibt das Alter von entweder der Mutter oder dem Vater zurück, je nachdem, welcher Wert kleiner ist.

- `max(field1, ..., fieldx)`: Gibt den Maximalwert unter den übergebenen Feldern zurück.
  - Beispiel: `max(${father_age}, ${mother_age})` gibt das Alter von entweder der Mutter oder dem Vater zurück, je nachdem, welcher Wert größer ist.

- `format-number(field)`: Formatiert den Wert eines Ganzzahl- oder Dezimalfeldes gemäß den Gebietsschema-Einstellungen (Locale) des Benutzers.
  - Beispiel: `format-number(${income})` Dieser Ausdruck könnte "120000" als "120.000" formatieren.

- `round(field, digits)`: Rundet den numerischen Feldwert auf die angegebene Anzahl von Stellen nach dem Dezimalpunkt.
  - Beispiel: `round(${interest_rate}, 2)`

- `abs(number)`: Gibt den Absolutwert einer Zahl zurück.

- `pow(base, exponent)`: Gibt den Wert des ersten Parameters erhoben zur Potenz des zweiten Parameters zurück.
  - Jeder Parameter kann ein Feld, eine Zahl oder ein Ausdruck sein.

- `log10(fieldorvalue)`: Gibt den Logarithmus zur Basis Zehn des übergebenen Feldes oder Wertes zurück.

- `sin(fieldorvalue)`: Gibt den Sinus des übergebenen Feldes oder Wertes zurück, ausgedrückt in Bogenmaß (Radiant).

- `cos(fieldorvalue)`: Gibt den Kosinus des übergebenen Feldes oder Wertes zurück, ausgedrückt in Bogenmaß.

- `tan(fieldorvalue)`: Gibt den Tangens des übergebenen Feldes oder Wertes zurück, ausgedrückt in Bogenmaß.

- `asin(fieldorvalue)`: Gibt den Arkussinus des übergebenen Feldes oder Wertes zurück, ausgedrückt in Bogenmaß.

- `acos(fieldorvalue)`: Gibt den Arkuskosinus des übergebenen Feldes oder Wertes zurück, ausgedrückt in Bogenmaß.

- `atan(fieldorvalue)`: Gibt den Arkustangens des übergebenen Feldes oder Wertes zurück, ausgedrückt in Bogenmaß.

- `atan2(x, y)`: Gibt den im Ursprung vom Punkt mit den Koordinaten (x, y) und der positiven x-Achse eingeschlossenen Winkel im Bogenmaß zurück. Das Ergebnis liegt im Bereich -pi() bis pi().

- `sqrt(fieldorvalue)`: Gibt die nicht-negative Quadratwurzel des übergebenen Feldes oder Wertes zurück.

- `exp(x)`: Gibt den Wert von e^x zurück.

- `pi()`: Gibt den Wert von pi zurück.

### Datums- und Zeitfunktionen

<Callout type="warning">
Datumswerte in rtSurvey werden als Strings im Format `YYYY-MM-DD` gespeichert. Datetime-Werte werden als ISO 8601-Strings gespeichert (`YYYY-MM-DDTHH:MM:SS`). Verwenden Sie `decimal-date-time()`, um sie für arithmetische Berechnungen (z. B. zur Berechnung von Zeitspannen) in eine Zahl umzuwandeln.
</Callout>

1. `today()`: Gibt das heutige Datum als String im Format `YYYY-MM-DD` zurück. Wird einmal beim Öffnen des Formulars ausgewertet.
   - Beispiel: `today()` → `'2024-03-15'`
   - Häufige Verwendung: Spalte `default`, um das heutige Datum vorab auszufüllen, oder in `relevant`/`constraint` zum Vergleich mit einem Datumsfeld.

2. `now()`: Gibt das aktuelle Datum und die aktuelle Uhrzeit als ISO 8601-String zurück. Wird jedes Mal ausgewertet, wenn der Ausdruck berechnet wird.
   - Beispiel: `now()` → `'2024-03-15T14:32:00.000+03:00'`
   - Häufige Verwendung: Aufzeichnung des exakten Zeitstempels eines bestimmten Ereignisses während der Umfrage.

3. `date(value)`: Konvertiert einen Wert (String oder Zahl) in einen Datums-String. Nützlich, um berechnete Werte in einen Datumstyp zu zwingen.
   - Beispiel: `date('2024-03-15')` → `'2024-03-15'`

4. `date-time(value)`: Konvertiert einen Wert in einen Datetime-String.
   - Beispiel: `date-time(${event_timestamp})`

5. `decimal-date-time(value)`: Konvertiert einen Datums- oder Datetime-String in eine Dezimalzahl, die die Millisekunden seit der Unix-Epoche geteilt durch 86400000 (d. h. Bruchteile von Tagen seit 1970-01-01) darstellt. Verwenden Sie dies, um arithmetische Berechnungen mit Daten durchzuführen.
   - Beispiel: Dauer in Tagen zwischen zwei Daten:
     `decimal-date-time(${end_date}) - decimal-date-time(${start_date})`
   - Beispiel: Dauer in Minuten zwischen zwei Datetimes:
     `(decimal-date-time(${end_time}) - decimal-date-time(${start_time})) * 1440`

6. `format-date(date, format)`: Formatiert einen Datumswert unter Verwendung eines Muster-Strings.
   - Format-Token: `%Y` (4-stelliges Jahr), `%y` (2-stelliges Jahr), `%m` (Monat 01–12), `%d` (Tag 01–31), `%a` (abgekürzter Wochentag), `%b` (abgekürzter Monatsname)
   - Beispiel: `format-date(today(), '%d/%m/%Y')` → `'15/03/2024'`
   - Beispiel: `format-date(${dob}, '%B %d, %Y')` → `'March 15, 1990'`

7. `format-date-time(datetime, format)`: Formatiert einen Datetime-Wert unter Verwendung eines Muster-Strings. Akzeptiert alle `format-date`-Token plus:
   - `%H` (Stunde 00–23), `%h` (Stunde 01–12), `%M` (Minuten 00–59), `%S` (Sekunden 00–59), `%3` (Millisekunden), `%P` (AM/PM)
   - Beispiel: `format-date-time(now(), '%d/%m/%Y %H:%M')` → `'15/03/2024 14:32'`
   - Beispiel: `format-date-time(${event_time}, '%I:%M %p')` → `'02:32 PM'`

8. `STRFTIME(format, datetime)`: Datumsformatierung im SQLite-Stil. Verfügbar innerhalb von SQL-Strings, die an `rawquery`-Abfragen übergeben werden – **nicht** verfügbar in den XLSForm-Spalten `calculation` oder `label`. Verwendet SQLite-Format-Token (`%Y`, `%m`, `%d`, `%H`, `%M`, `%S`).
   - Beispiel innerhalb eines rawquery-SQL-Strings: `'SELECT STRFTIME(''%Y-%m'', interview_date) AS month FROM data WHERE id = ?'`
   - Hinweis: Verwenden Sie `format-date-time()` für die Datumsformatierung in XLSForm-Ausdrücken. `STRFTIME()` ist eine SQLite-Funktion, die nur innerhalb von SQL verfügbar ist, das an `rawquery` übergeben wird.

### Boolesche Funktionen

1. `boolean(value)`: Konvertiert einen beliebigen Wert in einen booleschen Wert. Gibt `true` für nicht leere Strings, Zahlen ungleich Null und `true` zurück; gibt `false` für leere Strings, `0` und `false` zurück.
   - Beispiel: `boolean(${name})` gibt `true` zurück, wenn `name` nicht leer ist.

2. `boolean-from-string(string)`: Gibt `true` zurück, wenn der String `'1'` oder `'true'` ist (unabhängig von der Groß-/Kleinschreibung); andernfalls wird `false` zurückgegeben.
   - Beispiel: `boolean-from-string(${enabled_flag})` – nützlich, wenn ein Feld `'true'`/`'false'` als Text speichert.

3. `true()`: Gibt den booleschen Wert `true` zurück.
   - Beispiel: In der Spalte `required` entspricht `true()` dem Wert `yes`.

4. `false()`: Gibt den booleschen Wert `false` zurück.
   - Beispiel: `if(${skip_section} = 'yes', false(), true())` – dynamisches Setzen von Pflichtfeldern.

5. `not(expression)`: Gibt die logische Negation des Ausdrucks zurück. Gibt `true` zurück, wenn der Ausdruck falsch ist, und umgekehrt.
   - Beispiel: `not(${consent} = 'yes')` – zeigt eine Warnung an, wenn die Zustimmung NICHT gegeben wurde.
   - Beispiel: `not(selected(${issues}, 'none'))` – erfordert Details nur dann, wenn "none" nicht ausgewählt wurde.

### Zusätzliche String-Funktionen

1. `starts-with(string, prefix)`: Gibt `true` zurück, wenn `string` mit `prefix` beginnt.
   - Beispiel: `starts-with(${phone}, '+254')` prüft, ob die Telefonnummer mit der Landesvorwahl für Kenia beginnt.

2. `contains(string, substring)`: Gibt `true` zurück, wenn `string` den `substring` enthält.
   - Beispiel: `contains(${email}, '@')` prüft, ob eine E-Mail-Adresse ein `@`-Zeichen enthält.
   - Beispiel: `contains(${notes}, 'urgent')` löst eine Folgefrage aus, wenn in den Notizen "dringend" (urgent) erwähnt wird.

3. `substring-before(string, needle)`: Gibt den Teil von `string` zurück, der vor dem ersten Vorkommen von `needle` erscheint.
   - Beispiel: `substring-before(${full_name}, ' ')` extrahiert das erste Wort (Vorname).

4. `substring-after(string, needle)`: Gibt den Teil von `string` zurück, der nach dem ersten Vorkommen von `needle` erscheint.
   - Beispiel: `substring-after(${email}, '@')` extrahiert den Domain-Teil einer E-Mail-Adresse.

5. `normalize-space(string)`: Entfernt führende und nachfolgende Leerzeichen und fasst alle internen Leerzeichenfolgen zu einem einzigen Leerzeichen zusammen.
   - Beispiel: `normalize-space(${name})` – bereinigt einen Namen, der möglicherweise mit zusätzlichen Leerzeichen eingegeben wurde.

6. `translate(string, search_chars, replace_chars)`: Ersetzt jedes Zeichen in `string`, das in `search_chars` vorkommt, durch das entsprechende Zeichen in `replace_chars`. Zeichen in `search_chars` ohne entsprechendes Zeichen in `replace_chars` werden gelöscht.
   - Beispiel: `translate(${code}, 'abcdefghijklmnopqrstuvwxyz', 'ABCDEFGHIJKLMNOPQRSTUVWXYZ')` konvertiert in Großbuchstaben (entspricht `upper()`).
   - Beispiel: `translate(${phone}, ' -()', '')` entfernt Leerzeichen, Bindestriche und Klammern aus einer Telefonnummer.

### Zusätzliche mathematische Funktionen

1. `floor(number)`: Gibt die größte Ganzzahl zurück, die kleiner oder gleich `number` ist (rundet in Richtung minus unendlich).
   - Beispiel: `floor(4.9)` = 4, `floor(-2.1)` = -3

2. `ceiling(number)`: Gibt die kleinste Ganzzahl zurück, die größer oder gleich `number` ist (rundet in Richtung plus unendlich).
   - Beispiel: `ceiling(4.1)` = 5, `ceiling(-2.9)` = -2

3. `random()`: Gibt eine zufällige Dezimalzahl zwischen 0.0 (einschließlich) und 1.0 (ausschließlich) zurück. Wird normalerweise in `calculate`-Feldern verwendet, um Zufallswerte zuzuweisen oder die Fragenreihenfolge zu randomisieren.
   - Beispiel: `random()` → z. B. `0.7341`
   - Beispiel: `int(random() * 6) + 1` → Zufallszahl 1–6 (Würfelwurf)

4. `coalesce(a, b)`: Gibt `a` zurück, wenn `a` nicht leer ist; andernfalls wird `b` zurückgegeben. Nützlich als Ausweichlösung (Fallback), wenn ein Feld leer sein könnte.
   - Beispiel: `coalesce(${preferred_name}, ${full_name})` – verwendet den bevorzugten Namen, falls festgelegt, andernfalls wird auf den vollständigen Namen zurückgegriffen.

5. `once(value)`: Wertet `value` aus und speichert ihn, aber nur, wenn das aktuelle Feld **leer** ist. Wenn das Feld bereits einen Wert hat (z. B. zuvor festgelegt wurde), gibt `once()` den vorhandenen Wert unverändert zurück. Dies verhindert, dass eine Neuberechnung Benutzereingaben überschreibt.
   - Beispiel: `once(today())` in der Spalte `default` setzt das heutige Datum einmal und aktualisiert es nicht, wenn der Interviewer das Formular erneut öffnet.
   - Beispiel: `once(uuid())` generiert einmal eine UUID und hält sie über Bearbeitungen hinweg stabil.

### Geo-Funktionen

1. `area(geoshape_value)`: Berechnet die **Fläche in Quadratmetern**, die von einem Geoshape-Wert (Polygon) eingeschlossen wird.
   - Der Parameter ist un Geoshape-Feldwert im Format `lat1 lon1 0 0; lat2 lon2 0 0; ...`
   - Beispiel: `area(${field_boundary})` – berechnet die Fläche eines vermessenen Feldes in m².
   - Beispiel: `round(area(${field_boundary}) div 10000, 2)` – Umrechnung in Hektar.

2. `distance(coordinates)`: Berechnet die **Gesamtpfadlänge in Metern** einer Geotrace (Linie) oder die Entfernung zwischen zwei Geopoints.
   - Für eine Geotrace: `distance(${route})` gibt die Gesamtpfadlänge in Metern zurück.
   - Für zwei Geopoints: `distance(concat(${point_a}, ' ', ${point_b}))` gibt die Entfernung zwischen ihnen zurück.
   - Beispiel: `round(distance(${road_trace}) div 1000, 3)` – Straßenlänge in Kilometern.

### Validierungsfunktionen

1. `regex(value, pattern)`: Gibt `true` zurück, wenn `value` dem regulären Ausdruck `pattern` entspricht. Verwendung in der Spalte `constraint` für musterbasierten Validierung.
   - Das Muster verwendet die Standard-Regex-Syntax (POSIX ERE-Subset).
   - Beispiel: `regex(., '^[0-9]{10}$')` – Validierung einer 10-stelligen Nummer.
   - Beispiel: `regex(., '^[A-Z]{2}[0-9]{6}$')` – Validierung eines Passnummernformats (2 Großbuchstaben gefolgt von 6 Ziffern).
   - Beispiel: `regex(., '^[^@]+@[^@]+\.[^@]{2,}$')` – einfache E-Mail-Formatprüfung.

2. `checklist(min, max, v1, v2, ...)`: Wertet eine Liste von booleschen Ausdrücken aus und gibt `true` zurück, wenn die Anzahl der `true`-Werte zwischen `min` und `max` (einschließlich) liegt. Übergeben Sie `-1` für `min` oder `max`, um diese Grenze zu überspringen.
   - Beispiel: `checklist(2, 3, ${q1} = 'yes', ${q2} = 'yes', ${q3} = 'yes')` – besteht, wenn genau 2 oder 3 der drei Bedingungen wahr sind.
   - Beispiel: `checklist(1, -1, ${smoke_alarm}, ${fire_ext}, ${emergency_plan})` – mindestens eine Sicherheitsmaßnahme muss wahr sein.

3. `weighted-checklist(min, max, v1, w1, v2, w2, ...)`: Wie `checklist()`, aber jeder Wert hat eine Gewichtung. Die Summe der Gewichtungen für `true`-Werte muss zwischen `min` und `max` liegen.
   - Beispiel: `weighted-checklist(10, -1, ${has_toilet}, 4, ${has_sink}, 3, ${has_shower}, 5)` – Summe der Gewichtungen für vorhandene Einrichtungen muss mindestens 10 betragen.

### Hilfsfunktionen

1. `uuid()`: Erzeugt eine zufällige UUID (RFC 4122 v4 Format) als String.
   - Beispiel: `uuid()` → `'a3f8b2c1-4d5e-6f7a-8b9c-0d1e2f3a4b5c'`
   - Wird normalerweise mit `once()` verwendet, um eine stabile eindeutige ID zu generieren: `once(uuid())`

2. `version()`: Gibt den Wert des `version`-Attributs des Formulars zurück, wie im Arbeitsblatt `settings` festgelegt.
   - Beispiel: `version()` → `'3.1'`
   - Nützlich in `calculate`-Feldern, um die Formularversion in exportierte Daten einzubetten.

3. `position()`: Wenn innerhalb einer **Wiederholungsgruppe** aufgerufen, wird der 1-basierte Index der aktuellen Wiederholungsinstanz zurückgegeben.
   - Beispiel: `position()` in der ersten Instanz gibt `1` zurück, in der zweiten `2` usw.
   - Siehe auch: `index()` (Alias), `indexed-repeat()` zum Referenzieren von Wiederholungswerten von außerhalb der Gruppe.

4. `thousandsep(length, separator, value)`: Formatiert eine Zahl mit einem Tausendertrennzeichen. `length` ist die minimale Gesamtstringlänge (mit Leerzeichen aufgefüllt, falls kürzer), `separator` ist das zu verwendende Zeichen (z. B. `','`) und `value` ist die zu formatierende Zahl.
   - Beispiel: `thousandsep(0, ',', 1234567)` → `'1,234,567'`
   - Beispiel: `thousandsep(0, '.', ${income})` – formatiert das Einkommen mit einem Punkt als Tausendertrennzeichen.

5. `substr-jsonpath(value, jsonpath)`: Extrahiert einen Wert aus einem JSON-String unter Verwendung eines JSONPath-Ausdrucks.
   - `value` muss ein JSON-String sein (z. B. ein Feld, in dem eine rohe API-Antwort mittels `callapi(..., 'json:', ...)` gespeichert wurde).
   - `jsonpath` ist ein JSONPath-Ausdruck (z. B. `'$.data.name'`, `'$.items[0].id'`).
   - Gibt immer einen **String** zurück – bei Verwendung in arithmetischen Operationen in `number()` einschließen.
   - Gibt einen leeren String `''` zurück, wenn der Pfad nicht gefunden wird oder `value` kein gültiges JSON ist.
   - Beispiel: `substr-jsonpath(${api_response}, '$.data.name')` – extrahiert das Feld `name`.
   - Beispiel: `substr-jsonpath(${api_response}, '$.items[0].label')` – erstes Element eines Arrays.
   - Beispiel: `number(substr-jsonpath(${api_response}, '$.price'))` – extrahiert einen numerischen Wert.
   - Wird normalerweise zusammen mit `callapi(..., 'json:', ...)` verwendet, um mehrere Felder aus einer API-Antwort zu extrahieren. Siehe [Abrufen mehrerer Werte aus einem API-Aufruf](../advanced-features/call-api#fetching-multiple-values-from-one-api-call).

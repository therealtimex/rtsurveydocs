# Støtt rtSurvey

rtSurvey er en gratis, åpen kildekode, selvdriftet plattform for feltdatainnsamling. Det er ingen SaaS-avgifter, ingen leverandøravhengighet og ingen data som forlater serverne dine.

Å holde det slik krever løpende utvikling, infrastruktur og dokumentasjon. Hvis rtSurvey sparer organisasjonen din tid eller penger, kan du vurdere å støtte utviklingen.

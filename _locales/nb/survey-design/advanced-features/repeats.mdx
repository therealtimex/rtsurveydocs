Denne siden dekker avanserte mønstre for arbeid med repetisjonsgrupper (repeat groups) i rtSurvey. For det grunnleggende om hvordan du setter opp en repetisjonsgruppe, se [Gruppering og repetisjoner](../repeats).

---

## Dynamisk antall repetisjoner

Som standard bestemmer intervjueren hvor mange ganger man skal repetere. Du kan fiksere antall repetisjoner ved hjelp av `repeat_count`:

| type | name | label | repeat_count |
|------|------|-------|--------------|
| begin_repeat | household_members | Husstandsmedlem | `${num_members}` |
| text | member_name | Medlemmets navn | |
| integer | member_age | Alder | |
| end_repeat | | | |

Repetisjonen kjører nøyaktig `${num_members}` ganger, der `num_members` ble samlet inn tidligere i skjemaet. Intervjueren kan ikke legge til eller fjerne forekomster.

---

## Indeksert tilgang: `indexed-repeat()`

Få tilgang til en spesifikk repetisjonsforekomst sin feltverdi fra **utsiden** av repetisjonsgruppen ved hjelp av `indexed-repeat(repeatedField, repeatGroup, index)`:

| type | name | label | calculation |
|------|------|-------|-------------|
| calculate | first_name | | `indexed-repeat(${member_name}, ${household_members}, 1)` |
| calculate | second_name | | `indexed-repeat(${member_name}, ${household_members}, 2)` |

Dette er nyttig for å bygge oppsummeringsfelt eller referere til dataene til det "primære" medlemmet etter repetisjonen.

---

## Posisjon for gjeldende forekomst: `index()`

Inne i en repetisjonsgruppe returnerer `index()` den 1-baserte posisjonen til den gjeldende forekomsten. Bruk den til å merke hver repetisjon eller lage unike identifikatorer:

| type | name | label |
|------|------|-------|
| begin_repeat | plots | Parsell |
| note | plot_label | Parsell nummer `${index()}` |
| text | plot_id | Parsell-ID |
| end_repeat | | |

---

## Referere til felt i samme forekomst

Innenfor en repetisjon, bruk `${fieldname}` for å referere til et annet felt **i samme repetisjonsforekomst**. Det er ikke behov for `indexed-repeat()` innenfor samme løkke:

| type | name | label | relevant |
|------|------|-------|----------|
| begin_repeat | members | Medlem | |
| text | member_name | Navn | |
| integer | member_age | Alder | |
| text | school_name | Skolenavn | `${member_age} < 18` |
| end_repeat | | | |

---

## Referere til foreldrefelt fra innsiden av en repetisjon

Felt utenfor (over) repetisjonsgruppen kan refereres til som normalt med `${fieldname}`:

| type | name | label |
|------|------|-------|
| text | village | Landsbyens navn |
| begin_repeat | plots | Landbruksparsell |
| note | plot_context | Parseller i `${village}` |
| end_repeat | | |

## Oppsummering av repetisjonsdata

Bruk repetisjonsaggregatfunksjoner **utenfor** repetisjonsgruppen for å oppsummere:

| Funksjon | Eksempel | Beskrivelse |
|----------|---------|-------------|
| `count(group)` | `count(${household_members})` | Antall forekomster |
| `sum(field)` | `sum(${loan_amount})` | Sum av et numerisk felt |
| `min(field)` | `min(${member_age})` | Minimumsverdi |
| `max(field)` | `max(${member_age})` | Maksimumsverdi |
| `join(sep, field)` | `join(', ', ${member_name})` | Kommaseparert liste |
| `count-if(group, expr)` | `count-if(${members}, ${member_age} < 18)` | Betinget telling |
| `sum-if(field, expr)` | `sum-if(${loan_amount}, ${loan_amount} > 500)` | Betinget sum |
| `join-if(sep, field, expr)` | `join-if(', ', ${name}, ${age} >= 18)` | Betinget sammenslåing |

### Eksempel: Husstandsoppsummering

| type | name | label | calculation |
|------|------|-------|-------------|
| integer | num_members | Hvor mange medlemmer? | |
| begin_repeat | members | Medlem | `${num_members}` |
| text | member_name | Navn | |
| integer | member_age | Alder | |
| end_repeat | | | |
| calculate | total_members | | `count(${members})` |
| calculate | children_count | | `count-if(${members}, ${member_age} < 18)` |
| calculate | adult_names | | `join-if(', ', ${member_name}, ${member_age} >= 18)` |
| note | summary | `${total_members}` medlemmer; `${children_count}` under 18. Voksne: `${adult_names}` | |

## Nøstede repetisjoner

En repetisjonsgruppe kan inneholde en annen repetisjonsgruppe. Bruk dette forsiktig – nøstede repetisjoner øker kompleksiteten og kan være forvirrende for intervjuere.

| type | name | label |
|------|------|-------|
| begin_repeat | households | Husstand |
| text | hh_id | Husstands-ID |
| begin_repeat | hh_members | Medlem |
| text | member_name | Medlemmets navn |
| end_repeat | | |
| end_repeat | | |

For å referere til et felt i en ytre repetisjon fra den indre repetisjonen, bruk `${fieldname}` – den peker til den nærmeste samsvarende overordnede:

Inne i `hh_members`-repetisjonen vil `${hh_id}` returnere ID-en til den **gjeldende** husstanden, ikke alle husstander.

## Rangering inne i repetisjonsgrupper: `rank-index()`

Når et `rank`-felt finnes inne i en repetisjon, bruk `rank-index(instanceNumber, repeatedField)` fra utsiden for å få den ordinale rangeringen til en spesifikk forekomst:

| type | name | label | calculation |
|------|------|-------|-------------|
| calculate | top_scorer | | `rank-index(1, ${score})` |

`rank-index(1, ${score})` returnerer forekomstindeksen for den høyeste poengsummen.

## `1screen`-utseende på `begin_repeat`

Ved å legge til `1screen` i `appearance`-kolonnen på en `begin_repeat`-rad, vises alle spørsmål for hver forekomst sammen på én skjerm, i stedet for ett spørsmål per skjerm.

| type | name | label | appearance |
|------|------|-------|------------|
| begin_repeat | household_members | Husstandsmedlem | `1screen` |
| text | member_name | Medlemmets navn | |
| integer | member_age | Alder | |
| end_repeat | | | |

Når `1screen` er satt, og det ikke finnes et `repeat_count`-felt eller et `add_repeat`-felt inne i gruppen, vil rtSurvey automatisk generere en sirkulær **+**-knapp nederst på skjermen slik at intervjuere kan legge til nye forekomster uten ekstra konfigurasjon.

| Utseende | Én skjerm per forekomst | Standard +-knapp lagt til |
|------------|-------------------------|------------------------|
| `1screen` | Ja | Ja (når ingen `add_repeat`-underordnet) |
| `field-list` | Ja | Nei |

Bruk `field-list` når du vil ha det grupperte oppsettet uten den automatiske legg til-knappen. Bruk `1screen` når du vil ha både det grupperte oppsettet og en innebygd måte å legge til forekomster på.

---

## `add_repeat` tilpasset legg til-knapp

Et `note`- (eller `text`-) felt plassert **inne** i repetisjonsgruppen med `appearance: add_repeat` vises som en "Legg til"-knapp i full bredde. Knappens tekst kommer fra feltets `label`-kolonne. Når et `add_repeat`-felt er til stede, blir den sirkulære standard +-knappen (fra `1screen`) undertrykt.

Plasser `add_repeat`-feltet som det siste feltet inne i repetisjonsgruppen:

| type | name | label | appearance |
|------|------|-------|------------|
| begin_repeat | members | Medlem | `1screen` |
| text | member_name | Medlemmets navn | |
| integer | member_age | Alder | |
| note | btn_add | + Legg til medlem | `add_repeat` |
| end_repeat | | | |

### Tilpasning av farger

Oppgi en fargekode inne i appearance-verdien for å style knappen:

| Appearance-verdi | Resultat |
|------------------|--------|
| `add_repeat <#04B404/>` | Grønn bakgrunn, standard tekstfarge |
| `add_repeat 04B404-ffffff` | Grønn bakgrunn, hvit tekst |

Den første fargen er bakgrunnen og den andre (etter bindestreken) er tekstfargen. Utelat `#` når du bruker bindestrek-separert form.

### Ikon-variant

Bruk `add_repeat icon` (med mellomrom) for å vise en kompakt sirkulær ikonknapp i stedet for knappen i full bredde:

| type | name | label | appearance |
|------|------|-------|------------|
| note | btn_add | + Legg til | `add_repeat icon` |

## Sletteknapper: `delete-repeat-current` og `delete-repeat-last`

Et `note`-felt inne i repetisjonsgruppen med `appearance: delete-repeat-current` eller `appearance: delete-repeat-last` vises som en delt sletteknapp.

| Utseende | Handling |
|------------|--------|
| `delete-repeat-current` | Sletter den gjeldende (aktive) forekomsten |
| `delete-repeat-last` | Sletter den siste forekomsten i repetisjonen |

Standardknappen (uten ikon) er en delt knapp: et søppelbøtteikon til venstre og feltets etikettekst til høyre, og den strekker seg over hele skjermens bredde.

### Ikon-variant

Legg til `-icon` for å få en kompakt sirkulær søppelbøtte-ikonknapp:

| Utseende | Resultat |
|------------|--------|
| `delete-repeat-current-icon` | Sirkulært søppelbøtteikon, sletter gjeldende forekomst |
| `delete-repeat-last-icon` | Sirkulært søppelbøtteikon, sletter siste forekomst |

### Tilpasning av farger

Fargeformatet er identisk med `add_repeat`: bruk `<#RRGGBB/>` eller `RRGGBB-RRGGBB` (bakgrunn-tekst).

### Komplett mønstereksempel

Følgende repetisjon bruker `1screen`, en sirkulær slett-gjeldende-knapp øverst, og en legg til-knapp i full bredde nederst:

| type | name | label | appearance |
|------|------|-------|------------|
| begin_repeat | members | Medlem | `1screen` |
| note | btn_del | Fjern | `delete-repeat-current-icon` |
| text | member_name | Medlemmets navn | |
| integer | member_age | Alder | |
| note | btn_add | + Legg til medlem | `add_repeat` |
| end_repeat | | | |

## Beste praksis

1. Bruk alltid `repeat_count` når antall repetisjoner er kjent på forhånd – det forhindrer at intervjuere ved et uhell legger til eller fjerner forekomster.
2. Hold repetisjonsgruppene fokuserte – en repetisjon med 20+ spørsmål per forekomst er vanskelig å navigere i.
3. Gi repetisjonsgruppene tydelige navn (f.eks. `household_members`, ikke `repeat1`) – navnet vises i funksjonskall og eksporterte data.
4. Test med det maksimale forventede antall forekomster for å verifisere ytelsen.
5. Bruk `1screen` på `begin_repeat` for å vise alle spørsmål på én skjerm per forekomst, kombinert med et `add_repeat`-notatfelt inne i gruppen for å gi intervjuerne en tydelig merket "Legg til"-knapp.

---

## Begrensninger

- `indexed-repeat()` krever en gyldig indeks (1 til antall forekomster) – indekser utenfor området returnerer tomt.
- Nøstede repetisjoner utover 2 nivåer anbefales ikke og kan føre til visningsproblemer på enkelte enheter.
- Aggregatfunksjoner (`sum`, `count`, osv.) opererer på hele repetisjonsgruppen – du kan ikke aggregere et delsett av forekomster uten `*-if`-varianter.

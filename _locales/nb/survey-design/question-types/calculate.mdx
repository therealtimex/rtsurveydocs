Spørsmålstypen `calculate` kjører en formel stille i bakgrunnen. Den lagrer resultatet i et navngitt felt som andre spørsmål kan referere til — men den viser ingen inndata eller etikett til intervjueren. Bruk den til å avlede verdier, slå sammen strenger, kjøre betinget logikk eller slå opp data som du trenger senere i skjemaet.

---

## Grunnleggende syntaks

| type | name | label | calculation |
|------|------|-------|-------------|
| calculate | total | | `${price} * ${quantity}` |

- **type**: Alltid `calculate`.
- **name**: Et unikt feltnavn. Andre spørsmål refererer til dette med `${name}`.
- **label**: La stå tomt — calculate-felt vises aldri for intervjueren.
- **calculation**: Formelen som skal evalueres. Støtter alle [XLSForm-funksjoner](../operators-and-functions/functions) og feltreferanser.

## Vanlige mønstre

### Aritmetikk

| type | name | label | calculation |
|------|------|-------|-------------|
| integer | price | Unit price | |
| integer | quantity | Quantity | |
| calculate | total | | `${price} * ${quantity}` |
| note | total_note | Total: `${total}` | |

### Sammenslåing av strenger (String concatenation)

| type | name | label | calculation |
|------|------|-------|-------------|
| text | first_name | First name | |
| text | last_name | Last name | |
| calculate | full_name | | `concat(${first_name}, ' ', ${last_name})` |

### Betinget verdi

| type | name | label | calculation |
|------|------|-------|-------------|
| integer | score | Score (0–100) | |
| calculate | grade | | `if(${score} >= 90, 'A', if(${score} >= 75, 'B', if(${score} >= 60, 'C', 'F')))` |

### Alder fra fødselsdato

| type | name | label | calculation |
|------|------|-------|-------------|
| date | dob | Date of birth | |
| calculate | age_years | | `int((today() - ${dob}) div 365.25)` |

## Bruk `once()` for å låse verdien

Som standard beregnes `calculate` på nytt hver gang et referert felt endres. Pakk formelen inn i `once()` for å evaluere bare ved første innlasting og fryse resultatet:

| type | name | label | calculation |
|------|------|-------|-------------|
| calculate | interview_start | | `once(now())` |

Bruk `once()` for tidsstempler, startverdier eller alle tilfeller der omberegning ved endring er uønsket.

## Hente data fra eksterne kilder

### Fra en CSV-fil

```
pulldata('staff.csv', 'department', 'name', ${staff_id})
```

Se [pulldata()](../operators-and-functions/pulldata) for fullstendig referanse.

### Fra en medfølgende SQLite-database

```
pulldata('rawquery',
  concat(${family_path}, '/locations.db::provinces'),
  'SELECT name FROM provinces WHERE id = ?',
  ${province_id})
```

Se [Lokalt databasesøk](../advanced-features/local-database-search) for detaljer om sti-konstruksjon.

### Fra app-kontekst

```
pulldata('app-api', 'user.username')
pulldata('app-api', 'family_path')
```

Se [App API](../app-api) for alle tilgjengelige nøkler.

## Bruk av calculate i relevant og constraint

Andre felt kan referere til et `calculate`-resultat akkurat som ethvert annet felt:

| type | name | label | relevant | constraint |
|------|------|-------|----------|------------|
| calculate | bmi | | | `${weight} div (${height} * ${height}) * 10000` |
| note | bmi_warning | BMI is very high — please verify weight and height. | `${bmi} > 40` | |

## Beste praksis

1. Gi calculate-felt meningsfulle navn — `total_cost` er tydeligere enn `calc1` og lettere å spore i eksporter.
2. Del opp komplekse formler i flere koblede calculate-felt i stedet for ett dypt nøstet uttrykk.
3. Bruk `once()` for tidsstempler og innledende øyeblikksbilder for å forhindre at verdier endres etter første registrering.
4. Plasser `calculate`-felt før det første spørsmålet som refererer til dem — evalueringsrekkefølgen følger skjemaets rekkefølge.
5. Hold `label`-kolonnen tom. Noen verktøy viser etiketten; å la den være blank unngår forvirrende utdata.

## Begrensninger

- Calculate-felt vises aldri direkte for intervjueren — bruk et `note`-felt for å vise resultatet.
- Kolonnen `calculation` er obligatorisk; en `calculate`-rad uten formel lagrer alltid en tom streng.
- Resultater beregnes på nytt ved hver skjemaendring med mindre de er pakket inn i `once()` — svært komplekse formler i store skjemaer kan påvirke ytelsen på enheter med lave spesifikasjoner.
- Beregnede verdier lagres som strenger i innsendingen. Bruk `number()`, `int()` eller `boolean()` for å konvertere typen når du sender resultatet til aritmetiske eller logiske uttrykk.

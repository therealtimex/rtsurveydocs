# Підтримайте rtSurvey

rtSurvey — безкоштовна, відкрита, самостійно розгорнута платформа для збору польових даних. Без платежів SaaS, без прив'язки до постачальника та без витоку даних з ваших серверів.

Підтримка цього потребує постійної розробки, інфраструктури та документації. Якщо rtSurvey економить час або гроші вашої організації, розгляньте можливість підтримки його розвитку.

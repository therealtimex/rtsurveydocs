Тип питання `calculate` непомітно виконує формулу у фоновому режимі. Він зберігає результат у іменованому полі, на яке можуть посилатися інші питання, але не показує інтерв'юеру жодних полів введення або міток. Використовуйте його для обчислення значень, об'єднання рядків, виконання умовної логіки або пошуку даних, які знадобляться вам пізніше у формі.

---

## Базовий синтаксис

| type | name | label | calculation |
|------|------|-------|-------------|
| calculate | total | | `${price} * ${quantity}` |

- **type**: Завжди `calculate`.
- **name**: Унікальне ім'я поля. Інші питання посилаються на нього за допомогою `${name}`.
- **label**: Залиште порожнім — поля calculate ніколи не показуються інтерв'юеру.
- **calculation**: Формула для обчислення. Підтримує всі [функції XLSForm](../operators-and-functions/functions) та посилання на поля.

---

## Поширені шаблони

### Арифметика

| type | name | label | calculation |
|------|------|-------|-------------|
| integer | price | Unit price | |
| integer | quantity | Quantity | |
| calculate | total | | `${price} * ${quantity}` |
| note | total_note | Total: `${total}` | |

### Об'єднання рядків (Конкатенація)

| type | name | label | calculation |
|------|------|-------|-------------|
| text | first_name | First name | |
| text | last_name | Last name | |
| calculate | full_name | | `concat(${first_name}, ' ', ${last_name})` |

### Умовне значення

| type | name | label | calculation |
|------|------|-------|-------------|
| integer | score | Score (0–100) | |
| calculate | grade | | `if(${score} >= 90, 'A', if(${score} >= 75, 'B', if(${score} >= 60, 'C', 'F')))` |

### Вік за датою народження

| type | name | label | calculation |
|------|------|-------|-------------|
| date | dob | Date of birth | |
| calculate | age_years | | `int((today() - ${dob}) div 365.25)` |

## Використання `once()` для фіксації значення

За замовчуванням `calculate` перераховується щоразу, коли змінюється будь-яке поле, на яке дається посилання. Оберніть формулу в `once()`, щоб вона обчислювалася лише при першому завантаженні і результат фіксувався:

| type | name | label | calculation |
|------|------|-------|-------------|
| calculate | interview_start | | `once(now())` |

Використовуйте `once()` для міток часу, початкових значень або будь-яких випадків, коли перерахунок при зміні небажаний.

## Витяг даних із зовнішніх джерел

### З CSV-файлу

```
pulldata('staff.csv', 'department', 'name', ${staff_id})
```

Повний довідник див. у розділі [pulldata()](../operators-and-functions/pulldata).

### З вбудованої бази даних SQLite

```
pulldata('rawquery',
  concat(${family_path}, '/locations.db::provinces'),
  'SELECT name FROM provinces WHERE id = ?',
  ${province_id})
```

Подробиці про побудову шляхів див. у розділі [Пошук у локальній базі даних](../advanced-features/local-database-search).

### З контексту програми

```
pulldata('app-api', 'user.username')
pulldata('app-api', 'family_path')
```

Усі доступні ключі див. у розділі [App API](../app-api).

## Використання calculate у relevant та constraint

Інші поля можуть посилатися на результат `calculate` так само, як і на будь-яке інше поле:

| type | name | label | relevant | constraint |
|------|------|-------|----------|------------|
| calculate | bmi | | | `${weight} div (${height} * ${height}) * 10000` |
| note | bmi_warning | BMI is very high — please verify weight and height. | `${bmi} > 40` | |

## Кращі практики

1. Дайте полям calculate змістовні імена — `total_cost` зрозуміліше, ніж `calc1`, і його легше відстежити при експорті.
2. Розбийте складні формули на кілька пов'язаних полів calculate замість одного глибоко вкладеного виразу.
3. Використовуйте `once()` для міток часу та початкових моментальних знімків, щоб значення не змінювалися після першого отримання.
4. Розміщуйте поля `calculate` перед першим питанням, яке на них посилається — порядок обчислення відповідає порядку у формі.
5. Залиште стовпець `label` порожнім. Деякі інструменти відображають мітку; якщо залишити її порожньою, це допоможе уникнути плутанини у виведенні.

## Обмеження

- Поля calculate ніколи не відображаються інтерв'юеру безпосередньо — використовуйте поле `note` для відображення результату.
- Стовпець `calculation` є обов'язковим; рядок `calculate` без формули завжди зберігає порожній рядок.
- Результати перераховуються при кожній зміні форми, якщо вони не обернуті в `once()` — дуже складні формули у великих формах можуть вплинути на продуктивність рендерингу на бюджетних пристроях.
- Обчислені значення зберігаються у відправці як рядки. Використовуйте `number()`, `int()` або `boolean()` для приведення типів при передачі результату в арифметичні або логічні вирази.

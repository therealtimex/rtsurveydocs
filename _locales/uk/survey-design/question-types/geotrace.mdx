Тип питання geotrace у XLSForm та rtSurvey дозволяє респондентам фіксувати серію пов'язаних точок на карті, створюючи лінії або шляхи. Ця функція особливо корисна для картування маршрутів, меж або лінійних об'єктів у просторових опитуваннях.

## Базова специфікація XLSForm

| type     | name        | label                           |
|----------|-------------|--------------------------------|
| geotrace | river_path  | Trace the path of the river     |

Для отримання додаткових відомостей про базовий тип питання geotrace дивіться [специфікацію XLSForm](https://xlsform.org/en/#question-types).

## Використання

Питання geotrace зазвичай використовуються для:

1. Картування маршрутів або шляхів, пройдених під час польових опитувань
2. Трасування лінійних об'єктів, таких як дороги, річки або кордони
3. Фіксування обсягу лінійної інфраструктури (наприклад, трубопроводи, лінії електропередач)
4. Запис маршрутів подорожей у транспортних дослідженнях
5. Визначення трансектів в екологічних опитуваннях

## Найкращі практики

1. Переконайтеся, що на пристрої увімкнені служби визначення місцезнаходження та надані дозволи.
2. Надавайте чіткі інструкції щодо того, як трасувати шлях та які об'єкти слід включити.
3. Розгляньте використання супутникових знімків або базових карт для допомоги респондентам у точному трасуванні шляхів.
4. Будьте уважні до потенційної складності трас та їх впливу на розмір і обробку даних.

## Приклад використання

Ось приклад того, як можна використовувати питання geotrace в опитуванні:

| type     | name           | label                                      | hint                                        |
|----------|----------------|--------------------------------------------|--------------------------------------------|
| geotrace | hiking_trail   | Trace the path of the hiking trail         | Start at the trailhead and end at the summit |

## Розширення rtSurvey

Хоча базова специфікація XLSForm для питань geotrace є простою, rtSurvey може пропонувати додаткові функції або налаштування:

1. Інтеграція з офлайн-картами для віддалених районів
2. Параметри для встановлення мінімальної та максимальної кількості точок для траси
3. Можливість редагувати або уточнювати траси після початкового малювання
4. Підтримка автоматичного трасування через встановлені інтервали під час руху

## Формат даних

Дані geotrace зазвичай зберігаються як рядок з розділених пробілами пар координат, схожий на geoshape, але без кінцевої точки:

```
lat1 lon1; lat2 lon2; lat3 lon3; ... latN lonN
```

Наприклад:
```
38.253094215699576 21.756382658677467; 38.25021274773806 21.756382658677467; 38.25007793942195 21.763892843919166; 38.25290886154963 21.763935759263404
```

## Міркування для аналізу

При використанні питань geotrace врахуйте:

1. Як географічні дані будуть візуалізовані та проаналізовані (наприклад, ПЗ ГІС)
2. Потенційну необхідність очищення або спрощення складних трас
3. Заходи конфіденційності та захисту даних для обробки детальних просторових даних
4. Інтеграція з іншими просторовими джерелами даних для комплексного аналізу

## Обмеження

- Трасування точних шляхів на маленьких мобільних екранах може бути складним.
- Складні траси можуть вимагати значних ресурсів для зберігання та обробки.
- Безперервне використання GPS для автоматичного трасування може швидко розряджати акумулятори пристроїв.
- Можуть виникнути проблеми конфіденційності, пов'язані зі збором детальних даних про шлях.

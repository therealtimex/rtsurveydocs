---

**Елементи керування навігацією у формі** — це значення оформлення, що розміщуються в полях типу `note` (або `text`), які відображаються у вигляді стилізованих кнопок на всю ширину в нижній частині опитування. Вони дозволяють інтерв'юеру зберегти надіслані дані та вийти з форми одним дотиком — або як завершений (фіналізований) запис, або як чернетку (незавершений запис).

---

## `SaveFinalizedExit<#COLOR/>`

Відображає кнопку, яка **зберігає надсилання як завершене** та закриває форму. Текст кнопки береться зі стовпця `label` цього поля.

| XLSForm column | Значення |
|----------------|-------|
| `type` | `note` |
| `name` | будь-яке унікальне ім'я (наприклад, `btn_finish`) |
| `label` | текст, що відображається на кнопці |
| `appearance` | `SaveFinalizedExit<#RRGGBB/> toc-hide` |

Надсилання позначається як остаточний, повний запис. Це еквівалентно натисканню на вбудовану кнопку надсилання.

---

## `SaveIncompleteExit<#COLOR/>`

Відображає кнопку, яка **зберігає надсилання як незавершене (чернетка)** та закриває форму. Інтерв'юер може повернутися до неї пізніше і продовжити заповнення.

| XLSForm column | Значення |
|----------------|-------|
| `type` | `note` |
| `name` | будь-яке унікальне ім'я (наприклад, `btn_pause`) |
| `label` | текст, що відображається на кнопці |
| `appearance` | `SaveIncompleteExit<#RRGGBB/> toc-hide` |

---

## Синтаксис кольору

Обидва оформлення приймають вбудований колір у форматі `<#RRGGBB/>`:

- `#`, за яким слідує рівно **6 шістнадцяткових цифр** (у верхньому або нижньому регістрі)
- Заключна частина `/>` **обов'язкова** — її відсутність порушує синтаксичний аналіз
- Приклад: `<#04B404/>` (зелений), `<#EDC602/>` (бурштиновий), `<#D9534F/>` (червоний)

Колір керує фоном кнопки. Колір тексту визначається додатком автоматично.

---

## Приклад

Наступні два поля, розміщені в кінці форми, створюють зелену кнопку **Надіслати** та бурштинову кнопку **Зберегти як чернетку**:

| type | name | label | appearance |
|------|------|-------|------------|
| note | btn_finish | Надіслати | `SaveFinalizedExit<#04B404/> toc-hide` |
| note | btn_pause | Зберегти як чернетку | `SaveIncompleteExit<#EDC602/> toc-hide` |

---

## toc-hide — виключення кнопок зі змісту

Токен оформлення `toc-hide` повідомляє rtSurvey про необхідність виключити поле зі **змісту** форми (загального списку питань). Кнопки навігації не є питаннями, тому вони ніколи не повинні відображатися у змісті.

Завжди додавайте `toc-hide` після оформлення виходу:

```
SaveFinalizedExit<#04B404/> toc-hide
SaveIncompleteExit<#EDC602/> toc-hide
```

Див. [Оформлення — toc-hide](../appearance#group-and-navigation) для довідки по toc-hide.

---

## Правила розміщення

При додаванні елементів керування навігацією у форму дотримуйтесь наступних правил:

- Розміщуйте обидві кнопки в **самому кінці** форми, після всіх питань та груп.
- Завжди включайте **обидві** кнопки разом — одну для завершення та одну для чернетки — щоб у інтерв'юера завжди була можливість вийти незалежно від стану заповнення.
- Використовуйте стовпець `relevant` для кнопки фіналізованого виходу, якщо надсилання має бути дозволено лише за виконання певних умов (наприклад, завершено обов'язковий розділ). Кнопка виходу для чернетки зазвичай повинна залишатися **завжди видимою**.

---

## Умовний фіналізований вихід

Використовуйте стовпець `relevant` для керування відображенням кнопки фіналізованого виходу. Вихід для чернетки має залишатися безумовно видимим, щоб інтерв'юер завжди міг перерватися і повернутися.

| type | name | label | appearance | relevant |
|------|------|-------|------------|----------|
| note | btn_finish | Надіслати | `SaveFinalizedExit<#04B404/> toc-hide` | `${consent} = 'yes' and ${section_a_complete} = '1'` |
| note | btn_pause | Зберегти як чернетку | `SaveIncompleteExit<#EDC602/> toc-hide` | |

У цьому прикладі кнопка **Надіслати** з'являється лише тоді, коли інтерв'юер дав згоду та позначив розділ А як завершений. Кнопка **Зберегти як чернетку** доступна завжди.

---

## Обмеження

- **Тип поля має бути `note` або `text`.** Використання цього оформлення для будь-яких інших типів питань не підтримується.
- **Лише 6-значний шістнадцятковий код.** Скорочений шістнадцятковий код (`<#FFF/>`) та іменовані кольори не підтримуються — завжди використовуйте повний 6-значний формат (наприклад, `<#FFFFFF/>`).
- **Стовпець label — це текст кнопки.** Стовпець `hint` для цих полів ігнорується; відображається лише `label`.
- **Повинні бути присутні обидві кнопки.** Відсутність кнопки виходу для чернетки позбавляє інтерв'юера можливості зробити паузу в середині форми.

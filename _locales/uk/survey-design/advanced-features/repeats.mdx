Ця сторінка описує просунуті шаблони для роботи з групами повторів у rtSurvey. Основи налаштування груп повторів див. у розділі [Групування та повтори](../repeats).

---

## Динамічна кількість повторів

За замовчуванням інтерв'юер сам вирішує, скільки разів повторити групу. Ви можете зафіксувати кількість повторів за допомогою `repeat_count`:

| type | name | label | repeat_count |
|------|------|-------|--------------|
| begin_repeat | household_members | Член домогосподарства | `${num_members}` |
| text | member_name | Ім'я члена | |
| integer | member_age | Вік | |
| end_repeat | | | |

Повтор буде виконано рівно `${num_members}` разів, де `num_members` — значення, зібране раніше у формі. Інтерв'юер не зможе додавати або видаляти ітерації.

---

## Індексований доступ: `indexed-repeat()`

Ви можете отримати доступ до значення поля конкретної ітерації повтору **ззовні** групи повторів, використовуючи функцію `indexed-repeat(repeatedField, repeatGroup, index)`:

| type | name | label | calculation |
|------|------|-------|-------------|
| calculate | first_name | | `indexed-repeat(${member_name}, ${household_members}, 1)` |
| calculate | second_name | | `indexed-repeat(${member_name}, ${household_members}, 2)` |

Це корисно для створення підсумкових полів або звернення до даних «основного» члена після завершення циклу повторів.

---

## Позиція поточної ітерації: `index()`

Усередині групи повторів функція `index()` повертає порядковий номер поточної ітерації (починаючи з 1). Використовуйте її для маркування кожного повтору або створення унікальних ідентифікаторів:

| type | name | label |
|------|------|-------|
| begin_repeat | plots | Ділянка |
| note | plot_label | Номер ділянки `${index()}` |
| text | plot_id | ID ділянки |
| end_repeat | | |

---

## Посилання на поля в тій же ітерації

Усередині повтору використовуйте `${fieldname}` для посилання на інше поле **в тій же ітерації**. У межах одного циклу немає потреби використовувати `indexed-repeat()`:

| type | name | label | relevant |
|------|------|-------|----------|
| begin_repeat | members | Член | |
| text | member_name | Ім'я | |
| integer | member_age | Вік | |
| text | school_name | Назва школи | `${member_age} < 18` |
| end_repeat | | | |

---

## Посилання на батьківські поля зсередини повтору

На поля, що знаходяться поза групою повторів (вище неї), можна посилатися звичайним способом через `${fieldname}`:

| type | name | label |
|------|------|-------|
| text | village | Назва села |
| begin_repeat | plots | Сільськогосподарська ділянка |
| note | plot_context | Ділянки у населеному пункті `${village}` |
| end_repeat | | |

## Підсумовування даних повторів

Використовуйте агрегатні функції повторів **поза** групою повторів для підбиття підсумків:

| Function | Example | Description |
|----------|---------|-------------|
| `count(group)` | `count(${household_members})` | Кількість ітерацій |
| `sum(field)` | `sum(${loan_amount})` | Сума числового поля |
| `min(field)` | `min(${member_age})` | Мінімальне значення |
| `max(field)` | `max(${member_age})` | Максимальне значення |
| `join(sep, field)` | `join(', ', ${member_name})` | Список через кому |
| `count-if(group, expr)` | `count-if(${members}, ${member_age} < 18)` | Кількість за умовою |
| `sum-if(field, expr)` | `sum-if(${loan_amount}, ${loan_amount} > 500)` | Сума за умовою |
| `join-if(sep, field, expr)` | `join-if(', ', ${name}, ${age} >= 18)` | Об'єднання за умовою |

### Приклад: Зведення по домогосподарству

| type | name | label | calculation |
|------|------|-------|-------------|
| integer | num_members | Скільки членів родини? | |
| begin_repeat | members | Член родини | `${num_members}` |
| text | member_name | Ім'я | |
| integer | member_age | Вік | |
| end_repeat | | | |
| calculate | total_members | | `count(${members})` |
| calculate | children_count | | `count-if(${members}, ${member_age} < 18)` |
| calculate | adult_names | | `join-if(', ', ${member_name}, ${member_age} >= 18)` |
| note | summary | Всього: `${total_members}`; Дітей до 18: `${children_count}`. Дорослі: `${adult_names}` | |

## Вкладені повтори

Група повторів може містити іншу групу повторів. Використовуйте це обережно — вкладені повтори ускладнюють форму та можуть заплутати інтерв'юерів.

| type | name | label |
|------|------|-------|
| begin_repeat | households | Домогосподарство |
| text | hh_id | ID домогосподарства |
| begin_repeat | hh_members | Член родини |
| text | member_name | Ім'я члена |
| end_repeat | | |
| end_repeat | | |

Щоб послатися на поле зовнішнього повтору з внутрішнього, використовуйте `${fieldname}` — пошук йтиме до найближчого відповідного предка:

Усередині повтору `hh_members` вираз `${hh_id}` поверне ID **поточного** домогосподарства, а не список усіх ID.

## Ранг усередині груп повторів: `rank-index()`

Якщо всередині повтору є поле типу `rank`, використовуйте `rank-index(instanceNumber, repeatedField)` ззовні, щоб отримати порядковий номер (індекс) конкретної ітерації за рангом:

| type | name | label | calculation |
|------|------|-------|-------------|
| calculate | top_scorer | | `rank-index(1, ${score})` |

`rank-index(1, ${score})` повертає індекс ітерації з найвищим балом.

## Зовнішній вигляд `1screen` для `begin_repeat`

Додавання `1screen` у колонку `appearance` рядка `begin_repeat` дозволяє відображати всі питання кожної ітерації разом на одному екрані, замість того щоб показувати по одному питанню на екран.

| type | name | label | appearance |
|------|------|-------|------------|
| begin_repeat | household_members | Член домогосподарства | `1screen` |
| text | member_name | Ім'я члена | |
| integer | member_age | Вік | |
| end_repeat | | | |

Якщо встановлено `1screen` і в групі відсутні поля `repeat_count` та `add_repeat`, rtSurvey автоматично відображає круглу кнопку **+** у нижній частині екрана, щоб інтерв'юери могли додавати нові ітерації без додаткового налаштування.

| Appearance | Один екран на ітерацію | Кнопка «+» за замовчуванням |
|------------|-------------------------|------------------------|
| `1screen` | Так | Так (якщо немає дочірнього `add_repeat`) |
| `field-list` | Так | Ні |

Використовуйте `field-list`, якщо вам потрібна групування на одному екрані, але без автоматичної кнопки додавання. Використовуйте `1screen`, якщо вам потрібна і групування, і вбудований спосіб додавання ітерацій.

## Настроювана кнопка додавання `add_repeat`

Поле типу `note` (або `text`), розміщене **всередині** групи повторів з `appearance: add_repeat`, відображається як кнопка «Додати» на всю ширину екрана. Текст кнопки береться з колонки `label` цього поля. Якщо поле `add_repeat` присутнє, стандартна кругла кнопка «+» (від `1screen`) ховається.

Розмістіть поле `add_repeat` останнім у групі повторів:

| type | name | label | appearance |
|------|------|-------|------------|
| begin_repeat | members | Член родини | `1screen` |
| text | member_name | Ім'я члена | |
| integer | member_age | Вік | |
| note | btn_add | + Додати члена родини | `add_repeat` |
| end_repeat | | | |

### Налаштування кольору

Ви можете задати колір кнопки у значенні `appearance`:

| Appearance value | Result |
|------------------|--------|
| `add_repeat <#04B404/>` | Зелений фон, стандартний колір тексту |
| `add_repeat 04B404-ffffff` | Зелений фон, білий текст |

Перший колір — фон, другий (після дефіса) — текст. Не використовуйте символ `#` при форматі з дефісом.

### Варіант з іконкою

Використовуйте `add_repeat icon` (через пробіл), щоб замість широкої кнопки відобразити компактну круглу кнопку з іконкою:

| type | name | label | appearance |
|------|------|-------|------------|
| note | btn_add | + Додати | `add_repeat icon` |

## Кнопки видалення: `delete-repeat-current` та `delete-repeat-last`

Поле типу `note` всередині групи повторів з `appearance: delete-repeat-current` або `appearance: delete-repeat-last` відображається як комбінована кнопка видалення.

| Appearance | Action |
|------------|--------|
| `delete-repeat-current` | Видаляє поточну (активну) ітерацію |
| `delete-repeat-last` | Видаляє останню ітерацію у групі |

Стандартна кнопка (без іконки) є комбінованою: іконка кошика зліва та текст мітки поля справа, на всю ширину екрана.

### Варіант з іконкою

Додайте суфікс `-icon`, щоб отримати компактну круглу кнопку з іконкою кошика:

| Appearance | Result |
|------------|--------|
| `delete-repeat-current-icon` | Кругла іконка кошика, видаляє поточну ітерацію |
| `delete-repeat-last-icon` | Кругла іконка кошика, видаляє останню ітерацію |

### Налаштування кольору

Формат кольору ідентичний `add_repeat`: використовуйте `<#RRGGBB/>` або `RRGGBB-RRGGBB` (фон-текст).

### Приклад повного шаблону

Наступний повтор використовує `1screen`, круглу кнопку видалення поточної ітерації зверху та широку кнопку додавання знизу:

| type | name | label | appearance |
|------|------|-------|------------|
| begin_repeat | members | Член родини | `1screen` |
| note | btn_del | Видалити | `delete-repeat-current-icon` |
| text | member_name | Ім'я члена | |
| integer | member_age | Вік | |
| note | btn_add | + Додати члена родини | `add_repeat` |
| end_repeat | | | |

## Найкращі практики

1. Завжди використовуйте `repeat_count`, якщо кількість повторів відома заздалегідь — це запобіжить випадковому додаванню або видаленню ітерацій інтерв'юером.
2. Робіть групи повторів лаконічними — повтори з 20+ питаннями на ітерацію складні для навігації.
3. Дайте групам повторів зрозумілі імена (наприклад, `household_members`, а не `repeat1`) — ім'я буде використовуватися у функціях та при експорті даних.
4. Тестуйте форму з максимально очікуваною кількістю ітерацій для перевірки продуктивності.
5. Використовуйте `1screen` у `begin_repeat`, щоб показувати всі питання на одному екрані на кожну ітерацію, у поєднанні з полем `add_repeat` всередині групи для створення чітко підписаної кнопки «Додати».

---

## Обмеження

- `indexed-repeat()` вимагає коректного індексу (від 1 до загальної кількості ітерацій) — вихід за межі діапазону поверне порожнє значення.
- Вкладеність повторів понад 2 рівні не рекомендується і може викликати проблеми з відображенням у деяких клієнтах.
- Агрегатні функції (`sum`, `count` тощо) працюють з усією групою повторів — ви не можете агрегувати підмножину ітерацій без використання `*-if` варіантів.

rtSurvey забезпечує надійну багатомовну підтримку, що дозволяє створювати опитування кількома мовами. Ця функція є вирішальною для проведення досліджень серед різноманітних мовних груп або в багатомовному середовищі.

## Налаштування багатомовних опитувань

Щоб створити багатомовне опитування в rtSurvey, вам потрібно додати до вашої XLSForm стовпці, специфічні для конкретної мови. Ось як це зробити:

1. **Переклади міток (Label Translations)**: Додайте стовпці для кожної мови, використовуючи формат `label::Language (code)`.
2. **Переклади підказок (Hint Translations)**: Використовуйте `hint::Language (code)` для перекладу підказок.
3. **Переклади медіафайлів (Media File Translations)**: Для медіафайлів, специфічних для мови, використовуйте `media::Language (code)`.

Приклад:

```
| type    | name | label::English (en) | label::Español (es) | hint::English (en) | hint::Español (es) |
|---------|------|---------------------|---------------------|---------------------|---------------------|
| integer | age  | How old are you?    | ¿Cuántos años tienes?| Enter your age      | Ingrese su edad     |
```

## Мовні коди

Рекомендується використовувати офіційні 2-символьні мовні коди (субтеги) після назви мови. Це полегшує відповідність мови форми мові інтерфейсу користувача. Офіційні коди можна знайти [тут](https://www.iana.org/assignments/language-subtag-registry/language-subtag-registry).

## Встановлення мови за замовчуванням

Щоб встановити мову за замовчуванням для збору даних, використовуйте робочий аркуш `settings` у вашій XLSForm:

```
| form_id   | version | default_language |
|-----------|---------|-------------------|
| test_form | 101     | French (fr)       |
```

## Особливості rtSurvey

### Динамічне перемикання мов

rtSurvey дозволяє користувачам динамічно перемикати мови під час збору даних:

- У веб-інтерфейсі використовуйте випадаючий список мов у верхній панелі навігації.
- У мобільному додатку перейдіть до мовних опцій через меню налаштувань.

### Мовні повідомлення про помилки валідації

rtSurvey розширює багатомовну підтримку на повідомлення про валідацію:

```
| type    | name | constraint | constraint_message::English (en) | constraint_message::Español (es) |
|---------|------|------------|----------------------------------|----------------------------------|
| integer | age  | . <= 150   | Age must be 150 or less          | La edad debe ser 150 o menos     |
```

### Локалізовані повідомлення про обов'язковість заповнення

Використовуйте `required_message::Language (code)`, щоб показати перекладену помилку, коли обов'язкове поле залишається порожнім:

```
| type | name | required | required_message::English (en) | required_message::Tiếng Việt (vi) |
|------|------|----------|-------------------------------|----------------------------------|
| text | name | yes | This field is required | Trường này là bắt buộc |
```

### Підтримка мов RTL

Для мов з письмом справа наліво (RTL), таких як арабська або іврит, rtSurvey автоматично налаштовує макет:

```
| type | name | label::English (en) | label::Arabic (ar) |
|------|------|---------------------|---------------------|
| text | name | Your name           | اسمк                |
```

### Мовний вигляд (Appearance)

rtSurvey дозволяє вказати різні вигляди для різних мов:

```
| type | name | label::English (en) | label::Chinese (zh) | appearance::English (en) | appearance::Chinese (zh) |
|------|------|---------------------|---------------------|--------------------------|---------------------------|
| text | address | Address          | 地址                 | multiline                | textarea                  |
```

## Форматування HTML у двомовних мітках

Ви можете комбінувати HTML-теги з мовними обгортками в одній клітинці мітки. rtSurvey витягує блок активної мови та відображає решту HTML.

Приклад використання жирного шрифту та кольору тексту для кожної мови:

```
<en><big><b>Section 2: Household Income</b></big><br>Ask the household head only.</en><vi><big><b>Phần 2: Thu nhập hộ gia đình</b></big><br>Chỉ hỏi chủ hộ.</vi>
```

Підтримувані інлайнові теги всередині мовних обгорток: `<b>`, `<i>`, `<u>`, `<big>`, `<small>`, `<font color="...">`, `<br>`, `<span style="...">`.

Приклад кольорового тексту для кожної мови:

```
<en><font color="red">Required field</font></en><vi><font color="red">Trường bắt buộc</font></vi>
```

## Обчислення з урахуванням мови

Коли форма має поле `${language_use}` (встановлюється віджетом `change_language`), використовуйте `if()`, щоб повернути значення активною мовою:

```
if(${language_use} = 'en', label_en, label_vi)
```

Приклад — відображення результату пошуку активною мовою за допомогою `pulldata('rawquery', ...)`:

```
| type      | name        | calculation                                                                 |
|-----------|-------------|-----------------------------------------------------------------------------|
| calculate | district_label | if(${language_use} = 'en', pulldata('rawquery', concat(${family_path}, '/locations.db::externalData'), 'SELECT label_en FROM externalData WHERE code = ?', ${district}), pulldata('rawquery', concat(${family_path}, '/locations.db::externalData'), 'SELECT label_vi FROM externalData WHERE code = ?', ${district})) |
```

Примітка: Поле `${language_use}` зазвичай встановлюється віджетом appearance `change_language`. Дивіться Appearance — change_language.

## Кращі практики для багатомовних опитувань

1. **Послідовне іменування**: Використовуйте однакові мовні коди у всій формі.
2. **Професійний переклад**: Залучайте професійних перекладачів, знайомих з контекстом опитування.
3. **Примітки щодо контексту**: Надавайте перекладачам примітки щодо контексту для забезпечення точності перекладів.
4. **Тестування**: Тестуйте вашу форму всіма мовами перед розгортанням.
5. **Підтримка Unicode**: Переконайтеся, що ваші пристрої для збору даних підтримують Unicode для нелатинських шрифтів.
6. **Специфічні для мови медіафайли**: Використовуйте культурно відповідні зображення або аудіо для кожної мови.
7. **Уникайте тексту на зображеннях**: Якщо ви використовуєте зображення з текстом, створіть окремі зображення для кожної мови.

## Обробка особливих випадків

### Відповіді на змішаних мовах

rtSurvey дозволяє респондентам вводити текст будь-яким шрифтом, незалежно від вибраної мови форми. Це корисно для фіксації імен або адрес в їх оригінальному написанні.

### Мовні типи питань

Деякі типи питань можуть бути більш доречними для певних мов. rtSurvey дозволяє використовувати різні типи питань для різних мов:

```
| type::English (en) | type::Japanese (ja) | name | label::English (en) | label::Japanese (ja) |
|--------------------|---------------------|------|---------------------|----------------------|
| text               | select_one kanji    | name | Enter your name     | 名前を選んでください    |
```

## Експорт багатомовних даних

При експорті даних з rtSurvey:

- Виберіть експорт конкретною мовою або включіть усі мовні версії.
- Мовні метадані включаються в експорт, вказуючи, яка мова була використана для кожної відповіді.

## Міркування щодо мобільного додатка

- Мобільний додаток rtSurvey підтримує перемикання мов в автономному режимі.
- Переконайтеся, що всі необхідні мовні файли завантажені перед переходом в автономний режим.

## Відомі обмеження

- Деякі розширені функції можуть бути доступні не всіма мовами.
- Надто довгі переклади можуть вплинути на макет на менших екранах.

Використовуючи багатомовні можливості rtSurvey, ви можете створювати інклюзивні та доступні опитування, які охоплюють різноманітні верстви населення та забезпечують високоякісні, лінгвістично точні дані.

SSL необхідно налаштувати перед входом у систему. Коли ви відкриєте програму вперше, ви будете автоматично перенаправлені на екран налаштування SSL.

---

## Варіанти налаштування SSL

![Варіанти налаштування SSL](/img/ssl-setup/ssl-setup-options.png)

Виберіть один із трьох варіантів:

| Варіант | Коли використовувати |
|---------|-----------------------|
| **Безкоштовний піддомен rtsurvey.com** *(Рекомендовано)* | Налаштування DNS не потрібне. Ми створимо запис за вас. Готово за 2–5 хвилин. |
| **Мій власний домен** | У вас уже є домен, і його DNS вказує на цей сервер. |
| **Встановити сертифікат вручну** | Корпоративний або власний центр сертифікації (CA). Потрібен доступ по SSH. |

---

## Варіант 1 — Безкоштовний піддомен rtsurvey.com *(Рекомендовано)*

Це найшвидший варіант. Реєстрація домену або зміна DNS не потрібні.

![Форма налаштування HTTPS](/img/ssl-setup/ssl-setup-form.png)

> **Перш ніж продовжити:** Для безкоштовного піддомену потрібен активний обліковий запис на [licenses.rtsurvey.com](https://licenses.rtsurvey.com). Безкоштовний план включає 1 піддомен (`*.rtsurvey.com`).

1. Натисніть **Free rtsurvey.com subdomain**, щоб розгорнути розділ
2. Введіть бажану назву піддомену в полі **YOUR SUBDOMAIN**

   > Використовуйте малі літери, цифри та дефіси. Від 3 до 30 символів.
   > Приклад: `myproject` → `myproject.rtsurvey.com`

3. Вставте ваш **rtSurvey DNS Token** з [licenses.rtsurvey.com](https://licenses.rtsurvey.com) у поле токена
4. Натисніть **Create secure subdomain**

Після надсилання програма почне підготовку вашого сертифіката:

![Процес налаштування HTTPS](/img/ssl-setup/ssl-setup-progress.png)

Чотири кроки виконуються автоматично:
- **Requesting DNS record** — створює запис DNS для вашого піддомену
- **Waiting for DNS to propagate** — зазвичай займає 2–5 хвилин
- **Issuing SSL certificate** — Let's Encrypt підписує ваш сертифікат
- **Activating HTTPS** — Nginx перезавантажується з новим сертифікатом

5. Після завершення ви будете автоматично перенаправлені на вашу нову URL-адресу HTTPS

## Варіант 2 — Мій власний домен

Використовуйте цей варіант, якщо у вас є існуючий домен і його запис DNS `A` вже вказує на IP-адресу цього сервера.

1. Натисніть **My own domain**, щоб розгорнути розділ
2. Введіть повне ім'я вашого домену (наприклад, `survey.myorganization.org`)
3. Натисніть **Create certificate**



Let's Encrypt перевірить ваш домен і видасть сертифікат. Це вимагає, щоб DNS спочатку був правильно налаштований — інакше запит не вдасться.

---

## Варіант 3 — Встановити сертифікат вручну

Для корпоративних середовищ, що використовують власний або внутрішній центр сертифікації (CA). Ви розмістите файли сертифіката на сервері через SSH, а потім введете свій домен у програмі.

### Попередні вимоги

- Доступ до сервера по SSH
- Дійсний сертифікат і закритий ключ для вашого домену (формат PEM)

### Крок 1 — Вхід на сервер по SSH

```bash
ssh root@<server-ip>
```

### Крок 2 — Розміщення файлів сертифіката

Створіть директорію та скопіюйте файли:

```bash
mkdir -p /etc/letsencrypt/live/<your-domain>
```

Скопіюйте ваші файли в цю директорію з цими точними назвами:

| Файл | Опис |
|------|-------------|
| `fullchain.pem` | Ваш сертифікат + будь-які проміжні сертифікати CA (об'єднані) |
| `privkey.pem` | Ваш закритий ключ |

Приклад:

```bash
# Копіювання з вашого локального комп'ютера (запускайте це локально, а не на сервері)
scp fullchain.pem root@<server-ip>:/etc/letsencrypt/live/<your-domain>/fullchain.pem
scp privkey.pem  root@<server-ip>:/etc/letsencrypt/live/<your-domain>/privkey.pem
```

Встановіть правильні права доступу:

```bash
chmod 644 /etc/letsencrypt/live/<your-domain>/fullchain.pem
chmod 600 /etc/letsencrypt/live/<your-domain>/privkey.pem
```

### Крок 3 — Введення домену в програмі



1. На екрані налаштування SSL натисніть **Install certificate manually**
2. Введіть ім'я вашого домену (воно має збігатися з Common Name або SAN сертифіката)
3. Натисніть **Apply**

Сервер налаштує Nginx з вашим сертифікатом і автоматично перезавантажиться.

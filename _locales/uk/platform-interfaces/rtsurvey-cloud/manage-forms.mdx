Модуль **Управління формами** є основним шлюзом для організації ваших інструментів опитування та координації польових завдань. Він надає детальний контроль над доступністю форм, переглядом даних та цільовими пристроями.

![Інтерфейс управління формами](/images/manage_forms.png)

## Огляд сімейства форм

У меню **Form & Data Entry** розділ **Form Family** відображає комплексну таблицю всіх імпортованих форм разом з основними елементами управління швидким доступом. Цей централізований вигляд дозволяє менеджерам проектів швидко розгортати та налаштовувати окремі опитування.

### Ключові стовпці даних і параметри конфігурації

- **Data View:** Прямий доступ до відправлених записів і попередніх переглядів наборів даних для кожної форми.
- **Allow Edit:** Швидке перемикання для блокування або розблокування можливості польових працівників редагувати відправлені дані (статуси Активний/Неактивний).
- **Public Visibility:** Перемикач для публічного доступу до форми без аутентифікації анкетера.
- **Webform's URL:** Миттєве отримання унікального публічного посилання для поширення форм збору даних на основі браузера.
- **Override Settings:** Розширене модальне вікно конфігурацій (доступне через значок шестерні) для налаштування правил, значень та відключення конкретних функцій форми.
- **Form Identifiers:** Перегляд стандартних метаданих, включаючи назву сімейства форм, код сімейства та унікальний ID форми.
- **Geo Configuration:** Специфічні картографічні або geo-point конфігурації, пов'язані зі структурою форми.
- **Lock Form:** Функція блокування доступу до відправлення для завершення фази збору даних.

## Дії з формами та навігація

Верхня панель управління полегшує пакетні операції та альтернативні перегляди форм:

- **Action to Device:** Потужний інструмент-випадаючий список, що дозволяє менеджерам проектів призначати завдання, надсилати цільові форми або виконувати дії безпосередньо на польові пристрої конкретних анкетерів.
- **XLSX Form Tab:** Швидка навігація з основної таблиці управління до середовищ завантаження для обробки нових файлів XLSForm.
- **Form Builder Tab:** Доступ до вбудованого інструменту для візуальної побудови або динамічного редагування форм без використання зовнішнього табличного програмного забезпечення.

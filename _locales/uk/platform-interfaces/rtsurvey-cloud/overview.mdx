rtCloud — це надійний серверний компонент екосистеми rtSurvey, призначений для спрощення збору, управління та аналізу даних. Як центральний вузол для операцій rtSurvey, rtCloud пропонує комплексний набір функцій для підтримки складних проектів опитування та лонгітюдних досліджень.

## Ключові функції

### Управління проектами
- Організуйте всі аспекти вашого проекту опитування в одному місці
- Управляйте ролями користувачів, формами, аналізом, результатами та дозволами в межах кожного проекту

### Управління користувачами та безпека
- Створюйте та управляйте обліковими записами користувачів з дозволами на основі ролей
- Забезпечуйте безпеку даних і контроль доступу на кожному рівні

### Управління формами
- Завантажуйте та управляйте XLSForm безпосередньо
- Підтримка оновлень версій форм, включаючи незначні зміни та структурні перетворення
- Прикріплюйте мультимедійні або додаткові дані до форм
- Справжня можливість видалення форм для повного контролю над вашими інструментами опитування

### Збір даних та управління відправленнями
- Безшовна інтеграція з мобільним додатком rtSurvey, веб-додатком та веб-формою
- Підтримка як відправлень аутентифікованих користувачів, так і анонімних публічних посилань
- Обробка мультимедійних даних і вкладень відправлень
- Інтерактивний табличний попередній перегляд даних відправлень для швидких інсайтів

### Розширені робочі процеси відправлень
- Повернення відправлень на пристрої користувачів для подальшого редагування або верифікації
- Пересилання відправлень на інші пристрої, забезпечуючи спільні робочі процеси та контроль якості

### Управління лонгітюдними даними
- Ефективне управління повторними вимірами та довгостроковими дослідженнями
- Відстеження змін і оновлень даних учасників з часом

### Гнучке підключення
- Дозволяйте мобільному додатку rtSurvey підключатися для завантаження форм і завантаження відправлень
- Підтримка офлайн-збору даних з безшовною синхронізацією при відновленні підключення

## Чим виділяється rtCloud

Натхнений іншими платформами збору даних, rtCloud пропонує унікальні функції, що вирізняють його:

1. **Справжнє видалення форм**: На відміну від деяких платформ, rtCloud дозволяє повне видалення форм за необхідності.

2. **Гнучкі робочі процеси відправлень**: Можливість повертати та пересилати відправлення забезпечує складні процеси перегляду даних і контролю якості.

3. **Інтегроване управління проектами**: rtCloud виходить за межі управління формами та даними, пропонуючи інструменти для організації всіх аспектів вашого проекту опитування.

4. **Пряма підтримка XLSForm**: Завантажуйте свої XLSForm безпосередньо без конвертації, спрощуючи процес створення форм.

5. **Комплексна система дозволів**: Детальний контроль доступу та можливостей користувачів у проектах.

## Початок роботи з rtCloud

Щоб розпочати використання rtCloud для своїх проектів опитування:

1. Налаштуйте свій сервер rtCloud або зверніться до rtSurvey для отримання рішень з хостингом.
2. Створіть свій перший проект та запросіть членів команди.
3. Завантажте свої XLSForm та налаштуйте свої робочі процеси збору даних.
4. Підключіть свої мобільні додатки rtSurvey та починайте збирати дані.

rtCloud надає дослідникам, організаціям та командам із збору даних можливість легко, безпечно та гнучко управляти складними проектами опитування. Незалежно від того, чи проводите ви одноразове опитування або багаторічне лонгітюдне дослідження, rtCloud надає інструменти, необхідні для успіху.

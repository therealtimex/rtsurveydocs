Typ otázky `calculate` ticho spúšťa vzorec na pozadí. Výsledok ukladá do pomenovaného poľa, na ktoré sa môžu odkazovať iné otázky — anketárovi sa však nezobrazuje žiadny vstup ani štítok. Použite ho na odvodenie hodnôt, spájanie reťazcov, vykonávanie podmienenej logiky alebo vyhľadávanie údajov, ktoré budete vo formulári potrebovať neskôr.

---

## Základná syntax

| type | name | label | calculation |
|------|------|-------|-------------|
| calculate | total | | `${price} * ${quantity}` |

- **type**: Vždy `calculate`.
- **name**: Unikátny názov poľa. Ostatné otázky naň odkazujú pomocou `${name}`.
- **label**: Ponechajte prázdne — polia calculate sa anketárovi nikdy nezobrazujú.
- **calculation**: Vzorec na vyhodnotenie. Podporuje všetky [funkcie XLSForm](../operators-and-functions/functions) a odkazy na polia.

---

## Bežné vzorce

### Aritmetika

| type | name | label | calculation |
|------|------|-------|-------------|
| integer | price | Unit price | |
| integer | quantity | Quantity | |
| calculate | total | | `${price} * ${quantity}` |
| note | total_note | Total: `${total}` | |

### Spájanie reťazcov (String concatenation)

| type | name | label | calculation |
|------|------|-------|-------------|
| text | first_name | First name | |
| text | last_name | Last name | |
| calculate | full_name | | `concat(${first_name}, ' ', ${last_name})` |

### Podmienená hodnota

| type | name | label | calculation |
|------|------|-------|-------------|
| integer | score | Score (0–100) | |
| calculate | grade | | `if(${score} >= 90, 'A', if(${score} >= 75, 'B', if(${score} >= 60, 'C', 'F')))` |

### Vek z dátumu narodenia

| type | name | label | calculation |
|------|------|-------|-------------|
| date | dob | Date of birth | |
| calculate | age_years | | `int((today() - ${dob}) div 365.25)` |

## Použitie `once()` na uzamknutie hodnoty

V predvolenom nastavení sa `calculate` prehodnocuje vždy, keď sa zmení akékoľvek odkazované pole. Zabaľte vzorec do `once()`, aby sa vyhodnotil iba pri prvom načítaní a výsledok sa zmrazil:

| type | name | label | calculation |
|------|------|-------|-------------|
| calculate | interview_start | | `once(now())` |

`once()` použite pre časové pečiatky, počiatočné hodnoty alebo akýkoľvek prípad, kedy je prepočítavanie pri zmene nežiaduce.

## Vyťahovanie údajov z externých zdrojov

### Zo súboru CSV

```
pulldata('staff.csv', 'department', 'name', ${staff_id})
```

Úplnú referenciu nájdete v [pulldata()](../operators-and-functions/pulldata).

### Z pribalenej databázy SQLite

```
pulldata('rawquery',
  concat(${family_path}, '/locations.db::provinces'),
  'SELECT name FROM provinces WHERE id = ?',
  ${province_id})
```

Podrobnosti o konštrukcii ciest nájdete v [Hľadanie v miestnej databáze](../advanced-features/local-database-search).

### Z kontextu aplikácie

```
pulldata('app-api', 'user.username')
pulldata('app-api', 'family_path')
```

Všetky dostupné kľúče nájdete v [App API](../app-api).

## Použitie calculate v relevant a constraint

Ostatné polia môžu odkazovať na výsledok `calculate` rovnako ako na akékoľvek iné pole:

| type | name | label | relevant | constraint |
|------|------|-------|----------|------------|
| calculate | bmi | | | `${weight} div (${height} * ${height}) * 10000` |
| note | bmi_warning | BMI is very high — please verify weight and height. | `${bmi} > 40` | |

## Osvedčené postupy

1. Dávajte poliam calculate zmysluplné názvy — `total_cost` je jasnejšie ako `calc1` a ľahšie sa sleduje v exportoch.
2. Rozdeľte zložité vzorce do viacerých reťazených polí calculate namiesto jedného hlboko vnoreného výrazu.
3. Používajte `once()` pre časové pečiatky a počiatočné snímky, aby ste zabránili zmene hodnôt po prvom zachytení.
4. Umiestnite polia `calculate` pred prvú otázku, ktorá na ne odkazuje — poradie vyhodnocovania nasleduje poradie formulára.
5. Stĺpec `label` ponechajte prázdny. Niektoré nástroje štítok zobrazujú; ponechanie prázdneho poľa zabráni mätúcemu výstupu.

## Obmedzenia

- Polia Calculate sa anketárovi nikdy nezobrazujú priamo — na zobrazenie výsledku použite pole `note`.
- Stĺpec `calculation` je povinný; riadok `calculate` bez vzorca vždy uloží prázdny reťazec.
- Výsledky sa prehodnocujú pri každej zmene formulára, pokiaľ nie sú zabalené v `once()` — veľmi zložité vzorce vo veľkých formulároch môžu ovplyvniť výkon vykresľovania na zariadeniach nižšej triedy.
- Vypočítané hodnoty sa v odoslanom formulári ukladajú ako reťazce. Pri odovzdávaní výsledku do aritmetických alebo logických výrazov použite `number()`, `int()` alebo `boolean()` na pretypovanie.

import { Callout } from 'nextra/components'

`family_path` je konvenčné výpočtové pole, ktoré uchováva cestu k adresáru pribalených médií formulára. Každý formulár, ktorý vykonáva vyhľadávanie v lokálnej databáze pomocou `rawquery`, `pulldata` alebo `search()`, musí obsahovať toto pole — bez neho nie je možné rozlíšiť cesty k súborom a vyhľadávania ticho vracajú prázdny výsledok.

---

## Pole calculate

Pridajte tento riadok blízko hornej časti vášho hárka survey, po akýchkoľvek meta poliach a pred prvú otázku, ktorá používa databázový súbor:

| type | name | label | calculation |
|---|---|---|---|
| calculate | `family_path` | | `pulldata('app-api', 'family_path')` |

Pole neukladá žiadnu viditeľnú hodnotu a nevyžaduje menovku (label). Je to tichý predpoklad pre všetky nasledujúce konštrukcie ciest.

---

## Prečo je to potrebné

RTSurvey balí médiá formulára — SQLite databázy, obrázky, audio klipy — do adresára prislúchajúceho formuláru v zariadení. Presná cesta sa líši medzi platformami (Android, iOS, web) a medzi zariadeniami.

Počas behu aplikácia automaticky vyplní `family_path`. Typická rozlíšená hodnota vyzerá takto:

```
resources/familyMedia/Phuong_Person_Test
```

Keďže cesta je špecifická pre platformu a určuje sa v čase spustenia, nemôže byť vo formulári zapísaná napevno. `pulldata('app-api', 'family_path')` je jediný spoľahlivý spôsob, ako ju získať.

---

## Ako ho použiť v cestách

Keď je `family_path` definovaná, vytvorte úplnú cestu k súboru pomocou `concat()`:

```
concat(${family_path}, '/file.db::tableName')
```

Prípona `::tableName` sa odstráni, keď aplikácia otvorí súbor; názov tabuľky sa používa iba vo vašom SQL dopyte.

---

## Kde sa family_path používa

`family_path` je vyžadovaná v argumente cesty vždy, keď odkazujete na pribalený súbor:

- **Vyhľadávanie v lokálnej databáze** — argument `db_path` funkcie `search-autocomplete-noedit-v2('rawquery', ...)` musí byť vytvorený pomocou `concat(${family_path}, ...)`. Úplné podrobnosti o používaní nájdete v časti [Vyhľadávanie v lokálnej databáze](local-database-search).
- **`pulldata` rawquery** — akékoľvek volanie `pulldata('rawquery', ...)`, ktoré číta zo súboru `.db`, používa rovnaký vzor `concat()`.
- **`search()` s lokálnym súborom** — vzhľady (appearances) pre dynamické vyhľadávanie, ktoré načítavajú z pribaleného súboru CSV alebo DB, sa tiež spoliehajú na `family_path` pri odkaze na súbor.

---

## Umiestnenie vo formulári

`family_path` sa musí objaviť **pred prvým poľom, ktoré naň odkazuje**. Odporúčaná poloha je hneď po skupine meta:

| type | name | label | calculation |
|---|---|---|---|
| begin_group | meta | | |
| deviceid | deviceid | | |
| start | start | | |
| end | end | | |
| end_group | | | |
| calculate | `family_path` | | `pulldata('app-api', 'family_path')` |
| select_one | province | Province | *(vzhľad rawquery odkazujúci na `${family_path}`)* |

<Callout type="warning">
Ak `family_path` vo formulári chýba alebo je umiestnená po prvom poli `rawquery` / `search()`, ktoré naň odkazuje, všetky vyhľadávania v pribalených súboroch ticho vrátia prázdnu hodnotu. Neexistuje žiadna chybová správa — automatické dopĺňanie jednoducho nezobrazí žiadne výsledky.
</Callout>

---

## Viaceré databázové súbory

Jeden formulár môže používať niekoľko súborov `.db`. Každá cesta sa vytvára nezávisle pomocou `concat()`:

```
concat(${family_path}, '/locations.db::externalData')
concat(${family_path}, '/health_facilities.db::facilities')
concat(${family_path}, '/household_list.db::households')
```

Definujte `family_path` raz; odkazujte na ňu v toľkých poliach, koľko potrebujete.

---

## Overenie počas vývoja

Pridajte dočasné pole `note` pod `family_path`, aby ste skontrolovali rozlíšenú hodnotu v zariadení:

| type | name | label | calculation |
|---|---|---|---|
| calculate | `family_path` | | `pulldata('app-api', 'family_path')` |
| note | family_path_check | `Cesta: ${family_path}` | |

Poznámka počas testovania zobrazí skutočnú rozlíšenú cestu. Pred nasadením finálneho formulára ju odstráňte.

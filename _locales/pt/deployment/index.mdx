Execute o rtCloud na sua própria infraestrutura usando Docker Compose. O auto-alojamento dá-lhe propriedade completa dos seus dados, rede e ambiente de implantação — ideal para organizações com requisitos de residência de dados, redes isoladas ou necessidades de infraestrutura personalizadas.

## O que é o Auto-Alojamento do rtCloud?

O Auto-Alojamento do rtCloud é uma imagem Docker oficial que empacota toda a plataforma rtCloud numa pilha de contentores portátil que pode executar em qualquer servidor Linux. A pilha inclui:

| Serviço | Descrição |
|---------|-----------|
| **Aplicação rtCloud** | Aplicação web Apache 2.4 + PHP 7.4 com fila de processos em segundo plano incorporada (Beanstalkd), servidor de análise (Shiny) e tarefas agendadas |
| **MySQL 8.0** | Base de dados relacional para todos os dados de aplicação e inquérito |
| **Keycloak** *(opcional)* | Servidor Single Sign-On incorporado para gestão de identidade empresarial |

## Quando Auto-Alojar

O auto-alojamento é a escolha certa quando:

- Requer **soberania de dados** — todos os dados permanecem dentro da sua própria infraestrutura
- Opera numa **rede isolada ou restrita** sem acesso a cloud externa
- Tem **requisitos de conformidade** (RGPD, HIPAA, políticas de dados governamentais) que exigem armazenamento local
- Precisa de integrar com um **fornecedor de identidade interno** (Active Directory, LDAP, SAML)
- Quer **personalizar recursos** — alocação de CPU, RAM e armazenamento nos seus próprios termos

## Visão Geral da Arquitetura

A implantação corre como um conjunto de contentores Docker ligados numa rede interna:

```
┌────────────────────────────────────────┐
│            rtcloud-app                 │
│  Apache 2.4 (porta 80)                 │
│  Aplicação PHP 7.4                     │
│  Fila Beanstalkd (interna)             │
│  Servidor Shiny (porta 3838)           │
│  Agendador Cron                        │
└─────────────────┬──────────────────────┘
                  │ rtcloud-net (bridge)
┌─────────────────▼──────────────────────┐
│            rtcloud-mysql               │
│  MySQL 8.0 (porta 3306, apenas interna)│
└────────────────────────────────────────┘
```

Quando o SSO está ativo, um terceiro contentor corre em paralelo:

```
┌─────────────────────────────────────────┐
│            rtcloud-keycloak             │
│  Keycloak (porta 8080, apenas interna)  │
│  UI Admin (porta 9000, apenas interna)  │
└─────────────────────────────────────────┘
```

Todos os contentores comunicam através de uma rede bridge Docker isolada. Apenas a porta da aplicação web e (opcionalmente) a porta do servidor de análise Shiny são expostas ao host.

Esta página cobre padrões avançados para trabalhar com grupos de repetição no rtSurvey. Para o básico sobre como configurar um grupo de repetição, consulte [Agrupamento e Repetições](../repeats).

---

## Contagem de repetição dinâmica

Por padrão, o enumerador decide quantas vezes repetir. Você pode fixar o número de repetições usando `repeat_count`:

| type | name | label | repeat_count |
|------|------|-------|--------------|
| begin_repeat | household_members | Membro do agregado familiar | `${num_members}` |
| text | member_name | Nome do membro | |
| integer | member_age | Idade | |
| end_repeat | | | |

A repetição é executada exatamente `${num_members}` vezes, onde `num_members` foi recolhido anteriormente no formulário. O enumerador não pode adicionar ou remover instâncias.

---

## Acesso indexado: `indexed-repeat()`

Aceda ao valor de um campo de uma instância de repetição específica **fora** do grupo de repetição usando `indexed-repeat(repeatedField, repeatGroup, index)`:

| type | name | label | calculation |
|------|------|-------|-------------|
| calculate | first_name | | `indexed-repeat(${member_name}, ${household_members}, 1)` |
| calculate | second_name | | `indexed-repeat(${member_name}, ${household_members}, 2)` |

Isto é útil para construir campos de resumo ou referenciar os dados do membro "primário" após a repetição.

---

## Posição da instância atual: `index()`

Dentro de um grupo de repetição, `index()` retorna a posição (baseada em 1) da instância atual. Use-o para rotular cada repetição ou criar identificadores únicos:

| type | name | label |
|------|------|-------|
| begin_repeat | plots | Parcela |
| note | plot_label | Parcela número `${index()}` |
| text | plot_id | ID da parcela |
| end_repeat | | |

---

## Referenciar campos na mesma instância

Dentro de uma repetição, use `${fieldname}` para referenciar outro campo **na mesma instância de repetição**. Não há necessidade de `indexed-repeat()` dentro do mesmo ciclo:

| type | name | label | relevant |
|------|------|-------|----------|
| begin_repeat | members | Membro | |
| text | member_name | Nome | |
| integer | member_age | Idade | |
| text | school_name | Nome da escola | `${member_age} < 18` |
| end_repeat | | | |

---

## Referenciar campos pai de dentro de uma repetição

Campos fora (acima) do grupo de repetição podem ser referenciados normalmente com `${fieldname}`:

| type | name | label |
|------|------|-------|
| text | village | Nome da aldeia |
| begin_repeat | plots | Parcela agrícola |
| note | plot_context | Parcelas em `${village}` |
| end_repeat | | |

## Resumo de dados de repetição

Use funções de agregação de repetição **fora** do grupo de repetição para resumir:

| Function | Example | Description |
|----------|---------|-------------|
| `count(group)` | `count(${household_members})` | Número de instâncias |
| `sum(field)` | `sum(${loan_amount})` | Soma de um campo numérico |
| `min(field)` | `min(${member_age})` | Valor mínimo |
| `max(field)` | `max(${member_age})` | Valor máximo |
| `join(sep, field)` | `join(', ', ${member_name})` | Lista separada por vírgulas |
| `count-if(group, expr)` | `count-if(${members}, ${member_age} < 18)` | Contagem condicional |
| `sum-if(field, expr)` | `sum-if(${loan_amount}, ${loan_amount} > 500)` | Soma condicional |
| `join-if(sep, field, expr)` | `join-if(', ', ${name}, ${age} >= 18)` | Junção condicional |

### Exemplo: Resumo do agregado familiar

| type | name | label | calculation |
|------|------|-------|-------------|
| integer | num_members | Quantos membros? | |
| begin_repeat | members | Membro | `${num_members}` |
| text | member_name | Nome | |
| integer | member_age | Idade | |
| end_repeat | | | |
| calculate | total_members | | `count(${members})` |
| calculate | children_count | | `count-if(${members}, ${member_age} < 18)` |
| calculate | adult_names | | `join-if(', ', ${member_name}, ${member_age} >= 18)` |
| note | summary | `${total_members}` membros; `${children_count}` com menos de 18 anos. Adultos: `${adult_names}` | |

## Repetições aninhadas

Um grupo de repetição pode conter outro grupo de repetição. Use isto com cuidado — as repetições aninhadas adicionam complexidade e podem ser confusas para os enumeradores.

| type | name | label |
|------|------|-------|
| begin_repeat | households | Agregado familiar |
| text | hh_id | ID do agregado familiar |
| begin_repeat | hh_members | Membro |
| text | member_name | Nome do membro |
| end_repeat | | |
| end_repeat | | |

Para referenciar um campo numa repetição externa a partir da repetição interna, use `${fieldname}` — ele resolve para o ancestral correspondente mais próximo:

Dentro da repetição `hh_members`, `${hh_id}` retorna o ID do agregado familiar **atual**, não de todos os agregados familiares.

## Classificação dentro de grupos de repetição: `rank-index()`

Quando existe um campo `rank` dentro de uma repetição, use `rank-index(instanceNumber, repeatedField)` de fora para obter a classificação ordinal de uma instância específica:

| type | name | label | calculation |
|------|------|-------|-------------|
| calculate | top_scorer | | `rank-index(1, ${score})` |

`rank-index(1, ${score})` retorna o índice da instância com a pontuação mais alta.

## Aparência `1screen` em `begin_repeat`

Adicionar `1screen` à coluna `appearance` de uma linha `begin_repeat` exibe todas as perguntas para cada instância juntas num único ecrã, em vez de uma pergunta por ecrã.

| type | name | label | appearance |
|------|------|-------|------------|
| begin_repeat | household_members | Membro do agregado familiar | `1screen` |
| text | member_name | Nome do membro | |
| integer | member_age | Idade | |
| end_repeat | | | |

Quando `1screen` está definido e não há campo `repeat_count` e nenhum campo `add_repeat` dentro do grupo, o rtSurvey renderiza automaticamente um botão circular **+** na parte inferior do ecrã para que os enumeradores possam adicionar novas instâncias sem qualquer configuração extra.

| Appearance | Um ecrã por instância | Botão + padrão adicionado |
|------------|-------------------------|------------------------|
| `1screen` | Sim | Sim (quando não há filho `add_repeat`) |
| `field-list` | Sim | Não |

Use `field-list` quando desejar o layout agrupado sem o botão de adição automático. Use `1screen` quando desejar tanto o layout agrupado quanto uma forma integrada de adicionar instâncias.

## Botão de adição personalizado `add_repeat`

Um campo `note` (ou `text`) colocado **dentro** do grupo de repetição com `appearance: add_repeat` é renderizado como um botão "Adicionar" de largura total. O rótulo do botão vem da coluna `label` do campo. Quando um campo `add_repeat` está presente, o botão circular + padrão (de `1screen`) é suprimido.

Coloque o campo `add_repeat` como o último campo dentro do grupo de repetição:

| type | name | label | appearance |
|------|------|-------|------------|
| begin_repeat | members | Membro | `1screen` |
| text | member_name | Nome do membro | |
| integer | member_age | Idade | |
| note | btn_add | + Adicionar membro | `add_repeat` |
| end_repeat | | | |

### Personalização de cores

Passe um código de cor dentro do valor de aparência para estilizar o botão:

| Appearance value | Result |
|------------------|--------|
| `add_repeat <#04B404/>` | Fundo verde, cor de texto padrão |
| `add_repeat 04B404-ffffff` | Fundo verde, texto branco |

A primeira cor é o fundo e a segunda (após o traço) é a cor do texto. Omita o `#` ao usar a forma separada por traço.

### Variante de ícone

Use `add_repeat icon` (com um espaço) para renderizar um botão de ícone circular compacto em vez do botão de largura total:

| type | name | label | appearance |
|------|------|-------|------------|
| note | btn_add | + Adicionar | `add_repeat icon` |

## Botões de exclusão: `delete-repeat-current` e `delete-repeat-last`

Um campo `note` dentro do grupo de repetição com `appearance: delete-repeat-current` ou `appearance: delete-repeat-last` é renderizado como um botão de exclusão dividido.

| Appearance | Action |
|------------|--------|
| `delete-repeat-current` | Exclui a instância atual (ativa) |
| `delete-repeat-last` | Exclui a última instância na repetição |

O botão padrão (sem ícone) é um botão dividido: um ícone de lixo à esquerda e o texto do rótulo do campo à direita, abrangendo toda a largura do ecrã.

### Variante de ícone

Anexe `-icon` para obter um botão de ícone de lixo circular compacto:

| Appearance | Result |
|------------|--------|
| `delete-repeat-current-icon` | Ícone de lixo circular, exclui a instância atual |
| `delete-repeat-last-icon` | Ícone de lixo circular, exclui a última instância |

### Personalização de cores

O formato de cor é idêntico ao `add_repeat`: use `<#RRGGBB/>` or `RRGGBB-RRGGBB` (fundo-texto).

### Exemplo de padrão completo

A seguinte repetição usa `1screen`, um botão circular de exclusão da instância atual no topo e um botão de adição de largura total na parte inferior:

| type | name | label | appearance |
|------|------|-------|------------|
| begin_repeat | members | Membro | `1screen` |
| note | btn_del | Remover | `delete-repeat-current-icon` |
| text | member_name | Nome do membro | |
| integer | member_age | Idade | |
| note | btn_add | + Adicionar membro | `add_repeat` |
| end_repeat | | | |

## Melhores Práticas

1. Use sempre `repeat_count` quando o número de repetições for conhecido antecipadamente — isso evita que os enumeradores adicionem ou removam instâncias acidentalmente.
2. Mantenha os grupos de repetição focados — uma repetição com mais de 20 perguntas por instância é difícil de navegar.
3. Nomeie os grupos de repetição de forma clara (ex: `household_members`, não `repeat1`) — o nome aparece nas chamadas de função e nos dados exportados.
4. Teste com o número máximo esperado de instâncias para verificar o desempenho.
5. Use `1screen` em `begin_repeat` para mostrar todas as perguntas num ecrã por instância, emparelhado com um campo de nota `add_repeat` dentro do grupo para dar aos enumeradores um botão "Adicionar" claramente rotulado.

---

## Limitações

- `indexed-repeat()` requer um índice válido (1 até a contagem de instâncias) — índices fora do intervalo retornam vazio.
- Repetições aninhadas além de 2 níveis não são recomendadas e podem causar problemas de exibição em alguns clientes.
- As funções de agregação (`sum`, `count`, etc.) operam em todo o grupo de repetição — não é possível agregar um subconjunto de instâncias sem as variantes `*-if`.

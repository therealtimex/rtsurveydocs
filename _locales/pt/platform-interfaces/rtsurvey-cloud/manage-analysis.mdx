O módulo **Gestão de Análises** no RT-CPMS fornece um conjunto abrangente de ferramentas para processar e visualizar os seus dados de inquérito. Está dividido em duas secções principais acessíveis a partir da barra lateral de navegação global: **Desenvolvimento de Análises** e **Análises e Relatórios**.

![Interface de Gestão de Análises](/images/manage_analysis.png)

## Desenvolvimento de Análises

A secção **Desenvolvimento de Análises** é o seu hub centralizado para criar e configurar novos designs de análise. É aqui que investigadores e gestores de dados definem como os dados brutos do inquérito devem ser processados e tabulados.

### Funcionalidades Principais do Desenvolvimento de Análises
- **Criar Novos Designs:** Use o proeminente botão **Nova Análise +** para começar a criar um novo modelo de relatório ou design de análise.
- **Gerir Designs Existentes:** A grelha principal fornece uma visão geral abrangente de todos os seus modelos analíticos, exibindo metadados chave como:
  - ID e Título/Descrição
  - Tags para categorização fácil
  - Rastreamento de versão
  - Timestamps de criação e atualização
  - Informação do autor
- **Pesquisar e Filtrar:** Localize facilmente designs específicos usando as ferramentas integradas de pesquisa e filtragem em cada coluna.
- **Ações Rápidas:** Visualize, edite ou elimine designs específicos diretamente a partir do menu de ação na grelha.

## Análises e Relatórios

Uma vez criado e executado um design de análise, a secção **Análises e Relatórios** é onde interage com a saída de business intelligence (BI) gerada.

### Funcionalidades Principais de Análises e Relatórios
- **Barra Lateral de Navegação de Relatórios:** Mude rapidamente entre diferentes relatórios disponíveis usando o painel dedicado do lado esquerdo.
- **Pesquisa e Filtragem:** Use a barra de pesquisa ou o filtro suspenso "Todas as análises" para reduzir a lista de relatórios.
- **Favoritos:** Marque relatórios importantes ou frequentemente acedidos como favoritos para acesso mais rápido no futuro.

## Integração no Dashboard

Para supervisão rápida, o **Dashboard Principal** apresenta um separador dedicado de **Relatórios** ao lado do rastreador principal de Formulários. Este separador fornece acesso imediato aos seus relatórios diretamente a partir do centro de comando administrativo, permitindo-lhe monitorizar de forma integrada tanto o progresso da recolha de dados como as saídas analíticas.

O módulo **Gestão de Submissões** (acedido através do botão **Visualização de Dados** na secção Família de Formulários) permite aos gestores de projeto e supervisores interagir diretamente com os dados brutos recebidos. Serve como um espaço de trabalho unificado para rever submissões de enumeradores, rastrear identificadores de dispositivos e realizar operações de qualidade de dados.

![Interface de Gestão de Submissões](/images/manage_submissions.png)

## Visão Geral dos Dados e Colunas

A grelha de dados exibe dinamicamente os dados recolhidos para um formulário específico. Opera em dois modos principais: **Oficial** (Registos Finalizados) e **Trabalho** (Registos em tempo real, não finalizados).

### Colunas de Dados Principais

Independentemente das perguntas personalizadas definidas no formulário, a grelha inclui várias colunas de metadados padrão para ajudar na auditoria:

- **Submetido por:** Identifica a plataforma de origem da submissão (por ex., FA para Aplicação de Campo, WEB para Formulário Web, RS para sistemas remotos).
- **Detalhe:** Abre uma vista focada num único registo (ícone de pesquisa) para inspecionar cada variável e resposta submetida para essa instância.
- **iNota:** Permite aos supervisores anexar notas laterais ou comentários internos a um registo específico sem alterar os dados recolhidos (representado por um ícone de lápis).
- **Campos de data:** Timestamps indicando quando o registo foi iniciado, concluído ou sincronizado.
- **Anexos de multimédia:** Links de miniaturas diretas para imagens, assinaturas ou ficheiros recolhidos durante o inquérito.
- **Grupos de repetição:** Links dedicados para aceder a tabelas aninhadas para perguntas repetidas dentro do formulário pai.

## Ações de Submissão

Para facilitar o controlo ativo da qualidade dos dados, a interface fornece um menu suspenso de comandos acionáveis que podem ser executados em registos selecionados:

- **Criar nova instância:** Permite aos administradores inserir manualmente um novo registo de inquérito diretamente na base de dados.
- **Devolver instância:** Rejeita o registo submetido e incumbe o enumerador de reverificar ou recolher novamente a informação.
- **Acompanhar instância:** Sinaliza um registo para mais atenção, geralmente despachando um alerta para a equipa de campo para esclarecimento.
- **Exportar para ficheiro de comandos Devolvidos / pacote de comandos de Acompanhamento:** Gera exportações em lote (ficheiros) contendo conjuntos de dados especificamente marcados para devoluções ou acompanhamentos.
- **Converter para XML:** Transforma o conjunto de dados estruturado de volta para o seu formato XML bruto para análise backend ou integração de sistema.
- **Encaminhar Instâncias:** (Disponível no modo *Trabalho*) Envia dados não finalizados imediatamente para outro dispositivo ou utilizador.
- **Eliminar:** Remove permanentemente instâncias selecionadas da base de dados.

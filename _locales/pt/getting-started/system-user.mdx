# Gestão de Utilizadores do Sistema

O módulo **Utilizador do Sistema** (`/cpms/cpmsSystemUser/admin`) é uma interface de gestão abrangente para controlar quem tem acesso à sua plataforma Real-Time Survey (RT-CPMS) e que ações podem realizar.

![Interface do Utilizador do Sistema](/images/system_user.png)

## Abordagem de Gestão Unificada

No RT-CPMS, um **Enumerador** é simplesmente uma Função específica atribuída a um Utilizador do Sistema. Não existe uma base de dados separada de "Enumeradores". Quer um utilizador seja um Administrador de alto nível a monitorizar o portal web ou um Enumerador de campo a recolher dados através da aplicação móvel, todos são geridos dentro desta estrutura única e unificada.

## Funcionalidades Principais

### 1. Diretório de Utilizadores e Vista em Grelha
A interface principal exibe uma lista paginada de todos os utilizadores ligados ao espaço de trabalho. Os atributos principais incluem:
* **ID e Nome da Organização**: Agrupamento lógico de utilizadores sob entidades organizacionais específicas (por ex., `rta`, `partner_org`).
* **Função**: Especifica o nível de permissão do utilizador (por ex., `Administrator`, `Leadteam`, `Enumerator`).
* **Grupo**: Atribuições de agrupamento espacial ou lógico (por ex., distritos específicos ou equipas operacionais).
* **Está Sincronizado**: Indica se a conta está integrada com sucesso com o sistema central de Single Sign-On (SSO).
* **Estado**: Indicadores visuais confirmando se uma conta está `Ativa`, `Inativa`, `Eliminada` ou `Bloqueada`.

**Ações Globais:**
* **Adicionar Utilizador do Sistema**: Criar manualmente um perfil individual.
* **Importar Utilizador do Sistema**: Carregamento em massa de contas usando um modelo Excel. Pode resolver conflitos usando os modos `Ignorar` ou `Substituir` e sincronizar diretamente com o SSO.
* **Eliminar em Massa**: Suporte de seleção múltipla para remoção em massa de contas.

### 2. Controlo de Acesso e Segurança
Ao criar ou editar um perfil de utilizador, vários campos críticos de segurança e fluxo de trabalho estão disponíveis:
* **Código de Utilizador**: Um identificador único que liga a conta CPMS local ao repositório central SSO.
* **Código de Mudança de Dispositivo**: Um token de segurança robusto necessário quando um enumerador precisa de trocar o dispositivo móvel que está a utilizar para a recolha de dados.
* **Nível de Poder**: Uma escala de prioridade/acesso granular que vai de 0 (mais baixo) a 20 (mais alto).
* **Alternância de Supervisão**: Uma caixa de verificação que eleva instantaneamente um utilizador padrão para o estado de gestão.
* **Automatização de Fluxo de Trabalho**: Uma opção para "Aprovar automaticamente o Pedido de Edição", que agiliza o processo de limpeza e verificação de dados para utilizadores de confiança.

### 3. Gestão de Códigos (Integração Automatizada)
Encontrada sob o separador secundário "Código", esta funcionalidade gere links de registo e convite baseados em hash, simplificando o processo de integração para grandes equipas.

* **Registo vs. Convite**: Escolha se os utilizadores podem auto-registar-se usando um link distribuído ou se requerem um convite direto do administrador.
* **Datas de Expiração**: Confine a integração a janelas de tempo específicas.
* **Limites de Utilização**: Limite o número de utilizadores que podem aderir usando um único código gerado.
* **Funções Pré-atribuídas**: Os utilizadores que aderem através destes códigos herdam automaticamente a função e o nível de poder pré-definidos, garantindo que estão prontos a trabalhar imediatamente sem intervenção manual do administrador.

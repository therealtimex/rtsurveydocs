Kolom `appearance` di rtSurvey memungkinkan Anda untuk menyesuaikan presentasi visual dan perilaku pertanyaan dalam survei Anda. Fitur ini meningkatkan pengalaman pengguna dan dapat secara signifikan meningkatkan efisiensi pengumpulan data. rtSurvey mendukung atribut tampilan standar XLSForm dan memperluasnya dengan opsi tambahan.

## Atribut Tampilan Standar XLSForm

rtSurvey mendukung atribut tampilan standar XLSForm berikut:

| Atribut Tampilan | Tipe Pertanyaan | Deskripsi |
|------------------|-----------------|-----------|
| multiline | text | Membuat kotak teks multi-baris (terbaik untuk klien web) |
| minimal | select_one, select_multiple | Menampilkan pilihan dalam menu dropdown |
| quick | select_one | Maju otomatis ke pertanyaan berikutnya setelah pemilihan (khusus seluler) |
| no-calendar | date | Menghilangkan tampilan kalender (khusus seluler) |
| month-year | date | Memungkinkan pemilihan bulan dan tahun saja |
| year | date | Memungkinkan pemilihan tahun saja |
| horizontal-compact | select_one, select_multiple | Menampilkan pilihan secara horizontal (khusus web) |
| horizontal | select_one, select_multiple | Menampilkan pilihan secara horizontal dalam kolom (khusus web) |
| likert | select_one | Menyajikan pilihan sebagai skala Likert |
| compact | select_one, select_multiple | Menampilkan pilihan berdampingan dengan padding minimal |
| quickcompact | select_one | Menggabungkan tampilan kompak dengan maju otomatis (khusus seluler) |
| field-list | groups | Menampilkan seluruh grup dalam satu layar (khusus seluler) |
| label | select_one, select_multiple | Menunjukkan label pilihan tanpa input |
| list-nolabel | select_one, select_multiple | Menunjukkan input tanpa label (gunakan dengan `label`) |
| table-list | groups | Menampilkan pertanyaan dalam format tabel |
| signature | image | Memungkinkan pengambilan tanda tangan (khusus seluler) |
| draw | image | Memungkinkan menggambar bebas (khusus seluler) |
| map, quick map | select_one, select_one_from_file | Memungkinkan pemilihan dari fitur peta |

## Praktik Terbaik untuk Menggunakan Tampilan

1. **Konsistensi**: Gunakan atribut tampilan secara konsisten di seluruh survei Anda untuk tampilan yang seragam.
2. **Seluler vs. Web**: Pertimbangkan bagaimana tampilan akan dirender pada perangkat dan platform yang berbeda.
3. **Performa**: Berhati-hatilah dengan atribut tampilan yang mungkin memperlambat pemuatan formulir (misalnya, `table-list` untuk grup besar).
4. **Pengalaman Pengguna**: Pilih tampilan yang membuat entri data lebih mudah dan lebih intuitif bagi responden.
5. **Pengujian**: Selalu uji formulir Anda pada perangkat target untuk memastikan tampilan berfungsi seperti yang diharapkan.

## Teknik Lanjutan

### Menggabungkan Tampilan

Beberapa atribut tampilan dapat digabungkan untuk tata letak yang lebih kompleks:

```
| type | name | label | appearance |
|------|------|-------|------------|
| select_one options | choice | Select one: | minimal compact |
```

### Tampilan Dinamis

rtSurvey memungkinkan perubahan tampilan dinamis berdasarkan logika formulir:

```
| type | name | label | appearance | relevant |
|------|------|-------|------------|----------|
| text | time | Enter time: | inline-[%H:%M] | ${show_time} = 'yes' |
```

## Pertimbangan Aplikasi Seluler

- Beberapa tampilan (misalnya, `quick`, `signature`) spesifik untuk perangkat seluler.
- Uji secara menyeluruh pada Android dan iOS untuk memastikan perilaku yang konsisten.

## Atribut Tampilan Tambahan rtSurvey

Selain tampilan standar XLSForm, rtSurvey mendukung opsi spesifik platform berikut:

### Kontrol data dan tampilan

| Atribut Tampilan | Tipe Pertanyaan | Deskripsi |
|------------------|-----------------|-----------|
| `invisible` | apa saja | Menyembunyikan bidang dari pandangan sambil tetap mengumpulkan atau menghitung nilainya. Berbeda dari tipe `hidden` — bidang tetap berpartisipasi dalam logika. |
| `displaytitle` | apa saja | Memaksa tampilan label/judul bidang bahkan ketika biasanya akan disembunyikan. |
| `autopull` | select_one, select_multiple | Secara otomatis mengambil data eksternal untuk mengisi pilihan saat formulir dimuat atau bidang pemicu berubah. |
| `floating_hint` | text, integer, decimal | Menunjukkan teks petunjuk sebagai label mengambang di atas bidang input, bukan di bawahnya. |
| `calculate-button` | calculate | Menambahkan tombol terlihat yang memicu kalkulasi ulang bidang sesuai permintaan, daripada menghitung secara otomatis. |

### Grup dan navigasi

| Atribut Tampilan | Tipe Pertanyaan | Deskripsi |
|------------------|-----------------|-----------|
| `section` | group | Merender grup sebagai kartu bagian yang dapat dilipat. Catatan: khusus aplikasi seluler. |
| `toc-hide` | apa saja | Mengecualikan pertanyaan dari panel navigasi daftar isi (TOC). |
| `minilog` | begin_repeat | Menampilkan entri pengulangan yang telah selesai sebagai daftar log mini yang kompak daripada memperluas setiap entri secara inline. |

### Perilaku input

| Atribut Tampilan | Tipe Pertanyaan | Deskripsi |
|------------------|-----------------|-----------|
| `proper` | text | Mengkapitalisasi huruf pertama dari setiap kata secara otomatis saat responden mengetik (perilaku title-case). |
| `text-nolabel` | text, integer, decimal | Merender bidang input tanpa label yang terlihat. |
| `inline-1line` | text | Memaksa input teks untuk ditampilkan sebagai satu baris bahkan ketika label pertanyaan panjang. |
| `popup` | apa saja | Merender bidang di dalam popup / overlay modal daripada inline di halaman. |

### Tata Letak

| Atribut Tampilan | Tipe Pertanyaan | Deskripsi |
|------------------|-----------------|-----------|
| `1screen` | group | Memaksa seluruh grup untuk ditampilkan pada satu layar terlepas dari ukuran grup. |
| `columns(n)` | select_one, select_multiple | Menampilkan pilihan dalam `n` kolom. Contoh: `columns(3)` menunjukkan tiga kolom tombol radio. |
| `gridformat<row=R col=C colspan=S align=center>` | apa saja | Menempatkan bidang dalam tata letak CSS-grid pada baris `R`, kolom `C`, mencakup `S` kolom. Digunakan dengan `advanced-extension/grid-layout`. |
| `ignore-simplify` | apa saja | Menginstruksikan perender formulir untuk melewatkan penyederhanaan otomatis atau pemadatan tata letak bidang ini. |
| `horizontal(N)` | select_one, select_multiple | Mengatur setiap pilihan untuk menempati `N` persen dari lebar baris. Contoh: `horizontal(50)` menempatkan dua pilihan per baris. |
| `scroll-view(N%)` | group, repeat | Membatasi kontainer ke tinggi maksimum `N%` dari viewport (atau induk), menambahkan bilah gulir saat konten meluap. Contoh: `scroll-view(60%)`. |

### Widget

| Atribut Tampilan | Tipe Pertanyaan | Deskripsi |
|------------------|-----------------|-----------|
| `likert` | select_one | Menyajikan pilihan sebagai baris skala Likert (sudah ada di tabel standar di atas; dikonfirmasi didukung). |
| `distress` | select_one | Merender pilihan sebagai widget visual Skala Distres Psikologis Kessler (K10) dengan ikon emosional. |
| `rating_box-fill-{c1}-{c2}-{c3}-{c4}-{c5}` | select_one | Merender pilihan sebagai kotak peringkat bergaya dengan lima slot warna. `c1` = batas kontainer luar, `c2` = batas tidak tercentang, `c3` = batas tercentang dan isian, `c4` = warna teks tidak tercentang, `c5` = warna teks tercentang. Contoh: `rating_box-fill-grey-blue-green-black-white`. |
| `tagging-choices-noshow-v2-{c1}-{c2}-{c3}-{c4}-{c5}` | select_multiple | Merender pilihan sebagai chip tag berwarna. Lima slot warna mengikuti urutan yang sama dengan `rating_box-fill`. Pilihan yang dipilih disorot; pilihan yang tidak dipilih disembunyikan dari tampilan ringkasan. |

### Integrasi API

| Atribut Tampilan | Tipe Pertanyaan | Deskripsi |
|------------------|-----------------|-----------|
| `callapi` | text, integer, decimal, select_one | Memungkinkan integrasi panggilan API untuk bidang ini. Kolom kalkulasi harus berisi ekspresi `callapi()`. Lihat [Panggil API](advanced-features/call-api). |
| `callapi-verify(params)` | text, integer, decimal | Memicu panggilan verifikasi API menggunakan parameter statis. Formulir memblokir kemajuan hingga API mengonfirmasi nilainya. |
| `callapi-verify(dynamicParams)` | text, integer, decimal | Sama seperti `callapi-verify` tetapi dengan parameter yang diturunkan dari nilai bidang lain saat runtime. |

### Pengalih bahasa

| Atribut Tampilan | Tipe Pertanyaan | Deskripsi |
|------------------|-----------------|-----------|
| `change_language-{colors} default('lang')` | note, text | Merender widget pengalih bahasa yang bergaya dengan kode warna yang diberikan. Token `default('lang')` menetapkan bahasa awal (misalnya `default('en')`); ini ditulis ulang menjadi `rtDefault('lang')` secara internal selama penguraian. Contoh: `change_language-blue-white default('vi')`. |

### Format tanggal/waktu sebaris (inline)

Untuk bidang `date`, `time`, dan `datetime`, Anda dapat menentukan format tampilan kustom menggunakan string format yang ditambahkan ke tampilan:

```
inline-[%d/%m/%Y]
inline-1line-[%d/%m/%Y %H:%M]
```

Token format sama dengan `format-date()` dan `format-date-time()`. Lihat [Fungsi — Fungsi tanggal dan waktu](operators-and-functions/functions#date-and-time-functions).

Contoh:

| type | name | label | appearance |
|------|------|-------|------------|
| datetime | event_time | Tanggal dan waktu acara | inline-[%d/%m/%Y %I:%M %p] |
| date | birth_date | Tanggal lahir | inline-[%d/%m/%Y] |

### Tata letak tombol sebaris (inline) — `display{}` dan `results{}`

Untuk tipe pertanyaan yang dirender sebagai tombol ikon sebaris (`date`, `time`, `datetime`, `image`, `audio`, `video`, `file`, `barcode`, `geopoint`), dua pemodifikasi tampilan mengontrol posisi tombol dan perilaku pasca-pengambilan.

#### `display{...}` — posisi tombol sebelum pengambilan

```
display{<align>, <size>, <color>}
```

| Parameter | Nilai | Default |
|-----------|-------|---------|
| Align | `left`, `right`, `top`, `center`, `bottom` | `right` |
| Size | `small`, `medium`, `large` | `small` |
| Color | hex misal `#FF5500` | warna tema utama |
| Flag | `inline-icon` | memaksa mode ikon |

| Nilai Align | Tata Letak |
|-------------|------------|
| `right` | Tombol di sebelah kanan label |
| `left` | Tombol di sebelah kiri label |
| `top` | Tombol di atas label, lebar penuh rata tengah |
| `center` / `bottom` | Tombol di bawah label, lebar penuh rata tengah |

#### `results{...}` — tata letak dan visibilitas setelah pengambilan

Mewarisi pengaturan `display{}`. Gunakan untuk memindahkan tombol atau menyembunyikan elemen setelah nilai diambil.

```
results{<align>, hide(<element>)}
```

| Nilai `hide` | Efek |
|--------------|------|
| `hide(capture)` | Menyembunyikan tombol pengambilan setelah file/nilai ada |
| `hide(review)` | Menyembunyikan thumbnail tinjauan / tombol putar ulang |
| `hide(filename)` | Menyembunyikan nama file yang ditampilkan setelah unggah |
| `hide(camera)` | Menyembunyikan tombol pemicu kamera setelah pengambilan |
| `hide(scanner)` | Menyembunyikan tombol pindai vonalkód setelah nilai dipindai |
| `hide(value)` | Menyembunyikan teks nilai yang dipindai (vonalkód / geopoint) |

Widget secara otomatis beralih dari tata letak `display{}` ke `results{}` saat nilai diambil.

**Contoh:**

```
inline display{right}                                    → ikon di kanan label
inline display{left, large}                              → ikon besar di kiri
inline display{center, large, #FF5500}                   → ikon oranye besar di bawah label
inline display{right} results{left}                      → ikon berpindah ke kiri setelah pengambilan
inline display{right} results{hide(capture)}             → ikon menghilang setelah pengambilan
inline display{center} results{hide(capture), hide(filename)}
```

## Batasan yang Diketahui

- Tampilan yang kompleks mungkin tidak dirender secara identik di semua platform.
- Beberapa tampilan rtSurvey tingkat lanjut mungkin tidak didukung dalam mode luring (offline).

## Pemecahan Masalah Tampilan

1. **Tampilan Tidak Diterapkan**: Periksa kesalahan ketik pada kolom tampilan (appearance).
2. **Perenderaan Tidak Konsisten**: Verifikasi kompatibilitas dengan tipe pertanyaan dan platform.
3. **Masalah Performa**: Pertimbangkan untuk menyederhanakan tampilan yang kompleks, terutama untuk survei besar.

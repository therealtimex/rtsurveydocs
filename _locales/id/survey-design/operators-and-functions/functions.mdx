### Fungsi string

<Callout type="warning">
Saat bekerja dengan string dalam ekspresi, penting untuk menggunakan tanda kutip tunggal ('') untuk mengapit string literal. Namun, pengecualian muncul jika Anda ingin menyertakan tanda kutip tunggal di dalam string literal. Dalam kasus seperti itu, Anda dapat menggunakan tanda kutip ganda ("") untuk mengapit seluruh string.

Sebagai contoh:
- Benar: if(`${yesno}` = 1, "a string with 'single quotes' in it", "no single quotes here")
- Salah: if(`${yesno}` = 1, 'a string with 'single quotes' in it', 'no single quotes here')

Mengenai tanda kutip cerdas (smart quotes), sangat penting untuk menyadari keberadaannya, karena dapat menyebabkan masalah dalam ekspresi. Banyak editor teks kaya secara otomatis mengubah tanda kutip lurus ("" atau '') menjadi tanda kutip cerdas atau tanda kutip lengkung (“” atau ‘’), yang dapat menyebabkan kesalahan sintaksis atau perilaku yang tidak terduga. Untuk menghindari hal ini, pastikan Anda menggunakan tanda kutip lurus ('') secara konsisten dalam ekspresi Anda.

Beri tahu saya jika Anda memiliki pertanyaan lebih lanjut atau butuh bantuan tambahan!
</Callout>

rtSurvey mendukung berbagai fungsi, termasuk:

1. `string(field)`: Mengonversi field menjadi string.
   - Contoh: `string(34.8)` akan dikonversi menjadi `'34.8'`.

2. `string-length(field)`: Mengembalikan panjang dari field string.
   - Contoh: `string-length(.) > 3 and string-length(.) < 10` dapat digunakan untuk memastikan field saat ini antara 3 dan 10 karakter.
   - **Pola dependensi kaskade**: `string-length(${province}) >= 0` selalu bernilai `true` tetapi memaksa rtSurvey untuk mengevaluasi kembali ekspresi setiap kali `${province}` berubah. Gunakan ini di `relevant` untuk memicu penyegaran kaskade saat field induk diperbarui:
     | type | name | relevant |
     |------|------|----------|
     | select_one | district | `string-length(${province}) >= 0` |
     Ini memastikan pertanyaan distrik mengevaluasi kembali tampilan (appearance) `search()` atau `rawquery`-nya setiap kali provinsi berubah.

3. `substr(fieldorstring, startindex, endindex)`: Mengembalikan substring yang dimulai pada `startindex` dan berakhir tepat sebelum `endindex`. Indeks dimulai dari 0 untuk karakter pertama dalam string.
   - Contoh: `substr(${phone}, 0, 3)` akan mengembalikan tiga digit pertama dari nomor telepon.

4. `concat(a, b, c, ...)`: Menggabungkan field (dan/atau string) bersama-sama.
   - Contoh: `concat(${firstname}, ' ', ${lastname})` akan mengembalikan nama lengkap dengan menggabungkan nilai-nilai dalam field `firstname` dan `lastname`.

5. `linebreak()`: Mengembalikan karakter ganti baris.
   - Contoh: `concat(${field1}, linebreak(), ${field2}, linebreak(), ${field3})` akan mengembalikan daftar tiga nilai field dengan ganti baris di antaranya.

6. `lower()`: Mengonversi string menjadi semua karakter huruf kecil.
   - Contoh: `lower('Street Name')` akan mengembalikan "street name".

7. `upper()`: Mengonversi string menjadi semua karakter huruf besar.
   - Contoh: `upper('Street Name')` akan mengembalikan "STREET NAME".

### fungsi select_one dan select_multiple

1. `count-selected(field)`: Mengembalikan jumlah item yang dipilih dalam field select_multiple.
   - Contoh: `count-selected(.) = 3` dapat digunakan sebagai ekspresi batasan (constraint) untuk memastikan tepat tiga pilihan yang dipilih.

2. `selected(field, value)`: Mengembalikan true atau false tergantung pada apakah nilai yang ditentukan dipilih dalam field select_one atau select_multiple.
   - Contoh: `selected(${color}, 'Blue')` dapat digunakan sebagai ekspresi relevansi untuk menampilkan grup atau field hanya jika responden memilih "Blue" sebagai warna favorit mereka.
   - Catatan: Parameter kedua harus selalu menentukan nilai pilihan (choice value), bukan label pilihan (choice label). Gunakan nilai dari kolom value di worksheet choices pada definisi formulir.

3. `selected-at(field, number)`: Mengembalikan item yang dipilih pada posisi yang ditentukan dalam field select_multiple. Saat angka yang dimasukkan adalah 0, ia mengembalikan item pertama yang dipilih; saat angkanya 1, ia mengembalikan item kedua yang dipilih, dan seterusnya.
   - Contoh: `selected-at(${fruits}, 0) = 'Apple'` dapat digunakan sebagai ekspresi relevansi untuk menampilkan grup atau field hanya jika pilihan pertama yang dipilih adalah "Apple".
   - Catatan: Nilai yang dikembalikan adalah nilai pilihan, bukan label pilihan. Gunakan nilai dari kolom value di worksheet choices pada definisi formulir.

4. `choice-label(field, value)`: Mengembalikan label untuk pilihan field select_one atau select_multiple, sebagaimana didefinisikan dalam worksheet choices pada definisi formulir.
   - Contoh 1: `choice-label(${country}, ${country})` akan mengembalikan label pilihan untuk pilihan yang saat ini dipilih dalam field bernama `country`.
   - Contoh 2: `choice-label(${languages}, selected-at(${languages}, 0))` akan mengembalikan label untuk pilihan pertama yang dipilih dalam field bernama `languages`.
   - Catatan: Fungsi ini mengambil label pilihan, bukan nilai. Ia menggunakan kolom label dari worksheet choices pada definisi formulir.

### Fungsi field berulang (repeated field)

Di rtSurvey, jika Anda ingin mengajukan pertanyaan yang sama berkali-kali, Anda dapat menempatkan field di dalam grup berulang (repeat group). Ini menghasilkan beberapa instans dari field yang sama. Fungsi-fungsi berikut dapat membantu Anda menangani field berulang ini dan data berulang yang dihasilkannya. Lihat topik bantuan tentang field berulang untuk detail lebih lanjut.

1. `join(string, repeatedfield)`: Untuk field di dalam grup berulang, menghasilkan daftar nilai yang dipisahkan oleh string. Parameter pertama menentukan pemisah (delimiter) yang digunakan untuk memisahkan nilai-nilai tersebut.
   - Contoh: `join(', ', ${member_name})` akan menghasilkan satu daftar yang dipisahkan koma dari semua nama yang dimasukkan.

2. `join-if(string, repeatedfield, expression)`: Berfungsi persis seperti `join()`, kecuali ia memeriksa setiap instans dalam grup berulang menggunakan ekspresi yang diberikan. Jika ekspresi bernilai false, item tersebut akan diabaikan dari output.
   - Contoh: `join-if(', ', ${member_name}, ${age} >= 18)` akan menghasilkan daftar nama yang dipisahkan koma hanya untuk anggota dewasa (mereka dengan usia 18 tahun ke atas).

3. `count(repeatgroup)`: Mengembalikan jumlah pengulangan saat ini dari sebuah grup berulang.
   - Contoh: `count(${groupname})` akan mengembalikan jumlah instans dari grup tersebut.

4. `count-if(repeatgroup, expression)`: Berfungsi persis seperti `count()`, kecuali ia memeriksa setiap instans dalam grup berulang menggunakan ekspresi yang diberikan. Jika ekspresi bernilai false, item tersebut akan diabaikan dari penghitungan.
   - Contoh: `count-if(${members}, ${age} >= 18)` akan mengembalikan jumlah anggota dewasa berdasarkan field age di dalam grup berulang "members".

5. `sum(repeatedfield)`: Untuk field di dalam grup berulang, menghitung jumlah dari semua nilai.
   - Contoh: `sum(${loan_amount})` akan mengembalikan total nilai dari semua pinjaman.

6. `sum-if(repeatedfield, expression)`: Berfungsi persis seperti `sum()`, kecuali ia memeriksa setiap instans dalam grup berulang menggunakan ekspresi yang diberikan. Jika ekspresi bernilai false, item tersebut akan diabaikan dari output.
   - Contoh: `sum-if(${loan_amount}, ${loan_amount} > 500)` akan mengembalikan total nilai dari semua pinjaman yang di atas 500. Pinjaman yang lebih kecil akan diabaikan.

7. `min(repeatedfield)`: Untuk field di dalam grup berulang, menghitung nilai minimum dari semua nilai.
   - Contoh: `min(${member_age})` akan mengembalikan usia anggota termuda dalam grup.

8. `min-if(repeatedfield, expression)`: Berfungsi persis seperti `min()`, kecuali ia memeriksa setiap instans dalam grup berulang menggunakan ekspresi yang diberikan. Jika ekspresi bernilai false, item tersebut akan diabaikan dari perhitungan minimum.
   - Contoh: `min-if(${member_age}, ${member_age} >= 18)` akan mengembalikan usia dewasa termuda dalam grup. Mereka yang lebih muda dari 18 tahun akan diabaikan.

9. `max(repeatedfield)`: Untuk field di dalam grup berulang, menghitung nilai maksimum dari semua nilai.
   - Contoh: `max(${member_age})` akan mengembalikan usia anggota tertua dalam grup.

10. `max-if(repeatedfield, expression)`: Berfungsi persis seperti `max()`, kecuali ia memeriksa setiap instans dalam grup berulang menggunakan ekspresi yang diberikan. Jika ekspresi bernilai false, item tersebut akan diabaikan dari perhitungan maksimum.
    - Contoh: `max-if(${member_age}, ${member_age} >= 18)` akan mengembalikan usia dewasa tertua dalam grup. Mereka yang lebih muda dari 18 tahun akan diabaikan.

11. `index()`: Dipanggil di dalam grup berulang, mengembalikan nomor indeks untuk grup atau instans saat ini.
    - Contoh: `index()` saat digunakan di dalam grup berulang akan mengembalikan 1 untuk instans pertama, 2 untuk yang kedua, dan seterusnya.

12. `indexed-repeat(repeatedfield, repeatgroup, index)`: Mereferensikan field atau grup yang berada di dalam grup berulang dari luar grup berulang tersebut. Parameter pertama menentukan field atau grup berulang yang dimaksud, kedua menentukan grup berulang tempat field atau grup tersebut berada, dan ketiga menentukan nomor instans di dalam grup berulang yang akan digunakan.
    - Contoh 1: `indexed-repeat(${name}, ${names}, 1)` akan mengembalikan nama pertama yang tersedia saat field name berada di dalam grup berulang sebelumnya bernama "names".
    - Contoh 2: `indexed-repeat(${name}, ${names}, index())` akan menarik nama yang sesuai dengan nomor instans dari grup berulang saat ini.

13. `rank-index(index, repeatedfield)`: Fungsi ini menghitung peringkat ordinal dari instans tertentu dari field berulang untuk digunakan di luar grup berulang. Peringkat 1 diberikan kepada instans dengan nilai tertinggi, peringkat 2 untuk instans dengan nilai tertinggi berikutnya, dan seterusnya. Jika Anda memasukkan indeks yang tidak valid atau indeks ke instans dengan nilai non-numerik, peringkat 999 akan dikembalikan.
    - Contoh: `rank-index(1, ${random_draw})` menghitung peringkat instans pertama berdasarkan nilai field `random_draw`-nya dibandingkan dengan nilai instans lainnya.

14. `rank-index-if(index, repeatedfield, expression)`: Fungsi ini bekerja mirip dengan `rank-index()`, tetapi ia memeriksa setiap instans dalam grup berulang field berulang menggunakan ekspresi yang diberikan. Jika ekspresi bernilai false, item tersebut akan diabaikan dari perhitungan. Indeks yang digunakan didasarkan pada set lengkap instans sebelum mengevaluasi ekspresi untuk setiap instans. Jika Anda memasukkan indeks untuk instans yang diabaikan karena tidak memenuhi ekspresi, itu dianggap sebagai indeks yang tidak valid, dan peringkat 999 akan dikembalikan.
    - Contoh: `rank-index-if(1, ${age}, ${age} >= 18)` menghitung peringkat usia dalam set orang dewasa, hanya mempertimbangkan instans di mana usianya lebih besar dari atau sama dengan 18.

### Fungsi angka

| Operator | Operasi | Contoh | Jawaban contoh |
|----------|-----------|---------|----------------|
| `+` | Penjumlahan | 1 + 1 | 2 |
| `-` | Pengurangan | 3 - 2 | 1 |
| `*` | Perkalian | 3 * 2 | 6 |
| `div` | Pembagian | 10 div 2 | 5 |
| `mod` | Modulus | 9 mod 2 | 1 |

rtSurvey mendukung fungsi angka, termasuk:
- `number(field)`: Mengonversi nilai field menjadi angka.
  - Contoh: `number('34.8')` = 34.8

- `int(field)`: Mengonversi nilai field menjadi bilangan bulat (integer).
  - Contoh: `int('39.2')` = 39

- `min(field1, ..., fieldx)`: Mengembalikan nilai minimum di antara field yang dimasukkan.
  - Contoh: `min(${father_age}, ${mother_age})` akan mengembalikan usia ibu atau ayah, mana saja yang lebih kecil.

- `max(field1, ..., fieldx)`: Mengembalikan nilai maksimum di antara field yang dimasukkan.
  - Contoh: `max(${father_age}, ${mother_age})` akan mengembalikan usia ibu atau ayah, mana saja yang lebih besar.

- `format-number(field)`: Memformat nilai field bilangan bulat atau desimal sesuai dengan pengaturan lokal (locale) pengguna.
  - Contoh: `format-number(${income})` Ekspresi ini mungkin memformat "120000" sebagai "120,000".

- `round(field, digits)`: Membulatkan nilai field numerik ke jumlah digit yang ditentukan setelah tanda desimal.
  - Contoh: `round(${interest_rate}, 2)`

- `abs(number)`: Mengembalikan nilai absolut dari sebuah angka.
  
- `pow(base, exponent)`: Mengembalikan nilai dari parameter pertama yang dipangkatkan dengan parameter kedua.
  - Setiap parameter bisa berupa field, angka, atau ekspresi.

- `log10(fieldorvalue)`: Mengembalikan logaritma berbasis sepuluh dari field atau nilai yang dimasukkan.

- `sin(fieldorvalue)`: Mengembalikan sinus dari field atau nilai yang dimasukkan, dinyatakan dalam radian.
  
- `cos(fieldorvalue)`: Mengembalikan kosinus dari field atau nilai yang dimasukkan, dinyatakan dalam radian.

- `tan(fieldorvalue)`: Mengembalikan tangen dari field atau nilai yang dimasukkan, dinyatakan dalam radian.

- `asin(fieldorvalue)`: Mengembalikan arcsine dari field atau nilai yang dimasukkan, dinyatakan dalam radian.

- `acos(fieldorvalue)`: Mengembalikan arccosine dari field atau nilai yang dimasukkan, dinyatakan dalam radian.

- `atan(fieldorvalue)`: Mengembalikan arctangent dari field atau nilai yang dimasukkan, dinyatakan dalam radian.

- `atan2(x, y)`: Mengembalikan sudut dalam radian yang dibentuk di titik asal oleh titik dengan koordinat (x, y) dan sumbu x positif. Hasilnya berada dalam rentang -pi() hingga pi().

- `sqrt(fieldorvalue)`: Mengembalikan akar kuadrat non-negatif dari field atau nilai yang dimasukkan.

- `exp(x)`: Mengembalikan nilai dari e^x.

- `pi()`: Mengembalikan nilai pi.

### Fungsi tanggal dan waktu

<Callout type="warning">
Nilai tanggal di rtSurvey disimpan sebagai string dalam format `YYYY-MM-DD`. Nilai datetime disimpan sebagai string ISO 8601 (`YYYY-MM-DDTHH:MM:SS`). Gunakan `decimal-date-time()` untuk mengonversi menjadi angka untuk aritmatika (misalnya, menghitung durasi).
</Callout>

1. `today()`: Mengembalikan tanggal hari ini sebagai string dalam format `YYYY-MM-DD`. Dievaluasi sekali saat formulir dibuka.
   - Contoh: `today()` → `'2024-03-15'`
   - Penggunaan umum: kolom `default` untuk mengisi otomatis tanggal hari ini, atau dalam `relevant`/`constraint` untuk membandingkan dengan field tanggal.

2. `now()`: Mengembalikan tanggal dan waktu saat ini sebagai string ISO 8601. Dievaluasi setiap kali ekspresi dihitung.
   - Contoh: `now()` → `'2024-03-15T14:32:00.000+03:00'`
   - Penggunaan umum: Mencatat stempel waktu (timestamp) yang tepat dari peristiwa tertentu selama survei.

3. `date(value)`: Mengonversi sebuah nilai (string atau angka) menjadi string tanggal. Berguna untuk memaksa nilai yang dihitung menjadi tipe tanggal.
   - Contoh: `date('2024-03-15')` → `'2024-03-15'`

4. `date-time(value)`: Mengonversi sebuah nilai menjadi string datetime.
   - Contoh: `date-time(${event_timestamp})`

5. `decimal-date-time(value)`: Mengonversi string tanggal atau datetime menjadi angka desimal yang mewakili milidetik sejak epoch Unix dibagi 86400000 (yaitu, pecahan hari sejak 1970-01-01). Gunakan ini untuk melakukan aritmatika pada tanggal.
   - Contoh: Durasi dalam hari antara dua tanggal:
     `decimal-date-time(${end_date}) - decimal-date-time(${start_date})`
   - Contoh: Durasi dalam menit antara dua datetime:
     `(decimal-date-time(${end_time}) - decimal-date-time(${start_time})) * 1440`

6. `format-date(date, format)`: Memformat nilai tanggal menggunakan string pola.
   - Token format: `%Y` (tahun 4 digit), `%y` (tahun 2 digit), `%m` (bulan 01–12), `%d` (hari 01–31), `%a` (hari dalam seminggu yang disingkat), `%b` (nama bulan yang disingkat)
   - Contoh: `format-date(today(), '%d/%m/%Y')` → `'15/03/2024'`
   - Contoh: `format-date(${dob}, '%B %d, %Y')` → `'March 15, 1990'`

7. `format-date-time(datetime, format)`: Memformat nilai datetime menggunakan string pola. Menerima semua token `format-date` ditambah:
   - `%H` (jam 00–23), `%h` (jam 01–12), `%M` (menit 00–59), `%S` (detik 00–59), `%3` (milidetik), `%P` (AM/PM)
   - Contoh: `format-date-time(now(), '%d/%m/%Y %H:%M')` → `'15/03/2024 14:32'`
   - Contoh: `format-date-time(${event_time}, '%I:%M %p')` → `'02:32 PM'`

8. `STRFTIME(format, datetime)`: Pemformatan tanggal gaya SQLite. Tersedia di dalam string SQL yang dimasukkan ke kueri `rawquery` — **tidak** tersedia di kolom `calculation` atau `label` XLSForm. Menggunakan token format SQLite (`%Y`, `%m`, `%d`, `%H`, `%M`, `%S`).
   - Contoh di dalam string SQL rawquery: `'SELECT STRFTIME(''%Y-%m'', interview_date) AS month FROM data WHERE id = ?'`
   - Catatan: Gunakan `format-date-time()` untuk pemformatan tanggal dalam ekspresi XLSForm. `STRFTIME()` adalah fungsi SQLite yang hanya tersedia di dalam SQL yang dimasukkan ke `rawquery`.

### Fungsi Boolean

1. `boolean(value)`: Mengonversi nilai apa pun menjadi boolean. Mengembalikan `true` untuk string yang tidak kosong, angka bukan nol, dan `true`; mengembalikan `false` untuk string kosong, `0`, dan `false`.
   - Contoh: `boolean(${name})` mengembalikan `true` jika `name` tidak kosong.

2. `boolean-from-string(string)`: Mengembalikan `true` jika string adalah `'1'` atau `'true'` (tidak peka huruf besar/kecil); mengembalikan `false` jika tidak.
   - Contoh: `boolean-from-string(${enabled_flag})` — berguna saat field menyimpan `'true'`/`'false'` sebagai teks.

3. `true()`: Mengembalikan nilai boolean `true`.
   - Contoh: Di kolom `required`, `true()` setara dengan `yes`.

4. `false()`: Mengembalikan nilai boolean `false`.
   - Contoh: `if(${skip_section} = 'yes', false(), true())` — mengatur status wajib (required) secara dinamis.

5. `not(expression)`: Mengembalikan negasi logis dari ekspresi. Mengembalikan `true` jika ekspresi bernilai false, dan sebaliknya.
   - Contoh: `not(${consent} = 'yes')` — menampilkan peringatan saat persetujuan TIDAK diberikan.
   - Contoh: `not(selected(${issues}, 'none'))` — mewajibkan detail hanya jika "none" tidak dipilih.

### Fungsi string tambahan

1. `starts-with(string, prefix)`: Mengembalikan `true` jika `string` dimulai dengan `prefix`.
   - Contoh: `starts-with(${phone}, '+254')` memeriksa apakah nomor telepon dimulai dengan kode negara Kenya.

2. `contains(string, substring)`: Mengembalikan `true` jika `string` mengandung `substring`.
   - Contoh: `contains(${email}, '@')` memeriksa apakah alamat email memiliki tanda `@`.
   - Contoh: `contains(${notes}, 'urgent')` memicu pertanyaan tindak lanjut jika catatan menyebutkan "urgent".

3. `substring-before(string, needle)`: Mengembalikan bagian dari `string` yang muncul sebelum kemunculan pertama `needle`.
   - Contoh: `substring-before(${full_name}, ' ')` mengambil kata pertama (nama depan).

4. `substring-after(string, needle)`: Mengembalikan bagian dari `string` yang muncul setelah kemunculan pertama `needle`.
   - Contoh: `substring-after(${email}, '@')` mengambil bagian domain dari alamat email.

5. `normalize-space(string)`: Menghapus spasi di awal dan akhir dan merampingkan semua urutan spasi internal menjadi satu spasi saja.
   - Contoh: `normalize-space(${name})` — membersihkan nama yang mungkin telah diketik dengan spasi ekstra.

6. `translate(string, search_chars, replace_chars)`: Mengganti setiap karakter dalam `string` yang muncul di `search_chars` dengan karakter yang sesuai di `replace_chars`. Karakter di `search_chars` yang tidak memiliki karakter yang sesuai di `replace_chars` akan dihapus.
   - Contoh: `translate(${code}, 'abcdefghijklmnopqrstuvwxyz', 'ABCDEFGHIJKLMNOPQRSTUVWXYZ')` mengonversi ke huruf besar (setara dengan `upper()`).
   - Contoh: `translate(${phone}, ' -()', '')` menghapus spasi, tanda hubung, dan tanda kurung dari nomor telepon.

### Fungsi matematika tambahan

1. `floor(number)`: Mengembalikan bilangan bulat terbesar yang kurang dari atau sama dengan `number` (pembulatan ke arah negatif tak hingga).
   - Contoh: `floor(4.9)` = 4, `floor(-2.1)` = -3

2. `ceiling(number)`: Mengembalikan bilangan bulat terkecil yang lebih besar dari atau sama dengan `number` (pembulatan ke arah positif tak hingga).
   - Contoh: `ceiling(4.1)` = 5, `ceiling(-2.9)` = -2

3. `random()`: Mengembalikan angka desimal acak antara 0.0 (inklusif) dan 1.0 (eksklusif). Biasanya digunakan di field `calculate` untuk memberikan nilai acak atau mengacak urutan pertanyaan.
   - Contoh: `random()` → misal, `0.7341`
   - Contoh: `int(random() * 6) + 1` → angka acak 1–6 (lemparan dadu)

4. `coalesce(a, b)`: Mengembalikan `a` jika `a` tidak kosong; jika tidak, mengembalikan `b`. Berguna sebagai cadangan (fallback) saat sebuah field mungkin kosong.
   - Contoh: `coalesce(${preferred_name}, ${full_name})` — menggunakan nama panggilan jika diatur, jika tidak kembali ke nama lengkap.

5. `once(value)`: Mengevaluasi `value` dan menyimpannya, tetapi hanya jika field saat ini **kosong**. Jika field sudah memiliki nilai (misalnya, sudah diatur sebelumnya), `once()` mengembalikan nilai yang ada tanpa perubahan. Ini mencegah penghitungan ulang yang menimpa input pengguna.
   - Contoh: `once(today())` di kolom `default` menetapkan tanggal hari ini sekali dan tidak diperbarui jika enumerator membuka kembali formulir.
   - Contoh: `once(uuid())` menghasilkan UUID sekali dan menjaganya tetap stabil meskipun formulir diedit kembali.

### Fungsi Geo

1. `area(geoshape_value)`: Menghitung **luas dalam meter persegi** yang dikelilingi oleh nilai geoshape (poligon).
   - Parameternya adalah nilai field geoshape dalam format `lat1 lon1 0 0; lat2 lon2 0 0; ...`
   - Contoh: `area(${field_boundary})` — menghitung luas lahan yang disurvei dalam m².
   - Contoh: `round(area(${field_boundary}) div 10000, 2)` — mengonversi ke hektar.

2. `distance(coordinates)`: Menghitung **total panjang lintasan dalam meter** dari sebuah geotrace (garis), atau jarak antara dua geopoint.
   - Untuk geotrace: `distance(${route})` mengembalikan total panjang lintasan dalam meter.
   - Untuk dua geopoint: `distance(concat(${point_a}, ' ', ${point_b}))` mengembalikan jarak di antara keduanya.
   - Contoh: `round(distance(${road_trace}) div 1000, 3)` — panjang jalan dalam kilometer.

### Fungsi Validasi

1. `regex(value, pattern)`: Mengembalikan `true` jika `value` cocok dengan ekspresi reguler `pattern`. Gunakan di kolom `constraint` untuk validasi berbasis pola.
   - Polanya menggunakan sintaks regex standar (subset POSIX ERE).
   - Contoh: `regex(., '^[0-9]{10}$')` — memvalidasi angka 10 digit.
   - Contoh: `regex(., '^[A-Z]{2}[0-9]{6}$')` — memvalidasi format nomor paspor (2 huruf besar diikuti oleh 6 digit).
   - Contoh: `regex(., '^[^@]+@[^@]+\.[^@]{2,}$')` — pemeriksaan format email dasar.

2. `checklist(min, max, v1, v2, ...)`: Mengevaluasi daftar ekspresi boolean dan mengembalikan `true` jika jumlah nilai `true` berada di antara `min` dan `max` (inklusif). Masukkan `-1` untuk `min` atau `max` untuk mengabaikan batasan tersebut.
   - Contoh: `checklist(2, 3, ${q1} = 'yes', ${q2} = 'yes', ${q3} = 'yes')` — lolos jika tepat 2 atau 3 dari tiga kondisi tersebut bernilai benar.
   - Contoh: `checklist(1, -1, ${smoke_alarm}, ${fire_ext}, ${emergency_plan})` — setidaknya satu tindakan pengamanan harus bernilai benar.

3. `weighted-checklist(min, max, v1, w1, v2, w2, ...)`: Seperti `checklist()`, tetapi setiap nilai memiliki bobot. Jumlah bobot untuk nilai `true` harus di antara `min` dan `max`.
   - Contoh: `weighted-checklist(10, -1, ${has_toilet}, 4, ${has_sink}, 3, ${has_shower}, 5)` — jumlah bobot untuk fasilitas yang ada harus setidaknya 10.

### Fungsi Utilitas

1. `uuid()`: Menghasilkan UUID acak (format RFC 4122 v4) sebagai string.
   - Contoh: `uuid()` → `'a3f8b2c1-4d5e-6f7a-8b9c-0d1e2f3a4b5c'`
   - Biasanya digunakan dengan `once()` untuk menghasilkan ID unik yang stabil: `once(uuid())`

2. `version()`: Mengembalikan nilai dari atribut `version` formulir sebagaimana diatur di worksheet settings.
   - Contoh: `version()` → `'3.1'`
   - Berguna di field `calculate` untuk menyertakan versi formulir dalam data yang diekspor.

3. `position()`: Saat dipanggil di dalam **grup berulang**, mengembalikan indeks berbasis 1 dari instans pengulangan saat ini.
   - Contoh: `position()` di instans pertama mengembalikan `1`, di instans kedua mengembalikan `2`, dan seterusnya.
   - Lihat juga: `index()` (alias), `indexed-repeat()` untuk mereferensikan nilai pengulangan dari luar grup.

4. `thousandsep(length, separator, value)`: Memformat angka dengan pemisah ribuan. `length` adalah panjang total minimum string (diisi dengan spasi jika lebih pendek), `separator` adalah karakter yang akan digunakan (misalnya, `','`), dan `value` adalah angka yang akan diformat.
   - Contoh: `thousandsep(0, ',', 1234567)` → `'1,234,567'`
   - Contoh: `thousandsep(0, '.', ${income})` → memformat pendapatan dengan titik sebagai pemisah ribuan.

5. `substr-jsonpath(value, jsonpath)`: Mengambil nilai dari string JSON menggunakan ekspresi JSONPath.
   - `value` harus berupa string JSON (misalnya, field yang menyimpan respons API mentah menggunakan `callapi(..., 'json:', ...)`).
   - `jsonpath` adalah ekspresi JSONPath (misalnya, `'$.data.name'`, `'$.items[0].id'`).
   - Selalu mengembalikan **string** — apit dengan `number()` saat digunakan dalam aritmatika.
   - Mengembalikan string kosong `''` jika path tidak ditemukan atau `value` bukan JSON yang valid.
   - Contoh: `substr-jsonpath(${api_response}, '$.data.name')` — mengambil field `name`.
   - Contoh: `substr-jsonpath(${api_response}, '$.items[0].label')` — elemen pertama dari sebuah array.
   - Contoh: `number(substr-jsonpath(${api_response}, '$.price'))` — mengambil nilai numerik.
   - Biasanya digunakan bersamaan dengan `callapi(..., 'json:', ...)` untuk mengambil beberapa field dari satu respons API. Lihat [Mengambil beberapa nilai dari satu panggilan API](../advanced-features/call-api#fetching-multiple-values-from-one-api-call).

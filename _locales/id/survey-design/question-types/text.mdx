---

Tipe pertanyaan `text` mengumpulkan string teks bebas. Ini adalah tipe input yang paling fleksibel dan mendukung sejumlah besar varian `appearance` yang mengubah cara input dirender — dari bidang satu baris sederhana hingga `speech-to-text`, dialog `popup`, editor teks kaya, dan pemutar numerik.

## Spesifikasi XLSForm Dasar

| type | name | label |
|------|------|-------|
| text | respondent_name | Nama lengkap responden |
| text | address | Alamat rumah |

Untuk spesifikasi standar, lihat [dokumentasi XLSForm](https://xlsform.org/en/#question-types).

---

## Mode tata letak

### Default — input satu baris

Tidak perlu `appearance`. Merender bidang `<input type="text">` standar.

---

### `multiline` — area teks

Merender area teks multi-baris. Pengguna dapat memperluasnya dengan mengetik; ini akan membesar secara otomatis.

```
multiline
```

**Kontrol tinggi baris** dengan menambahkan `[initRows, maxRows]`:

```
multiline [3,8]     → dimulai dengan 3 baris, memanjang hingga 8
multiline [5]       → tetap pada 5 baris
```

Default adalah 1 baris tanpa maks. Shift+Enter menyisipkan jeda baris; Enter melanjutkan ke pertanyaan berikutnya.

---

### `floating_hint` — petunjuk mengambang sebagai label

Teks `hint` dirender di dalam bidang input sebagai placeholder. Saat pengguna mulai mengetik, petunjuk akan mengambang di atas bidang sebagai label.

```
floating_hint
```

---

### `embed` — petunjuk di dalam input

Mirip dengan `floating_hint` — petunjuk dirender di dalam batas input saat bidang kosong. Tidak mengambang saat mengetik.

```
embed
```

---

### `textpopup` — input dialog modal

Mengetuk bidang akan membuka dialog modal SweetAlert dengan input yang lebih besar, bukan mengedit secara inline. Berguna di perangkat seluler untuk memberikan lebih banyak ruang layar untuk mengetik.

```
textpopup
```

---

### `richtext` — editor WYSIWYG

Merender editor teks kaya lengkap (Monaco / Draft.js). Responden dapat menebalkan, memiringkan, menambahkan daftar, dll. Nilai yang disimpan adalah HTML.

```
richtext
richtext(30%)       → tinggi editor 30% dari viewport
```

---

### `charcount` — penghitung karakter langsung

Menambahkan tampilan penghitung karakter `(n)` di bawah input, memperbarui saat pengguna mengetik.

```
charcount
multiline charcount
```

## Varian input numerik

`appearance` ini bekerja pada tipe `text` untuk mengumpulkan angka dengan pemformatan atau pola interaksi khusus.

### `numbers` — keyboard numerik

Memaksa tipe input HTML menjadi `number`, memicu keyboard numerik di perangkat seluler.

```
numbers
```

### `thousandsep` — pemisah ribuan

Menampilkan angka dengan pengelompokan koma (misalnya `1,234,567`) sambil menyimpan angka mentah. Tipe input dipaksa menjadi `text` untuk memungkinkan tampilan koma.

```
thousandsep
```

### `digisep(n, "sep")` — pengelompokan digit kustom

Mengelompokkan digit menjadi blok `n` yang dipisahkan oleh karakter kustom. Berguna untuk nomor telepon, nomor ID, dll.

```
digisep(4,"-")      → 0912-3456-789
digisep(3," ")      → 012 345 678
```

### `number-hspinner` — pemutar horizontal

Mengganti input dengan pemutar horizontal **− nilai +**. Pengguna mengetuk tombol minus/plus untuk mengurangi atau menambah nilai. Bekerja dengan tipe `int` dan `decimal`.

```
number-hspinner
```

**Sesuaikan `appearance` tombol** menggunakan `hspinner()`:

```
number-hspinner hspinner('left-small-square','right-small-square','1')
```

Parameter: bentuk tombol kiri, bentuk tombol kanan, nilai langkah.

**Warna kustom** menggunakan `colors()`:

```
number-hspinner colors(0099FF,FFFFFF,FF5500,FFFFFF)
```

Empat nilai warna: latar belakang kiri, ikon kiri, latar belakang kanan, ikon kanan.

### `prefix(expr)` — tambahkan awalan

Menambahkan string yang dihitung atau statis ke nilai yang ditampilkan. Nilai yang disimpan tidak menyertakan awalan.

```
prefix('USD ')      → menampilkan "USD 100", menyimpan "100"
prefix(${currency}) → awalan dinamis dari bidang lain
```

### `textonly` — paksa tipe input teks

Memaksa `type="text"` bahkan ketika bidang tersebut adalah `integer` atau `decimal`. Berguna untuk menghindari keanehan input angka browser.

```
textonly
```

## Transformasi teks

`appearance` ini secara otomatis mengubah nilai saat pengguna mengetik.

| Appearance | Efek | Contoh input → disimpan |
|---|---|---|
| `upper` | Mengubah menjadi HURUF BESAR | `hello` → `HELLO` |
| `lower` | Mengubah menjadi huruf kecil | `HELLO` → `hello` |
| `proper` | Mengubah menjadi Huruf Kapital Setiap Kata | `john doe` → `John Doe` |

---

## Pembantu pengambilan input

### `inputs{stt}` — `speech to text`

Menambahkan tombol mikrofon di samping input. Mengetuknya memulai pengenalan suara browser (Web Speech API). Teks yang ditranskripsi ditambahkan ke bidang.

```
inputs{stt}
```

Tidak didukung di Safari. Membutuhkan izin mikrofon.

### `inputs{qrscan}` — pemindai QR / barcode

Menambahkan tombol pemindaian kode QR di samping input. Membuka modal pemindai kamera dan mengisi bidang dengan nilai yang dipindai.

```
inputs{qrscan}
```

**Tokenisasi** (menambahkan nilai yang dipindai alih-alih mengganti):

```
inputs{qrscan} append(${separator})
```

### `inputs{stt,qrscan}` — suara dan pindai

Merender tombol mikrofon dan pemindai QR secara berdampingan.

```
inputs{stt,qrscan}
inputs{qrscan,stt}
```

## Varian yang terkait dengan pemilihan

`appearance` ini menautkan bidang teks ke daftar pilihan `select_one`, memungkinkan pengguna memilih dari daftar atau mengetik secara bebas.

### `selection_one_hide` — pemilih dropdown

Merender input teks dengan panah dropdown. Mengetuk panah menunjukkan pilihan dari daftar `search()` yang tertaut. Memilih pilihan mengisi input dan menguncinya (menunjukkan ✕ untuk menghapus).

```
selection_one_hide
```

### `selection_one_show` — daftar radio di bawah

Merender input teks dengan tombol radio di bawahnya. Memilih radio mengisi dan mengunci input.

```
selection_one_show
```

Kedua varian membutuhkan ekspresi `search()` di kolom `calculation` untuk mendefinisikan daftar pilihan.

---

## Perataan jawaban

Mengontrol perataan horizontal teks yang diketik di dalam input.

```
align_answer = left
align_answer = right
align_answer = center
```

## Widget input waktu (jam sebaris)

rtSurvey memperluas `text` dengan widget pemilih jam. `appearance` ini menampilkan ikon jam yang diketuk enumerator untuk memilih nilai waktu. Nilai disimpan sebagai teks biasa dalam format yang dipilih.

### `Appearance`

| Appearance | Deskripsi |
|---|---|
| `inline` | Tombol ikon jam di samping bidang, membuka modal |
| `inline-onlyresult` | Ikon jam menghilang setelah pemilihan |
| `inline-1line` | Pemutar waktu satu baris ringkas |
| `inline colors("RRGGBB")` | Ikon jam dengan warna kustom |
| `inline-1line colors("RRGGBB","RRGGBB")` | Pemutar dengan dua warna aksen |

### Token format

Tambahkan `-[format]` untuk mengontrol komponen waktu mana yang ditampilkan dan disimpan:

| Format | Menampilkan |
|---|---|
| `inline-[%H:%M]` | Jam : Menit (24j) |
| `inline-[%h:%M]` | Jam : Menit (12j) |
| `inline-[%H:%M:%S]` | Jam : Menit : Detik (24j) |
| `inline-[%M:%S]` | Menit : Detik |
| `inline-[%H:%M:%3]` | Jam : Menit : Milidetik |
| `inline-[%S]` | Detik saja |
| `inline-[%3]` | Milidetik saja |
| `inline-[%H]` | Jam saja (24j) |

### Posisi tombol dengan `display{}`

Sama dengan tipe `inline` lainnya — mengontrol posisi dan ukuran tombol jam:

```
inline display{right}
inline display{center, large}
inline-onlyresult display{left, medium, #0099FF}
```

## Batasan dan validasi

Terapkan batasan untuk memberlakukan format, panjang, atau pola:

| type | name | label | constraint | constraint_message |
|------|------|-------|------------|-------------------|
| text | name | Nama lengkap | `string-length(.) >= 2` | Setidaknya 2 karakter diperlukan |
| text | code | Kode referensi | `regex(., '^[A-Z]{2}[0-9]{4}$')` | 2 huruf kapital + 4 digit |
| text | phone | Nomor telepon | `regex(., '^[0-9]{9,15}$')` | Masukkan nomor telepon yang valid |

---

## Praktik Terbaik

1. Gunakan tipe yang lebih spesifik (`integer`, `decimal`, `date`) saat data memiliki struktur yang diketahui — ini mencegah entri yang tidak valid.
2. Gunakan `multiline [3,8]` untuk pertanyaan terbuka untuk memberi ruang kepada responden untuk menulis tanpa membanjiri layar.
3. Gunakan `thousandsep` atau `digisep()` alih-alih `numbers` saat Anda membutuhkan tampilan yang diformat — `numbers` saja hanya mengubah keyboard.
4. Gunakan `inputs{qrscan}` untuk menghilangkan kesalahan pengetikan manual untuk kode, ID, dan nomor seri.
5. Gunakan `floating_hint` ketika petunjuk adalah konteks penting yang harus tetap terlihat saat mengetik — petunjuk standar menghilang dari pandangan di layar kecil.
6. Gunakan `charcount` pada pertanyaan dengan batasan panjang sehingga responden dapat memantau diri sendiri.

## Batasan

- `inputs{stt}` membutuhkan browser yang mendukung Web Speech API. Chrome adalah yang paling andal; Safari tidak didukung.
- `richtext` menyimpan HTML — rencanakan penghapusan HTML atau sanitasi dalam alur analisis Anda jika teks biasa diharapkan.
- `selection_one_hide` dan `selection_one_show` membutuhkan ekspresi `search()` dan hanya didukung di klien web.
- `number-hspinner` memvalidasi terhadap kolom `constraint` pada setiap penekanan tombol, bukan hanya saat blur — rancang batasan sesuai.

---
title: "Geopoint"
description: "Pertanyaan geopoint menangkap koordinat geografis (lintang, bujur, ketinggian, dan akurasi) sebagai bagian dari survei."
---

Tipe pertanyaan `geopoint` menangkap koordinat geografis (lintang, bujur, ketinggian, akurasi) menggunakan GPS perangkat. rtSurvey menampilkan pemilih dengan beberapa mode tata letak dan mendukung otomatisasi melalui parameter `inputs{}` dan `outputs{}`.

## Spesifikasi Dasar XLSForm

| type     | name        | label                           |
|----------|-------------|---------------------------------|
| geopoint | location    | Rekam lokasi saat ini           |

Untuk spesifikasi standar, lihat [dokumentasi XLSForm](https://xlsform.org/en/#question-types).

## Format Data

Disimpan sebagai empat nilai yang dipisahkan spasi:

```
latitude longitude altitude accuracy
```

Contoh: `13.756331 100.501762 15 8`

---

## Mode Tata Letak

### Default — tombol persegi panjang

Tombol persegi panjang "START GEOPOINT" membuka modal peta penuh tempat enumerator memilih suatu titik. Setelah pengambilan, label tombol berubah menjadi "Lihat atau ubah titik geo" dan koordinat muncul di bawah.

Tidak diperlukan nilai appearance.

---

### `display{inline-icon}` — tombol bidik melingkar

Menampilkan tombol ikon melingkar (bidik ⊕) alih-alih tombol persegi panjang. Mengetuknya akan membuka modal peta yang sama.

```
display{inline-icon}
```

**Dikombinasikan dengan posisi dan ukuran:**

```
display{inline-icon, left}           → tombol di kiri label
display{inline-icon, top}            → tombol di atas label
display{inline-icon, bottom}         → tombol di bawah label, di tengah
display{inline-icon, large}          → ikon besar (75px)
display{inline-icon, medium}         → ikon sedang (50px)
display{inline-icon, left, large}    → tombol besar di kiri
```

| Ukuran | Tinggi/lebar ikon |
|--------|-------------------|
| *(default)* | 25px              |
| `medium` | 50px              |
| `large` | 75px              |

---

### `display{thumbnail-square}` — thumbnail peta langsung

Menampilkan pratinjau peta langsung (Leaflet) langsung pada pertanyaan alih-alih tombol. Thumbnail menunjukkan posisi GPS saat ini dan titik yang dipilih. Mengetuk tombol expand akan membuka modal penuh.

```
display{thumbnail-square}
```

**Ukuran thumbnail kustom:**

```
display{thumbnail-square-[WxH]}          → piksel tetap
display{thumbnail-square-[400x200]}      → lebar 400px × tinggi 200px

display{thumbnail-square-[W%xH%]}        → persentase lebar formulir
display{thumbnail-square-[100%x30%]}     → lebar penuh × 30% lebar formulir
```

---

## `display{}` vs `results{}` — sebelum dan sesudah pengambilan

`display{}` mengontrol tata letak **sebelum** pengguna mengambil lokasi. `results{}` mengontrol tata letak **setelah** nilai ada. Keduanya dapat memiliki penjajaran yang berbeda.

```
display{inline-icon, right} results{left}
```

Ini menampilkan tombol di kanan sebelum pengambilan, kemudian memindahkannya ke kiri setelah titik direkam.

### `hide(value)` — menekan tampilan koordinat

Secara default, teks lat/lon/akurasi/ketinggian yang diambil ditampilkan di bawah tombol. Sembunyikan dengan:

```
results{hide(value)}
display{inline-icon} results{hide(value)}
```

## `inputs{}` — Otomatisasi GPS

### Pengambilan otomatis saat memuat

Secara otomatis merekam posisi GPS saat formulir dimuat, tanpa enumerator menekan apa pun.

```
inputs{auto-take}
```

**Pengambilan otomatis kondisional** menggunakan ekspresi XLSForm:

```
inputs{autotakeGeo(expression(if(${capture_now} = 'yes', true(), false())))}
```

### Pra-isi dari kolom teks

Mengisi geopoint dari pertanyaan yang berisi nama tempat atau string alamat. rtSurvey melakukan geocoding terbalik string ke koordinat melalui OpenStreetMap Nominatim.

```
inputs{question(address_field)}
```

---

## `outputs{}` — geocoding terbalik ke teks

Setelah titik diambil, secara otomatis mengisi pertanyaan `text` dengan alamat yang dapat dibaca manusia (geocoding terbalik dari koordinat).

```
outputs{question(address_field)}
```

Contoh:

| type     | name     | label             | appearance                   |
|----------|----------|-------------------|------------------------------|
| geopoint | location | Rekam lokasi      | `outputs{question(address_text)}` |
| text     | address_text | Alamat            |                              |

---

## `nomap` — Pengambilan GPS tanpa peta

Mengganti modal peta dengan dialog sederhana yang meminta izin lokasi dan merekam koordinat. Tidak ada peta yang ditampilkan. Berguna untuk pengambilan khusus GPS pada perangkat kelas bawah atau ketika tile peta tidak tersedia secara offline.

```
nomap
```

## Gaya tombol kustom

Gunakan `styleButton()` untuk menerapkan CSS kustom ke tombol persegi panjang default:

```
styleButton({"backgroundColor":"#1976D2","color":"#ffffff","borderRadius":"8px"})
```

## Praktik Terbaik

1.  Gunakan `inputs{auto-take}` untuk survei verifikasi enumerator di mana GPS wajib — ini menghilangkan langkah manual.
2.  Gunakan `display{thumbnail-square}` ketika Anda ingin enumerator mengkonfirmasi secara visual titik yang dipilih sebelum melanjutkan.
3.  Pasangkan `outputs{question(...)}` dengan kolom `text` hanya-baca untuk menampilkan alamat yang di-geocoding terbalik kepada enumerator.
4.  Gunakan `nomap` di area tanpa konektivitas internet di mana tile peta tidak dapat dimuat.
5.  Biarkan GPS stabil sebelum merekam — akurasi di bawah 10m biasanya cukup untuk survei lapangan.

## Keterbatasan

-   Geocoding `inputs{question(name)}` memerlukan akses internet — ini memanggil OpenStreetMap Nominatim API.
-   Geocoding terbalik `outputs{question(name)}` juga memerlukan akses internet.
-   Thumbnail peta (`display{thumbnail-square}`) memerlukan internet untuk memuat tile; koordinat masih diambil secara offline.
-   Akurasi GPS bervariasi tergantung perangkat dan lingkungan — kondisi dalam ruangan atau jurang perkotaan dapat menghasilkan akurasi > 50m.
-   Mengumpulkan data lokasi dapat secara signifikan memengaruhi masa pakai baterai perangkat selama survei panjang.

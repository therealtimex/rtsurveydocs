title: "Geoshape"
description: "Pertanyaan Geoshape menangkap poligon tertutup yang ditentukan oleh urutan titik GPS."
---

Tipe pertanyaan `geoshape` menangkap poligon tertutup — serangkaian koordinat GPS di mana titik pertama dan terakhir adalah sama. Dalam formulir web rtSurvey, ini dirender sebagai **input teks** di mana enumerator memasukkan atau menempelkan string koordinat secara langsung.

## Spesifikasi Dasar XLSForm

| type     | name        | label                            |
|----------|-------------|----------------------------------|
| geoshape | field_area  | Gambar batas lapangan            |
| geoshape | zone        | Catat batas zona                 |

Untuk spesifikasi standar lihat [dokumentasi XLSForm](https://xlsform.org/en/#question-types).

---

## Format Data

Disimpan sebagai daftar titik yang dipisahkan titik koma dengan **tanpa spasi di sekitar titik koma**. Setiap titik terdiri dari empat nilai yang dipisahkan spasi:

```
lat lon alt acc;lat lon alt acc;lat lon alt acc;lat lon alt acc
```

| Component | Description |
|-----------|-------------|
| `lat` | Lintang dalam derajat desimal |
| `lon` | Bujur dalam derajat desimal |
| `alt` | Ketinggian dalam meter (`0` jika tidak diketahui) |
| `acc` | Akurasi GPS dalam meter (`0` jika tidak diketahui) |

**Poligon harus tertutup** — titik terakhir harus sama dengan titik pertama.

**Contoh — poligon empat titik (segitiga, tertutup):**
```
13.756331 100.501762 0 0;13.758000 100.503000 0 0;13.757000 100.506000 0 0;13.756331 100.501762 0 0
```

Minimal tiga titik berbeda ditambah pengulangan penutup diperlukan untuk membentuk poligon yang valid.

## Cara perenderaan di rtSurvey

Dalam formulir web rtSurvey, `geoshape` dirender sebagai **bidang teks** biasa. Enumerator mengetik atau menempelkan string koordinat. Tidak ada pemilih peta poligon interaktif bawaan untuk tipe ini dalam formulir web saat ini.

### Mengumpulkan titik poligon secara interaktif

Pola yang direkomendasikan untuk pengumpulan lapangan adalah **grup pengulangan (repeat group) dari pertanyaan `geopoint`** — setiap simpul menggunakan pemilih peta GPS lengkap — digabungkan dengan `calculate` untuk menghasilkan string geoshape:

| type | name | label | calculation |
|------|------|-------|-------------|
| begin repeat | polygon_points | Catat setiap sudut | |
| geopoint | point | Ketuk untuk mencatat sudut | |
| end repeat | polygon_points | | |
| calculate | geoshape_value | | `join(';', ${polygon_points/point})` |

Setelah digabungkan, tambahkan titik pertama secara manual untuk menutup poligon, atau gunakan calculate kedua untuk menggabungkannya.

## Contoh penggunaan

| type | name | label | hint | required |
|------|------|-------|------|----------|
| geoshape | farm_boundary | Catat batas lapangan | Masukkan semua sudut yang dipisahkan oleh titik koma. Titik pertama dan terakhir harus sama. | yes |

## Praktik Terbaik

1. Gunakan grup pengulangan dari pertanyaan `geopoint` untuk pengumpulan berbasis peta interaktif dan gabungkan nilainya — ini memberi enumerator pemilih GPS untuk setiap simpul.
2. Selalu tutup poligon (ulangi titik pertama di akhir) sebelum mengirimkan.
3. Sertakan format yang diharapkan di kolom `hint` saat entri koordinat manual diperlukan.
4. Syaratkan setidaknya 3 titik sudut yang berbeda untuk poligon yang valid — terapkan ini melalui instruksi daripada batasan XLSForm.
5. Gunakan `geopoint` untuk pertanyaan lokasi tunggal dan `geoshape` hanya jika demarkasi area adalah tujuan survei yang sebenarnya.

## Keterbatasan (Limitations)

- Tidak ada pemilih peta poligon interaktif bawaan untuk `geoshape` di formulir web rtSurvey.
- Poligon harus ditutup secara manual — tidak ada mekanisme penutupan otomatis dalam mode input teks.
- Memvalidasi topologi poligon (misalnya, tidak ada perpotongan sendiri, area minimum) memerlukan pemrosesan pasca di luar batasan XLSForm.
- Batas panjang dengan banyak simpul menghasilkan string teks yang besar.

Tipe pertanyaan `barcode` menangkap nilai kode dengan memindai QR code atau barcode dengan kamera perangkat. Modal pemindai juga menyertakan input teks manual sebagai cadangan ketika pemindaian tidak memungkinkan.

## Basic XLSForm Specification

| type    | name         | label                    |
|---------|--------------|--------------------------|
| barcode | product_code | Scan the product barcode |
| barcode | ticket_id    | Scan the ticket          |

Untuk spesifikasi standar lihat [dokumentasi XLSForm](https://xlsform.org/en/#question-types).

---

## Supported formats

rtSurvey mendukung QR codes dan barcode 1D standar melalui kamera perangkat, termasuk:

- QR Code
- UPC-A, UPC-E
- EAN-8, EAN-13
- Code 39, Code 128
- ITF, Codabar

---

## Default layout

Tanpa pengaturan `appearance`, pertanyaan merender tombol lebar penuh **"GET BARCODE"**. Mengetuknya akan membuka modal pemindai. Setelah pemindaian berhasil, tombol berubah menjadi **"REPLACE BARCODE"** dan nilai yang dipindai muncul di bawah sebagai tautan yang dapat diklik.

---

## Scanner modal

Modal pemindai selalu menyertakan:
- **Tampilan kamera langsung (Live camera view)** — memindai secara otomatis saat terdeteksi; modal tertutup setelah pemindaian berhasil.
- **Input teks manual (Manual text input)** — bidang teks di bagian bawah tempat enumerator dapat mengetik kode jika pemindaian gagal.
- **Tombol Selesai (Done button)** — mengirimkan nilai yang diketik secara manual.

Ketika kamera perangkat tidak tersedia, modal beralih ke opsi **"Upload an image"** — enumerator dapat mengirimkan foto barcode untuk didekode.

---

## Inline button layout

Tambahkan `inline` untuk merender pemindai sebagai **tombol ikon lingkaran** di samping label alih-alih tombol lebar penuh.

```
| type    | name | label     | appearance                              |
|---------|------|-----------|----------------------------------------|
| barcode | code | Scan item | inline display{right}                  |
| barcode | code | Scan item | inline display{left, large}            |
| barcode | code | Scan item | inline display{center, large, <0099FF/>} |
```

**Posisi tombol** — `left`, `right` *(default)*, `top`, `center`, `bottom`

**Ukuran tombol** — `small` *(default)*, `medium`, `large`

**Warna tombol** — tambahkan warna hex di dalam `display{}` untuk mengganti warna utama:

```
inline display{right, large, <FF5500/>}
```

**Kontrol pasca-penangkapan — `results{}`:**

| Appearance | Efek |
|---|---|
| `results{hide(scanner)}` | Menyembunyikan tombol pemindaian setelah nilai ditangkap |
| `results{hide(review)}` | Menyembunyikan tautan nilai yang dipindai setelah penangkapan |
| `results{hide(value)}` | Menyembunyikan tampilan teks nilai yang dipindai |
| `results{left}` | Memindahkan ikon ke kiri setelah penangkapan |

Contoh — sembunyikan pemindai setelah pemindaian pertama:
```
inline display{center, large} results{hide(scanner)}
```

---

## `inputs{auto-close(N)}` — tutup otomatis pemindai

Menutup modal pemindai secara otomatis setelah `N` detik jika tidak ada barcode yang terdeteksi. Pengatur waktu mundur langsung ditampilkan di dalam modal.

```
inputs{auto-close(10)}     → tertutup setelah 10 detik
inputs{auto-close(5)}      → tertutup setelah 5 detik
```

Gabungkan dengan inline:
```
inline display{right} inputs{auto-close(10)}
```

---

## `inputs{floating}` — pemindai mengambang yang dapat diseret

Menampilkan **tombol minimalkan** (ikon kompres ⊞) di header modal pemindai. Mengetuknya akan menciutkan pemindai menjadi ikon lingkaran mengambang kecil yang dapat diseret ke mana saja di layar. Mengetuk ikon mengambang akan membuka kembali pemindai.

```
inputs{floating}
inline display{right} inputs{floating}
```

Berguna dalam alur kerja di mana enumerator perlu melihat formulir saat pemindai aktif (misalnya, memindai item dalam daftar).

---

## `invisible auto-show` — buka otomatis pemindai

Menyembunyikan widget pertanyaan dari tata letak tetapi secara otomatis membuka pemindai saat halaman dimuat. Berguna untuk menyematkan langkah pemindaian senyap dalam alur formulir.

```
invisible auto-show
inline invisible auto-show
```

---

## Dalam grup repetisi (In repeat groups)

Ketika `barcode` berada di dalam grup `begin repeat`, pemindaian yang berhasil secara otomatis berlanjut ke **instansi repetisi berikutnya** setelah nilai dicatat. Ini memungkinkan pemindaian berurutan yang cepat tanpa enumerator mengetuk "Tambah" (Add) di antara item.

---

## Sembunyikan label (Suppress the label)

```
inline text-nolabel display{center, large}
```

## Praktik Terbaik

1. Gunakan `inputs{auto-close(N)}` untuk mencegah pemindai tetap terbuka tanpa batas waktu — pilih nilai yang memberi enumerator cukup waktu untuk memposisikan barcode (biasanya 8–15 detik).
2. Gunakan `inputs{floating}` saat formulir harus tetap terlihat selama pemindaian (misalnya, memindai dari daftar di mana enumerator melakukan referensi silang ke bidang yang terlihat).
3. Tempatkan pertanyaan barcode di dalam grup repetisi untuk pemindaian berurutan yang cepat — kemajuan repetisi otomatis menghilangkan langkah "Tambah" manual.
4. Selalu sertakan kolom `hint` dengan instruksi pemosisian (misalnya, "Pegang barcode dalam jarak 10–30 cm dari kamera, dalam cahaya yang baik").
5. Input teks manual di modal pemindai selalu tersedia — latih enumerator untuk menggunakannya sebagai cadangan untuk barcode yang rusak atau kotor.

## Batasan

- Akurasi pemindaian bergantung pada kualitas kamera, pencahayaan, dan kondisi barcode — kode yang rusak atau kontras rendah mungkin tidak terpindai dengan andal.
- Pemindai menggunakan kamera belakang (menghadap ke lingkungan); perangkat tanpa kamera belakang akan beralih ke opsi unggah gambar.
- `invisible auto-show` hanya terbuka pada pemuatan halaman pertama; menavigasi kembali ke halaman tidak memicu kembali pembukaan otomatis.

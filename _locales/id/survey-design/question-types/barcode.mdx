Tipe pertanyaan `barcode` menangkap nilai kode dengan memindai kode QR atau barcode dengan kamera perangkat. Modal pemindai juga menyertakan input teks manual sebagai cadangan ketika pemindaian tidak memungkinkan.

## Spesifikasi Dasar XLSForm

| type    | name         | label                          |
|---------|--------------|--------------------------------|
| barcode | product_code | Pindai barcode produk          |
| barcode | ticket_id    | Pindai tiket                   |

Untuk spesifikasi standar, lihat [dokumentasi XLSForm](https://xlsform.org/en/#question-types).

---

## Format yang didukung

rtSurvey mendukung kode QR dan barcode 1D standar melalui kamera perangkat, termasuk:

- Kode QR
- UPC-A, UPC-E
- EAN-8, EAN-13
- Kode 39, Kode 128
- ITF, Codabar

---

## Tata letak default

Tanpa `appearance` yang diatur, pertanyaan akan menampilkan tombol **"GET BARCODE"** selebar penuh. Mengetuknya akan membuka modal pemindai. Setelah pemindaian berhasil, tombol berubah menjadi **"REPLACE BARCODE"** dan nilai yang dipindai muncul di bawah sebagai tautan yang dapat diklik.

---

## Modal pemindai

Modal pemindai selalu menyertakan:
- **Tampilan kamera langsung** — memindai secara otomatis saat terdeteksi; modal akan menutup setelah pemindaian berhasil.
- **Input teks manual** — kolom teks di bagian bawah tempat enumerator dapat mengetik kode jika pemindaian gagal.
- **Tombol Selesai** — mengirimkan nilai yang diketik secara manual.

Ketika kamera perangkat tidak tersedia, modal akan kembali ke opsi **"Unggah gambar"** — enumerator dapat mengirimkan foto barcode untuk dekode.

---

## Tata letak tombol inline

Tambahkan `inline` untuk merender pemindai sebagai **tombol ikon melingkar** di sebelah label, bukan tombol selebar penuh.

```
| type    | name | label     | appearance                              |
|---------|------|-----------|----------------------------------------|
| barcode | code | Pindai item | inline display{right}                  |
| barcode | code | Pindai item | inline display{left, large}            |
| barcode | code | Pindai item | inline display{center, large, <0099FF/>} |
```

**Posisi tombol** — `left`, `right` *(default)*, `top`, `center`, `bottom`

**Ukuran tombol** — `small` *(default)*, `medium`, `large`

**Warna tombol** — tambahkan warna hex di dalam `display{}` untuk menimpa warna primer:

```
inline display{right, large, <FF5500/>}
```

**Kontrol pasca-rekaman — `results{}`:**

| Appearance | Efek                                  |
|------------|---------------------------------------|
| `results{hide(scanner)}` | Menyembunyikan tombol pindai setelah nilai ditangkap |
| `results{hide(review)}` | Menyembunyikan tautan nilai yang dipindai setelah penangkapan |
| `results{hide(value)}` | Menyembunyikan tampilan teks nilai yang dipindai |
| `results{left}` | Memindahkan ikon ke kiri setelah penangkapan |

Contoh — sembunyikan pemindai setelah pemindaian pertama:
```
inline display{center, large} results{hide(scanner)}
```

---

## `inputs{auto-close(N)}` — pemindai tutup otomatis

Secara otomatis menutup modal pemindai setelah `N` detik jika tidak ada barcode yang terdeteksi. Penghitung waktu mundur langsung ditampilkan di dalam modal.

```
inputs{auto-close(10)}     → menutup setelah 10 detik
inputs{auto-close(5)}      → menutup setelah 5 detik
```

Gabungkan dengan inline:
```
inline display{right} inputs{auto-close(10)}
```

---

## `inputs{floating}` — pemindai mengambang yang dapat diseret

Menampilkan **tombol minimize** (ikon kompres ⊞) di header modal pemindai. Mengetuknya akan menyusutkan pemindai menjadi ikon melingkar kecil yang mengambang dan dapat diseret ke mana saja di layar. Mengetuk ikon mengambang akan membuka kembali pemindai.

```
inputs{floating}
inline display{right} inputs{floating}
```

Berguna dalam alur kerja di mana enumerator perlu melihat formulir saat pemindai aktif (misalnya, memindai item dalam daftar).

---

## `invisible auto-show` — pemindai buka otomatis

Menyembunyikan widget pertanyaan dari tata letak tetapi secara otomatis membuka pemindai saat halaman dimuat. Berguna untuk menyematkan langkah pemindaian senyap dalam alur formulir.

```
invisible auto-show
inline invisible auto-show
```

---

## Dalam grup berulang

Ketika `barcode` berada di dalam grup `begin repeat`, pemindaian yang berhasil secara otomatis akan maju ke **instance pengulangan berikutnya** setelah nilai dicatat. Ini memungkinkan pemindaian berurutan yang cepat tanpa enumerator harus mengetuk "Tambah" di antara item.

---

## Menekan label

```
inline text-nolabel display{center, large}
```

## Praktik Terbaik

1.  Gunakan `inputs{auto-close(N)}` untuk mencegah pemindai tetap terbuka tanpa batas — pilih nilai yang memberi enumerator cukup waktu untuk memposisikan barcode (8–15 detik biasanya).
2.  Gunakan `inputs{floating}` ketika formulir perlu tetap terlihat saat memindai (misalnya, memindai dari daftar di mana enumerator merujuk silang bidang yang terlihat).
3.  Tempatkan pertanyaan barcode di dalam grup berulang untuk pemindaian berurutan yang cepat — kemajuan pengulangan otomatis menghilangkan langkah "Tambah" manual.
4.  Selalu sertakan kolom `hint` dengan instruksi pemosisian (misalnya, "Pegang barcode dalam jarak 10–30 cm dari kamera, dalam cahaya yang baik").
5.  Input teks manual di modal pemindai selalu tersedia — latih enumerator untuk menggunakannya sebagai cadangan untuk barcode yang rusak atau kotor.

## Keterbatasan

-   Akurasi pemindaian tergantung pada kualitas kamera, pencahayaan, dan kondisi barcode — kode yang rusak atau kontras rendah mungkin tidak dapat dipindai dengan andal.
-   Pemindai menggunakan kamera belakang (menghadap lingkungan); perangkat tanpa kamera belakang akan kembali ke opsi unggah gambar.
-   `invisible auto-show` hanya terbuka pada pemuatan halaman pertama; menavigasi kembali ke halaman tidak akan memicu kembali pembukaan otomatis.

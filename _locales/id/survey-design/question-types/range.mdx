Tipe pertanyaan `range` memungkinkan responden memilih angka dalam rentang minimum dan maksimum yang ditentukan. Dalam formulir web rtSurvey, ini dirender sebagai **input angka** standar — enumerator mengetikkan nilai secara langsung. Parameter `start`, `end`, dan `step` mendefinisikan rentang yang valid dan diberlakukan sebagai batasan.

## Spesifikasi XLSForm Dasar

| type | name | label | parameters |
|------|------|-------|------------|
| range | satisfaction | Seberapa puas Anda dengan layanan ini? | start=1 end=5 step=1 |

Kolom `parameters` mendefinisikan batas penggeser dan ukuran langkah:

| Parameter | Deskripsi | Default |
|-----------|-------------|---------|
| `start` | Nilai minimum (inklusif) | 0 |
| `end` | Nilai maksimum (inklusif) | 10 |
| `step` | Kenaikan antara nilai-nilai yang valid | 1 |

Untuk detail lebih lanjut tentang tipe pertanyaan `range` standar, lihat [spesifikasi XLSForm](https://xlsform.org/en/#question-types).

## Kegunaan

Pertanyaan `range` umumnya digunakan untuk:

1. Skala kepuasan atau penilaian (misalnya, 1–5 atau 0–10)
2. Skala numerik gaya Likert
3. Mengumpulkan pengukuran di mana hanya nilai diskrit yang valid
4. Kelompok usia atau rentang skor di mana penggeser meningkatkan kegunaan dibandingkan bidang teks

## Contoh Penggunaan

### Skala penilaian dasar

| type | name | label | parameters |
|------|------|-------|------------|
| range | overall_rating | Penilaian keseluruhan (0–10) | start=0 end=10 step=1 |

### Langkah desimal

| type | name | label | parameters |
|------|------|-------|------------|
| range | weight_kg | Berat (kg) | start=0 end=200 step=0.5 |

### Menggunakan nilai dalam perhitungan

| type | name | label | parameters | calculation |
|------|------|-------|------------|-------------|
| range | score | Skor tes (0–100) | start=0 end=100 step=5 | |
| calculate | grade | | | if(`${score}` >= 90, 'A', if(`${score}` >= 80, 'B', if(`${score}` >= 70, 'C', 'F'))) |
| note | grade_note | Nilai Anda adalah: `${grade}` | | |

## Praktik Terbaik

1. Selalu tetapkan nilai `start`, `end`, dan `step` yang bermakna — jangan mengandalkan nilai default.
2. Beri label ujung skala Anda di kolom `hint` (misalnya, `hint: 0 = Sangat tidak puas, 10 = Sangat puas`) untuk memberikan konteks kepada responden.
3. Untuk skala Likert 5 poin, gunakan `start=1 end=5 step=1` daripada 0–4, karena responden mengharapkan "1" berarti yang terendah.
4. Gunakan `range` alih-alih `integer` + batasan saat sifat terikat input adalah bagian dari desain pertanyaan (penggeser mengkomunikasikan skala secara visual).

## Batasan

- Tidak ada widget penggeser di formulir web rtSurvey — entri nilai adalah input angka biasa. Untuk pengalaman penggeser visual, gunakan klien seluler yang mendukung widget `range`.
- Untuk rentang yang sangat lebar (misalnya, 0–10000), `integer` biasa dengan batasan sama efektifnya dan lebih ramah pengguna.
- Nilai langkah yang halus (misalnya, `step=0.1`) berfungsi sebagai batasan tetapi tidak memiliki masalah presisi penggeser di formulir web.

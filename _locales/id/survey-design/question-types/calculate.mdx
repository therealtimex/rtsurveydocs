Tipe pertanyaan `calculate` menjalankan rumus secara diam-diam di latar belakang. Ini menyimpan hasilnya dalam bidang bernama yang dapat dirujuk oleh pertanyaan lain — tetapi tidak menampilkan input atau label kepada enumerator. Gunakan ini untuk menurunkan nilai, menggabungkan string, menjalankan logika kondisional, atau mencari data yang Anda butuhkan nanti dalam formulir.

---

## Sintaks dasar

| type | name | label | calculation |
|------|------|-------|-------------|
| calculate | total | | `${price} * ${quantity}` |

- **type**: Selalu `calculate`.
- **name**: Nama bidang yang unik. Pertanyaan lain merujuk ini dengan `${name}`.
- **label**: Kosongkan — bidang calculate tidak pernah ditampilkan kepada enumerator.
- **calculation**: Rumus yang akan dievaluasi. Mendukung semua [fungsi XLSForm](../operators-and-functions/functions) dan referensi bidang.

---

## Pola umum

### Aritmatika

| type | name | label | calculation |
|------|------|-------|-------------|
| integer | price | Unit price | |
| integer | quantity | Quantity | |
| calculate | total | | `${price} * ${quantity}` |
| note | total_note | Total: `${total}` | |

### Penggabungan string (String concatenation)

| type | name | label | calculation |
|------|------|-------|-------------|
| text | first_name | First name | |
| text | last_name | Last name | |
| calculate | full_name | | `concat(${first_name}, ' ', ${last_name})` |

### Nilai kondisional

| type | name | label | calculation |
|------|------|-------|-------------|
| integer | score | Score (0–100) | |
| calculate | grade | | `if(${score} >= 90, 'A', if(${score} >= 75, 'B', if(${score} >= 60, 'C', 'F')))` |

### Usia dari tanggal lahir

| type | name | label | calculation |
|------|------|-------|-------------|
| date | dob | Date of birth | |
| calculate | age_years | | `int((today() - ${dob}) div 365.25)` |

## Menggunakan `once()` untuk mengunci nilai

Secara default, `calculate` mengevaluasi kembali setiap kali ada bidang yang dirujuk berubah. Bungkus rumus dalam `once()` untuk mengevaluasi hanya pada pemuatan pertama dan membekukan hasilnya:

| type | name | label | calculation |
|------|------|-------|-------------|
| calculate | interview_start | | `once(now())` |

Gunakan `once()` untuk stempel waktu, nilai awal, atau kasus apa pun di mana perhitungan ulang saat terjadi perubahan tidak diinginkan.

## Menarik data dari sumber eksternal

### Dari file CSV

```
pulldata('staff.csv', 'department', 'name', ${staff_id})
```

Lihat [pulldata()](../operators-and-functions/pulldata) untuk referensi lengkap.

### Dari database SQLite yang dibundel

```
pulldata('rawquery',
  concat(${family_path}, '/locations.db::provinces'),
  'SELECT name FROM provinces WHERE id = ?',
  ${province_id})
```

Lihat [Pencarian Database Lokal](../advanced-features/local-database-search) untuk detail konstruksi jalur.

### Dari konteks aplikasi

```
pulldata('app-api', 'user.username')
pulldata('app-api', 'family_path')
```

Lihat [App API](../app-api) untuk semua kunci yang tersedia.

## Menggunakan calculate dalam relevant dan constraint

Bidang lain dapat merujuk hasil `calculate` seperti bidang apa pun:

| type | name | label | relevant | constraint |
|------|------|-------|----------|------------|
| calculate | bmi | | | `${weight} div (${height} * ${height}) * 10000` |
| note | bmi_warning | BMI is very high — please verify weight and height. | `${bmi} > 40` | |

## Praktik Terbaik

1. Berikan nama yang bermakna pada bidang calculate — `total_cost` lebih jelas daripada `calc1` dan lebih mudah dilacak dalam ekspor.
2. Pecah rumus yang kompleks menjadi beberapa bidang calculate yang dirantai daripada satu ekspresi yang bersarang dalam.
3. Gunakan `once()` untuk stempel waktu dan snapshot awal untuk mencegah nilai berubah setelah pengambilan pertama.
4. Tempatkan bidang `calculate` sebelum pertanyaan pertama yang merujuknya — urutan evaluasi mengikuti urutan formulir.
5. Biarkan kolom `label` kosong. Beberapa alat menampilkan label; membiarkannya kosong menghindari output yang membingungkan.

## Batasan

- Bidang Calculate tidak pernah ditampilkan secara langsung kepada enumerator — gunakan bidang `note` untuk menunjukkan hasilnya.
- Kolom `calculation` wajib diisi; baris `calculate` tanpa rumus selalu menyimpan string kosong.
- Hasil dievaluasi kembali pada setiap perubahan formulir kecuali jika dibungkus dalam `once()` — rumus yang sangat kompleks dalam formulir besar dapat memengaruhi kinerja rendering pada perangkat kelas bawah.
- Nilai yang dihitung disimpan sebagai string dalam pengiriman. Gunakan `number()`, `int()`, atau `boolean()` untuk melakukan pemeranan tipe saat meneruskan hasil ke ekspresi aritmatika atau logika.

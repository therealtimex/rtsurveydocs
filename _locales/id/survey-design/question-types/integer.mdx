---

Tipe pertanyaan `integer` mengumpulkan bilangan bulat (tanpa tempat desimal). Ini memicu keyboard numerik di ponsel dan memblokir entri titik desimal. Ini mendukung opsi penampilan yang sama dengan tipe `text` untuk tata letak dan pemformatan.

## Spesifikasi Dasar XLSForm

| type | name | label |
|------|------|-------|
| integer | age | Usia responden |
| integer | household_size | Jumlah orang dalam rumah tangga |

Untuk spesifikasi standar, lihat [dokumentasi XLSForm](https://xlsform.org/en/#question-types).

---

## Opsi Penampilan

### `number-hspinner` — pemutar horizontal

Mengganti input dengan pemutar horizontal **− nilai +**. Mengetuk minus/plus mengurangi atau menambah nilai sebesar 1 (atau langkah kustom).

```
number-hspinner
```

**Kustomisasi bentuk dan langkah tombol** menggunakan `hspinner()`:

```
number-hspinner hspinner('left-small-square','right-small-square','5')
```

Parameter: bentuk tombol kiri, bentuk tombol kanan, nilai langkah (default `1` untuk bilangan bulat).

**Warna kustom** menggunakan `colors()`:

```
number-hspinner colors(0099FF,FFFFFF,FF5500,FFFFFF)
```

Empat nilai secara berurutan: latar belakang tombol kiri, ikon tombol kiri, latar belakang tombol kanan, ikon tombol kanan.

---

### `thousandsep` — pemisah ribuan

Memformat angka yang ditampilkan dengan pengelompokan koma (misalnya `1,234,567`). Angka mentah disimpan tanpa koma. Tipe input dialihkan ke `"text"` untuk memungkinkan tampilan yang diformat.

```
thousandsep
```

---

### `digisep(n, "sep")` — pengelompokan digit kustom

Mengelompokkan digit menjadi blok `n` yang dipisahkan oleh pemisah kustom. Berguna untuk ID yang diformat atau kode referensi yang bersifat numerik.

```
digisep(4,"-")      → 0912-3456-789
digisep(3," ")      → 012 345 678
```

Tipe input dialihkan ke `"text"` saat penampilan ini aktif.

---

### `textonly` — paksa keyboard teks

Memaksa `type="text"` pada elemen input. Ini mencegah kekhasan input angka browser (seperti menyembunyikan angka nol di depan atau menambahkan panah putar di browser desktop) sambil tetap mengumpulkan nilai numerik.

```
textonly
```

---

### `floating_hint` — petunjuk mengambang sebagai label

Teks `hint` dirender di dalam input sebagai placeholder. Ketika pengguna mulai mengetik, teks itu akan mengambang di atas bidang sebagai label.

```
floating_hint
```

---

### `embed` — petunjuk di dalam batas input

Mirip dengan `floating_hint` — petunjuk berada di dalam batas input saat kosong. Tidak mengambang saat pengguna mengetik.

```
embed
```

---

### `textpopup` — input dialog modal

Mengetuk bidang akan membuka dialog modal dengan input yang lebih besar, bukan mengedit secara sebaris. Berguna di layar kecil di mana input layar penuh lebih mudah.

```
textpopup
```

---

### `charcount` — penghitung karakter langsung

Menampilkan hitungan karakter `(n)` langsung di bawah input, diperbarui saat pengguna mengetik.

```
charcount
```

---

### `prefix(expr)` — tambahkan awalan

Menambahkan string statis atau terhitung ke nilai yang ditampilkan. Nilai yang disimpan tidak menyertakan awalan.

```
prefix('Item #')        → menampilkan "Item #42", menyimpan "42"
prefix(${code_prefix})  → awalan dinamis dari bidang lain
```

---

### `align_answer` — perataan teks input

Mengontrol perataan horizontal nilai yang diketik di dalam input.

```
align_answer = left
align_answer = right
align_answer = center
```

---

### `inputs{qrscan}` — pemindaian QR / barcode ke bidang

Menambahkan tombol pemindaian kode QR di samping input. Membuka pemindai kamera dan mengisi bidang dengan nilai numerik yang dipindai.

```
inputs{qrscan}
```

## Referensi cepat penampilan

| Penampilan | Widget yang Dirender |
|---|---|
| *(tidak ada)* | Input angka (`type="number"`) — keyboard numerik di ponsel |

| `number-hspinner hspinner(...)` | Pemutar dengan bentuk dan langkah tombol kustom |
| `number-hspinner colors(...)` | Pemutar dengan warna tombol kustom |

| `digisep(n,"sep")` | Pengelompokan digit kustom |

## Batasan dan Validasi

Gunakan batasan untuk menegakkan rentang nilai. Batasan di kolom `constraint` dievaluasi setelah setiap penekanan tombol dalam mode `number-hspinner`, bukan hanya saat blur.

| type | name | label | constraint | constraint_message |
|------|------|-------|------------|-------------------|
| integer | age | Usia | `. > 0 and . <= 120` | Usia harus antara 1 dan 120 |
| integer | year | Tahun | `. >= 1800 and . <= 2100` | Masukkan tahun yang valid |
| integer | count | Jumlah item | `. >= 0` | Tidak boleh negatif |

---

## Contoh — Survei Rumah Tangga

| type | name | label | appearance | constraint | constraint_message |
|------|------|-------|------------|------------|-------------------|
| integer | household_size | Jumlah orang dalam rumah tangga | `number-hspinner` | `. >= 1 and . <= 30` | Harus antara 1 dan 30 |
| integer | under_5 | Anak di bawah 5 tahun | `number-hspinner` | `. >= 0 and . <= ${household_size}` | Tidak boleh melebihi ukuran rumah tangga |
| integer | year_built | Tahun rumah dibangun | `textonly` | `. >= 1800 and . <= 2100` | Masukkan tahun yang valid |

## Praktik Terbaik

1. Gunakan `number-hspinner` untuk hitungan rentang kecil di mana mengklik ± lebih cepat daripada mengetik (misalnya jumlah anak, skor pada skala 1–10).
2. Gunakan `thousandsep` saat menampilkan bilangan bulat besar (populasi, pendapatan) agar responden dapat memeriksa sendiri besarnya.
3. Gunakan `textonly` saat browser menambahkan UI input angka yang tidak diinginkan (panah putar, gulir sentuh) yang membingungkan responden.
4. Terapkan batasan rentang daripada mengandalkan jenis keyboard seluler — penegakan keyboard tidak universal.

## Keterbatasan

- Input titik desimal diblokir — jika Anda membutuhkan nilai pecahan, gunakan tipe `decimal`.
- `number-hspinner` memvalidasi `constraint` pada setiap penekanan tombol — hindari batasan yang mahal (misalnya rantai `if()` yang kompleks) dalam mode pemutar.
- `thousandsep` dan `digisep()` menyimpan angka mentah tanpa pemformatan — jangan mengandalkan nilai tampilan yang diformat dalam perhitungan.

---
title: "Geotrace"
description: "Pertanyaan Geotrace menangkap serangkaian titik GPS yang membentuk garis atau jalur."
---

Jenis pertanyaan `geotrace` menangkap urutan koordinat geografis yang membentuk garis atau jalur (polyline). Dalam formulir web rtSurvey, ini dirender sebagai **input teks** di mana enumerator memasukkan atau menempelkan string koordinat secara langsung.

## Spesifikasi Dasar XLSForm

| type     | name        | label                        |
|----------|-------------|------------------------------|
| geotrace | river_path  | Telusuri jalur sungai |
| geotrace | road_route  | Rekam rute jalan |

Untuk spesifikasi standar, lihat [dokumentasi XLSForm](https://xlsform.org/en/#question-types).

---

## Format Data (Data Format)

Disimpan sebagai daftar titik yang dipisahkan titik koma dengan **tanpa spasi di sekitar titik koma**. Setiap titik adalah empat nilai yang dipisahkan spasi:

```
lat lon alt acc;lat lon alt acc;lat lon alt acc
```

| Component | Description |
|-----------|-------------|
| `lat` | Lintang dalam derajat desimal |
| `lon` | Bujur dalam derajat desimal |
| `alt` | Ketinggian dalam meter (`0` jika tidak diketahui) |
| `acc` | Akurasi GPS dalam meter (`0` jika tidak diketahui) |

**Contoh — jalur tiga titik:**
```
13.756331 100.501762 15 8;13.758000 100.503000 14 6;13.760000 100.505000 13 5
```

Minimal dua titik diperlukan untuk membentuk jalur yang valid.

## Cara kerjanya di rtSurvey

Dalam formulir web rtSurvey, `geotrace` dirender sebagai **bidang teks** biasa. Enumerator mengetik atau menempelkan string koordinat. Tidak ada pemilih peta interaktif bawaan untuk jenis ini dalam formulir web saat ini.

### Mengumpulkan titik secara interaktif

Pola yang direkomendasikan untuk pengumpulan lapangan adalah **grup pengulangan (repeat group) dari pertanyaan `geopoint`** — setiap titik menggunakan pemilih peta GPS lengkap — dikombinasikan dengan `calculate` untuk menghasilkan string geotrace:

| type | name | label | calculation |
|------|------|-------|-------------|
| begin repeat | path_points | Rekam setiap titik jalan (waypoint) | |
| geopoint | point | Ketuk untuk merekam titik | |
| end repeat | path_points | | |
| calculate | geotrace_value | | `join(';', ${path_points/point})` |

String yang dihitung kemudian dapat disimpan dalam pertanyaan `text` atau digunakan dalam `geotrace`.

## Contoh penggunaan

| type | name | label | hint | required |
|------|------|-------|------|----------|
| geotrace | farm_boundary_path | Rekam jalur akses ke peternakan | Masukkan setiap titik jalan yang dipisahkan oleh titik koma | yes |

---

## Praktik Terbaik

1. Gunakan grup pengulangan pertanyaan `geopoint` untuk pengumpulan berbasis peta interaktif, lalu gabungkan nilainya — ini memberi enumerator pemilih GPS untuk setiap titik individu.
2. Sertakan format yang diharapkan dalam kolom `hint` saat input koordinat manual diperlukan.
3. Validasi keberadaan dengan `required = yes` saat jalur bersifat wajib.
4. Rencanakan pembersihan data — jalur yang dimasukkan secara manual mungkin memiliki presisi yang tidak konsisten.

## Batasan (Limitations)

- Tidak ada pemilih peta interaktif bawaan untuk `geotrace` di formulir web rtSurvey.
- String koordinat bisa panjang untuk jalur yang kompleks — ingatlah ini untuk kinerja dan penyimpanan formulir.
- Memvalidasi topologi jalur (misalnya, jumlah titik minimum, perpotongan sendiri) memerlukan pemrosesan pasca di luar batasan XLSForm.

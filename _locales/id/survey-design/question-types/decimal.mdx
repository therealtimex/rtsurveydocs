Tipe pertanyaan `decimal` mengumpulkan angka yang mungkin menyertakan bagian pecahan (misalnya `3.14`, `72.5`). Ini memicu keyboard numerik pada ponsel dan mendukung opsi tampilan (appearance) yang sama dengan tipe `text` untuk tata letak dan pemformatan.

## Spesifikasi Dasar XLSForm

| type | name | label |
|------|------|-------|
| decimal | weight_kg | Berat (kg) |
| decimal | height_m | Tinggi (m) |
| decimal | temperature | Suhu tubuh (°C) |

Untuk spesifikasi standar lihat [dokumentasi XLSForm](https://xlsform.org/en/#question-types).

---

## Opsi tampilan (Appearance options)

### `number-hspinner` — pemutar horizontal

Mengganti input dengan pemutar horizontal **− nilai +**. Mengetuk minus/plus menyesuaikan nilai berdasarkan langkah (step) yang dikonfigurasi.

```
number-hspinner
```

Nilai yang ditampilkan diformat dengan satu tempat desimal (misalnya `3.0`, `72.5`). Langkah default adalah `1`; gunakan `hspinner()` untuk menyetel langkah desimal.

**Sesuaikan bentuk tombol dan langkah** menggunakan `hspinner()`:

```
number-hspinner hspinner('left-small-square','right-small-square','0.1')
```

Parameter: bentuk tombol kiri, bentuk tombol kanan, nilai langkah. Gunakan langkah desimal seperti `0.5` atau `0.1` untuk kontrol yang lebih halus.

**Warna kustom** menggunakan `colors()`:

```
number-hspinner colors(0099FF,FFFFFF,FF5500,FFFFFF)
```

Empat nilai secara berurutan: latar belakang tombol kiri, ikon tombol kiri, latar belakang tombol kanan, ikon tombol kanan.

---

### `thousandsep` — pemisah ribuan

Memformat angka yang ditampilkan dengan pengelompokan koma (misalnya `1,234.56`). Angka mentah disimpan tanpa koma. Tipe input dialihkan ke `"text"` untuk memungkinkan tampilan yang diformat.

```
thousandsep
```

---

### `digisep(n, "sep")` — pengelompokan digit kustom

Mengelompokkan digit bagian integer ke dalam blok `n` yang dipisahkan oleh pemisah kustom.

```
digisep(3," ")      → 1 234 567.89
```

Tipe input dialihkan ke `"text"` saat tampilan ini aktif.

---

### `textonly` — paksa keyboard teks

Memaksa `type="text"` pada elemen input. Mencegah keanehan input angka browser (menyembunyikan angka nol di belakang, panah putar desktop) sambil tetap menerima nilai desimal.

```
textonly
```

---

### `floating_hint` — petunjuk melayang sebagai label

Teks `hint` merender di dalam input sebagai placeholder. Saat pengguna mulai mengetik, teks tersebut melayang di atas bidang sebagai label.

```
floating_hint
```

---

### `embed` — petunjuk di dalam batas input

Mirip dengan `floating_hint` — petunjuk berada di dalam batas input saat kosong. Petunjuk tidak melayang saat pengguna mengetik.

```
embed
```

---

### `textpopup` — input dialog modal

Mengetuk bidang akan membuka dialog modal dengan input yang lebih besar. Berguna pada layar kecil.

```
textpopup
```

---

### `charcount` — penghitung karakter langsung

Menampilkan penghitung karakter `(n)` langsung di bawah input, diperbarui saat pengguna mengetik.

```
charcount
```

---

### `prefix(expr)` — tambahkan awalan

Menambahkan string statis atau terhitung ke nilai yang ditampilkan. Nilai yang disimpan tidak termasuk awalan.

```
prefix('USD ')          → menampilkan "USD 72.50", menyimpan "72.50"
prefix(${currency})     → awalan dinamis dari bidang lain
```

---

### `align_answer` — perataan teks input

Mengontrol perataan horizontal nilai yang diketik di dalam input.

```
align_answer = left
align_answer = right
align_answer = center
```

---

### `inputs{qrscan}` — pemindaian QR / kode batang ke dalam bidang

Menambahkan tombol pemindaian kode QR di sebelah input. Membuka pemindai kamera dan mengisi bidang dengan nilai yang dipindai.

```
inputs{qrscan}
```

## Batasan dan validasi (Constraints and validation)

| type | name | label | constraint | constraint_message |
|------|------|-------|------------|-------------------|
| decimal | weight | Berat (kg) | `. > 0 and . <= 500` | Masukkan nilai antara 0 dan 500 |
| decimal | height | Tinggi (m) | `. > 0 and . <= 3` | Masukkan nilai antara 0 dan 3 |
| decimal | temp | Suhu (°C) | `. >= 35 and . <= 42` | Suhu normal: 35°C–42°C |
| decimal | percentage | Persentase | `. >= 0 and . <= 100` | Masukkan nilai antara 0 dan 100 |

## Contoh — formulir pengukuran

| type | name | label | appearance | constraint | constraint_message |
|------|------|-------|------------|------------|-------------------|
| decimal | weight_kg | Berat (kg) | `number-hspinner hspinner('left-small-square','right-small-square','0.5')` | `. > 0 and . <= 300` | Masukkan berat yang valid |
| decimal | height_m | Tinggi (m) | `number-hspinner hspinner('left-small-square','right-small-square','0.01')` | `. > 0 and . <= 3` | Masukkan tinggi yang valid |
| calculate | bmi | | | | |

Kolom perhitungan BMI:
```
${weight_kg} div (${height_m} * ${height_m})
```

## Praktik Terbaik

1. Gunakan `number-hspinner hspinner(..., '0.1')` untuk pengukuran yang memerlukan presisi satu desimal — pemutar memformat secara otomatis ke satu tempat desimal, menjaga nilai tetap konsisten.
2. Gunakan `textonly` saat browser menambahkan kontrol putar yang tidak diinginkan atau memotong angka nol di belakang (misalnya `3.0` ditampilkan sebagai `3`).
3. Gunakan `thousandsep` untuk nilai keuangan yang besar sehingga responden dapat memverifikasi bahwa mereka memasukkan besaran yang benar.
4. Terapkan batasan rentang daripada hanya mengandalkan tipe keyboard ponsel saja.

## Keterbatasan (Limitations)

- Pemutar selalu menampilkan satu tempat desimal — jika Anda memerlukan presisi lebih pada nilai yang ditampilkan, gunakan input biasa saja.
- `thousandsep` dan `digisep()` menyimpan angka mentah — jangan membaca nilai tampilan yang diformat dalam perhitungan.

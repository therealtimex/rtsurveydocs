Tipe pertanyaan `decimal` mengumpulkan angka yang mungkin menyertakan bagian pecahan (misalnya `3.14`, `72.5`). Ini memicu keyboard numerik di perangkat seluler dan mendukung opsi `appearance` yang sama dengan tipe `text` untuk tata letak dan pemformatan.

## Spesifikasi Dasar XLSForm

| type    | name        | label                   |
|---------|-------------|-------------------------|
| decimal | weight_kg   | Berat (kg)              |
| decimal | height_m    | Tinggi (m)              |
| decimal | temperature | Suhu tubuh (°C)         |

Untuk spesifikasi standar, lihat [dokumentasi XLSForm](https://xlsform.org/en/#question-types).

---

## Opsi appearance

### `number-hspinner` — pemutar horizontal

Menggantikan input dengan pemutar horizontal **− nilai +**. Mengetuk minus/plus menyesuaikan nilai dengan langkah yang dikonfigurasi.

```
number-hspinner
```

Nilai yang ditampilkan diformat dengan satu tempat desimal (misalnya `3.0`, `72.5`). Langkah default adalah `1`; gunakan `hspinner()` untuk mengatur langkah desimal.

**Sesuaikan bentuk tombol dan langkah** menggunakan `hspinner()`:

```
number-hspinner hspinner('left-small-square','right-small-square','0.1')
```

Parameter: bentuk tombol kiri, bentuk tombol kanan, nilai langkah. Gunakan langkah desimal seperti `0.5` atau `0.1` untuk kontrol yang lebih halus.

**Warna kustom** menggunakan `colors()`:

```
number-hspinner colors(0099FF,FFFFFF,FF5500,FFFFFF)
```

Empat nilai secara berurutan: latar belakang tombol kiri, ikon tombol kiri, latar belakang tombol kanan, ikon tombol kanan.

---

### `thousandsep` — pemisah ribuan

Memformat angka yang ditampilkan dengan pengelompokan koma (misalnya `1,234.56`). Angka mentah disimpan tanpa koma. Tipe input diubah menjadi `"text"` untuk memungkinkan tampilan yang diformat.

```
thousandsep
```

---

### `digisep(n, "sep")` — pengelompokan digit kustom

Mengelompokkan digit bagian integer menjadi blok `n` yang dipisahkan oleh pemisah kustom.

```
digisep(3," ")      → 1 234 567.89
```

Tipe input diubah menjadi `"text"` ketika appearance ini aktif.

---

### `textonly` — paksa keyboard teks

Memaksa `type="text"` pada elemen input. Mencegah keanehan input angka browser (menyembunyikan angka nol di belakang, panah putar desktop) sambil tetap menerima nilai desimal.

```
textonly
```

---

### `floating_hint` — petunjuk mengambang sebagai label

Teks `hint` dirender di dalam input sebagai placeholder. Saat pengguna mulai mengetik, teks tersebut mengambang di atas kolom sebagai label.

```
floating_hint
```

---

### `embed` — petunjuk di dalam batas input

Mirip dengan `floating_hint` — petunjuk berada di dalam batas input saat kosong. Petunjuk tidak mengambang saat pengguna mengetik.

```
embed
```

---

### `textpopup` — input dialog modal

Mengetuk kolom akan membuka dialog modal dengan input yang lebih besar. Berguna di layar kecil.

```
textpopup
```

---

### `charcount` — penghitung karakter langsung

Menampilkan penghitung karakter `(n)` langsung di bawah input, diperbarui saat pengguna mengetik.

```
charcount
```

---

### `prefix(expr)` — tambahkan awalan

Menambahkan string statis atau terhitung ke nilai yang ditampilkan. Nilai yang disimpan tidak menyertakan awalan.

```
prefix('USD ')          → menampilkan "USD 72.50", menyimpan "72.50"
prefix(${currency})     → awalan dinamis dari kolom lain
```

---

### `align_answer` — penjajaran teks input

Mengontrol penjajaran horizontal nilai yang diketik di dalam input.

```
align_answer = left
align_answer = right
align_answer = center
```

---

### `inputs{qrscan}` — pemindaian QR / barcode ke kolom

Menambahkan tombol pindai kode QR di sebelah input. Membuka pemindai kamera dan mengisi kolom dengan nilai yang dipindai.

```
inputs{qrscan}
```

## Referensi cepat appearance

| Appearance                        | Widget yang dirender                               |
|-----------------------------------|----------------------------------------------------|

| `floating_hint`                   | Petunjuk mengambang di atas kolom saat mengetik      |

| `charcount`                       | Penghitung karakter langsung di bawah input        |

## Batasan dan validasi

| type    | name       | label                     | constraint               | constraint_message             |
|---------|------------|---------------------------|--------------------------|--------------------------------|
| decimal | weight     | Berat (kg)                | `. > 0 and . <= 500`     | Masukkan nilai antara 0 dan 500 |
| decimal | height     | Tinggi (m)                | `. > 0 and . <= 3`       | Masukkan nilai antara 0 dan 3 |
| decimal | temp       | Suhu (°C)                 | `. >= 35 and . <= 42`    | Suhu normal: 35°C–42°C        |
| decimal | percentage | Persentase                | `. >= 0 and . <= 100`    | Masukkan nilai antara 0 dan 100 |

## Contoh — formulir pengukuran

| type    | name        | label               | appearance                                              | constraint             | constraint_message       |
|---------|-------------|---------------------|---------------------------------------------------------|------------------------|--------------------------|
| decimal | weight_kg   | Berat (kg)          | `number-hspinner hspinner('left-small-square','right-small-square','0.5')` | `. > 0 and . <= 300`   | Masukkan berat yang valid |
| decimal | height_m    | Tinggi (m)          | `number-hspinner hspinner('left-small-square','right-small-square','0.01')` | `. > 0 and . <= 3`     | Masukkan tinggi yang valid |

Kolom perhitungan BMI:
```
${weight_kg} div (${height_m} * ${height_m})
```

## Praktik Terbaik

1.  Gunakan `number-hspinner hspinner(..., '0.1')` untuk pengukuran yang memerlukan satu desimal presisi — pemutar secara otomatis memformat ke satu tempat desimal, menjaga nilai tetap konsisten.
2.  Gunakan `textonly` ketika browser menambahkan kontrol putar yang tidak diinginkan atau memotong angka nol di belakang (misalnya `3.0` ditampilkan sebagai `3`).
3.  Gunakan `thousandsep` untuk nilai keuangan yang besar agar responden dapat memverifikasi bahwa mereka memasukkan besaran yang benar.
4.  Terapkan batasan rentang daripada hanya mengandalkan jenis keyboard seluler.

## Keterbatasan

-   Pemutar selalu menampilkan satu tempat desimal — jika Anda memerlukan presisi lebih dalam nilai yang ditampilkan, gunakan input biasa sebagai gantinya.
-   `thousandsep` dan `digisep()` menyimpan angka mentah — jangan membaca nilai tampilan yang diformat dalam perhitungan.

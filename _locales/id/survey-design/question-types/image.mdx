Jenis pertanyaan `image` (gambar) di XLSForm dan rtSurvey memungkinkan responden untuk mengambil dan mengirimkan foto sebagai bagian dari tanggapan survei mereka. Fitur ini sangat berguna untuk mengumpulkan data visual, mendokumentasikan observasi, atau memberikan bukti dalam survei lapangan.

## Spesifikasi XLSForm Dasar

| type  | name        | label                           |
|-------|-------------|--------------------------------|
| image | photo       | Ambil foto lokasi               |

Untuk detail lebih lanjut tentang jenis pertanyaan `image` dasar, lihat [spesifikasi XLSForm](https://xlsform.org/en/#question-types).

## Kegunaan

Pertanyaan gambar umumnya digunakan untuk:

1. Mendokumentasikan kondisi atau observasi lapangan
2. Mengumpulkan bukti visual dalam studi penelitian
3. Mengambil foto sebelum dan sesudah dalam penilaian dampak
4. Memverifikasi penyelesaian tugas atau kehadiran di lokasi
5. Mengumpulkan data visual untuk analisis jarak jauh

## Praktik Terbaik

1. Berikan instruksi yang jelas tentang apa yang harus difoto.
2. Pertimbangkan implikasi privasi dan informasikan responden tentang bagaimana foto mereka akan digunakan.
3. Perhatikan ukuran file dan batasan penyimpanan, terutama untuk survei di area dengan konektivitas internet terbatas.
4. Pastikan perangkat memiliki ruang penyimpanan yang cukup dan izin kamera diberikan.

## Contoh Penggunaan

Berikut adalah contoh bagaimana Anda dapat menggunakan pertanyaan gambar dalam survei:

| type  | name           | label                                      | hint                                        |
|-------|----------------|--------------------------------------------|--------------------------------------------|
| image | storefront     | Ambil foto pintu masuk toko                 | Pastikan nama toko terlihat jelas         |

## Ekstensi rtSurvey

### Tata letak tombol sebaris

Tambahkan `inline` ke kolom `appearance` untuk merender kamera sebagai **tombol ikon melingkar** di samping label, bukan area tangkap lebar penuh. Mengetuknya akan membuka modal.

```
| type  | name  | label        | appearance                          |
|-------|-------|--------------|-------------------------------------|
| image | photo | Ambil foto | inline display{right}               |
| image | photo | Ambil foto | inline display{center, large}       |
```

**Posisi tombol — `display{}`:**

| Nilai | Tata Letak |
|-------|------------|
| `right` *(default)* | Ikon di kanan label |
| `left` | Ikon di kiri label |
| `top` | Ikon di atas label, di tengah |
| `center` / `bottom` | Ikon di bawah label, di tengah |

**Ukuran tombol:**

| Nilai | Ukuran |
|-------|--------|
| `small` *(default)* | Lingkaran kecil |
| `medium` | Lingkaran sedang |
| `large` | Lingkaran besar |

**Warna tombol** — tambahkan warna hex di dalam `display{}` untuk menimpa warna primer:

```
inline display{right, large, <FF5500/>}
inline display{center, medium, <0099FF/>}
```

**Kontrol pasca-pengambilan — `results{}`:**

| Appearance | Efek |
|---|---|
| `results{hide(capture)}` | Menyembunyikan tombol kamera setelah foto diambil |
| `results{hide(camera)}` | Sama dengan `hide(capture)` — alias untuk jenis gambar |
| `results{hide(review)}` | Menyembunyikan pratinjau gambar mini setelah pengambilan |
| `results{hide(filename)}` | Menyembunyikan nama file yang ditampilkan setelah unggahan |
| `results{left}` | Memindahkan ikon ke kiri setelah pengambilan |

Contoh — tombol besar di tengah, sembunyikan kamera setelah pengambilan:
```
inline display{center, large} results{hide(capture)}
```

### `invisible auto-show` — kamera buka otomatis

Menyembunyikan widget pertanyaan dari tata letak tetapi secara otomatis membuka kamera saat halaman dimuat. Berguna untuk menyematkan langkah pengambilan senyap dalam alur formulir.

```
invisible auto-show
inline invisible auto-show
```

### Tanda tangan dan gambar

| Appearance | Deskripsi |
|---|---|
| `signature` | Modal pad tanda tangan layar penuh |
| `signature display{quick}` | Pad tanda tangan cepat sebaris — tanpa modal |
| `draw` | Kanvas gambar bebas |

### Watermark

Tambahkan watermark teks atau gambar ke foto yang diambil:

```
watermark(text, "Survey ID: ${id}", bottom-right, 0.5)
watermark(file, logo.png, top-left, 1.0, 20%)
```

### Sembunyikan label

```
inline text-nolabel display{center, large}
```

## Penanganan Data

Gambar yang dikumpulkan melalui jenis pertanyaan ini biasanya:

1. Disimpan dalam format gambar umum (misalnya, JPG, PNG)
2. Disimpan bersama data survei lainnya, seringkali dalam folder media terpisah
3. Dapat diakses untuk dilihat dan dianalisis melalui platform manajemen survei

## Pertimbangan untuk Analisis

Saat menggunakan pertanyaan gambar, pertimbangkan:

1. Bagaimana gambar akan dianalisis (misalnya, tinjauan manual, analisis gambar otomatis)
2. Ruang penyimpanan tambahan yang diperlukan untuk file gambar
3. Langkah-langkah privasi dan perlindungan data untuk menyimpan dan menangani foto
4. Potensi kebutuhan alat pengeditan atau pengorganisasian gambar dalam fase analisis

## Batasan

- File gambar bisa berukuran besar, yang dapat memengaruhi transfer data dan penyimpanan.
- Tidak semua perangkat mungkin memiliki kamera berkualitas tinggi atau ruang penyimpanan yang cukup.
- Menganalisis sejumlah besar gambar dapat memakan waktu.
- Mungkin ada masalah privasi saat mengambil gambar, terutama di ruang publik.

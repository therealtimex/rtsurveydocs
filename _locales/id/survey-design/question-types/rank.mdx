Tipe pertanyaan `rank` menyajikan daftar pilihan yang diurutkan oleh responden berdasarkan preferensi atau prioritas. Ini menyimpan hasilnya sebagai daftar nilai pilihan yang dipisahkan spasi dalam urutan peringkat, dengan pilihan prioritas tertinggi di tempat pertama.

> **Formulir web rtSurvey:** Widget `drag-to-rank` saat ini tidak diterapkan. Dalam formulir web, `rank` dirender sebagai daftar pilihan. Gunakan tipe ini saat menargetkan klien seluler yang mendukung widget `rank`, atau saat format nilai yang disimpan lebih penting daripada interaksi `drag-to-order`.

## Spesifikasi XLSForm Dasar

| type | name | label |
|------|------|-------|
| rank priorities | main_priority | Urutkan kebutuhan masyarakat ini dari yang paling penting hingga yang paling tidak penting |

Pilihan didefinisikan di **worksheet `choices`** sama seperti `select_one`:

**survey:**

| type | name | label |
|------|------|-------|
| rank priorities | main_priority | Urutkan kebutuhan ini dari yang paling penting hingga yang paling tidak penting |

**choices:**

| list_name | name | label |
|-----------|------|-------|
| priorities | water | Air bersih |
| priorities | health | Perawatan kesehatan |
| priorities | education | Pendidikan |
| priorities | roads | Jalan |
| priorities | electricity | Listrik |

## Format nilai yang disimpan

Nilai yang disimpan adalah **daftar yang dipisahkan spasi** dari nilai pilihan dalam urutan peringkat (pertama = prioritas tertinggi):

```
water education health roads electricity
```

## Mengekstrak posisi peringkat

Gunakan `selected-at()` untuk mendapatkan pilihan pada peringkat tertentu:

| type | name | label | calculation |
|------|------|-------|-------------|
| rank priorities | main_priority | Peringkat kebutuhan masyarakat | |
| calculate | top_priority | | selected-at(`${main_priority}`, 0) |
| calculate | second_priority | | selected-at(`${main_priority}`, 1) |

`selected-at(${main_priority}, 0)` mengembalikan nilai yang ditempatkan **pertama** (indeks 0 = peringkat teratas).

## Menggunakan `rank-index()` dengan grup berulang

Ketika `rank` digunakan di dalam grup berulang, `rank-index()` memungkinkan Anda mereferensikan peringkat ordinal dari luar pengulangan:

| type | name | label | calculation |
|------|------|-------|-------------|
| calculate | first_ranked | | rank-index(1, `${score}`) |

Lihat [Fungsi — Fungsi bidang berulang](../operators-and-functions/functions#repeated-field-functions) untuk detail lengkap tentang `rank-index()` dan `rank-index-if()`.

## Kegunaan

Pertanyaan `rank` umumnya digunakan untuk:

1. **Peringkat prioritas** — meminta masyarakat untuk memeringkat kebutuhan pembangunan
2. **Pengurutan preferensi** — memeringkat fitur produk, atribut layanan, atau opsi kebijakan
3. **Pengurutan item ujian** — mengatur langkah-langkah dalam suatu proses
4. **Pemilihan Top-N** — dikombinasikan dengan `selected-at()` untuk mengekstrak hanya 1, 2, atau 3 pilihan teratas

## Praktik Terbaik

1. Buat daftar tetap pendek (3–7 item) — peringkat menjadi beban kognitif di luar 7–8 pilihan.
2. Gunakan label pilihan yang jelas dan saling eksklusif untuk menghindari kebingungan tentang apa arti "pertama".
3. Tambahkan teks petunjuk yang menjelaskan arah peringkat (misalnya, "Seret untuk mengurutkan: pertama = paling penting").
4. Validasi menggunakan `count-selected(.) = x` jika Anda perlu memastikan semua pilihan diberi peringkat.

## Batasan

- Widget `drag-to-rank` tidak diterapkan di formulir web rtSurvey.
- Anda tidak dapat melakukan peringkat sebagian — semua pilihan harus diurutkan.
- Pertahankan daftar 3–7 item; daftar yang lebih panjang menjadi sulit dikelola terlepas dari klien.

SSL harus dikonfigurasi sebelum Anda dapat masuk. Saat Anda membuka aplikasi untuk pertama kalinya, Anda akan dialihkan ke layar pengaturan SSL secara otomatis.

---

## Opsi pengaturan SSL

![Opsi pengaturan SSL](/img/ssl-setup/ssl-setup-options.png)

Pilih salah satu dari tiga opsi:

| Opsi | Kapan menggunakannya |
|--------|-------------|
| **Subdomain rtsurvey.com gratis** *(Direkomendasikan)* | Tidak perlu pengaturan DNS. Kami membuatkan catatannya untuk Anda. Siap dalam 2–5 menit. |
| **Domain saya sendiri** | Anda sudah memiliki domain dan DNS-nya mengarah ke server ini. |
| **Instal sertifikat secara manual** | Enterprise atau CA khusus. Memerlukan akses SSH. |

---

## Opsi 1 — Subdomain rtsurvey.com gratis *(Direkomendasikan)*

Ini adalah opsi tercepat. Tidak diperlukan pendaftaran domain atau perubahan DNS.

![Formulir pengaturan HTTPS](/img/ssl-setup/ssl-setup-form.png)

> **Sebelum Anda melanjutkan:** Subdomain gratis memerlukan akun aktif di [licenses.rtsurvey.com](https://licenses.rtsurvey.com). Paket gratis mencakup 1 subdomain (`*.rtsurvey.com`).

1. Klik **Subdomain rtsurvey.com gratis** untuk memperluas bagian tersebut
2. Ketik nama subdomain yang Anda inginkan di bidang **SUBDOMAIN ANDA**

   > Gunakan huruf kecil, angka, dan tanda hubung. 3–30 karakter.
   > Contoh: `proyeksaya` → `proyeksaya.rtsurvey.com`

3. Tempel **rtSurvey DNS Token** Anda dari [licenses.rtsurvey.com](https://licenses.rtsurvey.com) ke dalam bidang token
4. Klik **Buat subdomain aman**

Setelah dikirimkan, aplikasi akan mulai menyiapkan sertifikat Anda:

![Progres pengaturan HTTPS](/img/ssl-setup/ssl-setup-progress.png)

Empat langkah berjalan secara otomatis:
- **Meminta catatan DNS** — membuat entri DNS untuk subdomain Anda
- **Menunggu propagasi DNS** — biasanya 2–5 menit
- **Menerbitkan sertifikat SSL** — Let's Encrypt menandatangani sertifikat Anda
- **Mengaktifkan HTTPS** — Nginx memuat ulang dengan sertifikat baru

5. Setelah selesai, Anda akan dialihkan ke URL HTTPS baru Anda secara otomatis.



---

## Opsi 2 — Domain saya sendiri

Gunakan ini jika Anda memiliki domain yang sudah ada dan catatan `A` DNS-nya sudah mengarah ke IP server ini.

1. Klik **Domain saya sendiri** untuk memperluas bagian tersebut
2. Masukkan nama domain lengkap Anda (misalnya `survey.organisasisaya.org`)
3. Klik **Buat sertifikat**



Let's Encrypt akan memverifikasi domain Anda dan menerbitkan sertifikat. Ini mengharuskan DNS diarahkan dengan benar terlebih dahulu — jika tidak, permintaan akan gagal.

## Opsi 3 — Instal sertifikat secara manual

Untuk lingkungan enterprise yang menggunakan CA khusus atau internal. Anda akan menempatkan file sertifikat Anda di server melalui SSH, lalu memasukkan domain Anda di aplikasi.

### Prasyarat

- Akses SSH ke server
- Sertifikat dan kunci privat yang valid untuk domain Anda (format PEM)

### Langkah 1 — SSH ke server

```bash
ssh root@<server-ip>
```

### Langkah 2 — Tempatkan file sertifikat Anda

Buat direktori dan salin file Anda:

```bash
mkdir -p /etc/letsencrypt/live/<domain-anda>
```

Salin file Anda ke direktori tersebut dengan nama persis seperti ini:

| File | Deskripsi |
|------|-------------|
| `fullchain.pem` | Sertifikat Anda + sertifikat CA perantara lainnya (digabungkan) |
| `privkey.pem` | Kunci privat Anda |

Contoh:

```bash
# Salin dari mesin lokal Anda (jalankan ini secara lokal, bukan di server)
scp fullchain.pem root@<server-ip>:/etc/letsencrypt/live/<domain-anda>/fullchain.pem
scp privkey.pem  root@<server-ip>:/etc/letsencrypt/live/<domain-anda>/privkey.pem
```

Atur izin yang benar:

```bash
chmod 644 /etc/letsencrypt/live/<domain-anda>/fullchain.pem
chmod 600 /etc/letsencrypt/live/<domain-anda>/privkey.pem
```

### Langkah 3 — Masukkan domain Anda di aplikasi



1. Di layar pengaturan SSL, klik **Instal sertifikat secara manual**
2. Masukkan nama domain Anda (harus sesuai dengan Common Name atau SAN sertifikat)
3. Klik **Terapkan**

Server akan mengonfigurasi Nginx dengan sertifikat Anda dan memuat ulang secara otomatis.

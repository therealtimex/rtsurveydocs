# Sponsor rtSurvey

rtSurvey adalah platform gratis, open-source, dan dihosting sendiri untuk pengumpulan data di lapangan. Tidak ada biaya SaaS, tidak ada vendor lock-in, dan data tidak meninggalkan server Anda.

Mempertahankannya membutuhkan pengembangan, infrastruktur, dan dokumentasi yang berkelanjutan. Jika rtSurvey menghemat waktu atau uang organisasi Anda, pertimbangkan untuk mendukung pengembangannya.

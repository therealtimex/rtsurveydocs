O SSL deve ser configurado antes de você poder fazer o login. Quando abrir o aplicativo pela primeira vez, você será redirecionado automaticamente para a tela de configuração de SSL.

---

## Opções de configuração de SSL

![Opções de configuração de SSL](/img/ssl-setup/ssl-setup-options.png)

Escolha uma das três opções:

| Opção | Quando usar |
|--------|-------------|
| **Subdomínio rtsurvey.com gratuito** *(Recomendado)* | Não é necessária configuração de DNS. Criamos o registro para você. Pronto em 2–5 minutos. |
| **Meu próprio domínio** | Você já tem um domínio e o DNS dele aponta para este servidor. |
| **Instalar certificado manualmente** | Enterprise ou CA personalizada. Requer acesso SSH. |

---

## Opção 1 — Subdomínio rtsurvey.com gratuito *(Recomendado)*

Esta é a opção mais rápida. Não é necessário registro de domínio ou alterações de DNS.

![Formulário de configuração de HTTPS](/img/ssl-setup/ssl-setup-form.png)

> **Antes de continuar:** Um subdomínio gratuito requer uma conta ativa em [licenses.rtsurvey.com](https://licenses.rtsurvey.com). O plano gratuito inclui 1 subdomínio (`*.rtsurvey.com`).

1. Clique em **Subdomínio rtsurvey.com gratuito** para expandir a seção
2. Digite o nome do subdomínio desejado no campo **SEU SUBDOMÍNIO**

   > Use letras minúsculas, números e hifens. 3–30 caracteres.
   > Exemplo: `meuprojeto` → `meuprojeto.rtsurvey.com`

3. Cole seu **rtSurvey DNS Token** de [licenses.rtsurvey.com](https://licenses.rtsurvey.com) no campo do token
4. Clique em **Criar subdomínio seguro**

Uma vez enviado, o aplicativo começará a provisionar seu certificado:

![Progresso da configuração de HTTPS](/img/ssl-setup/ssl-setup-progress.png)

As quatro etapas ocorrem automaticamente:
- **Solicitando registro DNS** — cria a entrada DNS para o seu subdomínio
- **Aguardando propagação do DNS** — geralmente 2–5 minutos
- **Emitindo certificado SSL** — o Let's Encrypt assina seu certificado
- **Ativando HTTPS** — o Nginx recarrega com o novo certificado

5. Uma vez concluído, você será redirecionado para sua nova URL HTTPS automaticamente



---

## Opção 2 — Meu próprio domínio

Use esta opção se você tiver um domínio existente e o registro DNS `A` dele já apontar para o IP deste servidor.

1. Clique em **Meu próprio domínio** para expandir a seção
2. Insira seu nome de domínio completo (ex: `survey.minhaorganizacao.org`)
3. Clique em **Criar certificado**



O Let's Encrypt verificará seu domínio e emitirá um certificado. Isso requer que o DNS esteja corretamente apontado primeiro — caso contrário, a solicitação falhará.

## Opção 3 — Instalar certificado manualmente

Para ambientes corporativos que usam uma CA personalizada ou interna. Você colocará os arquivos do seu certificado no servidor via SSH e, em seguida, inserirá seu domínio no aplicativo.

### Pré-requisitos

- Acesso SSH ao servidor
- Um certificado válido e chave privada para o seu domínio (formato PEM)

### Passo 1 — SSH para o servidor

```bash
ssh root@<server-ip>
```

### Passo 2 — Coloque os arquivos do seu certificado

Crie o diretório e copie seus arquivos:

```bash
mkdir -p /etc/letsencrypt/live/<your-domain>
```

Copie seus arquivos para esse diretório com estes nomes exatos:

| Arquivo | Descrição |
|------|-------------|
| `fullchain.pem` | Seu certificado + quaisquer certificados CA intermediários (concatenados) |
| `privkey.pem` | Sua chave privada |

Exemplo:

```bash
# Copie da sua máquina local (execute isso localmente, não no servidor)
scp fullchain.pem root@<server-ip>:/etc/letsencrypt/live/<your-domain>/fullchain.pem
scp privkey.pem  root@<server-ip>:/etc/letsencrypt/live/<your-domain>/privkey.pem
```

Defina as permissões corretas:

```bash
chmod 644 /etc/letsencrypt/live/<your-domain>/fullchain.pem
chmod 600 /etc/letsencrypt/live/<your-domain>/privkey.pem
```

### Passo 3 — Insira seu domínio no aplicativo



1. Na tela de configuração de SSL, clique em **Instalar certificado manualmente**
2. Insira seu nome de domínio (deve corresponder ao Common Name ou SAN do certificado)
3. Clique em **Aplicar**

O servidor configurará o Nginx com seu certificado e recarregará automaticamente.

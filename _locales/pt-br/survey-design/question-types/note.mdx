---
title: "Nota"
description: "As perguntas de nota exibem texto ou mídia somente leitura para fornecer informações ou instruções na sua pesquisa."
---

O tipo de pergunta note em XLSForms e rtSurvey é usado para exibir texto ou mídia somente leitura para o respondente da pesquisa. Não é uma pergunta que requer uma resposta, mas sim uma forma de fornecer informações, instruções ou contexto dentro da pesquisa.

## Especificação básica do XLSForm

| type | name | label |
|------|------|-------|
| note | info_text | Esta pesquisa é sobre seus hábitos de leitura. |

Para mais detalhes sobre o tipo básico de pergunta note, consulte a [especificação do XLSForm](https://xlsform.org/en/#question-types).

## Usos

As perguntas de nota são comumente usadas para:

1. Fornecer instruções ou contexto para perguntas futuras
2. Exibir resultados calculados ou resumos
3. Mostrar imagens ou outras mídias
4. Separar seções de uma pesquisa
5. Dar feedback com base em respostas anteriores

## Práticas recomendadas

1. Mantenha o texto da nota conciso e claro para manter o engajamento do respondente.
2. Use formatação (negrito, itálico) para enfatizar informações importantes.
3. Considere usar mídia (imagens, áudio) para melhorar a compreensão quando apropriado.
4. Use notas com moderação para evitar sobrecarregar a pesquisa.

## Exemplo de uso

Aqui está um exemplo de como você pode usar perguntas de nota em uma pesquisa:

| type | name | label |
|------|------|-------|
| note | intro | Bem-vindo à nossa pesquisa sobre hábitos de leitura. Faremos perguntas sobre suas preferências e frequência de leitura. |
| ... | ... | ... |
| calculate | books_per_month | `${fiction_books}` + `${non_fiction_books}` |
| note | reading_summary | Você lê aproximadamente `${books_per_month}` livros por mês. |

Neste exemplo, usamos notas para apresentar a pesquisa e fornecer um resumo dos resultados calculados.

## Extensões do rtSurvey

Embora a especificação básica do XLSForm para perguntas de nota seja direta, o rtSurvey pode oferecer recursos ou personalizações adicionais:

1. Formatação de texto rico
2. Suporte para mídia incorporada (imagens, áudio, vídeo)
3. Conteúdo dinâmico com base em respostas anteriores
4. Opções de estilo personalizado

## Uso avançado

### Exibição condicional

Você pode usar expressões de relevância para mostrar notas condicionalmente:

| type | name | label | relevant |
|------|------|-------|----------|
| note | high_reader_note | Você é um leitor ávido! | `${books_per_month}` > 5 |

### Incluindo cálculos

As notas podem incluir cálculos para fornecer feedback dinâmico:

| type | name | label |
|------|------|-------|
| note | reading_time | Com base em suas respostas, você passa aproximadamente `${books_per_month * 5}` horas lendo por mês. |

## Limitações

- As notas não coletam dados, portanto não devem ser usadas quando você precisa reunir informações dos respondentes.
- O uso excessivo de notas pode fazer uma pesquisa parecer desordenada ou excessivamente longa.
- Algumas opções avançadas de formatação ou mídia podem não ser suportadas em todos os dispositivos ou plataformas.

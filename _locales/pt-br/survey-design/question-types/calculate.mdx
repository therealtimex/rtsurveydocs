O tipo de pergunta `calculate` executa uma fórmula silenciosamente em segundo plano. Ele armazena o resultado em um campo nomeado que outras perguntas podem referenciar — mas não exibe nenhuma entrada ou rótulo para o enumerador. Use-o para derivar valores, concatenar strings, executar lógica condicional ou buscar dados que você precisará mais tarde no formulário.

---

## Sintaxe básica

| type | name | label | calculation |
|------|------|-------|-------------|
| calculate | total | | `${price} * ${quantity}` |

- **type**: Sempre `calculate`.
- **name**: Um nome de campo exclusivo. Outras perguntas referenciam isso com `${name}`.
- **label**: Deixe em branco — os campos calculate nunca são exibidos para o enumerador.
- **calculation**: A fórmula a ser avaliada. Suporta todas as [funções XLSForm](../operators-and-functions/functions) e referências de campo.

---

## Padrões comuns

### Aritmética

| type | name | label | calculation |
|------|------|-------|-------------|
| integer | price | Unit price | |
| integer | quantity | Quantity | |
| calculate | total | | `${price} * ${quantity}` |
| note | total_note | Total: `${total}` | |

### Concatenação de strings

| type | name | label | calculation |
|------|------|-------|-------------|
| text | first_name | First name | |
| text | last_name | Last name | |
| calculate | full_name | | `concat(${first_name}, ' ', ${last_name})` |

### Valor condicional

| type | name | label | calculation |
|------|------|-------|-------------|
| integer | score | Score (0–100) | |
| calculate | grade | | `if(${score} >= 90, 'A', if(${score} >= 75, 'B', if(${score} >= 60, 'C', 'F')))` |

### Idade a partir da data de nascimento

| type | name | label | calculation |
|------|------|-------|-------------|
| date | dob | Date of birth | |
| calculate | age_years | | `int((today() - ${dob}) div 365.25)` |

## Usando `once()` para bloquear o valor

Por padrão, o `calculate` é reavaliado sempre que qualquer campo referenciado muda. Envolva a fórmula em `once()` para avaliar apenas no primeiro carregamento e congelar o resultando:

| type | name | label | calculation |
|------|------|-------|-------------|
| calculate | interview_start | | `once(now())` |

Use `once()` para registros de data e hora (timestamps), valores iniciais ou qualquer caso em que o recálculo na alteração seja indesejável.

## Extraindo dados de fontes externas

### De um arquivo CSV

```
pulldata('staff.csv', 'department', 'name', ${staff_id})
```

Consulte [pulldata()](../operators-and-functions/pulldata) para a referência completa.

### De um banco de dados SQLite empacotado

```
pulldata('rawquery',
  concat(${family_path}, '/locations.db::provinces'),
  'SELECT name FROM provinces WHERE id = ?',
  ${province_id})
```

Consulte [Busca em banco de datos local](../advanced-features/local-database-search) para detalhes da construção do caminho.

### Do contexto do aplicativo

```
pulldata('app-api', 'user.username')
pulldata('app-api', 'family_path')
```

Consulte [App API](../app-api) para todas as chaves disponíveis.

## Usando calculate em relevant e constraint

Outros campos podem referenciar um resultado de `calculate` exatamente como qualquer campo:

| type | name | label | relevant | constraint |
|------|------|-------|----------|------------|
| calculate | bmi | | | `${weight} div (${height} * ${height}) * 10000` |
| note | bmi_warning | BMI is very high — please verify weight and height. | `${bmi} > 40` | |

## Melhores Práticas

1. Dê nomes significativos aos campos calculate — `total_cost` é mais claro do que `calc1` e mais fácil de rastrear em exportações.
2. Divida fórmulas complexas em vários campos calculate encadeados em vez de uma única expressão profundamente aninhada.
3. Use `once()` para registros de data e hora e instantâneos iniciais para evitar que os valores mudem após a primeira captura.
4. Coloque os campos `calculate` antes da primeira pergunta que os referencia — a ordem de avaliação segue a ordem do formulário.
5. Mantenha a coluna `label` vazia. Algumas ferramentas exibem o rótulo; deixá-la em branco evita resultados confusos.

## Limitações

- Os campos Calculate nunca são exibidos diretamente para o enumerador — use um campo `note` para mostrar o resultado.
- A coluna `calculation` é obrigatória; uma linha `calculate` sem fórmula sempre armazena uma string vazia.
- Os resultados são reavaliados em cada alteração do formulário, a menos que sejam envolvidos em `once()` — fórmulas muito complexas em formulários grandes podem afetar o desempenho de renderização em dispositivos de baixo custo.
- Os valores calculados são armazenados como strings no envio. Use `number()`, `int()` ou `boolean()` para converter o tipo ao passar o resultado para expressões aritméticas ou lógicas.

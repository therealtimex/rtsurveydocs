`family_path` é um campo de cálculo de convenção que contém o caminho para o diretório de mídia empacotado do formulário. Todo formulário que realiza pesquisas em bancos de dados locais com `rawquery`, `pulldata` ou `search()` deve incluir este campo — sem ele, os caminhos dos arquivos não podem ser resolvidos e as pesquisas retornam silenciosamente resultados vazios.

---

## O campo calculate

Adicione esta linha perto do topo da sua folha survey, após quaisquer campos meta e antes da primeira pergunta que utiliza um arquivo de banco de dados:

| type | name | label | calculation |
|---|---|---|---|
| calculate | `family_path` | | `pulldata('app-api', 'family_path')` |

O campo não armazena nenhum valor visível e não requer rótulo (label). É um pré-requisito silencioso para toda a construção de caminhos que se segue.

---

## Por que é necessário

O RTSurvey empacota os arquivos de mídia do formulário — bancos de dados SQLite, imagens, clipes de áudio — dentro de um diretório por formulário no dispositivo. O caminho exato difere entre plataformas (Android, iOS, web) e entre dispositivos.

Em tempo de execução, o aplicativo preenche o `family_path` automaticamente. Um valor resolvido típico se assemelha a:

```
resources/familyMedia/Phuong_Person_Test
```

Como o caminho é específico da plataforma e determinado no momento do lançamento, ele não pode ser codificado rigidamente no formulário. `pulldata('app-api', 'family_path')` é a única forma confiável de obtê-lo.

---

## Como usá-lo em caminhos

Assim que o `family_path` estiver definido, construa um caminho completo de arquivo com `concat()`:

```
concat(${family_path}, '/file.db::tableName')
```

O sufixo `::tableName` is removido quando o aplicativo abre o arquivo; o nome da tabela é usado apenas dentro da sua consulta SQL.

---

## Onde o family_path é usado

O `family_path` é necessário no argumento do caminho sempre que você referenciar um arquivo empacotado:

- **Pesquisa em banco de dados local** — o argumento `db_path` de `search-autocomplete-noedit-v2('rawquery', ...)` deve ser construído com `concat(${family_path}, ...)`. Consulte [Pesquisa em Banco de Dados Local](local-database-search) para detalhes completos de utilização.
- **`pulldata` rawquery** — qualquer chamada `pulldata('rawquery', ...)` que lê de um arquivo `.db` usa o mesmo padrão `concat()`.
- **`search()` com um arquivo local** — aparências (appearances) de pesquisa dinâmica que carregam a partir de um arquivo CSV ou DB empacotado também dependem do `family_path` para a referência do arquivo.

---

## Colocação no formulário

O `family_path` deve aparecer **antes do primeiro campo que o referencia**. A posição recomendada é imediatamente após o grupo meta:

| type | name | label | calculation |
|---|---|---|---|
| begin_group | meta | | |
| deviceid | deviceid | | |
| start | start | | |
| end | end | | |
| end_group | | | |
| calculate | `family_path` | | `pulldata('app-api', 'family_path')` |
| select_one | province | Province | *(aparência rawquery referenciando `${family_path}`)* |

<Callout type="warning">
Se o `family_path` estiver ausente no formulário, ou se for colocado após o primeiro campo `rawquery` / `search()` que o referencia, todas as pesquisas em arquivos empacotados retornarão silenciosamente resultados vazios. Não existe mensagem de erro — o preenchimento automático simplesmente não mostra resultados.
</Callout>

---

## Múltiplos arquivos de banco de dados

Um único formulário pode usar vários arquivos `.db`. Cada caminho é construído de forma independente com `concat()`:

```
concat(${family_path}, '/locations.db::externalData')
concat(${family_path}, '/health_facilities.db::facilities')
concat(${family_path}, '/household_list.db::households')
```

Defina o `family_path` uma vez; referencie-o em tantos campos quantos forem necessários.

---

## Verificação durante o desenvolvimento

Adicione um campo `note` temporário abaixo do `family_path` para inspecionar o valor resolvido no dispositivo:

| type | name | label | calculation |
|---|---|---|---|
| calculate | `family_path` | | `pulldata('app-api', 'family_path')` |
| note | family_path_check | `Caminho: ${family_path}` | |

A nota exibirá o caminho resolvido real durante os testes. Remova-a antes de implantar o formulário final.

As expressões no rtSurvey são escritas em um subconjunto de **XPath 1.0**, estendido com funções JavaRosa/ODK e funções personalizadas do rtSurvey. Você usa expressões nas colunas `calculate`, `constraint`, `relevant`, `required` e `default` do seu XLSForm.

## Referenciando valores de campo

Use `${fieldname}` para referenciar o valor de outro campo:

```
${age} > 18
```

Use `.` (um único ponto) para referenciar o **valor do campo atual** — comumente usado em expressões de `constraint`:

```
. >= 0 and . <= 100
```

Use `..` para referenciar o grupo pai (uso avançado em repetições).

## Sintaxe de expressão

As expressões seguem as regras padrão do XPath:

- **Strings** devem ser colocadas entre aspas simples: `'yes'`
- **Números** são escritos como estão: `42`, `3.14`
- Resultados **booleanos** são usados para `relevant`, `required` e `constraint` — qualquer valor não vazio e não zero é verdadeiro
- Espaços em branco são ignorados ao redor dos operadores

<Callout type="warning">
Sempre use aspas retas (`'` ou `"`) — nunca "aspas inteligentes" (aspas curvas). Editores de texto rico geralmente convertem aspas automaticamente e quebrarão suas expressões.
</Callout>

## Exemplos rápidos

| Caso de uso | Expressão |
|-------------|-----------|
| Mostrar se a idade for maior que 18 | `${age} > 18` |
| Mostrar apenas se "sim" foi selecionado | `${consent} = 'yes'` |
| Obrigar se outro campo não estiver vazio | `${name} != ''` |
| Calcular total | `${adults} + ${children}` |
| Concatenar nome | `concat(${first_name}, ' ', ${last_name})` |
| Data de hoje | `today()` |
| Verificar se opção foi selecionada | `selected(${interests}, 'sports')` |

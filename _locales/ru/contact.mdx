# Свяжитесь с нами

## Общие вопросы и поддержка

Пишите нам на **[support@rta.vn](mailto:support@rta.vn)** по вопросам, помощи с развёртыванием или по любым другим темам.

Для технических ошибок и запросов на новые функции, пожалуйста, используйте [GitHub Issues](https://github.com/therealtimex/rtsurvey/issues), чтобы сообщество могло воспользоваться обсуждением.

---

## Корпоративные клиенты и партнёрство

Нужно индивидуальное развёртывание, поддержка по SLA или помощь с интеграцией? Посетите **[rtsurvey.com](https://rtsurvey.com)** или напишите нам напрямую.

---

## Безопасность

Пожалуйста, **не** создавайте публичные GitHub Issues для сообщений об уязвимостях безопасности. Свяжитесь с нами приватно по адресу [support@rta.vn](mailto:support@rta.vn) с темой письма `[Security]`.

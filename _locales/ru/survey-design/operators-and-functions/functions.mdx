### Строковые функции

<Callout type="warning">
При работе со строками в выражениях важно использовать одинарные кавычки ('') для заключения литеральных строк. Однако исключение возникает, когда вы хотите включить одинарные кавычки внутрь литеральной строки. В таких случаях вы можете использовать двойные кавычки ("") для заключения всей строки.

Например:
- Верно: if(`${yesno}` = 1, "a string with 'single quotes' in it", "no single quotes here")
- Неверно: if(`${yesno}` = 1, 'a string with 'single quotes' in it', 'no single quotes here')

Что касается «умных» кавычек, крайне важно знать об их присутствии, так как они могут вызвать проблемы в выражениях. Многие текстовые редакторы автоматически преобразуют прямые кавычки ("" или '') в «умные» или фигурные кавычки (“” или ‘’), что может привести к синтаксическим ошибкам или неожиданному поведению. Чтобы избежать этого, убедитесь, что вы последовательно используете прямые кавычки ('') в своих выражениях.

Пожалуйста, дайте мне знать, если у вас возникнут дополнительные вопросы или потребуется помощь!
</Callout>

rtSurvey поддерживает различные функции, включая:

1. `string(field)`: Преобразует поле в строку.
   - Пример: `string(34.8)` будет преобразовано в `'34.8'`.

2. `string-length(field)`: Возвращает длину строкового поля.
   - Пример: `string-length(.) > 3 and string-length(.) < 10` можно использовать для проверки того, что текущее поле содержит от 3 до 10 символов.
   - **Шаблон каскадной зависимости**: `string-length(${province}) >= 0` всегда возвращает `true`, но заставляет rtSurvey заново вычислять выражение каждый раз, когда меняется `${province}`. Используйте это в `relevant`, чтобы инициировать каскадное обновление при обновлении родительского поля:
     | type | name | relevant |
     |------|------|----------|
     | select_one | district | `string-length(${province}) >= 0` |
     Это гарантирует, что вопрос о районе (district) заново вычисляет свой `appearance` с `search()` или `rawquery` всякий раз, когда меняется провинция (province).

3. `substr(fieldorstring, startindex, endindex)`: Возвращает подстроку, начинающуюся с `startindex` и заканчивающуюся непосредственно перед `endindex`. Индексы начинаются с 0 для первого символа в строке.
   - Пример: `substr(${phone}, 0, 3)` вернет первые три цифры номера телефона.

4. `concat(a, b, c, ...)`: Объединяет (конкатенирует) поля (и/или строки) вместе.
   - Пример: `concat(${firstname}, ' ', ${lastname})` вернет полное имя, объединив значения в полях `firstname` и `lastname`.

5. `linebreak()`: Возвращает символ разрыва строки.
   - Пример: `concat(${field1}, linebreak(), ${field2}, linebreak(), ${field3})` вернет список из трех значений полей с разрывами строк между ними.

6. `lower()`: Преобразует строку во все строчные буквы.
   - Пример: `lower('Street Name')` вернет "street name".

7. `upper()`: Преобразует строку во все заглавные буквы.
   - Пример: `upper('Street Name')` вернет "STREET NAME".

### Функции select_one и select_multiple

1. `count-selected(field)`: Возвращает количество элементов, выбранных в поле select_multiple.
   - Пример: `count-selected(.) = 3` можно использовать в качестве выражения ограничения (`constraint`), чтобы гарантировать выбор ровно трех вариантов.

2. `selected(field, value)`: Возвращает true или false в зависимости от того, было ли выбрано указанное значение в поле select_one или select_multiple.
   - Пример: `selected(${color}, 'Blue')` можно использовать в качестве выражения релевантности (`relevant`), чтобы показать группу или поле только в том случае, если респондент выбрал "Blue" (Синий) в качестве своего любимого цвета.
   - Примечание: Второй параметр всегда должен указывать значение выбора (choice value), а не метку выбора (choice label). Используйте значение из столбца value на листе choices определения формы.

3. `selected-at(field, number)`: Возвращает выбранный элемент в указанной позиции в поле select_multiple. Когда передаваемое число равно 0, функция возвращает первый выбранный элемент; когда число равно 1 — второй выбранный элемент и так далее.
   - Пример: `selected-at(${fruits}, 0) = 'Apple'` можно использовать в качестве выражения релевантности, чтобы показать группу или поле только в том случае, если первым выбранным вариантом является "Apple" (Яблоко).
   - Примечание: Возвращаемым значением будет значение выбора (value), а не метка выбора (label). Используйте значение из столбца value на листе choices определения формы.

4. `choice-label(field, value)`: Возвращает метку (label) для выбора поля select_one или select_multiple, как определено на листе choices определения формы.
   - Пример 1: `choice-label(${country}, ${country})` вернет метку выбора для текущего выбранного варианта в поле с именем `country`.
   - Пример 2: `choice-label(${languages}, selected-at(${languages}, 0))` вернет метку для первого выбранного варианта в поле с именем `languages`.
   - Примечание: Эта функция извлекает метку выбора (label), а не значение (value). Она использует столбец label из листа choices определения формы.

### Функции повторяющихся полей

В rtSurvey, если вы хотите задать один и тот же вопрос(ы) несколько раз, вы можете поместить поле внутрь группы повторения (`repeat group`). Это приводит к созданию нескольких экземпляров одного и того же поля. Следующие функции помогут вам работать с этими повторяющимися полями и данными, которые они производят. См. раздел справки по повторяющимся полям для получения более подробной информации.

1. `join(string, repeatedfield)`: Для поля внутри группы повторения генерирует список значений, разделенных строкой. Первый параметр указывает разделитель, который будет использоваться для разделения значений.
   - Пример: `join(', ', ${member_name})` сгенерирует единый список всех введенных имен, разделенных запятыми.

2. `join-if(string, repeatedfield, expression)`: Работает точно так же, как `join()`, за исключением того, что проверяет каждый экземпляр в группе повторения с помощью предоставленного выражения. Если выражение ложно, элемент будет исключен из вывода.
   - Пример: `join-if(', ', ${member_name}, ${age} >= 18)` сгенерирует список имен только взрослых членов (тех, чей возраст 18 лет и старше), разделенных запятыми.

3. `count(repeatgroup)`: Возвращает текущее количество раз, которое повторилась группа повторения.
   - Пример: `count(${groupname})` вернет количество экземпляров группы.

4. `count-if(repeatgroup, expression)`: Работает точно так же, как `count()`, за исключением того, что проверяет каждый экземпляр в группе повторения с помощью предоставленного выражения. Если выражение ложно, элемент будет исключен из подсчета.
   - Пример: `count-if(${members}, ${age} >= 18)` вернет количество взрослых членов на основе поля возраста (age) внутри группы повторения "members".

5. `sum(repeatedfield)`: Для поля внутри группы повторения вычисляет сумму всех значений.
   - Пример: `sum(${loan_amount})` вернет общую сумму всех кредитов.

6. `sum-if(repeatedfield, expression)`: Работает точно так же, как `sum()`, за исключением того, что проверяет каждый экземпляр в группе повторения с помощью предоставленного выражения. Если выражение ложно, элемент будет исключен из суммы.
   - Пример: `sum-if(${loan_amount}, ${loan_amount} > 500)` вернет общую сумму всех кредитов, размер которых превышает 500. Меньшие кредиты будут проигнорированы.

7. `min(repeatedfield)`: Для поля внутри группы повторения вычисляет минимум из всех значений.
   - Пример: `min(${member_age})` вернет возраст самого младшего члена группы.

8. `min-if(repeatedfield, expression)`: Работает точно так же, как `min()`, за исключением того, что проверяет каждый экземпляр в группе повторения с помощью предоставленного выражения. Если выражение ложно, элемент будет проигнорирован.
   - Пример: `min-if(${member_age}, ${member_age} >= 18)` вернет возраст самого молодого взрослого в группе. Лица моложе 18 лет будут проигнорированы.

9. `max(repeatedfield)`: Для поля внутри группы повторения вычисляет максимум из всех значений.
   - Пример: `max(${member_age})` вернет возраст самого старшего члена группы.

10. `max-if(repeatedfield, expression)`: Работает точно так же, как `max()`, за исключением того, что проверяет каждый экземпляр в группе повторения с помощью предоставленного выражения. Если выражение ложно, элемент будет проигнорирован.
    - Пример: `max-if(${member_age}, ${member_age} >= 18)` вернет возраст самого старого взрослого в группе. Лица моложе 18 лет будут проигнорированы.

11. `index()`: Вызываемая внутри группы повторения, возвращает номер индекса для текущей группы или экземпляра.
    - Пример: `index()` при использовании внутри группы повторения вернет 1 для первого экземпляра, 2 для второго и так далее.

12. `indexed-repeat(repeatedfield, repeatgroup, index)`: Ссылается на поле или группу, находящуюся внутри группы повторения, извне этой группы. Первый параметр указывает на интересующее повторяющееся поле или группу, второй — на группу повторения, в которой находится поле или группа, а третий — на номер экземпляра внутри группы повторения, который следует использовать.
    - Пример 1: `indexed-repeat(${name}, ${names}, 1)` вернет первое доступное имя, когда поле имени (name) находится внутри предшествующей группы повторения с именем "names".
    - Пример 2: `indexed-repeat(${name}, ${names}, index())` извлечет имя, соответствующее номеру экземпляра текущей группы повторения.

13. `rank-index(index, repeatedfield)`: Эта функция вычисляет порядковый ранг указанного экземпляра повторяющегося поля для использования вне группы повторения. Ранг 1 присваивается экземпляру с самым высоким значением, ранг 2 — экземпляру со следующим по величине значением и так далее. Если вы передадите недопустимый индекс или индекс экземпляра с нечисловым значением, будет возвращен ранг 999.
    - Пример: `rank-index(1, ${random_draw})` вычисляет ранг первого экземпляра на основе значения его поля `random_draw` по сравнению со значениями других экземпляров.

14. `rank-index-if(index, repeatedfield, expression)`: Эта функция работает аналогично `rank-index()`, но проверяет каждый экземпляр в группе повторения повторяющегося поля с помощью предоставленного выражения. Если выражение ложно, элемент будет исключен из расчета. Используемый индекс основан на полном наборе экземпляров перед вычислением выражения для каждого экземпляра. Если вы передадите индекс для экземпляра, который был проигнорирован из-за невыполнения выражения, он считается недопустимым индексом, и будет возвращен ранг 999.
    - Пример: `rank-index-if(1, ${age}, ${age} >= 18)` вычисляет ранг возраста в наборе взрослых, учитывая только те экземпляры, где возраст больше или равен 18.

### Числовые функции

| Оператор | Операция | Пример | Пример ответа |
|----------|-----------|---------|----------------|
| `+` | Сложение | 1 + 1 | 2 |
| `-` | Вычитание | 3 - 2 | 1 |
| `*` | Умножение | 3 * 2 | 6 |
| `div` | Деление | 10 div 2 | 5 |
| `mod` | Остаток от деления | 9 mod 2 | 1 |

rtSurvey поддерживает числовые функции, включая:
- `number(field)`: Преобразует значение поля в число.
  - Пример: `number('34.8')` = 34.8

- `int(field)`: Преобразует значение поля в целое число.
  - Пример: `int('39.2')` = 39

- `min(field1, ..., fieldx)`: Возвращает минимальное значение среди переданных полей.
  - Пример: `min(${father_age}, ${mother_age})` вернет возраст либо матери, либо отца, в зависимости от того, какой из них меньше.

- `max(field1, ..., fieldx)`: Возвращает максимальное значение среди переданных полей.
  - Пример: `max(${father_age}, ${mother_age})` вернет возраст либо матери, либо отца, в зависимости от того, какой из них больше.

- `format-number(field)`: Форматирует значение целого или десятичного поля в соответствии с локальными настройками пользователя.
  - Пример: `format-number(${income})` Это выражение может отформатировать "120000" как "120,000".

- `round(field, digits)`: Округляет числовое значение поля до указанного количества знаков после запятой.
  - Пример: `round(${interest_rate}, 2)`

- `abs(number)`: Возвращает абсолютное значение числа.
  
- `pow(base, exponent)`: Возвращает значение первого параметра, возведенное в степень второго параметра.
  - Каждый параметр может быть полем, числом или выражением.

- `log10(fieldorvalue)`: Возвращает десятичный логарифм переданного поля или значения.

- `sin(fieldorvalue)`: Возвращает синус переданного поля или значения, выраженный в радианах.
  
- `cos(fieldorvalue)`: Возвращает косинус переданного поля или значения, выраженный в радианах.

- `tan(fieldorvalue)`: Возвращает тангенс переданного поля или значения, выраженный в радианах.

- `asin(fieldorvalue)`: Возвращает арксинус переданного поля или значения, выраженный в радианах.

- `acos(fieldorvalue)`: Возвращает арккосинус переданного поля или значения, выраженный в радианах.

- `atan(fieldorvalue)`: Возвращает арктангенс переданного поля или значения, выраженный в радианах.

- `atan2(x, y)`: Возвращает угол в радианах, образуемый в начале координат точкой с координатами (x, y) и положительной осью x. Результат находится в диапазоне от -pi() до pi().

- `sqrt(fieldorvalue)`: Возвращает неотрицательный квадратный корень из переданного поля или значения.

- `exp(x)`: Возвращает значение e^x.

- `pi()`: Возвращает значение числа пи.

### Функции даты и времени

<Callout type="warning">
Значения дат в rtSurvey хранятся как строки в формате `YYYY-MM-DD`. Значения даты и времени хранятся как строки ISO 8601 (`YYYY-MM-DDTHH:MM:SS`). Используйте `decimal-date-time()` для преобразования в число для арифметических операций (например, для вычисления длительности).
</Callout>

1. `today()`: Возвращает сегодняшнюю дату в виде строки в формате `YYYY-MM-DD`. Вычисляется один раз при открытии формы.
   - Пример: `today()` → `'2024-03-15'`
   - Обычное использование: столбец `default` для предварительного заполнения сегодняшней даты или в `relevant`/`constraint` для сравнения с полем даты.

2. `now()`: Возвращает текущую дату и время в виде строки ISO 8601. Вычисляется каждый раз при расчете выражения.
   - Пример: `now()` → `'2024-03-15T14:32:00.000+03:00'`
   - Обычное использование: Запись точной метки времени конкретного события во время опроса.

3. `date(value)`: Преобразует значение (строку или число) в строку даты. Полезно для принудительного преобразования вычисленных значений в тип даты.
   - Пример: `date('2024-03-15')` → `'2024-03-15'`

4. `date-time(value)`: Преобразует значение в строку даты и времени.
   - Пример: `date-time(${event_timestamp})`

5. `decimal-date-time(value)`: Преобразует строку даты или даты-времени в десятичное число, представляющее количество миллисекунд, прошедших с эпохи Unix, деленное на 86400000 (т. е. дробные дни с 1970-01-01). Используйте это для выполнения арифметических операций над датами.
   - Пример: Длительность в днях между двумя датами:
     `decimal-date-time(${end_date}) - decimal-date-time(${start_date})`
   - Пример: Длительность в минутах между двумя значениями даты-времени:
     `(decimal-date-time(${end_time}) - decimal-date-time(${start_time})) * 1440`

6. `format-date(date, format)`: Форматирует значение даты, используя строку шаблона.
   - Токены формата: `%Y` (4-значный год), `%y` (2-значный год), `%m` (месяц 01–12), `%d` (день 01–31), `%a` (сокращенный день недели), `%b` (сокращенное название месяца)
   - Пример: `format-date(today(), '%d/%m/%Y')` → `'15/03/2024'`
   - Пример: `format-date(${dob}, '%B %d, %Y')` → `'March 15, 1990'`

7. `format-date-time(datetime, format)`: Форматирует значение даты и времени, используя строку шаблона. Принимает все токены `format-date`, а также:
   - `%H` (час 00–23), `%h` (час 01–12), `%M` (минуты 00–59), `%S` (секунды 00–59), `%3` (миллисекунды), `%P` (AM/PM)
   - Пример: `format-date-time(now(), '%d/%m/%Y %H:%M')` → `'15/03/2024 14:32'`
   - Пример: `format-date-time(${event_time}, '%I:%M %p')` → `'02:32 PM'`

8. `STRFTIME(format, datetime)`: Форматирование даты в стиле SQLite. Доступно внутри строк SQL, передаваемых в запросы `rawquery` — **недоступно** в столбцах XLSForm `calculation` или `label`. Использует токены формата SQLite (`%Y`, `%m`, `%d`, `%H`, `%M`, `%S`).
   - Пример внутри строки SQL rawquery: `'SELECT STRFTIME(''%Y-%m'', interview_date) AS month FROM data WHERE id = ?'`
   - Примечание: Используйте `format-date-time()` для форматирования даты в выражениях XLSForm. `STRFTIME()` — это функция SQLite, доступная только в SQL, передаваемом в `rawquery`.

### Булевы (логические) функции

1. `boolean(value)`: Преобразует любое значение в булево (логическое). Возвращает `true` для непустых строк, ненулевых чисел и `true`; возвращает `false` для пустых строк, `0` и `false`.
   - Пример: `boolean(${name})` возвращает `true`, если поле `name` не пустое.

2. `boolean-from-string(string)`: Возвращает `true`, если строка равна `'1'` или `'true'` (без учета регистра); в противном случае возвращает `false`.
   - Пример: `boolean-from-string(${enabled_flag})` — полезно, когда поле хранит `'true'`/`'false'` как текст.

3. `true()`: Возвращает логическое значение `true`.
   - Пример: В столбце `required` функция `true()` эквивалентна `yes`.

4. `false()`: Возвращает логическое значение `false`.
   - Пример: `if(${skip_section} = 'yes', false(), true())` — динамическая установка обязательности поля.

5. `not(expression)`: Возвращает логическое отрицание выражения. Возвращает `true`, если выражение ложно, и наоборот.
   - Пример: `not(${consent} = 'yes')` — показать предупреждение, когда согласие НЕ было получено.
   - Пример: `not(selected(${issues}, 'none'))` — требовать подробности только в том случае, если не было выбрано "none" (ничего).

### Дополнительные строковые функции

1. `starts-with(string, prefix)`: Возвращает `true`, если `string` начинается с `prefix`.
   - Пример: `starts-with(${phone}, '+254')` проверяет, начинается ли номер телефона с кода Кении.

2. `contains(string, substring)`: Возвращает `true`, если `string` содержит `substring`.
   - Пример: `contains(${email}, '@')` проверяет наличие символа `@` в адресе электронной почты.
   - Пример: `contains(${notes}, 'urgent')` активирует последующий вопрос, если в примечаниях упоминается "urgent" (срочно).

3. `substring-before(string, needle)`: Возвращает часть `string`, которая находится перед первым вхождением `needle`.
   - Пример: `substring-before(${full_name}, ' ')` извлекает первое слово (имя).

4. `substring-after(string, needle)`: Возвращает часть `string`, которая находится после первого вхождения `needle`.
   - Пример: `substring-after(${email}, '@')` извлекает доменную часть адреса электронной почты.

5. `normalize-space(string)`: Удаляет начальные и конечные пробелы и объединяет все внутренние последовательности пробелов в один пробел.
   - Пример: `normalize-space(${name})` — очищает имя, которое могло быть введено с лишними пробелами.

6. `translate(string, search_chars, replace_chars)`: Заменяет каждый символ в `string`, который появляется в `search_chars`, соответствующим символом из `replace_chars`. Символы в `search_chars`, для которых нет соответствующего символа в `replace_chars`, удаляются.
   - Пример: `translate(${code}, 'abcdefghijklmnopqrstuvwxyz', 'ABCDEFGHIJKLMNOPQRSTUVWXYZ')` преобразует в верхний регистр (эквивалентно `upper()`).
   - Пример: `translate(${phone}, ' -()', '')` удаляет пробелы, тире и скобки из номера телефона.

### Дополнительные математические функции

1. `floor(number)`: Возвращает наибольшее целое число, меньшее или равное `number` (округление в сторону отрицательной бесконечности).
   - Пример: `floor(4.9)` = 4, `floor(-2.1)` = -3

2. `ceiling(number)`: Возвращает наименьшее целое число, большее или равное `number` (округление в сторону положительной бесконечности).
   - Пример: `ceiling(4.1)` = 5, `ceiling(-2.9)` = -2

3. `random()`: Возвращает случайное десятичное число в диапазоне от 0.0 (включительно) до 1.0 (исключительно). Обычно используется в полях `calculate` для присвоения случайных значений или рандомизации порядка вопросов.
   - Пример: `random()` → например, `0.7341`
   - Пример: `int(random() * 6) + 1` → случайное число от 1 до 6 (бросок кубика).

4. `coalesce(a, b)`: Возвращает `a`, если `a` не пустое; в противном случае возвращает `b`. Полезно в качестве запасного варианта, когда поле может быть пустым.
   - Пример: `coalesce(${preferred_name}, ${full_name})` — использовать предпочитаемое имя, если оно задано, в противном случае использовать полное имя.

5. `once(value)`: Вычисляет `value` и сохраняет его, но только если текущее поле **пусто**. Если поле уже имеет значение (например, было установлено ранее), `once()` возвращает существующее значение без изменений. Это предотвращает перезапись введенных пользователем данных при пересчете.
   - Пример: `once(today())` в столбце `default` устанавливает сегодняшнюю дату один раз и не обновляет ее, если интервьюер снова открывает форму.
   - Пример: `once(uuid())` генерирует UUID один раз и сохраняет его стабильным при повторном редактировании.

### Гео-функции

1. `area(geoshape_value)`: Вычисляет **площадь в квадратных метрах**, ограниченную значением `geoshape` (многоугольник).
   - Параметром является значение поля geoshape в формате `lat1 lon1 0 0; lat2 lon2 0 0; ...`
   - Пример: `area(${field_boundary})` — вычислить площадь обследуемого поля в м².
   - Пример: `round(area(${field_boundary}) div 10000, 2)` — перевести в гектары.

2. `distance(coordinates)`: Вычисляет **общую длину пути в метрах** для `geotrace` (линия) или расстояние между двумя точками `geopoint`.
   - Для geotrace: `distance(${route})` возвращает общую длину пути в метрах.
   - Для двух geopoints: `distance(concat(${point_a}, ' ', ${point_b}))` возвращает расстояние между ними.
   - Пример: `round(distance(${road_trace}) div 1000, 3)` — длина дороги в километрах.

### Функции валидации

1. `regex(value, pattern)`: Возвращает `true`, если `value` соответствует регулярному выражению `pattern`. Используйте в столбце `constraint` для валидации на основе шаблонов.
   - Шаблон использует стандартный синтаксис регулярных выражений (POSIX ERE subset).
   - Пример: `regex(., '^[0-9]{10}$')` — валидация 10-значного числа.
   - Пример: `regex(., '^[A-Z]{2}[0-9]{6}$')` — валидация формата номера паспорта (2 заглавные буквы, за которыми следуют 6 цифр).
   - Пример: `regex(., '^[^@]+@[^@]+\.[^@]{2,}$')` — базовая проверка формата электронной почты.

2. `checklist(min, max, v1, v2, ...)`: Вычисляет список булевых выражений и возвращает `true`, если количество значений `true` находится между `min` и `max` (включительно). Передайте `-1` для `min` или `max`, чтобы пропустить эту границу.
   - Пример: `checklist(2, 3, ${q1} = 'yes', ${q2} = 'yes', ${q3} = 'yes')` — проходит, если ровно 2 или 3 из трех условий верны.
   - Пример: `checklist(1, -1, ${smoke_alarm}, ${fire_ext}, ${emergency_plan})` — хотя бы одна мера безопасности должна быть верна.

3. `weighted-checklist(min, max, v1, w1, v2, w2, ...)`: Аналогично `checklist()`, но каждое значение имеет вес. Сумма весов для значений `true` должна быть между `min` и `max`.
   - Пример: `weighted-checklist(10, -1, ${has_toilet}, 4, ${has_sink}, 3, ${has_shower}, 5)` — сумма весов имеющихся удобств должна быть не менее 10.

### Вспомогательные функции

1. `uuid()`: Генерирует случайный UUID (формат RFC 4122 v4) в виде строки.
   - Пример: `uuid()` → `'a3f8b2c1-4d5e-6f7a-8b9c-0d1e2f3a4b5c'`
   - Обычно используется с `once()` для генерации стабильного уникального идентификатора: `once(uuid())`

2. `version()`: Возвращает значение атрибута `version` формы, заданное на листе settings.
   - Пример: `version()` → `'3.1'`
   - Полезно в полях `calculate` для встраивания версии формы в экспортируемые данные.

3. `position()`: При вызове внутри **группы повторения** возвращает индекс текущего экземпляра повторения (начиная с 1).
   - Пример: `position()` в первом экземпляре вернет `1`, во втором — `2` и так далее.
   - См. также: `index()` (псевдоним), `indexed-repeat()` для ссылки на значения повторов извне группы.

4. `thousandsep(length, separator, value)`: Форматирует число с разделителем тысяч. `length` — это минимальная общая длина строки (дополняется пробелами, если короче), `separator` — используемый символ (например, `','`), а `value` — форматируемое число.
   - Пример: `thousandsep(0, ',', 1234567)` → `'1,234,567'`
   - Пример: `thousandsep(0, '.', ${income})` → форматирует доход с точкой в качестве разделителя тысяч.

5. `substr-jsonpath(value, jsonpath)`: Извлекает значение из строки JSON с помощью выражения JSONPath.
   - `value` должно быть строкой JSON (например, поле, в котором хранится необработанный ответ API с использованием `callapi(..., 'json:', ...)`).
   - `jsonpath` — это выражение JSONPath (например, `'$.data.name'`, `'$.items[0].id'`).
   - Всегда возвращает **строку** — оберните в `number()` при использовании в арифметических операциях.
   - Возвращает пустую строку `''`, если путь не найден или `value` не является допустимым JSON.
   - Пример: `substr-jsonpath(${api_response}, '$.data.name')` — извлечь поле `name`.
   - Пример: `substr-jsonpath(${api_response}, '$.items[0].label')` — первый элемент массива.
   - Пример: `number(substr-jsonpath(${api_response}, '$.price'))` — извлечь числовое значение.
   - Обычно используется вместе с `callapi(..., 'json:', ...)` для извлечения нескольких полей из одного ответа API. См. [Извлечение нескольких значений из одного вызова API](../advanced-features/call-api#fetching-multiple-values-from-one-api-call).

Тип вопроса note в XLSForm и rtSurvey используется для отображения текста или медиафайлов только для чтения. Это не вопрос, требующий ответа, а способ предоставить информацию, инструкции или контекст в рамках опроса.

## Базовая спецификация XLSForm

| type | name | label |
|------|------|-------|
| note | info_text | Этот опрос посвящён вашим читательским привычкам. |

Дополнительную информацию о базовом типе вопроса note см. в [спецификации XLSForm](https://xlsform.org/en/#question-types).

## Применение

Вопросы типа note обычно используются для:

1. Предоставления инструкций или контекста для предстоящих вопросов
2. Отображения вычисленных результатов или сводок
3. Показа изображений или других медиафайлов
4. Разделения разделов опроса
5. Предоставления обратной связи на основе предыдущих ответов

## Лучшие практики

1. Держите текст заметки кратким и понятным для поддержания вовлечённости респондентов.
2. Используйте форматирование (жирный, курсив) для выделения важной информации.
3. Рассмотрите использование медиафайлов (изображения, аудио) для улучшения понимания, когда это уместно.
4. Используйте заметки экономно, чтобы не перегружать опрос.

## Пример использования

Ниже приведён пример использования вопросов типа note в опросе:

| type | name | label |
|------|------|-------|
| note | intro | Добро пожаловать в наш опрос о читательских привычках. Мы зададим вопросы о ваших предпочтениях и частоте чтения. |
| ... | ... | ... |
| calculate | books_per_month | `${fiction_books}` + `${non_fiction_books}` |
| note | reading_summary | Вы читаете приблизительно `${books_per_month}` книг в месяц. |

В этом примере заметки используются для введения опроса и предоставления сводки вычисленных результатов.

## Расширения rtSurvey

rtSurvey может предлагать дополнительные функции для вопросов типа note:

1. Форматирование насыщенного текста
2. Поддержка встроенных медиафайлов (изображения, аудио, видео)
3. Динамическое содержимое на основе предыдущих ответов
4. Пользовательские параметры стиля

## Расширенное использование

### Условное отображение

Можно использовать выражения релевантности для условного отображения заметок:

| type | name | label | relevant |
|------|------|-------|----------|
| note | high_reader_note | Вы заядлый читатель! | `${books_per_month}` > 5 |

### Включение вычислений

Заметки могут включать вычисления для предоставления динамической обратной связи:

| type | name | label |
|------|------|-------|
| note | reading_time | Судя по вашим ответам, вы тратите примерно `${books_per_month * 5}` часов на чтение в месяц. |

## Ограничения

- Заметки не собирают данные, поэтому их не следует использовать, когда нужно получить информацию от респондентов.
- Чрезмерное использование заметок может сделать опрос загроможденным или слишком длинным.
- Некоторые расширенные варианты форматирования или медиафайлов могут не поддерживаться на всех устройствах или платформах.

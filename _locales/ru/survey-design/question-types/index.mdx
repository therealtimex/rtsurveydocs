rtSurvey поддерживает все стандартные типы вопросов XLSForm, а также ряд расширений. Каждый тип вопроса определяет, какие данные собираются и как отображается виджет ввода на устройстве.

Для установки типа вопроса введите имя типа в столбце `type` листа **survey** XLSForm.

## Текстовый ввод

| Тип | Описание |
|-----|----------|
| [text](text) | Свободный текстовый ответ — допускаются любые символы |
| [integer](integer) | Целое число (без дробной части) |
| [decimal](decimal) | Число с дробной частью |
| [range](range) | Число, выбранное с помощью ползунка в заданном диапазоне min/max |

## Выбор

| Тип | Описание |
|-----|----------|
| [select_one listname](select-one) | Выбор ровно одного варианта из списка |
| [select_multiple listname](select-multiple) | Выбор одного или нескольких вариантов из списка |
| [select_one_from_file filename](select-one-from-file) | Выбор одного варианта из внешнего CSV-файла |
| [rank listname](rank) | Упорядочивание вариантов по предпочтению или приоритету |

## Дата и время

| Тип | Описание |
|-----|----------|
| [date](date) | Календарная дата (год, месяц, день) |
| [time](time) | Время суток (часы, минуты) |
| [datetime](datetime-date-time) | Объединённые дата и время |

## Местоположение

| Тип | Описание |
|-----|----------|
| [geopoint](geopoint) | Одна GPS-координата (широта, долгота, высота, точность) |
| [geotrace](geotrace) | Путь — серия GPS-точек, образующих линию |
| [geoshape](geoshape) | Область — замкнутый полигон из GPS-точек |

## Медиафайлы

| Тип | Описание |
|-----|----------|
| [image](image) | Захват фото или загрузка изображения |
| [audio](audio) | Запись аудио |
| [video](video) | Запись видео |
| [file](file) | Загрузка общего файла (PDF, документ и т.д.) |

## Прочее

| Тип | Описание |
|-----|----------|
| [barcode](barcode) | Сканирование штрихкода или QR-кода |
| [note](note) | Отображаемый только для чтения текст — инструкции или вычисленные сводки |
| [calculate](calculate) | Скрытое поле, хранящее вычисленное значение |
| [hidden](hidden) | Скрытое поле, хранящее статическое или предзаполненное значение |
| [trigger / acknowledge](trigger) | Флажок, который перечислитель должен отметить, подтверждая прочтение утверждения |
| [meta](meta) | Автоматические метаданные: временные метки, ID устройства, данные перечислителя |

## Как тип и внешний вид работают вместе

`type` определяет **какие данные собираются**. Столбец `appearance` управляет **тем, как выглядит виджет**. Многие типы поддерживают несколько вариантов внешнего вида — например, `select_one` может отображаться как переключатели, выпадающий список, шкала Лайкерта или компактная сетка.

Полный список вариантов см. в разделе [Внешний вид](../appearance).

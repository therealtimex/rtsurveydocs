Тип вопроса `calculate` незаметно выполняет формулу в фоновом режиме. Он сохраняет результат в именованном поле, на которое могут ссылаться другие вопросы, но не показывает интервьюеру никаких полей ввода или меток. Используйте его для вычисления значений, объединения строк, выполнения условной логики или поиска данных, которые понадобятся вам позже в форме.

---

## Базовый синтаксис

| type | name | label | calculation |
|------|------|-------|-------------|
| calculate | total | | `${price} * ${quantity}` |

- **type**: Всегда `calculate`.
- **name**: Уникальное имя поля. Другие вопросы ссылаются на него с помощью `${name}`.
- **label**: Оставьте пустым — поля calculate никогда не показываются интервьюеру.
- **calculation**: Формула для вычисления. Поддерживает все [функции XLSForm](../operators-and-functions/functions) и ссылки на поля.

## Распространенные шаблоны

### Арифметика

| type | name | label | calculation |
|------|------|-------|-------------|
| integer | price | Unit price | |
| integer | quantity | Quantity | |
| calculate | total | | `${price} * ${quantity}` |
| note | total_note | Total: `${total}` | |

### Объединение строк (Конкатенация)

| type | name | label | calculation |
|------|------|-------|-------------|
| text | first_name | First name | |
| text | last_name | Last name | |
| calculate | full_name | | `concat(${first_name}, ' ', ${last_name})` |

### Условное значение

| type | name | label | calculation |
|------|------|-------|-------------|
| integer | score | Score (0–100) | |
| calculate | grade | | `if(${score} >= 90, 'A', if(${score} >= 75, 'B', if(${score} >= 60, 'C', 'F')))` |

### Возраст по дате рождения

| type | name | label | calculation |
|------|------|-------|-------------|
| date | dob | Date of birth | |
| calculate | age_years | | `int((today() - ${dob}) div 365.25)` |

## Использование `once()` для фиксации значения

По умолчанию `calculate` пересчитывается всякий раз, когда меняется любое поле, на которое дается ссылка. Оберните формулу в `once()`, чтобы она вычислялась только при первой загрузке и результат фиксировался:

| type | name | label | calculation |
|------|------|-------|-------------|
| calculate | interview_start | | `once(now())` |

Используйте `once()` для меток времени, начальных значений или любых случаев, когда пересчет при изменении нежелателен.

## Извлечение данных из внешних источников

### Из CSV-файла

```
pulldata('staff.csv', 'department', 'name', ${staff_id})
```

Полный справочник см. в разделе [pulldata()](../operators-and-functions/pulldata).

### Из встроенной базы данных SQLite

```
pulldata('rawquery',
  concat(${family_path}, '/locations.db::provinces'),
  'SELECT name FROM provinces WHERE id = ?',
  ${province_id})
```

Подробности о построении путей см. в разделе [Поиск в локальной базе данных](../advanced-features/local-database-search).

### Из контекста приложения

```
pulldata('app-api', 'user.username')
pulldata('app-api', 'family_path')
```

Все доступные ключи см. в разделе [App API](../app-api).

## Использование calculate в relevant и constraint

Другие поля могут ссылаться на результат `calculate` так же, как и на любое другое поле:

| type | name | label | relevant | constraint |
|------|------|-------|----------|------------|
| calculate | bmi | | | `${weight} div (${height} * ${height}) * 10000` |
| note | bmi_warning | BMI is very high — please verify weight and height. | `${bmi} > 40` | |

## Лучшие практики

1. Дайте полям calculate осмысленные имена — `total_cost` понятнее, чем `calc1`, и его легче отследить при экспорте.
2. Разбейте сложные формулы на несколько связанных полей calculate вместо одного глубоко вложенного выражения.
3. Используйте `once()` для меток времени и начальных моментальных снимков, чтобы значения не менялись после первого получения.
4. Размещайте поля `calculate` перед первым вопросом, который на них ссылается — порядок вычисления соответствует порядку в форме.
5. Оставьте столбец `label` пустым. Некоторые инструменты отображают метку; если оставить ее пустой, это поможет избежать путаницы в выводе.

## Ограничения

- Поля calculate никогда не отображаются интервьюеру напрямую — используйте поле `note` для отображения результата.
- Столбец `calculation` обязателен; строка `calculate` без формулы всегда сохраняет пустую строку.
- Результаты пересчитываются при каждом изменении формы, если они не обернуты в `once()` — очень сложные формулы в больших формах могут повлиять на производительность рендеринга на бюджетных устройствах.
- Вычисленные значения сохраняются в отправке как строки. Используйте `number()`, `int()` или `boolean()` для приведения типов при передаче результата в арифметические или логические выражения.

Эта страница описывает продвинутые шаблоны для работы с группами повторов в rtSurvey. Основные сведения о настройке групп повторов см. в разделе [Группировка и повторы](../repeats).

---

## Динамическое количество повторов

По умолчанию интервьюер сам решает, сколько раз повторить группу. Вы можете зафиксировать количество повторов с помощью `repeat_count`:

| type | name | label | repeat_count |
|------|------|-------|--------------|
| begin_repeat | household_members | Член домохозяйства | `${num_members}` |
| text | member_name | Имя члена | |
| integer | member_age | Возраст | |
| end_repeat | | | |

Повтор будет выполнен ровно `${num_members}` раз, где `num_members` — значение, собранное ранее в форме. Интервьюер не сможет добавлять или удалять итерации.

---

## Индексированный доступ: `indexed-repeat()`

Вы можете получить доступ к значению поля конкретной итерации повтора **извне** группы повторов, используя функцию `indexed-repeat(repeatedField, repeatGroup, index)`:

| type | name | label | calculation |
|------|------|-------|-------------|
| calculate | first_name | | `indexed-repeat(${member_name}, ${household_members}, 1)` |
| calculate | second_name | | `indexed-repeat(${member_name}, ${household_members}, 2)` |

Это полезно для создания сводных полей или обращения к данным «основного» члена после завершения цикла повторов.

---

## Позиция текущей итерации: `index()`

Внутри группы повторов функция `index()` возвращает порядковый номер текущей итерации (начиная с 1). Используйте её для маркировки каждого повтора или создания уникальных идентификаторов:

| type | name | label |
|------|------|-------|
| begin_repeat | plots | Участок |
| note | plot_label | Номер участка `${index()}` |
| text | plot_id | ID участка |
| end_repeat | | |

---

## Ссылка на поля в той же итерации

Внутри повтора используйте `${fieldname}` для ссылки на другое поле **в той же итерации**. Внутри одного цикла нет необходимости использовать `indexed-repeat()`:

| type | name | label | relevant |
|------|------|-------|----------|
| begin_repeat | members | Член | |
| text | member_name | Имя | |
| integer | member_age | Возраст | |
| text | school_name | Название школы | `${member_age} < 18` |
| end_repeat | | | |

---

## Ссылка на родительские поля изнутри повтора

На поля, находящиеся вне группы повторов (выше неё), можно ссылаться обычным способом через `${fieldname}`:

| type | name | label |
|------|------|-------|
| text | village | Название деревни |
| begin_repeat | plots | Сельскохозяйственный участок |
| note | plot_context | Участки в населенном пункте `${village}` |
| end_repeat | | |

## Суммирование данных повторов

Используйте агрегатные функции повторов **вне** группы повторов для подведения итогов:

| Function | Example | Description |
|----------|---------|-------------|
| `count(group)` | `count(${household_members})` | Количество итераций |
| `sum(field)` | `sum(${loan_amount})` | Сумма числового поля |
| `min(field)` | `min(${member_age})` | Минимальное значение |
| `max(field)` | `max(${member_age})` | Максимальное значение |
| `join(sep, field)` | `join(', ', ${member_name})` | Список через запятую |
| `count-if(group, expr)` | `count-if(${members}, ${member_age} < 18)` | Количество по условию |
| `sum-if(field, expr)` | `sum-if(${loan_amount}, ${loan_amount} > 500)` | Сумма по условию |
| `join-if(sep, field, expr)` | `join-if(', ', ${name}, ${age} >= 18)` | Объединение по условию |

### Пример: Сводка по домохозяйству

| type | name | label | calculation |
|------|------|-------|-------------|
| integer | num_members | Сколько человек в семье? | |
| begin_repeat | members | Член семьи | `${num_members}` |
| text | member_name | Имя | |
| integer | member_age | Возраст | |
| end_repeat | | | |
| calculate | total_members | | `count(${members})` |
| calculate | children_count | | `count-if(${members}, ${member_age} < 18)` |
| calculate | adult_names | | `join-if(', ', ${member_name}, ${member_age} >= 18)` |
| note | summary | Всего: `${total_members}`; Детей до 18: `${children_count}`. Взрослые: `${adult_names}` | |

## Вложенные повторы

Группа повторов может содержать другую группу повторов. Используйте это с осторожностью — вложенные повторы усложняют форму и могут запутать интервьюеров.

| type | name | label |
|------|------|-------|
| begin_repeat | households | Домохозяйство |
| text | hh_id | ID домохозяйства |
| begin_repeat | hh_members | Член семьи |
| text | member_name | Имя члена |
| end_repeat | | |
| end_repeat | | |

Чтобы сослаться на поле внешнего повтора из внутреннего, используйте `${fieldname}` — поиск будет идти до ближайшего подходящего предка:

Внутри повтора `hh_members` выражение `${hh_id}` вернет ID **текущего** домохозяйства, а не список всех ID.

## Ранг внутри групп повторов: `rank-index()`

Если внутри повтора есть поле типа `rank`, используйте `rank-index(instanceNumber, repeatedField)` извне, чтобы получить порядковый номер (индекс) конкретной итерации по рангу:

| type | name | label | calculation |
|------|------|-------|-------------|
| calculate | top_scorer | | `rank-index(1, ${score})` |

`rank-index(1, ${score})` возвращает индекс итерации с наивысшим баллом.

## Внешний вид `1screen` для `begin_repeat`

Добавление `1screen` в колонку `appearance` строки `begin_repeat` позволяет отображать все вопросы каждой итерации вместе на одном экране, вместо того чтобы показывать по одному вопросу на экран.

| type | name | label | appearance |
|------|------|-------|------------|
| begin_repeat | household_members | Член домохозяйства | `1screen` |
| text | member_name | Имя члена | |
| integer | member_age | Возраст | |
| end_repeat | | | |

Если установлено `1screen` и в группе отсутствуют поля `repeat_count` и `add_repeat`, rtSurvey автоматически отображает круглую кнопку **+** в нижней части экрана, чтобы интервьюеры могли добавлять новые итерации без дополнительной настройки.

| Appearance | Один экран на итерацию | Кнопка «+» по умолчанию |
|------------|-------------------------|------------------------|
| `1screen` | Да | Да (если нет дочернего `add_repeat`) |
| `field-list` | Да | Нет |

Используйте `field-list`, если вам нужна группировка на одном экране, но без автоматической кнопки добавления. Используйте `1screen`, если вам нужна и группировка, и встроенный способ добавления итераций.

## Настраиваемая кнопка добавления `add_repeat`

Поле типа `note` (или `text`), размещенное **внутри** группы повторов с `appearance: add_repeat`, отображается как кнопка «Добавить» во всю ширину экрана. Текст кнопки берется из колонки `label` этого поля. Если поле `add_repeat` присутствует, стандартная круглая кнопка «+» (от `1screen`) скрывается.

Разместите поле `add_repeat` последним внутри группы повторов:

| type | name | label | appearance |
|------|------|-------|------------|
| begin_repeat | members | Член семьи | `1screen` |
| text | member_name | Имя члена | |
| integer | member_age | Возраст | |
| note | btn_add | + Добавить члена семьи | `add_repeat` |
| end_repeat | | | |

### Настройка цвета

Вы можете задать цвет кнопки в значении `appearance`:

| Appearance value | Result |
|------------------|--------|
| `add_repeat <#04B404/>` | Зеленый фон, стандартный цвет текста |
| `add_repeat 04B404-ffffff` | Зеленый фон, белый текст |

Первый цвет — фон, второй (после дефиса) — текст. Опускайте символ `#` при использовании формата с дефисом.

### Вариант с иконкой

Используйте `add_repeat icon` (через пробел), чтобы вместо широкой кнопки отобразить компактную круглую кнопку с иконкой:

| type | name | label | appearance |
|------|------|-------|------------|
| note | btn_add | + Добавить | `add_repeat icon` |

## Кнопки удаления: `delete-repeat-current` и `delete-repeat-last`

Поле типа `note` внутри группы повторов с `appearance: delete-repeat-current` или `appearance: delete-repeat-last` отображается как комбинированная кнопка удаления.

| Appearance | Action |
|------------|--------|
| `delete-repeat-current` | Удаляет текущую (активную) итерацию |
| `delete-repeat-last` | Удаляет последнюю итерацию в группе |

Стандартная кнопка (без иконки) является комбинированной: иконка корзины слева и текст метки поля справа, на всю ширину экрана.

### Вариант с иконкой

Добавьте суффикс `-icon`, чтобы получить компактную круглую кнопку с иконкой корзины:

| Appearance | Result |
|------------|--------|
| `delete-repeat-current-icon` | Круглая иконка корзины, удаляет текущую итерацию |
| `delete-repeat-last-icon` | Круглая иконка корзины, удаляет последнюю итерацию |

### Настройка цвета

Формат цвета идентичен `add_repeat`: используйте `<#RRGGBB/>` или `RRGGBB-RRGGBB` (фон-текст).

### Пример полного шаблона

Следующий повтор использует `1screen`, круглую кнопку удаления текущей итерации сверху и широкую кнопку добавления снизу:

| type | name | label | appearance |
|------|------|-------|------------|
| begin_repeat | members | Член семьи | `1screen` |
| note | btn_del | Удалить | `delete-repeat-current-icon` |
| text | member_name | Имя члена | |
| integer | member_age | Возраст | |
| note | btn_add | + Добавить члена семьи | `add_repeat` |
| end_repeat | | | |

## Лучшие практики

1. Всегда используйте `repeat_count`, если количество повторов известно заранее — это предотвратит случайное добавление или удаление итераций интервьюером.
2. Делайте группы повторов лаконичными — повторы с 20+ вопросами на итерацию сложны для навигации.
3. Давайте группам повторов понятные имена (например, `household_members`, а не `repeat1`) — имя будет использоваться в функциях и при экспорте данных.
4. Тестируйте форму с максимально ожидаемым количеством итераций для проверки производительности.
5. Используйте `1screen` в `begin_repeat`, чтобы показывать все вопросы на одном экране на каждую итерацию, в сочетании с полем `add_repeat` внутри группы для создания четко подписанной кнопки «Добавить».

## Ограничения

- `indexed-repeat()` требует корректного индекса (от 1 до общего числа итераций) — выход за пределы диапазона вернет пустое значение.
- Вложенность повторов более 2 уровней не рекомендуется и может вызвать проблемы с отображением в некоторых клиентах.
- Агрегатные функции (`sum`, `count` и т.д.) работают со всей группой повторов — вы не можете агрегировать подмножество итераций без использования `*-if` вариантов.

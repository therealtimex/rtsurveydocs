description: "Используйте значения оформления SaveFinalizedExit и SaveIncompleteExit для отображения стилизованных кнопок выхода, которые сохраняют данные и закрывают форму."
---

**Элементы управления навигацией в форме** — это значения оформления, размещаемые в полях типа `note` (или `text`), которые отображаются в виде стилизованных кнопок во всю ширину в нижней части опроса. Они позволяют интервьюеру сохранить отправленные данные и выйти из формы одним касанием — либо как завершенную (финализированную) запись, либо как черновик (незавершенную запись).

---

## `SaveFinalizedExit<#COLOR/>`

Отображает кнопку, которая **сохраняет отправку как завершенную** и закрывает форму. Текст кнопки берется из столбца `label` этого поля.

| XLSForm column | Значение |
|----------------|-------|
| `type` | `note` |
| `name` | любое уникальное имя (например, `btn_finish`) |
| `label` | текст, отображаемый на кнопке |
| `appearance` | `SaveFinalizedExit<#RRGGBB/> toc-hide` |

Отправка помечается как окончательная, полная запись. Это эквивалентно нажатию на встроенную кнопку отправки.

---

## `SaveIncompleteExit<#COLOR/>`

Отображает кнопку, которая **сохраняет отправку как незавершенную (черновик)** и закрывает форму. Интервьюер может вернуться к ней позже и продолжить заполнение.

| XLSForm column | Значение |
|----------------|-------|
| `type` | `note` |
| `name` | любое уникальное имя (например, `btn_pause`) |
| `label` | текст, отображаемый на кнопке |
| `appearance` | `SaveIncompleteExit<#RRGGBB/> toc-hide` |

---

## Синтаксис цвета

Оба оформления принимают встроенный цвет в формате `<#RRGGBB/>`:

- `#`, за которым следует ровно **6 шестнадцатеричных цифр** (в верхнем или нижнем регистре)
- Закрывающая часть `/>` **обязательна** — ее отсутствие нарушает синтаксический анализ
- Пример: `<#04B404/>` (зеленый), `<#EDC602/>` (янтарный), `<#D9534F/>` (красный)

Цвет управляет фоном кнопки. Цвет текста определяется приложением автоматически.

---

## Пример

Следующие два поля, помещенные в конце формы, создают зеленую кнопку **Отправить** и янтарную кнопку **Сохранить как черновик**:

| type | name | label | appearance |
|------|------|-------|------------|
| note | btn_finish | Отправить | `SaveFinalizedExit<#04B404/> toc-hide` |
| note | btn_pause | Сохранить как черновик | `SaveIncompleteExit<#EDC602/> toc-hide` |

---

## toc-hide — исключение кнопок из оглавления

Токен оформления `toc-hide` сообщает rtSurvey о необходимости исключить поле из **оглавления** формы (общего списка вопросов). Кнопки навигации не являются вопросами, поэтому они никогда не должны отображаться в оглавлении.

Всегда добавляйте `toc-hide` после оформления выхода:

```
SaveFinalizedExit<#04B404/> toc-hide
SaveIncompleteExit<#EDC602/> toc-hide
```

См. [Оформление — toc-hide](../appearance#group-and-navigation) для справки по toc-hide.

## Правила размещения

При добавлении элементов управления навигацией в форму соблюдайте следующие правила:

- Размещайте обе кнопки в **самом конце** формы, после всех вопросов и групп.
- Всегда включайте **обе** кнопки вместе — одну для завершения и одну для черновика — чтобы у интервьюера всегда была возможность выйти независимо от состояния заполнения.
- Используйте столбец `relevant` для кнопки финализированного выхода, если отправка должна быть разрешена только при выполнении определенных условий (например, завершен обязательный раздел). Кнопка выхода для черновика обычно должна оставаться **всегда видимой**.

---

## Условный финализированный выход

Используйте столбец `relevant` для управления отображением кнопки финализированного выхода. Выход для черновика должен оставаться безусловно видимым, чтобы интервьюер всегда мог прерваться и вернуться.

| type | name | label | appearance | relevant |
|------|------|-------|------------|----------|
| note | btn_finish | Отправить | `SaveFinalizedExit<#04B404/> toc-hide` | `${consent} = 'yes' and ${section_a_complete} = '1'` |
| note | btn_pause | Сохранить как черновик | `SaveIncompleteExit<#EDC602/> toc-hide` | |

В этом примере кнопка **Отправить** появляется только тогда, когда интервьюер дал согласие и пометил раздел А как завершенный. Кнопка **Сохранить как черновик** доступна всегда.

---

## Ограничения

- **Тип поля должен быть `note` или `text`.** Использование этого оформления для любых других типов вопросов не поддерживается.
- **Только 6-значный шестнадцатеричный код.** Сокращенный шестнадцатеричный код (`<#FFF/>`) и именованные цвета не поддерживаются — всегда используйте полный 6-значный формат (например, `<#FFFFFF/>`).
- **Столбец label — это текст кнопки.** Столбец `hint` для этих полей игнорируется; отображается только `label`.
- **Должны присутствовать обе кнопки.** Отсутствие кнопки выхода для черновика лишает интервьюера возможности сделать паузу в середине формы.

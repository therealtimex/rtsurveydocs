import { Callout } from 'nextra/components'

`family_path` — это условное поле типа calculate, которое содержит путь к директории медиафайлов, упакованных вместе с формой. Любая форма, выполняющая поиск в локальной базе данных с помощью `rawquery`, `pulldata` или `search()`, должна включать это поле. Без него пути к файлам не могут быть разрешены, и результаты поиска будут всегда пустыми.

---

## Поле calculate

Добавьте эту строку в верхней части вашего листа survey, после мета-полей и перед первым вопросом, использующим файл базы данных:

| type | name | label | calculation |
|---|---|---|---|
| calculate | `family_path` | | `pulldata('app-api', 'family_path')` |

Поле не хранит видимого значения и не требует метки (label). Оно является неявным обязательным условием для всех последующих конструкций путей.

---

## Почему это необходимо

RTSurvey упаковывает медиафайлы формы — базы данных SQLite, изображения, аудиоклипы — в отдельную директорию для каждой формы на устройстве. Точный путь различается в зависимости от платформы (Android, iOS, веб) и устройства.

Во время выполнения приложение заполняет `family_path` автоматически. Типичное разрешенное значение выглядит так:

```
resources/familyMedia/Phuong_Person_Test
```

Поскольку путь зависит от платформы и определяется во время запуска, он не может быть жестко закодирован в форме. `pulldata('app-api', 'family_path')` — единственный надежный способ его получить.

---

## Как использовать его в путях

После определения `family_path` создайте полный путь к файлу с помощью `concat()`:

```
concat(${family_path}, '/file.db::tableName')
```

Суффикс `::tableName` отсекается, когда приложение открывает файл; имя таблицы используется только внутри вашего SQL-запроса.

---

## Где используется family_path

`family_path` требуется в аргументе пути каждый раз, когда вы ссылаетесь на файл, упакованный с формой:

- **Поиск в локальной базе данных** — аргумент `db_path` функции `search-autocomplete-noedit-v2('rawquery', ...)` должен быть построен с помощью `concat(${family_path}, ...)`. См. [Поиск в локальной базе данных](local-database-search) для получения подробной информации.
- **`pulldata` rawquery** — любой вызов `pulldata('rawquery', ...)`, который считывает данные из файла `.db`, использует тот же шаблон `concat()`.
- **`search()` с локальным файлом** — внешний вид (appearances) для динамического поиска, который загружает данные из упакованного CSV- или DB-файла, также зависит от `family_path` для ссылки на файл.

---

## Размещение в форме

`family_path` должен появиться **перед первым полем, которое ссылается на него**. Рекомендуемое расположение — сразу после мета-группы:

| type | name | label | calculation |
|---|---|---|---|
| begin_group | meta | | |
| deviceid | deviceid | | |
| start | start | | |
| end | end | | |
| end_group | | | |
| calculate | `family_path` | | `pulldata('app-api', 'family_path')` |
| select_one | province | Province | *(внешний вид rawquery, ссылающийся на `${family_path}`)* |

<Callout type="warning">
Если `family_path` отсутствует в форме или расположен после первого поля `rawquery` / `search()`, которое ссылается на него, все поиски по упакованным файлам будут возвращать пустые значения. Сообщение об ошибке не выводится — автозаполнение просто не показывает результатов.
</Callout>

---

## Несколько файлов базы данных

Одна форма может использовать несколько файлов `.db`. Каждый путь строится независимо с помощью `concat()`:

```
concat(${family_path}, '/locations.db::externalData')
concat(${family_path}, '/health_facilities.db::facilities')
concat(${family_path}, '/household_list.db::households')
```

Определите `family_path` один раз; ссылайтесь на него в любом количестве полей.

---

## Проверка во время разработки

Добавьте временное поле `note` под `family_path`, чтобы проверить разрешенное значение на устройстве:

| type | name | label | calculation |
|---|---|---|---|
| calculate | `family_path` | | `pulldata('app-api', 'family_path')` |
| note | family_path_check | `Path: ${family_path}` | |

В заметке будет отображаться фактический разрешенный путь во время тестирования. Удалите его перед развертыванием финальной версии формы.

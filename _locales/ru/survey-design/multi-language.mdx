rtSurvey обеспечивает надежную многоязычную поддержку, позволяя создавать опросы на нескольких языках. Эта функция имеет решающее значение для проведения исследований среди различных лингвистических групп населения или в многоязычной среде.

## Настройка многоязычных опросов

Чтобы создать многоязычный опрос в rtSurvey, вам необходимо добавить в форму XLSForm столбцы, специфичные для конкретного языка. Вот как это сделать:

1. **Переводы меток (Label Translations)**: Добавьте столбцы для каждого языка, используя формат `label::Language (code)`.
2. **Переводы подсказок (Hint Translations)**: Используйте `hint::Language (code)` для перевода подсказок.
3. **Переводы медиафайлов (Media File Translations)**: Для медиафайлов, специфичных для языка, используйте `media::Language (code)`.

Пример:

```
| type    | name | label::English (en) | label::Español (es) | hint::English (en) | hint::Español (es) |
|---------|------|---------------------|---------------------|---------------------|---------------------|
| integer | age  | How old are you?    | ¿Cuántos años tienes?| Enter your age      | Ingrese su edad     |
```

## Языковые коды

Рекомендуется использовать официальные 2-символьные языковые коды (субтеги) после названия языка. Это облегчает сопоставление языка формы с языком пользовательского интерфейса. Официальные коды можно найти [здесь](https://www.iana.org/assignments/language-subtag-registry/language-subtag-registry).

## Установка языка по умолчанию

Чтобы установить язык по умолчанию для сбора данных, используйте рабочий лист `settings` в вашей форме XLSForm:

```
| form_id   | version | default_language |
|-----------|---------|-------------------|
| test_form | 101     | French (fr)       |
```

## Функции, специфичные для rtSurvey

### Динамическое переключение языка

rtSurvey позволяет пользователям динамически переключать языки во время сбора данных:

- В веб-интерфейсе используйте выпадающий список языков в верхней навигационной панели.
- В мобильном приложении доступ к языковым настройкам осуществляется через меню настроек.

### Сообщения о валидации на конкретном языке

rtSurvey расширяет многоязычную поддержку на сообщения о валидации:

```
| type    | name | constraint | constraint_message::English (en) | constraint_message::Español (es) |
|---------|------|------------|----------------------------------|----------------------------------|
| integer | age  | . <= 150   | Age must be 150 or less          | La edad debe ser 150 o menos     |
```

### Локализованные сообщения об обязательности заполнения

Используйте `required_message::Language (code)`, чтобы показать переведенную ошибку, когда обязательное поле остается пустым:

```
| type | name | required | required_message::English (en) | required_message::Tiếng Việt (vi) |
|------|------|----------|-------------------------------|----------------------------------|
| text | name | yes | This field is required | Trường này là bắt buộc |
```

### Поддержка языков RTL

Для языков с письмом справа налево (RTL), таких как арабский или иврит, rtSurvey автоматически корректирует макет:

```
| type | name | label::English (en) | label::Arabic (ar) |
|------|------|---------------------|---------------------|
| text | name | Your name           | اسمк                |
```

### Внешний вид (Appearance), специфичный для языка

rtSurvey позволяет указывать различные типы внешнего вида для разных языков:

```
| type | name | label::English (en) | label::Chinese (zh) | appearance::English (en) | appearance::Chinese (zh) |
|------|------|---------------------|---------------------|--------------------------|---------------------------|
| text | address | Address          | 地址                 | multiline                | textarea                  |
```

## HTML-форматирование в двуязычных метках

Вы можете комбинировать HTML-теги с языковыми обертками (wrappers) в одной ячейке метки. rtSurvey извлекает блок активного языка и отрисовывает остальной HTML.

Пример использования жирного шрифта и цвета шрифта для каждого языка:

```
<en><big><b>Section 2: Household Income</b></big><br>Ask the household head only.</en><vi><big><b>Phần 2: Thu nhập hộ gia đình</b></big><br>Chỉ hỏi chủ hộ.</vi>
```

Поддерживаемые встроенные теги внутри языковых оберток: `<b>`, `<i>`, `<u>`, `<big>`, `<small>`, `<font color="...">`, `<br>`, `<span style="...">`.

Пример цветного текста для каждого языка:

```
<en><font color="red">Required field</font></en><vi><font color="red">Trường bắt buộc</font></vi>
```

## Вычисления с учетом языка (Language-aware calculations)

Если в форме есть поле `${language_use}` (устанавливаемое виджетом `change_language`), используйте `if()`, чтобы возвращать значения на активном языке:

```
if(${language_use} = 'en', label_en, label_vi)
```

Пример — отображение результата поиска на активном языке с помощью `pulldata('rawquery', ...)`:

```
| type      | name        | calculation                                                                 |
|-----------|-------------|-----------------------------------------------------------------------------|
| calculate | district_label | if(${language_use} = 'en', pulldata('rawquery', concat(${family_path}, '/locations.db::externalData'), 'SELECT label_en FROM externalData WHERE code = ?', ${district}), pulldata('rawquery', concat(${family_path}, '/locations.db::externalData'), 'SELECT label_vi FROM externalData WHERE code = ?', ${district})) |
```

Примечание: Поле `language_use` обычно устанавливается виджетом внешнего вида `change_language`. См. Appearance — change_language.

## Рекомендации по проведению многоязычных опросов

1. **Последовательное именование**: Используйте одинаковые языковые коды во всей форме.
2. **Профессиональный перевод**: Пользуйтесь услугами профессиональных переводчиков, знакомых с контекстом опроса.
3. **Контекстные примечания**: Предоставляйте переводчикам контекстные примечания для обеспечения точности перевода.
4. **Тестирование**: Протестируйте форму на всех языках перед развертыванием.
5. **Поддержка Unicode**: Убедитесь, что устройства для сбора данных поддерживают Unicode для нелатинских шрифтов.
6. **Медиафайлы для конкретных языков**: Используйте изображения или аудио, соответствующие культурным особенностям каждого языка.
7. **Избегайте текста на изображениях**: Если вы используете изображения с текстом, создайте отдельные изображения для каждого языка.

## Обработка особых случаев

### Ответы на разных языках

rtSurvey позволяет респондентам вводить текст на любом языке, независимо от выбранного языка формы. Это полезно для ввода имен или адресов на языке оригинала.

### Типы вопросов, специфичные для языка

Некоторые типы вопросов могут быть более подходящими для определенных языков. rtSurvey позволяет использовать различные типы вопросов для разных языков:

```
| type::English (en) | type::Japanese (ja) | name | label::English (en) | label::Japanese (ja) |
|--------------------|---------------------|------|---------------------|----------------------|
| text               | select_one kanji    | name | Enter your name     | 名前を選んでください    |
```

## Экспорт многоязычных данных

При экспорте данных из rtSurvey:

- Выберите экспорт на конкретном языке или включите все языковые версии.
- Языковые метаданные включаются в экспорт, указывая, какой язык использовался для каждого ответа.

## Рекомендации для мобильного приложения

- Мобильное приложение rtSurvey поддерживает переключение языков в автономном режиме.
- Перед переходом в автономный режим убедитесь, что все необходимые языковые файлы загружены.

## Известные ограничения

- Некоторые расширенные функции могут не быть доступны не на всех языках.
- Чрезвычайно длинные переводы могут повлиять на макет на экранах небольшого размера.

Используя многоязычные возможности rtSurvey, вы можете создавать инклюзивные, доступные опросы, охватывающие различные группы населения и предоставляющие высококачественные, лингвистически точные данные.

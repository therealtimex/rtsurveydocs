rtSurvey предоставляет надёжную многоязычную поддержку, позволяя создавать опросы на нескольких языках. Эта функция крайне важна для проведения исследований среди разнородных языковых групп или в многоязычной среде.

## Настройка многоязычных опросов

Для создания многоязычного опроса в rtSurvey необходимо добавить языковые столбцы в XLSForm:

1. **Переводы меток**: добавьте столбцы для каждого языка в формате `label::Language (code)`.
2. **Переводы подсказок**: используйте `hint::Language (code)` для перевода подсказок.
3. **Переводы медиафайлов**: для медиафайлов на конкретных языках используйте `media::Language (code)`.

Пример:

```
| type    | name | label::English (en) | label::Español (es) | hint::English (en) | hint::Español (es) |
|---------|------|---------------------|---------------------|---------------------|---------------------|
| integer | age  | How old are you?    | ¿Cuántos años tienes?| Enter your age      | Ingrese su edad     |
```

## Коды языков

Рекомендуется использовать официальные 2-символьные коды языков (подтеги) после названия языка. Это облегчает сопоставление языка формы с языком интерфейса пользователя. Официальные коды можно найти [здесь](https://www.iana.org/assignments/language-subtag-registry/language-subtag-registry).

## Установка языка по умолчанию

Для установки языка по умолчанию при сборе данных используйте рабочий лист `settings` в XLSForm:

```
| form_id   | version | default_language |
|-----------|---------|-------------------|
| test_form | 101     | French (fr)       |
```

## Функции rtSurvey

### Динамическое переключение языков

rtSurvey позволяет пользователям переключать языки в процессе сбора данных:

- В веб-интерфейсе используйте выпадающий список языков на верхней панели навигации.
- В мобильном приложении получите доступ к настройкам языка через меню настроек.

### Языковые сообщения валидации

rtSurvey расширяет многоязычную поддержку на сообщения валидации:

```
| type    | name | constraint | constraint_message::English (en) | constraint_message::Español (es) |
|---------|------|------------|----------------------------------|----------------------------------|
| integer | age  | . <= 150   | Age must be 150 or less          | La edad debe ser 150 o menos     |
```

### Поддержка языков с написанием справа налево (RTL)

Для языков с написанием справа налево (RTL), таких как арабский или иврит, rtSurvey автоматически корректирует макет:

```
| type | name | label::English (en) | label::Arabic (ar) |
|------|------|---------------------|---------------------|
| text | name | Your name           | اسمك                |
```

### Языковой внешний вид

rtSurvey позволяет задавать разный внешний вид для разных языков:

```
| type | name | label::English (en) | label::Chinese (zh) | appearance::English (en) | appearance::Chinese (zh) |
|------|------|---------------------|---------------------|--------------------------|---------------------------|
| text | address | Address          | 地址                 | multiline                | textarea                  |
```

## Лучшие практики для многоязычных опросов

1. **Согласованные обозначения**: используйте согласованные коды языков во всей форме.
2. **Профессиональный перевод**: привлекайте профессиональных переводчиков, знакомых с контекстом опроса.
3. **Контекстные пояснения**: предоставляйте переводчикам контекстные пояснения для точного перевода.
4. **Тестирование**: тестируйте форму на всех языках перед развёртыванием.
5. **Поддержка Unicode**: убедитесь, что устройства для сбора данных поддерживают Unicode для нелатинских шрифтов.
6. **Языковые медиафайлы**: используйте культурно подходящие изображения или аудиозаписи для каждого языка.
7. **Избегайте текста на изображениях**: если используете изображения с текстом, создайте отдельные изображения для каждого языка.

## Обработка особых случаев

### Ответы на смешанных языках

rtSurvey позволяет респондентам вводить текст на любом языке, независимо от выбранного языка формы. Это полезно для сбора имён или адресов на оригинальном языке.

### Языковые типы вопросов

Некоторые типы вопросов могут быть более подходящими для определённых языков. rtSurvey позволяет использовать разные типы вопросов для разных языков:

```
| type::English (en) | type::Japanese (ja) | name | label::English (en) | label::Japanese (ja) |
|--------------------|---------------------|------|---------------------|----------------------|
| text               | select_one kanji    | name | Enter your name     | 名前を選んでください    |
```

## Экспорт многоязычных данных

При экспорте данных из rtSurvey:

- Выберите экспорт на конкретном языке или включите все языковые версии.
- Метаданные языка включаются в экспорт, указывая, какой язык использовался для каждого ответа.

## Соображения для мобильного приложения

- Мобильное приложение rtSurvey поддерживает офлайн-переключение языков.
- Убедитесь, что все необходимые языковые файлы загружены до перехода в офлайн-режим.

## Известные ограничения

- Некоторые расширенные функции могут быть недоступны на всех языках.
- Очень длинные переводы могут влиять на макет на меньших экранах.

Используя многоязычные возможности rtSurvey, вы можете создавать инклюзивные, доступные опросы, охватывающие разнообразные группы населения и обеспечивающие высококачественные, лингвистически точные данные.

Столбец `appearance` в rtSurvey позволяет настраивать визуальное представление и поведение вопросов в ваших опросах. Эта функция улучшает пользовательский опыт и может значительно повысить эффективность сбора данных. rtSurvey поддерживает стандартные атрибуты внешнего вида XLSForm и расширяет их дополнительными опциями.

## Стандартные атрибуты внешнего вида XLSForm

rtSurvey поддерживает следующие стандартные атрибуты внешнего вида XLSForm:

| Атрибут внешнего вида | Типы вопросов | Описание |
|----------------------|----------------|-------------|
| multiline | text | Создает многострочное текстовое поле (лучше всего для веб-клиентов) |
| minimal | select_one, select_multiple | Отображает варианты выбора в выпадающем меню |
| quick | select_one | Автоматически переходит к следующему вопросу после выбора (только для мобильных устройств) |
| no-calendar | date | Отключает отображение календаря (только для мобильных устройств) |
| month-year | date | Позволяет выбирать только месяц и год |
| year | date | Позволяет выбирать только год |
| horizontal-compact | select_one, select_multiple | Отображает варианты выбора горизонтально (только для веб-интерфейса) |
| horizontal | select_one, select_multiple | Отображает варианты выбора горизонтально в колонках (только для веб-интерфейса) |
| likert | select_one | Представляет варианты выбора в виде шкалы Лайкерта |
| compact | select_one, select_multiple | Отображает варианты выбора рядом друг с другом с минимальными отступами |
| quickcompact | select_one | Сочетает компактное отображение с автоматическим переходом (только для мобильных устройств) |
| field-list | groups | Отображает всю группу на одном экране (только для мобильных устройств) |
| label | select_one, select_multiple | Показывает метки вариантов без полей ввода |
| list-nolabel | select_one, select_multiple | Показывает поля ввода без меток (используется вместе с `label`) |
| table-list | groups | Отображает вопросы в табличном формате |
| signature | image | Включает захват подписи (только для мобильных устройств) |
| draw | image | Позволяет рисовать от руки (только для мобильных устройств) |
| map, quick map | select_one, select_one_from_file | Позволяет делать выбор на основе объектов карты |

## Рекомендации по использованию внешнего вида

1. **Последовательность**: Используйте атрибуты внешнего вида последовательно во всем опросе для единообразия.
2. **Мобильные устройства против Веб**: Учитывайте, как внешний вид будет отображаться на разных устройствах и платформах.
3. **Производительность**: Будьте осторожны с атрибутами внешнего вида, которые могут замедлить загрузку формы (например, `table-list` для больших групп).
4. **Пользовательский опыт**: Выбирайте варианты внешнего вида, которые делают ввод данных более простым и интуитивно понятным для респондентов.
5. **Тестирование**: Всегда тестируйте форму на целевых устройствах, чтобы убедиться, что внешний вид работает должным образом.

## Расширенные техники

### Комбинирование атрибутов внешнего вида

Некоторые атрибуты внешнего вида можно комбинировать для создания более сложных макетов:

```
| type | name | label | appearance |
|------|------|-------|------------|
| select_one options | choice | Выберите один вариант: | minimal compact |
```

### Динамический внешний вид

rtSurvey позволяет динамически изменять внешний вид на основе логики формы:

```
| type | name | label | appearance | relevant |
|------|------|-------|------------|----------|
| text | time | Введите время: | inline-[%H:%M] | ${show_time} = 'yes' |
```

## Особенности мобильного приложения

- Некоторые атрибуты внешнего вида (например, `quick`, `signature`) специфичны для мобильных устройств.
- Тщательно тестируйте как на Android, так и на iOS для обеспечения стабильной работы.

## Расширенные атрибуты внешнего вида rtSurvey

В дополнение к стандартным возможностям XLSForm, rtSurvey поддерживает следующие специфические для платформы опции:

### Управление данными и отображением

| Атрибут внешнего вида | Типы вопросов | Описание |
|----------------------|----------------|-------------|
| `invisible` | any | Скрывает поле из вида, продолжая при этом собирать или вычислять его значение. Отличается от типа `hidden` — поле по-прежнему участвует в логике. |
| `displaytitle` | any | Принудительно отображает метку/заголовок поля, даже если они обычно скрыты. |
| `autopull` | select_one, select_multiple | Автоматически загружает внешние данные для заполнения вариантов выбора при загрузке формы или изменении триггерного поля. |
| `floating_hint` | text, integer, decimal | Отображает текст подсказки как всплывающую метку над полем ввода, а не под ним. |
| `calculate-button` | calculate | Добавляет видимую кнопку, которая запускает пересчет поля по запросу, а не автоматически. |

### Группы и навигация

| Атрибут внешнего вида | Типы вопросов | Описание |
|----------------------|----------------|-------------|
| `section` | group | Отображает группу как сворачиваемую карточку раздела. Примечание: только для мобильного приложения. |
| `toc-hide` | any | Исключает вопрос из панели навигации оглавления (TOC). |
| `minilog` | begin_repeat | Отображает завершенные записи повторов в виде компактного списка мини-логов, вместо развертывания каждой записи в строку. |

### Поведение ввода

| Атрибут внешнего вида | Типы вопросов | Описание |
|----------------------|----------------|-------------|
| `proper` | text | Автоматически делает заглавной первую букву каждого слова по мере ввода респондентом (поведение title-case). |
| `text-nolabel` | text, integer, decimal | Отображает поле ввода без видимой метки. |
| `inline-1line` | text | Принудительно отображает ввод текста в одну строку, даже если метка вопроса длинная. |
| `popup` | any | Отображает поле внутри всплывающего/модального окна, а не в строке на странице. |

### Макет

| Атрибут внешнего вида | Типы вопросов | Описание |
|----------------------|----------------|-------------|
| `1screen` | group | Принудительно отображает всю группу на одном экране независимо от размера группы. |
| `columns(n)` | select_one, select_multiple | Отображает варианты выбора в `n` колонках. Пример: `columns(3)` показывает три колонки радиокнопок. |
| `gridformat<row=R col=C colspan=S align=center>` | any | Позиционирует поле в макете CSS-grid в строке `R`, колонке `C`, занимая `S` колонок. Используется с `advanced-extension/grid-layout`. |
| `ignore-simplify` | any | Указывает рендереру формы пропустить автоматическое упрощение или уплотнение макета этого поля. |
| `horizontal(N)` | select_one, select_multiple | Устанавливает каждый вариант выбора так, чтобы он занимал `N` процентов ширины строки. Пример: `horizontal(50)` размещает два варианта в строке. |
| `scroll-view(N%)` | group, repeat | Ограничивает контейнер максимальной высотой `N%` от вьюпорта (или родителя), добавляя полосу прокрутки при переполнении контента. Пример: `scroll-view(60%)`. |

### Виджеты

| Атрибут внешнего вида | Типы вопросов | Описание |
|----------------------|----------------|-------------|
| `likert` | select_one | Представляет варианты выбора в виде строки шкалы Лайкерта (уже в стандартной таблице выше; поддержка подтверждена). |
| `distress` | select_one | Отображает варианты выбора в виде визуального виджета психологической шкалы дистресса Кесслера (K10) с эмоциональными иконками. |
| `rating_box-fill-{c1}-{c2}-{c3}-{c4}-{c5}` | select_one | Отображает варианты выбора в виде стилизованных боксов рейтинга с пятью цветовыми слотами. `c1` = рамка внешнего контейнера, `c2` = рамка невыбранного элемента, `c3` = рамка и заливка выбранного элемента, `c4` = цвет текста невыбранного элемента, `c5` = цвет текста выбранного элемента. Пример: `rating_box-fill-grey-blue-green-black-white`. |
| `tagging-choices-noshow-v2-{c1}-{c2}-{c3}-{c4}-{c5}` | select_multiple | Отображает варианты выбора в виде цветных тегов. Пять цветовых слотов следуют тому же порядку, что и в `rating_box-fill`. Выбранные варианты подсвечиваются; невыбранные варианты скрываются из итогового вида. |

### Интеграция с API

| Атрибут внешнего вида | Типы вопросов | Описание |
|----------------------|----------------|-------------|
| `callapi` | text, integer, decimal, select_one | Включает интеграцию вызовов API для этого поля. Столбец вычислений должен содержать выражение `callapi()`. См. [Call API](advanced-features/call-api). |
| `callapi-verify(params)` | text, integer, decimal | Запускает вызов проверки API с использованием статических параметров. Форма блокирует прогресс до тех пор, пока API не подтвердит значение. |
| `callapi-verify(dynamicParams)` | text, integer, decimal | То же самое, что и `callapi-verify`, но с параметрами, производными от значений других полей во время выполнения. |

### Переключатель языка

| Атрибут внешнего вида | Типы вопросов | Описание |
|----------------------|----------------|-------------|
| `change_language-{colors} default('lang')` | note, text | Отображает виджет переключателя языка, стилизованный с использованием заданных цветовых кодов. Токен `default('lang')` устанавливает начальный язык (например, `default('en')`); он внутренне заменяется на `rtDefault('lang')` во время парсинга. Пример: `change_language-blue-white default('vi')`. |

### Формат даты/времени в строке

Для полей `date`, `time` и `datetime` вы можете указать пользовательский формат отображения, используя строку формата, добавленную к атрибуту внешнего вида:

```
inline-[%d/%m/%Y]
inline-1line-[%d/%m/%Y %H:%M]
```

Токены формата такие же, как в `format-date()` и `format-date-time()`. См. [Функции — Функции даты и времени](operators-and-functions/functions#date-and-time-functions).

Пример:

| type | name | label | appearance |
|------|------|-------|------------|
| datetime | event_time | Дата и время события | inline-[%d/%m/%Y %I:%M %p] |
| date | birth_date | Дата рождения | inline-[%d/%m/%Y] |

### Макет встроенных кнопок — `display{}` и `results{}`

Для типов вопросов, которые отображаются в виде встроенной кнопки с иконкой (`date`, `time`, `datetime`, `image`, `audio`, `video`, `file`, `barcode`, `geopoint`), два модификатора внешнего вида управляют положением кнопки и поведением после захвата данных.

#### `display{...}` — положение кнопки до захвата

```
display{<align>, <size>, <color>}
```

| Параметр | Значения | По умолчанию |
|-----------|--------|---------|
| Align (Выравнивание) | `left`, `right`, `top`, `center`, `bottom` | `right` |
| Size (Размер) | `small`, `medium`, `large` | `small` |
| Color (Цвет) | hex, например, `#FF5500` | основной цвет темы |
| Flag (Флаг) | `inline-icon` | принудительно включает режим иконки |

| Значение Align | Макет |
|-------------|--------|
| `right` | Кнопка справа от метки |
| `left` | Кнопка слева от метки |
| `top` | Кнопка над меткой, по центру на всю ширину |
| `center` / `bottom` | Кнопка под меткой, по центру на всю ширину |

#### `results{...}` — макет и видимость после захвата

Наследует настройки `display{}`. Используется для перемещения кнопки или скрытия элементов после того, как значение было захвачено.

```
results{<align>, hide(<element>)}
```

| Значение `hide` | Эффект |
|---|---|
| `hide(capture)` | Скрывает кнопку захвата, когда файл/значение уже существует |
| `hide(review)` | Скрывает миниатюру просмотра / кнопку воспроизведения |
| `hide(filename)` | Скрывает имя файла, отображаемое после загрузки |
| `hide(camera)` | Скрывает кнопку спуска камеры после захвата |
| `hide(scanner)` | Скрывает кнопку сканирования штрих-кода после сканирования значения |
| `hide(value)` | Скрывает текст отсканированного значения (штрих-код / геопункт) |

Виджет автоматически переключается с макета `display{}` на `results{}` в момент захвата значения.

**Примеры:**

```
inline display{right}                                    → иконка справа от метки
inline display{left, large}                              → большая иконка слева
inline display{center, large, #FF5500}                   → большая оранжевая иконка под меткой
inline display{right} results{left}                      → иконка перемещается влево после захвата
inline display{right} results{hide(capture)}             → иконка исчезает после захвата
inline display{center} results{hide(capture), hide(filename)}
```

## Известные ограничения

- Сложные атрибуты внешнего вида могут отображаться неодинаково на всех платформах.
- Некоторые расширенные атрибуты внешнего вида rtSurvey могут не поддерживаться в автономном (offline) режиме.

## Устранение неполадок с внешним видом

1. **Внешний вид не применился**: Проверьте на наличие опечаток в столбце appearance.
2. **Непоследовательное отображение**: Проверьте совместимость с типом вопроса и платформой.
3. **Проблемы с производительностью**: Рассмотрите возможность упрощения сложных атрибутов внешнего вида, особенно для больших опросов.

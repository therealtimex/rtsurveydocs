rtCloud — надёжный серверный компонент экосистемы rtSurvey, разработанный для оптимизации сбора, управления и анализа данных. Являясь центральным узлом операций rtSurvey, rtCloud предлагает широкий набор функций для поддержки сложных проектов опросов и лонгитюдных исследований.

## Ключевые функции

### Управление проектами
- Организуйте все аспекты проекта опроса в одном месте
- Управляйте ролями пользователей, формами, анализом, поставками и разрешениями внутри каждого проекта

### Управление пользователями и безопасность
- Создавайте учётные записи пользователей с разрешениями на основе ролей и управляйте ими
- Обеспечивайте безопасность данных и контроль доступа на каждом уровне

### Управление формами
- Загружайте и управляйте XLSForms напрямую
- Поддержка обновлений версий форм, включая незначительные правки и структурные изменения
- Прикрепляйте мультимедиа или дополнительные данные к формам
- Возможность полного удаления форм для полного контроля над инструментами опроса

### Сбор данных и управление отправками
- Бесшовная интеграция с мобильным приложением rtSurvey, веб-приложением и веб-формой
- Поддержка отправок аутентифицированных пользователей и анонимных публичных ссылок
- Обработка мультимедиа и вложений данных в отправках
- Интерактивный табличный предпросмотр данных отправок для быстрого анализа

### Расширенные рабочие процессы отправок
- Возврат отправок на устройства пользователей для дополнительного редактирования или верификации
- Пересылка отправок на другие устройства, обеспечивающая совместные рабочие процессы и контроль качества

### Управление лонгитюдными данными
- Эффективная обработка повторных измерений и долгосрочных исследований
- Отслеживание изменений и обновлений данных участников во времени

### Гибкое подключение
- Возможность подключения мобильного приложения rtSurvey для загрузки форм и отправки данных
- Поддержка офлайн-сбора данных с бесшовной синхронизацией при восстановлении связи

## Чем отличается rtCloud

Вдохновлённый другими платформами сбора данных, rtCloud предлагает уникальные функции, выделяющие его среди конкурентов:

1. **Полное удаление форм**: В отличие от некоторых платформ, rtCloud позволяет полностью удалять формы при необходимости.

2. **Гибкие рабочие процессы отправок**: Возможность возврата и пересылки отправок обеспечивает сложные процессы проверки данных и контроля качества.

3. **Интегрированное управление проектами**: rtCloud выходит за рамки управления формами и данными, предлагая инструменты для организации всех аспектов проекта опроса.

4. **Прямая поддержка XLSForm**: Загружайте XLSForms напрямую без конвертации, упрощая процесс создания форм.

5. **Комплексная система разрешений**: Детальный контроль над доступом пользователей и возможностями внутри проектов.

## Начало работы с rtCloud

Для начала использования rtCloud в ваших проектах опросов:

1. Настройте сервер rtCloud или свяжитесь с rtSurvey для получения хостинговых решений.
2. Создайте первый проект и пригласите членов команды.
3. Загрузите XLSForms и настройте рабочие процессы сбора данных.
4. Подключите мобильные приложения rtSurvey и начните сбор данных.

rtCloud расширяет возможности исследователей, организаций и команд по сбору данных для управления сложными проектами опросов с лёгкостью, безопасностью и гибкостью. Будь то разовый опрос или многолетнее лонгитюдное исследование, rtCloud предоставляет инструменты, необходимые для успеха.

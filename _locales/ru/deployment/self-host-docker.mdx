Используйте это руководство, если хотите запустить rtSurvey на собственном сервере (VPS, bare metal или локальная машина) с помощью публичного образа Docker `rtawebteam/rtcloud:survey-public`.

**Вход в Docker Hub не требуется** — образ публичный.

Контейнер включает всё в одном образе:
- Apache + PHP (сервер приложений)
- Shiny Server (аналитические дашборды, порт 3838)
- Beanstalkd (очередь фоновых задач)

---

## Требования

### Сервер

| Ресурс | Минимум | Рекомендуется |
|--------|---------|--------------|
| RAM | 4 ГБ | 8 ГБ |
| Диск | 50 ГБ | 100 ГБ SSD |
| CPU | 2 vCPU | 4 vCPU |
| ОС | Ubuntu 22.04 LTS | Ubuntu 22.04 LTS |

### Программное обеспечение

- **Docker Engine 24.0+** — [руководство по установке](https://docs.docker.com/engine/install/ubuntu/)
- **Docker Compose v2.0+** — входит в Docker Desktop; на Linux: `apt install docker-compose-plugin`

## Настройка

<Steps>

### Создать рабочую директорию

```bash
mkdir -p /opt/rtsurvey && cd /opt/rtsurvey
```

### Создать `docker-compose.yml`

```yaml
services:
  mysql:
    image: mysql:8.0
    container_name: rtsurvey-mysql
    restart: unless-stopped
    command: >
      --default-authentication-plugin=mysql_native_password
      --character-set-server=utf8
      --collation-server=utf8_unicode_ci
      --sql-mode=NO_ENGINE_SUBSTITUTION
    environment:
      MYSQL_ROOT_PASSWORD: ${MYSQL_ROOT_PASSWORD}
      MYSQL_DATABASE: ${MYSQL_DATABASE:-smartsurvey}
      MYSQL_USER: ${MYSQL_USER:-smartsurvey}
      MYSQL_PASSWORD: ${MYSQL_PASSWORD}
      MYSQL_ROOT_HOST: '%'
    volumes:
      - mysql_data:/var/lib/mysql
    networks:
      - rtsurvey-net
    healthcheck:
      test: ["CMD-SHELL", "mysqladmin ping -h localhost -u root -p$$MYSQL_ROOT_PASSWORD"]
      interval: 10s
      timeout: 5s
      retries: 5
      start_period: 30s

  rtsurvey:
    image: rtawebteam/rtcloud:survey-public
    container_name: rtsurvey-app
    restart: unless-stopped
    entrypoint: ["/bin/entrypoint-production.sh"]
    depends_on:
      mysql:
        condition: service_healthy
    ports:
      - "${APP_PORT:-8080}:80"
      - "${SHINY_PORT:-3838}:3838"
    env_file:
      - .env
    volumes:
      - app_uploads:/var/www/html/smartsurvey/uploads
      - app_audios:/var/www/html/smartsurvey/audios
      - app_downloads:/var/www/html/smartsurvey/downloads
      - app_gallery:/var/www/html/smartsurvey/gallery
      - app_tmp:/var/www/html/smartsurvey/tmp
      - app_cache:/var/www/html/smartsurvey/cache
      - app_runtime:/var/www/html/smartsurvey/protected/runtime
      - app_assets:/var/www/html/smartsurvey/assets
      - app_aggregate:/var/www/html/smartsurvey/aggregate
    networks:
      - rtsurvey-net
    healthcheck:
      test: ["CMD", "curl", "-f", "http://localhost/health"]
      interval: 30s
      timeout: 10s
      retries: 3
      start_period: 90s

  # Optional: Embedded Keycloak SSO
  # Start with: docker compose --profile embed-keycloak up -d
  keycloak:
    image: quay.io/keycloak/keycloak:latest
    container_name: rtsurvey-keycloak
    restart: unless-stopped
    profiles:
      - embed-keycloak
    command: start --import-realm
    environment:
      KEYCLOAK_ADMIN: ${KEYCLOAK_ADMIN_USER:-admin}
      KEYCLOAK_ADMIN_PASSWORD: ${KEYCLOAK_ADMIN_PASSWORD}
      KC_HTTP_ENABLED: "true"
      KC_HTTP_RELATIVE_PATH: /auth
      KC_PROXY_HEADERS: xforwarded
      KC_HOSTNAME: ${KC_HOSTNAME}
      KC_HOSTNAME_STRICT: "false"
      KC_DB: mysql
      KC_DB_URL_DATABASE: ${KEYCLOAK_DB:-keycloak}
      KC_DB_URL_HOST: mysql
      KC_DB_USERNAME: ${KEYCLOAK_DB_USER:-keycloak}
      KC_DB_PASSWORD: ${KEYCLOAK_DB_PASSWORD}
    volumes:
      - ./keycloak-import:/opt/keycloak/data/import
    ports:
      - "${KEYCLOAK_PORT:-8091}:8080"
    depends_on:
      mysql:
        condition: service_healthy
    networks:
      - rtsurvey-net
    healthcheck:
      test: ["CMD-SHELL", "curl -f http://localhost:9000/health/ready || exit 1"]
      interval: 30s
      timeout: 10s
      retries: 10
      start_period: 120s

volumes:
  mysql_data:
  app_uploads:
  app_audios:
  app_downloads:
  app_gallery:
  app_tmp:
  app_cache:
  app_runtime:
  app_assets:
  app_aggregate:

networks:
  rtsurvey-net:
    driver: bridge
```

### Создать `.env`

```bash
# Project
PROJECT_ID=mysurvey
PROJECT_TYPE=rtsurvey
PROJECT_URL=your-server-ip-or-domain
HTTP_PROTOCOL=http
TZ=UTC

# Database
MYSQL_HOST=mysql
MYSQL_DATABASE=smartsurvey
MYSQL_USER=smartsurvey
MYSQL_ROOT_PASSWORD=change-this-root-password
MYSQL_PASSWORD=change-this-app-password

# Admin (set before first startup — cannot change via env after DB is created)
ADMIN_PASSWORD=change-this-admin-password

# Runtime
RUN_ENV=prod
RUN_MODE=admin
GII_ENABLED=false
CSRF_VALIDATION_ENABLED=true

# Ports (optional — defaults shown)
APP_PORT=8080
SHINY_PORT=3838
```

<Callout type="warning">
Измените `MYSQL_ROOT_PASSWORD` и `MYSQL_PASSWORD` перед запуском. Используйте надёжные случайные строки (32+ символа) в продакшене.
</Callout>

### Запустить стек

```bash
docker compose up -d
```

Первый запуск занимает около 60–90 секунд — MySQL инициализирует базу данных при первом запуске.

### Проверить

```bash
# Check all containers are running
docker compose ps

# Check application health
curl http://localhost:8080/health
```

</Steps>

## Первый вход

После успешной проверки работоспособности откройте браузер:

```
http://your-server:8080/cpms/cpmsSite/login
```

| Поле | Значение |
|------|---------|
| Имя пользователя | `admin` |
| Пароль | значение `ADMIN_PASSWORD` в вашем `.env` (по умолчанию `admin`) |

<Callout type="warning">
Установите `ADMIN_PASSWORD` в вашем `.env` перед первым запуском. Точка входа задаёт его при первом запуске — изменение после инициализации базы данных не имеет эффекта.
</Callout>

## Переменные окружения

### Необходимые для контейнера приложения

Точка входа откажется запускаться, если какая-либо из них отсутствует:

| Переменная | Описание |
|-----------|---------|
| `PROJECT_ID` | Уникальный идентификатор этого экземпляра (буквенно-цифровой, без пробелов) |
| `PROJECT_URL` | Домен или IP, по которому доступно приложение (без префикса `http://`) |
| `MYSQL_HOST` | Имя хоста MySQL — используйте имя службы Docker (напр. `mysql`) |
| `MYSQL_DATABASE` | Название базы данных |
| `MYSQL_PASSWORD` | Пароль пользователя базы данных |

### Необходимые для контейнера MySQL

| Переменная | Описание |
|-----------|---------|
| `MYSQL_ROOT_PASSWORD` | Пароль root MySQL (используется контейнером `mysql`, не приложением) |

### Рекомендуемые

| Переменная | По умолчанию | Описание |
|-----------|------------|---------|
| `MYSQL_USER` | `smartsurvey` | Имя пользователя базы данных |
| `ADMIN_PASSWORD` | `admin` | Начальный пароль администратора — **установите перед первым запуском**, нельзя изменить через env после создания БД |
| `HTTP_PROTOCOL` | `https` | Установите `http`, если не используете SSL |
| `PROJECT_PORT` | `80` | Внешний порт, к которому подключаются пользователи (не внутренний порт Docker) |
| `PROJECT_TYPE` | `rtwork` | Тип платформы — используйте `rtsurvey` для платформы опросов |
| `TZ` | `UTC` | Часовой пояс (напр. `Asia/Bangkok`, `America/New_York`) |

### Среда выполнения

| Переменная | По умолчанию | Описание |
|-----------|------------|---------|
| `RUN_ENV` | `prod` | Режим среды (`prod` или `dev`) |
| `RUN_MODE` | `admin` | Роль службы — используйте `admin` для односерверной настройки |
| `GII_ENABLED` | `false` | Оставьте `false` в продакшене (генератор кода Yii) |
| `CSRF_VALIDATION_ENABLED` | `true` | Защита CSRF — оставьте `true` |

### Лицензия

| Переменная | По умолчанию | Описание |
|-----------|------------|---------|
| `REQUIRE_LICENSE` | `false` | Установите `true` для принудительной проверки лицензии |
| `RTCLOUD_LICENSE_KEY` | — | Ваш лицензионный ключ — требуется при `REQUIRE_LICENSE=true` |

## Сохранение данных

Все пользовательские данные хранятся в именованных томах Docker. Они сохраняются при перезапусках контейнеров и обновлениях образов.

| Том | Содержимое |
|-----|-----------|
| `mysql_data` | База данных (опросы, пользователи, ответы) |
| `app_uploads` | Файлы, загруженные из опросов |
| `app_gallery` | Медиабиблиотека |
| `app_downloads` | Сгенерированные файлы экспорта |
| `app_audios` | Аудиозаписи |
| `app_runtime` | Файлы сессии PHP и кэш |
| `app_aggregate` | Агрегированные аналитические данные |


```bash
docker compose restart rtsurvey
```

```bash
docker compose exec rtsurvey bash
```

```bash
docker compose exec rtsurvey php /var/www/html/smartsurvey/protected/yiic migrate
```

## Обновления

Образ имеет тег `survey-public`. Для обновления до последней версии:

```bash
docker compose pull
docker compose up -d
```

Миграции базы данных запускаются автоматически при запуске через производственную точку входа.

## Резервное копирование и восстановление

### Резервная копия базы данных

```bash
docker compose exec mysql \
  mysqldump -u root -p"${MYSQL_ROOT_PASSWORD}" smartsurvey \
  > backup-$(date +%Y%m%d).sql
```

### Восстановление базы данных

```bash
docker compose exec -T mysql \
  mysql -u root -p"${MYSQL_ROOT_PASSWORD}" smartsurvey \
  < backup-20240101.sql
```

### Резервная копия загруженных файлов

```bash
docker run --rm \
  -v rtsurvey_app_uploads:/data \
  -v $(pwd):/backup \
  alpine tar czf /backup/uploads-$(date +%Y%m%d).tar.gz -C /data .
```

## Встроенный Keycloak (опциональный SSO)

Производственный файл compose включает опциональный контейнер Keycloak для SSO. Он использует тот же экземпляр MySQL и активируется через профиль Docker Compose.

<Callout type="info">
Встроенный Keycloak требует не менее **4 ГБ RAM**. Он опционален — пропустите, если SSO не нужен.
</Callout>

### Добавить переменные Keycloak в `.env`

```bash
# Keycloak admin
KEYCLOAK_ADMIN_USER=admin
KEYCLOAK_ADMIN_PASSWORD=change-this-keycloak-password

# Keycloak database (created automatically in the shared MySQL on first run)
KEYCLOAK_DB=keycloak
KEYCLOAK_DB_USER=keycloak
KEYCLOAK_DB_PASSWORD=change-this-keycloak-db-password

# KC_HOSTNAME: full public URL of your server (Keycloak appends /auth automatically)
KC_HOSTNAME=http://your-server:8091

# Port Keycloak listens on (host)
KEYCLOAK_PORT=8091

# Tell the rtCloud app to connect to embedded Keycloak
EMBED_KEYCLOAK=true
KEYCLOAK_URL=http://your-server:8091
KEYCLOAK_REALM=rtsurvey
KEYCLOAK_CLIENT_ID=rtsurvey
KEYCLOAK_CLIENT_SECRET=your-client-secret
```

Служба `keycloak` уже включена в `docker-compose.yml` выше (под профилем `embed-keycloak` — не запустится, если не использовать `--profile embed-keycloak`).

Создайте директорию импорта (Keycloak запустится без неё, но автоматическое создание realm не будет работать):

```bash
mkdir -p /opt/rtsurvey/keycloak-import
```

### Запуск с Keycloak

```bash
docker compose --profile embed-keycloak up -d
```

Для запуска без Keycloak (по умолчанию):

```bash
docker compose up -d
```

### Консоль администратора Keycloak

После успешного запуска, откройте интерфейс администратора Keycloak по адресу:

```
http://your-server:8091/auth/admin
```

Войдите с `KEYCLOAK_ADMIN_USER` / `KEYCLOAK_ADMIN_PASSWORD`.

## Следующие шаги

- **HTTPS** — Разместите nginx или Caddy перед приложением и следуйте руководству по [настройке SSL](ssl-setup)
- **SSO** — Подключите Azure AD или Keycloak через руководство по [аутентификации SSO](sso-authentication)
- **Облачное развёртывание** — Смотрите [Облачные провайдеры](cloud-providers) для настройки с автоматизированными скриптами

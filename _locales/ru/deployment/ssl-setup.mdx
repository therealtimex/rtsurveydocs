SSL должен быть настроен перед тем, как вы сможете войти в систему. При первом открытии приложения вы будете автоматически перенаправлены на экран настройки SSL.

---

## Варианты настройки SSL

![SSL setup options](/img/ssl-setup/ssl-setup-options.png)

Выберите один из трех вариантов:

| Вариант | Когда использовать |
|---------|-------------------|
| **Бесплатный поддомен rtsurvey.com** *(Рекомендуется)* | Настройка DNS не требуется. Мы создадим запись за вас. Готовность через 2–5 минут. |
| **Мой собственный домен** | У вас уже есть домен, и его DNS указывает на этот сервер. |
| **Установить сертификат вручную** | Корпоративный или собственный центр сертификации (CA). Требуется доступ по SSH. |

---

## Вариант 1 — Бесплатный поддомен rtsurvey.com *(Рекомендуется)*

Это самый быстрый вариант. Регистрация домена или изменение настроек DNS не требуются.

![HTTPS Setup form](/img/ssl-setup/ssl-setup-form.png)

> **Прежде чем продолжить:** Для бесплатного поддомена требуется активная учетная запись на [licenses.rtsurvey.com](https://licenses.rtsurvey.com). Бесплатный тариф включает 1 поддомен (`*.rtsurvey.com`).

1. Нажмите **Free rtsurvey.com subdomain**, чтобы развернуть раздел.
2. Введите желаемое имя поддомена в поле **YOUR SUBDOMAIN**.

   > Используйте строчные буквы, цифры и дефисы. От 3 до 30 символов.
   > Пример: `myproject` → `myproject.rtsurvey.com`

3. Вставьте ваш **rtSurvey DNS Token** из [licenses.rtsurvey.com](https://licenses.rtsurvey.com) в поле токена.
4. Нажмите **Create secure subdomain**.

После отправки приложение начнет подготовку вашего сертификата:

![Setting up HTTPS progress](/img/ssl-setup/ssl-setup-progress.png)

Четыре шага выполняются автоматически:
- **Запрос записи DNS** — создает запись DNS для вашего поддомена.
- **Ожидание распространения DNS** — обычно занимает 2–5 минут.
- **Выпуск сертификата SSL** — Let's Encrypt подписывает ваш сертификат.
- **Активация HTTPS** — Nginx перезагружается с новым сертификатом.

5. После завершения вы будете автоматически перенаправлены на ваш новый URL-адрес HTTPS.

## Вариант 2 — Мой собственный домен

Используйте этот вариант, если у вас есть существующий домен и его DNS-запись `A` уже указывает на IP-адрес этого сервера.

1. Нажмите **My own domain**, чтобы развернуть раздел.
2. Введите полное доменное имя (например, `survey.myorganization.org`).
3. Нажмите **Create certificate**.



Let's Encrypt проверит ваш домен и выпустит сертификат. Для этого необходимо, чтобы DNS был правильно настроен заранее — в противном случае запрос будет отклонен.

## Вариант 3 — Установить сертификат вручную

Для корпоративных сред, использующих собственный или внутренний центр сертификации. Вы разместите файлы сертификатов на сервере через SSH, а затем введете свой домен в приложении.

### Предварительные условия

- Доступ к серверу по SSH.
- Действующий сертификат и закрытый ключ для вашего домена (формат PEM).

### Шаг 1 — Подключитесь к серверу по SSH

```bash
ssh root@<server-ip>
```

### Шаг 2 — Разместите файлы сертификата

Создайте каталог и скопируйте файлы:

```bash
mkdir -p /etc/letsencrypt/live/<your-domain>
```

Скопируйте файлы в этот каталог с указанными именами:

| Файл | Описание |
|------|----------|
| `fullchain.pem` | Ваш сертификат + любые промежуточные сертификаты CA (объединенные). |
| `privkey.pem` | Ваш закрытый ключ. |

Пример:

```bash
# Скопируйте с локальной машины (запустите это локально, а не на сервере)
scp fullchain.pem root@<server-ip>:/etc/letsencrypt/live/<your-domain>/fullchain.pem
scp privkey.pem  root@<server-ip>:/etc/letsencrypt/live/<your-domain>/privkey.pem
```

Установите правильные разрешения:

```bash
chmod 644 /etc/letsencrypt/live/<your-domain>/fullchain.pem
chmod 600 /etc/letsencrypt/live/<your-domain>/privkey.pem
```

### Шаг 3 — Введите свой домен в приложении



1. На экране настройки SSL нажмите **Install certificate manually**.
2. Введите свое доменное имя (оно должно соответствовать Common Name или SAN сертификата).
3. Нажмите **Apply**.

Сервер настроит Nginx с вашим сертификатом и автоматически перезагрузится.

Před přihlášením je nutné nakonfigurovat SSL. Při prvním otevření aplikace budete automaticky přesměrováni na obrazovku nastavení SSL.

---

## Možnosti nastavení SSL

![SSL setup options](/img/ssl-setup/ssl-setup-options.png)

Vyberte jednu ze tří možností:

| Možnost | Kdy použít |
|--------|-------------|
| **Bezplatná subdoména rtsurvey.com** *(Doporučeno)* | Není vyžadováno žádné nastavení DNS. Záznam vytvoříme za vás. Hotovo za 2–5 minut. |
| **Moje vlastní doména** | Již máte doménu a její DNS záznamy směřují na tento server. |
| **Instalovat certifikát ručně** | Podniková nebo vlastní certifikační autorita (CA). Vyžaduje přístup přes SSH. |

---

## Možnost 1 — Bezplatná subdoména rtsurvey.com *(Doporučeno)*

Toto je nejrychlejší možnost. Není vyžadována žádná registrace domény ani změny DNS.

![HTTPS Setup form](/img/ssl-setup/ssl-setup-form.png)

> **Než budete pokračovat:** Bezplatná subdoména vyžaduje aktivní účet na [licenses.rtsurvey.com](https://licenses.rtsurvey.com). Bezplatný plán zahrnuje 1 subdoménu (`*.rtsurvey.com`).

1. Kliknutím na **Bezplatná subdoména rtsurvey.com** rozbalte sekci
2. Do pole **YOUR SUBDOMAIN** zadejte požadovaný název subdomény

   > Používejte malá písmena, čísla a pomlčky. 3–30 znaků.
   > Příklad: `myproject` → `myproject.rtsurvey.com`

3. Vložte svůj **rtSurvey DNS Token** z [licenses.rtsurvey.com](https://licenses.rtsurvey.com) do pole pro token
4. Klikněte na **Vytvořit zabezpečenou subdoménu**

Po odeslání aplikace začne připravovat váš certifikát:

![Setting up HTTPS progress](/img/ssl-setup/ssl-setup-progress.png)

Čtyři kroky probíhají automaticky:
- **Vyžádání záznamu DNS** — vytvoří záznam DNS pro vaši subdoménu
- **Čekání na propagaci DNS** — obvykle 2–5 minut
- **Vydání SSL certifikátu** — Let's Encrypt podepíše váš certifikát
- **Aktivace HTTPS** — Nginx se znovu načte s novým certifikátem

5. Po dokončení budete automaticky přesměrováni na svou novou HTTPS URL automaticky

## Možnost 2 — Moje vlastní doména

Tuto možnost použijte, pokud máte existující doménu a její záznam DNS `A` již směřuje na IP adresu tohoto serveru.

1. Kliknutím na **Moje vlastní doména** rozbalte sekci
2. Zadejte svůj úplný název domény (např. `survey.myorganization.org`)
3. Klikněte na **Vytvořit certifikát**

Let's Encrypt ověří vaši doménu a vydá certifikát. To vyžaduje, aby DNS záznamy byly nejprve správně nasměrovány — v opačném případě požadavek selže.

---

## Možnost 3 — Instalovat certifikát ručně

Pro podniková prostředí využívající vlastní nebo interní certifikační autoritu (CA). Soubory certifikátu umístíte na server přes SSH a poté v aplikaci zadáte svou doménu.

### Požadavky

- Přístup k serveru přes SSH
- Platný certifikát a soukromý klíč pro vaši doménu (formát PEM)

### Krok 1 — Přihlášení k serveru přes SSH

```bash
ssh root@<server-ip>
```

### Krok 2 — Umístění souborů certifikátu

Vytvořte adresář a zkopírujte své soubory:

```bash
mkdir -p /etc/letsencrypt/live/<your-domain>
```

Zkopírujte své soubory do tohoto adresáře pod těmito přesnými názvy:

| Soubor | Popis |
|------|-------------|
| `fullchain.pem` | Váš certifikát + případné certifikáty zprostředkujících autorit (zřetězené) |
| `privkey.pem` | Váš soukromý klíč |

Example:

```bash
# Kopírovat z místního počítače (spusťte místně, nikoli na serveru)
scp fullchain.pem root@<server-ip>:/etc/letsencrypt/live/<your-domain>/fullchain.pem
scp privkey.pem  root@<server-ip>:/etc/letsencrypt/live/<your-domain>/privkey.pem
```

Nastavte správná oprávnění:

```bash
chmod 644 /etc/letsencrypt/live/<your-domain>/fullchain.pem
chmod 600 /etc/letsencrypt/live/<your-domain>/privkey.pem
```

### Krok 3 — Zadání domény v aplikaci

1. Na obrazovce nastavení SSL klikněte na **Instalovat certifikát ručně**
2. Zadejte název své domény (musí odpovídat Common Name nebo SAN v certifikátu)
3. Klikněte na **Apply**

Server nakonfiguruje Nginx s vaším certifikátem a automaticky jej znovu načte.

Sloupec `appearance` v rtSurvey vám umožňuje přizpůsobit vizuální prezentaci a chování otázek ve vašich průzkumech. Tato funkce vylepšuje uživatelský zážitek a může výrazně zlepšit efektivitu sběru dat. rtSurvey podporuje standardní atributy vzhledu XLSForm a rozšiřuje je o další možnosti.

## Standardní atributy vzhledu XLSForm

rtSurvey podporuje následující standardní atributy vzhledu XLSForm:

| Atribut vzhledu (Appearance Attribute) | Typy otázek (Question Types) | Popis |
|----------------------|----------------|-------------|
| multiline | text | Vytvoří víceřádkové textové pole (nejlepší pro webové klienty) |
| minimal | select_one, select_multiple | Zobrazí možnosti v rozbalovací nabídce |
| quick | select_one | Po výběru automaticky přejde na další otázku (pouze mobilní zařízení) |
| no-calendar | date | Potlačí zobrazení kalendáře (pouze mobilní zařízení) |
| month-year | date | Umožňuje výběr pouze měsíce a roku |
| year | date | Umožňuje výběr pouze roku |
| horizontal-compact | select_one, select_multiple | Zobrazuje možnosti horizontálně (pouze web) |
| horizontal | select_one, select_multiple | Zobrazuje možnosti horizontálně ve sloupcích (pouze web) |
| likert | select_one | Prezentuje možnosti jako Likertovu škálu |
| compact | select_one, select_multiple | Zobrazuje možnosti vedle sebe s minimálním odsazením |
| quickcompact | select_one | Kombinuje kompaktní zobrazení s automatickým přechodem (pouze mobilní zařízení) |
| field-list | groups | Zobrazí celou skupinu na jedné obrazovce (pouze mobilní zařízení) |
| label | select_one, select_multiple | Zobrazuje popisky voleb bez vstupních polí |
| list-nolabel | select_one, select_multiple | Zobrazuje vstupní pole bez popisků (použijte s `label`) |
| table-list | groups | Zobrazuje otázky ve formátu tabulky |
| signature | image | Umožňuje zachycení podpisu (pouze mobilní zařízení) |
| draw | image | Umožňuje kreslení od ruky (pouze mobilní zařízení) |
| map, quick map | select_one, select_one_from_file | Umožňuje výběr z prvků mapy |

## Osvědčené postupy pro používání Appearance

1. **Konzistence**: Používejte atributy vzhledu v celém průzkumu konzistentně pro jednotný vzhled.
2. **Mobilní zařízení vs. Web**: Zvažte, jak se budou vzhledy vykreslovat na různých zařízeních a platformách.
3. **Výkon**: Buďte opatrní s atributy vzhledu, které by mohly zpomalit načítání formuláře (např. `table-list` u velkých skupin).
4. **Uživatelský zážitek**: Volte vzhledy, které respondentům usnadní a zpřehlední zadávání dat.
5. **Testování**: Vždy formulář otestujte na cílových zařízeních, abyste se ujistili, že vzhledy fungují podle očekávání.

## Pokročilé techniky

### Kombinování vzhledů

Některé atributy vzhledu lze kombinovat pro složitější rozvržení:

```
| type | name | label | appearance |
|------|------|-------|------------|
| select_one options | choice | Vyberte jednu možnost: | minimal compact |
```

### Dynamické vzhledy

rtSurvey umožňuje dynamické změny vzhledu na základě logiky formuláře:

```
| type | name | label | appearance | relevant |
|------|------|-------|------------|----------|
| text | time | Zadejte čas: | inline-[%H:%M] | ${show_time} = 'yes' |
```

## Důležité aspekty pro mobilní aplikaci

- Některé vzhledy (např. `quick`, `signature`) jsou specifické pro mobilní zařízení.
- Důkladně testujte na Androidu i iOS, abyste zajistili konzistentní chování.

## Rozšířené atributy vzhledu rtSurvey

Kromě standardních vzhledů XLSForm podporuje rtSurvey následující možnosti specifické pro platformu:

### Řízení dat a zobrazení

| Atribut vzhledu (Appearance Attribute) | Typy otázek (Question Types) | Popis |
|----------------------|----------------|-------------|
| `invisible` | any | Skryje pole před zobrazením, zatímco stále shromažďuje nebo vypočítává jeho hodnotu. Liší se od typu `hidden` – pole se stále účastní logiky. |
| `displaytitle` | any | Vynutí zobrazení popisku/názvu pole i tam, kde by byl jinak potlačen. |
| `autopull` | select_one, select_multiple | Automaticky načte externí data pro naplnění voleb při načtení formuláře nebo změně spouštěcího pole. |
| `floating_hint` | text, integer, decimal | Zobrazuje text nápovědy (hint) jako plovoucí popisek nad vstupním polem namísto pod ním. |
| `calculate-button` | calculate | Přidá viditelné tlačítko, které na vyžádání spustí přepočet pole, místo aby se počítalo automaticky. |

### Skupina a navigace

| Atribut vzhledu (Appearance Attribute) | Typy otázek (Question Types) | Popis |
|----------------------|----------------|-------------|
| `section` | group | Vykreslí skupinu jako sbalitelnou kartu sekce. Poznámka: pouze mobilní aplikace. |
| `toc-hide` | any | Vyloučí otázku z navigačního panelu obsahu (TOC). |
| `minilog` | begin_repeat | Zobrazuje dokončené položky opakování jako kompaktní seznam (mini-log) namísto rozbalování každé položky v řádku. |

### Chování vstupu

| Atribut vzhledu (Appearance Attribute) | Typy otázek (Question Types) | Popis |
|----------------------|----------------|-------------|
| `proper` | text | Automaticky převede první písmeno každého slova na velké během psaní respondenta (chování title-case). |
| `text-nolabel` | text, integer, decimal | Vykreslí vstupní pole bez viditelného popisku. |
| `inline-1line` | text | Vynutí zobrazení textového vstupu jako jeden řádek, i když je popisek otázky dlouhý. |
| `popup` | any | Vykreslí pole v vyskakovacím okně (popup) / modální vrstvě namísto v řádku na stránce. |

### Rozvržení (Layout)

| Atribut vzhledu (Appearance Attribute) | Typy otázek (Question Types) | Popis |
|----------------------|----------------|-------------|
| `1screen` | group | Vynutí zobrazení celé skupiny na jedné obrazovce bez ohledu na velikost skupiny. |
| `columns(n)` | select_one, select_multiple | Zobrazí možnosti v `n` sloupcích. Příklad: `columns(3)` zobrazí tři sloupce přepínačů (radio buttons). |
| `gridformat<row=R col=C colspan=S align=center>` | any | Umístí pole v CSS-grid rozvržení na řádek `R`, sloupec `C`, s rozpětím přes `S` sloupců. Používá se s `advanced-extension/grid-layout`. |
| `ignore-simplify` | any | Instruuje vykreslovač formuláře, aby přeskočil automatické zjednodušení nebo zahuštění rozvržení tohoto pole. |
| `horizontal(N)` | select_one, select_multiple | Nastaví každou volbu tak, aby zabírala `N` procent šířky řádku. Příklad: `horizontal(50)` umístí dvě volby na řádek. |
| `scroll-view(N%)` | group, repeat | Omezí kontejner na maximální výšku `N%` výřezu (viewportu) (nebo nadřazeného prvku) a přidá posuvník při přetečení obsahu. Příklad: `scroll-view(60%)`. |

### Widgety

| Atribut vzhledu (Appearance Attribute) | Typy otázek (Question Types) | Popis |
|----------------------|----------------|-------------|
| `likert` | select_one | Prezentuje možnosti jako řádek Likertovy škály (již ve standardní tabulce výše; potvrzena podpora). |
| `distress` | select_one | Vykreslí možnosti jako vizuální widget Kesslerovy škály psychického stresu (K10) s emočními ikonami. |
| `rating_box-fill-{c1}-{c2}-{c3}-{c4}-{c5}` | select_one | Vykreslí možnosti jako stylované hodnotící boxy s pěti barevnými sloty. `c1` = vnější ohraničení kontejneru, `c2` = nezaškrtnuté ohraničení, `c3` = zaškrtnuté ohraničení a výplň, `c4` = barva nezaškrtnutého textu, `c5` = barva zaškrtnutého textu. Příklad: `rating_box-fill-grey-blue-green-black-white`. |
| `tagging-choices-noshow-v2-{c1}-{c2}-{c3}-{c4}-{c5}` | select_multiple | Vykreslí možnosti jako barevné štítky (tag chips). Pět barevných slotů sleduje stejné pořadí jako u `rating_box-fill`. Vybrané možnosti jsou zvýrazněny; nevybrané možnosti jsou v souhrnném zobrazení potlačeny. |

### API integrace

| Atribut vzhledu (Appearance Attribute) | Typy otázek (Question Types) | Popis |
|----------------------|----------------|-------------|
| `callapi` | text, integer, decimal, select_one | Umožňuje integraci volání API pro toto pole. Sloupec calculation by měl obsahovat výraz `callapi()`. Viz [Call API](advanced-features/call-api). |
| `callapi-verify(params)` | text, integer, decimal | Spustí ověřovací volání API pomocí statických parametrů. Formulář blokuje postup, dokud API hodnotu nepotvrdí. |
| `callapi-verify(dynamicParams)` | text, integer, decimal | Stejné jako `callapi-verify`, ale s parametry odvozenými z jiných hodnot polí za běhu. |

### Přepínač jazyků (Language switcher)

| Atribut vzhledu (Appearance Attribute) | Typy otázek (Question Types) | Popis |
|----------------------|----------------|-------------|
| `change_language-{colors} default('lang')` | note, text | Vykreslí widget pro přepínání jazyků stylovaný danými barevnými kódy. Token `default('lang')` nastavuje počáteční jazyk (např. `default('en')`); při parsování je interně přepsán na `rtDefault('lang')`. Příklad: `change_language-blue-white default('vi')`. |

### Inline formát data/času

U polí `date`, `time` a `datetime` můžete specifikovat vlastní formát zobrazení pomocí formátovacího řetězce připojeného ke vzhledu:

```
inline-[%d/%m/%Y]
inline-1line-[%d/%m/%Y %H:%M]
```

Formátovací tokeny jsou stejné jako u `format-date()` a `format-date-time()`. Viz [Funkce — Funkce data a času](operators-and-functions/functions#date-and-time-functions).

Příklad:

| type | name | label | appearance |
|------|------|-------|------------|
| datetime | event_time | Datum a čas události | inline-[%d/%m/%Y %I:%M %p] |
| date | birth_date | Datum narození | inline-[%d/%m/%Y] |

### Inline rozvržení tlačítek — `display{}` a `results{}`

U typů otázek, které se vykreslují jako inline ikona s tlačítkem (`date`, `time`, `datetime`, `image`, `audio`, `video`, `file`, `barcode`, `geopoint`), ovládají dva modifikátory vzhledu pozici tlačítka a chování po zachycení.

#### `display{...}` — pozice tlačítka před zachycením

```
display{<align>, <size>, <color>}
```

| Parametr | Hodnoty | Výchozí |
|-----------|--------|---------|
| Zarovnání (Align) | `left`, `right`, `top`, `center`, `bottom` | `right` |
| Velikost (Size) | `small`, `medium`, `large` | `small` |
| Barva (Color) | hex např. `#FF5500` | primární barva motivu |
| Příznak (Flag) | `inline-icon` | vynutí režim ikony |

| Hodnota Align | Rozvržení |
|-------------|--------|
| `right` | Tlačítko vpravo od popisku |
| `left` | Tlačítko vlevo od popisku |
| `top` | Tlačítko nad popiskem, vycentrované na celou šířku |
| `center` / `bottom` | Tlačítko pod popiskem, vycentrované na celou šířku |

#### `results{...}` — rozvržení a viditelnost po zachycení

Dědí nastavení `display{}`. Použijte k přesunu tlačítka nebo skrytí prvků po zachycení hodnoty.

```
results{<align>, hide(<element>)}
```

| Hodnota `hide` | Efekt |
|---|---|
| `hide(capture)` | Skryje tlačítko pro zachycení, jakmile existuje soubor/hodnota |
| `hide(review)` | Skryje náhledový obrázek / tlačítko přehrávání |
| `hide(filename)` | Skryje název souboru zobrazený po nahrání |
| `hide(camera)` | Skryje tlačítko spouště fotoaparátu po zachycení |
| `hide(scanner)` | Skryje tlačítko pro skenování čárového kódu po naskenování hodnoty |
| `hide(value)` | Skryje text naskenované hodnoty (čárový kód / geopoint) |

Widget se automaticky přepne z rozvržení `display{}` do rozvržení `results{}` v momentě zachycení hodnoty.

**Příklady:**

```
inline display{right}                                    → ikona vpravo od popisku
inline display{left, large}                              → velká ikona vlevo
inline display{center, large, #FF5500}                   → velká oranžová ikona pod popiskem
inline display{right} results{left}                      → ikona se po zachycení přesune doleva
inline display{right} results{hide(capture)}             → ikona po zachycení zmizí
inline display{center} results{hide(capture), hide(filename)}
```

## Známá omezení

- Komplexní vzhledy se nemusí vykreslovat identicky na všech platformách.
- Některé pokročilé vzhledy rtSurvey nemusí být podporovány v offline režimu.

## Řešení problémů se vzhledem

1. **Vzhled nebyl aplikován**: Zkontrolujte překlepy ve sloupci appearance.
2. **Nekonzistentní vykreslování**: Ověřte kompatibilitu s typem otázky a platformou.
3. **Problémy s výkonem**: Zvažte zjednodušení komplexních vzhledů, zejména u rozsáhlých průzkumů.

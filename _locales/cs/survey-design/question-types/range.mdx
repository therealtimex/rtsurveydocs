---
title: "Rozsah"
description: "Otázky typu rozsah umožňují respondentům vybrat číslo posunutím posuvníku mezi definovanou minimální a maximální hodnotou."
---

Typ otázky `range` umožňuje respondentům vybrat číslo v rámci definovaného minima a maxima. Ve webovém formuláři rtSurvey se toto vykresluje jako standardní **číselný vstup** — tazatel zadává hodnotu přímo. Parametry `start`, `end` a `step` definují platný rozsah a jsou vynucovány jako omezení.

## Základní specifikace XLSForm

| type | name | label | parameters |
|------|------|-------|------------|
| range | satisfaction | Jak jste spokojeni se službou? | start=1 end=5 step=1 |

Sloupec `parameters` definuje hranice posuvníku a velikost kroku:

| Parametr | Popis | Výchozí |
|-----------|-------------|---------|
| `start` | Minimální hodnota (včetně) | 0 |
| `end` | Maximální hodnota (včetně) | 10 |
| `step` | Přírůstek mezi platnými hodnotami | 1 |

Další podrobnosti o standardním typu otázky rozsah naleznete v [specifikaci XLSForm](https://xlsform.org/en/#question-types).

## Použití

Otázky s rozsahem se běžně používají pro:

1. Stupnice spokojenosti nebo hodnocení (např. 1–5 nebo 0–10)
2. Číselné stupnice Likertova typu
3. Sběr měření, kde jsou platné pouze diskrétní hodnoty
4. Věkové skupiny nebo rozsahy skóre, kde posuvník zlepšuje použitelnost oproti textovému poli

## Příklad použití

### Základní stupnice hodnocení

| type | name | label | parameters |
|------|------|-------|------------|
| range | overall_rating | Celkové hodnocení (0–10) | start=0 end=10 step=1 |

### Desetinný krok

| type | name | label | parameters |
|------|------|-------|------------|
| range | weight_kg | Hmotnost (kg) | start=0 end=200 step=0.5 |

### Použití hodnoty ve výpočtu

| type | name | label | parameters | calculation |
|------|------|-------|------------|-------------|
| range | score | Skóre testu (0–100) | start=0 end=100 step=5 | |
| calculate | grade | | | if(`${score}` >= 90, 'A', if(`${score}` >= 80, 'B', if(`${score}` >= 70, 'C', 'F'))) |
| note | grade_note | Vaše známka je: `${grade}` | | |

## Osvědčené postupy

1. Vždy nastavte smysluplné hodnoty `start`, `end` a `step` — nespoléhejte na výchozí nastavení.
2. Označte konce své stupnice ve sloupci `hint` (např. `hint: 0 = Velmi nespokojen, 10 = Velmi spokojen`), abyste respondentům poskytli kontext.
3. Pro pětibodové Likertovy stupnice použijte raději `start=1 end=5 step=1` než 0–4, protože respondenti očekávají, že „1“ bude znamenat nejnižší hodnotu.
4. Použijte `range` místo `integer` + omezení, pokud je ohraničená povaha vstupu součástí návrhu otázky (posuvník vizuálně sděluje měřítko).

## Omezení

- Ve webovém formuláři rtSurvey není k dispozici widget posuvníku — zadávání hodnoty probíhá přes prostý číselný vstup. Pro vizuální zážitek s posuvníkem použijte mobilního klienta, který widget rozsah podporuje.
- Pro velmi široké rozsahy (např. 0–10000) je stejně účinný a uživatelsky přívětivější prostý `integer` s omezením.
- Jemné hodnoty kroku (např. `step=0.1`) fungují jako omezení, ale ve webovém formuláři nepředstavují problém s přesností posuvníku.

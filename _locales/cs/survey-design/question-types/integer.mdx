---
title: "Celé číslo"
description: "Typ otázky pro zadávání celých čísel v rtSurvey"
---

Typ otázky `integer` shromažďuje celá čísla (bez desetinných míst). Na mobilních zařízeních vyvolává numerickou klávesnici a blokuje zadávání desetinné čárky. Podporuje stejné možnosti vzhledu jako typ `text` pro rozvržení a formátování.

## Základní specifikace XLSForm

| type | name | label |
|------|------|-------|
| integer | age | Věk respondenta |
| integer | household_size | Počet osob v domácnosti |

Standardní specifikaci naleznete v [dokumentaci XLSForm](https://xlsform.org/en/#question-types).

---

## Možnosti vzhledu

### `number-hspinner` — horizontální číselník

Nahradí vstup horizontálním číselníkem **− hodnota +**. Klepnutím na mínus/plus se hodnota sníží nebo zvýší o 1 (nebo o vlastní krok).

```
number-hspinner
```

**Přizpůsobte tvar tlačítka a krok** pomocí `hspinner()`:

```
number-hspinner hspinner('left-small-square','right-small-square','5')
```

Parametry: tvar levého tlačítka, tvar pravého tlačítka, hodnota kroku (pro integer je výchozí `1`).

**Vlastní barvy** pomocí `colors()`:

```
number-hspinner colors(0099FF,FFFFFF,FF5500,FFFFFF)
```

Čtyři hodnoty v pořadí: pozadí levého tlačítka, ikona levého tlačítka, pozadí pravého tlačítka, ikona pravého tlačítka.

---

### `thousandsep` — oddělovač tisíců

Formátuje zobrazené číslo s oddělovačem tisíců (např. `1 234 567`). Nezpracované číslo se ukládá bez oddělovačů. Typ vstupu se přepne na `"text"`, aby bylo možné formátované zobrazení.

```
thousandsep
```

---

### `digisep(n, "sep")` — vlastní seskupování číslic

Seskupuje číslice do bloků o velikosti `n` oddělených vlastním oddělovačem. Užitečné pro formátovaná ID nebo referenční kódy, které jsou číselné.

```
digisep(4,"-")      → 0912-3456-789
digisep(3," ")      → 012 345 678
```

Pokud je tento vzhled aktivní, typ vstupu se přepne na `"text"`.

---

### `textonly` — vynucení textové klávesnice

Vynutí `type="text"` na vstupním prvku. To zabraňuje chování prohlížeče u číselných vstupů (jako je skrývání počátečních nul nebo přidávání šipek v desktopových prohlížečích) při zachování sběru číselné hodnoty.

```
textonly
```

---

### `floating_hint` — nápověda jako plovoucí štítek

Text `hint` se ve vstupu vykreslí jako zástupný symbol (placeholder). Když uživatel začne psát, nápověda se vysune nad pole jako štítek.

```
floating_hint
```

---

### `embed` — nápověda uvnitř ohraničení vstupu

Podobné jako `floating_hint` — nápověda je umístěna uvnitř ohraničení vstupu, pokud je prázdný. Při psaní se neposouvá nahoru.

```
embed
```

---

### `textpopup` — vstup v modálním dialogu

Klepnutím na pole se otevře modální dialog s větším vstupem místo úprav přímo v řádku. Užitečné na malých obrazovkách, kde je celoobrazovkový vstup jednodušší.

```
textpopup
```

---

### `charcount` — živé počítadlo znaků

Zobrazuje živý počet znaků `(n)` pod vstupem, který se aktualizuje během psaní.

```
charcount
```

---

### `prefix(expr)` — přidání předpony

Přidá statický nebo vypočítaný řetězec před zobrazenou hodnotu. Uložená hodnota předponu neobsahuje.

```
prefix('Položka č. ')   → zobrazí "Položka č. 42", uloží "42"
prefix(${code_prefix})  → dynamická předpona z jiného pole
```

---

### `align_answer` — zarovnání textu vstupu

Ovládá horizontální zarovnání zadávané hodnoty uvnitř vstupu.

```
align_answer = left
align_answer = right
align_answer = center
```

---

### `inputs{qrscan}` — skenování QR / čárového kódu do pole

Přidá tlačítko pro skenování QR kódu vedle vstupu. Otevře skener fotoaparátu a vyplní pole naskenovanou číselnou hodnotou.

```
inputs{qrscan}
```

## Omezení a validace

K vynucení rozsahů hodnot použijte omezení (constraints). Omezení ve sloupci `constraint` jsou vyhodnocována po každém stisknutí tlačítka v režimu `number-hspinner`, nikoli pouze při opuštění pole.

| type | name | label | constraint | constraint_message |
|------|------|-------|------------|-------------------|
| integer | age | Věk | `. > 0 and . <= 120` | Věk musí být mezi 1 a 120 |
| integer | year | Rok výstavby | `. >= 1800 and . <= 2100` | Zadejte platný rok |
| integer | count | Počet položek | `. >= 0` | Nesmí být záporné |

## Příklad — průzkum domácností

| type | name | label | appearance | constraint | constraint_message |
|------|------|-------|------------|------------|-------------------|
| integer | household_size | Počet osob v domácnosti | `number-hspinner` | `. >= 1 and . <= 30` | Musí být mezi 1 a 30 |
| integer | under_5 | Děti do 5 let | `number-hspinner` | `. >= 0 and . <= ${household_size}` | Nesmí překročit velikost domácnosti |
| integer | year_built | Rok výstavby domu | `textonly` | `. >= 1800 and . <= 2100` | Zadejte platný rok |

## Osvědčené postupy

1. Používejte `number-hspinner` pro počty v malém rozsahu, kde je klikání na ± rychlejší než psaní (např. počet dětí, skóre na stupnici 1–10).
2. Používejte `thousandsep` při zobrazování velkých celých čísel (populace, příjem), aby si respondenti mohli sami zkontrolovat řádovou velikost.
3. Používejte `textonly`, když prohlížeče přidávají nechtěné uživatelské rozhraní pro číselné vstupy (šipky číselníku, posouvání dotykem), které respondenty mate.
4. Vynucujte omezení rozsahu raději než spoléhání se na typ mobilní klávesnice — vynucení klávesnice není univerzální.

## Omezení

- Zadávání desetinné čárky je blokováno — pokud potřebujete zlomkové hodnoty, použijte typ `decimal`.
- `number-hspinner` validuje `constraint` při každém stisknutí tlačítka — v režimu číselníku se vyhněte náročným omezením (např. složité řetězce `if()`).
- `thousandsep` a `digisep()` ukládají nezpracované číslo bez formátování — ve výpočtech nespoléhejte na formátovanou zobrazenou hodnotu.

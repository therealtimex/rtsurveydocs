title: "Geobod"
description: "Geopoint otázky zaznamenávají zeměpisné souřadnice (zeměpisná šířka, délka, nadmořská výška a přesnost) jako součást průzkumu."
---

Typ otázky `geopoint` zachycuje zeměpisné souřadnice (zeměpisná šířka, délka, nadmořská výška, přesnost) pomocí GPS zařízení. rtSurvey vykresluje výběr s několika režimy rozložení a podporuje automatizaci prostřednictvím parametrů `inputs{}` a `outputs{}`.

## Základní specifikace XLSForm

| type     | name        | label                       |
|----------|-------------|-----------------------------|
| geopoint | location    | Zaznamenejte aktuální polohu |

Pro standardní specifikaci viz [dokumentace XLSForm](https://xlsform.org/en/#question-types).

## Formát dat

Uloženo jako čtyři hodnoty oddělené mezerami:

```
zeměpisná_šířka zeměpisná_délka nadmořská_výška přesnost
```

Příklad: `13.756331 100.501762 15 8`

---

## Režimy rozložení

### Výchozí — obdélníkové tlačítko

Obdélníkové tlačítko "SPUSTIT GEOPOINT" otevře celoobrazovkové modální okno mapy, kde tazatel vybere bod. Po zachycení se popisek tlačítka změní na "Zobrazit nebo změnit geobod" a pod ním se objeví souřadnice.

Není potřeba žádná hodnota vzhledu.

---

### `display{inline-icon}` — kruhové tlačítko s nitkovým křížem

Vykreslí kruhové ikonové tlačítko (nitkový kříž ⊕) namísto obdélníkového tlačítka. Klepnutím na něj se otevře stejné modální okno mapy.

```
display{inline-icon}
```

**Kombinováno s pozicí a velikostí:**

```
display{inline-icon, left}           → tlačítko vlevo od popisku
display{inline-icon, top}            → tlačítko nad popiskem
display{inline-icon, bottom}         → tlačítko pod popiskem, vycentrováno
display{inline-icon, large}          → velká ikona (75px)
display{inline-icon, medium}         → střední ikona (50px)
display{inline-icon, left, large}    → velké tlačítko vlevo
```

| Velikost | Výška/šířka ikony |
|----------|-------------------|
| *(výchozí)* | 25px |
| `medium` | 50px |
| `large` | 75px |

---

### `display{thumbnail-square}` — živá miniatura mapy

Vykreslí živý náhled mapy (Leaflet) přímo na otázce namísto tlačítka. Miniatura zobrazuje aktuální polohu GPS a vybraný bod. Klepnutím na tlačítko pro rozbalení se otevře celé modální okno.

```
display{thumbnail-square}
```

**Vlastní velikost miniatury:**

```
display{thumbnail-square-[WxH]}          → pevné pixely
display{thumbnail-square-[400x200]}      → 400px široké × 200px vysoké

display{thumbnail-square-[W%xH%]}        → procenta šířky formuláře
display{thumbnail-square-[100%x30%]}     → celá šířka × 30% šířky formuláře
```

---

## `display{}` vs `results{}` — před a po zachycení

`display{}` řídí rozložení **před** tím, než uživatel zachytí polohu. `results{}` řídí rozložení **po** existenci hodnoty. Mohou mít různá zarovnání.

```
display{inline-icon, right} results{left}
```

Toto vykreslí tlačítko vpravo před zachycením a poté ho přesune vlevo, jakmile je bod zaznamenán.

### `hide(value)` — potlačení zobrazení souřadnic

Ve výchozím nastavení se zachycený text lat/lon/accuracy/altitude zobrazuje pod tlačítkem. Skryjte jej pomocí:

```
results{hide(value)}
display{inline-icon} results{hide(value)}
```

## `inputs{}` — automatizace GPS

### Automatické zachycení při načtení

Automaticky zaznamená polohu GPS při načtení formuláře, aniž by tazatel musel cokoli stisknout.

```
inputs{auto-take}
```

**Podmíněné automatické zachycení** pomocí výrazu XLSForm:

```
inputs{autotakeGeo(expression(if(${capture_now} = 'yes', true(), false())))}
```

### Předvyplnění z textového pole

Vyplňte geobod z otázky, která obsahuje název místa nebo řetězec adresy. rtSurvey provede reverzní geokódování řetězce na souřadnice pomocí OpenStreetMap Nominatim.

```
inputs{question(address_field)}
```

---

## `outputs{}` — reverzní geokódování na text

Po zachycení bodu automaticky vyplňte otázku typu `text` lidsky čitelnou adresou (reverzní geokódování ze souřadnic).

```
outputs{question(address_field)}
```

Příklad:

| type | name | label | appearance |
|------|------|-------|------------|
| geopoint | location | Zaznamenat polohu | `outputs{question(address_text)}` |
| text | address_text | Adresa | |

---

## `nomap` — zachycení GPS bez mapy

Nahradí modální okno mapy jednoduchým dialogem, který požaduje povolení polohy a zaznamenává souřadnice. Mapa se nezobrazuje. Užitečné pro zachycení pouze GPS na zařízeních nižší třídy nebo když mapové dlaždice nejsou dostupné offline.

```
nomap
```

## Osvědčené postupy

1. Použijte `inputs{auto-take}` pro průzkumy ověřování tazatele, kde je GPS povinná – odstraňuje ruční krok.
2. Použijte `display{thumbnail-square}`, když chcete, aby tazatel vizuálně potvrdil vybraný bod před pokračováním.
3. Spojte `outputs{question(...)}` s textovým polem `read-only` pro zobrazení reverzně geokódované adresy tazateli.
4. Použijte `nomap` v oblastech bez připojení k internetu, kde nelze načíst mapové dlaždice.
5. Před záznamem nechte čas na stabilizaci GPS – přesnost pod 10m je obvykle dostatečná pro terénní průzkumy.

## Omezení

- Geokódování `inputs{question(name)}` vyžaduje přístup k internetu – volá OpenStreetMap Nominatim API.
- Reverzní geokódování `outputs{question(name)}` také vyžaduje přístup k internetu.
- Miniatura mapy (`display{thumbnail-square}`) vyžaduje internet pro načítání dlaždic; souřadnice jsou stále zachycovány offline.
- Přesnost GPS se liší podle zařízení a prostředí – vnitřní nebo městské kaňonové podmínky mohou mít přesnost > 50 m.
- Sběr dat o poloze může výrazně ovlivnit životnost baterie zařízení během dlouhých průzkumů.

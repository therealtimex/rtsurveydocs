Typ otázky note v XLSForms a rtSurvey se používá pro zobrazení textu nebo médií jen pro čtení respondentovi průzkumu. Není to otázka, která vyžaduje odpověď, ale spíše způsob, jak poskytnout informace, pokyny nebo kontext v rámci průzkumu.

## Základní specifikace XLSForm

| type | name | label |
|------|------|-------|
| note | info_text | Tento průzkum se týká vašich čtenářských návyků. |

## Použití

Otázky note se běžně používají pro:

1. Poskytování pokynů nebo kontextu pro nadcházející otázky
2. Zobrazování vypočítaných výsledků nebo souhrnů
3. Zobrazení obrázků nebo jiných médií
4. Oddělování sekcí průzkumu
5. Poskytování zpětné vazby na základě předchozích odpovědí

## Osvědčené postupy

1. Udržujte text poznámky stručný a jasný pro zachování angažovanosti respondenta.
2. Používejte formátování (tučné písmo, kurzíva) pro zdůraznění důležitých informací.
3. Zvažte použití médií (obrázky, zvuk) pro zlepšení porozumění, kde je to vhodné.
4. Používejte poznámky střídmě, abyste se vyhnuli přeplnění průzkumu.

## Příklad použití

| type | name | label |
|------|------|-------|
| note | intro | Vítejte v našem průzkumu čtenářských návyků. Budeme se ptát na vaše preference a frekvenci čtení. |
| ... | ... | ... |
| calculate | books_per_month | `${fiction_books}` + `${non_fiction_books}` |
| note | reading_summary | Čtete přibližně `${books_per_month}` knih za měsíc. |

V tomto příkladu používáme poznámky k představení průzkumu a poskytnutí souhrnu vypočítaných výsledků.

## Rozšíření rtSurvey

rtSurvey rozšiřuje poznámky o:

1. Formátování RTF textu pomocí HTML tagů
2. Podporu vložených médií (obrázky, zvuk, video)
3. Dynamický obsah na základě předchozích odpovědí
4. Vlastní možnosti stylování

Viz [HTML stylování](../advanced-extension/html-styling) pro podrobnosti o použití HTML v popisках poznámek.

Typ otázky `calculate` spouští vzorec tiše na pozadí. Výsledek uloží do pojmenovaného pole, na které mohou odkazovat jiné otázky – tazateli se však nezobrazí žádný vstup ani popisek. Použijte jej k odvození hodnot, spojování řetězců, spouštění podmíněné logiky nebo vyhledávání dat, která budete potřebovat později ve formuláři.

---

## Základní syntaxe

| type | name | label | calculation |
|------|------|-------|-------------|
| calculate | total | | `${price} * ${quantity}` |

- **type**: Vždy `calculate`.
- **name**: Unikátní název pole. Ostatní otázky na něj odkazují pomocí `${name}`.
- **label**: Ponechte prázdné – pole typu calculate se tazateli nikdy nezobrazují.
- **calculation**: Vzorec k vyhodnocení. Podporuje všechny [funkce XLSForm](../operators-and-functions/functions) a odkazy na pole.

## Běžné vzorce

### Aristmetika

| type | name | label | calculation |
|------|------|-------|-------------|
| integer | price | Unit price | |
| integer | quantity | Quantity | |
| calculate | total | | `${price} * ${quantity}` |
| note | total_note | Total: `${total}` | |

### Spojování řetězců

| type | name | label | calculation |
|------|------|-------|-------------|
| text | first_name | First name | |
| text | last_name | Last name | |
| calculate | full_name | | `concat(${first_name}, ' ', ${last_name})` |

### Podmíněná hodnota

| type | name | label | calculation |
|------|------|-------|-------------|
| integer | score | Score (0–100) | |
| calculate | grade | | `if(${score} >= 90, 'A', if(${score} >= 75, 'B', if(${score} >= 60, 'C', 'F')))` |

### Věk z data narození

| type | name | label | calculation |
|------|------|-------|-------------|
| date | dob | Date of birth | |
| calculate | age_years | | `int((today() - ${dob}) div 365.25)` |

## Použití `once()` k uzamčení hodnoty

Ve výchozím nastavení se `calculate` přehodnocuje pokaždé, když se změní jakékoli odkazované pole. Zabalte vzorec do `once()`, aby se vyhodnotil pouze při prvním načtení a výsledek se zmrazil:

| type | name | label | calculation |
|------|------|-------|-------------|
| calculate | interview_start | | `once(now())` |

Použijte `once()` pro časová razítka, počáteční hodnoty nebo jakýkoli případ, kdy je přepočet při změně nežádoucí.

## Načítání dat z externích zdrojů

### Ze souboru CSV

```
pulldata('staff.csv', 'department', 'name', ${staff_id})
```

Úplnou referenci naleznete v části [pulldata()](../operators-and-functions/pulldata).

### Z přibalené databáze SQLite

```
pulldata('rawquery',
  concat(${family_path}, '/locations.db::provinces'),
  'SELECT name FROM provinces WHERE id = ?',
  ${province_id})
```

Podrobnosti o konstrukci cesty naleznete v části [Hledání v lokální databázi](../advanced-features/local-database-search).

### Z kontextu aplikace

```
pulldata('app-api', 'user.username')
pulldata('app-api', 'family_path')
```

Všechny dostupné klíče naleznete v části [App API](../app-api).

## Použití calculate v relevant a constraint

Ostatní pole mohou odkazovat na výsledek `calculate` stejně jako na jakékoli jiné pole:

| type | name | label | relevant | constraint |
|------|------|-------|----------|------------|
| calculate | bmi | | | `${weight} div (${height} * ${height}) * 10000` |
| note | bmi_warning | BMI is very high — please verify weight and height. | `${bmi} > 40` | |

## Osvědčené postupy

1. Pojmenovávejte pole calculate smysluplně – `total_cost` je jasnější než `calc1` a snadněji se sleduje v exportech.
2. Rozdělte složité vzorce do více řetězených polí calculate namísto jednoho hluboce vnořeného výrazu.
3. Používejте `once()` pro časová razítka a počáteční snímky, aby se zabránilo změnám hodnot po prvním zachycení.
4. Pole `calculate` umístěte před první otázku, která na ně odkazuje – pořadí vyhodnocování odpovídá pořadí ve formuláři.
5. Sloupec `label` ponechte prázdný. Některé nástroje popisek zobrazují; jeho ponechání prázdného zabrání matoucím výstupům.

## Omezení

- Pole Calculate se tazateli nikdy nezobrazují přímo – k zobrazení výsledku použijte pole `note`.
- Sloupec `calculation` je povinný; řádek `calculate` bez vzorce vždy ukládá prázdný řetězec.
- Výsledky se přehodnocují při každé změně formuláře, pokud nejsou zabaleny v `once()` – velmi složité vzorce ve velkých formulářích mohou ovlivnit výkon vykreslování na méně výkonných zařízeních.
- Vypočtené hodnoty se v odeslaných datech ukládají jako řetězce. Při předávání výsledku do aritmetických nebo logických výrazů použijte k přetypování `number()`, `int()` nebo `boolean()`.

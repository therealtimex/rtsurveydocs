XLSForm a rtSurvey výpočetní otázky se používají k provádění výpočtů na základě jiných polí nebo hodnot formuláře. Tyto otázky nejsou zobrazeny uživateli, ale jsou prováděny na pozadí a ukládají své výsledky pro pozdější použití nebo odeslání.

## Syntaxe

Výpočetní otázka XLSForm je definována následovně:

| type      | name     | label | calculation |
|-----------|----------|-------|-------------|
| calculate | calc_q1  |       | `${q1}` + `${q2}` |

- **type**: Pro tento typ otázky vždy "calculate".
- **name**: Jedinečný název výpočetní otázky.
- **label**: Obvykle se nechává prázdné, protože výpočetní otázky nejsou zobrazeny uživatelům.
- **calculation**: Vyhodnocovaný vzorec.

## Případy použití

Výpočetní otázky se často používají pro:

1. Provádění aritmetických operací
2. Spojování řetězců
3. Použití složité logiky nebo funkcí
4. Ukládání mezivýsledků pro pozdější použití

## Příklady

### Základní aritmetika

```
| type      | name     | calculation |
|-----------|----------|-------------|
| calculate | total    | ${price} * ${quantity} |
```

### Spojování řetězců

```
| type      | name     | calculation |
|-----------|----------|-------------|
| calculate | full_name| concat(${first_name}, ' ', ${last_name}) |
```

### Použití funkcí

```
| type      | name     | calculation |
|-----------|----------|-------------|
| calculate | age      | int((today() - ${date_of_birth}) / 365.25) |
```

## Pokročilé použití v rtSurvey

### Funkce pulldata()

rtSurvey podporuje funkci `pulldata()` ve výpočetních polích, což umožňuje získávat data z externích CSV souborů:

```
| type      | name     | calculation |
|-----------|----------|-------------|
| calculate | city     | pulldata('cities', 'city_name', 'zip_code', ${zip_input}) |
```

#### Syntaxe

Základní syntaxe pulldata() je:

```
pulldata('název_csv_souboru', 'vrácený_sloupec', 'klíčový_sloupec', ${odpovídající_hodnota})
```

- 'název_csv_souboru': Název CSV souboru (bez přípony .csv)
- 'vrácený_sloupec': Název sloupce obsahujícího data, která chcete získat
- 'klíčový_sloupec': Název sloupce pro shodu
- `${odpovídající_hodnota}`: Hodnota, kterou je třeba vyhledat v klíčovém sloupci (často proměnná z formuláře)

#### Důležité poznámky

1. CSV soubor musí být nahrán spolu s vaším XLSFormem při nasazování průzkumu.
2. V CSV souboru používejte čárky jako oddělovače, nikoli středníky.
3. Vyhněte se čárkám v datových polích CSV, protože mohou způsobit problémy se zpracováním.
4. pulldata() podporuje pouze vztahy 1 ku 1. Pokud je nalezeno více shod, vrátí se pouze první.
5. Mohou existovat omezení délky textu, který lze získat (kolem 76 znaků).
6. pulldata() můžete použít v omezeních pro ověřování vstupů proti datům z CSV.

### Podmíněné výpočty

Pro podmíněné výpočty můžete použít příkazy if():

```
| type      | name     | calculation |
|-----------|----------|-------------|
| calculate | discount | if(${total} > 1000, ${total} * 0.1, 0) |
```

## Nejlepší postupy

1. Používejte smysluplné názvy výpočetních polí pro zlepšení čitelnosti formuláře.
2. Vyhněte se příliš složitým výpočtům v jednom poli; v případě potřeby je rozdělte.
3. Důkladně otestujte své výpočty, zejména při použití složitých vzorců nebo externích dat.
4. Mějte na paměti, že výpočetní pole se provádí pokaždé, když je formulář vyhodnocen, což může ovlivnit výkon velmi složitých nebo velkoobjemových výpočtů.
5. Při použití pulldata() zajistěte, aby vaše soubory CSV byly správně naformátovány a důkladně otestujte s konkrétními daty a strukturou formuláře.

## Omezení

- Výpočetní pole nejsou přímo editovatelná uživateli.
- Výsledek výpočetního pole není okamžitě viditelný, pokud není specifikován ve zobrazovacím poli nebo použit v logice formuláře.

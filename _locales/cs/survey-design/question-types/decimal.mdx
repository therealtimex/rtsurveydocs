title: "Desetinné číslo"

---

Typ otázky `decimal` shromažďuje čísla, která mohou obsahovat desetinnou část (např. `3.14`, `72.5`). Na mobilních zařízeních se spustí numerická klávesnice a podporuje stejné možnosti vzhledu jako typ `text` pro rozložení a formátování.

## Základní specifikace XLSForm

| type | name | label |
|------|------|-------|
| decimal | weight_kg | Hmotnost (kg) |
| decimal | height_m | Výška (m) |
| decimal | temperature | Tělesná teplota (°C) |

Pro standardní specifikaci viz [dokumentace XLSForm](https://xlsform.org/en/#question-types).

---

## Možnosti vzhledu

### `number-hspinner` — horizontální volič

Nahrazuje vstup horizontálním voličem **− hodnota +**. Klepnutím na mínus/plus se hodnota upraví o nakonfigurovaný krok.

```
number-hspinner
```

Zobrazená hodnota je formátována na jedno desetinné místo (např. `3.0`, `72.5`). Výchozí krok je `1`; použijte `hspinner()` k nastavení desetinného kroku.

**Přizpůsobit tvar tlačítka a krok** pomocí `hspinner()`:

```
number-hspinner hspinner('left-small-square','right-small-square','0.1')
```

Parametry: tvar levého tlačítka, tvar pravého tlačítka, hodnota kroku. Pro přesné ovládání použijte desetinný krok jako `0.5` nebo `0.1`.

**Vlastní barvy** pomocí `colors()`:

```
number-hspinner colors(0099FF,FFFFFF,FF5500,FFFFFF)
```

Čtyři hodnoty v pořadí: pozadí levého tlačítka, ikona levého tlačítka, pozadí pravého tlačítka, ikona pravého tlačítka.

---

### `thousandsep` — oddělovač tisíců

Formátuje zobrazené číslo se seskupováním čárkou (např. `1,234.56`). Nezpracované číslo je uloženo bez čárek. Typ vstupu je přepnut na `"text"`, aby bylo umožněno formátované zobrazení.

```
thousandsep
```

---

### `digisep(n, "sep")` — vlastní seskupování číslic

Seskupuje číslice celočíselné části do bloků o velikosti `n` oddělených vlastním oddělovačem.

```
digisep(3," ")      → 1 234 567.89
```

Typ vstupu je přepnut na `"text"`, když je tato volba vzhledu aktivní.

---

### `textonly` — vynutí textovou klávesnici

Vynutí `type="text"` na vstupním prvku. Zabraňuje chybám prohlížeče při zadávání čísel (skrývání koncových nul, šipky pro zvýšení/snížení hodnoty na počítači) a přitom stále přijímá desetinné hodnoty.

```
textonly
```

---

### `floating_hint` — nápověda plave jako popisek

Text `hint` se vykreslí uvnitř vstupu jako zástupný text. Když uživatel začne psát, plave nad polem jako popisek.

```
floating_hint
```

---

### `embed` — nápověda uvnitř hranice vstupu

Podobné jako `floating_hint` – nápověda se nachází uvnitř hranice vstupu, když je prázdná. Když uživatel píše, neplave.

```
embed
```

---

### `textpopup` — vstup v modálním dialogu

Klepnutím na pole se otevře modální dialog s větším vstupním polem. Užitečné na malých obrazovkách.

```
textpopup
```

---

### `charcount` — živé počítadlo znaků

Zobrazuje živé počítadlo znaků `(n)` pod vstupním polem, které se aktualizuje, jak uživatel píše.

```
charcount
```

---

### `prefix(expr)` — připojení prefixu

Připojí statický nebo vypočítaný řetězec k zobrazené hodnotě. Uložená hodnota neobsahuje prefix.

```
prefix('USD ')          → zobrazí "USD 72.50", uloží "72.50"
prefix(${currency})     → dynamický prefix z jiného pole
```

---

### `align_answer` — zarovnání textu vstupu

Řídí vodorovné zarovnání zadané hodnoty uvnitř vstupu.

```
align_answer = left
align_answer = right
align_answer = center
```

---

### `inputs{qrscan}` — skenování QR / čárového kódu do pole

Přidá tlačítko pro skenování QR kódu vedle vstupu. Otevře skener kamery a vyplní pole naskenovanou hodnotou.

```
inputs{qrscan}
```

## Omezení a validace

| type | name | label | constraint | constraint_message |
|------|------|-------|------------|-------------------|
| decimal | weight | Hmotnost | `. > 0 and . <= 500` | Zadejte hodnotu mezi 0 a 500 |
| decimal | height | Výška | `. > 0 and . <= 3` | Zadejte hodnotu mezi 0 a 3 |
| decimal | temp | Teplota (°C) | `. >= 35 and . <= 42` | Normální teplota: 35°C–42°C |
| decimal | percentage | Procento | `. >= 0 and . <= 100` | Zadejte hodnotu mezi 0 a 100 |

## Příklad — formulář měření

| type | name | label | appearance | constraint | constraint_message |
|------|------|-------|------------|------------|-------------------|
| decimal | weight_kg | Hmotnost (kg) | `number-hspinner hspinner('left-small-square','right-small-square','0.5')` | `. > 0 and . <= 300` | Zadejte platnou hmotnost |
| decimal | height_m | Výška (m) | `number-hspinner hspinner('left-small-square','right-small-square','0.01')` | `. > 0 and . <= 3` | Zadejte platnou výšku |
| calculate | bmi | | | | |

Sloupec výpočtu BMI:
```
${weight_kg} div (${height_m} * ${height_m})
```

## Osvědčené postupy

1. Použijte `number-hspinner hspinner(..., '0.1')` pro měření vyžadující jednu desetinnou přesnost – volič automaticky formátuje na jedno desetinné místo, čímž udržuje hodnoty konzistentní.
2. Použijte `textonly`, když prohlížeče přidávají nežádoucí ovládací prvky pro posun nebo zkracují koncové nuly (např. `3.0` zobrazené jako `3`).
3. Použijte `thousandsep` pro velké finanční hodnoty, aby respondenti mohli ověřit, že zadali správnou velikost.
4. Vynucujte omezení rozsahu namísto spoléhání se pouze na typ mobilní klávesnice.

## Omezení

- Volič vždy zobrazuje jedno desetinné místo – pokud potřebujete větší přesnost v zobrazené hodnotě, použijte namísto něj jednoduchý vstup.
- `thousandsep` a `digisep()` ukládají nezpracované číslo – nečtěte formátovanou zobrazenou hodnotu ve výpočtech.

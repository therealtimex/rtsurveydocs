---
title: "Geoshape"
description: "Otázky typu geoshape zachycují uzavřený polygon definovaný sekvencí bodů GPS."
---

Typ otázky `geoshape` zachycuje uzavřený polygon — řadu souřadnic GPS, kde první a poslední bod jsou stejné. Ve webovém formuláři rtSurvey se tento typ vykresluje jako **textové pole**, kam tazatel přímo zadává nebo vkládá řetězec souřadnic.

## Základní specifikace XLSForm

| type     | name        | label                            |
|----------|-------------|----------------------------------|
| geoshape | field_area  | Nakreslete hranici pole          |
| geoshape | zone        | Zaznamenejte hranici zóny        |

Standardní specifikaci naleznete v [dokumentaci XLSForm](https://xlsform.org/en/#question-types).

---

## Formát dat

Ukládá se jako seznam bodů oddělených středníkem **bez mezer kolem středníků**. Každý bod tvoří čtyři hodnoty oddělené mezerou:

```
lat lon alt acc;lat lon alt acc;lat lon alt acc;lat lon alt acc
```

| Komponenta | Popis |
|-----------|-------------|
| `lat` | Zeměpisná šířka v desítkových stupních |
| `lon` | Zeměpisná délka v desítkových stupních |
| `alt` | Nadmořská výška v metrech (`0`, pokud není známa) |
| `acc` | Přesnost GPS v metrech (`0`, pokud není známa) |

**Polygon musí být uzavřený** — poslední bod se musí rovnat prvnímu bodu.

**Příklad — čtyřbodový polygon (trojúhelník, uzavřený):**
```
13.756331 100.501762 0 0;13.758000 100.503000 0 0;13.757000 100.506000 0 0;13.756331 100.501762 0 0
```

K vytvoření platného polygonu jsou zapotřebí minimálně tři odlišné body plus uzavírací opakování.

---

## Jak se vykresluje v rtSurvey

Ve webovém formuláři rtSurvey se `geoshape` vykresluje jako prosté **textové pole**. Tazatel napíše nebo vloží řetězec souřadnic. V současném webovém formuláři není pro tento typ vestavěný interaktivní výběr polygonu na mapě.

### Interaktivní sběr bodů polygonu

Doporučený vzor pro sběr v terénu je **skupina opakování otázek typu `geopoint`** — každý vrchol používá plnohodnotný výběr na mapě GPS — v kombinaci s výpočtem `calculate` pro vytvoření řetězce geoshape:

| type | name | label | calculation |
|------|------|-------|-------------|
| begin repeat | polygon_points | Zaznamenejte každý roh | |
| geopoint | point | Klepnutím zaznamenejte roh | |
| end repeat | polygon_points | | |
| calculate | geoshape_value | | `join(';', ${polygon_points/point})` |

Po spojení ručně připojte první bod pro uzavření polygonu nebo použijte druhý výpočet `calculate` k jeho zřetězení.

---

## Nejlepší postupy

1. Pro interaktivní sběr na mapě použijte skupinu opakování otázek typu `geopoint` a hodnoty spojte — tazatelé tak získají výběr GPS pro každý vrchol.
2. Před odesláním polygon vždy uzavřete (zopakujte první bod na konci).
3. Pokud je vyžadováno ruční zadání souřadnic, uveďte očekávaný formát do sloupce `hint`.
4. Vyžadujte alespoň 3 odlišné rohové body pro platný polygon — vynucujte to spíše pokyny než omezeními XLSForm.
5. `geopoint` používejte pro otázky s jedním umístěním a `geoshape` pouze tehdy, když je skutečným cílem průzkumu vymezení oblasti.

## Omezení

- Ve webovém formuláři rtSurvey není pro `geoshape` vestavěný interaktivní výběr polygonu na mapě.
- Polygon musí být uzavřen ručně — v režimu textového vstupu neexistuje žádný mechanismus automatického uzavírání.
- Validace topologie polygonu (např. neprotínání se, minimální plocha) vyžaduje následné zpracování mimo omezení XLSForm.
- Dlouhé hranice s mnoha vrcholy vytvářejí dlouhé textové řetězce.

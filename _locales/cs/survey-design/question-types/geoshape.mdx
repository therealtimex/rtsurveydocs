---
title: "Geotvar"
description: "Otázky typu Geoshape zaznamenávají uzavřený mnohoúhelník definovaný posloupností bodů GPS."
---

Typ otázky `geoshape` zachycuje uzavřený mnohoúhelník – řadu souřadnic GPS, kde první a poslední bod jsou stejné. Ve webovém formuláři rtSurvey se to zobrazuje jako **textové pole**, kam tazatel zadává nebo vkládá řetězec souřadnic přímo.

## Základní specifikace XLSForm

| type     | name        | label                            |
|----------|-------------|----------------------------------|
| geoshape | field_area  | Nakreslete hranici pole          |
| geoshape | zone        | Zaznamenejte hranici zóny        |

Standardní specifikaci naleznete v [dokumentaci XLSForm](https://xlsform.org/en/#question-types).

---

## Formát dat

Ukládá se jako středníkem oddělený seznam bodů **bez mezer kolem středníků**. Každý bod se skládá ze čtyř hodnot oddělených mezerou:

```
lat lon alt acc;lat lon alt acc;lat lon alt acc;lat lon alt acc
```

| Komponenta | Popis                                |
|------------|--------------------------------------|
| `lat`      | Zeměpisná šířka ve stupních          |
| `lon`      | Zeměpisná délka ve stupních          |
| `alt`      | Nadmořská výška v metrech (`0` pokud neznámá) |
| `acc`      | Přesnost GPS v metrech (`0` pokud neznámá) |

**Polygon musí být uzavřen** – poslední bod se musí rovnat prvnímu bodu.

**Příklad – čtyřbodový polygon (trojúhelník, uzavřený):**
```
13.756331 100.501762 0 0;13.758000 100.503000 0 0;13.757000 100.506000 0 0;13.756331 100.501762 0 0
```

K vytvoření platného polygonu jsou vyžadovány minimálně tři různé body plus uzavírací opakování.

---

## Jak se vykresluje v rtSurvey

Ve webovém formuláři rtSurvey se `geoshape` vykresluje jako obyčejné **textové pole**. Tazatel zadá nebo vloží řetězec souřadnic. V současné webové formě pro tento typ není vestavěný interaktivní nástroj pro výběr polygonu na mapě.

### Interaktivní sběr bodů polygonu

Doporučený vzor pro sběr v terénu je **opakovaná skupina otázek `geopoint`** – každý vrchol používá plný výběr GPS mapy – v kombinaci s `calculate` pro vytvoření řetězce geoshape:

| type | name | label | calculation |
|------|------|-------|-------------|
| begin repeat | polygon_points | Zaznamenejte každý roh | |
| geopoint | point | Klepněte pro zaznamenání rohu | |
| end repeat | polygon_points | | |
| calculate | geoshape_value | | `join(';', ${polygon_points/point})` |

Po spojení ručně připojte první bod pro uzavření polygonu, nebo použijte druhý `calculate` pro zřetězení.

| type | name | label | hint | required |
|------|------|-------|------|----------|
| geoshape | farm_boundary | Zaznamenejte hranici pole | Zadejte všechny rohy oddělené středníky. První a poslední bod musí být stejný. | yes |

---

## Nejlepší postupy

1. Použijte opakovanou skupinu otázek `geopoint` pro interaktivní sběr dat založený na mapě a spojte hodnoty – to poskytuje tazatelům GPS výběr pro každý vrchol.
2. Vždy uzavřete polygon (opakujte první bod na konci) před odesláním.
3. Pokud je vyžadováno ruční zadání souřadnic, uveďte očekávaný formát ve sloupci `hint`.
4. Pro platný polygon vyžadujte minimálně 3 různé rohové body – vynucujte to spíše prostřednictvím pokynů než omezení XLSForm.
5. Použijte `geopoint` pro otázky s jednou lokalitou a `geoshape` pouze tehdy, když je cílem průzkumu vymezení oblasti.

## Omezení

- Ve webovém formuláři rtSurvey není pro `geoshape` vestavěný interaktivní nástroj pro výběr polygonu na mapě.
- Polygon musí být uzavřen ručně – v režimu textového vstupu neexistuje automatický mechanismus uzavírání.
- Ověřování topologie polygonu (např. nekřížení se, minimální plocha) vyžaduje následné zpracování mimo omezení XLSForm.
- Dlouhé hranice s mnoha vrcholy vytvářejí velké textové řetězce.

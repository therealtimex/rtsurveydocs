---
title: "Čárový kód"
description: "Otázky s čárovým kódem skenují a zaznamenávají QR kódy a data čárových kódů ve vašem průzkumu."
---

Typ otázky `barcode` zachycuje hodnotu kódu skenováním QR kódu nebo čárového kódu pomocí fotoaparátu zařízení. Modální okno skeneru také obsahuje ruční textový vstup jako záložní řešení, když skenování není možné.

## Základní specifikace XLSForm

| type    | name         | label                    |
|---------|--------------|--------------------------|
| barcode | product_code | Naskenujte čárový kód produktu |
| barcode | ticket_id    | Naskenujte lístek         |

Pro standardní specifikaci viz [dokumentace XLSForm](https://xlsform.org/en/#question-types).

---

## Podporované formáty

rtSurvey podporuje QR kódy a standardní 1D čárové kódy pomocí fotoaparátu zařízení, včetně:

- QR Code
- UPC-A, UPC-E
- EAN-8, EAN-13
- Code 39, Code 128
- ITF, Codabar

---

## Výchozí rozložení

Bez nastaveného `appearance` se otázka vykreslí jako tlačítko **"ZÍSKAT ČÁROVÝ KÓD"** po celé šířce. Klepnutím na něj se otevře modální okno skeneru. Po úspěšném skenování se tlačítko změní na **"NAHRADIT ČÁROVÝ KÓD"** a naskenovaná hodnota se zobrazí níže jako klikatelný odkaz.

---

## Modální okno skeneru

Modální okno skeneru vždy obsahuje:
- **Živý náhled kamery** — skenuje automaticky po detekci; modální okno se zavře po úspěšném skenování.
- **Ruční textový vstup** — textové pole dole, kam může tazatel zadat kód, pokud skenování selže.
- **Tlačítko Hotovo** — odešle ručně zadanou hodnotu.

Pokud kamera zařízení není k dispozici, modální okno se přepne na možnost **"Nahrát obrázek"** — tazatel může odeslat fotografii čárového kódu k dekódování.

---

## Rozložení inline tlačítka

Přidejte `inline` pro vykreslení skeneru jako **kruhového ikonového tlačítka** vedle popisku namísto tlačítka po celé šířce.

```
| type    | name | label     | appearance                              |
|---------|------|-----------|----------------------------------------|
| barcode | code | Naskenovat položku | inline display{right}                  |
| barcode | code | Naskenovat položku | inline display{left, large}            |
| barcode | code | Naskenovat položku | inline display{center, large, <0099FF/>} |
```

**Pozice tlačítka** — `left`, `right` *(výchozí)*, `top`, `center`, `bottom`

**Velikost tlačítka** — `small` *(výchozí)*, `medium`, `large`

**Barva tlačítka** — přidejte hex barvu uvnitř `display{}` pro přepsání primární barvy:

```
inline display{right, large, <FF5500/>}
```

**Ovládání po zachycení — `results{}`:**

| Appearance | Effect |
|---|---|
| `results{hide(scanner)}` | Skryje tlačítko skeneru po zachycení hodnoty |
| `results{hide(review)}` | Skryje odkaz naskenované hodnoty po zachycení |
| `results{hide(value)}` | Skryje textové zobrazení naskenované hodnoty |
| `results{left}` | Přesune ikonu doleva po zachycení |

Příklad – skrytí skeneru po prvním skenování:
```
inline display{center, large} results{hide(scanner)}
```

---

## `inputs{auto-close(N)}` — automatické zavření skeneru

Automaticky zavře modální okno skeneru po `N` sekundách, pokud není detekován žádný čárový kód. Uvnitř modálního okna se zobrazí živý odpočítávací časovač.

```
inputs{auto-close(10)}     → zavře se po 10 sekundách
inputs{auto-close(5)}      → zavře se po 5 sekundách
```

Kombinace s inline:
```
inline display{right} inputs{auto-close(10)}
```

---

## `inputs{floating}` — plovoucí přetahovatelný skener

Zobrazí **tlačítko pro minimalizaci** (ikona komprese ⊞) v záhlaví modálního okna skeneru. Klepnutím na něj se skener sbalí do malé plovoucí kruhové ikony, kterou lze přetáhnout kamkoli na obrazovce. Klepnutím na plovoucí ikonu se skener znovu otevře.

```
inputs{floating}
inline display{right} inputs{floating}
```

Užitečné v pracovních postupech, kde tazatel potřebuje vidět formulář, zatímco je skener aktivní (např. skenování položek v seznamu).

---

## `invisible auto-show` — automatické otevření skeneru

Skryje widget otázky z rozložení, ale automaticky otevře skener při načtení stránky. Užitečné pro vložení tichého kroku skenování do toku formuláře.

```
invisible auto-show
inline invisible auto-show
```

---

## Ve skupinách opakování

Když je `barcode` uvnitř skupiny `begin repeat`, úspěšné skenování automaticky přejde na **další instanci opakování** po zaznamenání hodnoty. To umožňuje rychlé sekvenční skenování, aniž by tazatel musel klepnout na "Přidat" mezi položkami.

## Osvědčené postupy

1. Použijte `inputs{auto-close(N)}` k zabránění tomu, aby skener zůstal otevřený neomezeně dlouho — zvolte hodnotu, která dává tazatelům dostatek času na umístění čárového kódu (typicky 8–15 sekund).
2. Použijte `inputs{floating}`, když formulář musí zůstat viditelný během skenování (např. skenování ze seznamu, kde tazatel křížově odkazuje na viditelné pole).
3. Umístěte otázku s čárovým kódem do skupiny opakování pro rychlé sekvenční skenování — automatické pokročení opakování eliminuje ruční krok "Přidat".
4. Vždy uveďte sloupec `hint` s pokyny k umístění (např. "Držte čárový kód ve vzdálenosti 10–30 cm od kamery, při dobrém osvětlení").
5. Ruční textový vstup v modálním okně skeneru je vždy k dispozici — vyškolte tazatele, aby jej používali jako záložní řešení pro poškozené nebo špinavé čárové kódy.

## Omezení

- Přesnost skenování závisí na kvalitě fotoaparátu, osvětlení a stavu čárového kódu — poškozené nebo málo kontrastní kódy se nemusí spolehlivě skenovat.
- Skener používá zadní (na prostředí směřující) kameru; zařízení bez zadní kamery se přepnou na možnost nahrání obrázku.
- `invisible auto-show` se otevře pouze při prvním načtení stránky; navigace zpět na stránku znovu nespustí automatické otevření.

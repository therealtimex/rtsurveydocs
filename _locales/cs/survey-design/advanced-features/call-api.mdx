title: "Volání API"
description: "Volání API umožňuje vašemu průzkumu získávat data z externí webové služby a používat odpověď k vyplnění polí nebo ověření odpovědí."
---

Funkce **Volání API** umožňuje poli průzkumu provést HTTP požadavek na externí službu a použít odpověď k naplnění vypočítané hodnoty nebo ověření uživatelského vstupu. To umožňuje vyhledávání v reálném čase, ověřování ID, vyhledávání čárových kódů a jakékoli další kontroly na straně serveru během sběru dat.

Existují dvě funkce:

- `callapi()` – načte hodnotu z API a uloží ji do pole typu `calculate` nebo `text`
- `callapi-verify()` – volá API a blokuje postup, pokud odpověď neodpovídá očekávané hodnotě (používá se v `constraint`)

---

## `callapi()` – Načtení a uložení odpovědi API

### Syntaxe

Umístěte `callapi()` do sloupce **`calculation`** pole typu `calculate` nebo `text`:

```
callapi(method, url, allowed_auto, max_retry, no_overwrite, extract_expr, timeout, lifetime, response_q, call_type, post_body)
```

### Parametry

| # | Parametr | Popis                                                                      |
|---|----------|----------------------------------------------------------------------------|
| 1 | `method` | HTTP metoda: `'GET'` nebo `'POST'`                                        |
| 2 | `url` | URL koncového bodu API                                                    |
| 3 | `allowed_auto` | `1` pro automatické volání při dosažení pole; `0` pro manuální spouštěcí tlačítko |
| 4 | `max_retry` | Maximální počet opakování při selhání                                   |
| 5 | `no_overwrite` | `1` pro zachování existující hodnoty, pokud pole již nějakou má; `0` pro vždy přepsání |
| 6 | `extract_expr` | Výraz JSONPath pro extrakci požadované hodnoty z odpovědi (např. `$.data.name`) |
| 7 | `timeout` | Časový limit požadavku v milisekundách                                   |
| 8 | `lifetime` | Jak dlouho (ms) zůstane cachovaná odpověď platná před opětovným načtením |
| 9 | `response_q` | Název pole pro uložení nezpracovaného kódu HTTP odpovědi (např. `${response_status}`) |
| 10 | `call_type` | *(Volitelné)* Speciální režim volání: `'lazy-upload'` nebo `'lazy-upload-multiple'` |
| 11 | `post_body` | *(Volitelné)* Řetězec těla POST. Odkazujte na pole formuláře pomocí `##fieldname##` |

### Příklad: GET požadavek pro vyhledání domácnosti podle ID

| type | name | label | appearance | calculation |
|------|------|-------|------------|-------------|
| text | household_id | ID domácnosti | | |
| calculate | hh_name | | callapi | `callapi('GET', concat('https://api.example.com/households/', ${household_id}), 1, 3, 0, '$.name', 10000, 0, '')` |
| note | hh_display | Domácnost: `${hh_name}` | | |

### Příklad: POST požadavek s tělem JSON

```
callapi('POST', 'https://api.example.com/lookup', 1, 2, 0, '$.result.value', 15000, 0, '', '', '{"id": "##household_id##"}')
```

V `post_body` použijte `##fieldname##` pro vložení aktuální hodnoty libovolného pole formuláře.

### Vzhled: `callapi`

Přidejte `callapi` do sloupce `appearance` pole, abyste povolili integraci volání API:

| type | name | label | appearance | calculation |
|------|------|-------|------------|-------------|
| calculate | api_result | | callapi | `callapi('GET', ...)` |

Když je `allowed_auto` nastaveno na `0`, rtSurvey zobrazí **tlačítko "Načíst"**, které tazatel klepne ručně.

## `callapi-verify()` – Ověření hodnoty proti API

`callapi-verify()` blokuje odeslání pole, dokud API nepotvrdí, že zadaná hodnota je platná. Použijte ji ve sloupci **`constraint`**.

### Syntaxe

```
callapi-verify(method, url, extract_expr, match_expr, timeout, constraint_mode, post_body, message)
```

### Parametry

| # | Parametr | Popis                                                                      |
|---|----------|----------------------------------------------------------------------------|
| 1 | `method` | HTTP metoda: `'GET'` nebo `'POST'`                                        |
| 2 | `url` | URL koncového bodu pro ověření                                             |
| 3 | `extract_expr` | JSONPath pro extrakci očekávané hodnoty z odpovědi                     |
| 4 | `match_expr` | Výraz porovnávající extrahovanou hodnotu s hodnotou pole (např. `$.status = 'valid'`) |
| 5 | `timeout` | Časový limit požadavku v milisekundách                                   |
| 6 | `constraint_mode` | `'soft'` pro pouze varování; `'hard'` pro blokování postupu            |
| 7 | `post_body` | *(Volitelné)* Tělo POST s náhradami `##fieldname##`                    |
| 8 | `message` | *(Volitelné)* Chybová zpráva. Podporuje vícejazyčnost: `<en>Invalid!</en><vi>Không hợp lệ!</vi>` |

### Příklad: Ověření čárového kódu proti registru majetku

| type | name | label | appearance | constraint | constraint_message |
|------|------|-------|------------|------------|-------------------|
| barcode | asset_code | Naskenujte čárový kód majetku | callapi-verify | `callapi-verify('POST', 'https://api.example.com/assets/verify', '$.valid', ". = 'true'", 10000, 'hard', '{"code": "##asset_code##"}')` | Majetek nebyl nalezen v registru |

### Vzhled: `callapi-verify(...)`

Sloupec `appearance` u pole s `callapi-verify()` v `constraint` by měl obsahovat `callapi-verify(params)` nebo `callapi-verify(dynamicParams)`, aby signalizoval rtSurvey, že toto pole používá ověřování API.

## Používání dat App API spolu s callapi

Zkombinujte `callapi()` s `pulldata('app-api', 'user.token')`, abyste vložili token ověřeného uživatele do vašeho API požadavku:

```
callapi('POST', 'https://api.example.com/data', 1, 2, 0, '$.value', 10000, 0, '', '',
  concat('{"token":"', pulldata('app-api','user.token'), '","id":"##item_id##"}'))
```

## Nejlepší postupy

1. Vždy nastavte rozumný `timeout` (5000–15000 ms) – nepoužívejte 0 nebo velmi vysoké hodnoty.
2. Nastavte `allowed_auto=0` pro ověřování, které by měl tazatel spouštět vědomě (např. kontroly ID).
3. Nastavte `no_overwrite=1`, když pole může být později editováno a nechcete, aby opětovné načtení přepsalo ruční opravy.
4. Použijte `extract_expr` se specifickým JSONPath, spíše než se spoléhat na nezpracovaný text odpovědi.
5. Testujte volání API v offline režimu – callapi selže elegantně a zobrazí chybu, ale formulář by měl být stále dokončitelný pro nekritická pole.

## Omezení

- Vyžaduje síťové připojení v době volání – volání selžou, když je zařízení offline.
- Odpovědi API musí být JSON – odpovědi ve formátu XML nebo prostého textu vyžadují dodatečnou analýzu.
- Vysoká frekvence volání (např. jedno volání API na instanci opakování) může zpomalit navigaci ve formuláři.

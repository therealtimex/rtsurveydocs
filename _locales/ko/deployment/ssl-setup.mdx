로그인하기 전에 SSL을 구성해야 합니다. 앱을 처음 열면 SSL 설정 화면으로 자동 리디렉션됩니다.

---

## SSL 설정 옵션

![SSL 설정 옵션](/img/ssl-setup/ssl-setup-options.png)

세 가지 옵션 중 하나를 선택하십시오.

| 옵션 | 사용 시기 |
|--------|-------------|
| **무료 rtsurvey.com 서브도메인** *(권장)* | DNS 설정이 필요하지 않습니다. 저희가 레코드를 생성해 드립니다. 2~5분 내에 준비됩니다. |
| **자체 도메인** | 이미 도메인이 있고 해당 DNS가 이 서버를 가리키고 있는 경우. |
| **수동으로 인증서 설치** | 엔터프라이즈 또는 커스텀 CA. SSH 액세스가 필요합니다. |

---

## 옵션 1 — 무료 rtsurvey.com 서브도메인 *(권장)*

가장 빠른 옵션입니다. 도메인 등록이나 DNS 변경이 필요하지 않습니다.

![HTTPS 설정 양식](/img/ssl-setup/ssl-setup-form.png)

> **계속하기 전에:** 무료 서브도메인을 사용하려면 [licenses.rtsurvey.com](https://licenses.rtsurvey.com)에 활성 계정이 있어야 합니다. 무료 요금제에는 서브도메인 1개(`*.rtsurvey.com`)가 포함됩니다.

1. **Free rtsurvey.com subdomain**을 클릭하여 섹션을 확장합니다.
2. **YOUR SUBDOMAIN** 필드에 원하는 서브도메인 이름을 입력합니다.

   > 소문자, 숫자, 하이픈을 사용하십시오. 3~30자.
   > 예: `myproject` → `myproject.rtsurvey.com`

3. [licenses.rtsurvey.com](https://licenses.rtsurvey.com)에서 받은 **rtSurvey DNS Token**을 토큰 필드에 붙여넣습니다.
4. **Create secure subdomain**을 클릭합니다.

제출하면 앱에서 인증서 프로비저닝을 시작합니다.

![HTTPS 설정 진행 상황](/img/ssl-setup/ssl-setup-progress.png)

다음 네 단계가 자동으로 실행됩니다.
- **DNS 레코드 요청** — 서브도메인의 DNS 항목을 생성합니다.
- **DNS 전파 대기** — 보통 2~5분 정도 소요됩니다.
- **SSL 인증서 발급** — Let's Encrypt에서 인증서에 서명합니다.
- **HTTPS 활성화** — 새 인증서로 Nginx를 다시 로드합니다.

5. 완료되면 새 HTTPS URL로 자동 리디렉션됩니다.

## 옵션 2 — 자체 도메인

기존 도메인이 있고 해당 DNS `A` 레코드가 이미 이 서버의 IP를 가리키고 있는 경우 이 옵션을 사용하십시오.

1. **My own domain**을 클릭하여 섹션을 확장합니다.
2. 전체 도메인 이름을 입력합니다(예: `survey.myorganization.org`).
3. **Create certificate**를 클릭합니다.



Let's Encrypt에서 도메인을 확인하고 인증서를 발급합니다. 이를 위해서는 DNS가 먼저 올바르게 설정되어 있어야 합니다. 그렇지 않으면 요청이 실패합니다.

---

## 옵션 3 — 수동으로 인증서 설치

커스텀 또는 내부 CA를 사용하는 엔터프라이즈 환경용입니다. SSH를 통해 서버에 인증서 파일을 배치한 다음 앱에 도메인을 입력합니다.

### 전제 조건

- 서버에 대한 SSH 액세스
- 도메인에 대한 유효한 인증서 및 개인 키(PEM 형식)

### 1단계 — 서버에 SSH 접속

```bash
ssh root@<server-ip>
```

### 2단계 — 인증서 파일 배치

디렉토리를 생성하고 파일을 복사합니다.

```bash
mkdir -p /etc/letsencrypt/live/<your-domain>
```

해당 디렉토리에 다음 이름으로 파일을 복사합니다.

| 파일 | 설명 |
|------|-------------|
| `fullchain.pem` | 인증서 + 중간 CA 인증서(하나로 합쳐진 형태) |
| `privkey.pem` | 개인 키 |

예시:

```bash
# 로컬 머신에서 복사(서버가 아닌 로컬에서 실행)
scp fullchain.pem root@<server-ip>:/etc/letsencrypt/live/<your-domain>/fullchain.pem
scp privkey.pem  root@<server-ip>:/etc/letsencrypt/live/<your-domain>/privkey.pem
```

올바른 권한 설정:

```bash
chmod 644 /etc/letsencrypt/live/<your-domain>/fullchain.pem
chmod 600 /etc/letsencrypt/live/<your-domain>/privkey.pem
```

### 3단계 — 앱에 도메인 입력



1. SSL 설정 화면에서 **Install certificate manually**를 클릭합니다.
2. 도메인 이름을 입력합니다(인증서의 Common Name 또는 SAN과 일치해야 함).
3. **Apply**를 클릭합니다.

서버가 인증서로 Nginx를 구성하고 자동으로 다시 로드합니다.

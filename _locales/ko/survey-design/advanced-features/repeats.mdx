이 페이지에서는 rtSurvey의 반복 그룹(repeat groups) 작업에 대한 고급 패턴을 다룹니다. 반복 그룹 설정의 기본 사항은 [그룹화 및 반복](../repeats)을 참조하십시오.

---

## 동적 반복 횟수

기본적으로 조사원이 반복 횟수를 결정합니다. `repeat_count`를 사용하여 반복 횟수를 고정할 수 있습니다.

| type | name | label | repeat_count |
|------|------|-------|--------------|
| begin_repeat | household_members | 가구원 | `${num_members}` |
| text | member_name | 구성원 이름 | |
| integer | member_age | 연령 | |
| end_repeat | | | |

반복은 양식 앞부분에서 수집된 `${num_members}` 값만큼 정확히 실행됩니다. 조사원은 인스턴스를 추가하거나 삭제할 수 없습니다.

---

## 인덱스 기반 액세스: `indexed-repeat()`

`indexed-repeat(repeatedField, repeatGroup, index)`를 사용하여 반복 그룹 **외부**에서 특정 반복 인스턴스의 필드 값에 액세스합니다.

| type | name | label | calculation |
|------|------|-------|-------------|
| calculate | first_name | | `indexed-repeat(${member_name}, ${household_members}, 1)` |
| calculate | second_name | | `indexed-repeat(${member_name}, ${household_members}, 2)` |

이는 요약 필드를 작성하거나 반복 종료 후 "주요" 구성원의 데이터를 참조하는 데 유용합니다.

---

## 현재 인스턴스 위치: `index()`

반복 그룹 내에서 `index()`는 현재 인스턴스의 1부터 시작하는 위치를 반환합니다. 이를 사용하여 각 반복에 레이블을 지정하거나 고유 식별자를 만듭니다.

| type | name | label |
|------|------|-------|
| begin_repeat | plots | 필지 |
| note | plot_label | 필지 번호 `${index()}` |
| text | plot_id | 필지 ID |
| end_repeat | | |

## 동일 인스턴스 내 필드 참조

반복 내에서 `${fieldname}`을 사용하여 **동일한 반복 인스턴스**의 다른 필드를 참조합니다. 동일한 루프 내에서는 `indexed-repeat()`를 사용할 필요가 없습니다.

| type | name | label | relevant |
|------|------|-------|----------|
| begin_repeat | members | 구성원 | |
| text | member_name | 이름 | |
| integer | member_age | 연령 | |
| text | school_name | 학교 이름 | `${member_age} < 18` |
| end_repeat | | | |

---

## 반복 내부에서 부모 필드 참조

반복 그룹 외부(위쪽)에 있는 필드는 일반적인 `${fieldname}` 형식을 사용하여 참조할 수 있습니다.

| type | name | label |
|------|------|-------|
| text | village | 마을 이름 |
| begin_repeat | plots | 농지 필지 |
| note | plot_context | `${village}`의 필지 |
| end_repeat | | |

## 반복 데이터 요약

반복 그룹 **외부**에서 반복 집계 함수를 사용하여 데이터를 요약합니다.

| 함수 | 예시 | 설명 |
|----------|---------|-------------|
| `count(group)` | `count(${household_members})` | 인스턴스 수 |
| `sum(field)` | `sum(${loan_amount})` | 숫자 필드의 합계 |
| `min(field)` | `min(${member_age})` | 최솟값 |
| `max(field)` | `max(${member_age})` | 최댓값 |
| `join(sep, field)` | `join(', ', ${member_name})` | 쉼표로 구분된 목록 |
| `count-if(group, expr)` | `count-if(${members}, ${member_age} < 18)` | 조건부 카운트 |
| `sum-if(field, expr)` | `sum-if(${loan_amount}, ${loan_amount} > 500)` | 조건부 합계 |
| `join-if(sep, field, expr)` | `join-if(', ', ${name}, ${age} >= 18)` | 조건부 결합 |

### 예시: 가구 요약

| type | name | label | calculation |
|------|------|-------|-------------|
| integer | num_members | 가구원이 몇 명입니까? | |
| begin_repeat | members | 구성원 | `${num_members}` |
| text | member_name | 이름 | |
| integer | member_age | 연령 | |
| end_repeat | | | |
| calculate | total_members | | `count(${members})` |
| calculate | children_count | | `count-if(${members}, ${member_age} < 18)` |
| calculate | adult_names | | `join-if(', ', ${member_name}, ${member_age} >= 18)` |
| note | summary | 구성원 `${total_members}`명, 18세 미만 `${children_count}`명. 성인: `${adult_names}` | |

## 중첩된 반복 (Nested repeats)

반복 그룹 안에 다른 반복 그룹을 포함할 수 있습니다. 중첩된 반복은 복잡성을 증가시키고 조사원에게 혼란을 줄 수 있으므로 주의해서 사용하십시오.

| type | name | label |
|------|------|-------|
| begin_repeat | households | 가구 |
| text | hh_id | 가구 ID |
| begin_repeat | hh_members | 구성원 |
| text | member_name | 구성원 이름 |
| end_repeat | | |
| end_repeat | | |

내부 반복에서 외부 반복의 필드를 참조하려면 `${fieldname}`을 사용합니다. 이는 가장 가까운 조상 필드로 확인됩니다.

`hh_members` 반복 내에서 `${hh_id}`는 모든 가구가 아닌 **현재** 가구의 ID를 반환합니다.

---

## 반복 그룹 내 순위: `rank-index()`

반복 내에 `rank` 필드가 있는 경우, 외부에서 `rank-index(instanceNumber, repeatedField)`를 사용하여 특정 인스턴스의 서수 순위를 가져옵니다.

| type | name | label | calculation |
|------|------|-------|-------------|
| calculate | top_scorer | | `rank-index(1, ${score})` |

`rank-index(1, ${score})`는 최고 점수의 인스턴스 인덱스를 반환합니다.

---

## `begin_repeat`의 `1screen` 스타일

`begin_repeat` 행의 `appearance` 열에 `1screen`을 추가하면 각 인스턴스의 모든 질문이 화면당 한 질문이 아니라 한 화면에 함께 표시됩니다.

| type | name | label | appearance |
|------|------|-------|------------|
| begin_repeat | household_members | 가구원 | `1screen` |
| text | member_name | 구성원 이름 | |
| integer | member_age | 연령 | |
| end_repeat | | | |

`1screen`이 설정되어 있고 그룹 내에 `repeat_count`와 `add_repeat` 필드가 없는 경우, rtSurvey는 화면 하단에 원형 **+** 버튼을 자동으로 생성하여 조사원이 추가 구성 없이 새 인스턴스를 추가할 수 있도록 합니다.

| 스타일 | 인스턴스당 한 화면 | 기본 + 버튼 추가됨 |
|------------|-------------------------|------------------------|
| `1screen` | 예 | 예 (`add_repeat` 자식 필드가 없을 때) |
| `field-list` | 예 | 아니요 |

자동 추가 버튼 없이 그룹화된 레이아웃을 원할 때는 `field-list`를 사용하십시오. 그룹화된 레이아웃과 인스턴스 추가를 위한 내장 방식이 모두 필요할 때는 `1screen`을 사용하십시오.

---

## `add_repeat` 사용자 정의 추가 버튼

반복 그룹 **내부**에 `appearance: add_repeat` 스타일의 `note`(또는 `text`) 필드를 배치하면 화면 전체 너비의 "추가" 버튼으로 표시됩니다. 버튼 레이블은 해당 필드의 `label` 열에서 가져옵니다. `add_repeat` 필드가 있으면 (`1screen`의) 기본 원형 + 버튼이 표시되지 않습니다.

`add_repeat` 필드를 반복 그룹의 마지막 필드로 배치하십시오.

| type | name | label | appearance |
|------|------|-------|------------|
| begin_repeat | members | 구성원 | `1screen` |
| text | member_name | 구성원 이름 | |
| integer | member_age | 연령 | |
| note | btn_add | + 구성원 추가 | `add_repeat` |
| end_repeat | | | |

### 색상 사용자 정의

스타일을 지정하려면 스타일 값 내에 색상 코드를 전달하십시오.

| 스타일 값 | 결과 |
|------------------|--------|
| `add_repeat <#04B404/>` | 녹색 배경, 기본 텍스트 색상 |
| `add_repeat 04B404-ffffff` | 녹색 배경, 흰색 텍스트 |

첫 번째 색상은 배경이고 두 번째 색상(대시 다음)은 텍스트 색상입니다. 대시 구분 형식을 사용할 때는 `#`을 생략하십시오.

### 아이콘 변형

전체 너비 버튼 대신 컴팩트한 원형 아이콘 버튼을 표시하려면 `add_repeat icon`(공백 포함)을 사용하십시오.

| type | name | label | appearance |
|------|------|-------|------------|
| note | btn_add | + 추가 | `add_repeat icon` |

## 삭제 버튼: `delete-repeat-current` 및 `delete-repeat-last`

반복 그룹 내부에 `appearance: delete-repeat-current` 또는 `appearance: delete-repeat-last` 스타일의 `note` 필드를 배치하면 분할된 삭제 버튼으로 표시됩니다.

| 스타일 | 동작 |
|------------|--------|
| `delete-repeat-current` | 현재(활성) 인스턴스를 삭제 |
| `delete-repeat-last` | 반복의 마지막 인스턴스를 삭제 |

기본(비아이콘) 버튼은 분할 버튼입니다. 왼쪽에는 휴지통 아이콘, 오른쪽에는 해당 필드의 레이블 텍스트가 화면 전체 너비에 걸쳐 표시됩니다.

### 아이콘 변형

컴팩트한 원형 휴지통 아이콘 버튼을 사용하려면 `-icon`을 추가하십시오.

| 스타일 | 결과 |
|------------|--------|
| `delete-repeat-current-icon` | 원형 휴지통 아이콘, 현재 인스턴스 삭제 |
| `delete-repeat-last-icon` | 원형 휴지통 아이콘, 마지막 인스턴스 삭제 |

### 색상 사용자 정의

색상 형식은 `add_repeat`와 동일합니다. `<#RRGGBB/>` 또는 `RRGGBB-RRGGBB`(배경-텍스트) 형식을 사용하십시오.

### 전체 패턴 예시

다음 반복 그룹은 `1screen`, 상단의 원형 현재 인스턴스 삭제 버튼, 하단의 전체 너비 추가 버튼을 사용합니다.

| type | name | label | appearance |
|------|------|-------|------------|
| begin_repeat | members | 구성원 | `1screen` |
| note | btn_del | 삭제 | `delete-repeat-current-icon` |
| text | member_name | 구성원 이름 | |
| integer | member_age | 연령 | |
| note | btn_add | + 구성원 추가 | `add_repeat` |
| end_repeat | | | |

## 권장 사항 (Best Practices)

1. 반복 횟수가 사전에 알려진 경우 항상 `repeat_count`를 사용하십시오. 조사원이 실수로 인스턴스를 추가하거나 삭제하는 것을 방지합니다.
2. 반복 그룹을 간결하게 유지하십시오. 인스턴스당 질문이 20개 이상인 반복은 탐색하기 어렵습니다.
3. 반복 그룹의 이름을 명확하게 지정하십시오(예: `repeat1`이 아닌 `household_members`). 이 이름은 함수 호출 및 내보낸 데이터에 나타납니다.
4. 성능 확인을 위해 예상되는 최대 인스턴스 수로 테스트하십시오.
5. 인스턴스당 모든 질문을 한 화면에 보여주려면 `begin_repeat`에 `1screen`을 사용하고, 그룹 내에 `add_repeat` note 필드를 함께 사용하여 조사원에게 명확하게 레이블이 지정된 "추가" 버튼을 제공하십시오.

## 제한 사항

- `indexed-repeat()`는 유효한 인덱스(1부터 인스턴스 수까지)가 필요합니다. 범위를 벗어난 인덱스는 빈 값을 반환합니다.
- 2단계를 초과하는 중첩 반복은 권장되지 않으며 일부 클라이언트에서 표시 문제가 발생할 수 있습니다.
- 집계 함수(`sum`, `count` 등)는 전체 반복 그룹에 대해 작동합니다. `*-if` 변형 없이는 인스턴스의 하위 집합을 집계할 수 없습니다.

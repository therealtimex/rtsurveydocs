오디오 녹음 기능을 사용하면 설문 조사의 특정 섹션 동안 오디오를 조용히 또는 명시적으로 캡처할 수 있습니다. 인터뷰 기록, 현장 관찰 중 주변 소음 또는 구조화된 답변을 보완하는 구두 응답을 녹음하는 데 유용합니다.

## 작동 원리

오디오 녹음은 **마커** 역할을 하는 두 개의 `text` 필드에 의해 제어됩니다.

- `audio-start` 외형을 가진 필드는 조사원이 해당 필드에 도달할 때 녹음을 시작합니다.
- `audio-end` 외형을 가진 필드는 녹음을 중지하고 오디오 파일을 제출물(submission)에 저장합니다.

두 마커 필드 모두 `text` 유형입니다. 일반적으로 조사원에게는 보이지 않도록 숨겨지지만(`relevant = false` 사용 또는 비대화형 위치에 배치), 보이게 설정할 수도 있습니다. 녹음된 오디오는 `audio-end` 필드와 연결된 파일로 제출물에 첨부됩니다.

---

## 기본 예시

| type | name | label | appearance |
|------|------|-------|------------|
| text | audio_s_a1 | | `audio-start` |
| text | q_name | 응답자 이름 | |
| text | q_occupation | 직업 | |
| integer | q_age | 연령 | |
| text | audio_e_a1 | | `audio-end` |

앱은 조사원이 `audio_s_a1`에 도달하면 녹음을 시작하고 `audio_e_a1`에 도달하면 중지합니다. 두 마커 사이의 모든 질문이 녹음됩니다.

---

## 무음 녹음: `audio-start invisible`

기본적으로 모바일 앱은 오디오가 캡처되는 동안 녹음 표시기를 화면에 표시합니다. 외형에 `invisible`을 추가하면 이 표시기가 사라지므로 응답자에게 시각적인 알림 없이 녹음이 진행됩니다.

| type | name | label | appearance |
|------|------|-------|------------|
| text | audio_s_a1 | | `audio-start invisible` |
| text | q_consent | 조사 참여에 동의하십니까? | |
| text | q_feedback | 피드백 | |
| text | audio_e_a1 | | `audio-end` |

`invisible`은 다른 수단(예: 녹음 섹션 전의 별도 서면 동의 필드)을 통해 고지 요구 사항이 충족된 경우에만 사용하십시오.

## 명명 규칙

프로덕션 폼에서는 마커 필드에 대해 일관된 명명 패턴을 사용합니다.

```
audio_s_{section}{n}   — 시작 마커
audio_e_{section}{n}   — 종료 마커
```

여기서 `{section}`은 폼 섹션의 짧은 레이블이고 `{n}`은 해당 섹션 내의 순차적인 번호입니다.

| 필드 이름 | 역할 | 의미 |
|------------|------|---------|
| `audio_s_a1` | 시작 | 섹션 A의 첫 번째 녹음 |
| `audio_e_a1` | 종료 | 섹션 A의 첫 번째 녹음 종료 |
| `audio_s_b1` | 시작 | 섹션 B의 첫 번째 녹음 |
| `audio_e_b1` | 종료 | 섹션 B의 첫 번째 녹음 종료 |
| `audio_s_a2` | 시작 | 섹션 A의 두 번째 녹음 |
| `audio_e_a2` | 종료 | 섹션 A의 두 번째 녹음 종료 |

이 규칙을 따르면 폼 정의와 제출 데이터를 검토할 때 녹음 범위를 쉽게 식별할 수 있습니다.

## 저장 및 검색

조사원이 `audio-end` 필드에 도달하면 앱은 오디오 파일을 완성하여 제출물에 첨부합니다. 파일은 다음과 같습니다.

- 제출물의 오디오 첨부 파일로 저장되며, `audio-end` 필드 이름과 연결됩니다.
- rtSurvey 백엔드 제출물 뷰어에서 다른 미디어 첨부 파일과 함께 확인할 수 있습니다.
- 표준 제출물 내보내기를 통해 다운로드할 수 있습니다. 오디오 파일은 `audio-end` 필드 이름에 해당하는 미디어 열에 나타납니다.

파일 형식과 비트레이트는 장치 및 앱 버전에 따라 다릅니다.

---

## 여러 녹음 섹션

하나의 폼에 겹치지 않는 여러 녹음 섹션을 포함할 수 있습니다. 각 `audio-start` / `audio-end` 마커 쌍은 완전히 포함되어야 하며, 섹션이 서로 엇갈려서는 안 됩니다.

| type | name | label | appearance |
|------|------|-------|------------|
| text | audio_s_a1 | | `audio-start` |
| text | q_intro | 소개 | |
| text | audio_e_a1 | | `audio-end` |
| note | section_break | — | |
| text | audio_s_b1 | | `audio-start invisible` |
| text | q_detail | 세부 정보 | |
| text | audio_e_b1 | | `audio-end` |

각 섹션은 해당 `audio-end` 필드에 첨부된 별도의 오디오 파일을 생성합니다.

---

## 제한 사항

- **모바일 앱 전용.** 이 기능은 웹 폼에서 지원되지 않습니다. 브라우저에서는 `audio-start` 및 `audio-end`가 무시됩니다.
- **중첩 불가.** 녹음 섹션은 겹칠 수 없습니다. 이전 `audio-end` 마커에 도달하기 전에 새로운 녹음을 시작하는 것은 지원되지 않습니다.
- **필드 유형은 `text`여야 함.** 다른 질문 유형에서 `audio-start` 또는 `audio-end`를 사용하는 것은 지원되지 않습니다.
- **업로드 크기.** 장시간 녹음하면 파일 크기가 커집니다. 제출 크기 제한과 현장의 네트워크 상태에 유의하십시오.
- **녹음 중 일시 중지 없음.** 녹음은 시작 마커에서 종료 마커까지 계속해서 실행됩니다. 섹션 내에서 일시 중지하고 다시 시작하는 메커니즘은 없습니다.

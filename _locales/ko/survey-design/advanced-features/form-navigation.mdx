---

**फ़ॉर्म नेविगेशन 컨트롤**은 설문 조사 하단에 전체 너비의 스타일이 적용된 버튼으로 렌더링되는 `note`(또는 `text`) 필드에 배치된 디자인 값입니다. 조사원은 탭 한 번으로 제출물을 저장하고 서식을 종료할 수 있습니다. 완료된(최종본) 기록 또는 초안(미완성) 기록으로 종료할 수 있습니다.

---

## `SaveFinalizedExit<#COLOR/>`

**제출물을 최종본으로 저장**하고 서식을 종료하는 버튼을 렌더링합니다. 버튼 레이블은 필드의 `label` 열에서 가져옵니다.

| XLSForm column | 값 |
|----------------|-------|
| `type` | `note` |
| `name` | 고유한 이름(예: `btn_finish`) |
| `label` | 버튼에 표시되는 텍스트 |
| `appearance` | `SaveFinalizedExit<#RRGGBB/> toc-hide` |

제출물은 최종 완성된 기록으로 표시됩니다. 이는 기본 제공되는 제출 버튼을 누르는 것과 동일합니다.

---

## `SaveIncompleteExit<#COLOR/>`

**제출물을 미완성(초안)으로 저장**하고 서식을 종료하는 버튼을 렌더링합니다. 조사원은 나중에 다시 돌아와서 계속 작성할 수 있습니다.

| XLSForm column | 값 |
|----------------|-------|
| `type` | `note` |
| `name` | 고유한 이름(예: `btn_pause`) |
| `label` | 버튼에 표시되는 텍스트 |
| `appearance` | `SaveIncompleteExit<#RRGGBB/> toc-hide` |

---

## 색상 구문

두 디자인 모두 `<#RRGGBB/>` 형식의 인라인 색상을 허용합니다.

- `#` 뒤에 정확히 **6자리 16진수**(대문자 또는 소문자)가 옵니다.
- 닫는 `/>`는 **필수**입니다. 생략하면 파싱이 중단됩니다.
- 예: `<#04B404/>`(녹색), `<#EDC602/>`(황색), `<#D9534F/>`(빨간색)

색상은 버튼 배경을 제어합니다. 텍스트 색상은 앱에서 자동으로 결정됩니다.

---

## 예시

서식 끝에 배치된 다음 두 필드는 녹색 **제출** 버튼과 황색 **초안으로 저장** 버튼을 생성합니다.

| type | name | label | appearance |
|------|------|-------|------------|
| note | btn_finish | 제출 | `SaveFinalizedExit<#04B404/> toc-hide` |
| note | btn_pause | 초안으로 저장 | `SaveIncompleteExit<#EDC602/> toc-hide` |

---

## toc-hide — 목차에서 버튼 제외하기

`toc-hide` 디자인 토큰은 rtSurvey에 서식의 **목차**(질문 개요 목록)에서 필드를 제외하도록 지시합니다. 탐색 버튼은 질문이 아니므로 목차에 표시되어서는 안 됩니다.

종료 디자인 뒤에 항상 `toc-hide`를 추가하십시오.

```
SaveFinalizedExit<#04B404/> toc-hide
SaveIncompleteExit<#EDC602/> toc-hide
```

toc-hide 참조는 [디자인 — toc-hide](../appearance#group-and-navigation)를 확인하십시오.

---

## 배치 규칙

서식에 탐색 컨트롤을 추가할 때 다음 규칙을 따르십시오.

- 두 버튼을 서식의 **맨 끝**, 모든 질문과 그룹 뒤에 배치하십시오.
- 완료 상태에 관계없이 조사원이 항상 종료할 수 있는 방법이 있도록 항상 **두 버튼 모두**를 함께 포함하십시오(최종본 하나, 미완성본 하나).
- 특정 조건이 충족될 때(예: 필수 섹션이 완료됨)만 제출을 허용해야 하는 경우 최종 종료 버튼에 `relevant` 열을 사용하십시오. 미완성 종료 버튼은 일반적으로 **항상 표시**되어야 합니다.

---

## 조건부 최종 종료

`relevant` 열을 사용하여 최종 종료 버튼이 표시되는 시점을 제어하십시오. 조사원이 언제든지 중단하고 돌아올 수 있도록 미완성 종료는 무조건 표시되어야 합니다.

| type | name | label | appearance | relevant |
|------|------|-------|------------|----------|
| note | btn_finish | 제출 | `SaveFinalizedExit<#04B404/> toc-hide` | `${consent} = 'yes' and ${section_a_complete} = '1'` |
| note | btn_pause | 초안으로 저장 | `SaveIncompleteExit<#EDC602/> toc-hide` | |

이 예에서 **제출** 버튼은 조사원이 동의하고 섹션 A를 완료로 표시한 경우에만 나타납니다. **초안으로 저장** 버튼은 항상 사용할 수 있습니다.

---

## 제한 사항

- **필드 유형은 `note` 또는 `text`여야 합니다.** 다른 질문 유형에서 이러한 디자인을 사용하는 것은 지원되지 않습니다.
- **6자리 16진수만 가능합니다.** 약식 16진수(`<#FFF/>`) 및 명명된 색상은 지원되지 않습니다. 항상 전체 6자리 형식(예: `<#FFFFFF/>`)을 사용하십시오.
- **레이블 열이 버튼 텍스트입니다.** 이 필드에서는 `hint` 열이 무시되며 `label`만 렌더링됩니다.
- **두 버튼이 모두 있어야 합니다.** 미완성 종료 버튼을 생략하면 조사원이 서식 중간에 중단할 방법이 없게 됩니다.

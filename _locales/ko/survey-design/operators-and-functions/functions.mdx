### 문자열 함수

<Callout type="warning">
표현식 내에서 문자열로 작업할 때 리터럴 문자열을 묶기 위해 작은따옴표('')를 사용하는 것이 중요합니다. 그러나 리터럴 문자열 내에 작은따옴표를 포함하려는 경우에는 예외가 발생합니다. 이 경우 전체 문자열을 큰따옴표("")로 묶을 수 있습니다.

예를 들어:
- 올바름: if(`${yesno}` = 1, "a string with 'single quotes' in it", "no single quotes here")
- 잘못됨: if(`${yesno}` = 1, 'a string with 'single quotes' in it', 'no single quotes here')

스마트 따옴표(smart quotes)와 관련하여, 표현식에서 문제를 일으킬 수 있으므로 주의해야 합니다. 많은 서식 있는 텍스트 편집기(Rich Text Editor)는 곧은 따옴표("" 또는 '')를 스마트 따옴표 또는 굽은 따옴표(“” 또는 ‘’)로 자동 변환하여 구문 오류나 예기치 않은 동작을 유발할 수 있습니다. 이를 방지하려면 표현식에서 일관되게 곧은 따옴표('')를 사용하고 있는지 확인하세요.

추가 질문이 있거나 도움이 필요하시면 알려주시기 바랍니다!
</Callout>

rtSurvey는 다음과 같은 다양한 함수를 지원합니다:

1. `string(field)`: 필드를 문자열로 변환합니다.
   - 예: `string(34.8)`은 `'34.8'`로 변환됩니다.

2. `string-length(field)`: 문자열 필드의 길이를 반환합니다.
   - 예: `string-length(.) > 3 and string-length(.) < 10`은 현재 필드가 3자에서 10자 사이인지 확인하는 데 사용할 수 있습니다.
   - **연쇄 종속성 패턴(Cascade dependency pattern)**: `string-length(${province}) >= 0`은 항상 `true`로 평가되지만, `${province}`가 변경될 때마다 rtSurvey가 표현식을 다시 평가하도록 강제합니다. 상위 필드가 업데이트될 때 연쇄 새로고침을 트리거하려면 `relevant`에서 이를 사용하세요:
     | type | name | relevant |
     |------|------|----------|
     | select_one | district | `string-length(${province}) >= 0` |
     이를 통해 province가 변경될 때마다 district 질문이 해당 `search()` 또는 `rawquery` appearance를 다시 평가하도록 보장합니다.

3. `substr(fieldorstring, startindex, endindex)`: `startindex`에서 시작하여 `endindex` 바로 앞에서 끝나는 부분 문자열(substring)을 반환합니다. 인덱스는 문자열의 첫 번째 문자에 대해 0부터 시작합니다.
   - 예: `substr(${phone}, 0, 3)`은 전화번호의 처음 세 자리를 반환합니다.

4. `concat(a, b, c, ...)`: 필드(및/또는 문자열)를 하나로 연결합니다.
   - 예: `concat(${firstname}, ' ', ${lastname})`은 `firstname`과 `lastname` 필드의 값을 결합하여 전체 이름을 반환합니다.

5. `linebreak()`: 줄바꿈 문자를 반환합니다.
   - 예: `concat(${field1}, linebreak(), ${field2}, linebreak(), ${field3})`은 줄바꿈으로 구분된 세 개의 필드 값 목록을 반환합니다.

6. `lower()`: 문자열을 모두 소문자로 변환합니다.
   - 예: `lower('Street Name')`은 "street name"을 반환합니다.

7. `upper()`: 문자열을 모두 대문자로 변환합니다.
   - 예: `upper('Street Name')`은 "STREET NAME"을 반환합니다.

### select_one 및 select_multiple 함수

1. `count-selected(field)`: select_multiple 필드에서 선택된 항목의 수를 반환합니다.
   - 예: `count-selected(.) = 3`은 정확히 세 개의 선택지가 선택되었는지 확인하는 constraint 표현식으로 사용할 수 있습니다.

2. `selected(field, value)`: select_one 또는 select_multiple 필드에서 지정된 값이 선택되었는지 여부에 따라 true 또는 false를 반환합니다.
   - 예: `selected(${color}, 'Blue')`는 응답자가 가장 좋아하는 색상으로 "Blue"를 선택한 경우에만 그룹이나 필드를 표시하는 relevance 표현식으로 사용할 수 있습니다.
   - 참고: 두 번째 매개변수는 항상 선택지 라벨(label)이 아닌 선택지 값(value)을 지정해야 합니다. 양식 정의의 choices 워크시트에 있는 value 열의 값을 사용하세요.

3. `selected-at(field, number)`: select_multiple 필드에서 지정된 위치에 선택된 항목을 반환합니다. 전달된 숫자가 0이면 첫 번째 선택 항목을 반환하고, 1이면 두 번째 선택 항목을 반환하는 식입니다.
   - 예: `selected-at(${fruits}, 0) = 'Apple'`은 첫 번째 선택지가 "Apple"인 경우에만 그룹이나 필드를 표시하는 relevance 표현식으로 사용할 수 있습니다.
   - 참고: 반환되는 값은 선택지 라벨이 아닌 선택지 값입니다. 양식 정의의 choices 워크시트에 있는 value 열의 값을 사용하세요.

4. `choice-label(field, value)`: 양식 정의의 choices 워크시트에 정의된 select_one 또는 select_multiple 필드 선택지의 라벨을 반환합니다.
   - 예 1: `choice-label(${country}, ${country})`는 `country`라는 이름의 필드에서 현재 선택된 선택지의 라벨을 반환합니다.
   - 예 2: `choice-label(${languages}, selected-at(${languages}, 0))`는 `languages`라는 이름의 필드에서 첫 번째로 선택된 선택지의 라벨을 반환합니다.
   - 참고: 이 함수는 값이 아닌 선택지 라벨을 가져옵니다. 양식 정의의 choices 워크시트에 있는 label 열을 사용합니다.

### 반복 필드 함수

rtSurvey에서 동일한 질문을 여러 번 묻고 싶다면 필드를 repeat 그룹 안에 넣을 수 있습니다. 이렇게 하면 동일한 필드의 인스턴스가 여러 개 생성됩니다. 다음 함수들은 이러한 반복 필드와 필드들이 생성하는 반복 데이터를 처리하는 데 도움이 됩니다. 자세한 내용은 반복 필드에 대한 도움말 항목을 참조하세요.

1. `join(string, repeatedfield)`: repeat 그룹 내의 필드에 대해 문자열로 구분된 값 목록을 생성합니다. 첫 번째 매개변수는 값을 구분하는 데 사용할 구분 기호를 지정합니다.
   - 예: `join(', ', ${member_name})`은 입력된 모든 이름으로 쉼표로 구분된 단일 목록을 생성합니다.

2. `join-if(string, repeatedfield, expression)`: `join()`과 똑같이 작동하지만, 제공된 표현식을 사용하여 repeat 그룹의 각 인스턴스를 확인합니다. 표현식이 false로 평가되면 해당 항목은 출력에서 제외됩니다.
   - 예: `join-if(', ', ${member_name}, ${age} >= 18)`은 성인 구성원(18세 이상)의 이름만 쉼표로 구분된 목록으로 생성합니다.

3. `count(repeatgroup)`: repeat 그룹이 반복된 현재 횟수를 반환합니다.
   - 예: `count(${groupname})`은 그룹의 인스턴스 수를 반환합니다.

4. `count-if(repeatgroup, expression)`: `count()`와 똑같이 작동하지만, 제공된 표현식을 사용하여 repeat 그룹의 각 인스턴스를 확인합니다. 표현식이 false로 평가되면 해당 항목은 출력에서 제외됩니다.
   - 예: `count-if(${members}, ${age} >= 18)`은 "members" repeat 그룹 내의 age 필드를 기반으로 성인 구성원의 수를 반환합니다.

5. `sum(repeatedfield)`: repeat 그룹 내의 필드에 대해 모든 값의 합계를 계산합니다.
   - 예: `sum(${loan_amount})`은 모든 대출의 총 가치를 반환합니다.

6. `sum-if(repeatedfield, expression)`: `sum()`과 똑같이 작동하지만, 제공된 표현식을 사용하여 repeat 그룹의 각 인스턴스를 확인합니다. 표현식이 false로 평가되면 해당 항목은 출력에서 제외됩니다.
   - 예: `sum-if(${loan_amount}, ${loan_amount} > 500)`은 500이 넘는 모든 대출의 총 가치를 반환합니다. 작은 대출은 무시됩니다.

7. `min(repeatedfield)`: repeat 그룹 내의 필드에 대해 모든 값 중 최솟값을 계산합니다.
   - 예: `min(${member_age})`는 그룹 내 최연소 구성원의 나이를 반환합니다.

8. `min-if(repeatedfield, expression)`: `min()`과 똑같이 작동하지만, 제공된 표현식을 사용하여 repeat 그룹의 각 인스턴스를 확인합니다. 표현식이 false로 평가되면 해당 항목은 출력에서 제외됩니다.
   - 예: `min-if(${member_age}, ${member_age} >= 18)`은 그룹 내 최연소 성인의 나이를 반환합니다. 18세 미만은 무시됩니다.

9. `max(repeatedfield)`: repeat 그룹 내의 필드에 대해 모든 값 중 최댓값을 계산합니다.
   - 예: `max(${member_age})`는 그룹 내 최고령 구성원의 나이를 반환합니다.

10. `max-if(repeatedfield, expression)`: `max()`와 똑같이 작동하지만, 제공된 표현식을 사용하여 repeat 그룹의 각 인스턴스를 확인합니다. 표현식이 false로 평가되면 해당 항목은 출력에서 제외됩니다.
    - 예: `max-if(${member_age}, ${member_age} >= 18)`은 그룹 내 최고령 성인의 나이를 반환합니다. 18세 미만은 무시됩니다.

11. `index()`: repeat 그룹 내에서 호출되며, 현재 그룹 또는 인스턴스의 인덱스 번호를 반환합니다.
    - 예: repeat 그룹 내에서 `index()`를 사용하면 첫 번째 인스턴스는 1, 두 번째는 2를 반환하는 식입니다.

12. `indexed-repeat(repeatedfield, repeatgroup, index)`: repeat 그룹 외부에 있는 repeat 그룹 내부의 필드 또는 그룹을 참조합니다. 첫 번째 매개변수는 관심 있는 반복 필드 또는 그룹을 지정하고, 두 번째는 해당 필드 또는 그룹이 위치한 repeat 그룹을 지정하며, 세 번째는 사용할 repeat 그룹 내의 인스턴스 번호를 지정합니다.
    - 예 1: `indexed-repeat(${name}, ${names}, 1)`은 name 필드가 "names"라는 이전 repeat 그룹 내에 있을 때 사용 가능한 첫 번째 이름을 반환합니다.
    - 예 2: `indexed-repeat(${name}, ${names}, index())`는 현재 repeat 그룹의 인스턴스 번호에 해당하는 이름을 가져옵니다.

13. `rank-index(index, repeatedfield)`: 이 함수는 repeat 그룹 외부에서 사용하기 위해 반복 필드의 지정된 인스턴스에 대한 서수 순위(ordinal rank)를 계산합니다. 가장 높은 값을 가진 인스턴스에 순위 1이 할당되고, 다음으로 높은 값을 가진 인스턴스에 순위 2가 할당되는 식입니다. 유효하지 않은 인덱스나 숫자가 아닌 값을 가진 인스턴스에 대한 인덱스를 전달하면 순위 999가 반환됩니다.
    - 예: `rank-index(1, ${random_draw})`는 첫 번째 인스턴스의 `random_draw` 필드 값을 다른 인스턴스들의 값과 비교하여 순위를 계산합니다.

14. `rank-index-if(index, repeatedfield, expression)`: 이 함수는 `rank-index()`와 유사하게 작동하지만, 제공된 표현식을 사용하여 반복 필드의 repeat 그룹 내 각 인스턴스를 확인합니다. 표현식이 false로 평가되면 해당 항목은 계산에서 제외됩니다. 사용되는 인덱스는 각 인스턴스에 대한 표현식을 평가하기 전의 전체 인스턴스 세트를 기반으로 합니다. 표현식을 만족하지 않아 무시된 인스턴스에 대한 인덱스를 전달하면 유효하지 않은 인덱스로 간주되어 순위 999가 반환됩니다.
    - 예: `rank-index-if(1, ${age}, ${age} >= 18)`은 나이가 18세 이상인 인스턴스만 고려하여 성인 세트 내에서의 나이 순위를 계산합니다.

### 숫자 함수

| Operator | Operation | Example | Example answer |
|----------|-----------|---------|----------------|
| `+` | 덧셈 | 1 + 1 | 2 |
| `-` | 뺄셈 | 3 - 2 | 1 |
| `*` | 곱셈 | 3 * 2 | 6 |
| `div` | 나눗셈 | 10 div 2 | 5 |
| `mod` | 나머지 | 9 mod 2 | 1 |

rtSurvey는 다음과 같은 숫자 함수를 지원합니다:
- `number(field)`: 필드의 값을 숫자로 변환합니다.
  - 예: `number('34.8')` = 34.8

- `int(field)`: 필드의 값을 정수로 변환합니다.
  - 예: `int('39.2')` = 39

- `min(field1, ..., fieldx)`: 전달된 필드 중 최솟값을 반환합니다.
  - 예: `min(${father_age}, ${mother_age})`는 어머니 또는 아버지 중 더 적은 나이를 반환합니다.

- `max(field1, ..., fieldx)`: 전달된 필드 중 최댓값을 반환합니다.
  - 예: `max(${father_age}, ${mother_age})`는 어머니 또는 아버지 중 더 많은 나이를 반환합니다.

- `format-number(field)`: 사용자의 로케일 설정에 따라 정수 또는 십진수 필드의 값 형식을 지정합니다.
  - 예: `format-number(${income})` 이 표현식은 "120000"을 "120,000"으로 형식화할 수 있습니다.

- `round(field, digits)`: 숫자 필드 값을 소수점 이하 지정된 자릿수까지 반올림합니다.
  - 예: `round(${interest_rate}, 2)`

- `abs(number)`: 숫자의 절대값을 반환합니다.
  
- `pow(base, exponent)`: 첫 번째 매개변수 값을 두 번째 매개변수 값만큼 거듭제곱한 값을 반환합니다.
  - 각 매개변수는 필드, 숫자 또는 표현식일 수 있습니다.

- `log10(fieldorvalue)`: 전달된 필드 또는 값의 상용로그(밑이 10인 로그)를 반환합니다.

- `sin(fieldorvalue)`: 전달된 필드 또는 값의 사인(sine) 값을 라디안 단위로 반환합니다.
  
- `cos(fieldorvalue)`: 전달된 필드 또는 값의 코사인(cosine) 값을 라디안 단위로 반환합니다.

- `tan(fieldorvalue)`: 전달된 필드 또는 값의 탄젠트(tangent) 값을 라디안 단위로 반환합니다.

- `asin(fieldorvalue)`: 전달된 필드 또는 값의 아크사인(arcsine) 값을 라디안 단위로 반환합니다.

- `acos(fieldorvalue)`: 전달된 필드 또는 값의 아크코사인(arccosine) 값을 라디안 단위로 반환합니다.

- `atan(fieldorvalue)`: 전달된 필드 또는 값의 아크탄젠트(arctangent) 값을 라디안 단위로 반환합니다.

- `atan2(x, y)`: 좌표 (x, y)를 가진 점과 양의 x축이 원점에서 이루는 각도를 라디안 단위로 반환합니다. 결과는 -pi()에서 pi() 사이의 범위에 있습니다.

- `sqrt(fieldorvalue)`: 전달된 필드 또는 값의 음이 아닌 제곱근을 반환합니다.

- `exp(x)`: e^x 값을 반환합니다.

- `pi()`: 원주율(pi) 값을 반환합니다.

### 날짜 및 시간 함수

<Callout type="warning">
rtSurvey의 날짜 값은 `YYYY-MM-DD` 형식의 문자열로 저장됩니다. 날짜시간(Datetime) 값은 ISO 8601 문자열(`YYYY-MM-DDTHH:MM:SS`)로 저장됩니다. 산술 연산(예: 기간 계산)을 위해 숫자로 변환하려면 `decimal-date-time()`을 사용하세요.
</Callout>

1. `today()`: 오늘 날짜를 `YYYY-MM-DD` 형식의 문자열로 반환합니다. 양식이 열릴 때 한 번 평가됩니다.
   - 예: `today()` → `'2024-03-15'`
   - 일반적인 사용: 오늘 날짜를 미리 채우기 위한 `default` 열, 또는 날짜 필드와 비교하기 위한 `relevant`/`constraint` 열.

2. `now()`: 현재 날짜와 시간을 ISO 8601 문자열로 반환합니다. 표현식이 계산될 때마다 평가됩니다.
   - 예: `now()` → `'2024-03-15T14:32:00.000+03:00'`
   - 일반적인 사용: 설문 조사 중 특정 이벤트의 정확한 타임스탬프 기록.

3. `date(value)`: 값(문자열 또는 숫자)을 날짜 문자열로 변환합니다. 계산된 값을 날짜 유형으로 강제 변환하는 데 유용합니다.
   - 예: `date('2024-03-15')` → `'2024-03-15'`

4. `date-time(value)`: 값을 날짜시간 문자열로 변환합니다.
   - 예: `date-time(${event_timestamp})`

5. `decimal-date-time(value)`: 날짜 또는 날짜시간 문자열을 Unix 에포크(epoch) 이후의 밀리초를 86400000으로 나눈 소수(즉, 1970-01-01 이후의 소수 자릿수가 포함된 일수)로 변환합니다. 날짜에 대한 산술 연산을 수행하려면 이를 사용하세요.
   - 예: 두 날짜 사이의 기간(일 단위):
     `decimal-date-time(${end_date}) - decimal-date-time(${start_date})`
   - 예: 두 날짜시간 사이의 기간(분 단위):
     `(decimal-date-time(${end_time}) - decimal-date-time(${start_time})) * 1440`

6. `format-date(date, format)`: 패턴 문자열을 사용하여 날짜 값의 형식을 지정합니다.
   - 형식 토큰: `%Y` (4자리 연도), `%y` (2자리 연도), `%m` (월 01~12), `%d` (일 01~31), `%a` (약어 요일), `%b` (약어 월 이름)
   - 예: `format-date(today(), '%d/%m/%Y')` → `'15/03/2024'`
   - 예: `format-date(${dob}, '%B %d, %Y')` → `'March 15, 1990'`

7. `format-date-time(datetime, format)`: 패턴 문자열을 사용하여 날짜시간 값의 형식을 지정합니다. 모든 `format-date` 토큰과 다음 토큰을 수용합니다:
   - `%H` (시 00~23), `%h` (시 01~12), `%M` (분 00~59), `%S` (초 00~59), `%3` (밀리초), `%P` (AM/PM)
   - 예: `format-date-time(now(), '%d/%m/%Y %H:%M')` → `'15/03/2024 14:32'`
   - 예: `format-date-time(${event_time}, '%I:%M %p')` → `'02:32 PM'`

8. `STRFTIME(format, datetime)`: SQLite 스타일의 날짜 형식 지정입니다. `rawquery` 쿼리에 전달되는 SQL 문자열 내부에서 사용할 수 있으며, XLSForm의 `calculation` 또는 `label` 열에서는 사용할 수 **없습니다**. SQLite 형식 토큰(`%Y`, `%m`, `%d`, `%H`, `%M`, `%S`)을 사용합니다.
   - rawquery SQL 문자열 내부의 예: `'SELECT STRFTIME(''%Y-%m'', interview_date) AS month FROM data WHERE id = ?'`
   - 참고: XLSForm 표현식의 날짜 형식 지정에는 `format-date-time()`을 사용하세요. `STRFTIME()`은 `rawquery`에 전달된 SQL 내에서만 사용할 수 있는 SQLite 함수입니다.

### 불리언(Boolean) 함수

1. `boolean(value)`: 모든 값을 불리언으로 변환합니다. 비어 있지 않은 문자열, 0이 아닌 숫자, `true`에 대해 `true`를 반환하고, 빈 문자열, `0`, `false`에 대해 `false`를 반환합니다.
   - 예: `boolean(${name})`은 `name`이 비어 있지 않으면 `true`를 반환합니다.

2. `boolean-from-string(string)`: 문자열이 `'1'` 또는 `'true'`(대소문자 구분 안 함)이면 `true`를 반환하고, 그렇지 않으면 `false`를 반환합니다.
   - 예: `boolean-from-string(${enabled_flag})` — 필드가 `'true'`/`'false'`를 텍스트로 저장할 때 유용합니다.

3. `true()`: 불리언 값 `true`를 반환합니다.
   - 예: `required` 열에서 `true()`는 `yes`와 동일합니다.

4. `false()`: 불리언 값 `false`를 반환합니다.
   - 예: `if(${skip_section} = 'yes', false(), true())` — 동적으로 필수를 설정합니다.

5. `not(expression)`: 표현식의 논리 부정을 반환합니다. 표현식이 false이면 `true`를 반환하고 그 반대도 마찬가지입니다.
   - 예: `not(${consent} = 'yes')` — 동의가 제공되지 않았을 때 경고를 표시합니다.
   - 예: `not(selected(${issues}, 'none'))` — "none"이 선택되지 않은 경우에만 세부 정보를 요구합니다.

### 추가 문자열 함수

1. `starts-with(string, prefix)`: `string`이 `prefix`로 시작하면 `true`를 반환합니다.
   - 예: `starts-with(${phone}, '+254')`는 전화번호가 케냐 국가 코드로 시작하는지 확인합니다.

2. `contains(string, substring)`: `string`에 `substring`이 포함되어 있으면 `true`를 반환합니다.
   - 예: `contains(${email}, '@')`는 이메일 주소에 `@` 기호가 있는지 확인합니다.
   - 예: `contains(${notes}, 'urgent')`는 메모에 "urgent"가 언급된 경우 후속 질문을 트리거합니다.

3. `substring-before(string, needle)`: `needle`이 처음 나타나기 전의 `string` 부분을 반환합니다.
   - 예: `substring-before(${full_name}, ' ')`는 첫 번째 단어(이름)를 추출합니다.

4. `substring-after(string, needle)`: `needle`이 처음 나타난 후의 `string` 부분을 반환합니다.
   - 예: `substring-after(${email}, '@')`는 이메일 주소의 도메인 부분을 추출합니다.

5. `normalize-space(string)`: 앞뒤 공백을 제거하고 모든 내부 공백 시퀀스를 단일 공백으로 축소합니다.
   - 예: `normalize-space(${name})` — 공백이 추가로 입력되었을 수 있는 이름을 정리합니다.

6. `translate(string, search_chars, replace_chars)`: `string`에서 `search_chars`에 나타나는 각 문자를 `replace_chars`의 해당 문자로 바꿉니다. `replace_chars`에 해당 문자가 없는 `search_chars`의 문자는 삭제됩니다.
   - 예: `translate(${code}, 'abcdefghijklmnopqrstuvwxyz', 'ABCDEFGHIJKLMNOPQRSTUVWXYZ')`는 대문자로 변환합니다(`upper()`와 동일).
   - 예: `translate(${phone}, ' -()', '')`는 전화번호에서 공백, 대시 및 괄호를 제거합니다.

### 추가 수학 함수

1. `floor(number)`: `number`보다 작거나 같은 가장 큰 정수를 반환합니다(음의 무한대 방향으로 내림).
   - 예: `floor(4.9)` = 4, `floor(-2.1)` = -3

2. `ceiling(number)`: `number`보다 크거나 같은 가장 작은 정수를 반환합니다(양의 무한대 방향으로 올림).
   - 예: `ceiling(4.1)` = 5, `ceiling(-2.9)` = -2

3. `random()`: 0.0(포함)과 1.0(제외) 사이의 랜덤한 소수를 반환합니다. 일반적으로 `calculate` 필드에서 랜덤 값을 할당하거나 질문 순서를 무작위로 정하는 데 사용됩니다.
   - 예: `random()` → 예: `0.7341`
   - 예: `int(random() * 6) + 1` → 랜덤 숫자 1~6 (주사위 굴리기)

4. `coalesce(a, b)`: `a`가 비어 있지 않으면 `a`를 반환하고, 그렇지 않으면 `b`를 반환합니다. 필드가 비어 있을 수 있는 경우 대체 수단으로 유용합니다.
   - 예: `coalesce(${preferred_name}, ${full_name})` — 선호하는 이름이 설정되어 있으면 사용하고, 그렇지 않으면 전체 이름으로 대체합니다.

5. `once(value)`: `value`를 평가하고 저장하지만, 현재 필드가 **비어 있는** 경우에만 저장합니다. 필드에 이미 값이 있는 경우(예: 이전에 설정됨) `once()`는 기존 값을 변경 없이 반환합니다. 이는 재계산이 사용자 입력을 덮어쓰는 것을 방지합니다.
   - 예: `default` 열의 `once(today())`는 오늘 날짜를 한 번 설정하고 조사원이 양식을 다시 열어도 업데이트하지 않습니다.
   - 예: `once(uuid())`는 UUID를 한 번 생성하고 재편집 시에도 안정적으로 유지합니다.

### 지오(Geo) 함수

1. `area(geoshape_value)`: 지오셰이프(다각형) 값으로 둘러싸인 **면적을 제곱미터 단위**로 계산합니다.
   - 매개변수는 `lat1 lon1 0 0; lat2 lon2 0 0; ...` 형식의 지오셰이프 필드 값입니다.
   - 예: `area(${field_boundary})` — 조사된 필드의 면적을 m² 단위로 계산합니다.
   - 예: `round(area(${field_boundary}) div 10000, 2)` — 헥타르로 변환합니다.

2. `distance(coordinates)`: 지오트레이스(선)의 **총 경로 길이를 미터 단위**로 계산하거나, 두 지오포인트 사이의 거리를 계산합니다.
   - 지오트레이스의 경우: `distance(${route})`는 총 경로 길이를 미터 단위로 반환합니다.
   - 두 지오포인트의 경우: `distance(concat(${point_a}, ' ', ${point_b}))`는 두 지점 사이의 거리를 반환합니다.
   - 예: `round(distance(${road_trace}) div 1000, 3)` — 도로 길이를 킬로미터 단위로 반환합니다.

### 검증 함수

1. `regex(value, pattern)`: `value`가 정규 표현식 `pattern`과 일치하면 `true`를 반환합니다. 패턴 기반 검증을 위해 `constraint` 열에서 사용하세요.
   - 패턴은 표준 정규식 구문(POSIX ERE 하위 집합)을 사용합니다.
   - 예: `regex(., '^[0-9]{10}$')` — 10자리 숫자를 검증합니다.
   - 예: `regex(., '^[A-Z]{2}[0-9]{6}$')` — 여권 번호 형식(대문자 2개 뒤에 숫자 6개)을 검증합니다.
   - 예: `regex(., '^[^@]+@[^@]+\.[^@]{2,}$')` — 기본 이메일 형식 확인.

2. `checklist(min, max, v1, v2, ...)`: 불리언 표현식 목록을 평가하고 `true` 값의 개수가 `min`과 `max` 사이(포함)인 경우 `true`를 반환합니다. 해당 범위를 건너뛰려면 `min` 또는 `max`에 `-1`을 전달하세요.
   - 예: `checklist(2, 3, ${q1} = 'yes', ${q2} = 'yes', ${q3} = 'yes')` — 세 가지 조건 중 정확히 2개 또는 3개가 참인 경우 통과합니다.
   - 예: `checklist(1, -1, ${smoke_alarm}, ${fire_ext}, ${emergency_plan})` — 적어도 하나의 안전 조치가 참이어야 합니다.

3. `weighted-checklist(min, max, v1, w1, v2, w2, ...)`: `checklist()`와 유사하지만 각 값에 가중치가 있습니다. `true` 값에 대한 가중치의 합은 `min`과 `max` 사이에 있어야 합니다.
   - 예: `weighted-checklist(10, -1, ${has_toilet}, 4, ${has_sink}, 3, ${has_shower}, 5)` — 현재 시설에 대한 가중치 합계가 10 이상이어야 합니다.

### 유틸리티 함수

1. `uuid()`: 랜덤 UUID(RFC 4122 v4 형식)를 문자열로 생성합니다.
   - 예: `uuid()` → `'a3f8b2c1-4d5e-6f7a-8b9c-0d1e2f3a4b5c'`
   - 일반적으로 안정적인 고유 ID를 생성하기 위해 `once()`와 함께 사용됩니다: `once(uuid())`

2. `version()`: settings 워크시트에서 설정된 양식의 `version` 속성 값을 반환합니다.
   - 예: `version()` → `'3.1'`
   - 내보낸 데이터에 양식 버전을 포함하기 위해 `calculate` 필드에서 유용하게 사용됩니다.

3. `position()`: **repeat 그룹** 내에서 호출될 때 현재 반복 인스턴스의 1부터 시작하는 인덱스를 반환합니다.
   - 예: 첫 번째 인스턴스의 `position()`은 `1`을 반환하고, 두 번째는 `2`를 반환하는 식입니다.
   - 참고: `index()`(별칭), 그룹 외부에서 반복 값을 참조하기 위한 `indexed-repeat()`.

4. `thousandsep(length, separator, value)`: 천 단위 구분 기호가 있는 숫자 형식을 지정합니다. `length`는 최소 전체 문자열 길이(더 짧은 경우 공백으로 채워짐), `separator`는 사용할 문자(예: `','`), `value`는 형식을 지정할 숫자입니다.
   - 예: `thousandsep(0, ',', 1234567)` → `'1,234,567'`
   - 예: `thousandsep(0, '.', ${income})` — 수입 형식을 마침표를 천 단위 구분 기호로 사용하여 지정합니다.

5. `substr-jsonpath(value, jsonpath)`: JSONPath 표현식을 사용하여 JSON 문자열에서 값을 추출합니다.
   - `value`는 JSON 문자열이어야 합니다(예: `callapi(..., 'json:', ...)`를 사용하여 원시 API 응답을 저장한 필드).
   - `jsonpath`는 JSONPath 표현식입니다(예: `'$.data.name'`, `'$.items[0].id'`).
   - 항상 **문자열**을 반환합니다. 산술 연산에 사용할 때는 `number()`로 묶으세요.
   - 경로를 찾을 수 없거나 `value`가 유효한 JSON이 아니면 빈 문자열 `''`을 반환합니다.
   - 예: `substr-jsonpath(${api_response}, '$.data.name')` — `name` 필드를 추출합니다.
   - 예: `substr-jsonpath(${api_response}, '$.items[0].label')` — 배열의 첫 번째 요소입니다.
   - 예: `number(substr-jsonpath(${api_response}, '$.price'))` — 숫자 값을 추출합니다.
   - 일반적으로 한 번의 API 응답에서 여러 필드를 추출하기 위해 `callapi(..., 'json:', ...)`와 함께 사용됩니다. [한 번의 API 호출로 여러 값 가져오기](../advanced-features/call-api#fetching-multiple-values-from-one-api-call)를 참조하세요.

rtSurvey는 견고한 다국어 지원을 제공하여 여러 언어로 설문조사를 작성할 수 있도록 합니다. 이 기능은 다양한 언어를 사용하는 인구를 대상으로 연구를 수행하거나 다국어 환경에서 작업할 때 매우 중요합니다.

## 다국어 설문조사 설정

rtSurvey에서 다국어 설문조사를 작성하려면 XLSForm에 언어별 열을 추가해야 합니다. 방법은 다음과 같습니다:

1. **라벨 번역**: `label::Language (code)` 형식을 사용하여 각 언어에 대한 열을 추가합니다.
2. **힌트 번역**: `hint::Language (code)`를 사용하여 힌트를 번역합니다.
3. **미디어 파일 번역**: 언어별 미디어의 경우 `media::Language (code)`를 사용합니다.

예시:

```
| type    | name | label::English (en) | label::Español (es) | hint::English (en) | hint::Español (es) |
|---------|------|---------------------|---------------------|---------------------|---------------------|
| integer | age  | How old are you?    | ¿Cuántos años tienes?| Enter your age      | Ingrese su edad     |
```

## 언어 코드

언어 이름 뒤에 공식 2자리 언어 코드(subtags)를 사용하는 것이 좋습니다. 이는 설문지 언어와 사용자 인터페이스 언어를 일치시키는 데 도움이 됩니다. 공식 코드는 [여기](https://www.iana.org/assignments/language-subtag-registry/language-subtag-registry)에서 확인할 수 있습니다.

## 기본 언어 설정

데이터 수집을 위한 기본 언어를 설정하려면 XLSForm의 `settings` 워크시트를 사용하세요:

```
| form_id   | version | default_language |
|-----------|---------|-------------------|
| test_form | 101     | French (fr)       |
```

## rtSurvey 전용 기능

### 동적 언어 전환

rtSurvey를 사용하면 데이터 수집 중에 사용자가 언어를 동적으로 전환할 수 있습니다:

- 웹 인터페이스의 경우, 상단 내비게이션 바의 언어 드롭다운을 사용하세요.
- 모바일 앱의 경우, 설정 메뉴를 통해 언어 옵션에 액세스하세요.

### 언어별 유효성 검사 메시지

rtSurvey는 유효성 검사 메시지까지 다국어 지원을 확장합니다:

```
| type    | name | constraint | constraint_message::English (en) | constraint_message::Español (es) |
|---------|------|------------|----------------------------------|----------------------------------|
| integer | age  | . <= 150   | Age must be 150 or less          | La edad debe ser 150 or menos    |
```

### 필수 입력 메시지 현지화

필수 필드가 비어 있을 때 번역된 오류 메시지를 표시하려면 `required_message::Language (code)`를 사용하세요:

```
| type | name | required | required_message::English (en) | required_message::Tiếng Việt (vi) |
|------|------|----------|-------------------------------|----------------------------------|
| text | name | yes | This field is required | Trường này là bắt buộc |
```

### RTL 언어 지원

아랍어나 히브리어와 같은 오른쪽에서 왼쪽으로 쓰는(RTL) 언어의 경우, rtSurvey는 레이아웃을 자동으로 조정합니다:

```
| type | name | label::English (en) | label::Arabic (ar) |
|------|------|---------------------|---------------------|
| text | name | Your name           | اسمك                |
```

### 언어별 Appearance

rtSurvey는 각 언어마다 다른 appearance를 지정할 수 있도록 합니다:

```
| type | name | label::English (en) | label::Chinese (zh) | appearance::English (en) | appearance::Chinese (zh) |
|------|------|---------------------|---------------------|--------------------------|---------------------------|
| text | address | Address          | 地址                 | multiline                | textarea                  |
```

## 이중 언어 라벨의 HTML 서식

단일 라벨 셀 내에서 HTML 태그와 언어 래퍼를 결합할 수 있습니다. rtSurvey는 활성 언어 블록을 추출하고 나머지 HTML을 렌더링합니다.

언어별 굵게 표시 및 글꼴 색상을 사용한 예시:

```
<en><big><b>Section 2: Household Income</b></big><br>Ask the household head only.</en><vi><big><b>Phần 2: Thu nhập hộ gia đình</b></big><br>Chỉ hỏi chủ hộ.</vi>
```

언어 래퍼 내에서 지원되는 인라인 태그: `<b>`, `<i>`, `<u>`, `<big>`, `<small>`, `<font color="...">`, `<br>`, `<span style="...">`.

언어별 색상 텍스트 예시:

```
<en><font color="red">Required field</font></en><vi><font color="red">Trường bắt buộc</font></vi>
```

## 언어 인식 계산

양식에 `${language_use}` 필드가 있는 경우(`change_language` 위젯에 의해 설정됨), `if()`를 사용하여 활성 언어로 값을 반환합니다:

```
if(${language_use} = 'en', label_en, label_vi)
```

예시 — `pulldata('rawquery', ...)`를 사용하여 활성 언어로 조회 결과 표시:

```
| type      | name        | calculation                                                                 |
|-----------|-------------|-----------------------------------------------------------------------------|
| calculate | district_label | if(${language_use} = 'en', pulldata('rawquery', concat(${family_path}, '/locations.db::externalData'), 'SELECT label_en FROM externalData WHERE code = ?', ${district}), pulldata('rawquery', concat(${family_path}, '/locations.db::externalData'), 'SELECT label_vi FROM externalData WHERE code = ?', ${district})) |
```

참고: `${language_use}` 필드는 일반적으로 `change_language` appearance 위젯에 의해 설정됩니다. Appearance — change_language를 참조하세요.

## 다국어 설문조사 모범 사례

1. **일관된 명명 규칙**: 양식 전체에 일관된 언어 코드를 사용하세요.
2. **전문적인 번역**: 설문조사 상황에 익숙한 전문 번역가를 고용하세요.
3. **상황 설명**: 정확한 번역을 위해 번역가에게 상황 설명을 제공하세요.
4. **테스트**: 배포 전에 모든 언어로 양식을 테스트하세요.
5. **유니코드 지원**: 데이터 수집 기기가 라틴 문자가 아닌 경우에도 유니코드를 지원하는지 확인하세요.
6. **언어별 미디어**: 각 언어에 문화적으로 적합한 이미지나 오디오를 사용하세요.
7. **이미지 내 텍스트 방지**: 텍스트가 포함된 이미지를 사용하는 경우 각 언어별로 별도의 이미지를 만드세요.

## 특수 케이스 처리

### 혼합 언어 응답

rtSurvey는 선택한 양식 언어와 관계없이 응답자가 모든 스크립트로 텍스트를 입력할 수 있도록 합니다. 이는 이름이나 주소를 원래의 스크립트로 캡처하는 데 유용합니다.

### 언어별 질문 유형

일부 질문 유형은 특정 언어에 더 적합할 수 있습니다. rtSurvey를 사용하면 언어마다 다른 질문 유형을 사용할 수 있습니다:

| type::English (en) | type::Japanese (ja) | name | label::English (en) | label::Japanese (ja) |
|--------------------|---------------------|------|---------------------|----------------------|
| text               | select_one kanji    | name | 이름을 입력하세요     | 名前を選んでください    |

## 다국어 데이터 내보내기

rtSurvey에서 데이터를 내보낼 때:

- 특정 언어로 내보내거나 모든 언어 버전을 포함하도록 선택할 수 있습니다.
- 언어 메타데이터가 내보내기에 포함되어 각 응답에 어떤 언어가 사용되었는지 나타냅니다.

## 모바일 앱 고려 사항

- rtSurvey 모바일 앱은 오프라인 언어 전환을 지원합니다.
- 오프라인으로 전환하기 전에 필요한 모든 언어 파일이 다운로드되었는지 확인하세요.

## 알려진 제한 사항

- 일부 고급 기능은 모든 언어에서 사용하지 못할 수도 있습니다.
- 번역된 내용이 너무 길면 작은 화면에서 레이아웃에 영향을 줄 수 있습니다.

rtSurvey의 다국어 기능을 활용하면 다양한 인구에게 다가가고 언어적으로 정확한 고품질 데이터를 제공하는 포괄적이고 접근 가능한 설문조사를 작성할 수 있습니다.

rtSurvey의 `appearance` 열을 사용하면 설문 조사 질문의 시각적 표현과 동작을 맞춤 설정할 수 있습니다. 이 기능은 사용자 경험을 향상시키고 데이터 수집 효율성을 크게 높일 수 있습니다. rtSurvey는 표준 XLSForm 외관 속성을 지원하며 추가 옵션으로 이를 확장합니다.

## 표준 XLSForm 외관 속성

rtSurvey는 다음과 같은 표준 XLSForm 외관 속성을 지원합니다.

| 외관 속성 | 질문 유형 | 설명 |
|-----------|-----------|------|
| multiline | text | 여러 줄 텍스트 상자를 생성합니다 (웹 클라이언트에 적합) |
| minimal | select_one, select_multiple | 드롭다운 메뉴에 선택지를 표시합니다 |
| quick | select_one | 선택 후 자동으로 다음 질문으로 넘어갑니다 (모바일 전용) |
| no-calendar | date | 달력 표시를 제한합니다 (모바일 전용) |
| month-year | date | 월과 연도만 선택할 수 있습니다 |
| year | date | 연도만 선택할 수 있습니다 |
| horizontal-compact | select_one, select_multiple | 선택지를 가로로 표시합니다 (웹 전용) |
| horizontal | select_one, select_multiple | 선택지를 가로 열로 표시합니다 (웹 전용) |
| likert | select_one | 선택지를 리커트 척도로 제시합니다 |
| compact | select_one, select_multiple | 최소한의 패딩으로 선택지를 나란히 표시합니다 |
| quickcompact | select_one | 컴팩트 표시와 자동 넘기기를 결합합니다 (모바일 전용) |
| field-list | groups | 전체 그룹을 한 화면에 표시합니다 (모바일 전용) |
| label | select_one, select_multiple | 입력란 없이 선택지 레이블만 표시합니다 |
| list-nolabel | select_one, select_multiple | 레이블 없이 입력란만 표시합니다 (`label`과 함께 사용) |
| table-list | groups | 질문을 표 형식으로 표시합니다 |
| signature | image | 서명 캡처를 활성화합니다 (모바일 전용) |
| draw | image | 자유형 그리기를 허용합니다 (모바일 전용) |
| map, quick map | select_one, select_one_from_file | 지도 기능에서 선택을 활성화합니다 |

## 외관 사용을 위한 모범 사례

1. **일관성**: 통일된 외관을 위해 설문 조사 전반에 걸쳐 외관 속성을 일관되게 사용하십시오.
2. **모바일 vs. 웹**: 다양한 기기 및 플랫폼에서 외관이 어떻게 렌더링될지 고려하십시오.
3. **성능**: 양식 로딩 속도를 늦출 수 있는 외관 속성(예: 대규모 그룹의 `table-list`) 사용에 주의하십시오.
4. **사용자 경험**: 응답자가 데이터 입력을 더 쉽고 직관적으로 할 수 있는 외관을 선택하십시오.
5. **테스트**: 외관이 예상대로 작동하는지 확인하기 위해 항상 대상 기기에서 양식을 테스트하십시오.

## 고급 기술

### 외관 조합

일부 외관 속성을 조합하여 더 복잡한 레이아웃을 만들 수 있습니다.

```
| type | name | label | appearance |
|------|------|-------|------------|
| select_one options | choice | Select one: | minimal compact |
```

### 동적 외관

rtSurvey를 사용하면 양식 로직에 따라 외관을 동적으로 변경할 수 있습니다.

```
| type | name | label | appearance | relevant |
|------|------|-------|------------|----------|
| text | time | Enter time: | inline-[%H:%M] | ${show_time} = 'yes' |
```

## 모바일 앱 고려 사항

- 일부 외관(예: `quick`, `signature`)은 모바일 기기에만 해당됩니다.
- 일관된 동작을 보장하기 위해 Android와 iOS 모두에서 철저히 테스트하십시오.

## rtSurvey 확장 외관 속성

표준 XLSForm 외관 외에도 rtSurvey는 다음과 같은 플랫폼별 옵션을 지원합니다.

### 데이터 및 표시 제어

| 외관 속성 | 질문 유형 | 설명 |
|-----------|-----------|------|
| `invisible` | 모든 유형 | 값을 수집하거나 계산하는 동안 필드를 보이지 않게 숨깁니다. `hidden` 유형과 달리 필드는 여전히 로직에 참여합니다. |
| `displaytitle` | 모든 유형 | 일반적으로 숨겨지는 경우에도 필드의 레이블/제목을 강제로 표시합니다. |
| `autopull` | select_one, select_multiple | 양식이 로드되거나 트리거 필드가 변경될 때 자동으로 외부 데이터를 가져와 선택지를 채웁니다. |
| `floating_hint` | text, integer, decimal | 힌트 텍스트를 입력 필드 아래가 아닌 위에 플로팅 레이블로 표시합니다. |
| `calculate-button` | calculate | 자동으로 계산하는 대신 요청 시 필드의 재계산을 트리거하는 버튼을 추가합니다. |

### 그룹 및 탐색

| 외관 속성 | 질문 유형 | 설명 |
|-----------|-----------|------|
| `section` | group | 그룹을 접을 수 있는 섹션 카드로 렌더링합니다. 참고: 모바일 앱 전용. |
| `toc-hide` | 모든 유형 | 목차(TOC) 탐색 패널에서 질문을 제외합니다. |
| `minilog` | begin_repeat | 완료된 반복 항목을 인라인으로 확장하는 대신 컴팩트한 미니 로그 목록으로 표시합니다. |

### 입력 동작

| 외관 속성 | 질문 유형 | 설명 |
|-----------|-----------|------|
| `proper` | text | 응답자가 입력할 때 각 단어의 첫 글자를 자동으로 대문자로 바꿉니다 (title-case 동작). |
| `text-nolabel` | text, integer, decimal | 가시적인 레이블 없이 입력 필드를 렌더링합니다. |
| `inline-1line` | text | 질문 레이블이 길더라도 텍스트 입력을 한 줄로 표시하도록 강제합니다. |
| `popup` | 모든 유형 | 페이지 내에 인라인으로 표시하는 대신 팝업 / 모달 오버레이 내에 필드를 렌더링합니다. |

### 레이아웃

| 외관 속성 | 질문 유형 | 설명 |
|-----------|-----------|------|
| `1screen` | group | 그룹 크기에 관계없이 전체 그룹을 단일 화면에 표시하도록 강제합니다. |
| `columns(n)` | select_one, select_multiple | 선택지를 `n`개의 열로 표시합니다. 예: `columns(3)`은 라디오 버튼을 3열로 표시합니다. |
| `gridformat<row=R col=C colspan=S align=center>` | 모든 유형 | CSS 그리드 레이아웃의 `R`행, `C`열에 필드를 배치하고 `S`개의 열을 차지하게 합니다. `advanced-extension/grid-layout`과 함께 사용됩니다. |
| `ignore-simplify` | 모든 유형 | 양식 렌더러가 이 필드 레이아웃의 자동 단순화 또는 압축을 건너뛰도록 지시합니다. |
| `horizontal(N)` | select_one, select_multiple | 각 선택지가 행 너비의 `N` 퍼센트를 차지하도록 설정합니다. 예: `horizontal(50)`은 한 행에 두 개의 선택지를 배치합니다. |
| `scroll-view(N%)` | group, repeat | 컨테이너를 뷰포트(또는 상위) 높이의 최대 `N%`로 제한하고 콘텐츠가 넘칠 경우 스크롤바를 추가합니다. 예: `scroll-view(60%)`. |

### 위젯

| 외관 속성 | 질문 유형 | 설명 |
|-----------|-----------|------|
| `likert` | select_one | 선택지를 리커트 척도 행으로 제시합니다 (위의 표준 표에 이미 포함되어 있으며 지원이 확인됨). |
| `distress` | select_one | 선택지를 감정 아이콘이 포함된 Kessler Psychological Distress Scale (K10) 시각적 위젯으로 렌더링합니다. |
| `rating_box-fill-{c1}-{c2}-{c3}-{c4}-{c5}` | select_one | 5개의 색상 슬롯이 있는 스타일링된 평가 상자로 선택지를 렌더링합니다. `c1` = 외부 컨테이너 테두리, `c2` = 선택되지 않은 테두리, `c3` = 선택된 테두리 및 채우기, `c4` = 선택되지 않은 텍스트 색상, `c5` = 선택된 텍스트 색상. 예: `rating_box-fill-grey-blue-green-black-white`. |
| `tagging-choices-noshow-v2-{c1}-{c2}-{c3}-{c4}-{c5}` | select_multiple | 선택지를 유색 태그 칩으로 렌더링합니다. 5개의 색상 슬롯은 `rating_box-fill`과 동일한 순서를 따릅니다. 선택된 선택지는 강조 표시되고, 선택되지 않은 선택지는 요약 보기에서 숨겨집니다. |

### API 통합

| 외관 속성 | 질문 유형 | 설명 |
|-----------|-----------|------|
| `callapi` | text, integer, decimal, select_one | 이 필드에 대한 API 호출 통합을 활성화합니다. calculation 열에는 `callapi()` 식이 포함되어야 합니다. [Call API](advanced-features/call-api)를 참조하십시오. |
| `callapi-verify(params)` | text, integer, decimal | 정적 매개변수를 사용하여 API 확인 호출을 트리거합니다. API가 값을 확인할 때까지 양식은 진행을 차단합니다. |
| `callapi-verify(dynamicParams)` | text, integer, decimal | `callapi-verify`와 동일하지만 매개변수가 런타임에 다른 필드 값에서 파생됩니다. |

### 언어 전환기

| 외관 속성 | 질문 유형 | 설명 |
|-----------|-----------|------|
| `change_language-{colors} default('lang')` | note, text | 주어진 색상 코드로 스타일링된 언어 전환기 위젯을 렌더링합니다. `default('lang')` 토큰은 초기 언어(예: `default('en')`)를 설정하며, 파싱 중에 내부적으로 `rtDefault('lang')`로 다시 작성됩니다. 예: `change_language-blue-white default('vi')`. |

### 인라인 날짜/시간 형식

`date`, `time`, `datetime` 필드의 경우 외관에 추가된 형식 문자열을 사용하여 사용자 정의 표시 형식을 지정할 수 있습니다.

```
inline-[%d/%m/%Y]
inline-1line-[%d/%m/%Y %H:%M]
```

형식 토큰은 `format-date()` 및 `format-date-time()`과 동일합니다. [함수 — 날짜 및 시간 함수](operators-and-functions/functions#date-and-time-functions)를 참조하십시오.

예시:

| type | name | label | appearance |
|------|------|-------|------------|
| datetime | event_time | 이벤트 날짜 및 시간 | inline-[%d/%m/%Y %I:%M %p] |
| date | birth_date | 생년월일 | inline-[%d/%m/%Y] |

### 인라인 버튼 레이아웃 — `display{}` 및 `results{}`

인라인 아이콘 버튼(`date`, `time`, `datetime`, `image`, `audio`, `video`, `file`, `barcode`, `geopoint`)으로 렌더링되는 질문 유형의 경우, 두 개의 외관 수정자가 버튼 위치와 캡처 후 동작을 제어합니다.

#### `display{...}` — 캡처 전 버튼 위치

```
display{<align>, <size>, <color>}
```

| 매개변수 | 값 | 기본값 |
|----------|------|--------|
| Align | `left`, `right`, `top`, `center`, `bottom` | `right` |
| Size | `small`, `medium`, `large` | `small` |
| Color | hex (예: `#FF5500`) | 기본 테마 색상 |
| Flag | `inline-icon` | 아이콘 모드 강제 |

| Align 값 | 레이아웃 |
|-----------|----------|
| `right` | 레이블 오른쪽 버튼 |
| `left` | 레이블 왼쪽 버튼 |
| `top` | 레이블 위 버튼, 전체 너비 중앙 정렬 |
| `center` / `bottom` | 레이블 아래 버튼, 전체 너비 중앙 정렬 |

#### `results{...}` — 캡처 후 레이아웃 및 가시성

`display{}` 설정을 상속합니다. 값이 캡처된 후 버튼을 이동하거나 요소를 숨기는 데 사용합니다.

```
results{<align>, hide(<element>)}
```

| `hide` 값 | 효과 |
|-----------|------|
| `hide(capture)` | 파일/값이 존재하면 캡처 버튼을 숨깁니다 |
| `hide(review)` | 리뷰 썸네일 / 재생 버튼을 숨깁니다 |
| `hide(filename)` | 업로드 후 표시되는 파일 이름을 숨깁니다 |
| `hide(camera)` | 캡처 후 카메라 트리거 버튼을 숨깁니다 |
| `hide(scanner)` | 값이 스캔된 후 바코드 스캔 버튼을 숨깁니다 |
| `hide(value)` | 스캔된 값 텍스트(바코드 / geopoint)를 숨깁니다 |

위젯은 값이 캡처되는 순간 `display{}` 레이아웃에서 `results{}` 레이아웃으로 자동으로 전환됩니다.

**예시:**

```
inline display{right}                                    → 레이블 오른쪽 아이콘
inline display{left, large}                              → 왼쪽 대형 아이콘
inline display{center, large, #FF5500}                   → 레이블 아래 대형 주황색 아이콘
inline display{right} results{left}                      → 캡처 후 아이콘이 왼쪽으로 이동
inline display{right} results{hide(capture)}             → 캡처 후 아이콘이 사라짐
inline display{center} results{hide(capture), hide(filename)}
```

## 알려진 제한 사항

- 복잡한 외관은 모든 플랫폼에서 동일하게 렌더링되지 않을 수 있습니다.
- 일부 고급 rtSurvey 외관은 오프라인 모드에서 지원되지 않을 수 있습니다.

## 외관 문제 해결

1. **외관이 적용되지 않음**: appearance 열의 오타를 확인하십시오.
2. **일관성 없는 렌더링**: 질문 유형 및 플랫폼과의 호환성을 확인하십시오.
3. **성능 문제**: 특히 대규모 설문 조사의 경우 복잡한 외관을 단순화하는 것을 고려하십시오.

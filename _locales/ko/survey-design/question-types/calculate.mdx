`calculate` 질문 유형은 백그라운드에서 수식을 조용히 실행합니다. 결과는 다른 질문이 참조할 수 있는 명명된 필드에 저장되지만 조사원에게는 입력이나 레이블이 표시되지 않습니다. 값을 도출하거나, 문자열을 연결하거나, 조건부 로직을 실행하거나, 양식의 나중에 필요한 데이터를 찾는 데 사용합니다.

---

## 기본 구문

| type | name | label | calculation |
|------|------|-------|-------------|
| calculate | total | | `${price} * ${quantity}` |

- **type**: 항상 `calculate`.
- **name**: 고유한 필드 이름. 다른 질문은 `${name}`으로 이를 참조합니다.
- **label**: 비워 둡니다 — calculate 필드는 조사원에게 표시되지 않습니다.
- **calculation**: 평가할 수식입니다. 모든 [XLSForm 함수](../operators-and-functions/functions) 및 필드 참조를 지원합니다.

---

## 공통 패턴

### 산술 연산

| type | name | label | calculation |
|------|------|-------|-------------|
| integer | price | Unit price | |
| integer | quantity | Quantity | |
| calculate | total | | `${price} * ${quantity}` |
| note | total_note | Total: `${total}` | |

### 문자열 연결

| type | name | label | calculation |
|------|------|-------|-------------|
| text | first_name | First name | |
| text | last_name | Last name | |
| calculate | full_name | | `concat(${first_name}, ' ', ${last_name})` |

### 조건부 값

| type | name | label | calculation |
|------|------|-------|-------------|
| integer | score | Score (0–100) | |
| calculate | grade | | `if(${score} >= 90, 'A', if(${score} >= 75, 'B', if(${score} >= 60, 'C', 'F')))` |

### 생년월일로부터 나이 계산

| type | name | label | calculation |
|------|------|-------|-------------|
| date | dob | Date of birth | |
| calculate | age_years | | `int((today() - ${dob}) div 365.25)` |

## `once()`를 사용하여 값 잠그기

기본적으로 `calculate`는 참조된 필드가 변경될 때마다 재평가됩니다. 수식을 `once()`로 묶어 처음 로드할 때만 평가하고 결과를 고정합니다.

| type | name | label | calculation |
|------|------|-------|-------------|
| calculate | interview_start | | `once(now())` |

타임스탬프, 초기값 또는 변경 시 재계산이 바람직하지 않은 경우에 `once()`를 사용합니다.

## 외부 소스에서 데이터 가져오기

### CSV 파일에서

```
pulldata('staff.csv', 'department', 'name', ${staff_id})
```

전체 참조는 [pulldata()](../operators-and-functions/pulldata)를 참조하세요.

### 번들된 SQLite 데이터베이스에서

```
pulldata('rawquery',
  concat(${family_path}, '/locations.db::provinces'),
  'SELECT name FROM provinces WHERE id = ?',
  ${province_id})
```

경로 생성 세부 정보는 [로컬 데이터베이스 검색](../advanced-features/local-database-search)을 참조하세요.

### 앱 컨텍스트에서

```
pulldata('app-api', 'user.username')
pulldata('app-api', 'family_path')
```

사용 가능한 모든 키는 [App API](../app-api)를 참조하세요.

## relevant 및 constraint에서 calculate 사용

다른 필드는 일반 필드와 마찬가지로 `calculate` 결과를 참조할 수 있습니다.

| type | name | label | relevant | constraint |
|------|------|-------|----------|------------|
| calculate | bmi | | | `${weight} div (${height} * ${height}) * 10000` |
| note | bmi_warning | BMI is very high — please verify weight and height. | `${bmi} > 40` | |

## 권장 사항

1. calculate 필드에 의미 있는 이름을 지정하십시오 — `total_cost`는 `calc1`보다 명확하고 내보내기에서 추적하기가 더 쉽습니다.
2. 복잡한 수식을 하나의 깊게 중첩된 표현식 대신 여러 개의 연결된 calculate 필드로 나눕니다.
3. 처음 캡처한 후 값이 변경되지 않도록 타임스탬프 및 초기 스냅샷에 `once()`를 사용합니다.
4. `calculate` 필드를 이를 참조하는 첫 번째 질문 앞에 배치하십시오 — 평가 순서는 양식 순서를 따릅니다.
5. `label` 열을 비워 둡니다. 일부 도구는 레이블을 표시합니다. 비워 두면 혼란스러운 출력을 피할 수 있습니다.

## 제한 사항

- Calculate 필드는 조사원에게 직접 표시되지 않습니다 — 결과를 표시하려면 `note` 필드를 사용하십시오.
- `calculation` 열은 필수입니다. 수식이 없는 `calculate` 행은 항상 빈 문자열을 저장합니다.
- `once()`로 묶이지 않는 한 모든 양식 변경 시 결과가 재평가됩니다 — 대규모 양식의 매우 복잡한 수식은 저사양 장치의 렌더링 성능에 영향을 줄 수 있습니다.
- 계산된 값은 제출 시 문자열로 저장됩니다. 산술 또는 로직 표현식에 결과를 전달할 때 유형을 캐스팅하려면 `number()`, `int()` 또는 `boolean()`을 사용하십시오.

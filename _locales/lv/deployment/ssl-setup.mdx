Pirms pieteikšanās ir jākonfigurē SSL. Pirmo reizi atverot lietotni, jūs tiksiet automātiski novirzīts uz SSL iestatīšanas ekrānu.

---

## SSL iestatīšanas opcijas

![SSL iestatīšanas opcijas](/img/ssl-setup/ssl-setup-options.png)

Izvēlieties vienu no trim opcijām:

| Opcija | Kad lietot |
|--------|-------------|
| **Bezmaksas rtsurvey.com apakšdomēns** *(Ieteicams)* | Nav nepieciešama DNS iestatīšana. Mēs izveidosim ierakstu jūsu vietā. Gatavs 2–5 minūšu laikā. |
| **Mans domēns** | Jums jau ir domēns, un tā DNS norāda uz šo serveri. |
| **Instalēt sertifikātu manuāli** | Uzņēmuma vai pielāgota CA. Nepieciešama SSH piekļuve. |

---

## 1. opcija — Bezmaksas rtsurvey.com apakšdomēns *(Ieteicams)*

Šī ir ātrākā opcija. Nav nepieciešama domēna reģistrācija vai DNS izmaiņas.

![HTTPS iestatīšanas forma](/img/ssl-setup/ssl-setup-form.png)

> **Pirms turpināt:** Bezmaksas apakšdomēnam ir nepieciešams aktīvs konts vietnē [licenses.rtsurvey.com](https://licenses.rtsurvey.com). Bezmaksas plānā ir iekļauts 1 apakšdomēns (`*.rtsurvey.com`).

1. Noklikšķiniet uz **Free rtsurvey.com subdomain**, lai izvērstu sadaļu
2. Laukā **YOUR SUBDOMAIN** ierakstiet vēlamo apakšdomēna nosaukumu

   > Izmantojiet mazos burtus, skaitļus un domuzīmes. 3–30 rakstzīmes.
   > Piemērs: `myproject` → `myproject.rtsurvey.com`

3. Ielīmējiet savu **rtSurvey DNS Token** no [licenses.rtsurvey.com](https://licenses.rtsurvey.com) marķiera laukā
4. Noklikšķiniet uz **Create secure subdomain**

Pēc iesniegšanas lietotne sāks jūsu sertifikāta nodrošināšanu:

![HTTPS iestatīšanas gaita](/img/ssl-setup/ssl-setup-progress.png)

Četri posmi tiek veikti automātiski:
- **DNS ieraksta pieprasīšana** — izveido DNS ierakstu jūsu apakšdomēnam
- **DNS izplatīšanās gaidīšana** — parasti 2–5 minūtes
- **SSL sertifikāta izsniegšana** — Let's Encrypt paraksta jūsu sertifikātu
- **HTTPS aktivizēšana** — Nginx tiek restartēts ar jauno sertifikātu

5. Pēc pabeigšanas jūs tiksiet automātiski novirzīts uz savu jauno HTTPS URL



---

## 2. opcija — Mans domēns

Izmantojiet šo, ja jums ir esošs domēns un tā DNS `A` ieraksts jau norāda uz šī servera IP adresi.

1. Noklikšķiniet uz **My own domain**, lai izvērstu sadaļu
2. Ievadiet savu pilno domēna nosaukumu (piemēram, `survey.myorganization.org`)
3. Noklikšķiniet uz **Create certificate**



Let's Encrypt pārbaudīs jūsu domēnu un izsniegs sertifikātu. Lai tas notiktu, DNS vispirms ir jābūt pareizi norādītam — pretējā gadījumā pieprasījums neizdosies.

---

## 3. opcija — Instalēt sertifikātu manuāli

Uzņēmumu vidēm, kurās tiek izmantota pielāgota vai iekšēja CA. Jūs izvietosiet sertifikāta failus serverī, izmantojot SSH, un pēc tam lietotnē ievadīsiet savu domēnu.

### Priekšnosacījumi

- SSH piekļuve serverim
- Derīgs sertifikāts un privātā atslēga jūsu domēnam (PEM formātā)

### 1. solis — SSH pieslēgšanās serverim

```bash
ssh root@<server-ip>
```

### 2. solis — Sertifikāta failu izvietošana

Izveidojiet direktoriju un nokopējiet failus:

```bash
mkdir -p /etc/letsencrypt/live/<jūsu-domēns>
```

Nokopējiet failus šajā direktorijā ar šādiem precīziem nosaukumiem:

| Fails | Apraksts |
|------|-------------|
| `fullchain.pem` | Jūsu sertifikāts + visi starpposma CA sertifikāti (apvienoti) |
| `privkey.pem` | Jūsu privātā atslēga |

Piemērs:

```bash
# Kopēt no vietējās mašīnas (palaidiet šo lokāli, nevis serverī)
scp fullchain.pem root@<server-ip>:/etc/letsencrypt/live/<jūsu-domēns>/fullchain.pem
scp privkey.pem  root@<server-ip>:/etc/letsencrypt/live/<jūsu-domēns>/privkey.pem
```

Iestatiet pareizas atļaujas:

```bash
chmod 644 /etc/letsencrypt/live/<jūsu-domēns>/fullchain.pem
chmod 600 /etc/letsencrypt/live/<jūsu-domēns>/privkey.pem
```

### 3. solis — Domēna ievadīšana lietotnē



1. SSL iestatīšanas ekrānā noklikšķiniet uz **Install certificate manually**
2. Ievadiet savu domēna nosaukumu (tam jāatbilst sertifikāta Common Name vai SAN)
3. Noklikšķiniet uz **Apply**

Serveris konfigurēs Nginx ar jūsu sertifikātu un automātiski to restartēs.

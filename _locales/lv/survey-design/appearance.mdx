Stabiņš `appearance` programmā rtSurvey ļauj pielāgot jautājumu vizuālo noformējumu un uzvedību jūsu aptaujās. Šī funkcija uzlabo lietotāja pieredzi un var ievērojami palielināt datu vākšanas efektivitāti. rtSurvey atbalsta standarta XLSForm izskata atribūtus un papildina tos ar papildu iespējām.

## Standarta XLSForm izskata atribūti

rtSurvey atbalsta šādus standarta XLSForm izskata atribūtus:

| Izskata atribūts | Jautājumu tipi | Apraksts |
|-------------------|----------------|----------|
| multiline | text | Izveido vairāku rindu teksta lodziņu (vislabāk piemērots tīmekļa klientiem) |
| minimal | select_one, select_multiple | Parāda izvēles nolaižamajā izvēlnē |
| quick | select_one | Automātiski pāriet pie nākamā jautājuma pēc izvēles veikšanas (tikai mobilajās ierīcēs) |
| no-calendar | date | Paslēpj kalendāra rādīšanu (tikai mobilajās ierīcēs) |
| month-year | date | Ļauj izvēlēties tikai mēnesi un gadu |
| year | date | Ļauj izvēlēties tikai gadu |
| horizontal-compact | select_one, select_multiple | Parāda izvēles horizontāli (tikai tīmeklī) |
| horizontal | select_one, select_multiple | Parāda izvēles horizontāli stabiņos (tikai tīmeklī) |
| likert | select_one | Prezentē izvēles kā Likerta skalu |
| compact | select_one, select_multiple | Parāda izvēles blakus ar minimālu atstarpi |
| quickcompact | select_one | Apvieno kompakto attēlošanu ar automātisko pāriešanu (tikai mobilajās ierīcēs) |
| field-list | groups | Parāda visu grupu vienā ekrānā (tikai mobilajās ierīcēs) |
| label | select_one, select_multiple | Rāda izvēļu etiķetes bez ievades laukiem |
| list-nolabel | select_one, select_multiple | Rāda ievades laukus bez etiķetēm (izmantot kopā ar `label`) |
| table-list | groups | Parāda jautājumus tabulas formātā |
| signature | image | Iespējo paraksta tveršanu (tikai mobilajās ierīcēs) |
| draw | image | Ļauj zīmēt ar brīvu roku (tikai mobilajās ierīcēs) |
| map, quick map | select_one, select_one_from_file | Iespējo izvēli no kartes funkcijām |

## Labākā prakse izskata izmantošanai

1. **Konsekvence**: Izmantojiet izskata atribūtus konsekventi visā aptaujā, lai nodrošinātu vienotu izskatu.
2. **Mobilās ierīces pret tīmekli**: Apsveriet, kā izskats tiks attēlots dažādās ierīcēs un platformās.
3. **Veiktspēja**: Esiet piesardzīgi ar izskata atribūtiem, kas varētu palēnināt veidlapas ielādi (piemēram, `table-list` lielām grupām).
4. **Lietotāja pieredze**: Izvēlieties izskatu, kas atvieglotu datu ievadi un padarītu to intuitīvāku respondentiem.
5. **Testēšana**: Vienmēr pārbaudiet veidlapu mērķa ierīcēs, lai pārliecinātos, ka izskats darbojas, kā paredzēts.

## Uzlabotas tehnikas

### Izskatu kombinēšana

Dažus izskata atribūtus var kombinēt sarežģītākiem izkārtojumiem:

```
| type | name | label | appearance |
|------|------|-------|------------|
| select_one options | choice | Select one: | minimal compact |
```

### Dinamisks izskats

rtSurvey ļauj veikt dinamiskas izskata izmaiņas, pamatojoties uz veidlapas loģiku:

```
| type | name | label | appearance | relevant |
|------|------|-------|------------|----------|
| text | time | Enter time: | inline-[%H:%M] | ${show_time} = 'yes' |
```

## Apsvērumi attiecībā uz mobilo lietotni

- Daži izskati (piemēram, `quick`, `signature`) ir specifiski mobilajām ierīcēm.
- Rūpīgi pārbaudiet gan Android, gan iOS, lai nodrošinātu konsekventu uzvedību.

## rtSurvey paplašinātie izskata atribūti

Papildus standarta XLSForm izskatiem rtSurvey atbalsta šādas platformai specifiskas opcijas:

### Datu un attēlošanas kontrole

| Izskata atribūts | Jautājumu tipi | Apraksts |
|-------------------|----------------|----------|
| `invisible` | jebkurš | Paslēpj lauku no skata, kamēr joprojām tiek vākti vai aprēķināti dati. Atšķiras no `hidden` tipa — lauks joprojām piedalās loģikā. |
| `displaytitle` | jebkurš | Piespiedu kārtā rāda lauka etiķeti/virsrakstu pat tad, ja tas parasti tiktu paslēpts. |
| `autopull` | select_one, select_multiple | Automātiski piesaista ārējos datus, lai aizpildītu izvēles, kad veidlapa tiek ielādēta vai mainās sprūda lauks. |
| `floating_hint` | text, integer, decimal | Rāda padoma tekstu kā peldošu etiķeti virs ievades lauka, nevis zem tā. |
| `calculate-button` | calculate | Pievieno redzamu pogu, kas pēc pieprasījuma aktivizē lauka pārrēķināšanu, nevis veic aprēķinu automātiski. |

### Grupa un navigācija

| Izskata atribūts | Jautājumu tipi | Apraksts |
|-------------------|----------------|----------|
| `section` | group | Attēlo grupu kā salokāmu sadaļas karti. Piezīme: tikai mobilajā lietotnē. |
| `toc-hide` | jebkurš | Izslēdz jautājumu no satura rādītāja (TOC) navigācijas paneļa. |
| `minilog` | begin_repeat | Parāda pabeigtos atkārtojuma ierakstus kā kompaktu mini žurnāla sarakstu, nevis paplašina katru ierakstu rindā. |

### Ievades uzvedība

| Izskata atribūts | Jautājumu tipi | Apraksts |
|-------------------|----------------|----------|
| `proper` | text | Automātiski raksta katra vārda pirmo burtu ar lielo burtu, respondentam rakstot (virsraksta reģistra uzvedība). |
| `text-nolabel` | text, integer, decimal | Attēlo ievades lauku bez redzamas etiķetes. |
| `inline-1line` | text | Piespiež teksta ievadi attēlot vienā rindā pat tad, ja jautājuma etiķete ir gara. |
| `popup` | jebkurš | Attēlo lauku uznirstošajā logā / modālajā pārklājumā, nevis rindā lapā. |

### Izkārtojums

| Izskata atribūts | Jautājumu tipi | Apraksts |
|-------------------|----------------|----------|
| `1screen` | group | Piespiež visu grupu attēlot vienā ekrānā neatkarīgi no grupas lieluma. |
| `columns(n)` | select_one, select_multiple | Parāda izvēles `n` stabiņos. Piemērs: `columns(3)` rāda trīs radiopogu stabiņus. |
| `gridformat<row=R col=C colspan=S align=center>` | jebkurš | Pozicionē lauku CSS tīkla izkārtojumā `R`. rindā, `C`. stabiņā, aptverot `S` stabiņus. Izmanto kopā ar `advanced-extension/grid-layout`. |
| `ignore-simplify` | jebkurš | Norāda veidlapas renderētājam izlaist šī lauka izkārtojuma automātisko vienkāršošanu vai saspiešanu. |
| `horizontal(N)` | select_one, select_multiple | Iestata katru izvēli aizņemt `N` procentus no rindas platuma. Piemērs: `horizontal(50)` izvieto divas izvēles katrā rindā. |
| `scroll-view(N%)` | group, repeat | Ierobežo konteineru līdz maksimālajam augstumam `N%` no skatvietas (vai vecākelementa), pievienojot ritjoslu, kad saturs pārsniedz izmēru. Piemērs: `scroll-view(60%)`. |

### Logrīki

| Izskata atribūts | Jautājumu tipi | Apraksts |
|-------------------|----------------|----------|
| `likert` | select_one | Prezentē izvēles kā Likerta skalas rindu (jau minēts standarta tabulā augstāk; apstiprināts atbalsts). |
| `distress` | select_one | Attēlo izvēles kā Keslera psiholoģiskā distresa skalas (K10) vizuālo logrīku ar emocionālām ikonām. |
| `rating_box-fill-{c1}-{c2}-{c3}-{c4}-{c5}` | select_one | Attēlo izvēles kā stilizētus vērtēšanas lodziņus ar piecām krāsu vietām. `c1` = ārējā konteinera apmale, `c2` = neatzīmētā apmale, `c3` = atzīmētā apmale un aizpildījums, `c4` = neatzīmētā teksta krāsa, `c5` = atzīmētā teksta krāsa. Piemērs: `rating_box-fill-grey-blue-green-black-white`. |
| `tagging-choices-noshow-v2-{c1}-{c2}-{c3}-{c4}-{c5}` | select_multiple | Attēlo izvēles kā krāsainas tagu skaidiņas. Piecas krāsu vietas seko tai pašai secībai kā `rating_box-fill`. Izvēlētās iespējas tiek izceltas; neizvēlētās iespējas kopsavilkuma skatā tiek paslēptas. |

### API integrācija

| Izskata atribūts | Jautājumu tipi | Apraksts |
|-------------------|----------------|----------|
| `callapi` | text, integer, decimal, select_one | Iespējo API izsaukumu integrāciju šim laukam. Aprēķinu stabiņā jābūt `callapi()` izteiksmei. Skatiet [Call API](advanced-features/call-api). |
| `callapi-verify(params)` | text, integer, decimal | Aktivizē API pārbaudes izsaukumu, izmantojot statiskus parametrus. Veidlapa bloķē progresu, līdz API apstiprina vērtību. |

### Valodas pārslēdzējs

| Izskata atribūts | Jautājumu tipi | Apraksts |
|-------------------|----------------|----------|
| `change_language-{colors} default('lang')` | note, text | Attēlo valodas pārslēdzēja logrīku, kas stilizēts ar norādītajiem krāsu kodiem. `default('lang')` marķieris iestata sākotnējo valodu (piemēram, `default('en')`); parsēšanas laikā tas tiek iekšēji pārrakstīts par `rtDefault('lang')`. Piemērs: `change_language-blue-white default('vi')`. |

### Iekļauts datuma/laika formāts

Laukiem `date`, `time` un `datetime` varat norādīt pielāgotu attēlošanas formātu, izmantojot formāta virkni, kas pievienota izskatam:

```
inline-[%d/%m/%Y]
inline-1line-[%d/%m/%Y %H:%M]
```

Formāta marķieri ir tādi paši kā `format-date()` un `format-date-time()`. Skatiet [Funkcijas — Datuma un laika funkcijas](operators-and-functions/functions#date-and-time-functions).

Piemērs:

| type | name | label | appearance |
|------|------|-------|------------|
| datetime | event_time | Notikuma datums un laiks | inline-[%d/%m/%Y %I:%M %p] |
| date | birth_date | Dzimšanas datums | inline-[%d/%m/%Y] |

### Iekļauts pogu izkārtojums — `display{}` un `results{}`

Jautājumu tipiem, kas tiek attēloti kā iekļauta ikonas poga (`date`, `time`, `datetime`, `image`, `audio`, `video`, `file`, `barcode`, `geopoint`), divi izskata modifikatori kontrolē pogas pozīciju un uzvedību pēc tveršanas.

#### `display{...}` — pogas pozīcija pirms tveršanas

```
display{<align>, <size>, <color>}
```

| Parametrs | Vērtības | Noklusējums |
|-----------|----------|-------------|
| Align | `left`, `right`, `top`, `center`, `bottom` | `right` |
| Size | `small`, `medium`, `large` | `small` |
| Color | hex, piemēram, `#FF5500` | galvenā tēmas krāsa |
| Flag | `inline-icon` | piespiež ikonas režīmu |

| Līdzinājuma vērtība | Izkārtojums |
|---------------------|-------------|
| `right` | Poga etiķetes labajā pusē |
| `left` | Poga etiķetes kreisajā pusē |
| `top` | Poga virs etiķetes, pilnā platumā centrēta |
| `center` / `bottom` | Poga zem etiķetes, pilnā platumā centrēta |

#### `results{...}` — izkārtojums un redzamība pēc tveršanas

Pārņem `display{}` iestatījumus. Izmantojiet, lai pārvietotu pogu vai paslēptu elementus, kad vērtība ir tverta.

```
results{<align>, hide(<element>)}
```

| `hide` vērtība | Efekts |
|---|---|
| `hide(capture)` | Paslēpj tveršanas pogu, kad fails/vērtība eksistē |
| `hide(review)` | Paslēpj pārskatīšanas sīktēlu / atskaņošanas pogu |
| `hide(filename)` | Paslēpj faila nosaukumu, kas redzams pēc augšupielādes |
| `hide(camera)` | Paslēpj kameras aktivizēšanas pogu pēc tveršanas |
| `hide(scanner)` | Paslēpj svītrkoda skenēšanas pogu pēc vērtības skenēšanas |
| `hide(value)` | Paslēpj skenētās vērtības tekstu (svītrkods / geopoint) |

Logrīks automātiski pārslēdzas no `display{}` uz `results{}` izkārtojumu brīdī, kad vērtība tiek tverta.

**Piemēri:**

```
inline display{right}                                    → ikona pa labi no etiķetes
inline display{left, large}                              → liela ikona kreisajā pusē
inline display{center, large, #FF5500}                   → liela oranža ikona zem etiķetes
inline display{right} results{left}                      → ikona pārvietojas pa kreisi pēc tveršanas
inline display{right} results{hide(capture)}             → ikona pazūd pēc tveršanas
inline display{center} results{hide(capture), hide(filename)}
```

## Zināmie ierobežojumi

- Sarežģīti izskati var netikt attēloti identiski visās platformās.
- Daži uzlaboti rtSurvey izskati var netikt atbalstīti bezsaistes režīmā.

## Izskata problēmu novēršana

1. **Izskats netiek lietots**: Pārbaudiet, vai appearance stabiņā nav drukas kļūdu.
2. **Nekonsekventa renderēšana**: Pārbaudiet saderību ar jautājuma tipu un platformu.
3. **Veiktspējas problēmas**: Apsveriet iespēju vienkāršot sarežģītus izskatus, īpaši lielām aptaujām.

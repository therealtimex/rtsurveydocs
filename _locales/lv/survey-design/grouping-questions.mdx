Grupas XLSForm ļauj organizēt saistītus jautājumus kopā, uzlabojot aptaujas struktūru un datu analīzes iespējas. rtSurvey pilnībā atbalsta XLSForm grupas un paplašina to funkcionalitāti ar papildu funkcijām.

## Pamata grupas struktūra

Lai izveidotu jautājumu grupu, izmantojiet sintaksi `begin_group` un `end_group`:

```
| type         | name       | label                                    |
|--------------|------------|------------------------------------------|
| begin_group  | respondent | Respondenta informācija                  |
| text         | name       | Ievadiet respondenta vārdu               |
| text         | position   | Ievadiet respondenta amatu               |
| end_group    |            |                                          |
```

Galvenie punkti:
- Rindai `begin_group` nepieciešams `name` un `label`.
- Rindai `end_group` nav nepieciešams vārds vai etiķete.
- Jautājumi starp `begin_group` un `end_group` ir daļa no grupas.

## Grupas izskats

rtSurvey atbalsta dažādas izskata opcijas grupām:

1. **field-list**: Rāda vairākus jautājumus vienā ekrānā.
   ```
   | type         | name       | label     | appearance |
   |--------------|------------|-----------|------------|
   | begin_group  | respondent | Respondents | field-list |
   | text         | name       | Vārds     |            |
   | text         | position   | Amats     |            |
   | end_group    |            |           |            |
   ```

2. **grid**: Izveido kompaktu, tabulai līdzīgu izkārtojumu grupām (rtSurvey specifisks).
   ```
   | type         | name       | label     | appearance |
   |--------------|------------|-----------|------------|
   | begin_group  | household  | Mājsaimniecība | grid  |
   | text         | member_name| Vārds     |            |
   | integer      | member_age | Vecums    |            |
   | end_group    |            |           |            |
   ```

3. **collapsible**: Izveido paplašināmas/sakļaujamas grupas (rtSurvey specifisks).
   ```
   | type         | name       | label     | appearance  |
   |--------------|------------|-----------|-------------|
   | begin_group  | details    | Sīkāka informācija | collapsible |
   | text         | address    | Adrese    |             |
   | text         | phone      | Tālrunis  |             |
   | end_group    |            |           |             |
   ```

## Ligzdotas grupas

Grupas var ligzdot citās grupās sarežģītākām struktūrām:

```
| type         | name       | label                                    |
|--------------|------------|------------------------------------------|
| begin_group  | hospital   | Slimnīcas informācija                    |
| text         | hosp_name  | Kāds ir šīs slimnīcas nosaukums?         |
| begin_group  | medication | Medikamentu pieejamība                   |
| select_one y_n| hiv_meds  | Vai šajā slimnīcā ir HIV medikamenti?    |
| end_group    |            |                                          |
| end_group    |            |                                          |
```

**Piezīme**: Vienmēr vispirms beidziet pēdējo sākto grupu, lai saglabātu pareizu ligzdošanu.

## Izlaišanas loģika grupām

Izmantojiet kolonnu `relevant`, lai ieviestu izlaišanas loģiku visām grupām:

```
| type         | name   | label                                        | relevant        |
|--------------|--------|----------------------------------------------|-----------------|
| integer      | age    | Cik jums gadu?                               |                 |
| begin_group  | child  | Bērns                                        | ${age} <= 5     |
| integer      | muac   | Reģistrēt bērna vidējā augšdelma apkārtmēru  |                 |
| select_one y_n| mrdt  | Vai bērna ātrās diagnostikas tests ir pozitīvs? |               |
| end_group    |        |                                              |                 |
```

Šajā piemērā grupa `child` parādīsies tikai tad, ja respondenta vecums ir 5 vai jaunāks.

## Labākā prakse grupu izmantošanā

1. Izmantojiet jēgpilnus grupas nosaukumus, lai uzlabotu datu analīzi.
2. Saglabājiet grupas koncentrētas uz saistītiem jautājumiem.
3. Izmantojiet ligzdotās grupas apdomīgi, lai izvairītos no pārmērīgi sarežģītām struktūrām.
4. Rūpīgi testējiet izlaišanas loģiku, izmantojot `relevant` grupās.
5. Apsveriet izskata varianta `field-list` izmantošanu īsām grupām, lai samazinātu ritināšanu.
6. Izmantojiet rtSurvey režģa izkārtojumu saistītas informācijas kompaktai attēlošanai.
7. Izmantojiet sakļaujamās grupas garām formām, lai uzlabotu navigāciju.

## rtSurvey specifiskās funkcijas

1. **Režģa izkārtojums**: Izmantojiet izskata variantu `grid` tabulai līdzīgiem attēlojumiem.
2. **Sakļaujamās grupas**: Ieviesiet izskata variantu `collapsible` paplašināmām sadaļām.
3. **Pielāgots stils**: Piemērojiet pielāgotu CSS grupām unikāliem vizuāliem dizainiem.
4. **Dinamiskā grupas uzvedība**: Ieviesiet sarežģītu izlaišanas loģiku un aprēķinus grupās.

## Daudzvalodu atbalsts

rtSurvey atbalsta daudzvalodu grupas. Izmantojiet valodai specifiskas kolonnas etiķetēm:

```
| type         | name       | label::English | label::French |
|--------------|------------|----------------|---------------|
| begin_group  | personal   | Personal Info  | Infos Personnelles |
| text         | name       | Name           | Nom           |
| end_group    |            |                |               |
```

## Mobilās lietotnes apsvērumi

- Grupas ar izskata variantu `field-list` mobilajā lietotnē tiek rādītas kā viens ekrāns.
- Sakļaujamās grupas var uzlabot navigāciju mazākos ekrānos.
- Režģa izkārtojumi var pielāgoties labākai redzamībai mobilajās ierīcēs.

## Zināmie ierobežojumi

- Ārkārtīgi dziļa grupu ligzdošana var ietekmēt veiktspēju dažās ierīcēs.
- Daži uzlabotie stila varianti var nebūt pieejami grupām mobilajā lietotnē.

## Grupu problēmu novēršana

1. Nodrošiniet, ka katram `begin_group` ir atbilstošs `end_group`.
2. Pārbaudiet, ka grupas nosaukumi ir unikāli formas ietvaros.
3. Pārbaudiet, ka izlaišanas loģika atsaucas uz pareiziem jautājumu nosaukumiem.
4. Rūpīgi testējiet grupas gan tīmekļa, gan mobilajās saskarnēs.

Efektīvi izmantojot grupas savās XLSForm formās ar rtSurvey, varat izveidot labi organizētas, efektīvas aptaujas, kas uzlabo gan datu vākšanas pieredzi, gan jūsu datu analīzes kvalitāti.

Η στήλη `appearance` στο rtSurvey σάς επιτρέπει να προσαρμόσετε την οπτική παρουσίαση και τη συμπεριφορά των ερωτήσεων στις έρευνές σας. Αυτό το χαρακτηριστικό βελτιώνει την εμπειρία του χρήστη και μπορεί να βελτιώσει σημαντικά την αποτελεσματικότητα της συλλογής δεδομένων. Το rtSurvey υποστηρίζει τις τυπικές ιδιότητες εμφάνισης XLSForm και τις επεκτείνει με πρόσθετες επιλογές.

## Τυπικές Ιδιότητες Εμφάνισης XLSForm

Το rtSurvey υποστηρίζει τις ακόλουθες τυπικές ιδιότητες εμφάνισης XLSForm:

| Ιδιότητα Εμφάνισης (Appearance Attribute) | Τύποι Ερωτήσεων (Question Types) | Περιγραφή |
|----------------------|----------------|-------------|
| multiline | text | Δημιουργεί ένα πλαίσιο κειμένου πολλαπλών γραμμών (καλύτερο για προγράμματα περιήγησης ιστού) |
| minimal | select_one, select_multiple | Εμφανίζει τις επιλογές σε ένα αναπτυσσόμενο μενού |
| quick | select_one | Προχωρά αυτόματα στην επόμενη ερώτηση μετά την επιλογή (μόνο για κινητά) |
| no-calendar | date | Καταργεί την εμφάνιση ημερολογίου (μόνο για κινητά) |
| month-year | date | Επιτρέπει την επιλογή μόνο μήνα και έτους |
| year | date | Επιτρέπει την επιλογή μόνο έτους |
| horizontal-compact | select_one, select_multiple | Εμφανίζει τις επιλογές οριζόντια (μόνο στον ιστό) |
| horizontal | select_one, select_multiple | Εμφανίζει τις επιλογές οριζόντια σε στήλες (μόνο στον ιστό) |
| likert | select_one | Παρουσιάζει τις επιλογές ως κλίμακα Likert |
| compact | select_one, select_multiple | Εμφανίζει τις επιλογές δίπλα-δίπλα με ελάχιστη απόσταση (padding) |
| quickcompact | select_one | Συνδυάζει τη συμπαγή εμφάνιση με την αυτόματη προώθηση (μόνο για κινητά) |
| field-list | groups | Εμφανίζει ολόκληρη την ομάδα σε μία οθόνη (μόνο για κινητά) |
| label | select_one, select_multiple | Εμφανίζει τις ετικέτες των επιλογών χωρίς πεδία εισαγωγής |
| list-nolabel | select_one, select_multiple | Εμφανίζει τα πεδία εισαγωγής χωρίς ετικέτες (χρησιμοποιείται με το `label`) |
| table-list | groups | Εμφανίζει τις ερωτήσεις σε μορφή πίνακα |
| signature | image | Επιτρέπει τη λήψη υπογραφής (μόνο για κινητά) |
| draw | image | Επιτρέπει το σχέδιο με το χέρι (μόνο για κινητά) |
| map, quick map | select_one, select_one_from_file | Επιτρέπει την επιλογή από χαρακτηριστικά χάρτη |

## Βέλτιστες Πρακτικές για τη Χρήση του Appearance

1. **Συνέπεια**: Χρησιμοποιήστε τις ιδιότητες εμφάνισης με συνέπεια σε όλη την έρευνά σας για ομοιόμορφη εμφάνιση.
2. **Κινητά vs. Ιστός**: Λάβετε υπόψη πώς θα εμφανίζονται οι μορφές σε διαφορετικές συσκευές και πλατφόρμες.
3. **Απόδοση**: Να είστε προσεκτικοί με ιδιότητες εμφάνισης που μπορεί να καθυστερήσουν τη φόρτωση της φόρμας (π.χ. `table-list` για μεγάλες ομάδες).
4. **Εμπειρία Χρήστη**: Επιλέξτε εμφανίσεις που κάνουν την εισαγωγή δεδομένων ευκολότερη και πιο διαισθητική για τους ερωτώμενους.
5. **Δοκιμές**: Πάντα να δοκιμάζετε τη φόρμα σας στις συσκευές-στόχους για να διασφαλίσετε ότι οι εμφανίσεις λειτουργούν όπως αναμένεται.

## Προηγμένες Τεχνικές

### Συνδυασμός Εμφανίσεων

Ορισμένες ιδιότητες εμφάνισης μπορούν να συνδυαστούν για πιο περίπλοκες διατάξεις:

```
| type | name | label | appearance |
|------|------|-------|------------|
| select_one options | choice | Επιλέξτε ένα: | minimal compact |
```

### Δυναμικές Εμφανίσεις

Το rtSurvey επιτρέπει δυναμικές αλλαγές εμφάνισης βάσει της λογικής της φόρμας:

```
| type | name | label | appearance | relevant |
|------|------|-------|------------|----------|
| text | time | Εισάγετε ώρα: | inline-[%H:%M] | ${show_time} = 'yes' |
```

## Σημεία Προσοχής για την Εφαρμογή σε Κινητά

- Ορισμένες εμφανίσεις (π.χ. `quick`, `signature`) είναι ειδικά για κινητές συσκευές.
- Δοκιμάστε διεξοδικά τόσο σε Android όσο και σε iOS για να διασφαλίσετε συνεπή συμπεριφορά.

## Εκτεταμένες Ιδιότητες Εμφάνισης του rtSurvey

Εκτός από τις τυπικές εμφανίσεις XLSForm, το rtSurvey υποστηρίζει τις ακόλουθες επιλογές που αφορούν ειδικά την πλατφόρμα:

### Έλεγχος δεδομένων και προβολής

| Ιδιότητα Εμφάνισης (Appearance Attribute) | Τύποι Ερωτήσεων (Question Types) | Περιγραφή |
|----------------------|----------------|-------------|
| `invisible` | any | Κρύβει το πεδίο από την προβολή ενώ συνεχίζει να συλλέγει ή να υπολογίζει την τιμή του. Διαφέρει από τον τύπο `hidden` — το πεδίο εξακολουθεί να συμμετέχει στη λογική. |
| `displaytitle` | any | Επιβάλλει την εμφάνιση της ετικέτας/τίτλου του πεδίου ακόμη και όταν θα ήταν διαφορετικά κρυμμένο. |
| `autopull` | select_one, select_multiple | Ανακτά αυτόματα εξωτερικά δεδομένα για να συμπληρώσει τις επιλογές όταν φορτώνεται η φόρμα ή όταν αλλάζει ένα πεδίο-ενεργοποιητής. |
| `floating_hint` | text, integer, decimal | Εμφανίζει το κείμενο υπόδειξης (hint) ως αιωρούμενη ετικέτα πάνω από το πεδίο εισαγωγής αντί για κάτω από αυτό. |
| `calculate-button` | calculate | Προσθέτει ένα ορατό κουμπί που ενεργοποιεί τον επαναϋπολογισμό του πεδίου κατ' απαίτηση, αντί για τον αυτόματο υπολογισμό. |

### Ομάδα και πλοήγηση

| Ιδιότητα Εμφάνισης (Appearance Attribute) | Τύποι Ερωτήσεων (Question Types) | Περιγραφή |
|----------------------|----------------|-------------|
| `section` | group | Εμφανίζει την ομάδα ως πτυσσόμενη κάρτα ενότητας. Σημείωση: μόνο για την εφαρμογή σε κινητά. |
| `toc-hide` | any | Εξαιρεί την ερώτηση από το πάνελ πλοήγησης του πίνακα περιεχομένων (TOC). |
| `minilog` | begin_repeat | Εμφανίζει τις ολοκληρωμένες εγγραφές επανάληψης ως μια συμπαγή λίστα (mini-log) αντί να επεκτείνει κάθε εγγραφή εντός της σελίδας. |

### Συμπεριφορά εισαγωγής

| Ιδιότητα Εμφάνισης (Appearance Attribute) | Τύποι Ερωτήσεων (Question Types) | Περιγραφή |
|----------------------|----------------|-------------|
| `proper` | text | Μετατρέπει αυτόματα το πρώτο γράμμα κάθε λέξης σε κεφαλαίο καθώς πληκτρολογεί ο ερωτώμενος (συμπεριφορά title-case). |
| `text-nolabel` | text, integer, decimal | Εμφανίζει το πεδίο εισαγωγής χωρίς ορατή ετικέτα. |
| `inline-1line` | text | Επιβάλλει την εμφάνιση της εισαγωγής κειμένου ως μία γραμμή, ακόμη και όταν η ετικέτα της ερώτησης είναι μεγάλη. |
| `popup` | any | Εμφανίζει το πεδίο μέσα σε ένα αναδυόμενο παράθυρο (popup) / επικαλυπτόμενο παράθυρο (modal) αντί για απευθείας στη σελίδα. |

### Διάταξη (Layout)

| Ιδιότητα Εμφάνισης (Appearance Attribute) | Τύποι Ερωτήσεων (Question Types) | Περιγραφή |
|----------------------|----------------|-------------|
| `1screen` | group | Επιβάλλει την εμφάνιση ολόκληρης της ομάδας σε μία οθόνη, ανεξάρτητα από το μέγεθος της ομάδας. |
| `columns(n)` | select_one, select_multiple | Εμφανίζει τις επιλογές σε `n` στήλες. Παράδειγμα: `columns(3)` εμφανίζει τρεις στήλες κουμπιών επιλογής (radio buttons). |
| `gridformat<row=R col=C colspan=S align=center>` | any | Τοποθετεί το πεδίο σε μια διάταξη CSS-grid στη σειρά `R`, στήλη `C`, εκτεινόμενο σε `S` στήλες. Χρησιμοποιείται με το `advanced-extension/grid-layout`. |
| `ignore-simplify` | any | Δίνει οδηγία στον μηχανισμό εμφάνισης της φόρμας να παραλείψει την αυτόματη απλοποίηση ή συμπύκνωση της διάταξης αυτού του πεδίου. |
| `horizontal(N)` | select_one, select_multiple | Ορίζει κάθε επιλογή να καταλαμβάνει το `N` τοις εκατό του πλάτους της σειράς. Παράδειγμα: `horizontal(50)` τοποθετεί δύο επιλογές ανά σειρά. |
| `scroll-view(N%)` | group, repeat | Περιορίζει το πλαίσιο σε μέγιστο ύψος `N%` της περιοχής προβολής (viewport) (ή του γονικού στοιχείου), προσθέτοντας μια γραμμή κύλισης όταν το περιεχόμενο υπερβαίνει το όριο. Παράδειγμα: `scroll-view(60%)`. |

### Γραφικά Στοιχεία (Widgets)

| Ιδιότητα Εμφάνισης (Appearance Attribute) | Τύποι Ερωτήσεων (Question Types) | Περιγραφή |
|----------------------|----------------|-------------|
| `likert` | select_one | Παρουσιάζει τις επιλογές ως σειρά κλίμακας Likert (περιλαμβάνεται ήδη στον τυπικό πίνακα παραπάνω, επιβεβαιωμένη υποστήριξη). |
| `distress` | select_one | Εμφανίζει τις επιλογές ως οπτικό στοιχείο της Κλίμακας Ψυχολογικής Δυσφορίας Kessler (K10) με συναισθηματικά εικονίδια. |
| `rating_box-fill-{c1}-{c2}-{c3}-{c4}-{c5}` | select_one | Εμφανίζει τις επιλογές ως στυλιζαρισμένα κουτιά βαθμολογίας με πέντε υποδοχές χρωμάτων. `c1` = εξωτερικό περίγραμμα πλαισίου, `c2` = περίγραμμα μη επιλεγμένου, `c3` = περίγραμμα και γέμισμα επιλεγμένου, `c4` = χρώμα κειμένου μη επιλεγμένου, `c5` = χρώμα κειμένου επιλεγμένου. Παράδειγμα: `rating_box-fill-grey-blue-green-black-white`. |
| `tagging-choices-noshow-v2-{c1}-{c2}-{c3}-{c4}-{c5}` | select_multiple | Εμφανίζει τις επιλογές ως χρωματιστά "τσιπ" ετικετών (tag chips). Οι πέντε υποδοχές χρωμάτων ακολουθούν την ίδια σειρά με το `rating_box-fill`. Οι επιλεγμένες επιλογές επισημαίνονται, ενώ οι μη επιλεγμένες αποκρύπτονται από την προβολή σύνοψης. |

### Ενσωμάτωση API

| Ιδιότητα Εμφάνισης (Appearance Attribute) | Τύποι Ερωτήσεων (Question Types) | Περιγραφή |
|----------------------|----------------|-------------|
| `callapi` | text, integer, decimal, select_one | Επιτρέπει την ενσωμάτωση κλήσεων API για αυτό το πεδίο. Η στήλη calculation θα πρέπει να περιέχει μια έκφραση `callapi()`. Δείτε [Call API](advanced-features/call-api). |
| `callapi-verify(params)` | text, integer, decimal | Ενεργοποιεί μια κλήση επαλήθευσης API χρησιμοποιώντας στατικές παραμέτρους. Η φόρμα εμποδίζει την πρόοδο μέχρι το API να επιβεβαιώσει την τιμή. |
| `callapi-verify(dynamicParams)` | text, integer, decimal | Το ίδιο με το `callapi-verify` αλλά με παραμέτρους που προέρχονται από άλλες τιμές πεδίων κατά τον χρόνο εκτέλεσης. |

### Εναλλαγή γλώσσας (Language switcher)

| Ιδιότητα Εμφάνισης (Appearance Attribute) | Τύποι Ερωτήσεων (Question Types) | Περιγραφή |
|----------------------|----------------|-------------|
| `change_language-{colors} default('lang')` | note, text | Εμφανίζει ένα στοιχείο εναλλαγής γλώσσας με στυλ βάσει των δοθέντων κωδικών χρωμάτων. Το διακριτικό `default('lang')` ορίζει την αρχική γλώσσα (π.χ. `default('en')`). Μετατρέπεται σε `rtDefault('lang')` εσωτερικά κατά την ανάλυση. Παράδειγμα: `change_language-blue-white default('vi')`. |

### Μορφή ημερομηνίας/ώρας εντός γραμμής (Inline)

Για τα πεδία `date`, `time`, και `datetime`, μπορείτε να καθορίσετε μια προσαρμοσμένη μορφή εμφάνισης χρησιμοποιώντας μια συμβολοσειρά μορφοποίησης που επισυνάπτεται στην εμφάνιση:

```
inline-[%d/%m/%Y]
inline-1line-[%d/%m/%Y %H:%M]
```

Τα διακριτικά μορφοποίησης είναι τα ίδια με τα `format-date()` και `format-date-time()`. Δείτε [Συναρτήσεις — Συναρτήσεις ημερομηνίας και ώρας](operators-and-functions/functions#date-and-time-functions).

Παράδειγμα:

| τύπος (type) | όνομα (name) | ετικέτα (label) | εμφάνιση (appearance) |
|------|------|-------|------------|
| datetime | event_time | Ημερομηνία και ώρα συμβάντος | inline-[%d/%m/%Y %I:%M %p] |
| date | birth_date | Ημερομηνία γέννησης | inline-[%d/%m/%Y] |

### Διάταξη κουμπιών εντός γραμμής — `display{}` και `results{}`

Για τύπους ερωτήσεων που εμφανίζονται ως ενσωματωμένο κουμπί εικονιδίου (`date`, `time`, `datetime`, `image`, `audio`, `video`, `file`, `barcode`, `geopoint`), δύο τροποποιητές εμφάνισης ελέγχουν τη θέση του κουμπιού και τη συμπεριφορά μετά τη λήψη.

#### `display{...}` — θέση κουμπιού πριν από τη λήψη

```
display{<align>, <size>, <color>}
```

| Παράμετρος | Τιμές | Προεπιλογή |
|-----------|--------|---------|
| Στοίχιση (Align) | `left`, `right`, `top`, `center`, `bottom` | `right` |
| Μέγεθος (Size) | `small`, `medium`, `large` | `small` |
| Χρώμα (Color) | hex π.χ. `#FF5500` | κύριο χρώμα θέματος |
| Σημαία (Flag) | `inline-icon` | επιβάλλει τη λειτουργία εικονιδίου |

| Τιμή Στοίχισης (Align) | Διάταξη |
|-------------|--------|
| `right` | Κουμπί στα δεξιά της ετικέτας |
| `left` | Κουμπί στα αριστερά της ετικέτας |
| `top` | Κουμπί πάνω από την ετικέτα, κεντραρισμένο σε πλήρες πλάτος |
| `center` / `bottom` | Κουμπί κάτω από την ετικέτα, κεντραρισμένο σε πλήρες πλάτος |

#### `results{...}` — διάταξη και ορατότητα μετά τη λήψη

Κληρονομεί τις ρυθμίσεις του `display{}`. Χρησιμοποιήστε το για να μετακινήσετε το κουμπί ή να αποκρύψετε στοιχεία μόλις ληφθεί μια τιμή.

```
results{<align>, hide(<element>)}
```

| Τιμή `hide` | Αποτέλεσμα |
|---|---|
| `hide(capture)` | Κρύβει το κουμπί λήψης μόλις υπάρξει αρχείο/τιμή |
| `hide(review)` | Κρύβει τη μικρογραφία ελέγχου / το κουμπί αναπαραγωγής |
| `hide(filename)` | Κρύβει το όνομα αρχείου που εμφανίζεται μετά τη μεταφόρτωση |
| `hide(camera)` | Κρύβει το κουμπί ενεργοποίησης της κάμερας μετά τη λήψη |
| `hide(scanner)` | Κρύβει το κουμπί σάρωσης γραμμωτού κώδικα μετά τη σάρωση μιας τιμής |
| `hide(value)` | Κρύβει το κείμενο της σαρωμένης τιμής (γραμμωτός κώδικας / γεωγραφικό σημείο) |

Το γραφικό στοιχείο μεταβαίνει αυτόματα από τη διάταξη `display{}` στη διάταξη `results{}` τη στιγμή που λαμβάνεται μια τιμή.

**Παραδείγματα:**

```
inline display{right}                                    → εικονίδιο δεξιά της ετικέτας
inline display{left, large}                              → μεγάλο εικονίδιο στα αριστερά
inline display{center, large, #FF5500}                   → μεγάλο πορτοκαλί εικονίδιο κάτω από την ετικέτα
inline display{right} results{left}                      → το εικονίδιο μετακινείται αριστερά μετά τη λήψη
inline display{right} results{hide(capture)}             → το εικονίδιο εξαφανίζεται μετά τη λήψη
inline display{center} results{hide(capture), hide(filename)}
```

## Γνωστοί Περιορισμοί

- Οι σύνθετες εμφανίσεις ενδέχεται να μην αποδίδονται πανομοιότυπα σε όλες τις πλατφόρμες.
- Ορισμένες προηγμένες εμφανίσεις του rtSurvey ενδέχεται να μην υποστηρίζονται σε λειτουργία εκτός σύνδεσης (offline mode).

## Αντιμετώπιση Προβλημάτων Εμφάνισης

1. **Η εμφάνιση δεν εφαρμόστηκε**: Ελέγξτε για τυπογραφικά λάθη στη στήλη appearance.
2. **Μη συνεπής απόδοση**: Επαληθεύστε τη συμβατότητα με τον τύπο ερώτησης και την πλατφόρμα.
3. **Θέματα απόδοσης**: Εξετάστε το ενδεχόμενο απλούστευσης σύνθετων εμφανίσεων, ειδικά για μεγάλες έρευνες.

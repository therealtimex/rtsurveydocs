Η στήλη `appearance` στο rtSurvey σας επιτρέπει να προσαρμόσετε την οπτική παρουσίαση και τη συμπεριφορά των ερωτήσεων στις έρευνές σας. Αυτή η λειτουργία βελτιώνει την εμπειρία του χρήστη και μπορεί να βελτιώσει σημαντικά την αποτελεσματικότητα της συλλογής δεδομένων. Το rtSurvey υποστηρίζει τυπικά χαρακτηριστικά εμφάνισης XLSForm και τα επεκτείνει με πρόσθετες επιλογές.

## Τυπικά Χαρακτηριστικά Εμφάνισης XLSForm

Το rtSurvey υποστηρίζει τα ακόλουθα τυπικά χαρακτηριστικά εμφάνισης XLSForm:

| Χαρακτηριστικό Εμφάνισης | Τύποι Ερωτήσεων | Περιγραφή |
|----------------------|----------------|-------------|
| multiline | text | Δημιουργεί ένα πλαίσιο κειμένου πολλαπλών γραμμών (καλύτερο για πελάτες ιστού) |
| minimal | select_one, select_multiple | Εμφανίζει τις επιλογές σε ένα αναπτυσσόμενο μενού |
| quick | select_one | Μεταβαίνει αυτόματα στην επόμενη ερώτηση μετά την επιλογή (μόνο για κινητά) |
| no-calendar | date | Καταστέλλει την εμφάνιση του ημερολογίου (μόνο για κινητά) |
| month-year | date | Επιτρέπει την επιλογή μόνο μήνα και έτους |
| year | date | Επιτρέπει την επιλογή μόνο έτους |
| horizontal-compact | select_one, select_multiple | Εμφανίζει τις επιλογές οριζόντια (μόνο για ιστό) |
| horizontal | select_one, select_multiple | Εμφανίζει τις επιλογές οριζόντια σε στήλες (μόνο για ιστό) |
| likert | select_one | Παρουσιάζει τις επιλογές ως κλίμακα Likert |
| compact | select_one, select_multiple | Εμφανίζει τις επιλογές δίπλα-δίπλα με ελάχιστο padding |
| quickcompact | select_one | Συνδυάζει τη συμπαγή εμφάνιση με την αυτόματη μετάβαση (μόνο για κινητά) |
| field-list | groups | Εμφανίζει ολόκληρη την ομάδα σε μία οθόνη (μόνο για κινητά) |
| label | select_one, select_multiple | Εμφανίζει τις ετικέτες επιλογών χωρίς πεδία εισαγωγής |
| list-nolabel | select_one, select_multiple | Εμφανίζει πεδία εισαγωγής χωρίς ετικέτες (χρήση με `label`) |
| table-list | groups | Εμφανίζει τις ερωτήσεις σε μορφή πίνακα |
| signature | image | Επιτρέπει τη λήψη υπογραφής (μόνο για κινητά) |
| draw | image | Επιτρέπει το ελεύθερο σχέδιο (μόνο για κινητά) |
| map, quick map | select_one, select_one_from_file | Επιτρέπει την επιλογή από χαρακτηριστικά χάρτη |

## Βέλτιστες Πρακτικές για τη Χρήση της Εμφάνισης

1. **Συνέπεια**: Χρησιμοποιήστε χαρακτηριστικά εμφάνισης με συνέπεια σε όλη την έρευνά σας για ομοιόμορφη εμφάνιση.
2. **Κινητά έναντι Ιστού**: Λάβετε υπόψη πώς θα εμφανίζονται οι εμφανίσεις σε διαφορετικές συσκευές και πλατφόρμες.
3. **Απόδοση**: Να είστε προσεκτικοί με χαρακτηριστικά εμφάνισης που μπορεί να επιβραδύνουν τη φόρτωση της φόρμας (π.χ. `table-list` για μεγάλες ομάδες).
4. **Εμπειρία Χρήστη**: Επιλέξτε εμφανίσεις που κάνουν την εισαγωγή δεδομένων ευκολότερη και πιο διαισθητική για τους ερωτηθέντες.
5. **Δοκιμή**: Πάντα να δοκιμάζετε τη φόρμα σας σε συσκευές-στόχους για να διασφαλίζετε ότι οι εμφανίσεις λειτουργούν όπως αναμένεται.

## Προηγμένες Τεχνικές

### Συνδυασμός Εμφανίσεων

Ορισμένα χαρακτηριστικά εμφάνισης μπορούν να συνδυαστούν για πιο σύνθετες διατάξεις:

```
| type | name | label | appearance |
|------|------|-------|------------|
| select_one options | choice | Select one: | minimal compact |
```

### Δυναμικές Εμφανίσεις

Το rtSurvey επιτρέπει δυναμικές αλλαγές εμφάνισης βάσει της λογικής της φόρμας:

```
| type | name | label | appearance | relevant |
|------|------|-------|------------|----------|
| text | time | Enter time: | inline-[%H:%M] | ${show_time} = 'yes' |
```

## Σημειώσεις για την Εφαρμογή Κινητών

- Ορισμένες εμφανίσεις (π.χ. `quick`, `signature`) είναι ειδικές για κινητές συσκευές.
- Δοκιμάστε διεξοδικά τόσο σε Android όσο και σε iOS για να διασφαλίσετε συνεπή συμπεριφορά.

## Εκτεταμένα Χαρακτηριστικά Εμφάνισης του rtSurvey

Εκτός από τις τυπικές εμφανίσεις XLSForm, το rtSurvey υποστηρίζει τις ακόλουθες επιλογές ειδικά για την πλατφόρμα:

### Έλεγχος δεδομένων και εμφάνισης

| Χαρακτηριστικό Εμφάνισης | Τύποι Ερωτήσεων | Περιγραφή |
|----------------------|----------------|-------------|
| `invisible` | any | Κρύβει το πεδίο από την προβολή, ενώ εξακολουθεί να συλλέγει ή να υπολογίζει την τιμή του. Διαφέρει από τον τύπο `hidden` — το πεδίο εξακολουθεί να συμμετέχει στη λογική. |
| `displaytitle` | any | Αναγκάζει την εμφάνιση της ετικέτας/τίτλου του πεδίου ακόμη και όταν διαφορετικά θα είχε κατασταλεί. |
| `autopull` | select_one, select_multiple | Ανακτά αυτόματα εξωτερικά δεδομένα για τη συμπλήρωση επιλογών όταν φορτώνεται η φόρμα ή όταν αλλάζει ένα πεδίο ενεργοποίησης. |
| `floating_hint` | text, integer, decimal | Εμφανίζει το κείμενο υπόδειξης (hint) ως αιωρούμενη ετικέτα πάνω από το πεδίο εισαγωγής αντί για κάτω από αυτό. |
| `calculate-button` | calculate | Προσθέτει ένα ορατό κουμπί που ενεργοποιεί τον επανυπολογισμό του πεδίου κατόπιν ζήτησης, αντί για αυτόματο υπολογισμό. |

### Διάταξη

| Χαρακτηριστικό Εμφάνισης | Τύποι Ερωτήσεων | Περιγραφή |
|----------------------|----------------|-------------|
| `1screen` | group | Αναγκάζει ολόκληρη την ομάδα να εμφανίζεται σε μία μόνο οθόνη ανεξάρτητα από το μέγεθος της ομάδας. |
| `columns(n)` | select_one, select_multiple | Εμφανίζει τις επιλογές σε `n` στήλες. Παράδειγμα: `columns(3)` εμφανίζει τρεις στήλες με κουμπιά επιλογής (radio buttons). |
| `gridformat<row=R col=C colspan=S align=center>` | any | Τοποθετεί το πεδίο σε διάταξη CSS-grid στη σειρά `R`, στήλη `C`, εκτεινόμενο σε `S` στήλες. Χρησιμοποιείται με το `advanced-extension/grid-layout`. |
| `ignore-simplify` | any | Καθοδηγεί τον αποδότη (renderer) της φόρμας να παραλείψει την αυτόματη απλοποίηση ή συμπύκνωση της διάταξης αυτού του πεδίου. |

### Widgets

| Χαρακτηριστικό Εμφάνισης | Τύποι Ερωτήσεων | Περιγραφή |
|----------------------|----------------|-------------|
| `likert` | select_one | Παρουσιάζει τις επιλογές ως σειρά κλίμακας Likert (περιλαμβάνεται ήδη στον τυπικό πίνακα παραπάνω· επιβεβαιωμένη υποστήριξη). |
| `distress` | select_one | Αποδίδει τις επιλογές ως το οπτικό widget της κλίμακας ψυχολογικής δυσφορίας Kessler (K10) με συναισθηματικά εικονίδια. |

### Ενοποίηση API

| Χαρακτηριστικό Εμφάνισης | Τύποι Ερωτήσεων | Περιγραφή |
|----------------------|----------------|-------------|
| `callapi` | text, integer, decimal, select_one | Επιτρέπει την ενοποίηση κλήσης API για αυτό το πεδίο. Η στήλη υπολογισμού (calculation) θα πρέπει να περιέχει μια έκφραση `callapi()`. Δείτε το [Call API](advanced-features/call-api). |
| `callapi-verify(params)` | text, integer, decimal | Ενεργοποιεί μια κλήση επαλήθευσης API χρησιμοποιώντας στατικές παραμέτρους. Η φόρμα εμποδίζει την πρόοδο μέχρι το API να επιβεβαιώσει την τιμή. |
| `callapi-verify(dynamicParams)` | text, integer, decimal | Ίδιο με το `callapi-verify` αλλά με παραμέτρους που προέρχονται από άλλες τιμές πεδίων κατά τον χρόνο εκτέλεσης. |

### Μορφή ημερομηνίας/ώρας εντός γραμμής (inline)

Για τα πεδία `date`, `time` και `datetime`, μπορείτε να καθορίσετε μια προσαρμοσμένη μορφή εμφάνισης χρησιμοποιώντας μια συμβολοσειρά μορφοποίησης που επισυνάπτεται στην εμφάνιση:

```
inline-[%d/%m/%Y]
inline-1line-[%d/%m/%Y %H:%M]
```

Τα διακριτικά μορφής (tokens) είναι τα ίδια με τα `format-date()` και `format-date-time()`. Δείτε τις [Συναρτήσεις — Συναρτήσεις ημερομηνίας και ώρας](operators-and-functions/functions#date-and-time-functions).

Παράδειγμα:

| type | name | label | appearance |
|------|------|-------|------------|
| datetime | event_time | Ημερομηνία και ώρα εκδήλωσης | inline-[%d/%m/%Y %I:%M %p] |
| date | birth_date | Ημερομηνία γέννησης | inline-[%d/%m/%Y] |

### Διάταξη κουμπιών εντός γραμμής — `display{}` και `results{}`

Για τύπους ερωτήσεων που αποδίδονται ως κουμπί εικονιδίου εντός γραμμής (`date`, `time`, `datetime`, `image`, `audio`, `video`, `file`, `barcode`, `geopoint`), δύο τροποποιητές εμφάνισης ελέγχουν τη θέση του κουμπιού και τη συμπεριφορά μετά τη λήψη.

#### `display{...}` — θέση κουμπιού πριν από τη λήψη

```
display{<align>, <size>, <color>}
```

| Παράμετρος | Τιμές | Προεπιλογή |
|-----------|--------|---------|
| Align (Στοίχιση) | `left`, `right`, `top`, `center`, `bottom` | `right` |
| Size (Μέγεθος) | `small`, `medium`, `large` | `small` |
| Color (Χρώμα) | hex π.χ. `#FF5500` | βασικό χρώμα θέματος |
| Flag | `inline-icon` | επιβάλλει τη λειτουργία εικονιδίου |

| Τιμή Align | Διάταξη |
|-------------|--------|
| `right` | Κουμπί στα δεξιά της ετικέτας |
| `left` | Κουμπί στα αριστερά της ετικέτας |
| `top` | Κουμπί πάνω από την ετικέτα, κεντραρισμένο σε πλήρες πλάτος |
| `center` / `bottom` | Κουμπί κάτω από την ετικέτα, κεντραρισμένο σε πλήρες πλάτος |

#### `results{...}` — διάταξη και ορατότητα μετά τη λήψη

Κληρονομεί τις ρυθμίσεις του `display{}`. Χρησιμοποιήστε το για να μετακινήσετε το κουμπί ή να αποκρύψετε στοιχεία μόλις ληφθεί μια τιμή.

```
results{<align>, hide(<element>)}
```

| Τιμή `hide` | Αποτέλεσμα |
|---|---|
| `hide(capture)` | Κρύβει το κουμπί λήψης μόλις υπάρχει αρχείο/τιμή |
| `hide(review)` | Κρύβει τη μικρογραφία επισκόπησης / το κουμπί αναπαραγωγής |
| `hide(filename)` | Κρύβει το όνομα αρχείου που εμφανίζεται μετά τη μεταφόρτωση |
| `hide(camera)` | Κρύβει το κουμπί ενεργοποίησης της κάμερας μετά τη λήψη |
| `hide(scanner)` | Κρύβει το κουμπί σάρωσης γραμμωτού κώδικα (barcode) μετά τη σάρωση μιας τιμής |
| `hide(value)` | Κρύβει το κείμενο της σαρωμένης τιμής (barcode / geopoint) |

Το widget μεταβαίνει αυτόματα από τη διάταξη `display{}` στη διάταξη `results{}` τη στιγμή που λαμβάνεται μια τιμή.

**Παραδείγματα:**

```
inline display{right}                                    → εικονίδιο δεξιά της ετικέτας
inline display{left, large}                              → μεγάλο εικονίδιο στα αριστερά
inline display{center, large, #FF5500}                   → μεγάλο πορτοκαλί εικονίδιο κάτω από την ετικέτα
inline display{right} results{left}                      → το εικονίδιο μετακινείται αριστερά μετά τη λήψη
inline display{right} results{hide(capture)}             → το εικονίδιο εξαφανίζεται μετά τη λήψη
inline display{center} results{hide(capture), hide(filename)}
```

## Γνωστοί Περιορισμοί

- Οι σύνθετες εμφανίσεις ενδέχεται να μην αποδίδονται πανομοιότυπα σε όλες τις πλατφόρμες.
- Ορισμένες προηγμένες εμφανίσεις του rtSurvey ενδέχεται να μην υποστηρίζονται σε λειτουργία εκτός σύνδεσης (offline).

## Αντιμετώπιση Προβλημάτων Εμφάνισης

1. **Η Εμφάνιση Δεν Εφαρμόστηκε**: Ελέγξτε για τυπογραφικά λάθη στη στήλη appearance.
2. **Ασυνεπής Απόδοση**: Επαληθεύστε τη συμβατότητα με τον τύπο ερώτησης και την πλατφόρμα.
3. **Προβλήματα Απόδοσης**: Εξετάστε το ενδεχόμενο απλούστευσης των σύνθετων εμφανίσεων, ειδικά για μεγάλες έρευνες.

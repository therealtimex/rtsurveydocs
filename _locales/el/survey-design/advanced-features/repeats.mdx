Αυτή η σελίδα καλύπτει προηγμένα μοτίβα για την εργασία με ομάδες επαναλήψεων (repeat groups) στο rtSurvey. Για τα βασικά της ρύθμισης μιας ομάδας επανάληψης, δείτε [Ομαδοποίηση και Επαναλήψεις](../repeats).

---

## Δυναμικός αριθμός επαναλήψεων

Από προεπιλογή, ο ερευνητής αποφασίζει πόσες φορές θα επαναληφθεί μια ομάδα. Μπορείτε να ορίσετε έναν σταθερό αριθμό επαναλήψεων χρησιμοποιώντας το `repeat_count`:

| type | name | label | repeat_count |
|------|------|-------|--------------|
| begin_repeat | household_members | Μέλος νοικοκυριού | `${num_members}` |
| text | member_name | Όνομα μέλους | |
| integer | member_age | Ηλικία | |
| end_repeat | | | |

Η επανάληψη εκτελείται ακριβώς `${num_members}` φορές, όπου το `num_members` συλλέχθηκε νωρίτερα στη φόρμα. Ο ερευνητής δεν μπορεί να προσθέσει ή να αφαιρέσει περιπτώσεις (instances).

## Πρόσβαση μέσω ευρετηρίου: `indexed-repeat()`

Πρόσβαση στην τιμή ενός πεδίου μιας συγκεκριμένης περίπτωσης επανάληψης από **έξω** από την ομάδα επανάληψης χρησιμοποιώντας την συνάρτηση `indexed-repeat(repeatedField, repeatGroup, index)`:

| type | name | label | calculation |
|------|------|-------|-------------|
| calculate | first_name | | `indexed-repeat(${member_name}, ${household_members}, 1)` |
| calculate | second_name | | `indexed-repeat(${member_name}, ${household_members}, 2)` |

Αυτό είναι χρήσιμο για τη δημιουργία πεδίων σύνοψης ή την αναφορά στα δεδομένα του "πρωτεύοντος" μέλους μετά την ολοκλήρωση της επανάληψης.

---

## Θέση τρέχουσας περίπτωσης: `index()`

Μέσα σε μια ομάδα επανάληψης, η συνάρτηση `index()` επιστρέφει τη θέση της τρέχουσας περίπτωσης (με βάση το 1). Χρησιμοποιήστε την για να επισημάνετε κάθε επανάληψη ή να δημιουργήσετε μοναδικά αναγνωριστικά:

| type | name | label |
|------|------|-------|
| begin_repeat | plots | Αγροτεμάχιο |
| note | plot_label | Αριθμός αγροτεμαχίου `${index()}` |
| text | plot_id | ID αγροτεμαχίου |
| end_repeat | | |

## Αναφορά σε πεδία στην ίδια περίπτωση

Μέσα σε μια επανάληψη, χρησιμοποιήστε το `${fieldname}` για να αναφερθείτε σε ένα άλλο πεδίο **στην ίδια περίπτωση επανάληψης**. Δεν χρειάζεται η χρήση της `indexed-repeat()` μέσα στον ίδιο βρόχο:

| type | name | label | relevant |
|------|------|-------|----------|
| begin_repeat | members | Μέλος | |
| text | member_name | Όνομα | |
| integer | member_age | Ηλικία | |
| text | school_name | Όνομα σχολείου | `${member_age} < 18` |
| end_repeat | | | |

---

## Αναφορά σε πεδία-γονείς μέσα από μια επανάληψη

Πεδία που βρίσκονται έξω (πάνω) από την ομάδα επανάληψης μπορούν να αναφερθούν κανονικά με το `${fieldname}`:

| type | name | label |
|------|------|-------|
| text | village | Όνομα χωριού |
| begin_repeat | plots | Αγροτικό τεμάχιο |
| note | plot_context | Αγροτεμάχια στο χωριό `${village}` |
| end_repeat | | |

## Σύνοψη δεδομένων επανάληψης

Χρησιμοποιήστε συναρτήσεις συγκέντρωσης επαναλήψεων (repeat aggregate functions) **έξω** από την ομάδα επανάληψης για σύνοψη:

| Function | Example | Description |
|----------|---------|-------------|
| `count(group)` | `count(${household_members})` | Αριθμός περιπτώσεων |
| `sum(field)` | `sum(${loan_amount})` | Άθροισμα αριθμητικού πεδίου |
| `min(field)` | `min(${member_age})` | Ελάχιστη τιμή |
| `max(field)` | `max(${member_age})` | Μέγιστη τιμή |
| `join(sep, field)` | `join(', ', ${member_name})` | Λίστα διαχωρισμένη με κόμμα |
| `count-if(group, expr)` | `count-if(${members}, ${member_age} < 18)` | Καταμέτρηση υπό συνθήκη |
| `sum-if(field, expr)` | `sum-if(${loan_amount}, ${loan_amount} > 500)` | Άθροισμα υπό συνθήκη |
| `join-if(sep, field, expr)` | `join-if(', ', ${name}, ${age} >= 18)` | Συνένωση υπό συνθήκη |

### Παράδειγμα: Σύνοψη νοικοκυριού

| type | name | label | calculation |
|------|------|-------|-------------|
| integer | num_members | Πόσα μέλη; | |
| begin_repeat | members | Μέλος | `${num_members}` |
| text | member_name | Όνομα | |
| integer | member_age | Ηλικία | |
| end_repeat | | | |
| calculate | total_members | | `count(${members})` |
| calculate | children_count | | `count-if(${members}, ${member_age} < 18)` |
| calculate | adult_names | | `join-if(', ', ${member_name}, ${member_age} >= 18)` |
| note | summary | `${total_members}` μέλη, `${children_count}` κάτω των 18. Ενήλικες: `${adult_names}` | |

## Ένθετες επαναλήψεις

Μια ομάδα επανάληψης μπορεί να περιέχει μια άλλη ομάδα επανάληψης. Χρησιμοποιήστε το προσεκτικά — οι ένθετες επαναλήψεις προσθέτουν πολυπλοκότητα και μπορεί να είναι μπερδεμένες για τους ερευνητές.

| type | name | label |
|------|------|-------|
| begin_repeat | households | Νοικοκυριό |
| text | hh_id | ID νοικοκυριού |
| begin_repeat | hh_members | Μέλος |
| text | member_name | Όνομα μέλους |
| end_repeat | | |
| end_repeat | | |

Για να αναφερθείτε σε ένα πεδίο μιας εξωτερικής επανάληψης από την εσωτερική επανάληψη, χρησιμοποιήστε το `${fieldname}` — επιλύεται στον πλησιέστερο αντίστοιχο πρόγονο:

Μέσα στην επανάληψη `hh_members`, το `${hh_id}` επιστρέφει το ID του **τρέχοντος** νοικοκυριού, όχι όλων των νοικοκυριών.

## Κατάταξη μέσα σε ομάδες επαναλήψεων: `rank-index()`

Όταν υπάρχει ένα πεδίο `rank` μέσα σε μια επανάληψη, χρησιμοποιήστε την `rank-index(instanceNumber, repeatedField)` από έξω για να λάβετε την τακτική κατάταξη μιας συγκεκριμένης περίπτωσης:

| type | name | label | calculation |
|------|------|-------|-------------|
| calculate | top_scorer | | `rank-index(1, ${score})` |

Η `rank-index(1, ${score})` επιστρέφει το ευρετήριο περίπτωσης (instance index) με την υψηλότερη βαθμολογία.

## Εμφάνιση `1screen` στο `begin_repeat`

Η προσθήκη του `1screen` στη στήλη `appearance` μιας γραμμής `begin_repeat` εμφανίζει όλες τις ερωτήσεις για κάθε περίπτωση μαζί σε μία οθόνη, αντί για μία ερώτηση ανά οθόνη.

| type | name | label | appearance |
|------|------|-------|------------|
| begin_repeat | household_members | Μέλος νοικοκυριού | `1screen` |
| text | member_name | Όνομα μέλους | |
| integer | member_age | Ηλικία | |
| end_repeat | | | |

Όταν έχει οριστεί το `1screen` και δεν υπάρχει `repeat_count` ούτε πεδίο `add_repeat` μέσα στην ομάδα, το rtSurvey εμφανίζει αυτόματα ένα κυκλικό κουμπί **+** στο κάτω μέρος της οθόνης, ώστε οι ερευνητές να μπορούν να προσθέτουν νέες περιπτώσεις χωρίς επιπλέον ρύθμιση.

| Appearance | Μία οθόνη ανά περίπτωση | Προσθήκη προεπιλεγμένου κουμπιού + |
|------------|-------------------------|------------------------|
| `1screen` | Ναι | Ναι (όταν δεν υπάρχει πεδίο-παιδί `add_repeat`) |
| `field-list` | Ναι | Όχι |

Χρησιμοποιήστε το `field-list` όταν θέλετε την ομαδοποιημένη διάταξη χωρίς το αυτόματο κουμπί προσθήκης. Χρησιμοποιήστε το `1screen` όταν θέλετε τόσο την ομαδοποιημένη διάταξη όσο και έναν ενσωματωμένο τρόπο προσθήκης περιπτώσεων.

## Προσαρμοσμένο κουμπί προσθήκης `add_repeat`

Ένα πεδίο `note` (ή `text`) που τοποθετείται **μέσα** στην ομάδα επανάληψης με `appearance: add_repeat` εμφανίζεται ως κουμπί "Προσθήκη" πλήρους πλάτους. Η ετικέτα του κουμπιού προέρχεται από τη στήλη `label` του πεδίου. Όταν υπάρχει ένα πεδίο `add_repeat`, το προεπιλεγμένο κυκλικό κουμπί + (από το `1screen`) καταργείται.

Τοποθετήστε το πεδίο `add_repeat` ως το τελευταίο πεδίο μέσα στην ομάδα επανάληψης:

| type | name | label | appearance |
|------|------|-------|------------|
| begin_repeat | members | Μέλος | `1screen` |
| text | member_name | Όνομα μέλους | |
| integer | member_age | Ηλικία | |
| note | btn_add | + Προσθήκη μέλους | `add_repeat` |
| end_repeat | | | |

### Προσαρμογή χρώματος

Περάστε έναν κωδικό χρώματος μέσα στην τιμή εμφάνισης (appearance) για να μορφοποιήσετε το κουμπί:

| Appearance value | Result |
|------------------|--------|
| `add_repeat <#04B404/>` | Πράσινο φόντο, προεπιλεγμένο χρώμα κειμένου |
| `add_repeat 04B404-ffffff` | Πράσινο φόντο, λευκό κείμενο |

Το πρώτο χρώμα είναι το φόντο και το δεύτερο (μετά την παύλα) είναι το χρώμα του κειμένου. Παραλείψτε το `#` όταν χρησιμοποιείτε τη μορφή με παύλα.

### Παραλλαγή εικονιδίου

Χρησιμοποιήστε το `add_repeat icon` (με κενό) για να εμφανίσετε ένα συμπαγές κυκλικό κουμπί εικονιδίου αντί για το κουμπί πλήρους πλάτους:

| type | name | label | appearance |
|------|------|-------|------------|
| note | btn_add | + Προσθήκη | `add_repeat icon` |

## Κουμπιά διαγραφής: `delete-repeat-current` και `delete-repeat-last`

Ένα πεδίο `note` μέσα στην ομάδα επανάληψης με `appearance: delete-repeat-current` ή `appearance: delete-repeat-last` εμφανίζεται ως διαιρεμένο κουμπί διαγραφής.

| Appearance | Action |
|------------|--------|
| `delete-repeat-current` | Διαγράφει την τρέχουσα (ενεργή) περίπτωση |
| `delete-repeat-last` | Διαγράφει την τελευταία περίπτωση στην επανάληψη |

Το προεπιλεγμένο κουμπί (χωρίς εικονίδιο) είναι ένα διαιρεμένο κουμπί: ένα εικονίδιο κάδου απορριμμάτων στα αριστερά και το κείμενο ετικέτας του πεδίου στα δεξιά, καλύπτοντας το πλήρες πλάτος της οθόης.

### Παραλλαγή εικονιδίου

Προσθέστε το `-icon` για να λάβετε ένα συμπαγές κυκλικό κουμπί εικονιδίου κάδου απορριμμάτων:

| Appearance | Result |
|------------|--------|
| `delete-repeat-current-icon` | Κυκλικό εικονίδιο κάδου, διαγράφει την τρέχουσα περίπτωση |
| `delete-repeat-last-icon` | Κυκλικό εικονίδιο κάδου, διαγράφει την τελευταία περίπτωση |

### Προσαρμογή χρώματος

Η μορφή χρώματος είναι ίδια με το `add_repeat`: χρησιμοποιήστε `<#RRGGBB/>` ή `RRGGBB-RRGGBB` (φόντο-κείμενο).

### Παράδειγμα πλήρους μοτίβου

Η ακόλουθη επανάληψη χρησιμοποιεί το `1screen`, ένα κυκλικό κουμπί διαγραφής τρέχουσας περίπτωσης στο επάνω μέρος και ένα κουμπί προσθήκης πλήρους πλάτους στο κάτω μέρος:

| type | name | label | appearance |
|------|------|-------|------------|
| begin_repeat | members | Μέλος | `1screen` |
| note | btn_del | Αφαίρεση | `delete-repeat-current-icon` |
| text | member_name | Όνομα μέλους | |
| integer | member_age | Ηλικία | |
| note | btn_add | + Προσθήκη μέλους | `add_repeat` |
| end_repeat | | | |

## Βέλτιστες Πρακτικές

1. Χρησιμοποιείτε πάντα το `repeat_count` όταν ο αριθμός των επαναλήψεων είναι γνωστός εκ των προτέρων — αυτό εμποδίζει τους ερευνητές να προσθέσουν ή να αφαιρέσουν κατά λάθος περιπτώσεις.
2. Διατηρείτε τις ομάδες επαναλήψεων εστιασμένες — μια επανάληψη με περισσότερες από 20 ερωτήσεις ανά περίπτωση είναι δύσκολη στην πλοήγηση.
3. Ονομάζετε τις ομάδες επαναλήψεων με σαφήνεια (π.χ. `household_members`, όχι `repeat1`) — το όνομα εμφανίζεται στις κλήσεις συναρτήσεων και στα εξαγόμενα δεδομένα.
4. Δοκιμάστε με τον μέγιστο αναμενόμενο αριθμό περιπτώσεων για να επαληθεύσετε την απόδοση.
5. Χρησιμοποιήστε το `1screen` στο `begin_repeat` για να εμφανίσετε όλες τις ερωτήσεις σε μία οθόνη ανά περίπτωση, σε συνδυασμό με ένα πεδίο σημείωσης `add_repeat` μέσα στην ομάδα για να δώσετε στους ερευνητές ένα σαφώς επισημασμένο κουμπί "Προσθήκη".

## Περιορισμοί

- Η `indexed-repeat()` απαιτεί έγκυρο ευρετήριο (1 έως τον αριθμό των περιπτώσεων) — ευρετήρια εκτός ορίων επιστρέφουν κενή τιμή.
- Οι ένθετες επαναλήψεις πέραν των 2 επιπέδων δεν συνιστώνται και ενδέχεται να προκαλέσουν προβλήματα εμφάνισης σε ορισμένους πελάτες.
- Οι συναρτήσεις συγκέντρωσης (`sum`, `count` κ.λπ.) λειτουργούν σε ολόκληρη την ομάδα επανάληψης — δεν μπορείτε να συγκεντρώσετε ένα υποσύνολο περιπτώσεων χωρίς τις παραλλαγές `*-if`.

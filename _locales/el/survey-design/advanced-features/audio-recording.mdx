Η ηχογράφηση επιτρέπει σε μια φόρμα να καταγράφει αθόρυβα ή ορατά ήχο κατά τη διάρκεια ενός τμήματος μιας έρευνας. Είναι χρήσιμη για την ηχογράφηση συνεντεύξεων, ήχου περιβάλλοντος κατά τη διάρκεια παρατηρήσεων πεδίου ή προφορικών απαντήσεων που συμπληρώνουν δομημένες απαντήσεις.

Πάντα να δοκιμάζετε στη συσκευή όταν απαιτείται ηχογράφηση.

## Πώς λειτουργεί

Η ηχογράφηση ελέγχεται από δύο πεδία `text` που λειτουργούν ως **δείκτες**:

- Ένα πεδίο με εμφάνιση `audio-start` ξεκινά την ηχογράφηση όταν ο ερευνητής φτάσει σε αυτό.
- Ένα πεδίο με εμφάνιση `audio-end` σταματά την ηχογράφηση και αποθηκεύει το αρχείο ήχου στην υποβολή.

Και τα δύο πεδία δείκτη είναι τύπου `text`. Συνήθως είναι κρυμμένα από τον ερευνητή (χρησιμοποιώντας `relevant = false` ή τοποθετημένα σε μη διαδραστική θέση), αν και μπορούν να είναι ορατά. Ο ηχογραφημένος ήχος επισυνάπτεται στην υποβολή ως αρχείο συνδεδεμένο με το πεδίο `audio-end`.

## Βασικό παράδειγμα

| type | name | label | appearance |
|------|------|-------|------------|
| text | audio_s_a1 | | `audio-start` |
| text | q_name | Όνομα ερωτώμενου | |
| text | q_occupation | Επάγγελμα | |
| integer | q_age | Ηλικία | |
| text | audio_e_a1 | | `audio-end` |

Η εφαρμογή ξεκινά την ηχογράφηση όταν ο ερευνητής φτάσει στο `audio_s_a1` και σταματά όταν φτάσει στο `audio_e_a1`. Όλες οι ερωτήσεις μεταξύ των δύο δεικτών ηχογραφούνται.

---

## Αθόρυβη ηχογράφηση: `audio-start invisible`

Από προεπιλογή, η εφαρμογή για κινητά εμφανίζει μια ένδειξη ηχογράφησης ενώ καταγράφεται ήχος. Προσθέτοντας το `invisible` στην εμφάνιση, η ένδειξη αυτή καταστέλλεται, έτσι η ηχογράφηση γίνεται χωρίς καμία ορατή ένδειξη στον ερωτώμενο.

| type | name | label | appearance |
|------|------|-------|------------|
| text | audio_s_a1 | | `audio-start invisible` |
| text | q_consent | Συμφωνείτε να συμμετάσχετε; | |
| text | q_feedback | Τα σχόλιά σας | |
| text | audio_e_a1 | | `audio-end` |

Χρησιμοποιήστε το `invisible` μόνο όταν οι απαιτήσεις γνωστοποίησης έχουν ικανοποιηθεί με άλλα μέσα (π.χ., ένα ξεχωριστό πεδίο γραπτής συγκατάθεσης πριν από το τμήμα ηχογράφησης).

## Σύμβαση ονοματολογίας

Οι φόρμες παραγωγής χρησιμοποιούν ένα σταθερό μοτίβο ονομασίας για τα πεδία δείκτη:

```
audio_s_{section}{n}   — δείκτης έναρξης
audio_e_{section}{n}   — δείκτης λήξης
```

Όπου `{section}` είναι μια σύντομη ετικέτα για το τμήμα της φόρμας και `{n}` είναι ένας διαδοχικός αριθμός μέσα σε αυτό το τμήμα.

| Όνομα πεδίου | Ρόλος | Σημασία |
|------------|------|---------|
| `audio_s_a1` | Έναρξη | Πρώτη ηχογράφηση στο τμήμα Α |
| `audio_e_a1` | Λήξη | Τέλος πρώτης ηχογράφησης στο τμήμα Α |
| `audio_s_b1` | Έναρξη | Πρώτη ηχογράφηση στο τμήμα Β |
| `audio_e_b1` | Λήξη | Τέλος πρώτης ηχογράφησης στο τμήμα Β |
| `audio_s_a2` | Έναρξη | Δεύτερη ηχογράφηση στο τμήμα Α |
| `audio_e_a2` | Λήξη | Τέλος δεύτερης ηχογράφησης στο τμήμα Α |

Η τήρηση αυτής της σύμβασης διευκολύνει τον εντοπισμό των ορίων ηχογράφησης κατά την εξέταση των ορισμών της φόρμας και των δεδομένων υποβολής.

## Αποθήκευση και ανάκτηση

Όταν ο ερευνητής φτάσει στο πεδίο `audio-end`, η εφαρμογή οριστικοποιεί το αρχείο ήχου και το επισυνάπτει στην υποβολή. Το αρχείο:

- Αποθηκεύεται ως συνημμένο ήχου στην υποβολή, συνδεδεμένο με το όνομα του πεδίου `audio-end`.
- Είναι προσβάσιμο στο πρόγραμμα προβολής υποβολών του rtSurvey back-end μαζί με άλλα συνημμένα πολυμέσων.
- Είναι δυνατή η λήψη του μέσω της τυπικής εξαγωγής υποβολών — τα αρχεία ήχου εμφανίζονται στη στήλη πολυμέσων που αντιστοιχεί στο όνομα του πεδίου `audio-end`.

Η μορφή αρχείου και ο ρυθμός bit (bitrate) εξαρτώνται από τη συσκευή και την έκδοση της εφαρμογής.

## Πολλαπλά τμήματα ηχογράφησης

Μια φόρμα μπορεί να περιέχει αρκετά μη επικαλυπτόμενα τμήματα ηχογράφησης. Κάθε ζεύγος δεικτών `audio-start` / `audio-end` πρέπει να περιέχεται πλήρως — τα τμήματα δεν πρέπει να παρεμβάλλονται μεταξύ τους.

| type | name | label | appearance |
|------|------|-------|------------|
| text | audio_s_a1 | | `audio-start` |
| text | q_intro | Εισαγωγή | |
| text | audio_e_a1 | | `audio-end` |
| note | section_break | — | |
| text | audio_s_b1 | | `audio-start invisible` |
| text | q_detail | Λεπτομέρειες | |
| text | audio_e_b1 | | `audio-end` |

Κάθε τμήμα παράγει ένα ξεχωριστό αρχείο ήχου που επισυνάπτεται στο αντίστοιχο πεδίο `audio-end`.

---

## Περιορισμοί

- **Μόνο για την εφαρμογή για κινητά.** Η λειτουργία δεν υποστηρίζεται στη διαδικτυακή φόρμα. Τα `audio-start` και `audio-end` αγνοούνται σιωπηλά σε ένα πρόγραμμα περιήγησης.
- **Όχι εμφώλευση.** Τα τμήματα ηχογράφησης δεν μπορούν να επικαλύπτονται. Η έναρξη μιας νέας ηχογράφησης πριν φτάσετε στον προηγούμενο δείκτη `audio-end` δεν υποστηρίζεται.
- **Ο τύπος πεδίου πρέπει να είναι `text`.** Η χρήση των `audio-start` ή `audio-end` σε οποιονδήποτε άλλο τύπο ερώτησης δεν υποστηρίζεται.
- **Μέγεθος μεταφόρτωσης.** Οι μεγάλες ηχογραφήσεις παράγουν μεγάλα αρχεία. Λάβετε υπόψη τα όρια μεγέθους υποβολής και τις συνθήκες δικτύου στο πεδίο.
- **Όχι παύση κατά την ηχογράφηση.** Η ηχογράφηση εκτελείται συνεχώς από τον δείκτη έναρξης έως τον δείκτη λήξης. Δεν υπάρχει μηχανισμός παύσης και επανέναρξης μέσα σε ένα τμήμα.

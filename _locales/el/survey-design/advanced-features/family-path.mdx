import { Callout } from 'nextra/components'

Το `family_path` είναι ένα πεδίο υπολογισμού (calculate) που περιέχει τη διαδρομή προς τον ενσωματωμένο κατάλογο πολυμέσων της φόρμας. Κάθε φόρμα που εκτελεί τοπικές αναζητήσεις στη βάση δεδομένων με `rawquery`, `pulldata` ή `search()` πρέπει να περιλαμβάνει αυτό το πεδίο — χωρίς αυτό, οι διαδρομές αρχείων δεν μπορούν να επιλυθούν και οι αναζητήσεις επιστρέφουν σιωπηλά κενά αποτελέσματα.

---

## Το πεδίο calculate

Προσθέστε αυτή τη σειρά κοντά στην κορυφή του φύλλου survey, μετά από τυχόν πεδία μεταδεδομένων (meta) και πριν από την πρώτη ερώτηση που χρησιμοποιεί αρχείο βάσης δεδομένων:

| type | name | label | calculation |
|---|---|---|---|
| calculate | `family_path` | | `pulldata('app-api', 'family_path')` |

Το πεδίο δεν αποθηκεύει καμία ορατή τιμή και δεν απαιτεί ετικέτα (label). Είναι μια σιωπηρή προϋπόθεση για όλη την κατασκευή διαδρομών που ακολουθεί.

---

## Γιατί είναι απαραίτητο

Το RTSurvey συγκεντρώνει τα πολυμέσα της φόρμας — βάσεις δεδομένων SQLite, εικόνες, ηχητικά κλιπ — μέσα σε έναν κατάλογο ανά φόρμα στη συσκευή. Η ακριβής διαδρομή διαφέρει μεταξύ των πλατφορμών (Android, iOS, web) και μεταξύ των συσκευών.

Κατά το χρόνο εκτέλεσης, η εφαρμογή συμπληρώνει αυτόματα το `family_path`. Μια τυπική επιλυμένη τιμή μοιάζει με:

```
resources/familyMedia/Phuong_Person_Test
```

Επειδή η διαδρομή εξαρτάται από την πλατφόρμα και καθορίζεται κατά την έναρξη, δεν μπορεί να κωδικοποιηθεί σταθερά στη φόρμα. Το `pulldata('app-api', 'family_path')` είναι ο μόνος αξιόπιστος τρόπος για την ανάκτησή της.

---

## Πώς να το χρησιμοποιήσετε σε διαδρομές

Μόλις οριστεί το `family_path`, δημιουργήστε μια πλήρη διαδρομή αρχείου με το `concat()`:

```
concat(${family_path}, '/file.db::tableName')
```

Το επίθεμα `::tableName` αφαιρείται όταν η εφαρμογή ανοίγει το αρχείο. Το όνομα του πίνακα χρησιμοποιείται μόνο μέσα στο ερώτημά σας SQL.

---

## Πού χρησιμοποιείται το family_path

Το `family_path` απαιτείται στο όρισμα διαδρομής κάθε φορά που αναφέρεστε σε ένα ενσωματωμένο αρχείο:

- **Τοπική αναζήτηση βάσης δεδομένων** — το όρισμα `db_path` του `search-autocomplete-noedit-v2('rawquery', ...)` πρέπει να κατασκευαστεί με το `concat(${family_path}, ...)`. Δείτε την [Τοπική αναζήτηση βάσης δεδομένων](local-database-search) για πλήρεις λεπτομέρειες χρήσης.
- **`pulldata` rawquery** — οποιαδήποτε κλήση `pulldata('rawquery', ...)` που διαβάζει από ένα αρχείο `.db` χρησιμοποιεί το ίδιο μοτίβο `concat()`.
- **`search()` με τοπικό αρχείο** — οι εμφανίσεις (appearances) δυναμικής αναζήτησης που φορτώνονται από ένα ενσωματωμένο αρχείο CSV ή DB βασίζονται επίσης στο `family_path` για την αναφορά αρχείου.

---

## Τοποθέτηση στη φόρμα

Το `family_path` πρέπει να εμφανίζεται **πριν από το πρώτο πεδίο που αναφέρεται σε αυτό**. Η συνιστώμενη θέση είναι αμέσως μετά την ομάδα μεταδεδομένων (meta):

| type | name | label | calculation |
|---|---|---|---|
| begin_group | meta | | |
| deviceid | deviceid | | |
| start | start | | |
| end | end | | |
| end_group | | | |
| calculate | `family_path` | | `pulldata('app-api', 'family_path')` |
| select_one | province | Province | *(εμφάνιση rawquery που αναφέρεται στο `${family_path}`)* |

<Callout type="warning">
Εάν το `family_path` λείπει από τη φόρμα ή έχει τοποθετηθεί μετά το πρώτο πεδίο `rawquery` / `search()` που αναφέρεται σε αυτό, όλες οι αναζητήσεις σε ενσωματωμένα αρχεία θα επιστρέφουν σιωπηλά κενά αποτελέσματα. Δεν υπάρχει μήνυμα σφάλματος — η αυτόματη συμπλήρωση απλώς δεν εμφανίζει αποτελέσματα.
</Callout>

---

## Πολλαπλά αρχεία βάσης δεδομένων

Μια μεμονωμένη φόρμα μπορεί να χρησιμοποιήσει αρκετά αρχεία `.db`. Κάθε διαδρομή κατασκευάζεται ανεξάρτητα με το `concat()`:

```
concat(${family_path}, '/locations.db::externalData')
concat(${family_path}, '/health_facilities.db::facilities')
concat(${family_path}, '/household_list.db::households')
```

Ορίστε το `family_path` μία φορά. Αναφέρετέ το σε όσα πεδία χρειάζεται.

---

## Επαλήθευση κατά την ανάπτυξη

Προσθέστε ένα προσωρινό πεδίο `note` κάτω από το `family_path` για να ελέγξετε την επιλυμένη τιμή στη συσκευή:

| type | name | label | calculation |
|---|---|---|---|
| calculate | `family_path` | | `pulldata('app-api', 'family_path')` |
| note | family_path_check | `Διαδρομή: ${family_path}` | |

Η σημείωση θα εμφανίσει την πραγματική επιλυμένη διαδρομή κατά τη διάρκεια της δοκιμής. Αφαιρέστε την πριν από την ανάπτυξη της τελικής φόρμας.

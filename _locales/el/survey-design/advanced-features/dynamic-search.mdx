---

Η **Δυναμική Αναζήτηση** (ονομάζεται επίσης Search API) επιτρέπει σε ένα πεδίο `select_one`, `select_multiple` ή `text` να φορτώνει τις επιλογές του από μια απομακρυσμένη διαδικτυακή υπηρεσία **κατά το χρόνο εκτέλεσης** καθώς ο απογραφέας πληκτρολογεί. Αυτή είναι η σωστή προσέγγιση όταν η λίστα επιλογών σας είναι πολύ μεγάλη για να συμπεριληφθεί σε ένα αρχείο CSV, ενημερώνεται συχνά ή προέρχεται από μια ζωντανή βάση δεδομένων.

---

## Εμφάνιση `search-api()`

Η δυναμική αναζήτηση ρυθμίζεται μέσω της στήλης `appearance` χρησιμοποιώντας τη συνάρτηση `search-api()`:

```
search-api(method, url, post_body, value_column, display, data_path, save_path)
```

### Παράμετροι

| Παράμετρος | Περιγραφή |
|-----------|-------------|
| `method` | Χρησιμοποιείτε πάντα `'POST'` |
| `url` | Το τελικό σημείο API για ερώτημα |
| `post_body` | Σώμα JSON που αποστέλλεται στο API. Χρησιμοποιήστε το `%__input__%` ως σύμβολο κράτησης θέσης για το τρέχον κείμενο αναζήτησης του απογραφέα |
| `value_column` | Το κλειδί στο αντικείμενο απόκρισης που θα χρησιμοποιηθεί ως η αποθηκευμένη **τιμή** (value) |
| `display` | Το κλειδί (ή πρότυπο) που θα χρησιμοποιηθεί ως η **ετικέτα** (label) που εμφανίζεται στο αναπτυσσόμενο μενού. Υποστηρίζει σύμβολα κράτησης θέσης `##key##` και εκφράσεις `@{func}` |
| `data_path` | JSONPath προς τον πίνακα αντικειμένων αποτελεσμάτων στην απόκριση (π.χ., `$.data`, `$.hits.hits.*._source`) |
| `save_path` | Ένα όνομα υπό το οποίο αποθηκεύεται η ακατέργαστη απόκριση για χρήση από άλλα πεδία |

## Βασικό παράδειγμα

Μια αναζήτηση υγειονομικής μονάδας όπου ο απογραφέας πληκτρολογεί μέρος του ονόματος της μονάδας:

| type | name | label | appearance |
|------|------|-------|------------|
| select_one | facility | Επιλέξτε υγειονομική μονάδα | `search-api('POST', 'https://api.example.com/facilities/search', '{"query": "%__input__%"}', 'id', 'name', '$.results', 'facility_data')` |

Το API λαμβάνει `{"query": "nair"}` όταν ο απογραφέας πληκτρολογεί "nair" και επιστρέφει:

```json
{
  "results": [
    {"id": "HF001", "name": "Nairobi Central Clinic"},
    {"id": "HF002", "name": "Nairobi West Hospital"}
  ]
}
```

Το αναπτυσσόμενο μενού δείχνει `Nairobi Central Clinic` και `Nairobi West Hospital`. η αποθηκευμένη τιμή είναι `HF001` ή `HF002`.

## Προηγμένη μορφοποίηση εμφάνισης

### Χρήση προτύπων `##key##`

Εμφάνιση πολλαπλών πεδίων στην ετικέτα:

```
search-api('POST', 'https://api.example.com/search', '{"q": "%__input__%"}', 'id', '##name## (##district##)', '$.data', 'res')
```

Εμφανίζεται ως: `Nairobi Central Clinic (Nairobi)`.

### Χρήση εκφράσεων `@{func}`

Εφαρμογή λογικής υπό όρους στην ετικέτα εμφάνισης:

```
search-api('POST', 'https://api.example.com/search', '{"q": "%__input__%"}', 'id',
  '@{if_else(eq("##status##", "active"), "✓ ##name##", "✗ ##name##")}',
  '$.data', 'res')
```

Τα ενεργά αποτελέσματα δείχνουν `✓ Clinic Name`, τα ανενεργά δείχνουν `✗ Clinic Name`.

---

## Ορισμός προεπιλεγμένης τιμής: `search-default-api()`

Χρησιμοποιήστε το `search-default-api()` μετά το `search-api()` για να προ-συμπληρώσετε το πεδίο με μια προεπιλεγμένη επιλογή που φορτώνεται από μια ξεχωριστή κλήση API (π.χ. κατά την επεξεργασία μιας υπάρχουσας εγγραφής):

```
appearance: search-api(...) search-default-api('POST', 'https://api.example.com/get', '{"id": "##saved_id##"}', 'id', 'name', '$.item')
```

---

## Προσαρμοσμένο διαχωριστικό για select_multiple: `search-default-separator()`

Για πεδία `select_multiple`, καθορίστε πώς συνδέονται οι πολλαπλές επιλεγμένες τιμές στην αποθηκευμένη συμβολοσειρά:

```
appearance: search-api(...) search-default-separator(' || ')
```

Το προεπιλεγμένο διαχωριστικό είναι ένα κενό διάστημα.

---

## Υποστηριζόμενοι τύποι ερωτήσεων

| Τύπος ερώτησης | Περίπτωση χρήσης |
|---------------|----------|
| `select_one` | Μία επιλογή από τα αποτελέσματα αναζήτησης |
| `select_multiple` | Πολλαπλές επιλογές από τα αποτελέσματα αναζήτησης |
| `text` | Αυτόματη συμπλήρωση — ο απογραφέας πληκτρολογεί ελεύθερα αλλά μπορεί να επιλέξει μια πρόταση |

## Χρήση αποθηκευμένων δεδομένων απόκρισης

Όταν ο απογραφέας επιλέγει ένα αποτέλεσμα, το rtSurvey αποθηκεύει ολόκληρο το αντικείμενο που ταιριάζει από την απόκριση υπό το όνομα `save_path`. Άλλα πεδία μπορούν να διαβάσουν από αυτό με δύο τρόπους.

### Μέθοδος 1 — Αναζήτηση `pulldata()`

Χρησιμοποιήστε το `pulldata('save_path', 'key')` για να διαβάσετε ένα πεδίο ανώτερου επιπέδου από το αποθηκευμένο αντικείμενο:

| type | name | label | calculation |
|------|------|-------|-------------|
| select_one | facility | Επιλέξτε μονάδα | |
| calculate | facility_district | | `pulldata('facility_data', 'district')` |
| calculate | facility_type | | `pulldata('facility_data', 'type')` |
| calculate | facility_beds | | `pulldata('facility_data', 'beds')` |

Η εμφάνιση στη σειρά `select_one` πρέπει να περιλαμβάνει το `search-api(..., 'facility_data')` με το αντίστοιχο `save_path`.

Για **ένθετα πεδία JSON**, συνδυάστε με το `substr-jsonpath()`:

```
substr-jsonpath(pulldata('facility_data', 'location'), '$.district')
```

## Αναζήτηση τοπικού αρχείου με search()

Η `search()` εκτελεί αναζητήσεις εκτός σύνδεσης, βάσει ισότητας στηλών, σε ένα ενσωματωμένο αρχείο SQLite `.db` — δεν απαιτείται σύνδεση δικτύου ούτε ερωτήματα SQL. Χρησιμοποιήστε την όταν τα δεδομένα αναφοράς σας είναι συσκευασμένα με τη φόρμα και χρειάζεστε μια απλή αναζήτηση "βρείτε όλες τις σειρές όπου η στήλη ισούται με την τιμή".

### Υπογραφή

```
search(path, 'matches', 'list_name', ${field})
```

### Παράμετροι

| Παράμετρος | Περιγραφή |
|-----------|-------------|
| `path` | Διαδρομή προς τον πίνακα SQLite: `concat(${family_path}, '/file.db::table')` |
| `'matches'` | Τελεστής αντιστοίχισης — επιστρέφει σειρές όπου η στήλη ισούται με την τιμή |
| `'list_name'` | Όνομα στήλης για αντιστοίχιση |
| `${field}` | Τιμή προς αντιστοίχιση, συνήθως μια αναφορά πεδίου |

### Παράδειγμα

Συμπλήρωση ενός `select_one` από μια τοπική βάση δεδομένων αντιστοιχίζοντας την τιμή του `${d307}` με τη στήλη `list_name` στον πίνακα `externalData` του `d307.db`:

| type | name | label | appearance |
|------|------|-------|------------|
| select_one | facility | Επιλέξτε μονάδα | `search(concat(${family_path}, '/d307.db::externalData'), 'matches', 'list_name', ${d307})` |

Όταν το `${d307}` ισούται με `"HF001"`, η `search()` επιστρέφει κάθε σειρά στο `externalData` όπου `list_name = 'HF001'` — εξ ολοκλήρου από το ενσωματωμένο αρχείο, χωρίς κλήση δικτύου.

### search() έναντι αυτόματης συμπλήρωσης rawquery

| Χαρακτηριστικό | `search()` | Αυτόματη συμπλήρωση `rawquery` |
|---------|-----------|------------------------|
| Ερωτήματα SQL | Όχι — μόνο ισότητα στηλών | Ναι — πλήρες `SELECT … FROM …` |
| Παραμετροποιημένη είσοδος | Αντιστοίχιση τιμής στήλης | Ενσωματωμένη σε συμβολοσειρά SQL |
| Ελεύθερη εισαγωγή κειμένου | Ναι — ο απογραφέας μπορεί να πληκτρολογήσει ελεύθερα | Όχι — πρέπει να επιλέξει από λίστα |
| UNION / πολλαπλοί πίνακες | Δεν υποστηρίζεται | Υποστηρίζεται |

### Πότε να χρησιμοποιείτε το καθένα

- Χρησιμοποιήστε τη **`search()`** όταν χρειάζεστε μια απλή αντιστοίχιση ισότητας σε ένα ενσωματωμένο αρχείο `.db`, η φόρμα πρέπει να λειτουργεί εκτός σύνδεσης και θέλετε να επιτρέψετε την ελεύθερη εισαγωγή κειμένου.
- Χρησιμοποιήστε την **αυτόματη συμπλήρωση `rawquery`** όταν χρειάζεστε ευελιξία SQL (JOINs, UNIONs, υπολογιζόμενες στήλες) ή πρέπει να κάνετε ερωτήματα σε πολλούς πίνακες και η φόρμα έχει αξιόπιστη συνδεσιμότητα.

## Βέλτιστες Πρακτικές

1. Βεβαιωθείτε ότι το τελικό σημείο API αποκρίνεται εντός 1-2 δευτερολέπτων — τα αργά API κάνουν την αναζήτηση να φαίνεται μη ανταποκρίσιμη.
2. Χρησιμοποιήστε το `%__input__%` στο `post_body`, ώστε το API να επιστρέφει μόνο τα αποτελέσματα που ταιριάζουν και όχι ολόκληρο το σύνολο δεδομένων.
3. Δημιουργήστε ευρετήριο στο πεδίο αναζήτησης στην πλευρά του διακομιστή (π.χ. Elasticsearch, ευρετήριο πλήρους κειμένου βάσης δεδομένων) για γρήγορες αποκρίσεις.
4. Περιορίστε τα αποτελέσματα σε 20–50 στοιχεία ανά ερώτημα — η επιστροφή χιλιάδων αποτελεσμάτων ακυρώνει τον σκοπό της αναζήτησης.
5. Συμπεριλάβετε μια απαίτηση ελάχιστου μήκους εισόδου στο API για να αποφύγετε την ενεργοποίηση ευρειών ερωτημάτων σε εισαγωγές ενός χαρακτήρα.

## Περιορισμοί

- Η Δυναμική Αναζήτηση απαιτεί συνδεσιμότητα δικτύου — δεν λειτουργεί εκτός σύνδεσης.
- Το σύμβολο κράτησης θέσης `%__input__%` εισάγεται ως έχει. εξυγιάνετε τις εισόδους στην πλευρά του διακομιστή για να αποτρέψετε επιθέσεις injection.
- Οι σύνθετες εκφράσεις εμφάνισης `@{func}` ενδέχεται να έχουν περιορισμένη υποστήριξη σε όλες τις εκδόσεις πελατών rtSurvey.

Το rtSurvey αποδίδει το κείμενο **ετικέτας (label)** και **υπόδειξης (hint)** ως HTML σε φόρμες ιστού. Αυτό σημαίνει ότι μπορείτε να χρησιμοποιήσετε τυπικές ετικέτες HTML για να μορφοποιήσετε κείμενο, να προσθέσετε αλλαγές γραμμής, να δημιουργήσετε συνδέσμους και να εφαρμόσετε χρώματα. Αυτό είναι ιδιαίτερα χρήσιμο για πεδία σημειώσεων, οδηγίες ενοτήτων και δυναμικές συνόψεις.

<Callout type="warning">
Η HTML στις ετικέτες αποδίδεται στη **φόρμα ιστού** και στις εφαρμογές rtSurvey για κινητά. Ενδέχεται να μην αποδίδεται σε όλους τους πελάτες που είναι συμβατοί με ODK. Πάντα να κάνετε δοκιμή στην πλατφόρμα-στόχο σας.
</Callout>

## Υποστηριζόμενες ετικέτες HTML

### Μορφοποίηση κειμένου

| Ετικέτα | Αποτέλεσμα |
|-----|--------|
| `<strong>text</strong>` ή `<b>text</b>` | **Έντονο κείμενο** |
| `<em>text</em>` ή `<i>text</i>` | *Πλάγιο κείμενο* |
| `<u>text</u>` | Υπογραμμισμένο κείμενο |
| `<br>` | Αλλαγή γραμμής |
| `<span style="...">text</span>` | Εσωτερική μορφοποίηση |

### Σύνδεσμοι

```html
<a href="https://example.com" target="_blank">Click here</a>
```

Ανοίγει σε νέα καρτέλα. Χρησιμοποιήστε το για έγγραφα αναφοράς, οδηγίες ή εξωτερικούς πόρους που πρέπει να συμβουλευτεί ο ερευνητής.

### Χρώματα

Χρησιμοποιήστε `<span>` με εσωτερικά στυλ:

```html
<span style="color: red;">Warning: value is out of range</span>
<span style="color: #009688;">Section completed</span>
```

## Μεταβλητές χρωματικού θέματος

Το rtSurvey υποστηρίζει **διακριτικά χρωματικού θέματος** που προσαρμόζονται στο διαμορφωμένο θέμα της εφαρμογής. Χρησιμοποιήστε τη σύνταξη `__COLOR_THEME_NAME__`:

```html
<span style="color: var(--color-theme-primary);">Primary color text</span>
```

Ή χρησιμοποιώντας τη συντόμευση διακριτικού στο κείμενο της ετικέτας:

```
<font color="var(--COLOR_THEME_PRIMARY)">Important note</font>
```

Αυτό μετατρέπεται αυτόματα στο αντίστοιχο `<span>` με μια μεταβλητή CSS κατά το χρόνο απόδοσης.

## Ετικέτες πολλαπλών γλωσσών

Περιβάλετε το περιεχόμενο με ετικέτες γλώσσας για να υποστηρίξετε πολλές γλώσσες σε ένα μόνο κελί ετικέτας:

```
<en>Enter the household size</en><vi>Nhập quy mô hộ gia đình</vi>
```

Το rtSurvey εξάγει το περιεχόμενο που αντιστοιχεί στην τρέχουσα γλώσσα της εφαρμογής. Εάν δεν βρεθεί αντίστοιχη ετικέτα γλώσσας, ολόκληρη η συμβολοσειρά εμφανίζεται ως έχει.

## Παραδείγματα σε πεδία σημειώσεων

### Οδηγία ενότητας με έντονη γραφή και αλλαγή γραμμής

| type | name | label |
|------|------|-------|
| note | section_intro | `<strong>Section 3: Land Use</strong><br>Ask all questions in this section to the household head only.` |

### Δυναμική σύνοψη με αναφορά υπολογισμού

| type | name | label |
|------|------|-------|
| calculate | total | | `${adults} + ${children}` |
| note | summary | `Total household members: <strong>${total}</strong><br><span style="color: gray;">Adults: ${adults} · Children: ${children}</span>` |

### Προειδοποίηση με κόκκινο χρώμα

| type | name | label | relevant |
|------|------|-------|----------|
| note | age_warning | `<span style="color: red;"><strong>Warning:</strong> Age entered (${age}) is unusually high. Please verify.</span>` | `${age} > 100` |

### Σύνδεσμος σε έγγραφο αναφοράς

| type | name | label |
|------|------|-------|
| note | guidelines_link | `Refer to the <a href="https://docs.example.com/guidelines" target="_blank">Field Guidelines</a> before starting this section.` |

## Ειδικές ετικέτες HTML του rtSurvey

### `<webbox src='url' title='title'>...</webbox>`

Ενσωματώνει ένα κουμπί που ανοίγει ένα URL σε ένα αναδυόμενο παράθυρο εντός της φόρμας. Δείτε το [Webbox](webbox) για πλήρεις λεπτομέρειες.

### `<delete-repeat-current>label</delete-repeat-current>`

Αποδίδει ένα κουμπί μέσα σε μια ομάδα επανάληψης που διαγράφει την τρέχουσα εμφάνιση επανάληψης όταν πατηθεί.

### `<delete-repeat-last>label</delete-repeat-last>`

Αποδίδει ένα κουμπί που διαγράφει την τελευταία εμφάνιση επανάληψης.

Παράδειγμα χρήσης σε ομάδα επανάληψης:

| type | name | label |
|------|------|-------|
| note | delete_btn | `<delete-repeat-current>Remove this member</delete-repeat-current>` |

## Δυναμικές συνόψεις HTML με το autopull()

Το `autopull()` αποδίδει ένα μπλοκ HTML μέσα σε ένα πεδίο `note` και **το επαναξιολογεί σε κάθε αλλαγή πεδίου** στη φόρμα. Αυτό το καθιστά κατάλληλο για ζωντανά πάνελ σύνοψης, οθόνες ελέγχου πριν την υποβολή και τρέχοντα σύνολα που ενημερώνονται καθώς ο ερευνητής συμπληρώνει δεδομένα.

<Callout type="info">
Το `autopull()` λειτουργεί μόνο σε πεδία **σημειώσεων (note)**. Η στήλη ετικέτας (label) αγνοείται — όλο το περιεχόμενο HTML πρέπει να παρέχεται μέσω της στήλης **εμφάνισης (appearance)** χρησιμοποιώντας το `concat()`.
</Callout>

### Σύνταξη

Τοποθετήστε το `autopull()` στη στήλη **εμφάνισης (appearance)** ενός πεδίου `note`:

```
autopull(concat('<html>...</html>'))
```

Οι αναφορές πεδίων (`${field_name}`) μέσα στο `concat()` αντικαθίστανται από τις τρέχουσες ζωντανές τιμές και η HTML επαναποδίδεται σε κάθε αλλαγή.

### Περιορισμός ύψους με το scroll-view()

Για μεγαλύτερες συνόψεις, συνδυάστε το `autopull()` με το `scroll-view(N%)` για να περιορίσετε το ύψος του πάνελ και να το κάνετε με δυνατότητα κύλισης:

```
scroll-view(45%) autopull(concat('<html>...</html>'))
```

Η τιμή `N%` είναι σχετική με την ορατή περιοχή της φόρμας. Το `45%` είναι μια πρακτική προεπιλογή για ένα πάνελ σύνοψης στη μέση της σελίδας.

### Πλήρες παράδειγμα — σύνοψη τοποθεσίας νοικοκυριού

Το ακόλουθο πεδίο `note` αποδίδει έναν πίνακα δύο στηλών που δείχνει την επιλεγμένη επαρχία, περιοχή και κοινότητα. Ενημερώνεται αυτόματα κάθε φορά που αλλάζει το `${tinh_name}`, το `${huyen_name}` ή το `${xa_name}`.

| type | name | label | appearance |
|------|------|-------|------------|
| note | location_summary | | `scroll-view(45%) autopull(concat('<html><table style="width:100%;border-collapse:collapse"><tr><td style="padding:4px;font-weight:bold">Province:</td><td style="padding:4px">', ${tinh_name}, '</td></tr><tr><td style="padding:4px;font-weight:bold">District:</td><td style="padding:4px">', ${huyen_name}, '</td></tr><tr><td style="padding:4px;font-weight:bold">Commune:</td><td style="padding:4px">', ${xa_name}, '</td></tr></table></html>'))` |

Στο XLSForm η τιμή εμφάνισης γράφεται σε ένα μόνο κελί:

```
scroll-view(45%) autopull(concat(
  '<html><table style="width:100%;border-collapse:collapse">
   <tr><td style="padding:4px;font-weight:bold">Province:</td>
       <td style="padding:4px">', ${tinh_name}, '</td></tr>
   <tr><td style="padding:4px;font-weight:bold">District:</td>
       <td style="padding:4px">', ${huyen_name}, '</td></tr>
   <tr><td style="padding:4px;font-weight:bold">Commune:</td>
       <td style="padding:4px">', ${xa_name}, '</td></tr>
   </table></html>'))
```

### Εσωτερικά στυλ

Τα εσωτερικά χαρακτηριστικά `style="..."` σε οποιοδήποτε στοιχείο HTML υποστηρίζονται και είναι ο συνιστώμενος τρόπος εφαρμογής οπτικής μορφοποίησης μέσα σε μπλοκ `autopull()`.

Τα παρακάτω **δεν** υποστηρίζονται μέσα στο περιεχόμενο του `autopull()`:

- Μπλοκ `<style>`
- Εξωτερικές ετικέτες `<link>` φύλλων στυλ
- JavaScript (`<script>`)

### Πότε να χρησιμοποιείτε το autopull()

| Περίπτωση χρήσης | Σημειώσεις |
|----------|-------|
| Οθόνη ελέγχου πριν την υποβολή | Εμφάνιση όλων των βασικών απαντήσεων σε ένα πάνελ πριν τελειώσει ο ερευνητής |
| Τρέχοντα σύνολα | Εμφάνιση ενός υπολογισμένου αθροίσματος που ενημερώνεται καθώς εισάγονται ποσότητες |
| Ορατό πάνελ αναφοράς | Εμφάνιση μιας επιλεγμένης τιμής αναζήτησης (π.χ. όνομα επαρχίας) ενώ ο ερευνητής συμπληρώνει δευτερεύοντα πεδία |

## Βέλτιστες πρακτικές

1. Χρησιμοποιήστε την HTML με φειδώ — οι υπερβολικά μορφοποιημένες ετικέτες είναι πιο δύσκολο να διαβαστούν, όχι πιο εύκολο.
2. Προτιμήστε το `<strong>` για έντονη γραφή και το `<em>` για πλάγια γραφή αντί των καταργημένων `<b>` και `<i>`.
3. Διατηρήστε τη χρήση χρωμάτων ουσιαστική — χρησιμοποιήστε το κόκκινο για προειδοποιήσεις, όχι για διακόσμηση.
4. Πάντα να δοκιμάζετε την απόδοση HTML τόσο στην εφαρμογή για κινητά όσο και στη φόρμα ιστού, καθώς η απόδοση μπορεί να διαφέρει ελαφρώς.
5. Αποφύγετε τις ετικέτες `<table>` μέσα στις ετικέτες — σπάνια αποδίδονται καλά σε οθόνες κινητών.
6. Μη χρησιμοποιείτε JavaScript (`<script>`) — θα αφαιρεθεί ή θα προκαλέσει σφάλματα.

## Περιορισμοί

- Η σύνθετη HTML (πίνακες, φόρμες, σενάρια) δεν υποστηρίζεται και ενδέχεται να χαλάσει την απόδοση.
- Ορισμένοι παλαιότεροι πελάτες κινητών ενδέχεται να εμφανίζουν ετικέτες HTML ως απλό κείμενο — δοκιμάστε σε όλες τις συσκευές-στόχους.
- Οι σύνδεσμοι `<a>` ανοίγουν σε πρόγραμμα περιήγησης ή WebView — ο ερευνητής εγκαταλείπει τη φόρμα, κάτι που μπορεί να είναι ενοχλητικό στο κινητό.

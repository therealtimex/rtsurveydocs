import { Callout } from 'nextra/components'

Η συνάρτηση `pulldata()` ανακτά μια τιμή από ένα αρχείο CSV που είναι συνδεδεμένο στη φόρμα. Δεδομένου ενός ονόματος αρχείου, μιας στήλης προς επιστροφή, μιας στήλης προς αντιστοίχιση και μιας τιμής κλειδί, επιστρέφει το κελί στην τομή της αντίστοιχης σειράς και της στήλης αποτελέσματος.

```
pulldata('filename.csv', 'result_column', 'key_column', ${key_field})
```

| Θέση | Παράμετρος | Περιγραφή |
|----------|-----------|-------------|
| 1 | Όνομα αρχείου | Το όνομα του αρχείου μέσων CSV (το ίδιο όνομα που χρησιμοποιείται στο `select_one_from_file`) |
| 2 | Στήλη αποτελέσματος | Η στήλη της οποίας την τιμή θέλετε να επιστρέψετε |
| 3 | Στήλη κλειδί | Η στήλη με την οποία θα γίνει η αντιστοίχιση |
| 4 | Τιμή κλειδί | Η τιμή προς αντιστοίχιση — συνήθως μια αναφορά πεδίου όπως `${field}` |

Η συνάρτηση επιστρέφει μια κενή συμβολοσειρά εάν δεν βρεθεί αντιστοιχία.

---

## Προϋποθέσεις

Το αρχείο CSV πρέπει να είναι συνδεδεμένο στη φόρμα ως **αρχείο μέσων (media file)**. Το ίδιο αρχείο που αναφέρεται από την `pulldata()` μπορεί επίσης να χρησιμοποιηθεί ως λίστα επιλογών για την `select_one_from_file`.

**Παράδειγμα CSV — `staff.csv`:**

```
name,id,department,phone
Alice,S001,Health,+1234567890
Bob,S002,Education,+0987654321
Carol,S003,Health,+1122334455
```

---

## Βασικό παράδειγμα

Αναζητήστε το τμήμα και το τηλέφωνο ενός μέλους του προσωπικού από το ID του:

**survey:**

| type | name | label | calculation |
|------|------|-------|-------------|
| select_one_from_file staff.csv | staff_id | Επιλέξτε μέλος προσωπικού | |
| calculate | dept | | `pulldata('staff.csv', 'department', 'name', ${staff_id})` |
| calculate | phone | | `pulldata('staff.csv', 'phone', 'name', ${staff_id})` |
| note | dept_note | Τμήμα: `${dept}` — Τηλέφωνο: `${phone}` | |

<Callout type="info">
Η στήλη `name` σε ένα CSV για `select_one_from_file` είναι η αποθηκευμένη τιμή. Όταν ο ερευνητής επιλέγει "Alice", το `${staff_id}` περιέχει "Alice", το οποίο χρησιμοποιεί η `pulldata()` ως κλειδί για να ανακτήσει το τμήμα και το τηλέφωνό της.
</Callout>

## Ανάκτηση της ετικέτας μιας επιλεγμένης επιλογής

Μια ερώτηση `select_one_from_file` αποθηκεύει την τιμή `name`. Για να εμφανίσετε την αναγνώσιμη από τον άνθρωπο ετικέτα (`label`), χρησιμοποιήστε την `pulldata()` για να την αναζητήσετε:

| type | name | label | calculation |
|------|------|-------|-------------|
| select_one_from_file villages.csv | village | Επιλέξτε χωριό | |
| calculate | village_label | | `pulldata('villages.csv', 'label', 'name', ${village})` |
| note | confirm | Επιλέξατε: `${village_label}` | |

---

## Πολλαπλές αναζητήσεις από μία επιλογή

Μπορείτε να καλέσετε την `pulldata()` πολλές φορές στο ίδιο αρχείο για να ανακτήσετε διαφορετικές στήλες για την ίδια επιλεγμένη σειρά:

| type | name | label | calculation |
|------|------|-------|-------------|
| select_one_from_file facilities.csv | facility | Επιλέξτε εγκατάσταση | |
| calculate | fac_type | | `pulldata('facilities.csv', 'type', 'name', ${facility})` |
| calculate | fac_district | | `pulldata('facilities.csv', 'district', 'name', ${facility})` |
| calculate | fac_beds | | `pulldata('facilities.csv', 'beds', 'name', ${facility})` |

---

## Χρήση pulldata στις relevant και constraint

Η `pulldata()` μπορεί να χρησιμοποιηθεί στις στήλες `relevant` και `constraint` για την εφαρμογή λογικής βάσει των αναζητούμενων τιμών:

| type | name | label | relevant | constraint |
|------|------|-------|----------|------------|
| select_one_from_file facilities.csv | facility | Επιλέξτε εγκατάσταση | | |
| integer | bed_count | Αριθμός κατειλημμένων κλινών | | `. <= number(pulldata('facilities.csv', 'beds', 'name', ${facility}))` |

---

## Χρήση pulldata με την `once()`

Για να αξιολογήσετε την `pulldata()` μόνο κατά την πρώτη φόρτωση (αποτρέποντας την επαναξιολόγηση όταν το πεδίο κλειδί αλλάζει μετά την αρχική εισαγωγή), τοποθετήστε την μέσα στην `once()`:

| type | name | label | calculation |
|------|------|-------|-------------|
| calculate | initial_dept | | `once(pulldata('staff.csv', 'department', 'name', ${staff_id}))` |

## Βέλτιστες Πρακτικές

1. Η στήλη κλειδί στο CSV πρέπει να αντιστοιχεί στη στήλη `name` που χρησιμοποιείται στην `select_one_from_file` — αυτές πρέπει να είναι η ίδια τιμή.
2. Τα ονόματα των στηλών στο CSV έχουν ευαισθησία σε πεζά-κεφαλαία (case-sensitive) — το `Department` και το `department` είναι διαφορετικές στήλες.
3. Εάν η τιμή κλειδί δεν βρεθεί, η `pulldata()` επιστρέφει μια κενή συμβολοσειρά — χρησιμοποιήστε `if(${field} != '', pulldata(...), '')` για προστασία από κενές επιλογές.
4. Διατηρήστε τα αρχεία CSV μικρά όπου είναι δυνατόν — τα μεγάλα αρχεία αυξάνουν τον χρόνο φόρτωσης της φόρμας σε συνδέσεις με χαμηλό εύρος ζώνης.
5. Για δεδομένα που αλλάζουν μεταξύ των γύρων συλλογής δεδομένων, ενημερώστε το αρχείο μέσων CSV ανεβάζοντας μια νέα έκδοση της φόρμας.

## Περιορισμοί

- Η `pulldata()` αντιστοιχεί μόνο στην **πρώτη** σειρά όπου η στήλη κλειδί ισούται με την τιμή κλειδί — δεν υποστηρίζονται διπλότυπες τιμές κλειδιών στο CSV.
- Το αρχείο CSV πρέπει να είναι συνδεδεμένο στη φόρμα πριν από την ανάπτυξη (deployment). Δεν μπορεί να ανακτηθεί από μια διεύθυνση URL κατά το χρόνο εκτέλεσης.
- Οι αριθμητικές τιμές που επιστρέφονται από την `pulldata()` είναι συμβολοσειρές — τοποθετήστε τις μέσα στη συνάρτηση `number()` όταν χρησιμοποιούνται σε αριθμητικές πράξεις: `number(pulldata(...))`.

<Callout type="info">
Το rtSurvey υποστηρίζει επίσης εκτεταμένες μορφές της `pulldata()` για την ανάγνωση μεταδεδομένων συσκευής, πεδίων JWT και δεδομένων JSON. Δείτε το [App API](../app-api) για την `pulldata('app-api', ...)` και τη σελίδα [Call API](../advanced-features/call-api) για μοτίβα αναζήτησης που βασίζονται σε JSON.
</Callout>

## Εκτεταμένες παραλλαγές της pulldata()

Πέρα από τις αναζητήσεις σε CSV, η `pulldata()` υποστηρίζει αρκετές πρόσθετες πηγές δεδομένων αλλάζοντας το πρώτο όρισμα.

### `pulldata('app-api', key)`

Διαβάστε μεταδεδομένα συσκευής, χαρακτηριστικά χρήστη και περιβάλλον εφαρμογής. Δείτε την πλήρη αναφορά στη σελίδα [App API](../app-api).

```
pulldata('app-api', 'user.name')
pulldata('app-api', 'serverTime')
pulldata('app-api', 'projectCode')
```

### `pulldata('json', jsonString, jsonpath)`

Αναλύστε μια εσωτερική συμβολοσειρά JSON και εξαγάγετε μια τιμή χρησιμοποιώντας μια έκφραση JSONPath. Χρήσιμο όταν έχετε μια τιμή JSON ενσωματωμένη στη φόρμα.

```
pulldata('json', '{"status":"active","code":42}', '$.code')
```

Επιστρέφει την αντιστοιχισμένη τιμή ως συμβολοσειρά ή κενή συμβολοσειρά εάν δεν βρεθεί.

### `pulldata('jsonpath', fieldRef, jsonpath)`

Εξαγάγετε μια τιμή από μια συμβολοσειρά JSON που είναι αποθηκευμένη σε άλλο πεδίο χρησιμοποιώντας μια έκφραση JSONPath. Αυτό είναι ισοδύναμο με το `substr-jsonpath(${field}, jsonpath)`.

```
pulldata('jsonpath', ${api_raw}, '$.data.id')
```

### `pulldata('jwt', tokenField, claimName)`

Αποκωδικοποιήστε ένα διακριτικό JWT που είναι αποθηκευμένο σε ένα πεδίο και επιστρέψτε την τιμή ενός συγκεκριμένου ισχυρισμού (claim) από το ωφέλιμο φορτίο (payload).

```
pulldata('jwt', ${auth_token}, 'sub')
pulldata('jwt', ${auth_token}, 'exp')
```

Επιστρέφει κενή συμβολοσειρά εάν το διακριτικό δεν είναι έγκυρο ή ο ισχυρισμός δεν είναι παρών.

### `pulldata('instanceid')`

Επιστρέφει το μοναδικό αναγνωριστικό παρουσίας (instance ID) της τρέχουσας υποβολής. Ισοδύναμο με το πεδίο μεταδεδομένων `instanceID`.

```
pulldata('instanceid')
```

### `pulldata('mapping', value, mappingName)`

Αντιστοιχίστε μια τιμή σε μια άλλη χρησιμοποιώντας έναν ονομασμένο πίνακα αντιστοίχισης που ορίζεται στη διαμόρφωση της φόρμας.

```
pulldata('mapping', ${district_code}, 'district_names')
```

Επιστρέφει την αντιστοιχισμένη τιμή ή κενή συμβολοσειρά εάν δεν ταιριάζει καμία αντιστοίχιση.

### `pulldata('options', optionName)`

Διαβάστε μια επιλογή διαμόρφωσης της φόρμας βάσει ονόματος.

```
pulldata('options', 'max_household_size')
```

### `pulldata('rawquery', path, sql, param1, ...)`

Εκτελέστε ένα SQL `SELECT` σε ένα ενσωματωμένο αρχείο SQLite `.db` και επιστρέψτε την τιμή από την πρώτη στήλη της πρώτης αντίστοιχης σειράς. Οι παράμετροι μετά τη συμβολοσειρά SQL αντικαθιστούν με τη σειρά τους τα σύμβολα κράτησης θέσης `?`.

| Position | Parameter | Description |
|----------|-----------|-------------|
| 1 | `'rawquery'` | Κυριολεκτική συμβολοσειρά που προσδιορίζει αυτήν την παραλλαγή |
| 2 | path | Διαδρομή αρχείου στη μορφή `concat(${family_path}, '/file.db::tableName')` |
| 3 | SQL | Μια δήλωση `SELECT` χρησιμοποιώντας το `?` ως σύμβολα κράτησης θέσης θέσης |
| 4+ | params | Τιμές που αντικαθίστανται για κάθε `?` με τη σειρά — συνήθως αναφορές πεδίων όπως `${field}` |

Επιστρέφει μια κενή συμβολοσειρά εάν δεν ταιριάζει καμία σειρά.

**Παράδειγμα — αναζήτηση ονόματος επαρχίας βάσει ID:**

```
pulldata('rawquery',
  concat(${family_path}, '/locations.db::provinces'),
  'SELECT name FROM provinces WHERE id = ?',
  ${province_id})
```

**Παράδειγμα — αναζήτηση ονόματος δημοτικού διαμερίσματος φιλτραρισμένου με κωδικούς επαρχίας και περιφέρειας:**

```
pulldata('rawquery',
  concat(${family_path}, '/locations.db::wards'),
  'SELECT name FROM wards WHERE province_code = ? AND district_code = ?',
  ${province_code},
  ${district_code})
```

Σε αντίθεση με την τυπική `pulldata()` τεσσάρων ορισμάτων που αντιστοιχίζει μια μεμονωμένη στήλη κλειδί σε ένα αρχείο CSV, η παραλλαγή `rawquery` εκτελεί ένα πλήρες SQL `SELECT` σε μια βάση δεδομένων SQLite, επιτρέποντας συνθήκες `WHERE` πολλαπλών στηλών και οποιαδήποτε στήλη ως τιμή επιστροφής.

<Callout type="info">
Το `rawquery` χρησιμοποιείται συνήθως με πεδία αυτόματης συμπλήρωσης για ιεραρχικές αναζητήσεις τοποθεσίας. Δείτε το [Local Database Search](../advanced-features/local-database-search) για λεπτομέρειες σχετικά με τη δημιουργία αρχείων `.db` και τη σύνδεσή τους με την `pulldata('rawquery', ...)`.
</Callout>

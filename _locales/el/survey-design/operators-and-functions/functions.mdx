### Συναρτήσεις συμβολοσειρών

<Callout type="warning">
Όταν εργάζεστε με συμβολοσειρές μέσα σε εκφράσεις, είναι σημαντικό να χρησιμοποιείτε μονά εισαγωγικά ('') για να περικλείετε κυριολεκτικές συμβολοσειρές. Ωστόσο, προκύπτει μια εξαίρεση όταν θέλετε να συμπεριλάβετε μονά εισαγωγικά μέσα σε μια κυριολεκτική συμβολοσειρά. Σε τέτοιες περιπτώσεις, μπορείτε να χρησιμοποιήσετε διπλά εισαγωγικά ("") για να περικλείσετε ολόκληρη τη συμβολοσειρά.

Για παράδειγμα:
- Σωστό: if(`${yesno}` = 1, "a string with 'single quotes' in it", "no single quotes here")
- Λανθασμένο: if(`${yesno}` = 1, 'a string with 'single quotes' in it', 'no single quotes here')

Όσον αφορά τα "έξυπνα" εισαγωγικά (smart quotes), είναι κρίσιμο να γνωρίζετε την παρουσία τους, καθώς μπορούν να προκαλέσουν προβλήματα στις εκφράσεις. Πολλοί επεξεργαστές εμπλουτισμένου κειμένου μετατρέπουν αυτόματα τα ευθεία εισαγωγικά ("" ή '') σε έξυπνα ή καμπυλωτά εισαγωγικά (“” ή ‘’), γεγονός που μπορεί να οδηγήσει σε σφάλματα σύνταξης ή απροσδόκητη συμπεριφορά. Για να το αποφύγετε αυτό, βεβαιωθείτε ότι χρησιμοποιείτε ευθεία εισαγωγικά ('') με συνέπεια στις εκφράσεις σας.

Παρακαλώ ενημερώστε με εάν έχετε περαιτέρω ερωτήσεις ή χρειάζεστε πρόσθετη βοήθεια!
</Callout>

Το rtSurvey υποστηρίζει διάφορες συναρτήσεις, συμπεριλαμβανομένων των:

1. `string(field)`: Μετατρέπει ένα πεδίο σε συμβολοσειρά.
   - Παράδειγμα: `string(34.8)` θα μετατραπεί σε `'34.8'`.

2. `string-length(field)`: Επιστρέφει το μήκος ενός πεδίου συμβολοσειράς.
   - Παράδειγμα: `string-length(.) > 3 and string-length(.) < 10` μπορεί να χρησιμοποιηθεί για να διασφαλιστεί ότι το τρέχον πεδίο είναι μεταξύ 3 και 10 χαρακτήρων.
   - **Πρότυπο εξάρτησης καταρράκτη (Cascade dependency pattern)**: `string-length(${province}) >= 0` αξιολογείται πάντα ως `true` αλλά αναγκάζει το rtSurvey να επανεκτιμήσει την έκφραση όποτε αλλάζει το `${province}`. Χρησιμοποιήστε το στο `relevant` για να προκαλέσετε μια ανανέωση καταρράκτη όταν ενημερώνεται ένα γονικό πεδίο:
     | type | name | relevant |
     |------|------|----------|
     | select_one | district | `string-length(${province}) >= 0` |
     Αυτό διασφαλίζει ότι η ερώτηση περιφέρειας επανεκτιμά την εμφάνιση `search()` ή `rawquery` όποτε αλλάζει η επαρχία.

3. `substr(fieldorstring, startindex, endindex)`: Επιστρέφει μια υποσυμβολοσειρά που ξεκινά στο `startindex` και τελειώνει ακριβώς πριν από το `endindex`. Οι δείκτες ξεκινούν από το 0 για τον πρώτο χαρακτήρα στη συμβολοσειρά.
   - Παράδειγμα: `substr(${phone}, 0, 3)` θα επιστρέψει τα πρώτα τρία ψηφία ενός αριθμού τηλεφώνου.

4. `concat(a, b, c, ...)`: Συνενώνει πεδία (ή/και συμβολοσειρές) μεταξύ τους.
   - Παράδειγμα: `concat(${firstname}, ' ', ${lastname})` θα επιστρέψει ένα πλήρες όνομα συνδυάζοντας τις τιμές στα πεδία `firstname` και `lastname`.

5. `linebreak()`: Επιστρέφει έναν χαρακτήρα αλλαγής γραμμής.
   - Παράδειγμα: `concat(${field1}, linebreak(), ${field2}, linebreak(), ${field3})` θα επιστρέψει μια λίστα με τρεις τιμές πεδίων με αλλαγές γραμμής ανάμεσά τους.

6. `lower()`: Μετατρέπει μια συμβολοσειρά σε όλους τους πεζούς χαρακτήρες.
   - Παράδειγμα: `lower('Street Name')` θα επιστρέψει "street name".

7. `upper()`: Μετατρέπει μια συμβολοσειρά σε όλους τους κεφαλαίους χαρακτήρες.
   - Παράδειγμα: `upper('Street Name')` θα επιστρέψει "STREET NAME".

### Συναρτήσεις select_one και select_multiple

1. `count-selected(field)`: Επιστρέφει τον αριθμό των στοιχείων που έχουν επιλεγεί σε ένα πεδίο select_multiple.
   - Παράδειγμα: `count-selected(.) = 3` μπορεί να χρησιμοποιηθεί ως έκφραση περιορισμού (constraint) για να διασφαλιστεί ότι έχουν επιλεγεί ακριβώς τρεις επιλογές.

2. `selected(field, value)`: Επιστρέφει true ή false ανάλογα με το αν η καθορισμένη τιμή επιλέχθηκε στο πεδίο select_one ή select_multiple.
   - Παράδειγμα: `selected(${color}, 'Blue')` μπορεί να χρησιμοποιηθεί ως έκφραση σχετικότητας (relevance) για να εμφανιστεί μια ομάδα ή ένα πεδίο μόνο εάν ο ερωτώμενος επέλεξε "Blue" ως το αγαπημένο του χρώμα.
   - Σημείωση: Η δεύτερη παράμετρος πρέπει πάντα να καθορίζει την τιμή της επιλογής (choice value), όχι την ετικέτα της επιλογής (choice label). Χρησιμοποιήστε την τιμή από τη στήλη value στο φύλλο εργασίας choices του ορισμού της φόρμας.

3. `selected-at(field, number)`: Επιστρέφει το επιλεγμένο στοιχείο στην καθορισμένη θέση σε ένα πεδίο select_multiple. Όταν ο αριθμός που μεταβιβάζεται είναι 0, επιστρέφει το πρώτο επιλεγμένο στοιχείο. όταν ο αριθμός είναι 1, επιστρέφει το δεύτερο επιλεγμένο στοιχείο κ.ο.κ.
   - Παράδειγμα: `selected-at(${fruits}, 0) = 'Apple'` μπορεί να χρησιμοποιηθεί ως έκφραση σχετικότητας για να εμφανιστεί μια ομάδα ή ένα πεδίο μόνο εάν η πρώτη επιλεγμένη επιλογή είναι "Apple".
   - Σημείωση: Η τιμή που επιστρέφεται θα είναι η τιμή της επιλογής, όχι η ετικέτα της επιλογής. Χρησιμοποιήστε την τιμή από τη στήλη value στο φύλλο εργασίας choices του ορισμού της φόρμας.

4. `choice-label(field, value)`: Επιστρέφει την ετικέτα για μια επιλογή πεδίου select_one ή select_multiple, όπως ορίζεται στο φύλλο εργασίας choices του ορισμού της φόρμας.
   - Παράδειγμα 1: `choice-label(${country}, ${country})` θα επιστρέψει την ετικέτα επιλογής για την τρέχουσα επιλεγμένη επιλογή στο πεδίο με όνομα `country`.
   - Παράδειγμα 2: `choice-label(${languages}, selected-at(${languages}, 0))` θα επιστρέψει την ετικέτα για την πρώτη επιλεγμένη επιλογή στο πεδίο με όνομα `languages`.
   - Σημείωση: Αυτή η συνάρτηση ανακτά την ετικέτα της επιλογής, όχι την τιμή. Χρησιμοποιεί τη στήλη label από το φύλλο εργασίας choices του ορισμού της φόρμας.

### Συναρτήσεις επαναλαμβανόμενων πεδίων

Στο rtSurvey, εάν θέλετε να κάνετε την ίδια ερώτηση ή ερωτήσεις πολλές φορές, μπορείτε να τοποθετήσετε ένα πεδίο μέσα σε μια ομάδα επανάληψης (repeat group). Αυτό έχει ως αποτέλεσμα πολλαπλές εμφανίσεις του ίδιου πεδίου. Οι ακόλουθες συναρτήσεις μπορούν να σας βοηθήουν να διαχειριστείτε αυτά τα επαναλαμβανόμενα πεδία και τα επαναλαμβανόμενα δεδομένα που παράγουν. Δείτε το θέμα βοήθειας για τα επαναλαμβανόμενα πεδία για περισσότερες λεπτομέρειες.

1. `join(string, repeatedfield)`: Για ένα πεδίο μέσα σε μια ομάδα επανάληψης, δημιουργεί μια λίστα τιμών διαχωρισμένων με συμβολοσειρά. Η πρώτη παράμετρος καθορίζει τον οριοθέτη που θα χρησιμοποιηθεί για τον διαχωρισμό των τιμών.
   - Παράδειγμα: `join(', ', ${member_name})` θα δημιουργήσει μια ενιαία λίστα διαχωρισμένη με κόμμα από όλα τα καταχωρημένα ονόματα.

2. `join-if(string, repeatedfield, expression)`: Λειτουργεί ακριβώς όπως η `join()`, με τη διαφορά ότι ελέγχει κάθε εμφάνιση στην ομάδα επανάληψης χρησιμοποιώντας την παρεχόμενη έκφραση. Εάν η έκφραση αξιολογηθεί ως false, το στοιχείο θα παραλειφθεί από το αποτέλεσμα.
   - Παράδειγμα: `join-if(', ', ${member_name}, ${age} >= 18)` θα δημιουργήσει μια λίστα ονομάτων διαχωρισμένη με κόμμα μόνο για τα ενήλικα μέλη (αυτά με ηλικία 18 ετών και άνω).

3. `count(repeatgroup)`: Επιστρέφει τον τρέχοντα αριθμό των φορών που έχει επαναληφθεί μια ομάδα επανάληψης.
   - Παράδειγμα: `count(${groupname})` θα επιστρέψει τον αριθμό των εμφανίσεων της ομάδας.

4. `count-if(repeatgroup, expression)`: Λειτουργεί ακριβώς όπως η `count()`, με τη διαφορά ότι ελέγχει κάθε εμφάνιση στην ομάδα επανάληψης χρησιμοποιώντας την παρεχόμενη έκφραση. Εάν η έκφραση αξιολογηθεί ως false, το στοιχείο θα παραλειφθεί από το αποτέλεσμα.
   - Παράδειγμα: `count-if(${members}, ${age} >= 18)` θα επιστρέψει τον αριθμό των ενήλικων μελών με βάση το πεδίο ηλικίας εντός της ομάδας επανάληψης "members".

5. `sum(repeatedfield)`: Για ένα πεδίο μέσα σε μια ομάδα επανάληψης, υπολογίζει το άθροισμα όλων των τιμών.
   - Παράδειγμα: `sum(${loan_amount})` θα επιστρέψει τη συνολική αξία όλων των δανείων.

6. `sum-if(repeatedfield, expression)`: Λειτουργεί ακριβώς όπως η `sum()`, με τη διαφορά ότι ελέγχει κάθε εμφάνιση στην ομάδα επανάληψης χρησιμοποιώντας την παρεχόμενη έκφραση. Εάν η έκφραση αξιολογηθεί ως false, το στοιχείο θα παραλειφθεί από το αποτέλεσμα.
   - Παράδειγμα: `sum-if(${loan_amount}, ${loan_amount} > 500)` θα επιστρέψει τη συνολική αξία όλων των δανείων που είναι πάνω από 500. Τα μικρότερα δάνεια θα αγνοηθούν.

7. `min(repeatedfield)`: Για ένα πεδίο μέσα σε μια ομάδα επανάληψης, υπολογίζει το ελάχιστο όλων των τιμών.
   - Παράδειγμα: `min(${member_age})` θα επιστρέψει την ηλικία του νεότερου μέλους στην ομάδα.

8. `min-if(repeatedfield, expression)`: Λειτουργεί ακριβώς όπως η `min()`, με τη διαφορά ότι ελέγχει κάθε εμφάνιση στην ομάδα επανάληψης χρησιμοποιώντας την παρεχόμενη έκφραση. Εάν η έκφραση αξιολογηθεί ως false, το στοιχείο θα παραλειφθεί από το αποτέλεσμα.
   - Παράδειγμα: `min-if(${member_age}, ${member_age} >= 18)` θα επιστρέψει την ηλικία του νεότερου ενήλικα στην ομάδα. Όσοι είναι κάτω των 18 θα αγνοηθούν.

9. `max(repeatedfield)`: Για ένα πεδίο μέσα σε μια ομάδα επανάληψης, υπολογίζει το μέγιστο όλων των τιμών.
   - Παράδειγμα: `max(${member_age})` θα επιστρέψει την ηλικία του γηραιότερου μέλους στην ομάδα.

10. `max-if(repeatedfield, expression)`: Λειτουργεί ακριβώς όπως η `max()`, με τη διαφορά ότι ελέγχει κάθε εμφάνιση στην ομάδα επανάληψης χρησιμοποιώντας την παρεχόμενη έκφραση. Εάν η έκφραση αξιολογηθεί ως false, το στοιχείο θα παραλειφθεί από το αποτέλεσμα.
    - Παράδειγμα: `max-if(${member_age}, ${member_age} >= 18)` θα επιστρέψει την ηλικία του γηραιότερου ενήλικα στην ομάδα. Όσοι είναι κάτω των 18 θα αγνοηθούν.

11. `index()`: Καλείται μέσα σε μια ομάδα επανάληψης, επιστρέφει τον αριθμό δείκτη για την τρέχουσα ομάδα ή εμφάνιση.
    - Παράδειγμα: `index()` όταν χρησιμοποιείται μέσα σε μια ομάδα επανάληψης θα επιστρέψει 1 για την πρώτη εμφάνιση, 2 για τη δεύτερη κ.ο.κ.

12. `indexed-repeat(repeatedfield, repeatgroup, index)`: Αναφέρεται σε ένα πεδίο ή ομάδα που βρίσκεται μέσα σε μια ομάδα επανάληψης από έξω από αυτήν την ομάδα επανάληψης. Η πρώτη παράμετρος καθορίζει το επαναλαμβανόμενο πεδίο ή την ομάδα ενδιαφέροντος, η δεύτερη καθορίζει την ομάδα επανάληψης εντός της οποίας βρίσκεται το πεδίο ή η ομάδα, και η τρίτη καθορίζει τον αριθμό εμφάνισης εντός της ομάδας επανάληψης που θα χρησιμοποιηθεί.
    - Παράδειγμα 1: `indexed-repeat(${name}, ${names}, 1)` θα επιστρέψει το πρώτο όνομα που είναι διαθέσιμο όταν το πεδίο name βρίσκεται μέσα σε μια προηγούμενη ομάδα επανάληψης με το όνομα "names".
    - Παράδειγμα 2: `indexed-repeat(${name}, ${names}, index())` θα τραβήξει το όνομα που αντιστοιχεί στον αριθμό εμφάνισης της τρέχουσας ομάδας επανάληψης.

13. `rank-index(index, repeatedfield)`: Αυτή η συνάρτηση υπολογίζει την τακτική κατάταξη (ordinal rank) της καθορισμένης εμφάνισης ενός επαναλαμβανόμενου πεδίου για χρήση εκτός της ομάδας επανάληψης. Η κατάταξη 1 αποδίδεται στην εμφάνιση με την υψηλότερη τιμή, η κατάταξη 2 στην εμφάνιση με την αμέσως επόμενη υψηλότερη τιμή κ.ο.κ. Εάν μεταβιβάσετε έναν μη έγκυρο δείκτη ή έναν δείκτη σε μια εμφάνιση με μη αριθμητική τιμή, θα επιστραφεί η κατάταξη 999.
    - Παράδειγμα: `rank-index(1, ${random_draw})` υπολογίζει την κατάταξη της πρώτης εμφάνισης με βάση την τιμή του πεδίου `random_draw` σε σύγκριση με τις τιμές των άλλων εμφανίσεων.

14. `rank-index-if(index, repeatedfield, expression)`: Αυτή η συνάρτηση λειτουργεί παρόμοια με την `rank-index()`, αλλά ελέγχει κάθε εμφάνιση στην ομάδα επανάληψης του επαναλαμβανόμενου πεδίου χρησιμοποιώντας την παρεχόμενη έκφραση. Εάν η έκφραση αξιολογηθεί ως false, το στοιχείο θα παραλειφθεί από τον υπολογισμό. Ο δείκτης που χρησιμοποιείται βασίζεται στο πλήρες σύνολο των εμφανίσεων πριν από την αξιολόγηση της έκφρασης για κάθε εμφάνιση. Εάν μεταβιβάσετε έναν δείκτη για μια εμφάνιση που αγνοήθηκε επειδή δεν ικανοποιούσε την έκφραση, θεωρείται μη έγκυρος δείκτης και θα επιστραφεί η κατάταξη 999.
    - Παράδειγμα: `rank-index-if(1, ${age}, ${age} >= 18)` υπολογίζει την κατάταξη ηλικίας εντός του συνόλου των ενηλίκων, λαμβάνοντας υπόψη μόνο τις εμφανίσεις όπου η ηλικία είναι μεγαλύτερη ή ίση με 18.

### Συναρτήσεις αριθμών

| Τελεστής | Λειτουργία | Παράδειγμα | Παράδειγμα απάντησης |
|----------|-----------|---------|----------------|
| `+` | Πρόσθεση | 1 + 1 | 2 |
| `-` | Αφαίρεση | 3 - 2 | 1 |
| `*` | Πολλαπλασιασμός | 3 * 2 | 6 |
| `div` | Διαίρεση | 10 div 2 | 5 |
| `mod` | Υπόλοιπο (Modulo) | 9 mod 2 | 1 |

Το rtSurvey υποστηρίζει συναρτήσεις αριθμών, συμπεριλαμβανομένων των:
- `number(field)`: Μετατρέπει την τιμή του πεδίου σε αριθμό.
  - Παράδειγμα: `number('34.8')` = 34.8

- `int(field)`: Μετατρέπει την τιμή του πεδίου σε ακέραιο.
  - Παράδειγμα: `int('39.2')` = 39

- `min(field1, ..., fieldx)`: Επιστρέφει την ελάχιστη τιμή μεταξύ των πεδίων που μεταβιβάστηκαν.
  - Παράδειγμα: `min(${father_age}, ${mother_age})` θα επιστρέψει την ηλικία είτε της μητέρας είτε του πατέρα, όποια είναι μικρότερη.

- `max(field1, ..., fieldx)`: Επιστρέφει τη μέγιστη τιμή μεταξύ των πεδίων που μεταβιβάστηκαν.
  - Παράδειγμα: `max(${father_age}, ${mother_age})` θα επιστρέψει την ηλικία είτε της μητέρας είτε του πατέρα, όποια είναι μεγαλύτερη.

- `format-number(field)`: Μορφοποιεί την τιμή ενός πεδίου ακεραίου ή δεκαδικού σύμφωνα με τις ρυθμίσεις τοπικού προσαρμογέα (locale) του χρήστη.
  - Παράδειγμα: `format-number(${income})` Αυτή η έκφραση μπορεί να μορφοποιήσει το "120000" ως "120,000".

- `round(field, digits)`: Στρογγυλοποιεί την αριθμητική τιμή του πεδίου στον καθορισμένο αριθμό ψηφίων μετά την υποδιαστολή.
  - Παράδειγμα: `round(${interest_rate}, 2)`

- `abs(number)`: Επιστρέφει την απόλυτη τιμή ενός αριθμού.
  
- `pow(base, exponent)`: Επιστρέφει την τιμή της πρώτης παραμέτρου υψωμένη στη δύναμη της δεύτερης παραμέτρου.
  - Κάθε παράμετρος μπορεί να είναι πεδίο, αριθμός ή έκφραση.

- `log10(fieldorvalue)`: Επιστρέφει τον δεκαδικό λογάριθμο του πεδίου ή της τιμής που μεταβιβάστηκε.

- `sin(fieldorvalue)`: Επιστρέφει το ημίτονο του πεδίου ή της τιμής που μεταβιβάστηκε, εκφρασμένο σε ακτίνια (radians).
  
- `cos(fieldorvalue)`: Επιστρέφει το συνημίτονο του πεδίου ή της τιμής που μεταβιβάστηκε, εκφρασμένο σε ακτίνια.

- `tan(fieldorvalue)`: Επιστρέφει την εφαπτομένη του πεδίου ή της τιμής που μεταβιβάστηκε, εκφρασμένη σε ακτίνια.

- `asin(fieldorvalue)`: Επιστρέφει το τόξο ημιτόνου του πεδίου ή της τιμής που μεταβιβάστηκε, εκφρασμένο σε ακτίνια.

- `acos(fieldorvalue)`: Επιστρέφει το τόξο συνημιτόνου του πεδίου ή της τιμής που μεταβιβάστηκε, εκφρασμένο σε ακτίνια.

- `atan(fieldorvalue)`: Επιστρέφει το τόξο εφαπτομένης του πεδίου ή της τιμής που μεταβιβάστηκε, εκφρασμένο σε ακτίνια.

- `atan2(x, y)`: Επιστρέφει τη γωνία σε ακτίνια που σχηματίζεται στην αρχή των αξόνων από το σημείο με συντεταγμένες (x, y) και τον θετικό άξονα x. Το αποτέλεσμα είναι στο εύρος -pi() έως pi().

- `sqrt(fieldorvalue)`: Επιστρέφει τη μη αρνητική τετραγωνική ρίζα του πεδίου ή της τιμής που μεταβιβάστηκε.

- `exp(x)`: Επιστρέφει την τιμή του e^x.

- `pi()`: Επιστρέφει την τιμή του π.

### Συναρτήσεις ημερομηνίας και ώρας

<Callout type="warning">
Οι τιμές ημερομηνίας στο rtSurvey αποθηκεύονται ως συμβολοσειρές σε μορφή `YYYY-MM-DD`. Οι τιμές ημερομηνίας-ώρας αποθηκεύονται ως συμβολοσειρές ISO 8601 (`YYYY-MM-DDTHH:MM:SS`). Χρησιμοποιήστε την `decimal-date-time()` για να τις μετατρέψετε σε αριθμό για αριθμητικές πράξεις (π.χ. υπολογισμός διάρκειας).
</Callout>

1. `today()`: Επιστρέφει τη σημερινή ημερομηνία ως συμβολοσειρά σε μορφή `YYYY-MM-DD`. Αξιολογείται μία φορά κατά το άνοιγμα της φόρμας.
   - Παράδειγμα: `today()` → `'2024-03-15'`
   - Κοινή χρήση: στήλη `default` για την προσυμπλήρωση της σημερινής ημερομηνίας, ή στο `relevant`/`constraint` για σύγκριση με ένα πεδίο ημερομηνίας.

2. `now()`: Επιστρέφει την τρέχουσα ημερομηνία και ώρα ως συμβολοσειρά ISO 8601. Αξιολογείται κάθε φορά που υπολογίζεται η έκφραση.
   - Παράδειγμα: `now()` → `'2024-03-15T14:32:00.000+03:00'`
   - Κοινή χρήση: Καταγραφή της ακριβούς χρονικής σήμανσης ενός συγκεκριμένου συμβάντος κατά τη διάρκεια της έρευνας.

3. `date(value)`: Μετατρέπει μια τιμή (συμβολοσειρά ή αριθμό) σε συμβολοσειρά ημερομηνίας. Χρήσιμο για τον εξαναγκασμό υπολογισμένων τιμών σε τύπο ημερομηνίας.
   - Παράδειγμα: `date('2024-03-15')` → `'2024-03-15'`

4. `date-time(value)`: Μετατρέπει μια τιμή σε συμβολοσειρά ημερομηνίας-ώρας.
   - Παράδειγμα: `date-time(${event_timestamp})`

5. `decimal-date-time(value)`: Μετατρέπει μια συμβολοσειρά ημερομηνίας ή ημερομηνίας-ώρας σε έναν δεκαδικό αριθμό που αντιπροσωπεύει τα χιλιοστά του δευτερολέπτου από την εποχή Unix διαιρούμενα με 86400000 (δηλαδή, κλασματικές ημέρες από το 1970-01-01). Χρησιμοποιήστε το για να εκτελέσετε αριθμητικές πράξεις σε ημερομηνίες.
   - Παράδειγμα: Διάρκεια σε ημέρες μεταξύ δύο ημερομηνιών:
     `decimal-date-time(${end_date}) - decimal-date-time(${start_date})`
   - Παράδειγμα: Διάρκεια σε λεπτά μεταξύ δύο ημερομηνιών-ώρας:
     `(decimal-date-time(${end_time}) - decimal-date-time(${start_time})) * 1440`

6. `format-date(date, format)`: Μορφοποιεί μια τιμή ημερομηνίας χρησιμοποιώντας μια συμβολοσειρά προτύπου.
   - Διακριτικά μορφοποίησης: `%Y` (4-ψήφιο έτος), `%y` (2-ψήφιο έτος), `%m` (μήνας 01–12), `%d` (ημέρα 01–31), `%a` (συντομογραφία καθημερινής), `%b` (συντομογραφία ονόματος μήνα)
   - Παράδειγμα: `format-date(today(), '%d/%m/%Y')` → `'15/03/2024'`
   - Παράδειγμα: `format-date(${dob}, '%B %d, %Y')` → `'March 15, 1990'`

7. `format-date-time(datetime, format)`: Μορφοποιεί μια τιμή ημερομηνίας-ώρας χρησιμοποιώντας μια συμβολοσειρά προτύπου. Δέχεται όλα τα διακριτικά της `format-date` συν:
   - `%H` (ώρα 00–23), `%h` (ώρα 01–12), `%M` (λεπτά 00–59), `%S` (δευτερόλεπτα 00–59), `%3` (χιλιοστά του δευτερολέπτου), `%P` (AM/PM)
   - Παράδειγμα: `format-date-time(now(), '%d/%m/%Y %H:%M')` → `'15/03/2024 14:32'`
   - Παράδειγμα: `format-date-time(${event_time}, '%I:%M %p')` → `'02:32 PM'`

8. `STRFTIME(format, datetime)`: Μορφοποίηση ημερομηνίας τύπου SQLite. Διαθέσιμη μέσα σε συμβολοσειρές SQL που μεταβιβάζονται σε ερωτήματα `rawquery` — **όχι** διαθέσιμη στις στήλες XLSForm `calculation` ή `label`. Χρησιμοποιεί διακριτικά μορφής SQLite (`%Y`, `%m`, `%d`, `%H`, `%M`, `%S`).
   - Παράδειγμα μέσα σε μια συμβολοσειρά SQL rawquery: `'SELECT STRFTIME(''%Y-%m'', interview_date) AS month FROM data WHERE id = ?'`
   - Σημείωση: Χρησιμοποιήστε την `format-date-time()` για μορφοποίηση ημερομηνίας σε εκφράσεις XLSForm. Η `STRFTIME()` είναι μια συνάρτηση SQLite διαθέσιμη μόνο εντός SQL που μεταβιβάζεται στο `rawquery`.

### Συναρτήσεις Boolean

1. `boolean(value)`: Μετατρέπει οποιαδήποτε τιμή σε boolean. Επιστρέφει `true` για μη κενές συμβολοσειρές, μη μηδενικούς αριθμούς και `true`. επιστρέφει `false` για κενές συμβολοσειρές, `0` και `false`.
   - Παράδειγμα: `boolean(${name})` επιστρέφει `true` εάν το `name` δεν είναι κενό.

2. `boolean-from-string(string)`: Επιστρέφει `true` εάν η συμβολοσειρά είναι `'1'` ή `'true'` (ανεξαρτήτως πεζών-κεφαλαίων). επιστρέφει `false` διαφορετικά.
   - Παράδειγμα: `boolean-from-string(${enabled_flag})` — χρήσιμο όταν ένα πεδίο αποθηκεύει `'true'`/`'false'` ως κείμενο.

3. `true()`: Επιστρέφει τη λογική τιμή `true`.
   - Παράδειγμα: Στη στήλη `required`, το `true()` είναι ισοδύναμο με το `yes`.

4. `false()`: Επιστρέφει τη λογική τιμή `false`.
   - Παράδειγμα: `if(${skip_section} = 'yes', false(), true())` — δυναμικός ορισμός του πεδίου ως απαιτούμενο.

5. `not(expression)`: Επιστρέφει τη λογική άρνηση της έκφρασης. Επιστρέφει `true` εάν η έκφραση είναι ψευδής και αντίστροφα.
   - Παράδειγμα: `not(${consent} = 'yes')` — εμφάνιση προειδοποίησης όταν ΔΕΝ δόθηκε συγκατάθεση.
   - Παράδειγμα: `not(selected(${issues}, 'none'))` — απαίτηση λεπτομερειών μόνο εάν δεν επιλέχθηκε το "none".

### Πρόσθετες συναρτήσεις συμβολοσειρών

1. `starts-with(string, prefix)`: Επιστρέφει `true` εάν η `string` ξεκινά με `prefix`.
   - Παράδειγμα: `starts-with(${phone}, '+254')` ελέγχει εάν ο αριθμός τηλεφώνου ξεκινά με τον κωδικό χώρας της Κένυας.

2. `contains(string, substring)`: Επιστρέφει `true` εάν η `string` περιέχει τη `substring`.
   - Παράδειγμα: `contains(${email}, '@')` ελέγχει ότι μια διεύθυνση email έχει το σύμβολο `@`.
   - Παράδειγμα: `contains(${notes}, 'urgent')` ενεργοποιεί μια ερώτηση παρακολούθησης εάν οι σημειώσεις αναφέρουν τη λέξη "urgent".

3. `substring-before(string, needle)`: Επιστρέφει το μέρος της `string` που εμφανίζεται πριν από την πρώτη εμφάνιση του `needle`.
   - Παράδειγμα: `substring-before(${full_name}, ' ')` εξάγει την πρώτη λέξη (όνομα).

4. `substring-after(string, needle)`: Επιστρέφει το μέρος της `string` που εμφανίζεται μετά από την πρώτη εμφάνιση του `needle`.
   - Παράδειγμα: `substring-after(${email}, '@')` εξάγει το μέρος του τομέα (domain) μιας διεύθυνσης email.

5. `normalize-space(string)`: Αφαιρεί τα κενά διαστήματα στην αρχή και στο τέλος και συμπτύσσει όλες τις εσωτερικές ακολουθίες κενών διαστημάτων σε ένα μόνο κενό.
   - Παράδειγμα: `normalize-space(${name})` — καθαρίζει ένα όνομα που μπορεί να πληκτρολογήθηκε με επιπλέον κενά.

6. `translate(string, search_chars, replace_chars)`: Αντικαθιστά κάθε χαρακτήρα στη `string` που εμφανίζεται στο `search_chars` με τον αντίστοιχο χαρακτήρα στο `replace_chars`. Οι χαρακτήρες στο `search_chars` χωρίς αντίστοιχο χαρακτήρα στο `replace_chars` διαγράφονται.
   - Παράδειγμα: `translate(${code}, 'abcdefghijklmnopqrstuvwxyz', 'ABCDEFGHIJKLMNOPQRSTUVWXYZ')` μετατρέπει σε κεφαλαία (ισοδύναμο με την `upper()`).
   - Παράδειγμα: `translate(${phone}, ' -()', '')` αφαιρεί κενά, παύλες και παρενθέσεις από έναν αριθμό τηλεφώνου.

### Πρόσθετες μαθηματικές συναρτήσεις

1. `floor(number)`: Επιστρέφει τον μεγαλύτερο ακέραιο που είναι μικρότερος ή ίσος με το `number` (στρογγυλοποίηση προς το αρνητικό άπειρο).
   - Παράδειγμα: `floor(4.9)` = 4, `floor(-2.1)` = -3

2. `ceiling(number)`: Επιστρέφει τον μικρότερο ακέραιο που είναι μεγαλύτερος ή ίσος με το `number` (στρογγυλοποίηση προς το θετικό άπειρο).
   - Παράδειγμα: `ceiling(4.1)` = 5, `ceiling(-2.9)` = -2

3. `random()`: Επιστρέφει έναν τυχαίο δεκαδικό αριθμό μεταξύ 0.0 (συμπεριλαμβανομένου) και 1.0 (εξαιρουμένου). Συνήθως χρησιμοποιείται σε πεδία `calculate` για την αντιστοίχιση τυχαίων τιμών ή την τυχαιοποίηση της σειράς των ερωτήσεων.
   - Παράδειγμα: `random()` → π.χ., `0.7341`
   - Παράδειγμα: `int(random() * 6) + 1` → τυχαίος αριθμός 1–6 (ρίψη ζαριού)

4. `coalesce(a, b)`: Επιστρέφει το `a` εάν το `a` δεν είναι κενό. διαφορετικά επιστρέφει το `b`. Χρήσιμο ως εφεδρική επιλογή όταν ένα πεδίο μπορεί να είναι κενό.
   - Παράδειγμα: `coalesce(${preferred_name}, ${full_name})` — χρήση του προτιμώμενου ονόματος εάν έχει οριστεί, διαφορετικά επιστροφή στο πλήρες όνομα.

5. `once(value)`: Αξιολογεί τη `value` και την αποθηκεύει, αλλά μόνο εάν το τρέχον πεδίο είναι **κενό**. Εάν το πεδίο έχει ήδη μια τιμή (π.χ. είχε οριστεί προηγουμένως), η `once()` επιστρέφει την υπάρχουσα τιμή αμετάβλητη. Αυτό εμποδίζει τον επανυπολογισμό από το να αντικαταστήσει την καταχώρηση του χρήστη.
   - Παράδειγμα: `once(today())` στη στήλη `default` ορίζει τη σημερινή ημερομηνία μία φορά και δεν ενημερώνεται εάν ο απογραφέας ξανανοίξει τη φόρμα.
   - Παράδειγμα: `once(uuid())` δημιουργεί ένα UUID μία φορά και το διατηρεί σταθερό σε όλες τις επανεπεξεργασίες.

### Συναρτήσεις Γεωγραφίας (Geo)

1. `area(geoshape_value)`: Υπολογίζει το **εμβαδόν σε τετραγωνικά μέτρα** που περικλείεται από μια τιμή geoshape (πολύγωνο).
   - Η παράμετρος είναι μια τιμή πεδίου geoshape στη μορφή `lat1 lon1 0 0; lat2 lon2 0 0; ...`
   - Παράδειγμα: `area(${field_boundary})` — υπολογισμός του εμβαδού ενός αποτυπωμένου αγρού σε m².
   - Παράδειγμα: `round(area(${field_boundary}) div 10000, 2)` — μετατροπή σε εκτάρια.

2. `distance(coordinates)`: Υπολογίζει το **συνολικό μήκος διαδρομής σε μέτρα** ενός geotrace (γραμμή), ή την απόσταση μεταξύ δύο geopoints.
   - Για ένα geotrace: `distance(${route})` επιστρέφει το συνολικό μήκος διαδρομής σε μέτρα.
   - Για δύο geopoints: `distance(concat(${point_a}, ' ', ${point_b}))` επιστρέφει την απόσταση μεταξύ τους.
   - Παράδειγμα: `round(distance(${road_trace}) div 1000, 3)` — μήκος δρόμου σε χιλιόμετρα.

### Συναρτήσεις επικύρωσης (Validation)

1. `regex(value, pattern)`: Επιστρέφει `true` εάν η `value` ταιριάζει με την κανονική έκφραση `pattern`. Χρησιμοποιήστε το στη στήλη `constraint` για επικύρωση βάσει προτύπου.
   - Το πρότυπο χρησιμοποιεί τυπική σύνταξη regex (υποσύνολο POSIX ERE).
   - Παράδειγμα: `regex(., '^[0-9]{10}$')` — επικύρωση 10-ψήφιου αριθμού.
   - Παράδειγμα: `regex(., '^[A-Z]{2}[0-9]{6}$')` — επικύρωση μορφής αριθμού διαβατηρίου (2 κεφαλαία γράμματα ακολουθούμενα από 6 ψηφία).
   - Παράδειγμα: `regex(., '^[^@]+@[^@]+\.[^@]{2,}$')` — βασικός έλεγχος μορφής email.

2. `checklist(min, max, v1, v2, ...)`: Αξιολογεί μια λίστα εκφράσεων boolean και επιστρέφει `true` εάν ο αριθμός των τιμών `true` είναι μεταξύ `min` και `max` (συμπεριλαμβανομένων). Μεταβιβάστε `-1` για το `min` ή το `max` για να παραλείψετε αυτό το όριο.
   - Παράδειγμα: `checklist(2, 3, ${q1} = 'yes', ${q2} = 'yes', ${q3} = 'yes')` — περνάει εάν ακριβώς 2 ή 3 από τις τρεις συνθήκες είναι αληθείς.
   - Παράδειγμα: `checklist(1, -1, ${smoke_alarm}, ${fire_ext}, ${emergency_plan})` — τουλάχιστον ένα μέτρο ασφαλείας πρέπει να είναι αληθές.

3. `weighted-checklist(min, max, v1, w1, v2, w2, ...)`: Όπως η `checklist()`, αλλά κάθε τιμή έχει ένα βάρος. Το άθροισμα των βαρών για τις τιμές `true` πρέπει να είναι μεταξύ `min` και `max`.
   - Παράδειγμα: `weighted-checklist(10, -1, ${has_toilet}, 4, ${has_sink}, 3, ${has_shower}, 5)` — το άθροισμα των βαρών για τις υπάρχουσες εγκαταστάσεις πρέπει να είναι τουλάχιστον 10.

### Βοηθητικές συναρτήσεις (Utility)

1. `uuid()`: Δημιουργεί ένα τυχαίο UUID (μορφή RFC 4122 v4) ως συμβολοσειρά.
   - Παράδειγμα: `uuid()` → `'a3f8b2c1-4d5e-6f7a-8b9c-0d1e2f3a4b5c'`
   - Συνήθως χρησιμοποιείται με την `once()` για τη δημιουργία ενός σταθερού μοναδικού αναγνωριστικού: `once(uuid())`

2. `version()`: Επιστρέφει την τιμή του χαρακτηριστικού `version` της φόρμας, όπως έχει οριστεί στο φύλλο εργασίας settings.
   - Παράδειγμα: `version()` → `'3.1'`
   - Χρήσιμο σε πεδία `calculate` για την ενσωμάτωση της έκδοσης της φόρμας στα εξαγόμενα δεδομένα.

3. `position()`: Όταν καλείται μέσα σε μια **ομάδα επανάληψης (repeat group)**, επιστρέφει τον δείκτη (με βάση το 1) της τρέχουσας εμφάνισης επανάληψης.
   - Παράδειγμα: `position()` στην πρώτη εμφάνιση επιστρέφει `1`, στη δεύτερη επιστρέφει `2` κ.ο.κ.
   - Δείτε επίσης: `index()` (ψευδώνυμο), `indexed-repeat()` για αναφορά σε τιμές επανάληψης από έξω από την ομάδα.

4. `thousandsep(length, separator, value)`: Μορφοποιεί έναν αριθμό με διαχωριστικό χιλιάδων. Το `length` είναι το ελάχιστο συνολικό μήκος συμβολοσειράς (συμπληρώνεται με κενά εάν είναι μικρότερο), το `separator` είναι ο χαρακτήρας που θα χρησιμοποιηθεί (π.χ. `','`) και η `value` είναι ο αριθμός προς μορφοποίηση.
   - Παράδειγμα: `thousandsep(0, ',', 1234567)` → `'1,234,567'`
   - Παράδειγμα: `thousandsep(0, '.', ${income})` → μορφοποιεί το εισόδημα με τελεία ως διαχωριστικό χιλιάδων.

5. `substr-jsonpath(value, jsonpath)`: Εξάγει μια τιμή από μια συμβολοσειρά JSON χρησιμοποιώντας μια έκφραση JSONPath.
   - Η `value` πρέπει να είναι μια συμβολοσειρά JSON (π.χ. ένα πεδίο που αποθήκευσε μια ακατέργαστη απάντηση API χρησιμοποιώντας `callapi(..., 'json:', ...)`).
   - Το `jsonpath` είναι μια έκφραση JSONPath (π.χ. `'$.data.name'`, `'$.items[0].id'`).
   - Επιστρέφει πάντα μια **συμβολοσειρά** — περικλείστε την σε `number()` όταν χρησιμοποιείται σε αριθμητικές πράξεις.
   - Επιστρέφει μια κενή συμβολοσειρά `''` εάν η διαδρομή δεν βρεθεί ή η `value` δεν είναι έγκυρο JSON.
   - Παράδειγμα: `substr-jsonpath(${api_response}, '$.data.name')` — εξαγωγή του πεδίου `name`.
   - Παράδειγμα: `substr-jsonpath(${api_response}, '$.items[0].label')` — πρώτο στοιχείο ενός πίνακα.
   - Παράδειγμα: `number(substr-jsonpath(${api_response}, '$.price'))` — εξαγωγή μιας αριθμητικής τιμής.
   - Συνήθως χρησιμοποιείται παράλληλα με την `callapi(..., 'json:', ...)` για την εξαγωγή πολλαπλών πεδίων από μία απάντηση API. Δείτε το [Ανάκτηση πολλαπλών τιμών από μία κλήση API](../advanced-features/call-api#fetching-multiple-values-from-one-api-call).

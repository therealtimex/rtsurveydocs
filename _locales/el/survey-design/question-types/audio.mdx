Ο τύπος ερώτησης `audio` επιτρέπει στους ερωτώμενους να **ηχογραφούν ήχο** ή να ανεβάζουν ένα υπάρχον αρχείο ήχου ως μέρος της απάντησής τους στην έρευνα. Είναι χρήσιμο για την καταγραφή προφορικών αφηγήσεων, περιβαλλοντικών ήχων, μαρτυριών ή οποιασδήποτε πληροφορίας που μεταφέρεται καλύτερα μέσω φωνής παρά μέσω κειμένου.

## Βασική προδιαγραφή XLSForm

| type  | name        | label                        |
|-------|-------------|------------------------------|
| audio | voice_note  | Παρακαλώ ηχογραφήστε τα σχόλιά σας  |

Για περισσότερες λεπτομέρειες σχετικά με τον τυπικό τύπο ερώτησης ήχου, ανατρέξτε στην [προδιαγραφή XLSForm](https://xlsform.org/en/#question-types).

## Χρήσεις

Οι ερωτήσεις ήχου χρησιμοποιούνται συνήθως για:

1. Καταγραφή ανοιχτών προφορικών απαντήσεων για μείωση του φόρτου πληκτρολόγησης του ερευνητή
2. Ηχογράφηση μαρτυριών, προσωπικών ιστοριών ή προφορικών ιστορικών
3. Τεκμηρίωση περιβαλλοντικών ήχων (π.χ. επίπεδα θορύβου κοντά σε υποδομές)
4. Συλλογή δειγμάτων φωνής για γλωσσολογική ή υγειονομική έρευνα
5. Επιτρέποντας στους ερωτώμενους να προσθέσουν προφορικές διευκρινίσεις σε αριθμητικές ή επιλεγμένες απαντήσεις

## Μορφή δεδομένων

Τα αρχεία ήχου αποθηκεύονται ως δυαδικά συνημμένα μαζί με την υποβολή της φόρμας, συνήθως:

- **Μορφή:** MP3 ή AAC (εγγραφή κινητού)· WAV (εγγραφή υψηλής ποιότητας)
- **Ονομασία:** `{instanceID}-{fieldname}.mp3` (ή ισοδύναμο)
- **Αποθήκευση:** Ανεβαίνουν στον φάκελο πολυμέσων του διακομιστή και συνδέονται με την εγγραφή υποβολής
- **Πρόσβαση:** Αναπαραγωγή και λήψη από τη διεπαφή διαχείρισης υποβολών

## Επεκτάσεις rtSurvey

### Μέγιστη διάρκεια

Χρησιμοποιήστε τη στήλη `parameters` για να περιορίσετε τη διάρκεια της ηχογράφησης:

| type | name | label | parameters |
|------|------|-------|------------|
| audio | interview | Ηχογραφήστε τη συνέντευξη | `max-duration=120` |

Η `max-duration` είναι σε δευτερόλεπτα. Η συσκευή εγγραφής σταματά αυτόματα στο όριο.

### Ρυθμίσεις ποιότητας

Η ποιότητα εγγραφής μπορεί να ρυθμιστεί μέσω `parameters`:

| type | name | label | parameters |
|------|------|-------|------------|
| audio | feedback | Ηχογραφήστε σχόλια | `quality=normal` |

Υποστηριζόμενες τιμές: `low`, `normal` (προεπιλογή), `voice-only`. Το `voice-only` βελτιστοποιεί για ομιλούμενο ήχο με μείωση θορύβου.

### Αναπαραγωγή πριν την υποβολή

Στο κινητό, ο ερευνητής μπορεί να αναπαράγει το ηχογραφημένο κλιπ πριν συνεχίσει. Αυτό είναι ενεργοποιημένο από προεπιλογή — δεν απαιτείται ρύθμιση.

### Ενσωμάτωση εγγενούς συσκευής εγγραφής

Σε Android και iOS, το `audio` εκκινεί την εγγενή εφαρμογή εγγραφής της συσκευής. Στον ιστό, χρησιμοποιεί το ενσωματωμένο API MediaRecorder του προγράμματος περιήγησης.

### Διάταξη κουμπιών σε σειρά

Προσθέστε `inline` για να εμφανίσετε το μικρόφωνο ως **κυκλικό κουμπί εικονιδίου** δίπλα στην ετικέτα.

```
| type  | name | label        | appearance                    |
|-------|------|--------------|-------------------------------|
| audio | clip | Ηχογραφήστε ήχο | inline display{right}         |
| audio | clip | Ηχογραφήστε ήχο | inline display{left, large}   |
```

**Θέση κουμπιού** — `left`, `right` *(προεπιλογή)*, `top`, `center`, `bottom`

**Μέγεθος κουμπιού** — `small` *(προεπιλογή)*, `medium`, `large`

**Χρώμα κουμπιού** — προσθέστε ένα δεκαεξαδικό χρώμα μέσα στο `display{}` για να παρακάμψετε το κύριο χρώμα:

```
inline display{right, large, <FF5500/>}
```

**Έλεγχος μετά τη λήψη — `results{}`:**

| Appearance | Effect |
|---|---|
| `results{hide(capture)}` | Κρύβει το κουμπί εγγραφής μετά τη λήψη ήχου |
| `results{hide(review)}` | Κρύβει το κουμπί αναπαραγωγής |
| `results{hide(filename)}` | Κρύβει το όνομα αρχείου και τη διάρκεια |
| `results{left}` | Μετακινεί το εικονίδιο αριστερά μετά τη λήψη |

Παράδειγμα — κρύψτε το κουμπί εγγραφής μετά τη λήψη, διατηρήστε την αναπαραγωγή:
```
inline display{right} results{hide(capture)}
```

## Παράδειγμα χρήσης

### Με μέγιστη διάρκεια και υπόδειξη

| type | name | label | hint | parameters |
|------|------|-------|------|------------|
| audio | story | Πείτε μας για το περιστατικό με τα δικά σας λόγια | Μιλήστε καθαρά. Η εγγραφή σταματά μετά από 3 λεπτά. | `max-duration=180` |

### Δεσμευμένος ήχος — μόνο αν αναφέρθηκε κάποιο πρόβλημα

| type | name | label | relevant | required |
|------|------|-------|----------|----------|
| select_one yesno | issue_found | Βρέθηκε κάποιο πρόβλημα; | | |
| audio | issue_audio | Ηχογραφήστε μια περιγραφή του προβλήματος | `${issue_found} = 'yes'` | `${issue_found} = 'yes'` |

## Βέλτιστες πρακτικές

1. Αναφέρετε σαφώς στην `label` ή στην `hint` τι πρέπει να πει ο ερευνητής και για πόσο καιρό.
2. Χρησιμοποιήστε `max-duration` για να αποφύγετε υπερβολικά μεγάλα αρχεία σε περιοχές με αργές ταχύτητες μεταφόρτωσης.
3. Ενημερώστε τους ερωτώμενους πριν ξεκινήσετε την ηχογράφηση — η απροσδόκητη ηχογράφηση μπορεί να εγείρει ανησυχίες σχετικά με την ιδιωτικότητα.
4. Δοκιμάστε την εγγραφή στην συσκευή στόχο και στις συνθήκες δικτύου πριν την ανάπτυξη.
5. Ορίστε `quality=voice-only` για ηχογραφήσεις τύπου συνέντευξης για να μειώσετε το μέγεθος του αρχείου χωρίς απώλεια ευκρίνειας.

## Περιορισμοί

- Τα αρχεία ήχου μπορεί να είναι μεγάλα (μια εγγραφή 2 λεπτών σε κανονική ποιότητα είναι ~2–4 MB) — λάβετε αυτό υπόψη στον σχεδιασμό των δεδομένων σας και στις εκτιμήσεις χρόνου μεταφόρτωσης.
- Δεν υποστηρίζουν όλα τα προγράμματα περιήγησης το MediaRecorder API — το Chrome και ο Firefox λειτουργούν αξιόπιστα· το Safari σε παλαιότερες εκδόσεις iOS ενδέχεται να έχει προβλήματα.
- Η μεταγραφή των ηχητικών απαντήσεων απαιτεί πρόσθετη μετα-επεξεργασία (μη αυτόματη ή αυτοματοποιημένη μετατροπή ομιλίας σε κείμενο).
- Οι κανονισμοί απορρήτου ενδέχεται να περιορίζουν την ηχογράφηση φωνών — επαληθεύστε τις τοπικές απαιτήσεις προστασίας δεδομένων.

Ο τύπος ερώτησης `audio` επιτρέπει στους ερωτηθέντες να **ηχογραφήσουν ήχο** ή να ανεβάσουν ένα υπάρχον αρχείο ήχου ως μέρος της απάντησής τους στην έρευνα. Είναι χρήσιμος για την καταγραφή προφορικών αφηγήσεων, ήχων περιβάλλοντος, μαρτυριών ή οποιασδήποτε πληροφορίας που μεταφέρεται καλύτερα μέσω της φωνής παρά μέσω κειμένου.

## Βασικές Προδιαγραφές XLSForm

| type  | name        | label                        |
|-------|-------------|------------------------------|
| audio | voice_note  | Παρακαλώ ηχογραφήστε τα σχόλιά σας |

Για περισσότερες λεπτομέρειες σχετικά με τον τυπικό τύπο ερώτησης ήχου, δείτε τις [προδιαγραφές XLSForm](https://xlsform.org/en/#question-types).

## Χρήσεις

Οι ερωτήσεις ήχου χρησιμοποιούνται συνήθως για:

1. Καταγραφή προφορικών απαντήσεων ανοικτού τύπου για τη μείωση του φόρτου πληκτρολόγησης του ερευνητή
2. Ηχογράφηση μαρτυριών, προσωπικών ιστοριών ή προφορικών ιστοριών
3. Τεκμηρίωση ήχων περιβάλλοντος (π.χ. επίπεδα θορύβου κοντά σε υποδομές)
4. Συλλογή δειγμάτων φωνής για γλωσσολογική ή υγειονομική έρευνα
5. Δυνατότητα στους ερωτηθέντες να προσθέτουν προφορικές διευκρινίσεις σε αριθμητικές απαντήσεις ή απαντήσεις επιλογής

## Μορφή δεδομένων

Τα αρχεία ήχου αποθηκεύονται ως δυαδικά συνημμένα μαζί με την υποβολή της φόρμας, συνήθως:

- **Μορφή:** MP3 ή AAC (ηχογράφηση από κινητό), WAV (ηχογράφηση υψηλής ποιότητας)
- **Ονοματοδοσία:** `{instanceID}-{fieldname}.mp3` (ή αντίστοιχο)
- **Αποθήκευση:** Ανεβαίνουν στον φάκελο πολυμέσων του διακομιστή και συνδέονται με το αρχείο υποβολής
- **Πρόσβαση:** Δυνατότητα αναπαραγωγής και λήψης από τη διεπαφή διαχείρισης υποβολών

## Επεκτάσεις rtSurvey

### Μέγιστη διάρκεια

Χρησιμοποιήστε τη στήλη `parameters` για να περιορίσετε τη διάρκεια της ηχογράφησης:

| type | name | label | parameters |
|------|------|-------|------------|
| audio | interview | Ηχογραφήστε τη συνέντευξη | `max-duration=120` |

Η παράμετρος `max-duration` ορίζεται σε δευτερόλεπτα. Η ηχογράφηση σταματά αυτόματα στο όριο.

### Ρυθμίσεις ποιότητας

Η ποιότητα ηχογράφησης μπορεί να οριστεί μέσω της στήλης `parameters`:

| type | name | label | parameters |
|------|------|-------|------------|
| audio | feedback | Ηχογραφήστε σχόλια | `quality=normal` |

Υποστηριζόμενες τιμές: `low`, `normal` (προεπιλογή), `voice-only`. Η τιμή `voice-only` βελτιστοποιεί την ηχογράφηση ομιλίας με μείωση θορύβου.

### Αναπαραγωγή πριν από την υποβολή

Σε κινητές συσκευές, ο ερευνητής μπορεί να αναπαράγει το ηχογραφημένο κλιπ πριν προχωρήσει. Αυτό είναι ενεργοποιημένο από προεπιλογή — δεν απαιτείται ρύθμιση.

### Ενσωμάτωση εγγενούς εφαρμογής ηχογράφησης

Σε Android και iOS, η ερώτηση `audio` εκκινεί την εγγενή εφαρμογή ηχογράφησης της συσκευής. Στον ιστό, χρησιμοποιεί το ενσωματωμένο MediaRecorder API του προγράμματος περιήγησης.

### Διάταξη κουμπιού εντός γραμμής (Inline button layout)

Προσθέστε την εμφάνιση `inline` για να εμφανίσετε το μικρόφωνο ως ένα **κυκλικό κουμπί με εικονίδιο** δίπλα στην ετικέτα.

```
| type  | name | label        | appearance                    |
|-------|------|--------------|-------------------------------|
| audio | clip | Ηχογραφήστε ήχο | inline display{right}         |
| audio | clip | Ηχογραφήστε ήχο | inline display{left, large}   |
```

**Θέση κουμπιού** — `left`, `right` *(προεπιλογή)*, `top`, `center`, `bottom`

**Μέγεθος κουμπιού** — `small` *(προεπιλογή)*, `medium`, `large`

**Χρώμα κουμπιού** — προσθέστε έναν κωδικό χρώματος hex μέσα στο `display{}` για να αντικαταστήσετε το κύριο χρώμα:

```
inline display{right, large, <FF5500/>}
```

**Έλεγχος μετά την καταγραφή — `results{}`:**

| Appearance | Effect |
|---|---|
| `results{hide(capture)}` | Κρύβει το κουμπί ηχογράφησης μετά την καταγραφή του ήχου |
| `results{hide(review)}` | Κρύβει το κουμπί αναπαραγωγής |
| `results{hide(filename)}` | Κρύβει το όνομα αρχείου και τη διάρκεια |
| `results{left}` | Μετακινεί το εικονίδιο στα αριστερά μετά την καταγραφή |

Παράδειγμα — απόκρυψη κουμπιού ηχογράφησης μετά την καταγραφή, διατήρηση αναπαραγωγής:
```
inline display{right} results{hide(capture)}
```

## Παράδειγμα χρήσης

### Με μέγιστη διάρκεια και υπόδειξη

| type | name | label | hint | parameters |
|------|------|-------|------|------------|
| audio | story | Πείτε μας για το περιστατικό με δικά σας λόγια | Μιλήστε καθαρά. Η ηχογράφηση σταματά μετά από 3 λεπτά. | `max-duration=180` |

### Υπό συνθήκη ήχος — μόνο εάν αναφέρθηκε πρόβλημα

| type | name | label | relevant | required |
|------|------|-------|----------|----------|
| select_one yesno | issue_found | Βρέθηκε κάποιο πρόβλημα; | | |
| audio | issue_audio | Ηχογραφήστε μια περιγραφή του προβλήματος | `${issue_found} = 'yes'` | `${issue_found} = 'yes'` |

## Βέλτιστες Πρακτικές

1. Δηλώστε σαφώς στην ετικέτα (`label`) ή την υπόδειξη (`hint`) τι πρέπει να πει ο ερευνητής και για πόση ώρα.
2. Χρησιμοποιήστε το `max-duration` για να αποφύγετε υπερβολικά μεγάλα αρχεία σε περιοχές με αργές ταχύτητες μεταφόρτωσης.
3. Ενημερώστε τους ερωτηθέντες πριν ξεκινήσετε την ηχογράφηση — η απροσδόκητη ηχογράφηση μπορεί να εγείρει ανησυχίες για το απόρρητο.
4. Δοκιμάστε την ηχογράφηση στην επιλεγμένη συσκευή και υπό συνθήκες δικτύου πριν από την ανάπτυξη.
5. Ορίστε την παράμετρο `quality=voice-only` για ηχογραφήσεις τύπου συνέντευξης για να μειώσετε το μέγεθος του αρχείου χωρίς να χάσετε την ευκρίνεια.

## Περιορισμοί

- Τα αρχεία ήχου μπορεί να είναι μεγάλα (μια ηχογράφηση 2 λεπτών σε κανονική ποιότητα είναι περίπου 2–4 MB) — λάβετε το υπόψη στο πακέτο δεδομένων σας και στους εκτιμώμενους χρόνους μεταφόρτωσης.
- Δεν υποστηρίζουν όλα τα προγράμματα περιήγησης το MediaRecorder API — το Chrome και το Firefox λειτουργούν αξιόπιστα. Το Safari σε παλαιότερες εκδόσεις iOS ενδέχεται να έχει προβλήματα.
- Η απομαγνητοφώνηση των ηχητικών απαντήσεων απαιτεί πρόσθετη μετα-επεξεργασία (χειροκίνητη ή αυτοματοποιημένη μετατροπή ομιλίας σε κείμενο).
- Οι κανονισμοί περί απορρήτου ενδέχεται να περιορίζουν την ηχογράφηση φωνών — επαληθεύστε τις τοπικές απαιτήσεις προστασίας δεδομένων.

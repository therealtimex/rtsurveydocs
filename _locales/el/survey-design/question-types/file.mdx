Ο τύπος ερώτησης `file` επιτρέπει στους ερωτώμενους να **ανεβάζουν οποιοδήποτε αρχείο** από τη συσκευή τους — έγγραφα, υπολογιστικά φύλλα, PDF ή άλλους τύπους αρχείων. Σε αντίθεση με τις ερωτήσεις `image`, `audio` και `video` που εκκινούν συγκεκριμένα εργαλεία λήψης, η ερώτηση `file` ανοίγει έναν επιλογέα αρχείων γενικής χρήσης.

## Βασική προδιαγραφή XLSForm

| type | name      | label                        |
|------|-----------|------------------------------|
| file | document  | Παρακαλώ ανεβάστε το έγγραφό σας |

Για περισσότερες λεπτομέρειες σχετικά με τον τυπικό τύπο ερώτησης αρχείου, ανατρέξτε στην [προδιαγραφή XLSForm](https://xlsform.org/en/#question-types).

## Χρήσεις

Οι ερωτήσεις αρχείου χρησιμοποιούνται συνήθως για:

1. Συλλογή δικαιολογητικών (αποδείξεις, πιστοποιητικά, συμβάσεις, αναφορές)
2. Ανέβασμα συμπληρωμένων έντυπων φορμών που έχουν σκαναριστεί
3. Συγκέντρωση υπολογιστικών φύλλων ή εξαγωγών δεδομένων από άλλα συστήματα
4. Οποιοδήποτε ψηφιακό τύπο αρχείου που δεν καλύπτουν οι ερωτήσεις εικόνας/ήχου/βίντεο

## Μορφή δεδομένων

Τα αρχεία που ανεβαίνουν αποθηκεύονται ως δυαδικά συνημμένα (binary attachments):

- **Μορφή:** Διατηρείται στην αρχική μορφή (PDF, XLSX, DOCX κ.λπ.)
- **Ονοματοδοσία:** `{instanceID}-{fieldname}.{extension}`
- **Αποθήκευση:** Ανεβαίνουν στον φάκελο πολυμέσων του διακομιστή μαζί με την υποβολή
- **Πρόσβαση:** Δυνατότητα λήψης από τη διεπαφή διαχείρισης υποβολών

## Εκτάσεις rtSurvey

### Αποδεκτοί τύποι αρχείων

Χρησιμοποιήστε τη στήλη `parameters` για να περιορίσετε ποιους τύπους αρχείων μπορεί να επιλέξει ο χρήστης:

| type | name | label | parameters |
|------|------|-------|------------|
| file | report | Ανεβάστε την αναφορά επιθεώρησης | `accept=.pdf` |
| file | spreadsheet | Ανεβάστε το αρχείο δεδομένων | `accept=.xlsx,.csv` |

Η παράμετρος `accept` χρησιμοποιεί την τυπική σύνταξη επεκτάσεων αρχείων (διαχωρισμένες με κόμμα).

### Οδηγίες μεγέθους αρχείου

Το rtSurvey δεν επιβάλλει σκληρό όριο μεγέθους αρχείου στο επίπεδο της ερώτησης, αλλά ισχύει το όριο μεταφόρτωσης του διακομιστή. Χρησιμοποιήστε τη στήλη `hint` για να ενημερώσετε τον ερευνητή για τις προσδοκίες:

| type | name | label | hint |
|------|------|-------|------|
| file | receipt | Ανεβάστε την απόδειξη πληρωμής | Αποδεκτά: PDF ή εικόνα. Μέγιστο μέγεθος αρχείου: 5 MB |

### Ενοποίηση με το σύστημα αρχείων της συσκευής και την αποθήκευση στο cloud

Σε Android και iOS, η ερώτηση `file` ανοίγει τον εγγενή επιλογέα αρχείων της συσκευής, ο οποίος μπορεί να περιλαμβάνει πρόσβαση σε:
- Τοπικό αποθηκευτικό χώρο συσκευής
- Κάρτα SD (Android)
- iCloud Drive (iOS)
- Google Drive, Dropbox (εάν είναι εγκατεστημένα)

Στο διαδίκτυο (web), ανοίγει το τυπικό παράθυρο διαλόγου μεταφόρτωσης αρχείων του προγράμματος περιήγησης.

### Διάταξη ενσωματωμένου κουμπιού (Inline)

Προσθέστε το `inline` για να εμφανίσετε τη μεταφόρτωση ως **κυκλικό κουμπί εικονιδίου** δίπλα στην ετικέτα αντί για έναν επιλογέα αρχείων πλήρους πλάτους.

```
| type | name | label           | appearance                              |
|------|------|-----------------|-----------------------------------------|
| file | doc  | Ανέβασμα εγγράφου | inline display{right}                   |
| file | doc  | Ανέβασμα εγγράφου | inline display{left, large}             |
| file | doc  | Ανέβασμα εγγράφου | inline display{center, large, <0099FF/>} |
```

**Θέση κουμπιού** — `left`, `right` *(προεπιλογή)*, `top`, `center`, `bottom`

**Μέγεθος κουμπιού** — `small` *(προεπιλογή)*, `medium`, `large`

**Χρώμα κουμπιού** — προσθέστε ένα δεκαεξαδικό (hex) χρώμα μέσα στο `display{}` για να παρακάμψετε το κύριο χρώμα:

```
inline display{right, large, <FF5500/>}
```

**Έλεγχος μετά τη λήψη — `results{}`:**

| Appearance | Effect |
|---|---|
| `results{hide(capture)}` | Κρύβει το κουμπί μεταφόρτωσης αφού επισυναφθεί ένα αρχείο |
| `results{hide(review)}` | Κρύβει το κουμπί ελέγχου/προεπισκόπησης μετά το ανέβασμα |
| `results{hide(filename)}` | Κρύβει το όνομα αρχείου που εμφανίζεται μετά το ανέβασμα |
| `results{left}` | Μετακινεί το εικονίδιο στα αριστερά μετά το ανέβασμα |

Παράδειγμα — απόκρυψη κουμπιού μεταφόρτωσης μετά την επισύναψη αρχείου:
```
inline display{right} results{hide(capture)}
```

### Κατάργηση της ετικέτας

```
inline text-nolabel display{center, large}
```

## Παράδειγμα χρήσης

### Απαιτούμενο ανέβασμα PDF

| type | name | label | hint | required | required_message |
|------|------|-------|------|----------|-----------------|
| file | signed_consent | Ανεβάστε το υπογεγραμμένο έντυπο συγκατάθεσης | Μόνο PDF, μέγιστο 2MB | yes | Απαιτείται έντυπο συγκατάθεσης |

### Ανέβασμα εγγράφου υπό όρους

| type | name | label | relevant |
|------|------|-------|----------|
| select_one yesno | has_land_title | Διαθέτει το νοικοκυριό τίτλο ιδιοκτησίας γης; | |
| file | land_title_doc | Ανεβάστε μια φωτογραφία ή σάρωση του τίτλου ιδιοκτησίας | `${has_land_title} = 'yes'` |

## Βέλτιστες πρακτικές

1. Χρησιμοποιήστε το `accept` για να περιορίσετε τους τύπους αρχείων — αυτό εμποδίζει τους ερευνητές να ανεβάσουν κατά λάθος λάθος αρχεία.
2. Συμπεριλαμβάνετε πάντα οδηγίες μεγέθους και μορφής στη στήλη `hint`.
3. Για φωτογραφίες και εικόνες, χρησιμοποιήστε τον τύπο `image` αντ' αυτού — προσφέρει καλύτερη συμπίεση και συνεπή χειρισμό μορφής.
4. Για μεγάλες έρευνες με συνημμένα αρχεία, σχεδιάστε ανάλογα την αποθήκευση των δεδομένων σας και το εύρος ζώνης λήψης.
5. Δοκιμάστε τον επιλογέα αρχείων στον τύπο συσκευής-στόχου (Android έναντι iOS έναντι web) πριν από την ανάπτυξη — η πρόσβαση σε δίσκους cloud ποικίλλει.

## Σημειώσεις χειρισμού δεδομένων

- Τα αρχεία αποθηκεύονται στην αρχική τους μορφή. δεν μετατρέπονται ούτε συμπιέζονται από το rtSurvey.
- Αναλύστε τα αρχεία μετά τη λήψη — το rtSurvey δεν εξάγει ούτε ευρετηριάζει τα περιεχόμενα των αρχείων.
- Τα συνημμένα μεγάλα αρχεία αυξάνουν σημαντικά τον χρόνο που απαιτείται για τη λήψη ενός πλήρους συνόλου δεδομένων.

## Περιορισμοί

- Οι ερωτήσεις αρχείου δεν επικυρώνουν το περιεχόμενο των αρχείων — μόνο ο έλεγχος επέκτασης αρχείου μέσω του `accept` επιβάλλεται στο επίπεδο της διεπαφής χρήστη.
- Πολύ μεγάλα αρχεία (100 MB+) ενδέχεται να παρουσιάσουν λήξη χρόνου κατά τη μεταφόρτωση σε περιβάλλοντα με χαμηλή συνδεσιμότητα.
- Οι ερευνητές που βρίσκονται εκτός σύνδεσης μπορούν να επισυνάψουν αρχεία, αλλά αυτά δεν θα ανεβούν μέχρι να αποκατασταθεί η συνδεσιμότητα.
- Ορισμένες διαμορφώσεις συσκευών περιορίζουν την πρόσβαση σε συγκεκριμένες τοποθεσίες αποθήκευσης (π.χ. εταιρικές πολιτικές MDM).

Ο τύπος ερώτησης `file` επιτρέπει στους ερωτώμενους να **ανεβάζουν οποιοδήποτε αρχείο** από τη συσκευή τους — έγγραφα, υπολογιστικά φύλλα, PDF ή άλλους τύπους αρχείων. Σε αντίθεση με τους τύπους `image`, `audio` και `video` που εκκινούν συγκεκριμένα εργαλεία λήψης, ο τύπος `file` ανοίγει έναν γενικού σκοπού επιλογέα αρχείων.

## Βασική προδιαγραφή XLSForm

| type | name      | label                        |
|------|-----------|------------------------------|
| file | document  | Παρακαλώ ανεβάστε το έγγραφό σας  |

Για περισσότερες λεπτομέρειες σχετικά με τον τυπικό τύπο ερώτησης αρχείου, ανατρέξτε στην [προδιαγραφή XLSForm](https://xlsform.org/en/#question-types).

## Χρήσεις

Οι ερωτήσεις αρχείου χρησιμοποιούνται συνήθως για:

1. Συλλογή υποστηρικτικών εγγράφων (αποδείξεις, πιστοποιητικά, συμβάσεις, αναφορές)
2. Ανέβασμα συμπληρωμένων εντύπων που έχουν σαρωθεί
3. Συλλογή υπολογιστικών φύλλων ή εξαγωγών δεδομένων από άλλα συστήματα
4. Οποιοσδήποτε τύπος ψηφιακού αρχείου που δεν καλύπτεται από εικόνες/ήχους/βίντεο

## Μορφή δεδομένων

Τα μεταφορτωμένα αρχεία αποθηκεύονται ως δυαδικά συνημμένα:

- **Μορφή:** Διατηρείται στην αρχική μορφή (PDF, XLSX, DOCX, κ.λπ.)
- **Ονομασία:** `{instanceID}-{fieldname}.{extension}`
- **Αποθήκευση:** Μεταφορτώνονται στον φάκελο πολυμέσων του διακομιστή μαζί με την υποβολή
- **Πρόσβαση:** Λήψη από τη διεπαφή διαχείρισης υποβολών

## Επεκτάσεις rtSurvey

### Αποδεκτοί τύποι αρχείων

Χρησιμοποιήστε τη στήλη `parameters` για να περιορίσετε ποιους τύπους αρχείων μπορούν να επιλεγούν:

| type | name | label | parameters |
|------|------|-------|------------|
| file | report | Ανεβάστε την έκθεση επιθεώρησης | `accept=.pdf` |
| file | spreadsheet | Ανεβάστε το αρχείο δεδομένων | `accept=.xlsx,.csv` |

Η παράμετρος `accept` χρησιμοποιεί την τυπική σύνταξη επέκτασης αρχείου (διαχωρισμένη με κόμμα).

### Οδηγίες μεγέθους αρχείου

Το rtSurvey δεν επιβάλλει σκληρό όριο μεγέθους αρχείου σε επίπεδο ερώτησης, αλλά ισχύει το όριο μεταφόρτωσης του διακομιστή. Χρησιμοποιήστε `hint` για να επικοινωνήσετε τις προσδοκίες στον ερευνητή:

| type | name | label | hint |
|------|------|-------|------|
| file | receipt | Ανεβάστε την απόδειξη πληρωμής | Αποδεκτά: PDF ή εικόνα. Μέγιστο μέγεθος αρχείου: 5 MB |

### Ενσωμάτωση με το σύστημα αρχείων της συσκευής και αποθήκευση στο cloud

Σε Android και iOS, η ερώτηση `file` ανοίγει τον εγγενή επιλογέα αρχείων της συσκευής, ο οποίος μπορεί να περιλαμβάνει πρόσβαση σε:
- Τοπική αποθήκευση συσκευής
- Κάρτα SD (Android)
- iCloud Drive (iOS)
- Google Drive, Dropbox (εάν είναι εγκατεστημένα)

Στον ιστό, ανοίγει τον τυπικό διάλογο μεταφόρτωσης αρχείων του προγράμματος περιήγησης.

### Διάταξη κουμπιών σε σειρά

Προσθέστε `inline` για να εμφανίσετε την μεταφόρτωση ως **κυκλικό κουμπί εικονιδίου** δίπλα στην ετικέτα αντί για έναν επιλογέα αρχείων πλήρους πλάτους.

```
| type | name | label           | appearance                              |
|------|------|-----------------|-----------------------------------------|
| file | doc  | Ανέβασμα εγγράφου | inline display{right}                   |
| file | doc  | Ανέβασμα εγγράφου | inline display{left, large}             |
| file | doc  | Ανέβασμα εγγράφου | inline display{center, large, <0099FF/>} |
```

**Θέση κουμπιού** — `left`, `right` *(προεπιλογή)*, `top`, `center`, `bottom`

**Μέγεθος κουμπιού** — `small` *(προεπιλογή)*, `medium`, `large`

**Χρώμα κουμπιού** — προσθέστε ένα δεκαεξαδικό χρώμα μέσα στο `display{}` για να παρακάμψετε το κύριο χρώμα:

```
inline display{right, large, <FF5500/>}
```

**Έλεγχος μετά τη λήψη — `results{}`:**

| Appearance | Effect |
|---|---|
| `results{hide(capture)}` | Κρύβει το κουμπί μεταφόρτωσης μετά την επισύναψη αρχείου |
| `results{hide(review)}` | Κρύβει το κουμπί επανεξέτασης/προεπισκόπησης μετά την μεταφόρτωση |
| `results{hide(filename)}` | Κρύβει το όνομα αρχείου που εμφανίζεται μετά την μεταφόρτωση |
| `results{left}` | Μετακινεί το εικονίδιο αριστερά μετά την μεταφόρτωση |

Παράδειγμα — κρύψτε το κουμπί μεταφόρτωσης μετά την επισύναψη αρχείου:
```
inline display{right} results{hide(capture)}
```

### Καταστολή της ετικέτας

```
inline text-nolabel display{center, large}
```

## Παράδειγμα χρήσης

### Απαιτούμενη μεταφόρτωση PDF

| type | name | label | hint | required | required_message |
|------|------|-------|------|----------|-----------------|
| file | signed_consent | Ανεβάστε τη φόρμα συγκατάθεσης με υπογραφή | Μόνο PDF, μέγ. 2MB | yes | Απαιτείται φόρμα συγκατάθεσης |

### Προαιρετική μεταφόρτωση εγγράφου

| type | name | label | relevant |
|------|------|-------|----------|
| select_one yesno | has_land_title | Διαθέτει το νοικοκυριό τίτλο ιδιοκτησίας; | |
| file | land_title_doc | Ανεβάστε μια φωτογραφία ή σάρωση του τίτλου ιδιοκτησίας | `${has_land_title} = 'yes'` |

## Βέλτιστες πρακτικές

1. Χρησιμοποιήστε `accept` για να περιορίσετε τους τύπους αρχείων — αυτό αποτρέπει τους ερευνητές από το να ανεβάζουν κατά λάθος λάθος αρχεία.
2. Πάντα να συμπεριλαμβάνετε οδηγίες μεγέθους και μορφής στη στήλη `hint`.
3. Για φωτογραφίες και εικόνες, χρησιμοποιήστε τον τύπο `image` — προσφέρει καλύτερη συμπίεση και συνεπή χειρισμό μορφής.
4. Για μεγάλες έρευνες με συνημμένα αρχεία, σχεδιάστε ανάλογα την αποθήκευση δεδομένων και το εύρος ζώνης λήψης.
5. Δοκιμάστε τον επιλογέα αρχείων στον τύπο συσκευής στόχο (Android έναντι iOS έναντι web) πριν την ανάπτυξη — η πρόσβαση σε cloud drives ποικίλλει.

## Θέματα χειρισμού δεδομένων

- Τα αρχεία αποθηκεύονται στην αρχική τους μορφή· δεν μετατρέπονται ή συμπιέζονται από το rtSurvey.
- Αναλύστε τα αρχεία μετά τη λήψη — το rtSurvey δεν εξάγει ή ευρετηριάζει περιεχόμενα αρχείων.
- Τα μεγάλα συνημμένα αρχεία αυξάνουν σημαντικά τον απαιτούμενο χρόνο για τη λήψη ενός πλήρους συνόλου δεδομένων.

## Περιορισμοί

- Οι ερωτήσεις αρχείου δεν επικυρώνουν τα περιεχόμενα των αρχείων — μόνο ο έλεγχος επέκτασης αρχείου μέσω `accept` επιβάλλεται σε επίπεδο διεπαφής χρήστη.
- Πολύ μεγάλα αρχεία (100 MB+) ενδέχεται να λήξουν κατά τη μεταφόρτωση σε περιβάλλοντα χαμηλής συνδεσιμότητας.
- Οι εκτός σύνδεσης ερευνητές μπορούν να επισυνάψουν αρχεία αλλά δεν θα μεταφορτωθούν μέχρι να αποκατασταθεί η συνδεσιμότητα.
- Ορισμένες διαμορφώσεις συσκευών περιορίζουν την πρόσβαση σε ορισμένες τοποθεσίες αποθήκευσης (π.χ. πολιτικές MDM εταιρειών).

Ο τύπος ερώτησης εικόνας σε XLSForms και rtSurvey επιτρέπει στους ερωτώμενους να τραβήξουν και να υποβάλουν φωτογραφίες ως μέρος των απαντήσεών τους στην έρευνα. Αυτή η λειτουργία είναι ιδιαίτερα χρήσιμη για τη συλλογή οπτικών δεδομένων, την τεκμηρίωση παρατηρήσεων ή την παροχή αποδεικτικών στοιχείων σε έρευνες πεδίου.

## Βασική προδιαγραφή XLSForm

| type  | name        | label                           |
|-------|-------------|--------------------------------|
| image | photo       | Τραβήξτε μια φωτογραφία της τοποθεσίας |

Για περισσότερες λεπτομέρειες σχετικά με τον βασικό τύπο ερώτησης εικόνας, ανατρέξτε στην [προδιαγραφή XLSForm](https://xlsform.org/en/#question-types).

## Χρήσεις

Οι ερωτήσεις εικόνας χρησιμοποιούνται συνήθως για:

1.  Τεκμηρίωση συνθηκών πεδίου ή παρατηρήσεων
2.  Συλλογή οπτικών αποδεικτικών στοιχείων σε ερευνητικές μελέτες
3.  Συλλογή φωτογραφιών πριν και μετά σε αξιολογήσεις επιπτώσεων
4.  Επαλήθευση ολοκλήρωσης εργασιών ή παρουσίας σε τοποθεσίες
5.  Συλλογή οπτικών δεδομένων για απομακρυσμένη ανάλυση

## Βέλτιστες πρακτικές

1.  Παρέχετε σαφείς οδηγίες για το τι πρέπει να φωτογραφηθεί.
2.  Λάβετε υπόψη τις επιπτώσεις στην ιδιωτική ζωή και ενημερώστε τους ερωτώμενους για το πώς θα χρησιμοποιηθούν οι φωτογραφίες τους.
3.  Λάβετε υπόψη το μέγεθος των αρχείων και τους περιορισμούς αποθήκευσης, ειδικά για έρευνες σε περιοχές με περιορισμένη συνδεσιμότητα στο διαδίκτυο.
4.  Βεβαιωθείτε ότι η συσκευή διαθέτει επαρκή χώρο αποθήκευσης και ότι έχουν χορηγηθεί οι άδειες κάμερας.

## Παράδειγμα χρήσης

Ακολουθεί ένα παράδειγμα για το πώς μπορείτε να χρησιμοποιήσετε μια ερώτηση εικόνας σε μια έρευνα:

| type  | name           | label                                      | hint                                        |
|-------|----------------|--------------------------------------------|--------------------------------------------|
| image | storefront     | Τραβήξτε μια φωτογραφία της εισόδου του καταστήματος | Βεβαιωθείτε ότι το όνομα του καταστήματος είναι σαφώς ορατό |

## επεκτάσεις rtSurvey

### Διάταξη κουμπιού ενσωμάτωσης

Προσθέστε `inline` στη στήλη `appearance` για να εμφανίσετε την κάμερα ως **κυκλικό κουμπί εικονιδίου** δίπλα στην ετικέτα αντί για μια περιοχή λήψης πλήρους πλάτους. Πατώντας το ανοίγει ένα αναδυόμενο παράθυρο.

```
| type  | name  | label        | appearance                          |
|-------|-------|--------------|-------------------------------------|
| image | photo | Τραβήξτε μια φωτογραφία | inline display{right}               |
| image | photo | Τραβήξτε μια φωτογραφία | inline display{center, large}       |
```

**Θέση κουμπιού — `display{}`:**

| Value | Layout |
|-------|--------|
| `right` *(προεπιλογή)* | Εικονίδιο δεξιά της ετικέτας |
| `left` | Εικονίδιο αριστερά της ετικέτας |
| `top` | Εικονίδιο πάνω από την ετικέτα, κεντραρισμένο |
| `center` / `bottom` | Εικονίδιο κάτω από την ετικέτα, κεντραρισμένο |

**Μέγεθος κουμπιού:**

| Value | Size |
|-------|------|
| `small` *(προεπιλογή)* | Μικρός κύκλος |
| `medium` | Μεσαίος κύκλος |
| `large` | Μεγάλος κύκλος |

**Χρώμα κουμπιού** — προσθέστε ένα δεκαεξαδικό χρώμα μέσα στο `display{}` για να παρακάμψετε το κύριο χρώμα:

```
inline display{right, large, <FF5500/>}
inline display{center, medium, <0099FF/>}
```

**Έλεγχος μετά τη λήψη — `results{}`:**

| Appearance | Effect |
|---|---|
| `results{hide(capture)}` | Κρύβει το κουμπί της κάμερας μετά τη λήψη φωτογραφίας |
| `results{hide(camera)}` | Ίδιο με `hide(capture)` — ψευδώνυμο για τον τύπο εικόνας |
| `results{hide(review)}` | Κρύβει την προεπισκόπηση μικρογραφίας μετά τη λήψη |
| `results{hide(filename)}` | Κρύβει το όνομα αρχείου που εμφανίζεται μετά την αποστολή |
| `results{left}` | Μετακινεί το εικονίδιο αριστερά μετά τη λήψη |

Παράδειγμα — μεγάλο κεντραρισμένο κουμπί, κρύψτε την κάμερα μετά τη λήψη:
```
inline display{center, large} results{hide(capture)}
```

### `invisible auto-show` — αυτόματη εκκίνηση κάμερας

Κρύβει το widget ερώτησης από τη διάταξη, αλλά ανοίγει αυτόματα την κάμερα όταν φορτώνεται η σελίδα. Χρήσιμο για την ενσωμάτωση ενός βήματος σιωπηλής λήψης σε μια ροή φόρμας.

```
invisible auto-show
inline invisible auto-show
```

### Υπογραφή και σχέδιο

| Appearance | Description |
|---|---|
| `signature` | Πλήρης οθόνη αναδυόμενο παράθυρο υπογραφής |
| `signature display{quick}` | Ενσωματωμένο αναδυόμενο παράθυρο γρήγορης σχεδίασης υπογραφής — χωρίς αναδυόμενο παράθυρο |
| `draw` | Καμβάς ελεύθερης σχεδίασης |

### Υδατογράφημα

Προσθέστε ένα υδατογράφημα κειμένου ή εικόνας στις ληφθείσες φωτογραφίες:

```
watermark(text, "Survey ID: ${id}", bottom-right, 0.5)
watermark(file, logo.png, top-left, 1.0, 20%)
```

### Κατάργηση της ετικέτας

```
inline text-nolabel display{center, large}
```

## Χειρισμός δεδομένων

Οι εικόνες που συλλέγονται μέσω αυτού του τύπου ερώτησης είναι συνήθως:

1.  Αποθηκεύονται σε μια κοινή μορφή εικόνας (π.χ. JPG, PNG)
2.  Αποθηκεύονται μαζί με άλλα δεδομένα έρευνας, συχνά σε έναν ξεχωριστό φάκελο πολυμέσων
3.  Προσβάσιμα για προβολή και ανάλυση μέσω της πλατφόρμας διαχείρισης έρευνας

## Ζητήματα για ανάλυση

Όταν χρησιμοποιείτε ερωτήσεις εικόνας, λάβετε υπόψη:

1.  Πώς θα αναλυθούν οι εικόνες (π.χ. μη αυτόματη αναθεώρηση, αυτοματοποιημένη ανάλυση εικόνας)
2.  Τον πρόσθετο χώρο αποθήκευσης που απαιτείται για αρχεία εικόνων
3.  Μέτρα προστασίας της ιδιωτικής ζωής και των δεδομένων για την αποθήκευση και τον χειρισμό φωτογραφιών
4.  Πιθανή ανάγκη για εργαλεία επεξεργασίας ή οργάνωσης εικόνων στη φάση ανάλυσης

## Περιορισμοί

-   Τα αρχεία εικόνων μπορεί να είναι μεγάλα, γεγονός που μπορεί να επηρεάσει τη μεταφορά δεδομένων και την αποθήκευση.
-   Δεν είναι όλες οι συσκευές πιθανό να διαθέτουν κάμερες υψηλής ποιότητας ή επαρκή χώρο αποθήκευσης.
-   Η ανάλυση μεγάλου αριθμού εικόνων μπορεί να είναι χρονοβόρα.
-   Ενδέχεται να υπάρχουν ανησυχίες για την ιδιωτική ζωή κατά τη λήψη εικόνων, ειδικά σε δημόσιους χώρους.

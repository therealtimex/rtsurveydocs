---

Ο τύπος ερώτησης `range` επιτρέπει στους ερωτώμενους να επιλέξουν έναν αριθμό εντός ενός καθορισμένου ελάχιστου και μέγιστου. Στην εφαρμογή ιστού του rtSurvey, αυτό εμφανίζεται ως μια τυπική **εισαγωγή αριθμού** — ο καταμετρητής πληκτρολογεί μια τιμή απευθείας. Οι παράμετροι `start`, `end` και `step` ορίζουν το έγκυρο εύρος και επιβάλλονται ως περιορισμοί.

## Βασική προδιαγραφή XLSForm

| type | name | label | parameters |
|------|------|-------|------------|
| range | satisfaction | Πόσο ικανοποιημένοι είστε με την υπηρεσία; | start=1 end=5 step=1 |

Η στήλη `parameters` ορίζει τα όρια του ρυθμιστικού και το μέγεθος του βήματος:

| Parameter | Description | Default |
|-----------|-------------|---------|
| `start` | Ελάχιστη τιμή (συμπεριλαμβανομένη) | 0 |
| `end` | Μέγιστη τιμή (συμπεριλαμβανομένη) | 10 |
| `step` | Αύξηση μεταξύ έγκυρων τιμών | 1 |

Για περισσότερες λεπτομέρειες σχετικά με τον τυπικό τύπο ερώτησης εύρους, ανατρέξτε στην [προδιαγραφή XLSForm](https://xlsform.org/en/#question-types).

## Χρήσεις

Οι ερωτήσεις εύρους χρησιμοποιούνται συνήθως για:

1.  Κλίμακες ικανοποίησης ή αξιολόγησης (π.χ. 1–5 ή 0–10)
2.  Αριθμητικές κλίμακες τύπου Likert
3.  Συλλογή μετρήσεων όπου μόνο διακριτές τιμές είναι έγκυρες
4.  Ηλικιακές ομάδες ή εύρη βαθμολογίας όπου ένα ρυθμιστικό βελτιώνει τη χρηστικότητα έναντι ενός πεδίου κειμένου

## Παράδειγμα χρήσης

### Βασική κλίμακα αξιολόγησης

| type | name | label | parameters |
|------|------|-------|------------|
| range | overall_rating | Συνολική βαθμολογία (0–10) | start=0 end=10 step=1 |

### Δεκαδικό βήμα

| type | name | label | parameters |
|------|------|-------|------------|
| range | weight_kg | Βάρος (kg) | start=0 end=200 step=0.5 |

### Χρήση της τιμής σε υπολογισμό

| type | name | label | parameters | calculation |
|------|------|-------|------------|-------------|
| range | score | Βαθμολογία τεστ (0–100) | start=0 end=100 step=5 | |
| calculate | grade | | | if(`${score}` >= 90, 'A', if(`${score}` >= 80, 'B', if(`${score}` >= 70, 'C', 'F'))) |
| note | grade_note | Ο βαθμός σας είναι: `${grade}` | | |

## Βέλτιστες πρακτικές

1.  Πάντα να ορίζετε σημαντικές τιμές `start`, `end` και `step` — μην βασίζεστε στις προεπιλογές.
2.  Επισημάνετε τα άκρα της κλίμακάς σας στη στήλη `hint` (π.χ. `hint: 0 = Πολύ δυσαρεστημένος, 10 = Πολύ ικανοποιημένος`) για να δώσετε στους ερωτώμενους πλαίσιο.
3.  Για κλίμακες Likert 5 βαθμών, χρησιμοποιήστε `start=1 end=5 step=1` αντί για 0–4, καθώς οι ερωτώμενοι αναμένουν ότι το "1" σημαίνει το χαμηλότερο.
4.  Χρησιμοποιήστε `range` αντί για `integer` + περιορισμός όταν η οριοθετημένη φύση της εισόδου αποτελεί μέρος του σχεδιασμού της ερώτησης (το ρυθμιστικό επικοινωνεί οπτικά την κλίμακα).

## Περιορισμοί

-   Δεν υπάρχει widget ρυθμιστικού στην εφαρμογή ιστού του rtSurvey — η εισαγωγή τιμής είναι μια απλή εισαγωγή αριθμού. Για μια οπτική εμπειρία ρυθμιστικού, χρησιμοποιήστε έναν κινητό πελάτη που υποστηρίζει το widget εύρους.
-   Για πολύ μεγάλα εύρη (π.χ. 0–10000), ένας απλός `integer` με περιορισμό είναι εξίσου αποτελεσματικός και πιο φιλικός προς τον χρήστη.
-   Οι τιμές λεπτών βημάτων (π.χ. `step=0.1`) λειτουργούν ως περιορισμοί, αλλά δεν υπάρχει ανησυχία για την ακρίβεια του ρυθμιστικού στην εφαρμογή ιστού.

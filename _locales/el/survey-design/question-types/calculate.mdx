Ο τύπος ερώτησης `calculate` εκτελεί έναν τύπο αθόρυβα στο παρασκήνιο. Αποθηκεύει το αποτέλεσμα σε ένα ονομασμένο πεδίο στο οποίο μπορούν να αναφέρονται άλλες ερωτήσεις — αλλά δεν εμφανίζει καμία εισαγωγή ή ετικέτα στον απογραφέα. Χρησιμοποιήστε το για να αντλήσετε τιμές, να συνενώσετε συμβολοσειρές, να εκτελέσετε λογική υπό όρους ή να αναζητήσετε δεδομένα που θα χρειαστείτε αργότερα στη φόρμα.

---

## Βασική σύνταξη

| type | name | label | calculation |
|------|------|-------|-------------|
| calculate | total | | `${price} * ${quantity}` |

- **type**: Πάντα `calculate`.
- **name**: Ένα μοναδικό όνομα πεδίου. Άλλες ερωτήσεις αναφέρονται σε αυτό με `${name}`.
- **label**: Αφήστε το κενό — τα πεδία calculate δεν εμφανίζονται ποτέ στον απογραφέα.
- **calculation**: Ο τύπος προς αξιολόγηση. Υποστηρίζει όλες τις [συναρτήσεις XLSForm](../operators-and-functions/functions) και αναφορές πεδίων.

---

## Κοινά μοτίβα

### Αριθμητική

| type | name | label | calculation |
|------|------|-------|-------------|
| integer | price | Unit price | |
| integer | quantity | Quantity | |
| calculate | total | | `${price} * ${quantity}` |
| note | total_note | Total: `${total}` | |

### Συνένωση συμβολοσειρών (String concatenation)

| type | name | label | calculation |
|------|------|-------|-------------|
| text | first_name | First name | |
| text | last_name | Last name | |
| calculate | full_name | | `concat(${first_name}, ' ', ${last_name})` |

### Τιμή υπό όρους

| type | name | label | calculation |
|------|------|-------|-------------|
| integer | score | Score (0–100) | |
| calculate | grade | | `if(${score} >= 90, 'A', if(${score} >= 75, 'B', if(${score} >= 60, 'C', 'F')))` |

### Ηλικία από ημερομηνία γέννησης

| type | name | label | calculation |
|------|------|-------|-------------|
| date | dob | Date of birth | |
| calculate | age_years | | `int((today() - ${dob}) div 365.25)` |

## Χρήση του `once()` για το "κλείδωμα" της τιμής

Από προεπιλογή, το `calculate` επαναξιολογείται κάθε φορά που αλλάζει οποιοδήποτε πεδίο αναφοράς. Τυλίξτε τον τύπο στο `once()` για να αξιολογηθεί μόνο κατά την πρώτη φόρτωση και να "παγώσει" το αποτέλεσμα:

| type | name | label | calculation |
|------|------|-------|-------------|
| calculate | interview_start | | `once(now())` |

Χρησιμοποιήστε το `once()` για χρονοσήμανση, αρχικές τιμές ή οποιαδήποτε περίπτωση όπου ο επανυπολογισμός κατά την αλλαγή είναι ανεπιθύμητος.

## Άντληση δεδομένων από εξωτερικές πηγές

### Από αρχείο CSV

```
pulldata('staff.csv', 'department', 'name', ${staff_id})
```

Δείτε το [pulldata()](../operators-and-functions/pulldata) για την πλήρη αναφορά.

### Από μια ενσωματωμένη βάση δεδομένων SQLite

```
pulldata('rawquery',
  concat(${family_path}, '/locations.db::provinces'),
  'SELECT name FROM provinces WHERE id = ?',
  ${province_id})
```

Δείτε την [Αναζήτηση σε τοπική βάση δεδομένων](../advanced-features/local-database-search) για λεπτομέρειες κατασκευής διαδρομής.

### Από το πλαίσιο της εφαρμογής (App context)

```
pulldata('app-api', 'user.username')
pulldata('app-api', 'family_path')
```

Δείτε το [App API](../app-api) για όλα τα διαθέσιμα κλειδιά.

## Χρήση του calculate σε relevant και constraint

Άλλα πεδία μπορούν να αναφέρονται σε ένα αποτέλεσμα `calculate` ακριβώς όπως σε οποιοδήποτε πεδίο:

| type | name | label | relevant | constraint |
|------|------|-------|----------|------------|
| calculate | bmi | | | `${weight} div (${height} * ${height}) * 10000` |
| note | bmi_warning | BMI is very high — please verify weight and height. | `${bmi} > 40` | |

## Βέλτιστες πρακτικές

1. Δώστε στα πεδία calculate περιγραφικά ονόματα — το `total_cost` είναι πιο σαφές από το `calc1` και ευκολότερο να εντοπιστεί στις εξαγωγές.
2. Σπάστε τους σύνθετους τύπους σε πολλαπλά αλυσιδωτά πεδία calculate αντί για μία βαθιά εμφωλευμένη έκφραση.
3. Χρησιμοποιήστε το `once()` για χρονοσήμανση και αρχικά στιγμιότυπα για να αποτρέψετε την αλλαγή των τιμών μετά την πρώτη λήψη.
4. Τοποθετήστε τα πεδία `calculate` πριν από την πρώτη ερώτηση που αναφέρεται σε αυτά — η σειρά αξιολόγησης ακολουθεί τη σειρά της φόρμας.
5. Διατηρήστε τη στήλη `label` κενή. Ορισμένα εργαλεία εμφανίζουν την ετικέτα. αφήνοντάς την κενή αποφεύγεται η σύγχυση στην έξοδο.

## Περιορισμοί

- Τα πεδία Calculate δεν εμφανίζονται ποτέ απευθείας στον απογραφέα — χρησιμοποιήστε ένα πεδίο `note` για να δείξετε το αποτέλεσμα.
- Η στήλη `calculation` είναι υποχρεωτική. μια σειρά `calculate` χωρίς τύπο αποθηκεύει πάντα μια κενή συμβολοσειρά.
- Τα αποτελέσματα επαναξιολογούνται σε κάθε αλλαγή φόρμας, εκτός εάν περιλαμβάνονται στο `once()` — πολύ περίπλοκοι τύποι σε μεγάλες φόρμες μπορεί να επηρεάσουν την απόδοση απόδοσης σε συσκευές χαμηλών προδιαγραφών.
- Οι υπολογισμένες τιμές αποθηκεύονται ως συμβολοσειρές στην υποβολή. Χρησιμοποιήστε `number()`, `int()` ή `boolean()` για μετατροπή τύπου κατά τη μεταβίβαση του αποτελέσματος σε αριθμητικές ή λογικές εκφράσεις.

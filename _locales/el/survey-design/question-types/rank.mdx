---

Ο τύπος ερώτησης `rank` παρουσιάζει μια λίστα επιλογών που ο ερωτώμενος ταξινομεί κατά προτίμηση ή προτεραιότητα. Αποθηκεύει το αποτέλεσμα ως μια λίστα τιμών επιλογών χωρισμένη με κενά σε ταξινομημένη σειρά, με την επιλογή υψηλότερης προτεραιότητας πρώτη.

> **rtSurvey web form:** Το widget μεταφοράς για κατάταξη δεν έχει υλοποιηθεί επί του παρόντος. Στη φόρμα ιστού, το `rank` αποδίδεται ως μια λίστα επιλογών. Χρησιμοποιήστε αυτόν τον τύπο όταν στοχεύετε πελάτες κινητών που υποστηρίζουν το widget κατάταξης ή όταν η μορφή της αποθηκευμένης τιμής είναι πιο σημαντική από την αλληλεπίδραση μεταφοράς για ταξινόμηση.

## Μορφή αποθηκευμένης τιμής

Η αποθηκευμένη τιμή είναι μια **λίστα χωρισμένη με κενά** των τιμών επιλογής σε ταξινομημένη σειρά (πρώτη = υψηλότερη προτεραιότητα):

```
water education health roads electricity
```

## Εξαγωγή ταξινομημένων θέσεων

Χρησιμοποιήστε το `selected-at()` για να λάβετε την επιλογή σε μια συγκεκριμένη κατάταξη:

| type | name | label | calculation |
|------|------|-------|-------------|
| rank priorities | main_priority | Κατάταξη κοινοτικών αναγκών | |
| calculate | top_priority | | selected-at(`${main_priority}`, 0) |
| calculate | second_priority | | selected-at(`${main_priority}`, 1) |

Το `selected-at(${main_priority}, 0)` επιστρέφει την τιμή που τοποθετήθηκε **πρώτη** (δείκτης 0 = κορυφαία κατάταξη).

## Χρήση του `rank-index()` με επαναλαμβανόμενες ομάδες

Όταν το `rank` χρησιμοποιείται μέσα σε μια επαναλαμβανόμενη ομάδα, το `rank-index()` σας επιτρέπει να αναφέρετε την ταξινομημένη σειρά από έξω από την επανάληψη:

| type | name | label | calculation |
|------|------|-------|-------------|
| calculate | first_ranked | | rank-index(1, `${score}`) |

Δείτε [Συναρτήσεις — Συναρτήσεις επαναλαμβανόμενων πεδίων](../operators-and-functions/functions#repeated-field-functions) για πλήρεις λεπτομέρειες σχετικά με τα `rank-index()` και `rank-index-if()`.

## Χρήσεις

Οι ερωτήσεις κατάταξης χρησιμοποιούνται συνήθως για:

1.  **Κατάταξη προτεραιοτήτων** — ζητώντας από τις κοινότητες να ταξινομήσουν τις αναπτυξιακές ανάγκες
2.  **Ταξινόμηση προτιμήσεων** — κατάταξη χαρακτηριστικών προϊόντων, ιδιοτήτων υπηρεσιών ή επιλογών πολιτικής
3.  **Ταξινόμηση στοιχείων εξέτασης** — διάταξη βημάτων σε μια διαδικασία
4.  **Επιλογή Top-N** — σε συνδυασμό με το `selected-at()` για την εξαγωγή μόνο των κορυφαίων 1, 2 ή 3 επιλογών

## Βέλτιστες πρακτικές

1.  Κρατήστε τη λίστα σύντομη (3–7 στοιχεία) — η κατάταξη γίνεται γνωστικά επίπονη πέραν των 7–8 επιλογών.
2.  Χρησιμοποιήστε σαφείς, αμοιβαία αποκλειόμενες ετικέτες επιλογών για να αποφύγετε τη σύγχυση σχετικά με το τι σημαίνει "πρώτο".
3.  Προσθέστε κείμενο υπόδειξης που εξηγεί την κατεύθυνση κατάταξης (π.χ. "Σύρετε για ταξινόμηση: πρώτο = πιο σημαντικό").
4.  Επικυρώστε χρησιμοποιώντας `count-selected(.) = x` εάν πρέπει να διασφαλίσετε ότι όλες οι επιλογές ταξινομούνται.

## Περιορισμοί

-   Το widget μεταφοράς για κατάταξη δεν έχει υλοποιηθεί στη φόρμα ιστού rtSurvey.
-   Δεν μπορείτε να ταξινομήσετε μερικώς — όλες οι επιλογές πρέπει να ταξινομηθούν.
-   Κρατήστε τις λίστες σε 3–7 στοιχεία. Μεγαλύτερες λίστες γίνονται δυσκίνητες ανεξάρτητα από τον πελάτη.

Οι τύποι ερώτησης `date`, `time` και `datetime` καταγράφουν τιμές ημερομηνίας και/ή ώρας. Το rtSurvey τις αποδίδει με διάφορους τρόπους διάταξης που ελέγχονται από τη στήλη `appearance`.

## Βασική προδιαγραφή XLSForm

| type     | name           | label                     |
|----------|----------------|---------------------------|
| date     | birth_date     | Ημερομηνία γέννησης       |
| time     | start_time     | Τι ώρα ξεκίνησε;         |
| datetime | event_datetime | Πότε συνέβη το γεγονός;   |

Για την τυπική προδιαγραφή δείτε την [τεκμηρίωση XLSForm](https://xlsform.org/en/#question-types).

## Λειτουργίες διάταξης

### Προεπιλογή — πάντα ανοιχτό ημερολόγιο

Δεν απαιτείται τιμή εμφάνισης. Το ημερολόγιο (και το ρολόι για `time`/`datetime`) εμφανίζεται απευθείας στη σελίδα — πάντα ορατό, δεν απαιτείται κουμπί.

| type | name       | label         | appearance |
|------|------------|---------------|------------|
| date | start_date | Ημερομηνία επίσκεψης |            |

---

### `inline` — κυκλικό κουμπί → modal

Ένα κυκλικό κουμπί εικονιδίου (ημερολόγιο ή ρολόι) επιπλέει δίπλα στην ετικέτα της ερώτησης. Πατώντας το, ανοίγει ένα modal με την επιλογή. Μετά την επιλογή, η επιλεγμένη τιμή εμφανίζεται ως κείμενο δίπλα στην ετικέτα.

- Φόντο κουμπιού: κύριο χρώμα θέματος (με δυνατότητα υπερκάλυψης)
- Σχήμα κουμπιού: πλήρης κύκλος (`border-radius: 50%`)

```
| type | name       | label         | appearance |
|------|------------|---------------|------------|
| date | start_date | Ημερομηνία επίσκεψης | inline     |
```

---

### `inline-onlyresult` — το κουμπί εξαφανίζεται μετά την επιλογή

Ίδιο με το `inline` αλλά το κουμπί κρύβεται μόλις επιλεγεί μια τιμή. Χρήσιμο όταν θέλετε μόνο την ημερομηνία ορατή μετά την επιλογή της, χωρίς ένα επίμονο εικονίδιο.

```
inline-onlyresult
```

---

### `inline-1line` — σειρά από περιστροφείς

Εμφανίζει μεμονωμένα χειριστήρια περιστροφέα (▲ τιμή ▼) σε μια ενιαία οριζόντια σειρά — μία στήλη ανά στοιχείο. Για `date`: μήνας / ημέρα / έτος. Για `datetime`: μήνας / ημέρα / έτος / ώρες / λεπτά. Για `time`: ώρες / λεπτά.

Δεν υπάρχει modal ή αναδυόμενο ημερολόγιο — ο χρήστης μετακινεί κάθε περιστροφέα ανεξάρτητα.

```
inline-1line
```

**Εμφάνιση μόνο συγκεκριμένων στοιχείων** προσθέτοντας τα ονόματα των στοιχείων:

```
inline-1line month year      → κρύβει τον περιστροφέα ημέρας
inline-1line year            → εμφανίζει μόνο το έτος
```

**Περιορισμός εύρους ετών:**

```
inline-1line y_range(2000-2030)
```

---

### `box` — εισαγωγή κειμένου

Εμφανίζει ένα απλό πεδίο εισαγωγής κειμένου. Ο χρήστης πληκτρολογεί την ημερομηνία απευθείας χρησιμοποιώντας τη μορφή που ορίζεται στην εμφάνιση.

```
box(%d/%m/%Y)       → ΗΗ/ΜΜ/ΕΕΕΕ
box(%Y-%m-%d)       → ΕΕΕΕ-ΜΜ-ΗΗ
```

---

### `month-year` — μόνο μήνας και έτος

Τυπική εμφάνιση XLSForm. Η επιλογή ξεκινάει από την προβολή έτους· ο χρήστης επιλέγει μήνα και έτος αλλά όχι συγκεκριμένη ημέρα.

```
month-year
```

---

### `year` — μόνο έτος

Τυπική εμφάνιση XLSForm. Η επιλογή ξεκινάει από την προβολή δεκαετίας· μόνο το έτος είναι επιλέξιμο.

```
year
```

## Προσαρμοσμένη μορφή εμφάνισης

Προσθέστε `-[format]` σε οποιαδήποτε `inline` εμφάνιση για να ελέγξετε πώς εμφανίζεται η επιλεγμένη τιμή ως κείμενο. Χρησιμοποιεί δείκτες τύπου strftime.

| Δείκτης | Σημασία | Παράδειγμα |
|-------|---------|---------|
| `%d`  | Ημέρα (με μηδενική συμπλήρωση) | 07 |
| `%e`  | Ημέρα (χωρίς συμπλήρωση) | 7 |
| `%m`  | Αριθμός μήνα | 04 |
| `%n`  | Αριθμός μήνα (χωρίς συμπλήρωση) | 4 |
| `%b`  | Συντομογραφία μήνα | Απρ |
| `%Y`  | Έτος 4 ψηφίων | 2026 |
| `%y`  | Έτος 2 ψηφίων | 26 |
| `%H`  | Ώρα (24ωρη) | 14 |
| `%h`  | Ώρα (χωρίς συμπλήρωση) | 14 |
| `%M`  | Λεπτό | 05 |
| `%S`  | Δευτερόλεπτο | 00 |
| `%a`  | Συντομογραφία ονόματος ημέρας | Τετ |

**Παραδείγματα:**

```
inline-[%d/%m/%Y]            → 07/04/2026
inline-[%d %b %Y]            → 07 Απρ 2026
inline-1line-[%Y-%m-%d]      → εισαγωγή με περιστροφέα, μορφοποιημένη εμφάνιση
inline-[%d/%m/%Y %H:%M]      → 07/04/2026 14:30
```

## Προσαρμογή χρώματος

Αντικαταστήστε το χρώμα του κουμπιού εικονιδίου χρησιμοποιώντας `colors()`:

```
inline colors("0099FF")                   → φόντο κουμπιού #0099FF
inline colors("0099FF","FFFFFF")          → φόντο #0099FF, χρώμα εικονιδίου #FFFFFF
inline-1line colors("0000FF","FFFF00")    → χρώματα έμφασης περιστροφέα
inline-onlyresult colors("E53935")        → κόκκινο κουμπί
```

---

## Θέση κουμπιού με `display{}`

Ο τροποποιητής `display{}` ελέγχει πού εμφανίζεται το κουμπί εικονιδίου σε σχέση με την ετικέτα της ερώτησης. Εφαρμόζεται στα `inline` και `inline-onlyresult`.

```
display{<align>, <size>, <color>}
```

| Παράμετρος | Τιμές | Προεπιλογή |
|-----------|--------|---------|
| Ευθυγράμμιση | `left`, `right`, `top`, `center`, `bottom` | `right` |
| Μέγεθος | `small`, `medium`, `large` | `small` |
| Χρώμα | δεκαεξαδικό π.χ. `#FF5500` | κύριο χρώμα θέματος |

**Συμπεριφορά ευθυγράμμισης:**

| Τιμή | Διάταξη |
|-------|--------|
| `right` | Κουμπί δεξιά της ετικέτας |
| `left` | Κουμπί αριστερά της ετικέτας |
| `top` | Κουμπί πάνω από την ετικέτα, κεντραρισμένο σε πλήρες πλάτος |
| `center` / `bottom` | Κουμπί κάτω από την ετικέτα, κεντραρισμένο σε πλήρες πλάτος |

**Παραδείγματα:**

```
inline display{left}
inline display{center, large}
inline display{right, medium, #E53935}
inline-onlyresult display{bottom, large, #0099FF}
```

## Περιορισμός εύρους ημερομηνιών

Χρησιμοποιήστε `inputs{range[...]}` για να περιορίσετε ποιες ημερομηνίες είναι επιλέξιμες.

```
inputs{range[dateGt(2024-01-01), dateLt(2024-12-31)]}
```

Παράμετροι μέσα στο `range[...]`:

| Παράμετρος | Περιγραφή |
|-----------|-------------|
| `dateGt(ΕΕΕΕ-ΜΜ-ΗΗ)` | Ελάχιστη επιλέξιμη ημερομηνία (μεγαλύτερη ή ίση) |
| `dateLt(ΕΕΕΕ-ΜΜ-ΗΗ)` | Μέγιστη επιλέξιμη ημερομηνία (μικρότερη ή ίση) |
| `indayTimeGt(ΩΩ:ΛΛ:ΔΔ)` | Ελάχιστη ώρα εντός ημέρας (μόνο datetime) |
| `indayTimeLt(ΩΩ:ΛΛ:ΔΔ)` | Μέγιστη ώρα εντός ημέρας (μόνο datetime) |

Μπορούν να οριστούν πολλαπλά εύρη — μια ημερομηνία είναι επιλέξιμη αν εμπίπτει σε **οποιοδήποτε** από τα εύρη.

## Καταστολή της ετικέτας

Προσθέστε `text-nolabel` για να κρύψετε την ετικέτα της ερώτησης. Το κουμπί εμφανίζεται μόνο του.

```
inline text-nolabel display{center, large}
```

## Βέλτιστες πρακτικές

1. Χρησιμοποιήστε `inline` για συμπαγείς φόρμες — εξοικονομεί κατακόρυφο χώρο σε σύγκριση με το πάντα ανοιχτό ημερολόγιο.
2. Χρησιμοποιήστε `inline-1line` όταν οι ερωτώμενοι πρέπει να προσαρμόσουν μεμονωμένα στοιχεία ημερομηνίας (π.χ. έτος γέννησης).
3. Χρησιμοποιήστε `box()` μόνο όταν εμπιστεύεστε τον ερευνητή να πληκτρολογήσει σωστά τις ημερομηνίες — δεν εμφανίζεται διεπαφή επικύρωσης.
4. Χρησιμοποιήστε `display{center, large}` για να κάνετε το κουμπί πιο εμφανές σε οθόνες κινητών.
5. Πάντα να καθορίζετε `-[format]` όταν η προεπιλεγμένη εμφάνιση `ΕΕΕΕ-ΜΜ-ΗΗ` θα μπέρδευε τους τοπικούς χρήστες.
6. Λάβετε υπόψη τις ζώνες ώρας κατά τη συλλογή δεδομένων ημερομηνίας-ώρας σε διαφορετικές περιοχές.

## Περιορισμοί

- Το `inline-1line` χρησιμοποιεί πάντα την σημερινή ημερομηνία ως προεπιλογή εάν δεν υπάρχει τιμή — χρησιμοποιήστε τη στήλη `default` για να προ-συμπληρώσετε μια συγκεκριμένη ημερομηνία.
- Η μορφή `box()` ελέγχει μόνο την εμφάνιση· η αποθηκευμένη τιμή είναι πάντα ISO 8601.
- Ο περιορισμός εύρους ημερομηνιών (`inputs{range[...]}`) δεν λειτουργεί με τη διάταξη `box`.
- Οι διαφορές ζώνης ώρας μπορούν να περιπλέξουν την ανάλυση δεδομένων εάν δεν αντιμετωπιστούν σωστά.

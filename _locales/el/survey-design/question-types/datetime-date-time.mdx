Οι τύποι ερωτήσεων `date`, `time` και `datetime` καταγράφουν τιμές ημερομηνίας ή/και ώρας. Το rtSurvey τις εμφανίζει με διάφορους τρόπους διάταξης που ελέγχονται από τη στήλη `appearance`.

## Βασικές Προδιαγραφές XLSForm

| type     | name           | label                         |
|----------|----------------|-------------------------------|
| date     | birth_date     | Ημερομηνία γέννησης           |
| time     | start_time     | Τι ώρα ξεκίνησε;              |
| datetime | event_datetime | Πότε συνέβη το γεγονός;       |

Για τις τυπικές προδιαγραφές, ανατρέξτε στην [τεκμηρίωση του XLSForm](https://xlsform.org/en/#question-types).

## Τρόποι διάταξης

### Προεπιλογή — πάντα ανοιχτό ημερολόγιο

Δεν απαιτείται τιμή εμφάνισης (appearance). Το ημερολόγιο (και το ρολόι για το `time`/`datetime`) εμφανίζεται απευθείας στη σελίδα — πάντα ορατό, δεν απαιτείται κουμπί.

| type | name       | label                | appearance |
|------|------------|----------------------|------------|
| date | start_date | Ημερομηνία επίσκεψης |            |

---

### `inline` — κυκλικό κουμπί → αναδυόμενο παράθυρο (modal)

Ένα κυκλικό κουμπί με εικονίδιο (ημερολόγιο ή ρολόι) εμφανίζεται δίπλα στην ετικέτα της ερώτησης. Πατώντας το ανοίγει ένα αναδυόμενο παράθυρο με τον επιλογέα. Μετά την επιλογή, η επιλεγμένη τιμή εμφανίζεται ως κείμενο δίπλα στην ετικέτα.

- Φόντο κουμπιού: βασικό χρώμα θέματος (δυνατότητα αντικατάστασης)
- Σχήμα κουμπιού: πλήρης κύκλος (`border-radius: 50%`)

```
| type | name       | label                | appearance |
|------|------------|----------------------|------------|
| date | start_date | Ημερομηνία επίσκεψης | inline     |
```

---

### `inline-onlyresult` — το κουμπί εξαφανίζεται μετά την επιλογή

Ίδιο με το `inline` αλλά το κουμπί κρύβεται μόλις επιλεγεί μια τιμή. Χρήσιμο όταν θέλετε να είναι ορατή μόνο η ημερομηνία μετά την επιλογή της, χωρίς μόνιμο εικονίδιο.

```
inline-onlyresult
```

---

### `inline-1line` — σειρά από περιστρεφόμενους επιλογείς (spinners)

Εμφανίζει μεμονωμένα στοιχεία ελέγχου επιλογής (▲ τιμή ▼) σε μια οριζόντια σειρά — μία στήλη ανά στοιχείο. Για `date`: μήνας / ημέρα / έτος. Για `datetime`: μήνας / ημέρα / έτος / ώρες / λεπτά. Για `time`: ώρες / λεπτά.

Δεν υπάρχει αναδυόμενο παράθυρο ή ημερολόγιο — ο χρήστης μετακινεί κάθε επιλογέα ανεξάρτητα.

```
inline-1line
```

**Εμφάνιση μόνο συγκεκριμένων στοιχείων** προσθέτοντας τα ονόματα των στοιχείων:

```
inline-1line month year      → κρύβει τον επιλογέα ημέρας
inline-1line year            → εμφανίζει μόνο το έτος
```

**Περιορισμός εύρους ετών:**

```
inline-1line y_range(2000-2030)
```

---

### `box` — εισαγωγή κειμένου

Εμφανίζει ένα απλό πεδίο εισαγωγής κειμένου. Ο χρήστης πληκτρολογεί την ημερομηνία απευθείας χρησιμοποιώντας τη μορφή που ορίζεται στο appearance.

```
box(%d/%m/%Y)       → ΗΗ/ΜΜ/ΕΕΕΕ
box(%Y-%m-%d)       → ΕΕΕΕ-ΜΜ-ΗΗ
```

---

### `month-year` — μήνας και έτος μόνο

Τυπική εμφάνιση XLSForm. Ο επιλογέας ξεκινά από την προβολή έτους. Ο χρήστης επιλέγει μήνα και έτος, αλλά όχι συγκεκριμένη ημέρα.

```
month-year
```

---

### `year` — έτος μόνο

Τυπική εμφάνιση XLSForm. Ο επιλογέας ξεκινά από την προβολή δεκαετίας. Μόνο το έτος είναι επιλέξιμο.

```
year
```

## Προσαρμοσμένη μορφή εμφάνισης

Προσθέστε το `-[format]` σε οποιαδήποτε εμφάνιση `inline` για να ελέγξετε πώς εμφανίζεται η επιλεγμένη τιμή ως κείμενο. Χρησιμοποιεί σύμβολα τύπου strftime.

| Σύμβολο | Σημασία | Παράδειγμα |
|-------|---------|---------|
| `%d`  | Ημέρα (με μηδενικό μπροστά) | 07 |
| `%e`  | Ημέρα (χωρίς μηδενικό) | 7 |
| `%m`  | Αριθμός μήνα | 04 |
| `%n`  | Αριθμός μήνα (χωρίς μηδενικό) | 4 |
| `%b`  | Συντομογραφία μήνα | Απρ |
| `%Y`  | 4ψήφιο έτος | 2026 |
| `%y`  | 2ψήφιο έτος | 26 |
| `%H`  | Ώρα (24ωρη) | 14 |
| `%h`  | Ώρα (χωρίς μηδενικό) | 14 |
| `%M`  | Λεπτό | 05 |
| `%S`  | Δευτερόλεπτο | 00 |
| `%a`  | Συντομογραφία ημέρας | Τετ |

**Παραδείγματα:**

```
inline-[%d/%m/%Y]            → 07/04/2026
inline-[%d %b %Y]            → 07 Απρ 2026
inline-1line-[%Y-%m-%d]      → εισαγωγή με επιλογέα, μορφοποιημένη εμφάνιση
inline-[%d/%m/%Y %H:%M]      → 07/04/2026 14:30
```

## Προσαρμογή χρωμάτων

Αντικαταστήστε το χρώμα του κουμπιού εικονιδίου χρησιμοποιώντας το `colors()`:

```
inline colors("0099FF")                   → φόντο κουμπιού #0099FF
inline colors("0099FF","FFFFFF")          → φόντο #0099FF, χρώμα εικονιδίου #FFFFFF
inline-1line colors("0000FF","FFFF00")    → χρώματα επιλογέα (spinner)
inline-onlyresult colors("E53935")        → κόκκινο κουμπί
```

---

## Θέση κουμπιού με `display{}`

Ο τροποποιητής `display{}` ελέγχει πού εμφανίζεται το κουμπί εικονιδίου σε σχέση με την ετικέτα της ερώτησης. Ισχύει για τα `inline` και `inline-onlyresult`.

```
display{<align>, <size>, <color>}
```

| Παράμετρος | Τιμές | Προεπιλογή |
|-----------|--------|---------|
| Align | `left`, `right`, `top`, `center`, `bottom` | `right` |
| Size | `small`, `medium`, `large` | `small` |
| Color | hex π.χ. `#FF5500` | βασικό χρώμα θέματος |

**Συμπεριφορά στοίχισης:**

| Τιμή | Διάταξη |
|-------|--------|
| `right` | Κουμπί στα δεξιά της ετικέτας |
| `left` | Κουμπί στα αριστερά της ετικέτας |
| `top` | Κουμπί πάνω από την ετικέτα, στο κέντρο σε πλήρες πλάτος |
| `center` / `bottom` | Κουμπί κάτω από την ετικέτα, στο κέντρο σε πλήρες πλάτος |

**Παραδείγματα:**

```
inline display{left}
inline display{center, large}
inline display{right, medium, #E53935}
inline-onlyresult display{bottom, large, #0099FF}
```

## Περιορισμός εύρους ημερομηνιών

Χρησιμοποιήστε το `inputs{range[...]}` για να περιορίσετε ποιες ημερομηνίες είναι επιλέξιμες.

```
inputs{range[dateGt(2024-01-01), dateLt(2024-12-31)]}
```

Παράμετροι μέσα στο `range[...]`:

| Παράμετρος | Περιγραφή |
|-----------|-------------|
| `dateGt(YYYY-MM-DD)` | Ελάχιστη επιλέξιμη ημερομηνία (μεγαλύτερη ή ίση) |
| `dateLt(YYYY-MM-DD)` | Μέγιστη επιλέξιμη ημερομηνία (μικρότερη ή ίση) |
| `indayTimeGt(HH:MM:SS)` | Ελάχιστη ώρα εντός μιας ημέρας (μόνο για datetime) |
| `indayTimeLt(HH:MM:SS)` | Μέγιστη ώρα εντός μιας ημέρας (μόνο για datetime) |

Μπορούν να οριστούν πολλαπλά εύρη — μια ημερομηνία είναι επιλέξιμη εάν εμπίπτει σε **οποιοδήποτε** από τα εύρη.

## Απόκρυψη της ετικέτας

Προσθέστε το `text-nolabel` για να κρύψετε την ετικέτα της ερώτησης. Το κουμπί εμφανίζεται μόνο του.

```
inline text-nolabel display{center, large}
```

## Βέλτιστες Πρακτικές

1. Χρησιμοποιήστε το `inline` για συμπαγείς φόρμες — εξοικονομεί κατακόρυφο χώρο σε σύγκριση με το πάντα ανοιχτό ημερολόγιο.
2. Χρησιμοποιήστε το `inline-1line` όταν οι ερωτώμενοι πρέπει να προσαρμόσουν μεμονωμένα στοιχεία ημερομηνίας (π.χ. έτος γέννησης).
3. Χρησιμοποιήστε το `box()` μόνο όταν εμπιστεύεστε τον ερευνητή να πληκτρολογήσει σωστά τις ημερομηνίες — δεν εμφανίζεται περιβάλλον επικύρωσης.
4. Χρησιμοποιήστε το `display{center, large}` για να κάνετε το κουμπί πιο εμφανές σε οθόνες κινητών.
5. Πάντα να καθορίζετε το `-[format]` όταν η προεπιλεγμένη εμφάνιση `YYYY-MM-DD` θα μπέρδευε τους τοπικούς χρήστες.
6. Λάβετε υπόψη τις ζώνες ώρας κατά τη συλλογή δεδομένων ημερομηνίας και ώρας σε διαφορετικές περιοχές.

## Περιορισμοί

- Το `inline-1line` έχει πάντα ως προεπιλογή τη σημερινή ημερομηνία εάν δεν υπάρχει τιμή — χρησιμοποιήστε τη στήλη `default` για να προ-συμπληρώσετε μια συγκεκριμένη ημερομηνία.
- Η μορφή `box()` ελέγχει μόνο την εμφάνιση. Η αποθηκευμένη τιμή είναι πάντα ISO 8601.
- Ο περιορισμός εύρους ημερομηνιών (`inputs{range[...]}`) δεν λειτουργεί με τη διάταξη `box`.
- Οι διαφορές στη ζώνη ώρας μπορούν να περιπλέξουν την ανάλυση των δεδομένων εάν δεν ληφθούν σωστά υπόψη.

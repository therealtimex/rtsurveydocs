Ο τύπος ερώτησης `geopoint` καταγράφει γεωγραφικές συντεταγμένες (πλάτος, μήκος, υψόμετρο, ακρίβεια) χρησιμοποιώντας το GPS της συσκευής. Το rtSurvey εμφανίζει τον επιλογέα με διάφορες λειτουργίες διάταξης και υποστηρίζει αυτοματοποίηση μέσω των παραμέτρων `inputs{}` και `outputs{}`.

## Βασικές προδιαγραφές XLSForm

| type     | name        | label                       |
|----------|-------------|-----------------------------|
| geopoint | location    | Καταγράψτε την τρέχουσα τοποθεσία |

Για τις τυπικές προδιαγραφές, ανατρέξτε στην [τεκμηρίωση του XLSForm](https://xlsform.org/en/#question-types).

## Μορφή δεδομένων

Αποθηκεύεται ως τέσσερις τιμές διαχωρισμένες με κενά:

```
latitude longitude altitude accuracy
```

Παράδειγμα: `13.756331 100.501762 15 8`

## Λειτουργίες διάταξης (Layout modes)

### Προεπιλογή — ορθογώνιο κουμπί

Ένα ορθογώνιο κουμπί "START GEOPOINT" ανοίγει ένα πλήρες παράθυρο χάρτη όπου ο απογραφέας επιλέγει ένα σημείο. Μετά την καταγραφή, η ετικέτα του κουμπιού αλλάζει σε "View or change geo point" και οι συντεταγμένες εμφανίζονται από κάτω.

Δεν απαιτείται τιμή εμφάνισης (appearance).

---

### `display{inline-icon}` — κυκλικό κουμπί στόχου

Εμφανίζει ένα κυκλικό κουμπί εικονιδίου (στόχος ⊕) αντί για το ορθογώνιο κουμπί. Πατώντας το ανοίγει το ίδιο παράθυρο χάρτη.

```
display{inline-icon}
```

**Σε συνδυασμό με τη θέση και το μέγεθος:**

```
display{inline-icon, left}           → κουμπί αριστερά της ετικέτας
display{inline-icon, top}            → κουμπί πάνω από την ετικέτα
display{inline-icon, bottom}         → κουμπί κάτω από την ετικέτα, κεντραρισμένο
display{inline-icon, large}          → μεγάλο εικονίδιο (75px)
display{inline-icon, medium}         → μεσαίο εικονίδιο (50px)
display{inline-icon, left, large}    → μεγάλο κουμπί στα αριστερά
```

| Size | Icon height/width |
|------|------------------|
| *(default)* | 25px |
| `medium` | 50px |
| `large` | 75px |

---

### `display{thumbnail-square}` — ζωντανή μικρογραφία χάρτη

Εμφανίζει μια ζωντανή προεπισκόπηση χάρτη (Leaflet) απευθείας στην ερώτηση αντί για κουμπί. Η μικρογραφία δείχνει την τρέχουσα θέση GPS και το επιλεγμένο σημείο. Πατώντας το κουμπί επέκτασης ανοίγει το πλήρες παράθυρο.

```
display{thumbnail-square}
```

**Προσαρμοσμένο μέγεθος μικρογραφίας:**

```
display{thumbnail-square-[WxH]}          → σταθερά εικονοστοιχεία (pixels)
display{thumbnail-square-[400x200]}      → πλάτος 400px × ύψος 200px

display{thumbnail-square-[W%xH%]}        → ποσοστό του πλάτους της φόρμας
display{thumbnail-square-[100%x30%]}     → πλήρες πλάτος × 30% του πλάτους της φόρμας
```

## `display{}` έναντι `results{}` — πριν και μετά την καταγραφή

Το `display{}` ελέγχει τη διάταξη **πριν** ο χρήστης καταγράψει μια τοποθεσία. Το `results{}` ελέγχει τη διάταξη **αφού** υπάρχει μια τιμή. Μπορούν να έχουν διαφορετικές στοιχίσεις.

```
display{inline-icon, right} results{left}
```

Αυτό εμφανίζει το κουμπί στα δεξιά πριν από την καταγραφή και στη συνέχεια το μετακινεί στα αριστερά μόλις καταγραφεί ένα σημείο.

### `hide(value)` — απόκρυψη εμφάνισης συντεταγμένων

Από προεπιλογή, το κείμενο πλάτους/μήκους/ακρίβειας/υψομέτρου που έχει καταγραφεί εμφανίζεται κάτω από το κουμπί. Αποκρύψτε το με:

```
results{hide(value)}
display{inline-icon} results{hide(value)}
```

## `inputs{}` — αυτοματισμός GPS

### Αυτόματη καταγραφή κατά τη φόρτωση

Καταγράφει αυτόματα τη θέση GPS όταν φορτώνεται η φόρμα, χωρίς ο απογραφέας να πατήσει τίποτα.

```
inputs{auto-take}
```

**Υπό όρους αυτόματη καταγραφή** χρησιμοποιώντας μια έκφραση XLSForm:

```
inputs{autotakeGeo(expression(if(${capture_now} = 'yes', true(), false())))}
```

### Προ-συμπλήρωση από πεδίο κειμένου

Συμπληρώστε το geopoint από μια ερώτηση που περιέχει ένα όνομα μέρους ή μια συμβολοσειρά διεύθυνσης. Το rtSurvey πραγματοποιεί αντίστροφη γεωκωδικοποίηση της συμβολοσειράς σε συντεταγμένες μέσω του OpenStreetMap Nominatim.

```
inputs{question(address_field)}
```

---

## `outputs{}` — αντίστροφη γεωκωδικοποίηση σε κείμενο

Αφού καταγραφεί ένα σημείο, συμπληρώστε αυτόματα μια ερώτηση `text` με την αναγνώσιμη από τον άνθρωπο διεύθυνση (με αντίστροφη γεωκωδικοποίηση από τις συντεταγμένες).

```
outputs{question(address_field)}
```

Παράδειγμα:

| type | name | label | appearance |
|------|------|-------|------------|
| geopoint | location | Καταγραφή τοποθεσίας | `outputs{question(address_text)}` |
| text | address_text | Διεύθυνση | |

---

## `nomap` — καταγραφή GPS χωρίς χάρτη

Αντικαθιστά το παράθυρο χάρτη με ένα απλό πλαίσιο διαλόγου που ζητά άδεια τοποθεσίας και καταγράφει συντεταγμένες. Δεν εμφανίζεται χάρτης. Χρήσιμο για καταγραφή μόνο GPS σε συσκευές χαμηλών προδιαγραφών ή όταν τα πλακίδια χάρτη δεν είναι διαθέσιμα εκτός σύνδεσης.

```
nomap
```

## Βέλτιστες πρακτικές

1. Χρησιμοποιήστε το `inputs{auto-take}` για έρευνες επαλήθευσης απογραφέα όπου το GPS είναι υποχρεωτικό — αφαιρεί το χειροκίνητο βήμα.
2. Χρησιμοποιήστε το `display{thumbnail-square}` όταν θέλετε ο απογραφέας να επιβεβαιώσει οπτικά το επιλεγμένο σημείο πριν προχωρήσει.
3. Συνδυάστε το `outputs{question(...)}` με ένα πεδίο `text` μόνο για ανάγνωση για να εμφανίσετε την αντίστροφα γεωκωδικοποιημένη διεύθυνση στον απογραφέα.
4. Χρησιμοποιήστε το `nomap` σε περιοχές χωρίς σύνδεση στο διαδίκτυο όπου τα πλακίδια χάρτη δεν μπορούν να φορτωθούν.
5. Αφήστε χρόνο στο GPS να σταθεροποιηθεί πριν από την καταγραφή — ακρίβεια κάτω από 10 μέτρα είναι συνήθως επαρκής για έρευνες πεδίου.

## Περιορισμοί (Limitations)

- Η γεωκωδικοποίηση του `inputs{question(name)}` απαιτεί πρόσβαση στο διαδίκτυο — καλεί το API OpenStreetMap Nominatim.
- Η αντίστροφη γεωκωδικοποίηση του `outputs{question(name)}` απαιτεί επίσης πρόσβαση στο διαδίκτυο.
- Η μικρογραφία χάρτη (`display{thumbnail-square}`) απαιτεί διαδίκτυο για τη φόρτωση πλακιδίων. Οι συντεταγμένες εξακολουθούν να καταγράφονται εκτός σύνδεσης.
- Η ακρίβεια του GPS ποικίλλει ανάλογα με τη συσκευή και το περιβάλλον — οι συνθήκες σε εσωτερικούς χώρους ή σε αστικά "φαράγγια" μπορεί να οδηγήσουν σε ακρίβεια > 50 μέτρα.
- Η συλλογή δεδομένων τοποθεσίας μπορεί να επηρεάσει σημαντικά τη διάρκεια ζωής της μπαταρίας της συσκευής κατά τη διάρκεια μακροχρόνιων ερευνών.

Ο τύπος ερώτησης `geopoint` καταγράφει γεωγραφικές συντεταγμένες (γεωγραφικό πλάτος, μήκος, υψόμετρο, ακρίβεια) χρησιμοποιώντας το GPS της συσκευής. Το rtSurvey εμφανίζει την επιλογή με διάφορους τρόπους διάταξης και υποστηρίζει αυτοματοποίηση μέσω των παραμέτρων `inputs{}` και `outputs{}`.

## Βασική προδιαγραφή XLSForm

| type     | name        | label                       |
|----------|-------------|-----------------------------|
| geopoint | location    | Καταγράψτε την τρέχουσα τοποθεσία |

Για την τυπική προδιαγραφή δείτε την [τεκμηρίωση XLSForm](https://xlsform.org/en/#question-types).

## Μορφή δεδομένων

Αποθηκεύεται ως τέσσερις τιμές διαχωρισμένες με κενό:

```
γεωγραφικό πλάτος γεωγραφικό μήκος υψόμετρο ακρίβεια
```

Παράδειγμα: `13.756331 100.501762 15 8`

## Λειτουργίες διάταξης

### Προεπιλογή — ορθογώνιο κουμπί

Ένα ορθογώνιο κουμπί "ΕΝΑΡΞΗ GEOPOINT" ανοίγει ένα πλήρες modal χάρτη όπου ο ερευνητής επιλέγει ένα σημείο. Μετά τη λήψη, η ετικέτα του κουμπιού αλλάζει σε "Προβολή ή αλλαγή γεωγραφικού σημείου" και οι συντεταγμένες εμφανίζονται παρακάτω.

Δεν απαιτείται τιμή εμφάνισης.

---

### `display{inline-icon}` — κυκλικό κουμπί σταυροειδούς στόχευσης

Εμφανίζει ένα κυκλικό κουμπί εικονιδίου (σταυροειδής στόχευση ⊕) αντί για το ορθογώνιο κουμπί. Πατώντας το, ανοίγει το ίδιο modal χάρτη.

```
display{inline-icon}
```

**Συνδυασμός με θέση και μέγεθος:**

```
display{inline-icon, left}           → κουμπί αριστερά της ετικέτας
display{inline-icon, top}            → κουμπί πάνω από την ετικέτα
display{inline-icon, bottom}         → κουμπί κάτω από την ετικέτα, κεντραρισμένο
display{inline-icon, large}          → μεγάλο εικονίδιο (75px)
display{inline-icon, medium}         → μεσαίο εικονίδιο (50px)
display{inline-icon, left, large}    → μεγάλο κουμπί στα αριστερά
```

| Μέγεθος | Ύψος/πλάτος εικονιδίου |
|------|------------------|
| *(προεπιλογή)* | 25px |
| `medium` | 50px |
| `large` | 75px |

---

### `display{thumbnail-square}` — ζωντανή μικρογραφία χάρτη

Εμφανίζει μια ζωντανή προεπισκόπηση χάρτη (Leaflet) απευθείας στην ερώτηση αντί για ένα κουμπί. Η μικρογραφία δείχνει την τρέχουσα θέση GPS και το επιλεγμένο σημείο. Πατώντας το κουμπί επέκτασης ανοίγει το πλήρες modal.

```
display{thumbnail-square}
```

**Προσαρμοσμένο μέγεθος μικρογραφίας:**

```
display{thumbnail-square-[ΠxΥ]}          → καθορισμένα pixel
display{thumbnail-square-[400x200]}      → 400px πλάτος × 200px ύψος

display{thumbnail-square-[Π%xΥ%]}        → ποσοστό του πλάτους της φόρμας
display{thumbnail-square-[100%x30%]}     → πλήρες πλάτος × 30% του πλάτους της φόρμας
```

## `display{}` vs `results{}` — πριν και μετά τη λήψη

Το `display{}` ελέγχει τη διάταξη **πριν** ο χρήστης καταγράψει μια τοποθεσία. Το `results{}` ελέγχει τη διάταξη **μετά** την ύπαρξη μιας τιμής. Μπορούν να έχουν διαφορετικές ευθυγραμμίσεις.

```
display{inline-icon, right} results{left}
```

Αυτό εμφανίζει το κουμπί στα δεξιά πριν τη λήψη, και στη συνέχεια το μετακινεί στα αριστερά μόλις καταγραφεί ένα σημείο.

### `hide(value)` — καταστολή εμφάνισης συντεταγμένων

Από προεπιλογή, το κείμενο ληφθέντων συντεταγμένων (πλάτος/μήκος/ακρίβεια/υψόμετρο) εμφανίζεται κάτω από το κουμπί. Κρύψτε το με:

```
results{hide(value)}
display{inline-icon} results{hide(value)}
```

## `inputs{}` — αυτοματοποίηση GPS

### Αυτόματη λήψη κατά τη φόρτωση

Καταγράφει αυτόματα τη θέση GPS όταν φορτώνεται η φόρμα, χωρίς ο ερευνητής να πατήσει τίποτα.

```
inputs{auto-take}
```

**Προαιρετική αυτόματη λήψη** χρησιμοποιώντας μια έκφραση XLSForm:

```
inputs{autotakeGeo(expression(if(${capture_now} = 'yes', true(), false())))}
```

### Προ-συμπλήρωση από πεδίο κειμένου

Συμπληρώστε το geopoint από μια ερώτηση που περιέχει ένα όνομα τόπου ή μια συμβολοσειρά διεύθυνσης. Το rtSurvey αντιστρέφει τη γεωκωδικοποίηση της συμβολοσειράς σε συντεταγμένες μέσω του OpenStreetMap Nominatim.

```
inputs{question(address_field)}
```

---

## `outputs{}` — αντιστροφή γεωκωδικοποίησης σε κείμενο

Μετά τη λήψη ενός σημείου, συμπληρώστε αυτόματα μια ερώτηση `text` με την αναγνώσιμη από τον άνθρωπο διεύθυνση (αντιστροφή γεωκωδικοποίησης από τις συντεταγμένες).

```
outputs{question(address_field)}
```

Παράδειγμα:

| type | name | label | appearance |
|------|------|-------|------------|
| geopoint | location | Καταγράψτε την τοποθεσία | `outputs{question(address_text)}` |
| text | address_text | Διεύθυνση | |

---

## `nomap` — λήψη GPS χωρίς χάρτη

Αντικαθιστά το modal χάρτη με έναν απλό διάλογο που ζητά άδεια τοποθεσίας και καταγράφει συντεταγμένες. Δεν εμφανίζεται χάρτης. Χρήσιμο για λήψη μόνο GPS σε συσκευές χαμηλού κόστους ή όταν τα πλακίδια χάρτη δεν είναι διαθέσιμα εκτός σύνδεσης.

```
nomap
```

## Βέλτιστες πρακτικές

1. Χρησιμοποιήστε `inputs{auto-take}` για έρευνες επαλήθευσης από ερευνητές όπου το GPS είναι υποχρεωτικό — αφαιρεί το χειροκίνητο βήμα.
2. Χρησιμοποιήστε `display{thumbnail-square}` όταν θέλετε ο ερευνητής να επιβεβαιώσει οπτικά το επιλεγμένο σημείο πριν συνεχίσει.
3. Συνδυάστε `outputs{question(...)}` με ένα πεδίο `text` μόνο για ανάγνωση για να εμφανίσετε την αντίστροφα γεωκωδικοποιημένη διεύθυνση στον ερευνητή.
4. Χρησιμοποιήστε `nomap` σε περιοχές χωρίς σύνδεση στο διαδίκτυο όπου δεν μπορούν να φορτωθούν πλακίδια χάρτη.
5. Αφήστε το GPS να σταθεροποιηθεί πριν την καταγραφή — ακρίβεια κάτω των 10m είναι συνήθως επαρκής για επιτόπιες έρευνες.

## Περιορισμοί

- Η γεωκωδικοποίηση `inputs{question(name)}` απαιτεί πρόσβαση στο διαδίκτυο — καλεί το OpenStreetMap Nominatim API.
- Η αντίστροφη γεωκωδικοποίηση `outputs{question(name)}` απαιτεί επίσης πρόσβαση στο διαδίκτυο.
- Η μικρογραφία χάρτη (`display{thumbnail-square}`) απαιτεί διαδίκτυο για τη φόρτωση πλακιδίων· οι συντεταγμένες εξακολουθούν να καταγράφονται εκτός σύνδεσης.
- Η ακρίβεια του GPS ποικίλλει ανάλογα με τη συσκευή και το περιβάλλον — οι συνθήκες σε εσωτερικούς χώρους ή σε αστικά φαράγγια μπορεί να παράγουν ακρίβεια > 50m.
- Η συλλογή δεδομένων τοποθεσίας μπορεί να επηρεάσει σημαντικά τη διάρκεια ζωής της μπαταρίας της συσκευής κατά τη διάρκεια μακρών ερευνών.

title: "Ακέραιος"
description: "Τύπος ερώτησης εισαγωγής ακέραιου αριθμού στο rtSurvey"
---

Ο τύπος ερώτησης `integer` συλλέγει ακέραιους αριθμούς (χωρίς δεκαδικά ψηφία). Ενεργοποιεί ένα αριθμητικό πληκτρολόγιο σε κινητές συσκευές και αποκλείει την εισαγωγή δεκαδικών ψηφίων. Υποστηρίζει τις ίδιες επιλογές εμφάνισης με τον τύπο `text` για διάταξη και μορφοποίηση.

## Βασική προδιαγραφή XLSForm

| type | name | label |
|------|------|-------|
| integer | age | Ηλικία ερωτώμενου |
| integer | household_size | Αριθμός ατόμων στο νοικοκυριό |

Για την τυπική προδιαγραφή ανατρέξτε στην [τεκμηρίωση XLSForm](https://xlsform.org/en/#question-types).

---

## Επιλογές εμφάνισης

### `number-hspinner` — οριζόντιος περιστρεφόμενος διακόπτης

Αντικαθιστά την είσοδο με έναν οριζόντιο περιστρεφόμενο διακόπτη **− τιμή +**. Πατώντας το μείον/συν μειώνει ή αυξάνει την τιμή κατά 1 (ή ένα προσαρμοσμένο βήμα).

```
number-hspinner
```

**Προσαρμόστε το σχήμα και το βήμα του κουμπιού** χρησιμοποιώντας `hspinner()`:

```
number-hspinner hspinner('left-small-square','right-small-square','5')
```

Παράμετροι: σχήμα αριστερού κουμπιού, σχήμα δεξιού κουμπιού, τιμή βήματος (προεπιλογή `1` για ακέραιο).

**Προσαρμοσμένα χρώματα** χρησιμοποιώντας `colors()`:

```
number-hspinner colors(0099FF,FFFFFF,FF5500,FFFFFF)
```

Τέσσερις τιμές κατά σειρά: φόντο αριστερού κουμπιού, εικονίδιο αριστερού κουμπιού, φόντο δεξιού κουμπιού, εικονίδιο δεξιού κουμπιού.

---

### `thousandsep` — διαχωριστικό χιλιάδων

Μορφοποιεί τον εμφανιζόμενο αριθμό με ομαδοποίηση με κόμμα (π.χ. `1.234.567`). Ο αρχικός αριθμός αποθηκεύεται χωρίς κόμματα. Ο τύπος εισαγωγής μετατρέπεται σε `"text"` για να επιτραπεί η μορφοποιημένη εμφάνιση.

```
thousandsep
```

---

### `digisep(n, "sep")` — προσαρμοσμένη ομαδοποίηση ψηφίων

Ομαδοποιεί ψηφία σε μπλοκ `n` που διαχωρίζονται από έναν προσαρμοσμένο διαχωριστικό. Χρήσιμο για μορφοποιημένα αναγνωριστικά ή κωδικούς αναφοράς που είναι αριθμητικοί.

```
digisep(4,"-")      → 0912-3456-789
digisep(3," ")      → 012 345 678
```

Ο τύπος εισαγωγής μετατρέπεται σε `"text"` όταν αυτή η εμφάνιση είναι ενεργή.

---

### `textonly` — εξαναγκασμός πληκτρολογίου κειμένου

Εξαναγκάζει `type="text"` στο στοιχείο εισαγωγής. Αυτό αποτρέπει τις ιδιορρυθμίες της εισαγωγής αριθμών του προγράμματος περιήγησης (όπως την απόκρυψη αρχικών μηδενικών ή την προσθήκη βελών περιστροφής σε προγράμματα περιήγησης επιφάνειας εργασίας) ενώ εξακολουθεί να συλλέγει μια αριθμητική τιμή.

```
textonly
```

---

### `floating_hint` — η υπόδειξη επιπλέει ως ετικέτα

Το κείμενο `hint` εμφανίζεται μέσα στην είσοδο ως σύμβολο κράτησης θέσης. Όταν ο χρήστης αρχίζει να πληκτρολογεί, επιπλέει πάνω από το πεδίο ως ετικέτα.

```
floating_hint
```

---

### `embed` — υπόδειξη μέσα στο όριο εισαγωγής

Παρόμοιο με το `floating_hint` — η υπόδειξη βρίσκεται μέσα στο όριο εισαγωγής όταν είναι κενή. Δεν επιπλέει όταν ο χρήστης πληκτρολογεί.

```
embed
```

---

### `textpopup` — εισαγωγή σε αναδυόμενο παράθυρο

Πατώντας το πεδίο ανοίγει ένα αναδυόμενο παράθυρο με μεγαλύτερη εισαγωγή αντί για επεξεργασία εντός γραμμής. Χρήσιμο σε μικρές οθόνες όπου μια εισαγωγή πλήρους οθόνης είναι ευκολότερη.

```
textpopup
```

---

### `charcount` — μετρητής χαρακτήρων σε πραγματικό χρόνο

Εμφανίζει έναν μετρητή χαρακτήρων `(n)` σε πραγματικό χρόνο κάτω από την είσοδο, ενημερωμένο καθώς ο χρήστης πληκτρολογεί.

```
charcount
```

---

### `prefix(expr)` — προσθήκη προθέματος

Προσθέτει μια στατική ή υπολογισμένη συμβολοσειρά στην εμφανιζόμενη τιμή. Η αποθηκευμένη τιμή δεν περιλαμβάνει το πρόθεμα.

```
prefix('Στοιχείο #')        → εμφανίζει "Στοιχείο #42", αποθηκεύει "42"
prefix(${code_prefix})  → δυναμικό πρόθεμα από άλλο πεδίο
```

---

### `align_answer` — ευθυγράμμιση κειμένου εισαγωγής

Ελέγχει την οριζόντια ευθυγράμμιση της πληκτρολογημένης τιμής μέσα στην είσοδο.

```
align_answer = left
align_answer = right
align_answer = center
```

---

### `inputs{qrscan}` — σάρωση QR / γραμμωτού κώδικα στο πεδίο

Προσθέτει ένα κουμπί σάρωσης QR κώδικα δίπλα στην είσοδο. Ανοίγει τον σαρωτή κάμερας και συμπληρώνει το πεδίο με την σαρωμένη αριθμητική τιμή.

```
inputs{qrscan}
```

## Γρήγορη αναφορά εμφάνισης

| Appearance | Widget που εμφανίζεται |

| `number-hspinner colors(...)` | Περιστρεφόμενος διακόπτης με προσαρμοσμένα χρώματα κουμπιών |
| `thousandsep` | Εμφάνιση αριθμού ομαδοποιημένου με κόμμα |
| `digisep(n,"sep")` | Προσαρμοσμένη ομαδοποίηση ψηφίων |
| `textonly` | Εξαναγκασμός πληκτρολογίου κειμένου |
| `floating_hint` | Η υπόδειξη επιπλέει πάνω από το πεδίο κατά την πληκτρολόγηση |
| `embed` | Η υπόδειξη βρίσκεται μέσα στο όριο εισαγωγής |
| `textpopup` | Πατήστε για να ανοίξει αναδυόμενο παράθυρο |
| `charcount` | Μετρητής χαρακτήρων σε πραγματικό χρόνο κάτω από την είσοδο |

## Περιορισμοί και επικύρωση

Χρησιμοποιήστε περιορισμούς για να επιβάλετε εύρη τιμών. Οι περιορισμοί στη στήλη `constraint` αξιολογούνται μετά από κάθε πάτημα κουμπιού σε λειτουργία `number-hspinner`, όχι μόνο κατά την απενεργοποίηση.

| type | name | label | constraint | constraint_message |
|------|------|-------|------------|-------------------|
| integer | age | Ηλικία | `. > 0 and . <= 120` | Η ηλικία πρέπει να είναι μεταξύ 1 και 120 |
| integer | year | Έτος κατασκευής | `. >= 1800 and . <= 2100` | Εισαγάγετε ένα έγκυρο έτος |
| integer | count | Αριθμός ειδών | `. >= 0` | Δεν μπορεί να είναι αρνητικός |

## Παράδειγμα — έρευνα νοικοκυριών

| type | name | label | appearance | constraint | constraint_message |
|------|------|-------|------------|------------|-------------------|
| integer | household_size | Άτομα στο νοικοκυριό | `number-hspinner` | `. >= 1 and . <= 30` | Πρέπει να είναι μεταξύ 1 και 30 |
| integer | under_5 | Παιδιά κάτω των 5 ετών | `number-hspinner` | `. >= 0 and . <= ${household_size}` | Δεν μπορεί να υπερβαίνει το μέγεθος του νοικοκυριού |
| integer | year_built | Έτος κατασκευής σπιτιού | `textonly` | `. >= 1800 and . <= 2100` | Εισαγάγετε ένα έγκυρο έτος |

---

## Βέλτιστες πρακτικές

1.  Χρησιμοποιήστε `number-hspinner` για μετρήσεις μικρού εύρους όπου το πάτημα ± είναι γρηγορότερο από την πληκτρολόγηση (π.χ. αριθμός παιδιών, βαθμολογία σε κλίμακα 1-10).
2.  Χρησιμοποιήστε `thousandsep` όταν εμφανίζετε μεγάλους ακέραιους (πληθυσμός, εισόδημα) ώστε οι ερωτώμενοι να μπορούν να ελέγχουν το μέγεθος.
3.  Χρησιμοποιήστε `textonly` όταν τα προγράμματα περιήγησης προσθέτουν ανεπιθύμητο UI εισαγωγής αριθμών (βελάκια περιστροφής, κύλιση αφής) που μπερδεύει τους ερωτώμενους.
4.  Επιβάλετε περιορισμούς εύρους αντί να βασίζεστε στον τύπο του πληκτρολογίου κινητού – η επιβολή πληκτρολογίου δεν είναι καθολική.

## Περιορισμοί

-   Η εισαγωγή δεκαδικών ψηφίων αποκλείεται – εάν χρειάζεστε κλασματικές τιμές, χρησιμοποιήστε τον τύπο `decimal`.
-   Το `number-hspinner` επικυρώνει τον `constraint` σε κάθε πάτημα κουμπιού – αποφύγετε δαπανηρούς περιορισμούς (π.χ. σύνθετες αλυσίδες `if()`) σε λειτουργία περιστρεφόμενου διακόπτη.
-   Το `thousandsep` και το `digisep()` αποθηκεύουν τον αρχικό αριθμό χωρίς μορφοποίηση – μην βασίζεστε στην μορφοποιημένη τιμή εμφάνισης στους υπολογισμούς.

Ο τύπος ερώτησης `geoshape` καταγράφει ένα κλειστό πολύγωνο — μια σειρά από γεωγραφικές συντεταγμένες όπου το πρώτο και το τελευταίο σημείο είναι τα ίδια. Στη διαδικτυακή φόρμα του rtSurvey, αυτό εμφανίζεται ως **πεδίο κειμένου** όπου ο ερευνητής εισάγει ή επικολλλά απευθείας το αλφαριθμητικό των συντεταγμένων.

## Βασική προδιαγραφή XLSForm

| type     | name        | label                            |
|----------|-------------|----------------------------------|
| geoshape | field_area  | Σχεδιάστε το όριο του πεδίου     |
| geoshape | zone        | Καταγράψτε το όριο της ζώνης     |

Για την τυπική προδιαγραφή ανατρέξτε στην [τεκμηρίωση του XLSForm](https://xlsform.org/en/#question-types).

---

## Μορφή δεδομένων

Αποθηκεύεται ως μια λίστα σημείων διαχωρισμένων με ελληνικό ερωτηματικό (;) **χωρίς κενά γύρω από τα ερωτηματικά**. Κάθε σημείο αποτελείται από τέσσερις τιμές διαχωρισμένες με κενό:

```
lat lon alt acc;lat lon alt acc;lat lon alt acc;lat lon alt acc
```

| Συστατικό | Περιγραφή |
|-----------|-------------|
| `lat` | Γεωγραφικό πλάτος σε δεκαδικές μοίρες |
| `lon` | Γεωγραφικό μήκος σε δεκαδικές μοίρες |
| `alt` | Υψόμετρο σε μέτρα (`0` εάν είναι άγνωστο) |
| `acc` | Ακρίβεια GPS σε μέτρα (`0` εάν είναι άγνωστη) |

**Το πολύγωνο πρέπει να είναι κλειστό** — το τελευταίο σημείο πρέπει να είναι ίδιο με το πρώτο.

**Παράδειγμα — ένα πολύγωνο τεσσάρων σημείων (τρίγωνο, κλειστό):**
```
13.756331 100.501762 0 0;13.758000 100.503000 0 0;13.757000 100.506000 0 0;13.756331 100.501762 0 0
```

Απαιτούνται τουλάχιστον τρία διακριτά σημεία συν την επανάληψη κλεισίματος για το σχηματισμό ενός έγκυρου πολυγώνου.

---

## Πώς εμφανίζεται στο rtSurvey

Στη διαδικτυακή φόρμα του rtSurvey, το `geoshape` εμφανίζεται ως ένα απλό **πεδίο κειμένου**. Ο ερευνητής πληκτρολογεί ή επικολλλά το αλφαριθμητικό των συντεταγμένων. Δεν υπάρχει ενσωματωμένος διαδραστικός επιλογέας πολυγώνου σε χάρτη για αυτόν τον τύπο στην τρέχουσα διαδικτυακή φόρμα.

### Διαδραστική συλλογή σημείων πολυγώνου

Το συνιστώμενο πρότυπο για συλλογή στο πεδίο είναι μια **ομάδα επανάληψης ερωτήσεων `geopoint`** — κάθε κορυφή χρησιμοποιεί τον πλήρη επιλογέα χάρτη GPS — σε συνδυασμό με μια ερώτηση `calculate` για την παραγωγή του αλφαριθμητικού geoshape:

| type | name | label | calculation |
|------|------|-------|-------------|
| begin repeat | polygon_points | Καταγράψτε κάθε γωνία | |
| geopoint | point | Πατήστε για καταγραφή γωνίας | |
| end repeat | polygon_points | | |
| calculate | geoshape_value | | `join(';', ${polygon_points/point})` |

Μετά τη συνένωση, προσθέστε το πρώτο σημείο χειροκίνητα για να κλείσετε το πολύγωνο ή χρησιμοποιήστε έναν δεύτερο υπολογισμό (`calculate`) για να το συνενώσετε.

## Παράδειγμα χρήσης

| type | name | label | hint | required |
|------|------|-------|------|----------|
| geoshape | farm_boundary | Καταγράψτε το όριο του αγροτεμαχίου | Εισαγάγετε όλες τις γωνίες διαχωρισμένες με ερωτηματικά. Το πρώτο και το τελευταίο σημείο πρέπει να είναι τα ίδια. | yes |

---

## Βέλτιστες πρακτικές

1. Χρησιμοποιήστε μια ομάδα επανάληψης ερωτήσεων `geopoint` για διαδραστική συλλογή βάσει χάρτη και συνενώστε τις τιμές — αυτό δίνει στους ερευνητές έναν επιλογέα GPS για κάθε κορυφή.
2. Κλείνετε πάντα το πολύγωνο (επαναλάβετε το πρώτο σημείο στο τέλος) πριν από την υποβολή.
3. Συμπεριλάβετε την αναμενόμενη μορφή στη στήλη `hint` όταν απαιτείται χειροκίνητη εισαγωγή συντεταγμένων.
4. Απαιτήστε τουλάχιστον 3 διακριτά σημεία γωνίας για ένα έγκυρο πολύγωνο — επιβάλετε το μέσω οδηγιών και όχι μέσω περιορισμών XLSForm.
5. Χρησιμοποιήστε το `geopoint` για ερωτήσεις μίας τοποθεσίας και το `geoshape` μόνο όταν η οριοθέτηση περιοχής είναι ο πραγματικός στόχος της έρευνας.

## Περιορισμοί

- Δεν υπάρχει ενσωματωμένος διαδραστικός επιλογέας πολυγώνου σε χάρτη για το `geoshape` στη διαδικτυακή φόρμα του rtSurvey.
- Το πολύγωνο πρέπει να κλείνει χειροκίνητα — δεν υπάρχει μηχανισμός αυτόματου κλεισίματος στη λειτουργία εισαγωγής κειμένου.
- Η επικύρωση της τοπολογίας του πολυγώνου (π.χ. μη αυτο-τομή, ελάχιστη επιφάνεια) απαιτεί μετα-επεξεργασία εκτός των περιορισμών του XLSForm.
- Τα μεγάλα όρια με πολλές κορυφές παράγουν μεγάλα αλφαριθμητικά κειμένου.

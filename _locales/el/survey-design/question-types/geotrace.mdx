Ο τύπος ερώτησης `geotrace` καταγράφει μια αλληλουχία γεωγραφικών συντεταγμένων που σχηματίζουν μια γραμμή ή μια διαδρομή (polyline). Στην έκδοση web της φόρμας rtSurvey, αυτό εμφανίζεται ως **πεδίο εισαγωγής κειμένου**, όπου ο απογραφέας (enumerator) εισάγει ή επικολλά απευθείας τη συμβολοσειρά συντεταγμένων.

## Βασικές προδιαγραφές XLSForm

| type     | name        | label                        |
|----------|-------------|------------------------------|
| geotrace | river_path  | Ιχνηλάτηση της πορείας του ποταμού |
| geotrace | road_route  | Καταγραφή της οδικής διαδρομής |

Για την τυπική προδιαγραφή, δείτε την [τεκμηρίωση του XLSForm](https://xlsform.org/en/#question-types).

---

## Μορφή Δεδομένων (Data Format)

Αποθηκεύεται ως μια λίστα σημείων που χωρίζονται με ερωτηματικό (semicolon) **χωρίς κενά γύρω από τα ερωτηματικά**. Κάθε σημείο αποτελείται από τέσσερις τιμές που χωρίζονται με κενό:

```
lat lon alt acc;lat lon alt acc;lat lon alt acc
```

| Component | Description |
|-----------|-------------|
| `lat` | Γεωγραφικό πλάτος σε δεκαδικές μοίρες |
| `lon` | Γεωγραφικό μήκος σε δεκαδικές μοίρες |
| `alt` | Υψόμετρο σε μέτρα (`0` εάν είναι άγνωστο) |
| `acc` | Ακρίβεια GPS σε μέτρα (`0` εάν είναι άγνωστη) |

**Παράδειγμα — μια διαδρομή τριών σημείων:**
```
13.756331 100.501762 15 8;13.758000 100.503000 14 6;13.760000 100.505000 13 5
```

Απαιτούνται τουλάχιστον δύο σημεία για να σχηματιστεί μια έγκυρη διαδρομή.

---

## Πώς εμφανίζεται στο rtSurvey

Στη φόρμα web του rtSurvey, το `geotrace` εμφανίζεται ως ένα απλό **πεδίο κειμένου**. Ο απογραφέας πληκτρολογεί ή επικολλά τη συμβολοσειρά συντεταγμένων. Δεν υπάρχει ενσωματωμένος διαδραστικός επιλογέας χάρτη για αυτόν τον τύπο στην τρέχουσα φόρμα web.

### Καταγραφή σημείων διαδραστικά

Το προτεινόμενο πρότυπο για τη συλλογή στο πεδίο είναι μια **ομάδα επανάληψης (repeat group) ερωτήσεων `geopoint`** — κάθε σημείο χρησιμοποιεί τον πλήρη επιλογέα χάρτη GPS — σε συνδυασμό με ένα `calculate` για τη δημιουργία της συμβολοσειράς geotrace:

| type | name | label | calculation |
|------|------|-------|-------------|
| begin repeat | path_points | Καταγράψτε κάθε σημείο διαδρομής | |
| geopoint | point | Πατήστε για καταγραφή σημείου | |
| end repeat | path_points | | |
| calculate | geotrace_value | | `join(';', ${path_points/point})` |

Η υπολογισμένη συμβολοσειρά μπορεί στη συνέχεια να αποθηκευτεί σε μια ερώτηση `text` ή να χρησιμοποιηθεί στο `geotrace`.

## Παράδειγμα χρήσης

| type | name | label | hint | required |
|------|------|-------|------|----------|
| geotrace | farm_boundary_path | Καταγράψτε τη διαδρομή πρόσβασης προς τη φάρμα | Εισάγετε κάθε σημείο διαδρομής χωρισμένο με ερωτηματικό | yes |

---

## Βέλτιστες πρακτικές

1. Χρησιμοποιήστε μια ομάδα επανάληψης ερωτήσεων `geopoint` για διαδραστική συλλογή βάσει χάρτη και στη συνέχεια ενώστε τις τιμές — αυτό δίνει στους απογραφείς έναν επιλογέα GPS για κάθε σημείο ξεχωριστά.
2. Συμπεριλάβετε την αναμενόμενη μορφή στη στήλη `hint` όταν απαιτείται χειροκίνητη εισαγωγή συντεταγμένων.
3. Επαληθεύστε την παρουσία με `required = yes` όταν η διαδρομή είναι υποχρεωτική.
4. Σχεδιάστε τον καθαρισμό των δεδομένων — οι διαδρομές που εισάγονται χειροκίνητα ενδέχεται να έχουν ασυνεπή ακρίβεια.

## Περιορισμοί (Limitations)

- Δεν υπάρχει ενσωματωμένος διαδραστικός επιλογέας χάρτη για το `geotrace` στη φόρμα web του rtSurvey.
- Η συμβολοσειρά συντεταγμένων μπορεί να είναι μεγάλη για περίπλοκες διαδρομές — λάβετε το υπόψη για την απόδοση της φόρμας και την αποθήκευση.
- Η επικύρωση της τοπολογίας της διαδρομής (π.χ. ελάχιστος αριθμός σημείων, αυτο-τομή) απαιτεί επεξεργασία μετά τη συλλογή, εκτός των περιορισμών του XLSForm.

Ο τύπος ερώτησης `text` συλλέγει μια συμβολοσειρά ελεύθερου κειμένου. Είναι ο πιο ευέλικτος τύπος εισαγωγής και υποστηρίζει μεγάλο αριθμό παραλλαγών εμφάνισης που αλλάζουν τον τρόπο εμφάνισης της εισαγωγής — από ένα απλό πεδίο μονής γραμμής έως αναγνώριση ομιλίας σε κείμενο, αναδυόμενα παράθυρα διαλόγου, εμπλουτισμένους επεξεργαστές κειμένου και αριθμητικούς περιστροφικούς διακόπτες.

## Βασική προδιαγραφή XLSForm

| type | name | label |
|------|------|-------|
| text | respondent_name | Πλήρες όνομα ερωτώμενου |
| text | address | Διεύθυνση κατοικίας |

Για την τυπική προδιαγραφή ανατρέξτε στην [τεκμηρίωση XLSForm](https://xlsform.org/en/#question-types).

---

## Λειτουργίες διάταξης

### Προεπιλογή — εισαγωγή μονής γραμμής

Δεν απαιτείται εμφάνιση. Αποδίδει ένα τυπικό πεδίο `<input type="text">`.

---

### `multiline` — περιοχή κειμένου

Αποδίδει μια πολυγραμμική περιοχή κειμένου. Ο χρήστης μπορεί να την επεκτείνει πληκτρολογώντας. Αυξάνεται αυτόματα.

```
multiline
```

**Έλεγχος ύψους γραμμής** με προσθήκη `[initRows, maxRows]`:

```
multiline [3,8]     → ξεκινά από 3 γραμμές, επεκτείνεται έως 8
multiline [5]       → σταθερό στις 5 γραμμές
```

Η προεπιλογή είναι 1 γραμμή χωρίς μέγιστο. Το Shift+Enter εισάγει αλλαγή γραμμής. Το Enter προχωρά στην επόμενη ερώτηση.

---

### `floating_hint` — η υπόδειξη επιπλέει ως ετικέτα

Το κείμενο `hint` αποδίδεται μέσα στο πεδίο εισαγωγής ως σύμβολο κράτησης θέσης. Όταν ο χρήστης αρχίζει να πληκτρολογεί, η υπόδειξη επιπλέει πάνω από το πεδίο ως ετικέτα.

```
floating_hint
```

---

### `embed` — υπόδειξη μέσα στην εισαγωγή

Παρόμοια με την `floating_hint` — η υπόδειξη αποδίδεται μέσα στο όριο εισαγωγής όταν το πεδίο είναι κενό. Δεν επιπλέει κατά την πληκτρολόγηση.

```
embed
```

---

### `textpopup` — αναδυόμενο παράθυρο διαλόγου εισαγωγής

Πατώντας το πεδίο ανοίγει ένα αναδυόμενο παράθυρο διαλόγου SweetAlert με μεγάλη εισαγωγή αντί για επεξεργασία εντός γραμμής. Χρήσιμο σε κινητές συσκευές για να παρέχει περισσότερο χώρο στην οθόνη για πληκτρολόγηση.

```
textpopup
```

---

### `richtext` — επεξεργαστής WYSIWYG

Αποδίδει έναν πλήρη επεξεργαστή εμπλουτισμένου κειμένου (Monaco / Draft.js). Ο ερωτώμενος μπορεί να κάνει το κείμενο έντονο, πλάγιο, να προσθέσει λίστες κ.λπ. Η αποθηκευμένη τιμή είναι HTML.

```
richtext
richtext(30%)       → ύψος επεξεργαστή 30% του οπτικού πεδίου
```

---

### `charcount` — μετρητής χαρακτήρων σε πραγματικό χρόνο

Προσθέτει μια οθόνη μέτρησης χαρακτήρων `(n)` κάτω από την εισαγωγή, η οποία ενημερώνεται καθώς ο χρήστης πληκτρολογεί.

```
charcount
multiline charcount
```

---

## Παραλλαγές αριθμητικής εισαγωγής

Αυτές οι εμφανίσεις λειτουργούν στον τύπο `text` για τη συλλογή αριθμών με ειδική μορφοποίηση ή μοτίβα αλληλεπίδρασης.

### `numbers` — αριθμητικό πληκτρολόγιο

Επιβάλλει τον τύπο εισαγωγής HTML σε `number`, ενεργοποιώντας ένα αριθμητικό πληκτρολόγιο σε κινητές συσκευές.

```
numbers
```

### `thousandsep` — διαχωριστής χιλιάδων

Εμφανίζει τον αριθμό με ομαδοποίηση με κόμμα (π.χ. `1.234.567`) ενώ αποθηκεύει τον ακατέργαστο αριθμό. Ο τύπος εισαγωγής εξαναγκάζεται σε `text` για να επιτρέψει την εμφάνιση με κόμμα.

```
thousandsep
```

### `digisep(n, "sep")` — προσαρμοσμένη ομαδοποίηση ψηφίων

Ομαδοποιεί ψηφία σε μπλοκ `n` χωρισμένα από έναν προσαρμοσμένο χαρακτήρα. Χρήσιμο για αριθμούς τηλεφώνου, αριθμούς ταυτότητας κ.λπ.

```
digisep(4,"-")      → 0912-3456-789
digisep(3," ")      → 012 345 678
```

### `number-hspinner` — οριζόντιος περιστροφικός διακόπτης

Αντικαθιστά την εισαγωγή με έναν οριζόντιο περιστροφικό διακόπτη **− τιμή +**. Ο χρήστης πατάει τα κουμπιά μείον/συν για να μειώσει ή να αυξήσει την τιμή. Λειτουργεί με τους τύπους `int` και `decimal`.

```
number-hspinner
```

**Προσαρμογή εμφάνισης κουμπιού** χρησιμοποιώντας `hspinner()`:

```
number-hspinner hspinner('left-small-square','right-small-square','1')
```

Παράμετροι: σχήμα αριστερού κουμπιού, σχήμα δεξιού κουμπιού, τιμή βήματος.

**Προσαρμοσμένα χρώματα** χρησιμοποιώντας `colors()`:

```
number-hspinner colors(0099FF,FFFFFF,FF5500,FFFFFF)
```

Τέσσερις τιμές χρώματος: αριστερό φόντο, αριστερό εικονίδιο, δεξί φόντο, δεξί εικονίδιο.

### `prefix(expr)` — προσθήκη προθέματος

Προσθέτει μια υπολογιζόμενη ή στατική συμβολοσειρά στην εμφανιζόμενη τιμή. Η αποθηκευμένη τιμή δεν περιλαμβάνει το πρόθεμα.

```
prefix('USD ')      → εμφανίζει "USD 100", αποθηκεύει "100"
prefix(${currency}) → δυναμικό πρόθεμα από άλλο πεδίο
```

### `textonly` — επιβολή τύπου εισαγωγής κειμένου

Επιβάλλει `type="text"` ακόμα και όταν το πεδίο είναι `integer` ή `decimal`. Χρήσιμο για την αποφυγή ιδιορρυθμιών εισαγωγής αριθμών του προγράμματος περιήγησης.

```
textonly
```

---

## Μετασχηματισμός κειμένου

Αυτές οι εμφανίσεις μετασχηματίζουν αυτόματα την τιμή καθώς ο χρήστης πληκτρολογεί.

| Appearance | Effect | Παράδειγμα εισαγωγής → αποθηκευμένο |
|---|---|---|
| `upper` | Μετατρέπει σε ΚΕΦΑΛΑΙΑ | `γεια` → `ΓΕΙΑ` |
| `lower` | Μετατρέπει σε πεζά | `ΓΕΙΑ` → `γεια` |
| `proper` | Μετατρέπει σε Κεφαλαιοποίηση Κάθε Λέξης | `john doe` → `John Doe` |

## Βοηθητικά προγράμματα καταγραφής εισόδου

### `inputs{stt}` — αναγνώριση ομιλίας σε κείμενο

Προσθέτει ένα κουμπί μικροφώνου δίπλα στην εισαγωγή. Πατώντας το ξεκινά την αναγνώριση ομιλίας του προγράμματος περιήγησης (Web Speech API). Το μεταγραμμένο κείμενο προστίθεται στο πεδίο.

```
inputs{stt}
```

Δεν υποστηρίζεται στο Safari. Απαιτεί άδεια μικροφώνου.

### `inputs{qrscan}` — σαρωτής QR / γραμμωτού κώδικα

Προσθέτει ένα κουμπί σάρωσης κωδικού QR δίπλα στην εισαγωγή. Ανοίγει το αναδυόμενο παράθυρο του σαρωτή κάμερας και συμπληρώνει το πεδίο με την σαρωμένη τιμή.

```
inputs{qrscan}
```

**Tokenize** (προσθήκη σαρωμένων τιμών αντί αντικατάστασης):

```
inputs{qrscan} append(${separator})
```

### `inputs{stt,qrscan}` — και ομιλία και σάρωση

Αποδίδει και το κουμπί μικροφώνου και το κουμπί σάρωσης QR δίπλα-δίπλα.

```
inputs{stt,qrscan}
inputs{qrscan,stt}
```

## Παραλλαγές συνδεδεμένες με επιλογή

Αυτές οι εμφανίσεις συνδέουν ένα πεδίο κειμένου με μια λίστα επιλογών `select_one`, επιτρέποντας στον χρήστη είτε να επιλέξει από τη λίστα είτε να πληκτρολογήσει ελεύθερα.

### `selection_one_hide` — επιλογέας αναπτυσσόμενης λίστας

Αποδίδει την εισαγωγή κειμένου με ένα αναπτυσσόμενο βέλος. Πατώντας το βέλος εμφανίζονται επιλογές από την συνδεδεμένη λίστα `search()`. Η επιλογή μιας επιλογής γεμίζει την εισαγωγή και την κλειδώνει (εμφανίζει ✕ για εκκαθάριση).

```
selection_one_hide
```

### `selection_one_show` — λίστα ραδιοφώνου κάτω

Αποδίδει την εισαγωγή κειμένου με κουμπιά ραδιοφώνου κάτω από αυτήν. Η επιλογή ενός ραδιοφώνου γεμίζει και κλειδώνει την εισαγωγή.

```
selection_one_show
```

Και οι δύο παραλλαγές απαιτούν μια έκφραση `search()` στη στήλη `calculation` για να ορίσουν τη λίστα επιλογών.

## Ευθυγράμμιση απάντησης

Ελέγχει την οριζόντια ευθυγράμμιση του πληκτρολογημένου κειμένου μέσα στην εισαγωγή.

```
align_answer = left
align_answer = right
align_answer = center
```

## Widget εισαγωγής ώρας (ενσωματωμένο ρολόι)

Το rtSurvey επεκτείνει το `text` με ένα widget επιλογής ρολογιού. Αυτές οι εμφανίσεις εμφανίζουν ένα εικονίδιο ρολογιού που ο καταμετρητής πατάει για να επιλέξει μια τιμή ώρας. Η τιμή αποθηκεύεται ως απλό κείμενο στην επιλεγμένη μορφή.

### Εμφανίσεις

| Appearance | Description |
|---|---|
| `inline` | Κουμπί εικονιδίου ρολογιού δίπλα στο πεδίο, ανοίγει αναδυόμενο παράθυρο |
| `inline-onlyresult` | Το εικονίδιο του ρολογιού εξαφανίζεται μετά την επιλογή |
| `inline-1line` | Συμπαγές, μονής γραμμής περιστροφικό εργαλείο ώρας |
| `inline colors("RRGGBB")` | Εικονίδιο ρολογιού με προσαρμοσμένο χρώμα |
| `inline-1line colors("RRGGBB","RRGGBB")` | Περιστροφικό εργαλείο με δύο τονιστικά χρώματα |

### Μάρκες μορφής

Προσθέστε `-[format]` για να ελέγξετε ποια στοιχεία ώρας εμφανίζονται και αποθηκεύονται:

| Format | Εμφανίζει |
|---|---|
| `inline-[%H:%M]` | Ώρες : Λεπτά (24ωρη) |
| `inline-[%h:%M]` | Ώρες : Λεπτά (12ωρη) |
| `inline-[%H:%M:%S]` | Ώρες : Λεπτά : Δευτερόλεπτα (24ωρη) |
| `inline-[%M:%S]` | Λεπτά : Δευτερόλεπτα |
| `inline-[%H:%M:%3]` | Ώρες : Λεπτά : Χιλιοστά του δευτερολέπτου |
| `inline-[%S]` | Μόνο δευτερόλεπτα |
| `inline-[%3]` | Μόνο χιλιοστά του δευτερολέπτου |
| `inline-[%H]` | Μόνο ώρες (24ωρη) |

### Θέση κουμπιού με `display{}`

Όπως και οι άλλοι ενσωματωμένοι τύποι — ελέγχει τη θέση και το μέγεθος του κουμπιού ρολογιού:

```
inline display{right}
inline display{center, large}
inline-onlyresult display{left, medium, #0099FF}
```

## Περιορισμοί και επικύρωση

Εφαρμόστε περιορισμούς για να επιβάλετε μορφή, μήκος ή μοτίβο:

| type | name | label | constraint | constraint_message |
|------|------|-------|------------|-------------------|
| text | name | Πλήρες όνομα | `string-length(.) >= 2` | Απαιτούνται τουλάχιστον 2 χαρακτήρες |
| text | code | Κωδικός αναφοράς | `regex(., '^[A-Z]{2}[0-9]{4}$')` | 2 κεφαλαία γράμματα + 4 ψηφία |
| text | phone | Αριθμός τηλεφώνου | `regex(., '^[0-9]{9,15}$')` | Εισαγάγετε έναν έγκυρο αριθμό τηλεφώνου |

## Βέλτιστες πρακτικές

1.  Χρησιμοποιήστε πιο συγκεκριμένους τύπους (`integer`, `decimal`, `date`) όταν τα δεδομένα έχουν γνωστή δομή — αυτό αποτρέπει μη έγκυρες καταχωρήσεις.
2.  Χρησιμοποιήστε `multiline [3,8]` για ερωτήσεις ανοικτού τύπου για να δώσετε στους ερωτώμενους χώρο να γράψουν χωρίς να υπερφορτώσετε την οθόνη.
3.  Χρησιμοποιήστε `thousandsep` ή `digisep()` αντί για `numbers` όταν χρειάζεστε μορφοποιημένη εμφάνιση — το `numbers` μόνο του αλλάζει μόνο το πληκτρολόγιο.
4.  Χρησιμοποιήστε `inputs{qrscan}` για να εξαλείψετε λάθη χειροκίνητης πληκτρολόγησης για κωδικούς, αναγνωριστικά και σειριακούς αριθμούς.
5.  Χρησιμοποιήστε `floating_hint` όταν η υπόδειξη είναι σημαντικό πλαίσιο που πρέπει να παραμείνει ορατό κατά την πληκτρολόγηση — οι τυπικές υποδείξεις εξαφανίζονται από την οθόνη σε μικρές οθόνες.
6.  Χρησιμοποιήστε `charcount` σε ερωτήσεις με περιορισμούς μήκους, ώστε οι ερωτώμενοι να μπορούν να αυτοπαρακολουθούνται.

## Περιορισμοί

-   Το `inputs{stt}` απαιτεί ένα πρόγραμμα περιήγησης που υποστηρίζει το Web Speech API. Το Chrome είναι το πιο αξιόπιστο. Το Safari δεν υποστηρίζεται.
-   Το `richtext` αποθηκεύει HTML — σχεδιάστε για αφαίρεση HTML ή απολύμανση στην ανάλυση σας, εάν αναμένεται απλό κείμενο.
-   Τα `selection_one_hide` και `selection_one_show` απαιτούν μια έκφραση `search()` και υποστηρίζονται μόνο από τον πελάτη ιστού.
-   Το `number-hspinner` επικυρώνει έναντι της στήλης `constraint` σε κάθε πάτημα κουμπιού, όχι μόνο κατά την απενεργοποίηση — σχεδιάστε τους περιορισμούς αναλόγως.

title: "Δεκαδικός"
description: "Τύπος ερώτησης εισαγωγής κλασματικού αριθμού στο rtSurvey"
---

Ο τύπος ερώτησης `decimal` συλλέγει αριθμούς που μπορεί να περιλαμβάνουν κλασματικό μέρος (π.χ. `3.14`, `72.5`). Ενεργοποιεί ένα αριθμητικό πληκτρολόγιο σε κινητές συσκευές και υποστηρίζει τις ίδιες επιλογές εμφάνισης με τον τύπο `text` για τη διάταξη και τη μορφοποίηση.

## Βασική προδιαγραφή XLSForm

| type | name | label |
|------|------|-------|
| decimal | weight_kg | Βάρος (kg) |
| decimal | height_m | Ύψος (m) |
| decimal | temperature | Θερμοκρασία σώματος (°C) |

Για την τυπική προδιαγραφή ανατρέξτε στην [τεκμηρίωση του XLSForm](https://xlsform.org/en/#question-types).

---

## Επιλογές εμφάνισης (Appearance)

### `number-hspinner` — οριζόντιος επιλογέας

Αντικαθιστά την είσοδο με έναν οριζόντιο επιλογέα **− τιμή +**. Πατώντας το μείον/συν προσαρμόζεται η τιμή κατά το ρυθμισμένο βήμα.

```
number-hspinner
```

Η εμφανιζόμενη τιμή μορφοποιείται με ένα δεκαδικό ψηφίο (π.χ. `3.0`, `72.5`). Το προεπιλεγμένο βήμα είναι `1`. χρησιμοποιήστε το `hspinner()` για να ορίσετε ένα δεκαδικό βήμα.

**Προσαρμογή σχήματος κουμπιού και βήματος** χρησιμοποιώντας το `hspinner()`:

```
number-hspinner hspinner('left-small-square','right-small-square','0.1')
```

Παράμετροι: σχήμα αριστερού κουμπιού, σχήμα δεξιού κουμπιού, τιμή βήματος. Χρησιμοποιήστε ένα δεκαδικό βήμα όπως `0.5` ή `0.1` για έλεγχο ακριβείας.

**Προσαρμοσμένα χρώματα** χρησιμοποιώντας το `colors()`:

```
number-hspinner colors(0099FF,FFFFFF,FF5500,FFFFFF)
```

Τέσσερις τιμές με τη σειρά: φόντο αριστερού κουμπιού, εικονίδιο αριστερού κουμπιού, φόντο δεξιού κουμπιού, εικονίδιο δεξιού κουμπιού.

---

### `thousandsep` — διαχωριστικό χιλιάδων

Μορφοποιεί τον εμφανιζόμενο αριθμό με ομαδοποίηση κόμματος (π.χ. `1,234.56`). Ο ακατέργαστος αριθμός αποθηκεύεται χωρίς κόμματα. Ο τύπος εισόδου αλλάζει σε `"text"` για να επιτραπεί η μορφοποιημένη εμφάνιση.

```
thousandsep
```

---

### `digisep(n, "sep")` — προσαρμοσμένη ομαδοποίηση ψηφίων

Ομαδοποιεί τα ψηφία του ακέραιου μέρους σε μπλοκ των `n` που χωρίζονται από ένα προσαρμοσμένο διαχωριστικό.

```
digisep(3," ")      → 1 234 567.89
```

Ο τύπος εισόδου αλλάζει σε `"text"` όταν αυτή η εμφάνιση είναι ενεργή.

---

### `textonly` — αναγκαστικό πληκτρολόγιο κειμένου

Επιβάλλει το `type="text"` στο στοιχείο εισόδου. Αποτρέπει τις ιδιορρυθμίες εισαγωγής αριθμών του προγράμματος περιήγησης (απόκρυψη μηδενικών στο τέλος, βέλη περιστροφής στην επιφάνεια εργασίας) ενώ εξακολουθεί να δέχεται δεκαδικές τιμές.

```
textonly
```

---

### `floating_hint` — η υπόδειξη επιπλέει ως ετικέτα

Το κείμενο της υπόδειξης (`hint`) εμφανίζεται μέσα στην είσοδο ως placeholder. Όταν ο χρήστης αρχίζει να πληκτρολογεί, επιπλέει πάνω από το πεδίο ως ετικέτα (label).

```
floating_hint
```

---

### `embed` — υπόδειξη εντός του ορίου εισόδου

Παρόμοιο με το `floating_hint` — η υπόδειξη βρίσκεται μέσα στο όριο εισόδου όταν είναι κενό. Δεν επιπλέει όταν ο χρήστης πληκτρολογεί.

```
embed
```

---

### `textpopup` — είσοδος σε αναδυόμενο παράθυρο

Το πάτημα στο πεδίο ανοίγει ένα αναδυόμενο παράθυρο (modal dialog) με μεγαλύτερη είσοδο. Χρήσιμο σε μικρές οθόνες.

```
textpopup
```

---

### `charcount` — ζωντανός μετρητής χαρακτήρων

Εμφανίζει έναν ζωντανό μετρητή χαρακτήρων `(n)` κάτω από την είσοδο, ο οποίος ενημερώνεται καθώς πληκτρολογεί ο χρήστης.

```
charcount
```

---

### `prefix(expr)` — προσθήκη προθέματος

Προσθέτει ένα στατικό ή υπολογισμένο αλφαριθμητικό πριν από την εμφανιζόμενη τιμή. Η αποθηκευμένη τιμή δεν περιλαμβάνει το πρόθεμα.

```
prefix('USD ')          → εμφανίζει "USD 72.50", αποθηκεύει "72.50"
prefix(${currency})     → δυναμικό πρόθεμα από άλλο πεδίο
```

---

### `align_answer` — στοίχιση κειμένου εισόδου

Ελέγχει την οριζόντια στοίχιση της πληκτρολογημένης τιμής μέσα στην είσοδο.

```
align_answer = left
align_answer = right
align_answer = center
```

---

### `inputs{qrscan}` — σάρωση QR / γραμμωτού κώδικα στο πεδίο

Προσθέτει ένα κουμπί σάρωσης κώδικα QR δίπλα στην είσοδο. Ανοίγει τον σαρωτή της κάμερας και συμπληρώνει το πεδίο με τη σαρωμένη τιμή.

```
inputs{qrscan}
```

## Βέλτιστες πρακτικές

1. Χρησιμοποιήστε το `number-hspinner hspinner(..., '0.1')` για μετρήσεις που απαιτούν ακρίβεια ενός δεκαδικού ψηφίου — ο επιλογέας μορφοποιεί αυτόματα σε ένα δεκαδικό ψηφίο, διατηρώντας τις τιμές συνεπείς.
2. Χρησιμοποιήστε το `textonly` όταν τα προγράμματα περιήγησης προσθέτουν ανεπιθύμητα στοιχεία ελέγχου περιστροφής ή περικόπτουν τα μηδενικά στο τέλος (π.χ. το `3.0` εμφανίζεται ως `3`).
3. Χρησιμοποιήστε το `thousandsep` για μεγάλες οικονομικές τιμές, ώστε οι ερωτώμενοι να μπορούν να επαληθεύσουν ότι εισήγαγαν το σωστό μέγεθος.
4. Επιβάλετε περιορισμούς εύρους αντί να βασίζεστε μόνο στον τύπο πληκτρολογίου κινητού.

## Περιορισμοί

- Ο επιλογέας εμφανίζει πάντα ένα δεκαδικό ψηφίο — εάν χρειάζεστε μεγαλύτερη ακρίβεια στην εμφανιζόμενη τιμή, χρησιμοποιήστε την απλή είσοδο.
- Το `thousandsep` και το `digisep()` αποθηκεύουν τον ακατέργαστο αριθμό — μην διαβάζετε τη μορφοποιημένη τιμή εμφάνισης στους υπολογισμούς.

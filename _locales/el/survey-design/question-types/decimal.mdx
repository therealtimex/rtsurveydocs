title: "Δεκαδικός"
description: "Τύπος ερώτησης εισαγωγής κλασματικού αριθμού στο rtSurvey"
---

Ο τύπος ερώτησης `decimal` συλλέγει αριθμούς που μπορεί να περιλαμβάνουν ένα κλασματικό μέρος (π.χ. `3.14`, `72.5`). Ενεργοποιεί ένα αριθμητικό πληκτρολόγιο στο κινητό και υποστηρίζει τις ίδιες επιλογές εμφάνισης με τον τύπο `text` για διάταξη και μορφοποίηση.

## Βασική προδιαγραφή XLSForm

| type | name | label |
|------|------|-------|
| decimal | weight_kg | Βάρος (kg) |
| decimal | height_m | Ύψος (m) |
| decimal | temperature | Θερμοκρασία σώματος (°C) |

Για την τυπική προδιαγραφή δείτε την [τεκμηρίωση XLSForm](https://xlsform.org/en/#question-types).

---

## Επιλογές εμφάνισης

### `number-hspinner` — οριζόντιος περιστροφέας

Αντικαθιστά την εισαγωγή με έναν οριζόντιο περιστροφέα **− τιμή +**. Πατώντας το πλην/συν προσαρμόζεται η τιμή κατά το ρυθμισμένο βήμα.

```
number-hspinner
```

Η εμφανιζόμενη τιμή μορφοποιείται με ένα δεκαδικό ψηφίο (π.χ. `3.0`, `72.5`). Το προεπιλεγμένο βήμα είναι `1`· χρησιμοποιήστε `hspinner()` για να ορίσετε ένα δεκαδικό βήμα.

**Προσαρμογή σχήματος κουμπιού και βήματος** χρησιμοποιώντας `hspinner()`:

```
number-hspinner hspinner('left-small-square','right-small-square','0.1')
```

Παράμετροι: σχήμα αριστερού κουμπιού, σχήμα δεξιού κουμπιού, τιμή βήματος. Χρησιμοποιήστε ένα δεκαδικό βήμα όπως `0.5` ή `0.1` για λεπτομερή έλεγχο.

**Προσαρμοσμένα χρώματα** χρησιμοποιώντας `colors()`:

```
number-hspinner colors(0099FF,FFFFFF,FF5500,FFFFFF)
```

Τέσσερις τιμές κατά σειρά: φόντο αριστερού κουμπιού, εικονίδιο αριστερού κουμπιού, φόντο δεξιού κουμπιού, εικονίδιο δεξιού κουμπιού.

---

### `thousandsep` — διαχωριστής χιλιάδων

Μορφοποιεί τον εμφανιζόμενο αριθμό με ομαδοποίηση με κόμμα (π.χ. `1.234,56`). Ο αρχικός αριθμός αποθηκεύεται χωρίς κόμματα. Ο τύπος εισόδου μετατρέπεται σε `"text"` για να επιτρέψει τη μορφοποιημένη εμφάνιση.

```
thousandsep
```

---

### `digisep(n, "sep")` — προσαρμοσμένη ομαδοποίηση ψηφίων

Ομαδοποιεί τα ψηφία του ακέραιου μέρους σε μπλοκ `n` διαχωρισμένα με έναν προσαρμοσμένο διαχωριστή.

```
digisep(3," ")      → 1 234 567.89
```

Ο τύπος εισόδου μετατρέπεται σε `"text"` όταν αυτή η εμφάνιση είναι ενεργή.

---

### `textonly` — αναγκαστικό πληκτρολόγιο κειμένου

Επιβάλλει `type="text"` στο στοιχείο εισόδου. Αποτρέπει τις ιδιορρυθμίες εισόδου αριθμών του προγράμματος περιήγησης (απόκρυψη μηδενικών, βελάκια περιστροφής επιφάνειας εργασίας) ενώ εξακολουθεί να δέχεται δεκαδικές τιμές.

```
textonly
```

---

### `floating_hint` — η υπόδειξη επιπλέει ως ετικέτα

Το κείμενο `hint` εμφανίζεται μέσα στην εισαγωγή ως κείμενο κράτησης θέσης. Όταν ο χρήστης αρχίζει να πληκτρολογεί, επιπλέει πάνω από το πεδίο ως ετικέτα.

```
floating_hint
```

---

### `embed` — υπόδειξη μέσα στο όριο εισόδου

Παρόμοιο με το `floating_hint` — η υπόδειξη βρίσκεται μέσα στο όριο εισόδου όταν είναι κενή. Δεν επιπλέει όταν ο χρήστης πληκτρολογεί.

```
embed
```

---

### `textpopup` — εισαγωγή διαλόγου modal

Πατώντας το πεδίο ανοίγει ένας διάλογος modal με μεγαλύτερη εισαγωγή. Χρήσιμο σε μικρές οθόνες.

```
textpopup
```

---

### `charcount` — ζωντανός μετρητής χαρακτήρων

Εμφανίζει έναν ζωντανό μετρητή χαρακτήρων `(n)` κάτω από την εισαγωγή, ο οποίος ενημερώνεται καθώς ο χρήστης πληκτρολογεί.

```
charcount
```

---

### `prefix(expr)` — προσθήκη προθέματος

Προσθέτει μια στατική ή υπολογιζόμενη συμβολοσειρά στην εμφανιζόμενη τιμή. Η αποθηκευμένη τιμή δεν περιλαμβάνει το πρόθεμα.

```
prefix('USD ')          → εμφανίζει "USD 72.50", αποθηκεύει "72.50"
prefix(${currency})     → δυναμικό πρόθεμα από άλλο πεδίο
```

---

### `align_answer` — ευθυγράμμιση κειμένου εισόδου

Ελέγχει την οριζόντια ευθυγράμμιση της πληκτρολογημένης τιμής μέσα στην εισαγωγή.

```
align_answer = left
align_answer = right
align_answer = center
```

---

### `inputs{qrscan}` — σάρωση QR / barcode στο πεδίο

Προσθέτει ένα κουμπί σάρωσης QR code δίπλα στην εισαγωγή. Ανοίγει τον σαρωτή κάμερας και συμπληρώνει το πεδίο με τη σαρωμένη τιμή.

```
inputs{qrscan}
```

## Βέλτιστες πρακτικές

1. Χρησιμοποιήστε `number-hspinner hspinner(..., '0.1')` για μετρήσεις που απαιτούν ένα δεκαδικό ψηφίο ακρίβειας — ο περιστροφέας μορφοποιείται αυτόματα σε ένα δεκαδικό ψηφίο, διατηρώντας τις τιμές συνεπείς.
2. Χρησιμοποιήστε `textonly` όταν τα προγράμματα περιήγησης προσθέτουν ανεπιθύμητα χειριστήρια περιστροφής ή περικόπτουν μηδενικά (π.χ. `3.0` εμφανίζεται ως `3`).
3. Χρησιμοποιήστε `thousandsep` για μεγάλες οικονομικές τιμές, ώστε οι ερωτώμενοι να μπορούν να επαληθεύσουν ότι εισήγαγαν τη σωστή τιμή.
4. Επιβάλλετε περιορισμούς εύρους αντί να βασίζεστε μόνο στον τύπο του πληκτρολογίου κινητού.

## Περιορισμοί

- Ο περιστροφέας εμφανίζει πάντα ένα δεκαδικό ψηφίο — εάν χρειάζεστε μεγαλύτερη ακρίβεια στην εμφανιζόμενη τιμή, χρησιμοποιήστε την απλή εισαγωγή αντίθετα.
- Το `thousandsep` και το `digisep()` αποθηκεύουν τον αρχικό αριθμό — μην διαβάζετε τη μορφοποιημένη εμφανιζόμενη τιμή σε υπολογισμούς.

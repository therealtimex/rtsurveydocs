Ο τύπος ερώτησης `video` επιτρέπει στους ερωτώμενους να **καταγράφουν βίντεο** ή να ανεβάζουν ένα υπάρχον αρχείο βίντεο ως μέρος της απάντησής τους στην έρευνα. Είναι χρήσιμο για τη λήψη οπτικών αποδεικτικών στοιχείων, επιδείξεων, περιβαλλοντικών συνθηκών ή οποιασδήποτε πληροφορίας που ωφελείται από την κίνηση και τον ήχο μαζί.

## Βασική προδιαγραφή XLSForm

| type  | name        | label                              |
|-------|-------------|-------------------------------------|
| video | demo_video  | Παρακαλώ καταγράψτε μια σύντομη επίδειξη |

Για περισσότερες λεπτομέρειες σχετικά με τον τυπικό τύπο ερώτησης βίντεο, ανατρέξτε στην [προδιαγραφή XLSForm](https://xlsform.org/en/#question-types).

## Χρήσεις

Οι ερωτήσεις βίντεο χρησιμοποιούνται συνήθως για:

1.  Τεκμηρίωση συνθηκών πεδίου — ζημιές οδών, κατάσταση υποδομών, υγεία καλλιεργειών
2.  Καταγραφή επιδείξεων προϊόντων ή ελέγχων συμμόρφωσης διαδικασιών
3.  Συλλογή μαρτυριών βίντεο από ερωτώμενους
4.  Λήψη αποδεικτικών στοιχείων που απαιτούν χωρικό πλαίσιο (π.χ. το μέγεθος και η έκταση μιας προβληματικής περιοχής)
5.  Τεκμηρίωση πριν/μετά για έρευνες παρακολούθησης και αξιολόγησης

## επεκτάσεις rtSurvey

### Μέγιστη διάρκεια

Χρησιμοποιήστε τη στήλη `parameters` για να περιορίσετε τη διάρκεια της εγγραφής:

| type | name | label | parameters |
|------|------|-------|------------|
| video | site_visit | Καταγράψτε τις συνθήκες του χώρου | `max-duration=60` |

Το `max-duration` είναι σε δευτερόλεπτα. Η εγγραφή σταματά αυτόματα στο όριο.

### Ποιότητα / ανάλυση

Ελέγξτε την ανάλυση εγγραφής μέσω `parameters`:

| type | name | label | parameters |
|------|------|-------|------------|
| video | evidence | Καταγράψτε αποδεικτικά βίντεο | `quality=low` |

Υποστηριζόμενες τιμές: `low` (ταχύτερη μεταφόρτωση), `normal` (προεπιλογή), `high`. Χρησιμοποιήστε `low` σε περιοχές με περιορισμένη συνδεσιμότητα.

### Μεταφόρτωση υπάρχοντος βίντεο

Σε κινητές συσκευές, ο ερωτώμενος μπορεί να επιλέξει να **μεταφορτώσει ένα υπάρχον βίντεο** από τη συλλογή της συσκευής αντί να καταγράψει ένα νέο. Αυτό είναι ενεργοποιημένο από προεπιλογή στην ενσωμάτωση εγγενούς κάμερας/συλλογής.

### Αναπαραγωγή πριν από την υποβολή

Σε κινητές συσκευές, το καταγεγραμμένο κλιπ μπορεί να αναθεωρηθεί πριν από την προώθηση. Δεν απαιτείται πρόσθετη διαμόρφωση.

### Διάταξη κουμπιού ενσωμάτωσης

Προσθέστε `inline` για να εμφανίσετε την κάμερα ως **κυκλικό κουμπί εικονιδίου** δίπλα στην ετικέτα αντί για μια περιοχή λήψης πλήρους πλάτους.

```
| type  | name  | label        | appearance                              |
|-------|-------|--------------|----------------------------------------|
| video | clip  | Καταγράψτε βίντεο | inline display{right}                  |
| video | clip  | Καταγράψτε βίντεο | inline display{left, large}            |
| video | clip  | Καταγράψτε βίντεο | inline display{center, large, <0099FF/>} |
```

**Θέση κουμπιού** — `left`, `right` *(προεπιλογή)*, `top`, `center`, `bottom`

**Μέγεθος κουμπιού** — `small` *(προεπιλογή)*, `medium`, `large`

**Χρώμα κουμπιού** — προσθέστε ένα δεκαεξαδικό χρώμα μέσα στο `display{}` για να παρακάμψετε το κύριο χρώμα:

```
inline display{right, large, <FF5500/>}
```

**Έλεγχος μετά τη λήψη — `results{}`:**

| Appearance | Effect |
|---|---|
| `results{hide(capture)}` | Κρύβει το κουμπί εγγραφής μετά τη λήψη βίντεο |
| `results{hide(review)}` | Κρύβει την προεπισκόπηση μικρογραφίας μετά τη λήψη |
| `results{hide(filename)}` | Κρύβει το όνομα αρχείου και τη διάρκεια |
| `results{left}` | Μετακινεί το εικονίδιο αριστερά μετά τη λήψη |

Παράδειγμα — κρύψτε το κουμπί εγγραφής, διατηρήστε την αναπαραγωγή:
```
inline display{right} results{hide(capture)}
```

### `thumbnail-square-[WxH]` — προεπισκόπηση βίντεο σταθερού μεγέθους

Μετά τη λήψη, εμφανίζει το βίντεο ως ενσωματωμένο πρόγραμμα αναπαραγωγής σταθερού μεγέθους αντί για πλήρες πλάτος. Συνδυάστε με `inline` για μια συμπαγή διάταξη.

```
inline display{right} thumbnail-square-[120x90]
inline display{center} thumbnail-square-[200x150]
```

Το πλάτος και το ύψος είναι σε pixel.

### `invisible auto-show` — αυτόματη έναρξη εγγραφής

Κρύβει το widget ερώτησης από τη διάταξη, αλλά ανοίγει αυτόματα τον βιντεογράφημα όταν φορτώνεται η σελίδα.

```
invisible auto-show
inline invisible auto-show
```

### Απόκρυψη της ετικέτας

```
inline text-nolabel display{center, large}
```

## Παράδειγμα χρήσης

### Βίντεο επιθεώρησης χώρου με όριο

| type | name | label | hint | parameters |
|------|------|-------|------|------------|
| video | site_video | Καταγράψτε το σημείο ύδρευσης | Περπατήστε γύρω από ολόκληρη την εγκατάσταση. Μέγιστο 90 δευτερόλεπτα. | `max-duration=90 quality=normal` |

### Δεσμευτικό βίντεο — μόνο εάν αναφερθεί ζημιά

| type | name | label | relevant | required |
|------|------|-------|----------|----------|
| select_one yesno | damage_found | Βρέθηκε ζημιά; | | |
| video | damage_video | Καταγράψτε βίντεο της ζημιάς | `${damage_found} = 'yes'` | `${damage_found} = 'yes'` |

## Βέλτιστες πρακτικές

1.  Ορίστε `max-duration` — οι απεριόριστες εγγραφές βίντεο μπορούν εύκολα να υπερβούν τα 100 MB και να αποτύχουν να μεταφορτωθούν σε αδύναμες συνδέσεις.
2.  Χρησιμοποιήστε `quality=low` για έρευνες παρακολούθησης όπου απαιτούνται οπτικά στοιχεία αλλά όχι λεπτομέρειες — μειώνει δραστικά το μέγεθος του αρχείου.
3.  Γράψτε συγκεκριμένες οδηγίες εγγραφής στη στήλη `hint` (π.χ. "Περπατήστε γύρω από ολόκληρο το κτίριο, κρατήστε την κάμερα σταθερή").
4.  Εξετάστε εάν το βίντεο είναι απαραίτητο — μια φωτογραφία (`image`) είναι συνήθως επαρκής για στατικά στοιχεία και παράγει πολύ μικρότερα αρχεία.
5.  Δοκιμάστε την απόδοση μεταφόρτωσης στο πραγματικό δίκτυο πεδίου πριν από την ανάπτυξη.

## Περιορισμοί

-   Τα αρχεία βίντεο είναι πολύ μεγάλα — ένα βίντεο 1 λεπτού σε κανονική ποιότητα είναι συνήθως 20–60 MB ανάλογα με τη συσκευή.
-   Η μεταφόρτωση μεγάλων αρχείων βίντεο απαιτεί καλή σύνδεση δικτύου. Εξετάστε το ενδεχόμενο να απαιτείται συγχρονισμός Wi-Fi για φόρμες με πολλά βίντεο.
-   Δεν υποστηρίζουν όλα τα προγράμματα περιήγησης ιστού την καταγραφή βίντεο μέσω MediaRecorder — το Chrome είναι το πιο αξιόπιστο.
-   Η ανάλυση των απαντήσεων βίντεο είναι χειροκίνητη και χρονοβόρα. Χρησιμοποιήστε την με φειδώ και μόνο όταν το περιεχόμενο βίντεο προσθέτει μοναδική αξία.

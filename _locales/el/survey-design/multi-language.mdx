Το rtSurvey παρέχει ισχυρή υποστήριξη πολλαπλών γλωσσών, επιτρέποντάς σας να δημιουργείτε έρευνες σε πολλές γλώσσες. Αυτή η δυνατότητα είναι κρίσιμη για τη διεξαγωγή έρευνας σε διαφορετικούς γλωσσικούς πληθυσμούς ή σε πολύγλωσσα περιβάλλοντα.

## Ρύθμιση Ερευνών Πολλαπλών Γλωσσών

Για να δημιουργήσετε μια έρευνα πολλαπλών γλωσσών στο rtSurvey, πρέπει να προσθέσετε στήλες ειδικές για κάθε γλώσσα στο XLSForm σας. Δείτε πώς:

1. **Μεταφράσεις Ετικετών (Label Translations)**: Προσθέστε στήλες για κάθε γλώσσα χρησιμοποιώντας τη μορφή `label::Language (code)`.
2. **Μεταφράσεις Υποδείξεων (Hint Translations)**: Χρησιμοποιήστε το `hint::Language (code)` για τη μετάφραση των υποδείξεων.
3. **Μεταφράσεις Αρχείων Πολυμέσων (Media File Translations)**: Για πολυμέσα ειδικά για μια γλώσσα, χρησιμοποιήστε το `media::Language (code)`.

Παράδειγμα:

```
| type    | name | label::English (en) | label::Español (es) | hint::English (en) | hint::Español (es) |
|---------|------|---------------------|---------------------|---------------------|---------------------|
| integer | age  | How old are you?    | ¿Cuántos años tienes?| Enter your age      | Ingrese su edad     |
```

## Κωδικοί Γλωσσών

Συνιστάται η χρήση των επίσημων κωδικών γλώσσας 2 χαρακτήρων (subtags) μετά το όνομα της γλώσσας. Αυτό διευκολύνει την αντιστοίχιση της γλώσσας της φόρμας με τη γλώσσα της διεπαφής χρήστη. Μπορείτε να βρείτε τους επίσημους κωδικούς [εδώ](https://www.iana.org/assignments/language-subtag-registry/language-subtag-registry).

## Ορισμός Προεπιλεγμένης Γλώσσας

Για να ορίσετε μια προεπιλεγμένη γλώσσα για τη συλλογή δεδομένων, χρησιμοποιήστε το φύλλο εργασίας `settings` στο XLSForm σας:

```
| form_id   | version | default_language |
|-----------|---------|-------------------|
| test_form | 101     | French (fr)       |
```

## Χαρακτηριστικά Ειδικά για το rtSurvey

### Δυναμική Εναλλαγή Γλώσσας

Το rtSurvey επιτρέπει στους χρήστες να αλλάζουν γλώσσες δυναμικά κατά τη διάρκεια της συλλογής δεδομένων:

- Στη διεπαφή ιστού, χρησιμοποιήστε το αναπτυσσόμενο μενού γλώσσας στην επάνω γραμμή πλοήγησης.
- Στην εφαρμογή για κινητά, αποκτήστε πρόσβαση στις επιλογές γλώσσας μέσω του μενού ρυθμίσεων.

### Μηνύματα Επικύρωσης Ειδικά για τη Γλώσσα

Το rtSurvey επεκτείνει την υποστήριξη πολλαπλών γλωσσών στα μηνύματα επικύρωσης:

```
| type    | name | constraint | constraint_message::English (en) | constraint_message::Español (es) |
|---------|------|------------|----------------------------------|----------------------------------|
| integer | age  | . <= 150   | Age must be 150 or less          | La edad debe ser 150 or menos     |
```

### Εντοπισμένα μηνύματα απαιτούμενων πεδίων

Χρησιμοποιήστε το `required_message::Language (code)` για να εμφανίσετε ένα μεταφρασμένο σφάλμα όταν ένα απαιτούμενο πεδίο παραμένει κενό:

```
| type | name | required | required_message::English (en) | required_message::Tiếng Việt (vi) |
|------|------|----------|-------------------------------|----------------------------------|
| text | name | yes | This field is required | Trường này là bắt buộc |
```

### Υποστήριξη Γλωσσών RTL

Για γλώσσες που γράφονται από δεξιά προς τα αριστερά (RTL), όπως τα Αραβικά ή τα Εβραϊκά, το rtSurvey προσαρμόζει αυτόματα τη διάταξη:

```
| type | name | label::English (en) | label::Arabic (ar) |
|------|------|---------------------|---------------------|
| text | name | Your name           | اسمك                |
```

### Εμφάνιση Ειδική για τη Γλώσσα

Το rtSurvey σάς επιτρέπει να καθορίσετε διαφορετικές εμφανίσεις για διαφορετικές γλώσσες:

```
| type | name | label::English (en) | label::Chinese (zh) | appearance::English (en) | appearance::Chinese (zh) |
|------|------|---------------------|---------------------|--------------------------|---------------------------|
| text | address | Address          | 地址                 | multiline                | textarea                  |
```

## Μορφοποίηση HTML σε δίγλωσσες ετικέτες

Μπορείτε να συνδυάσετε ετικέτες HTML με περιτύλιγμα γλώσσας σε ένα μόνο κελί ετικέτας. Το rtSurvey εξάγει το μπλοκ της ενεργής γλώσσας και αποδίδει το υπόλοιπο HTML.

Παράδειγμα χρήσης έντονης γραφής και χρώματος γραμματοσειράς ανά γλώσσα:

```
<en><big><b>Section 2: Household Income</b></big><br>Ask the household head only.</en><vi><big><b>Phần 2: Thu nhập hộ gia đình</b></big><br>Chỉ hỏi chủ hộ.</vi>
```

Υποστηριζόμενες ετικέτες inline μέσα σε περιτύλιγμα γλώσσας: `<b>`, `<i>`, `<u>`, `<big>`, `<small>`, `<font color="...">`, `<br>`, `<span style="...">`.

Παράδειγμα έγχρωμου κειμένου ανά γλώσσα:

```
<en><font color="red">Required field</font></en><vi><font color="red">Trường bắt buộc</font></vi>
```

## Υπολογισμοί με επίγνωση γλώσσας

Όταν μια φόρμα έχει ένα πεδίο `${language_use}` (που ορίζεται από ένα widget `change_language`), χρησιμοποιήστε το `if()` για να επιστρέψετε τιμές στην ενεργή γλώσσα:

```
if(${language_use} = 'en', label_en, label_vi)
```

Παράδειγμα — εμφάνιση αποτελέσματος αναζήτησης στην ενεργή γλώσσα χρησιμοποιώντας το `pulldata('rawquery', ...)`:

```
| type      | name        | calculation                                                                 |
|-----------|-------------|-----------------------------------------------------------------------------|
| calculate | district_label | if(${language_use} = 'en', pulldata('rawquery', concat(${family_path}, '/locations.db::externalData'), 'SELECT label_en FROM externalData WHERE code = ?', ${district}), pulldata('rawquery', concat(${family_path}, '/locations.db::externalData'), 'SELECT label_vi FROM externalData WHERE code = ?', ${district})) |
```

Σημείωση: Το πεδίο `language_use` ορίζεται συνήθως από ένα widget εμφάνισης `change_language`. Δείτε Appearance — change_language.

## Βέλτιστες Πρακτικές για Έρευνες Πολλαπλών Γλωσσών

1. **Συνεπής Ονοματοδοσία**: Χρησιμοποιήστε συνεπείς κωδικούς γλώσσας σε όλη τη φόρμα σας.
2. **Επαγγελματική Μετάφραση**: Απασχολήστε επαγγελματίες μεταφραστές που είναι εξοικειωμένοι με το πλαίσιο της έρευνας.
3. **Σημειώσεις Πλαισίου**: Παρέχετε σημειώσεις πλαισίου για τους μεταφραστές για να διασφαλίσετε ακριβείς μεταφράσεις.
4. **Δοκιμή**: Δοκιμάστε τη φόρμα σας σε όλες τις γλώσσες πριν από την ανάπτυξη.
5. **Υποστήριξη Unicode**: Βεβαιωθείτε ότι οι συσκευές συλλογής δεδομένων υποστηρίζουν Unicode για μη λατινικές γραφές.
6. **Πολυμέσα Ειδικά για τη Γλώσσα**: Χρησιμοποιήστε πολιτισμικά κατάλληλες εικόνες ή ήχο για κάθε γλώσσα.
7. **Αποφύγετε Κείμενο σε Εικόνες**: Εάν χρησιμοποιείτε εικόνες με κείμενο, δημιουργήστε ξεχωριστές εικόνες για κάθε γλώσσα.

## Διαχείριση Ειδικών Περιπτώσεων

### Απαντήσεις σε Μεικτές Γλώσσες

Το rtSurvey επιτρέπει στους ερωτηθέντες να εισάγουν κείμενο σε οποιαδήποτε γραφή, ανεξάρτητα από την επιλεγμένη γλώσσα της φόρμας. Αυτό είναι χρήσιμο για την καταγραφή ονομάτων ή διευθύνσεων στην αρχική τους γραφή.

### Τύποι Ερωτήσεων Ειδικοί για τη Γλώσσα

Ορισμένοι τύποι ερωτήσεων μπορεί να είναι πιο κατάλληλοι για ορισμένες γλώσσες. Το rtSurvey σάς επιτρέπει να χρησιμοποιείτε διαφορετικούς τύπους ερωτήσεων για διαφορετικές γλώσσες:

```
| type::English (en) | type::Japanese (ja) | name | label::English (en) | label::Japanese (ja) |
|--------------------|---------------------|------|---------------------|----------------------|
| text               | select_one kanji    | name | Enter your name     | 名前を選んでください    |
```

## Εξαγωγή Δεδομένων Πολλαπλών Γλωσσών

Κατά την εξαγωγή δεδομένων από το rtSurvey:

- Επιλέξτε να κάνετε εξαγωγή σε μια συγκεκριμένη γλώσσα ή να συμπεριλάβετε όλες τις γλωσσικές εκδόσεις.
- Τα μεταδεδομένα γλώσσας περιλαμβάνονται στην εξαγωγή, υποδεικνύοντας ποια γλώσσα χρησιμοποιήθηκε για κάθε απάντηση.

## Σκέψεις για την Εφαρμογή για Κινητά

- Η εφαρμογή rtSurvey για κινητά υποστηρίζει εναλλαγή γλώσσας εκτός σύνδεσης.
- Βεβαιωθείτε ότι όλα τα απαιτούμενα αρχεία γλώσσας έχουν ληφθεί πριν βγείτε εκτός σύνδεσης.

## Γνωστοί Περιορισμοί

- Ορισμένες προηγμένες λειτουργίες ενδέχεται να μην είναι διαθέσιμες σε όλες τις γλώσσες.
- Οι εξαιρετικά μεγάλες μεταφράσεις ενδέχεται να επηρεάσουν τη διάταξη σε μικρότερες οθόνες.

Αξιοποιώντας τις δυνατότητες πολλαπλών γλωσσών του rtSurvey, μπορείτε να δημιουργήσετε περιεκτικές, προσβάσιμες έρευνες που προσεγγίζουν διαφορετικούς πληθυσμούς και παρέχουν υψηλής ποιότητας, γλωσσικά ακριβή δεδομένα.

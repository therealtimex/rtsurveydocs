Η ενότητα **Διαχείριση υποβολών** (που προσπελαύνεται μέσω του κουμπιού **Προβολή δεδομένων** στην ενότητα Οικογένειας φορμών) επιτρέπει στους διαχειριστές έργων και εποπτεύοντες να αλληλεπιδρούν άμεσα με εισερχόμενα ακατέργαστα δεδομένα.


## Επισκόπηση δεδομένων και στήλες

Το πλέγμα δεδομένων εμφανίζει δυναμικά δεδομένα που συλλέγονται για μια συγκεκριμένη φόρμα. Λειτουργεί σε δύο κύριες λειτουργίες: **Επίσημη** (Οριστικοποιημένες εγγραφές) και **Εργασίας** (Πραγματικός χρόνος, μη οριστικοποιημένες εγγραφές).

### Κύριες στήλες δεδομένων

Ανεξάρτητα από τις ερωτήσεις της φόρμας, το πλέγμα περιλαμβάνει πολλές τυπικές στήλες μεταδεδομένων:

- **Υποβλήθηκε από:** Αναγνωρίζει την πλατφόρμα προέλευσης της υποβολής (π.χ. FA για εφαρμογή πεδίου, WEB για φόρμα web, RS για απομακρυσμένα συστήματα).
- **Λεπτομέρεια:** Ανοίγει εστιασμένη, μεμονωμένη προβολή εγγραφής (εικονίδιο αναζήτησης) για επιθεώρηση κάθε μεταβλητής και απάντησης.
- **iNote:** Επιτρέπει σε εποπτεύοντες να επισυνάψουν πλαϊνές σημειώσεις ή εσωτερικά σχόλια σε συγκεκριμένη εγγραφή χωρίς αλλαγή των δεδομένων (εικονίδιο μολυβιού).
- **Πεδία ημερομηνίας:** Χρονοσφραγίδες που υποδηλώνουν πότε ξεκίνησε, ολοκληρώθηκε ή συγχρονίστηκε η εγγραφή.
- **Συνημμένα πολυμέσα:** Άμεσοι σύνδεσμοι μικρογραφιών σε εικόνες, υπογραφές ή αρχεία που συλλέχθηκαν κατά την έρευνα.
- **Ομάδες επανάληψης:** Αφιερωμένοι σύνδεσμοι για πρόσβαση σε ένθετους πίνακες για επαναλαμβανόμενες ερωτήσεις.

## Ενέργειες υποβολής

Η διεπαφή παρέχει αναπτυσσόμενο μενού ενεργειών που μπορούν να εκτελεστούν σε επιλεγμένες εγγραφές:

- **Δημιουργία νέας εγκατάστασης:** Επιτρέπει στους διαχειριστές να εισάγουν χειροκίνητα νέα εγγραφή έρευνας απευθείας στη βάση δεδομένων.
- **Επιστροφή εγκατάστασης:** Απορρίπτει την υποβεβλημένη εγγραφή και αναθέτει στον απαριθμητή να επαληθεύσει ή να επανασυλλέξει τις πληροφορίες.
- **Παρακολούθηση εγκατάστασης:** Επισημαίνει εγγραφή για περαιτέρω προσοχή, συνήθως αποστέλλοντας ειδοποίηση στην ομάδα πεδίου.
- **Εξαγωγή σε αρχείο εντολών επιστροφής / Πακέτο εντολών παρακολούθησης:** Δημιουργεί μαζικές εξαγωγές που περιέχουν σύνολα δεδομένων επισημασμένα για επιστροφές ή παρακολουθήσεις.
- **Μετατροπή σε XML:** Μετατρέπει το δομημένο σύνολο δεδομένων πίσω στην ακατέργαστη μορφή XML για ανάλυση backend ή ενσωμάτωση συστήματος.
- **Προώθηση εγκαταστάσεων:** (Διαθέσιμο σε λειτουργία *Εργασίας*) Ωθεί μη οριστικοποιημένα δεδομένα αμέσως σε άλλη συσκευή ή χρήστη.
- **Διαγραφή:** Αφαιρεί μόνιμα επιλεγμένες εγκαταστάσεις από τη βάση δεδομένων.

Το SSL πρέπει να διαμορφωθεί πριν μπορέσετε να συνδεθείτε. Όταν ανοίξετε την εφαρμογή για πρώτη φορά, θα ανακατευθυνθείτε αυτόματα στην οθόνη ρύθμισης SSL.

---

## Επιλογές ρύθμισης SSL

![Επιλογές ρύθμισης SSL](/img/ssl-setup/ssl-setup-options.png)

Επιλέξτε μία από τις τρεις επιλογές:

| Επιλογή | Πότε να χρησιμοποιηθεί |
|---------|------------------------|
| **Δωρεάν υποτομέας rtsurvey.com** *(Προτείνεται)* | Δεν απαιτείται ρύθμιση DNS. Δημιουργούμε την εγγραφή για εσάς. Έτοιμο σε 2–5 λεπτά. |
| **Δικό μου domain** | Έχετε ήδη ένα domain και το DNS του δείχνει σε αυτόν τον διακομιστή. |
| **Μη αυτόματη εγκατάσταση πιστοποιητικού** | Εταιρική ή προσαρμοσμένη CA. Απαιτεί πρόσβαση SSH. |

---

## Επιλογή 1 — Δωρεάν υποτομέας rtsurvey.com *(Προτείνεται)*

Αυτή είναι η ταχύτερη επιλογή. Δεν απαιτείται εγγραφή domain ή αλλαγές DNS.

![Φόρμα ρύθμισης HTTPS](/img/ssl-setup/ssl-setup-form.png)

> **Πριν συνεχίσετε:** Ένας δωρεάν υποτομέας απαιτεί ενεργό λογαριασμό στο [licenses.rtsurvey.com](https://licenses.rtsurvey.com). Το δωρεάν πρόγραμμα περιλαμβάνει 1 υποτομέα (`*.rtsurvey.com`).

1. Κάντε κλικ στο **Δωρεάν υποτομέας rtsurvey.com** για να αναπτύξετε την ενότητα
2. Πληκτρολογήστε το επιθυμητό όνομα υποτομέα στο πεδίο **Ο ΥΠΟΤΟΜΕΑΣ ΣΑΣ**

   > Χρησιμοποιήστε πεζά γράμματα, αριθμούς και παύλες. 3–30 χαρακτήρες.
   > Παράδειγμα: `myproject` → `myproject.rtsurvey.com`

3. Επικολλήστε το **rtSurvey DNS Token** σας από το [licenses.rtsurvey.com](https://licenses.rtsurvey.com) στο πεδίο token
4. Κάντε κλικ στο **Δημιουργία ασφαλούς υποτομέα**

Μόλις υποβληθεί, η εφαρμογή θα ξεκινήσει την προετοιμασία του πιστοποιητικού σας:

![Πρόοδος ρύθμισης HTTPS](/img/ssl-setup/ssl-setup-progress.png)

Τα τέσσερα βήματα εκτελούνται αυτόματα:
- **Αίτημα εγγραφής DNS** — δημιουργεί την εγγραφή DNS για τον υποτομέα σας
- **Αναμονή για διάδοση DNS** — συνήθως 2–5 λεπτά
- **Έκδοση πιστοποιητικού SSL** — το Let's Encrypt υπογράφει το πιστοποιητικό σας
- **Ενεργοποίηση HTTPS** — το Nginx επαναφορτώνεται με το νέο πιστοποιητικό

5. Μόλις ολοκληρωθεί, θα ανακατευθυνθείτε αυτόματα στη νέα σας διεύθυνση HTTPS

## Επιλογή 2 — Δικό μου domain

Χρησιμοποιήστε το εάν έχετε ένα υπάρχον domain και η εγγραφή `A` του DNS του δείχνει ήδη στην IP αυτού του διακομιστή.

1. Κάντε κλικ στο **Δικό μου domain** για να αναπτύξετε την ενότητα
2. Εισαγάγετε το πλήρες όνομα του domain σας (π.χ. `survey.myorganization.org`)
3. Κάντε κλικ στο **Δημιουργία πιστοποιητικού**



Το Let's Encrypt θα επαληθεύσει το domain σας και θα εκδώσει ένα πιστοποιητικό. Αυτό απαιτεί το DNS να έχει κατευθυνθεί σωστά πρώτα — διαφορετικά το αίτημα θα αποτύχει.

## Επιλογή 3 — Μη αυτόματη εγκατάσταση πιστοποιητικού

Για εταιρικά περιβάλλοντα που χρησιμοποιούν μια προσαρμοσμένη ή εσωτερική CA. Θα τοποθετήσετε τα αρχεία του πιστοποιητικού σας στον διακομιστή μέσω SSH και, στη συνέχεια, θα εισαγάγετε το domain σας στην εφαρμογή.

### Προαπαιτούμενα

- Πρόσβαση SSH στον διακομιστή
- Ένα έγκυρο πιστοποιητικό και ιδιωτικό κλειδί για το domain σας (μορφή PEM)

### Βήμα 1 — Σύνδεση στον διακομιστή μέσω SSH

```bash
ssh root@<server-ip>
```

### Βήμα 2 — Τοποθέτηση των αρχείων πιστοποιητικού σας

Δημιουργήστε τον κατάλογο και αντιγράψτε τα αρχεία σας:

```bash
mkdir -p /etc/letsencrypt/live/<your-domain>
```

Αντιγράψτε τα αρχεία σας σε αυτόν τον κατάλογο με αυτά τα ακριβή ονόματα:

| Αρχείο | Περιγραφή |
|--------|-----------|
| `fullchain.pem` | Το πιστοποιητικό σας + τυχόν ενδιάμεσα πιστοποιητικά CA (συνενωμένα) |
| `privkey.pem` | Το ιδιωτικό σας κλειδί |

Παράδειγμα:

```bash
# Αντιγραφή από το τοπικό σας μηχάνημα (εκτελέστε το τοπικά, όχι στον διακομιστή)
scp fullchain.pem root@<server-ip>:/etc/letsencrypt/live/<your-domain>/fullchain.pem
scp privkey.pem  root@<server-ip>:/etc/letsencrypt/live/<your-domain>/privkey.pem
```

Ορίστε τα σωστά δικαιώματα:

```bash
chmod 644 /etc/letsencrypt/live/<your-domain>/fullchain.pem
chmod 600 /etc/letsencrypt/live/<your-domain>/privkey.pem
```

### Βήμα 3 — Εισαγωγή του domain σας στην εφαρμογή



1. Στην οθόνη ρύθμισης SSL, κάντε κλικ στο **Μη αυτόματη εγκατάσταση πιστοποιητικού**
2. Εισαγάγετε το όνομα του domain σας (πρέπει να ταιριάζει με το Common Name ή το SAN του πιστοποιητικού)
3. Κάντε κλικ στο **Εφαρμογή**

Ο διακομιστής θα διαμορφώσει το Nginx με το πιστοποιητικό σας και θα επαναφορτωθεί αυτόματα.

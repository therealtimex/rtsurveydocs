import { Callout, Steps } from 'nextra/components'

Χρησιμοποιήστε αυτόν τον οδηγό εάν θέλετε να εκτελέσετε το rtSurvey στον δικό σας διακομιστή (VPS, bare metal ή τοπικό μηχάνημα) χρησιμοποιώντας τη δημόσια εικόνα Docker `rtawebteam/rtcloud:survey-public`.

**Δεν απαιτείται σύνδεση στο Docker Hub** — η εικόνα είναι δημόσια.

Το container ενσωματώνει τα πάντα σε μια ενιαία εικόνα:
- Apache + PHP (διακομιστής εφαρμογής)
- Shiny Server (πίνακες αναλυτικών, θύρα 3838)
- Beanstalkd (ουρά εργασιών παρασκηνίου)

## Απαιτήσεις

### Διακομιστής

| Πόρος | Ελάχιστο | Συνιστώμενο |
|-------|---------|-------------|
| RAM | 4 GB | 8 GB |
| Δίσκος | 50 GB | 100 GB SSD |
| CPU | 2 vCPUs | 4 vCPUs |
| ΛΣ | Ubuntu 22.04 LTS | Ubuntu 22.04 LTS |

### Λογισμικό

- **Docker Engine 24.0+** — [οδηγός εγκατάστασης](https://docs.docker.com/engine/install/ubuntu/)
- **Docker Compose v2.0+** — περιλαμβάνεται στο Docker Desktop· σε Linux: `apt install docker-compose-plugin`

## Εγκατάσταση

<Steps>

### Δημιουργήστε έναν κατάλογο εργασίας

```bash
mkdir -p /opt/rtsurvey && cd /opt/rtsurvey
```

### Δημιουργήστε `docker-compose.yml`

```yaml
services:
  mysql:
    image: mysql:8.0
    container_name: rtsurvey-mysql
    restart: unless-stopped
    command: >
      --default-authentication-plugin=mysql_native_password
      --character-set-server=utf8
      --collation-server=utf8_unicode_ci
      --sql-mode=NO_ENGINE_SUBSTITUTION
    environment:
      MYSQL_ROOT_PASSWORD: ${MYSQL_ROOT_PASSWORD}
      MYSQL_DATABASE: ${MYSQL_DATABASE:-smartsurvey}
      MYSQL_USER: ${MYSQL_USER:-smartsurvey}
      MYSQL_PASSWORD: ${MYSQL_PASSWORD}
      MYSQL_ROOT_HOST: '%'
    volumes:
      - mysql_data:/var/lib/mysql
    networks:
      - rtsurvey-net
    healthcheck:
      test: ["CMD-SHELL", "mysqladmin ping -h localhost -u root -p$$MYSQL_ROOT_PASSWORD"]
      interval: 10s
      timeout: 5s
      retries: 5
      start_period: 30s

  rtsurvey:
    image: rtawebteam/rtcloud:survey-public
    container_name: rtsurvey-app
    restart: unless-stopped
    entrypoint: ["/bin/entrypoint-production.sh"]
    depends_on:
      mysql:
        condition: service_healthy
    ports:
      - "${APP_PORT:-8080}:80"
      - "${SHINY_PORT:-3838}:3838"
    env_file:
      - .env
    volumes:
      - app_uploads:/var/www/html/smartsurvey/uploads
      - app_audios:/var/www/html/smartsurvey/audios
      - app_downloads:/var/www/html/smartsurvey/downloads
      - app_gallery:/var/www/html/smartsurvey/gallery
      - app_tmp:/var/www/html/smartsurvey/tmp
      - app_cache:/var/www/html/smartsurvey/cache
      - app_runtime:/var/www/html/smartsurvey/protected/runtime
      - app_assets:/var/www/html/smartsurvey/assets
      - app_aggregate:/var/www/html/smartsurvey/aggregate
    networks:
      - rtsurvey-net
    healthcheck:
      test: ["CMD", "curl", "-f", "http://localhost/health"]
      interval: 30s
      timeout: 10s
      retries: 3
      start_period: 90s

  # Optional: Embedded Keycloak SSO
  # Start with: docker compose --profile embed-keycloak up -d
  keycloak:
    image: quay.io/keycloak/keycloak:latest
    container_name: rtsurvey-keycloak
    restart: unless-stopped
    profiles:
      - embed-keycloak
    command: start --import-realm
    environment:
      KEYCLOAK_ADMIN: ${KEYCLOAK_ADMIN_USER:-admin}
      KEYCLOAK_ADMIN_PASSWORD: ${KEYCLOAK_ADMIN_PASSWORD}
      KC_HTTP_ENABLED: "true"
      KC_HTTP_RELATIVE_PATH: /auth
      KC_PROXY_HEADERS: xforwarded
      KC_HOSTNAME: ${KC_HOSTNAME}
      KC_HOSTNAME_STRICT: "false"
      KC_DB: mysql
      KC_DB_URL_DATABASE: ${KEYCLOAK_DB:-keycloak}
      KC_DB_URL_HOST: mysql
      KC_DB_USERNAME: ${KEYCLOAK_DB_USER:-keycloak}
      KC_DB_PASSWORD: ${KEYCLOAK_DB_PASSWORD}
    volumes:
      - ./keycloak-import:/opt/keycloak/data/import
    ports:
      - "${KEYCLOAK_PORT:-8091}:8080"
    depends_on:
      mysql:
        condition: service_healthy
    networks:
      - rtsurvey-net
    healthcheck:
      test: ["CMD-SHELL", "curl -f http://localhost:9000/health/ready || exit 1"]
      interval: 30s
      timeout: 10s
      retries: 10
      start_period: 120s

volumes:
  mysql_data:
  app_uploads:
  app_audios:
  app_downloads:
  app_gallery:
  app_tmp:
  app_cache:
  app_runtime:
  app_assets:
  app_aggregate:

networks:
  rtsurvey-net:
    driver: bridge
```

### Δημιουργήστε `.env`

```bash
# Project
PROJECT_ID=mysurvey
PROJECT_TYPE=rtsurvey
PROJECT_URL=your-server-ip-or-domain
HTTP_PROTOCOL=http
TZ=UTC

# Database
MYSQL_HOST=mysql
MYSQL_DATABASE=smartsurvey
MYSQL_USER=smartsurvey
MYSQL_ROOT_PASSWORD=change-this-root-password
MYSQL_PASSWORD=change-this-app-password

# Admin (set before first startup — cannot change via env after DB is created)
ADMIN_PASSWORD=change-this-admin-password

# Runtime
RUN_ENV=prod
RUN_MODE=admin
GII_ENABLED=false
CSRF_VALIDATION_ENABLED=true

# Ports (optional — defaults shown)
APP_PORT=8080
SHINY_PORT=3838
```

<Callout type="warning">
Αλλάξτε τα `MYSQL_ROOT_PASSWORD` και `MYSQL_PASSWORD` πριν ξεκινήσετε. Χρησιμοποιήστε ισχυρές τυχαίες συμβολοσειρές (32+ χαρακτήρες) σε παραγωγή.
</Callout>

### Εκκινήστε τη στοίβα

```bash
docker compose up -d
```

Η πρώτη εκκίνηση διαρκεί περίπου 60–90 δευτερόλεπτα — η MySQL αρχικοποιεί τη βάση δεδομένων κατά την πρώτη εκτέλεση.

### Επαλήθευση

```bash
# Check all containers are running
docker compose ps

# Check application health
curl http://localhost:8080/health
```

</Steps>

## Πρώτη Σύνδεση

Μόλις περάσει ο έλεγχος υγείας, ανοίξτε τον περιηγητή σας:

```
http://your-server:8080/cpms/cpmsSite/login
```

| Πεδίο | Τιμή |
|-------|------|
| Όνομα χρήστη | `admin` |
| Κωδικός πρόσβασης | τιμή του `ADMIN_PASSWORD` στο αρχείο `.env` σας (προεπιλογή: `admin`) |

<Callout type="warning">
Ορίστε το `ADMIN_PASSWORD` στο αρχείο `.env` σας πριν από την πρώτη εκκίνηση. Το entrypoint το ορίζει κατά την πρώτη εκτέλεση — η αλλαγή του μετά την αρχικοποίηση της βάσης δεδομένων δεν έχει αποτέλεσμα.
</Callout>

## Μεταβλητές Περιβάλλοντος

### Απαιτούμενες από το container εφαρμογής

Το entrypoint θα αρνηθεί να ξεκινήσει εάν λείπει οποιαδήποτε από αυτές:

| Μεταβλητή | Περιγραφή |
|-----------|-----------|
| `PROJECT_ID` | Μοναδικό αναγνωριστικό για αυτή την παρουσία (αλφαριθμητικό, χωρίς κενά) |
| `PROJECT_URL` | Domain ή IP όπου προσπελαύνεται η εφαρμογή (χωρίς πρόθεμα `http://`) |
| `MYSQL_HOST` | Hostname MySQL — χρησιμοποιήστε το όνομα της υπηρεσίας Docker (π.χ. `mysql`) |
| `MYSQL_DATABASE` | Όνομα βάσης δεδομένων |
| `MYSQL_PASSWORD` | Κωδικός χρήστη βάσης δεδομένων |

### Απαιτούμενες από το container MySQL

| Μεταβλητή | Περιγραφή |
|-----------|-----------|
| `MYSQL_ROOT_PASSWORD` | Κωδικός root MySQL (χρησιμοποιείται από το container `mysql`, όχι από την εφαρμογή) |

### Συνιστώμενες

| Μεταβλητή | Προεπιλογή | Περιγραφή |
|-----------|-----------|-----------|
| `MYSQL_USER` | `smartsurvey` | Όνομα χρήστη βάσης δεδομένων |
| `ADMIN_PASSWORD` | `admin` | Αρχικός κωδικός διαχειριστή — **ορίστε πριν από την πρώτη εκκίνηση**, δεν μπορεί να αλλάξει μέσω env μετά τη δημιουργία βάσης δεδομένων |
| `HTTP_PROTOCOL` | `https` | Ορίστε σε `http` εάν δεν χρησιμοποιείτε SSL |
| `PROJECT_PORT` | `80` | Εξωτερική θύρα στην οποία συνδέονται οι χρήστες (όχι η εσωτερική θύρα Docker) |
| `PROJECT_TYPE` | `rtwork` | Τύπος πλατφόρμας — χρησιμοποιήστε `rtsurvey` για την πλατφόρμα ερευνών |
| `TZ` | `UTC` | Ζώνη ώρας (π.χ. `Asia/Bangkok`, `America/New_York`) |

### Χρόνος εκτέλεσης

| Μεταβλητή | Προεπιλογή | Περιγραφή |
|-----------|-----------|-----------|
| `RUN_ENV` | `prod` | Λειτουργία περιβάλλοντος (`prod` ή `dev`) |
| `RUN_MODE` | `admin` | Ρόλος υπηρεσίας — χρησιμοποιήστε `admin` για εγκατάσταση single-server |
| `GII_ENABLED` | `false` | Διατηρήστε `false` σε παραγωγή (γεννήτρια κώδικα Yii) |
| `CSRF_VALIDATION_ENABLED` | `true` | Προστασία CSRF — διατηρήστε `true` |

### Άδεια χρήσης

| Μεταβλητή | Προεπιλογή | Περιγραφή |
|-----------|-----------|-----------|
| `REQUIRE_LICENSE` | `false` | Ορίστε σε `true` για επιβολή επαλήθευσης άδειας |
| `RTCLOUD_LICENSE_KEY` | — | Το κλειδί άδειάς σας — απαιτείται όταν `REQUIRE_LICENSE=true` |

## Διατήρηση Δεδομένων

Όλα τα δεδομένα χρηστών αποθηκεύονται σε ονομαστικούς τόμους Docker. Αυτοί επιβιώνουν επανεκκινήσεων container και ενημερώσεων εικόνας.

| Τόμος | Περιεχόμενα |
|-------|------------|
| `mysql_data` | Βάση δεδομένων (έρευνες, χρήστες, απαντήσεις) |
| `app_uploads` | Αρχεία ανεβασμένα από έρευνες |
| `app_gallery` | Βιβλιοθήκη πολυμέσων |
| `app_downloads` | Δημιουργημένα αρχεία εξαγωγής |
| `app_audios` | Ηχογραφήσεις |
| `app_runtime` | Αρχεία session και cache PHP |
| `app_aggregate` | Συγκεντρωτικά δεδομένα αναλυτικών |

docker compose pull

## Δημιουργία Αντιγράφων Ασφαλείας & Αποκατάσταση

### Δημιουργία αντιγράφου ασφαλείας βάσης δεδομένων

```bash
docker compose exec mysql \
  mysqldump -u root -p"${MYSQL_ROOT_PASSWORD}" smartsurvey \
  > backup-$(date +%Y%m%d).sql
```

### Αποκατάσταση βάσης δεδομένων

```bash
docker compose exec -T mysql \
  mysql -u root -p"${MYSQL_ROOT_PASSWORD}" smartsurvey \
  < backup-20240101.sql
```

### Δημιουργία αντιγράφου ασφαλείας ανεβασμένων αρχείων

```bash
docker run --rm \
  -v rtsurvey_app_uploads:/data \
  -v $(pwd):/backup \
  alpine tar czf /backup/uploads-$(date +%Y%m%d).tar.gz -C /data .
```

## Ενσωματωμένο Keycloak (Προαιρετικό SSO)

Το αρχείο compose παραγωγής περιλαμβάνει ένα προαιρετικό container Keycloak για SSO. Μοιράζεται την ίδια παρουσία MySQL και ενεργοποιείται μέσω προφίλ Docker Compose.

<Callout type="info">
Το ενσωματωμένο Keycloak απαιτεί τουλάχιστον **4 GB RAM**. Είναι προαιρετικό — παραλείψτε το εάν δεν χρειάζεστε SSO.
</Callout>

### Προσθέστε μεταβλητές Keycloak στο `.env`

```bash
# Keycloak admin
KEYCLOAK_ADMIN_USER=admin
KEYCLOAK_ADMIN_PASSWORD=change-this-keycloak-password

# Keycloak database (created automatically in the shared MySQL on first run)
KEYCLOAK_DB=keycloak
KEYCLOAK_DB_USER=keycloak
KEYCLOAK_DB_PASSWORD=change-this-keycloak-db-password

# KC_HOSTNAME: full public URL of your server (Keycloak appends /auth automatically)
KC_HOSTNAME=http://your-server:8091

# Port Keycloak listens on (host)
KEYCLOAK_PORT=8091

# Tell the rtCloud app to connect to embedded Keycloak
EMBED_KEYCLOAK=true
KEYCLOAK_URL=http://your-server:8091
KEYCLOAK_REALM=rtsurvey
KEYCLOAK_CLIENT_ID=rtsurvey
KEYCLOAK_CLIENT_SECRET=your-client-secret
```

Η υπηρεσία `keycloak` περιλαμβάνεται ήδη στο `docker-compose.yml` παραπάνω (υπό το προφίλ `embed-keycloak` — δεν θα εκκινήσει εκτός αν χρησιμοποιήσετε `--profile embed-keycloak`).

Δημιουργήστε τον κατάλογο εισαγωγής (το Keycloak θα ξεκινήσει χωρίς αυτόν αλλά η αυτόματη προμήθεια realm δεν θα λειτουργήσει):

```bash
mkdir -p /opt/rtsurvey/keycloak-import
```

### Εκκίνηση με Keycloak

```bash
docker compose --profile embed-keycloak up -d
```

Για εκκίνηση χωρίς Keycloak (προεπιλογή):

```bash
docker compose up -d
```

### Κονσόλα διαχείρισης Keycloak

Μόλις είναι υγιές, αποκτήστε πρόσβαση στο UI διαχείρισης Keycloak στη διεύθυνση:

```
http://your-server:8091/auth/admin
```

Συνδεθείτε με `KEYCLOAK_ADMIN_USER` / `KEYCLOAK_ADMIN_PASSWORD`.

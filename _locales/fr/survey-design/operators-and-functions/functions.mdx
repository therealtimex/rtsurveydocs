### Fonctions de chaîne

<Callout type="warning">
Lorsque vous travaillez avec des chaînes dans des expressions, il est important d'utiliser des guillemets simples ('') pour encadrer les chaînes littérales. Cependant, une exception survient lorsque vous souhaitez inclure des guillemets simples à l'intérieur d'une chaîne littérale. Dans ce cas, vous pouvez utiliser des guillemets doubles ("") pour encadrer toute la chaîne.

Par exemple :
- Correct : if(`${yesno}` = 1, "a string with 'single quotes' in it", "no single quotes here")
- Incorrect : if(`${yesno}` = 1, 'a string with 'single quotes' in it', 'no single quotes here')

Concernant les guillemets typographiques (smart quotes), il est crucial d'être conscient de leur présence, car ils peuvent causer des problèmes dans les expressions. De nombreux éditeurs de texte enrichi convertissent automatiquement les guillemets droits ("" ou '') en guillemets typographiques ou courbes (“” ou ‘’), ce qui peut entraîner des erreurs de syntaxe ou un comportement inattendu. Pour éviter cela, assurez-vous d'utiliser des guillemets droits ('') de manière cohérente dans vos expressions.

N'hésitez pas à me faire savoir si vous avez d'autres questions ou si vous avez besoin d'une assistance supplémentaire !
</Callout>

rtSurvey prend en charge diverses fonctions, notamment :

1. `string(field)` : Convertit un champ en chaîne de caractères.
   - Exemple : `string(34.8)` sera converti en `'34.8'`.

2. `string-length(field)` : Renvoie la longueur d'un champ de chaîne.
   - Exemple : `string-length(.) > 3 and string-length(.) < 10` peut être utilisé pour s'assurer que le champ actuel contient entre 3 et 10 caractères.
   - **Modèle de dépendance en cascade** : `string-length(${province}) >= 0` est toujours évalué à `true` mais force rtSurvey à réévaluer l'expression chaque fois que `${province}` change. Utilisez ceci dans `relevant` pour déclencher un rafraîchissement en cascade lorsqu'un champ parent est mis à jour :
     | type | name | relevant |
     |------|------|----------|
     | select_one | district | `string-length(${province}) >= 0` |
     Cela garantit que la question sur le district réévalue son apparence `search()` ou `rawquery` chaque fois que la province change.

3. `substr(fieldorstring, startindex, endindex)` : Renvoie une sous-chaîne commençant à `startindex` et se terminant juste avant `endindex`. Les index commencent à 0 pour le premier caractère de la chaîne.
   - Exemple : `substr(${phone}, 0, 3)` renverra les trois premiers chiffres d'un numéro de téléphone.

4. `concat(a, b, c, ...)` : Concatène des champs (et/ou des chaînes) ensemble.
   - Exemple : `concat(${firstname}, ' ', ${lastname})` renverra un nom complet en combinant les valeurs des champs `firstname` et `lastname`.

5. `linebreak()` : Renvoie un caractère de saut de ligne.
   - Exemple : `concat(${field1}, linebreak(), ${field2}, linebreak(), ${field3})` renverra une liste de trois valeurs de champ avec des sauts de ligne entre elles.

6. `lower()` : Convertit une chaîne en minuscules.
   - Exemple : `lower('Street Name')` renverra "street name".

7. `upper()` : Convertit une chaîne en majuscules.
   - Exemple : `upper('Street Name')` renverra "STREET NAME".

### Fonctions select_one et select_multiple

1. `count-selected(field)` : Renvoie le nombre d'éléments sélectionnés dans un champ select_multiple.
   - Exemple : `count-selected(.) = 3` peut être utilisé comme expression de contrainte pour s'assurer que exactement trois choix sont sélectionnés.

2. `selected(field, value)` : Renvoie true ou false selon que la valeur spécifiée a été sélectionnée dans le champ select_one ou select_multiple.
   - Exemple : `selected(${color}, 'Blue')` peut être utilisé comme expression de pertinence pour afficher un groupe ou un champ uniquement si le répondant a sélectionné "Blue" comme couleur préférée.
   - Note : Le deuxième paramètre doit toujours spécifier la valeur du choix, pas l'étiquette du choix. Utilisez la valeur de la colonne value de la feuille de calcul choices de la définition du formulaire.

3. `selected-at(field, number)` : Renvoie l'élément sélectionné à la position spécifiée dans un champ select_multiple. Lorsque le nombre transmis est 0, il renvoie le premier élément sélectionné ; lorsque le nombre est 1, il renvoie le deuxième élément sélectionné, et ainsi de suite.
   - Exemple : `selected-at(${fruits}, 0) = 'Apple'` peut être utilisé comme expression de pertinence pour afficher un groupe ou un champ uniquement si le premier choix sélectionné est "Apple".
   - Note : La valeur renvoyée sera la valeur du choix, pas l'étiquette du choix. Utilisez la valeur de la colonne value de la feuille de calcul choices de la définition du formulaire.

4. `choice-label(field, value)` : Renvoie l'étiquette pour un choix de champ select_one ou select_multiple, tel que défini dans la feuille de calcul choices de la définition du formulaire.
   - Exemple 1 : `choice-label(${country}, ${country})` renverra l'étiquette du choix pour le choix actuellement sélectionné dans le champ nommé `country`.
   - Exemple 2 : `choice-label(${languages}, selected-at(${languages}, 0))` renverra l'étiquette du premier choix sélectionné dans le champ nommé `languages`.
   - Note : Cette fonction récupère l'étiquette du choix, pas la valeur. Elle utilise la colonne label de la feuille de calcul choices de la définition du formulaire.

### Fonctions de champ répété

Dans rtSurvey, si vous souhaitez poser la ou les mêmes questions plusieurs fois, vous pouvez placer un champ dans un groupe répété (repeat group). Cela entraîne plusieurs instances du même champ. Les fonctions suivantes peuvent vous aider à gérer ces champs répétés et les données répétées qu'ils produisent. Consultez le sujet d'aide sur les champs répétitifs pour plus de détails.

1. `join(string, repeatedfield)` : Pour un champ dans un groupe répété, génère une liste de valeurs séparées par une chaîne. Le premier paramètre spécifie le délimiteur à utiliser pour séparer les valeurs.
   - Exemple : `join(', ', ${member_name})` générera une liste unique séparée par des virgules à partir de tous les noms saisis.

2. `join-if(string, repeatedfield, expression)` : Fonctionne exactement comme `join()`, sauf qu'elle vérifie chaque instance du groupe répété à l'aide de l'expression fournie. Si l'expression est évaluée à false, l'élément sera omis du résultat.
   - Exemple : `join-if(', ', ${member_name}, ${age} >= 18)` générera une liste de noms séparés par des virgules pour les membres adultes uniquement (ceux âgés de 18 ans et plus).

3. `count(repeatgroup)` : Renvoie le nombre actuel de répétitions d'un groupe répété.
   - Exemple : `count(${groupname})` renverra le nombre d'instances du groupe.

4. `count-if(repeatgroup, expression)` : Fonctionne exactement comme `count()`, sauf qu'elle vérifie chaque instance du groupe répété à l'aide de l'expression fournie. Si l'expression est évaluée à false, l'élément sera omis du résultat.
   - Exemple : `count-if(${members}, ${age} >= 18)` renverra le nombre de membres adultes basé sur le champ d'âge au sein du groupe répété "members".

5. `sum(repeatedfield)` : Pour un champ dans un groupe répété, calcule la somme de toutes les valeurs.
   - Exemple : `sum(${loan_amount})` renverra la valeur totale de tous les prêts.

6. `sum-if(repeatedfield, expression)` : Fonctionne exactement comme `sum()`, sauf qu'elle vérifie chaque instance du groupe répété à l'aide de l'expression fournie. Si l'expression est évaluée à false, l'élément sera omis du résultat.
   - Exemple : `sum-if(${loan_amount}, ${loan_amount} > 500)` renverra la valeur totale de tous les prêts supérieurs à 500. Les prêts plus petits seront ignorés.

7. `min(repeatedfield)` : Pour un champ dans un groupe répété, calcule le minimum de toutes les valeurs.
   - Exemple : `min(${member_age})` renverra l'âge du membre le plus jeune du groupe.

8. `min-if(repeatedfield, expression)` : Fonctionne exactement comme `min()`, sauf qu'elle vérifie chaque instance du groupe répété à l'aide de l'expression fournie. Si l'expression est évaluée à false, l'élément sera omis du résultat.
   - Exemple : `min-if(${member_age}, ${member_age} >= 18)` renverra l'âge de l'adulte le plus jeune du groupe. Ceux de moins de 18 ans seront ignorés.

9. `max(repeatedfield)` : Pour un champ dans un groupe répété, calcule le maximum de toutes les valeurs.
   - Exemple : `max(${member_age})` renverra l'âge du membre le plus âgé du groupe.

10. `max-if(repeatedfield, expression)` : Fonctionne exactement comme `max()`, sauf qu'elle vérifie chaque instance du groupe répété à l'aide de l'expression fournie. Si l'expression est évaluée à false, l'élément sera omis du résultat.
    - Exemple : `max-if(${member_age}, ${member_age} >= 18)` renverra l'âge de l'adulte le plus âgé du groupe. Ceux de moins de 18 ans seront ignorés.

11. `index()` : Appelé au sein d'un groupe répété, renvoie le numéro d'index du groupe ou de l'instance actuelle.
    - Exemple : `index()` utilisé au sein d'un groupe répété renverra 1 pour la première instance, 2 pour la seconde, et ainsi de suite.

12. `indexed-repeat(repeatedfield, repeatgroup, index)` : Référence un champ ou un groupe qui se trouve à l'intérieur d'un groupe répété depuis l'extérieur de ce groupe répété. Le premier paramètre spécifie le champ ou le groupe répété concerné, le second spécifie le groupe répété dans lequel se trouve le champ ou le groupe, et le troisième spécifie le numéro d'instance au sein du groupe répété à utiliser.
    - Exemple 1 : `indexed-repeat(${name}, ${names}, 1)` renverra le premier nom disponible lorsque le champ de nom se trouve à l'intérieur d'un groupe répété précédent nommé "names".
    - Exemple 2 : `indexed-repeat(${name}, ${names}, index())` extraira le nom correspondant au numéro d'instance du groupe répété actuel.

13. `rank-index(index, repeatedfield)` : Cette fonction calcule le rang ordinal de l'instance spécifiée d'un champ répété pour une utilisation en dehors du groupe répété. Le rang 1 est attribué à l'instance ayant la valeur la plus élevée, le rang 2 à l'instance ayant la valeur immédiatement inférieure, et ainsi de suite. Si vous transmettez un index non valide ou un index vers une instance ayant une valeur non numérique, un rang de 999 sera renvoyé.
    - Exemple : `rank-index(1, ${random_draw})` calcule le rang de la première instance en fonction de la valeur de son champ `random_draw` par rapport aux valeurs des autres instances.

14. `rank-index-if(index, repeatedfield, expression)` : Cette fonction fonctionne de manière similaire à `rank-index()`, mais elle vérifie chaque instance dans le groupe répété du champ répété à l'aide de l'expression fournie. Si l'expression est évaluée à false, l'élément sera omis du calcul. L'index utilisé est basé sur l'ensemble complet des instances avant d'évaluer l'expression pour chaque instance. Si vous transmettez un index pour une instance qui a été ignorée car elle ne satisfaisait pas l'expression, il est considéré comme un index non valide et un rang de 999 sera renvoyé.
    - Exemple : `rank-index-if(1, ${age}, ${age} >= 18)` calcule le rang d'âge au sein de l'ensemble des adultes, en ne considérant que les instances où l'âge est supérieur ou égal à 18.

### Fonctions numériques

| Opérateur | Opération | Exemple | Exemple de réponse |
|-----------|-----------|---------|--------------------|
| `+` | Addition | 1 + 1 | 2 |
| `-` | Soustraction | 3 - 2 | 1 |
| `*` | Multiplication | 3 * 2 | 6 |
| `div` | Division | 10 div 2 | 5 |
| `mod` | Modulo | 9 mod 2 | 1 |

rtSurvey prend en charge les fonctions numériques, notamment :
- `number(field)` : Convertit la valeur du champ en nombre.
  - Exemple : `number('34.8')` = 34.8

- `int(field)` : Convertit la valeur du champ en entier.
  - Exemple : `int('39.2')` = 39

- `min(field1, ..., fieldx)` : Renvoie la valeur minimale parmi les champs transmis.
  - Exemple : `min(${father_age}, ${mother_age})` renverra l'âge de la mère ou du père, selon lequel est le plus petit.

- `max(field1, ..., fieldx)` : Renvoie la valeur maximale parmi les champs transmis.
  - Exemple : `max(${father_age}, ${mother_age})` renverra l'âge de la mère ou du père, selon lequel est le plus grand.

- `format-number(field)` : Formate la valeur d'un champ entier ou décimal selon les paramètres régionaux de l'utilisateur.
  - Exemple : `format-number(${income})` Cette expression peut formater "120000" en "120 000".

- `round(field, digits)` : Arrondit la valeur numérique du champ au nombre spécifié de chiffres après la virgule.
  - Exemple : `round(${interest_rate}, 2)`

- `abs(number)` : Renvoie la valeur absolue d'un nombre.
  
- `pow(base, exponent)` : Renvoie la valeur du premier paramètre élevé à la puissance du second paramètre.
  - Chaque paramètre peut être un champ, un nombre ou une expression.

- `log10(fieldorvalue)` : Renvoie le logarithme décimal du champ ou de la valeur transmise.

- `sin(fieldorvalue)` : Renvoie le sinus du champ ou de la valeur transmise, exprimé en radians.
  
- `cos(fieldorvalue)` : Renvoie le cosinus du champ ou de la valeur transmise, exprimé en radians.

- `tan(fieldorvalue)` : Renvoie la tangente du champ ou de la valeur transmise, exprimé en radians.

- `asin(fieldorvalue)` : Renvoie l'arcsinus du champ ou de la valeur transmise, exprimé en radians.

- `acos(fieldorvalue)` : Renvoie l'arccosinus du champ ou de la valeur transmise, exprimé en radians.

- `atan(fieldorvalue)` : Renvoie l'arctangente du champ ou de la valeur transmise, exprimé en radians.

- `atan2(x, y)` : Renvoie l'angle en radians sous-tendu à l'origine par le point de coordonnées (x, y) et l'axe des x positifs. Le résultat est compris dans l'intervalle -pi() à pi().

- `sqrt(fieldorvalue)` : Renvoie la racine carrée non négative du champ ou de la valeur transmise.

- `exp(x)` : Renvoie la valeur de e^x.

- `pi()` : Renvoie la valeur de pi.

### Fonctions de date et d'heure

<Callout type="warning">
Les valeurs de date dans rtSurvey sont stockées sous forme de chaînes au format `YYYY-MM-DD`. Les valeurs de date et d'heure sont stockées sous forme de chaînes ISO 8601 (`YYYY-MM-DDTHH:MM:SS`). Utilisez `decimal-date-time()` pour les convertir en nombre pour l'arithmétique (par exemple, le calcul de durées).
</Callout>

1. `today()` : Renvoie la date du jour sous forme de chaîne au format `YYYY-MM-DD`. Évaluée une seule fois à l'ouverture du formulaire.
   - Exemple : `today()` → `'2024-03-15'`
   - Utilisation courante : colonne `default` pour pré-remplir la date du jour, ou dans `relevant`/`constraint` pour comparer avec un champ de date.

2. `now()` : Renvoie la date et l'heure actuelles sous forme de chaîne ISO 8601. Évaluée chaque fois que l'expression est calculée.
   - Exemple : `now()` → `'2024-03-15T14:32:00.000+03:00'`
   - Utilisation courante : Enregistrement de l'horodatage exact d'un événement spécifique pendant l'enquête.

3. `date(value)` : Convertit une valeur (chaîne ou nombre) en une chaîne de date. Utile pour forcer des valeurs calculées vers un type de date.
   - Exemple : `date('2024-03-15')` → `'2024-03-15'`

4. `date-time(value)` : Convertit une valeur en une chaîne de date et d'heure.
   - Exemple : `date-time(${event_timestamp})`

5. `decimal-date-time(value)` : Convertit une chaîne de date ou de date et d'heure en un nombre décimal représentant les millisecondes depuis l'époque Unix divisées par 86400000 (c'est-à-dire les jours fractionnaires depuis le 01/01/1970). Utilisez ceci pour effectuer des calculs arithmétiques sur les dates.
   - Exemple : Durée en jours entre deux dates :
     `decimal-date-time(${end_date}) - decimal-date-time(${start_date})`
   - Exemple : Durée en minutes entre deux dates et heures :
     `(decimal-date-time(${end_time}) - decimal-date-time(${start_time})) * 1440`

6. `format-date(date, format)` : Formate une valeur de date à l'aide d'une chaîne de modèle.
   - Jetons de format : `%Y` (année à 4 chiffres), `%y` (année à 2 chiffres), `%m` (mois 01–12), `%d` (jour 01–31), `%a` (jour de la semaine abrégé), `%b` (nom du mois abrégé)
   - Exemple : `format-date(today(), '%d/%m/%Y')` → `'15/03/2024'`
   - Exemple : `format-date(${dob}, '%B %d, %Y')` → `'March 15, 1990'`

7. `format-date-time(datetime, format)` : Formate une valeur de date et d'heure à l'aide d'une chaîne de modèle. Accepte tous les jetons de `format-date` plus :
   - `%H` (heure 00–23), `%h` (heure 01–12), `%M` (minutes 00–59), `%S` (secondes 00–59), `%3` (millisecondes), `%P` (AM/PM)
   - Exemple : `format-date-time(now(), '%d/%m/%Y %H:%M')` → `'15/03/2024 14:32'`
   - Exemple : `format-date-time(${event_time}, '%I:%M %p')` → `'02:32 PM'`

8. `STRFTIME(format, datetime)` : Formatage de date de style SQLite. Disponible à l'intérieur des chaînes SQL transmises aux requêtes `rawquery` — **pas** disponible dans les colonnes XLSForm `calculation` ou `label`. Utilise les jetons de format SQLite (`%Y`, `%m`, `%d`, `%H`, `%M`, `%S`).
   - Exemple dans une chaîne SQL rawquery : `'SELECT STRFTIME(''%Y-%m'', interview_date) AS month FROM data WHERE id = ?'`
   - Note : Utilisez `format-date-time()` pour le formatage de date dans les expressions XLSForm. `STRFTIME()` est une fonction SQLite disponible uniquement au sein du SQL transmis à `rawquery`.

### Fonctions booléennes

1. `boolean(value)` : Convertit n'importe quelle valeur en un booléen. Renvoie `true` pour les chaînes non vides, les nombres non nuls et `true` ; renvoie `false` pour les chaînes vides, `0` et `false`.
   - Exemple : `boolean(${name})` renvoie `true` si `name` n'est pas vide.

2. `boolean-from-string(string)` : Renvoie `true` si la chaîne est `'1'` ou `'true'` (insensible à la casse) ; renvoie `false` sinon.
   - Exemple : `boolean-from-string(${enabled_flag})` — utile lorsqu'un champ stocke `'true'`/`'false'` sous forme de texte.

3. `true()` : Renvoie la valeur booléenne `true`.
   - Exemple : Dans la colonne `required`, `true()` est équivalent à `yes`.

4. `false()` : Renvoie la valeur booléenne `false`.
   - Exemple : `if(${skip_section} = 'yes', false(), true())` — définit dynamiquement le champ comme requis.

5. `not(expression)` : Renvoie la négation logique de l'expression. Renvoie `true` si l'expression est fausse, et vice versa.
   - Exemple : `not(${consent} = 'yes')` — affiche un avertissement lorsque le consentement n'a PAS été donné.
   - Exemple : `not(selected(${issues}, 'none'))` — requiert des détails uniquement si "aucun" n'a pas été sélectionné.

### Fonctions de chaîne supplémentaires

1. `starts-with(string, prefix)` : Renvoie `true` si `string` commence par `prefix`.
   - Exemple : `starts-with(${phone}, '+254')` vérifie si le numéro de téléphone commence par le code pays du Kenya.

2. `contains(string, substring)` : Renvoie `true` si `string` contient `substring`.
   - Exemple : `contains(${email}, '@')` vérifie qu'une adresse e-mail contient un signe `@`.
   - Exemple : `contains(${notes}, 'urgent')` déclenche une question de suivi si les notes mentionnent "urgent".

3. `substring-before(string, needle)` : Renvoie la partie de `string` qui apparaît avant la première occurrence de `needle`.
   - Exemple : `substring-before(${full_name}, ' ')` extrait le premier mot (prénom).

4. `substring-after(string, needle)` : Renvoie la partie de `string` qui apparaît après la première occurrence de `needle`.
   - Exemple : `substring-after(${email}, '@')` extrait la partie domaine d'une adresse e-mail.

5. `normalize-space(string)` : Supprime les espaces blancs au début et à la fin et réduit toutes les séquences d'espaces blancs internes à un seul espace.
   - Exemple : `normalize-space(${name})` — nettoie un nom qui a pu être saisi avec des espaces supplémentaires.

6. `translate(string, search_chars, replace_chars)` : Remplace chaque caractère de `string` apparaissant dans `search_chars` par le caractère correspondant dans `replace_chars`. Les caractères de `search_chars` n'ayant pas de caractère correspondant dans `replace_chars` sont supprimés.
   - Exemple : `translate(${code}, 'abcdefghijklmnopqrstuvwxyz', 'ABCDEFGHIJKLMNOPQRSTUVWXYZ')` convertit en majuscules (équivalent à `upper()`).
   - Exemple : `translate(${phone}, ' -()', '')` supprime les espaces, les tirets et les parenthèses d'un numéro de téléphone.

### Fonctions mathématiques supplémentaires

1. `floor(number)` : Renvoie le plus grand entier inférieur ou égal à `number` (arrondit vers l'infini négatif).
   - Exemple : `floor(4.9)` = 4, `floor(-2.1)` = -3

2. `ceiling(number)` : Renvoie le plus petit entier supérieur ou égal à `number` (arrondit vers l'infini positif).
   - Exemple : `ceiling(4.1)` = 5, `ceiling(-2.9)` = -2

3. `random()` : Renvoie un nombre décimal aléatoire compris entre 0,0 (inclus) et 1,0 (exclus). Généralement utilisé dans les champs `calculate` pour attribuer des valeurs aléatoires ou randomiser l'ordre des questions.
   - Exemple : `random()` → par exemple, `0.7341`
   - Exemple : `int(random() * 6) + 1` → nombre aléatoire de 1 à 6 (jet de dé)

4. `coalesce(a, b)` : Renvoie `a` si `a` n'est pas vide ; sinon renvoie `b`. Utile comme solution de repli lorsqu'un champ peut être vide.
   - Exemple : `coalesce(${preferred_name}, ${full_name})` — utilise le nom préféré s'il est défini, sinon revient au nom complet.

5. `once(value)` : Évalue `value` et la stocke, mais seulement si le champ actuel est **vide**. Si le champ a déjà une valeur (par exemple, s'il a été précédemment défini), `once()` renvoie la valeur existante inchangée. Cela empêche le recalcul d'écraser la saisie de l'utilisateur.
   - Exemple : `once(today())` dans la colonne `default` définit la date du jour une fois et ne se met pas à jour si l'enquêteur rouvre le formulaire.
   - Exemple : `once(uuid())` génère un UUID une fois et le maintient stable lors des rééditions.

### Fonctions géo

1. `area(geoshape_value)` : Calcule l'**aire en mètres carrés** délimitée par une valeur geoshape (polygone).
   - Le paramètre est une valeur de champ geoshape au format `lat1 lon1 0 0; lat2 lon2 0 0; ...`
   - Exemple : `area(${field_boundary})` — calcule l'aire d'un champ arpenté en m².
   - Exemple : `round(area(${field_boundary}) div 10000, 2)` — convertit en hectares.

2. `distance(coordinates)` : Calcule la **longueur totale du chemin en mètres** d'un geotrace (ligne), ou la distance entre deux geopoints.
   - Pour un geotrace : `distance(${route})` renvoie la longueur totale du chemin en mètres.
   - Pour deux geopoints : `distance(concat(${point_a}, ' ', ${point_b}))` renvoie la distance qui les sépare.
   - Exemple : `round(distance(${road_trace}) div 1000, 3)` — longueur d'une route en kilomètres.

### Fonctions de validation

1. `regex(value, pattern)` : Renvoie `true` si `value` correspond à l'expression régulière `pattern`. À utiliser dans la colonne `constraint` pour une validation basée sur des modèles.
   - Le modèle utilise la syntaxe regex standard (sous-ensemble POSIX ERE).
   - Exemple : `regex(., '^[0-9]{10}$')` — valide un nombre à 10 chiffres.
   - Exemple : `regex(., '^[A-Z]{2}[0-9]{6}$')` — valide un format de numéro de passeport (2 lettres majuscules suivies de 6 chiffres).
   - Exemple : `regex(., '^[^@]+@[^@]+\.[^@]{2,}$')` — vérification basique du format d'e-mail.

2. `checklist(min, max, v1, v2, ...)` : Évalue une liste d'expressions booléennes et renvoie `true` si le nombre de valeurs `true` est compris entre `min` et `max` (inclus). Passez `-1` pour `min` ou `max` pour ignorer cette limite.
   - Exemple : `checklist(2, 3, ${q1} = 'yes', ${q2} = 'yes', ${q3} = 'yes')` — passe si exactement 2 ou 3 des trois conditions sont vraies.
   - Exemple : `checklist(1, -1, ${smoke_alarm}, ${fire_ext}, ${emergency_plan})` — au moins une mesure de sécurité doit être vraie.

3. `weighted-checklist(min, max, v1, w1, v2, w2, ...)` : Comme `checklist()`, mais chaque valeur a un poids. La somme des poids pour les valeurs `true` doit être comprise entre `min` et `max`.
   - Exemple : `weighted-checklist(10, -1, ${has_toilet}, 4, ${has_sink}, 3, ${has_shower}, 5)` — la somme des poids pour les installations présentes doit être d'au moins 10.

### Fonctions utilitaires

1. `uuid()` : Génère un UUID aléatoire (format RFC 4122 v4) sous forme de chaîne.
   - Exemple : `uuid()` → `'a3f8b2c1-4d5e-6f7a-8b9c-0d1e2f3a4b5c'`
   - Généralement utilisé avec `once()` pour générer un ID unique stable : `once(uuid())`

2. `version()` : Renvoie la valeur de l'attribut `version` du formulaire tel que défini dans la feuille de calcul settings.
   - Exemple : `version()` → `'3.1'`
   - Utile dans les champs `calculate` pour intégrer la version du formulaire dans les données exportées.

3. `position()` : Lorsqu'il est appelé à l'intérieur d'un **groupe répété (repeat group)**, renvoie l'index (commençant à 1) de l'instance de répétition actuelle.
   - Exemple : `position()` dans la première instance renvoie `1`, dans la seconde renvoie `2`, et ainsi de suite.
   - Voir aussi : `index()` (alias), `indexed-repeat()` pour référencer les valeurs de répétition depuis l'extérieur du groupe.

4. `thousandsep(length, separator, value)` : Formate un nombre avec un séparateur de milliers. `length` est la longueur totale minimale de la chaîne (remplie d'espaces si elle est plus courte), `separator` est le caractère à utiliser (par exemple, `','`), et `value` est le nombre à formater.
   - Exemple : `thousandsep(0, ',', 1234567)` → `'1,234,567'`
   - Exemple : `thousandsep(0, '.', ${income})` → formate le revenu avec un point comme séparateur de milliers.

5. `substr-jsonpath(value, jsonpath)` : Extrait une valeur d'une chaîne JSON à l'aide d'une expression JSONPath.
   - `value` doit être une chaîne JSON (par exemple, un champ qui a stocké une réponse API brute à l'aide de `callapi(..., 'json:', ...)`).
   - `jsonpath` est une expression JSONPath (par exemple, `'$.data.name'`, `'$.items[0].id'`).
   - Renvoie toujours une **chaîne** — à encadrer dans `number()` lorsqu'elle est utilisée dans des calculs arithmétiques.
   - Renvoie une chaîne vide `''` si le chemin n'est pas trouvé ou si `value` n'est pas un JSON valide.
   - Exemple : `substr-jsonpath(${api_response}, '$.data.name')` — extraire le champ `name`.
   - Exemple : `substr-jsonpath(${api_response}, '$.items[0].label')` — premier élément d'un tableau.
   - Exemple : `number(substr-jsonpath(${api_response}, '$.price'))` — extraire une valeur numérique.
   - Généralement utilisé aux côtés de `callapi(..., 'json:', ...)` pour extraire plusieurs champs d'une seule réponse API. Voir [Récupération de plusieurs valeurs à partir d'un seul appel API](../advanced-features/call-api#fetching-multiple-values-from-one-api-call).

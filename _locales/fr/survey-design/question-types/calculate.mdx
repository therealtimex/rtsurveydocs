Le type de question `calculate` exécute une formule discrètement en arrière-plan. Il stocke le résultat dans un champ nommé auquel d'autres questions μπορούν se référer — mais il n'affiche aucune saisie ni libellé à l'enquêteur. Utilisez-le pour dériver des valeurs, concaténer des chaînes, exécuter une logique conditionnelle ή rechercher des données dont vous aurez besoin plus tard dans le formulaire.

---

## Syntaxe de base

| type | name | label | calculation |
|------|------|-------|-------------|
| calculate | total | | `${price} * ${quantity}` |

- **type** : Toujours `calculate`.
- **name** : Un nom de champ unique. Les autres questions y font référence avec `${name}`.
- **label** : Laissez vide — les champs calculate ne sont jamais affichés à l'enquêteur.
- **calculation** : La formule à évaluer. Prend en charge toutes les [fonctions XLSForm](../operators-and-functions/functions) et les références de champs.

---

## Modèles courants

### Arithmétique

| type | name | label | calculation |
|------|------|-------|-------------|
| integer | price | Unit price | |
| integer | quantity | Quantity | |
| calculate | total | | `${price} * ${quantity}` |
| note | total_note | Total: `${total}` | |

### Concaténation de chaînes

| type | name | label | calculation |
|------|------|-------|-------------|
| text | first_name | First name | |
| text | last_name | Last name | |
| calculate | full_name | | `concat(${first_name}, ' ', ${last_name})` |

### Valeur conditionnelle

| type | name | label | calculation |
|------|------|-------|-------------|
| integer | score | Score (0–100) | |
| calculate | grade | | `if(${score} >= 90, 'A', if(${score} >= 75, 'B', if(${score} >= 60, 'C', 'F')))` |

### Âge à partir de la date de naissance

| type | name | label | calculation |
|------|------|-------|-------------|
| date | dob | Date of birth | |
| calculate | age_years | | `int((today() - ${dob}) div 365.25)` |

## Utiliser `once()` pour figer la valeur

Par défaut, `calculate` est réévalué chaque fois qu'un champ référencé change. Enveloppez la formule dans `once()` pour l'évaluer uniquement au premier chargement et figer le résultat :

| type | name | label | calculation |
|------|------|-------|-------------|
| calculate | interview_start | | `once(now())` |

Utilisez `once()` pour les horodatages, les valeurs initiales ou tout cas où un recalcul lors d'un changement n'est pas souhaitable.

## Extraction de données de sources externes

### À partir d'un fichier CSV

```
pulldata('staff.csv', 'department', 'name', ${staff_id})
```

Voir [pulldata()](../operators-and-functions/pulldata) pour la référence complète.

### À partir d'une base de données SQLite intégrée

```
pulldata('rawquery',
  concat(${family_path}, '/locations.db::provinces'),
  'SELECT name FROM provinces WHERE id = ?',
  ${province_id})
```

Voir [Recherche dans la base de données locale](../advanced-features/local-database-search) pour les détails de construction du chemin.

### À partir du contexte de l'application

```
pulldata('app-api', 'user.username')
pulldata('app-api', 'family_path')
```

Voir [App API](../app-api) pour toutes les clés disponibles.

## Utilisation de calculate dans relevant et constraint

D'autres champs peuvent faire référence à un résultat `calculate` comme n'importe quel champ :

| type | name | label | relevant | constraint |
|------|------|-------|----------|------------|
| calculate | bmi | | | `${weight} div (${height} * ${height}) * 10000` |
| note | bmi_warning | BMI is very high — please verify weight and height. | `${bmi} > 40` | |

## Bonnes pratiques

1. Donnez aux champs calculate des noms significatifs — `total_cost` est plus clair que `calc1` et plus facile à tracer dans les exportations.
2. Décomposez les formules complexes en plusieurs champs calculate chaînés au lieu d'une seule expression profondément imbriquée.
3. Utilisez `once()` pour les horodatages et les instantanés initiaux afin d'empêcher les valeurs de changer après la première capture.
4. Placez les champs `calculate` avant la première question qui y fait référence — l'ordre d'évaluation suit l'ordre du formulaire.
5. Laissez la colonne `label` vide. Certains outils affichent le libellé ; le laisser vide évite des sorties confuses.

## Limites

- Les champs calculate ne sont jamais affichés directement à l'enquêteur — utilisez un champ `note` pour afficher le résultat.
- La colonne `calculation` est obligatoire ; une ligne `calculate` sans formule stocke toujours une chaîne vide.
- Les résultats sont réévalués à chaque changement de formulaire, sauf s'ils sont enveloppés dans `once()` — des formules très complexes dans des formulaires volumineux peuvent affecter les performances de rendu sur des appareils bas de gamme.
- Les valeurs calculées sont stockées sous forme de chaînes de caractères dans la soumission. Utilisez `number()`, `int()` ou `boolean()` pour transtyper le résultat lorsque vous le passez à des expressions arithmétiques ou logiques.

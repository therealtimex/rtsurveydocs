title: "Entier"

---

Le type de question `integer` recueille des nombres entiers (sans décimales). Il déclenche un clavier numérique sur mobile et bloque la saisie de points décimaux. Il prend en charge les mêmes options `appearance` que le type `text` pour la mise en page et le formatage.

## Spécification XLSForm de base

| type | name | label |
|------|------|-------|
| integer | age | Âge du répondant |
| integer | household_size | Nombre de personnes dans le foyer |

Pour la spécification standard, consultez la [documentation XLSForm](https://xlsform.org/en/#question-types).

---

## Options d'apparence

### `number-hspinner` — sélecteur horizontal

Remplace l'entrée par un sélecteur horizontal **− valeur +**. Appuyer sur moins/plus décrémente ou incrémente la valeur de 1 (ou d'un pas personnalisé).

```
number-hspinner
```

**Personnaliser la forme du bouton et le pas** à l'aide de `hspinner()` :

```
number-hspinner hspinner('left-small-square','right-small-square','5')
```

Paramètres : forme du bouton gauche, forme du bouton droit, valeur du pas (par défaut `1` pour les entiers).

**Couleurs personnalisées** à l'aide de `colors()` :

```
number-hspinner colors(0099FF,FFFFFF,FF5500,FFFFFF)
```

Quatre valeurs dans l'ordre : arrière-plan du bouton gauche, icône du bouton gauche, arrière-plan du bouton droit, icône du bouton droit.

---

### `thousandsep` — séparateur de milliers

Formate le nombre affiché avec un regroupement par virgules (par exemple, `1,234,567`). Le nombre brut est stocké sans virgules. Le type d'entrée est remplacé par `"text"` pour permettre l'affichage formaté.

```
thousandsep
```

---

### `digisep(n, "sep")` — regroupement de chiffres personnalisé

Regroupe les chiffres en blocs de `n` séparés par un séparateur personnalisé. Utile pour les identifiants formatés ou les codes de référence numériques.

```
digisep(4,"-")      → 0912-3456-789
digisep(3," ")      → 012 345 678
```

Le type d'entrée est remplacé par `"text"` lorsque cette `appearance` est active.

---

### `textonly` — forcer le clavier texte

Force `type="text"` sur l'élément d'entrée. Cela empêche les bizarreries de saisie de nombres du navigateur (telles que la masquage des zéros en tête ou l'ajout de flèches de rotation dans les navigateurs de bureau) tout en collectant une valeur numérique.

```
textonly
```

---

### `floating_hint` — l'indice flotte comme étiquette

Le texte `hint` s'affiche à l'intérieur de l'entrée comme un espace réservé. Lorsque l'utilisateur commence à taper, il flotte au-dessus du champ comme une étiquette.

```
floating_hint
```

---

### `embed` — indice à l'intérieur de la limite d'entrée

Similaire à `floating_hint` — l'indice se trouve à l'intérieur de la limite d'entrée lorsqu'il est vide. Il ne flotte pas lorsque l'utilisateur tape.

```
embed
```

---

### `textpopup` — entrée de dialogue modale

Appuyer sur le champ ouvre une boîte de dialogue modale avec une entrée plus grande au lieu d'éditer en ligne. Utile sur les petits écrans où une entrée plein écran est plus facile.

```
textpopup
```

---

### `charcount` — compteur de caractères en direct

Affiche un compteur de caractères en direct `(n)` sous l'entrée, mis à jour au fur et à mesure que l'utilisateur tape.

```
charcount
```

---

### `prefix(expr)` — ajouter un préfixe

Ajoute une chaîne statique ou calculée à la valeur affichée. La valeur stockée n'inclut pas le préfixe.

```
prefix('Item #')        → affiche "Item #42", stocke "42"
prefix(${code_prefix})  → préfixe dynamique d'un autre champ
```

---

### `align_answer` — alignement du texte d'entrée

Contrôle l'alignement horizontal de la valeur tapée à l'intérieur de l'entrée.

```
align_answer = left
align_answer = right
align_answer = center
```

---

### `inputs{qrscan}` — scan QR / code-barres dans le champ

Ajoute un bouton de scan de code QR à côté de l'entrée. Ouvre le scanner de la caméra et remplit le champ avec la valeur numérique scannée.

```
inputs{qrscan}
```

## Référence rapide de l'apparence

| Appearance | Widget rendu |
|---|---|
| *(aucun)* | Entrée numérique (`type="number"`) — clavier numérique sur mobile |

| `number-hspinner hspinner(...)` | Sélecteur avec forme de bouton et pas personnalisés |

## Contraintes et validation

Utilisez des contraintes pour appliquer des plages de valeurs. Les contraintes de la colonne `constraint` sont évaluées après chaque appui sur un bouton en mode `number-hspinner`, et pas seulement lors de la perte de focus.

| type | name | label | constraint | constraint_message |
|------|------|-------|------------|-------------------|
| integer | age | Âge | `. > 0 and . <= 120` | L'âge doit être compris entre 1 et 120 |
| integer | year | Année de construction | `. >= 1800 and . <= 2100` | Entrez une année valide |
| integer | count | Nombre d'articles | `. >= 0` | Ne peut pas être négatif |

---

## Exemple — enquête auprès des ménages

| type | name | label | appearance | constraint | constraint_message |
|------|------|-------|------------|------------|-------------------|
| integer | household_size | Personnes dans le foyer | `number-hspinner` | `. >= 1 and . <= 30` | Doit être compris entre 1 et 30 |
| integer | under_5 | Enfants de moins de 5 ans | `number-hspinner` | `. >= 0 and . <= ${household_size}` | Ne peut pas dépasser la taille du ménage |
| integer | year_built | Année de construction de la maison | `textonly` | `. >= 1800 and . <= 2100` | Entrez une année valide |

## Bonnes pratiques

1. Utilisez `number-hspinner` pour les petits nombres où cliquer sur ± est plus rapide que de taper (par exemple, nombre d'enfants, score sur une échelle de 1 à 10).
2. Utilisez `thousandsep` lors de l'affichage de grands entiers (population, revenu) afin que les répondants puissent vérifier l'ordre de grandeur.
3. Utilisez `textonly` lorsque les navigateurs ajoutent une interface utilisateur de saisie numérique indésirable (flèches de rotation, défilement tactile) qui perturbe les répondants.
4. Appliquez des contraintes de plage plutôt que de vous fier au type de clavier mobile — l'application du clavier n'est pas universelle.

## Limitations

- La saisie de points décimaux est bloquée — si vous avez besoin de valeurs fractionnaires, utilisez le type `decimal`.
- `number-hspinner` valide la `constraint` à chaque appui sur un bouton — évitez les contraintes coûteuses (par exemple, les chaînes `if()` complexes) en mode sélecteur.
- `thousandsep` et `digisep()` stockent le nombre brut sans formatage — ne vous fiez pas à la valeur d'affichage formatée dans les calculs.

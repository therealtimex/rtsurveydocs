---
title: "Date et heure, date, heure"
description: "Les questions de type Datetime permettent aux répondants de saisir à la fois la date et l'heure dans un seul champ."
---

Les types de question `date`, `time` et `datetime` capturent des valeurs de date et/ou d'heure. rtSurvey les affiche avec plusieurs modes de disposition contrôlés par la colonne `appearance`.

## Spécification XLSForm de base

| type     | name           | label                     |
|----------|----------------|---------------------------|
| date     | birth_date     | Date de naissance             |
| time     | start_time     | À quelle heure cela a-t-il commencé ?   |
| datetime | event_datetime | Quand l'événement a-t-il eu lieu ? |

Pour la spécification standard, consultez la [documentation XLSForm](https://xlsform.org/en/#question-types).

## Modes de disposition

### Par défaut — calendrier toujours ouvert

Aucune valeur d'apparence n'est nécessaire. Le calendrier (et l'horloge pour `time`/`datetime`) s'affiche directement sur la page — toujours visible, aucun bouton requis.

| type | name       | label         | appearance |
|------|------------|---------------|------------|
| date | start_date | Date de la visite |            |

---

### `inline` — bouton circulaire → modal

Un bouton icône circulaire (calendrier ou horloge) flotte à côté de l'étiquette de la question. En appuyant dessus, un modal s'ouvre avec le sélecteur. Après la sélection, la valeur choisie apparaît sous forme de texte à côté de l'étiquette.

- Fond du bouton : couleur du thème principal (modifiable)
- Forme du bouton : cercle complet (`border-radius: 50%`)

```
| type | name       | label         | appearance |
|------|------------|---------------|------------|
| date | start_date | Date de la visite | inline     |
```

---

### `inline-onlyresult` — le bouton disparaît après la sélection

Identique à `inline` mais le bouton se masque une fois qu'une valeur est sélectionnée. Utile lorsque vous souhaitez que la date ne soit visible qu'après avoir été choisie, sans icône persistante.

```
inline-onlyresult
```

---

### `inline-1line` — ligne de sélecteurs

Affiche des contrôles de sélecteur individuels (▲ valeur ▼) sur une seule ligne horizontale — une colonne par composant. Pour `date` : mois / jour / année. Pour `datetime` : mois / jour / année / heures / minutes. Pour `time` : heures / minutes.

Pas de modal ni de fenêtre contextuelle de calendrier — l'utilisateur fait défiler chaque sélecteur indépendamment.

```
inline-1line
```

**Afficher uniquement des composants spécifiques** en ajoutant les noms des composants :

```
inline-1line month year      → masque le sélecteur de jour
inline-1line year            → affiche uniquement l'année
```

**Limiter la plage d'années :**

```
inline-1line y_range(1940-2026)
```

---

### `box` — saisie de texte

Affiche un champ de saisie de texte simple. L'utilisateur tape la date directement en utilisant le format défini dans l'apparence.

```
box(%d/%m/%Y)       → DD/MM/YYYY
box(%Y-%m-%d)       → YYYY-MM-DD
```

---

### `month-year` — mois et année uniquement

Apparence XLSForm standard. Le sélecteur commence par la vue année ; l'utilisateur sélectionne le mois et l'année mais pas un jour spécifique.

```
month-year
```

---

### `year` — année uniquement

Apparence XLSForm standard. Le sélecteur commence par la vue décennie ; seule l'année est sélectionnable.

```
year
```

---

## Format d'affichage personnalisé

Ajoutez `-[format]` à toute apparence `inline` pour contrôler la façon dont la valeur sélectionnée est affichée sous forme de texte. Utilise des jetons de style strftime.

| Token | Meaning | Example |
|-------|---------|---------|
| `%d`  | Jour (rempli de zéros) | 07 |
| `%e`  | Jour (sans remplissage) | 7 |
| `%m`  | Numéro du mois | 04 |
| `%n`  | Numéro du mois (sans remplissage) | 4 |
| `%b`  | Abréviation du mois | Avr |
| `%Y`  | Année à 4 chiffres | 2026 |
| `%y`  | Année à 2 chiffres | 26 |
| `%H`  | Heure (24h) | 14 |
| `%h`  | Heure (sans remplissage) | 14 |
| `%M`  | Minute | 05 |
| `%S`  | Seconde | 00 |
| `%a`  | Abréviation du nom du jour | Mer |

**Exemples :**

```
inline-[%d/%m/%Y]            → 07/04/2026
inline-[%d %b %Y]            → 07 Avr 2026
inline-1line-[%Y-%m-%d]      → saisie par sélecteur, affichage formaté
inline-[%d/%m/%Y %H:%M]      → 07/04/2026 14:30
```

## Personnalisation des couleurs

Remplacez la couleur du bouton icône en utilisant `colors()` :

```
inline colors("0099FF")                   → arrière-plan du bouton #0099FF
inline colors("0099FF","FFFFFF")          → arrière-plan #0099FF, couleur de l'icône #FFFFFF
inline-1line colors("0000FF","FFFF00")    → couleurs d'accentuation du sélecteur
inline-onlyresult colors("E53935")        → bouton rouge
```

---

## Position du bouton avec `display{}`

Le modificateur `display{}` contrôle où le bouton icône apparaît par rapport à l'étiquette de la question. S'applique à `inline` et `inline-onlyresult`.

```
display{<align>, <size>, <color>}
```

| Parameter | Values | Default |
|-----------|--------|---------|
| Align | `left`, `right`, `top`, `center`, `bottom` | `right` |
| Size | `small`, `medium`, `large` | `small` |
| Color | hex e.g. `#FF5500` | primary theme color |

**Comportement d'alignement :**

| Value | Layout |
|-------|--------|
| `right` | Bouton à droite de l'étiquette |
| `left` | Bouton à gauche de l'étiquette |
| `top` | Bouton au-dessus de l'étiquette, centré sur toute la largeur |
| `center` / `bottom` | Bouton sous l'étiquette, centré sur toute la largeur |

**Exemples :**

```
inline display{left}
inline display{center, large}
inline display{right, medium, #E53935}
inline-onlyresult display{bottom, large, #0099FF}
```

## Restriction de la plage de dates

Utilisez `inputs{range[...]}` pour restreindre les dates sélectionnables.

```
inputs{range[dateGt(2024-01-01), dateLt(2024-12-31)]}
```

Paramètres à l'intérieur de `range[...]` :

| Parameter | Description |
|-----------|-------------|
| `dateGt(YYYY-MM-DD)` | Date minimale sélectionnable (supérieure ou égale) |
| `dateLt(YYYY-MM-DD)` | Date maximale sélectionnable (inférieure ou égale) |
| `indayTimeGt(HH:MM:SS)` | Heure minimale dans une journée (datetime uniquement) |
| `indayTimeLt(HH:MM:SS)` | Heure maximale dans une journée (datetime uniquement) |

Plusieurs plages peuvent être définies — une date est sélectionnable si elle se situe dans **l'une quelconque** des plages.

---

## Supprimer l'étiquette

Ajoutez `text-nolabel` pour masquer l'étiquette de la question. Le bouton s'affiche seul.

```
inline text-nolabel display{center, large}
```

## Résumé de la disposition

| Appearance | Widget rendered | Color customizable |
|---|---|---|
| *(none)* | Calendrier toujours ouvert | Non |
| `inline` | Bouton circulaire → calendrier modal | Oui |
| `inline-onlyresult` | Bouton circulaire → modal, se masque après sélection | Oui |
| `inline-1line` | Ligne de sélecteurs | Oui |
| `box(%format%)` | Champ de saisie de texte | Non |
| `month-year` | Sélecteur mois/année | Non |
| `year` | Sélecteur d'année uniquement | Non

---

## Exemple d'utilisation

```
| type     | name        | label              | appearance                              |
|----------|-------------|--------------------|-----------------------------------------|
| date     | visit_date  | Date de la visite      | inline display{right} -[%d/%m/%Y]       |
| date     | birth_date  | Date de naissance      | inline-1line y_range(1940-2026)         |
| time     | start_time  | Heure de début         | inline-1line                            |
| datetime | event_time  | Date et heure de l'événement  | inline display{center, large} -[%d/%m/%Y %H:%M] |
| date     | report_date | Date de déclaration     | box(%d/%m/%Y)                           |
```

---

## Bonnes pratiques

1. Utilisez `inline` pour les formulaires compacts — cela économise de l'espace vertical par rapport au calendrier toujours ouvert.
2. Utilisez `inline-1line` lorsque les répondants doivent ajuster des composants de date individuels (par exemple, année de naissance).
3. N'utilisez `box()` que si vous faites confiance à l'enquêteur pour saisir les dates correctement — aucune interface utilisateur de validation n'est affichée.
4. Utilisez `display{center, large}` pour rendre le bouton plus proéminent sur les écrans mobiles.
5. Spécifiez toujours `-[format]` lorsque l'affichage par défaut `AAAA-MM-JJ` pourrait prêter à confusion pour les utilisateurs locaux.
6. Tenez compte des fuseaux horaires lors de la collecte de données de date et d'heure dans différentes régions.

## Limites

- `inline-1line` utilise toujours la date d'aujourd'hui par défaut si aucune valeur n'existe — utilisez la colonne `default` pour pré-remplir une date spécifique.
- Le format `box()` ne contrôle que l'affichage ; la valeur stockée est toujours ISO 8601.
- La restriction de la plage de dates (`inputs{range[...]}`) ne fonctionne pas avec la disposition `box`.
- Les différences de fuseau horaire peuvent compliquer l'analyse des données si elles ne sont pas correctement prises en compte.

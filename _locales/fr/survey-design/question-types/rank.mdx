---
title: "Classement (Rank)"
description: "Les questions de classement permettent aux répondants d'ordonner un ensemble de choix par préférence ou priorité."
---

Le type de question `rank` (classement) présente une liste de choix que le répondant ordonne par préférence ou priorité. Il stocke le résultat sous la forme d'une liste de valeurs de choix séparées par des espaces dans l'ordre de classement, le choix le plus prioritaire étant en premier.

> **Formulaire web rtSurvey :** Le widget de glisser-déposer pour classer n'est pas actuellement implémenté. Dans le formulaire web, `rank` s'affiche comme une liste de sélection. Utilisez ce type lorsque vous ciblez des clients mobiles qui prennent en charge le widget de classement, ou lorsque le format de la valeur stockée est plus important que l'interaction de glisser-déposer.

## Spécification XLSForm de base

| type | name | label |
|------|------|-------|
| rank priorities | main_priority | Classez ces besoins communautaires du plus au moins important |

Les choix sont définis dans la **feuille de calcul des choix** comme `select_one` :

**enquête :**

| type | name | label |
|------|------|-------|
| rank priorities | main_priority | Classez ces besoins du plus au moins important |

**choix :**

| list_name | name | label |
|-----------|------|-------|
| priorities | water | Eau potable |
| priorities | health | Soins de santé |
| priorities | education | Éducation |
| priorities | roads | Routes |
| priorities | electricity | Électricité |

## Format de la valeur stockée

La valeur stockée est une **liste séparée par des espaces** des valeurs de choix dans l'ordre de classement (le premier = priorité la plus élevée) :

```
water education health roads electricity
```

## Extraction des positions classées

Utilisez `selected-at()` pour obtenir le choix à un rang spécifique :

| type | name | label | calculation |
|------|------|-------|-------------|
| rank priorities | main_priority | Classer les besoins communautaires | |
| calculate | top_priority | | selected-at(`${main_priority}`, 0) |
| calculate | second_priority | | selected-at(`${main_priority}`, 1) |

`selected-at(${main_priority}, 0)` renvoie la valeur placée **en premier** (index 0 = rang le plus élevé).

## Utilisation de `rank-index()` avec des groupes répétitifs

Lorsque `rank` est utilisé dans un groupe répétitif, `rank-index()` vous permet de référencer le rang ordinal depuis l'extérieur de la répétition :

| type | name | label | calculation |
|------|------|-------|-------------|
| calculate | first_ranked | | rank-index(1, `${score}`) |

Voir [Fonctions — Fonctions de champ répété](../operators-and-functions/functions#repeated-field-functions) pour tous les détails sur `rank-index()` et `rank-index-if()`.

## Utilisations

Les questions de classement sont couramment utilisées pour :

1. **Classement par priorité** — demander aux communautés de classer les besoins de développement
2. **Ordre de préférence** — classer les fonctionnalités de produits, les attributs de service ou les options de politique
3. **Ordre des éléments d'examen** — organiser les étapes d'un processus
4. **Sélection Top-N** — combinée avec `selected-at()` pour extraire uniquement les 1, 2 ou 3 premiers choix

## Bonnes pratiques

1. Gardez la liste courte (3 à 7 éléments) — le classement devient cognitivement exigeant au-delà de 7 à 8 choix.
2. Utilisez des étiquettes de choix claires et mutuellement exclusives pour éviter toute confusion quant à ce que signifie "premier".
3. Ajoutez un texte d'indice expliquant la direction du classement (par exemple, "Faites glisser pour ordonner : premier = le plus important").
4. Validez en utilisant `count-selected(.) = x` si vous devez vous assurer que tous les choix sont classés.

## Limites

- Le widget de glisser-déposer pour classer n'est pas implémenté dans le formulaire web rtSurvey.
- Vous ne pouvez pas classer partiellement — tous les choix doivent être ordonnés.
- Gardez les listes à 3-7 éléments ; les listes plus longues deviennent difficiles à gérer quel que soit le client.

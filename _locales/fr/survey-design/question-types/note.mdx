Le type de question `note` dans XLSForms et rtSurvey est utilisé pour afficher du texte ou des médias en lecture seule au répondant de l'enquête. Ce n'est pas une question qui nécessite une réponse, mais plutôt un moyen de fournir des informations, des instructions ou du contexte au sein de l'enquête.

## Spécification XLSForm de Base

| type | name | label |
|------|------|-------|
| note | info_text | Cette enquête porte sur vos habitudes de lecture. |

Pour plus de détails sur le type de question `note` de base, consultez la [spécification XLSForm](https://xlsform.org/en/#question-types).

## Utilisations

Les questions de type note sont couramment utilisées pour :

1. Fournir des instructions ou du contexte pour les questions à venir
2. Afficher des résultats calculés ou des résumés
3. Montrer des images ou d'autres médias
4. Séparer les sections d'une enquête
5. Donner des commentaires basés sur les réponses précédentes

## Meilleures Pratiques

1. Gardez le texte de la note concis et clair pour maintenir l'engagement du répondant.
2. Utilisez le formatage (gras, italique) pour souligner les informations importantes.
3. Envisagez d'utiliser des médias (images, audio) pour améliorer la compréhension lorsque cela est approprié.
4. Utilisez les notes avec parcimonie pour éviter d'encombrer l'enquête.

## Exemple d'Utilisation

Voici un exemple de la manière dont vous pourriez utiliser des questions de type note dans une enquête :

| type | name | label |
|------|------|-------|
| note | intro | Bienvenue dans notre enquête sur les habitudes de lecture. Nous vous interrogerons sur vos préférences et votre fréquence de lecture. |
| ... | ... | ... |
| calculate | books_per_month | `${fiction_books}` + `${non_fiction_books}` |
| note | reading_summary | Vous lisez environ `${books_per_month}` livres par mois. |

Dans cet exemple, nous utilisons des notes pour introduire l'enquête et fournir un résumé des résultats calculés.

## Extensions rtSurvey

Bien que la spécification XLSForm de base pour les questions de type note soit simple, rtSurvey peut proposer des fonctionnalités ou des personnalisations supplémentaires :

1. Formatage de texte enrichi (Rich text)
2. Prise en charge des médias intégrés (images, audio, vidéo)
3. Contenu dynamique basé sur les réponses précédentes
4. Options de style personnalisées

(Note : Les extensions spécifiques disponibles dans rtSurvey pour les questions de type note devront être confirmées et détaillées ici.)

## Utilisation Avancée

### Affichage Conditionnel

Vous pouvez utiliser des expressions de pertinence (relevance) pour afficher des notes de manière conditionnelle :

| type | name | label | relevant |
|------|------|-------|----------|
| note | high_reader_note | Vous êtes un grand lecteur ! | `${books_per_month}` > 5 |

### Inclusion de Calculs

Les notes peuvent inclure des calculs pour fournir un retour dynamique :

| type | name | label |
|------|------|-------|
| note | reading_time | D'après vos réponses, vous passez environ `${books_per_month * 5}` heures à lire chaque mois. |

## Limitations

- Les notes ne collectent pas de données, elles ne doivent donc pas être utilisées lorsque vous avez besoin de recueillir des informations auprès des répondants.
- L'utilisation excessive de notes peut donner à une enquête une impression d'encombrement ou de longueur excessive.
- Certaines options de formatage avancé ou de médias peuvent ne pas être prises en charge sur tous les appareils ou plateformes.

---
title: "Décimal"
description: "Type de question à saisie de nombre fractionnaire dans rtSurvey"
---

Le type de question `decimal` recueille des nombres pouvant inclure une partie fractionnaire (par exemple `3.14`, `72.5`). Il déclenche un clavier numérique sur mobile et prend en charge les mêmes options d'apparence que le type `text` pour la disposition et le formatage.

## Spécification XLSForm de base

| type | name | label |
|------|------|-------|
| decimal | weight_kg | Poids (kg) |
| decimal | height_m | Taille (m) |
| decimal | temperature | Température corporelle (°C) |

Pour la spécification standard, consultez la [documentation XLSForm](https://xlsform.org/en/#question-types).

---

## Options d'apparence

### `number-hspinner` — sélecteur horizontal

Remplace la saisie par un sélecteur horizontal **− valeur +**. Taper sur moins/plus ajuste la valeur par le pas configuré.

```
number-hspinner
```

La valeur affichée est formatée avec une décimale (par exemple `3.0`, `72.5`). Le pas par défaut est `1` ; utilisez `hspinner()` pour définir un pas décimal.

**Personnaliser la forme et le pas du bouton** en utilisant `hspinner()` :

```
number-hspinner hspinner('left-small-square','right-small-square','0.1')
```

Paramètres : forme du bouton gauche, forme du bouton droit, valeur du pas. Utilisez un pas décimal comme `0.5` ou `0.1` pour un contrôle précis.

**Couleurs personnalisées** en utilisant `colors()` :

```
number-hspinner colors(0099FF,FFFFFF,FF5500,FFFFFF)
```

Quatre valeurs dans l'ordre : arrière-plan du bouton gauche, icône du bouton gauche, arrière-plan du bouton droit, icône du bouton droit.

---

### `thousandsep` — séparateur de milliers

Formate le nombre affiché avec des groupes de virgules (par exemple `1,234.56`). Le nombre brut est stocké sans virgules. Le type d'entrée est basculé sur `"text"` pour permettre l'affichage formaté.

```
thousandsep
```

---

### `digisep(n, "sep")` — regroupement de chiffres personnalisé

Regroupe les chiffres de la partie entière en blocs de `n` séparés par un séparateur personnalisé.

```
digisep(3," ")      → 1 234 567.89
```

Le type d'entrée est basculé sur `"text"` lorsque cette apparence est active.

---

### `textonly` — forcer le clavier texte

Force `type="text"` sur l'élément d'entrée. Empêche les bizarreries de saisie numérique du navigateur (masquer les zéros de fin, les flèches de rotation du bureau) tout en acceptant les valeurs décimales.

```
textonly
```

---

### `floating_hint` — l'indice flotte comme étiquette

Le texte `hint` s'affiche à l'intérieur de la saisie comme un espace réservé. Lorsque l'utilisateur commence à taper, il flotte au-dessus du champ comme une étiquette.

```
floating_hint
```

---

### `embed` — indice à l'intérieur de la bordure de saisie

Similaire à `floating_hint` — l'indice se trouve à l'intérieur de la bordure de saisie lorsqu'il est vide. Il ne flotte pas lorsque l'utilisateur tape.

```
embed
```

---

### `textpopup` — saisie de dialogue modale

Taper sur le champ ouvre un dialogue modal avec une saisie plus grande. Utile sur les petits écrans.

```
textpopup
```

---

### `charcount` — compteur de caractères en direct

Affiche un compteur de caractères `(n)` en direct sous l'entrée, mis à jour au fur et à mesure que l'utilisateur tape.

```
charcount
```

---

### `prefix(expr)` — ajouter un préfixe

Ajoute une chaîne statique ou calculée à la valeur affichée. La valeur stockée n'inclut pas le préfixe.

```
prefix('USD ')          → affiche "USD 72.50", stocke "72.50"
prefix(${currency})     → préfixe dynamique d'un autre champ
```

---

### `align_answer` — alignement du texte de saisie

Contrôle l'alignement horizontal de la valeur tapée à l'intérieur de l'entrée.

```
align_answer = left
align_answer = right
align_answer = center
```

---

### `inputs{qrscan}` — scan QR / code-barres dans le champ

Ajoute un bouton de scan de code QR à côté de la saisie. Ouvre le scanner de caméra et remplit le champ avec la valeur scannée.

```
inputs{qrscan}
```

## Contraintes et validation

| type | name | label | constraint | constraint_message |
|------|------|-------|------------|-------------------|
| decimal | weight | Poids (kg) | `. > 0 and . <= 500` | Entrez une valeur entre 0 et 500 |
| decimal | height | Taille (m) | `. > 0 and . <= 3` | Entrez une valeur entre 0 et 3 |
| decimal | temp | Température (°C) | `. >= 35 and . <= 42` | Température normale : 35°C–42°C |
| decimal | percentage | Pourcentage | `. >= 0 and . <= 100` | Entrez une valeur entre 0 et 100 |

## Exemple — formulaire de mesure

| type | name | label | appearance | constraint | constraint_message |
|------|------|-------|------------|------------|-------------------|
| decimal | weight_kg | Poids (kg) | `number-hspinner hspinner('left-small-square','right-small-square','0.5')` | `. > 0 and . <= 300` | Entrez un poids valide |
| decimal | height_m | Taille (m) | `number-hspinner hspinner('left-small-square','right-small-square','0.01')` | `. > 0 and . <= 3` | Entrez une taille valide |
| calculate | bmi | | | | |

Colonne de calcul de l'IMC :
```
${weight_kg} div (${height_m} * ${height_m})
```

## Bonnes pratiques

1. Utilisez `number-hspinner hspinner(..., '0.1')` pour les mesures nécessitant une décimale de précision — le sélecteur formate automatiquement à une décimale, en maintenant des valeurs cohérentes.
2. Utilisez `textonly` lorsque les navigateurs ajoutent des contrôles de rotation indésirables ou tronquent les zéros de fin (par exemple `3.0` affiché comme `3`).
3. Utilisez `thousandsep` pour les grandes valeurs financières afin que les répondants puissent vérifier qu'ils ont saisi la bonne magnitude.
4. Appliquez des contraintes de plage plutôt que de vous fier uniquement au type de clavier mobile.

## Limites

- Le sélecteur affiche toujours une décimale — si vous avez besoin de plus de précision dans la valeur affichée, utilisez la saisie simple à la place.
- `thousandsep` et `digisep()` stockent le nombre brut — ne lisez pas la valeur affichée formatée dans les calculs.

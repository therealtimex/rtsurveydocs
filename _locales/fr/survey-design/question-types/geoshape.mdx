---
title: "Geoshape"
description: "Les questions Geoshape capturent un polygone fermé défini par une séquence de points GPS."
---

Le type de question `geoshape` capture un polygone fermé — une série de coordonnées GPS où le premier et le dernier point sont identiques. Dans le formulaire web de rtSurvey, cela s'affiche sous la forme d'une **saisie de texte** où l'enquêteur saisit ou colle directement la chaîne de coordonnées.

## Spécification XLSForm de base

| type     | name        | label                            |
|----------|-------------|----------------------------------|
| geoshape | field_area  | Dessiner la limite du champ      |
| geoshape | zone        | Enregistrer la limite de la zone |

Pour la spécification standard, consultez la [documentation XLSForm](https://xlsform.org/en/#question-types).

---

## Format des données

Stocké sous la forme d'une liste de points séparés par des points-virgules avec **aucun espace autour des points-virgules**. Chaque point est composé de quatre valeurs séparées par des espaces :

```
lat lon alt acc;lat lon alt acc;lat lon alt acc;lat lon alt acc
```

| Component | Description |
|-----------|-------------|
| `lat` | Latitude en degrés décimaux |
| `lon` | Longitude en degrés décimaux |
| `alt` | Altitude en mètres (`0` si inconnue) |
| `acc` | Précision GPS en mètres (`0` si inconnue) |

**Le polygone doit être fermé** — le dernier point doit être égal au premier point.

**Exemple — un polygone à quatre points (triangle, fermé) :**
```
13.756331 100.501762 0 0;13.758000 100.503000 0 0;13.757000 100.506000 0 0;13.756331 100.501762 0 0
```

Un minimum de trois points distincts plus la répétition de fermeture est nécessaire pour former un polygone valide.

---

## Comment cela s'affiche dans rtSurvey

Dans le formulaire web de rtSurvey, `geoshape` s'affiche comme un simple **champ de texte**. L'enquêteur tape ou colle la chaîne de coordonnées. Il n'y a pas de sélecteur de carte de polygone interactif intégré pour ce type dans le formulaire web actuel.

### Collecte interactive de points de polygone

Le modèle recommandé pour la collecte sur le terrain est un **groupe de répétition de questions `geopoint`** — chaque sommet utilise le sélecteur de carte GPS complet — combiné à un `calculate` pour produire la chaîne geoshape :

| type | name | label | calculation |
|------|------|-------|-------------|
| begin repeat | polygon_points | Enregistrer chaque coin | |
| geopoint | point | Appuyer pour enregistrer le coin | |
| end repeat | polygon_points | | |
| calculate | geoshape_value | | `join(';', ${polygon_points/point})` |

Après avoir joint, ajoutez manuellement le premier point pour fermer le polygone, ou utilisez un second calcul pour le concaténer.

---

## Exemple d'utilisation

| type | name | label | hint | required |
|------|------|-------|------|----------|
| geoshape | farm_boundary | Enregistrer la limite du champ | Entrez tous les coins séparés par des points-virgules. Le premier et le dernier point doivent être identiques. | yes |

---

## Meilleures pratiques

1. Utilisez un groupe de répétition de questions `geopoint` pour une collecte interactive basée sur la carte et joignez les valeurs — cela donne aux enquêteurs un sélecteur GPS pour chaque sommet.
2. Fermez toujours le polygone (répétez le premier point à la fin) avant de soumettre.
3. Incluez le format attendu dans la colonne `hint` lorsqu'une saisie manuelle des coordonnées est requise.
4. Exigez au moins 3 points de coin distincts pour un polygone valide — imposez cela par des instructions plutôt que par des contraintes XLSForm.
5. Utilisez `geopoint` pour les questions de localisation unique et `geoshape` uniquement lorsque la démarcation de zone est l'objectif réel de l'enquête.

## Limitations

- Il n'y a pas de sélecteur de carte de polygone interactif intégré pour `geoshape` dans le formulaire web de rtSurvey.
- Le polygone doit être fermé manuellement — il n'y a pas de mécanisme de fermeture automatique en mode saisie de texte.
- La validation de la topologie du polygone (par exemple, non-auto-intersection, zone minimale) nécessite un post-traitement en dehors des contraintes XLSForm.
- Les limites longues avec de nombreux sommets produisent de grandes chaînes de texte.

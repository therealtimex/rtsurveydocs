Le type de question `text` collecte une chaîne de texte libre. C'est le type de saisie le plus flexible et il prend en charge un grand nombre de variantes d'apparence qui modifient la façon dont la saisie est rendue — d'un simple champ monoligne à la reconnaissance vocale, aux boîtes de dialogue contextuelles, aux éditeurs de texte enrichi et aux sélecteurs numériques.

## Spécification XLSForm de base

| type | name | label |
|------|------|-------|
| text | respondent_name | Nom complet du répondant |
| text | address | Adresse du domicile |

Pour la spécification standard, consultez la [documentation XLSForm](https://xlsform.org/en/#question-types).

---

## Modes de disposition

### Par défaut — saisie monoligne

Aucune apparence nécessaire. Rend un champ `<input type="text">` standard.

---

### `multiline` — zone de texte

Rend une zone de texte multiligne. L'utilisateur peut l'agrandir en tapant ; elle s'agrandit automatiquement.

```
multiline
```

**Contrôler la hauteur des lignes** en ajoutant `[initRows, maxRows]` :

```
multiline [3,8]     → commence à 3 lignes, s'étend jusqu'à 8
multiline [5]       → fixé à 5 lignes
```

La valeur par défaut est 1 ligne sans maximum. Shift+Entrée insère un saut de ligne ; Entrée passe à la question suivante.

---

### `floating_hint` — l'indice flotte comme étiquette

Le texte `hint` s'affiche à l'intérieur du champ de saisie comme un espace réservé. Lorsque l'utilisateur commence à taper, l'indice flotte au-dessus du champ comme une étiquette.

```
floating_hint
```

---

### `embed` — indice à l'intérieur de la saisie

Similaire à `floating_hint` — l'indice s'affiche à l'intérieur de la limite de saisie lorsque le champ est vide. Ne flotte pas lors de la saisie.

```
embed
```

---

### `textpopup` — saisie par boîte de dialogue modale

Appuyer sur le champ ouvre une boîte de dialogue modale SweetAlert avec une grande saisie au lieu d'éditer en ligne. Utile sur mobile pour donner plus d'espace d'écran pour la saisie.

```
textpopup
```

---

### `richtext` — éditeur WYSIWYG

Rend un éditeur de texte riche complet (Monaco / Draft.js). Le répondant peut mettre en gras, en italique, ajouter des listes, etc. La valeur stockée est HTML.

```
richtext
richtext(30%)       → hauteur de l'éditeur 30% de la fenêtre d'affichage
```

---

### `charcount` — compteur de caractères en direct

Ajoute un affichage du nombre de caractères `(n)` en direct sous la saisie, mis à jour au fur et à mesure que l'utilisateur tape.

```
charcount
multiline charcount
```

---

## Variantes de saisie numérique

Ces apparences fonctionnent sur le type `text` pour collecter des nombres avec des formats ou des modèles d'interaction spéciaux.

### `numbers` — clavier numérique

Force le type d'entrée HTML à `number`, déclenchant un clavier numérique sur mobile.

```
numbers
```

### `thousandsep` — séparateur de milliers

Affiche le nombre avec un regroupement par virgules (par exemple `1,234,567`) tout en stockant le nombre brut. Le type d'entrée est forcé à `text` pour permettre l'affichage de la virgule.

```
thousandsep
```

### `digisep(n, "sep")` — regroupement de chiffres personnalisé

Regroupe les chiffres en blocs de `n` séparés par un caractère personnalisé. Utile pour les numéros de téléphone, les numéros d'identification, etc.

```
digisep(4,"-")      → 0912-3456-789
digisep(3," ")      → 012 345 678
```

### `number-hspinner` — sélecteur horizontal

Remplace la saisie par un sélecteur horizontal **− valeur +**. L'utilisateur appuie sur les boutons moins/plus pour décrémenter ou incrémenter la valeur. Fonctionne avec les types `int` et `decimal`.

```
number-hspinner
```

**Personnaliser l'apparence du bouton** en utilisant `hspinner()`:

```
number-hspinner hspinner('left-small-square','right-small-square','1')
```

Paramètres : forme du bouton gauche, forme du bouton droit, valeur du pas.

**Couleurs personnalisées** en utilisant `colors()`:

```
number-hspinner colors(0099FF,FFFFFF,FF5500,FFFFFF)
```

Quatre valeurs de couleur : arrière-plan gauche, icône gauche, arrière-plan droit, icône droit.

### `prefix(expr)` — ajouter un préfixe

Ajoute une chaîne calculée ou statique à la valeur affichée. La valeur stockée n'inclut pas le préfixe.

```
prefix('USD ')      → affiche "USD 100", stocke "100"
prefix(${currency}) → préfixe dynamique d'un autre champ
```

### `textonly` — forcer le type de saisie texte

Force `type="text"` même lorsque le champ est `integer` ou `decimal`. Utile pour éviter les bizarreries de saisie numérique du navigateur.

```
textonly
```

## Transformation de texte

Ces apparences transforment automatiquement la valeur au fur et à mesure que l'utilisateur tape.

| Appearance | Effect | Example input → stored |
|---|---|---|
| `upper` | Convertit en MAJUSCULES | `hello` → `HELLO` |
| `lower` | Convertit en minuscules | `HELLO` → `hello` |
| `proper` | Convertit en casse appropriée | `john doe` → `John Doe` |

## Aides à la capture d'entrée

### `inputs{stt}` — reconnaissance vocale

Ajoute un bouton microphone à côté de l'entrée. Taper dessus démarre la reconnaissance vocale du navigateur (Web Speech API). Le texte transcrit est ajouté au champ.

```
inputs{stt}
```

Non pris en charge sur Safari. Nécessite l'autorisation du microphone.

### `inputs{qrscan}` — scanner QR / code-barres

Ajoute un bouton de scan de code QR à côté de l'entrée. Ouvre la modale du scanner de l'appareil photo et remplit le champ avec la valeur scannée.

```
inputs{qrscan}
```

**Tokeniser** (ajouter les valeurs scannées au lieu de les remplacer) :

```
inputs{qrscan} append(${separator})
```

### `inputs{stt,qrscan}` — à la fois la parole et le scan

Affiche à la fois les boutons microphone et scan QR côte à côte.

```
inputs{stt,qrscan}
inputs{qrscan,stt}
```

## Variantes liées à la sélection

Ces apparences lient un champ de texte à une liste de choix `select_one`, permettant à l'utilisateur de choisir dans la liste ou de taper librement.

### `selection_one_hide` — sélecteur déroulant

Rend l'entrée de texte avec une flèche déroulante. Taper sur la flèche affiche les choix de la liste `search()` liée. La sélection d'un choix remplit l'entrée et la verrouille (affiche ✕ pour effacer).

```
selection_one_hide
```

### `selection_one_show` — liste radio ci-dessous

Rend l'entrée de texte avec des boutons radio en dessous. La sélection d'un bouton radio remplit et verrouille l'entrée.

```
selection_one_show
```

Les deux variantes nécessitent une expression `search()` dans la colonne `calculation` pour définir la liste de choix.

---

## Alignement de la réponse

Contrôle l'alignement horizontal du texte saisi dans la zone de saisie.

```
align_answer = left
align_answer = right
align_answer = center
```

---

## Widget de saisie de l'heure (horloge en ligne)

rtSurvey étend `text` avec un widget de sélection d'heure. Ces apparences affichent une icône d'horloge que l'énumérateur touche pour sélectionner une valeur horaire. La valeur est stockée en texte brut dans le format choisi.

### Apparences

| Appearance | Description |
|---|---|
| `inline` | Bouton icône horloge à côté du champ, ouvre une modale |
| `inline-onlyresult` | L'icône horloge disparaît après la sélection |
| `inline-1line` | Sélecteur d'heure compact à une seule ligne |
| `inline colors("RRGGBB")` | Icône horloge avec couleur personnalisée |
| `inline-1line colors("RRGGBB","RRGGBB")` | Sélecteur avec deux couleurs d'accentuation |

### Jetons de format

Ajoutez `-[format]` pour contrôler quels composants de temps sont affichés et stockés :

| Format | Affiche |
|---|---|
| `inline-[%H:%M]` | Heures : Minutes (24h) |
| `inline-[%h:%M]` | Heures : Minutes (12h) |
| `inline-[%H:%M:%S]` | Heures : Minutes : Secondes (24h) |
| `inline-[%M:%S]` | Minutes : Secondes |
| `inline-[%H:%M:%3]` | Heures : Minutes : Millisecondes |
| `inline-[%S]` | Secondes seulement |
| `inline-[%3]` | Millisecondes seulement |
| `inline-[%H]` | Heures seulement (24h) |

### Position du bouton avec `display{}`

Identique aux autres types en ligne — contrôle la position et la taille du bouton de l'horloge :

```
inline display{right}
inline display{center, large}
inline-onlyresult display{left, medium, #0099FF}
```

## Contraintes et validation

Appliquer des contraintes pour faire respecter le format, la longueur ou le motif :

| type | name | label | constraint | constraint_message |
|------|------|-------|------------|-------------------|
| text | name | Nom complet | `string-length(.) >= 2` | Au moins 2 caractères requis |
| text | code | Code de référence | `regex(., '^[A-Z]{2}[0-9]{4}$')` | 2 lettres majuscules + 4 chiffres |
| text | phone | Numéro de téléphone | `regex(., '^[0-9]{9,15}$')` | Saisir un numéro de téléphone valide |

## Bonnes pratiques

1. Utilisez des types plus spécifiques (`integer`, `decimal`, `date`) lorsque les données ont une structure connue — cela empêche les entrées non valides.
2. Utilisez `multiline [3,8]` pour les questions ouvertes afin de donner aux répondants de l'espace pour écrire sans surcharger l'écran.
3. Utilisez `thousandsep` ou `digisep()` au lieu de `numbers` lorsque vous avez besoin d'un affichage formaté — `numbers` seul ne fait que changer le clavier.
4. Utilisez `inputs{qrscan}` pour éliminer les erreurs de saisie manuelle pour les codes, les identifiants et les numéros de série.
5. Utilisez `floating_hint` lorsque l'indice est un contexte important qui doit rester visible pendant la saisie — les indices standard disparaissent de la vue sur les petits écrans.
6. Utilisez `charcount` sur les questions avec des contraintes de longueur afin que les répondants puissent s'auto-surveiller.

## Limitations

- `inputs{stt}` nécessite un navigateur qui prend en charge l'API Web Speech. Chrome est le plus fiable ; Safari n'est pas pris en charge.
- `richtext` stocke le HTML — prévoyez l'élimination ou la désinfection du HTML dans votre pipeline d'analyse si du texte brut est attendu.
- `selection_one_hide` et `selection_one_show` nécessitent une expression `search()` et ne sont pris en charge que sur le client web.
- `number-hspinner` valide par rapport à la colonne `constraint` à chaque pression de bouton, et pas seulement lors de la perte de focus — concevez les contraintes en conséquence.

Bu kılavuzu, rtSurvey'i kendi sunucunuzda (VPS, bare metal veya yerel makine) `rtawebteam/rtcloud:survey-public` genel Docker imajını kullanarak çalıştırmak istiyorsanız kullanın.

**Docker Hub girişi gerekmez** — imaj herkese açıktır.

Konteyner her şeyi tek bir imajda bir araya getirir:
- Apache + PHP (uygulama sunucusu)
- Shiny Server (analitik panolar, port 3838)
- Beanstalkd (arka plan iş kuyruğu)

---

## Gereksinimler

### Sunucu

| Kaynak | Minimum | Önerilen |
|--------|---------|----------|
| RAM | 4 GB | 8 GB |
| Disk | 50 GB | 100 GB SSD |
| CPU | 2 vCPU | 4 vCPU |
| İşletim Sistemi | Ubuntu 22.04 LTS | Ubuntu 22.04 LTS |

### Yazılım

- **Docker Engine 24.0+** — [kurulum kılavuzu](https://docs.docker.com/engine/install/ubuntu/)
- **Docker Compose v2.0+** — Docker Desktop ile birlikte gelir; Linux'ta: `apt install docker-compose-plugin`

## Kurulum

<Steps>

### Çalışma dizini oluşturun

```bash
mkdir -p /opt/rtsurvey && cd /opt/rtsurvey
```

### `docker-compose.yml` oluşturun

```yaml
services:
  mysql:
    image: mysql:8.0
    container_name: rtsurvey-mysql
    restart: unless-stopped
    command: >
      --default-authentication-plugin=mysql_native_password
      --character-set-server=utf8
      --collation-server=utf8_unicode_ci
      --sql-mode=NO_ENGINE_SUBSTITUTION
    environment:
      MYSQL_ROOT_PASSWORD: ${MYSQL_ROOT_PASSWORD}
      MYSQL_DATABASE: ${MYSQL_DATABASE:-smartsurvey}
      MYSQL_USER: ${MYSQL_USER:-smartsurvey}
      MYSQL_PASSWORD: ${MYSQL_PASSWORD}
      MYSQL_ROOT_HOST: '%'
    volumes:
      - mysql_data:/var/lib/mysql
    networks:
      - rtsurvey-net
    healthcheck:
      test: ["CMD-SHELL", "mysqladmin ping -h localhost -u root -p$$MYSQL_ROOT_PASSWORD"]
      interval: 10s
      timeout: 5s
      retries: 5
      start_period: 30s

  rtsurvey:
    image: rtawebteam/rtcloud:survey-public
    container_name: rtsurvey-app
    restart: unless-stopped
    entrypoint: ["/bin/entrypoint-production.sh"]
    depends_on:
      mysql:
        condition: service_healthy
    ports:
      - "${APP_PORT:-8080}:80"
      - "${SHINY_PORT:-3838}:3838"
    env_file:
      - .env
    volumes:
      - app_uploads:/var/www/html/smartsurvey/uploads
      - app_audios:/var/www/html/smartsurvey/audios
      - app_downloads:/var/www/html/smartsurvey/downloads
      - app_gallery:/var/www/html/smartsurvey/gallery
      - app_tmp:/var/www/html/smartsurvey/tmp
      - app_cache:/var/www/html/smartsurvey/cache
      - app_runtime:/var/www/html/smartsurvey/protected/runtime
      - app_assets:/var/www/html/smartsurvey/assets
      - app_aggregate:/var/www/html/smartsurvey/aggregate
    networks:
      - rtsurvey-net
    healthcheck:
      test: ["CMD", "curl", "-f", "http://localhost/health"]
      interval: 30s
      timeout: 10s
      retries: 3
      start_period: 90s

  # İsteğe bağlı: Gömülü Keycloak SSO
  # Şununla başlatın: docker compose --profile embed-keycloak up -d
  keycloak:
    image: quay.io/keycloak/keycloak:latest
    container_name: rtsurvey-keycloak
    restart: unless-stopped
    profiles:
      - embed-keycloak
    command: start --import-realm
    environment:
      KEYCLOAK_ADMIN: ${KEYCLOAK_ADMIN_USER:-admin}
      KEYCLOAK_ADMIN_PASSWORD: ${KEYCLOAK_ADMIN_PASSWORD}
      KC_HTTP_ENABLED: "true"
      KC_HTTP_RELATIVE_PATH: /auth
      KC_PROXY_HEADERS: xforwarded
      KC_HOSTNAME: ${KC_HOSTNAME}
      KC_HOSTNAME_STRICT: "false"
      KC_DB: mysql
      KC_DB_URL_DATABASE: ${KEYCLOAK_DB:-keycloak}
      KC_DB_URL_HOST: mysql
      KC_DB_USERNAME: ${KEYCLOAK_DB_USER:-keycloak}
      KC_DB_PASSWORD: ${KEYCLOAK_DB_PASSWORD}
    volumes:
      - ./keycloak-import:/opt/keycloak/data/import
    ports:
      - "${KEYCLOAK_PORT:-8091}:8080"
    depends_on:
      mysql:
        condition: service_healthy
    networks:
      - rtsurvey-net
    healthcheck:
      test: ["CMD-SHELL", "curl -f http://localhost:9000/health/ready || exit 1"]
      interval: 30s
      timeout: 10s
      retries: 10
      start_period: 120s

volumes:
  mysql_data:
  app_uploads:
  app_audios:
  app_downloads:
  app_gallery:
  app_tmp:
  app_cache:
  app_runtime:
  app_assets:
  app_aggregate:

networks:
  rtsurvey-net:
    driver: bridge
```

### `.env` oluşturun

```bash
# Project
PROJECT_ID=mysurvey
PROJECT_TYPE=rtsurvey
PROJECT_URL=your-server-ip-or-domain
HTTP_PROTOCOL=http
TZ=UTC

# Database
MYSQL_HOST=mysql
MYSQL_DATABASE=smartsurvey
MYSQL_USER=smartsurvey
MYSQL_ROOT_PASSWORD=change-this-root-password
MYSQL_PASSWORD=change-this-app-password

# Admin (set before first startup — cannot change via env after DB is created)
ADMIN_PASSWORD=change-this-admin-password

# Runtime
RUN_ENV=prod
RUN_MODE=admin
GII_ENABLED=false
CSRF_VALIDATION_ENABLED=true

# Ports (optional — defaults shown)
APP_PORT=8080
SHINY_PORT=3838
```

<Callout type="warning">
Başlatmadan önce `MYSQL_ROOT_PASSWORD` ve `MYSQL_PASSWORD` değerlerini değiştirin. Üretimde güçlü rastgele dizeler (32+ karakter) kullanın.
</Callout>

### Yığını başlatın

```bash
docker compose up -d
```

İlk başlatma yaklaşık 60–90 saniye sürer — MySQL ilk çalıştırmada veritabanını başlatır.

### Doğrulayın

```bash
# Tüm konteynerlerin çalışıp çalışmadığını kontrol edin
docker compose ps

# Uygulama sağlığını kontrol edin
curl http://localhost:8080/health
```

</Steps>

## İlk Giriş

Sağlık kontrolü geçtikten sonra tarayıcınızı açın:

```
http://your-server:8080/cpms/cpmsSite/login
```

| Alan | Değer |
|------|-------|
| Kullanıcı adı | `admin` |
| Şifre | `.env` dosyanızdaki `ADMIN_PASSWORD` değeri (varsayılan: `admin`) |

<Callout type="warning">
İlk başlatmadan önce `.env` dosyanızda `ADMIN_PASSWORD` değerini ayarlayın. Giriş noktası bunu ilk çalıştırmada ayarlar — veritabanı başlatıldıktan sonra değiştirmenin etkisi olmaz.
</Callout>

## Ortam Değişkenleri

### Uygulama konteyneri için gerekli

Bunlardan herhangi biri eksikse giriş noktası başlamayı reddeder:

| Değişken | Açıklama |
|----------|----------|
| `PROJECT_ID` | Bu örnek için benzersiz tanımlayıcı (alfasayısal, boşluk yok) |
| `PROJECT_URL` | Uygulamaya erişilen alan adı veya IP (`http://` öneki olmadan) |
| `MYSQL_HOST` | MySQL ana bilgisayar adı — Docker servis adını kullanın (örn. `mysql`) |
| `MYSQL_DATABASE` | Veritabanı adı |
| `MYSQL_PASSWORD` | Veritabanı kullanıcı şifresi |

### MySQL konteyneri için gerekli

| Değişken | Açıklama |
|----------|----------|
| `MYSQL_ROOT_PASSWORD` | MySQL root şifresi (`mysql` konteyneri tarafından kullanılır, uygulama tarafından değil) |

### Önerilen

| Değişken | Varsayılan | Açıklama |
|----------|------------|----------|
| `MYSQL_USER` | `smartsurvey` | Veritabanı kullanıcı adı |
| `ADMIN_PASSWORD` | `admin` | İlk yönetici şifresi — **ilk başlatmadan önce ayarlayın**, DB oluşturulduktan sonra env ile değiştirilemez |
| `HTTP_PROTOCOL` | `https` | SSL kullanmıyorsanız `http` olarak ayarlayın |
| `PROJECT_PORT` | `80` | Kullanıcıların bağlandığı dış port (iç Docker portu değil) |
| `PROJECT_TYPE` | `rtwork` | Platform türü — anket platformu için `rtsurvey` kullanın |
| `TZ` | `UTC` | Saat dilimi (örn. `Asia/Bangkok`, `America/New_York`) |

### Çalışma Zamanı

| Değişken | Varsayılan | Açıklama |
|----------|------------|----------|
| `RUN_ENV` | `prod` | Ortam modu (`prod` veya `dev`) |
| `RUN_MODE` | `admin` | Servis rolü — tek sunucu kurulumu için `admin` kullanın |
| `GII_ENABLED` | `false` | Üretimde `false` tutun (Yii kod üreteci) |
| `CSRF_VALIDATION_ENABLED` | `true` | CSRF koruması — `true` tutun |

### Lisans

| Değişken | Varsayılan | Açıklama |
|----------|------------|----------|
| `REQUIRE_LICENSE` | `false` | Lisans doğrulamasını zorlamak için `true` yapın |
| `RTCLOUD_LICENSE_KEY` | — | Lisans anahtarınız — `REQUIRE_LICENSE=true` olduğunda gerekli |

## Veri Kalıcılığı

Tüm kullanıcı verileri adlandırılmış Docker birimlerinde saklanır. Bunlar konteyner yeniden başlatmalarından ve imaj güncellemelerinden kurtulur.

| Birim | İçerik |
|-------|--------|
| `mysql_data` | Veritabanı (anketler, kullanıcılar, yanıtlar) |
| `app_uploads` | Anketlerden dosya yüklemeleri |
| `app_gallery` | Medya kütüphanesi |
| `app_downloads` | Oluşturulan dışa aktarma dosyaları |
| `app_audios` | Ses kayıtları |
| `app_runtime` | PHP oturum ve önbellek dosyaları |
| `app_aggregate` | Toplanmış analitik veriler |

## Yaygın İşlemler

### Günlükleri görüntüleyin

```bash
docker compose logs -f rtsurvey
docker compose logs -f mysql
```

### Uygulamayı yeniden başlatın

```bash
docker compose restart rtsurvey
```

### Bir kabuk açın

```bash
docker compose exec rtsurvey bash
```


## Güncellemeler

İmaj `survey-public` olarak etiketlenmiştir. En son sürüme güncellemek için:

```bash
docker compose pull
docker compose up -d
```

## Yedekleme ve Geri Yükleme

### Veritabanını yedekleyin

```bash
docker compose exec mysql \
  mysqldump -u root -p"${MYSQL_ROOT_PASSWORD}" smartsurvey \
  > backup-$(date +%Y%m%d).sql
```

### Veritabanını geri yükleyin

```bash
docker compose exec -T mysql \
  mysql -u root -p"${MYSQL_ROOT_PASSWORD}" smartsurvey \
  < backup-20240101.sql
```

### Yüklenen dosyaları yedekleyin

```bash
docker run --rm \
  -v rtsurvey_app_uploads:/data \
  -v $(pwd):/backup \
  alpine tar czf /backup/uploads-$(date +%Y%m%d).tar.gz -C /data .
```

## Gömülü Keycloak (İsteğe Bağlı SSO)

Üretim compose dosyası, SSO için isteğe bağlı bir Keycloak konteyneri içerir. Aynı MySQL örneğini paylaşır ve bir Docker Compose profili aracılığıyla etkinleştirilir.

<Callout type="info">
Gömülü Keycloak en az **4 GB RAM** gerektirir. İsteğe bağlıdır — SSO'ya ihtiyacınız yoksa atlayın.
</Callout>

### `.env` dosyasına Keycloak değişkenleri ekleyin

```bash
# Keycloak admin
KEYCLOAK_ADMIN_USER=admin
KEYCLOAK_ADMIN_PASSWORD=change-this-keycloak-password

# Keycloak database (created automatically in the shared MySQL on first run)
KEYCLOAK_DB=keycloak
KEYCLOAK_DB_USER=keycloak
KEYCLOAK_DB_PASSWORD=change-this-keycloak-db-password

# KC_HOSTNAME: full public URL of your server (Keycloak appends /auth automatically)
KC_HOSTNAME=http://your-server:8091

# Port Keycloak listens on (host)
KEYCLOAK_PORT=8091

# Tell the rtCloud app to connect to embedded Keycloak
EMBED_KEYCLOAK=true
KEYCLOAK_URL=http://your-server:8091
KEYCLOAK_REALM=rtsurvey
KEYCLOAK_CLIENT_ID=rtsurvey
KEYCLOAK_CLIENT_SECRET=your-client-secret
```

`keycloak` servisi yukarıdaki `docker-compose.yml` dosyasına zaten dahildir (`embed-keycloak` profili altında — `--profile embed-keycloak` kullanmadığınız sürece başlamaz).

İçe aktarma dizinini oluşturun (Keycloak onsuz başlayacak ancak alan otomatik sağlama çalışmayacak):

```bash
mkdir -p /opt/rtsurvey/keycloak-import
```

### Keycloak ile başlatın

```bash
docker compose --profile embed-keycloak up -d
```

Keycloak olmadan başlatmak için (varsayılan):

```bash
docker compose up -d
```

### Keycloak yönetici konsolu

Sağlıklı duruma geldiğinde, Keycloak yönetici arayüzüne şu adresten erişin:

```
http://your-server:8091/auth/admin
```

`KEYCLOAK_ADMIN_USER` / `KEYCLOAK_ADMIN_PASSWORD` ile giriş yapın.

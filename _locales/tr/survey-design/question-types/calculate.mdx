`calculate` soru tipi, arka planda sessizce bir formül çalıştırır. Sonucu, diğer soruların referans verebileceği adlandırılmış bir alanda saklar; ancak anketöre herhangi bir girdi veya etiket göstermez. Değer türetmek, dizeleri birleştirmek, koşullu mantık yürütmek veya formda daha sonra ihtiyaç duyacağınız verileri aramak için kullanın.

---

## Temel sözdizimi

| type | name | label | calculation |
|------|------|-------|-------------|
| calculate | total | | `${price} * ${quantity}` |

- **type**: Her zaman `calculate`.
- **name**: Benzersiz bir alan adı. Diğer sorular buna `${name}` ile referans verir.
- **label**: Boş bırakın — calculate alanları anketöre asla gösterilmez.
- **calculation**: Değerlendirilecek formül. Tüm [XLSForm işlevlerini](../operators-and-functions/functions) ve alan referanslarını destekler.

---

## Yaygın kalıplar

### Aritmetik

| type | name | label | calculation |
|------|------|-------|-------------|
| integer | price | Unit price | |
| integer | quantity | Quantity | |
| calculate | total | | `${price} * ${quantity}` |
| note | total_note | Total: `${total}` | |

### Dize birleştirme (String concatenation)

| type | name | label | calculation |
|------|------|-------|-------------|
| text | first_name | First name | |
| text | last_name | Last name | |
| calculate | full_name | | `concat(${first_name}, ' ', ${last_name})` |

### Koşullu değer

| type | name | label | calculation |
|------|------|-------|-------------|
| integer | score | Score (0–100) | |
| calculate | grade | | `if(${score} >= 90, 'A', if(${score} >= 75, 'B', if(${score} >= 60, 'C', 'F')))` |

### Doğum tarihinden yaş hesaplama

| type | name | label | calculation |
|------|------|-------|-------------|
| date | dob | Date of birth | |
| calculate | age_years | | `int((today() - ${dob}) div 365.25)` |

## Değeri kilitlemek için `once()` kullanma

Varsayılan olarak, referans verilen herhangi bir alan değiştiğinde `calculate` yeniden değerlendirilir. Formülü yalnızca ilk yüklemede değerlendirmek ve sonucu dondurmak için `once()` içine alın:

| type | name | label | calculation |
|------|------|-------|-------------|
| calculate | interview_start | | `once(now())` |

Zaman damgaları, başlangıç değerleri veya değişiklikle yeniden hesaplamanın istenmediği durumlar için `once()` kullanın.

## Harici kaynaklardan veri çekme

### Bir CSV dosyasından

```
pulldata('staff.csv', 'department', 'name', ${staff_id})
```

Tam referans için [pulldata()](../operators-and-functions/pulldata) sayfasına bakın.

### Paketlenmiş bir SQLite veritabanından

```
pulldata('rawquery',
  concat(${family_path}, '/locations.db::provinces'),
  'SELECT name FROM provinces WHERE id = ?',
  ${province_id})
```

Yol oluşturma ayrıntıları için [Yerel Veritabanı Araması](../advanced-features/local-database-search) sayfasına bakın.

### Uygulama bağlamından

```
pulldata('app-api', 'user.username')
pulldata('app-api', 'family_path')
```

Mevcut tüm anahtarlar için [App API](../app-api) sayfasına bakın.

## relevant ve constraint sütunlarında calculate kullanma

Diğer alanlar, herhangi bir alan gibi bir `calculate` sonucuna referans verebilir:

| type | name | label | relevant | constraint |
|------|------|-------|----------|------------|
| calculate | bmi | | | `${weight} div (${height} * ${height}) * 10000` |
| note | bmi_warning | BMI is very high — please verify weight and height. | `${bmi} > 40` | |

## En İyi Uygulamalar

1. Calculate alanlarına anlamlı adlar verin — `total_cost`, `calc1`den daha nettir ve dışa aktarmalarda izlenmesi daha kolaydır.
2. Karmaşık formülleri tek bir derin iç içe geçmiş ifade yerine birden fazla zincirlenmiş calculate alanına bölün.
3. Değerlerin ilk yakalamadan sonra değişmesini önlemek için zaman damgaları ve ilk anlık görüntüler için `once()` kullanın.
4. `calculate` alanlarını, onlara referans veren ilk sorudan önce yerleştirin — değerlendirme sırası form sırasını takip eder.
5. `label` sütununu boş bırakın. Bazı araçlar etiketi görüntüler; boş bırakmak kafa karıştırıcı çıktıları önler.

## Sınırlamalar

- Calculate alanları anketöre asla doğrudan gösterilmez — sonucu göstermek için bir `note` alanı kullanın.
- `calculation` sütunu zorunludur; formülü olmayan bir `calculate` satırı her zaman boş bir dize saklar.
- Sonuçlar, `once()` içine alınmadıkça her form değişikliğinde yeniden değerlendirilir — büyük formlardaki çok karmaşık formüller, düşük donanımlı cihazlarda oluşturma performansını etkileyebilir.
- Hesaplanan değerler gönderimde dize olarak saklanır. Sonucu aritmetik veya mantık ifadelerine geçirirken tür dönüşümü yapmak için `number()`, `int()` veya `boolean()` kullanın.

XLSForm'daki gruplar, ilgili soruları bir araya organize etmenize, anket yapınızı iyileştirmenize ve veri analizi yeteneklerini geliştirmenize olanak tanır. rtSurvey, XLSForm gruplarını tam olarak destekler ve bunları ek özelliklerle genişletir.

## Temel Grup Yapısı

Bir soru grubu oluşturmak için `begin_group` ve `end_group` sözdizimini kullanın:

```
| type         | name       | label                                    |
|--------------|------------|------------------------------------------|
| begin_group  | respondent | Katılımcı Bilgileri                      |
| text         | name       | Katılımcının adını girin                 |
| text         | position   | Katılımcının pozisyonunu girin           |
| end_group    |            |                                          |
```

Temel noktalar:
- `begin_group` satırı bir `name` ve `label` gerektirir.
- `end_group` satırının ad veya etikete ihtiyacı yoktur.
- `begin_group` ile `end_group` arasındaki sorular grubun bir parçasıdır.

## Grup Görünümü

rtSurvey, gruplar için çeşitli görünüm seçeneklerini destekler:

1. **field-list**: Birden fazla soruyu aynı ekranda görüntüler.
   ```
   | type         | name       | label     | appearance |
   |--------------|------------|-----------|------------|
   | begin_group  | respondent | Katılımcı | field-list |
   | text         | name       | Ad        |            |
   | text         | position   | Pozisyon  |            |
   | end_group    |            |           |            |
   ```

2. **grid**: Gruplar için kompakt, tablo benzeri bir düzen oluşturur (rtSurvey'e özgü).
   ```
   | type         | name       | label     | appearance |
   |--------------|------------|-----------|------------|
   | begin_group  | household  | Hane      | grid       |
   | text         | member_name| Ad        |            |
   | integer      | member_age | Yaş       |            |
   | end_group    |            |           |            |
   ```

3. **collapsible**: Genişletilebilir/daraltılabilir gruplar oluşturur (rtSurvey'e özgü).
   ```
   | type         | name       | label     | appearance  |
   |--------------|------------|-----------|-------------|
   | begin_group  | details    | Ayrıntılar| collapsible |
   | text         | address    | Adres     |             |
   | text         | phone      | Telefon   |             |
   | end_group    |            |           |             |
   ```

## İç İçe Gruplar

Gruplar, daha karmaşık yapılar için diğer grupların içine yerleştirilebilir:

```
| type         | name       | label                                    |
|--------------|------------|------------------------------------------|
| begin_group  | hospital   | Hastane Bilgileri                        |
| text         | hosp_name  | Bu hastanenin adı nedir?                 |
| begin_group  | medication | İlaç Mevcudiyeti                         |
| select_one y_n| hiv_meds  | Bu hastanede HIV ilacı var mı?           |
| end_group    |            |                                          |
| end_group    |            |                                          |
```

**Not**: Doğru iç içe yapıyı korumak için her zaman en son başlatılan grubu önce bitirin.

## Gruplar için Atlama Mantığı

Tüm gruplar için atlama mantığı uygulamak üzere `relevant` sütununu kullanın:

```
| type         | name   | label                                        | relevant        |
|--------------|--------|----------------------------------------------|-----------------|
| integer      | age    | Kaç yaşındasınız?                            |                 |
| begin_group  | child  | Çocuk                                        | ${age} <= 5     |
| integer      | muac   | Çocuğun orta üst kol çevresini kaydedin      |                 |
| select_one y_n| mrdt  | Çocuğun hızlı tanı testi pozitif mi?         |                |
| end_group    |        |                                              |                 |
```

Bu örnekte, `child` grubu yalnızca katılımcının yaşı 5 veya altındaysa görünür.

## Grupları Kullanmak için En İyi Uygulamalar

1. Veri analizini iyileştirmek için gruplar için anlamlı adlar kullanın.
2. Grupları ilgili sorulara odaklanmış tutun.
3. Aşırı karmaşık yapılardan kaçınmak için iç içe grupları dikkatli kullanın.
4. Gruplar üzerinde `relevant` kullanırken atlama mantığını kapsamlı biçimde test edin.
5. Kaydırmayı azaltmak için kısa gruplar için `field-list` görünümünü kullanmayı düşünün.
6. İlgili bilgilerin kompakt görüntülenmesi için rtSurvey'in ızgara düzenini kullanın.
7. Uzun formlar için gezinmeyi iyileştirmek üzere daraltılabilir gruplar kullanın.

## rtSurvey'e Özgü Özellikler

1. **Izgara Düzeni**: Tablo benzeri görüntüler için `grid` görünümünü kullanın.
2. **Daraltılabilir Gruplar**: Genişletilebilir bölümler için `collapsible` görünümünü uygulayın.
3. **Özel Stil**: Benzersiz görsel tasarımlar için gruplara özel CSS uygulayın.
4. **Dinamik Grup Davranışı**: Gruplar içinde karmaşık atlama mantığı ve hesaplamalar uygulayın.

## Çok Dilli Destek

rtSurvey, çok dilli grupları destekler. Etiketler için dile özgü sütunları kullanın:

```
| type         | name       | label::English | label::French |
|--------------|------------|----------------|---------------|
| begin_group  | personal   | Kişisel Bilgi  | Infos Personnelles |
| text         | name       | Ad             | Nom           |
| end_group    |            |                |               |
```

## Mobil Uygulama Hususları

- `field-list` görünümüne sahip gruplar mobil uygulamada tek bir ekran olarak görüntülenir.
- Daraltılabilir gruplar daha küçük ekranlarda gezinmeyi iyileştirebilir.
- Izgara düzenleri mobil cihazlarda daha iyi görünürlük için ayarlanabilir.

## Bilinen Sınırlamalar

- Son derece derin iç içe gruplar bazı cihazlarda performansı etkileyebilir.
- Bazı gelişmiş stil seçenekleri mobil uygulamadaki gruplar için mevcut olmayabilir.

## Grupları Sorun Giderme

1. Her `begin_group`'un karşılık gelen bir `end_group`'a sahip olduğundan emin olun.
2. Grup adlarının form içinde benzersiz olduğunu kontrol edin.
3. Atlama mantığının doğru soru adlarına referans verdiğini doğrulayın.
4. Grupları hem web hem de mobil arayüzlerde kapsamlı biçimde test edin.

rtSurvey ile XLSForm'larda grupları etkin biçimde kullanarak, hem veri toplama deneyimini hem de veri analizi kalitesini artıran, iyi organize edilmiş ve verimli anketler oluşturabilirsiniz.

Het vraagtype `calculate` voert een formule geruisloos op de achtergrund uit. Het slaat het resultaat op in een benoemd veld waarnaar andere vragen kunnen verwijzen, maar toont geen invoer of label aan de teller. Gebruik het om waarden af te leiden, strings samen te voegen, voorwaardelijke logica uit te voeren of gegevens op te zoeken die u later in het formulier nodig hebt.

---

## Basissyntaxis

| type | name | label | calculation |
|------|------|-------|-------------|
| calculate | total | | `${price} * ${quantity}` |

- **type**: Altijd `calculate`.
- **name**: Een unieke veldnaam. Andere vragen verwijzen hiernaar met `${name}`.
- **label**: Laat leeg — calculate-velden worden nooit getoond aan de teller.
- **calculation**: De te evalueren formule. Ondersteunt alle [XLSForm-functies](../operators-and-functions/functions) en veldverwijzingen.

## Veelvoorkomende patronen

### Rekenkunde

| type | name | label | calculation |
|------|------|-------|-------------|
| integer | price | Unit price | |
| integer | quantity | Quantity | |
| calculate | total | | `${price} * ${quantity}` |
| note | total_note | Total: `${total}` | |

### String-samenvoeging (String concatenation)

| type | name | label | calculation |
|------|------|-------|-------------|
| text | first_name | First name | |
| text | last_name | Last name | |
| calculate | full_name | | `concat(${first_name}, ' ', ${last_name})` |

### Voorwaardelijke waarde

| type | name | label | calculation |
|------|------|-------|-------------|
| integer | score | Score (0–100) | |
| calculate | grade | | `if(${score} >= 90, 'A', if(${score} >= 75, 'B', if(${score} >= 60, 'C', 'F')))` |

### Leeftijd op basis van geboortedatum

| type | name | label | calculation |
|------|------|-------|-------------|
| date | dob | Date of birth | |
| calculate | age_years | | `int((today() - ${dob}) div 365.25)` |

## `once()` gebruiken om de waarde te vergrendelen

Standaard wordt `calculate` opnieuw geëvalueerd telkens wanneer een naar verwezen veld verandert. Plaats de formule in `once()` om deze alleen bij de eerste keer laden te evalueren en het resultaat te bevriezen:

| type | name | label | calculation |
|------|------|-------|-------------|
| calculate | interview_start | | `once(now())` |

Gebruik `once()` voor tijdstempels, beginwaarden of elk geval waarin herberekening bij wijziging ongewenst is.

## Gegevens ophalen uit externe bronnen

### Uit een CSV-bestand

```
pulldata('staff.csv', 'department', 'name', ${staff_id})
```

Zie [pulldata()](../operators-and-functions/pulldata) voor de volledige referentie.

### Uit een gebundelde SQLite-database

```
pulldata('rawquery',
  concat(${family_path}, '/locations.db::provinces'),
  'SELECT name FROM provinces WHERE id = ?',
  ${province_id})
```

Zie [Lokaal zoeken in database](../advanced-features/local-database-search) voor details over padconstructie.

### Uit app-context

```
pulldata('app-api', 'user.username')
pulldata('app-api', 'family_path')
```

Zie [App API](../app-api) voor alle beschikbare sleutels.

## Calculate gebruiken in relevant en constraint

Andere velden kunnen verwijzen naar een `calculate`-resultaat, net als naar elk ander veld:

| type | name | label | relevant | constraint |
|------|------|-------|----------|------------|
| calculate | bmi | | | `${weight} div (${height} * ${height}) * 10000` |
| note | bmi_warning | BMI is very high — please verify weight and height. | `${bmi} > 40` | |

## Best Practices

1. Geef calculate-velden betekenisvolle namen — `total_cost` is duidelijker dan `calc1` en gemakkelijker te traceren bij exports.
2. Splits complexe formules op in meerdere gekoppelde calculate-velden in plaats van één diep geneste uitdrukking.
3. Gebruik `once()` voor tijdstempels en initiële snapshots om te voorkomen dat waarden veranderen na de eerste opname.
4. Plaats `calculate`-velden vóór de eerste vraag die ernaar verwijst — de evaluatievolgorde volgt de volgorde van het formulier.
5. Houd de kolom `label` leeg. Sommige tools tonen het label; door het leeg te laten worden verwarrende outputs vermeden.

## Beperkingen

- Calculate-velden worden nooit rechtstreeks aan de teller getoond — gebruik een `note`-veld om het resultaat te tonen.
- De kolom `calculation` is verplicht; een `calculate`-rij zonder formule slaat altijd een lege string op.
- Resultaten worden bij elke wijziging in het formulier opnieuw geëvalueerd, tenzij ze zijn ingesloten in `once()` — zeer complexe formules in grote formulieren kunnen de weergaveprestaties op goedkope apparaten beïnvloeden.
- Berekende waarden worden als strings opgeslagen in de inzending. Gebruik `number()`, `int()` of `boolean()` voor type-omzetting wanneer u het resultaat doorgeeft aan rekenkundige of logische uitdrukkingen.

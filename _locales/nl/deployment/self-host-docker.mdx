import { Callout, Steps } from 'nextra/components'

Gebruik deze handleiding als u rtSurvey wilt uitvoeren op uw eigen server (VPS, bare metal of lokale machine) met behulp van de publieke Docker-image `rtawebteam/rtcloud:survey-public`.

**Geen Docker Hub-aanmelding vereist** — de image is publiek.

De container bundelt alles in één enkele image:
- Apache + PHP (toepassingsserver)
- Shiny Server (analysedashboards, poort 3838)
- Beanstalkd (achtergrondjobwachtrij)

---

## Vereisten

### Server

| Resource | Minimum | Aanbevolen |
|----------|---------|-------------|
| RAM | 4 GB | 8 GB |
| Schijf | 50 GB | 100 GB SSD |
| CPU | 2 vCPU's | 4 vCPU's |
| OS | Ubuntu 22.04 LTS | Ubuntu 22.04 LTS |

### Software

- **Docker Engine 24.0+** — [installatiehandleiding](https://docs.docker.com/engine/install/ubuntu/)
- **Docker Compose v2.0+** — inbegrepen bij Docker Desktop; op Linux: `apt install docker-compose-plugin`

## Installatie

<Steps>

### Maak een werkmap aan

```bash
mkdir -p /opt/rtsurvey && cd /opt/rtsurvey
```

### Maak `docker-compose.yml` aan

```yaml
services:
  mysql:
    image: mysql:8.0
    container_name: rtsurvey-mysql
    restart: unless-stopped
    command: >
      --default-authentication-plugin=mysql_native_password
      --character-set-server=utf8
      --collation-server=utf8_unicode_ci
      --sql-mode=NO_ENGINE_SUBSTITUTION
    environment:
      MYSQL_ROOT_PASSWORD: ${MYSQL_ROOT_PASSWORD}
      MYSQL_DATABASE: ${MYSQL_DATABASE:-smartsurvey}
      MYSQL_USER: ${MYSQL_USER:-smartsurvey}
      MYSQL_PASSWORD: ${MYSQL_PASSWORD}
      MYSQL_ROOT_HOST: '%'
    volumes:
      - mysql_data:/var/lib/mysql
    networks:
      - rtsurvey-net
    healthcheck:
      test: ["CMD-SHELL", "mysqladmin ping -h localhost -u root -p$$MYSQL_ROOT_PASSWORD"]
      interval: 10s
      timeout: 5s
      retries: 5
      start_period: 30s

  rtsurvey:
    image: rtawebteam/rtcloud:survey-public
    container_name: rtsurvey-app
    restart: unless-stopped
    entrypoint: ["/bin/entrypoint-production.sh"]
    depends_on:
      mysql:
        condition: service_healthy
    ports:
      - "${APP_PORT:-8080}:80"
      - "${SHINY_PORT:-3838}:3838"
    env_file:
      - .env
    volumes:
      - app_uploads:/var/www/html/smartsurvey/uploads
      - app_audios:/var/www/html/smartsurvey/audios
      - app_downloads:/var/www/html/smartsurvey/downloads
      - app_gallery:/var/www/html/smartsurvey/gallery
      - app_tmp:/var/www/html/smartsurvey/tmp
      - app_cache:/var/www/html/smartsurvey/cache
      - app_runtime:/var/www/html/smartsurvey/protected/runtime
      - app_assets:/var/www/html/smartsurvey/assets
      - app_aggregate:/var/www/html/smartsurvey/aggregate
    networks:
      - rtsurvey-net
    healthcheck:
      test: ["CMD", "curl", "-f", "http://localhost/health"]
      interval: 30s
      timeout: 10s
      retries: 3
      start_period: 90s

  # Optional: Embedded Keycloak SSO
  # Start with: docker compose --profile embed-keycloak up -d
  keycloak:
    image: quay.io/keycloak/keycloak:latest
    container_name: rtsurvey-keycloak
    restart: unless-stopped
    profiles:
      - embed-keycloak
    command: start --import-realm
    environment:
      KEYCLOAK_ADMIN: ${KEYCLOAK_ADMIN_USER:-admin}
      KEYCLOAK_ADMIN_PASSWORD: ${KEYCLOAK_ADMIN_PASSWORD}
      KC_HTTP_ENABLED: "true"
      KC_HTTP_RELATIVE_PATH: /auth
      KC_PROXY_HEADERS: xforwarded
      KC_HOSTNAME: ${KC_HOSTNAME}
      KC_HOSTNAME_STRICT: "false"
      KC_DB: mysql
      KC_DB_URL_DATABASE: ${KEYCLOAK_DB:-keycloak}
      KC_DB_URL_HOST: mysql
      KC_DB_USERNAME: ${KEYCLOAK_DB_USER:-keycloak}
      KC_DB_PASSWORD: ${KEYCLOAK_DB_PASSWORD}
    volumes:
      - ./keycloak-import:/opt/keycloak/data/import
    ports:
      - "${KEYCLOAK_PORT:-8091}:8080"
    depends_on:
      mysql:
        condition: service_healthy
    networks:
      - rtsurvey-net
    healthcheck:
      test: ["CMD-SHELL", "curl -f http://localhost:9000/health/ready || exit 1"]
      interval: 30s
      timeout: 10s
      retries: 10
      start_period: 120s

volumes:
  mysql_data:
  app_uploads:
  app_audios:
  app_downloads:
  app_gallery:
  app_tmp:
  app_cache:
  app_runtime:
  app_assets:
  app_aggregate:

networks:
  rtsurvey-net:
    driver: bridge
```

### Maak `.env` aan

```bash
# Project
PROJECT_ID=mysurvey
PROJECT_TYPE=rtsurvey
PROJECT_URL=your-server-ip-or-domain
HTTP_PROTOCOL=http
TZ=UTC

# Database
MYSQL_HOST=mysql
MYSQL_DATABASE=smartsurvey
MYSQL_USER=smartsurvey
MYSQL_ROOT_PASSWORD=change-this-root-password
MYSQL_PASSWORD=change-this-app-password

# Admin (set before first startup — cannot change via env after DB is created)
ADMIN_PASSWORD=change-this-admin-password

# Runtime
RUN_ENV=prod
RUN_MODE=admin
GII_ENABLED=false
CSRF_VALIDATION_ENABLED=true

# Ports (optional — defaults shown)
APP_PORT=8080
SHINY_PORT=3838
```

<Callout type="warning">
Wijzig `MYSQL_ROOT_PASSWORD` en `MYSQL_PASSWORD` voordat u start. Gebruik sterke willekeurige tekenreeksen (32+ tekens) in productie.
</Callout>

### Start de stack

```bash
docker compose up -d
```

De eerste opstart duurt ongeveer 60–90 seconden — MySQL initialiseert de database bij de eerste run.

### Verifieer

```bash
# Check all containers are running
docker compose ps

# Check application health
curl http://localhost:8080/health
```

</Steps>

## Eerste aanmelding

Zodra de gezondheidscontrole is geslaagd, opent u uw browser:

```
http://your-server:8080/cpms/cpmsSite/login
```

| Veld | Waarde |
|-------|-------|
| Gebruikersnaam | `admin` |
| Wachtwoord | waarde van `ADMIN_PASSWORD` in uw `.env` (standaard `admin`) |

<Callout type="warning">
Stel `ADMIN_PASSWORD` in uw `.env` in vóór de eerste opstart. Het ingangspunt stelt dit in bij de eerste run — het wijzigen nadat de database is geïnitialiseerd heeft geen effect.
</Callout>

## Omgevingsvariabelen

### Vereist door de app-container

Het ingangspunt weigert te starten als een van deze ontbreekt:

| Variabele | Beschrijving |
|----------|-------------|
| `PROJECT_ID` | Unieke identificator voor deze instantie (alfanumeriek, geen spaties) |
| `PROJECT_URL` | Domein of IP waar de app toegankelijk is (geen `http://`-prefix) |
| `MYSQL_HOST` | MySQL-hostnaam — gebruik de Docker-servicenaam (bijv. `mysql`) |
| `MYSQL_DATABASE` | Databasenaam |
| `MYSQL_PASSWORD` | Databasegebruikerswachtwoord |

### Vereist door de MySQL-container

| Variabele | Beschrijving |
|----------|-------------|
| `MYSQL_ROOT_PASSWORD` | MySQL root-wachtwoord (gebruikt door de `mysql`-container, niet de app) |

### Aanbevolen

| Variabele | Standaard | Beschrijving |
|----------|---------|-------------|
| `MYSQL_USER` | `smartsurvey` | Databasegebruikersnaam |
| `ADMIN_PASSWORD` | `admin` | Initieel beheerderswachtwoord — **stel in vóór de eerste opstart**, kan niet worden gewijzigd via env nadat de DB is aangemaakt |
| `HTTP_PROTOCOL` | `https` | Stel in op `http` als u geen SSL gebruikt |
| `PROJECT_PORT` | `80` | Externe poort waarmee gebruikers verbinding maken (niet de interne Docker-poort) |
| `PROJECT_TYPE` | `rtwork` | Platformtype — gebruik `rtsurvey` voor het enquêteplatform |
| `TZ` | `UTC` | Tijdzone (bijv. `Asia/Bangkok`, `America/New_York`) |

### Runtime

| Variabele | Standaard | Beschrijving |
|----------|---------|-------------|
| `RUN_ENV` | `prod` | Omgevingsmodus (`prod` of `dev`) |
| `RUN_MODE` | `admin` | Servicerol — gebruik `admin` voor een enkelvoudige serverinstallatie |
| `GII_ENABLED` | `false` | Houd `false` in productie (Yii-codegenerator) |
| `CSRF_VALIDATION_ENABLED` | `true` | CSRF-bescherming — houd `true` |

### Licentie

| Variabele | Standaard | Beschrijving |
|----------|---------|-------------|
| `REQUIRE_LICENSE` | `false` | Stel in op `true` om licentievalidatie af te dwingen |
| `RTCLOUD_LICENSE_KEY` | — | Uw licentiesleutel — vereist wanneer `REQUIRE_LICENSE=true` |

## Back-up en herstel

### Database back-up maken

```bash
docker compose exec mysql \
  mysqldump -u root -p"${MYSQL_ROOT_PASSWORD}" smartsurvey \
  > backup-$(date +%Y%m%d).sql
```

### Database herstellen

```bash
docker compose exec -T mysql \
  mysql -u root -p"${MYSQL_ROOT_PASSWORD}" smartsurvey \
  < backup-20240101.sql
```

### Back-up van geüploade bestanden

```bash
docker run --rm \
  -v rtsurvey_app_uploads:/data \
  -v $(pwd):/backup \
  alpine tar czf /backup/uploads-$(date +%Y%m%d).tar.gz -C /data .
```

## Ingebedde Keycloak (optionele SSO)

Het productie-compose-bestand bevat een optionele Keycloak-container voor SSO. Het deelt dezelfde MySQL-instantie en wordt geactiveerd via een Docker Compose-profiel.

<Callout type="info">
Ingebedde Keycloak vereist minimaal **4 GB RAM**. Het is optioneel — sla dit over als u geen SSO nodig heeft.
</Callout>

### Keycloak-variabelen toevoegen aan `.env`

```bash
# Keycloak admin
KEYCLOAK_ADMIN_USER=admin
KEYCLOAK_ADMIN_PASSWORD=change-this-keycloak-password

# Keycloak database (created automatically in the shared MySQL on first run)
KEYCLOAK_DB=keycloak
KEYCLOAK_DB_USER=keycloak
KEYCLOAK_DB_PASSWORD=change-this-keycloak-db-password

# KC_HOSTNAME: full public URL of your server (Keycloak appends /auth automatically)
KC_HOSTNAME=http://your-server:8091

# Port Keycloak listens on (host)
KEYCLOAK_PORT=8091

# Tell the rtCloud app to connect to embedded Keycloak
EMBED_KEYCLOAK=true
KEYCLOAK_URL=http://your-server:8091
KEYCLOAK_REALM=rtsurvey
KEYCLOAK_CLIENT_ID=rtsurvey
KEYCLOAK_CLIENT_SECRET=your-client-secret
```

De `keycloak`-service is al opgenomen in de `docker-compose.yml` hierboven (onder het `embed-keycloak`-profiel — het start niet tenzij u `--profile embed-keycloak` gebruikt).

Maak de importmap aan (Keycloak start zonder deze, maar automatische realm-inrichting werkt niet):

```bash
mkdir -p /opt/rtsurvey/keycloak-import
```

### Starten met Keycloak

```bash
docker compose --profile embed-keycloak up -d
```

Starten zonder Keycloak (standaard):

```bash
docker compose up -d
```

### Keycloak-beheerconsole

Zodra gezond, toegang tot de Keycloak-admin-UI op:

```
http://your-server:8091/auth/admin
```

Log in met `KEYCLOAK_ADMIN_USER` / `KEYCLOAK_ADMIN_PASSWORD`.

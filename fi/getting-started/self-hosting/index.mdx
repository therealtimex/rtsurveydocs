Käytä rtCloudia omassa infrastruktuurissasi Docker Composen avulla. Itse isännöinti antaa sinulle täydellisen omistajuuden tiedoistasi, verkostasi ja käyttöönottosi ympäristöstä — ihanteellinen organisaatioille, joilla on tietojen sijoitteluvaatimuksia, ilmarakoverkostoja tai mukautettuja infrastruktuuritarpeita.

## Mikä on rtCloud-itse isännöinti?

rtCloud-itse isännöinti on virallinen Docker-kuva, joka pakkaa koko rtCloud-alustan siirrettäväksi konttipinoksi, jota voit ajaa millä tahansa Linux-palvelimella. Pino sisältää:

| Palvelu | Kuvaus |
|---------|-------------|
| **rtCloud-sovellus** | Apache 2.4 + PHP 7.4 -verkkosovellus sisäänrakennetulla taustajononhallinnalla (Beanstalkd), analytiikkapalvelimella (Shiny) ja ajastettujen tehtävien hallinnalla |
| **MySQL 8.0** | Relaatiotietokanta kaikelle sovellus- ja kysely-datalle |
| **Keycloak** *(valinnainen)* | Upotettu kertakirjautumis (SSO) -palvelin yrityksen identiteetinhallintaan |

## Milloin isännöidä itse

Itse isännöinti on oikea valinta, kun:

- Vaadit **tietojen itsemääräämisoikeutta** — kaikki data pysyy omassa infrastruktuurissasi
- Toimit **ilmarakoverkossa tai rajoitetussa verkossa** ilman ulkoista pilvipääsyä
- Sinulla on **vaatimustenmukaisuusvaatimuksia** (GDPR, HIPAA, valtion tietosuojakäytännöt), jotka edellyttävät paikallista tallennusta
- Sinun täytyy integroida **sisäisen identiteetintarjoajan** kanssa (Active Directory, LDAP, SAML)
- Haluat **mukauttaa resursseja** — CPU, RAM ja tallennustila ehdoillasi

## Arkkitehtuurin yleiskatsaus

Käyttöönotto toimii Docker-konttijoukkona, jotka ovat yhteydessä sisäisessä verkossa:

```
┌────────────────────────────────────────┐
│            rtcloud-app                 │
│  Apache 2.4 (portti 80)                │
│  PHP 7.4 -sovellus                     │
│  Beanstalkd-jono (sisäinen)            │
│  Shiny Server (portti 3838)            │
│  Cron-ajastin                          │
└─────────────────┬──────────────────────┘
                  │ rtcloud-net (silta)
┌─────────────────▼──────────────────────┐
│            rtcloud-mysql               │
│  MySQL 8.0 (portti 3306, vain sisäinen)│
└────────────────────────────────────────┘
```

Kun SSO on käytössä, kolmas kontti toimii rinnalla:

```
┌─────────────────────────────────────────┐
│            rtcloud-keycloak             │
│  Keycloak (portti 8080, vain sisäinen)  │
│  Hallintakäyttöliittymä (portti 9000)   │
└─────────────────────────────────────────┘
```

Kaikki kontit viestivät eristetyn Docker-siltaverkon kautta. Vain verkkosovelluksen portti ja (valinnaisesti) Shiny-analytiikkapalvelimen portti on esillä isännälle.

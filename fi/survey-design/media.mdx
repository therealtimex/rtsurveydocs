rtSurvey tukee monipuolista mediaintegraatiota kyselyissä, mahdollistaen kyselyihin kuvien, äänen ja videon lisäämisen. Tämä ominaisuus voi merkittävästi parantaa vastaajien kokemusta ja kerätyn tiedon laatua.

## Tuetut mediatyypit

rtSurvey tukee seuraavia mediatyyppejä:
- Kuvat (jpg, png, gif)
- Ääni (mp3, wav)
- Video (mp4, webm)

## Median lisääminen kyselyyn

Sisällyttääksesi mediaa rtSurvey-lomakkeeseen, käytä seuraavia sarakkeita XLSFormissasi:

- `image`: Kuvien näyttämiseen
- `audio`: Äänitiedostojen toistamiseen
- `video`: Videotiedostojen toistamiseen

Esimerkki:

```
| type | name          | label         | image        | audio       | video       |
|------|---------------|---------------|--------------|-------------|-------------|
| note | media_example | Mediaesimerkki| example.jpg  | sound.mp3   | clip.mp4    |
```

## Mediatiedostojen hallinta

### Webpohjaiset kyselyt
Webpohjaisia kyselyitä varten rtSurvey tarjoaa medianhallintaliittymän, johon voit ladata ja järjestää mediatiedostojasi. Nämä tiedostot ovat sen jälkeen automaattisesti käytettävissä kyselyissäsi.

### Mobiilisovellus
Käytettäessä rtSurvey-mobiilisovellusta:
1. Sijoita mediatiedostosi laitteellasi `/rtSurvey/forms/[lomakkeen-nimi]-media/`-kansioon.
2. Viittaa tarkkaan tiedostonimeen XLSFormissasi.

## rtSurvey-kohtaiset ominaisuudet

### Dynaaminen median lataus
rtSurvey tukee dynaamista median lataamista kyselyvastausten perusteella:

```
| type         | name      | label              | image                    |
|--------------|-----------|--------------------|--------------------------| 
| select_one species | animal | Valitse eläin   | ${animal}.jpg            |
```

### Media vastausvaihtoehtoissa
rtSurvey mahdollistaa median käytön valintojen vaihtoehdoissa:

```
| type                | name    | label           | media::image |
|---------------------|---------|-----------------|--------------|
| select_one_from_file animals | Valitse eläin |              |
```

Valintalomakkeella:
```
| list_name | name  | label | media::image |
|-----------|-------|-------|--------------|
| animals   | dog   | Koira | dog.jpg      |
| animals   | cat   | Kissa | cat.jpg      |
```

### Median tallentaminen
rtSurvey laajentaa XLSFormia median tallentamisominaisuuksilla:

```
| type  | name        | label               |
|-------|-------------|---------------------|
| image | photo       | Ota kuva            |
| audio | voice_note  | Nauhoita äänimuistio |
| video | video_clip  | Nauhoita video      |
```

## Parhaat käytännöt median käytössä

1. **Optimoi tiedostokoot**: Suuret mediatiedostot voivat hidastaa kyselyn latautumista ja lähetystä.
2. **Käytä sopivia formaatteja**: Pidättäydy laajalti tuetuissa formaateissa (jpg kuvilla, mp3 äänelle, mp4 videolle).
3. **Tarjoa vaihtoehtoja**: Sisällytä aina tekstivaihtoehdot saavutettavuuden vuoksi.
4. **Testaa perusteellisesti**: Varmista, että media näkyy oikein kaikilla kohdejaitteilla.
5. **Harkitse offline-käyttöä**: Kyselyissä, jotka saatetaan suorittaa offline-tilassa, varmista, että kaikki media on saatavilla paikallisesti.

## Monikielinen mediatuki

rtSurvey tukee kielikohtaista mediaa. Käytä `::kieli`-liitettä:

```
| type | name  | label    | image::English | image::Finnish |
|------|-------|----------|----------------|----------------|
| note | intro | Tervetuloa | welcome_en.jpg | welcome_fi.jpg |
```

## Media tietojen viennissä

Tietoja rtSurveysta vietäessä:
- Webkyselyissä vientiin sisällytetään median URL-osoitteet.
- Mobiilisovelluksen kyselyissä sisällytetään tiedostopolut.

## Mobiilisovelluksen huomioiminen

- Varmista, että laitteilla on riittävästi tallennustilaa mediarikkaita kyselyitä varten.
- rtSurveyn mobiilisovellus tukee offline-median toistoa ja tallentamista.
- Suuret mediatiedostot saattavat vaikuttaa sovelluksen suorituskykyyn alempitasoisilla laitteilla.

## Tunnetut rajoitukset

- Jotkut vanhemmat selaimet eivät välttämättä tue kaikkia mediaformaatteja.
- Erittäin suuret videotiedostot saattavat aiheuttaa ongelmia alhaisella kaistaleveydellä.

## Mediaongelmien vianmääritys

1. **Media ei näy**: Tarkista tiedostopolut ja -nimet tarkkuuden varalta.
2. **Toisto-ongelmat**: Varmista, että mediaformaatti on tuettu kohdejaitteilla.
3. **Hidas latautuminen**: Harkitse tiedostokokojen optimointia tai median esilataamista.

## Edistyneet mediaominaisuudet

### Geotunnistaminen
rtSurvey voi automaattisesti geotunnistaa kyselyjen aikana tallennetun median:

```
| type  | name        | label        | appearance |
|-------|-------------|--------------|------------|
| image | photo       | Ota kuva     | geotag     |
```

### Median merkitseminen
Salli vastaajien merkitä kuvia:

```
| type  | name        | label        | appearance |
|-------|-------------|--------------|------------|
| image | photo       | Merkitse kuva | annotate  |
```

Käyttämällä mediaa tehokkaasti rtSurvey-lomakkeissasi voit luoda kiinnostavampia, informatiivisempia ja tarkempia kyselyitä. Muista tasapainottaa median sisällyttämisen hyödyt suorituskykyhuomioiden kanssa, erityisesti kyselyissä, jotka otetaan käyttöön alueilla, joilla on rajoitettu internet-yhteys tai alempitasoiset laitteet.

Docker Compose ఉపయోగించి మీ స్వంత మౌలిక సదుపాయాలపై rtCloud నడపండి. స్వయం-హోస్టింగ్ మీకు డేటా, నెట్‌వర్క్ మరియు డిప్లాయ్‌మెంట్ వాతావరణంపై పూర్తి యాజమాన్యం ఇస్తుంది — డేటా నివాస అవసరాలు, ఎయిర్-గ్యాప్డ్ నెట్‌వర్కులు లేదా అనుకూల మౌలిక సదుపాయాల అవసరాలు ఉన్న సంస్థలకు అనువైనది.

## rtCloud స్వయం-హోస్టింగ్ అంటే ఏమిటి?

rtCloud స్వయం-హోస్టింగ్ అనేది అధికారిక Docker ఇమేజ్, ఇది మొత్తం rtCloud వేదికను మీరు ఏ Linux సర్వర్‌పైనైనా నడిపించగలిగే పోర్టబుల్ కంటైనర్ స్టాక్‌లో ప్యాకేజ్ చేస్తుంది. స్టాక్ ఇవి కలిగి ఉంటుంది:

| సేవ | వివరణ |
|---------|-------------|
| **rtCloud App** | Apache 2.4 + PHP 7.4 వెబ్ అప్లికేషన్, అంతర్నిర్మిత బ్యాక్‌గ్రౌండ్ క్యూ (Beanstalkd), విశ్లేషణ సర్వర్ (Shiny) మరియు షెడ్యూల్డ్ టాస్క్‌లతో |
| **MySQL 8.0** | అన్ని అప్లికేషన్ మరియు సర్వే డేటా కోసం రిలేషనల్ డేటాబేస్ |
| **Keycloak** *(ఐచ్ఛికం)* | ఎంటర్‌ప్రైజ్ గుర్తింపు నిర్వహణ కోసం ఎంబెడెడ్ Single Sign-On సర్వర్ |

## స్వయం-హోస్ట్ ఎప్పుడు చేయాలి

మీరు ఈ స్వయం-హోస్టింగ్ ఎంచుకోవాలి:

- **డేటా సార్వభౌమత్వం** అవసరమైనప్పుడు — అన్ని డేటా మీ స్వంత మౌలిక సదుపాయాలలోనే ఉంటుంది
- బాహ్య క్లౌడ్ యాక్సెస్ లేకుండా **ఎయిర్-గ్యాప్డ్ లేదా పరిమిత నెట్‌వర్క్‌లో** నిర్వహించేటప్పుడు
- ఆన్-ప్రెమైస్ స్టోరేజ్ నిర్బంధించే **సమ్మతి అవసరాలు** (GDPR, HIPAA, ప్రభుత్వ డేటా విధానాలు) ఉన్నప్పుడు
- **అంతర్గత గుర్తింపు ప్రదాత** (Active Directory, LDAP, SAML) తో అనుసంధానించాల్సినప్పుడు
- **వనరులు అనుకూలీకరించాలని** కోరుకున్నప్పుడు — మీ షరతులపై CPU, RAM మరియు నిల్వ కేటాయింపు

## ఆర్కిటెక్చర్ అవలోకనం

డిప్లాయ్‌మెంట్ అంతర్గత నెట్‌వర్క్‌పై కనెక్ట్ అయిన Docker కంటైనర్‌ల సెట్‌గా నడుస్తుంది:

```
┌────────────────────────────────────────┐
│            rtcloud-app                 │
│  Apache 2.4 (port 80)                  │
│  PHP 7.4 application                   │
│  Beanstalkd queue (internal)           │
│  Shiny Server (port 3838)              │
│  Cron scheduler                        │
└─────────────────┬──────────────────────┘
                  │ rtcloud-net (bridge)
┌─────────────────▼──────────────────────┐
│            rtcloud-mysql               │
│  MySQL 8.0 (port 3306, internal only)  │
└────────────────────────────────────────┘
```

SSO ప్రారంభించినప్పుడు, పక్కన మూడవ కంటైనర్ నడుస్తుంది:

```
┌─────────────────────────────────────────┐
│            rtcloud-keycloak             │
│  Keycloak (port 8080, internal only)    │
│  Admin UI (port 9000, internal only)    │
└─────────────────────────────────────────┘
```

అన్ని కంటైనర్‌లు ఒంటరి Docker బ్రిడ్జ్ నెట్‌వర్క్‌లో కమ్యూనికేట్ చేస్తాయి. వెబ్ అప్లికేషన్ పోర్ట్ మరియు (ఐచ్ఛికంగా) Shiny విశ్లేషణ పోర్ట్ మాత్రమే హోస్ట్‌కు బహిరంగపరచబడతాయి.

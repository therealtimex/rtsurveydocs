rtSurvey सभी मानक XLSForm question types के साथ-साथ कई extensions का समर्थन करता है। प्रत्येक question type यह नियंत्रित करता है कि किस प्रकार का डेटा एकत्र किया जाता है और device पर input widget कैसे render होता है।

question type सेट करने के लिए, अपने XLSForm की **survey** worksheet के `type` column में type का नाम दर्ज करें।

## Text input

| Type | विवरण |
|------|-------------|
| [text](text) | Free-text response — कोई भी characters allowed |
| [integer](integer) | पूर्ण संख्या (कोई decimals नहीं) |
| [decimal](decimal) | decimal places के साथ संख्या |
| [range](range) | एक defined min/max range के भीतर slider से चुनी गई संख्या |

## Selection

| Type | विवरण |
|------|-------------|
| [select_one listname](select-one) | एक list से ठीक एक विकल्प चुनें |
| [select_multiple listname](select-multiple) | एक list से एक या अधिक विकल्प चुनें |
| [select_one_from_file filename](select-one-from-file) | बाहरी CSV file से load किया गया एक विकल्प चुनें |
| [rank listname](rank) | preference या priority के अनुसार choices को order करें |

## Date और Time

| Type | विवरण |
|------|-------------|
| [date](date) | Calendar date (year, month, day) |
| [time](time) | दिन का समय (hours, minutes) |
| [datetime](datetime-date-time) | संयुक्त date और time |

## Location

| Type | विवरण |
|------|-------------|
| [geopoint](geopoint) | एकल GPS coordinate (latitude, longitude, altitude, accuracy) |
| [geotrace](geotrace) | एक path — GPS points की series जो line बनाती है |
| [geoshape](geoshape) | एक area — GPS points का closed polygon |

## Media

| Type | विवरण |
|------|-------------|
| [image](image) | Photo capture या image upload |
| [audio](audio) | Audio recording |
| [video](video) | Video recording |
| [file](file) | General file upload (PDF, document, आदि) |

## अन्य

| Type | विवरण |
|------|-------------|
| [barcode](barcode) | barcode या QR code scan करें |
| [note](note) | Read-only display text — instructions या calculated summaries दिखाता है |
| [calculate](calculate) | Hidden field जो computed value store करता है |
| [hidden](hidden) | Hidden field जो static या prefilled value store करता है |
| [trigger / acknowledge](trigger) | एक checkbox जिसे गणनाकर्ता को एक statement पढ़ने की पुष्टि करने के लिए tick करना होगा |
| [meta](meta) | Automatic metadata: timestamps, device ID, enumerator की जानकारी |

## Type और appearance एक साथ कैसे काम करते हैं

`type` यह निर्धारित करता है कि **क्या डेटा एकत्र किया जाता है**। `appearance` column यह नियंत्रित करता है कि **widget कैसा दिखता है**। कई types multiple appearances का समर्थन करते हैं — उदाहरण के लिए `select_one` radio buttons, dropdown, Likert scale, या compact grid के रूप में दिखाई दे सकता है।

विकल्पों की पूरी list के लिए [Appearance](../appearance) देखें।

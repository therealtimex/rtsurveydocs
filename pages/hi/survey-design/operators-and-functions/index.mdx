rtSurvey में Expressions **XPath 1.0** के एक subset में लिखे जाते हैं, जो JavaRosa/ODK functions और custom rtSurvey functions के साथ विस्तारित होते हैं। आप अपने XLSForm के `calculate`, `constraint`, `relevant`, `required`, और `default` columns में expressions का उपयोग करते हैं।

## Field values का संदर्भ लेना

किसी अन्य field के मूल्य का संदर्भ लेने के लिए `${fieldname}` का उपयोग करें:

```
${age} > 18
```

**वर्तमान field के मूल्य** का संदर्भ लेने के लिए `.` (एक single dot) का उपयोग करें — सामान्यतः `constraint` expressions में उपयोग किया जाता है:

```
. >= 0 and . <= 100
```

Parent group का संदर्भ लेने के लिए `..` का उपयोग करें (repeats में advanced usage)।

## Expression syntax

Expressions मानक XPath नियमों का पालन करते हैं:

- **Strings** को single quotes में enclosed होना चाहिए: `'yes'`
- **Numbers** को as-is लिखा जाता है: `42`, `3.14`
- **Boolean** परिणाम `relevant`, `required`, और `constraint` के लिए उपयोग किए जाते हैं — कोई भी non-empty, non-zero मूल्य truthy होता है
- Operators के आस-पास Whitespace को नज़रअंदाज़ किया जाता है

<Callout type="warning">
हमेशा straight quotes (`'` या `"`) का उपयोग करें — कभी भी "smart quotes" (curly quotes) का नहीं। Rich text editors अक्सर quotes को स्वचालित रूप से convert करते हैं और आपके expressions को तोड़ देंगे।
</Callout>

## त्वरित उदाहरण

| Use case | Expression |
|----------|------------|
| दिखाएं अगर age 18 से अधिक है | `${age} > 18` |
| केवल तभी दिखाएं जब "yes" चुना गया हो | `${consent} = 'yes'` |
| आवश्यक करें यदि अन्य field खाली न हो | `${name} != ''` |
| कुल calculate करें | `${adults} + ${children}` |
| नाम concatenate करें | `concat(${first_name}, ' ', ${last_name})` |
| आज की तारीख | `today()` |
| जांचें कि विकल्प चुना गया था | `selected(${interests}, 'sports')` |

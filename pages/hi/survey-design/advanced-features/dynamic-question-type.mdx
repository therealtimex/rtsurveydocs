description: "डायनामिक प्रश्न प्रकार एक फील्ड के प्रश्न प्रकार और विजेट को API प्रतिक्रिया या गणना किए गए मूल्य के आधार पर रनटाइम पर निर्धारित करने की अनुमति देता है।"
---

**Dynamic Question Type** सुविधा एक फील्ड के इनपुट विजेट और सत्यापन व्यवहार को फ़ॉर्म डिज़ाइन समय के बजाय **रनटाइम पर** निर्धारित करने की अनुमति देती है। यह एक उन्नत rtSurvey एक्सटेंशन है जिसका उपयोग तब किया जाता है जब संग्रह किए जाने वाले डेटा का प्रकार सर्वर-साइड कॉन्फ़िगरेशन, API प्रतिक्रिया या पूर्ववर्ती फील्ड मूल्य पर निर्भर करता है।

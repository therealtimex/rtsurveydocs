Be standartinio `image` klausimo tipo, rtSurvey suteikia plėtinius **vandens ženklų** nufotografuotiems nuotraukoms ir kelių vaizdų rodymo **medijos tinklelyje**. Tai naudinga įrodymais grįstoms apklausoms, kur nuotraukos turi būti pažymėtos surašytojo tapatybe ar apklausos metaduomenimis, ir vizualinio peržiūros sąsajoms.

---

## Vandens ženklas

Vandens ženklo funkcija uždeda tekstą arba vaizdą ant užfiksuotos nuotraukos prieš ją saugant. Tai naudojama lauko nuotraukoms pažymėti data, surašytojo vardu, GPS vieta arba bet kokiais kitais apklausos duomenimis — taip sunkiau pateikti iš anksto esamas nuotraukas kaip šviežiai užfiksuotus įrodymus.

### Konfigūracija

Naudokite `watermark()` stulpelyje **`calculation`** `image` lauko, kartu su `callapi` išvaizda:

```
watermark(type, size, distance, color, shadow, rotate, blur)
```

| Parametras | Aprašymas |
|-----------|-------------|
| `type` | `'text'` teksto vandens ženklui; `'file'` vaizdo vandens ženklui |
| `size` | Šrifto dydis pikseliais (tekstas) arba vandens ženklo dydis kaip % vaizdo pločio (failas) |
| `distance` | Atstumas tarp pasikartojančių vandens ženklo plytelių (pikseliai) |
| `color` | Teksto spalva (CSS spalva arba hex). Nenaudojama `file` tipui |
| `shadow` | Šešėlio spalva (CSS spalva arba hex) |
| `rotate` | Pasukimo kampas laipsniais (pvz., `45` įstrižai) |
| `blur` | Vandens ženklo neskaidrumas (0 = nematomas, 100 = pilnai neskaidrus) |

### Teksto vandens ženklo pavyzdys

Uždėkite surašytojo vardą ir šiandienos datą įstrižai ant kiekvienos užfiksuotos nuotraukos:

| type | name | label | appearance | calculation |
|------|------|-------|------------|-------------|
| calculate | wm_text | | | `concat(pulldata('app-api', 'user.name'), ' | ', format-date(today(), '%d/%m/%Y'))` |
| image | site_photo | Nufotografuokite vietą | watermark | `watermark('text', 20, 60, '#ffffff', '#000000', 45, 40)` |

Vandens ženklo tekstas paimamas iš `${wm_text}`. Nustatykite vandens ženklo teksto lauką **prieš** vaizdo lauką formoje.

### Vaizdo/logotipo vandens ženklo pavyzdys

Uždėkite organizacijos logotipą (pridėtą kaip medijos failą pavadinimu `logo.png`):

| type | name | label | appearance | calculation |
|------|------|-------|------------|-------------|
| image | evidence_photo | Nufotografuokite įrodymą | watermark | `watermark('file', 25, 80, '', '#000000', 0, 50)` |

### Atšaukimas/kartojimas

Vandens ženklo redaktorius palaiko atšaukimą ir kartojimą — surašytojai gali grįžti per redagavimo istoriją prieš patvirtindami nuotrauką.

### Vandens ženklo plytelėjimas

Vandens ženklas automatiškai kartojasi (plyteliuoja) per visą vaizdą. Parametras `distance` valdo atstumą tarp plytelių; `rotate` valdo kiekvienos plytelės kampą.

## Medijos tinklelio valdiklis

Medijos tinklelio valdiklis rodo medijos failų (vaizdų, garso, vaizdo) rinkinį tinklelio išdėstyme, leidžiant peržiūrėtojams ar surašytojams vizualiai naršyti užfiksuotus failus.

Šis valdiklis aktyvuojamas `mediagridwidget` išvaizda ir paprastai naudojamas `note` arba `calculate` laukuose, kad rodytų anksčiau užfiksuotą mediją iš kartojimų grupės.

### Pavyzdys: visų nuotraukų iš kartojimo rodymas kaip tinklelį

| type | name | label | appearance | calculation |
|------|------|-------|------------|-------------|
| calculate | photo_list | | | `join(' ', ${site_photo})` |
| note | photo_review | Peržiūrėkite užfiksuotas nuotraukas | mediagridwidget | |

## Geriausios vandens ženklų nuotraukų praktikos

1. Visada apskaičiuokite vandens ženklo tekstą `calculate` lauke **aukščiau** vaizdo lauko, kad jis būtų prieinamas, kai daromas nuotrauka.
2. Naudokite pasukimo kampą (pvz., 45°), kad vandens ženklus būtų sunkiau apkarpyti.
3. Nustatykite neskaidrumą (`blur`) nuo 30–60% — pakankamai aukštas, kad būtų skaitomas, pakankamai žemas, kad neužstotų nuotraukos objekto.
4. Įtraukite surašytojo vardą, datą ir GPS koordinates vandens ženklo tekste, kad maksimaliai padidintumėte audito vertę.
5. Patikrinkite vandens ženklo atvaizdavimą žemiausia specifikacijos įrenginyje savo lauke — drobės pagrindu veikiantis vandens ženklas gali būti lėtas senesniuose įrenginiuose.

## Apribojimai

- Vandens ženklas taikomas kliento pusėje naudojant HTML5 Canvas API — reikia pajėgios naršyklės arba mobiliosios WebView.
- Labai didelės raiškos nuotraukos gali būti kelias sekundes vandens ženklinamos žemesnės klasės įrenginiuose.
- Vandens ženklai yra įkelti į vaizdo failą — jų negalima pašalinti po pateikimo be vaizdo redagavimo.
- `file` vandens ženklo tipas reikalauja, kad logotipo vaizdas būtų pridėtas kaip medijos failas su tiksliu tikėtinu failo pavadinimu.

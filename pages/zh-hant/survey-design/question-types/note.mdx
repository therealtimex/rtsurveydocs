---
title: "備注"
description: "備注問題顯示唯讀文字或媒體，以在問卷調查中提供資訊或說明。"
---

XLSForms 和 rtSurvey 中的 note 問題類型用於向問卷調查受訪者顯示唯讀文字或媒體。它不是需要回答的問題，而是在問卷調查中提供資訊、說明或上下文的方式。

## 基本 XLSForm 規格

| type | name | label |
|------|------|-------|
| note | info_text | 本問卷調查是關於您的閱讀習慣。 |

有關基本 note 問題類型的更多詳細資訊，請參閱 [XLSForm 規格](https://xlsform.org/en/#question-types)。

## 用途

備注問題通常用於：

1. 為後續問題提供說明或上下文
2. 顯示計算結果或摘要
3. 顯示圖片或其他媒體
4. 分隔問卷調查的各個部分
5. 根據之前的回應給予回饋

## 最佳實踐

1. 保持備注文字簡潔清晰，以維持受訪者的參與度。
2. 使用格式化（粗體、斜體）強調重要資訊。
3. 在適當情況下考慮使用媒體（圖片、音頻）來增強理解。
4. 謹慎使用備注，以避免問卷調查過於雜亂。

## 使用範例

以下是如何在問卷調查中使用備注問題的範例：

| type | name | label |
|------|------|-------|
| note | intro | 歡迎參加我們的閱讀習慣問卷調查。我們將詢問您的閱讀偏好和頻率。 |
| ... | ... | ... |
| calculate | books_per_month | `${fiction_books}` + `${non_fiction_books}` |
| note | reading_summary | 您每月大約閱讀 `${books_per_month}` 本書。 |

在此範例中，我們使用備注介紹問卷調查並提供計算結果的摘要。

## rtSurvey 擴展

雖然 note 問題的基本 XLSForm 規格很簡單，但 rtSurvey 可能提供額外的功能或自訂選項：

1. 富文字格式
2. 支援嵌入媒體（圖片、音頻、視頻）
3. 基於先前回應的動態內容
4. 自訂樣式選項

（注意：rtSurvey 中針對 note 問題可用的特定擴展需要在此處確認和詳細說明。）

## 進階用法

### 條件顯示

您可以使用相關性表達式有條件地顯示備注：

| type | name | label | relevant |
|------|------|-------|----------|
| note | high_reader_note | 您是個熱愛閱讀的人！ | `${books_per_month}` > 5 |

### 包含計算

備注可以包含計算以提供動態回饋：

| type | name | label |
|------|------|-------|
| note | reading_time | 根據您的回應，您每月大約花 `${books_per_month * 5}` 小時閱讀。 |

## 限制

- 備注不收集資料，因此不應在需要從受訪者收集資訊時使用。
- 過多使用備注可能使問卷調查感覺雜亂或過長。
- 某些高級格式化或媒體選項可能不被所有裝置或平台支援。

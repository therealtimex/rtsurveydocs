---
title: "地理路徑"
description: "地理路徑問題允許受訪者在地圖上捕獲一系列連接的點，創建線條或路徑作為問卷調查的一部分。"
---

XLSForms 和 rtSurvey 中的 geotrace 問題類型使受訪者能夠在地圖上捕獲一系列連接的點，創建線條或路徑。此功能對於空間問卷調查中的路線製圖、邊界追蹤或線性特徵記錄特別有用。

## 基本 XLSForm 規格

| type     | name        | label                           |
|----------|-------------|--------------------------------|
| geotrace | river_path  | 追蹤河流的路徑                  |

有關基本 geotrace 問題類型的更多詳細資訊，請參閱 [XLSForm 規格](https://xlsform.org/en/#question-types)。

## 用途

地理路徑問題通常用於：

1. 繪製實地調查中所走的路線或路徑
2. 追蹤道路、河流或邊界等線性特徵
3. 捕獲線性基礎設施的範圍（例如管道、電力線）
4. 在交通研究中記錄行進路徑
5. 在生態調查中定義樣帶

## 最佳實踐

1. 確保裝置已啟用定位服務並已授予權限。
2. 提供有關如何追蹤路徑以及應包含哪些特徵的清晰說明。
3. 考慮使用衛星圖像或底圖幫助受訪者準確追蹤路徑。
4. 注意追蹤的潛在複雜性及其對資料大小和處理的影響。

## 使用範例

以下是如何在問卷調查中使用地理路徑問題的範例：

| type     | name           | label                                      | hint                                        |
|----------|----------------|--------------------------------------------|--------------------------------------------|
| geotrace | hiking_trail   | 追蹤登山步道的路徑                          | 從登山口開始，到山頂結束                   |

## rtSurvey 擴展

雖然 geotrace 問題的基本 XLSForm 規格很簡單，但 rtSurvey 可能提供額外的功能或自訂選項：

1. 與離線地圖整合以適用於偏遠地區
2. 設定追蹤最小和最大點數的選項
3. 初始繪製後編輯或優化追蹤的能力
4. 支援在移動過程中以設定間隔自動追蹤

（注意：rtSurvey 中針對 geotrace 問題可用的特定擴展需要在此處確認和詳細說明。）

## 資料格式

地理路徑資料通常儲存為以分號分隔的座標對字串，類似於 geoshape 但沒有閉合點：

```
lat1 lon1; lat2 lon2; lat3 lon3; ... latN lonN
```

例如：
```
38.253094215699576 21.756382658677467; 38.25021274773806 21.756382658677467; 38.25007793942195 21.763892843919166; 38.25290886154963 21.763935759263404
```

## 分析注意事項

使用地理路徑問題時，請考慮：

1. 如何將地理資料視覺化和分析（例如 GIS 軟體）
2. 對複雜追蹤進行資料清理或簡化的潛在需求
3. 處理詳細空間資料的隱私和資料保護措施
4. 與其他空間資料來源整合以進行全面分析

## 限制

- 在小型行動螢幕上追蹤準確路徑可能具有挑戰性。
- 複雜追蹤可能需要大量儲存和處理能力。
- 自動追蹤的持續 GPS 使用可能會快速耗盡裝置電池。
- 收集詳細路徑資料可能存在隱私問題。

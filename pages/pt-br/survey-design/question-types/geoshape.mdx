---
title: "Geoshape"
description: "As perguntas de geoshape permitem que os respondentes desenhem formas em um mapa, capturando dados geográficos complexos como parte da pesquisa."
---

O tipo de pergunta geoshape em XLSForms e rtSurvey permite que os respondentes desenhem formas (polígonos) em um mapa, capturando dados geográficos complexos. Este recurso é particularmente útil para mapear áreas, definir limites ou marcar regiões de interesse em pesquisas espaciais.

## Especificação básica do XLSForm

| type     | name        | label                           |
|----------|-------------|--------------------------------|
| geoshape | field_area  | Desenhe o limite do campo       |

Para mais detalhes sobre o tipo básico de pergunta geoshape, consulte a [especificação do XLSForm](https://xlsform.org/en/#question-types).

## Usos

As perguntas de geoshape são comumente usadas para:

1. Mapeamento de limites de campos em pesquisas agrícolas
2. Definição de áreas de impacto ambiental
3. Marcação de zonas em estudos de planejamento urbano
4. Delimitação de regiões para pesquisas geológicas
5. Captura de características geográficas complexas para análise espacial

## Práticas recomendadas

1. Garanta que o dispositivo tenha os serviços de localização habilitados e as permissões concedidas.
2. Forneça instruções claras sobre como desenhar a forma e qual área deve ser incluída.
3. Considere usar imagens de satélite ou mapas base para ajudar os respondentes a desenhar formas com precisão.
4. Esteja ciente da complexidade potencial das formas e seu impacto no tamanho e processamento dos dados.

## Exemplo de uso

Aqui está um exemplo de como você pode usar uma pergunta geoshape em uma pesquisa:

| type     | name           | label                                      | hint                                        |
|----------|----------------|--------------------------------------------|--------------------------------------------|
| geoshape | forest_area    | Delimite o contorno do fragmento florestal  | Use pelo menos 3 pontos para criar uma forma fechada |

## Extensões do rtSurvey

Embora a especificação básica do XLSForm para perguntas geoshape seja direta, o rtSurvey pode oferecer recursos ou personalizações adicionais:

1. Integração com mapas offline para áreas remotas
2. Opções para definir número mínimo e máximo de pontos para a forma
3. Capacidade de editar ou refinar formas após o desenho inicial
4. Suporte para diferentes tipos de forma (por exemplo, retângulos, círculos) além de polígonos de forma livre

## Formato de dados

Os dados de geoshape são tipicamente armazenados como uma string de pares de coordenadas separados por espaço, entre parênteses:

```
(lat1 lon1; lat2 lon2; lat3 lon3; ... latN lonN)
```

Por exemplo:
```
(38.253094215699576 21.756382658677467; 38.25021274773806 21.756382658677467; 38.25007793942195 21.763892843919166; 38.25290886154963 21.763935759263404; 38.253094215699576 21.756382658677467)
```

## Considerações para análise

Ao usar perguntas de geoshape, considere:

1. Como os dados geográficos serão visualizados e analisados (por exemplo, software GIS)
2. A possível necessidade de limpeza ou simplificação de dados de formas complexas
3. Medidas de privacidade e proteção de dados para manipulação de dados espaciais detalhados
4. Integração com outras fontes de dados espaciais para análise abrangente

## Limitações

- Desenhar formas precisas em telas de celulares pequenas pode ser desafiador.
- Formas complexas podem requerer capacidade significativa de armazenamento e processamento.
- As perguntas de geoshape podem não ser adequadas para todos os tipos de pesquisas ou respondentes.
- Pode haver preocupações de privacidade associadas à coleta de dados espaciais detalhados.

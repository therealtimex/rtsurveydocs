rtSurvey admite todos los tipos de pregunta estándar de XLSForm, más varias extensiones. Cada tipo de pregunta controla qué tipo de datos se recopilan y cómo se renderiza el widget de entrada en el dispositivo.

Para establecer el tipo de pregunta, ingrese el nombre del tipo en la columna `type` de la hoja de trabajo **survey** de su XLSForm.

## Entrada de texto

| Tipo | Descripción |
|------|-------------|
| [text](text) | Respuesta de texto libre — se permiten cualquier tipo de caracteres |
| [integer](integer) | Número entero (sin decimales) |
| [decimal](decimal) | Número con decimales |
| [range](range) | Número seleccionado con un control deslizante dentro de un rango mínimo/máximo definido |

## Selección

| Tipo | Descripción |
|------|-------------|
| [select_one listname](select-one) | Elegir exactamente una opción de una lista |
| [select_multiple listname](select-multiple) | Elegir una o más opciones de una lista |
| [select_one_from_file filename](select-one-from-file) | Elegir una opción cargada desde un archivo CSV externo |
| [rank listname](rank) | Ordenar opciones por preferencia o prioridad |

## Fecha y hora

| Tipo | Descripción |
|------|-------------|
| [date](date) | Fecha de calendario (año, mes, día) |
| [time](time) | Hora del día (horas, minutos) |
| [datetime](datetime-date-time) | Fecha y hora combinadas |

## Ubicación

| Tipo | Descripción |
|------|-------------|
| [geopoint](geopoint) | Coordenada GPS única (latitud, longitud, altitud, precisión) |
| [geotrace](geotrace) | Un trayecto — serie de puntos GPS que forman una línea |
| [geoshape](geoshape) | Un área — polígono cerrado de puntos GPS |

## Medios

| Tipo | Descripción |
|------|-------------|
| [image](image) | Captura de foto o carga de imagen |
| [audio](audio) | Grabación de audio |
| [video](video) | Grabación de video |
| [file](file) | Carga de archivos generales (PDF, documento, etc.) |

## Otros

| Tipo | Descripción |
|------|-------------|
| [barcode](barcode) | Escanear un código de barras o código QR |
| [note](note) | Texto de solo lectura — muestra instrucciones o resúmenes calculados |
| [calculate](calculate) | Campo oculto que almacena un valor calculado |
| [hidden](hidden) | Campo oculto que almacena un valor estático o precargado |
| [trigger / acknowledge](trigger) | Una casilla de verificación que el encuestador debe marcar para confirmar que ha leído una declaración |
| [meta](meta) | Metadatos automáticos: marcas de tiempo, ID del dispositivo, información del encuestador |

## Cómo funcionan juntos el tipo y la apariencia

El `type` determina **qué datos se recopilan**. La columna `appearance` controla **cómo se ve el widget**. Muchos tipos admiten múltiples apariencias — por ejemplo, `select_one` puede aparecer como botones de radio, un menú desplegable, una escala Likert o una cuadrícula compacta.

Consulte [Apariencia](../appearance) para obtener la lista completa de opciones.

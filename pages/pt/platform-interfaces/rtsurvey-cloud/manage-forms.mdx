O módulo **Gestão de Formulários** serve como porta de entrada principal para organizar os seus instrumentos de inquérito e coordenar as tarefas de trabalho de campo. Fornece controlo detalhado sobre a acessibilidade dos formulários, visualização de dados e direcionamento de dispositivos.

![Interface de Gestão de Formulários](/images/manage_forms.png)

## Visão Geral da Família de Formulários

No menu **Entrada de Formulários e Dados**, a secção **Família de Formulários** exibe uma grelha abrangente de todos os seus formulários importados juntamente com controlos essenciais de acesso rápido. Esta vista centralizada permite aos gestores de projeto implantar e configurar rapidamente inquéritos individuais.

### Colunas de Dados Principais e Opções de Configuração

- **Visualização de Dados:** Aceda a registos submetidos e pré-visualizações de conjunto de dados diretamente para cada formulário.
- **Permitir Edição:** Um botão de alternância rápida para bloquear ou desbloquear a capacidade de os trabalhadores de campo editarem os seus dados submetidos (estados Ativo/Inativo).
- **Visibilidade Pública:** Um botão de alternância para tornar um formulário publicamente disponível sem exigir autenticação de enumeradores.
- **URL do Formulário Web:** Obtenha instantaneamente o link público único para partilhar formulários de recolha de dados baseados em navegador.
- **Substituir Configurações:** Um modal de configurações avançadas (acedido através do ícone de engrenagem) para adaptar regras específicas de formulários, valores e desativar funcionalidades específicas.
- **Identificadores de Formulário:** Visualize metadados padrão, incluindo o nome da Família de Formulários, Código de Família e um ID de Formulário único.
- **Configuração Geo:** Configurações específicas de mapeamento ou geo-ponto vinculadas à estrutura do formulário.
- **Bloquear Formulário:** Funcionalidade para bloquear o acesso a submissões para finalizar a fase de recolha de dados.

## Ações de Formulário e Navegação

O painel de controlo superior facilita operações em lote e vistas alternativas de formulários:

- **Ação para Dispositivo:** Uma ferramenta de menu suspenso poderosa que permite aos gestores de projeto atribuir tarefas, enviar formulários direcionados ou despachar ações diretamente para os dispositivos de campo de enumeradores específicos.
- **Separador Formulário XLSX:** Navegue rapidamente da grelha de gestão principal para ambientes de carregamento para lidar com novos ficheiros XLSForm nativos.
- **Separador Construtor de Formulários:** Aceda à ferramenta incorporada para construir ou modificar formulários visualmente de forma dinâmica sem usar software de folha de cálculo exterior.

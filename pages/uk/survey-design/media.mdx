rtSurvey підтримує інтеграцію медіа в опитування, дозволяючи покращувати ваші анкети зображеннями, аудіо та відео. Ця функція може значно покращити досвід респондентів та якість зібраних даних.

## Підтримувані типи медіа

rtSurvey підтримує такі типи медіа:
- Зображення (jpg, png, gif)
- Аудіо (mp3, wav)
- Відео (mp4, webm)

## Додавання медіа до опитування

Для включення медіа у форму rtSurvey використовуйте такі стовпці в XLSForm:

- `image`: Для відображення зображень
- `audio`: Для відтворення аудіофайлів
- `video`: Для відтворення відеофайлів

Приклад:

```
| type | name          | label         | image        | audio       | video       |
|------|---------------|---------------|--------------|-------------|-------------|
| note | media_example | Media example | example.jpg  | sound.mp3   | clip.mp4    |
```

## Управління медіафайлами

### Веб-опитування
Для веб-опитувань rtSurvey надає інтерфейс управління медіа, де ви можете завантажувати та організовувати медіафайли. Ці файли потім автоматично доступні для використання у ваших опитуваннях.

### Мобільний додаток
При використанні мобільного додатку rtSurvey:
1. Помістіть медіафайли у папку `/rtSurvey/forms/[form-name]-media/` на вашому пристрої.
2. Вкажіть точну назву файлу у вашому XLSForm.

## Специфічні функції rtSurvey

### Динамічне завантаження медіа
rtSurvey підтримує динамічне завантаження медіа на основі відповідей опитування:

```
| type         | name      | label              | image                    |
|--------------|-----------|--------------------|--------------------------| 
| select_one species | animal | Select an animal | ${animal}.jpg            |
```

### Медіа у варіантах вибору
rtSurvey дозволяє використовувати медіа у варіантах вибору для питань select:

```
| type                | name    | label           | media::image |
|---------------------|---------|-----------------|--------------|
| select_one_from_file animals | Choose an animal |              |
```

У таблиці choices:
```
| list_name | name  | label | media::image |
|-----------|-------|-------|--------------|
| animals   | dog   | Dog   | dog.jpg      |
| animals   | cat   | Cat   | cat.jpg      |
```

### Захоплення медіа
rtSurvey розширює XLSForm можливостями захоплення медіа:

```
| type  | name        | label               |
|-------|-------------|---------------------|
| image | photo       | Take a photo        |
| audio | voice_note  | Record a voice note |
| video | video_clip  | Record a video      |
```

## Найкращі практики використання медіа

1. **Оптимізуйте розміри файлів**: Великі медіафайли можуть уповільнити завантаження та відправлення опитування.
2. **Використовуйте відповідні формати**: Дотримуйтесь широко підтримуваних форматів (jpg для зображень, mp3 для аудіо, mp4 для відео).
3. **Надавайте альтернативи**: Завжди включайте текстові альтернативи для доступності.
4. **Тестуйте ретельно**: Переконайтеся, що медіа правильно відображається на всіх цільових пристроях.
5. **Враховуйте офлайн-використання**: Для опитувань, які можуть проводитися офлайн, переконайтеся, що всі медіа доступні локально.

## Підтримка багатомовних медіа

rtSurvey підтримує мовно-специфічні медіа. Використовуйте суфікс `::language`:

```
| type | name  | label    | image::English | image::Spanish |
|------|-------|----------|----------------|----------------|
| note | intro | Welcome  | welcome_en.jpg | welcome_es.jpg |
```

## Медіа в експорті даних

При експорті даних з rtSurvey:
- Для веб-опитувань URL медіа включаються в експорт.
- Для опитувань через мобільний додаток включаються шляхи до файлів.

## Міркування щодо мобільного додатку

- Переконайтеся, що на пристроях достатньо місця для медіаємних опитувань.
- Мобільний додаток rtSurvey підтримує офлайн-відтворення та захоплення медіа.
- Великі медіафайли можуть впливати на продуктивність додатку на пристроях нижчого класу.

## Відомі обмеження

- Деякі старіші браузери можуть не підтримувати всі медіаформати.
- Дуже великі відеофайли можуть спричиняти проблеми в умовах низької пропускної здатності.

## Усунення неполадок із медіа

1. **Медіа не відображається**: Перевірте шляхи та імена файлів на точність.
2. **Проблеми з відтворенням**: Переконайтеся, що медіаформат підтримується цільовими пристроями.
3. **Повільне завантаження**: Розгляньте оптимізацію розмірів файлів або попереднє завантаження медіа.

## Розширені функції медіа

### Геотегування
rtSurvey може автоматично геотегувати медіа, захоплені під час опитувань:

```
| type  | name        | label        | appearance |
|-------|-------------|--------------|------------|
| image | photo       | Take a photo | geotag     |
```

### Анотації зображень
Дозвольте респондентам анотувати зображення:

```
| type  | name        | label        | appearance |
|-------|-------------|--------------|------------|
| image | photo       | Annotate the image | annotate |
```

Ефективно використовуючи медіа у ваших формах rtSurvey, ви можете створювати більш привабливі, інформативні та точні опитування. Пам'ятайте про баланс між перевагами включення медіа та міркуваннями продуктивності, особливо для опитувань, розгорнутих у районах з обмеженим підключенням до Інтернету або на пристроях нижчого класу.

rtSurvey is a CAPI platform for building forms, collecting data in the field (online or offline), and analyzing results in real time. Before you can do any of that, you need a running rtCloud server.

## Start here: Deploy a Server

The fastest path to a working rtSurvey environment is to deploy your own rtCloud instance using Docker Compose. It takes under 10 minutes on any Linux server.

**[Quick Start — Deploy rtCloud with Docker →](/deployment/quick-start)**

If you need cloud-specific setup (DigitalOcean, Linode), see [Cloud Providers](/deployment/cloud-providers).

## Prefer a managed service?

If you do not want to manage your own infrastructure, you can use [rtSurvey Cloud](https://rtsurvey.com/#rtsurvey-cloud) — the official hosted version. No server setup required.

## What comes after deployment

Once your server is running:

1. **Explore the dashboard** — understand the command center for managing projects and enumerators.
2. **Design your first form** — use XLSForm or the Form Builder (Beta).
3. **Install the mobile app** — Android and iOS apps are available for offline data collection.
4. **Collect and analyze** — sync submissions and connect to Power BI, R, or CSV exports.

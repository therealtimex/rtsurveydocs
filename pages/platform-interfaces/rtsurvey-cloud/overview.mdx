rtCloud is the robust server component of the rtSurvey ecosystem, designed to streamline data collection, management, and analysis. As the central hub for rtSurvey operations, rtCloud offers a comprehensive set of features to support complex survey projects and longitudinal studies.

## Key Features

### Project Management
- Organize all aspects of your survey project in one place
- Manage user roles, forms, analysis, deliverables, and permissions within each project

### User Management and Security
- Create and manage user accounts with role-based permissions
- Ensure data security and access control at every level

### Form Management
- Upload and manage XLSForms directly
- Support for form version updates, including minor tweaks and structural changes
- Attach multimedia or additional data to forms
- True form deletion capability for complete control over your survey instruments

### Data Collection and Submission Management
- Seamless integration with rtSurvey mobile app, web app, and web form
- Support for both authenticated user submissions and anonymous public links
- Handle submission multimedia and data attachments
- Interactive table preview of submission data for quick insights

### Advanced Submission Workflows
- Return submissions to users' devices for further editing or verification
- Forward submissions to other devices, enabling collaborative workflows and quality control

### Longitudinal Data Management
- Efficiently handle repeated measures and long-term studies
- Track changes and updates to participant data over time

### Flexible Connectivity
- Allow rtSurvey Mobile App to connect for form downloads and submission uploads
- Support offline data collection with seamless syncing when connectivity is restored

## How rtCloud Stands Out

While inspired by other data collection platforms, rtCloud offers unique features that set it apart:

1. **True Form Deletion**: Unlike some platforms, rtCloud allows complete removal of forms when needed.

2. **Flexible Submission Workflows**: The ability to return and forward submissions enables complex data review and quality control processes.

3. **Integrated Project Management**: rtCloud goes beyond form and data management, offering tools to organize all aspects of your survey project.

4. **Direct XLSForm Support**: Upload your XLSForms directly without conversion, streamlining the form creation process.

5. **Comprehensive Permissions System**: Fine-grained control over user access and capabilities within projects.

## Getting Started with rtCloud

To begin using rtCloud for your survey projects:

1. Set up your rtCloud server or contact rtSurvey for hosted solutions.
2. Create your first project and invite team members.
3. Upload your XLSForms and configure your data collection workflows.
4. Connect your rtSurvey mobile apps and start collecting data.

rtCloud empowers researchers, organizations, and data collection teams to manage complex survey projects with ease, security, and flexibility. Whether you're conducting a one-time survey or a multi-year longitudinal study, rtCloud provides the tools you need to succeed.

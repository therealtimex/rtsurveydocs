The **Managing Users** module (often labeled **Manage Staff** in the Setting Up menu) is the centralized directory for handling all accounts within your CPMS environment. It provides project administrators with the tools needed to onboard personnel, assign roles, and dictate geographical access levels.

![Managing Users Interface](/images/manage_users.png)

## User Grid Overview

The main interface features a comprehensive grid displaying all registered staff members. This view allows administrators to quickly search, filter, and review account statuses.

### Key Data Columns

The grid includes the following essential details for each user:

- **Username & Fullname:** Primary identifiers for the staff member.
- **Email:** Contact email address associated with the account.
- **User Role:** Indicates the system permissions granted to the user (e.g., Administrator, Staff, Monitor, Guest).
- **Group:** Displays the specific user group or team the staff member belongs to.
- **Status:** Indicates whether the account is currently **Active** or **Inactive**.
- **Created Date:** The timestamp when the account was registered.

## Staff Management Actions

Administrators have access to a suite of tools for onboarding and maintaining user accounts, accessible from the top control panel:

- **Add Staff:** Opens a detailed creation form to manually input a new user's profile, including their role, assigned regions, and contact information.
- **Import Staffs:** Allows for bulk account creation by uploading an Excel spreadsheet. This is particularly useful for establishing large field teams quickly.
- **Download import template:** Provides the standardized `.xlsx` template required for the bulk import process.
- **Export to Excel:** Generates a downloadable report containing the current grid's filtered list of users and their details.
- **Delete:** Permanently removes selected user accounts from the system.

## User Profiles and Assignments

When creating or editing a specific user (via the **Add Staff** button or by clicking on a Username), administrators can configure detailed profiles:

- **Personal Information:** Fields for Date of Birth, Gender, Identification Number, and Avatar.
- **Contact Details:** Cellphone number and detailed location information (Province, District, Ward, Address).
- **System Assignments:** Crucial for data security, administrators can link users to specific **Regions** and assign precise **User Roles**.
- **Supervisor Configuration:** In advanced setups, users can be assigned specific supervision codes or mapped to specific tablets (devices).

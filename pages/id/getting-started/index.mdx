rtSurvey memungkinkan Anda membangun formulir dan alur kerja yang canggih untuk mengumpulkan data yang Anda butuhkan di mana pun berada. Anda dapat:

1.  Membangun formulir yang canggih mencakup foto, lokasi GPS, logika lewati,
    kalkulasi, dataset eksternal, berbagai bahasa, dan banyak lagi.
2.  Mengumpulkan data secara offline menggunakan aplikasi mobile maupun aplikasi web.
    Formulir dan kiriman disinkronkan ketika koneksi Internet tersedia.
3.  Menganalisis dengan mudah dengan mengunduh data Anda sebagai CSV atau menghubungkan rtSurvey
    ke Excel, Power BI, Python, atau R untuk membuat dasbor yang diperbarui secara langsung.

Peneliti, tim lapangan, dan para profesional seperti Anda menggunakan rtSurvey
untuk mengumpulkan data penting mereka. Berikut cara memulainya.

## 1. Dapatkan rtSurvey Cloud

Untuk mendapatkan rtSurvey Cloud, cara tercepat dan termudah adalah menggunakan layanan hosting terkelola resmi yang disebut [rtSurvey
Cloud](https://rtSurvey.com/#rtSurvey-cloud). Layanan ini tersedia di situs web rtSurvey dan dibangun di atas infrastruktur yang cepat, andal, dan aman.

## 2. Unggah XLSForm Anda ke rtCloud atau buat formulir menggunakan Form Builder (Beta)

1.  Buat definisi formulir menggunakan XLSForm atau coba [formulir Semua Widget
    ini](https://docs.google.com/spreadsheets/d/1af_Sl8A_L8_EULbhRLHVl8OclCfco09Hq2tqb9CslwQ/edit#gid=0).
2.  Unggah XLSForm Anda ke rtCloud dan publikasikan.

## 3. Dapatkan aplikasi rtSurvey

Untuk mengunduh aplikasi rtSurvey, ikuti langkah-langkah berikut sesuai perangkat Anda:

### Untuk Perangkat Android:
1. Kunjungi [Google Play Store](https://play.google.com/store/apps/details?id=vn.rta.rtsurvey).
2. Cari "rtSurvey" di bilah pencarian.
3. Ketuk aplikasi dengan logo rtSurvey.
4. Klik tombol "Instal" untuk mengunduh dan memasang aplikasi di perangkat Android Anda.

### Untuk Perangkat iOS:
1. Buka [App Store](https://apps.apple.com/vn/app/rtsurvey/id1178851547) di perangkat iOS Anda.
2. Cari "rtSurvey" di tab pencarian.
3. Temukan aplikasi dengan logo rtSurvey.
4. Ketuk tombol "Dapatkan" untuk mengunduh dan memasang aplikasi di perangkat iOS Anda.

Setelah aplikasi diunduh dan dipasang, Anda dapat meluncurkannya dan mulai menggunakan rtSurvey untuk layanan survei dan analitik.

## 4. Hubungkan Collect ke rtCloud

1.  Buat Pengguna Aplikasi di rtCloud dan
    tetapkan formulir Anda ke pengguna tersebut.
2.  Buka Collect, ketuk `Konfigurasikan dengan kode QR` dan pindai kode yang dibuat untuk Pengguna Aplikasi Anda.

## 5. Isi formulir Anda di Collect

1.  Pilih `Isi Formulir Kosong` untuk mengisi
    formulir Anda.
2.  Data formulir Anda akan otomatis dikirim ke rtCloud ketika
    Anda selesai.

## 6. Gunakan data Anda di rtCloud

1.  Masuk ke rtCloud dan lihat data Anda.
2.  Unduh data Anda sebagai CSV atau
    visualisasikan di Power BI.

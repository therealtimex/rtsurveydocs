Ο τύπος ερώτησης note στα XLSForms και στο rtSurvey χρησιμοποιείται για την εμφάνιση κειμένου ή πολυμέσων μόνο για ανάγνωση στον ερωτώμενο. Δεν είναι ερώτηση που απαιτεί απάντηση, αλλά τρόπος παροχής πληροφοριών, οδηγιών ή πλαισίου μέσα στην έρευνα.

## Βασική προδιαγραφή XLSForm

| type | name | label |
|------|------|-------|
| note | info_text | Αυτή η έρευνα αφορά τις αναγνωστικές σας συνήθειες. |

Για περισσότερες λεπτομέρειες σχετικά με τον βασικό τύπο note, δείτε την [προδιαγραφή XLSForm](https://xlsform.org/en/#question-types).

## Χρήσεις

Οι ερωτήσεις note χρησιμοποιούνται συνήθως για:

1. Παροχή οδηγιών ή πλαισίου για τις επόμενες ερωτήσεις
2. Εμφάνιση υπολογισμένων αποτελεσμάτων ή περιλήψεων
3. Εμφάνιση εικόνων ή άλλων πολυμέσων
4. Διαχωρισμός ενοτήτων μιας έρευνας
5. Παροχή ανατροφοδότησης βάσει προηγούμενων αποκρίσεων

## Βέλτιστες πρακτικές

1. Διατηρείτε το κείμενο note συνοπτικό και σαφές για διατήρηση της προσοχής του ερωτώμενου.
2. Χρησιμοποιείτε μορφοποίηση (έντονο, πλάγιο) για τονισμό σημαντικών πληροφοριών.
3. Εξετάστε τη χρήση πολυμέσων (εικόνες, ήχος) για βελτίωση της κατανόησης όπου αρμόζει.
4. Χρησιμοποιείτε notes με φειδώ για αποφυγή υπερφόρτωσης της έρευνας.

## Παράδειγμα χρήσης

Δείτε πώς μπορείτε να χρησιμοποιήσετε ερωτήσεις note σε μια έρευνα:

| type | name | label |
|------|------|-------|
| note | intro | Καλώς ορίσατε στην έρευνά μας για αναγνωστικές συνήθειες. Θα ρωτήσουμε για τις προτιμήσεις και τη συχνότητα ανάγνωσής σας. |
| ... | ... | ... |
| calculate | books_per_month | `${fiction_books}` + `${non_fiction_books}` |
| note | reading_summary | Διαβάζετε περίπου `${books_per_month}` βιβλία το μήνα. |

Σε αυτό το παράδειγμα, χρησιμοποιούμε notes για να εισαγάγουμε την έρευνα και να παρέχουμε περίληψη υπολογισμένων αποτελεσμάτων.

## Επεκτάσεις rtSurvey

Ενώ η βασική προδιαγραφή XLSForm για ερωτήσεις note είναι απλή, το rtSurvey μπορεί να προσφέρει επιπλέον χαρακτηριστικά ή προσαρμογές:

1. Μορφοποίηση rich text
2. Υποστήριξη για ενσωματωμένα πολυμέσα (εικόνες, ήχος, βίντεο)
3. Δυναμικό περιεχόμενο βάσει προηγούμενων αποκρίσεων
4. Επιλογές προσαρμοσμένης στυλιστικής διαμόρφωσης

## Προχωρημένη χρήση

### Υπό συνθήκη εμφάνιση

Μπορείτε να χρησιμοποιήσετε εκφράσεις relevance για να εμφανίσετε notes υπό συνθήκη:

| type | name | label | relevant |
|------|------|-------|----------|
| note | high_reader_note | Είστε φανατικός αναγνώστης! | `${books_per_month}` > 5 |

### Συμπερίληψη υπολογισμών

Τα notes μπορούν να περιλαμβάνουν υπολογισμούς για δυναμική ανατροφοδότηση:

| type | name | label |
|------|------|-------|
| note | reading_time | Βάσει των αποκρίσεών σας, αφιερώνετε περίπου `${books_per_month * 5}` ώρες ανάγνωσης κάθε μήνα. |

## Περιορισμοί

- Τα notes δεν συλλέγουν δεδομένα, οπότε δεν πρέπει να χρησιμοποιούνται όταν χρειάζεται να συγκεντρώσετε πληροφορίες από ερωτώμενους.
- Η υπερχρήση notes μπορεί να κάνει την έρευνα να φαίνεται φορτωμένη ή υπερβολικά μεγάλη.
- Ορισμένες επιλογές προχωρημένης μορφοποίησης ή πολυμέσων μπορεί να μην υποστηρίζονται σε όλες τις συσκευές ή πλατφόρμες.

Οι εκφράσεις στο rtSurvey γράφονται σε ένα υποσύνολο **XPath 1.0**, επεκτεταμένο με συναρτήσεις JavaRosa/ODK και προσαρμοσμένες συναρτήσεις rtSurvey. Χρησιμοποιείτε εκφράσεις στις στήλες `calculate`, `constraint`, `relevant`, `required` και `default` του XLSForm σας.

## Αναφορά τιμών πεδίων

Χρησιμοποιήστε `${fieldname}` για αναφορά στην τιμή ενός άλλου πεδίου:

```
${age} > 18
```

Χρησιμοποιήστε `.` (μονή τελεία) για αναφορά στην **τιμή του τρέχοντος πεδίου** — χρησιμοποιείται συνήθως σε εκφράσεις `constraint`:

```
. >= 0 and . <= 100
```

Χρησιμοποιήστε `..` για αναφορά στη γονική ομάδα (προχωρημένη χρήση σε επαναλήψεις).

## Σύνταξη εκφράσεων

Οι εκφράσεις ακολουθούν τυπικούς κανόνες XPath:

- **Συμβολοσειρές** πρέπει να περικλείονται σε μονά εισαγωγικά: `'yes'`
- **Αριθμοί** γράφονται ως έχουν: `42`, `3.14`
- **Boolean** αποτελέσματα χρησιμοποιούνται για `relevant`, `required` και `constraint` — κάθε μη κενή, μη μηδενική τιμή είναι αληθής
- Κενά αγνοούνται γύρω από τελεστές

<Callout type="warning">
Πάντα χρησιμοποιείτε ευθεία εισαγωγικά (`'` ή `"`) — ποτέ "έξυπνα εισαγωγικά" (στρογγυλά). Επεξεργαστές rich text συχνά μετατρέπουν εισαγωγικά αυτόματα και θα σπάσουν τις εκφράσεις σας.
</Callout>

## Ενότητες σε αυτό το κεφάλαιο

- **[Τελεστές](operators)** — τελεστές σύγκρισης (`=`, `!=`, `>`, `<`, `>=`, `<=`) και λογικοί τελεστές (`and`, `or`, `not()`)
- **[Συναρτήσεις](functions)** — συναρτήσεις συμβολοσειρών, επιλογής, αριθμών, ημερομηνίας/ώρας, boolean, γεωγραφικές και βοηθητικές
- **[Αναφορές](references)** — τρόπος αναφοράς πεδίων και τιμών πλαισίου

## Γρήγορα παραδείγματα

| Περίπτωση χρήσης | Έκφραση |
|------------------|---------|
| Εμφάνιση εάν ηλικία > 18 | `${age} > 18` |
| Εμφάνιση μόνο εάν επιλέχθηκε "ναι" | `${consent} = 'yes'` |
| Απαίτηση εάν άλλο πεδίο δεν είναι κενό | `${name} != ''` |
| Υπολογισμός συνόλου | `${adults} + ${children}` |
| Συνένωση ονόματος | `concat(${first_name}, ' ', ${last_name})` |
| Σημερινή ημερομηνία | `today()` |
| Έλεγχος επιλογής | `selected(${interests}, 'sports')` |

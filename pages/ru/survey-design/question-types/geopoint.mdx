---
title: "Геоточка"
description: "Вопросы типа geopoint захватывают географические координаты (широту, долготу, высоту и точность) в рамках опроса."
---

Тип вопроса geopoint в XLSForm и rtSurvey обеспечивает сбор географических координат с использованием GPS или других служб определения местоположения устройства. Эта функция особенно полезна для географической привязки ответов опроса, отслеживания полевой деятельности или связывания данных с конкретными местоположениями.

## Базовая спецификация XLSForm

| type     | name        | label                            |
|----------|-------------|----------------------------------|
| geopoint | location    | Запишите текущее местоположение  |

Дополнительную информацию о базовом типе вопроса geopoint см. в [спецификации XLSForm](https://xlsform.org/en/#question-types).

## Применение

Вопросы типа geopoint обычно используются для:

1. Географической привязки ответов опроса
2. Проверки местоположения полевой деятельности
3. Отслеживания маршрутов перечислителей
4. Связывания экологических или социальных данных с конкретными местоположениями
5. Расчёта расстояний или площадей в географическом анализе

## Лучшие практики

1. Убедитесь, что на устройстве включены службы определения местоположения и предоставлены необходимые разрешения.
2. Дайте достаточно времени GPS для получения точного сигнала.
3. Учитывайте вопросы конфиденциальности и информируйте респондентов о сборе данных о местоположении.
4. Используйте вместе с другими типами вопросов для предоставления контекста для данных о местоположении.

Ниже приведён пример использования вопроса типа geopoint в опросе:

## Расширения rtSurvey

rtSurvey может предлагать дополнительные функции для вопросов типа geopoint:

1. Интеграция с картой для визуального подтверждения захваченного местоположения
2. Настройки порога точности
3. Возможность ввода координат вручную
4. Интеграция с офлайн-картами для отдалённых районов

## Формат данных

Данные геоточки обычно хранятся в виде строки из четырёх значений, разделённых пробелами:

```
широта долгота высота точность
```

Например:
```
41.40338 2.17403 30.5 10
```

## Соображения для анализа

При использовании вопросов типа geopoint учитывайте:

1. Как будут визуализироваться географические данные (например, в программном обеспечении для картографирования)
2. Точность собранных координат и её влияние на анализ
3. Меры конфиденциальности и защиты данных при обработке данных о местоположении
4. Потенциальную интеграцию с инструментами ГИС (географической информационной системы)

## Ограничения

- Точность может варьироваться в зависимости от устройства и условий окружающей среды.
- Сигналы GPS могут быть слабыми или недоступными в помещениях или в местах с препятствиями.
- Сбор данных о местоположении может значительно влиять на время работы батареи устройства.
- С сбором точных данных о местоположении могут быть связаны опасения по поводу конфиденциальности.

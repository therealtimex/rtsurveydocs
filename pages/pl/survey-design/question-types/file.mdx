---

Typ pytania `file` umożliwia przesyłanie ogólnych plików (PDF, dokumenty, arkusze kalkulacyjne itp.).

## Podstawowa specyfikacja XLSForm

| type | name     | label                         |
|------|----------|-------------------------------|
| file | contract | Prześlij podpisaną umowę (PDF) |

## Obsługiwane formaty

txt, pdf, xls, xlsx, doc, docx, rtf, zip

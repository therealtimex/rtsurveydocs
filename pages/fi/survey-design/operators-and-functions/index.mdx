rtSurveyn lausekkeet kirjoitetaan **XPath 1.0**:n osajoukkoon, jota laajennetaan JavaRosa/ODK-funktioilla ja mukautetuilla rtSurvey-funktioilla. Käytät lausekkeita XLSFormisi `calculate`-, `constraint`-, `relevant`-, `required`- ja `default`-sarakkeissa.

## Kenttäarvoihin viittaaminen

Käytä `${fieldname}` viittaaksesi toisen kentän arvoon:

```
${age} > 18
```

Käytä `.` (yksittäinen piste) viittaaksesi **nykyisen kentän arvoon** — yleisesti käytetty `constraint`-lausekkeissa:

```
. >= 0 and . <= 100
```

Käytä `..` viittaaksesi yläryhmään (edistynyt käyttö toistoissa).

## Lausekkeen syntaksi

Lausekkeet noudattavat vakio XPath-sääntöjä:

- **Merkkijonot** on ympäröitävä yksittäisillä lainausmerkeillä: `'yes'`
- **Numerot** kirjoitetaan sellaisenaan: `42`, `3.14`
- **Boolean**-tuloksia käytetään `relevant`-, `required`- ja `constraint`-kohdissa — mikä tahansa ei-tyhjä, nollasta eroava arvo on tosi
- Tyhjä merkki operaattorien ympärillä jätetään huomiotta

<Callout type="warning">
Käytä aina suoria lainausmerkkejä (`'` tai `"`) — ei "älykkäitä lainausmerkkejä" (kaarevat lainausmerkit). Rikkaat tekstieditorit muuntavat usein lainausmerkit automaattisesti ja rikkovat lausekkeesi.
</Callout>

## Pikakäyttöesimerkit

| Käyttötapaus | Lauseke |
|--------------|---------|
| Näytä jos ikä on yli 18 | `${age} > 18` |
| Näytä vain jos "kyllä" on valittu | `${consent} = 'yes'` |
| Vaadi jos toinen kenttä ei ole tyhjä | `${name} != ''` |
| Laske yhteensä | `${adults} + ${children}` |
| Yhdistä nimi | `concat(${first_name}, ' ', ${last_name})` |
| Tämän päivän päivämäärä | `today()` |
| Tarkista onko vaihtoehto valittu | `selected(${interests}, 'sports')` |

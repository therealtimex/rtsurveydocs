---
title: "Geopoint"
description: "Geopoint-Fragen erfassen geografische Koordinaten (Breitengrad, Längengrad, Höhe und Genauigkeit) als Teil der Umfrage."
---

Der `geopoint`-Fragetyp in XLSForms und rtSurvey ermöglicht die Erfassung geografischer Koordinaten mithilfe des GPS des Geräts oder anderer Ortungsdienste. Diese Funktion ist besonders nützlich für die Kartierung von Umfrageantworten, die Verfolgung von Außendienstaktivitäten oder die Verknüpfung von Daten mit bestimmten Standorten.

## Grundlegende XLSForm-Spezifikation

| type     | name        | label                           |
|----------|-------------|--------------------------------|
| geopoint | location    | Aktuellen Standort aufzeichnen  |

Weitere Details zum grundlegenden `geopoint`-Fragetyp finden Sie in der [XLSForm-Spezifikation](https://xlsform.org/en/#question-types).

## Anwendungen

`Geopoint`-Fragen werden häufig verwendet für:

1. Geografische Kartierung von Umfrageantworten
2. Verifizierung des Standorts von Außendienstaktivitäten
3. Verfolgung der Route von Enumeratoren
4. Verknüpfung von Umwelt- oder Sozialdaten mit bestimmten Standorten
5. Berechnung von Entfernungen oder Flächen in geografischen Analysen

## Best Practices

1. Stellen Sie sicher, dass am Gerät die Ortungsdienste aktiviert und die entsprechenden Berechtigungen erteilt sind.
2. Planen Sie genügend Zeit ein, damit das GPS eine genaue Position bestimmen kann.
3. Berücksichtigen Sie Datenschutzaspekte und informieren Sie die Befragten über die Erhebung von Standortdaten.
4. Verwenden Sie den Fragetyp in Verbindung mit anderen Fragetypen, um Kontext für die Standortdaten zu liefern.

## Beispielhafte Verwendung

Hier ist ein Beispiel dafür, wie Sie eine `geopoint`-Frage in einer Umfrage verwenden könnten:

| type     | name           | label                                      | hint                                        |
|----------|----------------|--------------------------------------------|--------------------------------------------|
| geopoint | sample_location| Standort der Probenentnahme aufzeichnen    | Stellen Sie sich für ein besseres GPS-Signal in einen offenen Bereich |

## rtSurvey-Erweiterungen

Während die grundlegende XLSForm-Spezifikation für `geopoint`-Fragen einfach ist, bietet rtSurvey möglicherweise zusätzliche Funktionen oder Anpassungen:

1. Kartenintegration zur visuellen Bestätigung des erfassten Standorts
2. Einstellungen für Genauigkeitsschwellenwerte
3. Option zur manuellen Eingabe von Koordinaten
4. Integration von Offline-Karten für abgelegene Gebiete

(Hinweis: Die spezifischen in rtSurvey verfügbaren Erweiterungen für `geopoint`-Fragen müssten hier bestätigt und detailliert werden.)

## Datenformat

Geopoint-Daten werden in der Regel als eine Zeichenfolge aus vier durch Leerzeichen getrennten Werten gespeichert:

```
Breitengrad Längengrad Höhe Genauigkeit
```

Beispiel:
```
41.40338 2.17403 30.5 10
```

## Überlegungen zur Analyse

Berücksichtigen Sie bei der Verwendung von `geopoint`-Fragen:

1. Wie die geografischen Daten visualisiert werden (z. B. Kartierungssoftware)
2. Die Genauigkeit der erfassten Koordinaten und deren Auswirkungen auf die Analyse
3. Datenschutz- und Datensicherheitsmaßnahmen für den Umgang mit Standortdaten
4. Potenzielle Integration mit GIS-Tools (Geoinformationssysteme)

## Einschränkungen

- Die Genauigkeit kann je nach Gerät und Umgebungsbedingungen variieren.
- GPS-Signale können in Innenräumen oder Bereichen mit Hindernissen schwach oder nicht verfügbar sein.
- Die Erfassung von Standortdaten kann die Akkulaufzeit des Geräts erheblich beeinflussen.
- Bei der Erfassung präziser Standortdaten können Datenschutzbedenken aufkommen.

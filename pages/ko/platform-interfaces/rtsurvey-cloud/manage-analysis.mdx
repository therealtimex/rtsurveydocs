RT-CPMS의 **분석 관리** 모듈은 설문 데이터를 처리하고 시각화하기 위한 종합적인 도구 모음을 제공합니다. 전역 탐색 사이드바에서 접근할 수 있는 **Analytics Dev** 및 **Analytics & Reports**라는 두 가지 주요 섹션으로 구성됩니다.

![분석 관리 인터페이스](/images/manage_analysis.png)

## Analytics Dev

**Analytics Dev** 섹션은 새 분석 설계를 만들고 구성하기 위한 중앙 허브입니다. 여기에서 연구자 및 데이터 관리자가 원시 설문 데이터를 처리하고 집계할 방법을 정의합니다.

### Analytics Dev의 주요 기능
- **새 설계 만들기:** **New Analytics +** 버튼을 사용하여 새 보고서 템플릿 또는 분석 설계 구축을 시작합니다.
- **기존 설계 관리:** 메인 그리드는 다음과 같은 주요 메타데이터를 표시하며 모든 분석 모델의 종합적인 개요를 제공합니다:
  - ID 및 제목/설명
  - 손쉬운 분류를 위한 태그
  - 버전 추적
  - 생성 및 업데이트 타임스탬프
  - 작성자 정보
- **검색 및 필터:** 각 열의 내장 검색 및 필터링 도구를 사용하여 특정 설계를 쉽게 찾습니다.
- **빠른 작업:** 그리드의 작업 메뉴에서 특정 설계를 직접 보기, 편집 또는 삭제합니다.

## Analytics & Reports

분석 설계가 생성되어 실행되면 **Analytics & Reports** 섹션에서 생성된 비즈니스 인텔리전스(BI) 출력과 상호 작용합니다.

### Analytics & Reports의 주요 기능
- **보고서 탐색 사이드바:** 전용 왼쪽 패널을 사용하여 다양한 사용 가능한 보고서 간에 빠르게 전환합니다.
- **검색 및 필터링:** 검색 바 또는 "All analytics" 드롭다운 필터를 사용하여 보고서 목록을 좁힙니다.
- **즐겨찾기:** 중요하거나 자주 접근하는 보고서를 즐겨찾기로 표시하여 향후 더 빠르게 접근합니다.

## 대시보드 통합

빠른 개요를 위해 메인 **홈 대시보드**는 기본 양식 트래커 옆에 전용 **보고서** 탭이 있습니다. 이 탭은 관리 제어 센터에서 바로 보고서에 즉시 접근을 제공하여 데이터 수집 진행 상황과 분석 출력을 원활하게 모니터링할 수 있습니다.

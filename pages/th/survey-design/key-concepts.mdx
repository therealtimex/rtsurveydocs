## XLSForm คืออะไร?
rtSurvey ใช้เวอร์ชันขยายของมาตรฐาน [XLSForm](https://xlsform.org/) สำหรับการออกแบบแบบฟอร์ม ซึ่งมีคุณสมบัติอันทรงพลังสำหรับการสร้างแบบสำรวจที่ซับซ้อน คู่มือนี้จะแนะนำคุณเกี่ยวกับแนวคิดหลักของการออกแบบแบบฟอร์มใน rtSurvey ตั้งแต่โครงสร้าง XLSForm พื้นฐานไปจนถึงคุณสมบัติเฉพาะของ rtSurvey

ด้วย XLSForms คุณสามารถสร้างแบบฟอร์มในรูปแบบที่มนุษย์อ่านได้โดยใช้เครื่องมือ Excel ที่คุ้นเคย ทำให้เข้าถึงได้สำหรับเกือบทุกคน มาตรฐานนี้ช่วยให้การแบ่งปันและทำงานร่วมกันในการสร้างแบบฟอร์มเป็นเรื่องง่าย

แม้ XLSForms จะเป็นมิตรกับผู้เริ่มต้น แต่ก็อนุญาตให้ผู้ใช้ที่มีประสบการณ์สร้างแบบฟอร์มที่ซับซ้อนได้

rtSurvey ให้วิธีที่สม่ำเสมอในการรวมฟังก์ชันขั้นสูงเช่น skip logic เข้ากับแบบฟอร์มในแพลตฟอร์มการเก็บข้อมูลทางเว็บและมือถือต่างๆ

## โครงสร้าง XLSForm
XLSForm โดยทั่วไปประกอบด้วยเวิร์กชีตหลักสองส่วน:

1. **survey**: กำหนดโครงสร้างและเนื้อหาของแบบฟอร์มคุณ
2. **choices**: ระบุตัวเลือกคำตอบสำหรับคำถามหลายตัวเลือก

เวิร์กชีต **settings** ที่เป็นทางเลือกสามารถให้ข้อมูลเพิ่มเติมระดับแบบฟอร์มได้

สิ่งสำคัญคือคอลัมน์บังคับในเวิร์กชีต survey และ choices ต้องมีอยู่เพื่อให้แบบฟอร์มทำงานได้อย่างถูกต้อง

### เวิร์กชีต survey
**เวิร์กชีต survey** คือที่ที่คุณกำหนดโครงสร้างของแบบฟอร์มและให้เนื้อหา แต่ละแถวในเวิร์กชีต survey แทนคำถามหรือองค์ประกอบในแบบฟอร์มของคุณ คอลัมน์ต่อไปนี้บังคับในเวิร์กชีต survey:

- `type`: ระบุประเภทรายการที่คุณคาดหวังสำหรับคำถาม
- `name`: ระบุชื่อตัวแปรที่ไม่ซ้ำกันสำหรับรายการนั้น
- `label`: มีข้อความจริงที่คุณเห็นสำหรับคำถามในแบบฟอร์ม

| type                | name     | label                |
| ------------------- | -------- | -------------------- |
| today               | today    |                      |
| select_one gender   | gender   | Respondent's gender? |
| integer             | age      | Respondent's age?    |

### เวิร์กชีต choices
**เวิร์กชีต `choices`** ใช้ระบุตัวเลือกคำตอบสำหรับคำถามหลายตัวเลือก แต่ละแถวแทนตัวเลือกคำตอบ คอลัมน์ต่อไปนี้บังคับ:

- **`list_name`**: จัดกลุ่มตัวเลือกคำตอบที่เกี่ยวข้องเข้าด้วยกัน
- **`name`**: ระบุชื่อตัวแปรที่ไม่ซ้ำกันสำหรับตัวเลือกคำตอบนั้น
- **`label`**: แสดงตัวเลือกคำตอบตามที่คุณต้องการให้ปรากฏในแบบฟอร์ม

| list_name           | name        | label                |
| ------------------- | ----------- | -------------------- |
| gender              | transgender | Transgender          |
| gender              | female      | Female               |
| gender              | male        | Male                 |
| gender              | other       | Other                |

### เวิร์กชีต settings

เวิร์กชีต settings เป็นทางเลือกแต่ช่วยให้คุณระบุข้อมูลเมตาและพฤติกรรมระดับแบบฟอร์มได้

| คอลัมน์ | คำอธิบาย |
|--------|-------------|
| form_title | ชื่อแบบฟอร์มที่ปรากฏต่อผู้ใช้ |
| form_id | ตัวระบุที่ไม่ซ้ำกันสำหรับแบบฟอร์ม |
| default_language | รหัสภาษาเริ่มต้นสำหรับแบบฟอร์มหลายภาษา |
| version | หมายเลขเวอร์ชันของแบบฟอร์ม |
| instance_name | นิพจน์เพื่อสร้างชื่อที่ไม่ซ้ำกันสำหรับการส่งแต่ละครั้ง |
| generation | จำนวนเต็มที่ระบุรุ่นของแบบฟอร์ม เพิ่มขึ้นสำหรับการเปลี่ยนแปลงโครงสร้าง |
| family | ตัวระบุเพื่อจัดกลุ่มแบบฟอร์มที่เกี่ยวข้องข้ามการเปลี่ยนแปลงโครงสร้าง |

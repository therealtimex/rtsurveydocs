description: "Dynamic question type อนุญาตให้ประเภทคำถามและวิดเจ็ตของฟิลด์ถูกกำหนดในขณะรันไทม์ตามการตอบสนอง API หรือค่าที่คำนวณ"
---

ฟีเจอร์ **Dynamic Question Type** อนุญาตให้วิดเจ็ตอินพุตและพฤติกรรมการตรวจสอบของฟิลด์ถูกกำหนด **ในขณะรันไทม์** แทนที่จะเป็นเวลาออกแบบแบบฟอร์ม นี่คือส่วนขยายขั้นสูงของ rtSurvey ที่ใช้เมื่อประเภทข้อมูลที่จะรวบรวมขึ้นอยู่กับการกำหนดค่าฝั่งเซิร์ฟเวอร์ การตอบสนอง API หรือค่าฟิลด์ก่อนหน้า

กรณีใช้งานทั่วไปคือรายการตรวจสอบที่กำหนดค่าได้ซึ่งเซิร์ฟเวอร์กำหนดว่าฟิลด์ใดจำเป็น ประเภทใด (text, integer, select ฯลฯ) และตัวเลือกใดพร้อมใช้งาน — โดยไม่ต้องสร้างแบบฟอร์มใหม่สำหรับทุกการกำหนดค่า

ម៉ូឌុល **Manage Analysis** នៅក្នុង RT-CPMS ផ្ដល់នូវ suite ដ៏ទូលំទូលាយ នៃឧបករណ៍ សម្រាប់ដំណើរការ និងការបង្ហាញ ទិន្នន័យស្ទង់មតិ។ វាត្រូវបានបែងចែក ជាពីរផ្នែក ដែលអាចចូលដំណើរការ ពី global navigation sidebar: **Analytics Dev** និង **Analytics & Reports**។

![Manage Analysis Interface](/images/manage_analysis.png)

## Analytics Dev

ផ្នែក **Analytics Dev** គឺជា hub ដែល centralized របស់អ្នក សម្រាប់ការបង្កើត និងការកំណត់ analysis designs ថ្មី។ នេះ ជា កន្លែង ដែល អ្នក ស្រាវជ្រាវ និងអ្នកគ្រប់គ្រង ទិន្នន័យ កំណត់ ថា ការ ដំណើរការ ទិន្នន័យ ស្ទង់មតិ raw ហើយ tabulated។

### មុខងារ សំខាន់ របស់ Analytics Dev
- **បង្កើត Designs ថ្មី:** ប្រើ ប៊ូតុង **New Analytics +** ដ៏ ហ្មត់ ចត់ ដើម្បី ចាប់ ផ្ដើម បង្កើត report template ឬ analysis design ថ្មី។
- **គ្រប់គ្រង Designs ដែល មានស្រាប់:** Grid ចម្បង ផ្ដល់ ទិដ្ឋភាព ទូ ទៅ ដ៏ ទូលំ ទូ លាយ នៃ models វិភាគ ទាំង អស់ របស់ អ្នក ដែល បង្ហាញ metadata សំខាន់ ៗ ដូចជា ID និង Title/Description, Tags, ការ track Version, timestamps ការ បង្កើត និង update, ព័ត៌មាន Author។
- **ស្វែងរក និង Filter:** ស្វែងរក designs ជាក់លាក់ ដោយ ងាយ ដោយ ប្រើ ឧបករណ៍ ស្វែងរក ហើយ filtering នៅ column នី មួយ ៗ។
- **Quick Actions:** មើល កែ ឬ លុប designs ជាក់លាក់ ដោយ ផ្ទាល់ ពី action menu ក្នុង grid។

## Analytics & Reports

នៅ ពេល analysis design ត្រូវ បាន បង្កើត ហើយ run, ផ្នែក **Analytics & Reports** ជា កន្លែង ដែល អ្នក ទំនាក់ ទំនង ជាមួយ business intelligence (BI) output ដែល បាន generate។

### មុខងារ សំខាន់ របស់ Analytics & Reports
- **Report Navigation Sidebar:** ផ្លាស់ ប្ដូរ រហ័ស រវាង reports ផ្សេងៗ ដែល ជំនួស ប្រើ panel ខាង ឆ្វេង ដែល ឧទ្ទិស។
- **ស្វែងរក និង Filtering:** ប្រើ search bar ឬ dropdown filter "All analytics" ដើម្បី narrow down បញ្ជី reports។
- **Favorites:** សម្គាល់ reports ដែល សំខាន់ ឬ ត្រូវ ចូល ញឹកញាប់ ជា favorites សម្រាប់ ការ ចូល ដំណើរការ ឆាប់ ជាង ក្នុង ការ ប្រើ ប្រាស់ ទៀតនេះ។

## Dashboard Integration

សម្រាប់ ការ ត្រួត ពិនិត្យ ឆាប់, **Home Dashboard** ចម្បង features ផ្ទាំង **Reports** ដែល ឧទ្ទិស ជំនួស Forms tracker ចម្បង។ ផ្ទាំង នេះ ផ្ដល់ ការ ចូល ដំណើរការ ភ្លាមៗ ទៅ reports ដោយ ផ្ទាល់ ពី administrative command center, អនុញ្ញាត ឱ្យ អ្នក ត្រួតពិនិត្យ ទាំង វឌ្ឍ ន ភាព ប្រមូល ទិន្នន័យ និង analytical outputs ។

---
title: "Geoshape"
description: "Geoshape 题目允许受访者在地图上绘制形状，将复杂的地理数据捕获为调查的一部分。"
---

XLSForm 和 rtSurvey 中的 geoshape 题目类型使受访者能够在地图上绘制形状（多边形），捕获复杂的地理数据。此功能在绘制区域、定义边界或在空间调查中标记感兴趣的区域时特别有用。

## 基本 XLSForm 规范

| type     | name        | label                           |
|----------|-------------|--------------------------------|
| geoshape | field_area  | 绘制田地的边界  |

有关基本 geoshape 题目类型的更多详情，请参阅 [XLSForm 规范](https://xlsform.org/en/#question-types)。

## 用途

Geoshape 题目通常用于：

1. 在农业调查中绘制田地边界
2. 定义环境影响区域
3. 在城市规划研究中标记区域
4. 在地质调查中划定区域
5. 为空间分析捕获复杂地理特征

## 最佳实践

1. 确保设备已启用位置服务并授予权限。
2. 提供关于如何绘制形状以及应包含哪些区域的清晰说明。
3. 考虑使用卫星图像或底图来帮助受访者准确绘制形状。
4. 注意形状的潜在复杂性及其对数据大小和处理的影响。

## 使用示例

以下是您可能在调查中使用 geoshape 题目的示例：

| type     | name           | label                                      | hint                                        |
|----------|----------------|--------------------------------------------|--------------------------------------------|
| geoshape | forest_area    | 勾勒出森林斑块的边界   | 至少使用 3 个点创建封闭形状 |

## rtSurvey 扩展

虽然 geoshape 题目的基本 XLSForm 规范很简单，但 rtSurvey 可能提供额外功能或自定义选项：

1. 与离线地图集成，适用于偏远地区
2. 设置形状点数最小值和最大值的选项
3. 初始绘制后编辑或细化形状的能力
4. 除自由形式多边形外还支持不同形状类型（例如，矩形、圆形）

## 数据格式

Geoshape 数据通常存储为空格分隔坐标对的字符串，括在括号内：

```
(lat1 lon1; lat2 lon2; lat3 lon3; ... latN lonN)
```

例如：
```
(38.253094215699576 21.756382658677467; 38.25021274773806 21.756382658677467; 38.25007793942195 21.763892843919166; 38.25290886154963 21.763935759263404; 38.253094215699576 21.756382658677467)
```

## 分析注意事项

使用 geoshape 题目时，请考虑：

1. 如何可视化和分析地理数据（例如，GIS 软件）
2. 复杂形状的数据清理或简化的潜在需求
3. 处理详细空间数据的隐私和数据保护措施
4. 与其他空间数据源集成进行综合分析

## 限制

- 在小型移动屏幕上精确绘制形状可能具有挑战性。
- 复杂形状可能需要大量存储和处理能力。
- Geoshape 题目可能不适合所有类型的调查或受访者。
- 收集详细空间数据可能涉及隐私问题。

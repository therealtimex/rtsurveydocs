rtSurvey 支持所有标准 XLSForm 题目类型，以及多种扩展类型。每种题目类型控制收集哪类数据，以及输入控件在设备上的渲染方式。

要设置题目类型，请在 XLSForm 的 **survey** 工作表的 `type` 列中输入类型名称。

## 文本输入

| 类型 | 描述 |
|------|-------------|
| [text](text) | 自由文本回答——允许任意字符 |
| [integer](integer) | 整数（无小数） |
| [decimal](decimal) | 带小数位的数字 |
| [range](range) | 在定义的最小/最大范围内通过滑块选择的数字 |

## 选择题

| 类型 | 描述 |
|------|-------------|
| [select_one listname](select-one) | 从列表中精确选择一个选项 |
| [select_multiple listname](select-multiple) | 从列表中选择一个或多个选项 |
| [select_one_from_file filename](select-one-from-file) | 从外部 CSV 文件加载的选项中选择一项 |
| [rank listname](rank) | 按偏好或优先级排列选项 |

## 日期和时间

| 类型 | 描述 |
|------|-------------|
| [date](date) | 日历日期（年、月、日） |
| [time](time) | 一天中的时间（小时、分钟） |
| [datetime](datetime-date-time) | 日期和时间组合 |

## 位置

| 类型 | 描述 |
|------|-------------|
| [geopoint](geopoint) | 单个 GPS 坐标（纬度、经度、海拔、精度） |
| [geotrace](geotrace) | 路径——构成线条的一系列 GPS 点 |
| [geoshape](geoshape) | 区域——GPS 点组成的封闭多边形 |

## 媒体

| 类型 | 描述 |
|------|-------------|
| [image](image) | 拍照或图片上传 |
| [audio](audio) | 音频录制 |
| [video](video) | 视频录制 |
| [file](file) | 通用文件上传（PDF、文档等） |

## 其他

| 类型 | 描述 |
|------|-------------|
| [barcode](barcode) | 扫描条形码或二维码 |
| [note](note) | 只读显示文本——显示说明或计算结果摘要 |
| [calculate](calculate) | 存储计算值的隐藏字段 |
| [hidden](hidden) | 存储静态或预填值的隐藏字段 |
| [trigger / acknowledge](trigger) | 枚举员必须勾选的复选框，以确认已阅读某个陈述 |
| [meta](meta) | 自动元数据：时间戳、设备 ID、枚举员信息 |

## 类型与外观的协同工作

`type` 决定**收集什么数据**。`appearance` 列控制**控件外观**。许多类型支持多种外观——例如 `select_one` 可以显示为单选按钮、下拉列表、李克特量表或紧凑网格。

请参阅[外观](../appearance)了解完整的选项列表。

# 系統使用者管理

**系統使用者**模組（`/cpms/cpmsSystemUser/admin`）是一個全面的管理介面，用於控制哪些人可以存取您的即時問卷調查平台（RT-CPMS）以及他們可以執行哪些操作。

![系統使用者介面](/images/system_user.png)

## 統一管理方式

在 RT-CPMS 中，**調查員**只是分配給系統使用者的特定角色。沒有獨立的「調查員」資料庫。無論使用者是透過網頁入口監控的高階管理員，還是透過行動應用程式收集資料的現場調查員，他們都在這個單一的統一框架內進行管理。

## 主要功能

### 1. 使用者目錄與網格檢視
主介面以分頁列表形式顯示連接至工作區的所有使用者。主要屬性包括：
* **組織 ID 和名稱**：將使用者按特定組織實體進行邏輯分組（例如 `rta`、`partner_org`）。
* **角色**：指定使用者的權限等級（例如 `管理員`、`組長`、`調查員`）。
* **群組**：空間或邏輯分組指派（例如特定地區或操作團隊）。
* **是否已同步**：表示帳號是否已成功與中央單一登入（SSO）系統整合。
* **狀態**：確認帳號是否為`啟用`、`停用`、`已刪除`或`已封鎖`的視覺指示器。

**全域操作：**
* **新增系統使用者**：手動建立個人個人資料。
* **匯入系統使用者**：使用 Excel 模板批次上傳帳號。您可以使用`略過`或`取代`模式解決衝突，並直接與 SSO 同步。
* **批次刪除**：支援多選以批次刪除帳號。

### 2. 存取控制與安全性
建立或編輯使用者個人資料時，有幾個關鍵的安全和工作流程欄位可供使用：
* **使用者代碼**：將本地 CPMS 帳號連結至中央 SSO 儲存庫的唯一識別碼。
* **更換裝置代碼**：調查員需要切換用於資料收集的行動裝置時所需的強健安全令牌。
* **權限等級**：細緻的優先順序/存取刻度，範圍從 0（最低）到 20（最高）。
* **督導切換**：即時將標準使用者提升為管理狀態的核取方塊。
* **工作流程自動化**：「自動批准編輯請求」選項，為受信任的使用者簡化資料清理和驗證流程。

### 3. 代碼管理（自動化入職）
在「代碼」子標籤下，此功能管理基於雜湊的註冊和邀請連結，簡化大型團隊的入職流程。

* **註冊與邀請**：選擇使用者是否可以使用分發的連結自行註冊，或者是否需要直接的管理員邀請。
* **到期日**：將入職限制在特定時間窗口內。
* **使用限制**：限制可使用單個生成代碼加入的使用者數量。
* **預先指派角色**：透過這些代碼加入的使用者自動繼承預定義的角色和權限等級，確保他們無需手動管理員介入即可立即開始工作。

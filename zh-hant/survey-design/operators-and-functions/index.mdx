rtSurvey 中的表達式以 **XPath 1.0** 的子集編寫，使用 JavaRosa/ODK 函數和自訂 rtSurvey 函數進行擴展。您在 XLSForm 的 `calculate`、`constraint`、`relevant`、`required` 和 `default` 欄中使用表達式。

## 參考字段值

使用 `${fieldname}` 參考另一個字段的值：

```
${age} > 18
```

使用 `.`（單個點）參考**當前字段的值**——通常在 `constraint` 表達式中使用：

```
. >= 0 and . <= 100
```

使用 `..` 參考父群組（在重複中高級 XPath 表達式的用法）。

## 表達式語法

表達式遵循標準 XPath 規則：

- **字符串**必須用單引號括起來：`'yes'`
- **數字**照原樣寫：`42`、`3.14`
- **Boolean** 結果用於 `relevant`、`required` 和 `constraint`——任何非空、非零值都是真值
- 運算符周圍的空格被忽略

<Warning>
始終使用直引號（`'` 或 `"`）——絕不使用「智慧引號」（彎引號）。富文字編輯器通常會自動轉換引號，這會破壞您的表達式。
</Warning>

## 快速範例

| 使用場景 | 表達式 |
|----------|------------|
| 如果年齡超過 18 歲則顯示 | `${age} > 18` |
| 僅在選取「是」時顯示 | `${consent} = 'yes'` |
| 如果另一個字段不為空則必填 | `${name} != ''` |
| 計算總計 | `${adults} + ${children}` |
| 串聯名稱 | `concat(${first_name}, ' ', ${last_name})` |
| 今天的日期 | `today()` |
| 檢查選項是否被選取 | `selected(${interests}, 'sports')` |

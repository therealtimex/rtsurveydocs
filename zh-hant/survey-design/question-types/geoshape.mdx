XLSForms 和 rtSurvey 中的 geoshape 問題類型使受訪者能夠在地圖上繪製形狀（多邊形），捕獲複雜地理資料。此功能對於空間問卷調查中的區域製圖、邊界定義或標記感興趣的區域特別有用。

## 基本 XLSForm 規格

| type     | name        | label                           |
|----------|-------------|--------------------------------|
| geoshape | field_area  | 繪製田地的邊界                  |

有關基本 geoshape 問題類型的更多詳細資訊，請參閱 [XLSForm 規格](https://xlsform.org/en/#question-types)。

## 用途

地理形狀問題通常用於：

1. 在農業問卷調查中繪製田地邊界
2. 定義環境影響區域
3. 在城市規劃研究中標記區域
4. 勾勒地質調查的區域
5. 捕獲複雜地理特徵以進行空間分析

## 最佳實踐

1. 確保裝置已啟用定位服務並已授予權限。
2. 提供有關如何繪製形狀以及應包含哪些區域的清晰說明。
3. 考慮使用衛星圖像或底圖幫助受訪者準確繪製形狀。
4. 注意形狀的潛在複雜性及其對資料大小和處理的影響。

## 使用範例

以下是如何在問卷調查中使用地理形狀問題的範例：

| type     | name           | label                                      | hint                                        |
|----------|----------------|--------------------------------------------|--------------------------------------------|
| geoshape | forest_area    | 勾勒森林地塊的邊界                          | 至少使用 3 個點創建封閉形狀               |

## rtSurvey 擴展

雖然 geoshape 問題的基本 XLSForm 規格很簡單，但 rtSurvey 可能提供額外的功能或自訂選項：

1. 與離線地圖整合以適用於偏遠地區
2. 設定形狀最小和最大點數的選項
3. 初始繪製後編輯或優化形狀的能力
4. 除自由形式多邊形外支援不同形狀類型（例如矩形、圓形）

（注意：rtSurvey 中針對 geoshape 問題可用的特定擴展需要在此處確認和詳細說明。）

## 資料格式

地理形狀資料通常儲存為以括號括起的以分號分隔的座標對字串：

```
(lat1 lon1; lat2 lon2; lat3 lon3; ... latN lonN)
```

例如：
```
(38.253094215699576 21.756382658677467; 38.25021274773806 21.756382658677467; 38.25007793942195 21.763892843919166; 38.25290886154963 21.763935759263404; 38.253094215699576 21.756382658677467)
```

## 分析注意事項

使用地理形狀問題時，請考慮：

1. 如何將地理資料視覺化和分析（例如 GIS 軟體）
2. 對複雜形狀進行資料清理或簡化的潛在需求
3. 處理詳細空間資料的隱私和資料保護措施
4. 與其他空間資料來源整合以進行全面分析

## 限制

- 在小型行動螢幕上繪製準確的形狀可能具有挑戰性。
- 複雜形狀可能需要大量儲存和處理能力。
- 地理形狀問題可能不適合所有類型的問卷調查或受訪者。
- 收集詳細空間資料可能存在隱私問題。

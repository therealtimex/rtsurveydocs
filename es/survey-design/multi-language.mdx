---


rtSurvey proporciona un sólido soporte multilingüe, lo que le permite crear encuestas en múltiples idiomas. Esta función es crucial para realizar investigaciones en poblaciones lingüísticas diversas o en entornos multilingües.

## Configuración de encuestas multilingües

Para crear una encuesta multilingüe en rtSurvey, debe agregar columnas específicas del idioma a su XLSForm. Así es como:

1. **Traducciones de etiquetas**: Agregue columnas para cada idioma usando el formato `label::Language (code)`.
2. **Traducciones de sugerencias**: Use `hint::Language (code)` para traducir las sugerencias.
3. **Traducciones de archivos multimedia**: Para medios específicos del idioma, use `media::Language (code)`.

Ejemplo:

```
| type    | name | label::English (en) | label::Español (es) | hint::English (en) | hint::Español (es) |
|---------|------|---------------------|---------------------|---------------------|---------------------|
| integer | age  | How old are you?    | ¿Cuántos años tienes?| Enter your age     | Ingrese su edad     |
```

## Códigos de idioma

Se recomienda usar los códigos de idioma oficiales de 2 caracteres (subetiquetas) después del nombre del idioma. Esto facilita la coincidencia del idioma del formulario con el idioma de la interfaz de usuario. Puede encontrar los códigos oficiales [aquí](https://www.iana.org/assignments/language-subtag-registry/language-subtag-registry).

## Establecimiento de un idioma predeterminado

Para establecer un idioma predeterminado para la recopilación de datos, use la hoja de trabajo `settings` en su XLSForm:

```
| form_id   | version | default_language |
|-----------|---------|-------------------|
| test_form | 101     | French (fr)       |
```

## Características específicas de rtSurvey

### Cambio dinámico de idioma

rtSurvey permite a los usuarios cambiar de idioma dinámicamente durante la recopilación de datos:

- En la interfaz web, use el menú desplegable de idioma en la barra de navegación superior.
- En la aplicación móvil, acceda a las opciones de idioma a través del menú de configuración.

### Mensajes de validación específicos del idioma

rtSurvey amplía el soporte multilingüe a los mensajes de validación:

```
| type    | name | constraint | constraint_message::English (en) | constraint_message::Español (es) |
|---------|------|------------|----------------------------------|----------------------------------|
| integer | age  | . <= 150   | Age must be 150 or less          | La edad debe ser 150 o menos     |
```

### Soporte de idiomas RTL

Para idiomas de derecha a izquierda (RTL) como el árabe o el hebreo, rtSurvey ajusta automáticamente el diseño:

```
| type | name | label::English (en) | label::Arabic (ar) |
|------|------|---------------------|---------------------|
| text | name | Your name           | اسمك                |
```

### Apariencia específica del idioma

rtSurvey le permite especificar diferentes apariencias para diferentes idiomas:

```
| type | name | label::English (en) | label::Chinese (zh) | appearance::English (en) | appearance::Chinese (zh) |
|------|------|---------------------|---------------------|--------------------------|---------------------------|
| text | address | Address          | 地址                 | multiline                | textarea                  |
```

## Mejores prácticas para encuestas multilingües

1. **Nomenclatura coherente**: Use códigos de idioma coherentes en todo su formulario.
2. **Traducción profesional**: Emplee traductores profesionales familiarizados con el contexto de la encuesta.
3. **Notas de contexto**: Proporcione notas de contexto a los traductores para garantizar traducciones precisas.
4. **Pruebas**: Pruebe su formulario en todos los idiomas antes de su implementación.
5. **Soporte Unicode**: Asegúrese de que sus dispositivos de recopilación de datos admitan Unicode para escrituras no latinas.
6. **Medios específicos del idioma**: Use imágenes o audio culturalmente apropiados para cada idioma.
7. **Evite texto en imágenes**: Si usa imágenes con texto, cree imágenes separadas para cada idioma.

## Manejo de casos especiales

### Respuestas de idioma mixto

rtSurvey permite a los encuestados ingresar texto en cualquier escritura, independientemente del idioma del formulario seleccionado. Esto es útil para capturar nombres o direcciones en su escritura original.

### Tipos de preguntas específicas del idioma

Algunos tipos de preguntas pueden ser más apropiados para ciertos idiomas. rtSurvey le permite usar diferentes tipos de preguntas para diferentes idiomas:

```
| type::English (en) | type::Japanese (ja) | name | label::English (en) | label::Japanese (ja) |
|--------------------|---------------------|------|---------------------|----------------------|
| text               | select_one kanji    | name | Enter your name     | 名前を選んでください    |
```

## Exportación de datos multilingües

Al exportar datos de rtSurvey:

- Elija exportar en un idioma específico o incluir todas las versiones de idioma.
- Los metadatos del idioma se incluyen en la exportación, indicando qué idioma se usó para cada respuesta.

## Consideraciones de la aplicación móvil

- La aplicación móvil rtSurvey admite el cambio de idioma sin conexión.
- Asegúrese de que todos los archivos de idioma necesarios estén descargados antes de quedarse sin conexión.

## Limitaciones conocidas

- Algunas funciones avanzadas pueden no estar disponibles en todos los idiomas.
- Las traducciones extremadamente largas pueden afectar el diseño en pantallas más pequeñas.

Al aprovechar las capacidades multilingües de rtSurvey, puede crear encuestas inclusivas y accesibles que llegan a poblaciones diversas y proporcionan datos lingüísticamente precisos y de alta calidad.

rtSurvey le permite crear formularios y flujos de trabajo potentes para recopilar los datos que necesita dondequiera que estén. Puede:

1.  Crear formularios avanzados que incluyan fotos, ubicaciones GPS, lógica de salto,
    cálculos, conjuntos de datos externos, múltiples idiomas y mucho más.
2.  Recopilar datos sin conexión con la aplicación móvil o la aplicación web.
    Los formularios y envíos se sincronizan cuando se detecta conexión a Internet.
3.  Analizar con facilidad descargando sus datos como CSV o conectando rtSurvey
    a Excel, Power BI, Python o R para crear paneles de actualización en vivo.

Investigadores, equipos de campo y otros profesionales como usted utilizan rtSurvey
para recopilar sus datos importantes. Así es como comenzar.

## 1. Obtenga rtSurvey Cloud {#getting-started-rtCloud}

Para obtener rtSurvey Cloud, el método más rápido y sencillo es utilizar el servicio de alojamiento administrado oficial llamado [rtSurvey
Cloud](https://rtSurvey.com/#rtSurvey-cloud). Está disponible en el sitio web de rtSurvey y está construido sobre una infraestructura rápida, confiable y segura.

## 2. Suba su XLSForm a rtCloud o cree un formulario con el Constructor de formularios (Beta) {#getting-started-create-form}

1.  Cree una definición de formulario usando `XLSForm <xlsform>`{.interpreted-text
    role="doc"} o pruebe este formulario [All Widgets
    form](https://docs.google.com/spreadsheets/d/1af_Sl8A_L8_EULbhRLHVl8OclCfco09Hq2tqb9CslwQ/edit#gid=0).
2.  `Suba su XLSForm a rtCloud <rtCloud-forms-upload>`{.interpreted-text
    role="ref"} y publíquelo.

## 3. Obtenga la aplicación rtSurvey {#getting-started-get-collect}

Para descargar la aplicación rtSurvey, siga estos pasos según su dispositivo:

### Para dispositivos Android:
1. Visite [Google Play Store](https://play.google.com/store/apps/details?id=vn.rta.rtsurvey).
2. Busque "rtSurvey" en la barra de búsqueda.
3. Toque la aplicación con el logotipo de rtSurvey.
4. Haga clic en el botón "Instalar" para descargar e instalar la aplicación en su dispositivo Android.

### Para dispositivos iOS:
1. Abra [App Store](https://apps.apple.com/vn/app/rtsurvey/id1178851547) en su dispositivo iOS.
2. Busque "rtSurvey" en la pestaña de búsqueda.
3. Localice la aplicación con el logotipo de rtSurvey.
4. Toque el botón "Obtener" para descargar e instalar la aplicación en su dispositivo iOS.

Una vez descargada e instalada la aplicación, puede iniciarla y comenzar a utilizar rtSurvey para servicios de encuestas y análisis.

## 4. Conecte Collect a rtCloud {#getting-started-connect}

1.  `Cree un usuario de la aplicación <rtCloud-users-app-overview>`{.interpreted-text
    role="ref"} en rtCloud y
    `asigne su formulario a ese usuario <rtCloud-projects-form-access>`{.interpreted-text
    role="ref"}.
2.  Abra Collect, toque `Configurar con código QR`{.interpreted-text
    role="guilabel"} y escanee el código creado para su usuario de la aplicación.

## 5. Complete su formulario en Collect {#getting-started-fill-form}

1.  Seleccione `Completar formulario en blanco`{.interpreted-text role="guilabel"} para
    completar su formulario.
2.  Sus datos del formulario se enviarán automáticamente a rtCloud cuando termine.

## 6. Use sus datos en rtCloud {#getting-started-use-data}

1.  Inicie sesión en rtCloud y vea sus datos.
2.  Descargue sus datos como CSV o
    `visualícelos en Power BI <rtCloud-submissions-odata>`{.interpreted-text
    role="ref"}.

rtSurvey — це потужна платформа для створення форм і робочих процесів для ефективного збору даних. За допомогою rtSurvey ви можете:

1. Створювати складні форми з фотографіями, GPS-координатами, логікою пропуску, обчисленнями, зовнішніми наборами даних, підтримкою кількох мов тощо.
2. Збирати дані за допомогою мобільного або веб-додатку з автоматичною синхронізацією при наявності підключення до Інтернету.
3. Легко аналізувати дані, експортуючи до CSV або Stata, або підключаючи rtSurvey до Excel, Power BI, Python або R для створення динамічних дашбордів з оновленням у реальному часі.

Дослідники, польові команди та фахівці з різних галузей покладаються на rtSurvey для збору критично важливих даних. Ось як розпочати:

## 1. Доступ до rtSurvey Cloud {#getting-started-get-rtCloud}

Найшвидший спосіб розпочати — скористатись [rtSurvey Cloud](https://rtsurvey.com/#rtsurvey-cloud), нашим офіційним керованим хостингом. Він доступний через сайт rtSurvey та побудований на надійній, захищеній інфраструктурі. Як альтернатива, за бажанням ви можете розгорнути rtSurvey на власній інфраструктурі.

## 2. Створіть форму опитування {#getting-started-create-form}

1. Розробіть форму за допомогою `XLSForm` або скористайтеся нашим шаблоном [форми All Widgets](https://docs.google.com/spreadsheets/d/1af_Sl8A_L8_EULbhRLHVl8OclCfco09Hq2tqb9CslwQ/edit#gid=0).
2. Завантажте свій XLSForm до rtSurvey Cloud та опублікуйте, або скористайтесь Form Builder (Beta) для візуального проектування.

## 3. Встановіть додаток rtSurvey {#getting-started-get-collect}

Завантажте додаток rtSurvey на свій мобільний пристрій:

### Для пристроїв Android:
1. Відвідайте [Google Play Store](https://play.google.com/store/apps/details?id=vn.rta.rtsurvey).
2. Знайдіть «rtSurvey» і натисніть на додаток із логотипом rtSurvey.
3. Натисніть «Встановити» для завантаження та налаштування.

### Для пристроїв iOS:
1. Відкрийте [App Store](https://apps.apple.com/vn/app/rtsurvey/id1178851547) на своєму пристрої.
2. Знайдіть «rtSurvey» і знайдіть додаток із логотипом rtSurvey.
3. Натисніть «Отримати» для завантаження та встановлення.

## 4. Підключіть додаток rtSurvey до rtSurvey Cloud {#getting-started-connect}

1. Створіть обліковий запис:
   - Адміністратор rtSurvey Cloud може створювати облікові записи для анкетерів.
   - Як альтернатива, адміністратор може згенерувати URL для самостійної реєстрації анкетерів.
2. Відкрийте додаток rtSurvey та увійдіть із вашими обліковими даними.

## 5. Проведіть опитування {#getting-started-fill-form}

1. У додатку виберіть «Заповнити порожню форму», щоб розпочати нове опитування.
2. Заповніть форму з даними респондента.
3. Після завершення дані форми автоматично синхронізуються з rtSurvey Cloud при наявності підключення до Інтернету.

## 6. Аналізуйте свої дані в rtSurvey Cloud {#getting-started-use-data}

1. Увійдіть до rtSurvey Cloud для доступу до зібраних даних.
2. Завантажте дані у різних форматах, таких як CSV або Stata, для подальшого аналізу.
3. Використовуйте вбудовані інструменти аналізу або інтегруйтеся з вашим улюбленим програмним забезпеченням для аналізу даних.

Тип питання note у XLSForm та rtSurvey використовується для відображення тексту або медіа лише для читання респонденту опитування. Це не питання, що вимагає відповіді, а радше спосіб надання інформації, інструкцій або контексту в межах опитування.

## Базова специфікація XLSForm

| type | name | label |
|------|------|-------|
| note | info_text | This survey is about your reading habits. |

Для отримання додаткових відомостей про базовий тип питання note дивіться [специфікацію XLSForm](https://xlsform.org/en/#question-types).

## Використання

Питання типу note зазвичай використовуються для:

1. Надання інструкцій або контексту для наступних питань
2. Відображення обчислених результатів або зведень
3. Показу зображень або інших медіа
4. Розділення розділів опитування
5. Надання зворотного зв'язку на основі попередніх відповідей

## Найкращі практики

1. Тримайте текст note стислим та чітким для підтримання залученості респондентів.
2. Використовуйте форматування (жирний, курсив) для виділення важливої інформації.
3. Розгляньте використання медіа (зображення, аудіо) для покращення розуміння, де це доречно.
4. Використовуйте notes помірно, щоб уникнути захаращення опитування.

## Приклад використання

Ось приклад того, як можна використовувати питання note в опитуванні:

| type | name | label |
|------|------|-------|
| note | intro | Welcome to our reading habits survey. We'll ask about your preferences and reading frequency. |
| ... | ... | ... |
| calculate | books_per_month | ${fiction_books} + ${non_fiction_books} |
| note | reading_summary | You read approximately ${books_per_month} books per month. |

У цьому прикладі notes використовуються для введення в опитування та надання зведення обчислених результатів.

## Розширення rtSurvey

Хоча базова специфікація XLSForm для питань note є простою, rtSurvey може пропонувати додаткові функції або налаштування:

1. Форматування тексту
2. Підтримка вбудованих медіа (зображення, аудіо, відео)
3. Динамічний вміст на основі попередніх відповідей
4. Кастомні параметри стилізації

## Розширене використання

### Умовне відображення

Ви можете використовувати вирази актуальності для умовного показу notes:

| type | name | label | relevant |
|------|------|-------|----------|
| note | high_reader_note | You're an avid reader! | ${books_per_month} > 5 |

### Включення обчислень

Notes можуть включати обчислення для надання динамічного зворотного зв'язку:

| type | name | label |
|------|------|-------|
| note | reading_time | Based on your responses, you spend approximately ${books_per_month * 5} hours reading each month. |

## Обмеження

- Notes не збирають дані, тому їх не слід використовувати, коли потрібно збирати інформацію від респондентів.
- Надмірне використання notes може зробити опитування захаращеним або надто довгим.
- Деякі розширені параметри форматування або медіа можуть не підтримуватися на всіх пристроях або платформах.

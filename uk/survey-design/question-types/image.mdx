Тип питання image у XLSForm та rtSurvey дозволяє респондентам знімати та надсилати фотографії як частину своїх відповідей на опитування. Ця функція особливо корисна для збору візуальних даних, документування спостережень або надання доказів у польових опитуваннях.

## Базова специфікація XLSForm

| type  | name        | label                           |
|-------|-------------|--------------------------------|
| image | photo       | Take a photo of the location    |

Для отримання додаткових відомостей про базовий тип питання image дивіться [специфікацію XLSForm](https://xlsform.org/en/#question-types).

## Використання

Питання типу image зазвичай використовуються для:

1. Документування польових умов або спостережень
2. Захоплення візуальних доказів у дослідницьких дослідженнях
3. Збору фотографій до та після в оцінках впливу
4. Перевірки виконання завдань або присутності в місцях
5. Збору візуальних даних для дистанційного аналізу

## Найкращі практики

1. Надавайте чіткі інструкції щодо того, що слід сфотографувати.
2. Враховуйте наслідки для конфіденційності та інформуйте респондентів про те, як будуть використовуватися їх фотографії.
3. Будьте уважні до розмірів файлів та обмежень сховища, особливо для опитувань у районах з обмеженим підключенням до Інтернету.
4. Переконайтеся, що на пристрої достатньо місця для зберігання та надані дозволи для камери.

## Приклад використання

Ось приклад того, як можна використовувати питання image в опитуванні:

| type  | name           | label                                      | hint                                        |
|-------|----------------|--------------------------------------------|--------------------------------------------|
| image | storefront     | Take a photo of the store's entrance       | Ensure the store name is clearly visible    |

## Розширення rtSurvey

Хоча базова специфікація XLSForm для питань image є простою, rtSurvey може пропонувати додаткові функції або налаштування:

1. Налаштування якості зображення (наприклад, низька, середня, висока роздільна здатність)
2. Можливість додавати підписи або теги до зображень
3. Захоплення кількох зображень для одного питання
4. Інтеграція з рідною камерою пристрою або галереєю

## Обробка даних

Зображення, зібрані через цей тип питання, зазвичай:

1. Зберігаються у поширеному форматі зображень (наприклад, JPG, PNG)
2. Зберігаються поряд з іншими даними опитування, часто в окремій медіапапці
3. Доступні для перегляду та аналізу через платформу управління опитуваннями

## Міркування для аналізу

При використанні питань image врахуйте:

1. Як зображення будуть проаналізовані (наприклад, ручний перегляд, автоматизований аналіз зображень)
2. Додаткове місце для зберігання, необхідне для файлів зображень
3. Заходи конфіденційності та захисту даних для зберігання та обробки фотографій
4. Потенційна необхідність інструментів редагування або організації зображень у фазі аналізу

## Обмеження

- Файли зображень можуть бути великими, що може впливати на передачу та зберігання даних.
- Не всі пристрої можуть мати якісні камери або достатньо місця для зберігання.
- Аналіз великої кількості зображень може бути трудомістким.
- Можуть виникнути проблеми конфіденційності при захопленні зображень, особливо в громадських місцях.

**Webbox** вбудовує зовнішню веб-сторінку всередині опитування як **модальне спливаюче вікно** (iframe). Анкетер натискає кнопку в мітці або тексті нотатки, сторінка відкривається в повноекранному накладанні у формі, і після закриття він повертається точно туди, де був. Це дозволяє показувати довідкові матеріали, карти, дашборди або спеціальні інструменти без відкриття окремої вкладки браузера.

---

## Синтаксис

Вставте HTML-тег `<webbox>` безпосередньо у стовпець `label` або `note`:

```html
<webbox src='https://example.com/reference' title='Reference Guide'>Open Reference Guide</webbox>
```

| Атрибут | Опис |
|-----------|-------------|
| `src` | URL для завантаження в iframe. |
| `title` | Текст у заголовку модального вікна. |
| *(вміст)* | Мітка кнопки, що клікується, у полі опитування |

---

## Базовий приклад

| type | name | label |
|------|------|-------|
| note | ref_guide | `<webbox src='https://docs.example.com/field-guide' title='Field Guide'>Open Field Guide</webbox>` |

---

## Передача значень форми на вбудовану сторінку

| type | name | label | calculation |
|------|------|-------|-------------|
| calculate | webbox_url | | `concat('https://dashboard.example.com/household?id=', ${household_id})` |
| note | hh_dash | `<webbox src='${webbox_url}' title='Household Dashboard'>Open Dashboard</webbox>` |

---

## Взаємодія з повторами: кнопки видалення

Webbox також підтримує спеціальні теги дій для управління групами повторів:

```html
<delete-repeat-current>Remove this row</delete-repeat-current>
<delete-repeat-last>Remove last row</delete-repeat-last>
```

---

## Спілкування з вбудованою сторінкою (postMessage)

Iframe webbox та батьківська форма можуть спілкуватися за допомогою API `postMessage` браузера. Вбудована сторінка може відповідати:

- `delete-repeat-current` — ініціює видалення поточного екземпляру повтору
- `delete-repeat-last` — ініціює видалення останнього екземпляру повтору

---

## Найкращі практики

1. Використовуйте webbox для **довідкових матеріалів** (інструкції, таблиці пошуку, карти).
2. Переконайтеся, що вбудований URL доступний з мережі пристрою.
3. Зберігайте вбудовану сторінку зручною для мобільних пристроїв.
4. Використовуйте описові написи кнопок.

## Обмеження

- Потребує підключення до мережі для завантаження вбудованого URL.
- Деякі зовнішні сайти блокують вбудовування в iframe.
- Webbox є розширенням веб-форм rtSurvey та може не працювати в інших клієнтах, сумісних з ODK.

Модуль **Управління відправленнями** (доступний через кнопку **Data View** в розділі Form Family) дозволяє менеджерам проектів та супервайзерам безпосередньо взаємодіяти з вхідними необробленими даними. Він слугує єдиним робочим простором для перегляду відправлень анкетерів, відстеження ідентифікаторів пристроїв та виконання операцій контролю якості даних.

![Інтерфейс управління відправленнями](/images/manage_submissions.png)

## Огляд даних і стовпці

Таблиця даних динамічно відображає дані, зібрані для конкретної форми. Вона працює у двох основних режимах: **Official** (Завершені записи) та **Working** (Реальний час, незавершені записи).

### Ключові стовпці даних

Незалежно від користувацьких питань, визначених у формі, таблиця включає кілька стандартних стовпців метаданих для допомоги в аудиті:

- **Submit by:** Ідентифікує платформу походження відправлення (наприклад, FA для польового застосунку, WEB для веб-форми, RS для віддалених систем).
- **Detail:** Відкриває сфокусований, однозапис перегляд (значок пошуку) для перевірки кожної змінної та відповіді, відправленої для цього екземпляру.
- **iNote:** Дозволяє супервайзерам прикріплювати нотатки або внутрішні коментарі до конкретного запису без зміни зібраних даних (представлений значком олівця).
- **Date fields:** Мітки часу, що вказують, коли запис був ініційований, завершений або синхронізований.
- **Media attachments:** Прямі посилання-мініатюри на зображення, підписи або файли, зібрані під час опитування.
- **Repeat groups:** Спеціальні посилання для доступу до вкладених таблиць для повторюваних питань у батьківській формі.

## Дії з відправленнями

Для полегшення активного контролю якості даних інтерфейс надає випадаючий список команд, які можна виконати над вибраними записами:

- **Create a new instance:** Дозволяє адміністраторам вручну вводити новий запис опитування безпосередньо в базу даних.
- **Return instance:** Відхиляє відправлений запис та доручає анкетеру повторно перевірити або зібрати інформацію.
- **Follow up instance:** Позначає запис для подальшої уваги, зазвичай відправляючи сповіщення польовій команді для уточнення.
- **Export to Returned commands file / Follow-up commands package:** Генерує пакетні експорти (файли), що містять набори даних, спеціально позначені для повернень або подальших дій.
- **Convert to XML:** Перетворює структурований набір даних назад у необроблений формат XML для бекенд-аналізу або системної інтеграції.
- **Forward Instances:** (Доступно в режимі *Working*) Негайно передає незавершені дані на інший пристрій або користувача.
- **Delete:** Остаточно видаляє вибрані екземпляри з бази даних.

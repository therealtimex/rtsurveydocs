Experimente o rtSurvey sob diferentes perspetivas utilizando as nossas contas de demonstração. Cada conta está configurada com funções específicas para mostrar as funcionalidades e permissões associadas a cada tipo de utilizador num projeto de inquérito CAPI.

### Administrador de Demonstração
- **Nome de utilizador:** admin_demo
- **Palavra-passe:** AdminRtSurvey
- **Função:** Acesso total a todas as configurações do sistema, gestão de utilizadores e configurações de projeto.

### Gestor de Projeto de Demonstração
- **Nome de utilizador:** pm_demo
- **Palavra-passe:** PMRtSurvey
- **Função:** Gerir projetos, atribuir tarefas e supervisionar a implementação do inquérito e a recolha de dados.

### Designer de Inquérito de Demonstração
- **Nome de utilizador:** designer_demo
- **Palavra-passe:** DesignerRtSurvey
- **Função:** Criar e testar inquéritos usando o editor XLSForm e o construtor de formulários visual do rtSurvey.

### Enumerador de Campo de Demonstração
- **Nome de utilizador:** enumerator_demo
- **Palavra-passe:** EnumeratorRtSurvey
- **Função:** Realizar inquéritos no campo usando a aplicação móvel rtSurvey, recolher dados e sincronizar com o rtSurvey Cloud.

### Analista de Dados de Demonstração
- **Nome de utilizador:** analyst_demo
- **Palavra-passe:** AnalystRtSurvey
- **Função:** Analisar dados recolhidos, gerar relatórios e integrar com ferramentas de análise externas como Excel, Power BI, Python e R.

## Como Utilizar as Contas de Demonstração

1. **Selecionar uma Função:**
   Escolha a função de demonstração que pretende explorar na lista acima.

2. **Iniciar Sessão:**
   Use o nome de utilizador e a palavra-passe fornecidos para iniciar sessão no rtSurvey.

3. **Explorar Funcionalidades:**
   Navegue pela plataforma para compreender as funcionalidades disponíveis para a função selecionada.

4. **Comentários:**
   Valorizamos a sua opinião! Por favor, forneça comentários sobre a sua experiência para nos ajudar a melhorar o rtSurvey.

## Diretrizes de Segurança e Utilização

- Estas são contas de demonstração partilhadas. Por favor, não introduza informações sensíveis ou pessoais.
- As contas de demonstração têm acesso limitado para garantir a segurança dos dados e prevenir uso indevido.
- A utilização das contas de demonstração é monitorizada para manter a integridade do sistema.

Ao utilizar estas contas de demonstração, pode obter uma compreensão abrangente de como o rtSurvey funciona para diferentes funções de utilizador num projeto de inquérito CAPI. Explore como o rtSurvey pode beneficiar as suas necessidades de recolha e análise de dados em várias fases da implementação do inquérito.

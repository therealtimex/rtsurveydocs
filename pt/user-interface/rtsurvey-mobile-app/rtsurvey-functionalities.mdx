A Aplicação Móvel rtSurvey oferece um conjunto abrangente de funcionalidades concebidas para simplificar o processo de inquérito. Aqui estão as funcionalidades principais:

## Preencher Formulário
A funcionalidade Preencher Formulário é onde os enumeradores podem aceder e inserir dados em formulários de inquérito em branco. Esta funcionalidade permite uma recolha de dados eficiente e precisa no campo. Os pontos principais incluem:

1. Listagem de Formulários: Ao aceder à secção Preencher Formulário, os utilizadores são apresentados com uma lista de todos os formulários em branco disponíveis atribuídos a eles.

2. Download Automático de Formulários: Ao contrário de algumas outras ferramentas de inquérito, a aplicação móvel rtSurvey descarrega automaticamente os formulários cujo acesso é concedido ao utilizador pelo administrador do inquérito ou gestor de projeto. Isto elimina a necessidade de os enumeradores recuperarem manualmente os formulários em branco.

3. Entrada de Dados Direta: Os enumeradores podem selecionar um formulário da lista e começar a inserir respostas do inquérito diretamente na aplicação.

4. Atualizações em Tempo Real: À medida que novos formulários são atribuídos ou atualizações são feitas, a lista de formulários disponíveis é atualizada automaticamente, garantindo que os enumeradores tenham sempre acesso aos inquéritos mais atuais.

5. Capacidade Offline: Os formulários podem ser descarregados quando a conectividade à internet está disponível, permitindo aos enumeradores preenchê-los mesmo em áreas com pouca ou nenhuma cobertura de rede.

## Editar Formulário

A funcionalidade Editar Formulário no rtSurvey oferece uma abordagem abrangente e flexível para gerir instâncias de inquérito, diferenciando-se de outras aplicações CAPI. Esta funcionalidade garante a precisão e completude dos dados através de três separadores distintos:

1. **Guardado**:
   - Aceda e modifique instâncias de entrevista incompletas guardadas no dispositivo do enumerador.
   - Semelhante a aplicações CAPI tradicionais, permitindo aos utilizadores retomar e completar inquéritos inacabados.

2. **Devolvido** (Exclusivo do rtSurvey):
   - Edite instâncias de inquérito que foram previamente concluídas, finalizadas e submetidas ao servidor.
   - Exclusivo do rtSurvey, esta funcionalidade permite edições pós-submissão quando são necessárias informações adicionais ou correções.

3. **Encaminhado** (Exclusivo do rtSurvey):
   - Aceda e edite instâncias de inquérito originalmente criadas noutro dispositivo.
   - Esta funcionalidade inovadora suporta vários cenários:
     * Os supervisores podem rever e editar submissões de enumeradores.
     * Os utilizadores podem continuar o trabalho num dispositivo diferente se o dispositivo original for perdido ou danificado.
     * Permite processos de edição colaborativa e controlo de qualidade.

Benefícios Principais:
- Qualidade de dados melhorada através de múltiplas oportunidades de revisão e edição.
- Flexibilidade de fluxo de trabalho melhorada para equipas de campo e supervisores.
- Continuação perfeita do trabalho entre dispositivos, reduzindo o tempo de inatividade e os riscos de perda de dados.


## Enviar Formulário
Submeta formulários 100% completos para o servidor central. Esta funcionalidade permite a transmissão de dados em tempo real, permitindo análise e tomada de decisões imediatas.

## Notificações
Receba avisos e atualizações importantes do servidor. Isto mantém todos os membros da equipa informados sobre desenvolvimentos do projeto, alterações ou assuntos urgentes.

## Tarefas
Aceda e gira tarefas atribuídas pelo servidor. Esta funcionalidade ajuda a organizar a carga de trabalho e a priorizar atividades de inquérito para os enumeradores de campo.

## Relatórios
Visualize todos os relatórios enviados do servidor para o tablet. Esta funcionalidade permite aos utilizadores aceder aos resultados de análise e insights do projeto diretamente no seu dispositivo.

## Rever Formulário

A funcionalidade Rever Formulário no rtSurvey oferece um sistema abrangente para examinar e gerir instâncias de inquérito finalizadas, garantindo um controlo de qualidade robusto e verificação de dados. Esta funcionalidade está dividida em quatro separadores distintos, cada um servindo um propósito específico no processo de gestão de dados:

1. **Finalizado**:
   - Contém instâncias concluídas e finalizadas que ainda não foram submetidas ao servidor.
   - Permite verificações finais antes da submissão.

2. **Enviado**:
   - Contém instâncias finalizadas que foram submetidas com sucesso ao servidor.
   - Fornece um registo dos dados transmitidos.

3. **Transferido**:
   - Exibe instâncias concluídas que foram transferidas para outros dispositivos.
   - Facilita o rastreamento do movimento de dados entre dispositivos.

4. **Recebido**:
   - Mostra instâncias concluídas originalmente criadas noutro dispositivo e transferidas para o dispositivo atual.
   - Permite trabalho colaborativo e partilha de dados entre membros da equipa.

Funcionalidades Principais:
- **Acesso Apenas de Visualização**: Todas as instâncias nestes separadores são inicialmente apenas de visualização, preservando a integridade dos dados dos formulários finalizados.
- **Sistema de Pedido de Edição**: Os utilizadores podem solicitar a edição de uma instância se forem necessárias correções.
  - Os pedidos podem ser aprovados automática ou manualmente por Administradores ou Gestores de Projeto.
  - Uma vez aprovada, a instância torna-se editável, permitindo as modificações necessárias.

Benefícios:
- Melhora a qualidade dos dados através de múltiplas fases de revisão.
- Fornece uma trilha de auditoria clara das submissões e transferências de dados.
- Oferece flexibilidade na gestão de dados enquanto mantém o controlo sobre os dados finalizados.
- Suporta fluxos de trabalho colaborativos e processos de garantia de qualidade.

Este sistema avançado de Revisão de Formulários distingue o rtSurvey ao oferecer uma abordagem estruturada para gerir dados finalizados, garantindo precisão e permitindo edições pós-finalização controladas quando necessário. Equilibra a integridade dos dados com a necessidade de correções ocasionais, tornando-o uma ferramenta inestimável para projetos de inquérito que requerem altos níveis de qualidade de dados e responsabilização.

## Mapa
Utilize a funcionalidade GPS para identificar a localização exata onde a entrevista está a ser realizada. Esta funcionalidade melhora a precisão dos dados e ajuda na análise espacial dos resultados do inquérito.

## Sair
Feche a aplicação sem terminar sessão na conta do rtSurvey. Isto permite a reentrada rápida na aplicação sem a necessidade de autenticação repetida.

Estas funcionalidades trabalham em conjunto para criar uma ferramenta de inquérito móvel poderosa e fácil de usar que atende a várias funções dentro do processo de inquérito, desde a recolha de dados até à análise e gestão de projetos.

O rtCloud é o componente de servidor robusto do ecossistema rtSurvey, concebido para agilizar a recolha, gestão e análise de dados. Como hub central das operações rtSurvey, o rtCloud oferece um conjunto abrangente de funcionalidades para suportar projetos de inquérito complexos e estudos longitudinais.

## Funcionalidades Principais

### Gestão de Projetos
- Organize todos os aspetos do seu projeto de inquérito num único local
- Gira funções de utilizadores, formulários, análises, entregas e permissões dentro de cada projeto

### Gestão de Utilizadores e Segurança
- Crie e gira contas de utilizadores com permissões baseadas em funções
- Garanta a segurança dos dados e o controlo de acesso em todos os níveis

### Gestão de Formulários
- Carregue e gira XLSForms diretamente
- Suporte para atualizações de versão de formulários, incluindo pequenas alterações e mudanças estruturais
- Anexe multimédia ou dados adicionais a formulários
- Capacidade de eliminação verdadeira de formulários para controlo total sobre os seus instrumentos de inquérito

### Recolha de Dados e Gestão de Submissões
- Integração perfeita com a aplicação móvel rtSurvey, aplicação web e formulário web
- Suporte para submissões de utilizadores autenticados e links públicos anónimos
- Gerir multimédia de submissões e anexos de dados
- Pré-visualização de tabela interativa dos dados de submissão para insights rápidos

### Fluxos de Trabalho Avançados de Submissão
- Devolver submissões aos dispositivos dos utilizadores para mais edição ou verificação
- Encaminhar submissões para outros dispositivos, permitindo fluxos de trabalho colaborativos e controlo de qualidade

### Gestão de Dados Longitudinais
- Gerir eficientemente medições repetidas e estudos de longo prazo
- Acompanhar alterações e atualizações aos dados dos participantes ao longo do tempo

### Conectividade Flexível
- Permitir à Aplicação Móvel rtSurvey ligar para descarregar formulários e carregar submissões
- Suporte à recolha de dados offline com sincronização perfeita quando a conectividade é restaurada

## Como o rtCloud se Destaca

Embora inspirado por outras plataformas de recolha de dados, o rtCloud oferece funcionalidades únicas que o diferenciam:

1. **Eliminação Verdadeira de Formulários**: Ao contrário de algumas plataformas, o rtCloud permite a remoção completa de formulários quando necessário.

2. **Fluxos de Trabalho de Submissão Flexíveis**: A capacidade de devolver e encaminhar submissões permite processos complexos de revisão de dados e controlo de qualidade.

3. **Gestão de Projetos Integrada**: O rtCloud vai além da gestão de formulários e dados, oferecendo ferramentas para organizar todos os aspetos do seu projeto de inquérito.

4. **Suporte Direto a XLSForm**: Carregue os seus XLSForms diretamente sem conversão, simplificando o processo de criação de formulários.

5. **Sistema de Permissões Abrangente**: Controlo detalhado sobre o acesso e capacidades dos utilizadores dentro dos projetos.

## Começar com o rtCloud

Para começar a usar o rtCloud nos seus projetos de inquérito:

1. Configure o seu servidor rtCloud ou contacte o rtSurvey para soluções alojadas.
2. Crie o seu primeiro projeto e convide membros da equipa.
3. Carregue os seus XLSForms e configure os seus fluxos de trabalho de recolha de dados.
4. Ligue as suas aplicações móveis rtSurvey e comece a recolher dados.

O rtCloud capacita investigadores, organizações e equipas de recolha de dados para gerir projetos de inquérito complexos com facilidade, segurança e flexibilidade. Quer esteja a realizar um inquérito único ou um estudo longitudinal multi-anual, o rtCloud fornece as ferramentas de que necessita para ter sucesso.

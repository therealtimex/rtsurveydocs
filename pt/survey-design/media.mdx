O rtSurvey suporta integração de multimédia rica em inquéritos, permitindo-lhe melhorar os seus questionários com imagens, áudio e vídeo. Esta funcionalidade pode melhorar significativamente a experiência do respondente e a qualidade dos dados recolhidos.

## Tipos de Multimédia Suportados

O rtSurvey suporta os seguintes tipos de multimédia:
- Imagens (jpg, png, gif)
- Áudio (mp3, wav)
- Vídeo (mp4, webm)

## Adicionar Multimédia ao Seu Inquérito

Para incluir multimédia no seu formulário rtSurvey, use as seguintes colunas no seu XLSForm:

- `image`: Para exibir imagens
- `audio`: Para reproduzir ficheiros de áudio
- `video`: Para reproduzir ficheiros de vídeo

Exemplo:

```
| type | name          | label         | image        | audio       | video       |
|------|---------------|---------------|--------------|-------------|-------------|
| note | media_example | Exemplo de multimédia | example.jpg  | sound.mp3   | clip.mp4    |
```

## Gestão de Ficheiros de Multimédia

### Inquéritos baseados na web
Para inquéritos baseados na web, o rtSurvey fornece uma interface de gestão de multimédia onde pode carregar e organizar os seus ficheiros de multimédia. Estes ficheiros ficam então automaticamente disponíveis para uso nos seus inquéritos.

### Aplicação móvel
Ao usar a aplicação móvel rtSurvey:
1. Coloque os seus ficheiros de multimédia na pasta `/rtSurvey/forms/[form-name]-media/` no seu dispositivo.
2. Referencie o nome exato do ficheiro no seu XLSForm.

## Funcionalidades Específicas do rtSurvey

### Carregamento Dinâmico de Multimédia
O rtSurvey suporta carregamento dinâmico de multimédia baseado nas respostas do inquérito:

```
| type         | name      | label              | image                    |
|--------------|-----------|--------------------|--------------------------| 
| select_one species | animal | Selecione um animal | ${animal}.jpg            |
```

### Multimédia nas Opções de Escolha
O rtSurvey permite-lhe usar multimédia nas opções de escolha para perguntas de seleção:

```
| type                | name    | label           | media::image |
|---------------------|---------|-----------------|--------------|
| select_one_from_file animals | Escolha um animal |              |
```

Na folha choices:
```
| list_name | name  | label | media::image |
|-----------|-------|-------|--------------|
| animals   | dog   | Cão   | dog.jpg      |
| animals   | cat   | Gato   | cat.jpg      |
```

O tipo de pergunta note em XLSForms e rtSurvey é usado para exibir texto ou multimédia apenas leitura ao respondente do inquérito. Não é uma pergunta que requer resposta, mas sim uma forma de fornecer informação, instruções ou contexto dentro do inquérito.

## Especificação XLSForm Básica

| type | name | label |
|------|------|-------|
| note | info_text | Este inquérito é sobre os seus hábitos de leitura. |

Para mais detalhes sobre o tipo de pergunta note básico, consulte a [especificação XLSForm](https://xlsform.org/en/#question-types).

## Utilizações

As perguntas note são comummente usadas para:

1. Fornecer instruções ou contexto para perguntas seguintes
2. Exibir resultados calculados ou resumos
3. Mostrar imagens ou outra multimédia
4. Separar secções de um inquérito
5. Dar feedback baseado em respostas anteriores

## Melhores Práticas

1. Mantenha o texto da nota conciso e claro para manter o envolvimento do respondente.
2. Use formatação (negrito, itálico) para enfatizar informação importante.
3. Considere usar multimédia (imagens, áudio) para melhorar a compreensão quando apropriado.
4. Use notas com moderação para evitar sobrecarregar o inquérito.

## Exemplo de Utilização

Aqui está um exemplo de como pode usar perguntas note num inquérito:

| type | name | label |
|------|------|-------|
| note | intro | Bem-vindo ao nosso inquérito sobre hábitos de leitura. Vamos perguntar sobre as suas preferências e frequência de leitura. |
| ... | ... | ... |
| calculate | books_per_month | ${fiction_books} + ${non_fiction_books} |
| note | reading_summary | Lê aproximadamente ${books_per_month} livros por mês. |

## Extensões rtSurvey

Embora a especificação XLSForm básica para perguntas note seja direta, o rtSurvey pode oferecer funcionalidades adicionais:

1. Formatação de texto enriquecido
2. Suporte a multimédia incorporada (imagens, áudio, vídeo)
3. Conteúdo dinâmico baseado em respostas anteriores
4. Opções de estilo personalizadas

## Utilização Avançada

### Exibição Condicional

Pode usar expressões de relevância para mostrar notas condicionalmente:

| type | name | label | relevant |
|------|------|-------|----------|
| note | high_reader_note | É um leitor ávido! | ${books_per_month} > 5 |

### Incluir Cálculos

As notas podem incluir cálculos para fornecer feedback dinâmico:

| type | name | label |
|------|------|-------|
| note | reading_time | Com base nas suas respostas, passa aproximadamente ${books_per_month * 5} horas a ler cada mês. |

## Limitações

- As notas não recolhem dados, por isso não devem ser usadas quando precisa de recolher informação dos respondentes.
- O uso excessivo de notas pode tornar um inquérito confuso ou excessivamente longo.
- Algumas opções avançadas de formatação ou multimédia podem não ser suportadas em todos os dispositivos ou plataformas.

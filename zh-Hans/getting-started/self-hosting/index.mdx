使用 Docker Compose 在您自己的基础设施上运行 rtCloud。自托管让您完全拥有数据、网络和部署环境——非常适合有数据驻留要求、隔离网络或自定义基础设施需求的组织。

## 什么是 rtCloud 自托管？

rtCloud 自托管是一个官方 Docker 镜像，将整个 rtCloud 平台打包到一个可移植的容器堆栈中，您可以在任何 Linux 服务器上运行。该堆栈包括：

| 服务 | 描述 |
|---------|-------------|
| **rtCloud 应用** | Apache 2.4 + PHP 7.4 网页应用，内置后台队列（Beanstalkd）、分析服务器（Shiny）和计划任务 |
| **MySQL 8.0** | 存储所有应用和调查数据的关系型数据库 |
| **Keycloak** *（可选）* | 用于企业身份管理的内嵌单点登录服务器 |

## 何时选择自托管

在以下情况下，自托管是正确选择：

- 需要**数据主权**——所有数据保留在您自己的基础设施内
- 在**隔离或受限网络**中运行，无法访问外部云端
- 有**合规要求**（GDPR、HIPAA、政府数据政策）要求本地存储
- 需要与**内部身份提供商**（Active Directory、LDAP、SAML）集成
- 想要**自定义资源**——按您的条件分配 CPU、RAM 和存储

## 架构概述

部署以一组 Docker 容器的形式运行，通过内部网络连接：

```
┌────────────────────────────────────────┐
│            rtcloud-app                 │
│  Apache 2.4 (port 80)                  │
│  PHP 7.4 application                   │
│  Beanstalkd queue (internal)           │
│  Shiny Server (port 3838)              │
│  Cron scheduler                        │
└─────────────────┬──────────────────────┘
                  │ rtcloud-net (bridge)
┌─────────────────▼──────────────────────┐
│            rtcloud-mysql               │
│  MySQL 8.0 (port 3306, internal only)  │
└────────────────────────────────────────┘
```

启用 SSO 时，另一个容器将并行运行：

```
┌─────────────────────────────────────────┐
│            rtcloud-keycloak             │
│  Keycloak (port 8080, internal only)    │
│  Admin UI (port 9000, internal only)    │
└─────────────────────────────────────────┘
```

所有容器通过隔离的 Docker 桥接网络通信。只有网页应用端口和（可选的）Shiny 分析端口对主机开放。

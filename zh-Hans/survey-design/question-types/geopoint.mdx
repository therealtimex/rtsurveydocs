XLSForm 和 rtSurvey 中的 geopoint 题目类型使用设备的 GPS 或其他位置服务收集地理坐标。此功能在绘制调查回答地图、跟踪现场活动或将数据与特定位置关联时特别有用。

## 基本 XLSForm 规范

| type     | name        | label                           |
|----------|-------------|--------------------------------|
| geopoint | location    | 记录当前位置     |

有关基本 geopoint 题目类型的更多详情，请参阅 [XLSForm 规范](https://xlsform.org/en/#question-types)。

## 用途

Geopoint 题目通常用于：

1. 地理绘制调查回答
2. 验证现场活动的位置
3. 追踪枚举员的路线
4. 将环境或社会数据与特定位置关联
5. 在地理分析中计算距离或面积

## 最佳实践

1. 确保设备已启用位置服务并授予权限。
2. 留出足够时间让 GPS 获取准确定位。
3. 考虑隐私影响并告知受访者位置数据收集。
4. 与其他题目类型结合使用，为位置数据提供上下文。

## 使用示例

以下是您可能在调查中使用 geopoint 题目的示例：

| type     | name           | label                                      | hint                                        |
|----------|----------------|--------------------------------------------|--------------------------------------------|
| geopoint | sample_location| 记录样品采集的位置 | 站在开阔区域以获得更好的 GPS 信号 |

## rtSurvey 扩展

虽然 geopoint 题目的基本 XLSForm 规范很简单，但 rtSurvey 可能提供额外功能或自定义选项：

1. 地图集成，用于视觉确认捕获的位置
2. 精度阈值设置
3. 手动输入坐标的选项
4. 与离线地图集成，适用于偏远地区

## 数据格式

Geopoint 数据通常存储为四个空格分隔值的字符串：

```
latitude longitude altitude accuracy
```

例如：
```
41.40338 2.17403 30.5 10
```

## 分析注意事项

使用 geopoint 题目时，请考虑：

1. 如何可视化地理数据（例如，地图软件）
2. 收集坐标的精度及其对分析的影响
3. 处理位置数据的隐私和数据保护措施
4. 与 GIS（地理信息系统）工具的潜在集成

## 限制

- 精度可能因设备和环境条件而异。
- 在室内位置或有障碍物的区域，GPS 信号可能较弱或不可用。
- 收集位置数据可能会显著影响设备电池寿命。
- 收集精确位置数据可能涉及隐私问题。

XLSForm 和 rtSurvey 中的 barcode 题目类型使用户能够在调查中直接扫描和捕获条形码数据。此功能在需要快速准确地输入编码信息的场景中特别有用，例如库存管理、产品跟踪等。

## 基本 XLSForm 规范

| type    | name          | label                   |
|---------|---------------|-------------------------|
| barcode | product_code  | 扫描产品条形码|

有关基本 barcode 题目类型的更多详情，请参阅 [XLSForm 规范](https://xlsform.org/en/#question-types)。

## 用途

条形码题目通常用于：

1. 库存调查中的产品识别
2. 现场作业中的资产追踪
3. 活动中的票务或身份验证
4. 编码信息的快速数据录入

## rtSurvey 扩展

虽然 barcode 题目的基本 XLSForm 规范很简单，但 rtSurvey 可能提供额外功能或自定义选项，包括：

1. 支持多种条形码格式（例如，二维码、UPC、EAN）
2. 与设备摄像头集成进行条形码扫描
3. 在条形码损坏或无法扫描时的手动输入选项

## 最佳实践

1. 确保适当的照明条件以准确扫描条形码。
2. 向用户提供关于如何定位设备进行扫描的清晰说明。
3. 包含手动输入选项作为扫描困难时的后备方案。
4. 在部署调查之前，使用各种设备和条形码类型测试条形码扫描功能。

## 限制

- 条形码扫描精度可能因设备的摄像头质量和环境条件而异。
- 某些旧款或低端设备可能不支持条形码扫描。
- 某些条形码类型可能不受支持，取决于实现方式。

## 使用示例

以下是您可能在库存调查中使用条形码题目的示例：

| type    | name          | label                   | hint                                      |
|---------|---------------|-------------------------|-------------------------------------------|
| barcode | product_code  | 扫描产品条形码| 将条形码放置在框架内     |
| integer | quantity      | 输入产品数量  |                                           |
| note    | confirmation  | 已扫描产品：${product_code}。数量：${quantity} |           |

在此示例中，调查捕获产品的条形码，询问数量，然后显示包含扫描信息的确认注释。

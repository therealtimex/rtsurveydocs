rtSurvey ist sowohl für Android- als auch für iOS-Geräte verfügbar, sodass Sie Umfragen durchführen und Daten auf einer Vielzahl von mobilen Plattformen erfassen können. Befolgen Sie diese Schritte, um rtSurvey auf Ihrem Gerät zu installieren.

## Systemanforderungen

Stellen Sie vor der Installation sicher, dass Ihr Gerät die folgenden Anforderungen erfüllt:

- Für Android: Android 7.0 oder höher
- Für iOS: iOS 11.0 oder höher
- Stabile Internetverbindung für den ersten Download und Updates

## Installation auf Android

1. Öffnen Sie den Google Play Store auf Ihrem Android-Gerät.
2. Geben Sie in der Suchleiste "rtSurvey" ein oder nutzen Sie diesen Direktlink: [rtSurvey im Google Play Store](https://play.google.com/store/apps/details?id=vn.rta.rtsurvey&hl=ln&gl=US)
3. Tippen Sie in den Suchergebnissen auf die rtSurvey-App.
4. Drücken Sie die Schaltfläche "Installieren".
5. Warten Sie, bis der Download und die Installation abgeschlossen sind.
6. Nach der Installation können Sie die App vom Startbildschirm oder über das App-Menü Ihres Geräts öffnen.

## Installation auf iOS

1. Öffnen Sie den App Store auf Ihrem iOS-Gerät.
2. Tippen Sie auf das Suchsymbol und geben Sie "rtSurvey" ein oder nutzen Sie diesen Direktlink: [rtSurvey im App Store](https://apps.apple.com/vn/app/rtsurvey/id1178851547)
3. Tippen Sie in den Suchergebnissen auf die rtSurvey-App.
4. Drücken Sie die Schaltfläche "Laden" oder das Wolken-Symbol, um den Download zu starten.
5. Gegebenenfalls müssen Sie sich mit Face ID, Touch ID oder Ihrem Apple-ID-Passwort authentifizieren.
6. Warten Sie, bis der Download und die Installation abgeschlossen sind.
7. Nach der Installation erscheint das App-Symbol auf Ihrem Startbildschirm.

## Fehlerbehebung bei Installationsproblemen

Falls Probleme während der Installation auftreten:

1. Überprüfen Sie Ihre Internetverbindung und versuchen Sie es erneut.
2. Stellen Sie sicher, dass Sie genügend Speicherplatz auf Ihrem Gerät haben.
3. Starten Sie Ihr Gerät neu und versuchen Sie die Installation erneut.
4. Für Android: Löschen Sie den Cache und die Daten des Google Play Store in den Geräteeinstellungen.
5. Für iOS: Melden Sie sich von Ihrer Apple-ID ab und wieder an.

Falls die Probleme weiterhin bestehen, besuchen Sie die rtSurvey-Support-Website oder kontaktieren Sie Ihren Systemadministrator.

## rtSurvey aktualisieren

Um sicherzustellen, dass Sie die neuesten Funktionen und Fehlerbehebungen haben:

- Auf Android: Aktivieren Sie automatische Updates im Google Play Store oder aktualisieren Sie die App manuell.
- Auf iOS: Schalten Sie automatische Updates in den App Store-Einstellungen ein oder aktualisieren Sie manuell.

Regelmäßige Updates helfen dabei, die Leistung und Sicherheit der App zu gewährleisten.

Nachdem Sie rtSurvey erfolgreich installiert haben, können Sie es für Ihre Datenerfassungsanforderungen nutzen. Der nächste Abschnitt führt Sie durch die Verbindung der App mit einem Server.

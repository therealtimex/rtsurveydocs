Die mobile rtSurvey-App bietet eine umfassende Reihe von Funktionen, die darauf ausgelegt sind, den Umfrageprozess zu optimieren. Hier sind die wichtigsten Funktionalitäten:

## Formular ausfüllen
Die Funktion "Fill Form" (Formular ausfüllen) ist der Ort, an dem Enumeratoren auf leere Umfrageformulare zugreifen und Daten eingeben können. Zu den Eckpunkten gehören:

1. Formularliste: Beim Aufrufen des Bereichs wird eine Liste aller verfügbaren leeren Formulare angezeigt, die dem Benutzer zugewiesen wurden.

2. Automatischer Formulardownload: Im Gegensatz zu vielen anderen Umfragetools lädt die mobile rtSurvey-App Formulare automatisch herunter, auf die der Administrator oder Projektmanager dem Benutzer Zugriff gewährt hat.

3. Direkte Dateneingabe: Enumeratoren können ein Formular aus der Liste auswählen und Antworten direkt in der App eingeben.

4. Echtzeit-Updates: Die Liste der verfügbaren Formulare wird automatisch aktualisiert, wenn neue Formulare zugewiesen oder Änderungen vorgenommen werden.

5. Offline-Fähigkeit: Formulare können bei bestehender Internetverbindung heruntergeladen werden, sodass sie auch in Gebieten ohne Netzabdeckung ausgefüllt werden können.

## Formular bearbeiten

Die Funktionalität "Edit Form" (Formular bearbeiten) in rtSurvey bietet einen flexiblen Ansatz zur Verwaltung von Umfrageinstanzen über drei Registerkarten:

1. **Gespeichert**: 
   - Zugriff auf unvollständige Interviews, die auf dem Gerät des Enumerators gespeichert sind.
   - Ermöglicht das Fortsetzen und Abschließen angefangener Umfragen.

2. **Zurückgegeben** (Exklusiv bei rtSurvey):
   - Bearbeiten von Umfrageinstanzen, die bereits abgeschlossen, finalisiert und an den Server übermittelt wurden.
   - Dies ermöglicht Korrekturen nach der Übermittlung, falls zusätzliche Informationen erforderlich sind.

3. **Weitergeleitet** (Exklusiv bei rtSurvey):
   - Zugriff auf Umfrageinstanzen, die ursprünglich auf einem anderen Gerät erstellt wurden.
   - Unterstützt Szenarien wie die Überprüfung durch Vorgesetzte oder das Fortsetzen der Arbeit auf einem neuen Gerät bei Verlust oder Beschädigung.

Hauptvorteile:
- Erhöhte Datenqualität durch mehrfache Überprüfungsmöglichkeiten.
- Verbesserte Flexibilität im Workflow für Außendienstteams und Supervisoren.
- Nahtlose Fortführung der Arbeit über Gerätegrenzen hinweg.

## Formular senden
Übermitteln Sie zu 100 % ausgefüllte Formulare an den zentralen Server für eine sofortige Analyse.

## Benachrichtigungen
Erhalten Sie wichtige serverbasierte Mitteilungen über Projektentwicklungen oder dringende Angelegenheiten.

## Aufgaben
Verwalten Sie vom Server zugewiesene Aufgaben, um das Arbeitspensum zu organisieren und Umfrageaktivitäten zu priorisieren.

## Berichte
Rufen Sie Analyseergebnisse und Projekteinblicke direkt auf Ihrem Tablet ab.

## Formular prüfen

Das System "Review Form" (Formular prüfen) dient der Qualitätssicherung und ist in vier Registerkarten unterteilt:

1. **Finalisiert**:
   - Enthält abgeschlossene Instanzen, die noch nicht an den Server gesendet wurden, für eine letzte Kontrolle.

2. **Gesendet**:
   - Archiv der erfolgreich an den Server übermittelten Instanzen.

3. **Übertragen**:
   - Zeigt Instanzen an, die an andere Geräte übertragen wurden.

4. **Empfangen**:
   - Zeigt Instanzen an, die von anderen Geräten empfangen wurden.

Wichtige Merkmale:
- **Nur-Lese-Zugriff**: Instanzen sind standardmäßig schreibgeschützt, um die Datenintegrität zu wahren.
- **Bearbeitungsanfrage-System**: Benutzer können eine Bearbeitung beantragen. Nach Genehmigung durch den Administrator wird die Instanz wieder editierbar.

## Karte
Nutzen Sie die GPS-Funktion, um den genauen Standort des Interviews zu bestimmen, was räumliche Analysen ermöglicht.

## Beenden
Schließen Sie die App, ohne sich abzumelden, um einen schnellen Wiedereinstieg ohne erneute Authentifizierung zu ermöglichen.

Diese Funktionen machen rtSurvey zu einem leistungsstarken und benutzerfreundlichen Werkzeug für alle Beteiligten am Umfrageprozess.

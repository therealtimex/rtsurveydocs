rtSurvey ช่วยให้คุณสร้างแบบฟอร์มและกระบวนการทำงานที่ทรงพลังเพื่อเก็บข้อมูลที่คุณต้องการไม่ว่าจะอยู่ที่ใด คุณสามารถ:

1.  สร้างแบบฟอร์มที่ทรงพลังซึ่งรวมถึงรูปภาพ ตำแหน่ง GPS ตรรกะการข้ามคำถาม
    การคำนวณ ชุดข้อมูลภายนอก หลายภาษา และอื่นๆ อีกมากมาย
2.  เก็บข้อมูลแบบออฟไลน์ด้วยแอปมือถือหรือแอปเว็บ
    แบบฟอร์มและการส่งข้อมูลจะซิงค์เมื่อมีการเชื่อมต่ออินเทอร์เน็ต
3.  วิเคราะห์ข้อมูลได้อย่างง่ายดายโดยดาวน์โหลดข้อมูลเป็น CSV หรือเชื่อมต่อ rtSurvey
    กับ Excel, Power BI, Python หรือ R เพื่อสร้างแดชบอร์ดที่อัปเดตสด

นักวิจัย ทีมภาคสนาม และผู้เชี่ยวชาญอื่นๆ เช่นเดียวกับคุณใช้ rtSurvey
เพื่อเก็บข้อมูลสำคัญของพวกเขา นี่คือวิธีเริ่มต้น

## 1. รับ rtSurvey Cloud {#getting-started-rtCloud}

เพื่อรับ rtSurvey Cloud วิธีที่รวดเร็วและง่ายที่สุดคือการใช้บริการโฮสติ้งที่มีการจัดการอย่างเป็นทางการที่เรียกว่า [rtSurvey
Cloud](https://rtSurvey.com/#rtSurvey-cloud) มีให้บริการบนเว็บไซต์ของ rtSurvey และสร้างบนโครงสร้างพื้นฐานที่รวดเร็ว เชื่อถือได้ และปลอดภัย

## 2. อัปโหลด XLSForm ของคุณไปยัง rtCloud หรือสร้างแบบฟอร์มโดยใช้ Form Builder (เบต้า) {#getting-started-create-form}

1.  สร้างนิยามแบบฟอร์มโดยใช้ `XLSForm <xlsform>`{.interpreted-text
    role="doc"} หรือลองใช้แบบฟอร์ม [All Widgets](https://docs.google.com/spreadsheets/d/1af_Sl8A_L8_EULbhRLHVl8OclCfco09Hq2tqb9CslwQ/edit#gid=0)
2.  `อัปโหลด XLSForm ของคุณไปยัง rtCloud <rtCloud-forms-upload>`{.interpreted-text
    role="ref"} และเผยแพร่

## 3. รับแอป rtSurvey {#getting-started-get-collect}

เพื่อดาวน์โหลดแอป rtSurvey ให้ทำตามขั้นตอนเหล่านี้ตามอุปกรณ์ของคุณ:

### สำหรับอุปกรณ์ Android:
1. ไปที่ [Google Play Store](https://play.google.com/store/apps/details?id=vn.rta.rtsurvey)
2. ค้นหา "rtSurvey" ในแถบค้นหา
3. แตะที่แอปที่มีโลโก้ rtSurvey
4. คลิกปุ่ม "ติดตั้ง" เพื่อดาวน์โหลดและติดตั้งแอปบนอุปกรณ์ Android ของคุณ

### สำหรับอุปกรณ์ iOS:
1. เปิด [App Store](https://apps.apple.com/vn/app/rtsurvey/id1178851547) บนอุปกรณ์ iOS ของคุณ
2. ค้นหา "rtSurvey" ในแท็บค้นหา
3. ค้นหาแอปที่มีโลโก้ rtSurvey
4. แตะปุ่ม "รับ" เพื่อดาวน์โหลดและติดตั้งแอปบนอุปกรณ์ iOS ของคุณ

เมื่อดาวน์โหลดและติดตั้งแอปแล้ว คุณสามารถเปิดใช้งานและเริ่มใช้ rtSurvey สำหรับบริการสำรวจและวิเคราะห์ข้อมูลได้

## 4. เชื่อมต่อ Collect กับ rtCloud {#getting-started-connect}

1.  `สร้าง App User <rtCloud-users-app-overview>`{.interpreted-text
    role="ref"} ใน rtCloud และ
    `กำหนดแบบฟอร์มให้ผู้ใช้คนนั้น <rtCloud-projects-form-access>`{.interpreted-text
    role="ref"}
2.  เปิด Collect แตะ `กำหนดค่าด้วยรหัส QR`{.interpreted-text
    role="guilabel"} และสแกนรหัสที่สร้างขึ้นสำหรับ App User ของคุณ

## 5. กรอกแบบฟอร์มใน Collect {#getting-started-fill-form}

1.  เลือก `กรอกแบบฟอร์มว่าง`{.interpreted-text role="guilabel"} เพื่อ
    กรอกแบบฟอร์มของคุณ
2.  ข้อมูลแบบฟอร์มของคุณจะถูกส่งไปยัง rtCloud โดยอัตโนมัติเมื่อคุณ
    เสร็จสิ้น

## 6. ใช้ข้อมูลของคุณใน rtCloud {#getting-started-use-data}

1.  เข้าสู่ระบบ rtCloud และดูข้อมูลของคุณ
2.  ดาวน์โหลดข้อมูลของคุณเป็น CSV หรือ
    `แสดงผลใน Power BI <rtCloud-submissions-odata>`{.interpreted-text
    role="ref"}

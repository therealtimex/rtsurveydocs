สัมผัสประสบการณ์ rtSurvey จากมุมมองต่างๆ โดยใช้บัญชีสาธิตของเรา แต่ละบัญชีถูกตั้งค่าด้วยบทบาทเฉพาะเพื่อแสดงฟังก์ชันการทำงานและสิทธิ์ที่เกี่ยวข้องกับผู้ใช้แต่ละประเภทในโครงการสำรวจ CAPI

### ผู้ดูแลระบบสาธิต
- **ชื่อผู้ใช้:** admin_demo
- **รหัสผ่าน:** AdminRtSurvey
- **บทบาท:** การเข้าถึงการตั้งค่าระบบทั้งหมด การจัดการผู้ใช้ และการกำหนดค่าโครงการ

### ผู้จัดการโครงการสาธิต
- **ชื่อผู้ใช้:** pm_demo
- **รหัสผ่าน:** PMRtSurvey
- **บทบาท:** จัดการโครงการ กำหนดงาน และดูแลการใช้งานแบบสำรวจและการเก็บข้อมูล

### นักออกแบบแบบสำรวจสาธิต
- **ชื่อผู้ใช้:** designer_demo
- **รหัสผ่าน:** DesignerRtSurvey
- **บทบาท:** ออกแบบและทดสอบแบบสำรวจโดยใช้โปรแกรมแก้ไข XLSForm และเครื่องมือสร้างแบบฟอร์มภาพของ rtSurvey

### ผู้ถามแบบสอบถามภาคสนามสาธิต
- **ชื่อผู้ใช้:** enumerator_demo
- **รหัสผ่าน:** EnumeratorRtSurvey
- **บทบาท:** ดำเนินการสำรวจในภาคสนามโดยใช้แอปมือถือ rtSurvey เก็บข้อมูล และซิงค์กับ rtSurvey Cloud

### นักวิเคราะห์ข้อมูลสาธิต
- **ชื่อผู้ใช้:** analyst_demo
- **รหัสผ่าน:** AnalystRtSurvey
- **บทบาท:** วิเคราะห์ข้อมูลที่เก็บรวบรวม สร้างรายงาน และผสานรวมกับเครื่องมือวิเคราะห์ภายนอก เช่น Excel, Power BI, Python และ R

## วิธีใช้บัญชีสาธิต

1. **เลือกบทบาท:**
   เลือกบทบาทสาธิตที่คุณต้องการสำรวจจากรายการด้านบน

2. **เข้าสู่ระบบ:**
   ใช้ชื่อผู้ใช้และรหัสผ่านที่ให้ไว้เพื่อเข้าสู่ระบบ rtSurvey

3. **สำรวจฟีเจอร์:**
   นำทางผ่านแพลตฟอร์มเพื่อทำความเข้าใจฟังก์ชันการทำงานที่มีสำหรับบทบาทที่เลือก

4. **ข้อเสนอแนะ:**
   เราให้ความสำคัญกับความคิดเห็นของคุณ โปรดให้ข้อเสนอแนะเกี่ยวกับประสบการณ์ของคุณเพื่อช่วยให้เราปรับปรุง rtSurvey

## แนวทางการรักษาความปลอดภัยและการใช้งาน

- นี่คือบัญชีสาธิตที่ใช้ร่วมกัน โปรดอย่าป้อนข้อมูลที่ละเอียดอ่อนหรือข้อมูลส่วนบุคคลใดๆ
- บัญชีสาธิตมีการเข้าถึงแบบจำกัดเพื่อความปลอดภัยของข้อมูลและป้องกันการใช้ในทางที่ผิด
- การใช้งานบัญชีสาธิตจะถูกตรวจสอบเพื่อรักษาความสมบูรณ์ของระบบ

โดยการใช้บัญชีสาธิตเหล่านี้ คุณสามารถเข้าใจอย่างครอบคลุมว่า rtSurvey ทำงานอย่างไรสำหรับบทบาทผู้ใช้ที่แตกต่างกันในโครงการสำรวจ CAPI สำรวจว่า rtSurvey สามารถเป็นประโยชน์ต่อความต้องการเก็บข้อมูลและการวิเคราะห์ของคุณได้อย่างไรในขั้นตอนต่างๆ ของการดำเนินการสำรวจ

โมดูล **Manage Forms** ทำหน้าที่เป็นประตูหลักสำหรับจัดระเบียบเครื่องมือสำรวจและประสานงานภารกิจภาคสนาม มีการควบคุมแบบละเอียดเกี่ยวกับการเข้าถึงแบบฟอร์ม การดูข้อมูล และการกำหนดเป้าหมายอุปกรณ์

![Form Management Interface](/images/manage_forms.png)

## ภาพรวม Form Family

ใต้เมนู **Form & Data Entry** ส่วน **Form Family** แสดงกริดครอบคลุมของแบบฟอร์มที่นำเข้าทั้งหมดพร้อมการควบคุมการเข้าถึงด่วนที่จำเป็น มุมมองรวมนี้ช่วยให้ผู้จัดการโครงการสามารถติดตั้งและกำหนดค่าแบบสำรวจแต่ละรายการได้อย่างรวดเร็ว

### คอลัมน์ข้อมูลสำคัญและตัวเลือกการกำหนดค่า

- **Data View:** เข้าถึงบันทึกที่ส่งและตัวอย่างชุดข้อมูลโดยตรงสำหรับแต่ละแบบฟอร์ม
- **Allow Edit:** สลับเพื่อล็อกหรือปลดล็อกความสามารถสำหรับพนักงานภาคสนามในการแก้ไขข้อมูลที่ส่งแล้ว (สถานะ Active/Inactive)
- **Public Visibility:** สลับเพื่อทำให้แบบฟอร์มพร้อมใช้งานสาธารณะโดยไม่ต้องยืนยันตัวตนผู้ถามแบบสอบถาม
- **Webform's URL:** ดึงลิงก์สาธารณะเฉพาะเพื่อแชร์แบบฟอร์มเก็บข้อมูลผ่านเบราว์เซอร์ทันที
- **Override Settings:** โมดัลการกำหนดค่าขั้นสูง (เข้าถึงผ่านไอคอนฟันเฟือง) สำหรับปรับแต่งกฎ ค่า และปิดใช้งานคุณสมบัติเฉพาะสำหรับแบบฟอร์ม
- **Form Identifiers:** ดูข้อมูลเมตามาตรฐาน รวมถึงชื่อ Form Family, Family Code และ Form ID เฉพาะ
- **Geo Configuration:** การกำหนดค่าแผนที่หรือ geo-point เฉพาะที่เชื่อมโยงกับโครงสร้างแบบฟอร์ม
- **Lock Form:** คุณสมบัติเพื่อล็อกการเข้าถึงการส่งเพื่อสิ้นสุดระยะเก็บข้อมูล

## การดำเนินการและการนำทางแบบฟอร์ม

แผงควบคุมด้านบนช่วยให้การดำเนินการแบบกลุ่มและมุมมองแบบฟอร์มทางเลือก:

- **Action to Device:** เครื่องมือดรอปดาวน์ที่ทรงพลังช่วยให้ผู้จัดการโครงการกำหนดงาน ส่งแบบฟอร์มที่ตั้งเป้าหมาย หรือส่งการดำเนินการโดยตรงไปยังอุปกรณ์ภาคสนามของผู้ถามแบบสอบถามเฉพาะ
- **XLSX Form Tab:** นำทางอย่างรวดเร็วจากกริดการจัดการหลักไปยังสภาพแวดล้อมอัปโหลดสำหรับจัดการไฟล์ XLSForm ดั้งเดิมใหม่
- **Form Builder Tab:** เข้าถึงเครื่องมือในตัวสำหรับสร้างหรือแก้ไขแบบฟอร์มแบบภาพแบบไดนามิกโดยไม่ใช้ซอฟต์แวร์สเปรดชีตภายนอก

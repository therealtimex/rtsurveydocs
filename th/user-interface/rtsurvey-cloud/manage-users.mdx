โมดูล **Managing Users** (มักเรียกว่า **Manage Staff** ในเมนู Setting Up) เป็นไดเรกทอรีรวมสำหรับจัดการบัญชีทั้งหมดภายในสภาพแวดล้อม CPMS ของคุณ มีเครื่องมือที่จำเป็นสำหรับผู้ดูแลระบบโครงการในการเริ่มต้นบุคลากร กำหนดบทบาท และกำหนดระดับการเข้าถึงทางภูมิศาสตร์

![Managing Users Interface](/images/manage_users.png)

## ภาพรวมกริดผู้ใช้

อินเทอร์เฟซหลักมีกริดครอบคลุมที่แสดงสมาชิกทีมทั้งหมดที่ลงทะเบียน มุมมองนี้ช่วยให้ผู้ดูแลระบบค้นหา กรอง และตรวจสอบสถานะบัญชีได้อย่างรวดเร็ว

### คอลัมน์ข้อมูลสำคัญ

กริดมีรายละเอียดสำคัญต่อไปนี้สำหรับผู้ใช้แต่ละคน:

- **Username & Fullname:** ตัวระบุหลักสำหรับสมาชิกทีม
- **Email:** ที่อยู่อีเมลติดต่อที่เชื่อมโยงกับบัญชี
- **User Role:** ระบุสิทธิ์ระบบที่มอบให้ผู้ใช้ (เช่น Administrator, Staff, Monitor, Guest)
- **Group:** แสดงกลุ่มผู้ใช้หรือทีมเฉพาะที่สมาชิกทีมสังกัดอยู่
- **Status:** ระบุว่าบัญชีปัจจุบัน **Active** หรือ **Inactive**
- **Created Date:** timestamp เมื่อบัญชีถูกลงทะเบียน

## การดำเนินการจัดการพนักงาน

ผู้ดูแลระบบมีชุดเครื่องมือสำหรับการเริ่มต้นและบำรุงรักษาบัญชีผู้ใช้ เข้าถึงได้จากแผงควบคุมด้านบน:

- **Add Staff:** เปิดแบบฟอร์มสร้างโดยละเอียดเพื่อป้อนโปรไฟล์ผู้ใช้ใหม่ด้วยตนเอง รวมถึงบทบาท พื้นที่ที่ได้รับมอบหมาย และข้อมูลติดต่อ
- **Import Staffs:** ช่วยให้สร้างบัญชีจำนวนมากโดยการอัปโหลดสเปรดชีต Excel มีประโยชน์มากสำหรับการสร้างทีมภาคสนามขนาดใหญ่อย่างรวดเร็ว
- **Download import template:** มีเทมเพลต `.xlsx` มาตรฐานที่จำเป็นสำหรับกระบวนการนำเข้าจำนวนมาก
- **Export to Excel:** สร้างรายงานที่ดาวน์โหลดได้ซึ่งมีรายการผู้ใช้ที่กรองแล้วของกริดปัจจุบันและรายละเอียด
- **Delete:** ลบบัญชีผู้ใช้ที่เลือกออกจากระบบอย่างถาวร

## โปรไฟล์และการมอบหมายผู้ใช้

เมื่อสร้างหรือแก้ไขผู้ใช้เฉพาะ (ผ่านปุ่ม **Add Staff** หรือโดยคลิกที่ Username) ผู้ดูแลระบบสามารถกำหนดค่าโปรไฟล์โดยละเอียด:

- **ข้อมูลส่วนตัว:** ฟิลด์สำหรับวันเกิด เพศ หมายเลขประจำตัว และอวาตาร์
- **รายละเอียดติดต่อ:** หมายเลขโทรศัพท์มือถือและข้อมูลตำแหน่งโดยละเอียด (จังหวัด อำเภอ ตำบล ที่อยู่)
- **การมอบหมายระบบ:** สำคัญสำหรับความปลอดภัยของข้อมูล ผู้ดูแลระบบสามารถเชื่อมโยงผู้ใช้กับ **พื้นที่** เฉพาะและกำหนด **User Roles** ที่แม่นยำ
- **การกำหนดค่าหัวหน้างาน:** ในการตั้งค่าขั้นสูง ผู้ใช้สามารถได้รับมอบหมายรหัสการดูแลเฉพาะหรือแมปกับแท็บเล็ตเฉพาะ (อุปกรณ์)

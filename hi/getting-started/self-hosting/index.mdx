Docker Compose का उपयोग करके अपने स्वयं के बुनियादी ढाँचे पर rtCloud चलाएं। स्व-होस्टिंग आपको अपने डेटा, नेटवर्क और डिप्लॉयमेंट परिवेश का पूर्ण स्वामित्व देती है — डेटा रेसिडेंसी आवश्यकताओं, एयर-गैप्ड नेटवर्क या कस्टम बुनियादी ढाँचे की जरूरतों वाले संगठनों के लिए आदर्श।

## rtCloud स्व-होस्टिंग क्या है?

rtCloud स्व-होस्टिंग एक आधिकारिक Docker इमेज है जो पूरे rtCloud प्लेटफ़ॉर्म को एक पोर्टेबल कंटेनर स्टैक में पैकेज करती है जिसे आप किसी भी Linux सर्वर पर चला सकते हैं। स्टैक में शामिल हैं:

| सेवा | विवरण |
|---------|-------------|
| **rtCloud App** | Apache 2.4 + PHP 7.4 वेब एप्लिकेशन जिसमें अंतर्निहित बैकग्राउंड क्यू (Beanstalkd), एनालिटिक्स सर्वर (Shiny) और शेड्यूल किए गए कार्य हैं |
| **MySQL 8.0** | सभी एप्लिकेशन और सर्वेक्षण डेटा के लिए रिलेशनल डेटाबेस |
| **Keycloak** *(वैकल्पिक)* | एंटरप्राइज़ पहचान प्रबंधन के लिए एम्बेडेड Single Sign-On सर्वर |

## स्व-होस्ट कब करें

स्व-होस्टिंग सही विकल्प है जब आप:

- **डेटा संप्रभुता** की आवश्यकता है — सभी डेटा आपके अपने बुनियादी ढाँचे के भीतर रहता है
- बाहरी क्लाउड एक्सेस के बिना **एयर-गैप्ड या प्रतिबंधित नेटवर्क** में काम करते हैं
- ऑन-प्रिमाइस स्टोरेज अनिवार्य करने वाली **अनुपालन आवश्यकताएं** (GDPR, HIPAA, सरकारी डेटा नीतियां) हैं
- **आंतरिक पहचान प्रदाता** (Active Directory, LDAP, SAML) के साथ एकीकृत करना चाहते हैं
- **संसाधन अनुकूलित** करना चाहते हैं — CPU, RAM और स्टोरेज आवंटन अपनी शर्तों पर

## आर्किटेक्चर अवलोकन

डिप्लॉयमेंट एक आंतरिक नेटवर्क पर जुड़े Docker कंटेनरों के एक सेट के रूप में चलती है:

```
┌────────────────────────────────────────┐
│            rtcloud-app                 │
│  Apache 2.4 (port 80)                  │
│  PHP 7.4 application                   │
│  Beanstalkd queue (internal)           │
│  Shiny Server (port 3838)              │
│  Cron scheduler                        │
└─────────────────┬──────────────────────┘
                  │ rtcloud-net (bridge)
┌─────────────────▼──────────────────────┐
│            rtcloud-mysql               │
│  MySQL 8.0 (port 3306, internal only)  │
└────────────────────────────────────────┘
```

जब SSO सक्षम हो, एक तीसरा कंटेनर साथ में चलता है:

```
┌─────────────────────────────────────────┐
│            rtcloud-keycloak             │
│  Keycloak (port 8080, internal only)    │
│  Admin UI (port 9000, internal only)    │
└─────────────────────────────────────────┘
```

सभी कंटेनर एक अलग Docker ब्रिज नेटवर्क पर संचार करते हैं। केवल वेब एप्लिकेशन पोर्ट और (वैकल्पिक रूप से) Shiny एनालिटिक्स पोर्ट होस्ट के सामने उजागर होते हैं।

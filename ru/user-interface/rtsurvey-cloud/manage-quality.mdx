Модуль **Управление качеством** (доступен через панель управления) предоставляет аналитику в реальном времени и пространственные визуализации для мониторинга хода сбора данных и эффективности интервьюеров. Он предлагает менеджерам проектов разделённый интерфейс для быстрого переключения между отдельными анкетами и настраиваемыми аналитическими отчётами.

![Панель управления качеством](/images/manage_quality.png)

## Обзор панели управления

Панель управления качеством разделена на две основные вкладки навигации: **Формы** и **Отчёты**. Это боковое меню позволяет пользователям эффективно выполнять поиск и выбирать конкретный набор данных или отчёт для анализа.

### Анализ форм

При выборе конкретной формы из списка панель управления предоставляет несколько встроенных инструментов визуализации для отслеживания качества и частоты отправок:

- **Количество по времени начала:** Столбчатая диаграмма, визуализирующая частоту инициированных интервью во времени.
- **Количество по времени окончания:** Столбчатая диаграмма, показывающая время завершения интервью.
- **Количество по дате отправки:** Отслеживает ежедневный объём данных, синхронизированных с сервером.
- **Количество по имени пользователя:** Столбчатая диаграмма, определяющая наиболее эффективных интервьюеров на основе общего числа их отправок.
- **Карта интервью:** Географическая диаграмма рассеяния (на основе Leaflet), отображающая GPS-координаты мест каждой отправки, позволяющая менеджерам верифицировать расположение полевых работ.

### Пользовательские отчёты

Вкладка **Отчёты** предоставляет доступ к предварительно настроенным аналитическим проектам R Markdown и другой настраиваемой статистике. После выбора отчёта основная область просмотра динамически загружает сгенерированный анализ через встроенный просмотрщик, обеспечивая более глубокую статистическую проверку собранных данных.

## Поиск и фильтрация

Строка быстрого поиска доступна над списком боковой панели, позволяя пользователям быстро находить конкретные формы или отчёты по имени.

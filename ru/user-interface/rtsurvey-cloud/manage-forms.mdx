Модуль **Управление формами** служит основным шлюзом для организации инструментов опросов и координации полевых задач. Он обеспечивает детальный контроль над доступностью форм, просмотром данных и таргетингом устройств.

![Интерфейс управления формами](/images/manage_forms.png)

## Обзор семейства форм

В меню **Ввод форм и данных** раздел **Семейство форм** отображает полную сетку всех импортированных форм вместе с основными элементами управления быстрым доступом. Этот централизованный вид позволяет менеджерам проектов быстро развёртывать и настраивать отдельные опросы.

### Ключевые столбцы данных и параметры конфигурации

- **Просмотр данных:** Прямой доступ к отправленным записям и предпросмотрам наборов данных для каждой формы.
- **Разрешить редактирование:** Быстрый переключатель для блокировки или разблокировки возможности редактирования отправленных данных полевыми сотрудниками (статусы «Активно»/«Неактивно»).
- **Публичная видимость:** Переключатель для открытия формы без требования аутентификации интервьюера.
- **URL веб-формы:** Мгновенное получение уникальной публичной ссылки для обмена формами сбора данных через браузер.
- **Переопределение настроек:** Расширенное модальное окно конфигурации (доступ через значок шестерёнки) для настройки правил, значений и отключения отдельных функций формы.
- **Идентификаторы формы:** Просмотр стандартных метаданных, включая название семейства форм, код семейства и уникальный идентификатор формы.
- **Конфигурация геопозиции:** Конкретные конфигурации картографирования или гео-точки, связанные со структурой формы.
- **Блокировка формы:** Функция блокировки доступа к отправкам для завершения этапа сбора данных.

## Действия с формами и навигация

Верхняя панель управления обеспечивает пакетные операции и альтернативные представления форм:

- **Действие на устройство:** Мощный инструмент выпадающего меню, позволяющий менеджерам проектов назначать задачи, отправлять целевые формы или выполнять действия непосредственно на полевых устройствах конкретных интервьюеров.
- **Вкладка XLSX Form:** Быстрый переход от основной сетки управления к среде загрузки для работы с новыми файлами XLSForm.
- **Вкладка Конструктор форм:** Доступ к встроенному инструменту для визуального создания или изменения форм без использования внешнего программного обеспечения для работы с таблицами.

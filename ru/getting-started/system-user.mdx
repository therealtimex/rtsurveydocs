# Управление системными пользователями

Модуль **Системные пользователи** (`/cpms/cpmsSystemUser/admin`) — это комплексный интерфейс управления, контролирующий, кто имеет доступ к платформе Real-Time Survey (RT-CPMS) и какие действия они могут выполнять.

![Интерфейс системных пользователей](/images/system_user.png)

## Единый подход к управлению

В RT-CPMS **Интервьюер** — это просто конкретная Роль, назначенная системному пользователю. Отдельной базы данных «Интервьюеров» не существует. Независимо от того, является ли пользователь высокоуровневым администратором, осуществляющим мониторинг через веб-портал, или полевым интервьюером, собирающим данные через мобильное приложение, — все они управляются в рамках единой унифицированной системы.

## Ключевые функции

### 1. Каталог пользователей и табличный вид
Главный интерфейс отображает постраничный список всех пользователей, подключённых к рабочему пространству. Ключевые атрибуты включают:
* **Идентификатор и название организации**: Логическая группировка пользователей по конкретным организационным структурам (например, `rta`, `partner_org`).
* **Роль**: Определяет уровень разрешений пользователя (например, `Администратор`, `Руководитель группы`, `Интервьюер`).
* **Группа**: Пространственные или логические группировки (например, конкретные районы или оперативные группы).
* **Синхронизирован**: Указывает, успешно ли учётная запись интегрирована с центральной системой единого входа (SSO).
* **Статус**: Визуальные индикаторы, подтверждающие статус учётной записи: `Активна`, `Неактивна`, `Удалена` или `Заблокирована`.

**Глобальные действия:**
* **Добавить системного пользователя**: Создание индивидуального профиля вручную.
* **Импортировать системных пользователей**: Массовая загрузка учётных записей с помощью шаблона Excel. Конфликты можно разрешать в режимах `Пропустить` или `Заменить` с прямой синхронизацией через SSO.
* **Массовое удаление**: Поддержка множественного выбора для массового удаления учётных записей.

### 2. Контроль доступа и безопасность
При создании или редактировании профиля пользователя доступны несколько критически важных полей безопасности и рабочего процесса:
* **Код пользователя**: Уникальный идентификатор, связывающий локальную учётную запись CPMS с центральным репозиторием SSO.
* **Код смены устройства**: Надёжный токен безопасности, необходимый при замене мобильного устройства для сбора данных.
* **Уровень полномочий**: Детализированная шкала приоритета/доступа от 0 (наименьший) до 20 (наибольший).
* **Переключатель супервизора**: Флажок, мгновенно повышающий стандартного пользователя до статуса менеджера.
* **Автоматизация рабочего процесса**: Опция «Автоматически одобрять запросы на редактирование», упрощающая процесс очистки и верификации данных для доверенных пользователей.

### 3. Управление кодами (автоматическая адаптация)
Функция, расположенная во вкладке «Код», управляет ссылками для регистрации и приглашениями на основе хешей, упрощая процесс адаптации для больших команд.

* **Регистрация vs. Приглашение**: Выбор между самостоятельной регистрацией пользователей по распространённой ссылке или прямым приглашением администратора.
* **Сроки действия**: Ограничение периода адаптации конкретными временными рамками.
* **Лимиты использования**: Ограничение числа пользователей, которые могут присоединиться по одному сгенерированному коду.
* **Предустановленные роли**: Пользователи, присоединяющиеся через эти коды, автоматически получают предопределённую роль и уровень полномочий, что позволяет им сразу приступить к работе без ручного вмешательства администратора.

Исследуйте rtSurvey с различных точек зрения с помощью демонстрационных учётных записей. Каждая учётная запись настроена с определёнными ролями, чтобы продемонстрировать функциональные возможности и разрешения, связанные с каждым типом пользователя в проекте CAPI-опроса.

### Демо-администратор
- **Имя пользователя:** admin_demo
- **Пароль:** AdminRtSurvey
- **Роль:** Полный доступ ко всем системным настройкам, управлению пользователями и конфигурации проектов.

### Демо-менеджер проекта
- **Имя пользователя:** pm_demo
- **Пароль:** PMRtSurvey
- **Роль:** Управление проектами, назначение задач, контроль развёртывания опросов и сбора данных.

### Демо-дизайнер опросов
- **Имя пользователя:** designer_demo
- **Пароль:** DesignerRtSurvey
- **Роль:** Разработка и тестирование опросов с помощью редактора XLSForm и визуального конструктора форм rtSurvey.

### Демо-полевой интервьюер
- **Имя пользователя:** enumerator_demo
- **Пароль:** EnumeratorRtSurvey
- **Роль:** Проведение опросов в полевых условиях с использованием мобильного приложения rtSurvey, сбор данных и синхронизация с rtSurvey Cloud.

### Демо-аналитик данных
- **Имя пользователя:** analyst_demo
- **Пароль:** AnalystRtSurvey
- **Роль:** Анализ собранных данных, формирование отчётов и интеграция с внешними инструментами анализа: Excel, Power BI, Python и R.

## Как использовать демонстрационные учётные записи

1. **Выберите роль:**
   Выберите демонстрационную роль из списка выше.

2. **Войдите в систему:**
   Используйте предоставленные имя пользователя и пароль для входа в rtSurvey.

3. **Изучите функции:**
   Перемещайтесь по платформе, чтобы понять доступные функции для выбранной роли.

4. **Обратная связь:**
   Мы ценим ваше мнение! Поделитесь отзывом о своём опыте, чтобы помочь нам улучшить rtSurvey.

## Правила безопасности и использования

- Это общие демонстрационные учётные записи. Пожалуйста, не вводите конфиденциальные или персональные данные.
- Демонстрационные учётные записи имеют ограниченный доступ для обеспечения безопасности данных и предотвращения злоупотреблений.
- Использование демонстрационных учётных записей отслеживается для поддержания целостности системы.

Используя эти демонстрационные учётные записи, вы получите исчерпывающее представление о том, как rtSurvey работает для различных ролей пользователей в проекте CAPI-опроса. Изучите, как rtSurvey может принести пользу вашим задачам по сбору и анализу данных на различных этапах реализации опроса.

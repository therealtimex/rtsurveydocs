rtSurvey позволяет создавать мощные формы и рабочие процессы для сбора необходимых данных в любом месте.
Вы можете:

1.  Создавать мощные формы, включающие фотографии, GPS-координаты, логику переходов,
    вычисления, внешние наборы данных, поддержку нескольких языков и многое другое.
2.  Собирать данные в автономном режиме с помощью мобильного приложения или веб-приложения.
    Формы и ответы синхронизируются при наличии подключения к интернету.
3.  С лёгкостью анализировать данные, загружая их в формате CSV или подключая rtSurvey
    к Excel, Power BI, Python или R для создания динамических обновляемых панелей.

Исследователи, полевые группы и другие специалисты используют rtSurvey
для сбора важных данных. Вот как начать работу.

## 1. Получите rtSurvey Cloud {#getting-started-rtCloud}

Чтобы получить rtSurvey Cloud, быстрейший и простейший способ — воспользоваться официальным управляемым хостингом
[rtSurvey Cloud](https://rtSurvey.com/#rtSurvey-cloud). Он доступен на сайте rtSurvey и построен на быстрой, надёжной и
безопасной инфраструктуре.

## 2. Загрузите XLSForm в rtCloud или создайте форму с помощью конструктора форм (бета) {#getting-started-create-form}

1.  Создайте определение формы с помощью `XLSForm <xlsform>`{.interpreted-text
    role="doc"} или попробуйте эту [форму All Widgets](https://docs.google.com/spreadsheets/d/1af_Sl8A_L8_EULbhRLHVl8OclCfco09Hq2tqb9CslwQ/edit#gid=0).
2.  `Загрузите XLSForm в rtCloud <rtCloud-forms-upload>`{.interpreted-text
    role="ref"} и опубликуйте его.

## 3. Установите приложение rtSurvey {#getting-started-get-collect}

Чтобы загрузить приложение rtSurvey, следуйте инструкциям в зависимости от вашего устройства:

### Для устройств Android:
1. Откройте [Google Play Store](https://play.google.com/store/apps/details?id=vn.rta.rtsurvey).
2. Найдите «rtSurvey» в строке поиска.
3. Нажмите на приложение с логотипом rtSurvey.
4. Нажмите кнопку «Установить», чтобы загрузить и установить приложение на устройство Android.

### Для устройств iOS:
1. Откройте [App Store](https://apps.apple.com/vn/app/rtsurvey/id1178851547) на устройстве iOS.
2. Найдите «rtSurvey» во вкладке поиска.
3. Найдите приложение с логотипом rtSurvey.
4. Нажмите кнопку «Загрузить», чтобы установить приложение на устройство iOS.

После загрузки и установки вы можете запустить приложение и начать использовать rtSurvey для проведения опросов и аналитики.

## 4. Подключите Collect к rtCloud {#getting-started-connect}

1.  `Создайте пользователя приложения <rtCloud-users-app-overview>`{.interpreted-text
    role="ref"} в rtCloud и
    `назначьте ему форму <rtCloud-projects-form-access>`{.interpreted-text
    role="ref"}.
2.  Откройте Collect, нажмите `Настроить с помощью QR-кода`{.interpreted-text
    role="guilabel"} и отсканируйте код, созданный для вашего пользователя приложения.

## 5. Заполните форму в Collect {#getting-started-fill-form}

1.  Выберите `Заполнить пустую форму`{.interpreted-text role="guilabel"} для
    заполнения формы.
2.  Данные формы будут автоматически отправлены в rtCloud после завершения.

## 6. Используйте данные в rtCloud {#getting-started-use-data}

1.  Войдите в rtCloud и просмотрите ваши данные.
2.  Загрузите данные в формате CSV или
    `визуализируйте их в Power BI <rtCloud-submissions-odata>`{.interpreted-text
    role="ref"}.

rtSurvey поддерживает интеграцию медиафайлов в опросы, позволяя дополнять анкеты изображениями, аудио и видео. Эта функция может значительно улучшить опыт респондентов и качество собираемых данных.

## Поддерживаемые типы медиафайлов

rtSurvey поддерживает следующие типы медиафайлов:
- Изображения (jpg, png, gif)
- Аудио (mp3, wav)
- Видео (mp4, webm)

## Добавление медиафайлов в опрос

Для включения медиафайлов в форму rtSurvey используйте следующие столбцы в XLSForm:

- `image`: для отображения изображений
- `audio`: для воспроизведения аудиофайлов
- `video`: для воспроизведения видеофайлов

Пример:

```
| type | name          | label         | image        | audio       | video       |
|------|---------------|---------------|--------------|-------------|-------------|
| note | media_example | Пример медиа | example.jpg  | sound.mp3   | clip.mp4    |
```

## Управление медиафайлами

### Веб-опросы
Для веб-опросов rtSurvey предоставляет интерфейс управления медиафайлами, где можно загружать и организовывать файлы. Эти файлы затем автоматически становятся доступными для использования в опросах.

### Мобильное приложение
При использовании мобильного приложения rtSurvey:
1. Поместите медиафайлы в папку `/rtSurvey/forms/[имя-формы]-media/` на вашем устройстве.
2. Укажите точное имя файла в XLSForm.

## Функции rtSurvey

### Динамическая загрузка медиафайлов
rtSurvey поддерживает динамическую загрузку медиафайлов на основе ответов опроса:

```
| type         | name      | label              | image                    |
|--------------|-----------|--------------------|--------------------------| 
| select_one species | animal | Выберите животное | ${animal}.jpg            |
```

### Медиафайлы в вариантах ответов
rtSurvey позволяет использовать медиафайлы в вариантах ответов для вопросов с выбором:

```
| type                | name    | label           | media::image |
|---------------------|---------|-----------------|--------------|
| select_one_from_file animals | Выберите животное |              |
```

В листе choices:
```
| list_name | name  | label | media::image |
|-----------|-------|-------|--------------|
| animals   | dog   | Собака| dog.jpg      |
| animals   | cat   | Кошка | cat.jpg      |
```

### Захват медиафайлов
rtSurvey расширяет XLSForm возможностями захвата медиафайлов:

```
| type  | name        | label                       |
|-------|-------------|----------------------------|
| image | photo       | Сделайте фото              |
| audio | voice_note  | Запишите голосовую заметку |
| video | video_clip  | Запишите видео             |
```

## Лучшие практики использования медиафайлов

1. **Оптимизируйте размер файлов**: большие медиафайлы могут замедлить загрузку и отправку опроса.
2. **Используйте подходящие форматы**: придерживайтесь широко поддерживаемых форматов (jpg для изображений, mp3 для аудио, mp4 для видео).
3. **Предоставляйте альтернативы**: всегда включайте текстовые альтернативы для обеспечения доступности.
4. **Тщательно тестируйте**: убедитесь, что медиафайлы корректно отображаются на всех целевых устройствах.
5. **Учитывайте офлайн-использование**: для опросов, которые могут проводиться офлайн, убедитесь, что все медиафайлы доступны локально.

## Многоязычная поддержка медиафайлов

rtSurvey поддерживает медиафайлы для конкретных языков. Используйте суффикс `::language`:

```
| type | name  | label     | image::English | image::Spanish |
|------|-------|-----------|----------------|----------------|
| note | intro | Добро пожаловать | welcome_en.jpg | welcome_es.jpg |
```

## Медиафайлы при экспорте данных

При экспорте данных из rtSurvey:
- Для веб-опросов в экспорт включаются URL медиафайлов.
- Для опросов через мобильное приложение включаются пути к файлам.

## Соображения для мобильного приложения

- Убедитесь, что на устройствах достаточно места для хранения медиафайлов в объёмных опросах.
- Мобильное приложение rtSurvey поддерживает офлайн-воспроизведение и захват медиафайлов.
- Большие медиафайлы могут влиять на производительность приложения на устройствах низкого класса.

## Известные ограничения

- Некоторые старые браузеры могут не поддерживать все форматы медиафайлов.
- Очень большие видеофайлы могут вызывать проблемы при низкой пропускной способности сети.

## Устранение проблем с медиафайлами

1. **Медиафайл не отображается**: проверьте пути и имена файлов на точность.
2. **Проблемы с воспроизведением**: убедитесь, что формат медиафайла поддерживается целевыми устройствами.
3. **Медленная загрузка**: рассмотрите возможность оптимизации размера файлов или предварительной загрузки медиафайлов.

## Расширенные функции медиафайлов

### Геотегирование
rtSurvey может автоматически добавлять геотеги к медиафайлам, захваченным в ходе опросов:

```
| type  | name        | label              | appearance |
|-------|-------------|--------------------|------------|
| image | photo       | Сделайте фото      | geotag     |
```

### Аннотации к изображениям
Разрешите респондентам аннотировать изображения:

```
| type  | name        | label                    | appearance |
|-------|-------------|--------------------------|------------|
| image | photo       | Аннотируйте изображение | annotate   |
```

Эффективно используя медиафайлы в формах rtSurvey, вы можете создавать более привлекательные, информативные и точные опросы. Помните о необходимости балансировать между преимуществами использования медиафайлов и соображениями производительности, особенно для опросов, проводимых в районах с ограниченным интернет-соединением или на устройствах низкого класса.

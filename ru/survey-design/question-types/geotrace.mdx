Тип вопроса geotrace в XLSForm и rtSurvey позволяет респондентам захватывать серию связанных точек на карте, создавая линии или пути. Эта функция особенно полезна для картографирования маршрутов, границ или линейных объектов в пространственных опросах.

## Базовая спецификация XLSForm

| type     | name        | label                           |
|----------|-------------|--------------------------------|
| geotrace | river_path  | Проследите путь реки            |

Дополнительную информацию о базовом типе вопроса geotrace см. в [спецификации XLSForm](https://xlsform.org/en/#question-types).

## Применение

Вопросы типа geotrace обычно используются для:

1. Картографирования маршрутов или путей во время полевых опросов
2. Трассировки линейных объектов, таких как дороги, реки или границы
3. Захвата протяжённости линейной инфраструктуры (например, трубопроводы, линии электропередач)
4. Записи маршрутов движения в транспортных исследованиях
5. Определения трансектов в экологических исследованиях

## Лучшие практики

1. Убедитесь, что на устройстве включены службы определения местоположения и предоставлены необходимые разрешения.
2. Предоставьте чёткие инструкции по трассировке пути и описанию включаемых объектов.
3. Рассмотрите использование спутниковых снимков или базовых карт для помощи респондентам в точной трассировке путей.
4. Учитывайте потенциальную сложность трасс и их влияние на размер и обработку данных.

## Пример использования

Ниже приведён пример использования вопроса типа geotrace в опросе:

| type     | name           | label                                       | hint                                               |
|----------|----------------|---------------------------------------------|----------------------------------------------------|
| geotrace | hiking_trail   | Проследите путь туристической тропы         | Начните у входа на тропу и завершите на вершине    |

## Расширения rtSurvey

rtSurvey может предлагать дополнительные функции для вопросов типа geotrace:

1. Интеграция с офлайн-картами для отдалённых районов
2. Параметры минимального и максимального количества точек для трека
3. Возможность редактирования или уточнения трасс после первоначального рисования
4. Поддержка автоматической трассировки через заданные интервалы при движении

## Формат данных

Данные геотрека обычно хранятся в виде строки пар координат, разделённых пробелами (аналогично geoshape, но без замыкающей точки):

```
lat1 lon1; lat2 lon2; lat3 lon3; ... latN lonN
```

Например:
```
38.253094215699576 21.756382658677467; 38.25021274773806 21.756382658677467; 38.25007793942195 21.763892843919166; 38.25290886154963 21.763935759263404
```

## Соображения для анализа

При использовании вопросов типа geotrace учитывайте:

1. Как будут визуализироваться и анализироваться географические данные (например, в программном обеспечении ГИС)
2. Потенциальную необходимость очистки или упрощения сложных трасс
3. Меры конфиденциальности и защиты данных при обработке детальных пространственных данных
4. Интеграцию с другими пространственными источниками данных для комплексного анализа

## Ограничения

- Точная трассировка путей на небольших мобильных экранах может быть затруднена.
- Сложные трассы могут требовать значительных ресурсов хранилища и вычислительной мощности.
- Непрерывное использование GPS для автоматической трассировки может быстро разрядить батарею устройства.
- С сбором детальных данных о путях могут быть связаны опасения по поводу конфиденциальности.

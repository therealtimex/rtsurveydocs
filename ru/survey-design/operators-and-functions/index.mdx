Выражения в rtSurvey записываются на подмножестве **XPath 1.0**, расширенном функциями JavaRosa/ODK и пользовательскими функциями rtSurvey. Выражения используются в столбцах `calculate`, `constraint`, `relevant`, `required` и `default` XLSForm.

## Обращение к значениям полей

Используйте `${fieldname}` для обращения к значению другого поля:

```
${age} > 18
```

Используйте `.` (одиночную точку) для обращения к **значению текущего поля** — часто применяется в выражениях `constraint`:

```
. >= 0 and . <= 100
```

Используйте `..` для обращения к родительской группе (продвинутое использование в повторениях).

## Синтаксис выражений

Выражения следуют стандартным правилам XPath:

- **Строки** должны быть заключены в одиночные кавычки: `'yes'`
- **Числа** записываются как есть: `42`, `3.14`
- **Булевы** результаты используются для `relevant`, `required` и `constraint` — любое непустое, ненулевое значение считается истинным
- Пробелы вокруг операторов игнорируются

<Warning>
Всегда используйте прямые кавычки (`'` или `"`) — никогда «умные кавычки» (типографские). Многие редакторы форматированного текста автоматически преобразуют кавычки и тем самым нарушают выражения.
</Warning>

## Быстрые примеры

| Сценарий | Выражение |
|----------|-----------|
| Показать, если возраст больше 18 | `${age} > 18` |
| Показать только если выбрано "yes" | `${consent} = 'yes'` |
| Обязательно, если другое поле не пустое | `${name} != ''` |
| Рассчитать итог | `${adults} + ${children}` |
| Объединить имя | `concat(${first_name}, ' ', ${last_name})` |
| Сегодняшняя дата | `today()` |
| Проверить, выбран ли вариант | `selected(${interests}, 'sports')` |

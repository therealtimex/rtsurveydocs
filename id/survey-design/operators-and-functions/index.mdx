Ekspresi di rtSurvey ditulis dalam subset **XPath 1.0**, diperluas dengan fungsi JavaRosa/ODK dan fungsi rtSurvey kustom. Anda menggunakan ekspresi di kolom `calculate`, `constraint`, `relevant`, `required`, dan `default` di XLSForm Anda.

## Mereferensikan nilai bidang

Gunakan `${fieldname}` untuk mereferensikan nilai bidang lain:

```
${age} > 18
```

Gunakan `.` (titik tunggal) untuk mereferensikan **nilai bidang saat ini** — umumnya digunakan dalam ekspresi `constraint`:

```
. >= 0 and . <= 100
```

Gunakan `..` untuk mereferensikan grup induk (penggunaan lanjutan dalam pengulangan).

## Sintaks ekspresi

Ekspresi mengikuti aturan XPath standar:

- **String** harus diapit dalam tanda kutip tunggal: `'yes'`
- **Angka** ditulis apa adanya: `42`, `3.14`
- Hasil **boolean** digunakan untuk `relevant`, `required`, dan `constraint` — nilai non-kosong, non-nol apa pun dianggap benar
- Spasi diabaikan di sekitar operator

<Warning>
Selalu gunakan tanda kutip lurus (`'` atau `"`) — jangan pernah menggunakan "tanda kutip pintar" (tanda kutip keriting). Editor teks kaya sering mengonversi tanda kutip secara otomatis dan akan merusak ekspresi Anda.
</Warning>

## Bagian dalam bab ini

- **[Operator](operators)** — operator perbandingan (`=`, `!=`, `>`, `<`, `>=`, `<=`) dan operator logika (`and`, `or`, `not()`)
- **[Fungsi](functions)** — fungsi string, pemilihan, angka, tanggal/waktu, boolean, geo, dan utilitas
- **[Referensi](references)** — cara mereferensikan bidang dan nilai konteks

## Contoh cepat

| Kasus penggunaan | Ekspresi |
|-----------------|---------|
| Tampilkan jika usia di atas 18 | `${age} > 18` |
| Tampilkan hanya jika "ya" dipilih | `${consent} = 'yes'` |
| Wajib jika bidang lain tidak kosong | `${name} != ''` |
| Hitung total | `${adults} + ${children}` |
| Gabungkan nama | `concat(${first_name}, ' ', ${last_name})` |
| Tanggal hari ini | `today()` |
| Periksa apakah opsi dipilih | `selected(${interests}, 'sports')` |

rtSurvey 支持在调查中集成丰富媒体，允许您用图像、音频和视频增强问卷。此功能可以显著改善受访者体验和所收集数据的质量。

## 支持的媒体类型

rtSurvey 支持以下媒体类型：
- 图像（jpg、png、gif）
- 音频（mp3、wav）
- 视频（mp4、webm）

## 向调查添加媒体

要在 rtSurvey 表单中包含媒体，请在 XLSForm 中使用以下列：

- `image`：用于显示图像
- `audio`：用于播放音频文件
- `video`：用于播放视频文件

示例：

```
| type | name          | label         | image        | audio       | video       |
|------|---------------|---------------|--------------|-------------|-------------|
| note | media_example | 媒体示例 | example.jpg  | sound.mp3   | clip.mp4    |
```

## 媒体文件管理

### 基于网页的调查
对于基于网页的调查，rtSurvey 提供媒体管理界面，您可以在其中上传和组织媒体文件。这些文件随后可自动用于您的调查。

### 移动应用
使用 rtSurvey 移动应用时：
1. 将媒体文件放在设备上的 `/rtSurvey/forms/[form-name]-media/` 文件夹中。
2. 在 XLSForm 中引用确切的文件名。

## rtSurvey 特有功能

### 动态媒体加载
rtSurvey 支持基于调查回答的媒体动态加载：

```
| type         | name      | label              | image                    |
|--------------|-----------|--------------------|--------------------------| 
| select_one species | animal | 选择一种动物 | ${animal}.jpg            |
```

### 选项中的媒体
rtSurvey 允许您在选择题的选项中使用媒体：

```
| type                | name    | label           | media::image |
|---------------------|---------|-----------------|--------------|
| select_one_from_file animals | 选择一种动物 |              |
```

在 choices 表中：
```
| list_name | name  | label | media::image |
|-----------|-------|-------|--------------|
| animals   | dog   | 狗   | dog.jpg      |
| animals   | cat   | 猫   | cat.jpg      |
```

### 媒体捕获
rtSurvey 通过媒体捕获功能扩展 XLSForm：

```
| type  | name        | label               |
|-------|-------------|---------------------|
| image | photo       | 拍照        |
| audio | voice_note  | 录制语音备注 |
| video | video_clip  | 录制视频      |
```

## 使用媒体的最佳实践

1. **优化文件大小**：大型媒体文件可能会减慢调查加载和提交速度。
2. **使用适当的格式**：坚持使用广泛支持的格式（图像用 jpg，音频用 mp3，视频用 mp4）。
3. **提供替代文案**：始终包含文本替代以确保可访问性。
4. **全面测试**：确保媒体在所有目标设备上正确显示。
5. **考虑离线使用**：对于可能在离线环境中进行的调查，确保所有媒体都可在本地获取。

## 多语言媒体支持

rtSurvey 支持特定语言的媒体。使用 `::language` 后缀：

```
| type | name  | label    | image::English | image::Spanish |
|------|-------|----------|----------------|----------------|
| note | intro | 欢迎  | welcome_en.jpg | welcome_es.jpg |
```

## 数据导出中的媒体

从 rtSurvey 导出数据时：
- 对于网页调查，媒体 URL 包含在导出中。
- 对于移动应用调查，包含文件路径。

## 移动应用注意事项

- 确保设备有足够的存储空间用于媒体密集型调查。
- rtSurvey 移动应用支持离线媒体播放和捕获。
- 大型媒体文件可能影响低端设备上的应用性能。

## 已知限制

- 某些较旧的浏览器可能不支持所有媒体格式。
- 非常大的视频文件在低带宽情况下可能会出现问题。

## 媒体问题故障排除

1. **媒体不显示**：检查文件路径和名称是否准确。
2. **播放问题**：确保媒体格式受目标设备支持。
3. **加载缓慢**：考虑优化文件大小或预加载媒体。

## 高级媒体功能

### 地理标记
rtSurvey 可以自动为调查期间捕获的媒体添加地理标记：

```
| type  | name        | label        | appearance |
|-------|-------------|--------------|------------|
| image | photo       | 拍照 | geotag     |
```

### 媒体注释
允许受访者注释图像：

```
| type  | name        | label        | appearance |
|-------|-------------|--------------|------------|
| image | photo       | 注释图像 | annotate |
```

通过在 rtSurvey 表单中有效使用媒体，您可以创建更有吸引力、更翔实、更准确的调查。请记住平衡媒体包含的好处和性能考虑因素，尤其是对于部署在互联网连接有限地区或低端设备上的调查。

rtCloud 是 rtSurvey 生态系统的强大服务器组件，旨在简化数据收集、管理和分析。作为 rtSurvey 运营的中央枢纽，rtCloud 提供全面的功能集，支持复杂的调查项目和纵向研究。

## 主要功能

### 项目管理
- 在一个地方组织调查项目的所有方面
- 在每个项目中管理用户角色、表单、分析、成果和权限

### 用户管理和安全性
- 使用基于角色的权限创建和管理用户账户
- 在每个层面确保数据安全和访问控制

### 表单管理
- 直接上传和管理 XLSForm
- 支持表单版本更新，包括小调整和结构性变更
- 为表单附加多媒体或其他数据
- 真正的表单删除能力，完全控制您的调查工具

### 数据收集和提交管理
- 与 rtSurvey 移动应用、网页应用和网页表单无缝集成
- 支持已认证用户提交和匿名公开链接提交
- 处理提交的多媒体和数据附件
- 交互式表格预览提交数据，快速获取洞察

### 高级提交工作流
- 将提交退回至用户设备进行进一步编辑或核实
- 将提交转发到其他设备，实现协作工作流和质量控制

### 纵向数据管理
- 高效处理重复测量和长期研究
- 跟踪参与者数据随时间的变化和更新

### 灵活连接
- 允许 rtSurvey 移动应用连接以下载表单和上传提交
- 支持离线数据收集，恢复连接后无缝同步

## rtCloud 的独特之处

虽然受其他数据收集平台启发，rtCloud 提供了使其与众不同的独特功能：

1. **真正的表单删除**：与某些平台不同，rtCloud 允许在需要时完全删除表单。

2. **灵活的提交工作流**：退回和转发提交的能力支持复杂的数据审查和质量控制流程。

3. **集成项目管理**：rtCloud 超越表单和数据管理，提供工具来组织调查项目的所有方面。

4. **直接 XLSForm 支持**：直接上传 XLSForm 而无需转换，简化表单创建流程。

5. **全面的权限系统**：对项目中用户访问和能力的细粒度控制。

## rtCloud 入门

开始将 rtCloud 用于您的调查项目：

1. 设置您的 rtCloud 服务器或联系 rtSurvey 获取托管解决方案。
2. 创建您的第一个项目并邀请团队成员。
3. 上传您的 XLSForm 并配置数据收集工作流。
4. 连接您的 rtSurvey 移动应用并开始收集数据。

rtCloud 让研究人员、组织和数据收集团队能够轻松、安全、灵活地管理复杂的调查项目。无论您是开展一次性调查还是多年纵向研究，rtCloud 都能提供您成功所需的工具。

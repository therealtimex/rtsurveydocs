Kolumnen `appearance` i rtSurvey låter dig anpassa den visuella presentationen och beteendet hos frågor i dina undersökningar. Den här funktionen förbättrar användarupplevelsen och kan avsevärt förbättra effektiviteten vid datainsamling. rtSurvey stöder standardattribut för XLSForm-utseende och utökar dem med ytterligare alternativ.

## rtSurvey-specifika utseendetillägg

rtSurvey utökar standardutseendealternativen med följande:

### Anpassning av tidsinmatning

För `text`-typfrågor som används för tidsinmatning:

- `appearance:` - Visar en klocka för att välja timmar och minuter
- `appearance: inline` - Visar klockan som en ikon
- `appearance: inline-1line` - Visar klockan i ett enkelradsformat
- `appearance: inline-onlyresult` - Visar klockikon som försvinner efter valet
- `appearance: inline-[FORMAT]` - Anpassar tidsformatvisningen (t.ex. `[%H:%M]`, `[%h:%M:%S]`)

### Färganpassning

rtSurvey tillåter färganpassning för olika utseenden:

- `appearance: inline colors("0099FF")` - Anpassar ikonfärgen
- `appearance: inline-1line colors("0000FF","FFFF00")` - Anpassar färger i enkelradsformat

### Rutnätslayout

rtSurvey introducerar en rutnätslayout för kompakta, tabellliknande visningar:

- `appearance: grid` - Tillämpas på grupper för att skapa en rutnätslayout

### Hopfällbara grupper

- `appearance: collapsible` - Skapar expanderbara/hopfällbara grupper

## Bästa praxis för utseende

1. **Konsekvens**: Använd utseendeattribut konsekvent i din undersökning för ett enhetligt utseende.
2. **Mobil kontra webb**: Tänk på hur utseenden renderas på olika enheter och plattformar.
3. **Prestanda**: Var försiktig med utseendeattribut som kan sakta ned formulärladdningen (t.ex. `table-list` för stora grupper).
4. **Användarupplevelse**: Välj utseenden som gör datainmatning enklare och mer intuitiv för respondenter.
5. **Testning**: Testa alltid ditt formulär på målenheter för att säkerställa att utseenden fungerar som förväntat.

## Avancerade tekniker

### Kombinera utseenden

Vissa utseendeattribut kan kombineras för mer komplexa layouter:

```
| type | name | label | appearance |
|------|------|-------|------------|
| select_one options | choice | Välj ett: | minimal compact |
```

### Dynamiska utseenden

rtSurvey tillåter dynamiska utseendeändringar baserade på formulärlogik:

```
| type | name | label | appearance | relevant |
|------|------|-------|------------|----------|
| text | time | Ange tid: | inline-[%H:%M] | ${show_time} = 'yes' |
```

## Överväganden för mobilappen

- Vissa utseenden (t.ex. `quick`, `signature`) är specifika för mobila enheter.
- Testa noggrant på både Android och iOS för att säkerställa konsekvent beteende.

## Kända begränsningar

- Komplexa utseenden kanske inte renderas identiskt på alla plattformar.
- Vissa avancerade rtSurvey-utseenden kanske inte stöds i offlineläge.

## Felsökning av utseendeproblem

1. **Utseende tillämpas inte**: Kontrollera om det finns stavfel i utseendekolumnen.
2. **Inkonsekvent rendering**: Verifiera kompatibilitet med frågans typ och plattform.
3. **Prestandaproblem**: Överväg att förenkla komplexa utseenden, särskilt för stora undersökningar.
